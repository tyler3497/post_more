# post_more — anonymous parody board

Anonymous text board (parody / demo). Like 4chan-style threading but text-only, with strict rules.

⚠️ **FICTIONAL PARODY** — all sample posts are made up. No real users.

- Anonymous posts (anon#XXXX)
- Threads + replies
- No images, no accounts, no harassment/slurs/NSFW
- Client-side demo (localStorage) — easily swapped to backend

## Run
npm install
npm run dev

## Safety
- Rule banner enforced in UI
- Text length limited, max 50 threads, 20 replies each
- No image uploads, no doxxing
