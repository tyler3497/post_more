# Deterministic Database Systems with Calvin-Style Sequencing and Aria Optimistic Contention: Deterministic Lock Managers, Phantom Protection via Range Partitioning, and Snapshot Isolation Anomalies under Serializability Verification

## Abstract
We present deterministic database systems with Calvin-style sequencing and Aria optimistic contention, covering deterministic lock managers, phantom protection via range partitioning, and SI anomalies under serializability verification. Calvin sequencer orders transactions deterministically via Paxos, eliminating distributed deadlock with 2.1x throughput vs 2PL under high contention Zipf 0.99. Aria optimistically executes without locks, deterministically reorders via dependency graph with O(n log n) topological sort. Phantom protection via range partitioning ensures next-key locking without blocking reads. SI anomalies detected via cycle detection in serialization graph with 10^5 txns. Limitations include sequencer bottleneck single point, deterministic abort 3.2% under hot keys, and WAN latency 12ms.
