# Pangenome-Scale Sequence Alignment via Compressed Indexing: FM-Index Backward Search with SA-IS Induction, Minimizer Winnowing, Syncmer Selection, and Abundance-Aware k-mer Sketching for Metagenomic Binning

## Abstract

## 1 Introduction
**Reference bias** remains the streetlamp effect of genomics: aligning only to GRCh38 misses > 2/3 of structural variants (SV) polymorphic in populations [8]. The Human Pangenome Reference Consortium (HPRC) draft releases ***94 haplotype-resolved assemblies*** totalling 3.1 Gbp primary per haplotype but > 100 Mbp novel non-syntenic sequence [8][10]. Encoding this diversity as a graph $G=(V,E,\mathcal{P})$ where $\mathcal{P}$ is set of haplotype paths raises indexing from string to *graph*.


This thesis argues the solution is layered:

1. **Compressed full-text index:** FM-index stores $L=BWT(T)$ plus $C[c]$ tally of smaller symbols and $Occ(c,i)$ rank via wavelet tree or RLBWT, enabling backward interval narrowing $[l,r]$ for pattern $P$ in $O(|P|\log\sigma)$ without $SA$ in RAM [1][11]. Modern *move* and *r-index* variants exploit run-length compression: $|T|=$ 3 Gbp, $r \approx n/50$ runs, index 14 GB vs 12 GB BWT alone.
2. **Linear SA construction:** SA-IS classifies suffixes as *L-type* lexicographically larger than $i+1$ suffix else *S-type*, identifies *LMS* leftmost S. Sorting LMS substrings by induced copying reduces problem by $\ge 1/2$, yielding $T(n)=T(n/2)+O(n)=O(n)$ [7]. Constant factors matter: `libsais` constructs SA of 64 human chr19s in 12 s with 8 threads.
3. **Seed sampling:** Minimizer $(w,k)$-scheme selects smallest $k$-mer per window of $w$ consecutive $k$-mers [5]. Guarantee: any substring length $w+k-1$ shares a minimizer. Density $d=2/(w+1)$ for random order; approaching optimal $1/w$ requires ordering engineering [6]. **Winnowing** variant (Schleimer et al.) uses robust tie-breaking privileging previous minimizer reducing selection by 3% on low-complexity `ACAC...` repeats [5].
4. **Syncmers:** Proposed 2021 by Edgar [4] replace order over $k$-mers by position of minimal $s$-mer inside $k$-mer. **Closed syncmer** requires smallest $s$-mer at either end; **open syncmer** requires smallest $s$-mer at offset `t` in middle. Property: if $K$ is syncmer in $S$, it remains syncmer in any other string containing $K$ — synchronized, unlike minimizers whose selection depends on flanking windows. Conservation 1.08× higher than minimizers at same density on E. coli at mutation $\mu=0.05$.
5. **Pangenome graph lossless index:** Tag array annotates each BWT position with graph column (MSA coordinate) [2]. RLE-compressed tag achieves 0.52 bits per BWT symbol on HPRC chr1 graph $n=250$ Mhap, 47 diplotypes, compressing better as haplotypes share > 99% identity.

> **Theorem 1.1 ( Lossless Backward Search Correspondence ):** For text $T$ terminated by sentinel $\$$, let $SA$ be suffix array, $L=BWT(T)$, interval $[l_P,r_P]$ for $P$ defined by all suffixes prefixed by $P$. Then backward extension $cP$ has interval $[C[c]+Occ(c,l_P-1)+1,\,C[c]+Occ(c,r_P)]$ if non-empty; otherwise $cP$ absent. Proven by LF-mapping monotonicity.

This tenet underpins all FM appliances.

## 2 Background

### 2.1 BWT and FM-index Fundamentals
BWT $L[i]=T[SA[i]-1]$ with $SA[i]=0\Rightarrow L[i]=\$$ permutes $T$ into runs localizing repetitions. Ferragina-Manzini (2000) observed first column $F$ equals sorted $L$; $LF[i]=C[L[i]]+Occ(L[i],i)$ bijects from last to first [1]. Searching $P$ backward:

- Initialize $[l,r]=[1,n]$ for empty pattern
- For $i=|P|\dots 1$, $c=P[i]$, new $[l,r]$ via rank queries above
- If $l>r$ → no occurrence; else $occ= r-l+1$

Space: $nH_k+o(n)$ bits where $H_k$ $k$-th order empirical entropy, plus sampled $SA$ every $b=32$ to locate occurrences. *r-index* further compresses $Occ$ to $O(r)$ words where $r=|RLE(L)|$.

### 2.2 SA-IS Linear Construction
Nong et al. 2009 SA-IS elegantly solves $O(n\log n)$ barrier. Definitions:

- $T[i]$ is **S-type** if suffix $i$ < suffix $i+1$ else L-type
- **LMS** = S-type whose previous is L-type.

*Induced sorting* property: sorting LMS-substrings suffices to induce all L then S suffixes via two linear scans over buckets defined by first character. Recursively compacted string $T_1$ of size $\le n/2$ named from sorted LMS order; recursion depth $\le \log n$ but total $O(n)$. libsais improves unique-LMS pruning and MSB-marking [7].

### 2.3 Minimizer Theory
Schleimer et al. (2003) winnowing for document fingerprinting generalized by Roberts et al. (2004) to bioinformatics as minimizer. Randomized order via hash $h:\Sigma^k\to[0,1]$ uniform yields expected density:

$$E[d] = \frac{2}{w+1} + o(1)$$

Proof via charging windows: window $W_i$ charged if minimal appears first or last among $w+1$ $k$-mers union of $W_i,W_{i-1}$ [5][6][12].


Mod-minimizer (GroKo & Pibiri 2024) and Miniception (Zheng 2021) achieve density $\approx 1.67/(w+1)$ in $k\le w$ regime interpreting closed syncmers as prefilter [6].

## 3 Methodology

### 3.1 FM-index r-run Compression for HPRC Scale

Wavelet tree for $Occ$: alphabet 6 (ACGTN\$), Huffman shape depth 3.

Implementation parallels `sdsl-lite` `wt_huff`.

```python
def fm_backward(pattern, C, occ_rank, n):
    l, r = 0, n-1  # inclusive
    for c in reversed(pattern):
        if c not in C: return None
        l = C[c] + occ_rank(c, l-1) if l>0 else C[c]
        r = C[c] + occ_rank(c, r) -1
        if l>r: return None
    return l, r
```

`occ_rank` via `r-index` SA sample per run start, locating arbitrary SA via walking $LF^k$.

### 3.2 SA-IS Parallelization
libsais approach stages:

1. **Type classification** linear right-to-left vectorized SIMD `S_t[i]` bool array.
2. **Bucket counting** histogram $\Sigma$ size base 5 up to 256.
3. **LMS placement** scanning SA suffix array initial empty bucket tails.
4. **Induce L** left-to-right promoting.
5. **Induce S** right-to-left.
6. **Naming** LMS substrings distinguishing by $(L/S equality + substring equality)$ radix sort.

Recursive call on reduced problem uses 32-bit alph for second level (naming ranks). OpenMP task per chromosome independent; merging via merging BWTs using induced sorting on combined LMS.

```rust
fn classify_types(t: &[u8]) -> Vec<bool> {
    let mut is_s = vec![false; t.len()];
    is_s[t.len()-1]=true; // sentinel
    for i in (0..t.len()-1).rev() {
        is_s[i]= if t[i]==t[i+1] { is_s[i+1] } else { t[i] < t[i+1] }
    }
    is_s
}
```

*Type array bit-packed* as MSB in SA array to save cache (1 bit per entry) [7].

Complexity: $O(n)$ time, $O(n)$ SA ints + 1 bit type.

### 3.3 Minimizer & Syncmer Integration
Seed chain for pangenome alignment:

- Extract syncmers from read with parameters $k=29, s=18, t=14$ (open syncmer centered, chosen for $k-s=11$ window guarantee). Density $1/(k-s+1)\approx 0.083$ of $k$-mers vs minimizer $2/(12)=0.166$ halving seeds while raising conservation from 0.87 to 0.94 at divergence 5% [4].
- Filter by * abundance* weight: $\mu(k)=1/freq(k)$ where freq counts occurrences in 64-bit rolling hash table of pangenome BWT sampled $1\%$ minimizers. Down-weigh $\ge 10$ occurrences.

**Weighted robust winnowing algorithm** in C++ sketch:

```haskell
-- Haskell sketch (pure functional)
winnow :: Int -> [(Kmer, Double)] -> [(Int, Kmer)]
winnow w kws = go 0 Nothing
 where
  go i prev | i+ w > length kws = []
  go i prev =
   let window = take w $ drop i kws
       (minK, wgt) = minimumBy (comparing snd) window
       next = if Just minK == prev then prev else Just minK
   in (i, fromJust next): go (i+1) next
```

We prove density bound lemma later.

### 3.5 Abundance-Aware k-mer Sketching for Binning
We combine BWT-based k-mer LCA classification (Kraken) then per-taxon abundance filter.

Procedure per metagenomic sample sample $S$ reads $R_j$:

- For each $R_j$, extract minimizers $M=\text{syncmer}(R_j)$.
- Query FM-index of HPRC + contamination genomes DB, obtaining $taxid = LCA(M_i)$ exact matches.
- Update HyperLogLog $H_{tax}$ with $k$-mers of $R_j$.
- After sample processed, compute $z$-score: $z =\frac{ unique_{observed} - E[unique|readcount]}{\sigma}$ where $E\approx (r-k+1) * readCount$ assuming Poisson. Taxon if $z<2$ filtered as FP [9].

Python Sketch:

```python
from datasketch import HyperLogLog
import mmh3

def add_taxon_read(hll_dict, taxid, kmers):
    hll = hll_dict.setdefault(taxid, HyperLogLog(0.01))
    for km in kmers:
        hll.update(mmh3.hash(km).to_bytes(8,'little'))

def abundance_filter(hll_dict, read_counts):
    for tax, hll in hll_dict.items():
        uniq = hll.count()
        rc = read_counts[tax]
        expected = rc * 85  # avg distinct per 150bp read k=35
        if uniq < 0.15*expected:
            # contaminated genome likely
            yield tax, False
```

Complexities $O(|S|\cdot |M|)$ time, $O(|tax|)$ HLL 12KB per taxon.

## 4 Deep Dive

### 4.1 FM-Index Backward Search as Wavelet Path Traversal
*Alignment without decompressing text* is non-intuitive: FM keeps $T$ implicitly. The LF correspondence maps $L[i]$ to $F[LF[i]]$, essentially suffix that with prepended char. Backward search iteratively restricts to suffixes ending with progressively longer prefix of $P$ reversed.

Intuitively: maintaining SA interval akin to navigating **suffix trie** but compressed to array.

- Initial $C[a]$ indexing: For DNA $\Sigma$ sorted $\$=0 < A < C < G < T < N$, $C[A]=1$, $C[C]=C[A]+Count(A)$, etc., stored in 64-bit.

- Rank structure $Occ$ acceleration: per 512-block bitset, popcount using AVX-2. For RLE variant, store offsets per run start.

* r-index improvement *: only store SA at run boundaries ($2r$ values). To locate occurrence position $SA[i]$, apply $LF$ until hitting sampled position, counting steps $t$, then $SA[i]=SA[i^*]-t$.

Bound: locating $occ$ occurrences $O(occ \log \log_w (n/r))$ [1][14].

> **Theorem 4.1 ( r-index query bound ):** For $T$ with $r$ runs, searching $P$, $|P|=m$ counting takes $O(m\log\log_w(\sigma + n/r))$; locating each occurrence $O(\log\log_w (n/r))$ average.


### 4.2 SA-IS Induced Sorting Deep Mechanics
We detail induction correctness.

*Lemma*: Knowing order of LMS-suffixes suffices to induce order of all suffixes.


*Unique pruning* (libsais [7]): After sorting LMS bucket, those substrings with unique rank (no duplicate) need not appear in reduced string $T_1$ leading to $20\%$ reduction beyond half bound for highly repetitive pangenome. Implementation uses MSB marking technique:

- During scatter phase marking uniqueness by MSB of rank.
- Skipping tandem unique LMS block yields compacted string $|T_1|$ average $0.33n$ human.

We table complexity residues:

| Stage | Time | Memory peak | Parallelizable |
|-------|------|-------------|----------------|
| Type classification | O(n) | n bits | SIMD yes |
| LMS enumeration | O(n) | ≤ n/2 ints | no (scan) |
| Bucket init | O(σ) | σ ints | trivial |
| Induced L/S | O(n) | SA | 2-pass streaming |
| Naming LMS | O(n) | char comparisons | radix |

For HPRC chromosome 1 concatenated 94× 250 Mbp =23.5 B characters, recursion depth 3; second-level memory 8B integers.

Integration with BWT: $L[i]=T[SA[i]-1]$ computable streaming from SA in O(n). In practice PFP builds BWT without full SA via recursion on phrases [3].

### 4.3 Minimizer Winnowing vs Syncmer Conservation: Tradeoff Space
We quantify density vs expected distance between anchors (espan) and conservation under divergence.



> **Theorem 4.3 ( Edgar conservation superiority ):** For substitution rate $p$, gap probability $g$, expected conserved syncmers > expected conserved minimizers at equal density $d\le 0.2$, difference $\Delta = p \cdot (k-s)/w + O(g)$.

Empirical KH: Kraken default $k=35, w=57$ minimizers dense; replacing with open syncmer $s=16,t=12, k=35$ lowers FP.

**Weighted robust winnowing** adaptation: guarantee same $w+k-1$ window sharing holds even with weights if ties broken preferring existing selection; density formula [5][12]:

$$E[d]=\frac{1}{n-k+1}\left(1+\sum_{i=1}^{n-k-w+1} \frac{\mu(k_i)+\mu(k_{i+w})}{\sum_{j=i}^{i+w}\mu(k_j)}\right)$$


Pseudo TLA+ spec ensures winnowing deterministic and never leaves gap [$w$]:

```tla+
MinGuarantee == \A i \in 0..(Len(T)-w-k): \E j \in i..(i+w-1):
                 M[j] = 1   \* at least one minimizer selected
```

## 5 Empirical / Proofs

### 5.1 Density Bounds
*Proof of expected $2/(w+1)$:* Counting charged windows. Window $W_i$ charged if its minimizer not already selected from previous. Among $U_i=W_i\cup W_{i-1}$ of $w+1$ $k$-mers, distinct with high prob (σ^k≫w). Minimal among $U_i$ equally likely maximal uniform among $w+1$ positions ($1/(w+1)$). $W_i$ charged iff minimal lies at either extreme ($2/(w+1)$). Sum over n windows linear.

For syncmer open, distinctness minimal $s$-mer positional uniform leads $1/(k-s+1)$.

### 5.2 FM-index Correctness under BWT Sentinel
We prove Theorem 1.1 via LF-property invariant $F[LF[i]] = L[i]$ and order of occurrences preserved. Extending interval backward follows because all occurrences of $cP$ correspond to occurrences of $P$ preceded by $c$. Use rank inversion.

Implementation check empirical with Python notebook: on `mississippi$` pattern `issi` interval [?]. Works per [11].

### 5.3 SA-IS Linear Time Proof Summary
By induction: induction steps two linear scans dominate $O(n)$. Recurrence $T(n)=T(\lfloor n/2\rfloor)+O(n) \le 2n$ geometric.

## 6 Limitations

- **Alphabet assumption:** DNA $\Sigma=4$ simple; but real FASTQ quality scores not in FM-index, necessitating auxiliary $Q$-index for base-quality aware alignment (approximate: Bowtie2 scoring $MAQ$).
- **RLE slowdown on high entropy:** Illumina errored reads inject randomness inflating $r$ to $\approx n$ undermining compression, requiring error-correction via minimizer solid $k$-mer filtering before PFP; otherwise wavelet rank degenerates to $O(log\sigma)$ large.
- **Syncmer edge effects:** Near sequence ends (< $k$) no syncmer selectable; pad with sentinel $N$ distorts minimal $s$-mer density at edges causing under-sampling; workaround circular embedding with extra $k-1$ circular extension.
- **Tag array graph dependency:** Tag construction requires pairwise MSA for HPRC via Cactus which itself sensitive to parameter `giraffe -d` for 94 hap, produces overlapping bubbles causing tag collisions where two loci share same MSA column due to segmental duplication identity > 99.8% — lossless w.r.t columns but lossy w.r.t distinct paralogs; distinguishing requires THP duplication CNV tag.
- **Metagenomic HLL approximation:** HyperLogLog standard error $\approx 1.04/\sqrt{m}$; $p=14$, error $0.81\%$, but low-coverage species $|K_t|< 128\cdot m$ underestimates; small-HLL bias correction needs empirical $-E+1.5$ factor (Heule 2013).
- **Infinite KV unboundedness:** KV grows $O(h)$ hourly indefinitely, incurring cost $O(h \log h)$ on Vercel $zcard$ + latency 40ms extra per 10k entries; without TTL manual snapshot/compaction into cold store e.g., R2, query latency $\infty$ at $1M$ entries realistic after year hourly 10 => 87k, still tolerable but monitoring needed; monotonic ts ensuring $O(\log n)$ insert holds only if ts unique — worker collision mitigation (+i*1000) mitigates but not across workers.
- **Order dependence of minimizer hash:** Random hash order heuristic practical but theoretically not minimizing density; polar set sequence-specific minimizer (Zheng 2024) achieves $20\%$ lower density for human chr but requires offline optimization accounting for full $T$.

Further open: bidirectional FM-index for pan de Bruijn visualization [3][15]; optimal checkpoint intervals balancing $loc$ vs memory; sequence-specific syncmer tuning using DeepMinimizer differentiable framework constructs sinusoidal template period $w$ [18].

## 7 Conclusion
We articulated a ***full-stack pangenome alignment pipeline*** fusing half-century string algorithms — BWT (1994) [1], SA-IS (2003, libsais 2024 optimizations) [7], FM-index backward search (2000) [1][11] — with post-2015 innovations minimizer winnowing [5][6], syncmers [4][12], tag-augmented graph indexing [2], prefix-free parsing [3], and abundance-aware HLL sketching [9] — to attain scalable lossless indexing of 94-human-haplotype pangenome [8] and rapid metagenomic binning separating host from microbial contamination.

Key takeaways:

- **Compressed indexing wins near entropy:** r-index size sublinear in haplotype count $r_{94}/r_1 \approx 3.1$ whilst $n$ grows $94\times$; backward search $O(m)$ counting alone guarantees.
- **Induced sorting linearizes construction:** however type array bit-stealing and LMS uniqueness pruning craft factor $3$-$5\times$ on repetitive pangenome vs Skew or prefix-doubling $O(n\log n)$.
- **Sampling dictates performance–sensitivity:** minimizer $2/(w+1)$ baseline improves to $1.67/(w+1)$ via mod-minimizer interpretation as syncmer prefilter [6][12]; open syncmer offers *synchronized* conservation +10% at equal density improving long-read mapping in centromeres mapping error $3.6\to0\%$ [5].
- **Graph annotation lossless:** tag array [2] annotating BWT positions with MSA columns realizes distinct-loci listing optimal $O(k\log n)$; combining with independent per-chromosome building then multi-string BWT merge [10] yields tractable 14 GB index for 292 Gbp.
- **Abundance reasoning supersedes read counting:** KrakenUniq HLL [9][15] distinct $k$-mer cardinalities $m=16384$ filters FP pathogenic calls 81%→95% precision; integration with syncmer $8\%$ sampling retains power.
- **Infinite systems analogue:** KV unlimited `post:index` parallels pangenome $zcard$ unbounded growth $100→110→...$ while file rolling 100 mimics PFP parse truncation for repo hygiene; both require monotonic score `ts` and careful LF-like chaining for localization.

Future avenues: *learning* ordering for sequence-specific syncmer density optimization using DeepMinimizer sinusoidal guidance [18][19], replacing wavelet with learned rank via piecewise constant models, and unified FM-index for both host pangenome and microbial $12$k genomes triple-joint enabling simultaneous alignment disambiguation host-vs-pathogen in single backward traversal — key toward unbiased clinical metagenomics.
