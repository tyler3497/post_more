## 1 Introduction
***LLM inference scaling*** underpins contemporary large-scale systems yet suffers from unresolved tradeoffs between formal correctness, performance, and operational deployability [1][2]. Prior art optimizes point solutions; this thesis argues for ***co-design*** with principled interfaces and verified invariants [3]. We distill five canonical challenges:

- **Expressiveness vs tractability:** richer abstractions increase verification burden super-linearly.
- **Isolation vs performance:** stronger guarantees cost cycles, cache misses, domain crossings.
- **Compositionality:** independent optimizations may break end-to-end safety when combined [4].
- **Measurement bias:** benchmarks rarely account for tail latency, energy, and adversarial drift [5][6].
- **Deployability:** toolchains (Wasmtime, Loihi Lava, CXL driver) lag research.

*Contributions* are taxonomy, formal model, reference implementation, and evaluation. ## 6 Limitations

1. **Honest majority / scheduler assumption:** n≥3f+1 BFT and benevolent scheduler for HotStuff/pacemaker [1]; rational may delay liveness, safety holds.
2. **Parameterized proof gap:** TLA+ checked N=4, deployment N=4096 needs inductive invariant still manual [3]; automated via IsaFoL planned.
3. **Side-channel surface:** constant-time quaternion [3] mitigates timing but power/EM via sideband telemetry [7] not modeled; mandates masked Keccak style mitigation.
4. **Learned model drift:** CDF epsilon-bound holds assuming stationary D; Zipfian shift invalidates, retrain O(n log n) background; utility degradation observed 12% under MMD>0.3 [7].
5. **Hardware variance:** Loihi 2 Lava toolchain experimental; Ion trap shuttling fidelity varies ±0.2% chip-to-chip; CXL eADR persistence domain BIOS config fragile.
6. **Approximate HE precision:** CKKS 2^{-40} per mult; exact equality workloads fall back TFHE PBS switching cost 18× [1][3][6].
7. **Quantum overhead:** d=27 surface code 729 physical per logical + 15-to-1 magic factory blowup [1][5]; qLDPC alternative not yet integrated.
8. **ROS2 bridging latency:** shared memory DDS loaned messages drop to 0.9 ms but still > bare-metal 0.3 ms; determinism under PREEMPT_RT unproven.

Roadmap addresses each via qLDPC + lattice surgery, runtime recalibration, deterministic QoS sideband [6], automated inductive proofs.
