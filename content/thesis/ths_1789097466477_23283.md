# Bosonic Quantum Error Correction in Superconducting Cavities: Cat Codes, Binomial Codes, and GKP Codes Beyond Break-Even

## Abstract

This thesis develops the theory and experimental state of bosonic quantum error correction (QEC) in superconducting circuit QED. Encoding a logical qubit in the infinite-dimensional Hilbert space of a single microwave oscillator enables hardware-efficient protection against photon loss, dephasing, and thermal noise. We derive the continuous-variable stabilizer formalism, state the Knill–Laflamme conditions specialized to bosonic codes, and analyze three code families — cat codes, binomial codes, and Gottesman–Kitaev–Preskill (GKP) grid codes — covering two-photon dissipation stabilization, Wigner-tomography-based characterization, bias-preserving fault-tolerant gates, and the experimental milestones at which logical lifetimes surpassed the break-even point [1][5][8].

---

## 1 Introduction

Conventional quantum error correction distributes logical information over many physical two-level systems: the surface code demands thousands of physical qubits per logical qubit at realistic error rates. Bosonic QEC takes the opposite route, exploiting the **infinite-dimensional Hilbert space of a single harmonic oscillator** — a high-quality-factor superconducting microwave cavity — to protect a logical qubit with minimal hardware [8]. In circuit QED, the oscillator couples dispersively to a transmon ancilla,

$$H_{\text{disp}} = \hbar\omega_c a^\dagger a + \hbar\omega_q |e\rangle\langle e| - \hbar\chi\, a^\dagger a\,|e\rangle\langle e|,$$

which grants photon-number-resolved measurement and universal cavity control. The dominant error channel in such a mode is **single-photon loss**, described by the Lindbladian $\mathcal{D}[\sqrt{\kappa}\,a]\rho$ with energy decay rate $\kappa$, accompanied by weaker dephasing and thermal excitation. Because this error model is so structured, codes tailored to it — rather than generic depolarizing noise — achieve break-even and beyond with a *single* ancilla [1][2][5].

The field's central milestones are well documented: the cat code first crossed the break-even point in 2016 [1], universal gate sets were demonstrated on binomial logical qubits [3], grid-state GKP correction reached break-even in 2020 [4], and real-time GKP correction with machine-learned control pushed the coherence gain to $G = 2.27 \pm 0.07$ in 2023 [5]. In 2025, concatenated repetition–cat architectures demonstrated scalable hardware-efficient logical memories [6]. This thesis unifies the formalism behind these advances.

## 2 Background

### 2.1 The error model of a superconducting cavity

A 3D aluminum cavity stores microwave photons with energy relaxation times $T_1 = 1/\kappa$ exceeding milliseconds. The quantum channel acting on the mode in time $\delta t$ is the amplitude-damping channel with Kraus operators

$$E_0 = I - \frac{\kappa\,\delta t}{2}\,a^\dagger a + O(\delta t^2), \qquad E_1 = \sqrt{\kappa\,\delta t}\;a,$$

to leading order in $\kappa\,\delta t$. Photon loss maps Fock state $|n\rangle$ to $|n-1\rangle$ with amplitude $\sqrt{n\kappa\,\delta t}$, so the error probability grows with excitation number — a fact that shapes every bosonic code design. Ancilla transmon errors (decay $\kappa_q$, dephasing $\gamma_\phi$, thermal population $n_{\text{th}}$) are the leading non-cavity error source and ultimately cap break-even gains [5].

### 2.2 Continuous-variable stabilizers

The quadrature operators $q = (a + a^\dagger)/\sqrt{2}$ and $p = (a - a^\dagger)/(i\sqrt{2})$ generate displacements $D(\beta) = \exp(\beta a^\dagger - \beta^* a)$. A **continuous-variable stabilizer code** is defined by an Abelian group of displacement operators $\{S_i\}$ whose simultaneous $+1$ eigenspace is the code space. Error detection amounts to measuring the **modular quadratures** $q \bmod \ell$ and $p \bmod \ell'$ via phase estimation with the ancilla; correctable displacements are those smaller than half the stabilizer lattice spacing. This framework subsumes all three code families studied here [7][8].

### 2.3 The Knill–Laflamme conditions for bosonic codes

For a code with projector $P$ onto the code space and correctable error set $\{E_j\}$, exact QEC requires

> **Theorem (Knill–Laflamme):** There exists a recovery channel correcting $\{E_j\}$ iff $P E_j^\dagger E_k P = \alpha_{jk} P$ for some Hermitian matrix $\alpha_{jk}$.

For bosonic codes, the natural error set is $\{I, a, a^2, \ldots, a^{L-1}\}$ (loss), $\{I, (a^\dagger a), \ldots\}$ (dephasing), or bounded displacements. Because $a$ and $a^\dagger$ are unbounded, exact satisfaction on an infinite-dimensional space is typically relaxed to **approximate QEC**, quantified by the channel fidelity of the Petz or transpose recovery; the deficit from exactness is controlled by the code's mean photon number and the overlap of error subspaces [2][7].

### 2.4 Wigner tomography

State reconstruction in a cavity proceeds via **Wigner tomography**: the displaced parity $\Pi(\beta) = D(\beta)\,e^{i\pi a^\dagger a}\,D^\dagger(\beta)$ is measured through ancilla Ramsey interferometry, yielding $W(\beta) = \frac{2}{\pi}\mathrm{Tr}[\rho\,\Pi(\beta)]$. Negativity of $W$ certifies non-classicality of the codewords; logical readout fidelity is extracted from the overlap of the measured Wigner function with the ideal codewords [4][5][8].

## 3 Methodology

Our analytical methodology combines: (i) Kraus-operator expansions of the amplitude-damping channel to identify correctable error sets; (ii) the Knill–Laflamme criterion, evaluated on finite-dimensional truncations of the oscillator, to certify code parameters (distance, spacing $S$, dephasing order $N$); (iii) Lindblad master-equation simulations of dissipative stabilization, including the two-photon driven-dissipative process $\mathcal{D}[\sqrt{\kappa_{2\text{ph}}}\,(a^2 - \alpha^2)]$; (iv) Wigner-function reconstruction and logical process tomography as the experimental figures of merit; and (v) randomized-benchmarking-style logical gate analysis for fault-tolerant constructions, tracking the propagation of biased noise through bias-preserving circuits [6][7][9].

## 4 Deep Dive

### 4.1 Cat codes: parity-protected coherent-state superpositions

The two-component cat code encodes [1][8]

$$|0_L\rangle = \mathcal{N}_+\,(|\alpha\rangle + |-\alpha\rangle), \qquad |1_L\rangle = \mathcal{N}_-\,(|\alpha\rangle - |-\alpha\rangle),$$

even- and odd-parity superpositions of coherent states. A photon loss $a$ maps even parity to odd parity: measuring photon-number parity $\Pi = e^{i\pi a^\dagger a}$ detects every single loss event without revealing the logical state. Tracking the parity record is *equivalent to correcting* the state, because a loss toggles the known parity frame; this is the property that made the cat code the first bosonic code to reach break-even [1].

The four-component cat code further protects against dephasing, with codewords $|\alpha\rangle \pm i|\alpha\rangle \pm |{-}\alpha\rangle \pm i|{-}i\alpha\rangle$ arranged on a square in phase space. Loss of $k$ photons rotates the codeword by $k\pi/2$, so counting losses modulo 4 both detects loss and corrects the induced phase rotation. The four-component variant satisfies the Knill–Laflamme conditions for $\{I, a, a^2, a^3\}$ exactly in the $\alpha \to \infty$ limit and approximately for finite $\alpha$, with residual errors scaling as $e^{-2|\alpha|^2}$ [8].

### 4.2 Binomial codes: exact correction at finite photon number

Binomial codes construct finite-Fock-support codewords [2]

$$|0_L\rangle = \frac{1}{2^{N/2}}\sum_{p\ \text{even}} \sqrt{\binom{N+1}{p}}\,|p(S+1)\rangle, \qquad |1_L\rangle = \frac{1}{2^{N/2}}\sum_{p\ \text{odd}} \sqrt{\binom{N+1}{p}}\,|p(S+1)\rangle,$$

with integer parameters $(N, S)$: the code corrects $L$ photon losses, $G$ photon gains, and $D$ dephasing errors where $L + G \le N$ and $D \le S$. The spacing $S+1$ between occupied Fock states guarantees that up to $S$ dephasing applications $a^\dagger a$ produce orthogonal error words, while the binomial coefficients enforce $\langle 0_L|(a^\dagger)^j a^j|0_L\rangle = \langle 1_L|(a^\dagger)^j a^j|1_L\rangle$ for $j \le N$ — exactly the diagonal Knill–Laflamme condition for $j$ losses. The simplest instance, the **kitten code** ($N = S = 1$),

$$|0_L\rangle = \tfrac{1}{\sqrt{2}}(|0\rangle + |4\rangle), \qquad |1_L\rangle = |2\rangle,$$

corrects a single photon loss with mean photon number $\bar{n} = 2$, and was the basis of the first universal gate set demonstrated on a bosonic logical qubit [3].

|---|---|---|---|---|
| 2-cat | $\alpha \gtrsim 1.5$ | 1 loss (parity-tracked) | $\|\alpha\|^2$ | Break-even 2016 [1] |
| 4-cat | $\alpha \gtrsim 2$ | 3 losses + dephasing | $\|\alpha\|^2$ | Demonstrated [8] |
| Binomial $(N,S)$ | integers $N, S$ | $L$ loss, $G$ gain, $D$ dephasing ($L+G\le N$, $D\le S$) | $\tfrac{1}{2}(N+1)(S+1)$ | Universal gates 2019 [3] |
| GKP (square) | lattice spacing $\sqrt{\pi}$, squeezing $\Delta$ | displacements $\|u\|, \|v\| < \sqrt{\pi}/2$ | $\approx 1/(2\Delta^2)$ | Break-even 2020 [4]; $G=2.27$ in 2023 [5] |

### 4.3 GKP codes: grid states and modular error correction

The Gottesman–Kitaev–Preskill code encodes a qubit in the common $+1$ eigenspace of the commuting stabilizers [7]

$$S_q = e^{i 2\sqrt{\pi}\,q} = D(i\sqrt{2\pi}), \qquad S_p = e^{-i 2\sqrt{\pi}\,p} = D(\sqrt{2\pi}),$$

with logical operators $\bar{X} = D(\sqrt{\pi/2})$, $\bar{Z} = D(i\sqrt{\pi/2})$ translating the grid by half a lattice spacing. Ideal codewords are infinite combs of position eigenstates; physical states are finite-energy approximations obtained by applying a Gaussian envelope of width $\Delta^{-1}$ to a squeezed grid of width $\Delta$. Any displacement error $D(u + iv)$ with $|u|,|v| < \sqrt{\pi}/2$ is corrected by measuring the modular quadratures $q \bmod \sqrt{\pi}$, $p \bmod \sqrt{\pi}$ and applying the inverse shift — converting the continuous error model into a discrete syndrome [4][7].

Because photon loss acts approximately as a small random displacement (the "twirling" approximation valid for $\kappa t \ll 1$), GKP codes correct loss with an error rate that decreases **exponentially** in $1/\Delta^2$, unlike the polynomial scaling of rotation-symmetric codes at fixed $\bar{n}$. This makes GKP the asymptotically preferred single-mode code, and the optimal recovery channel for the loss channel is provably approached by GKP decoding [7]. Experimentally, echoed conditional displacement gates enabled real-time GKP stabilization: the 2020 Yale experiment reached break-even [4], and reinforcement-learned pulse optimization extended the logical lifetime to $G = 2.27 \pm 0.07$ times the best physical component in 2023 [5].

### 4.4 Two-photon dissipation and Kerr-cat stabilization

Rather than discrete syndrome measurement, a bosonic manifold can be stabilized **autonomously** by engineered dissipation [6][8]:

$$\frac{d\rho}{dt} = \mathcal{D}\big[\sqrt{\kappa_{2\text{ph}}}\,(a^2 - \alpha^2)\big]\rho, \qquad \text{or} \qquad H = -K a^{\dagger 2} a^2 + \varepsilon_2 (a^{\dagger 2} + a^2).$$

Both confine the oscillator to the cat manifold $\{|\alpha\rangle, |-\alpha\rangle\}$. The resulting **cat qubit** cannot correct loss, but its noise is strongly **biased**: bit flips ($|\alpha\rangle \leftrightarrow |-\alpha\rangle$) are suppressed as $\exp(-2|\alpha|^2)$ while phase flips grow only linearly with $|\alpha|^2$. This engineered noise asymmetry is the foundation of biased-noise fault tolerance [6][9].

### 4.5 Fault-tolerant gates and biased-noise architectures

Fault tolerance with bosonic codes exploits two complementary strategies. First, **error-transparent and error-corrected gates**: drives engineered so that a photon jump during the gate maps to a correctable error rather than a logical fault, demonstrated on binomial and cat encodings with process fidelities above the uncorrected baseline [3][9]. Second, **bias-preserving gates** on stabilized cat qubits: a controlled-NOT constructed to never convert the dominant phase-flip errors into bit flips, so that the exponential bit-flip suppression survives entangling operations [6]. Concatenating noise-biased cat qubits with an outer repetition code that corrects only the remaining phase flips yields a scalable architecture: a distance-5 repetition–cat memory with a hardware-efficient CX gate was demonstrated in 2025, showing logical error suppression with linear — rather than quadratic — physical overhead scaling [6].

The Knill–Laflamme conditions reappear at the gate level as the requirement that gate-induced error propagation remain within the correctable set — the bosonic analogue of transversality. Ancilla fault tolerance is equally critical: a single ancilla decay during parity measurement can imprint an uncorrectable error, mitigated by fault-tolerant syndrome extraction using a third ancilla level as a flag [9].

## 5 Empirical Results / Proofs

**Break-even milestones.** (i) Cat code, 2016: logical lifetime $T_L = 1.1\,T_{\text{best}}$, the first QEC system of any kind to exceed the lifetime of all its constituents [1]. (ii) GKP code, 2020: real-time grid-state correction reached break-even with logical error per cycle below the physical baseline [4]. (iii) GKP code, 2023: $G = 2.27 \pm 0.07$ coherence gain via reinforcement-learned control and tantalum transmon fabrication [5]. (iv) Repetition–cat concatenation, 2025: distance-5 logical memory with exponential suppression of logical error in code distance [6].

**Key quantitative relations.** For the binomial $(N,S)$ code, exact Knill–Laflamme satisfaction for loss order $N$ follows from the binomial-moment identity $\sum_p \binom{N+1}{p} p^{\underline{j}} = (N+1)^{\underline{j}} 2^{N+1-j}$, $j \le N$, where $p^{\underline{j}}$ is the falling factorial [2]. For GKP, the logical error probability under pure loss scales as $P_L \sim \exp(-\pi/(4\Delta^2))$ for squeezing parameter $\Delta \ll 1$ [7]. For the Kerr-cat qubit, the bit-flip rate is $\Gamma_X \propto \exp(-2|\alpha|^2)$ while $\Gamma_Z \propto |\alpha|^2\kappa$, giving a bias $\eta = \Gamma_Z/\Gamma_X$ exceeding $10^3$ at $|\alpha|^2 \approx 8$ [6][8].

**Wigner-tomography verification.** Logical state fidelity in all experiments above was extracted from displaced-parity measurements; GKP codewords exhibit the characteristic grid negativity with peak spacing $\sqrt{\pi}$ in both quadratures, and cat-code parity tracking was verified by correlating ancilla outcomes with logical Pauli-frame updates [1][4][5].

```python
import numpy as np
from math import comb, factorial

def binomial_codewords(N, S):
    """Return (zero, one) codeword amplitudes over Fock states."""
    norm = 2 ** (N / 2)
    dim = (N + 1) * (S + 1) + 1
    z = np.zeros(dim, dtype=complex)
    o = np.zeros(dim, dtype=complex)
    for p in range(N + 2):
        amp = np.sqrt(comb(N + 1, p)) / norm
        if p % 2 == 0:
            z[p * (S + 1)] = amp
        else:
            o[p * (S + 1)] = amp
    return z, o

def knill_laflamme_loss(z, o, L):
    """Check diagonal KL condition <0|E_j^dagger E_j|0> == <1|...|1> for j losses."""
    n = np.arange(len(z))
    out = []
    for j in range(L + 1):
        fall = np.array([np.prod(np.arange(k - j + 1, k + 1)) if k >= j else 0.0
                         for k in n])  # <k|(a^dagger)^j a^j|k>
        out.append((abs(z) ** 2 @ fall, abs(o) ** 2 @ fall))
    return out  # equal pairs certify exact loss correction to order L

z, o = binomial_codewords(N=1, S=1)  # kitten code
print(knill_laflamme_loss(z, o, L=1))
```

## 6 Limitations

Bosonic QEC is not a panacea. **Ancilla errors dominate**: every milestone above was ultimately limited by transmon decay, dephasing, and thermal population during syndrome extraction; fault-tolerant ancilla protocols add significant control overhead [5][9]. **Leakage out of the code space** accumulates for finite-energy GKP states, requiring periodic re-pumping of the grid envelope [4][7]. **Gate speed vs. coherence trade-off**: numerically optimized logical gates on binomial codes take microseconds, consuming a non-negligible fraction of the cavity $T_1$ budget [3][9]. **Scalability of control**: universal control of many cavity modes demands per-mode ancillas and fast beamsplitters; while high-fidelity beamsplitters now exist, a thousand-mode machine remains an engineering prospect, not a demonstration [6][8]. Finally, approximate Knill–Laflamme satisfaction means logical error rates bottom out at a floor set by $\bar{n}$ and $\Delta$; pushing below $10^{-6}$ per cycle will require concatenation with an outer qubit code, reintroducing multi-component overhead [6][7].

## 7 Conclusion

Bosonic quantum error correction has matured from a theoretical curiosity into the leading hardware-efficient path to fault tolerance in superconducting circuits. The stabilizer formalism in continuous variables, sharpened by the Knill–Laflamme conditions, yields three complementary code families: cat codes, whose parity structure made them first past break-even [1]; binomial codes, with exact finite-photon-number correction and demonstrated universal gates [2][3]; and GKP codes, whose grid stabilizers offer asymptotically optimal protection against loss and the strongest experimental gains to date [4][5][7]. Engineered two-photon dissipation converts these codes' cousins — the stabilized cat qubits — into noise-biased building blocks for concatenated, fault-tolerant architectures with bias-preserving gates [6]. The remaining challenges are engineering ones: better ancillas, faster high-fidelity control, and multi-mode integration. The theoretical foundations, by contrast, are now firmly established.
