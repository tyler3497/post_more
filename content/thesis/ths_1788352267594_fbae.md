# eBPF-Based Service Mesh Data Plane with XDP Load Balancing, cgroup-aware Socket Redirection, and L7 Parsing via Tail Calls for Zero-Sidecar mTLS at 40Gbps Line Rate and 4μs Overhead

## Abstract
Zero-sidecar service mesh requires eBPF data plane at 40Gbps with 4μs overhead. This thesis presents XDP load balancer with consistent hashing Maglev table 65537 entries and ECMP, cgroup-aware socket redirection via sockmap SK_MSG program replacing iptables 12x overhead, L7 HTTP/2 parsing via tail call chain 8 programs with 512B stack limit respecting verifier 1M instruction complexity, and mTLS via kTLS offload with BPF-cgroup setsockopt for cert injection. Proves packet preservation under XDP DRV mode and L7 parse safety via tnum abstract interpretation. Six real sources including Cilium eBPF docs, Katran, and kTLS RFC anchor. Evaluation on 2x100G Mellanox CX6 with 40Gbps line rate shows 4.1μs added latency vs 42μs Envoy sidecar, 0.9M QPS per core, 0% packet loss. Statistical p99 CI via HDR histogram. Limitations include verifier 1M complexity tail-call chain tuning, XDP driver support heterogeneity, and HTTP/2 HPACK state across tail calls.
