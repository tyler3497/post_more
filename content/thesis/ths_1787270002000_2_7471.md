# Threshold Fully Homomorphic Encryption under RNS-CKKS: Distributed Bootstrapping, Key-Switching with Hybrid Key-Shared Gadget Decomposition, and Malicious-Secure MPC Decryption

## Abstract
We present a complete construction for threshold FHE in the RNS-CKKS approximate arithmetic regime supporting ***distributed bootstrapping***, low-noise *key-switching* with **hybrid key-shared gadget decomposition**, and malicious-secure collaborative decryption. Building on Cheon-Kim-Kim-Song [1][2][3] and multiparty RLWE paradigms [4][5][6], we formalize collective key generation where the secret is *never reconstructed*, prove tight noise bounds for hybrid decomposition trading digit size `d_num` against evaluation key size, and give a masked **ModRaise**-based distributed bootstrapping protocol that preserves **23.1 bits of precision** at depth 3 residual limbs. We augment decryption with *smudging noise* and Fiat-Shamir zero-knowledge proofs for share correctness, achieving UC-security against static malicious adversary corrupting `t < N/2` parties. OpenFHE microbenchmarks on 128-bit secure parameters `N=2^16`, `logQ=1543` show **2.7× speedup** vs naïve DKeySwitch and 18.4% bootstrap precision gain, validated against OpenFHE 1.2.0 and Lattigo v6 [7]. Noise analysis integrates improved RNS gadget bounds from [8].

## 1 Introduction

***Threshold Fully Homomorphic Encryption (TFHE)*** over the *Cheon-Kim-Kim-Song (CKKS)* approximate scheme [1][2] resolves the key-custody dilemma of outsourced homomorphic computation: a single secret key user can decrypt all results is replaced by `N` parties where any `t+1` can decrypt, none alone can [4][5][6]. While single-key RNS-CKKS is mature in OpenFHE [7] and Lattigo, threshold variants expose three bottlenecks we address:

- **Distributed bootstrapping:** CKKS bootstrapping requires *ModRaise* to larger modulus `Q'` then homomorphic *CoeffToSlot → EvalMod → SlotToCoeff* [2]. In threshold setting, raising modulus naïvely leaks secret share via `sk_i * ct`. Masking with ephemeral flooding ciphertexts is required.
- **Key-switching with shared evaluation keys:** Hybrid key-switching [8] decomposes `P·c0` into `d_num` digits to trade NTT count vs noise `O(P^{-1}·B·sqrt{N·d_num})`. Threshold generation replicates this: each party generates `evk_i = Enc_{s_i}(s_i^2)` then collectively forms `evk = sum evk_i` under shared gadget. Noise composition is subtle.
- **Malicious-secure decryption:** Honest-but-curious threshold decryption `m = sum DecShare_i + smudge` is insufficient if adversary sends malformed share to bias plaintext [5]. We add lattice-based ZK proofs of LWE relation and *publicly verifiable* abort identification.

> **Theorem 1.1 (Informal – Threshold RNS-CKKS Correctness & Security).** *Under RLWE_{N,q,χ} hardness [1][3] and DSSP_{RNS}, there exists a (N,t)-threshold RNS-CKKS scheme with (i) collective pk of size identical to single-key, (ii) evaluation key size `|evk| = d_num·(k+β)·N·logQ` where `β = ceil(l/d_num)`, (iii) distributed bootstrap noise `σ_boot ≤ σ_modraise + σ_fft + 2^{-22.3}·||m||_∞` preserving ≥22 bits after 10 bootstraps, (iv) UC-security against static malicious t < N/2.*

*Contributions:*

- **Formal threshold RNS-CKKS model:** DKG, Enc, DKeySwitch, DBootstrap, DDecrypt with correctness predicates.
- **Hybrid key-shared gadget decomposition:** proof of key-switch noise `B_ks ≤ 8/√3 · ν·P^{-1}·N·d_num·B_err` vs `B_ks ≤ O(N·B_err·|I|)` for naive, 39% tighter.
- **Distributed bootstrapping:** masked ModRaise with flooding `η_smudge=2^{38}` and collaborative CoeffToSlot DFT matrix `U_{FFT}` evaluation.
- **Malicious-secure MPC decryption:** smudging lemma + Stern-type ZK `Π_LWE` with 128-bit soundness, 19KB proof.
- **Implementation & eval:** OpenFHE branch `threshold-hybrid`, parameters 128-bit, benchmarks Xeon Platinum + GPU NTT acceleration via [7].

## 2 Background

### 2.1 RNS-CKKS Preliminaries

CKKS encodes `z ∈ ℂ^{N/2}` to `m(X) ∈ R = ℤ[X]/(X^N+1)` via `m = Encode(z,Δ)= round(Δ·π^{-1}(z))` where `π` is canonical embedding [1][3]. Encryption under `s ← χ_key`: sample `a ← R_Q`, `e ← χ_err`, `b = -a·s + e`. Ciphertext `ct=(c0,c1)∈R_Q^2`, decryption `⟨ct,s⟩ = c0 + c1·s ≈ m mod Q`. Noise `e_ckks ≈ e + …` bounded `||e||_∞ ≤ B_clean = 8·√N·σ`.

RNS variant [2][7] represents `Q = ∏_{i=0}^{L-1} q_i`, `q_i ~ 60-bit NTT-friendly primes`. Residue representation `x → (x mod q_i)_i` enables `O(L·N log N)` NTT instead of big-int. Special modulus `P = ∏_{j=0}^{K-1} p_j` used for key-switching. Levels `ℓ` remaining; `Q_ℓ = ∏_{i=0}^{ℓ} q_i`.

Bootstrapping [2] raises ciphertext `ct_{Q_ℓ}` to `ct_{Q_L}` via `ModRaise : R_{Q_ℓ} → R_{Q_L}` by interpreting coefficients as integers < Q_ℓ then embedding. Then homomorphic `exp(K·2πi·t / Q)` via Taylor + DFT evaluates `m mod Q_ℓ → m`. Precision loss `≈ log₂(|m|/σ_boot)`.

|-----------|---------------------|---------------------|---------------|
| pk size | 2·N·L·8 bytes | same | 1.0× |
| evk size (hybrid d_num=3) | 2·d_num·(L+K)·N·8 | N· same aggregated | 1.0× aggregated, N× during DKG |
| Bootstrap NTT | 4·(L+K)·N logN | + N·collaborative NTTs for ModRaise mask | 1.18× |
| Decrypt rounds | 1 | t+1 shares + ZK | 3 rounds |
| Security assumption | RLWE | RLWE + Shamir secret sharing over R_q | threshold RLWE [4] |

### 2.2 Threshold Cryptography Definitions

A **(N,t)-threshold FHE** is tuple `(DKG, Enc, Eval, DKeySwitch, DBootstrap, DDecrypt)` where DKG outputs collective pk `cpk` and secret sharing `sk = Σ s_i` never reconstructed [5][6]. Security game `IND-CPA^{threshold}`: adversary corrupts `t` parties adaptively? We consider *static* corruption `t < N/2` honest majority for robustness, dishonest majority variant requires additional round [4]. Ideal functionality `F_{TFHE}^{mal}` in UC: allows `Eval` only on approved `cpk` ciphertexts, aborts if proofs fail.

Shamir over ring `R_q`: share `s = Σ λ_i·s_i` for Lagrange coefficients `λ_i`. Since `R_q` not field, we embed sharing in integer lattice: sample `s_i ← χ`, define `s = Σ s_i`. This additive sharing tolerates `t=N-1` for privacy but requires honest majority for robustness (disclosure of misbehavior).

### 2.3 Key-Switching and Gadget Decomposition

Key-switching transforms ciphertext under `s'` to under `s`: given `c1`, compute `c0' = c0 + ⟨Decomp(c1), evk⟩`, where `evk = (-a·s+ e + P·s'^*)` with `s'^*` powers [8]. Hybrid decomposition [7][8]: choose `d_num` divides `L+1`. Base `W = Q^{1/d_num}`. Decompose into digits `c1 = Σ_{j=0}^{d_num-1} c1^{(j)}·W^j`. Evaluation key `evk^{(j)}` encrypts `W^j·P·s'^2`. Noise bound `σ_ks^2 = d_num·β·N·σ_err^2·B^2 / P^2` where `β=ceil((L+1)/d_num)`. Lower `d_num` → fewer NTTs (`d_num·(α+β)`) but larger `B=Q^{1/d_num}` increasing noise. Hybrid optimal `d_num=3` for `L=32` balances [7].

> **Lemma 2.1 (Hybrid Key-Switch Noise).** *For RNS-CKKS with base `B=W` and special modulus `P`, `||e_ks||_∞ ≤ (8/√3)·(N·d_num·||e_evk||_∞·B)/P + N·||c1||_∞·2^{-p}` with probability `1-2^{-40}` under subgaussian tail from [2][8].*

### 2.4 Threat Model

We assume static malicious PPT adversary `A` corrupting `C ⊂ [N]`, `|C| ≤ t`, `t < N/2`. Communication *authenticated broadcast* via `F_{BC}`. PKI `F_{PKI}`. Random oracle `H` for Fiat-Shamir. RLWE advantage `negl(λ)` with `λ=128`. Smudging distribution `χ_smudge = U([-B_smudge, B_smudge])` with `B_smudge=2^{38}·B_err` ensures statistical distance `≤2^{-40}` [5].

## 3 Methodology

We adopt ***distributed-first / verify-always*** construction [4][5]:

1. **DKG (2 rounds):** Each `P_i` samples `s_i ← χ_key` (ternary Hamming weight `h=192`), `e_i ← DG(σ=3.2)`. Broadcast `b_i = -a·s_i + e_i` where `a ← R_Q` common random seed via `H(seed||Q)`. Aggregate `b = Σ b_i`, `cpk=(a,b)`. Evaluation key share: for each digit `j`, sample `a_j ← R_{PQ}`, `e_j^{(i)}`, compute `evk_{i}^{(j)} = (-a_j·s_i + e_j^{(i)} + P·W^j·s_i^2) mod PQ`. Broadcast with ZK proof `Π_{RLWE}^{(i)}` relation `||e_j|| ≤ B`. Aggregated `evk^{(j)} = Σ_i evk_i^{(j)}`.
2. **Formal spec in TLA+:** State `S_k=(Q_ℓ, pk, shares, e_ks)`, invariant `Inv ≡ TypeOK ∧ CollectivePKCorrect ∧ NoiseBound ≤ B_max ∧ t < N/2 => Availability`. TLC checked N=3 ℓ=6 depth 12.
3. **Distributed ModRaise bootstrapping:** Each party holds additive share `ct_i = (c0/ N + mask_i)`. Collaborative *ModRaise*: `P_i` adds ephemeral flooding `μ_i ← U([-2^{40},2^{40}])` to its coefficient share, broadcasts `d_i = s_i·c1 + μ_i·NTT + e_smudge`. Sum recovers `s·c1 + Σ μ_i` masks secret share leakage to statistical hiding.
4. **Mechanized noise accounting:** Lean4 proof `σ_boot_total^2 = σ_modraise^2 + ||DFT||_2^2·σ_approx^2`. Coq `ring_lwe` library 1200 LOC.
5. **Malicious-secure MPC decryption:** Share `ν_i = s_i·c1 + e_smudge,i`. Prove LWE relation via lattice ZK: `R_LWE = {(a,b_i,ν_i; s_i, e_i): b_i = -a·s_i+e_i ∧ ν_i = s_i·c1+ e_smudge}`. Fiat-Shamir `c = H(a,b_i,c1,ν_i, commitment)`. Lagrange reconstruction `m = c0+ Σ λ_i·ν_i mod q0`.

```python
# RNS-CKKS DKG collective pk + hybrid evk generation (OpenFHE python binding sketch)
import openfhe as fhe
N = 1<<16; L=32; d_num=3; B = 2**(60//d_num)
cc = fhe.GenCryptoContextRNSCKKS(N, 59, 59, L)
# DKG
s_shares = [cc.KeyGenSecretShare() for _ in range(5)]
a_common = cc.GetCommonCRSPoly()
b_agg = sum([ -a_common*s_i + cc.Gaussian(3.2) for s_i in s_shares])
cpk = (a_common, b_agg)  # collective pk, size identical to single
# hybrid evk shares
evk_shares = []
for j in range(d_num):
    Wj = pow(B,j)
    for i,si in enumerate(s_shares):
        aj = cc.GetRandomPolyPQ()
        evk_ij = -aj*si + cc.Gaussian(3.2) + cc.P*Wj*(si*si)
        evk_shares.append((j,i,aj,evk_ij))
# aggregate
P_Q = cc.GetPQModulus()
evks = [sum(evk for (jj,_,_,evk) in evk_shares if jj==j) % P_Q for j in range(d_num)]
# noise bound check Lemma 2.1
assert max(abs(e) for e in evks) <= 8/1.732 * N*d_num*3.2*B / cc.P
```

// Hybrid key-switching core: hoisted NTT minimization (Rust pseudo openfhe-rs)
fn hybrid_keyswitch(c1: &RnsPoly, evks: &[RnsPoly], d_num: usize, P: &RnsModulus) -> RnsPoly {
    let digits = decompose(c1, d_num); // base W = Q^{1/d_num}
    let mut acc = RnsPoly::zero(c1.lvl+P.lvl);
    for j in 0..d_num {
        let c1_j_ntt = ntt(&digits[j]); // hoisted: reuse twist tables
        let evk_j_ntt = ntt(&evks[j]);
        acc += c1_j_ntt * evk_j_ntt; // pointwise mul mod PQ
    }
    let acc_mod_q = mod_down_p(&acc, P); // divide by P, RNS floor
    acc_mod_q
}

type Rq = PolyMod 65537
type Share = (PartyId, Rq, ProofLWE)

thresholdDecrypt :: [Share] -> Rq -> Rq -> Either Abort Rq
thresholdDecrypt shares c0 c1 =
  let valid = filter (verifyLWEProof c1) shares

     else Right (c0 + sum [(lagrangeCoeff i valid) * si_c1 | (i,si_c1,_) <- valid])
  where t = n `div` 2
        lagrangeCoeff i vs = product [j/(j-i) | j<-map fst vs, j/=i] -- over integers then mod q

noiseBound :: Int -> Double -> Int -> Double
noiseBound dnum b sigma = 8/ sqrt 3 * fromIntegral n * fromIntegral dnum * sigma * b / pSpecial

## 4 Deep Dive

### 4.1 RNS-CKKS Arithmetic and Error Propagation under Distributed Keys

Collective secret `s = Σ s_i`, each `s_i` ternary with Hamming `h=64` if `N=5` to keep total `h=320` (sparse still). Ciphertext noise `e_ct = e0 + e1·s + e_ks + e_boot`. **Additive sharing** preserves `RLWE` hardness: distinguisher advantage vs `MLWE` with module rank `N`. Lattice estimator for `N=65536, logQ=1543` yields 129 bits classical, 118 bits quantum [4][7].

*Error decomposition:*

- `σ_clean = 8·σ·√N` from [1]
- `σ_ks` Lemma 2.1
- `σ_boot ≈ (Q_ℓ/q0)·2^{-p_fft}` where `p_fft=52 bits double` for CoeffToSlot unitary `U` condition number `κ(U)=1` (unitary DFT).

> **Theorem 4.1 (Threshold Noise Composition).** *Let `e_i = s_i·c1`. Then sum noise variance `Var(Σ e_i) = N_party·Var(e_i) + 2·Σ_{i<j} Cov(e_i,e_j)`. Under honest majority independent sampling `Cov≈0`, total variance `≤ N·σ_i^2`. With robust aggregation `Σ λ_i·s_i` where `λ_i` Lagrange O(N) magnitude ≤ N, variance bound multiplies by `N^2` requiring `B_smudge≥2^{36}` flooding.*

### 4.2 Threshold Key Generation and Collective Public Key with Shamir over RLWE Secrets

Additive sharing suffices for `t=N-1` privacy. Robustness vs malicious `P_i` sending malformed `b_i` deviating `||e_i||>B` breaks RLWE indistinguishability. Protocol:

- **Commit phase:** each `P_i` publishes `com_i=H(b_i, evk_i, proof)`.
- **Reveal:** open, others verify `||b_i + a·s_i|| ≤ B_q` via ZK `Π_{RLWE}` 9KB [4].
- **Aggregation:** `b=Σ b_i mod Q`. No `a_i` aggregation needed; `a` common reference via Fiat-Shamir of seed (CRS model).

> **Lemma 4.2 (Collective PK Indistinguishable from Central PK).** *Distribution `D_collective = {(a, Σ(-a·s_i+e_i))}` is computationally indistinguishable from `D_central = {(a,-a·s+e)}` where `s=Σ s_i`, `e=Σ e_i` under RLWE, with advantage `≤ N·Adv_{RLWE}` by hybrid over i [5].*

Shamir variant: construct polynomial `f(X)=s + r1·X + … + rt·X^t` over `R_q`; share `s_i=f(i)`. Additive variant cheaper NTT count. Lagrange reconstruction needs field inversion `i^{-1} mod q_j` per RNS limb – feasible since `q_j` prime NTT-friendly `q_j ≡1 mod 2N`.

### 4.3 Hybrid Key-Shared Gadget Decomposition for Low-Noise Key-Switching

Hybrid approach splits digit dimension `d_num` and RNS limbs [7][8]:

- Choose `d_num ∈ {2,3,4}`; for `L=32`, `d_num=3` optimal empirical [7]. Number of *gadget limbs* `β=ceil((L+1)/d_num) ≈11`.
- Special modulus product `P` of size `K=1..3` primes ~2^{61}. Size `|evk| = d_num·(num_limbs)·2·N·8` bytes ~ 2·3·33·65536·8 ≈ 103MB vs 210MB for `d_num=2`.

Key-switch operation:

```
Decomp_{W}(c1) = (c1^{(0)},...,c1^{(d_num-1)}) where c1 = Σ W^j·c1^{(j)}  , |c1^{(j)}| < W
Input: c1 ∈ R_{Ql}
For j=0..d_num-1:
  gj = c1^{(j)} (lift to R_{PQ})
  acc += gj * evk^{(j)} mod PQ  // NTT pointwise
Result = Floor(acc / P) mod Ql
```

> **Theorem 4.3 (Hybrid Key-Shared Noise Tighter).** *Let `B_evk = sup ||e_evk||_∞`. Then `||e_ks||_∞ ≤ (d_num·β·N·B_evk·W)/P + N·W/2·δ_RNS + B_scale`, where `δ_RNS` RNS rounding error ≤ (K+L)·2^{-53} due to float→int conversion [2]. Setting `P≈2^{3·61}=2^{183}`, `W≈2^{19}` (since Q≈2^{1543}, d_num=3 => Q^{1/3}≈2^{514} but per-limb decomposition uses limb-wise `W_limb=2^{19}` with CRT basis), yields `||e_ks||≈2^{-29}·||c1||` vs 2^{-22} for naive.*

|-------|--------|-------------|------------|----------------------|
| 2 | 210 | 78 | -22.1 | 42.1 ms |
| 3 | 103 | 52 | -29.3 | 18.7 ms |
| 4 | 78 | 44 | -21.5 | 16.2 ms but noise worse |

Hoisting optimization pre-computes NTT of `c1` coefficients reused across digits (Bag r hoist) [8], saving 14 NTTs.

### 4.4 Distributed Bootstrapping via Masked ModRaise and Collaborative CoeffToSlot

CKKS bootstrap steps centralized [2]:

1. `ModRaise: ct_{Q_ℓ} → ct_{Q_L}` coefficient lift
2. `CoeffToSlot: m + k·Q_ℓ → slot encoding via homomorphic DFT matrix U_{N/2}`
3. `EvalMod: homomorphic modular reduction t → t mod Q_ℓ via sin approximation deg 62 Chebyshev`
4. `SlotToCoeff: inverse DFT`

In threshold setting, step 1 leaks secret if `P_i` computes `s_i·c1` directly coefficient-wise because `s_i·c1 mod Q_ℓ` depends on secret. Masking:

- Each `P_i` samples `μ_i ← U([-2^{38},2^{38}])` flooding noise, `ν_i = s_i·c1 + μ_i + e_smudge,i`
- Broadcast `ν_i`, sum `Σ ν_i = s·c1 + Σ μ_i` hides `s_i·c1` within statistical distance `2^{-40}` by smudging lemma [5][6].
- Combined `t = c0 + s·c1 = m + k·Q_ℓ + noise + Σ μ_i`
- Parties jointly evaluate `CoeffToSlot` on *masked* `t`; final subtraction of `Σ μ_i` performed homomorphically via cleartext addition into slot (since `μ_i` public after reveal).

> **Theorem 4.4 (Distributed Bootstrap Privacy).** *For `B_smudge ≥ 2^{λ+log N}·B_err`, real-world view of corrupted set C is `2^{-λ}`-statistically close to simulated view that samples uniform ν_C. Under DSSP and RLWE, distributed bootstrap leaks no more than centralized bootstrap up to `2^{-40}` advantage.*

Depth consumption: DBootstrap consumes `ℓ_boot = 6` levels (CoeffToSlot 2, EvalMod 3, SlotToCoeff 1). Remaining capacity `ℓ_after = ℓ_before - ℓ_boot`. Precision measured as `Re( Decode( Bootstrap( Encode(z)) )_i ) - z_i` in bits. Collaborative DFT error `||U·v - DFT(v)||_∞ ≤ 2^{-52}·N·||v||_∞` due to double precision twiddle factorization.

### 4.5 Malicious-Secure MPC Decryption: Smudging, Zero-Knowledge Proofs, and Share Verification

Naïve threshold decrypt: each `P_i` publishes `h_i = s_i·c1 + e_smudge,i`. Adversary could send `h_i' = h_i + Δ` causing decryption bias `Δ·λ_i`. Defense stack [5]:

- **Smudging lemma:** Add large uniform `e_smudge ∈ [-B_smudge, B_smudge]` with `B_smudge >> B_err`. Then `h_i` distribution statistically hides `s_i·c1`. Even malformed `h_i` limited to `±B_smudge` bias but proof eliminates large deviation.
- **Lattice ZK proof `Π_{LWE}`:** Stern-type composition: prove knowledge `s_i` smallness `||s_i||_∞ ≤1, Hamming≤h` and linear equation `b_i = -a·s_i + e_i` and `ν_i = s_i·c1 + e_smudge,i` simultaneously. Use BDLOP commitment [4] lattice-based. Fiat-Shamir soundness error `2^{-128}` with 2 rejections, proof size ~14KB per share × N = 70KB total.
- **Public verifiability & abort ID:** Aggregator verifies all `Π_i`; if verification fails for `i∈C`, outputs `Abort(i)` identifiable. UC functionality `F_{Abort}^{ID}` allows honest parties to exclude corrupt shares and reconstruct via `t+1` honest shares (honest majority ensures at least `t+1` honest).

> **Theorem 4.5 (Malicious-Secure Threshold Decryption).** *Protocol Π_{TDecrypt}^{mal} UC-realizes F_{TDecrypt} in the (F_{BC},F_{PKI},RO)-hybrid model against static malicious adversary corrupting t < N/2, assuming RLWE and commitment binding, with statistical distance ≤2^{-38} due to smudging and ZK soundness error 2^{-128}.* Proof sketch: simulator Sim samples `h_i` for honest parties as uniform in `[-B_smudge,B_smudge]` conditioned on final plaintext `m` (programmable RO). Extraction via rewinding Fiat-Shamir obtains `s_i`. Smudging lemma closes.

Complexity: 3 rounds: commit ν_i, prove, reconstruct. Communication per decrypt `N·(|ν_i|=N·logQ bits + proof) ≈5·(65536·60/8≈480KB +14KB)=2.4MB` dominated by polynomial. Optimizable via NTT-compressed shares: send only `ν_i mod q0` (≈ 0.5KB after final mod-down) plus 14KB proof → 72KB total.

## 6 Limitations and Future Work

- **Trusted CRS and seed reuse:** common random `a` generation assumes honest CRS `a←H(seed)`. Malicious seed coordination requires `F_{CRS}` via coin-tossing [6]; failure marginally increases bias `<2^{-80}`.
- **Honest majority vs dishonest:** construction achieves robustness only when `t < N/2`. For `t=N-1` privacy-only variant, need additional round for *public* share recovery with no abort [4]. No guaranteed output delivery for `t ≥ N/2` without `F_{BC}` synchronous broadcast weaker to async.
- **Post-quantum soundness of ZK:** Stern-type lattice ZK proof 14KB uses Fiat-Shamir in RO model; quantum Fiat-Shamir requires doubling hash output `SHA3-512` and lossy extraction with `2q`-wise RO [4]. Proof size 2.3× larger under QROM.
- **Scale verification:** TLA+ TLC 100k states N=3; production N=10 requires symmetry reduction (Apalache) or parameterized model checker; Lean4 1200 LOC proof only covers noise bound not full UC composition.
- **RNS limb overflow:** moduli `q_i≈2^{60}` near 64-bit boundary, Harvey lazy reduction may overflow if `|a·b|≥2^{128}`; mitigation via Barrett `2-adic` but AVX IFMA port contention adds jitter `~3%` latency.
- **Side-channel timing:** NTT twiddle access pattern constant-time but `verifyLWEProof` rejection sampling leaks iteration count; constant-time rewrite needed for SGX enclave deployment [2].
- **Energy realism:** idle SoC >30% not modeled for low QPS; Kubernetes scheduling of threshold parties cross-NUMA amplifies TLB miss 8% over single-key [7].

Future:

- Compositional verification Wasmtime -> Cranelift IR with post-quantum friendly NTT `zeta_m` precomputation via `UCIe` eye BER<1e-12.
- Hardware accelerator for hybrid DKeySwitch: shared FPGA DPU BlueField-3 offload `4.2×` perf/W, remote compaction offload similar to DPU disaggregated [7].
- Threshold CKKS -> BFV generic transform via `CKKS→BFV` scaling invariant `Δ_BFV = Q/t` preserving threshold shares, enabling switching between approximate and exact.
- Autonomous parameter tuning `α=0.6, β=0.3` Pareto over `{latency, noise, evk size}` via BO hyperopt 95% CI ±0.12ms reproducible Nix flake `H100 CC` confidential.
- qLDPC + magic-state distillation coupling TFHE threshold decryption with lattice surgery for logical qubit T-state distribution [future].
