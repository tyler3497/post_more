# Unifying Circuit PSI and Homomorphic Encryption PSI: A Comparative Architecture for BFV, CKKS, and OT Extension Protocols

## Abstract
Private Set Intersection (PSI) has evolved from Diffie-Hellman primitives to a diverse ecosystem spanning OT-extension, garbled circuits, and homomorphic encryption. This thesis dissects the convergence of three dominant paradigms: OT-extension-based PSI using Oblivious PRF and Oblivious Key-Value Stores, BFV-based leveled homomorphic PSI via oblivious polynomial evaluation, and CKKS-based approximate PSI for encrypted analytics. We formalize circuit PSI as the generalization that produces secret-shared intersection for arbitrary post-processing, analyze cuckoo and permutation-based hashing optimizations reducing comparison complexity from O(n²) to O(n log n / log log n), and quantify the tradeoffs between communication-optimal Spot-Low and computation-optimal KKRT.

---

## 1. Introduction

Private Set Intersection allows two parties, a sender holding set $Y$ with $|Y|=N$ and receiver holding $X$ with $|X|=n$, to learn $X \cap Y$ and nothing else. Formalized by Freedman-Nissim-Pinkas in 2004, PSI is now infrastructure: private contact discovery, ad conversion measurement, breach alert, and federated health linkage all reduce to PSI with payload.

> The central research question has shifted from *can we compute intersection privately?* to *what can we compute after intersection, at launch scale, under what trust model?*

Three lineages dominate:

- **OT-extension PSI:** IKNP03 → Pinkas-Schneider-Zohner 2014 → KKRT16 → CM20 → VOLE-PSI (Raghuraman-Rindal 2022)
- **FHE-PSI:** Freedman FHE → Chen-Laine-Rindal 2017 (CLR17) BFV → Cong et al. 2021 labelled PSI → Hu-Dai 2023 threshold BFV
- **Circuit PSI:** Huang-Katz-Evans 2012 sort-compare-shuffle → Pinkas-Schneider-Segev-Zohner Phasing 2015 → Bienstock et al. USENIX 23 → van Baarsen-Stevens 2024 amortized circuit PSI

This thesis unifies them under the lens of **circuit PSI** $\mathcal{F}_{cPSI}$ where output is secret-shared bit $b_i = [x_i \in Y]$ rather than revealed intersection, enabling $z = f(X \cap Y)$ for arbitrary $f$ evaluated in MPC.

## 2. Preliminaries

### 2.1 PSI Ideal Functionality

$$\mathcal{F}_{PSI}: (X,Y) \mapsto (\bot, X \cap Y) \text{ or } (X \cap Y, \bot)$$

Circuit PSI strengthens to:

$$\mathcal{F}_{cPSI}: (X,Y) \mapsto (\langle b \rangle_0, \langle b \rangle_1) \text{ where } b_i = 1 \iff x_i \in Y$$

Extensions: PSI-Cardinality ($|X \cap Y|$), PSI-Sum $(\sum_{y \in X\cap Y} v_y)$, Threshold PSI ($|X\cap Y| \ge t$), Labelled PSI $(y, label(y))$.

### 2.2 OT Extension

Base 1-out-of-2 OT of $\kappa=128$ instances is extended to $m$ OTs using only symmetric crypto:

- IKNP03: $m$ random OTs from $\kappa$ base OTs using correlation $q_j = t_j \oplus s \cdot r_j$
- ALSZ13/KOS15: optimization to $O(m \kappa)$ with security against malicious receiver
- Silent OT (Boyle et al. 2019): $O(log m)$ communication via LPN, enables billion-element PSI

OT-extension yields **random OT** → **OPRF** → PSI in 2 messages.

### 2.3 BFV and CKKS Leveled FHE

BFV (Fan-Vercauteren 2012) operates on ring $R_q = \mathbb{Z}_q[x]/(x^n+1)$, exact integer arithmetic:

$$ct = (a, a s + \Delta m + e) \mod q, \quad \Delta = \lfloor q/t \rfloor$$

CKKS (Cheon-Kim-Kim-Song 2017) supports $\mathbb{C}^{n/2}$ approximate arithmetic with rescaling:

$$\text{Decode}(\text{Encode}(z) \cdot \text{Encode}(z')) \approx z \odot z' + \text{small error}$$

Both support SIMD packing of $n$ slots, crucial for hash-bin batched PSI. BFV preferred for exact membership; CKKS for analytics after intersection (dot product, ML inference on labels) with 40-60 bits precision.

### 2.4 Hashing Reduction

Naive circuit requires $O(n N)$ comparisons. Hashing to $\beta = 1.2 n$ bins via cuckoo hashing reduces to $O(n \log n / \log \log n)$:

```python
# Permutation-based hashing (Phasing [PSSZ15])
def phasing_insert(x):
    bin = H1(x) # or H2(x) for cuckoo
    tag = x_{high} xor bin # store only short tag
    stash for cuckoo failure O(1)
```

PSSZ15 proves tag length $\lambda + \log n$ suffices for $2^{-\lambda}$ failure. Recent vector-OLE PSI [RR22] reduces $k$ hash evaluations to 2 using Cuckoo + Simple hashing hybrid.

## 3. OT-Extension-Based PSI

### 3.1 KKRT16 and Its Successors

KKRT16 BATched OPRF construction:

- Receiver cuckoo-hashes $X$ into $B$ bins, each 1 item
- Sender simple-hashes $Y$ into same bins, up to $O(log n / log log n)$ per bin
- For each bin, parties run OPRF $F_k(x) = H(k, x)$ where $k$ from OT-extension: receiver learns $F_k(x_i)$, sender learns $F_k(y_j)$
- Intersection iff tags equal

Complexity: $O(n)$ OTs, communication $O(n \kappa)$. Semi-honest security from random oracle on $H$.

**Improvements:**

- CM20 (Crypto 2020): lightweight OPRF using 2-round OT + OKVS with 30% less comm but 3x slower in LAN – balanced for Internet.
- Efficient OPRF via OT + OKVS (AsiaCCS 2025): overcomes cuckoo uncertainty by programming OKVS, 22-41% faster than KKRT, 5.8% less comm than CM.
- VOLE-based OPPRF (Rindal et al. 2021): reduces base OT to VOLE correlation, 3x LAN speedup over KKRT, 1.7-2.4x over OPPRF.

*Fig 1: Modern OT-extension PSI pipeline. Base OTs → IKNP/KOS extension → Random OTs → BaRK-OPRF → OKVS-programmed table → binwise intersection.*

### 3.2 Security Against Malicious Adversaries

RR16 upgrade: add coin-toss and checks that sender's OPRF programming consistent across bins. Cost ~ 2x. Authenticated PSI [ArXiv 2506.04647] adds Merkle inclusion proofs:

- Achieves $O(n \lambda + n \log n)$ comm aligning with unauthenticated best-known
- Multiparty $O(n \kappa + n \log n)$ with verification of insertion

Threat model transition from semi-honest to malicious is required for ad conversion where platform may inject fake impressions.

## 4. BFV-Based Homomorphic PSI

### 4.1 Polynomial Encoding Paradigm (CLR17 / FNP04)

Sender encodes $Y$ as coefficients of polynomial:

$$P_Y(z) = \prod_{y \in Y} (z - y) \in R_t$$

Receiver encrypts each $x_i$ under BFV and sends $Enc(x_i)$. Sender homomorphically evaluates $r_i \cdot P_Y(x_i) + m_i$ where $r_i$ random non-zero mask and $m_i$ optional payload. If $x_i \in Y$, $P_Y(x_i)=0$ → receiver decrypts $m_i$ else random.

Leveled BFV constraints:
- Depth $\approx \log N$ multiplications → noise $O(B^t N)$; modulus chain $q_0 > q_1 > q_2$ with $n=8192$, $log q ~ 200$ for $N=2^{20}$
- SIMD packing: pack $n$ polynomial slots per ciphertext, amortizing 8192 comparisons per homomorphic multiply
- Requires sender to rotate packed ciphertexts; windowing technique reduces rots $O(\sqrt{N})$.

Communication: receiver upload $O(n)$ ciphertexts ~ 64KB each → $n=2^{20}$ → ~64GB naive,  ~6.4GB packed; download $O(n)$. Lower bound $\Omega(min(N,n))$ proved by Hu-Dai [IACR 2023/1407].

### 4.2 Threshold PSI via BFV

Hu-Dai 2023 formalize threshold PSI:

- Compute encrypted intersection cardinality via homomorphic add of equality results
- Use non-zero-preserving mapping $\phi: \mathbb{F}^d \to \mathbb{F}$ to compress field size, reducing computation while preserving zero
- Achieves million-scale threshold in single thread ~3.8s, 1.6GB vs DH-based 1.4GB but 60× faster w/ 4 threads

Delegated PSI from HE [EPRINT 2025/868] reduces client work via Bloom filters:

- Bloom filter of sender set encrypted under multi-key FHE (MKTFHE floating)
- Cloud evaluates membership with series of secure ANDs, communication $O(\kappa)$ for client regardless of $N$
- Provinces outsourced and distributed billion-scale intersect in <1 minute, 11× over prior

Leveled reliability issue: False accepts compound with DB size into Realization Soundness Error (RSE). Uzun 2025 proves naive kernel RSE →100% at million records. CSTPSI closes gap via independent token rounds, raising per-trial bound to matching power: 2 rounds sufficient for million-scale at $10^{-6}$.

## 5. CKKS-Based Approximate PSI and Labelled Analytics

Classical PSI reveals only equality. Labeled PSI allows $f$ on associated real vectors:

$$f(X \cap Y) = \sum_{i \in inter} w_i \cdot v_i / |inter|$$

CKKS enables floating-point under encryption without decryption of identifiers.

Protocol sketch from Chen et al. 2026 (Academia):

1. Identifier PSI via BFV OKVS + FHE packing for large domain 64/128-bit handling
2. Label retrieval: CKKS ciphertexts of labels $Enc_{CKKS}(label)$ selected by matching index vector (one-hot)
3. Downstream pipeline: $Enc(label)^T \cdot W$ homomorphic matrix mul, 40-bit precision suffices for fraud model AUC loss <0.001

Speedup claimed $1.4-6.8\times$ over prior = 65 sec for 1M fraud records with downstream logistic regression.

Multi-Key CKKS (CDKS scheme Chen et al. CCS19/Kim et al. CCS23) enables multi-owner PSI analytics, but SMHE [ArXiv 2506.20101] identifies masking vulnerability leaking plaintext across parties – proposes masking $\cdot$ LWE flooding with <2× overhead.

## 6. Circuit PSI: The Unifying Abstraction

### 6.1 Why Circuit PSI Subsumes All

Ciampi-Orlandi [EPRINT 2018/105] show OT-based PSI output $\mathbf{b}$ can be kept secret-shared for combination with garbled circuits, secret sharing, HE:

- Use OPPRF to get shares $s_i^0, s_i^1$ where $s_i^0 \oplus s_i^1 = F_k(x_i)$ iff match
- Feed into generic 2PC comparator that checks $q_j = r_i$
- Garbled circuit for $S\$CS (Sort-Compare-Shuffle) PSI [HEK12] achieves $O(n \log n)$ comparisons via permutation network, 5× faster than basic SCS with Phasing

State-of-art semi-honest circuit PSI Bienstock et al. USENIX23:

- Linear comm $O(n \cdot |tag|)$ instead of $O(n \log n \cdot |tag|)$ via per-bin single comparison (OPPRF programmable to 0 on non-match)
- Bins $B = 1.27n$ Cuckoo hashed; OKVS size $m = 1.2n$

Amortized setting [CIC 2024]: multiple senders/receivers reuse same set, offline OKVS precomputation amortizes 40% of OT extension. Novel PRF with secret-shared outputs yields linear comm *and* linear comp, stronger notion of malicious receiver.

### 6.2 Performance Landscape

## 7. Evaluation Methodology or Proofs

### 7.1 Security Reduction Sketch

Theorem (OT-PSI semi-honest): Assuming KOS OT extension secure and $H$ modeled as random oracle, KKRT construction securely realizes $\mathcal{F}_{PSI}$ against semi-honest adversary.

Proof sketch: Simulator $Sim_S$ extracts $k$ from OKVS programmability, programs random outputs for non-intersecting tags. Indistinguishability from RO. Simulator $Sim_R$ uses random OT keys. Hybrids $H_0$ real, $H_1$ replace RO with programmed, $H_2$ replace early outputs with Sim – advantage negligible $O(q_{RO}/2^{\kappa})$.

BFV threshold correctness bound:

$$Pr[Dec(Enc(x) \cdot P_Y)] \neq 0 \text{ if } x \notin Y] \le \|e\|_\infty \cdot B / q < 2^{-40}$$

with $B$ noise variance from homomorphic product tree depth $d=\log N$.

### 7.2 Parameter Selection for BFV

Select $n$ s.t. $n \ge \text{security}(\lambda=128)$. For $log q = 218$, $n=8192$ gives ~128-bit (LWE estimator). Use SEAL/HElib style modulus switching:

```python
parms.poly_modulus_degree = 8192
parms.coeff_modulus = [60,40,40,60] # 200 bits
parms.plain_modulus = 536903681 # 29-bit, NTT-friendly primes
```

Throws tradeoff: large plain_modulus reduces SIMD slots but enables larger $Y$ encoding without CRT explosion.

## 8. Limitations and Open Problems

- **Unbalanced PSI:** $|Y| \gg |X|$ (big database, tiny query) – e.g., $N=10^9$, $n=10^3$. Current OT-PSI unbalanced suffers 1000x overhead. PIR-PSI [DRRT18] combines PIR + PSI: download v fixed but hidden.
- **Post-quantum OT:** IKNP/KOS reliance on symmetric crypto post-quantum secure but base OTs from DH. Replacement Kyber/McEliece OT [MDPI 2024] additive/multiplicative homomorphic properties evaluated: McEliece fastest but not homomorphically secure; Kyber secure but 10x slower. Candidate for PQ PSI.
- **CKKS HE leakage:** Approximate decryption reveals $\approx$ plaintext + small noise; recent Li-Micciancio 2021 attack extracts secret from decryption oracle. Threshold CKKS with smudging noise needed – performance penalty ~ 3x.
- **Composability of RSE:** Fuzzy PSI reduction to set-threshold kernels compounds false accepts; CSTPSI only partially solves – still requires independent token rounds, doubling upload.
- **Cloud-assisted collusion:** CMPSI [MDPI 2023] proves security against server-client collusion via MKTFHE multi-key gating operations, but assumes single server non-colluding between participants – unrealistic.

Open problem: Can we achieve linear $O(N+n)$ communication *and* computation with *malicious* security in standard model (no RO) without relying on number-theoretic groups? VOLE-PSI approaches but requires random oracle on LPN.

## 9. Conclusion

OT-extension PSI remains performance king for exact set intersection; its OPRF+OKVS abstraction yields 22-41% speedup over KKRT and integrates seamlessly into circuit PSI via OPPRF, allowing arbitrary $f$ on intersection without revealing it. BFV PSI provides threshold and cardinality guarantees with optimal lower-bound communication $\Omega(min(N,n))$, and its SIMD packing enables practical million-scale outsourced filtering despite 3-10x overhead vs OT. CKKS pushes beyond binary membership to real-valued analytics after PSI, enabling private fraud scoring in 65s and multi-key federated flows, albeit with approximate decrypted leakage requiring mitigation.

The future is hybrid: run OT-extension VOLE-PSI for fast membership, output secret-shared intersection indicators, then switch to BFV/CKKS for labeled computation – a *PSImate* architecture using the right primitive per stage. Formalizing composable reliability (RSE) across fuzzy, threshold, and labelled dimensions remains the critical step toward deployable planetary-scale PSI.
