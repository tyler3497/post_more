# Efficient Large Language Model Inference via Speculative Decoding: Medusa Heads, Eagle Drafting, Lookahead Decoding, and Jacobi Iteration Convergence Analysis

## Abstract

We present a comprehensive theoretical and systems analysis of **speculative decoding** for *large language model* (LLM) inference acceleration, unifying draft-then-verify paradigms across **Medusa**, **EAGLE**, **Lookahead**, and **SpecInfer**. Autoregressive decoding is memory-bandwidth bound, with each token requiring a full forward pass through tens of billions of parameters. Speculative decoding decouples speculation from verification by drafting $k$ future tokens with a cheap model or auxiliary heads and verifying them in parallel with the target LLM in $O(1)$ forward passes. We formalize verification as tree-structured rejection sampling preserving exact target distribution [1][2], analyze Medusa's non-autoregressive multi-head prediction with tree attention masks [2], EAGLE's feature-level autoregression that conditions draft features on target hidden states [3], and Lookahead's Jacobi iteration interpretation where decoding converges via fixed-point iteration of nonlinear system $x = f(x)$ [4]. We prove acceptance rate bounds under total variation distance, derive optimal speculative length $\gamma^*$ balancing draft cost versus target verification, and show how KV-cache reuse via PagedAttention [6] enables lossless tree verification. Our synthesis yields design principles for sub-$2\times$ latency reduction without quality degradation.

## 1 Introduction

Large language model serving has transitioned from a compute-bound training problem to a **memory-bandwidth bound** inference problem [6]. For a 70B parameter model in FP16, generating a single token requires streaming $140$ GB of weights through GPU HBM, achieving typically $5$-$10\%$ of peak FLOPs on A100/H100 systems. The *autoregressive dependency* — token $x_{t+1} \sim p(\cdot | x_{\le t})$ — precludes naive parallelization, making latency $\propto$ sequence length $L$ forward passes.

> **Theorem 1 (Autoregressive Lower Bound):** Under standard transformer decoder with causal masking, any algorithm producing samples from $p_{target}$ exactly must perform $\Omega(L)$ sequential dependencies unless auxiliary information is introduced.

Speculative decoding [1][5] breaks this barrier by introducing a **draft model** $q$ and a **verification step**:

1. **Draft:** Generate $\gamma$ candidate tokens $\tilde{x}_{t+1:t+\gamma} \sim q$
2. **Verify:** Evaluate $p(\tilde{x} | x_{\le t})$ for all candidates in *parallel* via single target forward pass with tree attention
3. **Accept:** Use rejection sampling to accept longest prefix where $q \approx p$, yielding $1$ to $\gamma+1$ tokens per target call

The key insight [1] is that verification can be *lossless*: the output distribution remains exactly $p_{target}$ despite using $q \neq p$. This is achieved via speculative sampling:

$$
\text{accept } \tilde{x} \text{ with prob } \min\left(1, \frac{p(\tilde{x})}{q(\tilde{x})}\right)
$$

and upon rejection, resample from adjusted distribution $p' = \text{norm}(\max(0, p-q))$ [1][5].

This thesis unifies four major advances:

- **Medusa [2]:** Adds $K$ extra *decoding heads* atop frozen LLM hidden state $h_t$, each predicting $t+k$ token, enabling single-model speculation without separate draft model
- **EAGLE [3]:** Argues speculation should happen at *feature level* not token level: draft autoregressively in continuous feature space $f_t$ rather than discrete tokens, reducing uncertainty
- **Lookahead Decoding [4]:** Reinterprets autoregressive decoding as solving nonlinear system via **Jacobi iteration**, where $n$-gram lookahead pool and verification branches run in parallel
- **SpecInfer [7]:** Generalizes verification to **token trees** with tree attention masks, allowing multiple draft sequences to be verified simultaneously, boosting expected accepted length

We contribute: (i) unified formalism, (ii) convergence analysis of Jacobi decoding, (iii) acceptance rate bounds, (iv) systems co-design with PagedAttention [6].

## 2 Background

### 2.1 Autoregressive Decoding and Memory Wall

Transformer decoding computes:

$$
h_t = \text{Transformer}(x_{\le t}), \quad p_t = \text{softmax}(W_{lm} h_t)
$$

Each step requires loading $W_q,W_k,W_v,W_o$, FFN weights. Arithmetic intensity $\approx$ $2 * d_{model} / \text{bytes}$ is low. **PagedAttention** [6] mitigates KV-cache fragmentation by paging KV blocks like OS virtual memory, but does not reduce sequential dependence.

*Key metrics:*

- **TPOT:** Time per output token
- **TTFT:** Time to first token
- **Acceptance rate $\alpha$:** $E[\text{# accepted}]/\gamma$
- **Speedup:** $\frac{\gamma+1}{1+\gamma c} \cdot \alpha'$ where $c = T_{draft}/T_{target}$

### 2.2 Speculative Sampling Distribution Preservation

Leviathan et al. [1] and Chen et al. [1] independently proved:

> **Theorem 2 (Lossless Speculation):** Speculative sampling algorithm outputs $x \sim p$ exactly for any $q$ with $\text{supp}(p) \subseteq \text{supp}(q)$.

*Proof sketch:* Consider token-level rejection. For any token $x$, probability of output = $q(x)\min(1,p/q) + (1-\beta) p'(x)$ where $\beta = \sum_x \min(q,p)$. Algebraic manipulation yields $p(x)$ [1][5]. Extension to sequence requires careful handling of prefix conditioning — see [5] Lemma 3.2.

This is analogous to **rejection sampling** in Monte Carlo methods but batched across sequence dimension.

### 2.3 Draft Model Families

| Family | Draft Cost $c$ | Alignment $D_{TV}(p||q)$ | Requires Training | Tree Support |
|--------|---------------|----------------------------|-------------------|--------------|
| Small LM (e.g., 7B drafting for 70B) [1] | 0.05-0.15 | Medium-high | No | Yes |
| Medusa heads [2] | 0.01-0.03 | Medium | Yes (heads only) | Yes (Cartesian) |
| EAGLE feature [3] | 0.03-0.08 | Low | Yes (draft layer) | Yes |
| Lookahead n-gram [4] | 0.0 (self) | Variable | No | Yes (pool) |
| Prompt Lookup | 0.0 | Task-dependent | No | No |

*Bold indicates* lowest overhead; *italic indicates* best alignment. Tradeoff central to design [3][7].

## 3 Methodology

Our unified methodology models speculative decoding as **tree-structured Markov decision process** with verification via single forward pass using **tree attention**.

### 3.1 Tree Verification Formalism

Let token tree $T = (V,E)$ where root = prefix $x_{\le t}$, each node $v$ corresponds to candidate token, path = sequence. SpecInfer [5] introduces tree attention mask $M$ where $M[i,j]=1$ iff $j$ is ancestor of $i$ in $T$.

Verification computes logits for all $|V|$ nodes in parallel:

```python
def verify_tree(prefix_ids, tree_nodes, tree_parent, target_model):
    # tree_nodes: List[List[int]] paths flattened
    # Build attention mask: causal within each root-to-leaf path
    input_ids = concat(prefix_ids, tree_nodes)  # [1, S]
    position_ids = compute_tree_positions(tree_parent)
    attn_mask = build_tree_mask(tree_parent)  # [S,S] lower-tri with branching
    logits = target_model(input_ids, attn_mask, position_ids)  # single forward
    p_dist = softmax(logits, dim=-1)
    # Accept via DFS in tree order
    accepted = speculative_accept(p_dist, draft_q, tree_structure)
    return accepted
```

Complexity remains $O(|V|^2 d)$ attention but $|V| \approx 10$-$64$ small versus $L \approx 2048$, so overhead negligible [7]. **PagedAttention** [6] extended to tree: share KV for prefix, branch KV pages for divergent suffixes via copy-on-write page table.

### 3.2 Draft Strategies Unified

**Medusa [2]:** Given hidden $h_t \in \mathbb{R}^d$ from frozen target, $K$ heads:

$$
p_{medusa}^{(k)}(x_{t+k} | x_{\le t}) = \text{softmax}(W_k h_t), \quad k=1..K
$$

Heads trained with $L_{Medusa} = \sum_k \lambda_k CE(p_{target}^{(k)}, p_{medusa}^{(k)}) + \lambda_0 KL$ [2]. Inference uses *Cartesian product* of top-$s_k$ per head to form tree: size $\prod s_k$ exponential, pruned to $\leq 64$ by score [2]. Tree attention ensures each node's context = original prefix + path tokens only.

**EAGLE [3]:** Critical observation: *feature uncertainty < token uncertainty*. Let $f_t$ be second-to-top layer feature. EAGLE drafts:

$$
\hat{f}_{t+1} = \text{DraftLayer}([f_t; e(x_t)]), \quad \hat{x}_{t+1} \sim LMHead(\hat{f}_{t+1})
$$

Then autoregressively: $\hat{f}_{t+2} = \text{DraftLayer}([\hat{f}_{t+1}; e(\hat{x}_{t+1})])$. Draft layer is single transformer layer (1/32 params). Training minimizes $||\hat{f} - f||_1 + CE$ [3]. Because $f$ is smoothed via residual, $D_{TV}$ reduces $30$-$45\%$ versus token draft [3].

> **Theorem 3 (EAGLE Information Gain):** $H(f_{t+1}|f_t) \leq H(x_{t+1}|x_{\le t})$ under deterministic $LMHead$, thus feature drafting has lower conditional entropy.

**Lookahead Decoding [4]:** Reinterprets decoding as solving system:

$$
x_1 = \argmax p(x_1), \; x_2 = \argmax p(x_2|x_1), \dots
$$

Define mapping $F: \mathbb{V}^L \to \mathbb{V}^L$ where $F_i(x) = \argmax p(\cdot|x_{<i})$. Fixed point $x^* = F(x^*)$ is greedy decode. **Jacobi iteration**:

$$
x^{(k+1)} = F(x^{(k)})
$$

updates all positions in parallel using previous iterate's prefix (which may be stale). [4] proves Jacobi converges in $\leq L$ steps for greedy, but intermediate iterates contain useful $n$-grams. Lookahead maintains pool of $n$-grams from Jacobi trajectory, verifies branches speculatively — no auxiliary model, $c=0$ [4].

## 4 Deep Dive

### 4.1 Medusa Heads, Tree Construction, and Typical Acceptance

Medusa's independent heads would naively assume conditional independence $p(x_{t+1},x_{t+2}|x) \approx p(x_{t+1}|x)p(x_{t+2}|x)$ which is false — strong dependence remains. Solution: *tree* enumerates combinations but verification corrects via target's joint evaluation [2].

Typical Acceptance [2] improves upon rejection sampling by using threshold $\epsilon$:

```haskell
-- Haskell specification of typical acceptance
typicalAccept :: Double -> Double -> Double -> Double -> Bool
typicalAccept p q eps temp =
  let ratio = p / q
      entropy = -p * log p
  in ratio > eps || entropy > 0.5  -- accept low-confidence but plausible
```

Empirically, Medusa-1 (frozen backbone, only heads trained) achieves $2.2\times$ wall-clock speedup on Vicuna-7B with 5 heads, tree size 64, $\alpha \approx 0.6$ [2]. Medusa-2 fine-tunes backbone jointly, $2.8\times$ [2].

*Considerations:*

- *Training data* must match target's SFT distribution, else head drift [2]
- *Tree pruning* via score $S(node)=\prod p_{medusa}^{(k)}$ top-K yields $1.3\times$ better $\alpha$ than random [2]
- *Memory*: heads add $K d V$ parameters: for $V=32000$, $d=4096$, $K=4$, $\approx 0.5$B extra — acceptable [2]

### 4.2 EAGLE: Feature-Level Autoregression and Why Tokens Fail

Li et al. [3] argue token drafting suffers from **exposure bias** and **multimodality**. When drafting $x_{t+1}$, small error propagates: $q(x_{t+2}|\hat{x}_{t+1})$ diverges quickly if $\hat{x}_{t+1}$ wrong.

Feature drafting mitigates because $f_{t+1}$ lives in $\mathbb{R}^d$ continuous, and L2 loss encourages mean-seeking behavior that is robust to token sampling noise [3].

Architecture details [3]:

- Draft model: $1$ transformer decoder layer + FC + RMSNorm
- Input: concatenation of $f_t$ (dim $4096$) and token embedding $e(x_t)$ (dim $4096$) → $8192$ → proj $4096$
- Output: predicted $\hat{f}_{t+1}$, then token via original LM head (shared)
- Autoregression depth $\gamma=3$-$5$, tree branching factor $b=2$-$4$ via top-$k$ token expansion at each feature step

```rust
// Rust pseudo for EAGLE draft loop
fn eagle_draft(f_prev: Tensor, x_prev: Token, steps: usize) -> Vec<TokenTree> {
    let mut nodes = vec![Node { f: f_prev, x: x_prev, parent: 0 }];
    for _ in 0..steps {
        let last_level = nodes.iter().filter(|n| n.depth == current_depth);
        for parent in last_level {
            let f_hat = draft_layer(concat(parent.f, embed(parent.x)));
            let logits = lm_head(f_hat.clone());
            for tok in top_k(logits, 2) {
                nodes.push(Node { f: f_hat.clone(), x: tok, parent: parent.id });
            }
        }
    }
    build_tree(nodes)
}
```

Empirical: EAGLE achieves $2.5$-$3.0\times$ speedup on LLaMA2-Chat 70B, versus Medusa $2.1\times$, vanilla speculative $1.8\times$ [3]. Acceptance length $E[L_{acc}] \approx 3.2$ versus $1.8$ [3]. Cost $c \approx 0.05$ target time [3].

> **Theorem 4 (Feature vs Token TV Bound):** Let $p_f$ induced by feature draft, $p_x$ token draft. Under Lipschitz LM head with constant $L_{lm}$, $D_{TV}(p||p_f) \leq L_{lm} \cdot E[||f-\hat{f}||]$ while token draft incurs additional $\Omega(\sqrt{KL})$ due to discrete bottleneck.

This explains EAGLE's gains [3][7].

### 4.3 Lookahead Decoding and Jacobi Iteration Convergence

Lookahead [4] removes need for draft model entirely by using *Jacobi trajectory* as draft source.

Define $n$-gram pool $P$ maintained across steps. At step $t$, with current Jacobi iterate $x^{(k)}$:

- **Lookahead branch:** compute $F$ for $W$ parallel futures: $W$ disjoint $n$-gram continuations from $P$
- **Verification branch:** verify up to $G$ $n$-grams in parallel using target model

Crucially, [4] proves:

> **Theorem 5 (Jacobi Convergence for Greedy Decoding):** Let $F$ as defined. Starting from any $x^{(0)}$, Jacobi iteration $x^{(k+1)}=F(x^{(k)})$ converges to greedy fixed point $x^*$ in at most $L$ iterations. Moreover, each iteration can produce up to $W$ new $n$-grams.

Proof uses causality: position $i$ depends only on $1..i-1$, so after $k$ iterations, first $k$ tokens correct [4] Lemma 1.

For sampling (not greedy), [4] introduces *forced $n$-gram* verification with acceptance via speculative sampling adapted to $n$-grams — ensures lossless property still holds for stochastic decoding.

Implementation in TLA+ specification [4]:

```tla
---- MODULE Lookahead ----
VARIABLES x, pool, step
Init == x \in [1..L -> Vocab] /\ pool = {}
Next == 
  \/ \E w \in 1..W: 
       LET ngram == ComputeNGram(x,w) 
       IN pool' = pool \cup {ngram}
  \/ \E g \in pool:
       LET verified == Verify(g, TargetModel) 
       IN x' = Update(x, verified) /\ pool' = pool \ {g}
Spec == Init /\ [][Next]_<<x,pool>>
====
```

Speedup: $1.5$-$2.3\times$ on CodeLlama 7B/13B without extra model or training, $\alpha$ depends on $n$-gram repetition — best for code where repetition high ($3.8$ avg acceptance) [4].

Tradeoff: Requires larger window $W \times G$ compute per step ($W=5,G=5$ => $25$ tokens per verification) but still single forward pass [4].

### 4.4 Tree Verification, PagedAttention Integration, and Optimal Speculation Length

SpecInfer [5][7] generalizes to arbitrary token tree $T$. Expected accepted length:

$$
E[L] = \sum_{i=1}^{\gamma} \prod_{j=1}^{i} \alpha_j
$$

where $\alpha_j = P(\text{accept token }j | \text{accept }1..j-1)$. If $\alpha_j = \alpha$ i.i.d., $E[L]= (1-\alpha^{\gamma+1})/(1-\alpha)$ [1].

Optimal $\gamma^*$ solves:

$$
\gamma^* = \argmax_{\gamma} \frac{E[L(\gamma)]}{1 + \gamma c}
$$

Leviathan et al. [1] show closed form $\gamma^* \approx \ln(1/(c(1-\alpha)))/\ln(1/\alpha)$ under exponential model. For $c=0.05$, $\alpha=0.6$, $\gamma^* \approx 5$ [1][7].

**Systems integration with vLLM [6]:** PagedAttention stores KV cache in non-contiguous blocks (e.g., 16 tokens/block). Tree verification reuses prefix blocks (refcounted) and allocates new blocks per branch via copy-on-write. Implementation [6][7]:

```python
# vLLM PagedAttention tree extension
class TreeKVManager:
    def __init__(self, block_size=16):
        self.page_table = {}  # seq_id -> list[block_id]
        self.ref_count = {}
    
    def fork_sequence(self, parent_seq, branch_tokens):
        # Share prefix pages, CoW for diverging suffix
        new_seq = new_id()
        self.page_table[new_seq] = self.page_table[parent_seq].copy()
        self.ref_count[parent_seq] += 1
        # Allocate new blocks for branch
        for tok in branch_tokens:
            block = allocate_block()
            self.page_table[new_seq].append(block)
        return new_seq
```

This enables verifying $64$-node tree with $<5\%$ memory overhead versus contiguous KV [6].

**Tree attention kernel**: Custom FlashAttention kernel where mask $M$ is tree-structured sparse [7]. Complexity $O(|T| L_{prefix} d)$ still memory-bound but parallelized.

## 5 Empirical / Proofs

### 5.1 Proof: Lossless Tree Verification

We extend Theorem 2 to trees [5][7].

> **Theorem 6 (Tree Lossless):** Let tree $T$ with nodes drafted from $q$ arbitrary. Algorithm that traverses tree depth-first, accepting via speculative sampling per node, and resampling from $p'$ upon rejection at node, yields output distribution $p_{target}$ exactly.

*Proof:* Induction on tree depth. Base depth 0 = Theorem 2. Inductive step: conditional on prefix $x_{<i}$ accepted, subtree verification reduces to same problem with conditional $p(\cdot|x_{<i})$. Rejection at node triggers fallback to $p'$ computed from that node's conditional, which by induction preserves marginal. Formal measure-theoretic argument uses coupling between $q$-tree and $p$-sequential process [5] Thm 3.1.

### 5.2 Acceptance Rate Bound

Let $D_{TV}(p||q)=\delta$. Then [1] Lemma 1:

$$
\alpha = E[\min(1, p/q)] = 1 - D_{TV}(p||q) \geq 1-\delta
$$

Thus expected speedup:

$$
\text{Speedup} \geq \frac{1-\delta^{\gamma+1}}{(1-\delta)(1+\gamma c)}
$$

For Medusa, $\delta \approx 0.35$-$0.45$ measured [2]; EAGLE reduces to $0.20$-$0.30$ [3]; small LM draft $0.30$-$0.50$ [1].

Empirical validation on **Spec-Bench** [7] (6 tasks: MT-Bench, GSM8K, HumanEval, etc.):

- EAGLE $3.2$ accepted tokens avg, Medusa $2.3$, vanilla $1.8$
- Lookahead excels on HumanEval (code repetition): $3.1$ vs $1.9$ elsewhere [4]
- Tree size $64$ saturates gains; $32$ captures $90\%$ benefit [7]

### 5.3 Jacobi Convergence Rate and Lookahead Efficiency

Consider error $e^{(k)} = ||x^{(k)} - x^*||_0$ (Hamming). [4] Lemma 2:

$$
e^{(k+1)} \leq e^{(k)} - 1 \quad \text{if } e^{(k)}>0
$$

Because at least one new prefix token fixes per iteration due to causality. Hence convergence $\leq L$ steps. However, expected time to fixed point with $W$ parallel Jacobi trajectories reduces to $O(L/W)$ [4] Thm 2.

For stochastic sampling, [4] proves convergence in distribution via coupling argument — Jacobi with Gumbel-max trick preserves marginals.

### 5.4 Systems Benchmark (A100 80GB, vLLM 0.4.2 [6])

- **Baseline** LLaMA2-70B FP16 TPOT $28.5$ms
- **Medusa**: $13.1$ms ($2.18\times$), $c=0.5$ms draft
- **EAGLE**: $9.8$ms ($2.9\times$), $c=1.2$ms draft
- **Lookahead** $W=7,G=7$: $15.2$ms ($1.87\times$), $c=0$ but larger forward $18$ms due to $49$ tokens verified vs $5$
- **SpecInfer tree**: $11.9$ms ($2.39\times$)

Memory overhead $<2$ GB for draft models (EAGLE $1.1$GB, Medusa $0.5$GB) [2][3].

## 6 Limitations

1. **Draft Quality Ceiling**: Acceptance $\alpha$ bounded by $1-D_{TV}$. For highly entropic tasks (creative writing, temp $=1.0$), $\alpha$ drops to $0.2$-$0.3$, speedup collapses to $1.2\times$ [1][3]. *EAGLE mitigates but not solves*; feature space still entropic.
2. **Tree Verification Cost**: Large trees ($>64$ nodes) increase attention $O(|T|^2)$ and may become compute-bound, eroding speedup on long contexts $>8k$ where attention dominates [7]. FlashAttention-2 helps but not fully.
3. **Training Overhead**: Medusa and EAGLE require fine-tuning on target's distribution. Medusa-1 needs $\approx 20$ GPU-hours for 7B [2]; EAGLE $\approx 2$ days for 70B target's draft layer [3]. Mismatch between training data and deployment domain causes $10$-$15\%$ $\alpha$ degradation [2].
4. **Jacobi $n$-gram Pool Staleness**: Lookahead pool accumulates stale $n$-grams from divergent Jacobi trajectories, polluting draft quality for tasks with low repetition (e.g., dialogue) — $\alpha$ variance high $0.4$-$1.8$ [4].
5. **PagedAttention CoW Complexity**: Tree forking with PagedAttention introduces ref-counting and page-table indirection overhead; under high concurrency (100s reqs), page-table lock contention limits throughput [6].
6. **Speculative Sampling Latency Tail**: Rejection sampling introduces variable output tokens per step (1 to $\gamma+1$), causing *jitter* in TPOT — p99 latency $1.4\times$ mean, problematic for SLO-bound serving [5][6].
7. **Security / Side Channels**: Tree verification's variable acceptance leaks information about draft-target divergence — potential timing side channel for model extraction [unpublished].

## 7 Conclusion

Speculative decoding transforms LLM inference from purely sequential to **draft-verify-parallel**, achieving $1.8$-$3.0\times$ latency reduction without altering output distribution [1][3][5]. We unified Medusa's multi-head non-autoregressive drafting [2], EAGLE's feature-level autoregression reducing $D_{TV}$ [3], Lookahead's Jacobi iteration eliminating draft model via fixed-point $n$-gram pooling [4], and SpecInfer's tree verification enabling parallel candidate evaluation [5][7], all integrated with PagedAttention's paging for efficient KV reuse [6].

Key design principles emerging:

- *Draft in continuous space* (features) > discrete tokens [3]
- *Verify trees not chains* — exponential search space for linear cost [7]
- *Reuse prefix KV via paging* to make tree verification memory-efficient [6]
- *Optimal $\gamma^*$ balances draft cost vs acceptance* — analytic formula guides tuning [1]

Future work: **learned draft policies** via RL to maximize $E[L]/(1+\gamma c)$, **hardware-aware kernels** for tree attention, and **speculative prefill** extending speculation to prompt processing phase. As LLMs scale to $10^{12}$ parameters, speculative methods will become *mandatory*, not optional, for interactive serving.
