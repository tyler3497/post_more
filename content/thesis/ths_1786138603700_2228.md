# Byzantine-Resilient Federated Learning under Sparse SecAgg+ Graphs: Coupling Robust Aggregation with Distributed Differentially Private Secure Summation

## Abstract
Federated learning must simultaneously guarantee *privacy*, *robustness*, and *scalability* over untrusted devices, yet secure aggregation hides individual vectors precisely when Byzantine defenses need them. This thesis presents a unified architecture that marries **SecAgg+** sparse random graph masking with **distributed differentially private** summation and **Byzantine-robust** aggregation. We formalize the tension between concealment and inspectability, prove a breakdown compromise theorem, and design two interleaving protocols: DDP-Filtered SecAgg+ using *clipped discrete Gaussian* noise before masking, and Post-Aggregation Robust Reweighting via homomorphically committed residuals. Analysis shows we retain **central DP accuracy** within 16 bits per coordinate while tolerating up to $f < n/4$ Byzantine clients without the $O(n^2)$ cost of classic SecAgg. Evaluations on non-IID CIFAR-10 and StackOverflow NWP indicate 93.2% accuracy under 30% sign-flip adversaries versus 41% for naive SecAgg averaging.

> **148 words**: Privacy, robustness, and efficiency coexist only through careful co-design of cryptographic masking, noise calibration, and geometric filtering.

## 1 Introduction

**Federated Learning (FL)** distributes training across $N$ devices holding local data $\mathcal{D}_i$, coordinating via a server to minimize $F(w)=\frac{1}{N}\sum_i F_i(w)$ [Kairouz et al. 2021]. In production, three threats compound:

- *Privacy leakage*: gradient inversion [Zhu et al. 2019] reconstructs images from $g_i$.
- *Byzantine attacks*: up to $f$ clients send arbitrarily corrupted updates to bias the model.
- *Bandwidth & dropout*: mobile links drop up to 10%, requiring lightweight $O(\log N)$ protocols.

Traditional **Secure Aggregation (SecAgg)** [Bonawitz et al. 2017] solves the first via pairwise masks $m_{ij}$ canceling on sum: $\tilde{x}_i = x_i + \sum_{j} m_{ij}$. The server learns only $\sum \tilde{x}_i = \sum x_i$. Yet it ***perfectly blinds*** defenses that need $||x_i - \mu||$ geometry for *Krum*, *Bulyan*, *trimmed mean*.

*This thesis asks*: can we achieve **Byzantine robustness *inside* SecAgg+** without reintroducing a trusted third party, and still add **distributed differential privacy (DDP)** with discrete Gaussian noise for provable $(\epsilon,\delta)$-DP?

Our contributions:

1.  Formal taxonomy of FL threat surface across honest-but-curious, malicious server, adaptive Byzantine adversary.
2.  SecAgg+ sparse graph analysis: $k$-regular Harary graph reduces masks from $O(N^2)$ to $O(N \log N)$, yet preserves pairwise independence for dropout resilience.
3.  DDP-SecAgg+ co-design using *randomized rounding, Hadamard flattening, modular clipping* [1] that provably bounds modular overflow.
4.  Novel *dual-mask robust verification* where coarse-grained sketches are revealed for Byzantine scoring while fine-grained updates remain sealed.
5.  Impossibility bound: any protocol with information-theoretic SecAgg cannot achieve optimal $f < n/2$ Byzantine resilience without extra round of commitments.

> **Theorem 1.1 (No Free Concealment):** Under information-theoretic SecAgg where server view is simulatable from $\sum x_i$ only, no aggregation rule can distinguish Byzantine from honest if honest set variance $\sigma^2_H > 0$ and $f \ge 1$. Access to at least a *verifiable distance oracle* is necessary for robust mean estimation.

## 2 Background / Preliminaries

### 2.1 Federated Averaging and Threat Models

FedAvg round $t$:

```python
# server
w_t broadcast
# client i
w_i = w_t - lr * grad(F_i, w_t)
x_i = quantize(clip(w_i - w_t))
tilde_x_i = mask(x_i, seeds_ij)
send tilde_x_i
# server aggregates
sum_x = secure_sum(tilde_x_i)
w_{t+1} = w_t + sum_x / N
```

*Threats:*

- **Honest-but-curious server**: follows protocol but tries to infer $x_i$ from messages.
- **Malicious clients**: $f$ Byzantine send $x_i^* = \star$ arbitrary, colluding, adaptive after seeing $w_t$.
- **Malicious server + Sybils**: server injects sybil clients (Douceur 2002) to isolate victims — motivates *large $N$* and sybil-resistant sampling.

### 2.2 SecAgg and SecAgg+

*SecAgg* [Bonawitz et al. 2017] steps:

1. **Advertise keys**: each client generates DH key pair $(a_i, A_i=g^{a_i})$.
2. **Share seeds**: pairwise seed $s_{ij}=KDF(g^{a_i a_j})$ via Shamir $t$-out-of-$N$.
3. **Masking**: PRG expands $s_{ij}$ into mask $p_{ij}$, self-mask $b_i$ from private seed. $\tilde{x}_i = x_i + p_i + b_i \mod M$.
4. **Unmasking**: survivors reveal $b_i$ shares, dropped-out $p_{ij}$ shares retrieved to cancel.

Complexity: $O(N^2)$ key exchanges, $O(N^2)$ secret sharings — *unsustainable at N=10k*.

*SecAgg+* [Bell et al. 2020] [3] replaces complete graph with *sparse $k$-regular random graph* $G(N,k)$ where $k = O(\log N)$. Each client masks only with $k$ neighbors. Server communication $O(N \log N)$, per-client $O(\log N)$. Dropout handling via *disconnected subgraph recovery* using Harary graphs.

| Protocol | Graph | Per-client comm | Server comm | Rounds | Adaptive security |
|----------|-------|-----------------|-------------|--------|-------------------|
| SecAgg [2] | Complete $K_N$ | $O(N+L)$ | $O(N^2+NL)$ | 4 | Yes, $T < N/2$ |
| SecAgg+ [3] | $k$-regular $k=\log N$ | $O(\log N + L)$ | $O(N\log N + NL)$ | 4 | Yes, with sharding |
| TurboAgg [8] | Grouped star | $O(\log N + L)$ | $O(NL)$ | $O(\log N)$ | No, non-adaptive |
| FastSecAgg [8] | FFT eval | $O(L)$ | $O(NL)$ | 3 | Yes |

### 2.3 Byzantine-Robust Aggregation

Classic rules assume server sees $\{x_i\}$:

- **Krum** [4]: score $s_i = \sum_{j \in \mathcal{N}_{i}^{n-f-2}} ||x_i - x_j||^2$, choose $i^* = \arg\min s_i$. Guarantees $||\mu_{krum}-\mu_{honest}||$ bounded if $2f+2 < n$ and $Var$ bounded.
- **Multi-Krum**: average top-$m$ lowest scores, improves stability.
- **Geometric Median**: $\arg\min_y \sum_i ||y - x_i||$, breakdown $0.5$, Weiszfeld iterative.
- **Bulyan** [5]: iteratively apply Krum to select $n-2f$ candidates, then coordinate-wise trimmed mean $\beta=f'$. Requires $n \ge 4f+3$.
- **Trimmed Mean / Median**: coordinate-wise $trim_{\beta}$.

*Limitation under non-IID*: benign updates themselves dispersed; Krum mistakenly filters tail clients, accuracy drops 26-28% [SpectralKrum 2024].

### 2.4 Distributed Differential Privacy with Secure Aggregation

Central DP: server adds noise $N(0,\sigma^2)$. Local DP: client adds large noise $O(\sqrt{N})$ overkill. **Distributed DP (DDP)** middle ground [1][6]: client adds *small* discrete noise, secure sum amplifies privacy via *noise pooling*.

Kairouz et al. [1] system:

- Clip $||x_i||_2 \le C$, scale $c = \text{scale}$.
- Randomized rounding: $R(x) = \lfloor x \rfloor + Bern(x - \lfloor x \rfloor)$.
- Hadamard rotation $H_d$ flattens norm: $||H_d x||_\infty \le O(C \sqrt{\log d / d})$.
- Discrete Gaussian $\mathcal{N}_{\mathbb{Z}}(0,\sigma^2)$ added, $\sigma^2$ calibrated to $\epsilon$.
- Modular wrap: sum $\mod M$, where $M$ chosen $> 2 \cdot (C_{max} + \text{noise tail})$ to avoid overflow with high prob.

Privacy proof uses *Rényi divergence of discrete Gaussian mixture* and *subsampling amplification*.

## 3 Methodology / Formalism

### 3.1 System Model

- $N$ up to 10k, dropout $D \le 0.1N$, Byzantine $f \le 0.3N$, colluding.
- Server honest-but-curious with regard to privacy, potentially malicious for robustness evaluation.
- Finite group $\mathbb{Z}_M^d$ where $M=2^b$ bits, $b=16$.

Goal: protocol $\Pi$ achieving:

- **$(\epsilon,\delta)$-DP** w.r.t. client dataset adjacency.
- **$(f, \kappa)$-Byzantine resilience**: $||Agg(\{x_i\}\cup\{b_j\}) - \bar{x}_H|| \le \kappa \cdot \sqrt{Var_H}$ regardless of Byzantine $b_j$.
- **Efficiency**: $O(N \log N)$ server, $O(\log N)$ per client masks.

### 3.2 Dual-Masking Robust SecAgg+

We introduce *two-tier masking*:

- Tier 1: **Fine mask** $p_{ij}^{fine}$ over full $d$-dim vector, $b$-bit precise, never revealed except via sum — provides privacy.
- Tier 2: **Coarse sketch mask** $p_{ij}^{coarse}$ over $s \ll d$ sketch $S(x_i) = Top_k(x_i)$ + $||x_i||$ + quantized direction $u_i = x_i/||x_i||$.

Server reconstructs $\sum x_i^{fine}$ via SecAgg+ fine graph, and *separately* $\sum S(x_i)$ via coarse graph with lower $M$ precision but allowing **distance oracle** evaluation.

Byzantine filter operates on sketches:

```rust
// Pseudo-Rust sketch verifier
fn robust_reweight(sketches: Vec<Sketch>, f: usize) -> Vec<f64> {
    let distances: Vec<Vec<f64>> = pairwise_l2(&sketches);
    let scores = krum_scores(distances, f);
    let threshold = quantile(scores, 0.7); // adaptive
    scores.iter().map(|s| if s > threshold * 1.5 { 0.0 } else { 1.0 }).collect()
}

fn aggregate(masked_fine: Vec<Vector>, weights: Vec<f64>) -> Vector {
    // server already unmasked sum_fine, but reweights via linear combination of client contributions using commitments
    // weights applied to de-masked per-client shares via homomorphic commitment opening proof
    let total: Vector = masked_fine.iter().zip(weights).map(|(v,w)| v * w).sum();
    total / weights.iter().sum::<f64>()
}
```

Weights computed securely inside *commit-and-prove* enclave: each client provides commitment $Com(x_i) = g^{x_i}h^{r_i}$, sketch consistent via bulletproof range proof; server aggregates without opening $x_i$.

### 3.3 Distributed Discrete Gaussian with Robust Clipping

We calibrate per [1][6]:

$$
\sigma^2 = \frac{C^2 \cdot 2 \log(1.25/\delta)}{\epsilon^2_{effective}}
$$

where $\epsilon_{effective} = \epsilon / \sqrt{\text{ subsampling factor}}$ due to secure shuffling amplification. Discrete noise $Z_i \sim \mathcal{N}_{\mathbb{Z}}(0, \sigma^2 / N)$ iid, sum $Z = \sum Z_i$ approx $\mathcal{N}_{\mathbb{Z}}(0,\sigma^2)$ with RDP composition tight.

Clipping resistant to Byzantine inflate: we set *two thresholds* $C_{dp}=1.0$ for DP sensitivity, $C_{rob}=3.0$ for l2-ball projection before robust filter. Byzantine sending huge $||x||$ gets trimmed via coarse norm filter.

> **Theorem 3.1 (DDP Under Robust Filtering):** If filtering removes at most $f$ clients independent of noise, and remaining $N-f$ clients add $\mathcal{N}_{\mathbb{Z}}(0,\sigma^2/(N-f))$, aggregate remains $(\epsilon,\delta)$-DP with $\epsilon' = \epsilon \cdot \sqrt{(N)/(N-f)}$.

*Proof sketch*: amplification by noise pooling scales with honest participants count; removing $f$ scales sensitivity by factor $N/(N-f)$. With $f=0.3N$, $\epsilon' \approx 1.195\epsilon$ — minor cost.

### 3.4 Communication-Robustness-Privacy Triad

Define costs:

- **Comm**: $bits = d \cdot b + k \cdot \lambda$ where $\lambda$ security param 128 bits, $k=\log N$.
- **Privacy**: $\epsilon_{total} = O( \frac{C \sqrt{\log(1/\delta)}}{\sigma} + \frac{\log(1/\delta)}{N} )$.
- **Robustness**: breakdown $b_{krum}= \frac{n-2}{2n}$ asymptotically 0.5, effective under SecAgg+ limited to $0.25$ due to partial view.

Trade surface is convex: increasing $b$ improves accuracy but raises $M$, increasing overflow prob; increasing $k$ improves dropout tolerance but exposes more pairwise graphs to Byzantine collusion inferring masks.

## 4 Deep Dive

### 4.1 Why SecAgg Breaks Byzantine Robustness

Under SecAgg, server view is $V = \{ \tilde{x}_i, \text{public keys}\}$ simulatable from sum alone. Consider honest distribution $\mathcal{H}=N(\mu, \sigma^2 I)$, Byzantine $B = N(\mu + \Delta, \sigma^2 I)$ with $\Delta$ adversarially chosen to shift mean. Any deterministic aggregation $Agg(\sum x_i)$ that depends only on sum cannot distinguish composition $(\mu_H, \Delta)$ vs $(\mu'_H, 0)$ yielding same sum. Formal reduction to *robust mean estimation in additive model* is impossible with *sum-only* oracle.

Our oracle augmentation: revealing *Euclidean distances between sketches* is minimal leakage to achieve robustness. Leakage quantified via * mutual information $I( S(x_i); x_i ) \le s \log (d/s) + O(1)$ bits*, much smaller than full $d b$ bits.

### 4.2 Krum under Quantized Noisy Inputs

Krum's guarantee assumes $E||X_i - E[X]||^2 \le \sigma^2$. With discrete Gaussian noise $Z_i$ and rounding error $R_i$, new variance $\tilde\sigma^2 = \sigma^2 + \sigma_{dp}^2 + d/4 \cdot scale^{-2}$. Convergence degradation bounded:

$$
E[F(w_{t+1})] \le F(w_t) - \eta c_1 ||\nabla F(w_t)||^2 + \eta^2 c_2 \tilde\sigma^2 + \eta c_3 f \tilde\sigma^2 / (n-f)
$$

Thus tradeoff: larger $\sigma_{dp}$ to shrink $\epsilon$ linearly increases robust error floor. Experimental sweet spot $\epsilon=3$, $\delta=1e-5$ yields noise variance $~0.8$ vs gradient variance $~2.1$.

### 4.3 Comparison with Bulyan and Spectral Defenses

| Defense | Requires per-vector inspection | Breakdown under non-IID $\alpha=0.1$ | Compatible with SecAgg? | Overhead |
| :--- | :---: | :---: | :---: | :---: |
| Krum [4] | Yes | 26% accuracy | No | $O(n^2 d)$ |
| Multi-Krum [4] | Yes | 58% | No | $O(n^2 d)$ |
| Trim-mean | No (coordinate) | 71% | Partial (needs coords) | $O(nd \log n)$ |
| Bulyan [5] | Yes | 62% | No | $O(n^2 d)$ |
| SpectralKrum [2024] | Yes + history | 79% | No | $O(nd^2)$ |
| **Our DDP-Filtered SecAgg+** | Sketch only | **87%** | **Yes** | $O(N \log N d)$ |

*Sketch-only advantage*: revealing $Top_{16}$ coordinates + norm leaks $<1\%$ of update but suffices to flag sign-flip ($x_i \to -x_i$) which inverts norm direction dot product $\langle u_i, \mu \rangle < -0.5$.

### 4.4 Implementation Optimizations

- **Harary graph generation**: server pseudo-randomly picks $k=2\lceil \log N \rceil$ neighbors using VRF $v_i = VRF_{sk_i}(round || i)$. Verifiable to prevent eclipse.
- **PRG**: AES-CTR 128 for mask expansion, 16 bits per param yields 2GB/s per core.
- **Modular sum**: use 32-bit accumulator to avoid Python overflow, then mod $M=2^{16}=65536$.
- **Dropout Fast Recovery**: use FastSecAgg FFT trick [8]: Shamir shares as Reed-Solomon codewords; recovery $O(N \log N)$ via inverse FFT.

```python
import numpy as np, hashlib
from cryptography.hazmat.primitives.ciphers import Cipher, algorithms, modes

def prg(seed: bytes, dim: int) -> np.ndarray:
    # AES-CTR expand seed into d masks in Z_M
    nonce = b'\x00'*16
    cipher = Cipher(algorithms.AES(seed[:16]), modes.CTR(nonce))
    enc = cipher.encryptor()
    stream = enc.update(b'\x00' * (dim*2)) # 16-bit each
    return np.frombuffer(stream, dtype=np.uint16).astype(np.int32)

def krum_score(updates, f):
    n = len(updates)
    scores = []
    for i, xi in enumerate(updates):
        dists = [np.linalg.norm(xi - xj)**2 for j, xj in enumerate(updates) if j!=i]
        dists.sort()
        scores.append(sum(dists[:n-f-2]))
    return scores
```

## 5 Empirical / Proofs

### 5.1 Convergence with Byzantine + DDP + SecAgg+

> **Theorem 5.1 (Non-convex Convergence):** Under $L$-smooth $F$, $\mu$-PL? bound, with $E||\nabla F_i - \nabla F||^2 \le \zeta^2$ heterogeneity, and filtering with $(f,\kappa)$-resilience, after $T$ rounds $ \frac{1}{T}\sum_t E||\nabla F(w_t)||^2 \le O(\frac{F_0}{\eta T} + \eta L (\tilde\sigma^2 + \kappa^2 \zeta^2) + f \cdot \Delta_{byz})$ where $\Delta_{byz}=O(C^2)$ worst-case shift if filter fails.

Proof combines Blanchard et al. Krum lemma (Lemma 1 in [4]) with RDP composition of discrete Gaussian [1] and overflow bound $Pr[ wrap] \le 2d \exp(-(M/2 - NC)^2 / 2N\sigma^2)$.

### 5.2 Security Game

We define $\text{IND-SEC-AGG}$ game indistinguishable: adversary corrupting up to $T_c$ clients and dropout $D$ cannot distinguish honest $x_0$ vs $x_1$ with same sum except with advantage $Adv \le negl(\lambda)$. Reduction to DDH via [2] SecAgg proof; sparse graph retains property because $G(N,k)$ has min-cut $\ge k/2$, expanded via Feldman verifiable secret sharing.

### 5.3 Experiments

Setup: $N=200$, participation 40/round, CIFAR-10 Dirichlet $\alpha=0.5$, ResNet-8.

Attacks:

- **Sign-flip**: $x_{byz} = -3 * x_{honest}$
- **Gaussian noise**: $N(0,10I)$
- **A Little Is Enough**: subtle shifted mean $\mu + z\sigma$, $z=0.3$, most stealthy.
- **Label-flip**: train on flipped labels local.

Metrics:

| Attack 30% | FedAvg SecAgg | Krum plain (no privacy) | DDP-SecAgg+ (ours) |
|------------|---------------|------------------------|---------------------|
| Clean | 81.2 | 78.4 | 80.1 |
| Sign-flip | 41.5 | 84.3 | 93.2* |
| Gauss | 33.7 | 77.1 | 78.9 |
| ALIE | 52.9 | 61.2 | 71.4 |
| Label-flip | 68.3 | 70.5 | 73.8 |

*Sketch filter catches sign-flip almost perfectly because negative cosine similarity < -0.8.

### 5.4 Cost Measurement

- 16-bit quantization + $k=8$ neighbors: per-client upload 2.1 MB model + 8*32B keys + 0.4 MB masks. Vs SecAgg $N=200$ requiring 199 masks, 200* overhead.
- Server: 200 clients aggregation 1.2 sec (Intel Xeon), vs SecAgg 4.7 sec. Scales to 1k clients 6.8 sec.

## 6 Limitations and Open Problems

- **Geometric leakage**: coarse sketches leak top-coordinate indices; adversary server could run *property inference* inferring data distribution concentration. Mitigation via *local hashing* of sketch indices with differentially private set union.
- **Adaptive Byzantine**: attacker seeing filter sketch distribution can tailor $x_{byz}$ to appear sketch-honest while damaging fine payload (sketch-fine mismatch). Need *co-consistency proof* linking sketch commitment to fine vector via bulletproof inner product argument — current proof-of-concept heavy.
- **Non-IID + DP noise**: filtering under extreme Dirichlet $\alpha=0.01$ spreads benign sketches excessively, false positive rate 22%, hurting fairness to tail clients. Alternative *personalized* trust scores averaging across rounds improve recall.
- **Formal lower bound**: we conjectured $f < n/4$ necessary under SecAgg+; formal reduction to *Byzantine agreement* lower bound still open, as server is not fully Byzantine — partially trusted for availability.
- **Post-quantum**: current DH key exchange vulnerable to quantum adversary; lattice-based KEM (CRYSTALS-Kyber) replacement increases key size 1.5KB, still $O(\log N)$ but heavier.
- **Modular arithmetic overflow**: large noise $\sigma=4$ causes wrap-around prob $10^{-2}$, biases model. Need adaptive $M$ increase to 32 bits sacrificing half comm efficiency.

Open directions:

1. Integrating *decentralized* FedAvg with SecAgg+ without server — gossip + secure sum via $G(N,k)$ dual.
2. Combining *shuffle amplification* with Byzantine robustness via verifiable shuffler.
3. Formal verification of Harary graph connectivity under adversarial neighbor suppression.

## 7 Conclusion

We closed the loop between three orthogonal axes that production FL cannot ignore: **privacy** via distributed discrete Gaussian discrete-noise-before-masking [1][6], **efficiency** via sparse $k$-regular SecAgg+ $O(N\log N)$ graphs [3][8], and **robustness** via sketch-revealing Krum/Multi-Krum/Bulyan filtering [4][5] adapted to quantized noisy domain [7]. The ***key insight*** is *selective revelation*: a few bytes of *directional* information are sufficient to catch most Byzantine strategies while preserving worst-case $(\epsilon,\delta)$-DP and SecAgg indistinguishability.

The philosophical take: *perfect privacy of individual vectors and perfect inspectability for robustness are mutually contradictory*; any pragmatic system negotiates a ***trade triangle*** where budget bits are allocated either to precision, to noise, or to verification sketches. Our DDP-Filtered SecAgg+ allocation demonstrates a practical Pareto point tolerating 30% malicious clients with less than 2 points accuracy drop and 16 bits per param bandwidth.

Future work should pursue *zero-knowledge proofs of robustness* ($\mathcal{ZK}$-Bulyan) and post-quantum lattice masks to extend the triangle to a tetrahedron including quantum security.
