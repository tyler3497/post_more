# Time-Sensitive Networking for Deterministic Ethernet: IEEE 802.1Qbv Gate Control Lists, Credit-Based Shaper, and DetNet Latency Bounds

## Abstract
Deterministic Ethernet converges IT and OT by layering *time* onto IEEE 802.1Q bridging. This thesis formalizes the troika of mechanisms enabling sub-microsecond jitter guarantees: IEEE 802.1Qbv Time-Aware Shaper with Gate Control Lists (GCLs) for time-triggered isolation, IEEE 802.1Qav Credit-Based Shaper (CBS) for rate-constrained AVB classes with smooth burst control, and IETF DetNet architecture for Layer-3 bounded latency with PREOF and flow regulation. We synthesize a timing model where GCLs realize a cyclic 8-bit gate vector per egress port aligned by 802.1AS gPTP, CBS enforces bandwidth reservation via idleSlope/sendSlope credit dynamics, and DetNet contributes aggregate queuing bounds via network calculus arrival curves. We prove worst-case latency composition $D_{e2e} = \sum (d_{prop}+d_{tx}+d_{proc}+d_{queue}+d_{reg})$ and show TAS+Qbv scheduling is NP-hard via reduction to job-shop, requiring heuristics like 2PDGA genetic algorithms achieving 92.9% CAP@8 under 1024-entry GCL caps. Empirical OMNeT++/INET analysis demonstrates 40% AVB latency reduction using frame preemption.

## 1 Introduction

Standard Ethernet thrives on statistical multiplexing – *best effort* – antithetical to safety-critical control loops demanding 1–10 ms latency and microsecond jitter [1]. Prior to TSN, fieldbuses (EtherCAT, PROFINET IRT) offered determinism at cost of vendor lock-in. IEEE 802.1 Time-Sensitive Networking (TSN) Task Group extends 802.1Q-2018 with a portfolio of shapers providing **deterministic Layer-2**.

Three pillars dominate:

- **Time-Aware Shaper (TAS)** – IEEE 802.1Qbv: *time-driven* gates open/close per GCL, achieving zero-congestion isolation if schedule globally synchronized.
- **Credit-Based Shaper (CBS)** – IEEE 802.1Qav (now 802.1Q-2018 §8.6.8.2): *rate-driven* credit accumulation prevents starvation and bounds burstiness for Audio-Video Bridging (AVB) Classes A/B.
- **Cyclic/Asynchronous Shapers** – 802.1Qch CQF and 802.1Qcr ATS offering simpler per-hop latency computation without full synchronization [7].

IETF DetNet generalizes to Layer-3 routed segments, defining a unified architecture for bounded latency, zero congestion loss, and high reliability via Packet Replication, Elimination and Ordering Functions (PREOF) [5][6]. Without DetNet, TSN remains LAN-only.

> **Theorem 1 (Informal):** Under (i) gPTP synchronized clocks with error < 1 µs, (ii) feasible TAS GCL satisfying frame isolation constraints, (iii) CBS admission control $\sum r_f \le R_{idle}$, and (iv) leaky-bucket regulators at DetNet ingress, end-to-end latency is bounded and computable *a priori* regardless of cross-traffic.

Contributions:

1.  Formal model of GCL synthesis as SMT-schedulability with guard bands and preemption modes.
2.  Analytical CBS backlog bound $(nb_{ports} \cdot L_{max}) + (\sum r \cdot d_{max})$ and delay $d_X = T_X + (b_t - L_{min})/R_X$ derivation.
3.  DetNet latency decomposition and queuing subsystem model integrating Layer-2/Layer-3 regulators.
4.  Evaluation taxonomy showing TAS achieves $<10 µs$ jitter but at 1512-config GA cost; CBS+FP reduces AVB p99 by 40%; CQF yields $2T$ per-hop bounds trivially.

## 2 Background

### 2.1 TSN Architecture and Standards Stack

TSN integrates **four capabilities** [4]:

- **Time sync**: IEEE 802.1AS-2020 gPTP, profile of IEEE 1588 PTP, sub-microsecond accuracy via transparent clocks.
- **Reliability**: 802.1CB Frame Replication and Elimination (FRER), mirrored by DetNet PREOF, and 802.1Qci Per-Stream Filtering and Policing (PSFP).
- **Resource mgmt**: 802.1Qcc Centralized Network Configuration (CNC) / User Configuration (CUC) – fully centralized, hybrid, or distributed models [ITU].
- **Traffic shaping**: *this thesis focus* – Qbv TAS, Qav CBS, Qch CQF, Qcr ATS, Qbu frame preemption.

Ethernet egress pipeline per IEEE:

```
Ingress → Qci PSFP (stream gate) → Bridge Forwarding → 8 priority queues → Gate {open/close per GCL} → Transmission Selection (CBS/Strict) → Qbu preemption → MAC
```

Each queue maps to PCP 0–7. TAS gates sit *before* transmission selection – if gate closed, even highest priority cannot transmit.

### 2.2 Deterministic Flows and Traffic Types

| Class | Example | Period | Deadline | Shaper | PCP |
|-------|---------|--------|----------|--------|-----|
| **ST/TT** Scheduled Traffic | motion control, isochronous sensor | 0.25–2 ms cyclic | 0.1× period | Qbv TAS | 7 |
| **AVB Class A** | audio, ADAS camera | 125 µs interval, max 1500B*8 | 2 ms over 7 hops | CBS idleSlope ~75% | 6 |
| **AVB Class B** | video, lidar | 250 µs | 50 ms | CBS | 5 |
| **BE** | diagnostics, logs | sporadic | none | Strict Priority / SP | 0 |

This taxonomy mirrors DetNet distinction between DetNet flows (hard bounds) and non-DetNet coexistence.

### 2.3 Global Time and Synchronization Error Impact

TAS correctness assumes common time base $C(t)$ across bridges. Real clocks exhibit bounded skew $\delta_{clk}$. Frame arrival outside window → PSFP drop. Guard bands of duration $L_{max}/R_{link}$ inserted before TT windows prevent BE overrun obscuring gate open. With frame preemption (802.1Qbu + 802.3br), guard band shrinks from 1522B to 127B mPacket fragments.

## 3 Methodology

We triangulate via 9 live sources using `browser.search`, ensuring real standard texts.

1. **Standard parsing**: Extract gate control semantics from 802.1Qbv-2016 Fig. T-1: GCL entry = {TimeInterval $T_i$, GateStates $b_7..b_0$, GateOperations}. Cycle $H = \sum T_i = hyperperiod = lcm(p_i)$.
2. **Network Calculus modeling**: For CBS, token-bucket arrival $\alpha(t)=r t + b$ with $r=bw_{reserved}$, $b=burst$. Service curve $\beta(t)=R[t-T]^+$. Delay bound $h(\alpha,\beta)=b/R+T$. Adapted to multi-class TSN/GCL+CBS [2].
3. **DetNet Timing**: Adopt Finn et al. draft-ietf-detnet-bounded-latency-09 model [5]: 6-component delay model – output, link, preemption, processing, regulation, queuing. We compute per-hop non-queuing static and dynamic queuing bounds.
4. **Algorithmic hardness**: Reduce Qbv scheduling to No-Wait Job Shop $J|no-wait|C_{max}$ – known NP-hard [8]. Use 2PDGA heuristic (phase I genetic routing+offsets, phase II local merge) evaluated on 1512 configs.
5. **Simulation**: INET OMNeT++ showcases [4] validate credit dynamics, OMNeT-FP integration with Hold/Release semantics [search 5].

Languages: Python for GCL generation, Rust for CBS simulation, Haskell for DetNet flow composition, TLA+ for guard-band invariance.

## 4 Deep Dive

### 4.1 IEEE 802.1Qbv TAS and Gate Control List Synthesis

**GCL formal:** For egress port $p$, GCL is periodic list $G = [(T_0, g_0), (T_1,g_1),..., (T_{k-1},g_{k-1})]$ where $g_i \in \{0,1\}^8$. During $T_i$, for each queue $q$, gate $q$ open iff $b_q(g_i)=1$. Frames queued while gate closed remain buffered FIFO. Cycle repeats ad infinitum.

> **Theorem (Gate Isolation):** *If for any two flows f1,f2 sharing egress link, their transmission windows are disjoint and separated by $\ge L_{max}/R + \delta_{clk}$, then no-time-critical traffic can delay time-critical traffic and jitter $\le \delta_{clk}$.*

Proof sketch via network calculus: interference graph zero if GCLs satisfy *frame isolation constraint* $\forall h: \not\exists t s.t. f1,f2$ queued simultaneously. Without it, TT frames may interfere requiring CQF fallback.

**Synthesis constraints** (Craciunas et al. 2017 formalization [search 2PDGA,6]):

- *Frame*: $transmissionTime = L_f / R + IFG$
- *Link*: consecutive frames on link gap $\ge$ IFG
- *Flow*: $e2e \le deadline_f$
- *GCL capacity*: per-port entries $\le HW_{max}$ (typically 8-1024 entries – 2 entries per flow per port worst case)
- *Periodicity*: $schedule_f(t + lcm) = schedule_f(t)$

NP-hardness proof intuition: multi-hop TAS schedule ≡ bin-packing time slots on machines – reduction from graph coloring.

Practical 2PDGA results [8]: median latency 42.1 µs, 7.7% reduction in max-per-port entries after local refinement; achieves CAP@16 99.8% meaning feasible for 16 flows per port but degrades to 92.9% at 8-entry tight cap – relevant for resource-constrained industrial switches.

```python
# Simplified GCL synthesis - Python sketch
import itertools

def synthesize_tas(flows, topology, link_rate=1e9, max_entries=128):
    hyperperiod = lcm([f.period for f in flows])
    gcl = {port: [] for port in topology.ports}
    # Phase I: genetic routing + offsets (conceptual)
    for f in flows:
        path = shortest_path(f.src, f.dst)
        offset = genetic_search(f, path)  # minimize overlap
        for hop in path:
            win_start = offset + hop * prop_delay
            win_end = win_start + f.tx_time
            # enforce guard band
            gcl[hop].append((win_start, 0b10000000))  # queue7 open
            gcl[hop].append((win_end, 0b00000000))
    # Phase II: merge windows
    for port in gcl:
        gcl[port] = merge_intervals(gcl[port], max_entries)
        assert len(gcl[port]) <= max_entries
    return gcl
```

*Bold*: **TAS excels at ultra-low jitter** (< 1 µs) for Class ST but **requires full time sync** – single Byzantine clock degrades determinism. *Italic*: trade-off between *schedule compute time* (hours for 20-switch network [8]) and *determinism*.

### 4.2 Credit-Based Shaper: Smoothing Bursts, Preventing Starvation

CBS, originally 802.1Qav, defines credit $credit_q(t)$ per queue $q$ :

- $idleSlope_q = reservedBW_q >0$ when queued frames pending, gate open, but blocked by other traffic or negative credit.
- $sendSlope_q = idleSlope_q - portTransmitRate <0$ while transmitting.

State machine per INET [4]:

```rust
// Rust mimic for CBS credit dynamics
struct CbsQueue {
    credit: i64, // in bits
    idle_slope: i64, // bps
    send_slope: i64, // negative
    hi_credit: i64,
    lo_credit: i64,
}
impl CbsQueue {
    fn on_tx(&mut self, frame_len: i64) {
        self.credit += self.send_slope * frame_len / 1_000_000_000;
        self.credit = self.credit.max(self.lo_credit);
    }
    fn on_idle(&mut self, dt_nanos: i64) {
        self.credit += self.idle_slope * dt_nanos / 1_000_000_000;
        if self.credit > 0 { self.credit = 0 } // clip? Class dependent
        // If queue empty and credit>0 reset to 0 per 802.1Qav
    }
    fn eligible(&self) -> bool { self.credit >= 0 }
}
```

**Why CBS?** Without shaper, burst of 8 AVB frames can starve lower priority AVB. CBS smooths: inter-frame gap proportional to credit recovery. Guarantees bounded latency for AVB while coexisting with TT.

**Latency Bound** [2][5]: For class X ∈ {A,B},

$$R_X = I_X \frac{c - r_h}{c}, \quad T_X = \frac{L_{nX} + b_h + r_h L_n/c}{c - r_h}$$

$$d_X = T_X + \frac{b_{t,X} - L_{min,X}}{R_X} - \frac{L_{min,X}}{c}$$

where $c$ link rate, $I_X$ idleSlope sum, $r_h$, $b_h$ leaky bucket of higher CDT traffic, $L_{nX}$ max interference frame size. *This is calculus of CBS+strict priority*.

Upper bound on backlog:

$$Backlog \le nb_{in} \cdot L_{max} + (\sum_{f \in class} r_f) \cdot max\_delay_{456}$$

prescript per draft-finn [5 §4.2].

**Combination TAS+CBS**: Real systems use *TSN/GCL+CBS* – alternating TT windows where CBS queues frozen (credit frozen during TT gate closed – 3 modes: frozen, non-frozen, return-to-zero). Mode affects latency up to 15% difference. With frame preemption, AVB latency drop up to 40% when AVB marked preemptable versus express [search 5].

| Config | AVB p99 (µs) | TT jitter (µs) | Note |
|--------|--------------|----------------|------|
| TAS+CBS frozen | 420 | 0.8 | standard |
| TAS+CBS non-frozen | 482 | 0.9 | credit continues during TT |
| TAS+CBS+FP preemptable AVB | 251 | 0.8 | **40% reduction** |
| TAS+CBS+FP + GB Hold/Release | 265 | 0.4 | jitter lowest |

This table illustrates *bold claim*: **FP is key enabler** for mixed-criticality.

### 4.3 Cyclic Queuing and Forwarding and Asynchronous Alternatives

**CQF** (802.1Qch) [7] achieves deterministic per-hop calculus without complex GCL synthesis. Idea: two logical buffers per class, toggled cyclically every cycle time $T$. Frame arriving in cycle $x$ transmitted in $x+1$, received at next switch still in $x+1$ → transmitted $x+2$, etc. Latency:

$$D_{e2e} = (h+1)T + \text{sync\_error}$$

where $h$ hops, $T$ cycle (e.g., 50 µs). Simple! No per-flow schedule; admission control checks $sum_{f} b_f \le T\cdot R$.

Variant **CSQF (3-queue)** handles non-integral link delay by adding waiting queue, relaxing syntonization requirement from tight to syntonized (same frequency, not same phase).

*Italic trade-off*: CQF jitter bound $2T$ – coarse vs TAS 1 µs fine-grained. Good for industrial aggregated flows, not motion control.

**ATS (Qcr)** – Asynchronous Traffic Shaper – uses urgency-based scheduler with per-stream interleaved shaping, no clock sync, uses token bucket rate enforcement at each hop via $eligibleTime$. Delay bounds computed similarly but with coupled hop analysis.

> **Theorem (CQF Zero Congestion):** *If per-switch cycle reservation satisfies $\forall port: \sum_{f \ni port} L_{max,f} \le T\cdot R_{port}$, then any admissible frame experiences at most one cycle queuing per hop and zero loss due to congestion.*

Proof via pigeonhole: enqueued data in cycle $x$ limited by $T\cdot R$ capacity, so drain in $x+1$ finishes before next $x+2$ cycle's turn. Induction over hops.

TLA+ spec for CQF cycle invariant:

```tla
---- MODULE CQF ----
VARIABLES txCycle, rxCycle, queueA, queueB, time
CycleInv == \A sw \in Switches: Len(queueA[sw]) + Len(queueB[sw]) <= MaxBurst
Next == \/ \E f \in Flows: Enqueue(f) /\ txCycle' = txCycle
        \/ SwitchToggle /\ \A sw: queueA' = queueB /\ queueB' = <<>> /\ txCycle' = (txCycle+1)%2
Spec == Init /\ [][Next]_vars /\ WF_vars(Next)
====
```

### 4.4 DetNet Bounded Latency and PREOF

DetNet operates at Layer-3 [6][5] – IP/MPLS overlay bridging multiple TSN domains. Supports both wireless and wired with PREOF for ultra reliability.

**Timing model** (draft-ietf-detnet-bounded-latency-09 Fig 1-3 [5]):

- End-System → Ingress: regulation delay $d_{reg}$
- Transit Node A: 3 stages – Input Regulators → Queuing Subsystem (FIFO + selection) → Output Queuing
- Internode: Link delay $d_{link}$ (propagation), plus MAC delays.

Total:

$$d_{per-hop} = d_{out} + d_{link} + d_{preempt} + d_{proc} + d_{reg} + d_{queue}$$

End-to-end $D = \sum_h d_{per-hop,h}$ . Non-queuing components static; $d_{queue}$ and $d_{reg}$ dynamic – dependent on competitor flows.

**PREOF** semantics:

- **Replication**: ingress duplicates DetNet flow over $k$ disjoint paths $P_1..P_k$.
- **Elimination**: egress drops duplicates by sequence number within window $W$.
- **Ordering**: reorder buffer ensures in-order delivery bounded by $D_{max}-D_{min}$ across replicas.

Haskell spec for reordering bound:

```haskell
type SeqNum = Int
data DetNetFlow = DF { bw :: Double, bkt :: Int, seq :: SeqNum }

preofElim :: Int -> [Packet] -> [Packet]
preofElim window ps = foldr dedup [] (sortOn seqNum ps)
  where dedup p acc | seqNum p `elem` map seqNum acc = acc
                    | otherwise = p:acc

detnetLatencyBound :: [Hop] -> Double
detnetLatencyBound hops = sum [nonQ hop + qBound hop | hop <- hops]
  where nonQ h = outDelay h + linkDelay h + procDelay h + preemptDelay h
        qBound h = regulation h + queuing h -- via NC
```

**Flow admission** requires resource allocation: For each node and class $X$, ensure $\sum r_{f,X} \le R_X$ (CBS idleSlope condition) and buffer $\ge Backlog bound$. This aligns DetNet queuing subsystem with TSN CBS model.

*Ordered requirements*:

1.  End-system policing via leaky bucket $(r,b)$.
2.  Per-hop service abstraction $(R,T)$ rate-latency.
3.  End-to-end delay computed via min-plus convolution $( \alpha \oslash \beta )$.
4.  Buffer provisioning for zero-congestion loss: $B_h \ge \sup_t (\alpha(t)-\beta(t))$.

Key insight: *Determinism is a control-plane promise – compute bound before flow admission*; if no path satisfies $D \le Deadline$, reject flow (vs Internet best-effort accept and pray).

## 5 Empirical Evaluation / Proofs

### 5.1 TAS Schedulability NP-Hardness and Heuristics

We sketch reduction: Given JSP instance with machines $M_i$ and jobs $J_j$ ops $O_{j,k}$ on $M_{i}$, create TSN flow per job, link per machine, operation duration → frame transmission time, deadline → make-span. Feasible TAS schedule ↔ feasible JSP no-wait schedule (frames can't wait mid-path due to no-wait TAS strategy). Since $J|no-wait|C_{max}$ NP-hard [8], TAS NP-hard.

Empirical 2PDGA [8] dataset:

| Switches | Flows | δgb (ns) | CAP@8 | CAP@16 | Median latency (µs) | GCL entries max |
|----------|-------|----------|-------|--------|---------------------|-----------------|
| 8 | 40 | 0 | 92.9% | 99.8% | 42.1 | 87 |
| 12 | 60 | 100 | 81.3% | 97.2% | 68.4 | 124 |
| 20 | 100 | 200 | 64.7% | 91.1% | 112.6 | 198 |

CAP@k = percentage configs fitting into per-port GCL entry limit $k$. Phase II reduces 7.7% entries – critical for 8-entry hardware (e.g., NXP SJA1110). Genetic population 100, generations 500 → compute 4 min on i7-12700 [8].

### 5.2 CBS Calculus and INET Validation

Using parameters $c=1 Gbps$, $I_A=0.6c$, $I_B=0.15c$, $L_{max}=1522 B$, $r_h=50 Mbps$, we compute:

$$R_A = 0.6c * (c-0.05c)/c = 570 Mbps$$

$$T_A = (1522*8 + 2000 + ...)/0.95c \approx 18 µs$$

Delay for burst $b_t=10*1522B$:

$$d_A = 18µs + (12176B - 64B)/570Mbps ≈ 18µs+ 170µs =188µs$$

over single hop; 7 hops → 1.316 ms < 2 ms Class A deadline.

INET showcase [4] screenshots: credit sawtooth $hiCredit$ ~+12000 bits, $loCredit$ ~-12000 bits, resets to 0 when empty. Smoothness metric: AVB peak-to-average ratio reduced from 8:1 (strict pri) to 1.3:1 (CBS).

Preemption evaluation [search 5] synthetic ring 5 switches line:

- Without FP: AVB Class A 99th 410 µs.
- With FP preemptable: 246 µs → **40%** saving.
- TT jitter with Hold/Release + with GB: <0.5 µs versus 3.2 µs without GB due to overrun blocking.

### 5.3 DetNet Latency Bound Computation and Proof Sketch

Draft-ietf model [5] defines per-output port max_delay456 = queuing (5) + regulation (6). Backlog bound derived above ensures zero loss.

Proof sketch bounded latency composition:

> **Lemma (Min-Plus Concatenation):** Service curve of tandem $h$ nodes $\beta_{e2e}= \beta_1 \otimes \beta_2 \otimes ... \otimes \beta_h$ where $\otimes$ is min-plus convolution. If each $\beta_i = R_i[t-T_i]^+$, then $R_{e2e}=min_i R_i$, $T_{e2e}= \sum_i T_i$.

Hence end-to-end delay for flow with arrival $\alpha = r t + b$ traversing such tandem:

$$D \le b / R_{e2e} + T_{e2e}$$

plus static delays. Since $R_{e2e}$ independent of cross-traffic (admission controlled), bound holds under future flow creation/deletion – dynamic calculation property [5 draft 05].

PREOF replication analysis: With $k=2$ disjoint paths, each with loss prob $p=10^{-4}$, composite loss $p^2=10^{-8}$ if independent (not always true – common-cause shared fate links). Latency penalty of ordering: at most $D_{max,max-min}$ difference between replicas ~ $1.5\cdot T$ for CQF.

## 6 Limitations

- **Clock fragility**: 802.1AS error cascades; 1 faulty grandmaster causes TAS window misalignment → PSFP drops 100% ST. Holdover oscillators mitigate but cost. CQF/ATS still need frequency sync (syntonized) not phase, more robust.
- **GCL scalability**: 802.1Qbv per-port entry limit (typical 64-1024) caps flows; hyperperiod explosion $H = lcm(periods)$. For periods 0.5ms, 1ms, 1.5ms → H=3ms manageable; random coprime periods 0.37ms, 0.41ms → H~152ms infeasible. Industry adopts 2-stage packing or window merging sacrificing isolation.
- **CBS reservation dilemma**: idleSlope sum capped ≤75% per AVB spec to leave BE headroom; dynamic flow creation without recomputing $R_X$ leads to pessimistic $d_X$ (poorer) vs static flow knowledge yields tighter bounds [draft 00 §3.1.2]. Dynamic bound $1.5-2×$ inflated.
- **DetNet-L2 integration complexity**: mapping IP DetNet flows to TSN PCP queues via RFC 9023 requires stateful mapping; regulator subsystem and queuing subsystem often fused in hardware – model mismatch causes implementation divergence; control plane (PCE) needs per-node delay collection via IGP TLVs not yet standardized.
- **Security – weaker threat model**: Draft unbounded in face of malicious node controlling physical link can delay arbitrarily [5 §Security]. Zero-congestion guarantee assumes authenticated conformant sources. Babbling idiot protection via PSFP mandatory; misconfigured leaky bucket floods AP’s backlog.
- **Interop fragmentation**: Three TSN profiles IEC/IEEE 60802 (industrial), 802.1DG (auto), 802.1DF (service provider) choose disjoint shaper subsets – TAS core in all but CBS optional in industrial; AVB optional in auto TAS-only variant. Producer design must pick.

Ordered future work:

1.  *Synthesis algorithms*: Hybrid SMT+GA for 1024-entry caps – learn merge patterns via GNN.
2.  *Long-distance TSN* OT backbone over optical – need 5G integration with DetNet scaling.
3.  *Certifiable worst-case* via formal OMNeT++ to P4 constraint translation.
4.  *Wireless TSN* – Wi-Fi randomized medium access violates bounded latency assumption; prototype reuses present wireless architecture to support TSN traffic [search wireless TSN] – open.
5.  *Energy/production*: Energy-efficient GCL – power-gate PHY during all-gates-closed intervals.

## 7 Conclusion

TSN's determinism is not magic but disciplined composition of *time* and *rate*.

- ***Time-Aware*: 802.1Qbv GCLs** realize time-division multiplexing in Ethernet switches – 8-bit gate vector, cyclic $T_i$, guard bands, Hold/Release preemption interactions – microsecond jitter if schedule feasible (NP-hard) and clocks synchronized via 802.1AS. 2PDGA heuristics with local refinement achieve deployability under entry caps.
- ***Credit-Smoothed*: 802.1Qav CBS** enforces token-bucket-like credit $idleSlope$, $sendSlope$, $hiCredit$/$loCredit$ clipping – smoothes burst, prevents starvation, yields computable $d_X$ bound. CBS softens TAS rigidity for AVB classes; combined with FP yields 40% p99 cut.
- ***Domain-Spanning*: IETF DetNet** lifts bounds beyond LAN by abstracting per-hop service $(R,T)$, sum of $d_{out}+d_{link}+d_{preempt}+d_{proc}+d_{reg}+d_{queue}$, with PREOF replication for $10^{-8}$ loss. Dynamic flow admission computes latency before transmission guarantee.

Together TAS+CBS+CQF+ATS+DetNet form continuum:

- Need *$<1 µs$* jitter, *full sync* okay → TAS.
- Need *bounded average latency*, *no sync* → CBS or ATS.
- Need *trivial computation* → CQF/CSQF $ (h+1)T$.
- Need *routed* → DetNet IP/MPLS.

Future deterministic Internet will be *hierarchical* – optical backbone tunneling independent TSN domains each with its own time domain, plus 5G URLLC segments. Convincing proof: Nokia Bell Labs demonstrations of partitioned scheduling tunneling 5G+IT alongside multiple TSN islands [Nokia search].

*Standing challenge*: bridging theory (network calculus bounds) to practice (P4-switch pipeline implementing GCL + CBS at 100 Gbps line rate with P4-TAS [P4 search]). Verification of P4 table entries mirroring GCL ensures no forwarding stall surpassing guard-band.

We close asserting: deterministic Ethernet is mature enough for deployment – successful automotive zonal backbone and Industry 4.0 isochronous control – but nascent in configurability and observability. Next decade: automated CNC synthesis, certified bounds, and resilient time.
