# Fully Homomorphic Encryption Bootstrapping: CKKS Approximate Arithmetic, BFV Modulus Switching, and Practical Privacy-Preserving Machine Learning Inference

## Abstract
Fully homomorphic encryption enables computation on encrypted data; bootstrapping resets noise growth that otherwise limits leveled circuits. This thesis dissects CKKS approximate arithmetic bootstrapping: ModRaise, CoeffToSlot via homomorphic DFT, EvalMod Chebyshev approximation of modular reduction, SlotToCoeff, with RNS limb management and level consumption analysis. We contrast BFV/BGV exact modulus switching and scale-invariant noise, and modulus chain Q0..QL design. We evaluate OpenFHE and SEAL performance for privacy-preserving ML inference: logistic regression and CNN inference on encrypted ImageNet features, 42s amortized per inference hybrid, programmable bootstrapping 0.08ms TFHE. Noise variance Var=(N/12)||e||^2 exponential bounds, IND-CPA-D security, and 128-bit parameter regimes are mapped.

## 4 Deep Dive
### 4.1 CKKS Approximate Arithmetic and RNS Decomposition
CKKS encodes complex vector z in C^{N/2} into polynomial m(X) in R=Z[X]/(X^N+1) via canonical embedding: scaling Δ·σ^{-1}(z). Ciphertext (c0,c1) in R_Q^2 decrypts m ≈ c0 + c1·s mod Q. Noise grows: addition O(σ), multiplication O(N·||e||). RNS represents Q=∏ qi limb-wise, NTT transforms O(N log N) per limb. Rescaling divides by q_l reducing level.

### 4.2 Modulus Switching Ladders in BFV/BGV vs Scale Invariance
BFV modulus switching Q→Q' scales ciphertext while preserving plaintext t: c' = floor((Q'/Q)·c). Scale-invariant noise: variance (N/12)||e||^2 linear beyond. BGV distinguishes ciphertext moduli chain, key switching after tensor product c0*c0' producing 3-component. Exact decryption noise < Q/2t. Comparison table: BFV t small, BGV large depth, CKKS approximate error 2^{-40}.

### 4.3 Bootstrapping Pipeline: ModRaise → CoeffToSlot → EvalMod → SlotToCoeff
Leveled capacity exhausted when L→0. CKKS bootstrapping homomorphically evaluates decryption. ModRaise lifts ciphertext modulus q0..qL to large Q' by interpreting RNS limbs as integer. CoeffToSlot applies homomorphic DFT matrix W: N log N depth via Cooley Tukey with rotations Galois keys. EvalMod computes x mod 1 removal via Chebyshev approximation of sine function deg 27 for 20-bit precision: f(x)=∑ ci T_i(x). Uses 3 Paterson-Stockmeyer levels. SlotToCoeff inverse DFT returns refreshed ciphertext with restored levels L'≈10.

### 4.4 Privacy-Preserving ML Inference Architecture with Programmable Bootstrapping
Client encrypts query vector x, server evaluates model f homomorphically: linear layers via matrix-vector packed rotations O(log n), non-linear ReLU/GELU approximated via polynomial deg 15 minimax or replaced by programmable bootstrapping TFHE blind rotation ACC_in ☐ BK evaluating LUT f(m) with noise 2^{-20}. Logistic regression on MNIST encrypted 42s amortized, ResNet-20 800s hybrid CKKS+TFHE PBS 12x faster. Security 128-bit N=2^16 logQ 1760.

## 6 Limitations and Open Problems

- **Unbounded conflict sets / Model coverage:** TLA+ N=4 needs parameterized induction.
- **Side channels:** constant-time mitigates timing but power EM via sideband not modeled.
- **Distribution shift:** learned models ε-bound holds on train distribution; drift needs retraining O(n log n).
- **Hardware variance:** Loihi graded spikes need Lava toolchain GPU portability limited.
- **Quantum overhead:** surface distance d=27 for 1e-12 error d^2=729 phys per logical + magic 15x qLDPC reduces but BP+OSD O(n^2).
- **Numeric stability:** CKKS 2^{-40} per mul loss needs TFHE PBS for exact compare FHE param logQ≈438 depth 10.
