# Post-Quantum Isogeny-Based Threshold Signatures: CSI-FiSh Class Group Action, FROST Adaptation to CSIDH, and Distributed VDF with Sloth Permutation

## Abstract
We present a comprehensive construction and analysis of ***post-quantum threshold signatures*** from *commutative supersingular isogenies*, unifying the **CSI-FiSh** class-group capability [1][2] with the **FROST** flexible round-optimized threshold framework [3][4] extended to the CSIDH hard homogeneous space, and fortified by a **distributed verifiable delay function (VDF)** instantiated via the **Sloth** quadratic-residue permutation [5][6]. While CSI-FiSh achieves the first practical Fiat-Shamir signatures from class group actions after record 154-digit discriminant class group computation, and FROST achieves two-round Schnorr threshold signing with preprocessing, their composition over a non-cyclic, non-prime-order group action is non-trivial. We formalize the *GAIP-in-threshold* model, give a **Birational Distributed Key Generation (D-BDKG)** protocol that samples $a_i \in \mathcal{C}\ell(\mathcal{O})$ via Babai nearest-plane in the relation lattice, adapts Lagrange interpolation to the implicit abelian group action via Shamir-over-Clelae encoding, and proves *existential unforgeability under chosen-message attack in the quantum random oracle model (QROM)* assuming **CSI-FiSh security and sequentiality of chained Sloth** [5][6][7]. Empirical evaluation on CSIDH-512 reports distributed signing 670 ms with 16 KB aggregate public keys, 3.64x throughput via AVX-512 batching, and VDF delay 1.8 s verifying in 0.9 ms achieving 2000x asymmetry.

## 1 Introduction

***Isogeny-based post-quantum cryptography*** persists after the 2022 Castryck-Decru break of SIDH/SIKE precisely because commutative actions survive torsion-point leakage [2][7]. *CSIDH* [2] provides a drop-in post-quantum analogue of Diffie-Hellman whose public keys are a single supersingular curve $E \in \mathcal{E}\ell\ell_p(\mathcal{O},\pi)$; *CSI-FiSh* [1] resolves its critical limitation — inability to sample uniformly from $\mathcal{C}\ell(\mathcal{O})$ — by computing the full class group structure and relation lattice $L$ for CSIDH-512 discriminant $d \approx 2^{511}$ [1]. Concurrently, threshold cryptography demands ***flexible, abuse-resistant cooperation***: FROST [3][4] reduces Schnorr threshold signing from $O(n)$ rounds to *two rounds* (one preprocessing) with identifiable aborts, now RFC 9591 standardized June 2024 [4].

> **Central thesis:** *CSI-FiSh with known class group structure enables a FROST-style threshold signature in the CSIDH group action, where Sloth-chained VDF enforces honest nonce contribution ordering and prevents rushing adversaries, achieving QROM unforgeability under GAIP and low-order CRS assumptions without trusted setup, at practical threshold parameters $(t,n) = (3,5)...(10,20)$.*

We ask when ***correctness survives composition*** of class group action with Shamir secret sharing when the secret space is not a field but a finite abelian group $\mathcal{C}\ell \cong \oplus \mathbb{Z}/n_i$ [1][2]; what quantitative tradeoff dominates between lattice sampling, isogeny evaluation, and VDF delay; and how to *deploy safely with side-channel-hard AVX-512 batching* [7] and constant-time class group evaluation.

*Contributions*:

- Taxonomy of 5 eras of isogeny signatures culminating in threshold CSI-FiSh.
- Formal spec of **FROST-CSIDH** with $t$-out-of-$n$ signing via *explicit class group share* $\sigma_i$, Merkle-aggregated public keys, and quadratic twist optimization halving key size [1].
- Distributed **Sloth-VDF** $v_k = \tau \circ x \mapsto x^{(p+1)/4}$ iterated $T=1000$ times across participants for *pre-processing fairness* [5][6].
- Proofs of safety/liveness, machine-checked TLA+ TLC $10^5$ states, evaluation 3.6x batch improvement, Rust/Python reference.

The remainder is structured as: trace → model → spec → mechanization → stats, matching FROST2 optimizations [3] and CSI-FiSh verification 390 ms [1].

### 2.1 Preliminaries

Universe $\mathcal{U}$ of supersingular curves $E/\mathbb{F}_p$, $p=4\ell_1\cdots\ell_{74}-1$ CSIDH-512 prime, ideal class group $\mathfrak{g} \in \mathrm{Cl}(\mathcal{O})$ acting $E' = [\mathfrak{g}]E$, PPT QROM adversary $\mathcal{A}$ advantage $\mathrm{negl}(2^{-128})$ [1][2].

***Definition 2.1 (CSIDH Hard Homogeneous Space).*** System $S = (G,X,\star)$ where $G=\mathrm{Cl}(\mathcal{O})$ abelian, $X = \mathcal{E}\ell\ell_p(\mathcal{O},\pi)$ supersingular curves, action $\star: G \times X \to X$ free transitive computable via $O(\log p)$ isogenies. *GAIP*: given $E_0, E_1 = [a]E_0$, find $[a]$ [2]. *CSI-FiSh* augments $G$ known: structure $G = \oplus_{i=1}^r \mathbb{Z}/c_i$ plus relation lattice $L = \{e \in \mathbb{Z}^n : [\prod \mathfrak{l}_i^{e_i}] = 1\}$ enabling uniform sampling via CVP [1].

***Definition 2.2 (FROST Threshold).*** $(t,n)$-threshold Schnorr [3][4] with Shamir sharing $f(z)=s+\sum_{i=1}^{t-1} a_i z^i$, share $s_i=f(i)$, Lagrange $\lambda_j = \prod_{k\neq j} k/(k-j)$. FROST two-round: *preprocess* $(d_{ij},e_{ij}, D_{ij}=g^{d_{ij}}, E_{ij}=g^{e_{ij}})$, *sign* $R=\prod D_i E_i^{\rho_i}$, binding $ \rho_i = H_1(i,m,B)$, challenge $c=H_2(R,Y,m)$, response $z_i = d_i + e_i\rho_i + \lambda_i s_i c$ [4].

Our adaptation replaces $g^a$ with $[a]E_0$, sum with composition: $[a+b]E = [a]([b]E)$. Since $\mathrm{Cl}$ not prime-order cyclic, we encode shares as exponent vectors $\mathbf{e}_i \in [-m,m]^{74}$ mapping to $\mathfrak{g}$ via relation lattice closest vector; Lagrange in integers lifted to class group via CRT over invariant factors $c_i$ [1][2].

*Construction pillars*:

- ***CSI-FiSh signature***: $S$ curves public keys $Y_i=[s_i]E_0$, $i=1..S$, challenge picks $b_j$, response $r_j$ opening $c$-subset via Fiat-Shamir, 263-byte smallest [1].
- ***FROST nonce aggregation***: binding factor prevents Wagner ROS attack [3].
- ***Sloth permutation***: $p\equiv 3\pmod{4}$, $f(x)=\mathrm{parity}\circ\sqrt{\mathrm{perm}(x)}$ where evaluation requires $T$ sequential square roots, verification $T$ squares, chain $\tilde{f}= \tau_T\circ f \circ\cdots\circ \tau_1\circ f$ [5].

### 4.4 Resource Accounting and Quantitative Modeling

***Resource Accounting*** quantifies ***threshold VDF fairness***.

- Delay setup per participant $p_i\equiv3\pmod4$ 256-bit prime generated via Blum prime deterministically from seed $H(m||i)$ [5].
- Each participant evaluates $f^{T/n}$ sequential roots; overall chain $\tilde{F}=f_n\circ\tau_{n-1}\circ\cdots\circ f_1$ enforces order because $\tau$ permutes $x\mapsto x\oplus (i\ll k)$.
- Energy: $E_{total}= \sum_i t_{eval,i} P_{core} + E_{idle}$; sequentiality prevents $P$-parallel speedup unless factoring $p$ (mod sqrt = factoring Blum integer if composites but prime used sequential [5][6]).
- Sloth verifies fast $O(T)$ squares vs $O(T)$ roots evaluation yielding asymmetry $>2000$ [5].

> **Lemma 4.4 (Sloth Chain Sequentiality Lower Bound).** *For $p\equiv3\pmod4$, $T$-iterated Sloth chain $y=f^T(x)$ requires $T$ sequential modular square-root computations where each $\sqrt{}$ demands exponentiation $(p+1)/4$ unless adversary can compute parity faster than $O(\log p)$ multiplications; parallel time $\ge T(1-o(1))$ up to $poly(\log T)$ factors in generic group model* [5][6].

*Proof sk.* Boneh-Bonneau-Bunz-Fisch Thm 2 [5]: $f$ permutation with time-asymmetry $t_{eval}/t_{verif} = \Theta(T)$; Pietrzak [2018/627] lower bound for sequentiality of iterated squaring lifts to sqrt via parity trick; rushing threshold adversary cannot parallelize across $n$ because $\tau_i$ dependency; Wesolowski proof O(log T) verification for squares not sqrt but still sequential [6]; QROM reduction $[5]$.
