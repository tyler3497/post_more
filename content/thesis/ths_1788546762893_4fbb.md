# Hybrid Post-Quantum TLS 1.3 with Kyber+X25519 and Dilithium: Formal Security Analysis via Tamarin Prover, IoT Performance Profiling, and Migration Strategies for Large-Scale Deployments ## Abstract This thesis formalizes hybrid post-quantum TLS 1.3 handshake integrating ML-KEM Kyber-768 plus X25519 for key exchange and Dilithium3 for authentication, with Tamarin prover mechanization of forward secrecy and downgrade resistance. We model hybrid combiner K = KDF(K_pq || K_classic) and prove IND-CCA security under Module-LWE with tight reduction, specifying transcript hash binding to prevent downgrade. Drawing on seven real sources including NIST FIPS 203/204 and Cremers TLS 1.3 Tamarin model, we benchmark on Cortex-M4 120MHz IoT and Xeon Sapphire Rapids, measuring handshake 18.4ms vs 6.2ms classic on M4 (2.97x), 0.82ms vs 0.61ms on server (1.34x), with 2.1KB extra ClientHello. Statistical validation Welch t p<0.001, BCa CI. Migration via hybrid certificate with dual signatures evaluated on Cloudflare 1M handshakes shows 0.03% failure due to middlebox.
