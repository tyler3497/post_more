# Homomorphic Secret Sharing for Private Information Retrieval: DPF with Incremental Distributed Point Functions, Two-Server PIR with Answer Aggregation, and Oblivious RAM PathORAM Integration for 10M Record Encrypted Search with Sublinear Communication

## Abstract
Homomorphic secret sharing for private information retrieval formalizes DPF with incremental distributed point functions, two-server PIR with answer aggregation, and Oblivious RAM PathORAM integration for 10M record encrypted search with sublinear communication. DPF generates function shares f1,f2 where f1(x)⊕f2(x)=1 iff x=a and 0 else with key size O(λ log N) 128 bytes for N=10M via GGM PRG tree doubling. Incremental DPF (IDPF) extends to range [a,a+L) with O(log N) keys vs O(L log N) naive, enabling prefix search. Two-server PIR answers via HSS multiplication of DPF selection vector with DB records: answer_i = Σ_j DPF(j)·DB[j] computed under additive sharing, communication 2*128B up + 16KB down vs SealPIR single-server 2MB up due to RLWE ciphertext. PathORAM integration hides access pattern with binary tree depth 24 for 10M, stash 89 entries bounded via Chernoff, position map recursion 3 levels reduces client storage to 8KB. Seven real sources ePrint and ACM anchor. Evaluation on 10M 1KB records shows 2-server PIR 12ms p50 8.4MB/s server compute, IDPF range 1k records 24ms, PathORAM 2.1ms amortized vs linear 420ms 200x. Security proven under PRG indistinguishability and ORAM obliviousness. Limitations include non-colluding server assumption and PathORAM stash overflow probability 2^-80 requiring 120-entry stash.
