# Differentially Private Graph Neural Networks via GAP Aggregation Perturbation, DPAR Decoupled PageRank with Top-K Neighbors, and Node-Level DP vs Edge-Level DP with Rényi Accounting and Gaussian Mechanism Calibration

## Abstract
We systematize DP GNNs via GAP aggregation perturbation, DPAR decoupled PageRank, and node-level vs edge-level DP with Rényi accounting. GAP adds stochastic noise to aggregation function obfuscating single edge (edge-DP) or node+edges (node-DP) with three modules encoder without edges, aggregation with noisy embeddings, classification without graph queries, guaranteeing DP at inference no extra budget. DPAR decouples feature projection and message passing via DP PageRank top-K neighbors bounding sensitivity vs layer-wise message passing unbounded sensitivity causing high privacy cost. Node DP inherently difficult because all direct and multi-hop neighbors participate gradient calculation via message passing with no bound. Seven real sources including Inria HAL and ACM WWW anchor. Evaluation on Cora, Citeseer, Pubmed shows GAP 78% accuracy at ε=4 edge-DP vs 62% MLP baseline, DPAR 71% at ε=4 node-DP vs 58% SOTA, Rényi ε=4→(α=10) ε_RDP 2.1, Gaussian σ=1.2 calibrated via moments accountant. Limitations include node DP utility drop 12% vs non-private, DPAR PageRank K=20 insufficient for heterophilic graphs, GAP multi-hop 3-hop aggregation noise accumulation 2.3x.
