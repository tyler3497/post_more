import math, random
def build_cover(sorted_keys, eps=64):
    segs=[]; i=0; n=len(sorted_keys)
    while i<n:
        j=i+1; slope=0.0; intercept=sorted_keys[i]
        while j<n and abs((sorted_keys[j]-intercept)-slope*(j-i))<=eps:
            if j>i: slope=(sorted_keys[j]-sorted_keys[i])/(j-i)
            j+=1
        segs.append((i,j-1,slope,intercept))
        i=j
    return segs

## 6 Limitations

1. Honest majority / benevolent scheduler BFT bound n>=3f+1 assumed [1] rational deviation may degrade liveness not safety [2][6].
2. Scope formal model TLC N=4 1e5 states parameterized N=4096 proof induction not machine-checked [3].
3. Side channels constant-time mitigations timing leakage [3] power/EM telemetry sideband health [6] not modeled TDX attestation TOCTOU 40ms [1].
4. Distribution shift CDF rank epsilon-bound holds trained D drift Zipf 0.6->1.2 invalidates requires periodic retrain O(n log n) [2][4].
5. Hardware variance H100 CC TC 0.9% overhead avg 3.2% tail SPDM contention [1][7] CXL switch 8-12us extra [2].
6. Quantum/FP overhead surface code distance d=27 for 1e-12 logical 729 phys/logical plus 15x magic factories SPARO [5][7] mitigates gaps qLDPC.
