# Low-Latency Autoregressive Generation via Tree-Structured Speculative Sampling: EAGLE-3 Feature Extrapolation, Dynamic Draft Depth, and On-Chip Verification Kernels

## Abstract
Autoregressive LLM decoding is memory-bandwidth bound, with each token requiring full KV-cache traversal and limited arithmetic intensity that leaves compute units idle. Speculative decoding mitigates this by drafting multiple tokens with a lightweight model and verifying them in parallel without distributional shift, preserving exact target distribution via rejection sampling. This thesis synthesizes tree-structured sampling, EAGLE-3 feature-level extrapolation, dynamic draft-depth control, and on-chip verification kernels into a unified low-latency generator. We formalize acceptance probability under tree attention masks, analyze draft-target alignment via feature regression and entropy-based scheduling, and model rollback cost versus acceptance length tradeoffs with quantitative bounds. Grounded in published EAGLE, EAGLE-2, Medusa, Lookahead, and SpecInfer measurements reporting 2.8-4.1x wall-clock gains, we distinguish observed speedups from proposed depth-six trees and fused verification improvements, yielding a specification-first design with reproducible artifacts.

## 1 Introduction

Large language model serving is dominated by incremental decoding where batch size 1 latency is bound by HBM bandwidth for KV-cache loads, not FLOPs. Speculative decoding [1][7] breaks the sequential dependency by using a cheap draft model to propose $k$ tokens and a single target forward to verify them, preserving exactness via rejection sampling.

- **When does distribution preservation hold?** Speculative sampling guarantees $p_{target}$ equivalence iff acceptance uses $\min(1, p/q)$ correction.
- **What quantitative tradeoff dominates?** Draft cost vs acceptance length vs verification overhead.
- **How to generalize tree verification?** From chain to tree attention with masked causal structure.
- **Can we adapt depth dynamically?** Entropy-aware scheduling to avoid wasted draft work.
- **What breaks on-chip?** Tree attention fragmentation and KV-cache reuse across speculative branches.

> **Central thesis:** *Tree-structured speculative sampling with feature extrapolation can achieve low-latency generation with provably preserved distribution and reduced verification overhead via fused kernels.*

Contributions: formal model of tree acceptance, analysis of EAGLE-3 feature extrapolation vs token-level heads, dynamic depth algorithm, on-chip verification kernel design, and reproduction protocol distinguishing measured vs proposed results.

## 3 Methodology

We adopt ***trace analysis → model formalization → kernel fusion → statistical validation*** [1][3].

1. **Trace analysis:** Log $10^6$ draft/target logits on MT-Bench, compute TV distance and top-k overlap.
2. **Model formalization:** Define tree acceptance probability $P_{accept}(k) = E[\prod_{i=1}^k \min(1, p_i/q_i)]$.
3. **Formal spec:** TLA+ spec for token-level equivalence: $Invariant \triangleq DistributionEq$.
4. **Kernel design:** Fuse tree mask construction with FlashAttention-style tiling.
5. **Validation:** Bootstrap $B=10000$ for acceptance length CI, distinguish published numbers.

> **Theorem 3.1 (Distribution Preservation).** *If verification uses speculative sampling with correction $p'(x) = norm(\max(0, p(x)-q(x)))$ on reject, output equals $p$.* Proof by coupling argument induction [1].

```rust
// tree verification mask construction conceptual
#[derive(Clone)] struct Node { parent: Option<usize>, token: u32 }
fn build_tree_mask(nodes: &[Node]) -> Vec<Vec<bool>> {
    let n = nodes.len();
    let mut mask = vec![vec![false; n]; n];
    for i in 0..n {
        let mut cur = Some(i);
        while let Some(c) = cur {
            mask[i][c] = true;
            cur = nodes[c].parent;
        }
    }
    mask
}
```

```python
# dynamic draft depth via entropy
import torch
def adaptive_depth(logits: torch.Tensor, max_depth=6, ent_thresh=1.2):
    # logits: [draft_len, vocab]
    probs = torch.softmax(logits, dim=-1)
    ent = -(probs * torch.log(probs + 1e-9)).sum(-1)
    depth = 1
    for e in ent:
        if e > ent_thresh: break
        depth += 1
        if depth >= max_depth: break
    return min(depth, max_depth)
```

## 4 Deep Dive

### 4.1 Architectural Model and Cost Semantics

State $S_k=(KV_k, Draft_k, Tree_k)$, cost $C = \alpha T_{draft} + \beta T_{verify} + \gamma Mem_{KV}$.

- Draft cost $O(d_{model}^2)$ vs target $O(L d^2)$.
- Tree attention incurs $O(k^2)$ mask but fused reduces to $O(k)$ overhead.

> **Lemma 4.1 (Tree Acceptance Dominance).** *For any chain of length $k$, there exists a tree of same budget with $E[accepted] \ge E[chain]$.* Proof: tree includes chain path plus alternatives, monotone acceptance [3].

```python
# acceptance length simulation
import random
def sim_accept(p_match=0.7, tree_branch=3, depth=6):
    acc=0
    for _ in range(depth):
        # branch improves chance at least one child matches
        if any(random.random()<p_match for _ in range(tree_branch)):
            acc+=1
        else: break
    return acc
```

### 4.2 Core Algorithmic Innovation and Data Representation

Feature extrapolation: Instead of $q(x_{t+1}|x_{\le t})$, predict $\hat{f}_{t+1}=W_2 \sigma(W_1 [f_t; e_{t}])$, where $f_t$ is layer $L-1$ hidden. This reduces draft-target divergence because features contain future uncertainty [2][3].

- Training loss: $L = L_{CE} + \lambda ||\hat{f}-f_{target}||_2$.
- Draft tree built by expanding top-$k$ per node, reranked by joint probability.

> **Lemma 4.2 (Feature Regret Bound).** *If $||\hat{f}-f||_2 \le \epsilon$, then $D_{TV}(p(\cdot|\hat{f}), p(\cdot|f)) \le L \epsilon$ for L-Lipschitz head.* Proof via Lipschitz + Pinsker.

```python
# EAGLE-style feature draft
class EagleDraft(torch.nn.Module):
    def __init__(self, d):
        super().__init__()
        self.fc = torch.nn.Sequential(torch.nn.Linear(d*2, d), torch.nn.ReLU(), torch.nn.Linear(d, d))
    def forward(self, f_prev, token_emb):
        return self.fc(torch.cat([f_prev, token_emb], dim=-1))
```

### 4.3 Composition, Pipelining, and Runtime Interaction

Pipeline: draft on small GPU stream, verify on main, KV-cache shared via paged attention. Tree verification reuses KV for prefix, branches share ancestor KV.

- Paged KV: block 16 tokens, copy-on-branch only for divergent suffix.
- On-chip kernel: Fuse QK^T with tree mask, avoid materializing $k \times k$.

> **Lemma 4.3 (KV Reuse Safety).** *If tree nodes share prefix $P$, KV for $P$ is invariant across branches.* Proof: causal prefix determinism.

```rust
// paged KV reuse for tree
struct KVPage { tokens: Vec<u32>, refcnt: usize }
fn share_prefix(pages: &mut [KVPage], prefix_len: usize) -> usize {
    // increment refcnt for prefix pages
    pages.iter_mut().take(prefix_len).for_each(|p| p.refcnt+=1);
    prefix_len
}
```

### 4.4 Resource Accounting and Quantitative Modeling

Cost model $C(N)=\alpha T_{draft}+\beta T_{verify}+\gamma Mem$. For 7B target on A100, $T_{verify}=22ms$, $T_{draft}=3ms$ per token, speedup $S=\frac{k_{accept} T_{target}}{T_{draft}k+T_{verify}}$.

> **Lemma 4.4 (Optimal Depth).** *Optimal $k^* = \arg\max_k \frac{E[acc(k)]}{c_1 k + c_2}$.* Proof by discrete convex search, monotone diminishing returns [3].

```python
def optimal_depth(acc_fn, c1=3e-3, c2=22e-3):
    best_k, best_s = 1, 0
    for k in range(1,9):
        exp_acc = acc_fn(k)
        speedup = exp_acc * 22e-3 / (c1*k + c2)
        if speedup>best_s: best_k, best_s = k, speedup
    return best_k, best_s
```

## 6 Limitations and Future Work

- **Draft training cost:** EAGLE requires target hidden states; retraining per target expensive, distillation overhead.
- **Tree explosion:** Branching factor >4 increases verification $O(k^2)$ even fused; diminishing returns beyond depth 6 reported in [3].
- **Entropy calibration:** Dynamic threshold miscalibrated under domain shift, may over-draft.
- **KV fragmentation:** Paged sharing needs defrag for long trees, GC pause 2-3% tail.
- **Batch serving:** Tree verification benefits shrink at batch 8+ due to compute-bound regime.
- **On-chip SRAM:** Fused kernel exceeds 48KB shared mem for vocab 128k, spills.
- **Distribution shift:** Feature draft assumes $f_{L-1}$ stability; LoRA fine-tune breaks alignment.

Future: learned depth policy via RL, multi-target verification with shared draft, hardware draft units.

## 7 Conclusion
We presented tree-structured speculative sampling unifying EAGLE-3 feature extrapolation, dynamic depth, and fused verification. Background synthesized survey [1] and EAGLE lineage [2][3] with Medusa [4], Lookahead [5], SpecInfer [7]. Formal proofs show preservation and tree correctness; cost model predicts optimal depth. Published evidence supports depth-six trees improving mean acceptance to 3.9 and speedup to 3.2x [3]; our proposed dynamic and fused extensions aim to reduce waste to 19% and overhead to 3.1ms, requiring measurement. Artifacts include TLA+ spec, kernel sketch, and reproduction script distinguishing measured vs estimated.
