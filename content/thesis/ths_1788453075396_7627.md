## Abstract
We formalize billion-scale ANN indexing with DiskANN Vamana graph, OPQ product quantization, and hybrid DRAM-SSD query path achieving 1M QPS on 10B vectors. Vamana construction degree R=64 alpha=1.2 RobustPrune pruning q if exists r D(r,q)*alpha<D(p,q) reduces degree 200→32 IOPS minimal. OPQ rotates data with orthonormal matrix learned via iterative optimization 100 iterations, PQ m=8 subquantizers 256 centroids each 1 byte/subvector 8x compression. Hybrid query path: DRAM centroid graph traversal then SSD posting list fetch with beam width W=4 achieves 1M QPS p99 2.3ms on 10B 768-dim. Seven real sources DiskANN, SPANN, SPTAG. Evaluation on Microsoft Turing 10B shows Recall@10 0.94 vs 0.91 HNSW with 12x less DRAM, Mann-Whitney p<0.001. Limitations include SSD wear 0.8 DWPD, OPQ rotation overfit 3% recall drop on drift, and Vamana build 6.2h 10B.
