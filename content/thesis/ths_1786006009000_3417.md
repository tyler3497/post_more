# Type Theory Foundations for Proof Assistants: System Fω, Calculus of Constructions, Homotopy Type Theory Univalence, and Lean 4 Elaboration with Universe Polymorphism

## Abstract
Type theory underpins proof assistants: System Fω extends System F with type operators and kinding Omega, polymorphic lambda abstraction over types and kinds, kind checking Star and K1=>K2 enabling higher-kinded polymorphism. Calculus of Constructions adds dependent Pi types impredicative Prop vs predicative Type hierarchy, strong normalization, and Curry-Howard correspondence for constructive logic. Homotopy Type Theory introduces identity as path space, higher inductive types circle S1 base loop, univalence equivalence (A≃B)≃(A=B) via transport. Lean 4 elaboration engine macro expansion, term elaboration with metavariables, universe polymorphism Type u, Type v, level constraints solving with impredicative Prop, kernel checking with definitional equality. We model universe tower Prop:Type0:Type1, Elaborator monad, and Lean4 QPF representation, comparing Coq, Agda, Lean proof term efficiency.
