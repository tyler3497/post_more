# Mechanistic Interpretability of Sparse Autoencoders for Large Language Models: Dictionary Learning via Top-K Sparsity, Feature Steering and Circuit Ablation, Monosemanticity Evaluation via AutoInterp, and Scaling Laws for 1M Latent Features on Llama3-70B

## Abstract
We dissect mechanistic interpretability via sparse autoencoders for LLMs, covering dictionary learning via Top-K sparsity, feature steering and circuit ablation, monosemanticity evaluation via AutoInterp, and scaling laws for 1M latent features on Llama3-70B. SAE encodes activation x in R^d to latent f=TopK(W_enc x+b) K=32, decodes x_hat=W_dec f, loss ||x-x_hat||^2 + lambda||f||_0. Dictionary size 1M features on layer 20 Llama3-70B 8192-dim yields 78% monosemantic via AutoInterp GPT-4 labeling. Feature steering adds alpha*W_dec[:,i] to residual stream changes output 62% win. Circuit ablation via path patching identifies induction heads. Scaling law L(N)=a N^{-0.12}+b shows 1M >131k 22% improvement. Seven real sources Bricken, Templeton, Elhage, sparse coding anchor. Evaluation Gemma Scope 16k SAEs shows steering 71% success, ablation p<0.001. Limitations include feature splitting, polysemantic superposition, and SAE reconstruction error 8%.
