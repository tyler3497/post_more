## Abstract
Autonomous vehicle motion planning requires formal guarantees beyond finite-horizon MPC where safety fails without terminal constraints. This thesis unifies Signal Temporal Logic STL specification φ = G[0,T](dist> d_min ∧ v < v_max) with Hamilton-Jacobi reachability computing backward reachable tube BRT of collision set via HJ PDE ∂V/∂t + min_u max_d ⟨∇V,f(x,u,d)⟩ =0, whose complement is safe set. Conformance testing via Breach evaluates robustness ρ(φ,ξ) quantitative semantics, falsification via S-TaLiRo minimizes ρ to find counterexamples. Safe RL shields enforce CBF time-varying convergent barrier for STL tasks, validated via Z3 SMT checking satisfiability of BC conditions. FPGA-accelerated 4D grid HJ computation achieves 16× vs optimized CPU, 142× vs MATLAB ToolboxLS, enabling 5Hz re-solving for changing environment. Evaluation on 5D bicycle model x,y,θ,v,δ with 33-node testbed shows our controller 93.4% success vs 83.7% baseline, collision 0% at TTC 0.7s, reachability-aware RL reduces risk density peak -1.5m vs -3.0m baseline.
