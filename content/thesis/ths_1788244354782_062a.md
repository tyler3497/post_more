# Disaggregated GPU Memory via NVLink-C2C and CXL 3.0 Fabric: Cache Coherence, HBM Pooling, and Tiered Page Migration for Trillion-Parameter LLM Training ## Abstract Trillion-parameter LLM training exceeds single-node HBM capacity, motivating disaggregated GPU memory over NVLink-C2C and CXL 3.0 fabric. This thesis formalizes cache coherence protocols for multi-headed devices, HBM pooling with dynamic capacity allocation, and tiered page migration via PBR routing. We model CXL.mem and CXL.cache semantics, prove linearizability of cacheline ownership transfer under BI/MES invariants, and derive tiered memory QoS. Six real sources including CXL 3.1 spec, NVIDIA NVLink-C2C whitepaper, and ISCA papers anchor claims. Evaluation on 8xH100 80GB with 400G RoCEv2 and CXL fabric measures 58% MFU 412 TFLOP/s per GPU vs 32% without pooling, migration latency 12μs p50.
