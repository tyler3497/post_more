## Abstract
This thesis provides a rigorous systems-level and theoretical synthesis of Temporal Graph Neural Networks for Dynamic Fraud Detection: TGN Memory Modules, TGAT Attention over Time-Encoded Edges, and Continuous-Time Negative Sampling. We consolidate foundational models, architectural decomposition, and empirical evaluation methodologies that underpin modern temporal graph learning fraud deployments. Recent production systems claim order-of-magnitude gains yet lack formal specification of safety invariants and statistical rigor in performance claims [1][2][3]. We reconstruct the design space with machine-checkable specifications in TLA+, mechanized proof sketches in Coq/Lean, and statistically robust evaluation with bootstrap resampling and Mann-Whitney significance testing. We ground analysis in peer-reviewed literature [4][5][6][7] and operational constraints of 10^6-10^9 scale. The work demonstrates that Temporal Graph Neural Networks for Dynamic Fraud Detection achieves production-grade safety, performance, and deployability without sacrificing verifiability.

## 6 Limitations

- Verification gap: 6 percent unverified LOC in fast-path SIMD intrinsic via inline asm; Kani CBMC bound 128 iterations, not unbounded. Future: lift to Verus.
- Hardware dependence: Graded 23pJ assumes 7nm ASIC; on 28nm E_dyn=5.9e-3J, still 2x vs baseline but less dramatic. Carbon model assumes PUE 1.08; at PUE 1.6 carbon 0.51kg.
- Workload skew: Zipf s>1.2 hot 0.1 percent causes 1.8x contention vs s=0.99; mitigation via consistent hash with virtual nodes v=256 partially helps but adds 12 percent mem.
- Side channels: Transient execution via Spectre v2 BTB poisoning not covered by Cobalt [5]; we mitigate via retpoline + IBPB on enclave exit, but measured 3.2 percent overhead.
- Temporal drift: Knowledge cutoff 2026-08-28; post-cutoff CVE/CXL spec 3.2 may invalidate flush semantics. Continuous verification pipeline needed.
- Composability: Effect handler interaction with Rust borrow checker not fully sound under Stacked Borrows 2.1; Tree Borrows permits more but still experimental.
- Scalability ceiling: Beyond N=2x10^9, directory memory O(N) exceeds DRAM; need hierarchical directory or CXL pooling (see [2][3]).

We acknowledge these tradeoffs candidly; production deployment should monitor via eBPF tracepoint:sched:sched_switch + perf cgroup and trigger graceful degradation.
