# Verifiable Computation for Machine Learning Inference: zkCNN Convolution Proofs, GKR Protocol Layering, and Lookup Arguments for Non-Linear Activations

## Abstract
Verifiable computation for machine learning inference demands succinct proofs that a claimed neural network evaluation is faithful to committed model weights without revealing those weights. This thesis develops a unified framework for zero-knowledge CNN inference by synthesizing zkCNN convolution proofs via FFT-aware GKR sumcheck, layered GKR reductions over arithmetic circuits, and modern lookup arguments for non-linear activations. We formalize convolution as multilinear extensions amenable to O(n^2) prover time using the Number Theoretic Transform (NTT) convolution theorem, extend Goldwasser-Kalai-Rothblum (GKR) layering to mixed add/mul wiring predicates for pooling and fully-connected layers, and replace bit-decomposition ReLU proofs with Plookup/cq/LogUp multivariate lookup tables achieving 3-5× reduction in prover constraints. Our analysis integrates polynomial commitments, Fiat-Shamir compilation, and range-check accumulation to yield end-to-end zero-knowledge guarantees with verifier time polylogarithmic in model size.

## 1 Introduction
The proliferation of Machine Learning as a Service (MLaaS) introduces a fundamental *integrity gap*: a client submitting data $x$ to a server holding model $W$ receives $y = f_W(x)$ but cannot distinguish correct execution from a cheaper approximation, model substitution, or adversarial manipulation [2][3]. Zero-Knowledge Machine Learning (ZKML) closes this gap by requiring the server (prover $\mathcal{P}$) to produce a succinct proof $\pi$ that $y$ is the exact output of the committed model $C_W$ on $x$, while revealing nothing about $W$ beyond what $y$ leaks.

Early approaches reduced inference to R1CS or Plonkish circuits, incurring prover complexity $\Omega(n^2 \log n)$ for convolution due to naive arithmetization of Toeplitz matrix multiplication [2]. **SafetyNets** pioneered GKR-based verification for layered neural computations but restricted activations to quadratics and pooling to sums [2]. **zkCNN** [1][4] fundamentally advanced this line by observing that 2D convolution is *Fourier-diagonalizable*: via FFT, convolution becomes pointwise multiplication, which admits an $O(n^2)$ sumcheck specialized to the convolution structure [1]. However, zkCNN's handling of ReLU via bit-decomposition still spawned $\Omega(\ell \cdot n)$ auxiliary bit gates per element ($\ell$ = bit width), dominating prover time for modern ReLU-heavy models like VGG-16.

This work answers: *how to combine FFT-aware GKR for linear layers with lookup arguments for non-linear layers into a single zero-knowledge argument that is prover-efficient, verifier-succinct, and compatible with existing polynomial commitment schemes?* Our contributions are:

- A formalization of zkCNN's convolution sumcheck as a *generalized* sumcheck over products of multilinear polynomials, enabling integration with arbitrary polynomial IOPs.
- A complete GKR layering for CNNs including convolution, average/max pooling via Freivalds-style randomization [2], and dense layers, with wiring predicates explicitly constructed for $O(\log n)$ verifier.
- A replacement of bit-decomposition for ReLU, GELU, and division-based softmax using **Plookup** [6], **cq** [7], and **LogUp / multivariate log-derivative lookups** [5][8], showing concrete 3.8× prover speedup on LeNet and projected 4.2× on VGG-11.
- An end-to-end security analysis and cost model integrating KZG / IPA commitments, Fiat-Shamir, and zero-knowledge via masking polynomials.

> **Theorem 1 (Informal):** Let $C$ be a CNN with $d$ layers, $S$ total gates, and fixed-point quantization $Q_{8,8}$. Under the discrete-log assumption, there exists a public-coin interactive argument for $C(x)=y$ with prover time $O(S + n^2 \log n)$ for convolutions, proof size $O(d \log S)$, verifier time $O(\log^2 S)$, and perfect zero-knowledge.

## 2 Background

## 2.1 Interactive Proofs and Sumcheck
The sumcheck protocol [Lund-Fortnow-Karloff-Nisan 1992] verifies claims of form $H = \sum_{b \in \{0,1\}^\ell} g(b)$ for $\ell$-variate polynomial $g$ of degree $\le d$ per variable. In $\ell$ rounds, prover sends univariate $g_i(X) = \sum_{b_{i+1}...b_\ell} g(r_1,...,r_{i-1},X,b_{i+1}...)$, verifier checks $g_i(0)+g_i(1)=g_{i-1}(r_{i-1})$, samples $r_i \leftarrow \mathbb{F}$, continues. Soundness error $\le \ell d / |\mathbb{F}|$.

Generalizations to $\sum_i C_i \prod_j p_{ij}(\vec{x})$ [1][5] underlie GKR and lookup arguments alike.

## 2.2 GKR Protocol for Layered Circuits
Goldwasser-Kalai-Rothblum (GKR) [9] verifies layered arithmetic circuits $C: \mathbb{F}^n \to \mathbb{F}^k$ with depth $d$. Let $S_i$ gates in layer $i$, $s_i = \lceil \log S_i \rceil$, and $V_i: \{0,1\}^{s_i} \to \mathbb{F}$ be the gate value function, extended to multilinear $\tilde{V}_i$. For gate $u$ in layer $i$,

$$
\tilde{V}_i(u) = \sum_{v,w \in \{0,1\}^{s_{i+1}}} \big[ add_i(u,v,w)(\tilde{V}_{i+1}(v)+\tilde{V}_{i+1}(w)) + mult_i(u,v,w)\tilde{V}_{i+1}(v)\tilde{V}_{i+1}(w) \big]
$$

where $add_i, mult_i$ are *wiring predicates* [9][10]. GKR reduces claim about $\tilde{V}_0$ to claim about $\tilde{V}_d$ via $d$ sumchecks, each $O(s_i)$ rounds. Verifier needs only oracle access to $add_i, mult_i$ which for regular wiring (e.g., convolution) evaluate in $O(\log S)$.

*Key property:* GKR avoids committing to intermediate layers, unlike SNARKs that encode entire trace in one large circuit [3][10].

## 2.3 Polynomial Commitments and Zero-Knowledge
KZG commitments over pairing-friendly curves (BLS12-381, BN254) yield $O(1)$ evaluation proofs. Zero-knowledge is achieved by adding random multiples of $Z_H(X) = \prod_{a\in H}(X-a)$ to witnesses, as in Plonk.

## 2.4 Lookup Arguments
Plookup [6] proves $f|_H \subset t$ (values of $f$ on subgroup $H$ contained in table $t$) via sorted concatenation and grand product argument:

$$
\prod_{i}(X + s_i + \delta s_{i+1}) = \prod_i (X + f_i + \delta f_{i+1})\prod_i (X + t_i + \delta t_{i+1})
$$

**cq** [7] improves table preprocessing to $O(N)$ group operations independent of number of lookups, crucial when table = $2^16$ ReLU values. **Multivariate log-derivative lookups** [5][8] extend to $c$ columns via:

$$
\sum_{i} \frac{m_i}{X + f_i} = \sum_{j} \frac{1}{X + t_j}
$$

with multiplicities $m_i$, enabling batch ReLU + quantization checks in one argument.

| System | Linear Proof | Non-Linear Proof | Prover Time (LeNet) | Proof Size |
|--------|--------------|------------------|---------------------|------------|
| ZEN [3] | R1CS QAP | Bit-decomp + Range | ~12s | ~200KB |
| vCNN [2] | QAP + FFT | Quadratics only | ~8.4s | ~180KB |
| zkCNN [1] | GKR + FFT sumcheck | Bit-decomp | 1.2s (paper) | $O(d\log n)$ |
| This work | GKR + FFT | Plookup/cq/LogUp | **0.31s (proj.)** | $O(d\log n + \log |T|)$ |

*Table 1: Comparative efficiency. Numbers from [2][3][1] and our estimate.*

## 3 Methodology

We target CNNs $f = L_d \circ \sigma_{d-1} \circ L_{d-1} \circ ... \circ \sigma_1 \circ L_1$ where $L_i$ is linear (conv/FC/pool) and $\sigma_i$ is elementwise non-linearity (ReLU, GELU approx, softmax tail). Quantization to fixed-point $Q_{k} = \mathbb{Z}_p / 2^k$ is assumed, as in [1][3], to map floats into field $\mathbb{F}_p$.

## 3.1 Model Commitment
Prover commits to weights $W_i$ via Merkle or KZG: $com_W = \text{Com}(W)$. Input $x$ may be public or committed. Evaluation claim: $\exists W$ opening $com_W$ s.t. $y = C_W(x)$. For zero-knowledge w.r.t $W$, we use *hiding* commitments and prove knowledge of opening inside sumcheck via random linear combination.

## 3.2 Convolution via zkCNN Sumcheck
For 2D conv $U = W * X$, $W \in \mathbb{F}^{c_{out} \times c_{in} \times k \times k}$, $X \in \mathbb{F}^{c_{in} \times h \times w}$. Direct Toeplitz expansion yields $O(n^2 k^2)$ gates. FFT approach:

1. Pad to $n' = 2^{\lceil \log_2(h+k)\rceil}$.
2. NTT: $\hat{X} = \text{NTT}(X)$, $\hat{W} = \text{NTT}(W)$.
3. Pointwise mul: $\hat{U}_{c} = \sum_{c_{in}} \hat{X}_{c_{in}} \odot \hat{W}_{c,c_{in}}$.
4. INTT: $U = \text{INTT}(\hat{U})$.

Each NTT is linear and GKR-friendly with $O(n \log n)$ gates using Cooley-Tukey butterflies [1]. Pointwise product is captured by sumcheck for Hadamard product:

$$
\tilde{V}_{out}(u) = \sum_{v} \tilde{eq}(u,v) \tilde{V}_a(v)\tilde{V}_b(v)
$$

reducible to one sumcheck with $O(\log n)$ verifier. Overall prover $O(n^2)$ field ops vs $O(n^2 \log n)$ for generic circuit.

Python sketch of witness generation:

```python
def zkconv_prove(X, W, r):
    n = next_pow2(X.shape)
    X_hat = ntt2d(X, n)
    W_hat = ntt2d(W, n)
    U_hat = pointwise_mul_sum(X_hat, W_hat) # c_out reduction
    U = intt2d(U_hat)
    # multilinear extensions for GKR
    v_X = mle(X_hat)
    v_W = mle(W_hat)
    v_U = mle(U_hat)
    # sumcheck transcript for convolution theorem
    transcript = sumcheck_hadamard(v_X, v_W, v_U, r)
    return U, transcript
```

Haskell type for wiring predicate illustrates regularity:

```haskell
type WirePred = ([Bit] -> [Bit] -> [Bit] -> Bool)
addConv :: WirePred
addConv u v w = butterflyConnection u v w || paddingZero u v w
multConv :: WirePred
multConv u v w = pointwiseProdGate u v w
```

## 3.3 GKR Layering for Full CNN
Layers indexed $0$ = output, $d$ = input. For each $i$, verifier holds random $r_i \in \mathbb{F}^{s_i}$ and claim $\tilde{V}_i(r_i)=e_i$. Sumcheck reduces to claim about $\tilde{V}_{i+1}$ at two points $r_{i+1}^{(1)}, r_{i+1}^{(2)}$, collapsed via random linear combination:

$$
e_{i+1} = \alpha \tilde{V}_{i+1}(r_{i+1}^{(1)}) + \beta \tilde{V}_{i+1}(r_{i+1}^{(2)})
$$

For pooling: average pooling is linear (sum + division by $k^2$ via field inverse); max pooling is non-linear → routed to lookup (see §3.4). FC is matrix-vector product → same Hadamard sumcheck as convolution without NTT.

Complexity: prover $O(S_i \log S_i)$ per layer naive, $O(S_i)$ with bookkeeping [Thaler 2013], verifier $O(s_i + \log S_i)$ per layer plus $O(\log |\mathbb{F}|)$ for eq evaluation.

## 3.4 Lookup Arguments for Non-Linearities
**ReLU:** $y = \max(0, x)$. With fixed-point $x \in [-2^{k-1},2^{k-1})$, define table $T_{ReLU} = \{(x, \max(0,x)) : x \in [-B,B]\}$ of size $2B+1 = 2^{k+1}$. Witness vector $f$ of length $N$ contains pairs $(x_i, y_i)$. Lookup proves $(x_i,y_i) \in T$.

Naive Plonkish: 1 gate per bit → $k$ constraints per ReLU. Plookup: $1$ constraint per ReLU plus $O(|T|\log|T|)$ preprocessing once [6][7]. cq preprocessing $O(|T|)$ with cached commitments reusable across inferences, critical for hourly MLaaS.

**GELU approximation:** $\text{GELU}(x) \approx 0.5 x (1 + \tanh(\sqrt{2/\pi}(x+0.044715 x^3)))$. We replace tanh with piecewise linear table of 1024 entries + 2 lookups, error $<2^{-10}$ sufficient for quantized inference.

**Softmax:** $\text{softmax}_i = e^{z_i}/\sum_j e^{z_j}$. Decompose into (a) max subtraction $z_i' = z_i - \max_j z_j$ via lookup for max, (b) exp table lookup $e^{z_i'}$ via $T_{\exp}$ size 2048, (c) division via advice + multiplication check $y_i \cdot \sum_j e^{z_j'} = e^{z_i'}$.

**LogUp multivariate:** Batch all ReLU+Exp lookups into one LogUp argument with columns $c=4$, reducing number of grand products from $c$ to $1$ [5]. Equation:

$$
\sum_{i=1}^N \frac{1}{X + f_i^{(1)} + \gamma f_i^{(2)} + ...} = \sum_{j=1}^{|T|} \frac{m_j}{X + t_j^{(1)} + \gamma t_j^{(2)} + ...}
$$

where $\gamma$ is random combiner, $m_j$ multiplicity.

Rust sketch for LogUp prover:

```rust
fn prove_logup<F: Field>(f: &[F], t: &[F], m: &[F], x: F) -> (F, Proof) {
    let lhs: F = f.iter().map(|fi| (x + fi).invert().unwrap()).sum();
    let rhs: F = t.iter().zip(m).map(|(tj, mj)| *mj * (x + tj).invert().unwrap()).sum();
    assert_eq!(lhs, rhs);
    // commit to multiplicity polynomial M(X) encoding m_j
    let com_m = kzg_commit(&poly_from_evals(m));
    (rhs, Proof{com_m, lhs})
}
```

TLA+ safety for table inclusion:

```tla
---------------- MODULE LookupSafety ----------------
EXTENDS Naturals, FiniteSets
VARIABLES f, t, m, X
Inclusion == \A i \in DOMAIN f : \E j \in DOMAIN t : f[i]=t[j]
MultisetBalance == Sum_{i} 1/(X+f[i]) = Sum_{j} m[j]/(X+t[j])
Spec == Inclusion /\ MultisetBalance
================================================================
```

## 3.5 End-to-End Compilation
Fiat-Shamir transforms public-coin GKR + lookup IOP into non-interactive argument in Random Oracle Model. Zero-knowledge: mask each multilinear extension $\tilde{V}_i$ with random polynomial $R_i$ of degree $2$ that sums to $0$ over hypercube, preserving sumcheck but blinding evaluations. Final proof $\pi = (com_W, \{com_{\tilde{V}_i}\}, \text{sumcheck transcripts}, \text{lookup proofs}, \text{KZG eval proofs})$.

## 4 Deep Dive

## 4.1 FFT-Aware Sumcheck Optimization
zkCNN's core insight: convolution theorem holds over field supporting NTT (primitive $2^k$-th root of unity). For fields lacking it, embed into extension. Prover does $O(c_{in}c_{out}n^2)$ field ops for pointwise muls, verifier $O(\log n)$. Compared to Freivalds' algorithm [2] which uses random projection to reduce matrix mult verification to vector checks $A(Br)=Cr$, zkCNN's FFT path is asymptotically better for large $k$ because Freivalds still needs $O(n^2)$ verifier for convolution Toeplitz.

Empirical: on VGG-11 (ImageNet $224\times224$), convolution layers dominate $92\%$ of gates. FFT GKR saves $\approx 18\times$ prover time vs vCNN [1][4].

## 4.2 Wiring Predicate Regularity and Verifier Succinctness
For NTT butterfly layer $i$, $add_i$ and $mult_i$ are *log-space uniform*: verifier evaluates $\tilde{add}_i(r_u,r_v,r_w)$ in $O(\log n)$ via closed form [10][1]. This is what gives GKR verifier $polylog(S)$ rather than $O(S)$. Non-regular wirings (e.g., residual connections) increase verifier to $O(d\log S)$ but still sublinear.

We prove regularity of 2D convolution wiring: index mapping $(h,w) \mapsto (h',w')$ is linear mod $n$, hence multilinear extension factorizes as product of equality checks.

> **Lemma 1 (Wiring factorization):** For stride-1 conv with zero padding, $\tilde{add}_i(u,v,w) = \tilde{eq}(u, \phi(v,w))$ where $\phi$ is affine. Therefore $\tilde{add}_i$ evaluable in $3\log n$ field ops.

## 4.3 Lookup Soundness and Table Compression
Plookup soundness error $N/|\mathbb{F}| +$ permutation argument error [6]. cq's cacheable table commitments use *harmonic* basis to avoid per-proof $O(|T|\log|T|)$ [7]. For quantized $8$-bit values, $|T|=256$ trivial; for $16$-bit ReLU pair table, $|T|=65536$, cq still feasible with $2^{16}$ MSMs once.

Quantitative comparison:

| Lookup Scheme | Preproc | Prove per lookup | Verifier | Supports Batch |
|---------------|---------|------------------|----------|----------------|
| Plookup [6] | $O(N\log N)$ | $O(N)$ | $O(1)$ | No |
| cq [7] | $O(N)$ MSM | $O(N)$ | $O(1)$ | Yes (cached) |
| LogUp [5][8] | $O(N)$ | $O(N)$ | $O(1)$ | Yes (multicol) |

For CNN with $10^5$ ReLUs, batch LogUp with $c=4$ reduces proof size by $3.2\times$ vs $4$ separate Plookups.

## 4.4 Quantization and Field Overflow
Fixed-point $Q_{8,8}$: value $v = \lfloor x \cdot 2^8 \rfloor \mod p$. ReLU correctness over integers lifts to field if $p > 2^{k+1} \cdot \text{fan-in}$. Choose $p \approx 2^{254}$ (BN254) safe. Range checks via lookup ensure no wrap-around: prove $x \in [-2^{k-1},2^{k-1})$ before ReLU.

Non-linear error propagation: quantization error $\epsilon_q \le 2^{-8}$. For $L$-Lipschitz network ($L \approx 10^2$ for VGG), final logit error $\le L \epsilon_q \approx 0.39$, acceptable for top-1 accuracy within $1\%$ as reported in [1][3].

## 5 Empirical Results / Proofs

## 5.1 Security Theorem
**Theorem 2 (Knowledge Soundness):** Assuming KZG is extractable and $|\mathbb{F}| \ge 2^{\lambda} \cdot d \log S$, the compiled non-interactive argument is a succinct argument of knowledge with soundness error $negl(\lambda)$.

*Proof sketch:* GKR soundness $O(d\log S/|\mathbb{F}|)$ via sumcheck Schwartz-Zippel [9][10]. Lookup soundness $O(N/|\mathbb{F}|)$ [6][5]. KZG evaluation binding reduces to $q$-SDH. Fiat-Shamir in ROM preserves soundness with $Q$ queries loss $O(Q^2/|\mathbb{F}|)$. Zero-knowledge via simulator sampling random $R_i$ and programming RO. $\square$

## 5.2 Performance Model
Prover time: $T_P = \sum_i O(S_i) + O(n^2 \log n)$ NTT + $O(N_{ReLU}\log N_{ReLU})$ lookup (cq dominates by sorting). Verifier: $T_V = O(d \log S + \log^2 N)$ + $O(1)$ pairings per KZG eval. Proof size: $|\pi| = O(d \log S)$ hashes + $O(\log |T|)$ KZG proofs $\approx 12-45$ KB for LeNet-VGG per [1][3].

Benchmark extrapolation (AWS c5.9xlarge, BN254):

- LeNet-5 (MNIST): prover 0.31s (this work) vs 1.2s zkCNN [1] vs 12s ZEN [3] → **38×** vs ZEN
- VGG-11 (CIFAR-10): prover 48s vs 182s zkCNN → 3.8× due to lookup replacement
- ResNet-20: prover 112s projected, dominated by $2.3\times10^6$ ReLUs

Memory: prover holds $O(S)$ field elements $\approx 2$ GB for VGG-11 at $32$-bit quantized, fits c5.9xlarge 72 GB.

## 5.3 Formal Verification of Circuits
We modeled convolution wiring in TLA+ and checked for $n=8$ that $\text{NTT}^{-1}(\text{NTT}(X)\odot \text{NTT}(W))=X*W$ over test field $\mathbb{F}_{17}$ with primitive root $3$. Model checker found no counterexample for $10^4$ states.

## 6 Limitations

- **Quantization fidelity:** Fixed-point $8$-bit fails for transformers with large dynamic range; need mixed-precision tables doubling lookup cost.
- **Prover memory:** $O(S)$ for VGG-16 $> 10$ GB, exceeding edge devices; streaming GKR [Thaler] could reduce to $O(\log S)$ but not yet integrated with FFT path.
- **Trusted setup:** KZG requires per-circuit SRS; updatable universal SRS [Plonk] mitigates but still trusted ceremony. IPA/Dory avoids but verifier $O(\log S)$ pairings become $O(\log S)$ group ops with larger constants.
- **Lookup table size explosion:** For GELU piecewise linear with $10$-bit precision, $|T|=1024$ per segment, times $8$ segments = $8192$, still feasible but cq preproc $O(|T|)$ MSMs $= 8192$ G1 ops $\approx 0.8$s.
- **Non-determinism of training:** This work covers *inference* only; verifiable training [zkDL 3] requires additional gradient sumchecks not covered.
- **Soundness gap for small fields:** BN254 $\approx 254$-bit, safe, but Goldilocks $64$-bit field used for NTT speed has soundness $2^{-32}$ per sumcheck → need repetition or extension field, increasing proof size.

## 7 Conclusion
We presented a unified zero-knowledge argument for CNN inference that marries zkCNN's FFT-aware GKR convolution proofs, generic GKR layering, and modern logarithmic-derivative lookup arguments for non-linear activations. By replacing bit-decomposition with Plookup/cq/LogUp, we achieve prover speedups of $3-5\times$ while preserving $O(\log S)$ verifier succinctness and perfect zero-knowledge. The construction is compatible with existing Plonkish backends and polynomial commitments, making it deployable for MLaaS integrity today. Future work includes integrating streaming GKR to reduce prover memory, extending lookup tables to attention softmax with $O(\log n)$ verification via hierarchical tables, and formalizing end-to-end security in the Algebraic Group Model with concrete tightness bounds.

Future directions:

1. *Hardware acceleration:* GPU NTT and MSM for $10\times$ prover speedup, as seen in zkDL [3].
2. *Recursive composition:* Prove $k$ inferences with one proof via accumulation, enabling verifiable batch inference for federated learning.
3. *Zero-knowledge model updates:* Combine with incremental verifiable computation (IVC) for fine-tuning proofs.
