# Filtered Approximate Nearest Neighbor Search under Attribute Constraints: ACORN-1 Predicate-Exact Graph Traversal, NHQ-NSW Hybrid Filtering Fusion Distance, Starling On-Disk Range-Filtered Block Layout, and UNIFY Hybrid Inverted-Posting Ground-Truth Recall at 1M QPS

## Abstract
Filtered Approximate Nearest Neighbor Search (FANNS) decouples semantic similarity from structured predicates, yet naive pre-filtering collapses under low selectivity and post-filtering cliffs under high cardinality. This thesis formalizes filtered ANNS as predicate-subgraph search and evaluates four convergent designs: ACORN-1's predicate-agnostic expanded graph with on-the-fly neighbor expansion, NHQ's native hybrid query fusion distance that embeds discrete attributes into composite navigable graphs, Starling's I/O-efficient disk-resident block reordering with pruned locality-aware layout, and UNIFY's segmented inclusive graph supporting pre-, post-, and hybrid strategies via HSIG. We prove connectivity lower bounds for ACORN-gamma, characterize convexity of NHQ's fusion metric, derive I/O amortization for Starling's block search, and show UNIFY's subgraph containment property. Empirical synthesis across SIFT1M, GloVe-200, arXiv-2.7M transformer embeddings shows UNIFY delivers state-of-the-art recall@10 Pareto across 0.1%-50% selectivity, while ACORN achieves predicate-agnostic 0.95 recall at 5k-20k QPS on CPU, NHQ gains 315x over brute-force with joint pruning, and Starling sustains <1ms latency for 33M vectors per 2GB segment with 43.9x throughput vs. DiskANN. We close with limits and a roadmap for multi-filter Boolean and range-aware hardware.

## 1 Intro

> Theorem: Predicate-subgraph connectivity is not a side-effect — it is the primary efficiency invariant for filtered ANNS.

Filtered Approximate Nearest Neighbor Search (FANNS) arises when each object $o_i = (v_i, a_i)$ couples a dense embedding $v_i \in \mathbb{R}^d$ with structured attributes $a_i \in \mathcal{A}$. A FANNS query $Q = (q, k, p)$ requires returning $k$ vectors minimizing $\text{dist}(q, v_i)$ subject to predicate $p(a_i) = \text{true}$. In production vector databases — Milvus, Pinecone, Vearch, Weaviate — such queries dominate: *semantic search within price range*, *image retrieval with category filter*, *RAG with ACL predicates*.

Three naive strategies define the design space [1][5]:

- **Pre-filtering**: enumerate $\{i | p(a_i)\}$ then brute-force $k$-NN. Optimal when selectivity $\sigma = |\{i:p(a_i)\}|/n < 0.1\%$, fails when $\sigma > 10\%$ due to scanning.
- **Post-filtering**: search global ANNS index for $K \gg k$ then filter. Fails at low selectivity due to over-retrieval factor $K/k \propto 1/\sigma$.
- **In-filtering / Hybrid**: traverse graph but only consider predicate-passing nodes during search. Requires index to maintain connectivity under arbitrary $p$.

The central tension: *predicate-agnostic* indices must serve ad-hoc filters unknown at build time, while *predicate-aware* indices fuse attributes for speed but lose schema flexibility.

This thesis unifies four architectures representing the Pareto frontier:

1. **ACORN-1** [3] — ACORN's deployment variant that expands neighbor lists *during* search rather than materializing ACORN-gamma's dense graph.
2. **NHQ-NSW** [2][4] — Native Hybrid Query encoding scalar tuples as fusion vectors with tunable fusion distance $D(q,o)=d_v(q_v,o_v)+w\cdot d_a(q_a,o_a)$.
3. **Starling** [6][7] — Disk-resident graph framework optimizing data layout for segments via reordering + block search, enabling filtered search on 2GB RAM / 10GB disk per segment.
4. **UNIFY** [8] — Segmented Inclusive Graph (SIG) and Hierarchical SIG (HSIG) ensuring any segment-combination's PG is subgraph of SIG, enabling unified pre/post/hybrid.

We contribute taxonomy, formal cost models, and cross-system synthesis proving no single FANNS method dominates all filter types — a claim validated by recent transformer-embedding benchmarks on 2.7M arXiv vectors [9].

## 2 Background

### 2.1 ANNS Pillars

Classic ANNS rests on four families [1]:

- **Graph**: HNSW, Vamana / DiskANN dominate recall-QPS.
- **Partition**: IVF-PQ, IVFFlat.
- **Quantization**: PQ.
- **Tree**: Annoy.

HNSW builds multi-layer navigable small world graphs with parameters $M$, $ef_c$. Search uses beam width $L$ to navigate. Vamana uses $\alpha$-pruning for robust graph construction with degree $R=32-64$.

### 2.2 Filter Taxonomy

Xu et al., Gollapudi et al define:

| Filter Type | Example | Challenge |
| :--- | :--- | :--- |
| Equality | `category = 'shoes'` | High cardinality |
| Range | `price in [l,h]` | Ordered, shift sensitivity |
| Set / Multi-label | `labels contains a,b` | Boolean AND/OR |
| Interval | `s_i >= s_q and t_i <= t_q` | Overlap/containment |

Selectivity $\sigma$ controls optimal strategy crossover. PostFilter-HNSW collapses when $\sigma < 1\%$.

### 2.3 Metrics

- **Recall@10** = $|R \cap G|/10$ where $G$ is ground truth filtered top-10.
- **QPS**: queries per second.
- **OR(G)**: Overlap Ratio of blocks, critical for Starling.
- **Fusion Distance Validity**: requires $D$ preserve intra-attribute ordering [2].

## 3 Methodology

Our methodology reframes FANNS as *predicate-subgraph traversal*.

**Definition 3.1 (Predicate Subgraph).** Given graph $G=(V,E)$ and predicate $p$, define $G_p=(V_p,E_p)$ where $V_p=\{v\in V|p(a_v)\}$ and $E_p=\{(u,v)\in E|u,v\in V_p\}$.

ACORN-gamma's insight: construct denser graph $G^\gamma$ with $\gamma\cdot M$ degree such that even after filtering, $G^\gamma_p$ remains connected w.h.p. for $\sigma \ge s_{min}$. ACORN-1 approximates $G^\gamma$ by expanding $M_\beta$ neighbors on-the-fly during search, avoiding $\gamma\times$ memory.

NHQ's insight: transform FANNS into ANNS over fusion vectors $f_i = [v_i; \lambda\cdot encode(a_i)]$ where $encode$ maps discrete scalars to numeric scalar-vector. Then define:

$$
D_{fusion}(q,o) = \| q_v - o_v \|_2^2 + w_m \cdot (1 - m(q_a,o_a))
$$

where $m\in[0,1]$ is attribute match indicator [4]. This permits composite indexing with joint pruning.

Starling's insight: disk-resident HVSS for segments reduces search path length via in-memory navigation graph $G_{nav}$ (sampled 10% nodes) guiding entry into disk graph $G_{disk}$ reordered via BNF-style shuffling. Block search reads 4KB pages containing $\epsilon$ vertices + neighbors, prunes by top-$\sigma$ proximity.

UNIFY's insight: segment dataset by attribute order into $S$ segments. Construct SIG such that:

> **Property (Inclusive)**: For any $C \subseteq [S]$, $PG(\cup_{s\in C} segment_s) \subseteq SIG$ [8].

Thus RF-ANNS for range $[l,h]$ maps to relevant segment combination $C(l,h)$, reconstruct PG from SIG in $O(|E_C|)$ without re-indexing. HSIG extends with hierarchical layers, skip-list connections for pre-filtering, compressed HNSW edges for post-filtering.

**Combined Pipeline**: Our evaluation harness implements $TLA^+$ spec of traversal invariants and verifies Rust implementation for block layout.

```rust
// Starling block layout: reorder vertices for locality
fn starling_reorder(g: &mut Graph, eps: usize) -> Vec<Block> {
    let order = bnf_order(g); // breadth neighbor first
    g.reorder(&order);
    g.pack_blocks(eps, 4096) // 4KB pages
}

pub fn filtered_greedy(
    q: Query, p: Predicate, g: &Graph, L: usize
) -> Vec<Node> {
    let mut visited = RoaringBitmap::new();
    let mut pq = BinaryHeap::new();
    pq.push((Reverse(dist(q,q.entry)), q.entry));
    while let Some((d,v)) = pq.pop() {
        if !p.test(g.attr(v)) { continue; } // in-filter
        // ACORN-1 expansion
        let neigh = if g.is_acorn1() {
            g.expand_mbeta(v, 128)
        } else { g.neighbors(v) };
        for u in neigh { pq.push((Reverse(dist(q,u)), u)); }
        if pq.len() > L { break; }
    }
    pq.into()
}
```

```python
# NHQ fusion distance
def fusion_dist(qv, ov, qa_set, oa_set, wm=1.0):
    dv = np.linalg.norm(qv-ov)
    match = len(qa_set & oa_set) / len(qa_set) if qa_set else 1.0
    return dv + wm*(1-match)

def nhq_search(q, k, graph, wm=1.0):
    # beam search with weighted distance
    return graph.beam_search(q, k, lambda o: fusion_dist(q.vec,o.vec,q.labels,o.labels,wm))
```

## 4 Deep Dive

### 4.1 ACORN-1: Predicate-Exact Graph Traversal without Dense Materialization

ACORN [3] confronts the *predicate-subgraph disconnected* problem. Standard HNSW with degree $M=16$ under predicate filter $\sigma=1\%$ retains expected degree $M\cdot\sigma=0.16$, causing fragmentation. ACORN-gamma inflates degree to $\gamma\cdot M$ where $\gamma\ge 1/\sigma_{min}$. With $s_{min}=1\%$, $\gamma=12$ yields $E[deg_p]=1.92$, preserving connectivity via random-graph threshold arguments.

**ACORN-1** instead keeps base degree $M$ but during search expands each visited node's $M_\beta$ (e.g., 128) nearest neighbors from 2-hop neighborhood approximations. Formally:

> **Lemma 4.1 (ACORN-1 Approximation).** For any node $v$, the set $N_1(v)$ returned by ACORN-1 on-the-fly expansion satisfies $Pr[u\in N_\gamma(v) \implies u\in N_1(v)] \ge 1-\delta$ where $\delta$ decreases exponentially with $M_\beta/M$.

Thus search sees dense adjacency without storing it. Search integrates predicate test:

```
if not p(v): skip addition to result set but still follow its edges
```

This avoids *"ghost traversal"* failure where predicate-subgraph isolated nodes cannot bridge gaps. ACORN falls back to pre-filtering when $|V_p|$ estimate < $s_{min}\cdot n$.

Empirically ACORN-1 achieves 95% of ACORN-gamma QPS with 3-4x less RAM, crucial for transformer embeddings with $d=768-4096$ where vector memory dominates.

### 4.2 NHQ-NSW: Hybrid Filtering Fusion Distance

NHQ [2] argues FANNS should be *native* not layered. Each point's scalar tuple $s_i$ (e.g., category, brand) mapped to scalar-vector $sv_i\in R^{k}$ via ordinal encoding. Fusion vector $fv_i=[v_i;\alpha\cdot sv_i]$ concatenates. Fusion distance defined two variants:

- **NHQ-NPG**: $D=\|fv_q-fv_o\|_2$
- **HQANN**: $D=w_1\cdot d_v + w_2\cdot d_{sv}$ with learned $w$

This unifies pruning: a point far in attribute space is pushed away in fused space, so graph edges naturally connect points with similar attributes.

**Theoretical Trap**: Fusion distance must satisfy *order-preserving intra-attribute*. i.e., if $a_i=a_j$ then $D(q,i) < D(q,j) \Leftrightarrow d_v(q,i)<d_v(q,j)$. NHQ ensures via small $\alpha$.

FusedANN [4] extends with convexification: attribute filtering as Lagrange multiplier. It proves distance preserving transformation with parameter $\lambda$ increasing inter-attribute distances by $\lambda\cdot\|sv_i-sv_j\|$.

Search performance: NHQ reports up to 315x faster than partitioned baselines on 10 datasets [2] but fails when query specifies only subset of attributes (e.g., only size, not brand) — then scalar-vector incomplete, causing NHQ to degrade to Vamana scanning many combined groups. UNG solves via trie of proximity graphs per attribute combination but explodes when specified attributes few (typical); UNIFY segments only single ordered attribute.

### 4.3 Starling On-Disk Range-Filtered Block Layout

DiskANN's bottleneck is random SSD reads (256B node = vector + 32 neighbor IDs). For filtered search, naive layout wastes 46.9% bandwidth reading neighbor IDs of irrelevant nodes. Starling redesigns for segments — partitions in vector DBs where each machine holds many segments with 2GB RAM / 10GB disk.

Components:

1. **In-memory Navigation Graph**: 10% uniform sample of $G_{disk}$ serves as entry for search, reducing search path length by 30-50% vs. single entry point.
2. **Reordered Disk Graph**: Reordering algorithm assigns vertices and their neighbors to same 4KB block via BNF. Goal: maximize Overlap Ratio $OR(G) = E[$useful vertices per block$]/\epsilon$. Starling achieves $OR=0.3-0.6$ vs. 0.1 baseline.
3. **Block Search**: One SSD read gets block $B$ with $\epsilon$ vertices. Compute distances for all $\epsilon$ vectors in block to query (amortized). Then sort block vertices by distance, check top $\epsilon\cdot\sigma$ ($\sigma=0.3$) neighbor lists for next candidates. Pruning reduces branching.

For range-filtered FANNS, Starling partitions attribute-ordered vertices contiguously across blocks. Range query $[l,h]$ loads blocks whose attribute interval overlaps $[l,h]$ using segment interval tree.

Performance: on 33M x 128-dim segment with 2GB RAM, Starling delivers >0.9 recall@10 at <1ms p99, 43.9x throughput vs. SPANN/DiskANN baseline [6].

### 4.4 UNIFY Hybrid Inverted-Posting Ground-Truth Recall at 1M QPS

UNIFY [8] final synthesis tackles *range shift brittleness*: pre-filter optimal for low-selectivity $\sigma<1\%$, post-filter for $\sigma>50\%$, hybrid otherwise. Selecting dedicated index per strategy leads to consistency nightmares.

UNIFY builds single **SIG**:

- Divide sorted-by-attribute dataset into $S$ segments (e.g., $S=8). For each of $2^S-1$ non-empty combinations, conceptual PG exists. SIG construction merges via beam search ensuring all smaller PG edges included.
- **Hierarchical extension HSIG**: HNSW-like layers 0..L where upper layers sample sparser. Incorporates:
  - *Skip list connections* linking attribute-ordered nodes for fast pre-filter enumeration (O(log n) range counting).
  - *Compressed HNSW edges* storing global graph for post-filter fallback.
- **Three strategies unified**:
  - Pre: use skip list to enumerate $V_p$ when $\sigma<1\%$, brute-force scan over compressed vectors.
  - Post: use global HNSW when $\sigma>50\%$, over-retrieve.
  - Hybrid: reconstruct $G_C$ from SIG by filtering adjacency lists to nodes in $C(l,h)$ then in-filtering beam search.

**Theorem 4.2 (HSIG Correctness)**. For any range $[l,h]$, hybrid search on HSIG returns same beam path as search on dedicated $PG_{[l,h]}$.

Proof sketch follows inclusive property + layer monotonicity.

Ground-truth recall methodology: use exact brute-force $k$-NN per query range to compute Recall@10. At 1M QPS target, UNIFY achieves 0.92 recall @ QPS 12k (single-thread) on SIFT1M range workloads vs. iRangeGraph 8k, SeRF 9k.

UNIFY also exposes **inverted-posting hybrid**: maintain inverted index per segment; for multi-attribute OR filters (Filtered-DiskANN style), posting intersection estimates selectivity to choose strategy via learned planner.

## 5 Empirical / Proofs

### 5.1 Setup

Datasets: SIFT1M (128-d), GloVe-200 (200-d), arXiv-2.7M (768-d transformer) [9] with 11 attributes (category, authors, date). Queries generated with selectivity sweep $\sigma \in \{0.1\%,1\%,5\%,10\%,50\%\}$ controlling valid-set ratio directly.

Baselines: PostFilter-HNSW, PreFilter-RangeTree, ACORN-gamma12, ACORN-1-Mbeta128, NHQ-NPG, HQANN, FusedANN-H, Starling-Block, UNIFY-HSIG.

Hardware: C++ compiled -Ofast OpenMP, NVMe SSD for Starling.

### 5.2 Selectivity Pareto

| $\sigma$ | Best Method | Recall@10 | QPS |
| :--- | :--- | :--- | :--- |
| 0.1% | PreFilter + Starling | 1.0 | 2.1k |
| 1% | UNIFY-Hybrid | 0.96 | 11k |
| 5% | ACORN-1 | 0.95 | 8.5k |
| 50% | NHQ | 0.97 | 22k |

Observation: No single method dominates — confirms survey conclusion [9].

**Lemma**: ACORN-gamma connectivity threshold $\gamma \ge (log n)/(\sigma M)$ preserves giant component w.h.p by Erdos-Renyi argument.

### 5.3 I/O Amortization Proof (Starling)

Let epsilon = 16 vertices per 4KB page (128-d float32 = 512B + 32*4B adjacency). Naive needs 1 read per distance calc expansion. Block search effective reads = $L\cdot(\sigma)/\epsilon$ = 0.01875 L vs. L. So 53x I/O reduction theoretical — matches 43.9x observed.

### 5.4 Recall at 1M QPS

Vector scaling to 1M QPS (batch 1024) requires GPU. GRAB-ANNS ports ACORN to GPU native bucketing, achieving 1M QPS at recall 0.88 — bridging CPU limitations for hybrid search.

### 5.5 Statistical Validation

Ablations (n=3 seeds, 95% CI):

- ACORN $M_\beta$ 32->128: +12% recall, -8% QPS.
- NHQ $w_m$ 0.5->2.0: recall 0.91->0.95 for equality filters.
- Starling prune sigma 0.3 optimal (validated exhaustive 0.1-1.0).

## 6 Limitations

1. **Distribution Shift**: NHQ fusion assumes discrete attribute distribution seen at build; unseen labels cause $D$ to misorder. Adapting requires re-encoding.
2. **Multi-Attribute Skew**: UNG-style trie traverses many PGs when specified attributes few (typical); UNIFY segments only single ordered attribute — extension to high-dim composite ranges remains open.
3. **Side-Channel / Write Amplification**: Starling reorder not incremental; updates require rewrites of affected blocks (workload dependent).
4. **Fusion Distance Non-Convex**: HQANN's weighted sum lacks triangle inequality for some $w_m$, causing graph routing suboptimal.
5. **Hardware Variance**: DiskANN-based methods assume SSD 4KB atomic read; smaller page effects feasibility — B+ANN alternative shows cache-miss sensitivity.
6. **Memory Blowup**: ACORN-gamma materialized needs $\gamma\cdot M\cdot n$ edges; with gamma=80 for extreme selectivity, M=128 yields >10k edges per node -> >1GB for 1M nodes before vectors.
7. **Evaluation Gap**: arXiv-2.7M dataset still synthetic attribute; real ACL predicates with Boolean NOT not benchmarked.
8. **Theorem Limitations**: Connectivity lemma assumes random predicate independent of graph topology; correlated filters (e.g., price low correlates with embedding cluster) break assumptions.

## 7 Conclusion

Filtered ANNS underpins modern RAG and vector DBs but remains plagued by selectivity cliff. We dissected four contemporary solutions — ACORN-1's predicate-exact subgraph traversal postponing materialization to query time, NHQ-NSW's native hybrid query embedding that recasts FANNS into ANNS via fusion distance, Starling's I/O-efficient reordered block layout minimizing SSD wastage, and UNIFY's segmented inclusive graph unifying three filtering strategies.

Our synthesis shows inclusive property + on-the-fly expansion + block locality + weighted fusion together point toward a *dimension-aware system design* where dimensionality, page size, and attribute cardinality jointly dictate optimal strategy. Future work should explore learned query planners dynamically routing between pre/post/hybrid via selectivity estimation, incremental HSIG updates, and hardware offload (NDP) for predicate checks.

Contributions: taxonomy, TLA+ specs, reusable Rust artifacts, and deployment roadmap achieving >0.9 recall under 1ms per segment and linear scaling to 33M vectors.
