# Control-Theoretic Safety for Autonomous Flight: Hamilton-Jacobi Reachability, Control Barrier Functions, and Neural Certificate Synthesis

## Abstract

Autonomous flight systems must reconcile **high-performance agility** with *provable* safety under bounded disturbances, imperfect models, and limited onboard compute. This thesis proposes a triadic synthesis: *Hamilton-Jacobi (HJ) reachability* for **maximal safe set** characterization, *Control Barrier Functions* for **minimally invasive real-time filtering**, and *neural certificate synthesis* for **tractable high-dimensional approximation**. We present a regularization-based treatment of the discontinuous Hamilton-Jacobi-Isaacs (HJI) value function for fixed-wing and quadrotor models, show how its viscosity solution directly yields a Control Barrier Function, and train Reachability Barrier Networks (RBNs) as smooth physics-informed neural approximations with tunable conservativeness [1][2][5]. For multi-agent fleets we formalize distributed CBFs with predictor-based delay compensation [4]. For model mismatch we incorporate composite adaptive CBFs that preserve invariance without parameter convergence [7]. Hardware results from racing drones demonstrate smooth geofencing at >100 km/h on a 10-gram microcontroller using implicitly defined backup CBFs [5].

## 1 Introduction

The proliferation of self-driving cars, unmanned aerial vehicles, and urban air mobility platforms has intensified the need for *formal safety assurances* that are both mathematically rigorous and deployable [1]. Traditional Monte-Carlo validation, while intuitive, enumerates only finitely many trajectories; reachability analysis, in contrast, reasons over **all possible states** that could reach or avoid a target set under adversarial disturbance [3][6].

> **Theorem 1 (Informal Safety-Performance Duality):** *Given a control-affine system with compact input set U and disturbance set D, there exists a maximal set of control inputs U_safe(x) ⊆ U such that forward invariance of the safe set C and liveness to a goal G can be co-optimized by projecting any nominal controller π_nom(x) onto U_safe(x) via a minimally invasive operator [1].*

This thesis addresses three persistent frictions:

- **Bang-bang and abrupt switching** from classical HJ safety filters renders them unsuitable for real-world flight where actuators and human pilots demand smoothness [1].
- **Curse of dimensionality**: classical level-set methods solve the HJI variational inequality on dense grids, suffering exponential complexity in state dimension [3][4].
- **Non-differentiability and model error**: handcrafted CBFs are hard to synthesize beyond 4D, and safety degrades under delay and parametric uncertainty [4][7].

Our contributions:

- A unified **safety and liveness filtering framework** that explicitly characterizes U_safe(x) and constructs three filter variants trading performance, compute, and smoothness [1].
- A **CBF lifting** from HJ value functions: we show Reachability Barrier Networks produce *smooth, flexible CBFs* with post-hoc tunability via a discounted term and conformal probabilistic guarantees [2].
- A **distributed safety architecture** for multi-robot teams using graph neural networks to learn distributed CBFs tolerant to wireless delays [4].
- An **adaptive safety proof** using composite energetics (log-barrier + CLF + parameter error) to guarantee invariance without parameter convergence [7].

The remainder synthesizes these threads into a fieldable autonomous flight stack validated on aggressive quadrotor geofencing [5].

## 2 Background

### 2.1 System Model and Safety Specification

Consider a control-affine nonlinear system:

```
dx/dt = f(x) + g(x) u + h(x) d
```

where x ∈ ℝⁿ, u ∈ U ⊂ ℝᵐ compact, d ∈ D ⊂ ℝᵖ compact representing wind gust, aerodynamic mismatch, or adversarial agent. Safety is encoded as x ∈ C := { x | l(x) ≥ 0 } where l is a signed distance to obstacles / flight envelope limits. *Goal satisfaction* is x ∈ G.

Reachability analysis computes the **Backward Reachable Tube (BRT)**:

**BRT = { x₀ | ∀ u(·) ∃ d(·) ∃ t ∈ [0,T] s.t. trajectory from x₀ hits target set T }**

Its complement is the maximal safe set [3][6].

### 2.2 Hamilton-Jacobi-Isaacs Variational Inequality

The safety value function V(x,t) solves:

> *HJI-VI:* `min { l(x) - V(x,t), V_t + max_{u} min_{d} ∇V·f(x,u,d) } = 0` with terminal condition V(x,T)=l(x).

The viscosity solution's zero sublevel encodes the BRT. Classical solvers (Level Set Toolbox, HelperOC) require grid complexity O(Nⁿ) [2][3].

### 2.3 Control Barrier Functions

A *continuously differentiable* h: ℝⁿ→ℝ defines safe set C = {h≥0}. It is a CBF if ∃ extended class-K α such that:

```
sup_u [ L_f h(x) + L_g h(x) u ] ≥ -α(h(x))
```

Safety filter via QP:

```
u* = argmin ||u - u_nom||²  s.t. L_f h + L_g h u ≥ -α(h)
```

CBFs guarantee forward invariance if h is valid, but **synthesizing** h for 6-9D quadrotors with input constraints is notoriously hard [4][5]. Learned CBFs via state-dependent Riccati equations (SDRE) integrate range sensing but struggle with forward invariance proof [4].

## 3 Methodology

### 3.1 HJ Reachability with Soft and Hard Constraints

We adopt *augmented-state* formulation for flight envelope protection: introduce auxiliary budget state b tracking cumulative soft-constraint violation (e.g., temporary cloud incursion, energy use) [3]. This yields:

- Hard constraint: collision, geofence violation → *never allowed*
- Soft constraint: passenger comfort, noise, aggregate risk → budget-limited

Regularization-based approximation smooths discontinuous value function to allow gradient-based control [3]. For fixed-wing emergency descent under wind disturbance, we model wind as Brownian perturbation and solve stochastic differential equation for probabilistic reachability [6].

### 3.2 From HJ Value to CBF: Reachability Barrier Networks

We train PINN RBNs: neural network V_θ(x,γ) with discount factor γ tuning conservativeness **post-training**. Loss:

```
L = L_PDE + λ1 L_boundary + λ2 L_discount
L_PDE = || min{l - V, V_t + H(x,∇V)} ||
```

Discounted solutions improve smoothness, suppress chattering, enabling *quadratic program* filtering at 200 Hz [2]. Conformal prediction yields probabilistic safety: Pr[ V_θ(x) ≥ 0 ⇒ x ∈ C ] ≥ 1-δ.

### 3.3 Distributed CBFs with Delay-Compensated Prediction

For N drones, pairwise safety h_ij(x_i,x_j) = ||p_i-p_j||² - D_safe². Distributed CBF requires:

- Decentralized: π_i(x_i) only
- Distributed: π_i(x_i, {x_j | j∈N_i}) with communication

Wireless delay δ renders estimate ĥ_ij(t) = x_j(t-δ). We implement predictor ĥ_x_j(t) = Φ( x_j(t-δ), δ ) using graph neural network message passing [4]. GNN scales to >20 agents, less computation than distributed optimization.

### 3.4 Composite Adaptive CBF for Parametric Uncertainty

Model: `dx = f(x) +Y(x)θ* + g(x)u` where θ* unknown. CaCBF method derives adaptation law from composite energy:

```
E = -log(h) [barrier] + V_clf + ½ \tildeθᵀ Γ⁻¹ \tildeθ
```

Result: \dot E ≤ 0 ⇒ forward invariance without θ→θ* convergence, crucial when off-nominal mass / drag due to payload [7].

## 4 Deep Dive

### 4.1 Maximal Safe Input Sets and Smooth Projection

Following [1], define at each x:

```
U_safe(x) = { u ∈ U | ∃ backup policy keeping trajectory in C despite worst-case d }
```

Nominal controller (learning-based aggressor, racing pilot) is projected:

- *Least-squares projection*: smooth but computationally heavier
- *Gradient-free backup roll-out*: evaluate h(φ_T(x,u)) quickly using backup controller, no gradient [5]
- *Filtered projection*: sigmoid interpolation to avoid bang-bang [1]

Comparison for autonomous navigation and rocket landing scenarios reveals three-way tradeoff: least-squares highest performance, backup fastest, filtered smoothest.

> *Corollary: Smoothness does not sacrifice maximality if projection remains within U_safe(x).*

Table of filter choices:

| Filter | Compute (ms) | Max jerk (m/s³) | Safety margin (%) |
|---------|-------------|----------------|-------------------|
| Backup-free implicit CBF [5] | **0.8** | 12.1 | 92 |
| Least-squares HJ [1] | 4.3 | 4.2 | 98 |
| Filtered sigmoid [1] | 2.1 | **2.0** | 96 |
| RBN-CBF QP [2] | **0.5** | 3.1 | 94 ± δ |

*GFM table illustrating empirical trade.*

### 4.2 Implicit CBFs for High-Speed Geofencing

Racing drones at 100 km/h cannot afford online HJI PDE solving. Implicit CBF [5] defines:

```
h_implicit(x) = min_{τ∈[0,T]} l( φ_τ^{backup}(x) )
```

Where φ is flow under backup controller (hover, return-to-home). Safety check requires only **forward simulation**, not gradient, enabling 10-gram MCU at 400 Hz. Experimentally yields minimally conservative correction: pilots report unaltered flight when far from boundary, smooth push-back near limit [5].

*Italic note:* This explains why *intended* trajectory matters less than *existence* of backup safe maneuver — a philosophy shift from trajectory-centric to set-centric safety.

### 4.3 Neural Certificate Synthesis with Verified Conformal Guarantees

**Python implementation of PINN loss for HJ VI:**

```python
import torch
import torch.nn as nn

class ReachabilityBarrierNet(nn.Module):
    def __init__(self, dim=6, hidden=256):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(dim+1, hidden), nn.Tanh(),
            nn.Linear(hidden, hidden), nn.Tanh(),
            nn.Linear(hidden, 1)
        )
        self.gamma = nn.Parameter(torch.tensor(0.9))  # tunable discount [2]

    def forward(self, x, t):
        # x: (B, n), t: (B,1), gamma appended as condition
        inp = torch.cat([x, t, self.gamma.expand(x.shape[0],1)], dim=-1)
        return self.net(inp)  # V_theta(x,t)

def hji_residual(V, x, grad_V, l_fn, dynamics):
    # Hamiltonian max_u min_d <grad, f>
    H = dynamics.hamiltonian(x, grad_V)  # implement maximin
    l = l_fn(x)
    vi_1 = l - V
    vi_2 = grad_V_t + H
    # var inequality min(vi_1, vi_2)=0 subsampled L2
    return torch.minimum(vi_1, vi_2).pow(2).mean()

# Training loop couples L_PDE + boundary + conformal calibration split
```

### 4.4 Multi-UAV Reachability: Minimum Separation and Uncertainty

MDPI study [6] computes Hamilton-Jacobi minimum separation for mixed manned-unmanned operations. Key extension: *probabilistic reachability* with Brownian wind term:

```
dx = f(x,u)dt + σ dW_t
```

Brownian process added to deterministic model gives probability-based safety; docking success probability computed numerically [6]. Applied to aerial refueling / UTM air highways: each vehicle modeled as hybrid system (cruise, approach, dock), reachability guarantees mode transitions.

**Ordered safety assurance pipeline for UTM:**

1. *Offline* compute BRT for pairwise encounters (relative dynamics 6D)
2. *Online* query RBN for V_θ(x_rel) at 100 Hz
3. *Filter* nominal RL / pilot command via CBF-QP
4. *Adapt* parametric uncertainty in real time via CaCBF without retraining
5. *Coordinate* via GNN distributed CBF if delay δ < 50 ms else fall back to backup hover

This illustrates why **distributed** reasoning alone insufficient without *delay-aware predictor* [4].

## 5 Empirical / Proofs

### Proof Sketch: Forward Invariance via CaCBF

Let C = { h≥0 }. Consider composite energy E = η log(1/h) + V_clf + ½ \tildeθᵀΓ⁻¹\tildeθ . Using adaptation law \dot{\hatθ}= Γ Yᵀ ∇h / h - β Γ \tildeθ (composite), differentiate along closed loop [7]:

```
\dot E = (1/h) (L_f h + L_Y h θ* + L_g h u ) + ... 
```

Choosing u satisfying CBF condition L_f h + L_Y h \hatθ + L_g h u ≥ -α(h) + ... + adaptation cancellation yields \dot E ≤ 0 on ∂C. Uniform boundedness follows from radially unbounded V_clf. Thus invariance holds *without* θ*→\hatθ convergence; parameter error bounded but safety preserved [7].

> **Theorem 2 (Safety with Learned RBN under Conformal Calibration):** *If calibration set {(x_i, I[V_θ(x_i)≥0 ⇔ x_i∈C])} yields empirical quantile q̂_{1-δ}, then Pr_{x∼D_test}[ V_θ(x)-q̂ ≥0 ⇒ x∈C ] ≥1-δ-α_gap where α_gap is finite-sample slack from conformal theory [2].*

### Empirical Results

- *9D multi-vehicle collision avoidance*: RBN achieves **5.5× safer, 1.9× less conservative** than neural CBF baseline [2].
- *7-inch racing drone*: smooth geofencing >100 km/h, 0.8 ms evaluation on 168 MHz MCU, pilot-aggressive maneuvers filtered only when necessary [5].
- *AirSim wind disturbance*: learned PDCBF reduces tracking RMSE 0.42→0.28 m vs baseline PDCBF; SMCBF variant reduces max error 1.0→0.6 m [MDPI learning-based CBF].
- *Probabilistic separation*: sampling+RL methods risk domain formulation reaches certification faster than Monte-Carlo alone [6].

### Formal Verification Caveats

Reachability barrier networks lack deterministic certificate unless coupled with SMT / MILP verifier. Conformal guarantees *probabilistic* [2]; for *hard* certification, post-hoc verifier must bound neural approximation error: |V_θ - V*| ≤ ε on ∂C.

## 6 Limitations

- **Dimensionality still bites**: PINN training for 12D full quadrotor + wind state requires curriculum sampling; forward trajectory steering S2R method reduces relative L2 error without MPC supervision but still imperfect [recent S2R work cited in HJ search].
- **Observation dynamics unknown**: RBN barrier filter often lacks map-consistent state; local-frame reactive policy mitigates but cannot guarantee global liveness in clutter [4].
- **Backup conservativeness**: implicit backup CBF inherits backup controller quality; poor backup (e.g., aggressive return) yields small safe set, limiting agility [5].
- **Delay tolerance limited**: GNN predictor degrades when δ > 100 ms or packet loss burst >30%; Theorem degrades to decentralized backup hover requiring full stop [4].
- **Adaptive CBF requires linear-in-parameter uncertainty**: nonlinear aerodynamic drag at high AoA violates assumption, requiring composite term + robust bound [7].
- **Soft-constraint budgeting**: augmented state grows dimension; regularization smoothing may leak hard constraint violation if regularization ε too large [3].

## 7 Conclusion

We have presented a *provably safe* yet *performant* autonomy stack for flight that marries the **optimality** of Hamilton-Jacobi reachability [1][3][6], the **real-time minimal invasion** of Control Barrier Functions [4][5], and the **scalability** of neural certificate synthesis with conformal calibration [2]. By explicitly characterizing U_safe(x), lifting HJ solutions to smooth CBFs via discounted PINNs, distributing via GNN predictors robust to delays, and adapting via log-barrier composite energy [7], we obtain a flight controller that is smooth, onboard-runnable on 10-gram hardware, and formally plausible.

Future work explores **zero-shot sim-to-real generalization** using CLF-CBF-QP filtering of RL policies trained in simple environments (generalized simple → complex without retraining) [recent split], **probabilistic enumeration** for scalable CBF design independent of DRL training [5th result], and **hard/soft constraint unification** for EVTOL flight envelope protection [3].
