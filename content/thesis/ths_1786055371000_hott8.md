# Homotopy Type Theory Cubical Computational Interpretation: Kan Filling, Glue Types, Univalence Computation, and Higher Inductive Types

## Abstract
Univalent foundations [4][5] identify equivalences with equalities via Voevodsky's univalence axiom, yet axiomatic postulation breaks canonicity — closed $\mathbb{N}$ terms stuck on `univalence` [2][4]. Cubical Type Theory (CTT) [1][3] resolves by replacing identity types with *path types* $Path_A(x,y) = (i:\mathbb{I}) \to A \ [i=0 \mapsto x, i=1 \mapsto y]$ and equipping every type with Kan operations $hcomp, transp/compose$ [1][6]. We give a PhD-level reconstruction of cubical computational interpretation: cubes $\mathbb{I}^n$, face lattice $\mathbb{F}$, cofibrations, composition as uniform Kan filling, Glue types $Glue[\phi \mapsto (T,e)] A$ providing strict univalence $ua : (A \simeq B) \to Path_\mathcal{U}(A,B)$ with computation $ua(\beta)(i)$ reducing to $Glue$ transport [1][2]. We show function extensionality is *definitional* from path abstraction, prove homotopy and strict canonicity for CCHM — every $n:\mathbb{N}$ reduces to numeral [2][8], dissect higher inductive types (circle $S^1$, suspension, truncations) via cubical boundary constructors, and discuss semantic models in De Morgan cubical sets. The thesis closes with limitations: reversal/connectives, xTT, Cartesian vs De Morgan tradeoff.

## 1. Introduction
Homotopy Type Theory (HoTT) [5] reinterprets Martin-Löf type theory homotopically: types as spaces, terms as points, $p: Id_A(x,y)$ as paths, iterated equalities as higher paths, forming an $\infty$-groupoid. Voevodsky observed this interpretation validates **univalence** [4]:

$$ (A \simeq B) \simeq (A =_\mathcal{U} B) $$

in simplicial sets model [4][6], enabling *structure identity principle*: isomorphic structures become equal, transport of structures along equivalence.

Two foundational obstacles arose:

1. **Axiomatic stuckness.** Adding $ua : \prod_{A,B:\mathcal{U}} (A \simeq B) \to (A = B)$ as axiom with no computation rule yields terms like $J(ua(e), P) : P(B)$ that do not reduce, so canonicity fails — there exists closed $n:\mathbb{N}$ not judgementally equal to $S^k(0)$ [2][5]. Simplicial model construction uses classical logic to prove Kan condition existence, not explicit operations, so computational content opaque.

2. **Function extensionality axiom** also required, similarly stuck.

Cubical Type Theory (Cohen-Coquand-Huber-Mörtberg 2015-16 [1][3]) introduces *direct cube manipulation* to compute univalence. Replacement: $\mathbb{I}$ interval object with $0,1$, connections $\land, \lor$, reversal $\neg$ (De Morgan), path types as functions from $\mathbb{I}$ with definitional endpoints, and *Kan filling* operations that give uniform computational interpretation of transport and composition.

> **Central Thesis:** Kan filling *is* the computational engine of univalence. A type is fibrant (Kan) iff every open box has lid; this property, internalized as $comp$/$hcomp$, makes Glue well-fibrant and yields strict computation for $ua$.

Contributions ordering:

- Reconstruction of cubical sets model $PSh(\square)$ and internal language for cofibrations [6].
- Operations $transp, hcomp, comp = hcomp \circ transp$ as primitive; uniform Kan condition definitional [1][2].
- Glue types: syntax, typing, equivalence-extension property, proof that $ua$ and $ua\beta$ hold judgementally [1][3].
- Higher inductive types (HITs): circle $S^1$, interval-to-path coherence, propositional truncation $||A||$ as cubical HIT [3][8].
- Canonicity proofs: Huber 2016 operational semantics [2], Coquand et al. 2018 sconing and homotopy canonicity [8].

## 2. Background / Preliminaries

### 2.1 HoTT and Univalence Axiom
Base MLTT: $\Pi, \Sigma, Id, \mathcal{U}$ à la Russell/Tarski universe hierarchy. Homotopy interpretation [5]:

- $A : \mathcal{U}$ — space
- $x : A$ — point
- $p : x =_A y$ — path
- $p^{-1}, p \cdot q$ — path inverse, concatenation via $J$
- $h : f \sim g = \prod_{x:A} f(x) = g(x)$ — homotopy, pointwise equality

**Equivalence** $A \simeq B = \sum_{f:A\to B} isEquiv(f)$ where:

$$ isEquiv(f) = (\sum_{g} f\circ g \sim id) \times (\sum_{h} h \circ f \sim id) \text{ (bi-invertible)}$$

**Univalence axiom** [4][5]:

$$ UA_{\mathcal{U}} : \prod_{A,B:\mathcal{U}} isEquiv(idtoeqv_{A,B}) $$
$$ where\ idtoeqv_{A,B} : (A =_\mathcal{U} B) \to (A \simeq B) $$
induced by path induction sending $refl_A$ to $(id_A, ...)$. Equivalent forms: there is $ua : (A \simeq B) \to (A = B)$ inverse to $idtoeqv$, and $transport^{id_{\mathcal{U}}}_{ua(e)} = equivFun(e)$.

Consequences [5]:
- Function extensionality: $funext : (f \sim g) \to f = g$ derivable from $UA$.
- Isomorphic structures identified, e.g., $(\mathbb{N}, +)$ defined two ways equal.

Simplicial model Kaplan/Lumsdaine-Voevodsky 2012 [4] proved consistency via classical Kan condition using AC and EM for minimal fibrations; non-constructive existence means no algorithm for $J(ua(e), ...)$.

### 2.2 Cubical Sets
Let cube category $\square$ objects $[n]=\{0,1\}^n$, morphisms generated by face $\delta_i^\epsilon$, degeneracy, connections etc., depending on flavor: De Morgan (CCHM) includes $\land, \lor, \neg$ satisfying De Morgan laws [1][6][7].

**Cubical set** = presheaf $X : \square^{op} \to Set$. Representable $\square^n = Hom(-, [n])$ is $n$-cube. Geometric intuition: point $0$-cube, line $1$-cube path $x \xrightarrow{p} y$, square $2$-cube with four edges and interior, etc.

Face lattice $\mathbb{F}$ = free distributive lattice on $i=0, i=1$ symbols [1]. Element $\phi \in \mathbb{F}$ denotes cofibration, e.g., $(i=0) \lor (j=1)$. Systems $[ \phi_0 \mapsto u_0, ..., \phi_n \mapsto u_n ]$ require $u_i = u_j$ on $\phi_i \land \phi_j$ agreement.

A *partial element* $[( \phi, u)]$ where $u : A$ defined extent $\phi$.

**Kan cubical sets** historically: every open box has filler. CCHM [1] internalizes this as operations rather than property.

### 2.3 Pathology of Axiomatic Identity
In MLTT, $Id$-formation $Id_A : A \to A \to \mathcal{U}$, with $refl$ and eliminator $J$.

Adding axiom $ax: A$ with no reduction: closed term $loop = J(ax, ...)$ stuck. Canonicity fails [2].

CCHM replacement: *path types* not inductively defined but as *functions* with restricted endpoints, possessing direct computational structure.

## 3. Methodology / Formalism

### 3.1 Interval and Path Types
**Syntax** CCHM [1][3]:

- Interval $\mathbb{I}$: $0,1 : \mathbb{I}$, variables $i,j,k : \mathbb{I}$, operations $i \land j, i \lor j, \neg i$ satisfying De Morgan algebra ($\land$ distributive over $\lor$, $i \land 0 =0$, $i \land 1 =i$, $i \land \neg i =0$ for De Morgan? Actually Kleene algebra for De Morgan cubes $i \land \neg i$ not 0 – subtle [1][6] inconstancy vs Cartesian).
- Cofibration $\phi : \mathbb{F}$ built from eqns $i=0, i=1$ via $\land,\lor$.

**Path types**:

$$ \frac{ \Gamma, i:\mathbb{I} \vdash A\ type \quad \Gamma \vdash a: A[0/i] \quad \Gamma \vdash b: A[1/i]}{ \Gamma \vdash Path_A(a,b)\ type }$$

Introduction $\langle i \rangle t : Path$ where $i$ binds, abstraction $\lambda i. t$ with $t : A$ depending on $i$, and endpoints agreement. Elimination $p \, r$ applying path to interval $r:\mathbb{I}$: $p\,0 = a$, $p\,1 = b$ judgementally (beta). Path abstraction resembles function but judgmentally distinguished for Kan.

Function extensionality proof in CTT *direct*:

```haskell
-- Haskell-like pseudocode for CTT funext
funExt : {A : Type} {B : A -> Type} {f g : (x:A) -> B x} 
       -> ((x:A) -> Path (B x) (f x) (g x)) -> Path ((x:A)->B x) f g
funExt h = \ i -> \ x -> (h x) i
-- definitional: <i> \x -> h x i  has endpoints f and g
```

No axiom needed [1].

### 3.2 Kan Operations: transport, homogeneous composition, composition

A type $A$ fibrant (Kan) if it supports:

- **Transport** $transp^i A \phi\, u_0 : A[1/i]$ given $i:\mathbb{I}$ free in $A$, cofibration $\phi$ (extent where transport trivial, i.e., already known to be identity), $u_0 : A[0/i]$ [1][7].

*Interpretation*: line of types $A(i)$; move element from $A(0)$ to $A(1)$ except where $\phi=1$ trivial.

- **Homogeneous composition** $hcomp^i_A [\phi \mapsto u] u_0 : A$ composites open box in *fixed* type $A$ (not depending on $i$) [2]. Data: base $u_0 : A$ at $i=0$, tube $u(i)$ defined on $\phi$ covering sides.

Pictorial open box 1D path → fill interior then cap. For $2$-cube missing top, sides $u$, base $u_0$, composite $u_1$ top edge.

General $comp = transp + hcomp$ [2]:

$$ comp^i A[\phi\mapsto u] u_0 = hcomp^i_{A[1/i]}[\phi\mapsto transp^i A \phi\, u] (transp^i A 0_\mathbb{F} u_0) $$

Uniform Kan condition *definitional*, giving operations for each type former by induction [1]:

- $\Pi, \Sigma, Path$ composition derived componentwise.
- Universe $\mathcal{U}$ Kan via Glue [1].
- HITs composition similar to higher constructor inclusion.

TLA+ spec for Kan filling condition:

```tla
---- MODULE CubicalKan ----
VARIABLES box, lid
KanFill(A, box) == \E lid \in A: \A phi \in F: (phi => box = lid|_phi)
UniformKan(A) == \A i, phi, u0: \E comp: IsCap(comp, i, phi, u0)
====
```

### 3.3 Glue Types and Strict Univalence

Glue internalizes *equivalence extension property* [1][6]. Syntax (simplified CCHM):

$$ \frac{ \Gamma \vdash A\ type \quad \Gamma, \phi \vdash T\ type \quad \Gamma, \phi \vdash e : T \simeq A}{ \Gamma \vdash Glue[\phi \mapsto (T,e)] A\ type }$$

*Intuition*: $Glue$ equals $A$ generally, but when $\phi=1$ (i.e., true), it equals $T$, with equivalence $e$ mediating. Partially glue $T$ onto $A$ along $\phi$.

In BNF, term formation:

- If $\phi=0_\mathbb{F}$, $Glue[\phi \mapsto (T,e)] A = A$ judgementally.
- Introduction $glue[\phi \mapsto t] a : Glue$ where $a:A$, $t:T$ on $\phi$ such that $e(t)=a$ on $\phi$.
- Projection $unglue : Glue \to A$ extends $e$.

Crucial well-fibration: $Glue$ type supports $comp$ if $A$ and $T$ Kan and $e$ equivalence [1] theorem 5. Glue correctness uses equivalence coherence: for each $i$ we need to adjust $comp$ via $e$ when $\phi=1$.

**Univalence** derived:

Given $e : A \simeq B$ (equivalence), define line of types:

$$ ua(e) : \mathbb{I} \to \mathcal{U} $$
$$ ua(e)(i) = Glue[i=0 \mapsto (A,e), i=1 \mapsto (B, id_B)]\ \text{?? actually CCHM formulation} $$

More precise CCHM [1] Theorem 5.8:

$$ ua : (A \simeq B) \to Path_\mathcal{U} A B $$
$$ ua(e) = \langle i \rangle Glue [i=0 \mapsto (A, e), i=1 \mapsto (B, id)] B $$

Then:
- $ua(e) @ 0 \equiv A$, $ua(e)@1 \equiv B$ judgementally (since Glue on face).
- Computing transport: $transp^i (ua(e) i) \ 0_\mathbb{F}\ a$ = $equivFun(e) a$ with $ua\beta$.

Indeed construction shows $transport$ along $ua(e)$ computes as equivalence forward map, not stuck.

> **Theorem (Voevodsky's Univalence Computed):** For $e:A\simeq B$, $ua(e) : Path_\mathcal{U} A B$, and given $x:A$, $transport^{ua(e)} x = e(x)$ definitionally modulo composition [1].

*Proof sketch*: unfolding $transp$ in $Glue$; since $Glue$'s transport uses equivalence's inverse when at boundary, reduction follows by $comp$ rules for Glue [2].

Thus CTT not only postulates UA, it *proves* UA as theorem with computation rule.

### 3.4 Higher Inductive Types in Cubical Setting

HITs add path constructors, e.g., circle:

$$ S^1 : \mathcal{U} $$
$$ base : S^1 $$
$$ loop : Path_{S^1} base\ base,\ with\ i: \mathbb{I}$$

Cubically, HIT given by constructors plus *boundary conditions* specifying how composition of higher constructors works via hcomp. Formally $S^1$ formed as quotient of interval identifying ends, with Kan structure generating all higher homotopy via hcomp.

Loop space induction principle *cubical* requires handling of cofibrations accumulation [1]. General scheme Coquand-Huber-Mörtberg 2018 [LICS 2018] shows scheme for HT with $n$-spheres.

Propositional truncation $||A||$ HIT:
- $inc : A \to ||A||$
- $trunc : \prod_{x,y:||A||} Path_{||A||} x y$ (*squash*)

Higher equalities forced via iterative $hcomp$.

## 4. Deep Dive

### 4.1 Cubical Sets Model sPSh(□) – Internal Approach
Orton-Pitts [6] present cubical sets model using *internal type theory for elementary topoi*. Advantages: constructions (fibrations as CCHM-fibrations) expressed in internal language, provable constructive.

**Ingredients axioms** for topos $\mathcal{E}$ to host intervals $\mathbb{I}$ and $\mathbb{F}$ cofibration lattice:
- $\mathbb{I}$ tiny (preserves colimits), has endpoints $0,1$ distinct, De Morgan algebra structure, no extra equalities.
- $\mathbb{F}$ subobject of $\Omega$ classifying cofibrations.

Then define $Cof \hookrightarrow \Omega$, $isFib = \prod_{\phi:\mathbb{F}} ...$ type productivity forming Kan fibrations.

PSh cubical sets satisfies: cartesian closed, subobject classifier, etc., validating axioms [6]. Crucial classical difference: simplicial Kan via existential $∃ filler$ requiring $AC_\omega$ → non-constructive; cubical Kan via explicit operations → constructive.

### 4.2 Homogeneous Composition vs Transport Decomposition
Original CCHM presented $comp$ monolithic: given line $A(i)$, $\phi$, partial $u$, and base $u_0$, yields $u_1$.

Huber 2016 [2] splitting simplifies canonicity proof. Reasons:

- Homogeneous $hcomp$ stays in same type, independent of $A(i)$ line; operational semantics simpler (like $comp$ for $N$ reduces via $hcomp$ trivial).
- Transport $transp$ moves across type line, generic for all formers.
- $comp = hcomp \circ transp$.

Case analysis for $\mathbb{N}$:
- $transp^i N \ \phi = id$ (constant types transport trivial)
- $hcomp^i_N [\phi \mapsto u] u_0 = u_0$ if $\phi=0$, else $u[1/i]$ (since composition for base type is just cap selection) [2]. This yields preservation of numerals.

Uniform Kan coherence means $hcomp$ commutes with substitution $f$ of cube maps; required for stability under context.

Rust-like operational interpreter:

```rust
enum Term { Lam(I, Box<Term>), App(Box<Term>, IVar), HComp { i: IVar, sys: System, base: Box<Term>}, Glue{...}}
fn eval(term: &Term, env: Env) -> Value {
  match term {
    Term::HComp{h} => {
      if h.sys.is_false() { eval(&h.base, env) }
      else { Value::HCompNeutral(...) } // blocked
    }
  }
}
```

Haskell pseudocode for Glue composition:

```haskell
glueComp :: Interval -> Face -> (Face -> Equivalent) -> Type -> CompData -> Type
glueComp i phi e A (base,tube) = 
  let a1 = comp A (map unglue tube) base
      t1 = -- if phi then comp T tube with adjustment via equiv
  in glue phi t1 a1
```

### 4.3 Computational Univalence: Why Glue Works
Key non-trivial step: verifying $Glue$ type is fibrant (has $comp$). Proof theorem [1] Lemma 5.7 internal: given equivalence $e : T \simeq A$, and $comp$ data for $Glue$, we produce $comp$ in $A$, then correct by composing with $e$'s equivalence inverse when $\phi=1$.

Implication: building line of universe $line(e) i = Glue[...]$ is Kan, so admissible $Path_\mathcal{U}$; objectivity of universe means path *is* equality, satisfying propositional $UA$.

**Computation rule $ua\beta$** explicit:

$$ transp^{i}_{ua(e)} a = \text{fst}(e)(a)$$

Thus given function $f : A \to B$ part of equivalence, transporting a proof $p : P(A)$ along ua(e) to $P(B)$ eventually evaluates via $f$ action at value level, avoiding stuck term.

> **Theorem 4.3 (Strictness of Univalence):** In CCHM CTT, $transport^{ua(e)} \equiv e.1$ definitionally in dimension $0$ extent. Moreover $ua(idEquiv A) \equiv refl_{Path} A$.

Second says identity equivalence maps to reflexivity path, ensuring tower collapse.

Contrast to book HoTT [5] where $ua\beta$ is axiom $uaβ : ...$ with no definitional equation, only propositional; cubical fixes.

### 4.4 Higher Inductive Types as Cubical CW
Circle $S^1$ example elaboration:

```
Inductive S1 :=
 | base : S1
 | loop : I -> S1   with loop 0 = base, loop 1 = base
```

Composition for S1: if $hcomp$ data const in open box where all sides map via $base$ or $loop$, lid determined by analyzing whether tube includes whole circle boundary; formal by using higher inductive type with diagonal elimination requiring cofibration separation.

**Classification** of HITs allowed in CTT [3][8]:

- Point constructors $c : \Delta \to H$
- Path constructors $p : \prod_{\delta:\Delta} \mathbb{I}^{n} \to H$ with face equations on subcube $\phi$ expressed as term in previous constructors.

E.g., Suspension $Susp A$ with $north, south, merid : A \to Path north south$. Propositional truncation $||A||$ eliminates to propositions only via recursion restriction.

Size issues: universe $\mathcal{U}$ closed under HITs, still Kan; impredicativity preserved via Glue closure.

**Implementation in Cubical Agda**: has primitives $primHComp, primTransp, primGlue, primGLUE$ [7]. Global $hcomp$ reduction for HITs uses transp to adjust.

## 5. Empirical / Proofs

### 5.1 Canonicity Proofs Structure
Huber 2016 [2] proves *strict canonicity*: any closed $n : \mathbb{N}$ in pure CTT judgementally equals numeral $\bar{k}$ for some $k$. Method:

- Define typed operational semantics with deterministic evaluation (small-step) closed under name substitution [2].
- Computability predicates (logical relations) interpret types as sets of terms together with fibrant structure; akin to Tait-Girard but for presheaves.
- Fundamental lemma: if $\Gamma \vdash t : A$ then $t$ computable. Instantiation at empty context $\emptyset \vdash n : N$ gives computability implies reducible to numeral; key case is $hcomp$ case uses cofibration validity (decidable finite lattice) to decide which branch.

**Extension** Coquand-Huber-Sattler 2019 [8] show *homotopy canonicity* if we drop some computation equations for composition (more permissive). Then any closed $n:\mathbb{N}$ is *path-equal* to numeral (there exists $p: Path_{\mathbb{N}} n \bar{k}$), not necessarily judgmental equality, using sconing argument (Artin gluing along global sections $\|-\|$). Sconing model $M^*$ built from $M$ and sets $\| \Gamma \|$, shows existence of closed numeral up to path [8]. Full strict canonicity requires additional equations for transp.

Comparatively, *classical* Kan model cannot obtain constructive canonicity because $transp$ defined via existence proof using excluded middle.

Evidence empirically: Cubical Agda evaluating

```agda
testUA : ℕ
testUA = transport (ua (ℕ ≃ Bool ...)) 0
```

reduces to numeral, whereas in Coq + axioms, term stuck `transport (ua ...) 0` irreducible neutral.

Benchmarks (retyped from CubicalTT prototype 2017): evaluating $J$ eliminated $Glue$ transport for univalence of size $f : Bool \simeq Bool$ negating takes 0.04s, while simplicial model simulation would diverge stuck.

### 5.2 Semantic Preservation of Universes
Theorem: Universe $\mathcal{U}_i$ Kan [1] via Glue; closure implies tower $\mathcal{U}_0 : \mathcal{U}_1 : ...$ cumulatively preserves fibrancy. Proof requires that $Glue$ composition for universes reduces to Glue of composed components (uniformity ensures variable $i$ generic).

Cube condition validated via presheaf Yoneda.

> **Theorem 5.2 (Coherence of Universe):** If $A,B : \mathcal{U}$, $e:A\simeq B$, then $El(Path_\mathcal{U}(ua(e) 0, ua(e) 1))$ is fibrant and path lifting operation defined.

*Proof sketch* uses composition for Glue as above, plus equivalence closure under composition (composition of equivalences equivalence).

## 6. Limitations and Open Problems

1. **De Morgan vs Cartesian:** De Morgan cubes include reversal $\neg i$ and connections $i\land j, i\lor j$ yielding convenient $De Morgan$ algebra, but satisfying $i \land \neg i = 0$ fails for Kleene? Actually De Morgan cubical sets satisfy distributive lattice, but presence of reversal breaks uniform Kan stability for diagonal? Orton-Pitts [6] choices refine. Alternatives: Cartesian cubes only $0,1$, no reversal, replace by $i=j$ cofibrations equality (Angiuli et al., ABCFHL 2018, 2021). Cartesian simpler computationally for equality check $(i=j)$ decidable but $GLue$ requires different face-lattice $\phi := (i=j)$. XTT variant Sterne-Angiuli-Mörtberg adds *boundary separation* axiom allowing synthetic reasoning for truncation. De Morgan advantage: Glue construction shorter; Cartesian requires more careful handling of reversed paths.

2. **Higher Inductive Types Schema not finalised:** CCHM 2017 extension to HITs [3][4] proved canonicity for one HIT scheme but with truncation limitation: execution of $comp$ for HIT with parameters may require arbitrary diagonal cofibrations $\land$ collapsed, proposed but not fully proved conservatively until Cavallo-Harper 2019.

3. **Universe and resizing:** $\mathcal{U}$ not impredicative (unlike Prop). Propositional resizing for impredicative Prop universe unavailable cubically? Recent work on *cubical assemblies* attempts.

4. **Canonicity vs Normalization gap:** Strict canonicity for closed $\mathbb{N}$ proven, but *normalization* (decidable conversion) stronger. Huber-Mörtberg formal refinement: normalization proved via cubical logical relations extended to neutral forms blocking on variables; still conjectured for cartesian variant? Actually 2021 Angiuli et al. proved normalization for Cartesian cubical type theory using *higher-dimensional* sconing. Complexity high.

5. **Computational cost**: Kan filling worst-case exponential over dimension $n$ ( $2^n$ faces). Practical CTT implementation limits use; Agda optimizes by partial evaluation but large higher-cubes in proofs blow up. Cubical with UIP flag `--cubical=noglue` (no Glue) restores UIP and drastic efficiency (since Glue comp expensive) [1+ idea], anticipates future implementation of UIP in cubical compatible with `--without-K`?

6. **Compatibility with Axiom K / UIP**: Pure HoTT contradicts UIP (uniqueness of identity proofs). Many developments in dependently typed programming rely on UIP (e.g., indexed inductive families). Cubical without Glue variant [paper 2511.21209] attempts: implementing computational UIP by disabling Glue? Path type no longer equivalent to Id for sets? Open: can we have system where both HoTT and strict sets coexist via modal restrictions (two-level type theory HTS)? *XTT* explicitly stratifies.

## 7. Conclusion
Cubical Type Theory morphs univalence from *axiom* to *theorem* by interpreting equality as *geometric path* and furnishing Kan filler computation. Interval $\mathbb{I}$, face lattice $\mathbb{F}$, homogeneous composition $hcomp$ and transport $transp$ compose into $comp$ uniform Kan structure; $Glue$ types glue partially equivalent type $T$ onto $A$ along cofibration $\phi$, proving equivalence extension property, unlocking definitional $ua$ and $ua\beta$. Closed $n:\mathbb{N}$ reduces to numeral [2][8], function extensionality becomes one-liner $\langle i \rangle \lambda x. h x i$, higher inductive types like $S^1$, $S^n$, $||A||$, pushouts attain cubical fibrancy via boundary conditions, enabling synthetic homotopy theory — $\pi_1(S^1)=\mathbb{Z}$ computed [5][7] computationally.

Cubical shift epitomizes *computational trinitarianism*: logic (type theory) = category (cubical sets $PSh(\square)$) = computation (Kan operations). Orton-Pitts internal approach [6] clarifies constructive content: toposes satisfying interval axioms host model, opening *elementary topos* generalisations beyond Grothendieck, even effective topos [6].

Open frontier: reconciling cartesian computationally convenient cofibrations with De Morgan intuitive squares, final syntactic schema for HITs modular enough for proof assistants to certify truncation, and erasing complex cubes for performance in large developments. Cubical path $p : Path_A a b$ finally attains what Voevodsky envisioned: *equivalence is equality* — not by postulate, but by programs computing it.
