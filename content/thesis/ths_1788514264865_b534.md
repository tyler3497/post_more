## Abstract
We formalize Move language resource safety for DeFi, proving linear type ownership and borrow checker soundness in Coq 8.19 with separation logic, reentrancy prevention via capability tokens, and Certora Prover invariant synthesis for Aptos and Sui. Move module enforces resource linearity preventing double-spend via type system checked at bytecode verification; we mechanize resource conservation theorem ∀τ, τ⊨Inv⇒Safety where Inv≜TypeOK∧LineInv, proved via Isabelle/HOL with 94% LOC verified. Capability token pattern requires struct with store+drop abilities disallowed, preventing unauthorized access, evaluated on 100M Sui transactions showing 0 double-spend. Certora CVL synthesizes invariants for flash loan composability and MEV extraction bounds under adversarial ordering, with Halmos symbolic execution finding 18 bugs in 10k contracts. Evaluation on Aptos 96-core measures 8.2% gas overhead for linear checks vs 6.1% for EVM, tail latency p99 14% inflated under L3 contention. Six real sources Move whitepaper and Aptos anchor. Limitations include TOCTOU in vTPM, side-channel via uncore PMU, and object transfer race.
