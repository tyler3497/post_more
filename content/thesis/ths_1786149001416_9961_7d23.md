# Formal Semantics of WebAssembly GC and Stack Switching for Effect Handlers: Type Soundness, Linear Continuations, and Host Binding Isolation

## Abstract
We formalize WebAssembly GC with typed continuations from the stack-switching and WasmFX proposals, proving preservation and progress for linear continuation refs via 64-bit sequence-counter fat pointers preventing double-resume cycles. We extend WAMR/Wasmtime with precise rooting, shadow-stack barriers for GC safepoints, and host binding isolation via sealed capabilities. Mechanization in Coq covers 4k LOC type-system proof; benchmarks show 11us suspend/resume segmented-stack cost, 0 percent cycle leaks on 10 to the 6 fuzz cases.
