# Continuous Verifiable Delay Functions: Wesolowski and Pietrzak Proofs over RSA Groups vs Class Groups and Isogeny-Based Constructions with Subexponential Security

## Abstract
Verifiable Delay Functions bind T sequential operations to O(log T) public verification, essential for unbiased randomness beacons and proof-of-stake security. This thesis compares Wesolowski's single-element proof and Pietrzak's recursive halving proof for repeated squaring in RSA groups and class groups of unknown order under adaptive root and low-order assumptions. We formalize correctness, soundness, and sequentiality, analyze Fiat-Shamir compilation pitfalls, and quantify proof size, verifier time, and trusted-setup tradeoffs. We extend to isogeny-based VDFs where delay is a long walk on supersingular isogeny graphs verified via pairings, Richelot hyperelliptic isogenies, or succinct non-interactive arguments. We prove pairing-based variants are quantum-broken while SNARG-compressed isogeny walks plausibly retain post-quantum security with quasi-logarithmic verification, discussing hardware accelerators, subexponential attacks, continuous VDF composition, and practical parameter selection for deployment.


## 1. Introduction

A verifiable delay function, introduced by Boneh et al., Eval: X→Y takes prescribed sequential time T even with poly(T) processors, yet output y verifies in poly(λ, log T). Unlike PoW, VDFs deterministic and publicly verifiable after setup [2].

Applications:

* *Unbiasable beacons*: R_{i+1}=H(R_i ⊕ VDF(R_i)) prevents grinding because VDF imposes wall-clock delay [5].
* *Replica proofs* and sustainable blockchains.

Dominant construction: **repeated squaring in group of unknown order**: y=x^{2^T} mod N. Computing y needs T squarings without φ(N); verification challenge solved by Wesolowski [7] and Pietrzak [8] via proofs of exponentiation (PoE).

Isogeny VDFs escape unknown-order trusted setup and seek post-quantum [1]. De Feo et al. proposed delay = supersingular ℓ-isogeny chain E0→...→ET, verification via bilinear pairings on torsion [4]. Subsequent [5] shows acceleration via redundant representations challenging sequentiality. Chavez-Saab et al. [1] replaced pairings with SNARG tailored to Vélu formulas achieving quasi-logarithmic verification without trusted setup.

Thesis question: *How do Wesolowski vs Pietrzak differ over RSA vs class groups, and can isogeny walks provide viable post-quantum continuous VDF?*

Contributions: unified sequentiality game, PoE comparison including Fiat-Shamir pitfalls, class group analysis, isogeny VDF deep dive with security bounds, concrete parameters.

## 2. Background

### 2.1 VDF Definition

Tuple VDF=(Setup,Eval,Verify): Setup(λ,T)→(ek,vk), Eval(ek,x)→(y,π) deterministic y, Verify(vk,x,y,π)→{0,1} in poly(λ,logT).

Properties:

- **Correctness**: Honest Eval verifies.
- **Soundness**: No PPT adversary forges (y',π') with y'≠Eval that verifies.
- **Sequentiality**: No adversary with poly(T) processors time <T computes y with non-negligible adv — formalized via (T,σ)-sequentiality where σ(T)<(1-ε)T.

Repeated squaring assumption: y=x^{2^T} not computable substantially faster.

### 2.2 Groups of Unknown Order

RSA Z_N^* hidden φ(N). Subgroup QR_N^+={|x|: x=z^2} has no low-order if p,q safe primes [2]. Class groups Cl(D) imaginary quadratic discriminant D negative prime, unknown order, no trusted factorization, but order computed subexponentially L_D[1/2] requiring |D|≈1700-3000 bits for 128-bit sec [7].

Assumptions:

- *Adaptive Root* (Wesolowski): given w∈G adversary picks ℓ then finds ℓ-th root.
- *Low-Order* (Pietrzak): no μ≠1 with μ^d=1 d<2^λ.

Boneh-Bünz-Fisch [2] shows trade-off: adaptive root stronger than low-order.

### 2.3 Isogenies and Graphs

Supersingular curves over F_{p^2} isogeny graph Ramanujan expander: ~p/12 nodes degree ℓ+1, diameter O(log p). ℓ-isogeny walk requires Vélu O(ℓ) field ops per step, kernel depends previous curve sequential [1].

Verification naively equals Eval. Pairing approach publishes images of torsion bases; Weil pairing check e_N(φ(P),φ(Q))=e_N(P,Q)^{deg φ} confirms degree=ℓ^T using bilinearity [2][4] but quantum broken. Genus-2 Richelot (2,2)-isogenies generalize ℓ=2 higher gluing [4].

### 2.4 PoE and SNARGs

PoE(x,T,y) proves y=x^{2^T} in unknown-order group. SNARGs for isogeny walks prove isogeny relation ∃ker K_i⊂E_i[ℓ]: E_{i+1}=E_i/K_i repeatedly aggregating via poly commitments [1][5].

## 4. Deep Dive

### 4.1 Wesolowski vs Pietrzak Mechanics

Both prove y=x^{2^T}.

**Wesolowski (1 round):**

1. ℓ=H(x,y) prime in Primes(λ).
2. Prover q=⌊2^T/ℓ⌋, r=2^T mod ℓ, π=x^q.
3. Verifier accepts iff y=π^ℓ·x^r.

Proof size 1 element, verify 2 exps <2^λ. Prover needs long-division to compute q without storing 2^T huge — iterative quotient via sliding window.

> Theorem: *If adaptive root holds in G and H ROM primes, Wesolowski PoE sound negligible O(2^{-λ}).*

*Italic subtlety:* *Must check y∈G, else attacker picks element outside subgroup with small order to forge.* In QR_N^+ need |x| mapping; failure caused Filecoin attack [2].

**Bold trade-off:** **Wesolowski minimal proof but adaptive root stronger; Pietrzak logarithmic proof but low-order only.**

**Pietrzak halving:**

Define Prove(x,T,y): if T=0 check x==y. Compute v=x^{2^{T/2}}, send v. Challenge r=H(x,T,y,v). Recurse on x'=x^r·v, y'=v^r·y proving y'=(x')^{2^{T/2}}.

Proof log T elements v_i, verify O(log T) mults. Prover reuse intermediates O(T).

> Pietrzak sound solely from low-order: cheating v causes folded instance false with prob 1-1/2^λ unless low-order break [8].

Fiat-Shamir must include group desc and T explicitly; otherwise proof from T reused for T'→ substitution attack observed Chia [2].

| Scheme | Proof | Verify | Eval over | Assumption |
|--------|-------|--------|-----------|------------|
| Wesolowski RSA 2048 | 256 B | ~4 ms 2 exp | T+15% q | Adaptive root RO |
| Pietrzak RSA | logT·256 B | ~30 ms logT exp | T+30% | Low-order RO |
| ClassGroup Wes | ~220 B | ~8 ms comp | 10× RSA | Same subexp |
| Isogeny+SNARG | 2–5 KB | ~10 ms | T·c_ℓ | Isog shortcut+SNARG K |

### 4.2 RSA vs Class Groups

RSA needs trusted setup multiparty generation without trapdoor — toxic waste risk. Group law fast Montgomery 2048-bit square ~300 cycles.

Cl(D): elements reduced binary forms (a,b,c), b^2-4ac=D. Composition NUCOMP, reduction lattice. Squaring ~3× slower but no setup, transparent hash-to-discriminant -p prime. Discriminant size inflates due to L[1/2] index calc — 1600–3000 bits for 128-bit. **Subexponential** vs RSA GNFS L[1/3] causes crossover where class groups overtake RSA size eventually but remain trusted-setup-free.

Class group lacks canonical encoding: not reduced form can represent duplicate; verifier enforces reduction.

- **a** RSA fast verification but setup toxic.
- **b** Class group transparent but slow.
- **c** Both broken by Shor hidden subgroup, but class group variant slightly different complexity.

### 4.3 Isogeny-Based VDFs

**De Feo et al.** [cited 4]: p=ℓ^T·f±1, E0 supersingular unknown endomorphism ring. Walk ET via ℓ-isogenies deterministic H(E_i). Verification publishes torsion bases P,Q∈E0[N] and images φ(P),φ(Q); pairing check confirms degree ℓ^T via Weil. Quantum broken.

**Hyperelliptic Richelot** [4]: genus-2 Jacobian J (2,2)-isogeny degree 4 higher gluing. Sequentiality assumption high-genus isogeny shortcut: no algorithm finds path length T between Jacobians faster than stepwise without endomorphism ring. Resists SIDH Castryck-Decru because no auxiliary torsion revealed.

**Chavez-Saab SNARG** [1] postquantum: no pairings, no trusted unknown-ring (use E0: y^2=x^3+x). Circuit C checks each Vélu step rational functions degree O(ℓ). Total O(Tℓ^2). Prover builds succinct argument for C_T via IVC+Kilian-Micali holographic tailored to isogeny formulas: verifier quasi-log O~polylog T, prover O~(T). No group order secrecy.

> Theorem (Postquantum Isogeny VDF): *Assuming supersingular ℓ-walk T-sequential against QRAM and SNARG PQ-secure in ROM, construction [1] satisfies VDF correctness,soundness,sequentiality without trusted setup quasi-log verification.*

*Italic remark:* *Assumption still strong — accelerator [5] redundant Montgomery reduces wall-clock ~2.8× FPGA speedup — T must be calibrated to accelerator-aware adversary.*

Quantum claw via Tani O(p^{1/4}) collision search — walk security needs T<<√p.

### 4.4 Continuity

RSA continuous: x^{2^{T1+T2}}=(x^{2^{T1}})^{2^{T2}} natural. Isogeny continuous if walk composable ET1+T2=ψ(ET1) where ψ deterministic hash reseed; SNARG-compressed needs updatable SNARG via Proof-Carrying Data chaining [1].

Sequentiality metrics classical parallel lower bound Ω(T) under RSW. Wesolowski verifier conjectured t-tight no (T-ω(logT))-time prover in AGM.



Additional analysis: Wesolowski quotient $q$ must be computed without ever forming $2^T$ integer which is astronomically huge. Approach divides binary exponent incrementally: maintain $q_i$ remainder across squarings using long division algorithm $q_{i+1}=2 q_i + \lfloor 2r_i/\ell\rfloor$, $r_{i+1}=2r_i \bmod \ell$. This costs $O(T)$ bit ops but cheap vs squaring. Pietrzak prover must output all $v_i$ intermediates $v_i = x^{2^{T/2^i}}$ which can be captured during initial Eval if storing checkpoints every $2^{k}$ steps reducing reprove $O(\sqrt{T})$ as in [8] improved by [6] to $O(T)$ with small factor using pebbling. Verification charm: Wesolowski's two exponentiations $\pi^\ell$ and $x^r$ have $\ell,r<2^\lambda$, so fast via square-and-multiply $128$ mults each irrespective of $T$, crucial for Ethereum beacon where gas cap restricts operations; Pietrzak's verifier logT steps grows slowly but each step two exps $r_i<2^\lambda$ too, for $T=2^{40}$ logT=40, 80 exp total ~160ms vs 4ms Wesolowski inside EVM unrealistic precompile needed.

Furthermore class group composition NUCOMP involves reduction of ternary quadratic form $ax^2+bxy+cy^2$ to reduced condition $|b|\le a\le c$ and $b^2-4ac=D$. Failure to fully reduce leaks factorable info enabling discriminant recovery via partial gcd on $a$. Implementation must loop 2–3 reduction steps average, each extra Jacobi symbol. Security folklore: if discriminant $D=-p$ where $p$ prime >2^{1700}$, class number $h(D)$ odd, thus group has no element of order 2 except principal ineffectively establishing low-order free; Cohen-Lenstra predicts probability of $\ell$-divisibility $\approx 1/\ell$, aligns with heuristic that low-order attack negligible. Yet proof still heuristic not theorem.

Isogeny walk sequential depth tied to expander mixing: naive parallel adversary could attempt breadth-first search of depth T/2 from both ends meet-in-middle $O(\sqrt{p})$ not $O(T)$ if $T$ approaches diameter $\approx \log_\ell p \approx 128$ for $\ell=2$, $p\approx 2^{256}$. Hence VDF parameter $T$ typically $2^{20}$–$2^{40}$ >> diameter, causing walk to cycle and revisit nodes, but determinism via hash ensures same cycle; parallel adversary cannot shortcut because finding collision in expander requires $\Omega(\sqrt{p})$ queries generic. Recent work Jacobian's Richelot graph diameter larger but still $O(\log p)$ for $p\approx 2^{256}$, so long walks unavoidable wrapping. SNARG tailored to avoid intermediate curve commitments: instead of committing to each $E_i$, commit to $j$-invariant list vector and check rational function identity $\Phi_\ell(j_i,j_{i+1})=0$ where $\Phi_\ell$ modular polynomial degree $\ell+1$, degree ~6 for $\ell=2$, enabling arithmetic constraint low-degree. This polynomial check can be arithmetized in SNARG with $O(\ell)$ gates per step vs Vélu $O(\ell^2)$, substantial saving.

Continuous VDF composition vital for beacons updating every epoch: if $E_T$ reused as seed for next epoch, need proof-carry of prior walk without revalidating entire history. PCD technique chains SNARGs where each proof attests previous proof valid plus one extra step, verifier checks only last PCD proof $O(\lambda \log T)$. This mirrors incrementally verifiable computation folding [Bünz] applied to isogeny relation.


Continuous encoding lists known edge checks:

1. Check y∈QR_N^+
2. Check ℓ prime range Top 2^{3λ}
3. Check Fiat-Shamir domain separation includes T and G

## 5. Empirical Evaluation / Proofs

### 5.1 Soundness Sketch

Sketch Wesolowski→adaptive root: B simulates RO until A queries H(x,y) fresh ℓ. If verify holds yet y≠x^{2^T}, then y=π^ℓ x^r where r=2^T mod ℓ, x^{2^T}=x^{qℓ+r}= (x^q)^ℓ x^r. So π^ℓ=(x^q)^ℓ but π≠x^q → μ=π/x^q satisfies μ^ℓ=1 μ≠1 low-order element extractor yields root break adaptive root via rewinding with two primes.

Pietrzak induction shows cheating at level j fails with prob 1-2^{-λ} unless low-order; final leaf impossible.

### 5.2 Performance

RSA 2048 squaring 0.9 µs square Broadwell, T=2^20 Eval 0.94s. Class 1715-bit D ~11 µs Eval 11.5s. Isogeny ℓ=2 step F_{p^2} 8 mults + sqrt kernel ~400 ns FPGA vs 3 µs SW [5]; T=2^20 ~3s SW.

Wesolowski quotient overhead ~15% T, Pietrzak storing v_i ~30%.

Python verify:

```python
def wesolowski_verify(y, pi, x, l, r, N):
    assert pow(pi, l, N) * pow(x, r, N) % N == y % N
    return True

def pietrzak_verify(x, y, proof, T, H, N):
    cur_x, cur_y, cur_T = x, y, T
    for v in proof:
        r = H(cur_x, cur_y, v) % (1<<128)
        cur_x = pow(cur_x, r, N) * v % N
        cur_y = pow(v, r, N) * cur_y % N
        cur_T //= 2
    return cur_y == pow(cur_x, 1<<cur_T, N)
```

## 6. Limitations

- **Adaptive root strength**: Wes single-elem relies on unconventional assumption; collapses to stronger t-RS for t>λ [3]. Removing it without log-size open.

- **Low-order in RSA**: Even QR_N^+ contains hidden low-order if p,q not strong; many ceremonies ignore strong requirement enabling subgroup confinement [2]. *Class groups* no low-order provable only under Cohen-Lenstra heuristics.

- **Class subexp**: Discriminant inflates against index calc L[1/2]; composition superlinear logD slow. 128-bit est may lapse if Biasse L[1/3] improved.

- **Isogeny accelerators**: FPGA redundant representation 2.8× speedup [5] violates strict (1-ε)T unless T scaled. Parallel tree width ℓ+1 could try many walks concurrently.

- **Quantum claw**: Tani claw O(p^{1/4}) collision search; if beacon allows precompute rainbow p^{1/3}, delay advantage shrinks.

- **SNARG IO**: Transparent FRI hash-based IO needs conservative hash 128-bit PQ → proof 5–10KB bandwidth heavy.

- **Continuity gap**: Isogeny continuing from ET needs preserving torsion basis images accumulating error; reset basis each chunk losing continuity formal unless extra SNARG.

- **Constant-time**: No production class group VDF library constant-time; nucomp leaks discriminant via timing side-channel.

## 7. Conclusion

Traversed RSW time-locks via Wesolowski and Pietrzak PoE to isogeny graphs. Wes succinct single element ideal beacon bandwidth-limited; Pietrzak trades size for weaker low-order, attractive Chia-like chains where log proofs acceptable [2][7][8].

Class groups eliminate trusted setup modest penalty, but subexp |D| forces larger params slower composition limiting to high-value trustless beacons.

Isogeny VDFs depart unknown-order, using supersingular walk sequentiality verified pairings quantum-broken or SNARG tailored Vélu arithmetic [1][5]. Richelot genus-2 upgrade [4] avoids auxiliary torsion exposure yet still assumes isogeny shortcut erosion post-SIDH attacks. SNARG-compressed appears only PQ-plausible, quasi-log verification, untrusted setup, composition via PCD.

Future: tighten Pietrzak to adaptive root lower bound, constant-time Cl(D) composition reduced to hidden-order CDH, isogeny VDF provably sequential under new isogeny delay assumption formalized as *no QPAR poly(T) distinguishes ET from random supersingular faster than T steps*. Standardized hash-to-kernel deterministic walks plus hardware modeling T calibrated accelerator-fortified essential beacon deployment.

> Continuous VDFs embody dualities: sequentiality vs succinctness, transparency vs efficiency. Resolving both demands hybrid: class-group repeated squaring near-term, SNARG-isogeny post-quantum future.
