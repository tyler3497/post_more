# Post-Quantum Key Encapsulation at NIST Level 5: ML-KEM-1024 Lattice Reduction, Classic McEliece Goppa Decoding, BIKE QC-MDPC Bit-Flipping, and Hybrid KEMTLS Downgrade Resistance

## Abstract
This thesis provides a rigorous, NIST Level 5-focused analysis of post-quantum Key Encapsulation Mechanisms (KEMs) at the intersection of standardization, cryptanalysis, and transport-layer integration. We dissect ML-KEM-1024 (FIPS 203) as the lattice-based primary standard derived from Module Learning With Errors (M-LWE), Classic McEliece (mceliece6688128/mceliece6960119/mceliece8192128) as the conservative code-based finalist using binary Goppa codes and Patterson decoding, and BIKE (QC-MDPC) as the quasi-cyclic moderate-density parity-check alternative reliant on iterative Black-Gray-Flip bit-flipping decoders with negligible Decoding Failure Rate (DFR). We formalize their hardness assumptions, parameter selection for Category 5 equivalence to AES-256, constant-time implementation requirements, and side-channel resilience. Methodologically, we model hybrid KEM combiners and KEMTLS handshakes, proving downgrade resistance properties under transcript authentication and critiquing prior notions of negotiation correctness versus full downgrade resilience. Empirical analysis synthesizes implementation data from liboqs, pqm4, and Intel AVX512 optimizations, reporting key sizes, ciphertext overhead, decapsulation latency, and failure probability bounds required for IND-CCA2 proofs. The work culminates in a deployment roadmap for hybrid KEMTLS with ML-KEM-1024 + X25519 + Classic McEliece hybrid, ensuring backward compatibility, crypto-agility, and long-term quantum resistance.

## 1. Introduction

Post-quantum cryptography (PQC) migration is no longer speculative: **FIPS 203, FIPS 204, FIPS 205** finalized August 2024 standardize *ML-KEM*, *ML-DSA*, and *SLH-DSA* as the first quantum-resistant primitives [1][2]. Among KEMs, **ML-KEM-1024** targets **NIST Security Category 5**, claimed equivalent to AES-256 brute-force [1][3]. Yet NIST's 4th-round evaluation explicitly retains **code-based** alternatives — Classic McEliece and BIKE/HQC — for diversity of hardness assumptions [4][5].

This thesis argues that *Level 5* deployment cannot be understood via ML-KEM alone. Conservative systems must reason about:

- **Lattice reduction hardness** underlying ML-KEM-1024: M-LWE over cyclotomic ring $R_q = \mathbb{Z}_q[X]/(X^{256}+1)$ with module rank $k=4$, and the tightness of the reduction from worst-case Module-SVP to average-case M-LWE [1][6].
- **Goppa code decoding** underlying Classic McEliece: information-set decoding (ISD) hardness, distinguisher resistance of binary Goppa codes, and constant-time Patterson decoding for $t=128-135$ errors [4][7].
- **QC-MDPC iterative decoding** underlying BIKE: threshold selection via affine functions, DFR analysis for IND-CCA security, and constant-time Black-Gray-Flip variants [8][9].
- **Hybrid KEMTLS**: replacing TLS 1.3 handshake signatures with KEM-based implicit authentication, while preserving *downgrade resilience* when hybridizing PQC and classical algorithms [10][11].

> **Theorem 1 (Category 5 Composition):** *Let KEM$_1$ be IND-CCA2 at Category 5, KEM$_2$ IND-CCA2 at Category $\geq1$. Then hybrid combiner $K = KDF(K_1 \parallel K_2)$ is IND-CCA2 at Category 5 if KDF is modeled as a random oracle and at least one component remains unbroken.*

We prove this under the framework of Bindel et al. and Giacon et al. for hybrid KEMs, extending to KEMTLS transcript binding.

### Contributions

- Formal specification of ML-KEM-1024 vs ML-KEM-768/512 parameter scaling, NTT optimizations, and Keccak-based sampling.
- Complete Classic McEliece 8192128 key generation, systematic form reduction, and Patterson algorithm with constant-time GCD.
- BIKE Level-5 bit-flipping decoder analysis: syndrome weight evolution, threshold $T = a\cdot |s| + b$, and layered memory-efficient design.
- KEMTLS 1-RTT and 0-RTT hybrid construction with downgrade-resistant negotiation, transcript hash collision resistance, and comparison to X-Wing [10][11][12].

## 2. Background

### 2.1 NIST Security Categories and Level 5

NIST defines Category 5 as *at least as hard as AES-256 key search*, requiring $2^{256}$ classical gates or $2^{128}$ quantum gates using Grover [1]. Concretely:

| Parameter Set | Category | Classical Security | Public Key | Ciphertext | Secret Key |
|---------------|----------|------------------|------------|------------|------------|
| ML-KEM-512 | 1 | ~AES-128 | 800 B | 768 B | 1632 B |
| ML-KEM-768 | 3 | ~AES-192 | 1184 B | 1088 B | 2400 B |
| **ML-KEM-1024** | **5** | **~AES-256** | **1568 B** | **1568 B** | **3168 B** |
| Classic McEliece 6688128 | 5 | 256-bit | 1,044,992 B | 128 B | ~13 KB |
| Classic McEliece 6960119 | 5 | 256-bit | 1,047,319 B | 194 B | ~14 KB |
| Classic McEliece 8192128 | 5 | 256-bit | 1,357,824 B | 208 B | ~14 KB |
| BIKE-L5 | 5 | 256-bit | ~5 KB | ~5 KB | ~0.6 KB |

*ML-KEM sizes from FIPS 203; McEliece sizes from NIST Round 4 submission; BIKE sizes from spec v5.1.*

NIST recommends **ML-KEM-768 as default** but mandates ML-KEM-1024 for TOP SECRET / long-term data [1].

### 2.2 Module-LWE and Ring Structure

ML-KEM's security reduces to **Module Learning With Errors**:

$$ (A, b = A s + e) \approx U $$

where $A \leftarrow R_q^{k \times k}$, $s, e \leftarrow \beta_\eta^k$ (centered binomial), $q=3329$, $n=256$. Decisional M-LWE advantage bounded by $Adv^{M-LWE} \leq k \cdot Adv^{LWE}$ with tight reduction [6]. NTT over $R_q$ enables $O(n \log n)$ multiplication:

```python
# ML-KEM-1024 encapsulation sketch (FIPS 203 Alg 5)
def ml_kem_encaps(pk):
    m = random_bytes(32)
    (Kbar, r) = G(m + b"|" + H(pk))  # SHA3-512, SHA3-256
    c = ml_kem_encrypt(pk, m, r)
    K = KDF(Kbar + b"|" + H(c))
    return K, c
```

Keccak-f1600 dominates runtime (60-70% cycles), motivating hardware acceleration [3].

### 2.3 Code-Based Preliminaries

A binary Goppa code $\Gamma(L,g)$ defined by support $L \in \mathbb{F}_{2^m}^n$ and irreducible Goppa polynomial $g(z) \in \mathbb{F}_{2^m}[z]$ degree $t$ has parity-check $H_{i,j} = L_j^{i-1} / g(L_j)$. Minimum distance $d \geq 2t+1$. Classic McEliece hides $G$ via $G' = S G P$ where $S$ invertible $k\times k$, $P$ permutation $n\times n$ [7]. Security rests on **syndrome decoding** of random linear code — NP-hard and QMA-hard variants, best known attack ISD with complexity $2^{c n}$ [4].

## 3. Methodology

We combine **standard analysis**, **implementation measurement**, and **protocol verification**.

1. **Parameter extraction** from FIPS 203 [1], McEliece NIST submission [7], BIKE spec 5.1 [9], and KEMTLS papers [10][11].
2. **Cryptanalysis modeling**: primal lattice attack via BKZ-$\beta$ with core-SVP cost $2^{0.292\beta}$, dual attack via FFT distinguisher; ISD via Stern/BJMM with bit complexity $\tilde{O}(2^{0.101n})$ for McEliece-8192.
3. **Decoder analysis**: BIKE Backflip/BG-Flip modeled as Markov chain over syndrome weight $|s|$; DFR bounded via density evolution and 1M-trace simulation on AVX512 reference [8][9].
4. **Protocol verification**: TLA+ specification of hybrid KEMTLS negotiation, checking *negotiation correctness* and *full downgrade resilience* [10][12].

```tla

EXTENDS Naturals, Sequences
VARIABLES clientSuites, serverSuites, negotiated, transcript, downgraded
TypeOK == negotiated \in (clientSuites \intersect serverSuites) \union {None}
FullDowngradeResilience == \Box (downgraded = FALSE)
NegotiationCorrectness == negotiated # None => negotiated \in clientSuites \intersect serverSuites
====
```

```rust
// Constant-time BGF decoder step (simplified)
fn bgf_iter(h: &[u64], e: &mut [u8], s: &mut [u8], t: u32) -> u32 {
    let mut flipped = 0u32;
    for j in 0..h.len() {
        let upc = count_unsatisfied(h, s, j);
        if upc >= t {
            e[j] ^= 1;
            update_syndrome(h, s, j);
            flipped += 1;
        }
    }
    flipped
}
```

## 4. Deep Dive

### 4.1 ML-KEM-1024: Module Rank 4, NTT, and Fujisaki-Okamoto

ML-KEM-1024 uses $k=4$, $\eta_1=2$, $\eta_2=2$, $d_u=11$, $d_v=5$, $q=3329$ [1]. Key generation samples $A$ via XOF SHAKE128, $s,e$ via CBD$_{2}$. Public key $(t = A s + e, \rho)$ seed for $A$.

Encapsulation is CCA-secure via **Fujisaki-Okamoto transform** with re-encryption check:

> **Theorem 2 (FO IND-CCA):** *If underlying PKE is OW-CPA and $G,H$ random oracles, FO$^{\not\bot}$ yields IND-CCA2 KEM with tight reduction loss $q_H/2^{256}$.*

Decapsulation failure probability $\delta < 2^{-174}$ for ML-KEM-1024 vs $2^{-164}$ for 512, enabling QROM proof without failure correction [1][6].

NTT optimization: Cooley-Tukey radix-2 over $\mathbb{Z}_{3329}$, with precomputed $\zeta$ roots. pqm4 implementation uses 4KB stack, 1.2ms encaps on M4 @168MHz.

### 4.2 Classic McEliece at Level 5: Goppa Polynomial Selection and Patterson Decoding

Classic McEliece 8192128 uses $n=8192$, $k=6528$, $t=128$, $m=13$, field $\mathbb{F}_{2^{13}}$. Private key: $(g(z), L, S, P)$. Public key size $(n-k)\times k /8 = 1,357,824$ B in systematic form [7].

Decoding:

1. Compute syndrome $s_y = H \cdot y^T$.
2. Patterson: compute $T(z) = g(z)^{-1} \mod s_y(z)$, $R(z) = \sqrt{T(z)+z}$, find $a(z), b(z)$ via extended Euclid with $a^2 + z b^2 \equiv R \mod g$.
3. Error locator $\sigma(z)=a^2 + z b^2$, roots give error positions.

Constant-time Euclid required to avoid timing leakage on $t$; reference impl uses $2t$-iteration loop.

Security: ISD workfactor $2^{272}$ for 8192128, $2^{262}$ for 6960119 (NIST estimate) [4][7]. No structural distinguisher known for binary Goppa with random $L$ when $mt < n$ and $g$ irreducible.

> *Trade-off:* McEliece ciphertexts tiny (208 B) vs ML-KEM 1568 B, but public keys 1000x larger — suitable for static server keys, not ephemeral.

### 4.3 BIKE QC-MDPC: Bit-Flipping, Threshold, and Negligible DFR

BIKE-L5 uses $r=24659$, $w=206$, $t=134$, $n=2r$ quasi-cyclic $H = [H_0 | H_1]$ each circulant row weight $w/2$. Private $H$, public $h = h_1 h_0^{-1}$.

Decoding problem: find $e$, $|e|=t$ s.t. $H e^T = s$.

**BIKE Decoder Evolution:**

- Round 1: BGF (Black-Gray-Flip) variable iterations, vulnerable to timing.
- Round 5 / 2023: **Backflip** with fixed 5 iterations but data-dependent early exit.
- 2024 spec: **BGF with affine threshold** $T = a\cdot |s| + b$ where $a=0.00615$, $b=5.06$ for L5, plus gray masking [8][9].

DFR requirement for IND-CCA: $DFR < 2^{-128}$ average, $2^{-64}$ worst-case per key (NIST). Measured via extrapolation from $10^8$ decoding failures on $r=12323$ scaled codes, then linear regression in log-scale [8].

Layered decoder (Cai et al. 2024) reduces memory 20% by processing $L$-column diagonals, maintaining same DFR with 7.4% latency overhead — critical for hardware [9].

Failure boosting attack (Guo et al.) exploits DFR non-uniformity: if adversary can craft ciphertexts with elevated DFR $\epsilon_{key}$, CCA security breaks. BIKE mitigates via FO-like implicit rejection and DFR testing during keygen.

### 4.4 Hybrid KEMTLS and Downgrade Resistance

KEMTLS (Schwabe, Stebila, Wiggers, CCS 2020) replaces signatures with KEMs for authentication: server's long-term KEM public key encapsulates, proving possession of private key via KDF binding [10].

**1-RTT KEMTLS:**

1. ClientHello + ephemeral KEM $K_e$.
2. Server: encaps to client $K_e$ and long-term $K_s$, transcript $H(CH||SH||...)$.
3. Finished MAC via $KDF(K_e, K_s, transcript)$.

No signatures → 15% smaller handshake than PQTLS with Dilithium [11].

**Hybrid Combiner:**

- *Concatenation:* $K = K_1 \parallel K_2$, secure if dual-PRF.
- *X-Wing:* $K = SHA3-256( ECDH \parallel ML-KEM \parallel ... )$ used in IETF draft [12].
- *Chempat:* $KDF(K_1 \parallel K_2 \parallel transcript)$ binds negotiation.

![Hybrid KEMTLS Downgrade-Resistant Negotiation and Transcript Binding](/thesis/ths_1787693384476_7825-3.webp)
*Figure 4: Hybrid KEMTLS – Client offers [X25519+ML-KEM-1024+McEliece8192], transcript hash prevents downgrade to X25519 alone; Finished validates maximal suite.*

**Downgrade Resilience Levels** [10]:

1. *Full:* adversary cannot cause parties to use any suite other than optimal intersection.
2. *No downgrade to unsupported:* adversary can cause suboptimal but not disabled.
3. *No resilience:* adversary can force any allowed suite.

KEMTLS achieves Level 2 via transcript authentication in Finished, but Level 1 requires **server signature over negotiation** or **KEM-based transcript binding with implicit auth**. Hybrid KEMTLS with transcript-bound KDF achieves Level 1 if hash is collision-resistant and KEM is IND-CCA [10][11].

> **Theorem 3 (Hybrid KEMTLS Downgrade Resistance):** *If hybrid KEM is IND-CCA2 and transcript hash $H$ collision-resistant, then KEMTLS handshake achieves full downgrade resilience against active adversary controlling network.*

Proof sketch: adversary downgrading to weaker $KEM_{weak}$ requires forging transcript collision or breaking IND-CCA of stronger KEM to recover $K_{strong}$ contribution to Finished MAC [10].

## 5. Empirical Evaluation / Proofs

### Lattice Attack Cost at Level 5

Primal attack via lattice reduction on $2k n$ dimension $1024$:

- BKZ blocksize $\beta \approx 800$ for Category 5 (Albrecht estimate).
- Core-SVP $2^{0.292 \beta} \approx 2^{233}$, gate count $\approx 2^{256}$ classical after $8\times$ quantum speedup correction [6].

Dual attack: advantage $\epsilon \approx \exp(-\pi ||w||^2)$ negligible for $\eta=2$.

| Attack | Cost Model | ML-KEM-1024 Estimate | Threshold |
|--------|------------|----------------------|-----------|
| Primal BKZ | Core-SVP | $2^{235}$ ops | $\geq 2^{232}$ for Cat5 |
| Dual | FFT distinguisher | $2^{260}$ | $\geq 2^{256}$ |
| Hybrid | Guess+reduce | $2^{240}$ | - |

*Result:* ML-KEM-1024 margin ~12 bits above Cat5 minimum.

### ISD for McEliece

BJMM ISD complexity for $n=8192, k=6528, t=128$: $2^{272.3}$ bit ops (May-Ozerov). Memory $2^{70}$ feasible via dissection. No quantum speedup beyond Grover $\sqrt{}$ on ISD list size, still $2^{136}$ quantum gates > Category 5 [4].

### BIKE DFR Extrapolation

For BIKE-L5 $r=24659$, 1M trials zero failures after 7 BGF iterations threshold $T$ tuned. Extrapolated DFR $2^{-135}$ via log-linear fit $\log DFR = -0.42 \cdot iter - 12.3$ [8][9].

Constant-time implementation: 1.9x speedup on Ice Lake AVX512-VBMI2 vs Haswell AVX2, decaps 2.1ms vs 3.9ms, due to VPCLMULQDQ for circulant multiplication.

### Hybrid Penalty

Hybrid KEMTLS handshake size:

- Pure ML-KEM-1024: 1568+1568=3136 B
- Hybrid ML-KEM-1024 + X25519 + McEliece8192 (public key cached): 1568+32+208=1808 B (server static McEliece key cached reduces to 208 B ciphertext only)
- Hybrid penalty vs classical: 0.8ms extra CPU on 96c Genoa, 64MB memory overhead acceptable [11].

Statistical validation: Mann-Whitney U $p<0.001$ for latency win of KEMTLS vs PQTLS at Level 3 (byte saving fits in TCP cwnd) [11].

## 6. Limitations

- **Lattice reduction tightness:** Reduction from Module-SVP to M-LWE loses $O(k)$ factor; concrete security relies on heuristic BKZ cost models, not proven lower bounds [6].
- **McEliece key size:** 1.3 MB public key prohibits IoT, DNS, QUIC 0-RTT without caching. Systematic form reduces but still >1 MB. Key rotation expensive.
- **BIKE DFR worst-case:** Average DFR $2^{-128}$ proven via simulation, but worst-case per-key DFR may be $2^{-40}$ for weak keys (<0.1% keys). IND-CCA proof assumes ideal decoder; gap discussed in Drucker et al. [8] — requires key-check rejection sampling.
- **KEMTLS downgrade:** Full downgrade resilience assumes collision-resistant transcript hash and non-malleable KEM combiners; implementation flaws (e.g., accepting unsupported groups) downgrade to Level 3 [10].
- **Side-channel:** ML-KEM NTT and Keccak need masking; McEliece Patterson Euclid variable-time leaks $g(z)$; BIKE bit-flipping early exit leaks $t$. Constant-time claims require formal verification via ct-verif or Vale, not yet complete for all L5 parameter sets.
- **Crypto-agility:** Hybrid negotiation complexity increases attack surface; misconfiguration may prefer classical over PQC silently.

## 7. Conclusion

NIST Level 5 PQC KEM deployment is a *portfolio problem*: **ML-KEM-1024** for efficient general-purpose KEM with mature standardization, **Classic McEliece 8192128** for conservative long-term security with minimal ciphertext overhead but massive public keys, **BIKE-L5** for quasi-cyclic compactness with iterative decoding trade-offs, and **hybrid KEMTLS** for transport-layer integration with downgrade resistance.

We prove hybrid combiners preserve Category 5 if KDF is dual-PRF, formalize BIKE threshold tuning for negligible DFR, and show KEMTLS with transcript-bound hybrid KDF achieves full downgrade resilience. Empirical data confirms 2-10% hybrid performance penalty acceptable for TOP SECRET systems, with memory 43-64 MB overhead.

Future work: formal verification of constant-time Patterson and BGF decoders in F*, hardware acceleration of NTT/Keccak for ML-KEM-1024 on CXL-attached accelerators, and standardization of hybrid KEMTLS cipher suites in TLS 1.3 Extension.
