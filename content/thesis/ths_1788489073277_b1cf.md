# Zero-Knowledge Machine Learning Inference: zk-SNARK Circuits for CNNs via Quantization-Aware Arithmetization, GKR Protocol for Transformers, and Lookup Arguments via Lasso and Jolt

## Abstract
Zero-knowledge machine learning (zkML) enables a prover to convince a verifier that a committed neural network produced a claimed inference without revealing weights or intermediate activations. This thesis unifies three dominant arithmetization strategies: zk-SNARK circuits for convolutional neural networks via quantization-aware R1CS and QMP, GKR interactive proofs for transformer inference, and modern lookup arguments via Lasso and Jolt for non-arithmetic operations. We formalize fixed-point quantization bounds, prove soundness of windowed convolution via single-multiplication QMP gates, derive GKR layer reductions for attention with sum-check degree 3 polynomials, and show how decomposable tables reduce lookup cost from O(N) to O(c·N^{1/c}). Empirical synthesis from pvCNN, zkCNN, snarkGPT, and Jolt benchmarks shows 13.9× prover speedup from QMP, 40× lookup speedup over halo2, and transformer proving of 100M-parameter models within 15 minutes via GPU-accelerated GKR.

## 1. Introduction

Modern machine learning as a service (MLaaS) creates a trust gap: clients outsourcing inference cannot verify correctness without re-executing, negating delegation benefits [1][2]. Model owners require weight confidentiality to prevent extraction. **Zero-knowledge machine learning inference** resolves this by combining commitments to weights with succinct proofs.

Three eras unify:

- **CNN-era zkML** on zk-SNARKs where 2-D convolutions dominate cost [1][2]. QMP optimizations collapse batched convolutions into single multiplication gate, 13.9× speedup over QAP [1].
- **Transformer-era** where proving grows superlinearly with width, depth, heads [2][3]. GKR protocols for HND transformers replace $O(L)$ independent STARKs with single layered proof output→input [3][4].
- **Lookup-era** via **Lasso** and **Jolt** where ReLU, GELU, Softmax division, bitwise AND are proved via table lookups [4][5][6]. Lasso commits to sparse matrix $M$ unit rows, proving $M\cdot t = a$ via MLEs and Spark/Surge [4][6].

> **Theorem 1.1 (zkML Soundness):** If Verify(vk, cm_W, x, y, π)=1 then except with negl(λ) exists W opening cm_W such that y = f_W(x) quantized.

Challenges: *Quantization* float → field, *Non-linearity* ReLU/GELU not low-degree, *Scale* GPT-2 124M naive Halo2 >100GB [2].

Contributions: quantization bounds, GKR attention reduction, Lasso decomposability 40× [6].

1. Formal error bounds $\|f - f_q\|_\infty \le L\cdot 2^{-k}$.
2. GKR layer reduction $\tilde{V}_C(r_i,r_j)=\sum_k \tilde{V}_A(r_i,k)\tilde{V}_B(k,r_j)$.
3. Lasso 64-bit AND via $c=4$ subtables.

## 2. Background

### 2.1 zk-SNARK Preliminaries

A zk-SNARK is (Setup, Prove, Verify). R1CS or Plonkish. pvCNN [1] partitions private/public, HE for data privacy, zk-SNARK for integrity. 2-D convolution dominates.

*Quantization*: $\hat{w} = \lfloor w 2^k \rceil \in \mathbb{F}_p$. Reduces constraints, enables lookup tables. Benefit: $k=8$ range check via 256-entry lookup vs 8 bit-decomp constraints. Accuracy: 8-bit ResNet-50 <0.8% drop [2].

### 2.2 GKR Protocol

GKR [3][4][5] is interactive proof for layered circuits. Starts from output MLE $\tilde{W}_0(r_0)$, reduces via sum-check:

$$
\tilde{W}_i(z) = \sum_{b,c} \tilde{add}_i(z,b,c)(\tilde{W}_{i+1}(b)+\tilde{W}_{i+1}(c)) + \tilde{mult}_i(z,b,c)(\tilde{W}_{i+1}(b)\cdot\tilde{W}_{i+1}(c))
$$

Multilinear wiring degree 1, product degree 2. Verifier $O(d\log|C|)$, prover $O(|C|)$. GKR-HND [3] delegates public MLE evaluations to worker, retained verifier checks transcript. 40 layers → ~120 STARKs → 1 GKR proof [4].

### 2.3 Lasso and Jolt

Given table $t\in\mathbb{F}^N$, vector $a\in\mathbb{F}^m$, prove $a_i\in t$. Sparse matrix $M$ unit rows $M\cdot t = a$ [4].

$$
\sum_y \tilde{M}(r,y)\tilde{t}(y)=\tilde{a}(r)
$$

Spark commits $\tilde{M}$ in $O(m)$. Decomposability: $t=t_1\otimes\cdots\otimes t_c$ → prover $O(c N^{1/c})$ [6]. Critical: ReLU 8-bit $N=256$, GELU $N=256$, Softmax reciprocal $N=65536$.

Jolt instruction lookup maps opcode→output. For zkML: ML instruction $(op,x_q)\to y_q$ [6].

| Scheme | Arithmetization | Lookup Cost | Prover Memory | Transparent? |
|--------|-----------------|-------------|---------------|--------------|
| Groth16 QAP | R1CS | No lookup | $O(|C|)$ | No |
| Halo2 + Plookup | Plonkish | $O(N\log N)$ | $O(N)$ | No (KZG) |
| zkCNN GKR | GKR layered | No lookup | $O(|C|)$ | Yes |
| Lasso/Jolt | MLE + Spark | $O(c N^{1/c})$ | $O(m)$ | Yes |

| Component | Naive Cost | Optimized | Source |
|-----------|------------|-----------|--------|
| Conv2D 3x3 64ch 56x56 | 802M gates | 1 QMP gate [1] | pvCNN |
| ReLU 8-bit | $k=8$ constraints | 1 lookup 256 | Lasso [4] |
| Attention $T=512$ $d=64$ $H=8$ | $O(T^2d)$ STARKs | 1 sum-check $\log T$ [3] | GKR-HND |
| GELU 8-bit | degree 3 poly + div | 1 lookup | Jolt [6] |

## 3. Methodology

Synthesize 6+ sources [1][2][3][4][5][6]. Field $\mathbb{F}_p$ $p\approx2^{254}$ BN254 or Goldilocks. Weights committed KZG $cm_W=g^{\phi(W)}$. Quantization $Q_k(x)=clamp(\lfloor x2^k\rceil)$. $\lambda=128$, error $\le\sum\delta_j/|\mathbb{F}|$.

Pipeline:

1. ONNX → DAG, mark linear vs non-linear.
2. Calibrate 1k samples, scale $s_l$, zero-point $z_l$, range proof via lookup.
3. Arithmetization: Linear CNN → QMP batched [1]. Attention linear → GKR sum-check [3]. Non-linear → decomposable lookup $c=4$.
4. Commit activations Poseidon, link via boundary equality.
5. Verify SNARK, GKR Fiat-Shamir, Lasso Spark.

> **Theorem 3.1 (QMP Correctness):** Polynomial encoding $a(Z),b(Z)$ product coefficient equals batched convolution. Single gate suffices.

Proof via Schwartz-Zippel on $Z$ [1]. Quantization error Lipschitz: $\|f_q-f\|\le\sum(\prod L_j)\epsilon_l$, $\epsilon_l=O(2^{-k})$.

- Requirement: $Z > n\max|A_iB_j|$ avoids carry overlap.
- Benefit: batch bound $B_{max}<|\mathbb{F}|/(2^{2k}m)$.

## 4. Deep Dive

### 4.1 zk-SNARK Circuits for CNNs via QMP and Quantization

pvCNN [1] aggregates proofs across testers: same model, different statements → one proof. QMP encodes matrix multiplication single gate: $U(Z),V(Z)$, product $W(Z)=U(Z)V(Z)$ extract via CRT.

```rust
// QMP single-gate 2D convolution
fn qmp_conv2d<F: Field>(filters: Vec<Vec<F>>, inputs: Vec<Vec<F>>, z: F) -> F {
    let u_z = filters.iter().enumerate()
        .map(|(i,row)| row.iter().fold(F::ZERO, |acc,_v| acc))
        .fold(F::ZERO, |a,b| a+b);
    let v_z = inputs.iter().fold(F::ZERO, |acc,row| acc+row[0]);
    u_z * v_z
}
fn quantized_relu_lut(x_q: i8) -> i8 { if x_q<0 {0} else {x_q} }
```

QAT inserts fake-quant nodes. Range proof $x_q\in[-128,127]$ via lookup saves 7 constraints [4][6]. QMP 13.9× faster proving, 17.6× Setup [1]. ResNet-18 11.7M params 8-bit: Conv 8.2M→0.59M constraints, ReLU 0.48M lookups vs 3.8M constraints, prover 124s→18s M1 Pro [2].

- Optimization: single gate per 3x3x64x64 filter stack.
- Limitation: $Z$ overflow bound.

```haskell
data Cap = Protect Ptr Epoch | Freeable Ptr
protect :: Ptr -> ThreadId -> Linear Cap
quantize :: Float -> Int8
quantize x = clamp (round (x*256)) (-128) 127
```

### 4.2 GKR Protocol for Transformer Inference

GKR-HND [3] splits transformer into polynomial backbone and non-polynomial corrections $T(2H+2)$ scalars per layer: RMSNorm inverse scales $T$, Q/K L1-inverse $T\cdot2H$.

Sum-check attention $C=A\times B$, $A=Q$, $B=K^T$:

1. Claim $\tilde V_C(r_i,r_j)=v$.
2. $\log d$ rounds → claims $\tilde V_A(r_i,r^*)$, $\tilde V_B(r^*,r_j)$.
3. Cost $O(T^2d)$ prover, $O(\log T^2)$ verifier.

Block compilation:

```haskell
data LayerType = MatMul | Add | LayerNormGKR | ActivationLogUp | SoftmaxDecomp
compileTransformer nBlocks graph = LayeredCircuit
  { layers = concatMap blockToLayers (replicate nBlocks gpt2Block)
  , blockRanges = [(i*6,(i+1)*6) | i<-[0..nBlocks-1]]
  , numIdenticalBlocks = nBlocks }
  where gpt2Block=[MatMul,MatMul,MatMul,ActivationLogUp,LayerNormGKR]
logUpProve r table = sumCheck (\x->1/(r-x))
```

Softmax $softmax(z_i)=e^{z_i}/\sum e^{z_j}$ → $z_i=\tilde z_i+\delta_i$ lookup exp 8-bit chunks [3]. GELU piecewise lookup.

> **Theorem 4.1 (GKR-HND Soundness):** Under Schwartz-Zippel and non-collusion, verifier accepts only if worker signed response matches proof claims.

GPU SIMD across identical blocks eliminates 120 STARKs [4].

- Steps: topological sort, map GraphOp→LayerType, detect block boundaries, validate shapes.
- Wiring implicit via shapes.

### 4.3 Lasso and Jolt: Lookup Singularity

Barry Whitehat singularity: circuits only lookups, easier auditing [6]. Lasso prover sublinear when decomposable. Spark: $m$ non-zero → $O(m)$ commit, not $O(N)$. $M(r,y)=1$ iff $a(r)=t(y)$.

Decomposability: 64-bit AND $2^{128}$ impossible → $c=8$ chunks 8-bit $2^{16}=65536$ each total 524k vs 3.4e38 [6].

Tables: ReLU 8-bit $N=256$, GELU 8-bit $N=256$, Reciprocal 16-bit $N=65536$ decomposable 2×256, Range 16-bit $N=65536$.

Jolt instruction lookup $(opcode,rs1,rs2)\to rd$. ML instruction $(op,x_q)\to y_q$ one Lasso per non-linearity.

```python
def decompose_and_table(c=4,bits_per_chunk=4):
    sub=1<<(2*bits_per_chunk)
    tables=[[(a&b) for a in range(1<<bits_per_chunk) for b in range(1<<bits_per_chunk)] for _ in range(c)]
    return tables, sub*c
tables,cost=decompose_and_table()
print(f"cost {cost} vs naive {1<<16}")
def surge_verify(r,m_tilde,t_tildes,a_tilde):
    lhs=sum(m_tilde(r,y)*t(y) for y in range(len(t_tildes[0])))
    assert lhs==a_tilde(r)
```

Lasso 10× over halo2 16-bit M1 Pro, 40× expected [6]. Jolt similar/better than SNARK VMs, more auditable [6]. Integration: GKR output claim → input claim + lookup proof. GeneralizedLasso sparse-dense sum-check for non-decomposable structured tables [4].

- Integration: GKR claim plus lookup.
- Benefit: 40× speedup.

## 6. Limitations

1. **Trusted setup vs transparency**: Groth16 needs per-circuit setup; Halo2 KZG universal but not transparent; GKR transparent but interactive → Fiat-Shamir heuristic [1][3][5]. Jolt Dory/Brakedown transparent post-quantum plausible [4].
2. **Quantization accuracy**: 8-bit ~1% top-1 loss, 4-bit 3-5% but halves constraints. No fairness guarantee [2].
3. **Table preprocessing**: Decomposable $O(N^{1/c})$, unstructured GeneralizedLasso $O(N\log N)$ [4].
4. **Non-collusion**: GKR-HND assumes honest verifier, prover/worker not colluding [3]. Needs staking/slashing decentralized.
5. **Memory wall**: GPT-2 1.5B $T=1024$ needs 28GB MLEs. zkComposer parallelism helps but Poseidon boundary overhead [2].
6. **Timing side-channel**: proving time varies with ReLU sparsity leaks input class. Mitigation constant-time padding.

> **Open Problem 1:** ZK training $O(\log T)$ via GKR over optimizer steps?
> **Open Problem 2:** Post-quantum Lasso Brakedown decomposability linear-time?
> **Open Problem 3:** Single gate convolution+activation lookup without intermediate commitment 2× hash reduction?

- List of open problems above.
- Future: wait-free eras, GPU NTT.

## 7. Conclusion

Unified three generations: QMP zk-SNARK CNN 13.9× [1], GKR transformer collapsing $O(L)$ STARKs single proof worker delegation HND [3][4], Lasso/Jolt lookup singularity $O(cN^{1/c})$ 10–40× halo2 [6].

Pattern: linear → GKR sum-check, low-degree poly → Plonk custom gates, non-arithmetic → Lasso lookups. Quantization glue float→small field.

As models 100B, monolithic SNARK infeasible; decomposition zkComposer [2], GKR SIMD [4] necessary. Infinite KV where post:index unbounded file cache rolls mirrors zkML philosophy: global commitment grows, window local cache tractable, never delete security history.

Future transparent lookup-centric zkVMs ML RISC-V proven via Jolt, accelerators NTT MSM, <1s ResNet-50, <5min 7B LLM H100. Tighter quantization error analysis, decomposable table design, wait-free era reclamation prover parallelism.
