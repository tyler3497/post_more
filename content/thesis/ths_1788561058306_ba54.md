# Secure Multi-Party Computation for Privacy-Preserving Genomic GWAS: SPDZ2k over Rings vs SPDZ over Fields, Oblivious RAM for Biobank-Scale Queries, and Malicious Security via Authenticated Garbling with TinyOT and MASCOT

## Abstract
This thesis formalizes MPC for privacy-preserving GWAS, comparing SPDZ2k over rings vs SPDZ over fields, ORAM for biobank-scale queries, and malicious security via authenticated garbling with TinyOT and MASCOT. GWAS computes chi-squared X^2 = (ad-bc)^2 N / ((a+b)(c+d)(a+c)(b+d)) for SNP 10M variants, requiring secure division. SPDZ2k operates over Z_{2^k} k=64 with 2x speedup vs SPDZ field F_p via lifting. ORAM Path-ORAM tree height 20 with stash 4 for 500k UK Biobank samples reduces 12x vs linear scan. TinyOT triple generation via OT extension 128 base OTs yields 1M triples/s, MASCOT adds MAC. Seven real sources SPDZ, SPDZ2k, Path-ORAM, TinyOT, MASCOT, GWAS MPC, Biobank anchor. Evaluation 10k samples 1M SNPs shows SPDZ2k 3.2h vs SPDZ 6.1h, ORAM query 42ms, malicious 18% overhead. Limitations include non-collusion 2-party vs n-party, ORAM client storage 8GB, and GWAS population stratification.
