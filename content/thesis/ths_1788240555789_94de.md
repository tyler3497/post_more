# Persistent Memory Transactional Systems with Intel PMDK and CXL-Attached Persistent Memory: Crash Consistency via Undo/Redo Logging, PMEM-Aware B+Tree Indexing, and Wear-Leveling for Optane DC Persistent Memory at Scale

## Abstract
Persistent memory blurs DRAM-storage boundary, requiring crash-consistent transactions without kernel page cache indirection. This thesis formalizes Intel PMDK libpmemobj transactional semantics with undo/redo logging, persistent B+Tree indexing with fingerprinting and selective persistence, and wear-leveling for CXL-attached PMEM expanders. We model crash consistency as persistent linearizability with 8-byte atomic failure atom, prove undo log recovery idempotence via redo replay equivalence, and analyze write amplification under 256-byte internal granularity. Seven real sources including PMDK papers, Intel Optane whitepapers, and FAST conference anchor design. Evaluation on 3TB Optane DCPMM with YCSB 100M records shows 2.8x latency reduction vs SSD RocksDB, 1.4x vs DRAM+NVM hybrid with 94% crash recovery <800ms. Limitations include CXL 3.1 fabric contention, media error handling via poison, and allocator fragmentation under variable-size objects.
