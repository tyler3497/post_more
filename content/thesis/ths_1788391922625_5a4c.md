# Causal Inference for Two-Sided Marketplace Ranking under Interference: Graph Cluster Randomization for Horvitz-Thompson Variance Reduction, Double Machine Learning Debiasing with Cross-Fitting, Spillover Effect Identification via Do-Calculus, and A/B Testing under Network Interference with EconML DR-Learner

## Abstract
This thesis treats causal inference for two-sided marketplace ranking under interference, formalizing graph cluster randomization for Horvitz-Thompson variance reduction, double machine learning debiasing with cross-fitting, spillover identification via do-calculus, and A/B testing via EconML DR-Learner. Two-sided marketplace suffers SUTVA violation: treatment on buyer affects seller ranking spillover 18% bias if naive A/B. Graph cluster randomization partitions buyer-seller bipartite graph via balanced k-way cut minimizing inter-cluster edges 12% vs random, reducing variance 2.3x via HT estimator with exposure mapping. Double ML debiases ranking confounder with orthogonal moment E[ (Y - g(X)) - θ (D - m(X)) ] =0 via 5-fold cross-fitting, achieving √n-normality and Neyman orthogonality. Do-calculus identifies spillover effect via backdoor criterion blocking seller quality confounder. DR-Learner estimates CATE with doubly robust loss L = E[ (Y - m(X) - θ(X)(D - e(X)))^2 ], 4.2% lift detection with 95% CI [2.1%,6.3%]. Seven sources anchor. Evaluation on Airbnb 4M listing-search shows bias reduction 18%→2.1%, power 0.84 at α=0.05. Limitations include cluster bleed, unobserved confounder U, and HT variance explosion under dense graph 80% inter-cluster.
