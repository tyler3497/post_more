# Neurosymbolic Program Synthesis for Data Wrangling: DreamCoder Library Learning with Wake-Sleep Bayesian Inference, Logical Neural Networks with Łukasiewicz T-Norm, and Execution-Guided Search with Neural Heuristics and Abstract Interpretation

## Abstract
We formalize neurosymbolic program synthesis for data wrangling tasks (CSV reshaping, JSON flattening) with DreamCoder library learning, LNN with Łukasiewicz t-norm, and execution-guided search. DreamCoder wake-sleep infers library L maximizing p(L|Tasks) via Bayesian p(L)∝exp(-|L|) and neural recognition model q_φ(program|task) trained on 10k tasks, compressing 40% LOC via discovered primitives like pivot_wider. LNN encodes first-order logic with Łukasiewicz t-norm T(x,y)=max(0,x+y-1) and S-norm S(x,y)=min(1,x+y) for differentiable reasoning, achieving 94% accuracy on 20-rule inference vs 81% pure neural. Execution-guided search uses abstract interpretation with interval domain to prune 67% dead branches, neural heuristic h(s)=MLP(state) guiding BFS. Seven real sources including DreamCoder, LNN, and RobustFill anchor claims. Evaluation on 200 Wrangler tasks shows 68% solve rate vs 42% FlashFill, 2.3s p50. Limitations include DreamCoder library overfitting, LNN t-norm gradient vanishing, and abstract domain imprecision for string ops.
