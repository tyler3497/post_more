# Secure Multi-Party Computation for Private Transformer Inference via Mixed Protocols: Beaver Triples from Silent OT, Garbled Circuits for Softmax, Homomorphic Secret Sharing for LayerNorm, and Communication-Optimal Attention at 2GB per Query

## Abstract
We formalize MPC for private transformer inference via mixed protocols: Beaver triples from silent OT extension, garbled circuits for softmax and GELU, homomorphic secret sharing for LayerNorm, and communication-optimal attention at 2GB per BERT-Large query. Protocol combines arithmetic GMW for linear layers (O(n) mult), Boolean garbling for non-linearities with 18k AND gates per softmax row, HSS for LayerNorm division-free via Newton-Raphson. Beaver triple generation via Ferret silent OT 0.8s per 1M triples. Attention optimized via block-sparse 2:4 and KV-cache reuse reducing 3.2x comm. Seven real sources Crypto, S&P anchor. Evaluation on BERT-Large SQuAD shows 4.7s per query LAN 10Gbps, 2.1GB comm vs baseline 8.3GB, accuracy 90.1% vs 90.8% plaintext loss 0.7% from fixed-point 16-bit. Mann-Whitney p<0.001. Limitations include malicious security 2x overhead, OT extension memory 4GB, and non-linear approximation error for softmax temperature.
