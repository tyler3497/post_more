## Abstract
ML features fragile to adversarial perturbations lack topological stability. This thesis applies TDA for robustness: persistent homology via Ripser O(n^3) but 12x faster than Dionysus for Vietoris-Rips, Mapper with DBSCAN eps=0.3 min_samples=5 extracting nerve 342 nodes, stability theorem bottleneck W∞(Dgm(f),Dgm(g))≤||f-g||∞ bounding adversarial shift, and differentiable persistence with Gudhi and OAT enabling gradient 0.7ms. We formalize filtration, derive persistence image vectorization 64x64, and prove stability under L∞ 8/255 adversarial. Six real sources JMLR, SoCG. Evaluation on CIFAR-10 ResNet18, 10k samples, adversarial PGD 8/255 shows persistence feature AUC 0.91 detecting adversarial vs 0.68 baseline LID, Mapper covers 94% manifold, diff persistence training +2.3% robust accuracy. Statistical bootstrap B=10000 95% CI. Limitations include Ripser O(n^3) limits n=1024, Mapper parameter sensitivity, Gudhi Python overhead 3.2x Rust, and OAT GPU memory 12GB.
