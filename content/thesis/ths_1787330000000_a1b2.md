# Linearizability Proofs for Lock-Free Memory Reclamation: Hazard Pointers, Epoch-Based Reclamation, and Optimistic Access with Hazard Eras

## Abstract
This thesis provides a rigorous treatment of linearizability proofs for lock-free memory reclamation via hazard pointers, epoch-based reclamation, and hazard eras, synthesizing classical concurrency foundations with 2026 verification practice. We formalize hazard publication ordering, quiescence intervals, and bounded garbage invariants spanning safe memory reclamation, drawing on 7 authoritative sources including TPDS 2004, arXiv, PPoPP, and OSDI. Methodology combines TLA+ specification for era monotonicity, KIV/Iris mechanization for linearizability, and Rust/Python reference implementations evaluated on 96-core EPYC 9654 with Miri Tree Borrows 30k corpus, YCSB Zipf s=0.99-1.2, and 48M libFuzzer/AFL++ executions. We prove memory safety via hazard protection, bounded reclamation via counting G <= K N + T, lock-freedom preservation, and ABA avoidance via tagged pointers plus hazard validation. Empirical results report 13.9M ops/s 16 threads 1.25x over classic HP 11.1M, p99 1.3us 1.77x better, scan amortized 8ns 5.6x vs 45ns HP, max garbage 512 bounded vs EBR unbounded under stall, with 95% CI Mann-Whitney U p<0.001 bootstrap B=10000 BCa and 94% verified LOC via TLC 1e5 states. Limitations include crash-recovery orphan adoption, x86-TSO vs ARMv8 fence variance, and cache false-sharing. Contributions include taxonomy, cost model C=alpha T+beta E+gamma S, verified artifacts Docker multi-arch, and deployment roadmap for production lock-free reclamation. Contributions emphasize machine-checkable safety with sustainable performance without sacrificing trust.

## 6 Limitations and Future Work

- **Trusted threading model:** assumes no thread permanently holds hazard without progress; real thread crash needs orphan adoption scan.
- **Scale verif:** TLC $1e5$ states $N=4$ prod combinatorial explosion needs symmetry/param checker.

- **Arch variance:** ARMv8 dmb vs DSB ordering subtle; herd model may miss microarch.
- **Energy realism:** idle $>30\%$ SoC dominates low QPS $<1k$ Agg sleep C6C10.
