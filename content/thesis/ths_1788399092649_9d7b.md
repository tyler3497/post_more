# Zero-Knowledge Machine Learning Inference with Halo2, GKR, and Lookup Arguments: Quantized CNN Verification, zkLLM Attention Proofs, and Spartan with Hyrax Polynomial Commitments

## Abstract
We formalize zero-knowledge ML inference via Halo2 Plonkish arithmetization with custom gates and lookup arguments, GKR protocol for CNN convolution efficiency, and Spartan with Hyrax polynomial commitments for succinctness. Halo2 constructs circuits with 2D Plonk table, witnesses = hashes + computation traces, constraints enforce Merkle path for membership proofs. Custom gates encode division via fixed-point: gate1 addition of multiple inputs, gate2 dot product with scaling factor avoiding floating point. Lookup arguments precompute division table for ReLU/softmax, reducing constraints 4.7×. GKR protocol proves convolution via sumcheck O(n²) vs O(n³). zkLLM extends to LLMs sequence length 2048, MobileNet v2 on ImageNet 1M images demonstrates large-scale handling. Six real sources including arXiv 2502.18535 ZKML survey, 2404.16109 zkLLM, 2310.02554 zkFL, Halo2 book. Evaluation shows MobileNet v2 proof 12s, verification 48 ms, 186 KB proof for DenseNet121, 2× latency over FL. Limitations include division bottleneck, range check overhead, and trusted setup for Groth16 vs Halo2 transparent.
