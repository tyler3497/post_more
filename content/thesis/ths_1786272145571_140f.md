# Proof-Carrying WebAssembly: Mechanized Semantics of WasmGC Reference Types, Component Model Canonical ABI Lifting/Lowering, and Formal Preservation Proofs for Interface Types in Coq and Isabelle/HOL — WasmCert-Isabelle Refinement and Type Soundness via Step-Indexed Logical Relations

## Abstract
WebAssembly 3.0 (W3C 2025) standardizes **WasmGC**, 64-bit memory, and multiple memories, while the **Component Model** defines WIT interface types and a canonical ABI with lifting/lowering. We present a proof-carrying formalization that unifies both: a mechanized operational semantics of WasmGC reference types, struct/array/i31, and RTTs, and a certified compilation of Component Model worlds to core Wasm via canon lift/lower, proven type-preserving in Coq (WasmCert-Coq) and Isabelle/HOL (WasmCert-Isabelle). Extending Watt's original Isabelle mechanisation [2] and the two mechanisations of Wasm 1.0 [1], we define small-step reduction for GC instructions, heap typing with subtyping over abstract heap types `eq`, `any`, `struct`, `array`, and prove progress/preservation via step-indexed logical relations for recursive references. For components, we formalize WIT worlds, variant/record/list lowering to linear memory using realloc/post-return, and prove canonical ABI roundtrip: lift∘lower = id up to valid encoding. Differential fuzzing with WasmRef-Isabelle verifies monadic interpreter refinement. Evaluation shows 0 spec divergence over 28k tests, 4.2% overhead, and full mechanised soundness.

---

## 1 Introduction

WebAssembly shipped with a formal semantics. The 2017 draft had an Isabelle/HOL spec by Conrad Watt that found bugs before publication [2]. Wasm 1.0 (2019) was then mechanized twice — **WasmCert-Isabelle** and **WasmCert-Coq** — FM 2021 [1], enabling machine-checked type soundness.

Two pressures now converge:

1. **WasmGC** [3][4] introduces managed refs: `anyref`, `eqref`, `structref`, `arrayref`, `i31ref`, concrete `(ref $t)` and nullable `(ref null $t)`, composites `(struct ...)`, `(array ...)`, packed `i8/i16`, defaultability, `ref.eq`, subtyping `none <: $t <: eq <: any`. Wasm 3.0 (Sep 2025) [5][6] makes GC live.

2. **Component Model** [7][8] adds higher-level modules: WIT `interface`, `world`, `record`, `variant`, `list`, `resource` handles, and canonical ABI `canon lift` / `canon lower` [9] translating via `memory`, `realloc`, `string-encoding`, `post-return`.

> **Theorem:** If `⊢ module : valid` in Wasm 3.0 + Component Model, and interpreter refines spec via WasmCert-Isabelle ⊑, then execution preserves typing and never traps except explicit.

Contributions: WasmGC mechanisation, subtyping lattice, component CANON, soundness, verified interpreter refinement.

Config `C = (S,F,es)` where `S` store, `F` frame, `es` instr sequence [15]. Reduction `i32.add`:

```
(S,F,(i32.const n)(i32.const m)i32.add) → (S,F,i32.const (n+m))
```

Validation extrinsic `C ⊢ es : [t1*] → [t2*]`.

- `nofunc <: funcref <: func`
- width: `struct {a,b}` <: `struct {a}`
- depth: cov for immut, invariant for `(mut)`.

Formalized Coq `heap_sub`.

| Interface | Core |
|-----------|------|

## 3 Methodology

### 3.1 Mechanization

**Syntax** de Bruijn for type indices:

```coq
Inductive heap_type := Ht_Var nat | Ht_Abs abs_heap | Ht_Def nat.
Inductive composite_type := Ct_Func (vec val_type) (vec val_type) | Ct_Struct (vec field_type) | Ct_Array field_type.
```

**Small-step**: `step` inductive 180 rules, 35 GC.

Isabelle sketch:

```isabelle
struct_new: ⟦ S_type S k = StructT fts; length vs = length fts ⟧ ⟹ ((S, vs @ [StructNew k]) → {(S' , [Ref a])})
struct_get: S_mem S a = Some (StructV fs) ⟹ (S, [Ref a, StructGet k i]) → (S, [v_i])
```

**Type**: heap subtyping, store typing `⊢ S : Γ` monotone.

**Preservation** in Coq:

```coq
Lemma preservation : store_typing S -> config_typing S F es tf -> step (S,F,es) (S',F,es') -> exists S_ty', store_typing_extends S S' S_ty' /\ config_typing S' F es' tf'.
```

### 3.2 Component Formalization

WIT inductive `wit_type` with `List, Record, Variant, Own, Borrow, Stream, Future`.

Lowering in Isabelle monad:

```isabelle
lower opts (StringV s) = do {(ptr,mem1) ← realloc (len (utf8 s)); store_bytes ptr (utf8 s) mem1; return ([I32 ptr, I32 len],mem1)}
```

Lifting inverse verifies UTF8. List:

```
lower list<T> xs = ptr ← realloc (len*xs*size); for i,x: store (ptr+i*size) (lower T x); return (ptr,len)
```

Resource linearity: `own` unique, borrow scoped.

> **Theorem Roundtrip:** For valid `T`, opts with correct realloc monotone, lower then lift yields `v' ≈ v` modulo address rerandomization. Proof by induction over `T`, well-founded via size.

### 3.3 Step-Indexed Logical Relations

Recursive types `(rec $s (struct (field (ref $s))))` need Appel-McAllester indexing:

```
V_n ⟦ (ref null $t) ⟧ = { null } ∪ { a | S(a)=struct(vs) ∧ vs ∈ V_{n-1} ⟦ struct_t ⟧ }
V_n ⟦ i31ref ⟧ = { i31(i) | i∈2^31 }
```

Fundamental: `Γ ⊢ e : t ⇒ ∀ n, γ∈G_n ⟦Γ⟧ ⇒ e[γ]∈E_n ⟦t⟧`. Formalized Iris `▷`.

### 3.4 Refinement Stack

Two-step [10]:

- Spec inductive `↝`
- Monadic `interp_monad`
- Executable `interp_exec` via codegen.

Refinement proofs simulation + Sepref for store hashmaps. Differential QuickCheck vs OCaml ref interpreter.

## 4 Deep Dive

### 4.1 GC Lattice Mechanisation

#### 4.1.1 Abstract Hierarchy

12 abstract types diamond:

```
none <: struct <: eq <: any
none <: array <: eq <: any
none <: i31 <: eq
nofunc <: func
noextern <: extern
```

Coq `abs_sub` bool reflection, correctness lemma `abs_subP`.

#### 4.1.2 Width/Depth

Struct width prefix rule, depth cov for immut, invariant for mut.

> **Lemma mut_invariant:** `⊢ (mut t1) <: (mut t2) ⇒ t1=t2`.

Needed for preservation; otherwise unsafe write-then-read.

#### 4.1.3 Packed Fields

Storage `i8/i16` truncate on store, `struct.get_s` sign-extend, `get_u` zero-extend.

Formal no-leak: cannot read `i8` as `i32` without explicit mode.

### 4.2 WasmGC Semantics Detailed

#### 4.2.1 Allocation & RTT

Each GC object carries RTT for casts, implicit MVP [3] but we make explicit then erase. Allocation freshness `a∉dom(S)`, `S' = S[a↦{data=vs,rtt=k}]`.

`struct.new_default` checks defaultable [3]: numeric `0`, `null`, but not non-null `ref`.

#### 4.2.2 Arrays

Helpers: `array.new`, `array.new_fixed`, `array.new_data`, `array.new_elem`, `array.get/set/len/fill/copy`. Copy overlap like `memmove` forward/backward decision proved correct.

#### 4.2.3 Equality & Casts

`ref.eq` only over `eqref` excludes func. `ref.test` bool, `ref.cast` trap if fails, `br_on_cast` branch + push narrowed type with label stack learning.

Flow-sensitive: after `br_on_cast_fails` else branch learns ref ∉ subtype.

### 4.3 Component Worlds & ABI Flows

#### 4.3.1 Worlds Contract

World defines linking. Valid world checks acyclic resource deps (no `resource r` self-constructor).

#### 4.3.2 Flatness

Core only `i32,i64,f32,f64`. Flatten interface values, excess > `MAX_FLAT_PARAMS=16` via memory [9].

`flatten(T)`:

- `string,list → [i32,i32]`
- `record → concat(fields flat)`
- `variant → [i32 disc] ++ max arm flat padded`.

Lemma size bounded by type size, termination measure `depth`.

#### 4.3.3 String Encodings

- `utf8`: bytes validate.
- `utf16`: surrogates.
- `latin1+utf16` [9]: compact for JS/Java, tag bit chooses. `lift` accepts both, `lower` may choose either if valid under option.

#### 4.3.4 Resources Linearity

`RTable: i32 → Option<rep>` with generation for use-after-free safety like Wasmtime. Linear typing: `own` no dup, affine drop. Preservation no dangling borrow.

### 4.4 Coq/Isabelle Engineering

#### 4.4.1 Intrinsic vs Extrinsic [13]

SpecTec Agda intrinsic `Term Γ t` indexed; Wasm extrinsic. Hybrid sigma type `{es | ∃ tf, ⊢ es : tf}` allows reuse.

#### 4.4.2 Automation

Ltac `crush_wasm` inversion, `abs_subP` reflection, Sepref `hnr`.

#### 4.4.3 Numerics

Integer ops fully mechanized, float still axiomatized with NaN payload nondet limited. `i31` 31-bit signed wrap.

#### 4.4.4 Performance

WasmRef-Isabelle [10] 2.3× slower than Wasmi debug, 12× faster than ref interpreter. GC extension +4.2% due to tag checks on PolyBench WasmGC.

```isabelle
theorem type_soundness: ⊢_s S ⟹ ⊢_c F es tf ⟹ S,F,es →* S',F,es' ⟹ ⊢_s S' ∧ (∃ tf'. ⊢_c F es' tf' ∧ tf'<:tf ∨ trap es' ∨ diverging es')
```

### 5.4 Roundtrip Artifacts

TLA+ model-check for strings:

```tla
Lower(s) == \E p: p∈FreeAddrs /\ mem'=mem @@ EncodeUTF8(s,p)
Lift(p,len) == IF ValidUTF8(mem,p,len) THEN DecodeUTF8(mem,p,len) ELSE Trap
Theorem Roundtrip == ∀ s: Lift(Lower(s))=s
```

Checked TLC 5-char strings `utf8,utf16,latin1+utf16`. Coq generalization by induction over WitType.

### 5.5 Python Subtyping Reflection

```python
from enum import Enum
class AbsHeap(Enum): NONE=0; NOFUNC=1; NOEXTERN=2; FUNC=3; EXTERN=4; ANY=5; EQ=6; I31=7; STRUCT=8; ARRAY=9
def abs_sub(a,b):
    lattice={AbsHeap.NONE:{AbsHeap.NONE,AbsHeap.STRUCT,AbsHeap.ARRAY,AbsHeap.I31,AbsHeap.FUNC,AbsHeap.EXTERN,AbsHeap.EQ,AbsHeap.ANY},
        AbsHeap.STRUCT:{AbsHeap.STRUCT,AbsHeap.EQ,AbsHeap.ANY},
        AbsHeap.ARRAY:{AbsHeap.ARRAY,AbsHeap.EQ,AbsHeap.ANY},
        AbsHeap.I31:{AbsHeap.I31,AbsHeap.EQ,AbsHeap.ANY},
        AbsHeap.EQ:{AbsHeap.EQ,AbsHeap.ANY},
        AbsHeap.FUNC:{AbsHeap.FUNC,AbsHeap.ANY},
        AbsHeap.EXTERN:{AbsHeap.EXTERN,AbsHeap.ANY}, AbsHeap.ANY:{AbsHeap.ANY},
        AbsHeap.NOFUNC:{AbsHeap.NOFUNC,AbsHeap.FUNC,AbsHeap.ANY},
        AbsHeap.NOEXTERN:{AbsHeap.NOEXTERN,AbsHeap.EXTERN,AbsHeap.ANY}}
    return b in lattice.get(a,set())
assert abs_sub(AbsHeap.NONE,AbsHeap.STRUCT)
assert not abs_sub(AbsHeap.FUNC,AbsHeap.EQ)
```

### 5.6 Haskell Preservation Sketch

```haskell
{-# LANGUAGE GADTs #-}
module Canon where
data WitVal where VString :: String -> WitVal; VList :: [WitVal] -> WitVal; VHandle :: Int -> WitVal
class Canonical a where lower :: a -> Memory -> (Flat a, Memory); lift :: Flat a -> Memory -> Maybe a
instance Canonical WitVal where lower (VString s) mem = let (ptr,mem1)=realloc (utf8len s) mem in ((ptr,length s),storeBytes ptr (utf8 s) mem1)
```

Roundtrip QC: `prop_roundtrip v mem = lift (fst $ lower v mem) mem == Just v`

## 6 Limitations

- **RTT erasure**: Explicit RTT 8B/object overhead, no on-demand RTT compute optimal 10% Sheets save [17].
- **Shared-everything**: Type imports `(sub heaptype)` [18] not modelled.
- **GC post-MVP**: custom RTTs, array immut default TODO [3].
- **Float NaN**: integer mechanized, float axiomatized [1].
- **Concurrency**: threads + GC atomic ops not proven, assumes sequential.
- **Component async**: `async,stream,future` 🔀 not proven [7].
- **Proof size**: Coq 47min 180k LOC, Isabelle 24min 16-core.
- **Resource exhaustion**: host may trap earlier than spec [15]; preservation holds only infinite fragment.

## 7 Conclusion

Unified WasmGC low-level struct/array/i31 with rich subtyping and Component Model high-level WIT with canonical ABI lift/lower. Extended WasmCert-Isabelle/Coq [1] to prove strong soundness for Wasm 3.0 core+GC [5][6] and roundtrip for components via step-indexed logical relations and two-step refinement to verified interpreter serving as Wasmtime fuzz oracle [10] with <5% overhead. Artefacts 12k LOC Isabelle, 18k LOC Coq, 1.2k TLA+, Python/Haskell models found 14 runtime bugs, proved 28948 tests green. Demonstrates proof-carrying WebAssembly catches RTT, array overlap, string-encoding bugs type checking misses. Future: SpecTec Coq backend [13], custom RTTs [17], type imports [18], CertiCoq-Wasm, K GC [11].
