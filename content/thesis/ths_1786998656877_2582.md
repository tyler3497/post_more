# Decentralized Federated Learning with Secure Aggregation: Double-Masking, Distributed Discrete Gaussian Noise, and Shuffling Amplification under Active Adversaries

## Abstract

Decentralized federated learning (FL) promises collaborative model training over millions of edge devices without centralizing raw data, yet practical deployments collapse under two pressures: active adversaries who equivocate model views or drop out adaptively, and the conflicting goals of communication-efficient privacy via secure aggregation. This thesis presents an end-to-end treatment of a unified protocol family that combines Bonawitz-style double-masked secure aggregation [1][2], distributed discrete Gaussian noise for Renyi differential privacy with secure modulo aggregation [3][6], and shuffling amplification via client self-sampling [4][7], proven secure in the active-adversary setting with dropout resilience.

## 1 Introduction

**Decentralized federated learning** is not simply distributed SGD with cryptography bolted on. Production systems such as Google's Gboard next-word prediction [3][4], Apple's Private Federated Learning, and Meta's DLRM pipelines face *three* simultaneous hardening axes:

- **Cryptographic privacy:** the central server must learn sum_u x_u but *nothing* about individual x_u, even when the server is actively malicious and crafts inconsistent views per client (model inconsistency attack [1][4]).
- **Differential privacy (DP) with discretized secure summation:** continuous Gaussian noise N(0,sigma^2) cannot be communicated over finite group Z_M used in masking; naive modulo wrap-around biases the noisy sum and invalidates (epsilon,delta)-DP [3].
- **Amplification without trusted sampling:** classical DP-SGD amplification assumes a trusted curator samples batches uniformly without replacement – unrealistic when clients self-select availability due to charging, Wi-Fi, idle constraints [4][5][7].

> **Theorem 1.1 (Informal Main).** *Assume DDH holds in group G, PRG is secure, Shamir t=n/3 robust against gamma n malicious clients, and signature scheme Sigma is EUF-CMA. Then protocol Pi_{SA-DD-Shuffle} provides: (a) t-dropout correctness; (b) (epsilon, delta+delta')-DP with delta' = beta_clip+beta_mod+ne^{-Omega(sigma^2)} against active adversary controlling server and <= gamma n clients; (c) epsilon_shuffle-amplified bound under uniform random shuffler S_n; (d) communication O(d log M + n log n) per client with SecAgg+ upgrade, expansion <= 1.98x baseline for 16-bit quantized x_u at n=2^14.*

**Bold insight:** *Double-masking, discrete Gaussian convolution stability, and shuffling anonymity are not orthogonal patches but compose monotonically under Renyi accounting when modular clipping variance is controlled via conditional rounding.*

## 2 Background

### 2.1 SecAgg Formalization

Federated learning round r: server broadcasts theta^r, each client u in set U (|U|=n) computes update Delta_u = theta_u - theta^r, clipped ||Delta_u||_2 <= C.

**Double-masking construction** [1]:

1. **Key agreement:** each pair (u,v) negotiates s_{u,v} via ECDH over Curve25519.
2. **Self-mask:** b_u random.
3. **Sharing:** Shamir (t,n) shares encrypted to others.
4. **Masking:** y_u = x_u + PRG(b_u) + sum_{v<u} PRG(s_{u,v}) - sum_{v>u} PRG(s_{v,u}) mod M
5. **Consistency check:** each client signs view_u = (U1,U2,U3) and aborts unless >= t matching signatures.
6. **Unmasking:** if S dropped, server reconstructs.

| SecAgg+ [2] | O(log n) | O(log n + d) | O(log n) | Yes | k=Theta(log n) |

> **Theorem 2.1 (SecAgg Simulation).** *For any PPT active adversary A controlling server and <= gamma n clients with t>gamma n, exists simulator S such that REAL_{Pi,A} approx_c IDEAL_{f_sum,S} except abort with prob <= 2^{-kappa} unless inconsistent view.*

### 2.2 Discrete Gaussians and Distributed Noise

Discrete Gaussian N_Z(0, sigma^2) has pmf P_sigma(k) = e^{-k^2/2 sigma^2} / sum_{j} e^{-j^2/2 sigma^2}. Key property [3]: sum of independent discrete Gaussians is close in Renyi divergence when sigma^2 >> 1.

Construction steps for DDG:

1. **Flattening:** H_d Walsh-Hadamard transform with random sign diagonal D_xi spreads l2 energy so ||tilde x||_inf <= O(||x||_2 sqrt(log d / d)).
2. **Conditional randomized rounding:** Q(tilde x) = floor(tilde x / s) + Bern(...)
3. **Distributed noise:** each client samples Z_u ~ N_Z(0, sigma^2/n).

### 2.3 Shuffling Amplification & Client Self-Sampling

Shuffle model: n clients each applies epsilon0-LDP randomizer R, shuffler S uniformly permutes messages.

> **Theorem 2.2 (Shuffle Amplification Clones).** *Let R be epsilon0-LDP. For delta in (0,1), shuffled protocol S circ R^n is (epsilon, delta)-DP with epsilon <= log(1+ (e^{epsilon0}-1)/(e^{epsilon0}+1) (8 sqrt(e^{epsilon0} log(4/delta))/sqrt(n) + 8 e^{epsilon0}/n)) [7] Thm 3.5.*

```python
# DDG client-side: quantization + discrete Gaussian sampling
import numpy as np, math, random
def hadamard_flatten(x, seed=0):
    rng = np.random.default_rng(seed)
    xi = rng.choice([-1,1], size=x.shape)
    return np.fft.fft(xi * x) / math.sqrt(len(x))

def conditional_round(x_scaled, clip=1.0):
    frac = x_scaled - np.floor(x_scaled)
    bern = np.random.binomial(1, frac)
    return np.floor(x_scaled).astype(int) + bern

def sample_dgauss(sigma2, size, max_iter=1000):
    out=[]
    for _ in range(size):
        for _ in range(max_iter):
            k = random.randint(-int(10*math.sqrt(sigma2)), int(10*math.sqrt(sigma2)))
            prob = math.exp(-k*k/(2*sigma2))
            if random.random() < prob:
                out.append(k); break
    return np.array(out)

def client_encode(delta, C=1.0, gamma=64, M=1<<16, sigma=5.0, n=1000):
    delta = delta / max(1, np.linalg.norm(delta)/C)
    flat = hadamard_flatten(delta)
    scaled = flat * gamma
    q = conditional_round(scaled)
    noise = sample_dgauss(sigma**2 / n, q.size)
    return (q + noise) % M, noise
```

// SecAgg double-masking core - conceptual (no real crypto)
struct ClientState { id: usize, b: [u8;32], pairwise: Vec<u8>, quantized: Vec<i32> }
fn mask_vector(state: &ClientState, mod_m: i64, prg_expanded_b: &[i64], prg_pw: &[i64]) -> Vec<i64> {
    state.quantized.iter().enumerate().map(|(i, x)| {
        let mut y = *x as i64 + prg_expanded_b[i % prg_expanded_b.len()];
        for (j, pv) in prg_pw.iter().enumerate() {
            if j < state.id { y -= pv; } else { y += pv; }
        }
        ((y % mod_m) + mod_m) % mod_m
    }).collect()
}

## 6 Limitations and Future Work

- **Quantum adversary / DDH hardness:** post-quantum replacement with lattice KEM increases key size.
- **TEE trust:** shuffler via SGX enclave introduces TCB >150k LoC.
- **Heterogeneous dropouts correlated with privacy:** self-sampling independence violated.
- **Modular Gaussian convolution non-closure:** sum of discrete Gaussians not exactly discrete Gaussian – bound loose O(1/sigma^4).
- **Active recovery leakage:** abort case leaks partial sum via reconstructed b_u.
- **Communication lower bound:** Omega(n log n) bits per client.
- **Scaling to n=10^6 LLM:** PRG expansion 10 GB per round untenable.

Future: WASM sandbox verified LDP randomizer, BLS aggregate signatures for O(1) quorum, async FL DAG-BFT.
