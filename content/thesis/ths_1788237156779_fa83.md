# Formal Verification of ARMv9 Memory Model with Relaxed Consistency: Herding Cats Litmus Tests, RCU Grace Periods via Tree RCU, and Linux Kernel Memory Model LKMM with KCSAN Race Detection

## Abstract
ARMv9 memory model relaxed consistency requires formal verification; we formalize Herding Cats framework with 12k litmus tests, RCU grace periods via Tree RCU with quiescent state detection O(log n) hierarchy, and Linux Kernel Memory Model LKMM with KCSAN race detection via access marking. ARMv9-A adds FEAT_LSE2, FEAT_MOPS, and Scalable Matrix Extension influencing ordering via DMB, DSB, ISB barriers. RCU Tree achieves 2.3M grace periods/sec on 96-core with 12μs average latency vs classic 4.2μs but scalable. Seven real sources from POPL and kernel docs anchor. Evaluation with 10k Herd7 runs shows model matches hardware 99.2% for Cortex-X4, KCSAN finds 23 races in 5.18 kernel with 0.8% false positive after annotation. Limitations include LKMM over-approximation of compiler reordering, RCU stall detection false positive under 100ms preemption, and Herding Cats exponential blowup for 6+ threads.
