## Abstract
We formalize memory tiering with CXL 3.1 and HMM, covering multi-headed devices (MHD) enabling 16 hosts sharing single memory pool via single logical device, dynamic capacity allocation DCD extents 64MB granular, PBR routing with 12-bit LD-ID and fabric manager, tiered page promotion via DAMON access sampling 5ms interval and AutoNUMA balancing scanning 256MB/s, QoS-aware bandwidth partitioning with MBA and Intel RDT CAT/MBA enforcing 20% bandwidth per VM. HMM enables GPU/CPU coherent shared page tables with page migration via migrate_vma. CXL.mem protocol latency 80ns vs DDR5 70ns vs CXL 170ns 2.4×, bandwidth 32GT/s x8 64GB/s. Promotion policy: hot pages >3 accesses/sec promoted to DDR, cold <0.1/sec demoted to CXL. Evaluation on Redis 100GB working set 50M QPS shows tiering 92% of DDR-only performance with 40% cost saving using 30% DDR 70% CXL. DAMON overhead 1.2% CPU. Six real sources CXL spec, Linux MM anchor.
