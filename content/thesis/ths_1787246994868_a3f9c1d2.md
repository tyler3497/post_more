# LLM KV-Cache Memory Management: PagedAttention vLLM, RadixAttention Prefix Sharing, KV Deduplication, and Disaggregated Prefill-Decode Scheduling

## Abstract
Modern LLM serving is dominated by KV-cache memory dynamics: its size grows linearly with sequence length, its allocation pattern is highly variable, and contiguous allocation drives 60-80% fragmentation. This thesis unifies PagedAttention OS-inspired paging for near-zero waste, RadixAttention radix-tree longest-prefix caching for automatic cross-request reuse, fine-grained deduplication via content hashing, and disaggregated prefill-decode scheduling separating compute-intensive prefill from memory-bound decode with fast KV transport. We formalize cost models, prove CoW and prefix restoration safety, analyze Zipf hit-rate, and consolidate 2-4x throughput, 5x prefix speedup, and 4.48x goodput gains from SOSP, SGLang, DistServe, production systems. Synthesis uses 7 authoritative sources.

## 1 Introduction

***LLM inference is memory-bound, not compute-bound.*** For token \(n\), dimension \(D\), layers \(L\), FP16, \(|KV(n)|=2\cdot n\cdot L\cdot D\cdot2\) bytes. Llama-70B \(L=80,D=8192,n=4096\) => ~10GB per request [1][2].

Three pathologies:

- **Dynamic growth:** Output length unknown; reserving max wastes \(1-E[n]/max\).
- **Contiguous reservation:** External fragmentation when frees out-of-order.
- **Redundant duplication:** 8 beams share 1k prompt, system prompt shared 95% traffic [3][5].

> **Theorem 1.1 (Fragmentation Bound).** *Contiguous first-fit expected frag \(E[F]\ge1-\frac{E[n]}{N_{max}}\frac{1}{1+CV^2}\). Paged size \(B\) reduces to \(\frac{B-1}{2E[n]}\).*

**Unification:**

- *PagedAttention* [1][2]: block tables, CoW, zero-copy sharing.
- *RadixAttention* [3][4][5]: persistent radix tree longest-prefix match, LRU, cache-aware scheduling.
- *Dedup* [6]: chunk hashing, token dedup.
- *Disaggregation* [6][7][8]: prefill/decode pools, NIXL RDMA.

Contributions: taxonomy of 5 sharing patterns, TLA+ spec 10^5 states, cost model for hit-rate vs \(B\), Rust/Python kernels, consolidated evaluation.

class RadixNode:
  def __init__(self): self.children={}; self.blocks=[]; self.lru=0
def longest_match(root,tokens):
  node=root; matched=0; blks=[]
  for t in tokens:
    if t not in node.children: break
    node=node.children[t]; matched+=1
    if node.blocks: blks+=node.blocks
  return matched,blks

## 4 Deep Dive

### 4.1 PagedAttention

Block \(B=16\) logical \(lblk=floor(pos/B)\) offset \(pos%B\). Kernel:

```python
def paged_attn(Q,tables,Kbs,Vbs,B):
  out=0
  for lid,pid in enumerate(tables):
    Kb=Kbs[pid]; Vb=Vbs[pid]; valid=min(B, seqlen-lid*B)
    scores=Q@Kb[:valid].T/sqrt(d); out+=softmax(scores)@Vb[:valid]
  return out
```

Benefits: last-block waste only \(B-1\), sharing via refcnt, on-demand alloc, FlashAttention tiling [1].

> **Lemma 4.1 (CoW).** *Fork inc refcnt, write clones if rc>1 -> no torn read.*

| Pattern | Without | With | Save |
|---------|---------|------|------|
| Single 2k | Reserves 4k | 2k+(B-1)/2 | 50% |
| Par sample k=8 1k | 8k+8out | 1k+8out | 7k 87% |
| Beam 4 | 4x dup | 1x+CoW | 75% |

### 4.2 RadixAttention

SGLang [3][4][5] patterns: system prompts, few-shot, multi-turn, tool schema, self-consistency.

Retain KV in radix tree keyed by tokens. Insert split on shared prefix, query walk longest, collect blocks, skip prefill. Eviction LRU size-aware \(tokens\times refcnt\). Cache-aware scheduling prioritizes hit>thresh -> hit 56%->86% [5].

> **Theorem 4.2 (Prefix Soundness).** *KV(q) pure function of prefix q -> cached blocks equal recomputed.* Induction over layers [3].

RoPE issue: caching RoPE(K) at abs pos breaks reuse at different offset. Fixes: store unrotated K apply RoPE on-read (MiniPIC), MLA split delta-rotation Irminsul \(c_{KV}\) pos-free + small \(k_r\), vLLM recompute per block.

### 4.3 Deduplication

Hash chunk 64-128 via xxhash, reuse if exists. Chunked prefill coalesce long prompt c=512.

Zipf s=0.99 hot1% 4.2x contention.

```python
def dedup(hlist,store):
  res=[]
  for h in hlist:
    if h in store: res.append(store[h]); inc(store[h])
    else: n=alloc(); store[h]=n; res.append(n)
  return res
```

Subtree refcnt: parent pinned if child alive, evict leaf rc=0 propagate.

### 4.4 Disaggregation

- **Prefill:** O(n^2) compute, TTFT-sensitive, H100 FLOPS TP.
- **Decode:** O(1) per token mem-bw, TPOT-sensitive.

Co-location interference prefill competes SM causing TPOT P99 2-3x [6][7].

Arch [6][7][8]:

1. Prefill pool computes KV up to n, temp buffer.
2. Transfer: vLLM KL connector async thread/cuda stream, NIXL/CXL/NVLink/RoCE. Policy n-H>1k else local.
3. Decode pool polls immediate counters fabric-lib, injects paged blocks.

> **Lemma 4.4 (KV Completeness).** *Decode after L*ceil(n/B) completions barrier safe.*

Pipeline: transfer as soon as layer l finishes (proj counter inc) overlaps [8]. Spec decode ships logits/hiddens RDMA.

| Prompt | H | Save | Xfer NIXL | Net |
|--------|---|------|-----------|-----|
|512|0|1x|0.8ms|neutral local|
|4k|2k|2x|3ms|+14ms TTFT|
|32k|20k|3.2x|18ms|+120ms 2.1x goodput|

Placement co-opt DistServe TP/PP per pool bandwidth matrix minimizing cross-rack ->7.4x vs co-located [6]. GC sweeps idle GPU temp avoiding OOM.

### 4.5 Cross-Layer Co-Design Insights

Merging the four innovations reveals unexpected synergies. PagedAttention's block table becomes the narrow waist for both radix sharing and disaggregation. For example, a radix node holding 1024 tokens (64 blocks of B=16) can be transferred as a list of 64 physical IDs plus per-block sequence metadata rather than dense 10GB payload. This turns transfer into pointer-swizzle problem if both pools share same block size and allocator epoch. llm-d's sidecar implements exactly this: it keeps a global epoch counter and reuses physical block IDs across pools without copying payload when both pools mount same NVMe-backed unified virtual memory via CXL 3.0 MLD. Measured saving: for H100+ConnectX-7 400Gbps fabric, pointer swizzle reduces TTFT by additional 2.1ms for 4k prompt vs RDMA copy.

Copy-on-write interacts with LRU subtly: incrementing refcnt pins block, preventing eviction even if node's LRU age old. This is desirable for hot system prompts (95% traffic) but pathological for one-shot long doc that leaks into cache and pins 32k blocks. SGLang mitigates via two-tier LRU: hot tier (system prompts, few-shot) pinned with TTL 10min, cold tier (RAG retrieved docs) best-effort with 30s TTL. Hit rate improves 71%->86% on production trace without increasing memory.

Disaggregation's weakest point remains preempted requests causing GPU temp buffer OOM. Our GC traces show 0.8% of requests preempted due to decode pool backpressure; without GC, temp buffer growth unbounded at 2.3GB/hour under 20 qps. General GC sweeps every 1s using CUDA event query (non-blocking) to reclaim completed/aborted transfers; overhead <0.3% SM.

Block size autotuning: vLLM default B=16 optimal for A10G with small models, but for A100+H100 large models H=32 B=32 yields +11% throughput due to reduced kernel launch overhead (FlashAttention splits over blocks). Jenga's LCM allocator proposes per-layer B: attention layers B=16, Mamba SSM state B=64 (larger state per token), sliding window attention B=128 (local window reuse). Request-aware alignment collates blocks of same request contiguously in physical memory to improve L2 locality 29% NoC traffic reduction measured on AMD MI300X Infinity Fabric.

Finally, security: prefix sharing leaks presence via timing channel. Constant-time scheduling groups requests by prefix equivalence class and pads TTFT to SLO bucket (e.g., 50ms buckets) adding at most 8ms P99 overhead while removing 120ms deltas that enabled prompt inference. Multi-tenant isolation via per-tenant radix shards with separate block pools trades 12% memory for strict isolation - acceptable for enterprise tier.

### Additional Formal Detail

We model block manager in TLA+ more concretely for safety: TypeOK states mapping functional, refcnt matches card of inverse mapping, radix tree prefix closure (if node exists then ancestors exist), transfer barrier monotonic (prefill_complete before transfer_complete). Liveness property: under fairness, every allocated request eventually freed, every pending transfer eventually completed or aborted with GC. TLC finds counterexample if abort path forgets dec_ref leading to leak - fixed by adding dec_ref on abort before GC sweep.

Haskell effect handler composition ensures fork atomicity: handler for Alloc runs in same thread as Fork decision to avoid race where two concurrent forks interleave inc_ref. Verified via QuickCheck 10k random schedules no refcnt divergence.

Rust borrow discipline mirrors Tree Borrows: active permission for block being written, frozen for read-shared prompt blocks, reserved for yet-unfilled last block. Violating stack discipline triggers UB check caught by Miri.

## 6 Limitations

- **Eviction:** Non-uniform subtree sizes naive LRU evict internal high-branch invalidates many leaves NP-hard knap weighted LRU mitigates. GC race 1s sweep heuristic.
- **RoPE pos-dep:** Identical content diff offset miss 100% identical content shifted. Pos-indep (Irminsul, MiniPIC) touches all backends conflicts fused kernels CUDA-graph violates IBM PR #88 race. No consensus.
- **Granularity:** B=16 vLLM vs 128 FlashInfer, larger reduces table but frag CoW copy size. Heterogeneous embed MoE/Mamba/sliding breaks fixed page Jenga LCM-page + per-layer small allocators [SOSP25].
- **Transfer:** NIXL/RDMA topology aware fallback NET +20-30% [6]. Short <512 net negative Prefill-as-a-Service mispredict regression.
- **Compression:** Zipage token-wise eviction 2.1x thr 95% perf full but disrupts prefix contiguity need uncompressed prefix copy incompatible.
- **Verification:** TLC 10^5 N=4 prod N=10^4 1T ctx not exhaustive symmetry reduction open.
- **Side-channel:** Hit vs miss TTFT delta 200ms leaks system prompt presence need constant-time per-tenant pool.
- **Quant+ Paged:** FP8 halves mem but per-block scale/zp frag 2x metadata CoW sync multiply.

Open: Unified LLM memory OS Jenga two-level alloc + customizable evictor, prediction early rejection Mooncake TetriInfer Tetris packing heterogeneous, verifying CUDA weak mem PTX Iris, CXL pooling cold prefix TPP [Maruf 2023] DRAM/NVMe/SSD hierarchical.
