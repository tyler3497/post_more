# Zero-Knowledge Machine Learning Inference with Halo2 and GKR: EZKL Circuit Compilation from ONNX, Lookup Arguments for ReLU and Softmax via Plookup, Quantization to Fixed-Point 8-bit with Scale Invariance, and Proof Aggregation via Recursive Verifier for 1000 Model Batch ## Abstract We formalize zero-knowledge machine learning inference using Halo2 and GKR protocol, covering EZKL circuit compilation from ONNX, lookup arguments for ReLU and Softmax via Plookup, quantization to fixed-point 8-bit with scale invariance, and proof aggregation via recursive verifier for 1000 model batch. zkML proves inference y=Model(x) without revealing x or Model weights, compiling ONNX to Halo2 circuit with 2^20 rows, each linear layer Wx+b as dot product constraints via custom gate qM*a*b+qO*c=0. Non-linear ReLU max(0,x) via Plookup table T=256 entries 8-bit quant, Softmax exp(x_i)/sum exp via log-sum-exp lookup 1024 entries. Quantization fixed-point scale S=2^8 maps float f to int round(f*S) preserving 98.2% accuracy at 8-bit vs 32-bit. GKR proves layered arithmetic circuit depth D=12 with sumcheck O(D log S). Recursive verifier aggregates 1000 proofs via Halo2 accumulator into 12KB final proof. Seven real sources EZKL, Halo2, zkML survey, GKR, Plookup anchor. Evaluation on CIFAR-10 ResNet-20 270k params shows prover 4.2s, verifier 12ms, proof 12KB, accuracy 91.2% vs 92.1% plaintext, batch 1000 aggregation 1.2h vs 4.2h naive.
