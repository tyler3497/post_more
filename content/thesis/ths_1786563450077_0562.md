## 6 Limitations

1. **Assumption of honest majority / benevolent scheduler:** Byzantine tolerance n>=3f+1 assumed [1]; rational adversaries deviating from protocol may degrade liveness though not safety.
2. **Scope of formal model:** TLA+ checked up to N=4, real deployment N=4096 requires parameterized proof via induction [3]; not yet machine-checked.
3. **Constant-time side channels:** while constant-time quaternion algorithms mitigate timing leakage [3], power / EM telemetry via sideband health monitoring [6] not modeled.
4. **Approximate nature of learned models:** CDF approximation epsilon-bound holds on trained distribution; distribution shift (concept drift) invalidates bound, requiring periodic retraining O(n log n) background job [2][4].
5. **Hardware variance:** Loihi 2 graded spikes reduce communication volume [1] but require custom compiler toolchain Lava; portability to GPU limited.
6. **Quantum overhead:** surface code distance d=27 for 1e-12 logical error [1][5] demands d^2=729 physical per logical, plus magic state factories 15x blowup; SPARO optimization [5] reduces but not eliminates gap with qLDPC.
7. **Numeric stability:** CKKS approximate homomorphism introduces 2^-40 precision loss per multiplication; workloads requiring bit-exact equality need TFHE programmable bootstrap switching [3][4].

These limitations define roadmap: integration of qLDPC + lattice surgery [5][7], runtime recalibration for width asymmetry [4], and deterministic sideband QoS [6].
