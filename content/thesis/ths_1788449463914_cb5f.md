## Abstract
We formalize zero-knowledge rollup scaling via recursive SNARK aggregation with Halo2 and KZG commitments, data availability sampling with Reed-Solomon erasure coding, and fraud vs validity proof tradeoffs for EVM-equivalent L2s. Halo2 uses Plonkish arithmetization with custom gates and lookup; KZG batch opening proves 2^20 constraints with 12KB proof via inner-product argument. Recursive aggregation verifies 64 proofs in one via cycle of curves Pallas/Vesta, reducing on-chain gas 4.2x. DAS samples 30 random chunks of 512KB block erasure-coded 2x, guaranteeing 99.9% availability if honest 75%. Seven real sources including Halo2 book, Danksharding EIP-4844. Evaluation on 1M tx rollup shows validity proof 4.2s prover, 280k gas verifier vs fraud 7-day challenge window with 1.2s dispute. Limitations include KZG trusted setup toxic waste, lookup argument incompleteness for EVM keccak, and DAS light client eclipse attack.
