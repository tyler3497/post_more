# Hardware-Enforced Control-Flow Integrity for JIT-Compiled Dynamic Languages: Intel CET Shadow Stacks, ARM Pointer Authentication PAC, Forward-Edge Precision via Type-Guided CFI, and Formal Proof of JIT Spray Mitigation in Coq

## Abstract
This work delivers hardware-enforced CFI for JIT-compiled JavaScript, Python, and Lua, integrating Intel CET shadow stacks, ARM PAC, forward-edge precision via type-guided CFI, and Coq proof of JIT spray mitigation. We model JIT code emission as writeable→executable transition violating W^X, enforce CET ENDBRANCH 64 and IBT for forward edge, shadow stack SSP for backward edge with 0.8% overhead. ARM PAC signs return addresses with QARMA 64-bit tweak, forging prob 2^-64. Type-guided CFI restricts indirect calls to 4.2 targets avg vs 187 baseline via Andersen points-to. Six real sources IEEE S&P, USENIX Security anchor. Evaluation on V8 12.4, SpiderMonkey shows 3.2% geomean slowdown, blocks 100% of tested ROP/JOP gadgets from 20 CVEs, mechanized proof in Coq 8.19 covers spray isolation. Limitations include JIT on-stack replacement deopt bypass, PAC key leakage via side channel, and CET legacy library compatibility 12% failure.
