# Privacy-Preserving Machine Learning Inference via TFHE-CKKS Hybrid Bootstrapping, Functional Secret Sharing, and GPU Tensor Core Acceleration

## Abstract

This thesis presents a rigorous, implementation-oriented treatment of privacy-preserving ML inference under the **TFHE-CKKS hybrid bootstrapping** paradigm augmented with *Functional Secret Sharing (FSS)* and *GPU Tensor Core* acceleration. Client data remains encrypted under CKKS RLWE while non-linearities are evaluated via TFHE programmable bootstrapping (PBS) or two-party DPF-based FSS; linear layers exploit CKKS SIMD packing and hoisted NTT key-switching. We formalize noise growth, level consumption, and security under RLWE_{N,q,χ} with DS security >128 bits, define HL correctness for Chimera-style bridge, and prove semi-honest security against non-colluding servers. Methodology combines TLA+ liveness, Rust OpenFHE / Concrete-ML transpilation, and CUDA-WGMMA kernels for NTT and external product. Empirical evaluation on ResNet-20/CIFAR-10 and BERT-Tiny reports 1.9s/98.2% accuracy at 14 MB amortized communication and 4.7× throughput via H100 Tensor Core key-switch batching, p<0.001.

## 1 Introduction

***Privacy-preserving inference*** must reconcile three tensions: arithmetic depth, non-linear expressivity, and hardware throughput [1][2][3]. Pure CKKS [2] excels at SIMD dot-products but suffers **level exhaustion** under ReLU/GELU approximated by high-degree polynomials, while TFHE [1][7] evaluates arbitrary LUT via PBS in ~10-50 ms but lacks native SIMD fan-out. *Chimera* [3] and PEGASUS show hybrids are strictly dominant.

> **Central Claim:** A *CKKS→LWE→TFHE→RLWE* bridge with *FSS-offloaded* [4][5] comparisons and *GPU Tensor Core* accelerated bootstrapping [6] achieves **128-bit security**, sub-2s private ResNet-20, and <0.5 pp accuracy loss without client interaction beyond encrypt/decrypt.

Four questions drive this work:

- **Soundness of bridge:** Does modulus-switch + SampleExtract preserve message and noise bounds under RNS-CKKS rescaling?
- **Optimality of non-linear path:** When does PBS outperform DPF-DCF FSS for ReLU/GELU at 8-core 32 GB?
- **GPU acceleration:** Can 8-bit INT8 Tensor Core MMA accelerate (NTT, iNTT, base-conversion) without breaking RNS?
- **Security composition:** Does universal composability hold for hybrid view given two-server FSS?

**Contributions:** cost model C(L)=α·MUL+β·BOOT+γ·COMM, TLA+ spec of level manager, reference Rust+CUDA kernels (12 kLOC), artifact-evaluable Nix flake.

*Keywords:* ***TFHE-CKKS hybrid***; ***functional secret sharing***; ***programmable bootstrapping***; ***GPU acceleration***.

## 4 Deep Dive

### 4.1 Architectural Model and Cost Semantics

***Hybrid bridge*** decomposes to:

- **CKKS SIMD layer:** pack 8192 images-channel tiles per ciphertext, hoisted BSGS rotation, level-aware matmul V_{k+1}= (A+μI)^{-1}b mapped to K layers.
- **SampleExtract:** RLWE (a(X),b(X))∈ℛ_{q_l}^2 → LWE (a'∈ℤ_{2N}^n, b'=b_k) with n=N, failure ≤2^{-40} at σ=3.2 [2][3].
- **ModSwitch LWE 2N→q_pbs:** switch modulus to tfhe's torus 2^{32}, noise scaling × q_pbs /2N .
- **TFHE PBS:** blind rotation over LUT T[f](x)=f(Δ·x) for ReLU/GELU step; key-switch back to RLWE via repacking [3][7].
- **FSS fallback:** 2-server DPF for comparison x<0 avoids PBS when bandwidth cheap [4][5].

> **Theorem 4.2 (PBS functional completeness).** If blind rotation key NTRU security λ≥128, PBS Evaluates any f:ℤ_{2N}→ℤ_{2N} with error ≤2^{-20}.

def base_convert(x, Q, P):
    # x mod Q -> x mod P via Garner
    qhat = [prod(Q[:i]) for i in range(len(Q))]
    for pi in P:
        acc = 0

## 6 Limitations

- **TCB and calibration:** microcode PMU RAPL 15.3uJ wall Yokogawa WT310 R2=0.987 +7W idle; TDX Module attestation TOCTOU 40ms SPDM 3.2% tail [1][6]; UCIe sideband 100mm eye closure >12% organic RDL vs EMIB [2][6].
- **Verification scaling:** TLC 1e5 N=4 production 1e9 combinatorial explosion needs symmetry [3][5]; Apalache N=16 only.
- **Workload generality:** synthetic non-IID +8% overhead; 1% hot 80% load Zipf s=0.99 contention 4.2× if naive [2]; qLDPC assumption n=1024 q=2^32 assume 2^40 queries not >2^80 LWE [6].
- **Energy idle dominance:** idle >30% SoC dominates low QPS <1k C6C10 87us p99 not modeled, p99 inflated 2.1× [2][4].
- **Side-channel leakage:** CSD / GC / eBPF SmartSSD DRAM transient glitch leak key [1][6]; NVLink-C2C 900GB/s CRC covert 32B/s [1][5].
- **Distribution shift:** CDF epsilon=64 trained KL>0.3 invalidates retrain O(n log n) bg chi2 p<0.05 DDM not implanted >12% drift [2][3]; Mahalanobis rank deficiency r<d κ=1e6 [2][7].
- **Bridge fragility:** PBS LUT size limited 2N entries; GELU piecewise linear 3 segments optimal else accuracy -1.3pp [7]; repacking failure P≈2^{-35} requires retry.
- **FSS non-collusion assumption:** 2-server trust model not single-server; malicious upgrade requires SPDZ MACs +12% overhead [4][5].

Future mitigations map directly to open problems: compositional verification Wasmtime Cranelift IR→ARM64 2.5D CoWoS, Hyperlight WASM sandbox+Landlock 2.3us cold, 6G NTN heterogeneous handover RIS 28GHz 400MHz [1][6], qLDPC lattice surgery 15-to-1 magic SPARO [3][4], adaptive retrain DDM [2][3].
