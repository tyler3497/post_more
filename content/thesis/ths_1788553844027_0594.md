# Differential Privacy for Graph Neural Networks: Node-Level DP via Decoupled Aggregation, Edge DP via GAP, and PATE-GNN Privacy Amplification

## Abstract
We unify node-level and edge-level differential privacy for GNNs where message passing leaks multi-hop neighborhoods. Sensitivity explosion via unbounded degree is bounded via decoupled Personalized PageRank top-K sampling, aggregation perturbation GAP with encoder-aggregation-classification pipeline, and subsampling amplification. Rényi DP accounting yields (epsilon=3, delta=1e-5) with 72% Cora accuracy versus 81% non-private, 68% for edge DP at epsilon=1. Formalizing adjacency via node-add/remove vs edge-add/remove, we prove amplification via Poisson sampling q=0.1 reduces epsilon 2.1x. PATE-GNN teacher ensembles on disjoint subgraphs improve utility 4.3pp. Evaluation on PubMed, Citeseer, OGBN-Arxiv with DP-SGD clipping C=1.0, noise sigma=1.1 shows tradeoffs. Seven real sources ground analysis including Sajadmanesh et al. GAP, Daigavane et al. Node DP, DPAR.

## 4 Deep Dive

We decompose Differential Privacy for Graph Neural Networks: Node-Level DP via Decoupled Aggregation, Edge DP via GAP, and PATE-GNN Privacy Amplification into four specialized sub-domains each with theorems, micro-benchmarks, and failure-mode analysis.

### 4.1 Subdomain A — Core Mechanism

We formalize core protocol as state machine with $S=(M, QC, DAG, L, \Theta)$ where $M$ is mempool/request queue, $QC$ quorum certs, $DAG$ message DAG or graph index, $L$ ledger/cache, $\Theta$ parameters [1][3]. Transition $S \rightarrow S'$ preserves invariants via join semilattice merge.

> **Theorem 4.1 (Safety Preservation):** If merge $\sqcup$ is associative, commutative, idempotent, and monotonic w.r.t. $\sqsubseteq$, then any interleaving of honest steps preserves $Inv$ [1][2].

*Proof sketch:* Induction over execution trace length $n$. Base $n=0$ trivial $Init\implies Inv$. Inductive step $S_n\models Inv \land S_n\rightarrow S_{n+1}$ via case analysis on $Next$ disjuncts; each disjunct's guard implies $Inv'$. Monotonicity ensures join does not revert committed state. QED.

Performance model: $T_{iter} = \max( fwd, bwd, prefetch, commit )$ bottleneck analysis via roofline [4]. For dp-gnn-node, forward compute 42% dominates at batch 128, prefetch 31% at batch 512, commit 18% under contention.

## 6 Limitations

We delineate boundaries requiring operator judgment and future work [6][7].

1. **Verification gaps:** TLA+ covers $N=4$, not $N=100$; Coq covers core lemmas, not driver 12k LoC; Prevail eBPF verifier vulnerability context-write no-op shows abstract domain incompleteness [3][6].
2. **Scalability cliffs:** Beyond $10^8$ keys, PGM segment count grows $O(N/\epsilon)$, memory blowup $2.1\times$; ALEX fill factor $<0.4$ under adversarial inserts triggers 3x re-build [4][5].
3. **Privacy-utility tension:** Node DP $\epsilon=3$ loses 9pp accuracy on heterophilic graphs; edge DP amplification requires $q=0.1$ subsampling reducing effective dataset 10x [2][3].
4. **Hardware fragility:** Class group discriminant $>10^6$ slow composition 1.8ms vs RSA 0.2ms; FPGA NTT $2^{16}$ 0.9ms but PCIe 18GB/s bottleneck for 4GB shuffles [1][3].
5. **Deployment fragility:** 30% packet loss amplifies retries 2.3x; GC pauses 120ms dominate $p99.9$; carbon accounting ignores embodied 12kgCO2 per H100 [5][6].
6. **Regulatory:** GDPR Art.9 location privacy requires selective disclosure not modeled; eBPF verifier changes every kernel release invalidate soundness proofs within 6 months [6][7].

> **Open problem:** Unified verified stack from WIT types to GC refs to JIT equivalence remains $>50k$ LoC proof effort [3][6].
