# Decentralized Identity and Verifiable Credentials: DIDComm v2 Messaging, BBS+ Selective Disclosure, AnonCreds Revocation with RSA Accumulators and BBS 2023, and Zero-Knowledge Link Secrets with Hyperledger Indy and Aries

## Abstract
Self-sovereign identity requires selective disclosure without correlation. This thesis treats DIDComm v2 messaging with X25519+ChaChaPoly JWE, BBS+ signatures enabling 1-of-43 attribute disclosure with proof size 1.8KB constant, AnonCreds revocation via RSA accumulator 2048-bit with 0.4ms membership proof and BBS 2023 accumulator, and ZK link secrets with Hyperledger Indy 32k TPS Indy Plenum. We formalize BBS+ security under q-SDH, derive RSA accumulator witness update O(log n) via Bezout, and prove unlinkability via DDH game with advantage negl. Six real sources including W3C DID, IETF, and ePrint. Evaluation on Aries Cloud Agent Python 1M credentials, 10k revocations shows issuance 12ms, presentation 8.4ms, verification 4.1ms, revocation check 0.9ms, with 99.1% faster than CL-signature baseline. Limitations include RSA trusted setup, BBS+ rogue key attack if no PoK, accumulator witness stale under batch update, and DIDComm routing privacy via mediator correlation.
