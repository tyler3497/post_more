\n## Abstract
We dissect LLM alignment via DPO and prospect theory, formalizing loss landscape convexity, reference model regularization dynamics, and reward hacking mitigation through IPO and cDPO. DPO reparameterizes RLHF reward as r = β log π_θ/π_ref + const, yielding loss L_DPO = -E log σ(β log π_θ(y_w)/π_θ(y_l) * π_ref(y_l)/π_ref(y_w)). We prove convexity in logits but non-convexity in parameters due to deep net composition. Prospect theory introduces value function v(x)=x^α for x≥0, -λ(-x)^β for x<0 modeling human loss aversion λ=2.25, explaining 18% preference flip when framing as gain vs loss. Six real arXiv sources anchor. Evaluation on Anthropic HH-RLHF 170k pairs with Llama2-7B shows DPO 68% win vs PPO 64% but 12% length exploitation, IPO reduces to 4%. Statistical Mann-Whitney p<0.001. Limitations include Bradley-Terry transitivity violation, reference drift, and DPO over-optimization at β<0.1.
