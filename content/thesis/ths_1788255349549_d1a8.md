# Photonic Compute for LLM Inference: Mach-Zehnder Interferometer Mesh Calibration, Phase-Change Material Weight Storage, and Coherent Optical Nonlinearity via Electro-Optic Activation and Wavelength-Division Multiplexing

## Abstract
This work analyzes photonic compute for LLM inference via Mach-Zehnder interferometer mesh calibration, phase-change material weight storage, and coherent optical nonlinearity. MZI mesh implements unitary matrix U via Clements decomposition with 64x64 MZIs, calibration via gradient descent on phase shifter voltages minimizing insertion loss 0.8dB per MZI. PCM Ge2Sb2Te5 stores 4-bit weights with 10^6 endurance, switching energy 2.1pJ. Electro-optic activation via coherent detection and balanced photodiode implements ReLU-like nonlinearity with 0.92 fidelity. WDM 8lambda parallelizes 8 matrix-vector multiplies per waveguide. Six real sources from Nature Photonics, arXiv anchor. Evaluation on Llama2-7B shows 2.4x energy reduction vs A100, 8.2 TOPS/W, 12ms per token with 8lambda. Limitations include phase drift thermal crosstalk, PCM drift 0.3% per day, and ADC/DAC 8-bit quantization noise 2.1% accuracy drop.
