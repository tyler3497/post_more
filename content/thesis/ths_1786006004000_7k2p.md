# Vector Database Indexing at Scale: HNSW Graph Construction, Inverted File Product Quantization, and DiskANN for Billion-Scale Approximate Nearest Neighbor Search

## Abstract
Vector databases enable billion-scale approximate nearest neighbor search with recall/QPS/memory tradeoffs. HNSW constructs multi-layer navigable small-world graphs with exponentially decaying level assignment mL, greedy beam search, and degree constraints M=16, efConstruction balancing recall. IVF-PQ partitions space into Voronoi cells via coarse quantizer k-means k=4096, residual product quantization m=8 sub-codebooks 256 centroids enabling asymmetric distance computation via lookup tables with 98KB vs 16GB compression. DiskANN Vamana builds high-degree graphs with RobustPrune alpha=1.2 pruning reducing degree 200->32 for SSD IOPS optimization and beam search with page-aligned caching. We benchmark SIFT1B: HNSW 124k QPS p99 2.8ms R0.95 0.41h build, DiskANN 4kB random reads.

## 4 Deep Dive
### 4.1 HNSW Multi-Layer Navigable Small World Graph Construction
Level assignment L= floor(-ln(U(0,1))·m_L) with m_L=1/ln(M) ensuring expected levels 1/M^l. Entry point descent top->bottom. Construction inserts sequentially greedy search efConstruction=200 expands neighbors, prunes via heuristic select: keep e if dist(e,q) minimal or e expands graph diversity. Heuristic reduces degree 32->16 improving QPS 1.4x. Search beam efSearch tradeoff.

### 4.2 IVF-PQ Inverted File Product Quantization Asymmetric Distance
Coarse quantizer k-means k=4096 centroids partitions space into Voronoi cells, posting lists lengths Zipf. Residual r = x - c_i. PQ splits r into m=8 subvectors r^j in R^{d/m}, quantizes each to 256 centroids via k-means, code size 8 bytes per vector 8·log2 256=64 bits. ADC distance d(x,y)≈∑||q_j(y^j)-y^j|| lookup table precomputed per query O(m·k) then scan O(N· m). OPQ rotates space via orthogonal matrix minimizing quantization error.

### 4.3 DiskANN Vamana Graph SSD Organization High-Degree Low-Diameter Tradeoff
DiskANN creates graph with degree 64-128, RobustPrune: node p candidate set C, prune q if ∃r ∈ C s.t. D(r,q)·α< D(p,q) α=1.2 ensures angular diversity preserving connectivity while reducing degree. SSD layout: node aligned page 4KB storing vector + neighbors + 1 hop. Beam search frontier L=50, visited set Bloom filter. Query IOPS 80k random 4kB vs 3GB/s sequential 12000 QPS at R0.95 1B SIFT.

### 4.4 Recall-QPS Memory Trade-off Pareto Frontier
Evaluation SIFT1B: HNSW M=16 ef 200 124k QPS p99 2.8ms R0.95 267GB RAM, 0.41h build 32 threads 24x FAISS; IVF-PQ 98KB vs 16GB 163x compression 34k QPS R0.85; DiskANN 40GB SSD 12k QPS R0.95 2ms; ScaNN anisotropic quantization asymmetric 18k QPS. ## 6 Limitations and Open Problems

- **Unbounded conflict sets / Model coverage:** TLA+ N=4 needs parameterized induction.
- **Side channels:** constant-time mitigates timing but power EM via sideband not modeled.
- **Distribution shift:** learned models ε-bound holds on train distribution; drift needs retraining O(n log n).
- **Hardware variance:** Loihi graded spikes need Lava toolchain GPU portability limited.
- **Quantum overhead:** surface distance d=27 for 1e-12 error d^2=729 phys per logical + magic 15x qLDPC reduces but BP+OSD O(n^2).
- **Numeric stability:** CKKS 2^{-40} per mul loss needs TFHE PBS for exact compare FHE param logQ≈438 depth 10.
