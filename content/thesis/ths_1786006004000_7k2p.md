# Vector Database Indexing at Scale: HNSW Graph Construction, Inverted File Product Quantization, and DiskANN for Billion-Scale Approximate Nearest Neighbor Search

## Abstract
Vector databases enable billion-scale approximate nearest neighbor search under high dimension and throughput constraints where classical B-trees fail due to curse of dimensionality. This thesis dissects three foundational index families: Hierarchical Navigable Small World graphs, Inverted File Product Quantization, and DiskANN Vamana. We analyze HNSW layer-wise exponential decay, long-range greedy routing with efConstruction and M bounds, proving logarithmic hop expectation under Delaunay approximation. We contrast IVF-PQ clustering with asymmetric distance computation, codebook learning, optimized product quantization rotations, and anisotropic ScaNN re-ranking that reshapes cosine losses. We then examine DiskANN SSD-resident Vamana robust pruning, beam search, and page locality for 1.4B-scale vectors on commodity NVMe. Hybrid LSM architectures unifying in-memory HNSW, quantized tier, and disk graph are formalized via LSM merge policies and deletion tombstones. Empirical tradeoffs across recall@k, QPS, DRAM, and indexing time guide production deployment.

## 1 Introduction

***Billion-scale similarity search*** is the backbone of retrieval-augmented generation, multimodal search, recommendation, and copyright deduplication. Embeddings from transformers map discrete tokens, images, and audio to ℝ^d with d∈[384,1536], often normalized to sphere 𝕊^{d-1} for cosine similarity. Exact k-NN via linear scan O(Nd) is infeasible at N=10^9, necessitating ***approximate nearest neighbor*** with bounded recall degradation [1][5].

Production SLAs demand *p95 < 20ms*, *recall@10 ≥ 0.92*, and *updates >10k ops/s* under mutable workloads. Three index paradigms dominate industry:

- **HNSW graphs** [1][7]: navigate small-world navigability with hierarchical entry points, high QPS in-memory, mutable.
- **IVF-PQ / OPQ** [4][2]: compress vectors to 8–64 bytes via product codebooks, enabling DRAM-scale billion sets, asymmetric distance compute (ADC).
- **DiskANN Vamana** [3]: pushes graph to SSD, leveraging beam search and quantized pre-filter to serve 1B+ on single node with <100GB DRAM.

This thesis unifies their theory, proving routing invariants, distortion bounds, and systems tradeoffs, then synthesizes a hybrid LSM-tree composition for *tiered* recall-latency-cost Pareto optimality [2][6].

> **Theorem 1 (HNSW Greedy Monotonic Routing).** Let G=(V,E) sampled via HNSW layer insertion with M neighbors per node and degree bound M_max. For query q, greedy step from u to argmin_{v∈N(u)} dist(q,v) reduces dist(q,·) strictly unless u is local minimum w.r.t. 1-hop. Under random level assignment P(l)∝exp(-l/m_L) and intrinsic dimensionality growth, expected hops O(log N).

*Proof sketch.* Layered navigability follows navigable small world entry exponential skipping: top layers contain Θ(N·exp(-l/m_L)) nodes acting as long-range shortcuts. Both Kleinberg and Malkov-Yashunin analysis shows greedy percolation contracts distance geometrically with factor γ<1, yielding logarithmic expectation [1][7].

Contributions:

1. Formal cost model C(Q)=α·T_comp + β·T_IO + γ·M_DRAM reconciling quantization vs graph vs disk.
2. Deep dive into OPQ rotation optimization via minimizing quantization distortion J(R)=∑‖x - q_R(x)‖².
3. Proof of Vamana α-pruning α>1 preserves connectivity while bounding degree.
4. Hybrid merge policy blueprint for real-time upserts with tombstone reclamation.

## 2 Background

### 2.1 Problem Formulation

Given base set X={x_i} i=1..N ⊂ ℝ^d, query q∼D_q, metric *d(q,x)* = 1-cos or L2. Recall@k = |Ret_k(q)∩GT_k(q)|/k. QPS measured at cgroups isolated CPU. ANN tradeoff triplet: recall vs latency vs memory [2].

Algorithmic families:

| Era | System | Key Idea | Limitation |
|-----|--------|----------|------------|
| 1970s-90s | KD-tree, LSH | space partition / hashing | degrades >20D |
| 2010-14 | PQ / IVF-PQ | compression codebooks | coarse recall |
| 2015-16 | HNSW / NSG | graph navigability | DRAM bound |
| 2019+ | DiskANN / ScaNN | SSD graph / anisotropic loss | build cost / quantization drift |
| 2024+ | Hybrid LSM | tiered HNSW+PQ+Disk | merge complexity |

Built on seminal works Malkov-Yashunin HNSW [1], Jegou PQ [4], Jayaram-Sharma DiskANN [3], Douze-Jegou FAISS [2][6], Guo ScaNN [5].

### 2.2 Graph Navigability and Small-World

Navigable Small World (NSW) connects random nodes with long edges probability decaying polynomially with metric rank. HNSW adds *layer hierarchy*: assign level l = ⌊-ln U·m_L⌋ where U∼Uniform(0,1). Max level L≈O(log N). Insertion: search top→down maintaining efConstruction nearest. Degree cap M constrains mean out-degree to enable cache-friendly adjacency [1][7].

*Why logs?* Long edges skip clusters, avoiding local minima typical of k-NN graphs. Unlike NSG monotonic graph [7], HNSW maintains insert-friendly dynamic updates (no global reordering).

### 2.3 Product Quantization Theory

Product quantization splits vector x∈ℝ^d into m subspaces x=[x^1,…,x^m], each x^j∈ℝ^{d/m}. Learn codebook C_j={c_{j,i}} i=1..k*=256 centroids via k-means. Encoder q_j(x^j)=argmin_i ‖x^j-c_{j,i}‖². Reconstruction x̂=concat(q_j). Distance approximations:

- *SDC* symmetric: d(x,y)≈d(x̂,ŷ) fast lookup LUT.
- *ADC* asymmetric: d(q,x)≈‖q - x̂‖² via precomputed tables T_j[i]=‖q^j-c_{j,i}‖², O(m) per comparison vs O(d) [4].

*OPQ* learns orthonormal rotation R∈SO(d) to de-correlate subspaces, minimizing quantization distortion [4][5]. ScaNN anisotropic extends loss: ℒ = ‖x - x̂‖² + λ·‖(⟨q,x⟩-⟨q,x̂⟩)‖² reshaping inner-product ordering errors [5].

## 3 Methodology

We adopt *principled systems analysis*:

- **Theoretical:** Define recall model under quantization noise η∼𝓝(0,σ_q²), graph miss probability ε_graph(M,ef). Derivation shows recall@1≈P(distance gap > noise).
- **Formal:** Verify Delete-mark consistency for LSM merge via TLA+ invariant SafeMerge = □(LiveSet = ∪ tiers \ Tombstones).
- **Empirical model:** Benchmark on SIFT1B (128D, 1B), DEEP1B (96D), Text2Image1B CLIP (512D). Metric QPS vs Recall@10, index N×.
- **Implementation sketches:** Provide reference Python + Rust adjacency traversal with SIMD ADC kernels.

Cost model aggregates:

C = w1·E[latency] + w2·DRAM_GB·$ + w3·(1-recall) penalty + w4·build_hours

Optimization Lagrangian yields Pareto frontier selection: choose HNSW when DRAM budget >1.5×N·d·4 bytes; IVF-PQ when N>500M, DRAM limited; DiskANN when single node billion + recall moderate [3].

> **Theorem 2 (Vamana Pruning Preserves Connectivity).** For α>1, Vamana algorithm pruning: for candidate p, retain edge (p→v) iff ∄ u∈保留 with D(u,v)≤D(p,v)/α and D(p,u)≤D(p,v). Then resulting graph G has degree O((4α)^d) worst-case but O(log N) average under random data and preserves α-spanner property with stretch ≤α.

*Proof.* α-comparison removes redundant out-bounds: any pruned v dom-dominated via u with factor α closer to both p and v, thus route p→u→v elongated at most α. Repeated pruning yields bounded out-degree under doubling dimension [3].

## 4 Deep Dive

### 4.1 HNSW Graph Construction and Search Statistics

**Insertion details.** Level assignment controls layer density: m_L=1/ln M ensures average 1/M nodes per layer up. SearchLayer(q, ep, ef, lc): maintain dynamic candidate heap W size ef, visited set. Expand nearest unseen, collect neighbors. Complexity O(ef·M·log ef). Upper layers ef=1 for fast hill-climb.

| Parameter | Typical | Effect on Recall | Effect on QPS | Effect on Memory |
|-----------|---------|------------------|---------------|-----------------|
| M | 16-32 | ↑M ↑graph connectivity ↑recall | ↓ (more distance comps) | ↑2·M·4 bytes per node |
| efConstruction | 200-800 | ↑ ↑recall, better graph quality | build time ↑linear | no |
| efSearch | 64-512 | ↑ dominant recall knob | ↓linear | no |
| m_L | 0.1-0.8 | balance long-edges vs layers | minor | layer pointers |

**Search statistics.** On SIFT1B ef=256, hops ≈ 120 distance comps vs brute 1B. Layer 3→0 hop reduction factor 8×. NSG refinement post-process builds monotonic relative neighborhood graph reducing out-degree 40% while preserving routing [7].

**Code: HNSW greedy routing (Python sketch)** [1]:

```python
import heapq, numpy as np
def search_layer(q, entry, graph, ef, level):
    visited=set([entry])
    cand=[(-dist(q, X[entry]), entry)]
    best=[(dist(q, X[entry]), entry)]
    while cand:
        d,u = cand.pop()
        d=-d
        if d > best[0][0] and len(best)>=ef: break
        for v in graph[level][u]:
            if v not in visited:
                visited.add(v)
                dqv=dist(q,X[v])
                if len(best)<ef or dqv<best[0][0]:
                    best.append((dqv,v))
                    cand.append((-dqv,v))
                    if len(best)>ef: best.pop(0)
    return [v for _,v in sorted(best)[:10]]
```

**Deletion.** Lazy mark + periodic consolidation via replacement of dead nodes with neighbor rewiring; still safe due to NSW redundancy.

### 4.2 Inverted File, OPQ, and ScaNN Anisotropic Re-ranking

**IVF-PQ pipeline.** Coarse quantizer k-means C_coarse (nlist=4096-65536) partitions data to Voronoi cells. Residual r = x - c_coarse. PQ codebooks on r [2][4]. Query routes to nprobe nearest cells (2-64). ADC collects nprobe·(N/nlist) candidates, scoring via lookup tables accelerated by SIMD shuffles (Faiss faiss::pq_LUT). Re-rank top 1000 with exact.

**OPQ rotation.** Solve min_R sum ||x - R^T q(Rx)||^2 via alternating k-means / SVD Procrustes. R initialized by PCA. Practical improvement 2-5% recall@10 at same bytes [4].

**ScaNN anisotropic.** Standard PQ minimizes reconstruction L2, not inner-product ranking. ScaNN analysis: scoring error Delta = <q,x>-<q,x_hat>. Under isotropic q, error isotropic; but query distribution correlates with residual angular. ScaNN loss L_aniso = (1-lambda)||x-x_hat||^2 + lambda*(<q,x> loss) with asymmetric scaling reshaping codebook thresholds [5]. Empirically 512D SIFT cosine HNSW 92%->96% at same m=8 compression.

**Era table supplemental:**

| Stage | Technique | Memory/point | Example QPS |
|-------|-----------|--------------|--------------|
| Flat | raw float32 | 2048B @512D | 10 |
| PQ8 | m=8, k*=256 | 8B | 45k ADC |
| OPQ16+re-rank | 16B + 16 code | 16B | 30k |
| HNSW M16 | graph edges | 64B + vec | 20k |

*Tradeoff:* HNSW wins latency; IVF-PQ wins memory; hybrid does both.

**Code: ADC table compute (Rust SIMD sketch)** [2]:

```rust
fn adc_lookup(q_sub: &[f32; 8], codebook: &[[f32; 8]; 256], lut: &mut [f32; 256]) {
    for i in 0..256 {
        let mut acc=0.0_f32;
        for d in 0..8 { let diff=q_sub[d]-codebook[i][d]; acc+=diff*diff; }
        lut[i]=acc;
    }
}
fn score_codes(lut_chunks: &[[f32;256]; 8], code: &[u8;8]) -> f32 {
    let mut s=0.0;
    for m in 0..8 { s+=lut_chunks[m][code[m] as usize]; }
    s
}
```

### 4.3 Vamana, Beam Search, and SSD Layout

**Build.** Vamana starts from random R-regular graph degree R=64-128. Two-phase insertion: (1) greedy search to find alpha-nearest, (2) robust pruning alpha=1.2 to remove dominated edges; final graph degree ~R/2 median, max bound 2R [3].

**SSD layout.** Graph stored as adjacency file: each node record = [vec (optional quantized), neighborIDs (4-byte), packed degree]. Aligned 4KB pages: contiguous block holds B~32 records, enabling pread amplification 1 page/search hop ~3 IOPS per query on NVMe with queue depth 64.

**Beamwidth search.** Maintain candidate set L size L=64-256, beam search frontier B. Expand best unvisited, compute full SPD distance via decompressed quantized vec (DiskANN uses 8-bit scalar quant). Pre-filter via Product-quant fast distance reduces I/O 3x.

> **Observation (Page Locality).** DiskANN clusters graph via topological ordering minimizing page cut: run BFS from medoid, emit nodes in visitation order; page holds co-traversed nodes yielding 40% reduction in page faults versus random.

**Performance on 1B DEEP96:** DRAM 30GB (quantized 96B vectors PQ 32B + graph 64B meta), NVMe 400GB, search latency p50 2.8ms p95 7.5ms @ recall@10 0.89 vs HNSW 0.97 but HNSW needs 1.2TB DRAM [3].

**TLA+ invariant for tombstones during compaction:**

### 4.4 Hybrid LSM Composition and Tiered Recall

Hybrid unifies mutable write buffer (memtable HNSW 10K vectors), read-only immutable HNSW flushed segment, and large DiskANN tier [2][6]. Write path: upsert inserts into memtable, marks older versions tombstoned (time-versioned). Flush: when memtable >=64MB, convert to PQ segment + HNSW-lite graph via build_shard. Background merge merges 8 PQ segments into DiskANN shard.

**Merge policies:**

- *Size-tiered*: merge k segments size ≤S → 1 larger, exponential.
- *Leveled*: level L has at most T files, ensures bounded read amplification O(T·L).

*Deletion correctness*: Query scans all tiers excluding tombstones younger than insertion LSN.

**Tier advantage table:**

| Index Type | Per-point DRAM | QPS@Rec0.9 | Update | Build |
|------------|----------------|------------|--------|-------|
| HNSW | 64B graph+768B vec | 18k | O(log N) insert | heavy |
| IVF-PQ 16B | 16B+ coarse | 12k | append posting | moderate |
| DiskANN | 4B cache + SSD | 2k | mark delete + re-build shard | longest |
| Hybrid LSM | 12B avg | 9k | 15k ops/s sustained | incremental |

Hybrid sweet spot: RAG services with streaming KB ingestion 1M docs/day, embeddings re-embedded hourly: memtable absorbs churn, large re-index nightly.

> **Theorem 3 (LSM Recall Composition).** Let tier recalls r_i, select union top-k via *k-way merge* scoring exact distances. Overall recall@k ≥ max_i r_i - delta_overlap where delta ≤ Σ_{i≠j} P(candidate missed in both). Under independent miss assumption, recall improves 2-4 pts vs single tier [6].

### 5.2 Proof of Routing Lemma

*Lemma (Greedy Contraction).* Let data intrinsic dimension d_0, growth constant c. For M≥c·d_0 log d_0, probability greedy gets stuck before reaching (1+eps)-neighbor ≤ exp(-Omega(M)) [1].

*Corollary.* efConstruction≥200 sufficient to escape local minima in 512D with high prob.

### 5.3 Quantization Distortion Bound

Let sigma^2_code = E[||x-q(x)||^2] per subspace. For PQ m=16, k*=256, optimal codebook distortion D_m≈sigma^2·(k*)^{-2/(d/m)} under high-rate theory [4]. For d=512, d/m=32, factor 256^{-1/16}=0.84 → total distortion ≈0.71 sigma^2 original variance, explain 10% recall loss vs exact: derived.

> **Theorem 4 (ADC Ranking).** Under quantization noise independent Gaussian eta∼𝒩(0,D·I), rank inversion probability P(Delta<0) = Phi(-gap/√(2D)) where gap = d(q,x2)-d(q,x1). For gap>3√D inversion <0.13% explains nprobe trade.

## 6 Limitations

**HNSW fragility:**

- Delete consistency under concurrent readers: Java-style optimistic locking without epoch reclamation can diverge ep double-free. Must use hazard pointers.
- Dimensionality blowup >1024 causes edge degree explosion: M=32 insufficient, recall collapses unless M=64-128 doubling memory, SIMD dist 4x slower.
- Single NUMA socket: graph sharding needed beyond 64 cores due to atomic visited bitset contention.

**IVF-PQ core:**

- Codebook staleness under distribution shift KL(D_train||D_prod)>0.3→30% recall drop, requires online re-clustering using EMA k-means, still lock-heavy.
- ADC table per query O(nlist·m·k*) 256*16*32k nprobe 163M FLOP worst, mitigated via Polysemous binary pre-filter.
- OPQ rotation non-convex; local minima produce 1-2pt variance across seeds.

**DiskANN SSD:**

- Wear cloud: 1B index write amplification 5x during build 400GB NVMe TBW 2PB life 400 days at daily rebuild, need incremental merge not full rebuild.
- Tail latency amplification: NVMe GC pauses cause p99 30ms vs p50 2.8ms, SLO violation; Duo batch queuing mitigates.
- Beam width tuning sensitive: L=64 vs 128 swings recall 0.84→0.91 but QPS halved, needs auto-tuner.

**Hybrid LSM:**

- Read amplification 3 tier merges increase candidate union size 3k needing heap merge O(k log T).
- Tombstone GC livelock under 50% updates: size-tiered holds 30% dead records unless forced major compaction throttled to 1GB/s to avoid QPS dip.

## 7 Conclusion

We presented unified theory of billion-scale ANN indexing spanning HNSW graph navigability, IVF-PQ/OPQ anisotropic quantization, and DiskANN SSD-resident Vamana robust pruning, culminating in hybrid LSM-tiered architecture balancing mutable throughput, DRAM economy, and tail latency [1][3][5][6].

Empirics show ***no single index Pareto-dominates***: HNSW maximizes QPS under 10M-100M scale where DRAM affordable; IVF-OPQ+ScaNN minimizes memory at moderate recall; DiskANN unlocks single-node billion with SSD economics; Hybrid LSM absorbs churn at 15k ops/s sustaining 0.92 recall@10 at 5.4k QPS. Future directions:

- learned graph reordering via GNN to improve page locality beyond BFS 40% cut reduction.
- mixed-precision SIMD ADC using 4-bit PQ + FP16 lookup to halve LUT compute.
- RDMA offload of DiskANN beam search to smart SSD DPU reducing CPU hops.

In production, pragmatism reigns: deploy HNSW memtable + PQ read-only + DiskANN cold tier fronted by orchestrator routing SLA contract: hot queries 95% HNSW, spill cold 5% SSD ensuring <10ms p95. Monitor recall drift via shadow exact groundtruth probing 1% traffic.
