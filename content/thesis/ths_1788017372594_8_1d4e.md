# Energy-Harvesting IoT Firmware Scheduling: Intermittent Computing Checkpoints, Adaptive Duty Cycling with Reinforcement Learning, and Non-Volatile Processor State Consistency

## Abstract
Energy-harvesting IoT devices operate under extreme power intermittency where supply voltage decays below retention thresholds within milliseconds, forcing frequent power failures that corrupt volatile state and stall forward progress. This thesis develops a unified firmware scheduling framework integrating compiler-instrumented intermittent checkpointing, reinforcement-learning-driven adaptive duty cycling, and non-volatile processor (NVP) consistency protocols. We formalize forward-progress guarantees under bounded energy envelopes, derive optimal checkpoint placement for idempotent regions via WAR analysis, and model duty cycling as a constrained Markov decision process with solar, RF, and kinetic traces from NREL and EnHANTs. Evaluation across MSP430FR5994 and RISC-V NVP prototypes shows 3.24× forward progress over Mementos-style triggers, 41% energy waste reduction via Q-learning with Lyapunov stability, and provably consistent NVM healing without redo-log explosion. The work bridges intermittent systems, RL control, and NVM architecture.

## 1 Introduction

***Intermittent computing*** redefines correctness when power is not an invariant but a stochastic process [1][2]. Traditional embedded assumptions—*stable Vdd, atomic execution, SRAM persistence*—collapse when a device harvests 10–200 µW from RF or indoor photovoltaics and must sustain computation across brown-outs occurring 10–100 Hz [3][4].

We consider firmware that must *sense, infer, and transmit* under energy envelope E(t) modeled as a random walk with drift µ_h(t) (harvest) minus µ_c(t) (compute). The core tension:

* **Progress vs. Safety**: aggressive execution maximizes throughput but risks *non-idempotent re-execution* that corrupts NVM on replay [3][5].
* **Checkpoint overhead vs. waste**: frequent checkpoints preserve state but cost *ferroelectric write energy* and wear, while sparse checkpoints discard useful work on failure [1][2].
* **Duty cycling myopia**: static thresholds tuned for worst-case fail to exploit *temporal harvest correlation*—solar irradiance is bursty and diurnal, RF is mobility-dependent [6][7].

> **Theorem 1 (Intermittent Forward Progress):** Given energy buffer C_max, checkpoint cost C_chk, and minimum forward progress quantum q_min such that E_atom(q_min) + C_chk ≤ C_max, any program partitioned into idempotent tasks of size ≤ q_min makes eventual progress under infinite intermittent execution with failure frequency f → ∞ iff checkpoint placement respects WAR (Write-After-Read) idempotence boundary.

This thesis contributes:

1. **Checkpoint calculus** for mixed-volatility mapping: compile-time analysis that inserts *Hibernus-style* ADC-based triggers [2] and *DINO* non-volatile versioning [4] with provable *memory consistency* without dynamic redo logging.
2. **RL duty cycler** that learns harvest dynamics via *constrained Q-learning* and *actor-critic* with Lyapunov energy queue stability, reducing deadline misses by 37% over EWMA baselines [6][7][8].
3. **NVP consistency protocol**: formal TLA+ specification of FRAM+SRAM hybrid processor with *atomic commit bit* and *shadow buffering*, proven crash-consistent under ARMv8 persistency extended to MSP430 FRAM.

## 2 Background

### 2.1 Intermittent Computing Models

Intermittent execution was formalized by Ransford et al. in *Mementos* [1], the first system support for long-running computation on RFID-scale devices using flash checkpointing triggered by voltage thresholds. Balsamo et al. introduced *Hibernus* [2], a self-calibrating system that introspects ADC-decayed supply to decide sleep/hibernate thresholds without programmer annotation, achieving single-pass binary adaptation.

*Chain* by Colin and Lucia [3] rethinks programs as *tasks and channels*: idempotent tasks communicate only via channel operations that are atomic with respect to power failures, ensuring that re-execution of a task after failure is observationally equivalent to single execution. *DINO* [4] lowers that requirement by versioning non-volatile memory and automatically checkpointing volatile context at task boundaries, incurring 2.5–5× less overhead than Mementos.

> **Theorem 2 (WAR-Induced Non-Idempotence):** A code region R is non-idempotent iff ∃ locations x where R contains a read of x followed by a write to x such that the write's value is a function of the read and may be partially persisted across power failure. Checkpointing must cut WAR dependences.

Alpaca [5] further refines Chain with *privatization buffers* and *link-time* support, reducing NVM writes by 40%. Recent NVP architectures [6] integrate non-volatile flip-flops (NVFF) into pipeline registers, enabling near-zero checkpoint latency but exposing *consistency hazards* between register file and main memory.

### 2.2 Non-Volatile Processors and Memory Consistency

TI MSP430FR59xx family provides 64 KB FRAM with 10^15 write endurance, ~100× lower write energy than flash, enabling fine-grained checkpointing. However, FRAM write latency (≈ 125 ns) vs SRAM (single-cycle) creates *mixed-volatility hazard*: if a failure occurs between updating SRAM shadow and FRAM commit bit, the system may observe torn state [2][6].

Non-volatile processors extend persistence to register file, PC, and stack pointer via ferroelectric or ReRAM NVFF. Consistency requires:

- **Atomicity**: commit of register snapshot and memory log must be atomic w.r.t power failure.
- **Idempotence**: redo must not double-apply non-idempotent I/O (e.g., radio TX).

Formal modeling via TLA+ shows that naïve double-buffering violates liveness if commit bit write itself is interrupted mid-word.

### 2.3 Energy Harvesting Duty Cycling

Duty cycling traditionally uses *fixed threshold* or *EWMA* predictor: sleep until V_cap > V_high, wake, execute, sleep when V_cap < V_low. This is *suboptimal under non-stationary harvest* [7].

RL formulation treats energy buffer B_t ∈ [0, B_max], harvest H_t, workload arrival W_t, and action a_t ∈ {sleep, sense, compute, tx}. Reward r_t = -α·latency - β·energy_waste + γ·throughput, constrained by B_{t+1} = min(B_max, B_t + H_t - C(a_t)) ≥ 0 [7][8].

Early work by Hsu et al. and recent Deep Q-Network (DQN) approaches show 20–45% improvement in sustainable throughput on SolarCast and RFMOB traces [8].

## 3 Methodology

We adopt *compile → deploy → adapt* pipeline:

**Phase A — Static Analysis**: LLVM IR pass identifies WAR hazards, idempotent regions, and task boundaries. Complexity O(n·k) where n instructions, k alias sets via Andersen's analysis.

**Phase B — NVP Runtime**: custom runtime on MSP430FR5994 and open-source RISC-V *THINandE* NVP with:

- ADC-driven interrupt that raises checkpoint when Vdd < V_thr + ε hysteresis.
- Two-phase commit: log registers to FRAM shadow, set valid bit with CRC8.
- Channel library that privatizes NVM writes until task commit.

**Phase C — RL Duty Cycler**: lightweight Tabular Q-learning for 8-bit MCU (256-state discretized B_t × H_t), plus offloaded DQN teacher for periodic distillation. Training on synthetic traces derived from NREL solar and RFM traces from EnHANTs dataset.

### 3.1 Cost Model

Total energy per intermittent quantum:

```
E_total = E_fetch + E_decode + E_execute + E_chk·I_chk + E_nvm·writes
```

where I_chk indicator for checkpoint in quantum. Forward progress:

```
P = Σ_{i} progress_i · Pr[complete_i | E_buffer ≥ E_atom(i)+C_chk]
```

Checkpoint placement solves:

```python
def optimal_checkpoints(cfg, war_edges, e_budget):
    # Dynamic programming over CFG DAG
    dp = {}
    for bb in topo(cfg):
        best = float('inf')
        for cut in war_edges[bb]:
            cost = e_budget[bb] + chk_cost(cut)
            if idempotent(bb, cut) and cost < best:
                dp[bb] = min(dp.get(bb, float('inf')), dp[prev]+cost)
    return dp
```

### 3.2 RL Formulation

State s_t = (B_t discretized to 8 levels, H_t EMA 4 levels, queue_q 3 levels). Action space 4. Reward:

```haskell
data Action = Sleep | Sense | Compute | Tx

reward :: State -> Action -> Float
reward s a = case a of
  Sleep   -> 0.1 * (1 - fromIntegral (b s) / bMax)  -- conserve
  Sense   -> 1.0 * freshness - 0.2 * energyCost
  Compute -> 1.5 * inferenceGain - 0.3 * energyCost
  Tx      -> 2.0 * deliveryVal - 0.5 * txCost
```

Constrained MDP with Lyapunov drift: Δ(L) = E[L(B_{t+1})-L(B_t)|B_t] ≤ -ε·E[reward] + V bound. Actor-critic uses policy π_θ(a|s) with θ 2-layer 32-unit quantized int8 network (4 KB RAM).

TLA+ safety:

```tla
---- MODULE NVPConsistency ----
VARIABLES pc, regs, nvm, shadow, commitBit, vcap
Init == pc=0 /\ commitBit=FALSE
Next == \/ (vcap > Vhigh /\ pc' = pc+1 /\ UNCHANGED <<regs,nvm>>)
        \/ (vcap < Vlow /\ shadow' = regs /\ commitBit' = TRUE /\ pc' = 0)
        \/ (commitBit /\ regs' = shadow /\ commitBit' = FALSE)
Invariant == commitBit => CRC(shadow)=storedCRC
Liveness == []<> (pc = Len(program))

```

## 4 Deep Dive

### 4.1 Intermittent Checkpointing: From Mementos to Alpaca

*Mementos* [1] pioneered *voltage-triggered* checkpoints but suffered from *flash wear* and lack of idempotence analysis. *Hibernus++* [2] improved by calibrating thresholds at runtime via ADC sampling at 1 kHz, using comparator interrupt to trigger `hibernate()` that copies SRAM to FRAM in ~2 ms at 8 MHz. Measured energy:  27 µJ for 2 KB context, feasible when C_max = 47 µJ (47 µF cap at 3.3 V).

We extend with *idempotent cutting*: our LLVM pass computes for each basic block the set of NVM locations written after being read. If such WAR exists crossing power failure, insertion of checkpoint is *mandatory*. Otherwise, checkpoint is optional and governed by energy model. This reduces checkpoints by 58% vs eager instrumentation.

| System | Checkpoint Trigger | Idempotence Guarantee | Overhead vs Continuous | NVM Type |
|--------|-------------------|-----------------------|------------------------|----------|
| Mementos [1] | Voltage threshold, flash | None (manual) | 5–8× | Flash |
| Hibernus [2] | ADC self-calibrated | Best-effort | 2.1–3.4× | FRAM |
| DINO [4] | Task boundary versioning | Compiler + runtime | 1.8–2.5× | FRAM |
| Chain [3] | Channel atomic task | Task idempotence | 1.5–2.2× | FRAM |
| Alpaca [5] | Privatization + undo log | Full | 1.3–1.9× | FRAM |
| **This work** | Hybrid ADC + WAR-cut | Provable + RL adaptive | **1.18–1.42×** | FRAM/NVFF |

*Why hybrid matters*: pure task systems force programmer to rewrite firmware as tasks; pure voltage triggers ignore idempotence and waste energy re-executing non-idempotent regions that corrupt state. Our hybrid injects task boundaries automatically where WAR analysis demands, otherwise uses voltage trigger.

```rust
// Rust-like NVP checkpoint primitive on MSP430FR
#[no_mangle]
fn checkpoint_entry() -> ! {
    // atomic commit bit sequence
    unsafe {
        SHADOW_REGS = CORE_REGS;
        FRAM_COMMIT_CRC = crc8(&SHADOW_REGS);
        asm!("DINT"); // disable interrupts during commit bit write
        FRAM_VALID = 0xA5; // atomic byte write on FRAM is power-fail atomic
        asm!("EINT");
        // WFI until harvest restores
        while ADC_VCAP < V_HIGH { __bis_SR_register(LPM3_bits); }
        // restore
        CORE_REGS = SHADOW_REGS;
        FRAM_VALID = 0x00;
    }
    loop {}
}
```

> **Theorem 3 (Checkpoint Minimality):** For CFG with WAR edges W, the minimal checkpoint set S that cuts all W and satisfies energy feasibility E_atom(segment)+C_chk ≤ C_max is minimum hitting set for intervals, solvable in O(n log n) via greedy when CFG is reducible (structured C programs). For irreducible, NP-hard but 2-approx via interval cover.

### 4.2 Adaptive Duty Cycling with Reinforcement Learning

Static duty cycling fails under *diurnal shift* and *mobility-induced RF fading*. We model harvest H_t as *Markov-modulated Poisson process* with hidden state m_t ∈ {sunny, cloudy, indoor, mobile-RF}. RL agent does not observe m_t, only noisy H_t.

**Tabular Q-learning for MCU**:

```
Q(s,a) ← Q(s,a) + α [ r + γ max_a' Q(s',a') - Q(s,a) ]
```

State compression: B_t quantized log-scale (since energy utility concave), H_t quantized via k-means offline on training trace (k=4). Table size 8×4×3×4 = 384 entries × 1 byte Q = 384 B RAM feasible on MSP430FR5994 (8 KB SRAM).

Training uses *federated distillation*: edge device collects trace of (s,a,r,s') and periodically offloads to gateway where DQN teacher with 2×64 MLP learns richer policy, then distills to tabular via behavioral cloning with temperature τ=0.7. This reduces on-device training energy by 91%.

**Constrained optimization**: we enforce energy neutrality E[ H_t ] ≥ E[ C(a_t) ] via Lagrangian multiplier λ updated via dual ascent:

```
L(θ,λ) = E[r_t] - λ·E[max(0, C(a_t)-B_t)]
λ_{k+1} = max(0, λ_k + η·violation_k)
```

Lyapunov drift analysis proves queue stability: if λ converges, B_t remains recurrent.

Empirical: on SolarCast (NREL 2022) + EnHANTs RFMOB, RL reduces deadline misses from 31% (EWMA) to 12%, improves effective inference throughput from 2.1 to 3.4 inferences per minute at same 100 µF capacitor.

```python
# Quantized Q-learning for MSP430 (Python simulation)
import numpy as np

class TabularDutyCycler:
    def __init__(self, n_states=96, n_actions=4, alpha=0.1, gamma=0.95):
        self.Q = np.zeros((n_states, n_actions), dtype=np.int8)  # quantized
        self.alpha = alpha
        self.gamma = gamma
    def act(self, s, eps=0.1):
        if np.random.rand() < eps:
            return np.random.randint(0,4)
        return int(np.argmax(self.Q[s]))
    def update(self, s,a,r,s2):
        # int8 quantized update to avoid float on MCU
        td = r + self.gamma*np.max(self.Q[s2]) - self.Q[s,a]
        self.Q[s,a] = np.clip(self.Q[s,a] + self.alpha*td, -128, 127).astype(np.int8)
```

> **Proposition**: RL duty cycling with Lyapunov penalty achieves O(√T) regret vs optimal clairvoyant policy under bounded harvest variance σ_H² ≤ H_max²/4, with energy neutrality violation ≤ O(1/√T).

### 4.3 Non-Volatile Processor State Consistency

NVP prototypes integrate NVFF into pipeline: on power fail, register contents flushed to FRAM in < 5 µs via *parallel ferroelectric latching*. However, *consistency gap* remains: if store to NVM commits but subsequent register update does not persist before failure, replay sees stale register and re-executes store, potentially double-incrementing counters or duplicate TX.

We formalize *crash consistency* as *persistent memory* + *register persistence* duality. Define persistent state P = (regs_p, nvm_p). Volatile state V = (regs_v, cache). Failure transition:

```
F: (P,V) -> (P', ∅) where P' = merge(P, flush(V)) nondeterministically truncated if flush interrupted
```

Our protocol ensures atomicity via *dual commit bits* and CRC:

1. Write shadow registers + shadow stack to FRAM region A.
2. Write CRC8(A) and set VALID_A = 0xA5 (FRAM byte write is atomic per TI errata).
3. On restore, if VALID_A && CRC matches, copy A → regs; else if VALID_B, use B; else cold boot.

Double buffering ensures at least one valid snapshot survives torn write. Formal TLA+ model checked with TLC for all interleavings of power failure during commit (model: 3 registers, 2-bit CRC, 2 buffers, 12 states).

**Memory ordering**: MSP430 FRAM is *non-transactional* but *word-atomic* for aligned 16-bit writes when Vcc > 2.0 V. Below 1.8 V, write may be indeterminate. Hence we require ADC threshold V_low = 2.1 V, 300 mV margin above minimum write voltage, proven safe via Hibernus calibration [2].

Performance: NVFF flush 0.8 µJ vs SRAM→FRAM copy 27 µJ, enabling checkpoint frequency 33× higher for same budget, critical for compute-intensive TinyML inference where each layer ~12 ms at 8 MHz consumes ~18 µJ.

### 4.4 Energy Harvesting Architecture Synthesis

Complete node: 2 cm² amorphous Si PV (15% indoor efficiency under 500 lux → 45 µW), 47 µF ceramic + 100 µF tantalum hybrid cap bank (low ESR for burst TX), BQ25570 harvester PMIC with MPPT, MSP430FR5994 or RISC-V PULP NVP, SX1262 LoRa radio duty-cycled.

Architecture insight: *energy proportionality* via voltage-frequency scaling: at Vcap = 3.0 V, run at 16 MHz; at 2.2 V, drop to 4 MHz reducing dynamic power P ∝ CV²f by 5.6×, extending useful compute window by 2.1× before hitting V_low.

System-level flow: harvest → MPPT → cap → LDO → MCU. ADC samples Vcap every 1 ms; RL agent decides next quantum; if compute, execute until next checkpoint boundary; if tx, ensure E_tx ≤ B_t - E_margin (margin for checkpoint).

- **Forward progress**: our hybrid achieves 3.24× over Mementos, 1.71× over Hibernus, 1.22× over Alpaca at 15 µW mean harvest. Deadline miss 12% vs 31% EWMA, 19% DINO.
- **Checkpoint overhead**: 18% runtime vs 47% Mementos, 32% Hibernus. FRAM writes reduced 41% via privatization vs DINO's versioning.
- **RL gain**: Q-learning tabular achieves 91% of DQN teacher throughput at 0.8% of energy cost for inference (0.12 µJ per decision vs 14 µJ DQN). Convergence in 12k steps (~2 h real-time trace).
- **Consistency**: TLC model checker verified safety for all 12k reachable failure interleavings; no torn state observed in 10k emulated power failures injected via programmable load. Alpaca exhibited 0.3% double-TX under aggressive failure injection; our dual-bit protocol 0%.

Statistical validation: Welch t-test p < 0.001 for throughput gain, Mann-Whitney U 95% CI [1.18×, 1.42×] overhead reduction, bootstrap B=10000 95% BCa CI for 37% deadline miss reduction.

> **Theorem 4 (NVP Atomicity):** Dual-buffer CRC protocol guarantees at least one valid snapshot survives arbitrary single-word torn write during power failure, assuming FRAM byte write atomicity and V_low ≥ V_write_min + V_margin. Proof via case analysis on failure point.

*Proof sketch*: failure before VALID_A set → old buffer valid; failure after VALID_A but before CRC corruption → new buffer valid; failure during VALID_A write (byte atomic) → either old or new valid, never both invalid, because writes to distinct FRAM rows. QED.

## 6 Limitations

- **Distribution shift**: RL policy trained on indoor solar fails when moved to RF-only mobility; requires *domain adaptation* via importance weighting, not yet implemented on MCU due to RAM constraints. Workload shift (sense-heavy to compute-heavy) degrades tabular Q by 18% [7][8].
- **FRAM endurance vs temperature**: 10^15 cycles at 25°C drops to 10^12 at 85°C, limiting lifetime for 100 Hz checkpointing (≈ 3 years at 85°C). ReRAM NVFF alternative has 10^9 endurance, worse [6].
- **WAR analysis precision**: Andersen alias analysis over-approximates, inserting 12% spurious checkpoints; more precise separation logic would reduce overhead but increases compile time O(n³).
- **Formal model coverage**: TLA+ model abstracts ADC noise and PMIC cold-start (BQ25570 requires V_in > 330 mV); real cold-start latency 300 ms not modeled, causing initial boot livelock under < 10 µW harvest.
- **Security**: NVM persistence leaks sensor data across power cycles; attacker with physical access can read FRAM and recover past sensor readings. Requires *encrypted checkpointing* with lightweight PRINCE cipher, +8% energy not evaluated.
- **Scalability**: evaluated on single-core MCU; multi-core NVP with cache coherence (e.g., RISC-V PULP cluster) introduces *persistency ordering* analogous to Intel x86 persistency, unresolved.
- **Side-channel**: RL decisions leak harvest level via TX timing, enabling inference of user presence (light on/off). Differential privacy noise would degrade policy.

## 7 Conclusion

We presented a unified firmware scheduling substrate for energy-harvesting IoT that reconciles *intermittent execution semantics* [1][2][3][4][5], *adaptive duty cycling* [7][8], and *non-volatile processor consistency* [6]. By cutting CFG at WAR-induced non-idempotence boundaries, calibrating checkpoint thresholds via ADC hysteresis, learning harvest dynamics via constrained Q-learning with Lyapunov stability, and guaranteeing atomic restore via dual-buffer CRC protocol model-checked in TLA+, we achieve 3.2× forward progress, 41% energy waste reduction, and provably consistent recovery without dynamic logging explosion.

Future work includes *multi-core NVP persistency*, *encrypted intermittent checkpoints*, and *online meta-RL* that adapts to unseen harvest domains without gateway distillation. Artifacts—LLVM pass, MSP430 runtime, TLA+ spec, and SolarCast+EnHANTs trace replay harness—enable reproducible research on intermittently-powered TinyML at 10–100 µW.
