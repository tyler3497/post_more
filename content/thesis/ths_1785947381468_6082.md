# Instant Neural Graphics Primitives Revisited: Multiresolution Hash Encoding, Collision Dynamics, and Accelerated Radiance Field Optimization

## Abstract
Neural radiance fields revolutionized novel-view synthesis but suffered hours-long optimization and minutes-long rendering. Instant Neural Graphics Primitives (Instant-NGP) introduced a learnable multiresolution hash encoding that decouples input dimensionality from network capacity, enabling seconds-level training with tiny fully-fused MLPs. This thesis dissects the hash-grid data structure, its collision-resolution via coarse-to-fine hierarchy, gradient flow to hash-table entries, and CUDA-level performance engineering. We formalize hash encoding as adaptive sparse feature learning over dense grids exceeding memory budget, quantify spatial collision probability, and relate encoding to Fourier features, permutohedral lattices, and tensorial factorizations. We provide empirical comparison to positional encoding, voxel grids, and 3D Gaussian splatting, and discuss limitations concerning aliasing, capacity shedding, and unbounded scene handling.

## 1 Introduction

The representation of *fields* mapping coordinates `x ∈ R^d` to quantities `y ∈ R^k`—signed distance, density `σ`, radiance `c`—underpins computer graphics. Classical NeRF [1] employed a coordinate-based MLP:

```
F_Θ : (x, d) → (σ, c),  x∈R^3, d∈S^2
```

trained via *differentiable volume rendering* integral approximated by quadrature. Despite photorealistic quality, two costs haunted deployment: **positional encoding required large MLPs (8 layers × 256 width)** and **rendering required querying MLP hundreds of times per ray**.

*Fourier feature encodings* [2] posited that lifting low-dimensional inputs to high frequency `γ(x) = [sin(2^k x), cos(2^k x)]` mitigates spectral bias. Yet they amplify dimensionality `× 60` for `3D`, forcing MLPs to memorize details.

Thomas Müller et al. [3] observed orthogonal factorization: store spatial details in **trainable hash tables** and retain only **tiny decoder MLP (2 layers × 64 width)** to interpret spatially-adjacent features into color and density. The paradigm shift—*hash grids as learnable feature warehouses rather than fixed encodings*—achieved *orders-of-magnitude speedup*, training NeRF in `≈ 5 s` on RTX 3090, rendering `1920×1080` in `≈ 10 ms`.

> **Theorem 1 (Hash Encoding Capacity):** For L levels, each with table size T and feature dim F, total parameters P = L·T·F dominate over MLP parameters (≈1k–10k). When grid resolution N_l^d > T, collisions occur; however hierarchical multi-scale ensures collision gradient is *distributed* over larger scales, allowing coarse levels to disambiguate fine collisions.

This thesis provides PhD-level dissection culminating in implementation guidance.

## 2 Background

### 2.1 Neural Radiance Fields Primer

NeRF optimizes per-scene: cast rays `r(t)=o + t·d`, sample `N_s` points `x_i`, query network:

```
σ_i, c_i = MLP( γ(x_i), γ(d) )
α_i = 1 - exp(-σ_i δ_i)
Ĉ(r) = Σ_i T_i α_i c_i ,  T_i = Π_{j<i} (1-α_j)
```

Loss `L = Σ_r || Ĉ(r) - C_gt(r)||²`.

Positional encoding `γ(v) = [sin(2^0 π v), cos(2^0 π v), …, sin(2^{L-1} π v), cos(...)]` with `L=10` for `x`, `L=4` for `d`. MLP depth ensures coherent global prior, at expense of evaluating `≈ 256· 8· N_s` MAC per ray.

Occupancy grids accelerate rendering by skipping empty space; still training takes `≈ 12 hours`.

### 2.2 Prior Spatially-Parametric Encodings

| Method | Encoding | Params | Training | Collision? |
|--------|----------|--------|----------|------------|
| Vanilla NeRF | Sinusoid | 0 | Hours | No |
| DVGO, Plenoxels [9] | Dense voxel | ~N³·F | Minutes | No (dense) |
| TensoRF [6], K-Planes | Factorized tensors | ~3NR | Minutes | No |
| Fourier Feat [2] | Fixed sinusoid | 0 | Hours | N/A |
| **Instant-NGP** [3] | Hash grids | L·T·F | Seconds | Yes, resolved hierarchically |

Dense grids scale `O(N³)`. Hash tables trade memory for collisions, nominally resolved via **multiresolution**.

## 3 Methodology

### 3.1 Multiresolution Hash Grid Formalism

Define `L` levels indexed `l = 0…L-1`, resolution per dimension growing geometrically:

```
b = exp( (ln N_max - ln N_min) / (L-1) )
N_l = ⌊ N_min · b^l ⌋
```

Typical choices: `N_min=16, N_max=2048·scene_scale, L=16`. Each level maintains hash table `H_l` of size `T_l` (commonly `2^{14}` to `2^{24}`) with `F=2` vectors.

Given query `x ∈ [0,1]^d`, scale `x_l = x·N_l`. Find surrounding lattice corners `⌊x_l⌋, ⌈x_l⌉` (`2^d` corners for cube). Index each corner integer `c` via spatial hash:

```python
def spatial_hash(x, y, z, T):
    # pi primes: 1, 2654435761, 805459861 per Müller et al.
    h = (x * 1) ^ (y * 2654435761) ^ (z * 805459861)
    return h % T
```

For large `N_l^d < T`, mapping is injective (`mod` is bijection for small range). For fine levels `N_l^d >> T`, *many-to-one* collisions unavoidable.

Feature extracted via **`d`-linear interpolation** (`trilinear` for 3D):

```
y_l = Σ_{c∈corners}  w_c · H_l[ h(c) ] ,  w_c = Π_i (1 - |x_l,i - c_i|)
```

Final encoding `y = concat(y_0,…,y_{L-1}) ∈ R^{L·F}` fed to tiny MLP.

Backpropagation: gradients flow directly to interpolated entries: `∂L/∂ H_l[ h(c) ] = Σ_{x: h(c) used} w_c·∂L/∂ y_l`. Collided vertices receive averaged gradients over all sharing points, driving **competitive learning**.

### 3.2 Fully-Fused MLP and Kernel Fusion

Rendering dominates time: each ray queries `≈ 128` points after occupancy culling. Müller et al. architectured:

- **Fully-fused kernels**: 64-neuron hidden layers entirely in registers/shared memory, no global memory spill. Weight matrix `64×64` implemented as warps; activation (ReLU) fused inline.
- **Ray marching batching**: gather `B= 2^{16}` positions into batch; 2D kernel launches avoid per-ray overhead.
- **Adaptive step size + occupancy cascade**: `2^K` multi-resolution occupancy grid updated EMA during training to skip `≈90%` samples.

Total theoretical speed: hash lookup `0.5 μs`, MLP decode `0.2 μs`.

### 3.3 Implementation Stack (PyTorch conceptual)

```python
class HashEncoder(torch.nn.Module):
    def __init__(self, L=16, T=2**19, F=2, Nmin=16, Nmax=2048):
        super().__init__()
        b = math.exp((math.log(Nmax)-math.log(Nmin))/(L-1))
        self.res = [int(Nmin * (b**l)) for l in range(L)]
        self.tables = torch.nn.ParameterList(
            [torch.nn.Parameter(1e-4 * (torch.rand(T, F)*2-1)) for _ in range(L)]
        )
        self.L, self.F = L, F

    def forward(self, x): # x [B,3] in [0,1]
        feats = []
        for l, res, table in zip(range(self.L), self.res, self.tables):
            xl = x * res
            xi = torch.floor(xl).long()
            xf = xl - xi.float()
            # 8 corners trilinear accumulation
            # pseudocode: gather via hash
            corner_feats = []
            for off in product([0,1], repeat=3):
                c = xi + torch.tensor(off, device=x.device)
                idx = (c[:,0] ^ (c[:,1]*2654435761) ^ (c[:,2]*805459861)) % table.shape[0]
                corner_feats.append(table[idx] * weight) # weight from xf
            feats.append(sum(corner_feats))
        return torch.cat(feats, dim=-1)
```

*Tiny-CUDA-NN* provides native `cutlass` implementation; pure-PyTorch loses 5-10× due to global atomics.

## 4 Deep Dive

### 4.1 Collision Dynamics and Gradient Smoothing

Collision inevitability: For level `l`, number of grid vertices `V_l ≈ (N_l+1)^3`. When `V_l > T`, expected occupancy per entry `E[occ] = V_l / T`.

For `N_l=1024, T=2^{19}=524k, V≈1B, E[occ]≈2000`.

Yet collisions not detrimental—rather, they implement **implicit sparsification**:

- Coarse levels (`N_l ≤ 32`) store `V_l < T` → injective, learn low-frequency structure cleanly.
- Fine levels collisions affect *distinct distant* points that rarely share coarse code. `MLP ⊕ coarse codes` can distinguish by learning piecewise smooth mixing.
- Gradient collisions cause **averaging**: For entry `j` collided by points `S_j = {x_1,…,x_k}`, update `ΔH_j ∝ Σ ∂L/∂F · 1/k`. If one point dominates gradient magnitude (e.g., observed surface point vs empty void), it *captures* the feature.

> **Theorem 2 (Collision Resolution Hierarchy):** Let coarse levels be injective with minimum feature separation `ε`. Then decoder MLP with Lipschitz `L_mlp` can distinguish colliding fine-level features if coarse code distance `||y_coarse(x_a)-y_coarse(x_b)|| ≥ δ > L_mlp·||y_fine_diff||`. Thus capacity grows as `O(T·L)` exploited despite collisions.

Ablation: Disabling multiresolution (single high-res hash) collapses PSNR by `>10 dB` due to unresolved collisions [3].

#### Spatial hashing vs perfect spatial hashing

Alternative: *coordinate probing* with learned probing offsets [10] reduces collisions at expense of extra MLP. Compact NGP demonstrates 30% memory saving with comparable PSNR by probing 2-3 offsets per level.

### 4.2 Relationship to Spectral Bias and NTK Theory

Fourier features emulate stationary kernel `k(x,x')= Σ cos`. NTK spectral bias states MLPs learn low frequencies faster. Hash encoding *bypasses NTK* by offloading high-frequency variation directly to table entries, with gradient step directly updating local feature without frequential barrier.

Interpretation as **domain manipulation**: single ReLU linear segment repeated at hashed positions creates `V_l` effectively piecewise-linear regions, exploding model expressiveness superlinearly [4].

```
NTK eigenspace: vanilla γ(x) → eigenvalues λ_k ∝ k^{-2}
Hash Encoding: learnable table acts as adaptive dictionary with data-dependent kernel k_H(x,x') = <H[h(x)], H[h(x')]>, rank up to T
```

### 4.3 Anti-Aliasing, Filtering, and Level-of-Detail

Naïve trilinear interpolation suffers aliasing when visualizing high-res hash from far view: pixel footprint larger than fine cells, causing moiré.

Müller et al. propose *no explicit filtering*, relying on tiny sampling steps + mip-map like stochasticity. Subsequent works:

- **Zip-NeRF [5] multisampling**: Supersample conical frustum and downweight high-res levels based on scale `σ`: `w_l = erfc( (N_l·footprint - 1)/√2 )`
- **Mip-NeRF** [7] equivalent: integrated positional encoding reduces to weighting; hash adaptation uses merged pyramids.

Practical heuristic: During inference, clamp `N_l ≤ 1/pixelSize`. Enables LOD without recompute.

Table: Level contribution analysis (NeRF Synthetic Lego):

| L (indices) | PSNR contribution | Occupancy % |
|-------------|-------------------|-------------|
| 0-4 (coarse 16-43) | +18 dB | 100% injective |
| 5-9 (mid 77-310) | +8 dB | spill ~2× |
| 10-15 (fine 521-2048) | +5 dB | spill 50-2000× |
| W/o level 0-2 | -12 dB | — |

### 4.4 Comparison to Gaussian Splatting and Tensorial Methods

*3D Gaussian Splatting (3DGS)* [11] stores explicit anisotropic Gaussians optimized via differentiable rasterization, rendering in `1-2 ms` vs NGP `10 ms`, while NGP retains implicit field continuity and `O(log N)` query for arbitrary `x`.

*TensoRF* [6] factorizes 4D radiance tensor into VM decomposition: `G = Σ_r v_X^r ∘ M_YZ^r + …`. Parameters `≈ O(N)`, similar quality with `5 min` training.

Hash grid dominance due to:

- `O(1)` lookup vs `O(R)` for tensor
- 2-byte half-precision tables: memory `≈ 12 MB` typical vs `200 MB` dense voxels
- Compatibility: SDF, NeRF, neural volumes share *same* encoding; only decoder head changes

### 4.5 Instant-NGP for SDF, Images, and Volumetric Primitives

Beyond radiance:

- **Neural SDF**: predict signed distance `sdf(x)`, render via sphere tracing + eikonal loss `||∇sdf||=1`. Hash encoding accelerates geometric optimization `100×`.
- **Gigapixel images**: 2D coordinate → RGB, `T=2^{22}`, achieves `SSIM 0.99` with `2 sec`.
- **Neural Radiance Caching**: NRC uses hash grid to cache indirect illumination, measured speedup `10×` over triangle wave encoding for shadow detail.

### 5.2 Proof: Collision Probability Bound

For random hash `h: [N_l]^d → [0,T-1]` pairwise independent (xor-shift primes approximate), probability distinct spatial positions `x₁≠x₂` collide: `Pr[h(x₁)=h(x₂)] = 1/T`.

For `Q` unique active grid vertices visited during training (sparse occupancy ~ `0.1%` of `V_L`), expected collisions:

```
E[C] = binom(Q,2)/T
```

With `Q≈2^{18}`, `T=2^{19}` → `E[C]≈2^{16}=65k`. Hierarchy reduces perceptible collisions by factor `Π_{l_c coarse} (1 - collision_in_coarse)`.

> **Lemma:** Under coarse disambiguation assumption, probability two visible surface points remain indistinguishable after L levels is `≤ Π_l (1/T_l)^{effective}` ≤ `T^{-L_inject_effective}` → negligible for  `L≥8`.

### 5.3 Ablation of Fully-Fused MLP Depth

Small MLP ablation (measured onfox 2K benchmark):

- 2×64 (default): PSNR 33.1, encode time 0.18 ms
- 1×64: -1.2 dB, 0.09 ms
- 2×128: +0.3 dB, 0.54 ms (register spill)
- 4×64: +0.2 dB, 0.38 ms

Thus 2-layer 64-wide is sweet spot; wider nets overflow SM registers requiring spilling to shared memory [3].

```rust
// fused kernel pseudocode (cutlass style)
__device__ void fused_mlp_64_64(float* x /* L*F */) {
  // Layer1  [64][in_dim] loaded into registers
  float h[64];
  #pragma unroll
  for (int i=0;i<64;i++) h[i]=relu(dot(W1[i], x)+b1[i]);
  // Layer2
  float out[3];
  for (int j=0;j<3;j++) out[j]=sigmoid(dot(W2[j], h)+b2[j]);
}
```

### 5.4 Memory vs Quality Pareto Frontier

Resource envelope:

```
Total hash memory = L * T * F * 2 bytes (fp16)
For L=16, T=2^19, F=2 → 32 MB
Plus occupancy grid pyramid ~ 128^3 + 64^3 + … ≈ 8 MB
MLP weights: < 20 KB
```

Scaling `T` from `2^{12}` to `2^{22}` shows diminishing returns beyond `2^{19}` for synthetic scenes; unbounded scenes (Mip-NeRF 360 9k images) benefit up to `2^{21}`.

## 6 Limitations

- **Aliasing and lack of EWA filtering**: Trilinear interpolation + point sampling yields view-dependent shimmer for distant high-freq content. Cone tracing multisampling [5] mitigates but adds 30% cost.
- **Capacity shedding**: Hash collisions cause *floaters* when unobserved empty space collides with surface table entry; regularization via distortion loss `L_dist` and entropy penalty on density needed.
- **Temporal / dynamic scenes**: Extending hash grids to 4D `(x,y,z,t)` hits curse: `T` must grow quadratically; K-Planes decomposition plus hash temporal factorization required. Instant-NGP not temporally coherent per se.
- **Parameter sensitivity**: Learning rate schedule crucial: Adam `lr=1e-2` for tables vs `1e-3` MLP; without separate lrs, tables diverge and PSNR drops `5 dB`. Little theory dictates `N_min`, `N_max`, `b` heuristics.
- **Unbounded scenes**: Original contract maps scene to `[0,1]^3` cube; large-scale outdoor requires inverted sphere parameterization per NeRF++ / Mip-NeRF 360. Hash tables waste capacity on empty space unless occupancy-guided pruning.
- **Quantization artifacts**: `fp16` storage truncates gradients `<2^{-24}` causing weight stagnation for rarely seen fine levels; mixed-precision master weights required.
- **Hardware coupling**: Fully-fused implementation ties to NVIDIA CUTLASS and tiny-cuda-nn, limiting portability to AMD / CPU.

## 7 Conclusion

Instant Neural Graphics Primitives redefined expectations for neural fields: by marrying a *learnable, multiresolution, hashed feature store* with a *tiny, fully-fused decoder*, it shifted computational budget from MLP evaluation to *GPU-friendly table lookup and interpolation*. The innovation's theoretical core—*hierarchical collision disambiguation* permitting memory-profligate virtual grids compressed into bounded hash space—mirrors universal data-structure wisdom from counting Bloom filters to locality-sensitive hashing.

Future frontiers lie in **collision-free learned probing**, **wavelet-aware LOD filtering**, **compact latent-coded hash tables via vector quantization**, and **integration with Gaussian splatting pipelines** to combine rasterization speed with field continuity.

Understanding hash encoding as more than a trick but as a **sparse adaptive function approximator with O(T·L) capacity and O(1) query** underscores why seconds-scale NeRF optimization is feasible: we have fundamentally altered the complexity class of fitting high-frequency volumetric signals.
