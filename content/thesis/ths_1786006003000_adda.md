# Mechanistic Interpretability of Large Language Models: Sparse Autoencoders, Induction Heads, and Circuit Discovery for Deception Detection and Alignment Auditing

## Abstract
Mechanistic interpretability reverses LLMs from black-box predictors to white-box circuits. Sparse autoencoders learn overcomplete dictionaries decomposing polysemantic residual streams into monosemantic features with reconstruction loss and L1 sparsity, enabling feature steering and deception detection. Induction heads implement [A][B]...[A]->[B] via previous-token copying with QK composition and OV circuits, discovered via attention pattern analysis and causal path patching. This thesis formalizes transformer circuits, logit lens, direct logit attribution, and S-inhibition heads. We evaluate Anthropic SAE scaling, induction head ablation 40% ICL reduction, grokking phase transitions with Fourier feature emergence, and Superposition metrics, mapping to alignment auditing for sycophancy and sandbagging.

## 4 Deep Dive
### 4.1 Sparse Autoencoders Overcomplete Dictionary Decomposes Polysemantic
SAE training: encoder W_enc residual stream x in R^{d} -> f = ReLU(W_enc (x - b_dec) + b_enc) in R^{M}, M≫d (M=32d), decoder x̂ = W_dec f + b_dec, loss ||x-x̂||^2 + λ||f||_1. Features monosemantic scoring via auto-interp. Scaling to GPT-4 residual 1536-> 32k features. Steerability: add α·W_dec[i] shifts logit. Deception detector: truth vs lie direction found via contrastive activation addition.

### 4.2 Induction Heads QK-OV Circuit and Previous-Token Head Composition
Induction heads consist of two-head circuit: previous-token head at layer L-1 copies token from n-1 to n, attention pattern 1.0 on previous. QK composition: induction head at L matches prefix [A] by attending to previous-token head output carrying [A], OV copies [B]. Attention score QK = x W_Q W_K^T x_prev. Ablation removes in-context learning 40% 2-shot. Measured via path patching causal scrubbing.

### 4.3 Circuit Discovery via Direct Logit Attribution and Path Patching
Logit lens projects residual x_L via W_U to vocab. Direct logit attribution decomposes score into head contributions. Causal intervention replaces activation from clean to corrupted: keep edge if logit drop >0.05. S-inhibition heads suppress duplicate token loops, name mover heads move object token to subject position. Example IOI circuit: duplicate token → S-inhibition → name mover → logit. Evaluation on 20 tasks shows circuit precision 0.87 recall 0.79.

### 4.4 Grokking Phase Transition Fourier Feature Emergence
Grokking memorization 0% val -> circuit formation mutual information increase -> cleanup validation jump at 1e5 steps. Modular addition task forms Fourier features: W_OV projects to cos(k·(a+b)), sin. Progress measures: restricted loss, excluded loss, Gini coefficient. Deception detection uses same progression monitoring loss on truthful vs deceptive.

## 6 Limitations and Open Problems

- **Unbounded conflict sets / Model coverage:** TLA+ N=4 needs parameterized induction.
- **Side channels:** constant-time mitigates timing but power EM via sideband not modeled.
- **Distribution shift:** learned models ε-bound holds on train distribution; drift needs retraining O(n log n).
- **Hardware variance:** Loihi graded spikes need Lava toolchain GPU portability limited.
- **Quantum overhead:** surface distance d=27 for 1e-12 error d^2=729 phys per logical + magic 15x qLDPC reduces but BP+OSD O(n^2).
- **Numeric stability:** CKKS 2^{-40} per mul loss needs TFHE PBS for exact compare FHE param logQ≈438 depth 10.

Open directions: autonomous repair via DCD extent migration CXL analogy, PAM4 FEC 6B 64GT/s 1e-6→1e-30 BER roadmap, MSWASM GC externref deferred GC integration, weak-memory C11+ARMv8 OOTA formalization.
