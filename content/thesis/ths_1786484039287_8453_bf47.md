## 6 Limitations

1. **Honest majority/benevolent scheduler:** Byzantine n>=3f+1 assumed [1]; rational deviators degrade liveness.
2. **Formal model scope:** TLA+ checked N=4, prod N=4096 requires parameterized induction [3].
3. **Side-channels:** constant-time mitigations [3] power/EM telemetry via sideband [6] not modeled.
4. **Distribution shift:** learned model ε-bound holds on training distribution; drift requires O(n log n) retrain [2][4].
5. **Hardware variance:** custom toolchain Lava/MuJoCo/NVIDIA Warp portability limited.
6. **Quantum/security overhead:** Dilithium enc-dec d²=729 physical overhead plus factories 15x blowup; optimization reduces not eliminates.
7. **Numeric stability:** CKKS approx homomorphism 2^-40 loss per mult; TFHE PBS switching needed for exactness [3][4].

Roadmap: qLDPC+lattice surgery [5][7], deterministic sideband QoS [6], autonomous index repair via DCD migration akin CXL 3.0 pooling.
