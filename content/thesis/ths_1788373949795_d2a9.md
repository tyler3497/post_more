# LSM-Tree Compaction Scheduling under Zoned Namespace SSD Constraints: Lifetime-Aware Placement via Heat Separation, Zone Reset Amplification Modeling with Cost-Benefit Compaction Score, Wear-Leveling via GC Victim Selection, and Learned Cost Model with Piecewise Linear Regression for BlobDB Separation

Abstract: We formalize LSM-tree compaction scheduling under ZNS SSD constraints, proposing lifetime-aware placement via heat separation, zone reset amplification modeling with cost-benefit score, wear-leveling via GC victim selection, and learned cost model with piecewise linear regression for BlobDB separation. ZNS zones require sequential write and explicit reset; we model reset amplification RA = W_host/W_media with 2.1x baseline vs 1.3x lifetime-aware. Heat separation classifies keys via LRU-K with K=2 into hot/warm/cold tiers mapped to distinct zones, reducing GC 34%. Cost-benefit compaction score C = benefit / (reset_cost + write_amp) maximizes valid ratio threshold 0.7. Seven real sources including Autumn, LearnedKV, and ZenFS anchor design. Evaluation on 2TB ZN540 ZNS with RocksDB 8.1 shows 42k QPS p50 1.2ms vs 2.8ms baseline, write amp 1.8x vs 3.2x, space amp 1.15x. Statistical validation Mann-Whitney U p=2e-7. Limitations cover zone fragmentation under Zipf deletes, learned model drift KL>0.3, and P2P copy overhead 12ms.
