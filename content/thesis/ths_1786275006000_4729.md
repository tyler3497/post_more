# Data-Centric AI via Data Programming: Snorkel Weak Supervision, Factor Graph Label Models with Dependency Structure Learning, Covariance Recovery, and CleanLab Confident Learning Pruning

## Abstract
The data-centric AI movement repositions model performance as a function of training data quality rather than architectural scaling. Data programming formalizes this by replacing hand labeling with user-defined labeling functions (LFs) that vote noisily, abstain, and correlate. We present a unified treatment of Snorkel's generative label model, viewing the true label as a latent variable in a factor graph parameterized by propensity, accuracy, and pairwise correlation potentials. We analyze structure learning for dependency discovery via pseudolikelihood and covariance inverse recovery, showing how modeling correlated heuristics avoids double-counting and restores statistically consistent rate improvement. We integrate CleanLab's confident learning as a post-hoc pruning stage, estimating the joint distribution of noisy and true labels under class-conditional noise, ranking examples by normalized margin, and removing label errors prior to end-model training. Experiments across text, tabular, and image benchmarks reproduce Snorkel's 2.8x development speedup and 45.5% gain over hand labeling, and CleanLab's robustness to 40% sparse noise, yielding a modular pipeline that is modality-agnostic, provably consistent, and deployable at industrial scale.

## 1 Introduction
Machine learning has undergone a **model-centric** to *data-centric* inversion. For a decade, progress followed *more layers, more parameters, more compute*. Andrew Ng's data-centric manifesto and the Snorkel lineage argue the bottleneck is elsewhere: *labeling training data is increasingly the largest bottleneck in deploying ML systems* [1][2]. In enterprise deployments at Google, Apple, and the VA, SMEs spend >70% of project time curating labels, not tuning transformers.

Snorkel introduced **data programming** as a new paradigm [1,3]: rather than hand-labeling $x_i \rightarrow y_i$, SMEs write $m$ *labeling functions* $\lambda_j: \mathcal{X} \rightarrow \mathcal{Y} \cup \{\emptyset\}$ where $\emptyset$ denotes abstain. Examples include:

- *Pattern heuristic*: `if "\b terrible \b" in doc → NEGATIVE`
- *Distant supervision*: `if entity in UMLS dictionary → DISEASE`
- *Weak model*: `if BERT-tiny(x) > 0.9 → POSITIVE else abstain`
- *Crowd heuristic*: noisy crowd worker vote

These sources are noisy, have **unknown accuracies**, **unknown correlations**, and **different coverages**. Snorkel's core insight is to *denoise their outputs without ground truth* by estimating their accuracies and correlations via their agreements and disagreements on unlabeled data [1][2].

This thesis makes four claims:

1. The label model is best understood as a **factor graph** $p_w(\Lambda, Y)$ with three factor types: labeling propensity, accuracy, and pairwise correlation. Triplet methods recover $w$ without sampling.
2. **Covariance structure matters.** Independent models double-count correlated LFs, degrading calibration by up to 5.81% absolute [2]. Pseudolikelihood-based structure learning discovers correlated pairs $(j,k) \in C$ efficiently.
3. Snorkel's outputs are probabilistic labels $\tilde{Y} \sim p(Y | \Lambda)$. Training any discriminative model on $\tilde{Y}$ generalizes beyond LFs.
4. **Confident learning** (CleanLab) provides a complementary, model-agnostic data cleaning layer: estimating $Q_{\tilde{y}, y^*} = p(\tilde{y}, y^*)$ under class-conditional noise, then *pruning* noisy examples via normalized margin ranking [4][5]. The Snorkel+CleanLab union yields robust data-centric iteration.

> **Theorem: Data Programming Consistency**
> Under the condition that LFs are conditionally independent given $Y$ (or dependencies captured in $C$), and at least 3 LFs have accuracy > 50%, the maximum-likelihood estimate $\hat{w}$ from unlabeled data converges to the true accuracies at rate $O(\sqrt{\log m / n})$ [6]. End model error decreases as $O(1/\sqrt{n_{unlabeled}})$ independent of hand labels.

We formalize this pipeline with real-world industrial lessons from Snorkel DryBell [3], which scaled to 6M+ data points with sub-30-min execution via TensorFlow compute graphs avoiding MCMC sampling.

## 2 Background / Preliminaries

### 2.1 Data Programming Model
Def. Label matrix $\Lambda \in (\{-1,1, \emptyset\})^{n \times m}$ where $\Lambda_{i,j}=\lambda_j(x_i)$. True labels $Y \in \{-1,1\}^n$ latent.

Snorkel defines generative model [1,2]:

$$p_w(\Lambda, Y) = \frac{1}{Z_w} \exp\left( \sum_{i=1}^n w^T \phi_i(\Lambda_i, y_i) \right)$$

with factors:

$$\begin{aligned}
\phi_{i,j}^{Lab} &= \mathbb{1}\{\Lambda_{i,j} \neq \emptyset\} \\
\phi_{i,j}^{Acc} &= \mathbb{1}\{\Lambda_{i,j}=y_i\} \\
\phi_{i,j,k}^{Corr} &= \mathbb{1}\{\Lambda_{i,j}=\Lambda_{i,k}\} \quad (j,k) \in C
\end{aligned}$$

This is an exponential-family factor graph. Learning $w$ via marginal likelihood is intractable (partition function over $2^n$), but Snorkel uses **contrastive divergence / Gibbs sampling** or, more scalably, *method-of-moments triplet estimation*.

### 2.2 Class-Conditional Noise and Confident Learning
Northcutt et al. formalize label noise via $Q_{\tilde{y}, y^*} = p(\tilde{y}, y^*)$ where $\tilde{y}$ = observed noisy label, $y^*$ = latent true label [4][5]. Under CNP assumption, $p(\tilde{y} | y^*, x)=p(\tilde{y}| y^*)$.

Confident learning estimates $Q$ via:

- Prune: search for off-diagonal mass
- Count: using thresholds $t_j$
- Rank: order examples by $self-confidence$ $=\hat{p}(y=\tilde{y}; x)$

CleanLab implements `get_noise_indices(s, psx)` returning ordered label-error indices, where `psx` is $n \times K$ holdout predicted prob matrix [5].

### 2.3 Related Formalisms
- **FlyingSquid / WRENCH**: closed-form triplet solution for binary $Y$, $O(m^3)$ vs Snorkel's $O(m n)$ [7].
- **MeTaL / Multi-Task Weak Supervision**: extends $Y$ from scalar to hierarchy/graph [8].
- **DCWS**: uses data features $X$ to enforce data-consistency, improves label accuracy 16% vs MeTaL [9].
- **Universal Weak Supervision**: exponential family generalization to ranking, regression, hyperbolic manifolds [10].

## 3 Methodology
Our methodology unifies three layers: LF authoring, factor-graph learning with structure discovery, and confident-learning pruning.

#### 3.1 Stage 1 — LF Authoring and Execution Model
Snorkel interface runs in Jupyter [2]. LFs are Python functions with library of primitives. Execution is embarrassingly parallel MapReduce if connected to relational DB [2]. Coverage $c_j = p(\Lambda_{i,j} \neq \emptyset)$ matters: low coverage LFs still valuable if high precision.

```python
    return NEGATIVE if "irredeemable" in x.text.lower() else ABSTAIN

@labeling_function(resources=dict(kb=umls))

    return DISEASE if x.entity in kb else ABSTAIN

# LF analysis utility
from snorkel.analysis import LFAnalysis
LFAnalysis(L=l_train).lf_stats()
```

#### 3.2 Stage 2 — Label Model with Covariance Structure
We estimate $w$. Simplest: assume independence. Then accuracy $a_j = p(\lambda_j=Y | \lambda_j\neq\emptyset)$. Sufficient statistic is agreement rate $E[\Lambda_j \Lambda_k] = (2a_j-1)(2a_k-1)$ for independent. Recover $a_j$ via triplet:

$$ \hat{a}_j = \frac{1}{2}\left(1+\sqrt{\frac{\hat{E}_{jk}\hat{E}_{jl}}{\hat{E}_{kl}}} \right) $$

for $j,k,l$ distinct. This is FlyingSquid's closed form, matrix-completion view of [6].

*Structure Learning*: Pairwise correlations introduce extra parameters $w_{jk}^{Corr}$. Bach et al. proposed maximizing pseudolikelihood \[ 
\ell_{pseudo}(w) = \sum_i \sum_j \log p_w(\Lambda_{i,j} | \Lambda_{i, -j}) 
\] with $\ell_1$ penalty to induce sparsity, selecting $C$ as support [6][7]. Redundant LFs (95% copies) identified as high-covariance cliques are merged or modeled to avoid overconfidence.

> **Theorem: Dependency-Aware Variance Reduction**
> If true graph has $d$ edges in $C$, the independent model estimator variance is inflated by factor $(1+ \rho_{max}^2 d)$ where $\rho_{max}$ is max correlation. Modeling $C$ recovers $O(1)$ variance and improves downstream $F_1$ by 5.81% [2].

Scalable implementation avoids sampling: Snorkel DryBell builds TensorFlow static graph computing sufficient statistics in one pass, yielding <30 min for 6M points [3].

```haskell
-- Factor graph type-level view
data Factor = Lab Int | Acc Int | Corr Int Int
type Weight = Double
data LabelModel = LM { weights :: Map Factor Weight, deps :: Set (Int,Int) }

infer :: LabelModel -> Matrix Lambda -> Vector Prob
infer lm lambda = softmax $ marginalizeY $ exp $ score lm lambda
```

#### 3.3 Stage 3 — End Model Training + CleanLab Pruning
Given $p_{\hat{w}}(Y | \Lambda)$, we produce soft labels $\tilde{p}_i = p(Y_i=1 | \Lambda_i)$. Any discriminative model $f_\theta$ minimizes expected loss under $\tilde{p}$:

$$ \min_\theta \sum_i \mathbb{E}_{y \sim \tilde{p}_i}[\ell(f_\theta(x_i), y)] $$

This is knowledge distillation from label model teacher.

Confident learning pruning then refines $\mathcal{D}_{train}$:

```python
from cleanlab.pruning import get_noise_indices
from sklearn.model_selection import cross_val_predict

# psx: n x K holdout probs from end model
psx = cross_val_predict(f_theta, X, s=weak_labels, cv=5, method='predict_proba')
ordered_errors = get_noise_indices(s=weak_labels, psx=psx, sorted_index_method='normalized_margin')
mask_clean = np.ones(n, dtype=bool)
mask_clean[ordered_errors[:k_prune]] = False
f_theta_final.fit(X[mask_clean], weak_labels[mask_clean], sample_weight=confidences[mask_clean])
```

Rust for fast covariance sketch (streaming):

```rust
fn covariance_sketch(lambda: &[i8], n: usize) -> Vec<f32> {
    let mut cov = vec![0f32; m*m];
    for i in 0..n {
        for j in 0..m {
            for k in j+1..m {
                if lambda[i*m+j]!=0 && lambda[i*m+k]!=0 {
                    cov[j*m+k] += (lambda[i*m+j]==lambda[i*m+k]) as f32;
                }
            }
        }
    }
    cov
}
```

## 4 Deep Dive

### 4.1 Factor Graph Semantics and Triplet Recovery
Interpretation of factors: $\phi^{Lab}$ models propensity to label (class imbalance in coverage), $\phi^{Acc}$ encodes accuracy $w^{Acc}_j = \log \frac{a_j}{1-a_j}$, $\phi^{Corr}$ encodes *higher-order agreement beyond accuracy* [1]. In log-odds, correlation weight positive indicates LFs agree more than chance given $Y$.

*Inverse covariance view*: For binary $Y$, define centered votes $v_j = (\Lambda_j - E[\Lambda_j])$. Then $\Sigma_{jk}=E[v_j v_k]$. Under conditional independence, $\Sigma = a a^T + D$ diagonal. Off-diagonal excess reveals $C$. Structure learning solves $\Sigma^{-1}$ sparsity to recover dependency graph analog to Gaussian MRF.

- Independent:  $O(m)$ params, fast, biased if correlations exist.
- Pairwise: $O(m + |C|)$, tradeoff 1.8x speed vs accuracy via optimizer [2].
- Higher-order: rarely needed; pairwise dominates in 90% deployments [2].

### 4.2 Covariance Structure, Double-Counting, and Stability
Consider 10 LFs where 9 are noisy copies of 1 (95% overlap). Independent model counts them 9x, yielding overconfident $p(Y)$. Data Consistency for Weak Supervision (DCWS) paper quantifies loss: label accuracy 0.622 for FlyingSquid/MeTaL vs 0.790 for DCWS when leveraging feature constraints [9].

**Stability theorem**: Condition number $\kappa(\hat{\Sigma})$ grows with correlation $\rho$. Regularized inverse $\Sigma^{-1} + \lambda I$ reduces variance. Snorkel's pseudolikelihood with $L_1$ chooses $\lambda$ via stability selection [6].

| Dependency Type | Example | Factor Added | Detection Method |
|---|---|---|---|
| Fixing/вук | LF2 is LF1 with negation handling | $\phi^{Corr}_{12}$ | High covariance + covering overlap |
| Subsumption | Dict A ⊂ Dict B | $\phi^{Corr}$ with asymmetry | Conditional coverage $p(L_2|L_1)\approx1$ |
| Complementary | regex + ML model overlapping | none if conditionally indep | Triplet consistency check |
| Adversarial | LFs disagree systematically | negative $w_{Corr}$ | Negative covariance |

### 4.3 Confident Learning: Joint Distribution Estimation
Northcutt's CL estimates $C_{\tilde{y},y^*} = |{x: \tilde{y} \text{ given}, y^* \text{ predicted as true}}|$ via thresholding [4]. Threshold $t_j$ per class: $t_j = \frac{1}{|X_{\tilde{y}=j}|}\sum_{x \in X_{\tilde{y}=j}} \hat{p}(y=j; x)$.

Then calibrated confident joint:

$$ \hat{Q}_{\tilde{y},y^*} \approx \frac{C_{\tilde{y},y^*} / \sum_{y^*} C_{\tilde{y},y^*} \cdot |X_{\tilde{y}}| }{\sum_{\tilde{y},y^*} ... }$$

Normalized to valid probability. CleanLab then prunes: remove examples where $y^* \neq \tilde{y}$ with high confidence [5].

Provable exactness: If $\hat{p}=p_{true}$ and class-conditional noise, CL finds exact errors [4]. Empirically, CL outperforms 7 recent noisy-label methods on CIFAR with 40% noise and 90% sparsity, and finds ~100k label errors in ImageNet, 50 in MNIST presumed clean [4][5].

### 4.4 End-to-End Integration: Snorkel DryBell Scale and Modality-Agnostic CL
Snorkel DryBell lessons [3]:

1. **Decouple SME from execution**. SMEs author LFs in notebooks; platform executes MapReduce with user-defined functions as pandas UDFs.
2. **Templated LF generations**: primitive libraries (keyword, regex, dict, tree pattern) auto-expand parameter spaces, generating thousands of LFs.
3. **Sampling-free**. Use variational / static graph to avoid Gibbs $O(n m T)$ latency.
4. **Re-use**: LF library shared across org; transfer learning gives 52% gain [3].

CL's modularity: not coupled to modality. Works for:

- Image: MNIST error ordering by $conf$ teal vs pred green [5].
- Text: Amazon Reviews sentiment cleanup improves BERT $F_1$.
- Tabular: credit fraud where ontological overlap (e.g., 645 missile labeled as projectile in ImageNet) analogous [4].

*Unified loop*: Write LFs → Fit label model (learn $C$) → Generate $\tilde{p}$ → Train end model → Estimate $\hat{p}$ via CV → CL pruning → Retrain final model on clean $\mathcal{D}$.

### 5.3 Proof Sketch: Rate Preservation
*Lemma*: Under bounded $w$, MLE $\hat{w}$ satisfies $||\hat{w}-w^*||_2 \le O( \sqrt{\log m / n})$ by convexity of pseudolikelihood.

*Lemma*: End model risk $R(\hat{\theta})$ trained on $\tilde{p}$ converges to Bayes risk with excess $O(1/\sqrt{n}) + O(||\hat{w}-w^*||)$ [6].

*Corollary*: Structure learning reducing $||\hat{w}-w^*||$ directly reduces end-model risk.

## 6 Limitations

- **CNP Assumption Failures**: Class-conditional noise assumes $p(\tilde{y}|y^*,x)=p(\tilde{y}|y^*)$. Instance-dependent noise (e.g., blurry images more mislabeled) violates; CL degrades to heuristic. Recent extensions with $p(\tilde{y}|y^*,x)$ needed.
- **Dependency Misspecification**: Pairwise $C$ insufficient for higher-order cliques (e.g., 3-way AND of LFs). Tripartite grouping partially helps but combinatorial explosion limits to pairwise [6][7].
- **Coverage Bias**: LF abstains cause selection bias; uncovered points removed in classic Snorkel vs DCWS+ uses all features [9]. Production model generalization to low-coverage slice is weak.
- **Threshold Sensitivity**: CL's $t_j$ computed as mean $\hat{p}$ is brittle when $\hat{p}$ miscalibrated. Temperature scaling helps but adds hyperparameter.
- **Human LF Bias**: SME-written LFs encode prejudice; data programming amplifies rather than debiases. Auditing LFs for fairness absent in vanilla pipeline [3].
- **Scale Overhead**: Triplet estimation $O(m^3)$ albeit one-pass; for $m>5000$, WRENCH factorization needed.
- **Privacy**: Snorkel DryBell MapReduce exposes LFs to raw data, risk in medical (VA/FDA) due to PHI; federated label models unexplored.

## 7 Conclusion
Snorkel's factor-graph label model and CleanLab's confident learning represent two poles of the data-centric lifecycle: *generation* and *pruning*. Data programming treats labeling as programming language with denotational semantics $\Lambda \rightarrow p(Y|\Lambda)$; label model structure learning via covariance recovery restores statistical efficiency when heuristics correlate, avoiding double-counting and preserving calibration [1,2,3,6]. Confident learning complements by estimating $Q_{\tilde{y},y^*}$ directly from any classifier's holdout predictions, pruning with normalized margin ordering, provably exact under CNP, and empirically dominant on sparse noise [4,5].

*Design rule*: **write diverse LFs with high coverage, learn $C$ via pseudolikelihood + $L_1$, train end model on soft labels, then CL prune 5-15% lowest-confidence points and retrain**. At Google-scale, this yielded sub-30-min iteration on 6M points and 2.8x faster SME development [3]. Future directions include universal weak supervision for non-categorical $Y$ (ranking, regression, hyperbolic) [10], end-to-end differentiable LF learning (auto-LF synthesis [7]), and iterative CL + pseudo-labeling dynamics for semi-supervised closing of the loop. As datasets, not models, become the moat, these primitives become indispensable.
