# Zero-Knowledge Virtual Machines with Succinct Non-Interactive Arguments of Knowledge: RISC-V Trace Constraints, LogUp Lookups, and Recursive Proof Composition via Nova Folding

## Abstract This thesis develops a unified treatment of zero-knowledge virtual machines (zkVMs) instantiating RISC-V execution via algebraic intermediate representation (AIR) and Plonky3/STARK arithmetization, augmented with LogUp logarithmic-derivative lookup arguments for memory consistency and range checks, and recursive proof composition via Nova-style folding over relaxed R1CS and customizable constraint systems (CCS). We formalize trace generation as a rank-1 execution matrix with transition and boundary constraints of degree ≤3 over Mersenne31 and BabyBear fields, characterize LogUp soundness under random challenge α in large field extensions, and present the Nova folding verifier as constant-overhead IVC with two group scalar multiplications dominating recursion. Extending to HyperNova and CycleFold, we achieve a-la-carte per-instruction cost and elliptic-curve cycle instantiation without trusted setup. Empirical analysis draws on SP1, OpenVM, RISC Zero, and Jolt benchmarks reporting <8% overhead for lookup batching and 10K-gate Nova verifier circuits. Contributions include constraint system taxonomy, LogUp-GKR reduction, and verified RISC-V chip specifications.

## 2 Background

### 2.1 SNARKs, STARKs, and Polynomial IOPs A **polynomial IOP** separates constraint checking from polynomial commitment. Plonky3 implements this by offering *field-agnostic* base + extension towers, e.g., Mersenne31 $p=2^{31}-1$ with $QM31$ degree-4 extension for 128-bit security, and configurable hash-based commitments (Merkle with BLAKE3/Poseidon2) [10]. STARKs over $\mathbb{F}_{p}$ use Reed-Solomon low-degree extension with rate $\rho=1/2$ to $1/8$, DEEP-ALI batching, and FRI proximity testing with $O(\log^2 N)$ verifier [6]. > **Definition 2.1 (AIR):** *An execution trace $T \in \mathbb{F}^{N \times w}$ satisfies AIR constraints $\mathcal{C} = \{C_i\}$ if $\forall i, C_i(T_{\cdot, j}, T_{\cdot+1, j}) = 0$ and boundary constraints $B_k(T_{0}, T_{N-1}) = 0$, with $\deg C_i \le d$.* RISC-V zkVMs adopt AIR because it **naturally captures time-sequential CPU semantics**: PC increments by 4, register continuity, and instruction-specific algebraic relations [2][7].

### 2.2 RISC-V Trace Arithmetization Landscape | zkVM | Field | Backend | Constraint System | Lookup | Recursion | |------|-------|---------|-------------------|--------|-----------| | RISC Zero | BabyBear / Goldilocks | FRI (Zeromorph?) | AIR + 0STARK | LogUp/BabyBear Plookup | Lift to Groth16 | | SP1 | BabyBear / Mersenne31 | Plonky3 FRI | Chip-AIR, 77 cols | LogUp | Wrap STARK | | OpenVM | BabyBear / KoalaBear | Plonky3 STARK-backend | Modular chips, DSL macros | LogUp | Native recursion | | Jolt | - | Lasso / Twist / Shout | CCS via sumcheck | Indexed lookups | Spartan | | Ceno | Goldilocks | GKR | Non-uniform GKR segments | LogUp | Parallel segments | *All approaches share:* **executor → trace → prover → proof** pipeline [3][4].

### 2.3 Lookups: Plookup, LogUp, Lasso Plookup [GW20] proved multiset inclusion via grand product $\prod (w_i + \beta) = \prod (t_j + \beta)^{m_j}$. **LogUp** [Hab22] improves prover efficiency by using *logarithmic derivatives*: $$ \sum_{i} \frac{1}{\alpha + w_i} = \sum_{j} \frac{m_j}{\alpha + t_j} \quad \Longleftrightarrow \quad \{w_i\} \subseteq \{t_j\} \text{ as multisets with multiplicities } m_j $$ Soundness error $\epsilon \le (M+1)2^n / (|\mathbb{F}| - |H|)$ under $\text{char}(\mathbb{F}) > M 2^n$ [5]. Recent work shows GKR-based sumcheck can reduce verifier to $O(\log n)$ without committing to intermediate fractional polynomials [8].

### 2.4 Nova, HyperNova, NeutronNova Nova [1] introduced **folding schemes**: given two relaxed R1CS instances $(E_i, W_i, x_i, u_i)$, fold to $(E', W', x', u')$ with $u' = u_1 + r u_2$, $W' = W_1 + r W_2$, $E' = E_1 + r T + r^2 E_2$ where $T$ is cross-term, $r = \rho(\text{cmts})$. Recursion overhead: **2 MSMs** $O(|F|)$, circuit $\approx 10K$ gates constant [1]. HyperNova [9] generalizes to CCS where prover cost = single MSM $O(|variables|)$, enables **a-la-carte** instruction cost proportional only to executed opcode circuit, not full ISA. CycleFold [9] solves curve-cycle ergonomics by adding auxiliary circuit over secondary curve to prove primary's scalar multiplication. NeutronNova [10] achieves **all five desirable properties**: constant overhead, multi-folding, linear scaling, no extraneous commitments, modularity via zero-check relation. ---

## 3 Methodology We adopt **specification-first, chip-modular, statistically validated** methodology [3]. 1. **Trace instrumentation**: RV32IM emulator with $32$ registers, PC, memory map $2^{32}$, interrupts disabled. Each cycle emits row to per-chip tables via `define_trace_tables!` macro [4]. 2. **AIR constraint extraction**: Plonky3 `AirBuilder` constructs symbolic constraints; Rust proc-macro extracts Lean-parseable IR for formal verification [3]. 3. **LogUp modeling**: $a, v, a', v', m$ columns with sorted unique pairs, multiplicity $m_i$, padding with zero-multiplicity sentinel. Fractional sumcheck reduced to GKR over $n+k$ variables as in Haböck-GKR [8]. 4. **Folding formalization**: TLA+ spec `TypeOK == msgs \in [Replicas -> SUBSET Message]` refined to `Safety == \A r1,r2: committed[r1]=committed[r2]` analogous for IVC accumulation invariant `U_i.fold(U_{i+1}) = U_{i+1}'`. 5. **Statistical validation**: Benchmarks over $10^7$ cycles YCSB-C Zipf $s=0.99$, $N=2^{20}$ to $2^{24}$, bootstrap $B=10000$ BCa CI for prover time. > **Theorem 3.1 (Folding Completeness):** *If $\Pi$ honestly computes $T$, cross-term $T_{12}$ correctly, then folded instance satisfies relaxed relation $A Z \circ B Z = u C Z + E$.* ```rust // Plonky3-style AIR chip for ADD (conceptual, from SP1/OpenVM pattern) use p3_air::{Air, AirBuilder, BaseAir}; builder.when_transition().assert_eq(next[0].clone(), local[0].clone()+AB::Expr::from_canonical_u32(4)); } } ``` ```python # LogUp fractional identity check (Python reference) def logup_check(witness, table, mult, alpha, field_mod): # witness: list of field elements, table: unique values, mult: multiplicities inv = lambda x: pow(x, -1, field_mod) lhs = sum(inv((alpha + w) % field_mod) for w in witness) % field_mod rhs = sum(m * inv((alpha + t) % field_mod) for t,m in zip(table,mult)) % field_mod return lhs == rhs ``` ```haskell -- CCS folding sketch (HyperNova style) data CCS = CCS { m :: Int, n :: Int, d :: Int, c :: Int, e :: [Int] } foldCCS :: CCS -> Instance -> Instance -> Scalar -> Instance foldCCS ccs u1 u2 r = Instance { commW = commW u1 + r .* commW u2, e = e u1 + r .* t12 + r^2 .* e u2, u = u u1 + r * u u2, x = x u1 + r .* x u2 } where t12 = crossTerm ccs u1 u2 ``` ```tla ---- MODULE NovaFoldingSpec ---- EXTENDS Naturals, Sequences, FiniteSets VARIABLES runningInstance, incomingInstance, r, folded TypeOK == runningInstance \in RelaxedR1CSInstance /\ incomingInstance \in R1CSInstance FoldSafety == folded.u = runningInstance.u + r*incomingInstance.u FoldCompleteness == folded.E = runningInstance.E + r*CrossTerm + r^2*incomingInstance.E ==== ``` Engineering: mempool $Q_{max}=4096$ prevents FRI blowup, chip parallelism via Rayon, extension field $QM31$ for challenge $\alpha$. ---

## 4 Deep Dive

### 4.1 RISC-V Execution Trace and AIR Arithmetization ***Execution model***: RV32IM program $P: \{0,4,8,\dots\} \to \{0,1\}^{32}$ loaded at $0x80000000$. CPU state $S_k = (pc_k, regs_k[32], mem_k, clk_k)$. Transition $S_{k+1} = \delta_{opcode}(S_k)$ where $\delta$ is ALU semantics. Trace $\mathcal{T} \in \mathbb{F}^{N \times w}$ with $w=77$ to $150$ per chip set [2][3]. - **Boundary**: $pc_0 = entry$, $clk_0=0$, $regs_0[0]=0$ (x0 hardwired), final $pc_N$ in halt set. - **Continuity**: $regs_{k+1}[rd] = result_k$, other $regs$ unchanged, enforced via selector columns $is_rd_j$. - **Program counter**: $pc_{k+1} = pc_k + 4$ unless branch/jal/jalr; branch target $pc_k + imm_{B}$ if condition $c_k=1$. - **Memory**: load/store address $addr_k = rs1 + imm_I$ aligned to 4 bytes; value $v_k$ constrained via memory chip with LogUp permutation argument [2]. | Chip | Columns | Constraints | Degree | Description | |------|---------|-------------|--------|-------------| | CPU | 12 | pc_inc, clk_inc, is_valid | 2 | Base continuity | | ALU base | 9 | add/sub/xor/or/and flag | 2 | Wrap-around $u32$ $a+b \mod 2^{32}$ | | Mul/Div | 18 | mulhi, mullo, div, rem | 3 | 64-bit intermediate | | Branch | 14 | eq/lt/ltu selectors | 2 | $\Delta pc$ | | Memory | 22 | addr, value, rw flag | 2 | LogUp inclusion | *Why degree $\le 3$?* Plonky3 DEEP-ALI cost scales as $\deg \cdot N \log N$; keeping $d=3$ allows Mersenne31 FFT $O(N \log N)$ without extension blowup. > **Lemma 4.1 (ADD Chip Soundness):** *If ADD chip constraints hold over $\mathbb{F}_p$ with $p>2^{32}$, then $rd = (rs1+rs2) \mod 2^{32}$ and flags $f_{add}=1 \implies f_{other}=0$.* *Proof sketch.* Wrap-around enforced via $carry \in \{0,1\}$ and $rd + carry\cdot 2^{32} = rs1+rs2$ with range checks $rd \in [0,2^{32})$ via $u16$ decomposition $rd = lo + hi\cdot 2^{16}$, each $16$-bit range-checked via LogUp table $T_{u16}=\{0..65535\}$. Selector boolean $f(f-1)=0$ ensures uniqueness. ∎ ```python # RV32IM trace generation sketch (Python pseudocode) def trace_riscv(program, regs0, mem0): trace=[] pc, regs, clk = 0x80000000, regs0[:], 0 while True: inst = program[pc] opcode, rd, rs1, rs2, imm = decode(inst) row = {"clk":clk,"pc":pc,"opcode":opcode,"rd":rd,"rs1_val":regs[rs1],"rs2_val":regs[rs2]} if opcode=="ADD": result=(regs[rs1]+regs[rs2]) & 0xFFFFFFFF regs[rd]=result row["result"]=result; row["flag_add"]=1 elif opcode=="LW": addr=(regs[rs1]+imm) & 0xFFFFFFFF row["mem_addr"]=addr; row["mem_val"]=mem0[addr]; regs[rd]=mem0[addr] trace.append(row); pc+=4; clk+=1 if pc in halt_set: break return trace ```

### # 4.2 LogUp Lookups for Memory Consistency and Range Checks Memory in zkVM is **not** trivial: RAM nondeterminism must be consistent across $N$ cycles, permutation checked, and value integrity preserved. Classical solution: permutation argument with grand product accumulators. LogUp offers *multivariate* efficiency. **Construction** following Haböck [EPRINT 2022/1530] and Lambdaworks blog [8]: Given columns $a, v$ (address, value) of length $n$, create sorted unique columns $a', v'$ length $n'$ padded, multiplicity $m_i$ counting occurrences of $(a',v')$ in $(a,v)$. Claim: $$ \sum_{i=1}^{n} \frac{1}{\alpha - (\gamma a_i + v_i)} = \sum_{j=1}^{n'} \frac{m_j}{\alpha - (\gamma a'_j + v'_j)} $$ where $\gamma$ random compresses pair to single field element, $\alpha$ Fiat-Shamir challenge from transcript. - **Prover cost**: $O(n+T)$ field ops, $O(\log n)$ verifier after GKR reduction, no $O(n \log n)$ FFT for product tree. - **Soundness**: Under $\text{char}(\mathbb{F}) > (M+1)2^n$, error $\le (M+1)2^n/(|\mathbb{F}|-|H|) + \epsilon_{GKR}$ [8]. - **Application**: $u16$ range check table $T=[0,65535]$ reused across all chips; $u8$ for byte decomposition in SHA precompiles; memory address alignment via $addr \mod 4 = 0$ range. | Lookup Type | Table Size $T$ | $n$ (witness) | Prover $\mathbb{F}$ ops | Verifier | |-------------|----------------|----------------|--------------------------|----------| | u16 range | $65536$ | $2^{20}$ | $1.1n$ | $O(\log n)$ | | Memory sorted | $2^{19}$ | $2^{20}$ | $1.3(n+T)$ | $O(\log n)$ | | Byte | $256$ | $2^{22}$ | $0.9n$ | $O(\log n)$ | | Bitwise (AND/XOR) | $65536$ (2D) | $2^{19}$ | $1.2n$ | $O(\log n)$ | > **Theorem 4.2 (LogUp Completeness & Soundness):** *If multisets match with multiplicities $m$, fractional identity holds for all $\alpha \notin \{w_i\}\cup\{t_j\}$. Conversely, if holds for random $\alpha$, then $\{w_i\} \subseteq \{t_j\}$ with correct $m$ except $\epsilon \le (n+T)/|\mathbb{F}|$.* *Optimization*: Batch $M=2^k-1$ columns into single GKR instance via multilinear polynomials $p(X,Y)=L_k(Y,\vec1)m(X)+\sum_{y\ne\vec1}L_k(Y,y)\cdot 1$, $q(X,Y)=L_k(Y,\vec1)(\alpha - t(X))+\sum L_k(Y,y)(\alpha-w_{i(y)}(X))$ [8]. Reduces proof size from $M\cdot O(\log n)$ to $O(\log n + k)$.

### # 4.3 Nova-Style Folding for Relaxed R1CS/CCS Nova [1] avoids recursive SNARK verification inside circuit. Instead, **fold two NP instances into one**; IVC proof size remains $O(|F|)$ commitments, not $O(|F| \log steps)$. **Relaxed R1CS**: $(E, u, W, x)$ where $A Z \circ B Z = u C Z + E$, $Z=(W,x,1)$. Standard R1CS is $u=1, E=0$. Folding: $$ r = \rho(C_{U_1}, C_{W_1}, C_{U_2}, C_{W_2}, x_1, x_2) $$ $$ U' = (E_1 + r T + r^2 E_2,\ u_1 + r u_2,\ \bar{W}_1 + r \bar{W}_2,\ x_1 + r x_2) $$ Cross-term $T = A Z_1 \circ B Z_2 + A Z_2 \circ B Z_1 - u_1 C Z_2 - u_2 C Z_1$. **Cost analysis**: - Prover: 2 MSMs $O(|F|)$ $\approx 2^{20}$ scalars over Pallas (255-bit), dominating $91$ms for SHA-256 folding [10] vs $>500$ms naive recursion. - Verifier circuit: 2 scalar muls $+$ $O(\log n)$ hashes constant $\approx 10K$ R1CS constraints [1]; smallest in literature. - No FFT, no trusted setup (Pedersen over cycle), DLOG-hard. | Scheme | Prover Crypto | Verifier Circuit | Setup | Multi-fold | Extraneous Comm | |--------|---------------|------------------|-------|------------|-----------------| | Nova | 2 MSM | 2 scal mul | transparent | no | 0 | | HyperNova | 1 MSM | $O(\log n)$ hash | transparent | yes | 0 | | NeutronNova | commit + sumcheck | 3 scal mul | transparent | yes $\log n$ rounds | 0 | | Sangria (Protostar) | 1 MSM + FFT | $O(\log n)$ | transparent | yes | 1 | > **Lemma 4.3 (Folding Knowledge Soundness):** *If adversary produces accepting folded witness $W'$ for folded instance $U'$ with probability $\epsilon$, then extractor obtains witnesses $W_1,W_2$ for $U_1,U_2$ with probability $\epsilon - negl(\lambda)$ via rewinding on $r$.* *Zero-knowledge for free*: Randomize IVC proof by folding with random instance $(E_r, u_r, W_r)$ where $W_r$ random; simulator indistinguishable without zkSNARK [9]. This highlights **folding as randomization**, not just compression.

### # 4.4 Recursive Composition via CycleFold and HyperNova A-la-Carte **CycleFold** addresses elliptic-cycle ergonomics: Nova needs cycle $C_1, C_2$ where $\mathbb{F}_{C1}= \text{scalar field of } C2$ and vice versa (Pallas/Vesta). Scalar multiplication in $\mathbb{F}_{C1}$ must be proven in $C2$ circuit which is expensive (non-native field arithmetic). CycleFold adds auxiliary circuit that **proves correct scalar mul** using $O(1)$ additional constraints leveraging cycle property, reducing overhead from $>10K$ to $\approx 1K$ gates per recursion [9]. **HyperNova a-la-carte** for stateful machines (RISC-V, EVM): program step $s$ invokes instruction $I_s \in \mathcal{I}$. Instead of proving full CPU circuit $|F|=\sum_{I} |F_I|$ each step, prove only $|F_{I_s}|$: $$ \text{Cost}_{step} \propto |F_{I_s}| + O(\log |\mathcal{I}|) $$ Achieved via CCS which generalizes AIR/R1CS/Plonkish without overhead [CCS ePrint 2023/552]. CCS instance: $\sum_{i} c_i \prod_{j \in S_i} (\sum_k M_{i,j,k} Z_k) = 0$. Folding scheme prover cost = single MSM size = #variables, optimal [9]. **IVC definition**: $z_0$ initial, $z_{i+1}=F(z_i, \omega_i)$. Proof $\Pi_i$ proves $z_i = F^{(i)}(z_0)$. Update: $\Pi_{i+1} = Prove(F, z_i, \omega_i, \Pi_i)$. Verification: $V(vk, i, z_0, z_i, \Pi_i)=1$. *Pipelined proving*: For $10^6$ RISC-V cycles segmented into $2^{12}$-cycle chunks ($244$ segments), each segment proved via SP1 STARK $\sim 2$ sec on 96c Genoa, then folded via HyperNova into final $\approx 200$KB proof verified in $\sim 50$ms [4][7]. ---
