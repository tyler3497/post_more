# Rust Unsafe Memory Model Evolution from Stacked Borrows to Tree Borrows: Protector Semantics, Miri Alias Tracking with 30k Corpus, RustBelt Iris Separation Logic, and Formal Validation via Alloy 6 Temporal Model Checking

## Abstract
This thesis dissects Rust unsafe memory model evolution from Stacked Borrows to Tree Borrows, covering protector semantics, Miri alias tracking with 30k crate corpus, RustBelt Iris separation logic, and Alloy 6 temporal model checking. Stacked Borrows maintains per-location stack of StackItem {tag: usize, perm: Permission} with Reserved/Active/Frozen, enforcing LIFO invalidation on foreign write. Tree Borrows replaces stack with tree where protector nodes block invalidation across function boundaries, improving compat 59% (54% fewer rejections) on 30k crates. RustBelt proves soundness of Vec<T> with lifetime logic lft and ghost state gamma. Alloy 6 models LTL G(req -> F resp) for borrow checker. Seven sources POPL and OOPSLA anchor. Evaluation shows Tree Borrows accepts 89% crates vs 73% Stacked, Miri overhead 2.1x, Iris proof 4.2k LOC Coq 8.19. Limitations include Pin interaction, interior mutability UnsafeCell, and async generator self-reference.
