## 6 Limitations

1. **Honest majority / benevolent scheduler:** BFT n>=3f+1 assumed [1]; rational deviants degrade liveness not safety.
2. **Scope of formal model:** TLA+ checked N=4, real N=4096 requires parameterized induction [3]; not yet machine-checked.
3. **Constant-time side channels:** constant-time quaternion [3] mitigates timing, power/EM via health monitoring [6] not modeled.
4. **Learned model drift:** CDF epsilon-bound holds trained distribution; concept drift invalidates bound requiring periodic retraining O(n log n) [2][4].
5. **Hardware variance:** Loihi 2 graded spikes reduce communication [1] but need Lava toolchain; GPU portability limited.
6. **Quantum overhead:** surface code distance d=27 for 1e-12 logical error demands d^2=729 per logical plus magic factories 15x; SPARO reduces partially.
7. **Numeric stability:** CKKS 2^-40 loss per multiply; bit-exact needs TFHE PBS switching [3][4].
8. **Revocation linkability:** accumulator updates leak revocation epoch unless batched with unlinkable randomizer [2][6].
9. **VDF sequentiality assumption:** iterated squaring in unknown-order groups conjectural; parallel ASIC speedup 10-20% observed for class groups.
10. **Speculative decoding distribution shift:** draft acceptance alpha degrades Zipf tail s=1.2, fallback <=1.15x optimal worst-case.
