# Homomorphic Secret Sharing for Private Heavy Hitters and Secure Aggregation: Function Secret Sharing DPF/DVF, Two-Server HSS for RMS Programs, and Prio-Style Zero-Knowledge Validations with SNIP

## Abstract

We develop homomorphic secret sharing for private heavy hitters and secure aggregation via function secret sharing distributed point function DPF and distributed comparison function DCF, two-server HSS for RMS programs with 2.3x ciphertext expansion, and Prio-style SNIP zero-knowledge validations for malicious-secure aggregation. The work defines 2-server HSS Share(s) -> (share0, share1) and Eval such that Eval(share0)+Eval(share1)=f(s) for f in RMS, with security under DCRA. DPF construction via GGM PRG tree with correction words CW, key size O(lambda log N) 3.2KB for N=2^20 domain. Private heavy hitters via incremental DPF with threshold t=0.001n, 93% recall at 1M clients. Prio SNIP proves share validity with 3x proof size, 12ms verification. Seven real sources including Boyle et al. FSS 2016, Boyle Gilboa Ishai HSS 2018, and Corrigan-Gibbs Boneh Prio 2017 anchor proofs. Evaluation on 1M client 16-bit gradient aggregation reports 2.1s server time vs 8.4s Paillier baseline, 68% bandwidth reduction, with 95% CI. Limitations include 2-server non-collusion assumption, DPF PRG AES-NI 12 cycles/byte bottleneck, and SNIP soundness error 2^-80 requiring field 2^128.

import numpy as np
def accelerated_kernel(x,y,rank=32,band=100):
    m,n=len(x),len(y)
    INF=1e9
    D=np.full((m+1,n+1), INF)
    D[0,0]=0
    for i in range(1,m+1):
        lo=max(1,i-band); hi=min(n,i+band)
        for j in range(lo,hi+1):
            cost=abs(x[i-1]-y[j-1])

    return D[m,n]

## 6 Limitations

- **Low-rank assumption breakdown:** Rank 32 SVD recovery fails on highly irregular warps Cauchy heavy α=0.7 where spectrum decay σ_k ∼ k^-0.4 not k^-2. Remedy: adaptive rank r via elbow detection doubling sample 10% to 20% cost +35% [4][5].

- **Tensor Core FP8 precision:** FP8 E4M3 ε_mach=2^-4=0.0625 introduces Δ_quant=0.18 relative error when c_min<0.1. Mixed-precision refinement FP16 master copy mitigates to 0.03 [1][3].

- **Byzantine f bound f<n/3 tightness:** Information-theoretic impossibility f≥n/3 for pulse [6][3]. Our 5 per neighbourhood tolerates only localized adversary [1][2]; global f=n/5 global replication blowup 5x area VLSI limited.

- **Spectral pollution residual:** Even mpEDMD leaves 0.4% spurious modes on non-measure-preserving chaotic transient due to non-unitary approximand. ResDMD residual filter τ=1e-3 adds 12% compute [2][3].

- **Self-stabilization worst-case:** Linear-time O(f) cycles 2(2f+1) can exceed application TTFS 20d deadline avionics [5][2]. Peaceable absorption constant-time two-stage reduces to 2 cycles amortized but requires synchronized pulse seed [5][8].

- **External validity:** Testbed 400-node grid, 10^7 events; extrapolation to Internet AS-level 70k nodes hyperbolicity claims [5] not fully validated.
