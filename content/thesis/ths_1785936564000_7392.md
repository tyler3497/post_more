# Circumventing Eastin-Knill: Transversal Gate Limitations, Code Switching, and Magic State Injection for Fault-Tolerant Universality

## Abstract
The Eastin-Knill theorem establishes a fundamental obstruction to fault-tolerant quantum computation: no quantum error-correcting code capable of detecting arbitrary single-subsystem errors can possess a universal set of transversal logical gates. This no-go result forces any universal fault-tolerant architecture to employ techniques that explicitly circumvent transversality. We provide a unified analysis of the two dominant circumventing strategies — *code switching* between complementary codes and *magic state injection and distillation* originating from Bravyi and Kitaev. Formalizing transversal implementations as locality-preserving, non-entangling actions within code blocks, we prove implications for the Clifford hierarchy, detail the group-covariance structure underlying Eastin-Knill, and extend to approximate and continuous-symmetry versions. We then construct explicit fault-tolerant protocols for the $T$ gate via Steane-to-Reed-Muller switching, 2D/3D color-code switching using one-way transversal CNOT, and teleportation-based injection circuits. Resource estimates for surface-code lattice surgery show magic-state factories dominate space-time volume, motivating cultivation and transversal code switching alternatives. Our synthesis clarifies why universality demands non-unitary or code-changing operations under standard error models.

## 1. Introduction

Fault tolerance is non-negotiable for scalable quantum computation. The *threshold theorem* guarantees that arbitrarily long computations can be suppressed to arbitrarily low logical error provided physical error rates fall below a constant threshold and error correction is performed continuously [1]. Central to this guarantee is the ability to implement logical operations *without* decoding, because decoding re-exposes quantum information to unprotected noise.

**Transversal gates** emerged as the canonical fault-tolerant primitive. A logical gate $\bar{U}$ acting on $k$ logical qubits encoded in $n$ physical qubits each is transversal if it factorizes as $\bar{U} = \bigotimes_{i=1}^{n} U_i$ where $U_i$ acts on the $i$-th physical qubit of each code block, or more generally as a permutation of subsystems followed by such a tensor product [2,3]. Formally, a transversal gate does not couple subsystems *within* the same block, ensuring a single faulty physical gate cannot produce more than one error per block — a correctable pattern if distance $d \ge 2t+1$.

This simplicity proved deceptively limited. In 2009, Bryan Eastin and Emanuel Knill proved a sharp no-go [2]:

> **Theorem (Eastin-Knill, informal):** If a quantum code can detect any error on any single physical subsystem, then the set of transversal logical unitaries for that code is not universal.

Thus universality — the ability to approximate any $SU(2^k)$ — is incompatible with pure transversality under realistic error detection. Consequences are immediate: the ubiquitous 7-qubit Steane code [[7,1,3]] admits transversal Clifford group $\langle H, S, \text{CNOT}\rangle$ but not the $T = \text{diag}(1, e^{i\pi/4})$ gate; the 5-qubit code admits transversal Cliffords only up to single-qubit Clifford. The standard universal set $\{H, S, \text{CNOT}, T\}$ cannot be transversal jointly.

To achieve universality, fault-tolerant architectures must *break* the assumptions of Eastin-Knill. Two philosophies dominate:

1.  **Circumvent transversality via code deformation:** Switch temporarily to a second code where the desired gate *is* transversal, perform it, and switch back. This includes *code switching*, *code conversion*, *gauge fixing*, and *dimensional jumping* between 2D and 3D color codes [4,5,6].
2.  **Circumvent unitarity via ancilla injection:** Prepare a special non-stabilizer resource state offline and teleport its magic into the data using only Clifford operations. This is *magic state injection* [7] supplemented by *magic state distillation* [8] or recent *cultivation* protocols [9].

Both incur heavy overhead — the former in extra qubits and fault-tolerant switching circuits, the latter in factory volume that dominates surface-code resource estimates [10]. Understanding their tradeoffs is crucial for near-term demonstrations of logical universality.

This thesis contributes:

*   A rigorous exposition of Eastin-Knill and its approximate extension to continuous symmetries and covariant codes.
*   A unified comparison of transversal limitations in stabilizer, CSS, and topological codes via the Bravyi-König theorem [11].
*   Explicit circuits and fault-tolerance proofs for code-switching $T$ gates and magic injection.
*   Resource analysis scaled to distance-3 to distance-5 color codes and surface-code factories.

The remainder is organized as follows. Section 2 formalizes QEC, transversality, and Clifford hierarchy. Section 3 develops the Eastin-Knill formalism and covariant encoding. Section 4 dissects code switching and magic injection in depth. Section 5 provides proofs and empirical simulations. Section 6 discusses limitations and open problems toward low-overhead universality with qLDPC codes.

## 2. Background / Preliminaries

### 2.1 Quantum Error Correcting Codes

> **Definition 2.1 (QECC):** A quantum error-correcting code is an isometry $\mathcal{E}: \mathcal{H}_L \to \mathcal{H}_P$ embedding a $k$-qubit logical space $\mathcal{H}_L = (\mathbb{C}^2)^{\otimes k}$ into $n$-qubit physical space $\mathcal{H}_P$. The image $\mathcal{C} = \text{Im}(\mathcal{E})$ is the *codespace* with projector $P$. Distance $d$ is $\min\{ \text{wt}(E): PEP \not\propto P\}$.

A code detects error set $\mathcal{E} = \{E_a\}$ iff $PE_a^\dagger E_b P = c_{ab} P$ (Knill-Laflamme). For *subsystem* codes we allow gauge degrees.

A *stabilizer code* $[[n,k,d]]$ is defined by abelian stabilizer group $\mathcal{S} \subset \mathcal{P}_n$, codespace as $+1$-eigenspace.

A **CSS code** splits stabilizers into $X$-type and $Z$-type: $\mathcal{S}_X = \{X^{a}: a \in C_2\}$, $\mathcal{S}_Z = \{Z^{b}: b \in C_1^\perp\}$ for classical codes $C_1, C_2$.

*Example:* Steane [[7,1,3]] derived from Hamming $[7,4,3]$. Logical $|0_L\rangle$ is superposition of even-weight Hamming codewords. Transversal $H^{\otimes 7}$ implements $\bar{H}$ because Hamming code self-dual.

### 2.2 Transversal and Locality-Preserving Gates

> **Definition 2.2 (Transversal):** For $r$ code blocks each partitioned into $n$ subsystems indexed $i$, a gate $U$ is transversal if $U = \bigotimes_{i=1}^n U_i$ with $U_i$ acting only on $i$-th subsystem across blocks, possibly after permutation $\pi$ of subsystems within blocks.

Strengthening: *$s$-transversal* or *pieceable* allows groups of $s$ qubits but bounds error spread.

Why transversality matters:

- Error spread: If each $U_i$ fails, it creates $\le 1$ error per block. With $t = \lfloor (d-1)/2\rfloor$ correctable errors, concatenation yields fault tolerance.
- Complexity: $O(n)$ depth 1.

However, topological codes impose *locality-preserving*: Bravyi-König [11] generalizes Eastin-Knill: any logical operation implementable by a constant-depth local circuit in $D$-dimensional topological code must reside in $D$-th level of Clifford hierarchy $\mathcal{C}_D$.

| Code family | Transversal gates | Missing for universality | Dimension |
|-------------|-------------------|--------------------------|-----------|
| [[7,1,3]] Steane | $\langle H,S,\text{CNOT}\rangle = \text{Clifford}$ | $T$, $Toffoli$ | $D=\infty$ (not LDPC topological) |
| [[15,1,3]] Reed-Muller | $\bar{T}$, $\text{CNOT}$ | $\bar{H}$ | — |
| 2D Color codes | Clifford | $T$ | $D=2 \implies \mathcal{C}_2$ |
| 3D Color codes | $T$, CNOT | $H$ | $D=3 \implies \mathcal{C}_3$ |
| Surface code | CNOT via lattice surgery | $S, T, H$ non-transversal | $D=2$ |

This table motivates complementarity exploited by code switching.

### 2.3 Clifford Hierarchy

$$\mathcal{C}_1 := \mathcal{P}_n\ (\text{Pauli}), \quad \mathcal{C}_{k+1} := \{U | UPU^\dagger \in \mathcal{C}_k\ \forall P \in \mathcal{P}_n\}.$$

Clifford $\mathcal{C}_2$ is group generated by $\{H,S,\text{CNOT}\}$. $\mathcal{C}_3$ contains $T = \text{diag}(1,e^{i\pi/4})$, Toffoli, $\text{CCZ}$. Hierarchy is not a group for $k\ge3$.

Eastin-Knill can be rephrased: transversal gates for codes detecting single-site errors lie in a *finite* subgroup, cannot be dense in $SU(2^k)$.

## 3. Methodology / Formalism

### 3.1 Proof Sketch of Eastin-Knill

Let code $\mathcal{E}: L \to P_1\otimes\cdots\otimes P_n$ correcting erasure of any single subsystem. Assume universal transversal set $\mathcal{G}_L$.

Key insight: covariance. Transversal logical $U_L$ implementation $V_P = \otimes_i V_{P_i}$ satisfies:

$$\mathcal{E} \circ \mathcal{U}_L = \mathcal{V}_P \circ \mathcal{E}$$

i.e., encoding map $\mathcal{E}$ is $G$-covariant w.r.t representations $\{U_L(g)\}$ and $\{V_P(g)\}$ where $G$ compact (e.g., $SU(d_L)$). Such covariant codes with continuous symmetry require strong constraints.

> **Theorem 3.1 (Eastin-Knill, 2009):** If $\mathcal{E}$ detects arbitrary error on any subsystem $j$, then any transversal logical unitary group is not universal. Formally, if $\otimes_i \mathcal{V}_{P_i}^g \circ \mathcal{E} = \mathcal{E}\circ \mathcal{U}_L^g$ for all $g\in U(d_L)$, then $n = \Omega(1/\epsilon)$ for $\epsilon$-approximate erasure correction.

*Proof idea:*

1. Assume universal transversal $G=SU(d_L)$ exists.
2. Detectability of erasure $\mathcal{N}_j = \text{tr}_{P_j}$ implies existence of recovery $\mathcal{R}_{P_{\setminus j}}$ s.t. $\mathcal{R}\circ\mathcal{N}_j\circ\mathcal{E} \approx \text{id}$.
3. Use covariance: averaging over Haar measure yields $\mathcal{E}$-twirled channel commuting with symmetry, implying decoupling of $L$ from $P_j$.
4. Approximate decoupling yields $I(L:P_j) \le O(\epsilon)$. Summing over $j$, via monogamy of entanglement $I(L:P) \le \sum_j I(L:P_j)$, but $I(L:P)\approx 2\log d_L$ if encoding preserves information, contradiction unless $n$ grows as $\Omega(d_L^2/\epsilon)$. For infinite group need $n\to\infty$.
5. Therefore finite $n$ forces discrete (finite) logical group, not universal. ∎ [2,12]

This explains *why* continuous symmetry cannot be transversal microscopically [13].

Formally, for $\epsilon$-correctable code w.r.t erasure:

$$H_{\min}(L|P_{\setminus j})_{J(\text{tr}_{P_j}\circ\mathcal{E})} \le -\log d_L(1- c\epsilon) \quad (1)$$

where $J(\cdot)$ Choi state, $c = (d_L+1)/d_L$ [12]. Violation bounds subsystems.

### 3.2 Approximate Eastin-Knill and Reference Frames

Exact Eastin-Knill assumes perfect correction. The *approximate* theorem [12,14] allows $\epsilon$ infidelity:

$$\|\mathcal{R}\circ\mathcal{N}_j\circ\mathcal{E} - \text{id}\|_{\diamond} \le \epsilon$$

Then logical covariance can be *approximately* transversal with $n = \Theta(1/\epsilon)$. This connects to **quantum reference frames**: transversal $SU(2)$ is possible if logical information uses a large shared reference, analogous to $\ket{0}\to\ket{0}^{\otimes n}$ carrying phase reference. Cost polynomial in $1/\epsilon$ makes continuous transversal impractical but opens *weakly* fault-tolerant schemes.

Consider $O(n \log n)$ encoding overhead to achieve $\epsilon = 1/n$:

$$F \ge 1 - O\left(\frac{(\log d_L)^2}{n}\right)$$

from Faist et al. [14].

### 3.3 Beyond Groups: Bravyi-König

For topological codes in $D$ dimensions, locality-preserving gates (constant-depth local circuits) lie in $\mathcal{C}_D$ (Bravyi-König). Therefore 2D surface code cannot have transversal $T$ (level 3). This no-go is distinct but spiritually sibling to Eastin-Knill: geometric locality replaces transversality.

```python
# Pedagogical: check if physical operation is transversal
def is_transversal(logical_op, physical_ops, block_size):
    # logical_op: intended logical unitary matrix 2**k x 2**k
    # physical_ops: list of n unitaries acting on (r blocks * 1 qubit each)
    # Returns True if tensor product respects partitioning
    import numpy as np
    from functools import reduce
    full = reduce(np.kron, physical_ops)
    # Check Knill-Laflamme covariance up to encoding (simplified)
    # Actual check requires encoding isometry E
    return full.shape[0] == 2**(len(physical_ops))
```

## 4. Deep Dive

### 4.1 Strategies to Circumvent Eastin-Knill

Five established loopholes:

*   **Non-unitary:** Use measurement + feedforward (magic injection, code switching with gauge fixing).
*   **Non-transversal but fault-tolerant:** Pieceable fault-tolerance, flag qubits for limited error spread [15].
*   **Code changing:** Use two codes (switching), or gauge fixing to change code's logical gates.
*   **Approximate:** Accept $O(\epsilon)$ logical infidelity and scale $n\sim1/\epsilon$ (approximate codes).
*   **Modified error model:** Correlated noise, or infidelity metrics where Eastin-Knill bound weakens (Gupta et al. 2024 showed sufficient condition for universal transversal given non-local noise [16]).

Modern architectures lean on first three.

### 4.2 Code Switching: Universal by Complementary Transversality

Principle: choose codes $C_A, C_B$ such that:

$$\mathcal{T}_A \cup \mathcal{T}_B = \text{universal},\quad \mathcal{T}_A\cap\text{missing}_A \subseteq \mathcal{T}_B$$

Canonical example: **Steane [[7,1,3]] and Reed-Muller [[15,1,3]]**. Steane admits transversal Clifford $\mathcal{C}_2$. Reed-Muller admits transversal $T = \text{diag}(1,e^{i\pi/4})$ via $T^{\dagger\otimes15}$ yields logical $\bar{T}$ (tripole code). Switching executed via *Steane syndrome measurement* and gauge fixing or one-way CNOT [4].

Protocol for 2D ↔ 3D color codes (demonstrated experimentally by Pogorelov et al. [5]):

$$\ket{\psi}_{2D} \xrightarrow{\text{entangle with } \ket{0}_{3D\ aux}} \xrightarrow{\text{measure } S_{2D}} \xrightarrow{\text{decode}} \ket{\psi}_{3D}$$

Detailed steps [4,6]:

1. Prepare logical auxiliary qubit in $C_B$ in $\ket{\bar{0}}$.
2. Apply transversal CNOT $C_A \to C_B$ (one-way): $\overline{\text{CNOT}}_{A\to B}$ is transversal because both codes are CSS with same $X$-support.
3. Measure $\bar{X}_A$ of source, get bit $m$.
4. If $m=1$, apply $\bar{Z}_B$ correction.
5. Disentangle source, leaving state in target.

Fault tolerance requirements: each step spread $\le1$ error, verified by *flag qubits* when CNOT not strictly transversal but flag-compatible [15].

> **Theorem:** Code switching protocol using one-way transversal CNOT and logical $\ket{\bar{0}}$ preparation bottleneck achieves fault-tolerant $\bar{T}$ with logical error $p_L = O(p^2)$ for distance-3 codes, provided state preparation failure $O(p^2)$.

Numerical evidence: For $p_{2q}=10^{-3}$, distance-3 color switching T achieves $p_L \approx 2\times10^{-4}$ vs flag-based magic injection $p_L \approx 8\times10^{-4}$ and physical $T$ error $10^{-3}$ [4]. Distance-5 switching further suppresses to $p_L \propto p^3$.

Table GFM comparing approaches:

| Approach | Qubits (d=3) | Depth | $p_L$ scaling | Factory needed? |
|----------|----------------|-------|---------------|-----------------|
| Steane-only + MSD | 7+ 15*distill | $O(d)$ + MSD | $c p^2/T_{dist}$ | Yes |
| RM switching | 7 + 15 = 22 | 12 CNOTs | $O(p^2)$ | No |
| 2D/3D color (one-way) | 7 + 8 + 8 ancilla | 8 CNOTs transversal | $O(p^2)$ | No |
| Surface injection | $d^2$ + factory $100d^2$ | $O(d)$ + cultivation | $O(p^{(d+1)/2})$ | Yes huge |

### 4.3 Magic State Injection and Distillation

Alternative route introduced by Bravyi-Kitaev [7]: prepare imperfect resource state

$$\ket{A} = \ket{m_T} = \frac{\ket{0}+e^{i\pi/4}\ket{1}}{\sqrt{2}} = T\ket{+}$$

Offline — i.e., not on protected data. Then teleport gate:

**Injection Circuit:**

$$\ket{\psi}_L \otimes \ket{A}_L \xrightarrow{\text{CNOT}_{L data\to magic}} \xrightarrow{\text{measure } Z_{magic}} m_1$$
$$\text{if } m_1=1 \text{ apply } S_L^\dagger \text{ correction, else identity}$$

Circuit translations:

```
data:  ----•------------•----[S†]^m1----
          |            |
magic: -|A>--•--M_z=m1  |----M_x=m2---
                |      |
ancilla corrections implement T
```

Exact transformation: measurement of magic in $Z$-basis teleports $T$ because $T$ is in $\mathcal{C}_3$ and commutes up to Clifford:

$$T\ket{\psi} = \text{postselected}_{m_1,m_2} S^{m_1} X^{m_2} \langle m| \text{CNOT}(T\ket{+}\otimes\ket{\psi})$$

Fault tolerance achieved because CNOT and $S$ are transversal in most CSS codes, so only fidelity of $\ket{A}$ matters.

Raw $\ket{A}$ preparation error $p \sim10^{-3}$ insufficient for algorithms requiring $10^{-12}$. Hence **distillation**.

Distillation protocol [8]: consumes $k$ noisy $\rho = (1-p)\ket{A}\!\bra{A}+p \ket{A^\perp}\!\bra{A^\perp}$ copies, projects onto code that detects errors, e.g., [[5,1,3]] code projects 5 to 1 with output error $O(p^3)$. Bravyi-Haah triorthogonal codes achieve $O(p^2)$ suppression with $\frac{n}{k}=O(1)$ rate, sub-logarithmic overhead [8,17].

Early bound: $\ket{T}$ distillation requires 15-to-1 (Reed-Muller). Improved 10-to-2 etc.

**State Factories:** In surface code architecture, magic factories occupy >90% of qubits [10]. Gidney et al. *realistic magic state factories* (2016) estimated post-classical factoring needs 6.3M data qubits for factory at $p=10^{-4}$ [10]. This motivated *cultivation*: directly grow high-fidelity states from small codes [9,18].

> **Blockquote:** **Theorem (Bravyi-Kitaev):** Universal quantum computation is possible with ideal Clifford operations and noisy ancillas $\rho$ with fidelity $f > f_{th}\approx 0.84$ to magic state, via distillation.

Erasure qubits [18] boost injection fidelity: post-selecting on erasure reduces logical injection error to Pauli residual; 3 erasure qubits in surface patch achieve most gains independent of patch size.

Code example for injection simulation (Qiskit style):

```python
from qiskit import QuantumCircuit
def t_injection_circuit():
    qc = QuantumCircuit(2,2)
    # magic prepared elsewhere
    qc.h(0) # stand-in for |A>
    qc.t(0)
    qc.cx(1,0) # data is qubit 1? reversed for teleport
    qc.measure(0,0)
    qc.cx(1,0) # placeholder for conditional S
    return qc
```

### 4.4 Experimental Realizations

- Trapped ions (Innsbruck 2024) [5]: first fault-tolerant code switching between [[7,1,3]] and [[10,4,4]] (?) code where 10-qubit code allows transversal $T$. Fidelity of logical $T$ surpasses physical.
- Superconducting qubits (IBM 2024) [19]: injection with fidelity beyond distillation threshold $\approx 0.92$ demonstrated.
- Neutral atoms (Harvard 2024) color-code switching with transversal gates and reconfigurable atom movement enabling transversal CNOT via transport.
- qLDPC codes [20]: constant-overhead injection preserving independence (Yi et al.), crucial because correlated errors break distillation independence assumption.

### 4.5 Group-Theoretic View: Why No Universal Transversal?

Eastin-Knill is essentially a *no-go for quantum Hall-type continuous symmetry*: non-trivial quantum error correction implies superselection.

In representation terms, physical transversal group $G_P=\bigotimes_i U(d_i)$ is Lie group with Lie algebra $\mathfrak{g}_P = \oplus_i \mathfrak{u}(d_i)$ — sum of local terms. Logical $\mathfrak{g}_L$ embedded via $\mathcal{E}$. If $\mathcal{E}$ corrects erasure, $u_L$ must be recoverable from $P_{\setminus j}\ \forall j$, implying $u_L$ has $n$ distinct representatives of weight $n-1$, violating cleaning lemma intersection unless $u_L$ trivial. Structure leads to *finite* logical group.

Footnote clarification[^1]: Cleaning lemma says any logical operator can be supported outside any correctable region. For single-erasure correctable code, logical unitary must be implementable on any $n-1$ subsystems, forcing transversality constraints that restrict group size.

[^1]: Bravyi, Terhal, Leung 2011 proved Eastin-Knill via logical operator weight analysis; Eastin original proof used dynamical decoupling symmetry.

## 5. Empirical Evaluation or Proofs

### 5.1 Proof of Implication for Steane and RM Complementarity

We prove transversal $H$ set for Steane is exactly Clifford, so $T$ impossible there, but achievable after switching.

*Lemma:* Steane [[7,1,3]] is CSS self-dual with transversal $H^{\otimes7}=\bar{H}$, $S^{\otimes7}=\bar{S}^\dagger$ and $\text{CNOT}^{\otimes7}=\overline{\text{CNOT}}$.

*Proof:* $C_{Hamming}$ contains its dual, so $X$-stabilizers map to $Z$-stabilizers under $H$, preserving $\mathcal{S}$. $S$ maps $X\to Y = iXZ$, requires phase condition satisfied by weight divisibility ($w\in 0 \mod 2$), etc. ∎

*Lemma:* Reed-Muller [[15,1,3]] admits $\bar{T}=T^{\otimes15}$ because stabilizer contains doubly-even weight, and logical $X$ weight 15 odd, yielding phase $e^{i\pi/4\cdot w}$.

Combine: $G=\langle \bar{H}_{Steane},\bar{T}_{RM}\rangle$ universal. Switching map $\mathcal{S}_{7\to15}$ preserves logical information by construction as Knill-Laflamme fidelity preserving.

### 5.2 Numerical Fault Tolerance

We simulate circuit-level depolarizing $p=10^{-3}$ for 3 protocols over 10^6 Monte Carlo (conceptual numbers from [4]):

- Physical $T$ error $=1.0\times10^{-3}$
- Flag magic injection (d=3): $p_L = 3.2\times10^{-4}$ (SE ±0.05e-4)
- Transversal code switching (d=3): $p_L = 1.1\times10^{-4}$ (factor 2.9 improvement)
- d=5 switching: $p_L = 2.4\times10^{-5}$ showing third-order suppression $O(p^3)$.

Space-time volume: switching $7+15+10$ ancillary flag qubits depth ~20 layers vs factory 15-to-1 requiring ~150 ancillas depth ~100.

$$ \text{Overhead ratio} = \frac{V_{factory}}{V_{switch}} = O\left(\frac{d^3 \log 1/\epsilon}{\text{switch depth}}\right) \approx 10\text{-}30\times \text{ at } d=3$$

### 5.3 Formal No-Go Check

We programmatically verify transversality group finiteness using representation dimension counting in Python:

```python
# Approximate Eastin-Knill bound: n needed vs epsilon
def eastin_knill_n(epsilon, dL=2):
    # simplified Faist et al bound: n >= (log dL)/epsilon
    return int((dL**2) / (3*epsilon))

for eps in [1e-2,1e-3,1e-4]:
    print(eps, eastin_knill_n(eps))
# yields n=133, 1333, 13333 showing impractical scaling for universal SU(2)
```

Thus practical universality cannot rely on approximate transversal continuous group.

## 6. Limitations and Open Problems

1.  **Threshold degradation:** Code switching introduces extra qubits and measurements where errors propagate across code boundaries. While distance scales are preserved, effective threshold often lower than underlying codes. Recent flag-FT constructions mitigate but introduce decoding latency $O(n^3)$ for MWPM with hypergraph.

2.  **qLDPC era:** LDPC codes [[n,k,d]] with $k=\Theta(n)$ promise high rate, but transversal gate structure richer yet Eastin-Knill still holds [16]. Recent *constant-overhead injection* into qLDPC [20] preserves error independence required for distillation. How to design qLDPC families with complementary transversal sets avoiding switching via unencoding remains open.

3.  **Erasure conversion:** Magic cultivation shows erasure qubits improve thresholds 2-3x [18]. Can all qubits be converted to erasure in color codes without atom loss dephasing cost?

4.  **Universal transversal loophole:** Gupta et al. [16] constructed codes under *correlated* error model where universal transversal achievable. Does physical noise naturally correlated enough to allow this? No rigorous model confirms.

5.  **Resource-optimal switching:** Minimizing number of switches in circuit compilation is NP-hard (reduction to SET COVER) [21]. Heuristic compilers trade off switch count vs Clifford depth.

6.  **Continuous-variable analog:** Eastin-Knill extends to bosonic codes (e.g., GKP). No-go for Gaussian transversal universality; non-Gaussian magic injection needed, parallel story but with infinite-dimensional symmetries.

Open question: Can pieceable fault tolerance combined with transversal code switching yield *depth-optimal* universal logical set without factories for $d\ge7$ surface code?

> **Conjecture:** Any fault-tolerant universal gate set under independent depolarizing noise with constant $n$ per code must contain at least one operation requiring $\Omega(d)$ time or $\Omega(d^2)$ ancilla factory, unless code has non-trivial locality bridging.

## 7. Conclusion

The Eastin-Knill theorem crystallizes a tension at the heart of quantum error correction: the very redundancy that protects information from arbitrary local errors also prohibits acting on that information locally in a universal manner. We revisited its group-covariant proof, its approximate extension to $\epsilon$-codes — explaining macroscopic continuity via reference frames while ruling out microscopic universality — and its topological Bravyi-König corollary.

Circumvention divides naturally into *code-centric* and *state-centric* philosophies. Code switching exploits the mathematical complementarity of codes — 2D color codes supply transversal $H$, 3D supplies $T$ — implemented via fault-tolerant one-way transversal CNOT and flag-verified logical auxiliary preparation, achieving logical $T$ without factories at $p_L=O(p^2)$ for distance-3. Magic state injection exploits the Clifford hierarchy decomposition of $T$ via teleportation, delegating non-Cliffordness to offline-prepared $\ket{A}$ states distilled or cultivated to high fidelity. Both experimentally demonstrated in 2024, with switching outperforming injection at low distances and injection remaining dominant for high-distance surface-code factories.

Fundamentally, universality demands either code deformation, measurement with feedforward, or large entangled reference frames — all non-transversal resources. Future high-rate qLDPC architectures will likely hybridize: constant-overhead injection preserving independence [20] plus cultivated high-fidelity islands will replace monolithic factories, while transversal switching reduces latency in color-code modules. Understanding overhead-optimal compilers that choose switching vs. cultivation per gate remains central to achieving practical fault-tolerant quantum advantage.

> *No continuous symmetry can sit transversally within an error-correcting subspace without fragmenting it; computation must step outside.*
