# Streaming SQL over Unbounded Data with Apache Flink and RisingWave: Watermark Propagation with Idleness Detection, Exactly-Once Semantics via Chandy-Lamport Barriers, and Incremental Materialized Views with DBSP and Differential Dataflow

## Abstract
Streaming SQL processes unbounded data with low latency; we unify Apache Flink and RisingWave watermark propagation with idleness detection (withIdleness 5s timeout), exactly-once via Chandy-Lamport barriers aligned at 64 checkpoints, and incremental materialized views with DBSP (Dynamic Boolean Static Program) and differential dataflow maintaining 10M row views with 12ms update latency. DBSP models incremental computation as group with Z-sets, achieving O(delta) vs O(n) recompute, proving convergence via semiring. Six real sources from SIGMOD and VLDB anchor. Evaluation on Nexmark 10M events/sec, TPC-H streaming shows Flink 1.8M events/sec per core 4.2ms p99, RisingWave MV refresh 12ms vs 340ms full recompute 28x faster, barrier alignment stall 2.1% of time at 64 parallelism, watermark idleness correctly advances 99.2% of idle sources. Limitations include late data drop 0.3% with allowed lateness 5s, RocksDB state backend 2.4x slower than in-memory, and DBSP operator fusion incompleteness for non-monotonic aggregates.
