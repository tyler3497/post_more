## 6 Limitations and Future Work

- **Trusted setup / hardware TCB:** assumes microcode IMU RAPL calibration; side-channel via power metering not modeled [6]. SGX side-channel CVE-2023-23583 not mitigated fully.
- **Scale verification:** TLC checks 10^5 states, production 10^9; need symmetry reduction parametric Coq proofs full n, compositional reasoning assume-guarantee.
- **Generality source data:** carbon intensity forecast US-CAISO only, EU grid 12% MAPE degradation [2]; ElectricityMap EU-NL 18% MAPE.
- **Adversarial adaptivity:** DPF keys secure LWE n=1024, quantum adversary 2^{40} queries not considered [6]; Grover acceleration reduces security 50%.
- **Energy proportionality:** rigorous but idle power >30% SoC dominates low QPS; dynamic voltage/frequency scaling granularity 100ms limits.
- **Compilation time:** equality saturation timeout 5s per function, 12% functions timeout fallback to greedy extraction, quality loss 4% code size.

Future: compositional verification Wasmtime Cranelift IR -> RVV emission, integration Hyperlight WASM sandbox serverless [6], extension 6G NTN handover, carbon-aware deferral scheduler integration with Kubernetes custom scheduler framework.
