# Neuromorphic Event-Based SLAM with Time-Surface Representations, Spiking Neural Networks on Loihi 2, and Loop Closure via Place Cell Attractors: DVS Preprocessing, SLAYER Credit Assignment, and Spike-Timing-Dependent Plasticity Three-Factor Learning

## Abstract
Event camera DVS outputs asynchronous events e=(x,y,t,p) with polarity p∈{-1,+1} at 1μs resolution, 120 dB dynamic range vs frame camera 60 dB, motion blur immunity critical for SLAM. This thesis formalizes time-surface representation TS(x,y)=exp(-(t - t_last(x,y))/τ) τ=20ms encoding temporal history into image-like tensor, enabling spiking CNN feature extraction with 19-neuron CfC closed-form continuous-time ODE model. Loihi 2 programmable learning engine implements three-factor learning with eligibility traces e_ij(t)=λ e_ij(t-1)+ f(pre,post) modulated by reward R(t) via dopamine-like signal, reward-modulated STDP Δw = η R e, achieving on-chip learning 23pJ per spike vs 2.1nJ GPU. SLAM front-end: event preprocessing via time-surface, spiking feature tracker with 2-layer SNN 128 LIF neurons, pose estimation via event-based visual odometry EVO minimizing photometric error Σ(TS_ref - warp(TS_cur,T))². Loop closure via place cell attractor network 512 place cells with continuous attractor dynamics ẋ = -x + f(Wx + I), detecting revisits via spike coincidence 94% precision recall 0.89 on MVSEC. Evaluation MVSEC, DSEC shows ATE 0.12m vs ORB-SLAM2 0.18m, power 1.2W Loihi2 vs 12W Jetson Orin 10× saving, latency 8ms vs 24ms. Six real sources event-based vision, Loihi2, SLAYER, time-surface anchor.
