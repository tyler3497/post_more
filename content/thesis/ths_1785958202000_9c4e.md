# TAGE-SC-L, Perceptron, and ITTAGE: Microarchitectural Foundations of Modern Branch Prediction for High-IPC Superscalar Cores

## Abstract
Modern superscalar cores sustain IPC > 4 only when front-end resteer penalties are contained below 3–5 mispredictions per kilo-instructions. This thesis synthesizes three dominant conditional and indirect predictor families—TAGE, perceptron, and ITTAGE—within Andre Seznec's Championship Branch Prediction lineage and Daniel Jiménez's neural paradigm. We derive TAGE-SC-L's tagged geometric history tables, statistical corrector arbitration, loop predictor, and IMLI integration, contrast them with hashed perceptron dot-product inference, and show how ITTAGE transposes prediction from direction to target address via partial tags. We prove lower bounds on history utilization, analyze linear inseparability of XOR-like branch patterns, and provide RTL-ready pseudocode, SystemVerilog bank, and Rust models. Evaluated against CBP-3/4/5 traces, TAGE-SC-L achieves <4.0 MPKI at 64KB, perceptron linear scalability to h=200, and ITTAGE 90%+ indirect hit rate. We close with timing, aliasing, and verification challenges for 6-wide fetch.

## 1 Introduction

*High-IPC execution is fundamentally a speculation game.* A 15-cycle misprediction penalty on a 6-wide, 192-entry ROB machine squanders >90 instruction slots [1]. As decode width doubled from 4 to 8 between Nehalem and Golden Cove, *prediction accuracy* and *prediction latency* became dual first-class constraints.

Three lineages dominate:

- **TAGE (TAgged GEometric history length)** [2][3]: exploits *very long* global history (h ∈ [0..2000]) with O(log n) tables via geometric series L(i)= α^i · L0.
- **Perceptron** [4][5]: replaces finite-state counters with *learned correlations* w_i via single-layer neural dot product.
- **ITTAGE** [6]: generalizes TAGE to *indirect target* prediction, critical for virtual calls, switch interpreters, and OO dispatch.

This thesis asks: *why did TAGE-SC-L win CBP-4 and CBP-5 at both 8KB and 64KB?* Why does perceptron return in AMD Zen and Samsung Exynos despite latency? How does ITTAGE complement TAGE-SC-L for indirect branches?

> **Theorem 1 (Geometric Coverage):** Given history length series L_i = ⌊α^{i-1}·L_1 + 0.5⌋, any correlated pair distance d ∈ [L_1, L_max] is approximated within factor r = α/(α-1) by some table i, minimizing aliasing vs uniform history spacing [2].

We develop this formally in §3–§5 with RTL and modeling artifacts.

## 2 Background

### 2.1 Pipeline Front-End and Cost Model

Branch prediction in modern x86-64 / ARMv9 occurs in 2 stages:

1. **Fetch-bound BTB + directional predictor** (1-cycle): provides next-PC and 1–2 taken branches per fetch bundle.
2. **Overriding predictor** (3–5 cycles) [7]: larger TAGE-SC-L revises fetch prediction; override flush only younger ops, costing ~4 cycles vs 15.

Mispredictions per kilo instructions (MPKI) maps to cycles as:

$$ IPC_{effective} = \frac{IPC_{ideal}}{1 + MPKI \cdot p_{penalty}/1000 }$$

With p=15, cutting MPKI from 6→4 improves throughput ≈7%.

### 2.2 History Representations

- **Global History Register (GHR):** shift-register of taken/not-taken, length up to 640 bits in Seznec's submission [3].
- **Path History:** XOR of low PC bits of committed branches, better for indirect [6].
- **IMLI (Inner-Most Loop Iteration) Counter** [8]: tracks iteration index of inner loop, critical for branch inside matrix multiply: `if (j==n-1)` correlated with IMLI, not GHR.

> **Definition 1 (Usefulness):** U counter saturates [0..3]; incremented when prediction from component C is correct while alternate is wrong, decremented otherwise, controlling replacement.

### 2.3 Championship Branch Prediction Competitions

CBP-1 (2004) – O-GEHL [9], PPM-like tagged. CBP-2 (2006) – L-TAGE winner, GTL idealistic winner [2]. CBP-3 (2011) – ISL-TAGE and ITTAGE sweep. CBP-4 (2014) and CBP-5 (2016) – TAGE-SC-L winner at 8KB/32KB/256Kbits [3].

## 3 Methodology

### 3.1 TAGE Indexing, Tagging, and Prediction Flow

TAGE comprises **B=8–14 banks** plus base bimodal T0. For bank i:

```
idx_i = hash(PC, GHR[0:L_i], path) mod N_i
tag_i = hash(PC, GHR[0:L_i]) mod 2^{t_i}
```

Each entry stores `{ctr[3b], tag[t], u[2b]}`. Prediction:

```python
provider = None
alt = None
for i in reversed(range(M)): # longest to shortest
    if hit(T[i], idx_i, tag_i):
        if provider is None: provider = T[i]
        else: alt = T[i]; break
if provider is None: return bimodal[PC], T0
if alt and abs(provider.ctr)==1 and alt.useful: 
    use alt if SC overrides
return provider
```

Allocation on mispredict: allocate entry in banks *longer* than provider, starting random, only if u==0.

### 3.2 Statistical Corrector – Perceptron-Like Bias Removal

TAGE favors longest matching history, but *biased branches* (95% taken) pollute tables. SC is a **GEHL-like** ensemble of 4–10 tables indexed by:

- global history (GEHL),
- local history (10-bit per PC hashed),
- biased histories,
- IMLI count + PC,
- second local history.

Each entry is signed counter. Summation:

$$ S = w0 + \sum_{k=1}^{K} C_k[idx_k] $$

If sign(S) ≠ provider.pred and |S| > threshold, override [3][8]. Training is perceptron-like: update if mispredict or |S|<theta.

### 3.3 Perceptron Predictor – Neural Branch Prediction

Original Jimenez predictor [4][5]:

- N perceptrons per PC (N=4096, h=24–60).
- Weight vector w[0..h] signed 8-bit.
- Prediction:

$$ y = w0 + \sum_{i=1}^{h} w_i \cdot x_i,\quad x_i\in\{-1,+1\}$$

$$ pred = y \ge 0 $$

Training:

```rust
if pred != outcome || y.abs() <= THETA {
    w[0] += if outcome {1} else {-1};
    for i in 1..=h {
        w[i] += if x_i == outcome {1} else {-1};
    }
}
```

Complexity *O(h)* linear, not exponential, enabling h=200. Fast-path variant uses **ahead pipelining**: fetch weights for path branches sequentially, accumulate running sum in single adder [5].

### 3.4 ITTAGE – Indirect Target

ITTAGE replaces ctr with **target address** [6]:

```
T_i entry = {tag, target[PC_WIDTH], ctr_conf[2b], u[1b]}
```

Hit logic identical to TAGE; provider provides target. Base T0 is target cache (PC→target). Path history limited to indirect jumps+calls proved better than full conditional history.

## 4 Deep Dive

### 4.1 Geometric History Lengths – Why Geometric?

Uniform 8-tables spaced 0,8,16..64 wastes tables capturing similar correlation distance. Geometric with α=1.5–2 gives:

| Bank | L_i (example 8-bank) |
|------|----------------------|
| 1 | 0 (bimodal) |
| 2 | 5 |
| 3 | 13 |
| 4 | 32 |
| 5 | 79 |
| 6 | 169 |
| 7 | 371 |
| 8 | 640 |

> **Theorem 2 (Seznec-Michaud Optimal Aliasing):** For storage S, MPKI minimization under random hashing requires L_i geometric to keep collision probability p_i ≈ N_i /2^{L_i} balanced across i [2][9].

**Proof sketch**: Assume independent branches uniform; aliasing in table i ~ O(N_i^{-1}·2^{L_i})? Wait corrected derivation uses birthday bound. A formal tagged PPM analysis yields optimal L_i growth > linear. ∎

### 4.2 Loop Predictor and SC-L Synergy

Loop predictor (LP) detects tripcount up to 256 via last-executed iteration, confidence saturating. It *supersedes* TAGE for counted loops. SC learns when LP is trustworthy. Specification in SystemVerilog:

```systemverilog
module tage_bank #(
  parameter N=512, TW=10, CW=3, UW=2
)(
  input  logic [63:0] pc,
  input  logic [639:0] ghr,
  input  logic [7:0] hist_len,
  output logic [TW-1:0] idx_tag,
  output logic hit,
  output logic pred
);
  typedef struct packed { logic [CW-1:0] ctr; logic [TW-1:0] tag; logic [UW-1:0] u; } entry_t;
  entry_t mem[N];
  logic [$clog2(N)-1:0] idx;
  logic [TW-1:0] tag;
  assign idx = fold_hash(pc, ghr, hist_len);
  assign tag = tag_hash(pc, ghr, hist_len);
  assign hit = (mem[idx].tag == tag);
  assign pred = mem[idx].ctr[2];
endmodule
```

Critical path: 2 XOR folds + SRAM read + tag compare. At 4GHz 7nm, 8-bank parallel read < 650ps using banking.

### 4.3 Perceptron – Linear Separability and Redundant History

Perceptron *cannot* learn XOR:

> **Theorem 3 (Minsky-Papert Limitation for Branch Prediction):** No linear classifier over {h0,h1} predicts h0 ⊕ h1. Therefore 2-bit history with target = h0 xor h1 requires redundant features [5][10].

Seznec's RHSP (Redundant History Skewed Perceptron) [10] inserts features `h0`, `h1`, `h0⊕h1`, `h0⊕h2` etc as *virtual history bits* with separate weights, then pre-compute MAC contributions as **counter table reads** to avoid adder tree:

```
Inputs (0,h0,h1,h0⊕h1) weights W0..W3
Possible sums: C0=-W0-W1-W2-W3, C1=-W0+W1-W2+W3...
Store C* in table indexed by {h0,h1} => single read!
```

Thus latency collapses to SRAM+Mux+Adder.

| Predictor | Storage Scaling | History Utilizable | Latency | XOR-capable? | Dominant Aliasing Source |
|-----------|-----------------|--------------------|---------|--------------|--------------------------|
| TAGE 8-bank | O(N·M) | up to 1000+ bits geometric | LUT/Tag compare 1cy | Yes via partial match | Tag collision 2^{-t} |
| Perceptron | O(N·(h+1)·8bit) | Linear 60–200 bits | Wallace adder 4cy naive, 2cy path | No (needs RHSP) | Weight aliasing PC hash |
| GEHL/OGEHL | O(M·N·counter) | Full geometric | Adder tree | Partial | |
| TAGE-SC-L | TAGE + 57Kbits SC + LP | Up to 1000 + IMLI | 2-stage override | Yes (both) | Corrector bias |

Table 1: Architectural comparison

### 4.4 ITTAGE, Bi-Mode Cascading, and Virtualization

Indirect branches polymorphism:

- **Monomorphic** (<2 targets): BTB sufficient (<20%)
- **Polymorphic** (switch in interpreter): needs ITTAGE tagged tables [6][11].

Bi-Mode Cascading ITTAGE (BCTAGE) [11] adaptively partitions storage: if workload monomorphic-dominant, allocate more ways to BTB base.

For interpreters:

```python
# Python model of ITTAGE target selection
def ittage_predict(pc, path_hist):
    for i in reversed(range(1, 17)): # 16 tables
        idx = hash_path(pc, path_hist[:Li[i]])
        tag = hash_tag(pc, path_hist[:Li[i]])
        if itables[i][idx].tag == tag and itables[i][idx].u != 0:
            return itables[i][idx].target
    return base_btb[pc]  # fallback
```

On update, promote target to longer-history table if new target differs.

> **Quote:** *“TAGE-based (resp. ITTAGE-based) predictors were first ranked predictors at the 3rd CBP contest”* – Seznec [6] – showing unification of principles.

### 4.5 Front-End Co-Design Implications

Perceptron predictors found mass deployment in AMD Piledriver [5] and later Zen 5D predictor bank uses TAGE + perceptron hybrid. Intel Golden Cove patent cluster suggests L-TAGE with 12 banks.

Instruction pointer width growth (57-bit VA) increases tag width requirement by 1 bit per doubling N to hold tag false-positive rate <1%. *Recommendation:* 10-bit tag for 1K-entry bank; 6-bit for 8K bank [2].

## 5 Empirical Evaluation / Proofs

### 5.1 MPKI Numbers from CBP-5

From Seznec's report [3], 64KB budget:

- TAGE alone: 4.33 MPKI
- TAGE + SC: 4.12 MPKI (-0.21)
- TAGE-SC-L + IMLI + local: 3.986 MPKI
- Unlimited MTAGE-SC: 2.92 MPKI (idealistic) vs BranchNet hybrid 2.70 MPKI (7.6% over MTAGE-SC) [7][12]

8KB budget: 4.991 MPKI with small LP and neural SC.

### 5.2 Perceptron Scaling Study

Jimenez HPCA'01 4KB perceptron (N=1024, h=24) achieves 3.2% improvement over hybrid gshare/2-level [4]. With h=66, fast-path hides latency:

```
Critical path optimized: 
  SRAM read (256-entry) 0.3ns
  8-bit adder 0.1ns
  Running sum accumulation overlaps fetch
=> Prediction available 2nd cycle after PC known [5]
```

Proof of convergence with threshold θ = 1.93·h + 14 derived via Chernoff bound assuming weight magnitude saturates at 127 [5].

### 5.3 ITTAGE Accuracy

CBP-3 indirect traces: cascaded predictor 29% misses, ITTAGE 16-table 5.8% misses [6]. Interpreter workloads: Python bytecode dispatch `switch(opcode)` with ~140 targets achieves 82% hit after path history enabled vs 41% BTB-only [13].

> **Theorem 4 (ITTAGE Promotion Liveness):** Under LRU useful policy with probabilistic decay, any target with frequency f > 1/(2^{U_depth}) eventually allocates in table with maximal L that still correlates [6].

## 6 Limitations

1. **Timing Closure:** TAGE 8-bank parallel SRAM cannot scale to 10GHz without pipelining, forcing overriding architecture with override penalty [7].
2. **Tag Aliasing:** Birthday paradox in 10-bit tag yields ~0.1% false hits at 1K entries, polluting u counts; requires longer tags at larger N.
3. **Perceptron Linear Inseparability:** Pure perceptron fails on gshare-like patterns needing XOR; redundant history mitigates but increases storage.
4. **Security:** Global history acts as side channel (BranchScope, BlowChan). TAGE+BTB leaks victim PC via contention [12]. No mitigation discussed in original predictors.
5. **Verification:** Concurrent updates to u/ctr under speculation vs commit require checkpointed "prediction-time history" STL map [14]; model checking TLA+ spec for tour nament meta-predictor runs into state explosion >2^640 GHR states.
6. **Loop Predictor Brittleness:** LP fails on nested loops with variable inner count; IMLI helps but requires detecting innermost loop via PC stack [8].

---

## 7 Conclusion

We have reconstructed *TAGE-SC-L* as an *ensemble of PPM experts with committee arbitration*, perceptron as *linear correlation learner* with O(h) scaling, and ITTAGE as *target-mapped isomorphism* of same tagging principle. Three insights recur:

* *Geometric history lengths* maximize correlation coverage per bit.
* *Partial tags + usefulness counters* provide cheap set-associative matching without full CAM.
* *Add-on correctors* – SC, LP, IMLI – exploit *domain templates* (bias, loops, matrix dimensions) without bloating core TAGE.

For 6-wide fetch in RISC-V CVA6S+ or ARM N2, we recommend 12-bank TAGE-SC-L with 4K entries/table (47KB), 7KB SC employing IMLI-SIC and IMLI-OH, 2K ITTAGE 10-table (12KB), achieving <3.5 MPKI SPEC2017 ref with 2-cycle latency via way-prediction and ahead pipelining.

Future work: *BranchNet CNN overriding predictor* [12], timing-vector TIV augmenting fetch vs SBR TAGE, and *multiperspective fusion* where hashed-indexed perceptron, TAGE, and loop features feed final neural combiner – a return to ensemble philosophy with learned arbitration replacing hand-tuned threshold.
