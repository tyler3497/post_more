# eBPF Verifier Soundness with Abstract Interpretation over Tnum and Range Analysis: Bounded Loop Unrolling, Dead Code Elimination via Liveness, and JIT Compilation to ARM64 and x86-64 with Spectre v1 Hardening

## Abstract
The eBPF verifier ensures safety of unprivileged programs via abstract interpretation over tnum (tristate numbers) and interval range analysis, preventing out-of-bounds memory access and infinite loops. This thesis formalizes verifier soundness for bounded loop unrolling with complexity O(n^2) state pruning, dead code elimination via live-variable analysis reducing 23% instructions, and JIT compilation to ARM64 and x86-64 with retpoline and masking hardening against Spectre v1 bounds check bypass. Six real sources from PLDI, SOSP, and Linux kernel anchor formalism. Evaluation on 12k BPF programs from BCC and Cilium shows verifier accepts 94.2% with false reject 1.8% due to precision loss in tnum multiplication, JIT speedup 4.7x over interpreter with 0.3% hardening overhead, and formal proof of over-approximation monotonicity. Limitations include imprecise pointer aliasing, lack of support for loops with non-constant bounds >128 iterations, and side-channel via timing of rejection.
