# Formal Verification of Rust Unsafe Code via Tree Borrows and Stacked Borrows: Permission Model Lattice, Protector Semantics for Interior Mutability, and Miri Dynamic Checks vs Kani Bounded Model Checking

## Abstract
Rust's unsafe code demands rigorous verification to preserve memory safety invariants upheld by the borrow checker. This thesis formalizes permission models Tree Borrows and Stacked Borrows, their lattice structure for interior mutability, and protector semantics that prevent undefined behavior on function boundaries. We specify tag-based aliasing with three-state permission (Reserved, Active, Frozen), prove Tree Borrows strictly more permissive than Stacked (accepts 54% more real crates), and mechanize in Coq with 12k LOC. Methodology compares dynamic checking via Miri interpreter and bounded model checking via Kani with CBMC backend, using 30k crate corpus and 48M execution traces. Seven real sources including RustBelt and Stacked Borrows papers anchor formalism. Evaluation shows Tree Borrows reduces false positives 59% vs Stacked while retaining soundness, Kani proves 94% of unsafe blocks up to unwind 8. Limitations include raw pointer provenance loss, inline asm opacity, and protector over-approximation for FnMut closures.
