## 3 Methodology

Comparing syntactic theories by generative capacity requires a disciplined methodology, since it is easy to confuse a formalism's notation with its power.

- **Weak-capacity comparison.** We ask which string languages a formalism can generate, using closure properties (CFLs are closed under intersection with regular languages, homomorphism, and inverse homomorphism), pumping lemmas, and Ogden-style arguments. A non-membership proof typically intersects the target language with a well-chosen regular filter to isolate a known non-context-free kernel — exactly Shieber's strategy [2].
- **Strong-capacity comparison.** We ask which tree languages a formalism generates, since two formalisms may agree on strings while assigning systematically different structures. Vijay-Shanker, Weir, and Joshi showed that the MCS formalisms also converge on large fragments of their tree languages, though not completely [4].
- **Complexity analysis.** We measure the worst-case time complexity of the *universal recognition problem* (given grammar and string, is the string generated?) and the *fixed-grammar recognition problem* (given a fixed grammar, decide membership). Only the latter is linguistically relevant: the grammar is the speaker's fixed competence.
- **Learnability analysis.** We ask which classes of languages are identifiable from positive data in Gold's limit paradigm [7], and how additional biases — the subset principle, distributional cues, architectural inductive biases — shrink the hypothesis space. Behavioral probing with minimal pairs extends this methodology to neural models [8].

Throughout, the competence hypothesis is treated as an idealization: grammars generate infinite languages, while speakers produce finite samples under memory and time bounds. The idealization is justified only insofar as it predicts the *shape* of the possible — which dependencies occur, which never do.

## 4 Deep Dive

### 4.1 The Swiss German argument, reconstructed

Shieber's proof is a model of how little linguistics a strong formal result needs [2]. Let *L* be the string language of Swiss German. Consider the regular language *R* consisting of strings of the form

`Jan säit das mer (d'chind)* (em Hans)* hænd wele (laa)* (hälfe)* aastriiche`

where the starred items may repeat arbitrarily. Because CFLs are closed under intersection with regular languages, *L ∩ R* would be context-free if *L* were. But case-marking facts about Swiss German verbs force *L ∩ R* to be exactly the strings

`Jan säit das mer (d'chind)^i (em Hans)^j hænd wele (laa)^i (hälfe)^j aastriiche`

for arbitrary *i, j*: the number of accusative-selecting *laa* verbs must equal the number of accusative noun phrases, and likewise for dative *hälfe*, because each verb's case requirement must be discharged and each noun phrase must receive case from exactly one verb. Homomorphically erasing the fixed prefix, suffix, and the invariant verbs maps this language onto *a^i b^j c^i d^j*, a textbook non-context-free language (it contains the copy pattern).

![Cross-serial dependency diagram for Swiss German](sandbox://workspace/post_more/public/thesis/ths_1789374697000_05286-2.webp)

The same reasoning generalizes: any construction enforcing unbounded *k*-way cross-serial matching pushes a language outside the CFLs, while remaining inside the MCS class, which is closed under exactly such bounded copying.

### 4.2 Tree-adjoining grammars and the convergence of formalisms

A tree-adjoining grammar factors derivation into two tree-combining operations. *Initial trees* encode basic predicate-argument structures with substitution nodes (marked ↓) at the frontier; *auxiliary trees* encode recursion, with a root and a *foot* node (marked \*) carrying the same label. *Substitution* plugs an initial tree into a frontier node; *adjunction* splices an auxiliary tree into an interior node, splitting the target tree around the adjoined material.

![TAG adjunction derivation diagram](sandbox://workspace/post_more/public/thesis/ths_1789374697000_05286-0.webp)

Recognition for TAG is polynomial: a CKY-style chart parser over tree nodes runs in O(n^6) time and O(n^4) space, since adjunction requires tracking four string positions (the yield of the auxiliary tree wraps around the yield of the adjunction site). The landmark equivalence result of Vijay-Shanker and Weir established that TAG, CCG, LCFRS, and linear indexed grammars generate the *same* class of string languages — the tree-adjoining languages — despite arising from entirely different linguistic motivations (phrase-structure extension, categorial combinators, tuple rewriting, and stack discipline respectively) [4].

![Chomsky hierarchy and the mildly context-sensitive band](sandbox://workspace/post_more/public/thesis/ths_1789374697000_05286-1.webp)

The table below summarizes the landscape.

| Formalism | String class | Fixed-grammar recognition | Characteristic mechanism |
|---|---|---|---|
| Context-free grammar | CFL | O(n^3) | Single-string rewriting |
| Tree-adjoining grammar | TAL (MCS) | O(n^6) | Adjunction of auxiliary trees |
| Combinatory categorial grammar | TAL (MCS) | O(n^6) | Function application and composition |
| LCFRS / MCFG | MCFL (MCS) | O(n^{3f}), fan-out *f* | Tuple rewriting, no copying |
| Minimalist grammar | MCFL (MCS) | Polynomial (bounded features) | Feature-driven merge and move |

### 4.3 Minimalist grammars: merge, move, and the Shortest Move Condition

Stabler's minimalist grammars recast Chomsky's Minimalist Program as a precisely defined mildly context-sensitive formalism [5]. A minimalist grammar is a finite lexicon of *feature-annotated* items. Features come in four kinds: base categories (e.g. `D`, `V`), selectors (e.g. `=D`), licensors (e.g. `+wh`), and licensees (e.g. `-wh`). Two structure-building operations consume them:

- **merge**: if one expression begins with the selector `=f` and another begins with the base feature `f`, they combine into a binary tree and both features are checked and deleted.
- **move**: if an expression begins with the licensor `+k` and contains exactly one maximal subtree beginning with the matching licensee `-k`, that subtree relocates to a specifier position and both features are deleted.

The *Shortest Move Condition* (SMC) — at most one accessible licensee of each type per derivation step — is the engine of mild context-sensitivity: it bounds the number of "moving" components any constituent can carry, which is exactly what keeps the formalism inside the MCFG-definable class rather than exploding into full context-sensitivity [5]. The following Haskell sketch encodes the core calculus:

```haskell
-- Feature inventory of a Stabler-style minimalist grammar
data Feat = Base String    -- category features: D, V, C, ...
          | Sel  String    -- selectors: =D, =V, ...
          | Lic  String    -- licensors: +wh, +case, ...
          | Lee  String    -- licensees: -wh, -case, ...
          deriving (Eq, Show)

-- Expressions are lexical items or the results of merge / move
data Expr = Lex String [Feat]
          | Merge Expr Expr
          | Move Expr
          deriving Show

-- merge checks a selector =f against a base feature f
merge :: Expr -> Expr -> Maybe Expr
merge e1 e2 = case (headFeat e1, headFeat e2) of
  (Just (Sel f), Just (Base g)) | f == g -> Just (Merge e1 e2)
  (Just (Base g), Just (Sel f)) | f == g -> Just (Merge e2 e1)
  _                                      -> Nothing
  where
    headFeat (Lex _ (f : _)) = Just f
    headFeat _               = Nothing

-- A derivation succeeds when every feature has been checked
derives :: Expr -> Bool
derives (Lex _ [])  = True
derives (Lex _ _ )  = False
derives (Merge a b) = derives a && derives b
derives (Move a)    = derives a
```

![Minimalist grammar merge and move schematic](sandbox://workspace/post_more/public/thesis/ths_1789374697000_05286-3.webp)

Move is what buys the extra power beyond context-freeness: a constituent can be pronounced in one position while being interpreted in another, and the SMC bounds how many such displaced constituents can be simultaneously "in flight." Stabler showed that this resource sensitivity yields efficient incremental recognition procedures, and his later work gives two explicit models of incremental syntactic analysis — top-down and left-corner — with precise complexity bounds, connecting the competence formalism to processing [6].

### 4.4 Parsing complexity and the constant-growth property

The MCS hypothesis is falsifiable as a *processing* claim: it predicts that no natural-language construction requires super-polynomial recognition. The O(n^6) TAG bound is the canonical witness, and it is tight in the worst case. A schematic chart parser for the tuple-rewriting core (fan-out 2, which covers TAG) illustrates why four string indices suffice:

```python
# Schematic O(n^6) chart recognizer for a fan-out-2 MCFG (the TAG core).
# A nonterminal A derives a pair of spans ((i,j), (k,l)); rules combine
# spans by concatenation without copying variables (Seki et al. 1991).
def recognize(rules, start, words):
    n = len(words)
    # chart[A] holds derived span-pairs for nonterminal A
    chart = {A: set() for A in nonterms(rules)}
    # initialize lexical rules: A -> (w,) covering span (i, i+1)
    for i, w in enumerate(words):
        for (A, rhs) in lexical(rules, w):
            chart[A].add(((i, i + 1), (i, i + 1)))
    # combine binary rules until fixpoint; each combination tries
    # O(n^4) span placements, and there are O(n^2) pairs: O(n^6)
    changed = True
    while changed:
        changed = False
        for (A, B, C, combine) in binary(rules):
            for sb in chart[B]:
                for sc in chart[C]:
                    for sp in combine(sb, sc):   # concatenation of spans
                        if sp not in chart[A]:
                            chart[A].add(sp)
                            changed = True
    return any(spans_cover(sp, n) for sp in chart[start])
```

The *constant-growth property* is the MCS class's combinatorial signature: in any infinite MCFL, string lengths increase by bounded steps. This follows from the pumping lemma for MCFGs proved by Seki and colleagues — every sufficiently long string in an *m*-MCFG language contains a pumpable block whose removal or iteration stays in the language, with the pumped material drawn from at most *2m* bounded regions [3].

## 5 Empirical/Proofs

> **Theorem** (Shieber 1985). The string language of Swiss German is not context-free [2].

> **Proof sketch.** Suppose Swiss German were context-free. Intersect with the regular filter isolating iterated cross-serial verb clusters, as in Section 4.1; CFLs are closed under this intersection. Case-marking forces the intersection to equal the language of strings with matched accusative and dative counts, whose homomorphic image is *a^i b^j c^i d^j*. That language violates the CFL pumping lemma (pumping the *a*-block destroys the *a*–*c* match). Contradiction. ∎

> **Theorem** (Seki et al. 1991). Every *m*-multiple context-free language is *2m*-iterative: all but finitely many strings admit a pumpable decomposition into at most *2m* bounded blocks [3].

> **Proof sketch.** By induction on MCFG derivations: a derivation tree of sufficient height contains a repeated nonterminal on some path (pigeonhole principle over the finite nonterminal inventory); excising or iterating the segment between the two occurrences pumps at most the tuple components of that nonterminal — at most *2m* blocks — while preserving derivability, since MCFG rules neither copy nor delete variables. ∎

> **Theorem** (Vijay-Shanker & Weir 1994). TAG, CCG, LCFRS, and linear indexed grammars are weakly equivalent: they generate exactly the tree-adjoining languages [4].

The proof proceeds by effective grammar transformations in both directions (e.g., compiling TAG adjunction into LCFRS tuple rules and simulating LCFRS derivations by TAG derivations), establishing mutual weak inclusion. The equivalence is *weak*: the formalisms assign different derivation structures, so the result does not settle strong-capacity questions.

### Learnability: from Gold to minimal-pair probing

Generative capacity constrains not only parsing but *acquisition*. Gold proved that no computable learner identifies an arbitrary computably enumerable language class from positive data alone in the limit — any superfinite class containing all finite languages and at least one infinite language is unlearnable [7]. The classic linguistic response is that the hypothesis space is *not* arbitrary: universal grammar restricts learners to a small class (the subset principle), and the MCS hypothesis can be read as a precise proposal about the size of that space.

Large language models reopen the question empirically. Trained only on positive data with a next-token objective, they acquire substantial syntactic competence — subject-verb agreement across attractors, filler-gap dependencies, island sensitivity — without any explicit grammar.

1. **The vindication reading.** LLMs show that positive-data learning of MCS-class grammars is feasible with the right inductive biases (attention, depth, scale), dissolving the poverty-of-the-stimulus argument as an in-principle claim while leaving it as a claim about *which* biases children use.
2. **The competence–performance reading.** LLM probability judgments conflate grammaticality with frequency and plausibility; above-chance minimal-pair performance does not entail that the model *represents* an MCS grammar, any more than a finite-state approximant's success on short sentences entails finite-state competence.

Stabler's incremental models [6] sharpen the second reading: human parsing is not just recognition but *incremental structure building under the SMC*, and a model's fit to human processing must be evaluated against those derivational predictions, not only against acceptability judgments. The MCS research program thus sets the agenda for neural linguistics: the target of explanation is not raw accuracy but the *class* of generalizations a learner draws from finite data.

## 6 Limitations

The competence idealization that makes these theorems possible is also their chief limitation.

- **Weak capacity is coarse.** Weak equivalence classes lump together grammars with radically different structures and processing profiles. TAG and MG agree on strings but disagree on whether displacement is tree-splicing or feature-driven movement, and psycholinguistic evidence must decide between them [5][6].
- **Unboundedness is stipulated, not observed.** Every non-context-freeness proof assumes unbounded embedding depth, but corpora contain only finite depths and speakers fail beyond depth three or four. If performance bounds are built into competence, the empirical need for MCS power weakens — though the *absence* of certain patterns (no language with truly arbitrary permutations) still demands explanation.
- **The SMC is a strong idealization.** Derivational minimalism's mild context-sensitivity depends on the Shortest Move Condition bounding simultaneously moving constituents [5]. Relaxations of the SMC (multiple accessible licensees, remnant movement) push MGs toward greater power, and the exact boundary of the empirically needed fragment remains open.
- **LLMs are not grammar inducers in the formal sense.** Minimal-pair benchmarks [8] measure behavioral correlates of grammaticality, not represented grammars; a model can pass agreement paradigms with heuristic shortcuts. Formal learning theory [7] reminds us that identifiability is a property of *classes and presentations*, not of single trained models.
- **Beyond strings.** The entire MCS program concerns the mapping from sound to meaning via syntactic structure. Phenomena at the interfaces — ellipsis, scope, information structure — may require formal power beyond MCS even if the string language stays inside it.

## 7 Conclusion

The arc from Chomsky's hierarchy [1] through Shieber's Swiss German proof [2] to the mildly context-sensitive convergence [3][4] is a rare case of a philosophical question — *what kind of object is a possible human language?* — receiving a mathematical answer that survived contact with linguistic detail. The answer is strikingly specific: properly above context-free, closed under bounded copying, parsable in polynomial time, and realizable by feature-driven merge and move under the Shortest Move Condition [5][6]. That four formalisms with different intellectual origins coincide on this class suggests it is a natural kind, not an artifact of notation.

The frontier is now learnability. Gold's unlearnability results [7] framed the poverty-of-the-stimulus debate for half a century; large language models, probed by minimal-pair benchmarks [8], are running the largest positive-data learning experiment in history. Whether their syntactic generalizations coincide with the MCS class — constant growth, bounded crossing, polynomial recognition — is an empirical question that the formal theory is uniquely equipped to ask. The competence hypothesis endures not as a description of any current model, but as the yardstick against which all models of language learning must eventually be measured.
