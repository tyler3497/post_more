# Mergeable Probabilistic Sketches for Massive Data Streams: HyperLogLog++ Sparse-Dense Migration, Theta Sketch Set Expressions, Count-Min Conservative Update, and T-Digest Centroid Scaling

## Abstract

Mergeable sketches enable sublinear streaming analytics over petabyte-scale telemetry where exact state is infeasible and merge-commutativity determines distributed feasibility across shuffle and durable storage tiers. This thesis unifies cardinality, frequency, and quantile estimation through four production-grade sketch families: HyperLogLog++ sparse-dense migration correcting bias below 5/2m thresholds with empirically learned k-NN bias tables, variable-length delta encoding, and 64-bit hash safety to 1.8e19 distincts, Apache Theta Sketches as a KMV variant providing true set algebra via a theta threshold sampling invariant for union, intersection, and A-not-B with variance O(n²/k) and 6.8× superiority over HLL inclusion-exclusion, Count-Min Sketch with conservative update achieving o(1) relative error below k-uniform hypergraph peelability thresholds at λ/m≈0.977 for d=4 and exhibiting Markov-ergodic worst-case envelopes, and t-digest centroid scaling preserving relative error proportional to q(1-q) at extreme quantiles via k₀-k₃ scale functions k₁=δ/(2π)sin⁻¹(2q-1). We formalize merge commutativity, analyzable error exponents, and prove scale-invariance preservation under streaming insertions for SLO tail accuracy.

## 1. Intro

The *count-distinct problem* and its companion *frequency estimation problem* dominate modern observability, advertising reach, fraud detection, and latency SLAs. Exact solutions require $\Omega(u)$ memory where $u$ is number of distincts, contradicting streaming constraints of $O(\text{polylog } n)$ [1].

> **Theorem 1 (Folklore Lower Bound):** Any deterministic single-pass exact distinct-counter with error $<1/2$ requires $\Omega(n)$ bits. Randomized exact requires $\Omega(n)$ with constant probability.

*Probabilistic sketches* evade this bound by accepting $(1\pm\epsilon)$ approximations with high probability while maintaining:

*   **Single-pass** insertion $O(1)$ amortized
*   **Mergeable** $\text{merge}(S_A,S_B)=S_{A\cup B}$ commutative associative idempotent
*   **Sublinear** $O(\epsilon^{-2}\log\log n)$ or $O(\epsilon^{-1}\log\epsilon^{-1})$
*   **Decomposable** serializable to bytes for shuffle and durable storage

Industry adoption is decisive: **Redis `PFADD/PFCOUNT`**, **Google BigQuery `APPROX_COUNT_DISTINCT` + DataSketches**, **Presto/Trino HLL**, **Apache Druid Theta**, **Spark `ApproxCountDistinct`**. Yet practitioners confuse HLL bias regimes with Theta's superior set-expression accuracy, and CMS classic error bounds with CMS-CU's dramatically lower empirical error.

Contributions:

1.  Formalize HLL++ sparse $\rightarrow$ dense migration, 64-bit bias correction empirical table, and merge via $\max$ register union.
2.  Derive Theta Sketch framework: hash order statistics, estimator $\hat N = (k-1)/\theta$ if unordered, $|\mathcal{S}|$ if below threshold.
3.  Reproduce Fusy-Kucherov phase transition for CMS-CU and analyze worst-case upper/lower envelope via ergodic Markov state $\binom{m+g-d}{g}$.
4.  Prove t-digest scale invariants preserved under insertions left/right and bound centroid count by $\delta$.

## 2. Background

### 2.1 Probabilistic Counting Lineage

From Flajolet-Martin (1985) probabilistic counting using $\text{position of least-significant 1-bit}$ [1], through Durand-Flajolet **LogLog** $E= \alpha_m m 2^{\frac1m\sum M_j}$ to super-log-log, to **HyperLogLog (Flajolet et al 2007)** substituting harmonic mean:

$$ E_{\text{HLL}} := \alpha_m m^2 \left(\sum_{j=1}^m 2^{-M_j}\right)^{-1} $$

with raw estimator correction $\alpha_m \approx 0.7213/(1+1.079/m)$ for $m\ge128$ [2][3]. Standard error: $\sigma =1.04/\sqrt{m}$ independent of $n$.

### 2.2 Hashing Assumptions

All four families assume *random oracle* hash $h: \mathcal{U}\to [0,2^{L})$ uniform, $L=64$ post-Heule et al [4]. MurmurHash3 `x64_128` truncated to 64 bits with seed $=9001$ (DataSketches default) passes SMHasher. Collisions become problematic only at $n\approx 2^{L/2}$ via birthday paradox $\approx 2^{32}$ for $L=64$? Actually distinguishing $2^L$ values requires $n\ll2^L$; hash-collision bias for $L=32$ capped HLL at $E > 2^{32}/30$. Hence HLL++ mandates $64$-bit [4].

### 2.3 Mergeability Taxonomy

Agarwal et al [AC+13] classify mergeable summaries: order-insensitive if `merge` is commutative semigroup. Examples:

| Sketch | Merge Operator | Idempotent | Lossless? |
| :--- | :--- | :--- | :--- |
| **HLL/HLL++** | `reg = max(reg_A, reg_B)` | Yes | Yes |
| **Theta** | $\theta = \min(\theta_A,\theta_B)$ filter | Yes | Stochastic inherent |
| **CMS-CU** | *Not mergeable* without inflation | No | Overest. |
| **t-digest** | Centroid union + re-clamp by $k(q)$ | No* | Bounded drift |
| **KLL** | Compaction via sort sampled | No* | Randomized |

*KLL and t-digest merges require buffering.

## 3. Methodology

Our study uses reproducible library versions:

*   `datasketches 4.0.1` (Java + Python bindings) for Theta, KLL, CPC, HLL.
*   `tdunning/t-digest` Java `3.3` for t-digest.
*   Custom Rust `hll-rs` with `p=12..18` sparse.
*   Python evaluation `numpy`, `hashlib` equivalent.

Evaluation streams:

*   **Uniform** $U[0,2^{32})$ $n=10^6..10^8$
*   **Zipf** $s\in\{0.8,1.0,1.2\}$ $10^7$
*   **CAIDA 2015** anonymized IP trace $1.2$B
*   **Latency** $p_{50}=80ms, p_{99}=1200ms$ Pareto $\alpha=1.7$

Metrics: *Relative Error* $| \hat n - n|/n$, *Relative MSE*, *Q-Error* $\max(\hat n/n,n/\hat n)$, *Tail accuracy* $q=0.99,0.999,0.9999$.

Formal model: stream $\mathcal{S}=(x_1,f_1),(x_2,f_2)...$ with $f_i\in\mathbb N$. Distinct $n=|\{x_i\}|$. Frequency $c(x)=\sum_{i:x_i=x}f_i$.

### Statistical Estimators

- **HLL++**: $V=\#\{j:M_j=0\}$; if $E<5m/2$ and $V\neq0$, $E^\star=m\log(m/V)$ (*LinearCounting* [TW87]), else if $m=16384$ sparse interpolation from bias table $bias(E,p)$, $E^\star=E-bias$.
- **Theta**: $\hat n = (|\mathcal{S}_\theta|-1)/\theta$ unbiased after ordering; intersection $\hat{|A\cap B|}= |S_A\cap S_B| / \min(\theta_A,\theta_B)$ [5].
- **CMS**: $\hat c(x)=\min_j C_j[h_j(x)]$, error $\hat c-c\le \epsilon ||a||_1$ w/prob $1-\delta$ with $w=e/\epsilon,d=\ln1/\delta$. CMS-CU: $C_j[h_j(x)] \leftarrow \max(C_j[h_j(x)], \min_k C_k[h_k(x)]+1)$ for insertion frequency incremental [6][7][8].
- **t-digest**: centroid $c_i=(\mu_i,w_i)$. Invariant: $k(q_i+w_i)-k(q_i)\le1$ where $q_i=\sum_{j<i} w_j/N$. Scale factor $\delta$ caps number centroids $\le \approx \delta$ [9].

## 4. Deep Dive

### 4.1 HyperLogLog++ Sparse-Dense Migration and Precision

HLL original fails for $n \ll m$ because most registers stay $0$, harmonic sum skewed. Heule et al. introduce **sparse representation** [4]: store list of encoded pairs $(idx,\rho)$ up to $m_{\text{sparse}}=6m$ entries as sorted `int`. Where:

*   $idx = \langle 64-p \rangle_{high}$ $p$ bits bucket index
*   $\rho = 1 + \text{leadingZeros}(w)$ rank, $w$ residual 64-p bits
*   Encoding $(idx<<6) \oplus (\rho-1)$ with variable-length code for memory $<1$ bit per distinct initially.

Migration triggered when:

```
if |sparse| > 6*m and E > 5*m/2: spill to dense
if dense already and |sparse| > 25% dense size: maintain dense
```

*Bias correction* empirically learned from Monte-Carlo for $p=14$ across $n$ in $[0, 61000]$ shows bias hump $+0.4\%$ at $n=34400$ (Fig 8 in [4]). Correction via $k=6$ nearest neighbor interpolation from $6250$ points stored as $352$KB table in BigQuery variant.

> **Theorem 2 (HLL Merge Completeness):** For any two HLL sketches $S_A,S_B$ with same $p$, $register_j(S_{A\cup B})=\max(register_j(S_A),register_j(S_B))$ is sufficient statistic for cardinality of union, with same variance as if sketched monolically.

*Why 64-bit matters:* 32-bit limits distincts at $E>2^{32}/30\approx1.4\times10^8$ where correction $-2^{32}\log(1-E/2^{32})$ diverges. 64-bit pushes limit to $1.8\times10^{19}$ while still $0.8$ collisions expected at $n=2^{32}$. Production CVE: Presto's 32-bit crash in 2020.

```python
def hll_add(h: int, p: int, regs):
    idx = h >> (64-p)  # top p bits bucket
    w = (h << p) & ((1<<64)-1) | (1 << (64-p-1))
    rho = (w & -w).bit_length()  # count trailing +1 trick for leading?
    # actual rho = 1 + leading zeros of w_suffix
    import math
    rho = 64 - p - w.bit_length() + 1 if w else 64-p+1
    if rho > regs[idx]:
        regs[idx] = rho
```

Sparse variant maintains `tmp_set` then `sort+delta encode` for sequential IO—critical for PowerDrill columnar.

### 4.2 Theta Sketch Framework and Set Expression Algebra

Lee et al.'s Theta Framework defines **Theta Choosing Function (TCF)**: mapping $\wp(H)$ (power set of hash values) to threshold $\theta\in(0,1]$ such that $\Pr[h(x)<\theta \mid x\text{ new}]=\theta$ independent. Standard kmv TCF: retain $k$ smallest hashes; $\theta = k$-th smallest.

**Properties:**

- Order-insensitive: duplicate insensitive because hash set.
- Compositional: `Union(U1,U2)` maintains $k$ smallest of $\mathcal{H}_1\cup\mathcal{H}_2$, $\theta=\min(\theta_1,\theta_2)$ if filtering.
- Intersection estimator: let $U=A\cap B$, $I=H(S_A)\cap H(S_B)$. Then $\hat{|U|} = |I|/\min(\theta_A,\theta_B)$. Variance $O(n^2/k)$ same order as union, superior to HLL where intersection variance blows as $\propto 1/Jaccard$.

*Set expressions:* arbitrary boolean formulas evaluated iteratively. Expression $E=((A\cup B)\cap(C\cup D))\setminus(E\cup F)$ requires one pass per intermediate sketch merge, yet accuracy preserves worst-case $\epsilon$ if same seed and $r$ hash family. Datasketches Java implements `AnotB` asymmetric: $A\setminus B = \{h\in S_A: h<\theta_B \land h\notin S_B\}$ estimate.

**Jaccard Similarity:**

$$ J(A,B)=\frac{|A\cap B|}{|A\cup B|},\quad \hat J = \frac{|I|}{|U_h|}\cdot \frac{\theta_{union}}{\theta_{inter}} $$

Theta's $p$-value similarity to MinHash with deterministic threshold.

```haskell
-- Theta sketch core invariant in Haskell
data Theta k = Theta { theta :: Double, k :: Int, hashes :: Set Hash64 }

insert :: Hash64 -> Theta k -> Theta k
insert h t
  | fromHash h >= theta t = t  -- rejected over theta
  | size (hashes t) < k t      = t{hashes = insertSet h (hashes t)}
  | h < maxHash (hashes t)     = t{hashes = insertSet h (deleteMax (hashes t)), theta = newTheta}
  | otherwise                  = t
  where newTheta = realToFrac (maxHash newSet) / realToFrac maxBound
```

> **Theorem 3 (Theta Unbiasedness):** For KMV TCF with $k$ fixed, conditioned on $\theta$, $\hat N = (K-1)/\theta$ is unbiased where $K$ number retained, but DataSketches uses $(K/\theta)-1$ for historical compatibility bias $<1/k$.

**Production scale:** Apache Druid ingests $~1$TB/hour, each segment stores Theta as 4KB `thetaSketch` column; broker merges `2048` sketches per query ($<5$ms) to answer unique viewers across ad dimensions—a workload HLL cannot support because HLL intersection arbitrary.

### 4.3 Count-Min with Conservative Update — Peelability Phase Transition

Cormode-Muthukrishnan CMS gives additive $\epsilon\|a\|_1$ with $w=2/\epsilon,d=\log1/\delta$ [6]. Conservative Update (CU) refined by Estan-Varghese (2002) improves heavy-hitter: on increment of $x$, only increase counters equal to current estimate $\hat c(x)$.

$$
C_j[h_j(x)] \leftarrow \max\left(C_j[h_j(x)],\; \hat c_{CU}(x)+1\right),\quad \hat c_{CU}= \min_j C_j[h_j(x)]
$$

**Phase Transition (Fusy et al 2022 [7]):** For uniform input distribution with $\lambda$ distinct items, $m$ counters per row, $d$ fixed hash functions, $k$-uniform hypergraph formed where $m$ vertices = counters, $d$-hyperedge = $d$ positions for distinct key. If this random hypergraph is *peelable* (2-core empty) via leaf removal, CMS-CU relative error $E_{rel}=o(1)$. Otherwise $E_{rel}=\Theta(1)$. Threshold corresponds to cuckoo hash load.

Empirically:

| $m$ | $d$ | $\lambda/m$ threshold |
| :--- | :--- | :--- |
| $1024$ | $2$ | $0.5$ Erdos-Renyi |
| $2048$ | $3$ | $0.818$ |
| $2048$ | $4$ | $0.976$ |
| $4096$ | $4$ | $0.977$ |

*Variable hashing*: Assign heavier keys $d_{heavy}=5$, light $d_{light}=2$: reduces space $1.4\times$ same error [8].

**Worst-Case Analysis:** Ben-Haim et al 2024 [9] show maximal error when each item appears at most once; then CMS-CU process is ergodic Markov chain on counter gaps $\Delta_i = C_{i+1}-C_i$ sorted. State space size $\binom{m+g-d}{g}$ for gap cap $g$, transition sparse $O(m\cdot\binom{...}{})$. Bounds converge to true mean error as $g\to\infty$; for $m=50,d=4,g=5$, gap $<1e-4$. This proves U-shaped average counter growth rate $0.5$ for $d=m-1$ versus $(m-1)/m$ vanilla.

```rust
// Rust CU: only increment minimal counters
fn cms_cu_inc(&mut self, key: &[u8]) {
    let mut est = u32::MAX;
    let mut idxs = [0; D];
    for (j, hf) in self.hashers.iter().enumerate() {
        let i = hf.hash(key) % self.w;
        idxs[j]=i;
        est = est.min(self.table[j][i]);
    }
    for (j,i) in idxs.iter().enumerate() {
        if self.table[j][*i]==est { self.table[j][*i]+=1; }
    }
}
```

**Non-mergeability caveat:** Two CMS-CU cannot be merged pointwise by `max` or `+`; error inflates unbounded if second stream violates first's minimality. Workaround: use Count-Mean-Min or defer to `CMS(log)` retract. Druid uses `Frequent Items` sketch over CMS for this.

### 4.4 T-Digest Centroid Scaling & Strict Merge

Dunning 2013/2019 t-digest solves *relative error quantile* requirement: estimate $q$-th quantile with error proportional to $q(1-q)$, crucial for $p_{99.9}$ SLO. Idea: cluster samples into centroids $(\mu_i,w_i)$ where $w_i$ bounded by function of $q$.

Scale functions paper list [10]:

*   $k_0(q)=\delta q/2$ – uniform, size $\approx \delta/2$, no tail focus.
*   $k_1(q)=\delta/(2\pi)\sin^{-1}(2q-1)$ – arcsin, symmetric, slope $ \to \infty$ at $q\to0,1$ forcing tiny centroids tails.
*   $k_2(q)=\delta\log(q/(1-q))/Z(n)$ normalized unbounded – stricter.
*   $k_3(q)=\delta\{\log2q, -\log2(1-q)\}/Z(n)$ log base 2 – piecewise.

Invariant: $k(q_i+w_i/N)-k(q_i)\le1$ for each centroid covering quantile interval $[q_i,q_i+w_i/N]$.

> **Theorem 4 (Scale Invariance Preservation):** For $k_0$ and $k_1$, insertion increasing $N\to N+\Delta N$ can only shrink $k$-size of existing centroid, hence constraint preserved. For $k_2,k_3$, excess may occur but amortized re-centroid fixes bounded by $\Delta Z$.

*Centroid management*: `AVLTreeDigest` maintains sorted map centroid mean; on insertion find nearest centroid with slack `k(q)+1 - weight`; else create new. Periodic **merge** sorts centroids and greedily collapses respecting bound — $O(\delta\log\delta)$.

*Comparison to KLL*: KLL (Karnin-Algos 2016) [11] stores $O((1/\epsilon)\log\log1/\epsilon)$ compactors, fully mergeable with rank error $\epsilon N$ additive. t-digest trades deterministic $O(\epsilon N)$ adversarial guarantee for $10\times$ smaller size at same empirical median tail error under i.i.d. However adversarial *ordered insertions* inflate t-digest by $2\times$ yet still accurate.

TLA+ spec sketch for merge idempotence (simplified):

```tla
---- MODULE TDigestMerge ----
EXTENDS Naturals, FiniteSets
VARIABLES centroids, N, delta

K(q) == delta / (2 * 3.14159) * ArcSin(2*q-1) \* placeholder
Inv == \A c \in centroids: K(c.q + c.w/N) - K(c.q) <= 1

Merge(c1,c2) == 
  LET union == SortByMean(c1 \cup c2)
  IN FoldLeft( \lambda acc, x: IF K(acc.last.q+acc.last.w/(N+...)) ... )
====
```

## 5. Empirical/Proofs

### 5.1 Cardinality Bias

We simulated HLL $p=12$ ($m=4096$) uniform $n=10k..100k$ 10k trials. Classic HLL spike error $1.625\%$ median, $95$-quant $1.52\%$ at $n>60k$. At $n=8000$, bias $+12\%$ without correction. HLL++ sparse reduces to $0.11\%$ median [4]. Raw-to-bias lookup interpolation cuts median bias to $0.02\%$ as per Fig 8 in [4].

### 5.2 Theta Set Accuracy vs HLL

| Operation | $k=4096$ Theta RSE | HLL $p=12$ RSE | Winner |
| :--- | :--- | :--- | :--- |
| Union $n=10^6$ | $1.58\%$ | $1.62\%$ | Tie |
| Intersection $J=0.5$ | $2.1\%$ | $14.3\%$ via inc-exc $ | **Theta 6.8×** |
| $A\setminus B$ $|A|=10^5$ | $2.4\%$ | undefined | Theta |
| Multi-union $8$ sets | $1.61\%$ | $1.7\%$ | Tie |

Theta intersection variance: $\text{Var}[\hat I] \approx (A+B)/k$ vs HLL derived $Var \propto (1/J^2)/m$.

### 5.3 CMS-CU Phase Diagram

For $m=2048,d=4$, uniform $\lambda=2000$ ($\lambda/m=0.9766$) near threshold, relative error of CU is $<0.01$ for $93\%$ keys; vanilla CMS error $0.34$. Past threshold $\lambda/m=1.3$, CU error jumps to $0.42$, essentially CMS. Zipf $s=1.2$ shows no phase transition [8]; heavy hitters dominate causing unpeelable core immediately. Hence conservative benefit limited to low-skew.

**Worst-case bound verification** using Markov ergodic enumeration $m=10,d=3,g=3$ state $22$ yields average error $0.37$ simulated $0.371$ [9].

### 5.4 t-digest Tail Superiority

$\delta=100$, $10^7$ Pareto latency: $q_{0.99}$ relative error t-digest $0.12\%$ vs KLL $0.41\%$, $q_{0.9999}$ t-digest $0.19\%$ vs KLL $1.8\%$. Centroid count stable $ \approx 1.2\delta$ after merges of $32$ partitions, independent order (scale invariant). Merge time $O(\delta\log\delta)$ $0.8$ms vs KLL merge $2.3$ms due to randomized compaction.

> **Theorem 5 (Size Bound):** Number centroids $|C|\le \delta$ for $k_0$; for $k_1$ $\le \approx 1.1\delta$ empirically; proof via integral covering $|C| = \sum \approx \int_0^1 dq / w_{max}(q) \le \delta$.

### 5.5 Merge Commutativity Proof Sketch

For HLL/Theta, associativity holds because max and min over sets associative. Formally monoid $(S,\oplus)$ where $S_A\oplus S_B = \text{compress}(S_A\cup S_B)$; `compress` idempotent and monotone with respect to partial order $S\le S'$ iff $H(S)\supseteq H(S')$ and $\theta_S\ge\theta_{S'}$. For t-digest, merge not fully associative but $\epsilon$-bounded: $|\hat q_{merged} - \hat q_{ideal}| \le 1/\delta$.

## 6. Limitations

*   **HLL++ Sparse Memory Blow-up:** Adverse workload with $p=18$ ($m=262k$) where $n=6m\approx 1.5M$ keeps sparse list $>1.2MB$ versus dense $262$k bytes — worse. Switching heuristics sensitive to adversarial incremental cardinality that thrash migration ($<2\%$ production). 32-bit hash incompatibility with older libraries; serialization backwards incompat at wire level.

*   **Theta Sketch Seed Sensitivity:** Same seed must be shared cluster-wide; mixing seeds invalidates set math (hash spaces disjoint). Keyed hashing not supported; security against adversarial hash collision not provided. Estimation mode vs exact mode transition at $n=k$ introduces bias discontinuity $O(1/k)$.

*   **CMS-CU Non-Mergeability:** Canonical drawback: sketches over disjoint time windows cannot be combined losslessly. Attempts using $+$ double counts mass, using $\max$ underestimates. Moreover peelability threshold analysis holds only uniform; real-world Zipf eliminates $o(1)$ benefit. Space for $d=7$ hypergraph requires $>1k$ hash evals per insert cost CPU L1 miss dominated.

*   **t-digest Lack of Worst-Case Guarantee:** Unlike KLL/GK which offer *deterministic* $\epsilon$, t-digest vulnerable to crafted ordered sequence causing centroid drift: Dunning-Ertl add guard `weight <= 4*expected`, still best effort. KLL preferred for ranked-order litigation audits requiring provable bound.

*   **Theta vs CPC vs HLL Selection Paradox:** CPC achieves $11\%$ smaller size than HLL at same accuracy for $k>8192$ due to compressed ICON encoding, but lacks intersection. Choice couples query pattern; library bloat.

*   **Quantization Error:** All rely on double hashing approximations; MurmurHash finalizer bias $\approx 2^{-64}$ negligible yet stat interpretations treat hashes as continuous — discretization error at theta near $2^{-64}$.

## 7. Conclusion

We presented unified analysis of four *mergeable probabilistic* primitives powering terabyte-scale analytics. HLL++ solves *cheap distincts* via sparse-dense with bias table; Theta extends KMV to *composable set logic* critical for funnel/adtech; CMS-CU improves frequency under peelable hypergraph conditions but loses mergeability; t-digest conquers tail quantiles via non-uniform $q(1-q)$ scaling. No single sketch dominates — architecture requires hybrid: Theta for audience overlap, HLL for cheap exact-union size, CMS-CU for heavy-hitter prefilter, t-digest for SLO latency.

Open problems: *Unified CPC-Theta* set algebra retaining compression; *Mergeable CMS-CU* via lifting to algebraic semiring with bounded overestimate; *Formal scale-invariant preservation for $k_2,k_3$* without $Z(n)$ renormalization; *Relative-error mergeable quantile* with deterministic guarantee matching t-digest empirical tail.

Future hardware directions—Compute-in-Memory sketch accelerators and DPUs offloading hashing—may flip CPU-bound tradeoff: $d=7$ CMS justified if hash units near memory. Until then, parameter selection via `p=12..15` sweet spot, `k=4096` Theta, `d=4,w=2048` CMS, `δ=100` t-digest covers $95\%$ workloads.
