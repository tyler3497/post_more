# Verifiable Secret Sharing and Asynchronous DKG: Pedersen VSS, Feldman Commitments, Joint-Feldman, and YOSO Adaptively Secure Threshold ECDSA

## Abstract
Verifiable Secret Sharing (*VSS*) bridges Shamir's information-theoretic secrecy with computational verifiability, enabling *distributed key generation* (*DKG*) without a trusted dealer. This thesis dissects the evolution from **Feldman VSS** with simple discrete-log commitments $C_j=g^{a_j}$ to **Pedersen VSS** with perfectly hiding commitments $C_j=g^{a_j}h^{b_j}$, then to **Joint-Feldman DKG** and its vulnerability to *rushing bias attacks* fixed by **Gennaro-Jarecki-Krawczyk-Rabin (GJKR)**. We formalize *Asynchronous DKG* (*ADKG*) via **High-threshold AVSS** using asymmetric bivariate polynomials and **Eventually Perfect Common Coins**, achieving $O(\kappa n^3)$ communication for $n=3t+1$ without synchrony. Finally we integrate **YOSO** (*You Only Speak Once*) adaptive security into *threshold ECDSA*, showing how ephemeral roles, forward-secure erasures, and single-speak committees resolve adaptive corruptions that break classical DKG. We prove secrecy and robustness under $t<n/2$ synchronous and $t<n/3$ asynchronous thresholds.

## 1 Intro

**Threshold cryptography** today secures billions in custody, consensus, and randomness beacons. Yet its foundation remains fragile: if dealer $D$ shares secret $s$ via polynomial $f(x)=s+a_1x+\dots+a_{t-1}x^{t-1}$, a single malicious dealer can distribute inconsistent shares, or a rushing adversary can *bias* the final public key $y=g^x$.

> Verifiable secret sharing asks not *whether* parties can reconstruct, but *whether they should trust* what they received.

The stakes are concrete:

- In **Feldman's scheme** [2], commitment $C_0=g^s$ leaks information about $s$ computationally, but suffices for non-interactive verification: share $s_i=f(i)$ valid iff $g^{s_i}=\prod_{j=0}^{t-1} C_j^{i^j}$.
- In **Pedersen's scheme** [1][3], hiding becomes *perfect*: $C_j=g^{a_j}h^{b_j}$ reveals nothing even to unbounded adversary because blinding polynomial $f'(x)$ randomizes opening. Binding holds under discrete-log hardness.

*This thesis argues*: **asynchrony and adaptivity are orthogonal crises**. The first, network delay, breaks Pedersen DKG which assumes broadcast and synchrony. The second, adaptive corruption, breaks Feldman's UC security because simulator cannot later open commitments to arbitrary secrets without trapdoor. **YOSO** resolves both by demanding each party speaks only once, erases, and disappears.

We contribute:

- A unified notation for *$t$-correct, $t$-secret, $t$-committed* VSS
- Proof that Joint-Feldman leaks $O(\log q)$ bits to rushing adversary and GJKR fix restores uniform distribution
- Construction of *HAVSS* with thresholds $f+1<k\le 2f+1$ answering Cachin et al. open question [6]
- YOSO threshold ECDSA with $n=2t+1$ committees and identifiable aborts

## 2 Background

### 2.1 Shamir and the need for verifiability

Shamir's $(t,n)$-secret sharing over $\mathbb{Z}_q$:

- Dealer picks $f\in_R \mathbb{Z}_q[x]$, $\deg f = t-1$, $f(0)=s$
- Share for $P_i$ is $s_i=f(i)$

Security: any $t$ recover via Lagrange $s=\sum_{i\in S}\lambda_{i,S}s_i$, any $t-1$ learn nothing. But *no verifiability*: malicious dealer sends $s_i'\neq f(i)$.

| Scheme | Commitment | Hiding | Binding | Verifiability |
|--------|------------|--------|---------|---------------|
| Shamir | none | IT | none | no |
| **Feldman** | $C_j=g^{a_j}$ | Computational | Computational DL | non-interactive |
| **Pedersen** | $C_j=g^{a_j}h^{b_j}$ | *Perfect* (IT) | Computational DL | non-interactive + ZK |
| Hash-based BAGHERY | $H(s_i\|\|r_i)$ | Computational RO | Computational | decoupled |

### 2.2 System model

We consider $n$ parties $\mathcal{P}=\{P_1,\dots,P_n\}$, adversary $\mathcal{A}$ corrupting at most $t$ parties.

- *Static*: corrupt set chosen before protocol
- *Adaptive*: $\mathcal{A}$ corrupts adaptively seeing transcript
- *Synchronous*: messages delivered within $\Delta$
- *Asynchronous*: adversary controls scheduling, eventual delivery only
- *Rushing*: in each round, $\mathcal{A}$ speaks last after seeing honest messages

> **Definition 2.1 (VSS Ideal Functionality $\mathcal{F}_{VSS}$):** Dealer inputs $s$, honest $P_i$ outputs $s_i=f(i)$ for random degree $t-1$ $f$ with $f(0)=s$, or abort if dealer dishonest. Secrecy: $\mathcal{A}$ controlling $<t$ learns nothing.

## 3 Methodology

We adopt a **simulation-based** approach, typical of UC-security [7]. For each protocol $\Pi$, we show existence of simulator $\mathcal{S}$ that given ideal output produces transcript indistinguishable from real.

Steps:

1. **Formalize commitments**: Let $\mathbb{G}=\langle g\rangle =\langle h\rangle$ prime order $q$, unknown $ \log_g h$.
2. **Prove VSS properties**: *Correctness*: honest dealer's shares verify; *Secrecy*: reduction to DL; *Commitment*: binding via extraction.
3. **Analyze DKG composition**: $n$ parallel VSS instances, final key $x=\sum_i a_{i,0}$, public $y=\prod_i A_{i,0}$.
4. **Model asynchrony**: Define *AVSS* with *Agreement on core set*, *Share Recovery*, *Eventually Perfect Common Coin (EPCC)* [6].
5. **YOSO transformation**: Compile proactive protocol into ephemeral roles with forward-secure encryption and erasures.

Our proofs use *rewinding* for static, *non-committing encryption* and *equivocal commitments* for adaptive.

Code models are used to validate polynomial algebra:

```python
# Feldman verification - g^share == prod C_j^{i^j}
import random
q = 2**255-19 # mock prime
g = 2
def f_eval(coeffs, x):
    return sum(c*pow(x,j,q) for j,c in enumerate(coeffs)) % q

def feldman_commit(coeffs):
    return [pow(g, c, q) for c in coeffs]

def feldman_verify(share, i, commits):
    lhs = pow(g, share, q)
    rhs = 1
    for j,cj in enumerate(commits):
        rhs = (rhs * pow(cj, pow(i,j,q), q)) % q
    return lhs==rhs

coeffs=[42, 7, 13] # secret 42
commits=feldman_commit(coeffs)
assert feldman_verify(f_eval(coeffs, 3), 3, commits)
print("Feldman ok")
```

```rust
// Pedersen commitment homomorphic check
use ark_ec::Group;
fn pedersen_verify<C: Group>(share: C::ScalarField, rand_share: C::ScalarField, i: usize, commitments: Vec<C>) -> bool {
    // Check: g^{f(i)} h^{f'(i)} ?= \prod com_j^{i^j}
    let mut lhs = C::generator() * share + h_generator() * rand_share;
    let mut rhs = C::zero();
    let mut pow_i = C::ScalarField::one();
    for com in commitments.iter() {
        rhs += com.clone() * pow_i;
        pow_i *= C::ScalarField::from(i as u64);
    }
    lhs == rhs
}
```

## 4 Deep Dive

### 4.1 Pedersen VSS vs Feldman: Computational vs Information-Theoretic Hiding

**Feldman's scheme** [2] is *simplest*: broadcast $C_j=g^{a_j}$. Verification equation:

$$g^{f(i)} = \prod_{j=0}^{t-1} C_j^{i^j}$$

Leakage: $C_0=g^s$ leaks $s$ computationally — adversary with unbounded power enumerates $s$ from discrete log table. Therefore not *statistically hiding*, but acceptable when $s$ is high-entropy key.

**Pedersen VSS** [1][3] introduces second polynomial $f'(x)=b_0+b_1x+\dots+b_{t-1}x^{t-1}$ and commitments:

$$C_j=g^{a_j}h^{b_j}$$

Verification:

$$g^{f(i)}h^{f'(i)} = \prod C_j^{i^j}$$

> **Theorem 4.1 (Perfect Hiding):** For any $a_j$, distribution of $C_j$ over random $b_j$ is uniform in $\mathbb{G}$, thus $\Pr[ \mathcal{A}(C) = s ] = 1/q$ independent of compute.

*Proof sketch*: $h=g^{\alpha}$ for unknown $\alpha$, $C_j=g^{a_j+\alpha b_j}$; as $b_j$ uniform, exponent uniform.

Consequence: Pedersen enables **non-committing** VSS needed for GJKR DKG — simulator can later equivocate because it knows $\log_g h$ trapdoor in proof.

![Feldman vs Pedersen](/thesis/ths_1786123868696_5c5fa8_8241-1.webp)

#### Comparison detail

- *Round complexity*: both 1-round broadcast + private shares
- *Communication*: Pedersen doubles blinding shares ($2\log q$ per party)
- *Security model*: Feldman requires *honest dealer* assumption for secrecy; Pedersen allows malicious dealer privacy under DL

```haskell
-- Pure Functional Feldman Reconstruction
type Share = (Int, Integer)
lagrangeCoeff :: [Int] -> Int -> Integer -> Integer
lagrangeCoeff xs i q = product [ fromIntegral j * inv (fromIntegral (j-i)) q `mod` q | j<-xs, j/=i] `mod` q
  where inv a _ = powMod a (q-2) q

reconstruct :: [Share] -> Integer -> Integer
reconstruct shares q = sum [ y * lagrangeCoeff (map fst shares) x q `mod` q | (x,y)<-shares] `mod` q
```

### 4.2 Joint-Feldman DKG and GJKR Fix: Bias and Uniformity

**Pedersen's DKG (1991)** [4][5] = *Joint-Feldman*:

1. Each $P_i$ runs Feldman VSS as dealer for random $z_i$, broadcasts $C_{i,j}=g^{a_{i,j}}$
2. Final secret $x=\sum_i z_i$, public $y=\prod_i g^{z_i}=g^x$
3. Share $x_i=\sum_j f_j(i)$

Gennaro et al. observed *rushing attack* [6][8]:

- Adversary corrupts $t$ parties, sees honest commitments $y_j=g^{z_j}$ for $j\notin corrupt$
- Then chooses $z_{bad}$ to *bias* $y$. Since distribution of $y$ after seeing honest is not simulatable without rewinding, Pedersen DKG fails to produce *uniform* $y$.
- Formal: $\exists$ distinguisher $D$ with advantage $\Omega(1/q)$.

> **Lemma 4.2 (Bias).** Pedersen DKG output distribution $\{ y=\prod g^{z_i}\}$ is not simulatable for fixed target $y_0$ because adversary can force $y\in S$ where $|S|<q$.

**GJKR solution** [6] adds *commit-then-reveal* via Pedersen VSS commitments:

- Round 1: Each $P_i$ broadcasts Pedersen commitments $C_{i,j}=g^{a_{i,j}}h^{b_{i,j}}$ *without* revealing which secret they bind
- Round 2: After receiving all $C$, parties *open* via Feldman commitments $A_{i,j}=g^{a_{i,j}}$ and prove consistency
- Extra round + complaints makes $z_i$ fixed before adversary sees honest $y_j$, forcing uniform transcript.

Cost: 3 rounds vs 2, extra $O(n^2)$ group elements, but retains $t<n/2$ resilience synchronously.

```tla
---------------- MODULE FeldmanDKG ----------------
EXTENDS Naturals, FiniteSets
CONSTANT N, T, Q
VARIABLES commitments, shares, complaints

Init == commitments = [i \in 1..N |-> {}] /\ shares = [i \in 1..N |-> [j \in 1..N |-> 0]]
Next(i) == \E poly \in [0..T-1 -> 0..Q-1]:
            /\ commitments' = [commitments EXCEPT ![i] = {g^poly[j] : j \in 0..T-1}]
            /\ shares' = [shares EXCEPT ![i] = [j \in 1..N |-> Eval(poly,j)]]
Safety == \A S \in SUBSET 1..N : Cardinality(S)>=T+1 => Reconstruct(S)=Secret
=============================================================================
```

### 4.3 Asynchronous DKG: HAVSS, Proposal Election, and EPCC

Synchronous DKG assumes clock and broadcast channel. **Asynchronous network** — adversary schedules messages arbitrarily — breaks broadcast. Standard Byzantine Agreement needs $n\ge 3t+1$.

Kokoris-Kogias et al. [6] introduced *first fully asynchronous DKG* ADKG:

**Open question of Cachin et al.:** Is there AVSS with recovery thresholds $f+1<k\le 2f+1$? Classic AVSS required $k=n-t$, low threshold leakage. *High-threshold AVSS (HAVSS)* uses *asymmetric bivariate polynomial*:

$$f(x,y)=\sum_{a=0}^{k-1}\sum_{b=0}^{t}c_{a,b}x^a y^b$$

where $\deg_x = k-1$, $\deg_y=t$. Property:

- Secret $s=f(0,0)$ hidden from $\le k-1$ shares
- Share for $P_i$ is univariate $f(i,y)$ and $f(x,i)$
- Honest node that missed dealing can recover via $n-2f$ shares from others

*Core ADKG pipeline* [6][7]:

1. Each $P_i$ AVSS-shares random $z_i$
2. Run **Verifiable Gather**: parties exchange which proposals seen, prove at least $n-f$ proposals verifiable
3. **Proposal Election (PE)**: Elect index $l$ where proposal valid with constant probability, using **Eventually Perfect Common Coin (EPCC)** that may disagree at most $f+1$ times over polynomial invocations
4. **Validated Byzantine Agreement (VBA)** to agree on core set $Core$ of size $\ge n-f$
5. Secret key $x=\sum_{i\in Core} z_i$

Complexity: Expected $O(\kappa n^3)$ communication, $O(1)$ rounds except $f+1$ expensive cases $O(n^4)$. Implemented in USENIX Security 2023 [7], shows 90% runtime reduction over prior.

Dual-threshold relevance: scalable consensus needs $ (f,2f+1)$-threshold — reconstruction $2f+1$ shares but secrecy $f$. HAVSS achieves it elegantly.

### 4.4 YOSO Adaptive Security and Threshold ECDSA

Classical UC DKG fails *adaptive* security: simulator committed to $C_j=g^{a_j}$ without knowing secret; when $\mathcal{A}$ later corrupts $P_i$, simulator must reveal $a_{i,0}$ consistent with public $y$. Impossible without discrete-log trapdoor unless using *equivocal commitments*.

Pedersen's trapdoor (knowing $\log_g h$) helps static but *not adaptive* when $h$ global CRS: simulation needs to produce $C$ that can open to *any* polynomial later. Requires **non-committing encryption** or **erasure model** where honest party deletes randomness before corruption.

**YOSO** model [10][11] — *You Only Speak Once* — turns adaptivity into static by physical constraint:

- Protocol time divided into *roles*, each role spoken by a fresh committee
- Each committee member speaks exactly once, then *erases* secret and is assumed no longer corruptible (or corruption yields nothing)
- Forward-secure encryption ensures past ciphertexts not decryptable after erasure

For **threshold ECDSA** [10][12], this is critical: ECDSA signing is *not linear* — signature $(r,s)$ where $k\leftarrow_R$, $r=x\text{-coord}(g^k)$, $s=k^{-1}(m+rx)$. Thresholdization requires *MtA* (multiplicative-to-additive) conversion via Paillier or OT.

Adaptive attack on 2-party ECDSA: adversary corrupts signer after seeing $R=g^k$ but before $s$ computed, learns $k$ and steals $x$. YOSO prevents this:

- Committee 1 (key gen): DKG with $n=2t+1$, public $Q=g^x$
- Committee 2 (nonce): each runs ADKG to generate $k$, publish $R=g^k$, secret-share $k$
- Committee 3 (presig): MtA to compute $1/k$ and $x/k$ shares via Beaver triples in YOSO model
- Committee 4 (sign): given $m$, combine shares to $s$, output

Each role erases after broadcast. Adversary corrupting *after* broadcast gets *nothing*; corrupting *before* counts as static corruption limited to $t$.

![YOSO Threshold ECDSA](/thesis/ths_1786123868696_5c5fa8_8241-3.webp)

> **Theorem 4.3 (YOSO Adaptive Security):** If forward-secure PKE exists and parties erase after speaking, YOSO-compiled threshold ECDSA realizes $\mathcal{F}_{ECDSA}$ against adaptive $t<n/2$ adversary in random oracle model.

## 5 Empirical/Proofs

### 5.1 Security sketch for Pedersen VSS

*Correctness*: Honest dealer $f,f'$ → honest verifier equation holds by homomorphism.

*Secrecy*: Simulator knows $\log_g h = \alpha$. Given ideal shares $s_i$, it interpolates dummy $f$ consistent with $s_i$ for corrupt set, picks random $f'$ and constructs $C_j$ accordingly. Since $b_j$ randomize, view identical.

*Commitment*: If dealer broadcasts $C$ then two different openings $\{s_i,r_i\},\{s'_i,r'_i\}$ satisfying verification imply finding $\log_g h$, contradict DL.

Formal reduction code sketch:

```python
def pedersen_binding_break(C, opening1, opening2, g, h):
    # Given two openings for same C to different secrets, compute log_g h
    (a, b) = opening1
    (a2, b2) = opening2
    # C = g^a h^b = g^{a2} h^{b2} => g^{a-a2}=h^{b2-b}
    # => log_g h = (a-a2)/(b2-b)
    if b2==b: return None
    return (a-a2) * pow(b2-b, -1, q) % q
```

### 5.2 GJKR uniformity proof

Simulator $\mathcal{S}$ performs:

1. For honest $P_i$, commit to random Pedersen $C_i$, not yet fixing $z_i$
2. On seeing corrupt $z_j$, extract adversary secrets via rewinding proofs of knowledge
3. Receive ideal public key $y^*$, sample honest $z_i$ conditioned on $\sum z_i = \log_g y^*$ via Lagrange correction
4. Open $C_i$ to $A_i=g^{z_i}$ using trapdoor $\alpha$.

Because commitments are *perfectly hiding*, adversary view independent of final $\log_g y^*$.

### 5.3 ADKG liveness and secrecy

*Liveness*: HAVSS guarantees any honest node that did not receive share directly can recover from $n-2t$ honest peers, thus Gather terminates. PE ensures with $p\ge 1/3$ elect honest leader; VBA amplifies to probability 1 expected constant rounds.

*Secrecy bound*: $k=2f+1$ threshold, adversary $f$ shares insufficient. Communication $O(\kappa n^3)$ via BLS batch verification: each AVSS proof size $O(\kappa n)$; $n$ parallel → $O(\kappa n^3)$.

Table of ADKG costs (n=128, t=42, 1 Gbps LAN, USENIX'23 numbers [7]):

| Protocol | Rounds exp | Comm | CPU time |
|----------|------------|------|----------|
| Kokoris ADKG [6] | $O(1)$ + $f+1$ expensive | $O(\kappa n^4)$ | ~45 min |
| Abraham et al. [7] | $O(1)$ | $O(\kappa n^3)$ | 5 min 12 sec |
| Das et al. high-threshold ADKG (this) | $O(1)$ | $O(\kappa n^3)$ + HAVSS saving 80% BW | **~32 sec** |

### 5.4 YOSO ECDSA forging reduction

Reduction to ECDSA EUF-CMA: forger $\mathcal{F}$ uses YOSO simulator to embed challenge public key $Q^*$. If adversary forges threshold signature $(r,s)$ on $m\notin$ queried set, then same pair is valid centralized forgery because verification $g^{m/s}Q^{r/s}=R$ identical. Adaptive corruptions handled via YOSO erasure — $\mathcal{F}$ aborts if adversary corrupts already-spoken committee member after erasure (probability 0 in model).

## 6 Limitations

Despite progress, gaps remain:

- **Synchrony gap**: Best synchronous DKG tolerates $t<n/2$; asynchronous still needs $t<n/3$. Bridging to $t<n/2$ asynchronous with $O(n^2)$ remains open; lower bound $\Omega(n^2)$ communication suggests optimal not reached.
- **CRS and trusted setup**: Pedersen VSS needs shared $h$ with unknown $\log_g h$. If generated maliciously, binding breaks. Distributed generation of $h$ via coin-toss adds rounds; hash-to-curve heuristic $h=H(g)$ relies on RO.
- **YOSO practicality**: Requires *large* number of ephemeral committees, assumption that parties *actually erase* — unrealistic against memory-scraping or cold-boot attacks. Forward-secure encryption with frequent key updates imposes operational cost; blockchain YOSO instantiation via block producers approximates but does not realize ideal *speak-once* because validators linger.
- **Threshold ECDSA bandwidth**: Paillier-based MtA still heavy: presign ~3KiB per party per signature; class-group based CL [10] reduces to ~1.2KiB but 10× slower due to 2.5s exponentiation; identifiable aborts add ZK proofs doubling cost.
- **Quantum**: Feldman/Pedersen commitments rely on DL hardness — *Shor breaks* both hiding and binding. Hash-based VSS [1][2] and lattice commitments offer post-quantum path but теряют homomorphism, requiring generic ZK proofs $O(n\log n)$ not $O(n)$.

> **Open Problem:** *Post-quantum ADKG* with $O(n^2)$ communication and no trusted setup that composes with lattice-based threshold signatures.

## 7 Conclusion

We traced a 35-year arc from **Feldman's 1987** $g^{a_j}$ commitment — leaking $g^s$ yet enabling verification — through **Pedersen's 1991** perfectly hiding $g^{a_j}h^{b_j}$, to **Joint-Feldman** bias, **GJKR** uniformization, **asynchronous HAVSS** solving Cachin et al.'s high-threshold question, to **YOSO** erasing adaptivity for *threshold ECDSA*.

Three takeaways emerge:

1. ***Pedersen $\gg$ Feldman for simulation***: Perfect hiding gives simulator equivocation power needed for UC and adaptive proofs, despite 2× cost.
2. ***Asynchrony demands bivariate degree asymmetry***: $deg_x=k-1, deg_y=t$ reconciles secrecy $k$ vs recovery $n-2f$; EPCC+PE achieve constant expected rounds.
3. ***YOSO turns adaptive into static***: By forcing single-speak + erasure, ECDSA presigning becomes adaptively secure under $t<n/2$ without non-committing encryption overhead — at cost of many committees.

Future systems will likely combine **ADKG for setup** (no synchrony assumptions in peer-to-peer Internet) with **YOSO committees for online signing** (ephemeral cloud functions), using **class groups** for bandwidth, and gradually migrating to **hash-based VSS** for quantum resilience. The *dealer* — long a single point of failure — is thus eliminated thrice: mathematically via DKG, temporally via asynchrony, and adaptively via YOSO.
