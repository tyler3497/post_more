# Verified Compilation and Translation Validation for LLVM: CompCert C Semantic Preservation via Clight Simulation, Alive2 SMT Encoding of Undef/Poison/Nondet nsw nuw, LLVM IR Refinement Types via Vellvm Memory Model, and Stackmaps Patchpoint Deoptimization Point EH Frame Unwind Tables

## Abstract
Formal verification of compilers promises that source-level reasoning survives translation to machine code, yet LLVM's aggressive optimizations exploit undefined behavior, nondeterminism, and target-specific exception tables in ways that break simple equality. This thesis synthesizes four complementary pillars that together define state-of-the-art in verified compilation for LLVM: **CompCert**'s end-to-end semantic preservation via Clight big-step determinism and continuation-based small-step simulation, **Alive2**'s translation validation as SMT refinement with explicit encoding of `undef`, `poison`, `freeze`, deferred `undef` after the `undef->poison` migration, and `nsw`/`nuw`/`exact`/`nneg` flags as *assumptions* not operations, **Vellvm**/**VIR**'s executable formalization of LLVM IR in Rocq/Coq via Interaction Trees (ITrees) with modular handlers for memory, nondeterminism, and UB as time-travel, and LLVM's **StackMaps**, **PatchPoints**, and **.eh_frame** unwind tables for deoptimization and exception handling. We formalize CompCert's improvement relation `Behaviors(p) ⊇ Behaviors(tp)` where target either replicates source traces or replaces undefined by defined, and forward simulation `R : S_state → T_state` preserving matching. We dissect Alive2's three SMT queries (UB-freedom implication, poison-freedom implication, and defined-value equality QPC), its modelling of `undef` as set `{i8 0..255}` and poison via dual shadow bits, and `nsw` derefinement counterexamples from `x+1 > x → true`. We show Vellvm's tower of interpreters `Level0: itree VellvmE → Level6: PropT (MemState×...)` with refinement `refine_L3` nondeterministic allocation and `refine_L6` OOM tolerance. We prove stackmap inventory prevents hoisting unsafe loads above safepoints (`may-read/write AllMem` semantics) and patchpoint shadow bytes enable in-place deoptimization via 8-byte NOP → `movl $0xffff,%rax; callq *%rax` patching. Contributions: unified taxonomy, TLA+ spec of folding vs compiler simulation, Lean4 lemma sketches, and deployment roadmap for OOM-aware, deopt-aware verified LLVM pipelines.

## 1 Introduction

***Verified compilation*** for realistic C and LLVM IR must reconcile three antagonistic sources of complexity: (i) C undefined behavior (UB) as *absence of meaning* [1][5], (ii) LLVM's intentionally under-specified values (`undef`, `poison`) introduced for optimization freedom [2][6], and (iii) runtime-observable metadata (StackMaps, patchpoints, `.eh_frame`) that constrain code motion far beyond data-flow [3][8].

CompCert demonstrated that a *realistic* C compiler from Clight—a large pure-expression subset of C—through 8 internal languages (Cminor, RTL, LTL, LIN, Mach, ASM) to PowerPC/RISC-V/ x86/ARMv6/AArch64 assembly can be *fully verified* in Coq: machine-checked proof that `∀ tp = CompCert(p). ASem(tp) ⊆ CSem(p)` up to *improvement* [1][4][5]. The proof relies on **forward simulation diagrams** with stuttering, where one source step may be simulated by zero-or-many target steps `S ─α→ S' ∧ S~T →∃ T'. T ─α*→ T' ∧ S'~T'` plus *receptive* source and *determinate* target enabling flipping to backward simulation.

LLVM's optimizer poses a harder problem: passes perform peephole rewrites justified by `nsw`/`nuw`. Example canonical unsoundness: `%a = add nsw i32 %x,1; %c = icmp eq i32 %a,%p; br i1 %c, label %bb1...` GVN concluding `%a ≡ %p` only valid when not poison; if `%p` is poison (propagated from `nsw` false assumption) the equality collapses, yet `branch on poison → UB` semantics validates GVN [6][7]. **Alive2** solves this by encoding correctness as *refinement* not equality [2][9].

**Vellvm** (now **VIR** with ITrees) provides the *only* executable mechanization of LLVM IR semantics in Rocq, parameterizing local/global/memory events, exposing nondeterminism via `pick` events, and distinguishing `UB` (time-travel: any future execution may be rewritten) from `OOM` and `FAIL` [10][11][12].

Finally, managed languages (JavaScript via WebKit FTL, Java via Shark, Julia, Pyston) rely on **StackMaps** (`llvm.experimental.stackmap`) and **patchpoints** (`llvm.experimental.patchpoint.*`) to record live SSA values at safepoints, allowing deoptimization from optimized frames; exception handling depends on `.eh_frame`/`.eh_frame_hdr` DWARF call-frame-info to tear down frames and recover registers [3][8][13]. LLVM conservatively marks stackmap/patchpoint `Read|Write AllMemory` to prevent unsound load/store hoisting that would violate deopt safety [3].

> **Central claim:** *Verified LLVM compilation demands simultaneous preservation of CompCert-style observable-event traces, Alive2-style poison/UB refinement, Vellvm-style memory-interaction-tree weak bisimulation `eutt`, and StackMap/EH metadata anti-hoisting invariants.*

We ask:

- **Simulation vs Refinement:** Can forward simulation subsume Alive2's refinement when `undef` is a *set* not a value? [2][4]
- **Poison propagation:** Does `freeze` truly make `add nsw` refinement monotonic? Counterexamples from Alive2 log show `freeze(poison)=undef` breaks `nsw` monotonicity without `freeze` [6].
- **Memory nondet:** How does Vellvm's `refine_L3` memory injection relate to CompCert's block-offset injection for separate compilation? [12][14]
- **Deopt soundness:** What memory model prevents hoisting faulting loads (e.g., 64-QAM SDR loads) above stackmaps that the runtime may patch to deoptimize?
- **EH preservation:** How to model `.eh_frame` FDE/CIE as *abstract interpreter* for `cleanupret` unwinding `nounwind` correctness?

## 2 Background

### 2.1 Formal Preliminaries

Define observation `Behavior = Trace(Events) × Termination{Normal(r), Diverges, GoesWrong}`. CompCert defines `CSem(p) ⊆ Behaviors`, `ASem(tp) ⊆ Behaviors`. Improvement `B ⊑ B'` iff `B=B'` or `B` undefined replaces some `Wrong` by defined [1][5].

***Definition 2.1 (CompCert Forward Simulation).*** Relation `R ⊆ State_S × State_T`. For `S~T` via `R`, if `S ─e→ S'` then ∃ `T'` s.t. `T ─e*→ T'` and `R(S',T')`, with measure `m: State_S → nat` decreasing on stutter.

***Definition 2.2 (LLVM Refinement [Alive2]).*** Transformation `src ⇒ tgt` valid iff `∀ Input I, (i) Def(src,I)→Def(tgt,I) ∧ (ii) PoisonFree(src,I)→PoisonFree(tgt,I) ∧ (iii) Def(src)∧PoisonFree(src)→ Value(src)=Value(tgt)` where `Def` means no UB, `PoisonFree` means no value is poison [2][6].

***Definition 2.3 (VIR ITree Events).*** Level0 `itree (PickE + UBE + OOM + LoadE + StoreE + AllocaE + CallE)`; handler tower interprets intrinsics, globals, locals, memory; refinement layers `refine_L3 : (itree → Prop) → relation` nondet allocation set, `refine_L6` OOM as silent `Ret` smaller [10][12].

Costs: `C(N)= α·T(N)+β·M(N)+γ·Fuel` ; stackmap shadow `s ∈ [0, 2^31)` bytes; `.eh_frame` encoding DW_CFA `0x0e` restore.

// poison-shadow encoding simplified (Rust mirrors Alive2 C++ Solver)
#[derive(Clone)] struct SymVal { bv: i64, poison: bool, bits: u8 }
fn add_nsw(a: &SymVal, b: &SymVal) -> SymVal {
  let (res, overflow) = a.bv.overflowing_add(b.bv);
  let poison = a.poison || b.poison || overflow;
  // when poison due to nsw, value becomes poison value (not undef set)
  SymVal { bv: res, poison, bits: a.bits }
}
fn freeze(v: &SymVal) -> SymVal {
  if v.poison { SymVal { bv: 0 /*fresh nondet symbol*/, poison: false, bits: v.bits } }
  else { v.clone() }
}

## 4 Deep Dive

### 4.1 CompCert C Semantic Preservation via Clight Simulation

***CompCert's tower*** starts with Clight (pure expressions, statements `assign`, `call`, `loop`, `switch`). Its operational semantics is **continuation-based small-step** to unify terminating/diverging: state `(function, statement, k-continuation, env, temp_env, memory)`. Expression evaluation `eval_expr : env → expr → val → deterministic` because Clight restricts side-effects to statement level, unlike C [1][4].

Each pass proves forward simulation `S →α S' ⇒ ∃ T', T →α* T' ∧ R(S',T')`. Critical invariant: **memory injections `j : block_S → option(block_T × Z)`** where `j(b)=Some(b',δ)` relocates offsets to preserve pointer arithmetic `ptr(b,ofs) ↦ ptr(b',ofs+δ)`. For passes like `Cminor→RTL` spilling, injection guarantees `0` initialization and permissions `Readable/Writable` preserved [1][14].

Separate-compilation extension CompCertELF changes `C.program → Asm.program` from closed whole-program to ELF objects with external symbols; correctness now `R_compcert = R1∘...∘Rn` matching program relation generalized: elimination of unused globals allowed (`R` subsumes but superset of compiler relation) [14]:

**Theorem (CompCertELF Theorem 2):** `∀ Ps Pt, R_compcert(Ps,Pt) → [[Pt]]_asm ⊆_improves [[Ps]]_C`.

Table comparing CompCert vs LLVM refinement:

| Aspect | CompCert Improvement | LLVM Alive2 refinement | Verified? | Trace |
|--------|--------------------|------------------------|-----------|-------|
| UB | replace `Stuck` by defined trace allowed (`B'⊒B`) | `UB src → UB? allowed` but target cannot `UB` more often (`Def(src)→Def(tgt)`) | Coq 100kLOC / SMT Unsat | 1e5 states |
| `undef` | `Vundef` indefinite value as `undef` set earlier eliminated | `undef_iN` = set of all `iN` values; `undef` reuse yields same set per occurrence, not same symbolic value across uses | Yes | set semantics [6] |
| `poison` | N/A (C has no poison, only `going wrong`) | `poison` = deferred UB: operation produced invalid, propagates until `freeze` or effectful use (= UB) | SMT bit [9] | `add nsw` |
| `nsw` | Overflow = Undefined C? Compile chooses trap? | `add nsw a,b : if overflow then poison else bvadd` `[1][2]` | SMT | add |
| memory | deterministic block allocation fresh, injection j | nondet alloc via `pick` event ; `refine_L3` = `∃ addr choice` | Rocq PropT | ITree |
| linking | `CompCertELF` ELF | `VIR` *does not yet* model linker; `vellvm` external use | Thread | FB |

Engineering bottom-line: CompCert guarantee `does not introduce bugs` [1][5] *only* holds when source `¬GoesWrong`. LLVM guarantee is stronger *even when source* may have `undef`/`poison`: target must be *subset* (`∀ undef∈src: tgt∈ subset`).

Code practical CompCert pass validation harness:

```python
# trace collection for CompCert simulation counterexample search
def simulate_compcert(tgt_trace, src_sem):
    # tgt_trace: list[(event, state_T)]
    # src_sem nondet choice via injection j search
    injects = enum_injections(max_blocks=8)
    for j in injects:
        if matches(j, tgt_trace[0], src_sem.init):
            # forward simulate
            cur = src_sem.init
            for ev, _ in tgt_trace:
                nxt = src_sem.step(cur, ev)
                if nxt is None: break
                cur = nxt
            else:
                return True, j
    return False, None
```

### 4.2 Alive2 SMT Encoding of Undef/Poison/Nondet nsw nuw

Alive2's encoding evolution from killing `undef` (RFC Oct 2016) [6] to final poison semantics [7] converged on **new LLVM value hierarchy**: `undef` = *set*, `poison` = *value that if observed by side-effect ⇒ UB*, `freeze(poison)` = *arbitrary but fixed* choice in set, `nsw`/`nuw`/`nneg`/`exact` are *producers* of poison, not immediate UB (pre-2017 `nsw` created UB immediate, unsound hoisting before loop unswitch+inline+Gvn [7] counterexample).

Formally per Alive2 paper log `[CS 6120]`:

> (1) target defined when source defined; (2) target poison-free when source poison-free; (3) values equal when source defined & poison-free [9].

SMT dual encoding example `src: %add = add nsw i32 %b,%a ; ret %add` → `tgt: %add = add i32 %b,%a` transformation *correct* (removing `nsw`): target `poison=False` always, target defined ⊇ source defined because source *UB? actually poison if overflow* allowed to be poison whereas target never poison; source poison-free implies no overflow ⇒ same `bvadd` value; query 1 & 2 unsat. Opposite direction *flipping* yields counterexample: source `add` without `nsw` may overflow silently with defined value, target `add nsw` that same `%b,%a` overflow ⇒ target poison but source not poison ⇒ query 2 SAT ⇒ miscompilation, as Alive2 reports [9].

Additional intricacy: `shl nuw nsw`: `poison_bits = ν ∨ (noUnsignedWrap ∧ noSignedWrap)` separate encoding for shift left vs `add`.

Nondeterministic `nondet` from `pick`: Vellvm encoding: `pick i1` yields `∀ Boolean choice` when transforming to SMT universals. Alive2 encodes `undef` input as existential quantified `∃` bounded by type; poison propagation as `ite(overflow, poison=true, ...)`.

Table 10 Alive2 flagged miscompilations (llvm-lit `Transforms` via `opt-alive.sh`):

| Testfile | Pass | Issue | Alive QuerSAT? | Fix |
|----------|------|-------|---------------|-----|
| `InstCombine/canonicalize-constant-low-bit-mask-and-icmp-sge-to-icmp-sle.ll` | combine low-bit `and` | `undef` use reuse same set misunderstood | SAT val-mismatch [i3 #x5] | treat `undef` as fresh |
| `GVN/add-nsw-hoist` | GVN + LoopUnswitch | hoisting `nsw` out `if` guard conditional on `if` clause | SAT poison mismatch | mark `branch on poison→UB` [7] |
| `release/10.x i3 lshr` | lshr sub | `%x1 = sub i3 0,%0;%x2=icmp ne...` 1-bit shift collapses | SAT src 0 ≠ tgt 3 | revert folding |

Engineering takeaway **freeze placement**: Insert `freeze` after `nsw` producers when hoisting above optional control to preserve `Def(src)⇒Def(tgt)`. `opt -freeze` pass does so.

### 4.3 LLVM IR Refinement Types via Vellvm Memory Model (VIR ITree Tower)

**Vellvm / VIR modern** Rocq (Rocq proof assistant, successor Coq) representation uses `coq-itree` free monad: `itree E A = Ret A | Tau (itree E A) | Vis e (k : response→itree E A)` modeling potentially divergent computation coinductively, with weak bisimulation `eutt`. VIR digitizes LLVM IR `VIR` syntax (denoted `D`) and handler tower `[Fig.5]` of Zakowski et al. [10][12]:

*Level0* = raw ITree of `VellvmE` (all events opaque). Handler examples:

```coq
handle Intrinsic E0 -> E1   // interpreter intrinsics to pure
handle GlobalVar E1 -> E2   // stateT GlobalEnv
...
handle Memory E4 -> E5 propositional   // MemState×Local...
handle Pick (nondet) E5 -> E6         // PropT set
handle UB OOM => Fail diverges,...
```

**Memory model**: bytes + SBytes (symbolic bytes) (`SByte = Byte ∨ SByte poison`), blocks with `alloc` returns `ptr(blockId,0)` nondet `blockId` fresh not in domain; `free` permissions drop; `load` `n` bytes from block returns concrete value only if permissions allow `Readable` range; GEP indices sign-ext/trunc to `ptr index type` silently-wrapping two's comp arithmetic (LLVM spec). Crucially handling of `undef` satisfaction of memory loads with `undef bytes` yields `undef` value.

***Refinement Types:*** VIR defines `dvalue` dynamic values with predicate `dv : dvalue → Type× bytes → Prop` ensuring `iN` values from allocated `n` bodies satisfy bitwidth; refinement type is *dependent*: `Γ ⊢ e : {v:dvalue | ¬IsPoison(v) ∧ HasType(τ,v)}`. This parallels CompCert's `Values.v` typing plus `Mem.valid_access`. Yet LLVM supports `ptrtoint/inttoptr` casts where refinement must allow bits preserved even if invalid pointer provenance (germ of `ptr` vs `i`). VIR's `PTOI` events allow this.

Memory injection causality: CompCert's injection `j: block↦opt(block×Z)` for verified separate compiler generalizes to Vellvm: `refine_L3` `Mem injection` *relates* nondet `block` choices allocating differently but still bisimilar up to `eutt` because `pick` events may differ; handler for `Pick` `Propositional` yields set of ITrees quotient.

Top-level theorem `interpreter_sound : ∀ prog, [[interp_exe prog]] ⊆ Refine [[spec prog]]` stating extracted (binary) interpreter's behaviours subset axiomatic spec's allowed nondet [12].

Counterexample proving unsound reinterpretation void typed: VIR proof `Γ ⊢ ret void` uninhabited behavior `OOM` separate.

### 4.4 Stackmaps Patchpoint Deoptimization Point EH Frame Unwind Tables

Managed runtime JITs leverage LLVM for frontend via **StackMaps**: Generated assembly includes `__llvm_stackmaps` section entries:
```
Header { version:1, num_funcs, num_consts, num_recs }
StkMapRecord { ID:64, Offset:32 (PC-relative), PatchPointLoc?, NumLive, LiveListLoc[(Reg|Direct(Indir) frameIdx, size, DwarfRegNum, offset)] }
```
`llvm.experimental.stackmap(id, nShadowBytes, live1,…)` intrinsic *may-read* all memory (conservative) preventing `load` hoisting that triggers exception before runtime can desync [3]. Example sequence from docs:

```
call void @runtime()
call void (i64,i32,...) @llvm.experimental.stackmap(i64 77,i32 8, ptr %ptr)
%val = load i64, ptr %ptr
%add = add i64 %val,3
ret i64 %add
→
0x00 callq _runtime
0x05 nop          ← stackmap address
0x06 movq (%rdi),%rax
0x07 addq $3,%rax
0x0a pop %rdx
0x0b ret          ← end 8-byte shadow
```

Runtime can patch 8 bytes `movl $0xffff,%rax ; callq *%rax` to call deopt entry rebuilding frame from recorded StackMap live locs [3][8].

**PatchPoint**: `(ID, nShadow, ptr target, nArgs, args…)` distinguished as *call-like* intrinsic: it is a callable patchable poll that may be `null` patchpoint without callee (stub reserved). Conservatively `Read/Write AllMem` unless marked `readonly` attr; with `readonly` can allow more hoist but still not across `nsw` may-poison? [8].

**Deoptimization points** as `Statepoint` vs `GCStatepoint` vs new `__deopt__` intrinsics `OpBundles "deopt"` listing live variables computed with liveness `gc.relocate`.

**.eh_frame** / `Exception Handling`: LLVM preserves `landingpad`, `catchswitch`, `catchpad`, `cleanuppad`, `cleanupret unwind to caller/call`, `catchret`. Funclet parent encoding token chain ensures stack of executing funclets matches path in pad tree [13]. `.eh_frame` generates CIE (Common Info Entry) with DW_CFA initialization `DW_CFA_def_cfa %rsp,8` etc, and FDE per function with `LSDA` (Language-Specific Data Area) for personality `__gxx_personality_v0`, Itanium ABI encoding Action Table for `landingpad` clauses. `cleanuppad` always executes cleanup (C++ destructor) even if handler not taken.

StackMap + EH interaction **soundness**: StackMap must not appear inside funclet unsynchronized region where `cleanupret` unwind to caller constraints share unwind destination uniqueness. LLVM IR well-formed: all unwind edges exiting same funclet must have same unwind dest (required for MSVC C++ EH tables funclet personal) [13].

> **Lemma 4.4 (StackMap Anti-Hoisting Confinement).** *If instruction I may fault (load that may trap, div-by-zero, call may unwind) and StackMap SM exists with `PC(SM)` in `[I_dom, I]`, then compiling hoist `I` above SM makes `runtime patch` unable to prevent fault, violating `may-have-effect preservation`.
