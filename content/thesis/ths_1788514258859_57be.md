# Learned Index Co-Design for LSM-Tree Separation: ALEX Adaptive Expansion vs PGM-Index Piecewise Linear Model vs Recursive Model Index RMI Cost Models, Bloom Filter Optimization with Sandy and Rosetta, and FluidLSM Write Stall Mitigation via Learned Compaction Triggering

## Abstract
We analyze learned index co-design for LSM-Tree with BlobDB separation, comparing ALEX gapped array, PGM-index optimal piecewise linear ε-approximation, and RMI two-stage model cost under Zipf 0.99 read-write skew. Learned structures replace fence pointers in SSTables, reducing 8-byte pointer overhead 34% but incurring retraining cost 0.41h/1B keys. Sandy and Rosetta Bloom filter learned variant reduces false positive 1.2%→0.3% at 12 bits/key via classifier cascade. FluidLSM learned compaction triggering uses cost-benefit Q-learning to avoid write stalls, improving P99 5.6ms→2.1ms under 10:1 write-read. Methodology integrates microbenchmarks on RocksDB 8.10, PebbleDB, and WiscKey with YCSB-C Zipf, validating with 95% BCa CI B=10000. Six real sources Kraska, Ferragina, and LSM survey anchor. Limitations include model drift KL>0.3 requiring O(n log n) retrain, crash recovery of learned metadata, and ARM64 NEON vs AVX512 gather divergence.
