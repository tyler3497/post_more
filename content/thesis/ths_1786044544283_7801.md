# Speculative Decoding for Large Language Models: Draft Model Distillation, Token Tree Verification, and Parallel Sampling Optimality

## Abstract

Speculative decoding has emerged as the dominant lossless acceleration paradigm for autoregressive large language model inference, achieving 2–4× latency reduction without altering model weights or output distribution. This thesis provides a comprehensive theoretical and systems treatment: we characterize draft model distillation beyond token-level imitation into feature-level autoregression, formalize token tree verification as a structured parallel decoding problem with tree attention, and establish optimality conditions for rejection sampling in multi-candidate settings. Through analysis of distributional alignment via Jensen-Shannon distance, dynamic programming for optimal tree topology, and hardware-aware KV-cache reuse, we show how acceptance length — the expected number of tokens verified per target forward pass — governs wall-clock speedup under memory-bandwidth bottlenecks. We unify perspectives from Medusa [4], EAGLE [5], EAGLE-2/3 [6], SpecInfer [3], and Hydra [7] within a single framework and derive practical limits for scaling to long-context and batched serving.

## 1 Introduction

Large language models (LLMs) such as LLaMA 2 70B, Mixtral 8×7B, and Chinchilla 70B exhibit inference latency dominated by *memory-bandwidth* rather than arithmetic intensity [1][2]. Autoregressive decoding requires K sequential forward passes to generate K tokens, each loading hundreds of billions of parameters from high-bandwidth memory (HBM) to on-chip SRAM. This serialization underutilizes modern accelerators whose FLOPs have outpaced HBM bandwidth by an order of magnitude since 2020.

**Speculative decoding** breaks this dependency [1][2]. A lightweight *draft* model $M_q$ with distribution $q(\cdot|x_{<t})$ proposes $\gamma$ future tokens $ \tilde{x}_{t+1} \dots \tilde{x}_{t+\gamma}$ cheaply; the large *target* model $M_p$ with distribution $p(\cdot|x_{<t})$ verifies them *in parallel* using a single forward pass with appropriately masked attention. If proposals align with $p$, multiple tokens are accepted per verification step, reducing target invocations by factor equal to expected acceptance length $\mathbb{E}[L]$.

> *Theorem:* Under speculative sampling with rejection resampling $p'(x)=\text{norm}(\max(0,p(x)-q(x)))$, the output distribution equals that of sampling directly from $p$ exactly [1][2].

This result is *lossless* — unlike quantization or distillation for deployment, no quality degradation is introduced. The engineering challenge is therefore purely about *maximizing* $\mathbb{E}[L]$ while minimizing draft cost $c = T_{draft}/T_{target}$.

*This thesis makes three contributions:*

- *Draft Model Distillation Theory:* We show token-level distillation is suboptimal vs. feature-level autoregression at the second-to-top-layer, resolving uncertainty via shifted token sequences as in EAGLE [5].
- *Token Tree Verification:* We formalize tree-structured speculation where multiple hypotheses share prefixes, verified via tree attention masks, and give DP for optimal static and dynamic trees under a node budget.
- *Parallel Sampling Optimality:* We prove multi-candidate speculative sampling's acceptance rate is upper-bounded by $1 - TV(p,q)$ mass and that tree verification achieves optimal expected acceptance under tree-consistent $q$.

## 2 Background

### Autoregressive Bottleneck

For transformer decoder $M_\theta$, generation of token $x_t$ requires computing $h_t = \text{Transformer}(x_{<t})$ then $z_t = W_{lm} h_t \in \mathbb{R}^{V}$ where $V \approx 32k-152k$ . With KV-caching, per-step complexity is $O(d^2 + n d)$ for hidden dimension $d$ and context $n$, but memory traffic $O(P)$ where $P$ is parameter count dominates [3]. On A100, loading 70B parameters in FP16 costs ~140 GB movement; compute per token is ~0.14 TFLOPs, far below peak 312 TFLOPs.

Speculative decoding was anticipated by *blockwise parallel decoding* [Stern et al. 2018] which used auxiliary heads but required greedy decoding. Modern lossless form arrived independently via Leviathan et al. [1] at Google Research (Nov 2022) and Chen et al. [2] at DeepMind (Feb 2023). Both proved distribution preservation via rejection sampling, achieving 2–3× speedup on T5-XXL and 2–2.5× on Chinchilla 70B respectively.

### Draft Paradigms

Three draft families evolved:

- **Independent small LM:** Pythia-410M drafting for LLaMA-7B, TinyLLaMA-1.1B for 70B [1]. Simple but $D_{JS}(p||q)$ large.
- **Self-speculative / Layer Skip:** Draft & Verify [Zhang et al. 2023], SWIFT, LayerSkip reuse early layers of $p$ itself, reducing memory footprint to zero extra parameters.
- **Head-based:** Medusa [4] adds $K$ extra heads $f_i(h_{t-1}) \to \tilde{x}_{t+i}$, Hydra [7] makes them sequentially dependent $f_i(h_{t-1}, e(\tilde{x}_{t+1:i-1}))$, EAGLE [5] autoregresses at *feature* level $ \hat{f}_{t+i} = \text{DraftLayer}(f_{t+i-1}, e_{t+i})$.

*EAGLE's insight:* Token-level autoregression is inherently more uncertain than feature-level: $\mathbb{H}[x_{t+1}|x_{<t}] > \mathbb{H}[f_{t+1}|f_{\le t}, x_{\le t+1}]$ because $f$ lies in continuous manifold and smooth. Predicting $f_{t+1}$ then projecting via $W_{lm}$ yields higher acceptance.

### Verification Criterion

Standard verification [1][2]: For $i=1..\gamma$, accept $\tilde{x}_i$ with prob $\alpha_i = \min(1, p_i(\tilde{x}_i)/q_i(\tilde{x}_i))$. If rejected at $j$, resample $x'_j \sim \text{norm}(\max(0,p_j - q_j))$ and stop. If all accepted, sample one bonus token $x_{t+\gamma+1} \sim p_{\gamma+1}$.

Expected accepted length: $\mathbb{E}[L] = \sum_{k=1}^{\gamma} \prod_{i=1}^{k} \beta_i$ where $\beta_i = \mathbb{E}_{x\sim q_i}[\alpha_i] = \sum_x \min(p_i(x), q_i(x)) = 1 - TV(p_i,q_i)$. Thus maximizing acceptance = minimizing total variation distance.

## 3 Methodology

We consider target $p$, draft $q_\theta$ parameterized by $\theta$. Given prefix $C$, draft generates tree $\mathcal{T}$ with $N$ nodes (including root). Each node $v$ corresponds to sequence $S_v = (x_1..x_{d_v})$ where $d_v$ depth. Verification evaluates $p(\cdot|S_v)$ for all $v \in \mathcal{T}$ in *one* forward pass using tree attention.

### 3.1 Tree Attention Kernel

Standard causal mask $M_{ij}= -\infty$ if $j>i$. For tree, we define ancestor relation: node $u$ attends to $v$ iff $S_v$ is prefix of $S_u$ (including self via shared trunk). Implementation uses *Medusa-style* compressed mask [4] or *SpecInfer* topology-aware causal mask [3]. With flatten order BFS, attention complexity $O(N^2 d)$ but $N \approx 10-60$, negligible vs. model FLOPs. KV-cache reuse requires custom kernel to gather ancestor KV entries: SpecInfer's *Tree KV* splits cache into tree-consistent vs. linear [3].

```python
def verify_tree(target_model, prefix_kv, tree_nodes, tree_mask):
    # tree_nodes: List[List[int]] token ids per node path
    # tree_mask: [N,N] bool, True if j can attend to i
    flat = flatten_tree(tree_nodes) # shared prefix dedup
    logits = target_model.forward(
        input_ids=flat,
        attention_mask=tree_mask,
        past_key_values=prefix_kv,
        use_tree_cache=True
    ) # [N, V]
    p_dist = softmax(logits, dim=-1)
    return p_dist # per-node distribution
```

### 3.2 Draft Distillation Objective

We distill draft $q_\theta$ to minimize $D_{KL}(p||q)$ but *weighted* by impact on $\mathbb{E}[L]$. A tighter bound:

> Theorem: $\mathbb{E}[L] \ge \gamma +1 - \sum_{i=1}^\gamma \mathbb{E}_{x_{<i}\sim q}[ D_{TV}(p_i||q_i)]$

Hence minimizing TV upper-bounds via KL: $D_{TV} \le \sqrt{0.5 D_{KL}}$. Feature-level loss [5]:

$$ \mathcal{L}_{EAGLE} = \| f_{t+1} - \hat{f}_{t+1} \|_1 + \lambda \cdot \text{CE}(p_{t+1}, \text{softmax}(W_{lm} \hat{f}_{t+1})) $$

where $f_{t+1}$ is target's second-to-top-layer feature at $t+1$, $\hat{f}_{t+1}$ predicted. The $L_1$ term stabilizes regression in high-dim. EAGLE-2 adds *dynamic tree* training [Li et al. 2024]: expose draft to its own predictions via multi-step unrolling.

### 3.3 System Model

Let $T_t$ = target forward latency, $T_d$ = draft latency per tree. Speedup:

$$ S = \frac{\mathbb{E}[L] \cdot T_t}{T_t + T_d + T_{verify\_overhead}} $$

If $T_d \ll T_t$ (true when draft < 1B vs. target 70B or head-based), $S \approx \mathbb{E}[L]$. Empirically, $T_d/T_t \approx 0.05-0.12$ for EAGLE draft (1 transformer layer). When $N$ grows large, $T_{verify}$ grows because larger attention matrix increases memory traffic modestly (~N×KV expansion). Optimal $N$ ≈ 30-60 for 7B, 10-30 for 70B.

## 4 Deep Dive

### 4.1 Draft Model Distillation and Feature-Level Autoregression

Traditional distillation $q = \arg\min \mathbb{E}_{x\sim D}[D_{KL}(p(\cdot|x)||q(\cdot|x))]$ fails for speculative decoding for two reasons:

- **Exposure bias:** Training on ground-truth prefix $x_{<t}$ but inference sees draft-generated $\tilde{x}$.
- **Distribution mismatch at $t+k$:** Acceptance depends on $p(\cdot|\tilde{x}_{<i})$ not $p(\cdot|x_{<i})$.

EAGLE [5] resolves by autoregressing in *feature space*. Let $f_{1:n} = \text{Transformer}_{[0;L-1]}(x_{1:n})$ be hidden states at layer $L-1$. Then $p_{n+1} = \text{softmax}(W_{lm} \cdot \text{Transformer}_L(f_n))$. Instead of predicting token $\tilde{x}_{n+1}$, draft predicts $\hat{f}_n$:

```rust
// Rust pseudo for feature draft head
struct EagleDraft {
    fc1: Linear<D, D>,
    attn: Attention,
}

impl EagleDraft {
    fn forward(&self, f_prev: Tensor, e_token: Tensor) -> Tensor {
        let x = concat([f_prev, e_token]);
        let h = self.fc1.forward(x).relu();
        self.attn.forward(h) // predicts f_{t+1}
    }
}
```

*Why better?* Second-to-top features are *Lipschitz-smoothed* relative to tokens; small perturbations in token embedding yield bounded $\| \Delta f \|$. Token prediction is discontinuous: a single token flip can send next-token distribution to orthogonal support (e.g., code identifiers). Empirically, Li et al. report top-1 feature-to-token projection matches target $78\%$ vs. $52\%$ for token-level small model on MT-Bench [5].

Hydra [7] adds sequential dependence to Medusa heads:

$$ p_{\text{draft}}( \hat{x}_{t+i} | x_{\le t}, \hat{x}_{t+1:i-1}) = f_{\text{Hydra},i}(h_{t-1}, e(x_t), e(\hat{x}_{t+1}),\dots,e(\hat{x}_{t+i-1})) $$

This reduces $D_{KL}$ by conditioning on draft history, unlike Medusa's independent heads where $f_i$ unaware of intermediate choices. Hydra yields +0.27 avg acceptance length over Medusa on Vicuna-7B [7].

Distillation data matters: *OnlineSpec* [Qian et al. 2025] shows serving traces inherently provide verification feedback measuring $\log p/q$ per token for free, enabling online gradient $ \nabla_\theta \log q_\theta(\tilde{x}) \cdot (r - b)$ where $r=\mathbf{1}[\text{accepted}]$. This closes loop draft-commits → feedback → adapts.

### 4.2 Token Tree Construction and Dynamic Pruning for Verification

Linear chain $\gamma=5$ is suboptimal because if token 1 rejected, tokens 2..5 wasted. Tree $\mathcal{T}$ mitigates by exploring *branching factor* $b_i$ per depth. SpecInfer [3] was first to formalize $N$-node budget: given small models' top-k predictions at each position, build tree maximizing expected accepted length.

**Problem:** Given node budget $N$, draft distribution $q$, choose tree $\mathcal{T}$ maximizing

$$ \mathbb{E}[L(\mathcal{T})] = \sum_{v \in \mathcal{T}} \prod_{u \in \text{Anc}(v)} \beta_u $$

where $\beta_u = \sum_x \min(p(x|S_u), q(x|S_u))$ approximated via $q$-confidence or calibrated score. This is NP-hard in general (tree knap). Sequoia [Chen et al. 2024] solves via DP: optimal substructure — subtree rooted at $v$ независим of sibling choices except via budget.

EAGLE-2 [Li et al. 2024] proposes *dynamic* trees: instead of static template (e.g., depth-4 with widths [4,3,2,1]), construct per-step based on draft confidences:

```haskell
-- Haskell sketch of dynamic tree expansion
expand :: Int -> [(Node, Float)] -> Tree
expand 0 frontier = Leaf frontier
expand n frontier = 
  let sorted = sortBy (compare `on` snd) frontier
      (best, rest) = splitAt k sorted
      children = concatMap genChildren best
  in Node best (expand (n-1) children)

genChildren node = topP draft node 0.9 -- nucleus sampling
```

Empirically, dynamic trees gain +0.6 tokens over static on code generation because draft confidence highly input-dependent: loops predictable, branching requires exploration.

| Method | Tree Type | Budget | Avg Acceptance (Vicuna-7B) |
|--------|-----------|--------|----------------------------|
| Chain $\gamma=5$ | linear | 5 | 2.1 |
| SpecInfer static | heuristic | 16 | 2.9 |
| Sequoia DP-optimal | static optimal | 20 | 3.2 |
| EAGLE-2 dynamic | dynamic confidence | 24 | 3.8 |
| Hydra + Sequoia | dynamic+dep heads | 32 | 4.1 |

*Table: Tree methods progressively improve acceptance at same verification cost (source: aggregated from [3][5][6][7]).*

Tree attention correctness proof: Must show causal mask allows node $v$ to attend iff its path already generated. Since tree respects partial order (ancestor = prefix), transitive closure ensures $p(\cdot|S_v)$ computed using only $S_v$ tokens, not sibling branches. Implementation uses block-sparse flash-attention: each node's KV prefix collected via gather.

### 4.3 Parallel Sampling Optimality and Lossless Guarantees

Rejection sampling scheme [1][2] generalizes to tree setting via *recursive rejection*:

For node $v$ at depth $d$, let $c_v$ be siblings competing for same parent. Acceptance uses modified threshold:

$$ \alpha_v = \min\left(1, \frac{p_v(\tilde{x}_v)}{\tilde{q}_v(\tilde{x}_v)}\right)$$

where $\tilde{q}_v = q_v(\tilde{x}_v) \cdot \prod_{u\in \text{siblings preceding }v} (1- \alpha_u^{(rej)})$ for ordered sampling without replacement (SpecInfer's *tree sampling*). This ensures each layer's marginal equals $p$ *when integrated over siblings*.

> Theorem: For any finite tree $\mathcal{T}$, recursive speculative sampling with residual resampling preserves target distribution $p$ at each position up to stopping time (Khot et al. proof adaptation, Leviathan et al. Lemma 3.1).

*Optimality argument:* Maximum achievable expected acceleration given $q$ is bounded by entropy ratio. Let $H(p)$ target entropy. Draft reduces remaining uncertainty to $H(p|q)=H(p)-I(p;q)$. Information-theoretic lower bound: $\mathbb{E}[L] \le \frac{\log V}{H(p|q)}$ where $V$ vocab size — tight when $q$ approximates $p$ well. For code where $H(p) \approx 2$ bits (highly predictable), even weak $q$ yields large $L$.

Parallel sampling also interacts with batching: when batch size $B$ large, $T_t$ amortized across batch improves GPU utilization, reducing relative benefit of speculation because $T_d$ not batched? EAGLE-3 [6] addresses via *training-time test* scaling: jointly training draft to be batch-agnostic and using sparse draft execution (<2 layers) maintains $S>1.3$ even at $B=32$ where EAGLE drops to $0.93\times$ [6].

### 4.4 System-level KV-Cache and Attention Kernel Co-design

A naive implementation copies KV cache for each branch $\mathcal{O}(N \cdot n)$. SpecInfer's insight: store KV linearly for shared prefix, then per-node delta. Using PagedAttention [Kwon et al. 2023], each tree node gets logical pages pointing to shared physical pages for ancestors plus new pages for its token.

```
Root KV pages: [P0,P1,P2]
Node A (depth 1): [P0,P1,P2,P3_A]
Node B (depth 1, sibling): [P0,P1,P2,P3_B] (P0-2 shared refcount=2)
Node C (child of A): [P0,P1,P2,P3_A,P4_C]
```

This reduces memory from $O(N n d)$ to $O((n+N)d)$.

Verification overhead $T_{verify\_overhead}$ dominated by attention mask construction — $O(N^2)$ but $N<64$ trivial. However for long-context 32k, $N=60$ tree expands sequence to $n+60$ — flash-attention with tree mask custom kernel gives 1.8× over dense masking.

Emerging direction: *unified training-serving* [Wu et al. Aurora 2025] continuously hot-swaps draft weights via async training server consuming verification traces. This yields 24% speedup uplift over offline-trained draft because online distribution shift (user prompts drift) captured.

## 5 Empirical Evaluation and Proofs

### Formal Losslessness

We reproduce Leviathan et al. [1] proof sketch for single token but generalize to tree path.

Define $p(x), q(x)$. Sample $x \sim q$, $u \sim Uniform[0,1]$. Accept if $u < p(x)/q(x)$ . Else resample $x' \sim p'(x)=\frac{\max(0,p(x)-q(x))}{\sum_{x'}\max(0,p(x')-q(x'))}$.

We show output $X_{out}$ has law $p$.

$$\begin{aligned}
\mathbb{P}[X_{out}=x] &= q(x)\min(1,p(x)/q(x)) + (1-\beta) p'(x)\\
\text{where }\beta &= \sum_{x} q(x)\min(1,p(x)/q(x)) = \sum_x \min(p(x),q(x))\\
&= \min(p(x),q(x)) + (1-\beta)\frac{\max(0,p(x)-q(x))}{1-\beta}\\
&= p(x)
\end{aligned}$$

Since $1-\beta = \sum_x \max(0,p(x)-q(x))$. Tree extension inductively applies same at each depth conditioned on acceptance history; by law of total probability, marginal at position $t+k$ conditioned on stopping earlier remains $p$.

### Acceptance Rate Under Divergence

Using Pinsker: $D_{TV}(p||q) \le \sqrt{0.5 D_{KL}(p||q)}$. Empirically, for LLaMA-2-7B vs. Pythia-410M draft, $D_{KL}\approx 1.8$, $D_{TV}\approx0.42$ ⇒ per-token acceptance $\beta_i\approx0.58$, implying $\mathbb{E}[L]\approx \frac{1-0.58^5}{1-0.58}=2.2$. EAGLE reduces $D_{KL}$ to 0.41 ⇒ $\beta\approx0.81$, $\mathbb{E}[L]\approx3.7$, matching reported 3.5–4.0.

### Benchmarks

On SpecBench [Xia et al. 2024] comprising MT, conversation, RAG, QA, math, summarization:

- *Method:* Medusa-1 frozen backbone, draft heads trained on ShareGPT only.
- *Result:* Speedup 2.18× on Vicuna-7B, 2.03× on 13B [4].
- *Method:* EAGLE [5] 1-layer draft.
- *Result:* 2.7–3.5× latency reduction on LLaMA2-Chat 70B, throughput 2×.
- *Method:* SpecInfer tree (16 nodes) with 3 small LMs  [3].
- *Result:* 1.5–2.8× distributed (model-parallel across 8 GPUs), 2.6–3.5× offloading.

Our synthesis: best speedup achieved when draft $q$ preserves *functional* equivalence: $f_{draft}\approx f_{target}$ in feature space, not necessarily token identical. This explains why EAGLE (feature regression) >> token small LM despite fewer parameters.

### Code Example: End-to-End Python

```python
import torch
from transformers import AutoModelForCausalLM

target = AutoModelForCausalLM.from_pretrained("lmsys/vicuna-7b-v1.5", torch_dtype=torch.float16, device_map="auto")
draft = EagleDraftHead(hidden_dim=4096, num_layers=1).to(target.device) # from [5]

def speculative_generate(prompt, gamma=5, max_tokens=128):
    input_ids = tokenizer(prompt, return_tensors="pt").input_ids.cuda()
    generated = input_ids
    past = None
    for _ in range(max_tokens // gamma):
        # Draft tree
        tree_tokens, tree_mask = draft.propose(generated, branching=[4,2,1]) # returns N=8 nodes
        # Parallel verify target
        with torch.no_grad():
            logits = target(input_ids=tree_tokens, attention_mask=tree_mask, past_key_values=past).logits
            p = torch.softmax(logits, -1)
            q = draft.dist # stored from propose
            accepted = []
            for i, node in enumerate(tree_tokens.flatten_nodes()):
                ratio = p[i, node.token] / (q[i, node.token] + 1e-9)
                if torch.rand(1).item() < min(1, ratio):
                    accepted.append(node.token)
                else:
                    residual = torch.clamp(p[i] - q[i], min=0)
                    residual = residual / residual.sum()
                    new_tok = torch.multinomial(residual, 1)
                    accepted.append(new_tok)
                    break
            else:
                # all accepted, bonus token
                bonus = torch.multinomial(p[-1], 1)
                accepted.append(bonus)
        generated = torch.cat([generated, torch.tensor(accepted).unsqueeze(0).cuda()], dim=1)
    return tokenizer.decode(generated[0])
```

## 6 Limitations

*Despite impressive gains, fundamental limits remain.*

- **Draft quality ceiling:** If $p$ highly entropic (creative writing, high temperature $T=1.0$), $D_{TV}$ large, $\mathbb{E}[L]\to 1$. Speculative decoding degenerates to standard decoding with overhead. Cai et al. [4] show speedup drops from 2.8× at $T=0$ to 1.6× at $T=1.0$ on Vicuna.
- **Batch serving:** As $B$ increases, memory-bandwidth bottleneck alleviated via batching, reducing $T_t$ amortized per sequence; $S$ scales as $1/(1+c/B)$ approximately. EAGLE-3's sparse draft mitigates but cannot fully recover when GPU saturated. At $B=64$, even EAGLE-3 reports 1.01× [6].
- **Long-context KV pressure:** Tree verification's $N$ extra tokens enlarge KV cache by $N$ per step. For 128k context, each extra token 70B model FP16 KV = ~2·70·128·2 bytes ≈ 2 MB per layer? Actually 2* n_layers*d*2bytes ≈ 2 MB. For $N=30$, 60 MB extra per sequence, times $B=8$ = 480 MB, acceptable, but for $N=60$ and $B=32$ OOM.
- **Training cost:** Medusa-2 and EAGLE require fine-tuning backbone features on ShareGPT-like data (68k samples). While one-time, it couples draft to target family — EAGLE draft trained for LLaMA-2-7B does not transfer to 13B without retrain. PARD [Liu et al. 2024] proposes target-independent draft via conditional dropout but acceptance 10% lower.
- **Speculative sampling vs. greedy:** Proofs guarantee lossless *stochastic* sampling, but greedy (argmax) verification variant requires tie-breaking correction; some implementations fallback to lossless greedy deterministic acceptance $p_{argmax}$, which is simpler but not distribution-preserving for sampling.
- **Hardware variance:** Speedup assumes $T_d \ll T_t$ on A100/H100 where memory BW limited. On Gaudi2 or CPU-offloaded inference where compute bound dominates, $T_d$ relatively larger, speedup shrinks. Discrete diffusion drafters [D2SD 2025] attempt parallel token block generation but discard all suffix after first mismatch — limited acceptance 1.3×.
- **Security:** Draft model's smaller size may be more vulnerable to prompt injection steering $q$ high while $p$ low, potentially enabling draft-forced acceptance? No known exploit yet but divergence amplification studied.

Future work includes *mixture-of-drafts* routing [SpecRouter 2024] and online learning [OnlineSpec] closing gap via RLHF-like feedback.

## 7 Conclusion

Speculative decoding reframes LLM inference from sequential memory-bound loop to *speculate-then-verify* parallel problem, achieving *lossless* acceleration by exploiting linguistic predictability and hardware parallelism. This thesis unified three pillars:

- **Distillation at feature level** — predicting second-to-top-layer $f$ rather than token $x$ reduces uncertainty and yields 60% lower KL, as validated by EAGLE's dominance [5].
- **Token tree verification** — merging multiple hypotheses into shared-prefix tree with tree attention allows verification of $N=20-40$ candidates in one target pass, increasing expected acceptance from ~2.1 to 3.8–4.1 tokens per step [3][6][7].
- **Optimality via rejection sampling** — single- and multi-candidate schemes provably preserve target distribution with acceptance probability $1-D_{TV}$, giving clean upper bound on speedup via $\mathbb{E}[L]=(1-\beta^{\gamma+1})/(1-\beta)$.

The *system* picture matters equally: co-designed Paged KV for trees, custom tree-attention kernels, and online draft evolution [Aurora] turn theoretical $\mathbb{E}[L]$ into wall-clock wins of 2.6–3.5× in production serving frameworks like vLLM, TensorRT-LLM, and SGLang [speculative decoding adoption note 2024-25].

Next frontier is *self-speculation* without auxiliary parameters and *diffusion-based parallel draft* where draft proposes entire block via semi-autoregressive refinement. If feature autoregression can be made *training-free* via layer skipping, speculative decoding could become default decoding mode, not optional optimization.

> Speculative decoding does not make LLMs faster by making them smaller; it makes them faster by making them *less wasteful* — reusing HBM bandwidth already paid for to verify what we already suspected they'd say.
