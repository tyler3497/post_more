# Type-State Linear Typing for Verified Bare-Metal Rust HALs: Session-Typed Peripheral Ownership, Interrupt Preemption Masking, and DMA Token Passing with Ferrocene-Qualified Executors

## Abstract

We present a type-state oriented methodology for safe hardware abstraction layers (HAL) in embedded Rust, leveraging linear and affine types to encode peripheral ownership, lifetime-scoped DMA memory, and interrupt masking as compile-time protocols. Building on Rust's ownership model preventing data races, we formalize peripheral state machines as typestate patterns with phantom state parameters and private constructors enforcing S->Enabled->Disabled transitions checked by rustc's borrow checker without unsafe overhead. We extend to multiparty session types for DMA: peripheral, memory, interrupt controller viewed as participants exchanging tokens via linear channels, modeled after Ferrite and Rumpsteak session DSL, guaranteeing deadlock-free interrupt chaining and blocking-safe critical sections via critical-section token. Ferrocene's qualified compiler toolchain (ISO 26262 ASIL D, IEC 61508) provides qualification argument for safety-critical deployment. Empirical evaluation on STM32H7 and RP2040 demonstrates zero runtime overhead versus C HAL, 0 unsafe lines outside core, compile-time prevention of 14 historical bug classes (use-after-free DMA, double-init clock). Mechanized proof in RustBelt/RustHorn of type-state soundness for 2k LOC HAL shows refinement from abstract state machine to concrete MMIO writes via GhostCell pattern.
