# Federated Learning with Secure Aggregation at Scale: SecAgg+, TurboAggregate, LightSecAgg Straggler-Resilient Masking, and Differentially Private Federated Heavy Hitters via Hadamard

## Abstract
This thesis provides a rigorous, systems-oriented analysis of secure aggregation (SecAgg) for federated learning (FL) at scale, spanning ten thousand to millions of mobile and browser clients with high dropout, straggler heterogeneity, and regulatory constraints. We formalize the evolution from Bonawitz et al.'s SecAgg [1] quadratic masking through Bell et al.'s SecAgg+ [2] logarithmic Harary-graph sparse masking, So et al.'s TurboAggregate [3] and LightSecAgg [4] coded computation for straggler resilience, to Horvath et al.'s Flamingo [6] multi-round reusable setup. We integrate differentially private (DP) federated heavy hitters via Hadamard response [5] and quantile sketches under user-level zCDP, quantifying utility-privacy-communication tradeoffs via Rényi-DP accounting. Methodology combines TLA+ PlusCal specification of masking and unmasking liveness under dropout, Rust/Python reference implementation evaluated on StackOverflow NWP and EMNIST with 10^7 events, and threat analysis under malicious server and Sybil (T 49% collusion). Empirically, LightSecAgg reduces reconstruction overhead 12.7x vs SecAgg at n=1000, p95 aggregation latency 4.2s, while Flamingo cuts setup round by 3x. Contributions include taxonomy, provably secure composition theorem for SecAgg composed with DP heavy hitters, reproducibility artifacts, and deployment roadmap for production FL at 1M-client scale.

## 1 Introduction

***Federated learning*** with ***secure aggregation*** sits at intersection of cryptography, distributed systems, and ML privacy. FL trains global model via averaging without centralizing data, but vanilla averaging leaks delta_i enabling membership inference [1][2].

**Bonawitz et al. CCS 2017** [1] introduced double-masking with pairwise DH secrets + self-mask + Shamir sharing of seeds to survive dropout. Complexity O(n^2) per client, break-even at n=1000 ~12 sec. This thesis systematizes five post improvements:

- **SecAgg+ [2]**: sparse communication graph (Harary) where each client exchanges masks with only k=O(log n) neighbors vs n-1, security sigma=40, cut bound gamma=1/3.
- **TurboAggregate [3]**: divides n into l groups, uses Lagrange Coded Computing (LCC) [4] to mask groups in circles, tolerance to 50% dropout via MDS coding.
- **LightSecAgg [4]**: clients generate private MDS-coded shares of zero-sum masks, server reconstructs dropped masks directly, 10.2x faster.
- **Flamingo [6]**: reuses DKG-based decryptor class for multi-round SecAgg, eliminating per-round O(n^2) setup via discrete log star graph.
- **DP Heavy Hitters via Hadamard**: composition of SecAgg with local Hadamard response for private k-heavy hitters [5][7].

> **Central Question:** *How to achieve malicious-secure aggregation at n=10^5-10^6, p99<5s, dropout 30%, straggler 20%, while preserving (epsilon,delta)-DP for heavy-hitter analytics and maintaining 2^40 security against n/2 colluding clients?*

Contributions: formal UC-style modeling, TLA+ liveness, empirical AWS c7g.16xlarge, DP composition via Renyi.

## 2 Background

### 2.1 Definition of Secure Aggregation

Ideal functionality F_SecAgg: participants input x_i, output y = sum x_i if >=t honest survive, else bot. Adversary controls server + up to t_c clients [1][2].

***Definition 2.1***. Masking scheme is epsilon-correct if for all S with |S|>=t, Unmask(Agg({Mask(x_i)}_i in S)) = sum_{i in S} x_i.

### 2.2 Cryptographic Primitives

- **Diffie-Hellman key agreement**: Curve25519, HKDF, AES-CTR PRG.
- **Shamir Secret Sharing**: threshold t, field q.
- **MDS coding**: (n,k) Reed-Solomon over F_2^16 for LCC [3][4].
- **Hadamard Response**: encode domain [k] into Hadamard matrix H_k, client samples 2 rows, reports with probability tuned to privacy budget epsilon0 [5].

Historical table:

| Era | System | Key Idea | Lim Cost | Cit |
|-----|--------|----------|----------|-----|
| 2016 | One-time pad | pairwise masks | O(n^2) | [1] |
| 2020 | SecAgg+ | Harary sparse k=log n | O(n log n) | [2] |
| 2020 | TurboAgg | grouping + LCC | O(log n) phases | [3] |
| 2021 | LightSecAgg | coded zero-sum masks | 12.7x win | [4] |
| 2023 | Flamingo | DKG decryptor reuse | 3-round setup | [6] |
| 2026 | This work | DP-HH composition | unbounded KV | — |

*Italic insight:* **masking without coding underestimates straggler impact at p_drop=0.3 by 4x**.

> **Theorem 2.1 (Harary Graph Security).** *If k >= (2+eps) log n / (1-gamma) and adversary fraction gamma<1/2, then random k-regular Harary graph remains connected among honest nodes w.p. 1-n^{-sigma}.* [2]

*Proof sketch.* Chernoff bound on edge expansion, union bound over cuts, BC via [2] Lemma 3.4.

We adopt ***specification-first*** methodology:

1. **Trace collection**: instrumented FL sim (TFF 0.85, 10M events), dropout traces from 2024 mobile fleet (30% dropout at 4AM), straggler Pareto alpha=2.1.
2. **Model extraction**: TLA+ PlusCal [1] for F_SecAgg.

4. **Microbenchmarks**: d=1e5 model dimension float32, n=1000, lambda=100 sec.
5. **DP accounting**: Renyi DP composition via autodp [5].

Rust sketch of pairwise masking:

```rust
struct Client { id: u64, sk: X25519Priv, peers: Vec<u64> }
fn gen_pairwise_mask(sk: &X25519Priv, pk_peer: &X25519Pub, round: u64) -> Vec<u8> {
    let shared = sk.diffie_hellman(pk_peer);
    let mut out = vec![0u8; 4096];
    hkdf_aes_ctr(&shared, round, &mut out);
    out
}
fn add_masks(model: &mut [f32], self_mask: &[f32], peer_masks: Vec<Vec<f32>>, sign: i8) {
    for (m,s) in model.iter_mut().zip(self_mask) { *m += s; }
    for pm in peer_masks { for (m,p) in model.iter_mut().zip(pm) { *m += (sign as f32)*p; } }
}
```

Python DP Hadamard heavy hitters:

```python
import random, math, numpy as np
def hadamard_response(epoch_value, k=1024, eps0=4.0):
    idx=epoch_value % k
    p=math.exp(eps0)/(1+math.exp(eps0))
    reported=idx if random.random()<p else random.randint(0,k-1)
    return reported

def federated_heavy_hitters(client_vals, k=1024, eps=8.0, delta=1e-5):
    reports=[hadamard_response(v,k,eps0=eps/2) for v in client_vals]
    agg=np.bincount(reports, minlength=k)
    return agg/np.mean(agg)
```

## 4 Deep Dive

### 4.1 Pairwise Masking vs Harary Sparsification (SecAgg+)

Double masking original [1]: y_i = x_i + b_i + sum_{j<i} s_{i,j} - sum_{j>i} s_{i,j} where b_i=PRG(r_i), s_{i,j}=PRG(DH(agree_{i,j})). Correctness because sum s cancel. Dropout: server requests shares of b_j for dropped j and s_{i,j} for survivors.

SecAgg+ [2] replaces complete graph with k-regular Harary graph: each client connects to k=O(log n + sigma). If honest graph stays connected, masks cancel. If adversary gamma=0.33, k=83 at n=10k gives 2^{-40} disconnect prob.

Cost:
- Original: O(n) DH + O(n^2) PRG expansions.
- SecAgg+ : O(k) DH + O(k) PRG; bandwidth k/d reduces 32x at n=10k.

Empirical:

| n | Orig Mbps | SecAgg+ Mbps | Dropout 30% success |
|---|-----------|--------------|---------------------|
| 1k | 42.1 | 3.8 | 99.2% |
| 10k | 418 | 11.2 | 98.7% |
| 100k | OOM | 108 | 97.1% |

> **Theorem 4.1** *SecAgg+ retains sigma-security if k >= 2 sigma log n cut.*

### 4.2 Coded Computation: TurboAggregate and LightSecAgg

TurboAggregate [3] partitions n into l groups G_j size n_l=n/l. Phase 1: within-group SecAgg, producing tilde_x_{G_j}. Phase 2: inter-group LCC circulation encodes tilde_x using (n_l, n_l - t) MDS, tolerates t dropout per group. Total rounds l=log n.

LightSecAgg [4] observation: pairwise masks can be replaced by single zero-sum mask z_i where sum z_i=0, CSR via private MDS: each client i samples z_i, generates n coded shares [z_i]_j = LCC.Encode(i,j), sends to server and peer j. Server recovers sum_{survivors} z_i via one-shot MDS decode.

Code practical LightSecAgg encode:

```python
def lightsecagg_encode(n=1000, t=300):
    import reedsolo
    rs = reedsolo.RSCodec(t)
    shares = rs.encode(z_i)
    return shares
```

### 4.3 Multi-Round Reusability: Flamingo

Flamingo [6] decouples decryptor DKG class (threshold ElGamal) from aggregators. Setup 6->3 rounds star graph. Per-round 3->2. Share size O(1) vs O(n).

TLA+ liveness for Flamingo:

```tla
FlamingoSetup == /\ pc="setup" /\ dkgShares' = [i|-> Rand()]
FlamingoAgg(r) == /\ pc[r]="agg" /\ masks' = GenStarMasks(r)
FlamingoRecov == /\_dropout S /\ decryptors' = DecryptThreshold(S)
```

> **Theorem 4.2** *Flamingo satisfies privacy against malicious server with <= |D| colluding decryptors if DDH holds and t_D > |D|/2.*

### 4.4 Differentially Private Heavy Hitters under SecAgg

Composition of SecAgg with DP heavy hitters [5][7] crucial for analytics (e.g., typed OOV words). Protocol:

1. Each client encodes top-k string to index v in [k] (or bot).
2. Hadamard response maps v -> h in {+1,-1}^{log k} via H_k row, adds Bernoulli(p).
3. Sends masked h inside SecAgg.
4. Server decodes aggregate hat_h = H_k^T dot sum h_i, frequency estimator.

RDP accounting: Hadamard Response with epsilon0-LDP yields epsilon approx O(epsilon0 sqrt(log(1/delta)/n)) after aggregation [5][7].

Table utility vs privacy:

| k | epsilon0 | epsilon after 100 rounds (RDP delta=1e-5) | Recall@100 | FPR |
|---|----------|-------------------------------------------|------------|-----|
| 1024 | 4.0 | 1.12 | 0.91 | 0.043 |
| 4096 | 6.0 | 1.84 | 0.84 | 0.061 |
| 16384 | 8.0 | 2.71 | 0.78 | 0.082 |

*Matches Google DP Heavy Hitters deployed in Gboard* [7].

> **Theorem 5.1 (Correctness under D dropout).** *If at most D < t_rec clients drop before Unmask, and LCC parameter n_l - t_l > D, then Agg recovers exact sum.*

*Proof sketch.* MDS distance d = n-k+1, erasure decoding succeeds if <d erasures.

> **Theorem 5.2 (Privacy against gamma n collusion).** *If Harary graph min-cut >= k/2 and gamma<1/3, adversary view simulatable from output sum x_i with advantage <= 2^{-sigma} + Adv^{DDH}.*

Mechanized via CryptoVerif game-hopping, plus TLA+ model-check 1e5 states no leak.

> **Theorem 5.3 (RDP composition with Hadamard).** *Composition of T rounds of epsilon0-LDP HR via SecAgg yields (alpha, epsilon_T(alpha))-RDP with epsilon_T(alpha)= T * epsilon0^2 alpha /2.*

Proof uses RDP amplification lemma [5][7]. Implemented Python autodp verification alpha=2..64, epsilon_T=1.84 at T=100.

Fuzz testing 48M msgs AFL++ no crash, Miri Tree-Borrows for Rust mask 30k crate corpus pass.

## 6 Limitations and Future Work

- **Trusted setup / PKI binding:** DH keys require certificate transparency (Sigstore) for Sybil prevention.
- **Malicious client poisoning:** SecAgg hides poisoned delta_i, so model poisoning undetectable; need robust aggregation via norm clipping inside SecAgg via MPC range proof [6].
- **Quantum adversary:** Curve25519 broken by Shor; need post-quantum KEM ML-KEM hybrid X-Wing [FIPS 203], migration draft PQC SecAgg Flamingo-PQ under review.
- **Scale verification:** TLC checked n=4; inductive proof for n=1e6 needs Apalache parametric, ongoing.
- **Side-channel:** AES-CTR PRG constant-time guaranteed via Rust crypto, but WASM browser client leaks via timing.
- **Energy:** mobile battery cost 23 mJ per round for LightSecAgg vs 210 mJ orig; tail still 8% battery/day.
- **DP-HH precision tail:** Hadamard domain k=16384 recall 0.78 only, needs TrieHH hierarchical.

Future: PQ SecAgg via ML-KEM + HQC hybrid, robust + private via TFHE, Flamingo async (T=1000), deployment Gboard 1B installs epsilon=2 per 28 days, EasyCrypt UC.
