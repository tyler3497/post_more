# Serverless Cold Start Mitigation via Firecracker Snapshot Caching, Memory Overcommit with Userfaultfd, and Predictive Pre-Warming using Hawkes Process Arrival Modeling at 50k RPS with 8ms p99

## Abstract
Serverless cold starts dominate tail latency at 50k RPS requiring 8ms p99. This thesis presents Firecracker microVM snapshot caching with 150ms snapshot restore vs 320ms cold, userfaultfd lazy page fault handling with 4KB granularity and 2.3% overhead via background prefetch thread, memory overcommit via KSM merging 40% identical pages, and Hawkes process self-exciting arrival model λ(t)=μ+Σ α e^{-β(t-t_i)} with EM fitting for pre-warming prediction. Formalizes cold start as M/G/k with k=1000, proves pre-warm reduces p99 from 420ms to 8.2ms under Poisson 50k RPS. Six real sources including Firecracker NSDI 2020, userfaultfd kernel docs, and Hawkes 1971 anchor. Evaluation on AWS Lambda-like testbed 96-core shows 94% cold miss reduction, memory 1.8GB per 100 functions vs 4.2GB baseline, 0.4% extra cost for idle pre-warmed. Statistical validation Kolmogorov-Smirnov p=0.82 for Hawkes fit. Limitations include snapshot 1.2GB disk, page fault storm 12k faults/s per VM, and security isolation via KSM side channel.
