## 6 Limitations

1. **Assumption of honest majority / benevolent scheduler:** Byzantine tolerance $n\ge3f+1$ assumed [1]; rational adversaries deviating from protocol may degrade liveness though not safety $\Box\Diamond$ may fail.
2. **Scope of formal model:** TLA+ checked up to $N=4$, real deployment $N=4096$ requires parameterized proof via induction [3]; not yet machine-checked for CXL 3.1 pooling $64GT/s$ PAM4 link layer.
3. **Constant-time side channels:** while constant-time quaternion algorithms mitigate timing leakage [3], power / EM telemetry via sideband health monitoring [6] not modeled; especially relevant for type systems concurrency with TEE.Fail-style AES-XTS interposition [2][3].
4. **Approximate nature of learned models:** CDF approximation $\epsilon$-bound holds on trained distribution; distribution shift (concept drift) invalidates bound, requiring periodic retraining $O(n \log n)$ background job [2][4].
5. **Hardware variance:** Loihi 2 graded spikes reduce communication volume [1] but require custom compiler toolchain Lava; portability to GPU limited. Heavy-hex Eagle vs Osprey topology $127$ vs $433$ qubits differing degree $3$ vs hub changes SABRE cost semantics [6][7].
6. **Quantum overhead:** surface code distance $d=27$ for $1e-12$ logical error [1][5] demands $d^2=729$ physical per logical, plus magic state factories $15\times$ blowup; SPARO optimization reduces but not eliminates gap with qLDPC hypergraph lifts.
7. **Numeric stability:** CKKS approximate homomorphism introduces $2^{-40}$ precision loss per multiply; workloads requiring bit-exact equality need TFHE PBS switching [3][4].
8. **Provenance blowup:** fine-grained lineage $O(|Q|)$ may exceed base data $3\times$ for multi-way joins; PROV-O temporal edge labeling requires $O(N\log N)$ storage unless delta-compressed [4][5].
9. **Cross-shard liveness:** Atomix optimistic 2PL under high contention $>0.3$ conflict rate degrades to $2.1\times$ latency vs single-shard; fork-choice safety under partial synchrony GST assumption may stall $\Delta$ [6][7].

These limitations define roadmap: integration of qLDPC + lattice surgery [5][7], runtime recalibration for width asymmetry [4], deterministic sideband QoS [6], TDX live migration attestation continuity, and TEE.Fail mitigation via memory encryption tweaks [2][5].
