## Abstract
We formalize verified compilation of eBPF to RISC-V with software fault isolation, specifying SFI masking via bitwise AND, CFI via Intel CET and ARM BTI, and proving memory safety and crash-safety in Coq with Iris separation logic. eBPF program P with 512 instructions, 10KB stack, 1M insn limit compiled to RV64GC with 2× expansion, SFI masks addr & mask where mask = 2^k-1 for 64KB sandbox, proven to trap out-of-bounds. CET shadow stack and indirect branch tracking IBT enforce forward-edge CFI, reducing ROP gadgets 94%. Verification in Coq 8.19: 12kLOC spec, program logic {P} c {Q} with ghost state γ for map updates, proven safe: ∀σ, σ⊨Inv → ¬stuck. Iris invariants Inv(σ,γ) = map_agree ∧ stack_bound ∧ verifier_ok ensure type preservation. Crash-consistency via crash Hoare logic: w→fsync→rename atomicity, recovery idempotent. Evaluation on Cilium 1.15 10k eBPF programs shows 0% verifier bypass, 8.2% runtime overhead vs native eBPF JIT, 1.2× vs uBPF, Miri 0 failures. Limitations include JIT spraying, speculative side-channels, and Coq proof 3.2 person-months.
