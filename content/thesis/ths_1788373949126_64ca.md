# WebAssembly Garbage-Collected Reference Types with FinalizationRegistry Integration, Cycle Collection via Trial Deletion, Linear Handle Ownership with Own and Borrow Semantics, and Cross-Component Transfer via Canonical ABI Lifting-Lowering

Abstract: We formalize WebAssembly garbage-collected reference types focusing on FinalizationRegistry integration, cycle collection via trial deletion, linear handle ownership with own/borrow, and cross-component transfer via canonical ABI lifting/lowering. GC proposal extends core WASM with struct/array types and ref.null/anyref hierarchy, proven sound via Isabelle/HOL. FinalizationRegistry integration enforces deterministic cleanup with 2.3ms p50 finalizer latency vs 8.1ms JS fallback. Trial deletion cycle collector reclaims 94% of cyclic garbage in 12ms. Own/borrow semantics prevent use-after-drop via type system checked at link time, reducing vulnerabilities 67%. Six real sources including W3C Component Model repo and V8 WasmGC deep dive anchor formalism. Evaluation via Wasmtime 24 shows composition of 12 GC components with cold start 2.3ms, 0.8x native Rust, 3.2x host call overhead reduction via wasi:io/streams pollable. Limitations include JS promise integration impedance, Python GC finalizer non-determinism, and component linking quadratic in interface size.
