# Time-Optimal Multi-Agent Path Finding: Conflict-Based Search CBS, ECBS Suboptimality Bounds, LaCAM Lazy Constraints, and Priority Inheritance PIBT for Lifelong MAPF

## Abstract
Multi-Agent Path Finding (MAPF) seeks collision-free paths for teams of agents on a shared graph while optimizing time-centric objectives. This thesis provides a unified treatment of four landmark solver families that define the modern Pareto frontier: Conflict-Based Search (CBS) for optimal sum-of-costs and makespan, Enhanced CBS (ECBS) and Explicit Estimation CBS (EECBS) for bounded-suboptimal search with factor w guarantees, LaCAM and LaCAM* for scalable lazy constraint addition with eventual optimality, and Priority Inheritance with Backtracking (PIBT) as a one-step rule-based engine for Lifelong MAPF via Rolling Horizon Collision Resolution (RHCR). We formalize constraint-tree invariants, focal-search suboptimality preservation, configuration-space DFS completeness, and priority inheritance deadlock-freedom, and synthesize empirical results on the Stern et al. 2019 benchmark suite (33 maps, 6 domains) up to 1000 agents. We show how composition—CBS optimality at low density, ECBS/EECBS anytime tradeoff, LaCAM* high-throughput initialization, PIBT reactive completion—enables warehouse-scale deployment where RHCR windows and PIBT fallback jointly sustain 10k agents throughput.

## 1 Introduction
The **time-optimal** MAPF problem asks for collision-free routes for *k* agents on graph *G=(V,E)* minimizing either **sum-of-costs (SoC)** *Σ_i |π_i|* or **makespan** *max_i |π_i|*, where each agent must move from *s_i* to *g_i* via adjacent moves or waits in discrete time [1][2]. Applications span automated warehouses (1000+ robots), airport surface operations, and UAV traffic management [3][4]. Despite NP-hardness for both objectives [Yu & LaValle 2013], real systems demand solvers that are *complete*, *bounded-suboptimal* (*cost ≤ w·C**), *fast* (<10s), and *scalable* (≥1000 agents).

Historically, coupled A* in joint space *O(|V|^k)* scaled to <10 agents. Decoupled approaches revolutionized scalability. Conflict-Based Search (CBS) [1][2] introduced a two-level constraint tree (CT) search that remains optimal yet expands orders of magnitude fewer states than A*. Its bounded-suboptimal variant ECBS [3] replaces best-first with focal search using same factor *w* on both levels, achieving 10-100× speedup at *w=1.1* while guaranteeing *cost ≤ w·C**. EECBS [4] corrects ECBS's negative correlation between *f* and heuristic *d* via explicit estimation search (EES).

Parallel to CBS, *lazy* search emerged: LaCAM (Lazy Constraints Addition Search) [5] performs DFS over *joint configurations* *C^t=(v_1^t,...,v_k^t)*, generating only **one** successor per expansion using PIBT as generator, and lazily adds constraints on revisit to force diversity. Its anytime variant LaCAM* [6] eventually converges to optimal when costs are accumulated transitions, solving 99% of benchmark instances up to 1000 agents within 10s.

Finally, Lifelong MAPF (LMAPF) where agents receive new goals upon arrival requires *throughput* maximization. PIBT [7] provides one-step priority-driven planner with inheritance and backtracking that is deadlock-free on biconnected graphs and scales to 10k agents. RHCR frames LMAPF as sequence of windowed MAPF instances.

This thesis unifies these threads:

- **We formalize** CT invariants, focal lower bounds, lazy configuration DFS, and PIBT priority DAG acyclicity.
- **We prove** suboptimality preservation *cost(N) ≤ w·LB* for ECBS, eventual optimality of LaCAM*, and completeness of LaCAM.
- **We synthesize** empirical tradeoffs across 6 map domains.
- **We propose** deployment blueprint: RHCR + LaCAM* + PIBT fallback, infinite KV storage.

> **Theorem 1 (CBS Optimality):** If low-level search returns optimal paths respecting constraints, high-level best-first over CT ordered by *cost(N)=Σ_i |path_i|* returns optimal SoC solution.

> **Theorem 2 (ECBS Bounded Suboptimality):** For factor *w ≥1*, let *f_min^i(N)* be min *f* in low-level OPEN for agent *i*, *LB(N)= Σ_i f_min^i(N)*, *LB = min LB(N)*. If *FOCAL={N | cost(N) ≤ w·LB}* sorted by conflict count, returned solution satisfies *SoC ≤ w·C**.

## 2 Background

### 2.1 Formal Definition
MAPF instance ⟨*G=(V,E)*, *A={a_1..a_k}*, *s:A→V*, *g:A→V*⟩. Path *π_i=(v_i^0,...,v_i^T)* with *v_i^0=s_i*, *v_i^T=g_i*. Two conflict types dominate [8]:

- **Vertex conflict:** ∃*t,i≠j* with *v_i^t = v_j^t*
- **Edge (swap) conflict:** ∃*t,i≠j* with *v_i^t=v_j^{t+1} ∧ v_i^{t+1}=v_j^t*

Minimize *SoC(Π)=Σ_i(|π_i|-1)* or *Makespan(Π)=max_i(|π_i|-1)*. Both NP-hard.

### 2.2 Benchmarks
Stern et al. [8] introduced 33 grid maps across 6 types: game grids, city streets, mazes, rooms, open+random, warehouse. Each map has 25 random and 25 even scenarios, up to 1000 agents, >1.5M instances total. Metrics: success rate, runtime, SoC, makespan.

### 2.3 Solver Taxonomy

| Family | Search Space | Optimality | Completeness | Scalability | Use |
|---|---|---|---|---|---|
| CBS [1][2] | Constraint Tree | Optimal | Yes | 50-150 agents | Optimal warehousing |
| ECBS [3]/EECBS [4] | CT+Focal | *w*-bounded | Yes | 200-400 *w=1.2* | Bounded-suboptimal |
| LaCAM [5]/LaCAM* [6] | Config DFS lazy | Suboptimal→eventual optimal | Yes | 1000 agents <10s | Fast feasible |
| PIBT [7] | One-step inheritance | None (greedy) | Biconnected | 10k real-time | Lifelong MAPF |

*Table 1: MAPF solver families.*

Key insight: ***no single solver dominates all densities***. Optimal at low density, bounded-suboptimal at mid, rule-based at ultra-scale.

## 3 Methodology
Our methodology combines **literature anchoring**, **algorithmic decomposition**, and **synthetic empirical analysis**.

1. **Literature anchoring:** 8 primary sources verified via web search: CBS AAAI 2012 [1], AIJ 2015 [2], ECBS SOCS 2014 [3], EECBS AAAI 2021 [4], LaCAM AAAI 2023 [5], LaCAM* IJCAI 2023 [6], PIBT AIJ 2022 [7], MAPF benchmarks SoCS 2019 [8].
2. **Unified notation:** *N* CT node with *N.constraints*, *N.paths*, *N.cost*, *N.LB*. Low-level *f=g+h* admissible. *w* suboptimality. *C^t* joint configuration.
3. **Formal modeling:** TLA+ for CT invariants, Haskell for PIBT, Python for focal.

### TLA+ Fragment
```tla
\* CBS CT invariant
Invariant == 
  /\ \A N \in CT : N.cost >= N.LB
  /\ LB = Min({N.LB : N \in OPEN})
  /\ \A N \in FOCAL : N.cost <= w * LB
Next == 
  \E N \in FOCAL : 
    /\ N = CHOOSE n \in FOCAL : \A m \in FOCAL : n.hc <= m.hc
    /\ ResolveConflict(N)
```

### Haskell: PIBT Core
```haskell
type Agent = Int
type Vertex = Int
pibt :: [Agent] -> Map Agent Vertex -> Map Agent Vertex -> Map Agent Double -> Map Agent Vertex
pibt [] _ next _ = next
pibt (a:as) cur nxt prio =
  let moves = sortBy (compare `on` distToGoal) (neighbors (cur!a) ++ [cur!a])
      try [] = backtrack a
      try (v:vs) = if occupied v nxt then
                      let b = owner v nxt
                          prio' = Map.insert b (prio!a) prio
                      in case pibt [b] cur nxt prio' of
                           nxt' | success nxt' -> Map.insert a v nxt'
                                | otherwise -> try vs
                   else Map.insert a v nxt
  in try moves
```

### Python: Low-Level Focal
```python
def low_level_focal(agent, constraints, other_paths, w=1.5):
    import heapq
    OPEN = [(h(s), 0, s, [])]
    best_f = float('inf')
    while OPEN:
        f, g, v, path = heapq.heappop(OPEN)
        best_f = min(best_f, f)
        if v == goal[agent] and respects_constraints(path, constraints):
            f_min = OPEN[0][0] if OPEN else f
            return path, f_min
        for nb in neighbors(v):
            if violates(nb, constraints, g+1): continue
            f_nb = g+1 + h(nb)
            conflicts = count_conflicts(path+[nb], other_paths)
            heapq.heappush(OPEN, (f_nb, g+1, nb, path+[nb]))
    return None, float('inf')
```

### Rust: LaCAM Successor
```rust
fn lacam_successor(config: &Config, constraints: &Constraints) -> Option<Config> {
    let mut order = config.agents_sorted_by_priority();
    let mut next = Config::new();
    for &a in &order {
        let candidates = allowed_moves(a, config, constraints);
        let chosen = candidates.iter()
            .min_by_key(|v| heuristic(**v, goal[a]) + conflict_penalty(**v, &next))?;
        next.insert(a, *chosen);
    }
    Some(next)
}
```

## 4 Deep Dive

### 4.1 CBS: Two-Level Optimal Search
CBS [1][2] starts with individually optimal paths ignoring collisions. High level maintains CT. Each node *N* stores constraints *N.C* (vertex *(a,v,t)* or edge *(a,u,v,t)*), solution *N.Π* respecting *N.C*, cost *N.cost=Σ_i|π_i|*, *LB(N)=Σ_i f_min^i*.

Loop:
1. Pop best-cost *N* from OPEN
2. Validate *N.Π* for first conflict
3. If none, return optimal
4. Else branch *N1=N∪{(a_i,v,t)}*, *N2=N∪{(a_j,v,t)}*, replan affected agent via space-time A*, push.

> **Theorem (CBS Completeness):** CT enumeration finite, and if solution exists, some CT node contains its constraints, so best-first eventually finds it.

Optimizations: *bypassing* (equal-cost alternative without conflict), *MDD-based reasoning*, *WDG heuristic* (weighted dependency graph min vertex cover) [Felner et al. 2018], *cardinal conflict prioritization*.

CBS shines sparse (random-32-32-20, 100 agents <1s) but degrades corridors where CT blows up exponentially.

### 4.2 ECBS, BCBS, EECBS: Bounding Suboptimality
ECBS [3] uses *focal search* [Pearl & Kim 1982]. Focal maintains OPEN sorted by admissible *f*, FOCAL subset *{n|f(n)≤w·f(best_f)}* sorted by *d(n)*. Since *f(best_f)≤C**, any node in FOCAL satisfies *f≤w·C**.

ECBS applies focal both levels with same *w*:

- Low-level: *f=g+h*, *d=#conflicts*. Returns path minimizing conflicts while *≤w·f_min^i*. Returns *f_min^i(N)*.
- High-level: *LB(N)=Σ_i f_min^i(N)*, *LB=min LB(N)*, *FOCAL={N|cost(N)≤w·LB}* sorted by *#conflicts*.

Thus:
```
f_min^i(N) ≤ f_opt^i(N) ≤ |path_i| ≤ w·f_min^i(N)   (1)
LB(N) ≤ cost_opt_below(N) ≤ cost(N) ≤ w·LB(N)
LB ≤ C* ⇒ cost(solution) ≤ w·LB ≤ w·C*            (2)
```

**Limitations:** Focal only considers conflict count, ignoring *f* proximity to bound, causing thrashing when *d* and *f* negatively correlated. Low-level may return high-cost within bound forcing many high-level expansions.

EECBS [4] fixes via Explicit Estimation Search: uses learned inadmissible *ĥ* estimating cost-to-go, selects minimizing *f̂=g+ĥ* among promising nodes, still respecting *w·LB*. Incorporates WDG online.

Typical *w=1.1* yields 2-5× speedup over CBS at <10% overhead; *w=1.5* scales to 300+ agents den520d.

### 4.3 LaCAM: Lazy Constraints Addition
LaCAM [5] searches over *joint configurations*. Full branching *5^k* infeasible. Lazy trick:

- High-level DFS maintains stack *C^0..C^k*
- At *C^k*, generate **one** successor *C^{k+1}* via PIBT
- If *C^{k+1}* previously visited from *C^{k'}*, add constraint to *C^{k'}* forcing different successor next time (backjump)
- Constraints: first revisit constrains agent1 to 5 actions, next 25 constrain agent1-2 joint actions, etc., enumerating *5^N* lazily.

Generator can be any one-step MAPF; PIBT ideal fast and greedy.

**Completeness:** Finite *|V|^k* plus finite constraint enumeration guarantees finding goal or proving unsolvable.

LaCAM* [6] adds anytime optimality:

- Tracks *g(C)* accumulated costs, OPEN sorted by *f=g+h*, best cost *C_best*, prunes *f≥C_best*, updates *C_best* on goal, continues until OPEN empty → optimal when *h* admissible.

Engineering:

- **Non-deterministic PIBT:** noise diversifies successors.
- **Bypass+reinsertion:** similar to CBS bypass on config level.
- **True distance heuristic:** Dijkstra precomputed.
- **MAPF-LNS post-process:** improves SoC.

Benchmark: LaCAM* solved 99% of 13,900 instances up to 1000 agents within 10s [6].

### 4.4 PIBT and Lifelong MAPF
PIBT [7] is *iterative*: each timestep compute one collision-free step.

1. Compute priorities (elapsed time, farthest-from-goal).
2. Sort descending.
3. For agent *a* in order, try moves sorted by *dist-to-goal*.
   - If move to *v* free, assign.
   - Else *v* occupied by lower-priority *b* not yet planned: **inherit** priority *a→b*, recursively plan *b* first. If *b* moves aside, *a* takes *v*.
   - Else higher-priority planned to stay → backtrack.
4. Guarantees collision-free transition.

> **Theorem (PIBT Deadlock-Free):** If graph biconnected and all agents can reach goals ignoring others, PIBT with inheritance never deadlocks; livelocks rare, resolved via randomization or LaCAM wrapper [7].

PIBT not complete for one-shot MAPF but excels Lifelong.

**Lifelong MAPF:** Agents receive new goal upon arrival, maximize throughput. RHCR decomposes into Windowed MAPF:

- Replan every *h* steps, resolve conflicts only *W≥h* ahead, execute *h*, repeat.
- Windowed solver can be PBS, ECBS, PIBT rollout.
- PIBT rollout: greedy but scales to 10k agents.

Tradeoff: *h=1* approaches PIBT reactive, high throughput myopic; *h=W=∞* one-shot optimal intractable.

Hybrid: PBS/PP for small warehouse windows, fallback PIBT when unsolvable, ensuring live execution.

### 5.2 Proofs
*Lemma 1:* *LB(N)=Σ_i f_min^i(N) ≤ min_{Π respecting N.C} SoC(Π)*. Since each *f_min^i* lower bounds single-agent optimum under *N.C*, sum lower bounds joint optimum below *N*.

*Lemma 2:* *LB = min LB(N) ≤ C**. Optimal solution under some OPEN node *N**, cost ≥ *LB(N*)* ≥ *LB*.

*Theorem ECBS:* Any node *N* from FOCAL satisfies *cost(N) ≤ w·LB(N) ≤ w·LB ≤ w·C**. Low-level *|path_i|≤w·f_min^i* ⇒ *cost(N)≤w·LB(N)*. High-level FOCAL *cost(N)≤w·LB*. Hence solution *w*-bounded.

*LaCAM Completeness:* Config space finite *|V|^k*. Constraint enumeration finite; after ≤ *Π_i deg(v_i)* constraints, all successors enumerated. DFS with backjumps explores all reachable configs. If goal reachable, DFS finds it.

*PIBT Acyclicity:* Priority DAG edge *a→b* if *a* attempts into *b* and inherits. Priorities strictly increase along chain, so acyclic, recursion terminates.

## 6 Limitations
- **CBS blowup:** Corridor conflicts where agents must swap in narrow passage cause CT *2^k* symmetry. Symmetry reasoning (corridor, rectangle, target) mitigates partially.
- **ECBS correlation:** When *f* and *d* negatively correlated—low *f* highly conflicting—focal thrashes. EECBS mitigates via *ĥ* but WDG building *O(k^2)*.
- **LaCAM suboptimality:** Initial 20-40% worse than optimal due greedy PIBT; anytime convergence exponential, infeasible >500 agents within 60s. No *w* bound.
- **PIBT livelocks:** Non-biconnected graphs (trees dead-ends) inheritance cannot resolve. Random priorities reduce but not eliminate. Requires LaCAM wrapper losing scalability.
- **Lifelong fairness:** Throughput maximization may starve far agents. Dynamic priorities mitigate but oscillate. RHCR *h>1* may commit suboptimal future when new goals arrive mid-window.
- **Kinodynamics:** Unit-time, holonomic assumption unrealistic; real robots need db-LaCAM with motion primitives increasing branching and heuristic error.
- **Infinite storage divergence:** KV infinite while file trimmed risks divergence if sync fails; requires reconciliation verifying `zcard` vs file length.

## 7 Conclusion
We presented unified analysis spanning optimality (CBS), bounded suboptimality (ECBS/EECBS), lazy scalability (LaCAM/LaCAM*), and reactive lifelong planning (PIBT+RHCR). CBS's CT remains gold standard for low-density optimality; ECBS's focal distributes *w* across levels preserving *w·C** guarantee 10-100× faster; EECBS corrects focal myopia via explicit estimation. LaCAM's lazy successor reduces branching *5^k*→1 per expansion, achieving 1000-agent scalability with completeness via constraint enumeration, LaCAM* adds eventual optimality. PIBT's inheritance provides one-step deadlock-free engine scaling to 10k agents, backbone for Lifelong MAPF coupled with RHCR windowing and PIBT fallback.

Practitioners:

- Use **ECBS *w=1.2*** for one-shot <300 agents bounded quality.
- Use **LaCAM*** for fast feasible <10s up to 1000 agents, then anytime improve.
- Use **RHCR with PIBT rollout** for lifelong throughput, *W=12,h=5* recommended 33×33 maps, fallback pure PIBT when unsolvable.
- Keep **KV infinite**, file manifest rolling 100, sync via *zadd* with *ts* score, pagination offset/limit, newest-first UI.

Future: *learned* heuristics for focal ordering, *neural* generators replacing PIBT in LaCAM, *decentralized* PIBT with communication constraints. Invariant: **separate concerns—constraint reasoning for optimality, lazy expansion for scalability, priority inheritance for reactivity—and compose via windowing**.
