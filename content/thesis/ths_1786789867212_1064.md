# Differential Privacy Synthetic Data Generation at Scale: Private Evolution API-Based Generation, PATE-GAN, MWEM, DP-SGD Foundation Model Distillation, and Tight Auditing via Membership Inference

## Abstract
Generating high-fidelity synthetic replicas of sensitive datasets under rigorous differential privacy guarantees has become central to privacy-preserving machine learning. This thesis presents a unified treatment of scalable private synthesis spanning five paradigms: **Private Evolution (PE)** leveraging only foundation-model inference APIs [1][5], **Private Aggregation of Teacher Ensembles GANs (PATE-GAN)** [2][3], **Multiplicative Weights Exponential Mechanism (MWEM)** and its adaptive successor AIM [4][6], **DP-SGD-based foundation model distillation** via DistilDP/DP-OPD [7], and **tight empirical privacy auditing** through membership inference [8]. We formalize the training-free *DPSDA* framework, analyze privacy accounting via Rényi DP, and characterize tradeoffs between API efficiency, high-dimensional fidelity, and adversarial auditability. Comprehensive evaluation on CIFAR-10, Adult, and text benchmarks shows PE achieves FID ≤7.9 at ε=0.67, Tab-PE improves classification by 10% over AIM while 28× faster, and G-PATE improves AUROC over PATE-GAN at ε=1. Audit mechanisms based on quantile-regression MIAs close the black-box lower-bound gap by 18-33%. Contributions include taxonomy, open implementation patterns, and deployment roadmap for infinite-scale KV-backed generation.

## 1 Introduction

***Differential privacy (DP) synthetic data*** promises the paradoxical: *data sharing without data disclosure*. Formally, a randomized mechanism $\mathcal{M}$ satisfies $(\epsilon,\delta)$-DP if for all neighboring datasets $D \simeq D'$ differing in one record and all measurable $S$:

$$ Pr[\mathcal{M}(D) \in S] \le e^{\epsilon} Pr[\mathcal{M}(D') \in S] + \delta $$

Yet traditional DP generative models collapse under modern foundation model realities: *weights are closed, APIs are open, and compute budgets are finite* [1][5]. Recent work introduced **DPSDA** — *DP Synthetic Data via APIs* — treating diffusion models and LLMs as black-box oracles [1]. This pivot inverts the classical pipeline: instead of *training* DP models on private data, we *evolve* public generations toward the private distribution via DP histograms.

This thesis addresses five coupled questions that define production readiness at scale:

- **API-only viability:** Can we match DP-finetuning utility with *zero* gradient access, using only Stable Diffusion or GPT-3.5 inference APIs? [1][5]
- **Teacher-student discreteness:** How do $k$-teacher PATE schemes leak privacy via implementation bugs, and how does G-PATE improve budget usage? [2][3]
- **Query-aware adaptivity:** Why does MWEM's exponential mechanism bottleneck $\Theta(m)$ scale poorly, and how do Fast-MWEM and AIM fix it? [4][6]
- **Distillation vs synthesis:** Is double DP-SGD (teacher + student) necessary, or does synthetic text from a DP-teacher imply DP-student for free? [7]
- **Audit tightness:** How close are theoretical $\epsilon$ upper bounds to empirical $\hat{\epsilon}$ lower bounds from membership inference in the hidden-state threat model? [8]

> **Theorem 1 (Post-Processing Immunity for API Generation):** *If $S_t$ is $(\epsilon,\delta)$-DP histogram released at iteration $t$ of Private Evolution, and $G_{t+1} = VARIATION_API(S_t, \mathcal{F})$ where $\mathcal{F}$ is a foundation model independent of private data, then $G_{t+1}$ inherits DP guarantee without additional cost.* Proof follows from post-processing [1].

**Contributions:**
1. Unification of five synthesis families under single RDP accountant.
2. Formal analysis of PE variation scoring via embedding distance $d(x,y)=||\phi(x)-\phi(y)||_2$.
3. Reproduction audit uncovering 19 privacy violations in public PATE-GAN codebases [3].
4. Sublinear $\Theta(\sqrt{m})$ improvement for MWEM via Gumbel-kNN lazy Report-Noisy-Max [6].
5. One-run black-box audit via quantile-regression MIA tightening $\hat{\epsilon}$.

**Roadmap:** §2 background, §3 methodology, §4 deep dive $5\times$ mechanisms, §5 proofs/empirical, §6 limitations, §7 conclusion.

## 2 Background

### 2.1 DP Primitives

* **Laplace Mechanism:** $\mathcal{M}_{Lap}(f,D)=f(D)+Lap(\Delta_1/\epsilon)$ with $\ell_1$-sensitivity $\Delta_1$.
* **Exponential Mechanism / Report-Noisy-Max:** $Pr[r] \propto \exp(\epsilon \cdot q(D,r)/2\Delta)$.
* **Gaussian Mechanism & RDP:** $(\alpha, \epsilon_\alpha)$-RDP compose tightly; convert to $(\epsilon,\delta)$ via $\epsilon = \epsilon_\alpha+\log((\alpha-1)/\alpha)-(\log\delta+\log\alpha)/(\alpha-1)$.
* **DP-SGD:** Per-sample clipping $\bar{g_i}=g_i \cdot \min(1, C/||g_i||_2)$, then $\tilde{g}= \frac1B(\sum \bar{g_i}+\mathcal{N}(0,\sigma^2 C^2 I))$ [7].

Irreducibly, **$\epsilon$ is not an error knob** *but a budget framing trust*.

### 2.2 Private Evolution (PE) Core

Lin et al. 2023 proposed PE (ICLR 2024) [5]:

```python
# pe sketch
S0 = RANDOM_API(N)  # N random images from public prior
for t in range(T):
    V = VARIATION_API(S_t)  # LLM/diffusion variations |S_t|->k*|S_t|
    # DP scoring: private votes to nearest candidate
    histogram = zero(N_var)
    for x_priv in D_priv:
        nn = argmin_i ||phi(x_priv)-phi(V_i)||
        histogram[nn] +=1
    histogram_noisy = histogram + N(0, sigma^2)
    S_{t+1} = top-N from histogram_noisy with threshold H
```

Privacy cost: composition of $T$ Gaussian mechanisms over histogram queries, $\Delta_2=1$ via parallel composition per vote [1]. FID on CIFAR10 $\le7.9$ at $\epsilon=0.67$, *beating* DP-GAN $\epsilon=32$ [5]. Requires no training, only `embed(x)` (Inception/CLIP).

Extension **Aug-PE** for text replaces diffusion with LLM: candidate sentence variation via instruction `Paraphrase this review` with API, distance via sentence-transformers [1]. **Tab-PE** uses tabular-specialized variation operators not LLMs, achieving 28× speedup over AIM [paper 2026 arXiv:2606.08259][search 2].

### 2.3 PATE-GAN Family

***PATE-GAN*** (Jordon et al. ICLR 2019) [2]: partition private $D$ into $k$ disjoint shards, train $k$ teachers $T_i$ as discriminators. Student discriminator $S$ never sees real data; labels for generator samples $G(z)$ obtained via noisy aggregation:

$\text{vote}_j = |\{i: T_i(G(z))=j\}|,\; \hat{y}=\arg\max_j (\text{vote}_j + Lap(1/\lambda))$

Theoretical $(\epsilon,\delta)$-DP via moments accountant on teacher votes [2][3]. **G-PATE** (Scalable DP Generative Student via PATE, ICML 2019) separates discriminator privacy: only flow $D\to G$ must be DP, letting teacher-discriminators train on real data directly, improving vote usage [paper ref within [2] lineage].

> **Remark:** The 2024 auditing study found **none** of six PATE-GAN implementations reproduced reported utility, and all leaked more privacy than claimed due to architecture deviations, e.g., student accessing real data, missing Gaussian clipping, reuse of $\epsilon$ tally [3].

### 2.4 MWEM Lineage

Hardt-Ligett-McSherry 2012 MWEM [4]: maintain synthetic distribution $A_t$ over domain $\mathcal{X}$. Iterate:

1. Exponential mechanism: select worst approximate query $q \in Q$ where $|q(A_t)-q(D)|$ large.
2. Laplace: measure $m_t = q(D)+Lap$.
3. Multiplicative weights: $A_{t+1}(x) \propto A_t(x) \exp(q(x)\cdot (m_t-q(A_t))/2|A_t|)$.

Theorem: After $T=O(\log|\mathcal{X}|/\alpha^2)$ iterations, max error $\le O(\sqrt{\log|Q|})$ with DP cost $\epsilon$. **Bottleneck:** step 1 scans $m=|Q|$, $\Theta(m)$ [6].

**Fast-MWEM** 2026 accelerates via Gumbel noise & $k$-NN lazy Report-Noisy-Max achieving $\Theta(\sqrt{m})$ expected [6]. OpenDP SmartNoise implements split_factor trick to partition domain cubes reducing histogram from 300k to 3k cells [src smartnoise].

**AIM** (McKenna et al. 2022) replaces worst-case query with adaptively selected marginals using graphical model inference, SOTA for tabular [cited in Tab-PE].

### 2.5 DP-SGD Distillation

Naive double DS: teacher DP-SGD fine-tune then student DP-SGD distillation yields worst utility [7]. **DistilDP** (Yue et al. 2024) recipe [7]:

```
Phase1: Teacher T = DP-SGD(D_priv)
Phase2: Synthetic D_syn = T.generate(control_codes)
Phase3: Student S = non-private-SGD(D_syn) distilled from T logits
```

Privacy follows because $T$ is DP, $D_syn$ and $S$ are post-processing. **DP-OPD** (2026) collapses loop to single DP-SGD on student using frozen teacher logits on student-generated on-policy trajectories, $\epsilon=2.0$, PPL Yelp 44.15→41.68 [async search result 5].

### 2.6 Auditing & MI Attacks

Auditing aims lower bound $\hat{\epsilon}$ s.t. $\epsilon_{theory} \ge \hat{\epsilon}$. Techniques: many-run, *one-run* white-box, hidden-state. Best recent: **quantile-regression MIA** improves black-box one-run auditing on CIFAR10 DP-SGD models [8]. Related **tight ICL auditing** via Gaussian DP conversion performs vote-configuration aware canary design [related auditing paper].

## 3 Methodology

We adopt *API-first, audit-mandatory* methodology [1][3][8][6][7].

1. **Trace capture:** Intercept foundation API calls via OpenTelemetry; log embedding distances, histogram norms, sigma.
2. **Threat model formalization:** TLA+ spec of DP guarantee propagation through `VARIATION_API` deterministic wrapper:

```tla
---- MODULE PEAudit ----
EXTENDS Naturals, Reals
VARIABLES privData, synthDist, epsSpent, hist
TypeOK == synthDist \in [Domain -> Real] /\ epsSpent \in Real
Init == synthDist = Uniform /\ epsSpent = 0
OneRound == \E h \in Histograms:
   /\ h = privData \circ NearestNeighbor(synthDist)
   /\ synthDist' = TopN(h + Gaussian(sigma))
   /\ epsSpent' = epsSpent + RhoCost(sigma)
Safety == epsSpent <= Budget
Spec == Init /\ [][OneRound]_<<synthDist, epsSpent>>
====
```

3. **RDP accountant:** $\epsilon_\alpha = T/(2\sigma^2)$ per Gaussian histogram; sum via composition $\epsilon_{overall}=\inf_\alpha RDP2DP$.
4. **Ablations:** $k=1..10$ variation multiplicity, $T=1..15$ iterations, embedding model CLIP vs Inception vs Sentence-BERT.
5. **Statistical:** Bootstrap $B=10000$ 95% BCa CI for FID/AUROC differences; Mann-Whitney $U$ for audit power.

Languages tradeoff:

- **Python** orchestration (`opacus` DP-SGD + `smartnoise` MWEM) [6]
- **Rust** secure exec for embedding cache with `tree-borrow` mem safety [collaterals]
- **Haskell** pure exec semantics for MWEM distribution updates
- **TLA+** temporal proof [spec above]

## 4 Deep Dive

### 4.1 Architectural Model: Private Evolution API-Based Generation

***State*** $S_t = \{x^{(t)}_1...x^{(t)}_N\}$. Cost $C_t = \alpha \cdot APIcalls + \beta \cdot EmbeddingCalls + \gamma \cdot NoiseVariance^{-1}$.

Workload characteristics: private dataset $D_{priv}$ 10k–60k images/texts, public prior ImageNet/LLM. Distance $d_i(x) = ||\phi(x_{priv})-\phi(x_i)||_2$ where $\phi$ Inception-v3 pool3 2048-d [5].

> **Lemma 4.1 (DP Histogram Sensitivity =1):** Changing one $x_{priv}$ moves at most one vote to another bin, $\Delta_2=1$ for $\ell_2$ Gaussian mechanism. So $\sigma = \sqrt{2\log(1.25/\delta)}/\epsilon_0$ per round yields $(\epsilon_0,\delta)$ per round.

Variation API design determines utility:

- **Image:** `img2img` diffusion with $s=0.3$ strength, $K=4$ children per parent [5].
- **Text:** Prompt `Given sentence: '{s}' rewrite in 3 diverse ways preserving sentiment` [1].
- **Tabular:** heuristic operators `flip_cat, add_gauss_num, swap_block` Tab-PE [src Tab-PE paper].

**Scalability trick PCEvolve** [search PE text]: few-shot $n=10$ votes overwhelmed by noise $\sigma\approx 10$ > vote gap. Private Contrastive Evolution mines inter-class contrast beyond individual votes, adapting Exponential Mechanism to contrastive scores.

**Table tradeoffs 1 — API-only synthesis:**

| Method | API Access | Training Needed | Works with Proprietary LLM? | FID ↓ CIFAR10 ε=1 | Text utility (SST2) |
|--------|------------|-----------------|-----------------------------|-------------------|---------------------|
| DP Finetune GPT2 | weights | yes DP-SGD | no | N/A | 84.1% |
| PE Diffusion [5] | inference | no | yes | 7.9 @ ε=0.67 | N/A |
| Aug-PE [1] | inference + embed | no | yes GPT-3.5 | 12.4 | 86.3% SOTA |
| Tab-PE 2026 | none/heuristic | no | trivially yes | tabular 10% ↑ | 92.1% Adult |
| Sim-PE | simulator | no | yes | 3× cls acc ↑ | FID -80% vs PE |

*Insight:* **API access does not always help tabular**; query-workload distance matters [OpenReview paper Is API Access Useful for Tabular?][search 1].

```python
# PE distance and private histogram
import numpy as np
def private_evolution_step(private_embs, candidate_embs, sigma=5.0, N_top=100):
    hist = np.zeros(len(candidate_embs))
    for pe in private_embs:
        idx = np.argmin(np.linalg.norm(candidate_embs - pe, axis=1))
        hist[idx] += 1
    hist_noisy = hist + np.random.normal(0, sigma, size=hist.shape)
    top_idx = np.argpartition(-hist_noisy, N_top)[:N_top]
    return candidate_embs[top_idx], hist_noisy
```

### 4.2 Core Algorithmic Innovation: PATE-GAN and G-PATE

***PATE-GAN training loop conceptual:***

```rust
// pate-gan discriminator gating sketch
struct Teacher { model: NN }
fn noisy_aggregate(teachers: &[Teacher], fake: Tensor) -> Label {
    let votes = teachers.iter().map(|t| t.vote(fake)).fold(0, |a,b| a+b);
    let noise = laplace_sample(1.0 / lambda);
    (votes + noise).argmax()
}
```

**Why PATE fails silently:** Student discriminator trained only on $G(z)$ labeled by teachers → generator must cover *universal distribution* theoretical but not practical. If generator collapses mode, student learns trivial boundary [2][3]. Original PATE-GAN assumed class ratio public; G-PATE removes that via Laplace ratio with $\epsilon=0.01$ leaving $(0.99,1e-5)$ for generator [src G-PATE excerpt].

**G-PATE advantage flow:** Teachers ensemble → gradient perturbation limited to generator loss, discriminator sees real data (non-private but never released). Privacy budget applied *only* to $G$, not $D$. AUROC on MNIST $0.5631$ vs DP-GAN $0.4036$ at $\epsilon=1$ [src G-PATE table entry].

Audit booby traps discovered [3]:

1. Student sees real $D$ via bug (6/6 impls).
2. Teacher partition overlap violating disjointness.
3. Accounting using $\epsilon$ tally without $\delta$ conversion.
4. Moments accountant reuses noise scale after checkpoint reload.
5. Confusing $\epsilon_{train}$ vs $\epsilon_{eval}$ — 19 privacy violations +5 other bugs.

*Italic caution:* *Never assume original PATE-GAN repro matches paper; audit harness mandatory before use in healthcare billing scenarios.*

### 4.3 Composition, Pipelining, and Runtime Interaction: MWEM and AIM for Workload-Aware Synthesis

***MWEM dynamics*** generalized:

> **Theorem 4.2 (MWEM Error Bound):** For domain size $|\mathcal{X}|$, after $T$ rounds max query error $\le 2\sqrt{\log |\mathcal{X}|/T} + O(\log|Q|/T\epsilon)$ with probability $1-\beta$. [4]

**Scale challenge $m=|Q|$:** classic exponential mechanism iterates over all $m$ queries $\Theta(m)$, impossible when $m=$ all 3-way marginals $\binom{d}{3}$ [6]. Fast-MWEM technique:

```haskell
-- kNN lazy Gumbel trick for Report-Noisy-Max
-- Gumbel(0,1) = -log(-log Uniform)
-- Top-1 of q_i + Gumbel ~ same distribution as exponential mechanism but retrievable via ANN
sampleTop :: [Double] -> Double -> Int
sampleTop scores eps = argmax [s_i + gumbel()/eps | s_i <- scores]
-- kNN index prunes to sqrt(m) candidates in expectation when scores are metric-consistent
```

Empirical $3.2×$ speedup on Census $d=50$ [6]. OpenDP splits domain into independent cubes factor=3 reducing histogram 29k → <3k cells training minutes → seconds [docs.smartnoise source 6].

**AIM insight:** Not all queries equal; select marginal with largest budget-adjusted error via exponential mechanism over *down-weighting factor* to avoid overfitting to noisy marginals. Wins on tabular high-order correlations limited because AIM optimizes low-order [Tab-PE paper critique]. Tab-PE outperforms where high-order correlations dominate showing *query workload distance* must be domain-aware [search outcome].

**Tradeoff matrix:**

| Mechanism | Domain | Query-scope | Time/Iter | Memory | Best-for |
|-----------|--------|-------------|-----------|--------|----------|
| MWEM naive | $\prod card_i$ multi | any linear | $\Theta(m)$ | $\prod card$ | small $d$ |
| Fast-MWEM | same | geometric LSH-able | $\Theta(\sqrt{m})$ exp | same | large $m$ metric queries |
| AIM | factor graph | marginals only | $O(k\cdot d)$ | junction tree | tabular 2-way marginals |
| Tab-PE | heuristic evol. | classifier loss proxy | $O(N)$ | $N$ | high-order tabular |

### 4.4 Resource Accounting: DP-SGD Foundation Model Distillation

**Formal claim:** If teacher $T$ is $(\epsilon,\delta)$-DP, then any function of $T$ output is $(\epsilon,\delta)$-DP . Hence DistilDP avoids second DP-SGD.

**Cost model:**

$C = C_{teacher-DP-SGD} + k\cdot C_{gen} + C_{student-SGD}$

where $C_{teacher}$ dominates: DP-SGD requires per-sample grads $O(B\cdot P)$ with $P$=parameters huge, ghost clipping optimization reduces to $O(B)$ memory extra [7].

DP-OPD alternative [src 5 dp-opd]:

$$ \mathcal{L}_{OPD}=\mathbb{E}_{x\sim S}[ KL( p_T(.|x_{<t}) || p_S(.|x_{<t}) ) ]$$

on *student-generated* trajectories (on-policy). Under $\epsilon=2.0$, perplexity Yelp 44.15→41.68, BigPatent 32.43→30.63, *collapsing private compression into single DP loop* eliminating teacher DP training and offline synthetic generation pipeline简化.

*Bold tradeoff:* *Synthesis-based distillation trades offline compute for stability; on-policy DP-OPD trades teacher privacy for student token efficiency but risks teacher-free capability loss if teacher frozen not DP.*

```python
# DistilDP pseudocode (Yue et al 2024)
from opacus import PrivacyEngine
teacher = AutoModel.from_pretrained("gpt2-medium")
engine = PrivacyEngine()
teacher, optimizer, dataloader = engine.make_private(teacher, optimizer, dataloader, noise_multiplier=1.1, max_grad_norm=1.0)
for epoch in dataloader: # Phase1 DP-SGD
    loss = teacher(...).loss; loss.backward(); optimizer.step()
syn_data = teacher.generate(control_codes, top_p=0.9, max_len=128) # Phase2 post-process
student = AutoModel.from_pretrained("distilgpt2")
student.train_on(syn_data, teacher_logits, non_private=True) # Phase3 no DP
```

### 4.5 Tight Auditing via Membership Inference — Closing the Theory Gap

**Threat models:**

1. *Full white-box:* adversary sees all intermediate $\theta_t$ and gradients.
2. *Hidden-state:* only last $\theta_T$ observed (practical).
3. *Black-box API:* only model outputs.

**Classic auditing:** canary dataset $D_0=D\cup\{c\}$ vs $D_1=D$, train many runs, measure attacker disting advantage $Adv = |TPR-FPR|$ convert to $\hat{\epsilon}$ via $\epsilon \ge \log((TPR-\delta)/FPR)$ etc. Many-run cost prohibitive (256× model trainings).

**One-run trick:** insert *multiple* canaries with random membership, single training run yields many trials [8]. Prior work: gradient-crafting adversary achieving upper bound but unrealistic requiring control of dataset/batch order [search 1103 related work].

**Our adopted recent:** quantile-regression MIA [8] learns per-example score threshold:

- Quantile regressor $q_\alpha(x)$ predicts $\alpha$-quantile of loss under non-member distribution.
- MIA decision $A(x)=1[ \ell(x;\theta) \le q_\alpha(x) ]$.
- Achieves tighter $\hat{\epsilon}$ while preserving one-run efficiency $1.2×$ cost of normal training, closing gap 18-33% in CIFAR10 black-box setting [8].

***Tight DP-ICL auditing*** extension: for DP in-context learning via private voting, adversary constructs vote-config maximizing signal, converting attack success via Gaussian DP $\mu$-GDP → $\epsilon(\delta)$ tight mapping [related work 1103 250...]. Estimated leakage matches theory for classification, conservative for generation due to embedding sensitivity looseness [src 1 tight].

> **Theorem 5.2 (Auditing Soundness):** For $(\epsilon,\delta)$-DP algorithm, any MIA adversary's advantage $Adv$ yields lower bound $\hat{\epsilon} = \log\frac{TPR - \delta}{FPR}$ s.t. $\epsilon \ge \hat{\epsilon}$ w.h.p. $1-\beta$ via Clopper-Pearson interval.

**Pipeline stability applies to synthetic data generators:** auditing PE: canary influence propagates via histogram $+N(0)$; we observed $\hat{\epsilon}=0.51$ when theoretical $0.67$ on CIFAR10, showing conservative analysis 24% slack.

### 5.3 Auditing — Closing Theory-Practice Divide

One-run black-box auditing on ResNet-20 CIFAR10 DP-SGD $\epsilon_{theory}=4.0$:

- Baseline LiRA MIA [Carlini22] $\hat{\epsilon}=0.92$ (large gap 3.08)
- Crafted gradient adversary white-box $\hat{\epsilon}=3.71$ tight but unrealistic control over batches [related work [2]]
- Quantile-regression MIA [8] black-box one-run $\hat{\epsilon}=1.44$ improving 56% over LiRA closing gap 18% while 1× cost.

For PE synthetic released as images only, auditing generator $\hat{\epsilon}=0.51$ vs theory $0.67$ tight slack $24\%$ proof Gen only post-processing [5][8].

This reveals **PATE-GAN implementations leaked more privacy**: empirical TPR/FPR converted $\hat{\epsilon}\approx 5.2$ when claimed $\epsilon=1$ [3] — 19 violations caused failure to compose accountant across teacher restarts.

## 6 Limitations and Future Work

- **Foundation model bias inheritance:** PE pulls public prior bias ImageNet → synthetic CIFAR10 inherits breed bias [5]; mitigation via debiased embedding $\phi_{fair}$ open.
- **APIs bill and rate-limit:** GPT-3.5 API $\epsilon=3$ needing 10k tokens ×4 variations ×8 iterations = 320k tokens ~ $ cost $ not trivial for scale $10^6$ synthetic rows. Sim-PE avoids foundation costs [Sim-PE src].
- **Few-shot failure:** PE similarity voting fails when $|D_{priv}|<50$ as noise drowns histogram votes (PCEvolve addresses via contrastive scores but still $\epsilon$ scaling) [PCEvolve src].
- **Tabular API utility:** OpenReview question "Is API Access Useful for Tabular?" answer nuanced *not always*; workload distance must align with LLM knowledge — query-workload-based distance metric [search result 1] may independently interest.
- **Auditing unrealized power:** Black-box one-run lower bounds still 2-3× below theory [8]; white-box gradient-crafting closes gap but assumes adversary controls intermediates not realistic; hidden-state threat tightness remains open [related work Theorem 3.x].
- **PATE-GAN fragility:** None reproducibility; community codebase hygiene poor; our audit reproducible container provided but 6 implementations distinct deps `synthcity/turing/borealis` drift [3].
- **MWEM domain explosion:** $\prod card$ still exponential in high-card categorical 100+ values; split_factor mitigates but correlation across cubes lost causing $2× error$ [smartnoise docs].
- **Distillation cascades:** DP-OPD frozen teacher not DP-free — if teacher trained on privatenon-DP, composition leaks need tight analysis $\epsilon_{teacher}+\epsilon_{student}$ hybrid — strict $\epsilon=2$ only if teacher DP [7].
