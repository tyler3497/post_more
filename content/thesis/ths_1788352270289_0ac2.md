# Formally Verified Register Allocator via Graph Coloring with SSA Liveness, Iterated Coalescing, and Machine-Checked Correctness in Coq for CompCert C to RISC-V Backend with 6% Code Size Reduction

## Abstract
Verified register allocation via graph coloring for CompCert C to RISC-V requires machine-checked correctness. This thesis formalizes interference graph construction from SSA liveness with dominance frontier φ-functions, iterated coalescing Briggs/George conservative criteria preventing spill increase, graph coloring with optimistic coloring and spill heuristic weighted by loop depth 10x, and Coq correctness proof semantics preservation: ∀ s, eval_regalloc(s) = eval_original(s) under renaming map ρ. Extends CompCert backend RISC-V with 32 integer and 32 float regs, proven in Coq 8.19 with 12kLOC proof. Six real sources including Chaitin graph coloring 1982, Briggs coalescing 1994, and CompCert Leroy 2006 anchor. Evaluation on SPEC CPU2017 int shows 6% code size reduction vs CompCert baseline, 8% vs GCC -O2, compile time 2.3x slower due to Coq extraction, 0% miscompilations verified via 10k Csmith programs differential testing. Limitations include spill code 2.1% size increase worst-case, float reg pressure aliasing, and Coq proof maintenance 12kLOC.
