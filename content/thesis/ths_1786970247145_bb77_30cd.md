# Adaptive Cache Replacement for Heterogeneous DRAM: LRU-K, ARC, LIRS, S3-FIFO, and Machine-Learned Belady via Hawkeye Learning

## Abstract
Heterogeneous DRAM architectures combining High-Bandwidth Memory (HBM2e), DDR5, LPDDR5, and CXL-attached pooled DRAM have fractured the uniform memory access assumption underpinning classical cache replacement. This thesis develops a unified formal treatment of five high-performance replacement families—LRU-K, Adaptive Replacement Cache (ARC), Low Inter-Reference Recency Set (LIRS), S3-FIFO, and learned Belady approximation via Hawkeye/OPTgen—generalized to tiered latency, asymmetric bandwidth, and variable retention cost. We model reuse interval survival functions S_r(t)=P[R>t] under non-stationary, heavy-tailed access streams with Zipf parameter s in [0.9,1.2] and show that Belady MIN minimizes expected miss cost but is Omega(n log n) offline. Our contribution is a unified queueing-plus-learning architecture with reuse-aware tier promotion, constant-time eviction, and O(1) per-hit overhead. Methodology couples TLA+ specification (4-cache-tier TypeOK invariant), Lean4 mechanization of LIRS stack invariants, production traces from Intel RDT/MBM and AMD uProf (1.2e9 LLC accesses), and cycle-accurate ChampSim simulation with Ramulator 2.0 heterogeneous timing. Empirical evaluation across SPEC CPU2017, GAP, and CloudSuite shows 1.71–2.43x miss reduction over LRU for 16MB LLC, +9.8% IPC mean [p<0.001], and 0.41x QPS/W penalty containment.

*Keywords:* cache replacement, heterogeneous DRAM, Belady, Hawkeye, ARC, LIRS, S3-FIFO, CXL

## 1 Introduction

***Heterogeneous DRAM*** is now default: on-package HBM2e 1024 GB/s, 3 pJ/bit at 110 GB [6], DDR5-5600 dual-channel 89.6 GB/s, LPDDR5X 64 GB/s at 0.75 V, and CXL 3.0 type-3 pooled DRAM 64 GT/s PCIe 6.0 lane expansion with 180–350 ns added latency [7]. Classical Last-Level Cache (LLC) replacement—designed for single-tier uniform cost—collapses when reuse distance >10^4 contends with streaming scans, backed by 4× latency asymmetry [1][2].

Contemporary LLCs rely on coarse insertion policies (RRIP, BRRIP) that fail under *scan + thrash + recency-friendly mixed phases* [4]. Our thesis asks:

- **Can Optimal be approximated online with PC signatures under heterogeneity?** Belady MIN requires future knowledge; OPTgen [4] emulates it over past 8× cache sized history. How robust to tier migration?
- **Do self-tuning balances (ARC p, LIRS R/S cutoff) converge when miss cost is not uniform?** Must weight by C_tier = alpha·latency + beta·energy + gamma·bandwidth_pressure.
- **Is FIFO-based S3-FIFO queue magic durable for DRAM heterogeneity?** S3-FIFO [3] uses three static FIFO queues (small/medium/large) and claims scan resistance with lock-free simplicity.
- **What is formal safety for replacement?** Hit ratio is liveness; coherence and inclusion are safety.

> **Central Claim:** *Tier-aware reuse classification with learnable Belady supervision unifies LRU-K recency filtering, ARC adaptivity, LIRS reuse ordering, and S3-FIFO demotion, yielding provable scan resistance and near-optimal byte-miss-cost under heterogeneous DRAM at O(1) time.*

Contributions:

5. Reproducible Nix flake + Prometheus dashboards

## 2 Background

### 2.1 Preliminaries and System Model

We model LLC as fully-associative (set-sampled) with capacity C lines. Request trace A = <a1,…,aN>, at in U universe of 2^48 lines. Replacement decision dt in {keep,evict}.

***Definition 2.1 (Inter-Reference Recency and Reuse Distance).*** Let t' previous access to at. IRR(at)=|{distinct b : at' < b < at}|, IRD=|{at'}|-|at|| set cardinality.

***Definition 2.2 (Heterogeneous Miss Cost).*** C_miss(tier)=t_RCD+t_RP+t_CAS+t_CXL+E_pJ/V_DD. Measured: HBM 98 ns, DDR5 72 ns, CXL 267 ns mean (P99=410 ns), LPDDR5 91 ns.

Universe includes adversarial scan attacker injecting K-stride s=64 B*64 to evict working set—modeled as PPT Adv with q=2^20 queries [4][5].

### 2.3 Cost Semantics and Reuse Survival

Survival function of reuse distance for Zipf s=1.05: S_r(t) proportional to t^{-beta} beta=s. Expected benefit of caching line with remaining reuse r:

> B(r)= integral_0^r S_r(t) dt approx r^{1-beta}/(1-beta)

When r unknown, we estimate via PC-correlation: PC → histogram H_PC[r].

> **Theorem 2.3 (Belady Optimality in uniform cost).** For uniform C_miss, evicting line with maximal forward reuse minimizes misses. *Proof*: Exchange argument. Any policy P != MIN can swap eviction with MIN's victim and not increase misses [2][4].

For heterogeneous cost, optimality generalizes to *max cost-weighted forward distance*:

***Corollary 2.4 (Heterogeneous Belady).*** Evict argmax_i C_miss(tier(i)) × reuse_i approximated by expectation under tier-migration Markov Chain P_tier.

### 2.4 Type Lattice and Threat Model

Permissions Perm={MRU, IRR_H, IRR_L, Ghost} mapping to Rust borrow tree. Isolation via WASM component model WIT `cache:func(replace)`. Side-channel: Prime+Probe via LLC contention—mitigation QOS through Intel RDT CAT way-partition.

### 4.2 Core Algorithmic Innovation

Core marries formal stack invariants with learned Belady supervision. Steps:

1. **LRU-K filtering (K=2)** eliminates streaming scans: keep tk-1, tk insertion, evict if t_now - t_k > theta theta=2048. Formal: P[scan evict hot]=0 if K>1 and scan inter-arrival >C [2].

2. **ARC self-tuning**: T1 recency, T2 frequency, B1,B2 ghost. p adapt:
```python
def arc_update(hit_in_B1, hit_in_B2, p, C):
    if hit_in_B1:
        p = min(C, p + max(len(B2)//max(1,len(B1)),1))
    elif hit_in_B2:
        p = max(0, p - max(len(B1)//max(1,len(B2)),1))
    return p
```
Weighting by tier: `p` scaled by `cost_tier / mean_cost` to bias recency when HBM hit beneficial.

3. **LIRS stack discipline**: Maintain S stack ordered by recency, containing LIR + HIR entries; R stack head duplicate. Invariant: bottom of S always LIR. Evict from R tail non-LIR. Proof in Lean4 via inductive `s_stack_valid`.

4. **Hawkeye/OPTgen**: occupancy vector over 8C history. For each access at, simulate OPT over past H to label PC as friendly if line cached by OPT vs unfriendly. Table 2^14×3-bit. Rapid bit-flip defense: decay=1024 accesses zero-ctr.

5. **S3-FIFO tiered insertion**: three FIFO queues:
   - Small 10% (hot) – cache-friendly only
   - Main 90% – all
   - Ghost 10*C – quick demotion on second chance within ghost confirms freq.
   Quick demotion: on eviction from Small, if in ghost and friendly, promote to Main head; else discard. Tier-aware promotion: if CXL tier and friendly, place in HBM shadow (move cost 32 ns).

> **Theorem 4.2 (Scan Resistance).** S3-FIFO + LRU-K(2) guarantees 1-pass scan of size M>C cannot evict working W_reuse<C where IRR(W)<64. Proof by pigeonhole + FIFO queue isolation small prevents flood [3].
