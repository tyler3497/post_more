# Differentially Private Graph Neural Network Training: Edge DP via Randomized Response, PATE Aggregation over Subgraphs, and RDP Accounting for Node-Level Privacy

## Abstract
Graph Neural Networks aggregate multi-hop neighborhood information, amplifying privacy risk because a single node participates in inference for many others. This thesis unifies three complementary defenses: edge local differential privacy via degree-preserving randomized response (DPRR), private knowledge transfer via graph-specific PATE over subgraph teacher ensembles, and tight privacy accounting via Rényi Differential Privacy (RDP) for node-level guarantees. We formalize edge-DP adjacency for undirected graphs, analyze Warner's RR with adaptive degree-preserving sampling, and show how budget splitting between structure perturbation and degree estimation restores utility. We then adapt PATE to avoid destructive graph partitioning by training teachers per query-node using public unlabeled data, and prove RDP composition for multi-layer GNNs under bounded-degree sampling. The synthesis yields end-to-end $(\epsilon,\delta)$-DP for both training and inference with 2-5x tighter accounting than naive moments accountant.

---

## 1 Introduction

Graph Neural Networks (GNNs) compute representations via *recursive neighborhood aggregation*:

$$ h_v^{(l+1)} = \sigma\left(W^{(l)} \cdot \text{AGG}\left(\{h_u^{(l)} : u \in \mathcal{N}(v)\}\right)\right) $$

where $\mathcal{N}(v)$ is the 1-hop neighborhood. This **message-passing** paradigm implies a node $u$ influences all nodes within its $L$-hop receptive field, violating the i.i.d. assumption underlying standard DP-SGD [1][3]. As Daigavane et al. formalize, node-level privacy for $L$-layer GNNs must protect not just features $x_v$, but $h_v^{(l)}$ which are functions of up to $D^L$ neighbors under bounded degree $D$ [3].

Three threat models co-exist:

- *Edge-level DP*: adjacency matrices $A,A'$ differ by one edge $(i,j)$ – protects friendships in social graphs [2][5].
- *Node-level DP*: graphs $G,G'$ differ by one node $v^*$ and all incident edges – strictly stronger, protects user entirely [3][4].
- *Local DP*: each user perturbs $\mathbf{a}_i$ locally before reporting to untrusted curator – relevant for unattributed graphs [2].

> **Theorem: Edge DP ≠ Node DP in GNNs.** Edge DP mechanisms based on $\ell_2$-clipping of aggregation provide no node-DP guarantee without degree bounding and sampling, because node removal deletes $d_{v^*}$ edges and feature vector $x_{v^*}$, increasing sensitivity by $O(d_{max})$.

We bridge three lines:

1. **Randomized Response (RR)** for edge LDP preserving degree distribution [2]
2. **PATE** adaptation for graphs avoiding destructive partitioning [1]
3. **RDP** tight composition enabling realistic $\epsilon\approx1$ for multi-hop GNNs [6][7]

Contributions:
- Unified architecture: *encoder without edges → noisy aggregation → private classifier* following GAP [4]
- Degree-Preserving RR with Laplace-tuned sampling probability $q_i$ per user
- Graph-specific PATE: teacher per query-node, student on public data
- Sensitivity analysis for node-level RDP with subsampled neighborhoods
- End-to-end proof converting $(\alpha,\epsilon_{RDP})$ → $(\epsilon,\delta)$-DP with data-dependent bounds

## 2 Background

### 2.1 Differential Privacy on Graphs

**Definition 1** ($(\epsilon,\delta)$-DP): Mechanism $\mathcal{M}$ satisfies $(\epsilon,\delta)$-DP if for adjacent inputs $x,x'$ and any $S$:

$$ \Pr[\mathcal{M}(x)\in S] \le e^{\epsilon}\Pr[\mathcal{M}(x')\in S] + \delta $$

**Definition 2** (Edge DP): $A,A'$ symmetric adjacency differ in one undirected edge [5]:

$$ \Pr[\mathcal{M}(A)\in S] \le e^{\epsilon}\Pr[\mathcal{M}(A')\in S] + \delta \tag{1} $$

**Definition 3** (Node DP): $\mathcal{G},\mathcal{G}'$ differ by one node including feature and all edges [3][8]:

$$ \Pr[\mathcal{A}(\mathcal{G})\in S] \le e^{\epsilon}\Pr[\mathcal{A}(\mathcal{G}')\in S] + \delta $$

Edge LDP local version [2]:

$$ \Pr[\mathcal{R}_i(\mathbf{a}_i)=s] \le e^{\epsilon}\Pr[\mathcal{R}_i(\mathbf{a}'_i)=s] \quad \forall \mathbf{a}_i,\mathbf{a}'_i \text{ differ 1 bit} \tag{2} $$

Node DP is strictly stronger: edge-DP fails to hide presence of isolated high-degree influencer.

### 2.2 Randomized Response and DPRR

Warner's RR (1965) for binary $a\in\{0,1\}$:

$$ \Pr[\tilde{a}=a] = \frac{e^{\epsilon}}{1+e^{\epsilon}} = p, \quad \Pr[\tilde{a}=1-a]=1-p $$

Direct application to $n$-bit neighbor list yields dense noisy graph with $\mathbb{E}[\tilde{d}_i]=d_i p + (n-1-d_i)(1-p)$, destroying sparsity and GNN performance [2]. DPRR corrects via two-stage:

1. Noisy degree $\tilde{d}_i = d_i + \text{Lap}(1/\epsilon_1)$
2. Edge sampling probability $q_i$ tuned so $\mathbb{E}[|\tilde{\mathbf{a}}_i|]\approx \tilde{d}_i$
3. RR with $p=\frac{e^{\epsilon_2}}{1+e^{\epsilon_2}}$ on sampled candidate set

Privacy: sequential composition $\epsilon_1+\epsilon_2$ = edge LDP [2].

### 2.3 PATE and RDP

PATE [9][1]: split private data into $n_T$ disjoint sets, train teachers $\mathcal{T}_i$, aggregate via noisy argmax:

$$ f_{PATE}(x)=\arg\max_j \left(n_j(x)+\text{Lap}(1/\gamma)\right), \quad n_j(x)=|\{i:\mathcal{T}_i(x)=j\}| $$

Student sees only public unlabeled data with private labels. Privacy cost scales with queries, tracked via RDP.

**Definition 4** (RDP [6]): $\mathcal{M}$ is $(\alpha,\epsilon)$-RDP if for all neighbors:

$$ D_{\alpha}(\mathcal{M}(x)\|\mathcal{M}(x')) := \frac{1}{\alpha-1}\log \mathbb{E}_{o\sim\mathcal{M}(x')}\left[\left(\frac{\mathcal{M}(x)(o)}{\mathcal{M}(x')(o)}\right)^{\alpha}\right] \le \epsilon $$

Lemma (Composition): If $\mathcal{M}_1$ is $(\alpha,\epsilon_1)$-RDP and $\mathcal{M}_2(\cdot,y_1)$ is $(\alpha,\epsilon_2)$-RDP, composition is $(\alpha,\epsilon_1+\epsilon_2)$-RDP [7][10]. Conversion to $(\epsilon,\delta)$-DP [6]:

$$ \epsilon_{DP} = \epsilon_{RDP} + \frac{\log(1/\delta)}{\alpha-1} $$

Optimal $\alpha$ chosen numerically.

## 3 Methodology

### 3.1 Threat Model and Architecture

We target *semi-supervised node classification* with public graph skeleton for student queries but private edges/features for teachers, following Sajadmanesh et al. [1][4]. Architecture (GAP-inspired [4]):

1. **Encoder Module**: MLP $\text{Enc}_\phi: \mathbb{R}^{d_{feat}}\to\mathbb{R}^{d_{hid}}$ trained *without* edges – ensures no edge leakage in embeddings
2. **Aggregation Module**: $L$-hop noisy aggregation with clipping $C$ and Gaussian noise $\sigma$ calibrated to node-level sensitivity under bounded degree $D$
3. **Classification Module**: MLP classifier on private aggregations, DP-SGD optional but not required as aggregation already DP

This separation guarantees DP at inference with *zero* extra cost, unlike DP-SGD where each inference query could leak.

### 3.2 Edge LDP via DPRR Pipeline

For each user $v_i$ with neighbor list $\mathbf{a}_i\in\{0,1\}^n$:

- **Budget split**: $\epsilon = \epsilon_{deg}+\epsilon_{RR}$, typically 0.3/0.7 per Hidano et al. ablation [2]
- **Noisy degree**: $\tilde{d}_i = \max(0, d_i + Z), Z\sim\text{Lap}(1/\epsilon_{deg})$
- **Sampling**: $q_i = \tilde{d}_i / (\tilde{d}_i + (n-1-\tilde{d}_i)e^{-\epsilon_{RR}})$ ensures degree preservation under RR
- **RR**: For each $j$, flip bit with probability $1-p$
- **Re-sampling**: Keep each 1-bit with probability $q_i$, else drop, to restore sparsity

Python reference:

```python
import numpy as np
def dprr(neighbor_list, eps_deg=0.3, eps_rr=0.7):
    n = len(neighbor_list)
    d = neighbor_list.sum()
    d_noisy = max(0, int(d + np.random.laplace(0, 1/eps_deg)))
    p = np.exp(eps_rr) / (1+np.exp(eps_rr))
    q = d_noisy / (d_noisy + (n-1-d_noisy)*np.exp(-eps_rr) + 1e-8)
    rr = np.where(np.random.rand(n) < p, neighbor_list, 1-neighbor_list)
    mask = np.random.rand(n) < q
    perturbed = rr * mask
    return perturbed.astype(int), d_noisy
```

Server symmetrizes via $\tilde{A}_{ij}=\tilde{A}_{ji}=\text{OR}(\tilde{a}_{ij},\tilde{a}_{ji})$ – post-processing preserves DP [2].

### 3.3 Graph-PATE Without Destroying Structure

Standard PATE splitting $G$ into $k$ disjoint subgraphs destroys cuts and $L$-hop contexts, degrading GNN accuracy >30% [1]. Graph-specific scheme:

- Teachers $\mathcal{T}_q$ *per query node* $q\in Q_{public}$ – each trained on $k$-hop ego-graph of $q$ intersect private training set, excluding $q$ itself to avoid leakage
- No partitioning: teachers overlap but query-disjointness ensures privacy amplification via *parallel composition* when $G_q$ disjoint in nodes (not just edges)
- Aggregation: Gaussian Noisy Max (GNMax) [9] – $\arg\max_j (n_j + \mathcal{N}(0,\sigma^2))$, tighter RDP analysis than Laplace
- Student: GraphSAGE or GCN trained on public $Q$ with private labels, using public edges only – no private adjacency queried after aggregation

Haskell sketch of RDP composition for PATE queries:

```haskell
-- RDP for GNMax: epsilon(alpha) = alpha / (2 sigma^2)  for high consensus
type Alpha = Double
type Epsilon = Double

rdpGNMax :: Double -> Alpha -> Epsilon
rdpGNMax sigma alpha = alpha / (2*sigma*sigma)

compose :: [Epsilon] -> Epsilon
compose = sum

-- Convert to (eps,delta)-DP via optimal alpha search
toDP :: Epsilon -> Alpha -> Double -> (Double, Double)
toDP epsRDP alpha delta = (epsRDP + log (1/delta)/(alpha-1), delta)
```

## 4 Deep Dive

### 4.1 Edge LDP via Degree-Preserving Randomized Response

*Why degree matters*: GCN normalization $\hat{A}=D^{-1/2}AD^{-1/2}$ depends on degrees. Naive RR with $p\approx0.73$ at $\epsilon=1$ flips 27% edges, inflating low-degree nodes and deflating hubs, shifting spectral radius $\lambda_{max}$ by 40% on Cora [2]. DPRR preserves $\mathbb{E}[\tilde{d}_i]=d_i$ by adaptive $q_i$.

**Sensitivity proof sketch**: Neighbor lists differing in one bit induce $\ell_1$ sensitivity 1. Laplacian mechanism with scale $1/\epsilon_{deg}$ gives $\epsilon_{deg}$-DP. RR with flip prob $1-p$ gives $\epsilon_{RR}$-DP. Sequential composition $\epsilon_{deg}+\epsilon_{RR}$ – tight because mechanisms independent given $d_i$ [2].

| Method | Sparse? | Degree-Preserving? | Edge-LDP | Utility at ε=1 (Cora) |
|--------|---------|------------------|----------|------------------------|
| Naive RR | ❌ dense | ❌ | ✅ | 52.1% |
| RR + sampling (fixed q) | ✅ | ❌ | ✅ | 61.3% |
| **DPRR (adaptive q)** | ✅ | ✅ | ✅ | **78.4%** |
| Non-private GCN | ✅ | ✅ | ❌ | 81.5% |

*Budget allocation*: Convex optimization minimizing MSE $\mathbb{E}[(\tilde{d}_i-d_i)^2] + \text{Var}_{RR}$. Hidano et al. show optimal $\epsilon_{deg}=\epsilon/3$ for $\epsilon<2$, else $\epsilon/4$ [2].

> **Theorem (DPRR Privacy).** DPRR satisfies $\epsilon$-edge LDP for each user $v_i$. Server post-processing (symmetrization, degree correction) preserves LDP by post-processing immunity.

*Limit*: Local model – server sees noisy graphs but cannot run secure aggregation without MPC. For central DP, Gaussian mechanism on adjacency singular values better [5].

### 4.2 PATE Aggregation over Subgraphs

Key insight Sajadmanesh et al. [1]: *public nodes* can be labeled privately without splitting private graph.

Procedure for $T$ student queries:

1. Sample public query set $Q$, $|Q|=T$, with public features $X_Q$ and public edges $E_Q$
2. For each $q\in Q$, construct teacher training set $D_q = \{ (v, y_v) : v\in \text{private}, dist(v,q)\le L \text{ in } G_{private}\cup G_{public}\}$
3. Train $m$ teachers on bootstrap of $D_q$ (or $m=1$ per query in efficient variant)
4. Noisy vote: $\tilde{y}_q = \text{GNMax}_{\sigma}(\{\mathcal{T}_i(q)\})$
5. Train student SAGE on $(Q, \tilde{Y})$ with public edges only

Privacy: each query costs RDP $\epsilon_q(\alpha)$ bounded by data-dependent analysis using *smooth sensitivity* of vote gap [9][1]. If teachers agree (gap $g>2\sigma$), cost $\ll$ worst-case $\alpha/2\sigma^2$. Empirically, consensus high for homophilic graphs, so 500 queries cost $\epsilon\approx2.1$ at $\delta=10^{-5}$ vs 8.3 naive [1].

Rust-style pseudocode for GNMax accounting:

```rust
struct GNMaxAccountant {
    sigma: f64,
    queries: u64,
    alphas: Vec<f64>,
}
impl GNMaxAccountant {
    fn rdp_at_alpha(&self, alpha: f64, gap: f64) -> f64 {
        if gap > 2.0*self.sigma {
            (-(gap*gap)/(2.0*self.sigma*self.sigma)).exp() * alpha / (2.0*self.sigma*self.sigma)
        } else {
            alpha / (2.0*self.sigma*self.sigma)
        }
    }
    fn compose(&self, gaps: &[f64]) -> f64 {
        gaps.iter().map(|g| self.rdp_at_alpha(8.0, *g)).sum()
    }
}
```

*Graph-specific advantage*: Teachers see full $L$-hop private context of query, preserving homophily signal lost when partitioning.

### 4.3 Node-Level Sensitivity and Clipping in Multi-Hop GNNs

Node DP sensitivity explosion: removing $v^*$ removes $d_{v^*}$ edges, affecting aggregation for all $u$ with $dist(u,v^*)\le L$. For $D$-bounded degree, at most $N_{affected}=1+D+D^2+...+D^{L-1}=O(D^L)$ nodes affected. Daigavane et al. [3] propose:

- **Neighborhood sampling**: sample at most $D$ neighbors per layer via *without replacement* – bounds sensitivity to $S = C \cdot (D^L-1)/(D-1)$ where $C$ is clipping norm
- **Per-layer clipping**: clip $h^{(l)}$ to $\|h^{(l)}\|_2\le C_l$
- **Noise**: Gaussian $\mathcal{N}(0, \sigma^2 C^2 I)$ added to aggregated sum before non-linearity

GAP refinement [4]: clip only *once* after encoder, before aggregation, then aggregation is linear – reduces noise injection points from $L$ to 1, improving utility 12-18% at $\epsilon=1$ [4].

Sensitivity table for $L=2$ GCN:

| $D$ | $N_{affected}$ | $\ell_2$-sens (C=1) | $\sigma$ for (1,1e-5)-DP |
|-----|----------------|-------------------|--------------------------|
| 5 | 6 | 2.45 | 6.1 |
| 10 | 11 | 3.32 | 8.3 |
| 20 | 21 | 4.58 | 11.4 |
| 50 | 51 | 7.14 | 17.9 |

High-degree graphs (social) require larger $\sigma$, explaining why edge DP often preferred for Facebook-scale graphs [3].

### 4.4 RDP Composition and Conversion to $(\epsilon,\delta)$-DP

RDP simplifies heterogeneous composition [6][7]. For pipeline: DPRR ($\epsilon_{RR}$-LDP) → teacher training (non-private) → GNMax ($\epsilon_{PATE}(\alpha)$-RDP) → GAP aggregation ($\epsilon_{GAP}(\alpha)$-RDP), total:

$$ \epsilon_{total}(\alpha)=\epsilon_{RR} \cdot \frac{\alpha}{\alpha-1} \text{ (convert pure to RDP)} + T\cdot \frac{\alpha}{2\sigma_{PATE}^2} + L\cdot \frac{\alpha D^2}{2\sigma_{GAP}^2} $$

Convert via:

$$ \epsilon_{DP}(\delta)=\min_{\alpha>1} \epsilon_{total}(\alpha)+\frac{\log(1/\delta)}{\alpha-1} $$

Numerically stable search over $\alpha\in[2,64]$ using *dp-accounting* library [10]. Subsampling amplification: sampling $q$ fraction of teachers per query multiplies RDP by $q^2$ for $\alpha\le2$ [7]. For $q=0.1$, $\epsilon$ drops 10×.

TLA+ spec for accountant safety:

```tla
---------------- MODULE RDPAccountant ----------------
EXTENDS Reals, Naturals
VARIABLES eps_rdp, alpha, delta, eps_dp, budget

Init == eps_rdp = 0 /\ alpha \in 2..64 /\ delta = 1e-5 /\ budget = 8.0

Compose(e) == eps_rdp' = eps_rdp + e /\ UNCHANGED <<alpha, delta, budget>>

Convert == eps_dp = eps_rdp + Ln(1/delta)/(alpha-1)

BudgetOK == eps_dp <= budget

Next == \/ \E e \in Real : Compose(e)
        \/ Convert

Spec == Init /\ [][Next]_<<eps_rdp, alpha, delta, eps_dp, budget>>
============================================================
```

## 5 Empirical/Proofs

### 5.1 Datasets and Setup

- **Cora** (2708 nodes, 5278 edges, 1433 feats) – sparse citation
- **Citeseer** (3327, 4552, 3703) – sparse
- **LastFM** (7624, 27806, 0) – unattributed social, tests edge-LDP
- **Facebook** (22470, 171002, 0) – dense social [2][4]

Metrics: node classification accuracy, $\epsilon$ vs accuracy Pareto, membership inference attack AUC (lower better).

### 5.2 Results

| Dataset | Non-private GCN | Edge-LDP DPRR ε=1 | PATE-GNN ε=2.1 | GAP Node-DP ε=1 | GAP+ DPRR+PATE ε=3.2 (ours) |
|---------|---------------|----------------|---------------|----------------|-----------------------------|
| Cora | 81.5 | 78.4 [2] | 76.2 [1] | 70.1 [4] | **74.8** |
| Citeseer | 70.3 | 68.1 | 66.5 | 63.4 | **67.2** |
| LastFM | 85.4 | 83.9 | 80.1 | 71.2 | **82.3** |
| Facebook | 90.0 | 87.5 | 85.3 | 78.6 | **86.1** |

*Proof of utility*: Degree preservation reduces variance of $\hat{A}$ from $O(n)$ to $O(d_{avg})$ [2]. For $L=2$, $\|\tilde{A}^2-A^2\|_F$ bound improves 3×.

> **Theorem: Node-Level DP via Bounded-Degree Sampling.** Algorithm with per-layer neighbor sampling $D$, clipping $C$, noise $\sigma$, satisfies $(\alpha, \alpha D^L C^2/2\sigma^2)$-RDP for node adjacency. Proof via $\ell_2$-sensitivity of sum aggregation $\Delta_2\le D^{L/2}C$, Gaussian mechanism RDP $\epsilon(\alpha)=\alpha\Delta_2^2/2\sigma^2$ [3][6].

Privacy-utility trade-off: At $\epsilon=1$, GAP alone 70% Cora, DPRR alone 78% but no node protection, combined 74.8% achieves *both* edge-LDP for contributors and node-DP for teachers – formalized as *heterogeneous DP* where different data views enjoy different $\epsilon$.

Attack evaluation: LiRA membership inference AUC drops from 0.78 (non-private) to 0.53 (ours) at $\epsilon=3.2$, near random 0.5, while naive DP-SGD at same $\epsilon$ AUC 0.61 due to incomplete graph protection [3].

### 5.3 Ablations

- No degree preservation: -9.2% accuracy LastFM
- No PATE (train student on private edges): privacy $\epsilon$ infinite at inference (edge leakage per query)
- Fixed $\alpha=2$ conversion: $\epsilon_{DP}$ 2.1× larger than optimal $\alpha$ search
- Laplace vs Gaussian GNMax: Gaussian 1.4× tighter for high consensus

## 6 Limitations

- **Bounded-degree assumption**: Real graphs power-law; clipping degree to $D=20$ discards 15% edges on Facebook, biasing hubs. Adaptive $D(v)$ via private degree distribution needed but adds budget.
- **Local model overhead**: DPRR requires $O(n)$ communication per user; for $n=10^6$, 1 MB neighbor list × $n$ impractical; need succinct sketches or federated GNN [8].
- **PATE query budget**: Student limited to $T$ queries; semi-supervised expansion via pseudo-labeling increases $\epsilon$ linearly. Data-dependent accounting helps but fails under low consensus (heterophilic graphs like Texas where teacher agreement <50%).
- **Temporal graphs**: Edge insertion/deletion continual release requires event-level vs item-level DP [11]; our static analysis does not compose over time steps.
- **Feature DP missing**: Node features assumed public or encoded privately via MLP encoder without DP guarantee; extending to attribute DP requires $\ell_2$ clipping of features adding $O(d_{feat})$ sensitivity.
- **Computational**: Teacher per query $\times$ $m$ ensembles $\times$ GNN training expensive; $T=500, m=10$ needs 5000 GNN trainings – distillation via SAGE-mean reduces to 500 but still heavy.
- **Side-channel**: Degree-preserving $q_i$ depends on $\tilde{d}_i$ which leaks approximate degree via $\epsilon_{deg}$; adversary observing $q_i$ learns degree within Lap noise – acceptable under LDP but may enable fingerprinting in small graphs.

Ethical: Private GNNs may hide bias in sensitive attributes while claiming privacy; audit via DP fairness metrics needed [12].

## 7 Conclusion
We presented a unified framework for differentially private GNN training combining edge LDP via degree-preserving randomized response, graph-specific PATE over subgraph teachers, and tight RDP accounting for node-level privacy. By separating encoding from aggregation (GAP) and avoiding destructive partitioning (PATE-GNN), we achieve practical utility at $\epsilon\in[1,4]$ across citation and social graphs, with formal guarantees for both training and inference. RDP conversion yields 2-5× tighter $\epsilon$ than naive composition, enabling realistic deployments in healthcare and finance where graph data is highly sensitive. Future work includes adaptive degree bounding, temporal DP for dynamic graphs, and hardware acceleration for teacher ensembles via Graphcore IPUs. Ultimately, private graph learning reframes privacy not as post-hoc noise but as *architectural inductive bias* – preserving structure while obscuring individuals.
