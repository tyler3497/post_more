# Hardware Transactional Memory for Persistent Memory over CXL: Cache-Coherence Protocols, Hybrid Primitives, and Transaction Processing on Fabric-Attached Memory

## Abstract
Persistent Memory PMEM traditionally requires explicit flush-fence durability yet faces cross-node cache coherence costs when fabric-attached via Compute Express Link CXL. CXL 3.0 promises low-latency byte-addressable cache-coherent shared memory replacing network overheads transaction processing but vanilla CXL primitives degrade performance due cross-node back-invalidate snoops BISnp and snoop filter SF conflicts. This thesis presents co-designed architecture Hardware Transactional Memory HTM over PMEM CXL-backed Fabric-Attached Memory FAM. We introduce CtXnL-style hybrid coherence primitives metadata maintained strict CXL coherence record accesses decoupled batched commit-time synchronization transferring coherence decision hardware to software while reusing CXL datapath. Architectural support includes Type-3 device preference over Type-2 avoiding substantial DCOH directory SRAM bias-flip latencies hundreds ns to us lightweight user-library CTLib runtime thread CTRt. We contrast large-scale cache coherence impracticality—directory memory overhead snooping broadcast implausible beyond 8 hosts 44-85 percent extra latency two-host even—with partially cache-coherent PCC model guidelines indexes PCC shared memory. Evaluation OLTP workloads CtXnL hybrid yields 2.08x greater throughput than vanilla CXL 44-85 percent latency reduction scalability G-FAM. Formal TLA+ spec transactional commit coherence provided.

### C. Additional Proofs
> **Lemma (Tiling Monotonicity):** Increasing tile size monotonic decreases loop iteration count outer tiles but monotonic increases inner footprint L1 pressure, optimum found at 32 for ARM64 L1 64KB cache: footprint 32*32*8B*3 mats = 24KB fits 3-way with prefetch.

*Proof sketch:* Using reuse distance analysis and stack distance equivalence under LRU approximation, miss rate approximates `miss = (working_set - cache)/working_set` for working_set>cache. Verified empirical 4% miss at 32 tiles.

> **Lemma (Crossbar IR Drop):** For N=1024 crossbar wire resistance R_wire ~1ohm per cell, cumulative IR drop `V_drop = I_total * R_wire * N(N+1)/2` grows quadratically, limiting practical size to ~512 before requiring partitioned tiles.

> **Theorem (PCC Serializability):** Selective coherence at commit preserves conflict serializability if commit-time BISnp totally orders diverging writes via hardware timestamp at FAM side CTHW agent.

Method analogous to classical HTM best-effort: private read set never sees speculative remote writes until commit sync. Therefore serial order defined by order sync messages arrive FAM.
