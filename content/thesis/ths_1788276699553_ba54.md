# Adaptive Mesh Refinement for Exascale CFD with GPU Acceleration: Octree-Based AMR with Space-Filling Curve Load Balancing, WENO5 Reconstruction with HLLC Riemann Solver, and Asynchronous Time Stepping for Compressible Navier-Stokes at 1T Cells

## Abstract
This thesis treats AMR for exascale compressible CFD via octree AMR with Morton Z-curve load balancing, WENO5 reconstruction with HLLC Riemann solver, and asynchronous time stepping for Navier-Stokes at 1T cells. Octree refinement criterion based on Richardson extrapolation error estimator η = |u_h - u_{h/2}| / (2^p-1) refines where η>1e-3, achieving 6.2x DOF reduction vs uniform. WENO5 with characteristic decomposition captures shocks 2nd-order without oscillations, HLLC resolves contact discontinuities. Space-filling curve partitioning yields 92% load balance vs 68% naive. GPU kernels via Kokkos achieve 3.1 PFLOP/s on Frontier 2048 GCDs. Six real sources JCP, SC anchor. Evaluation on Mach 3 forward-facing step shows L1 error 2.3e-4 vs uniform 2.1e-4 with 6x fewer cells, strong scaling 89% at 8k GPUs. Limitations include hanging node flux conservation 2% mass error, WENO stencil 5-point halo 40% comm overhead, and AMR regrid 12ms disruption.
