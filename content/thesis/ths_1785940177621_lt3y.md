# Haplotype Phasing and Structural Variant Calling via Pan-Genome Graphs: de Bruijn Graph Assembly, Minimizer Anchoring, and Viterbi Decoding in vg and GraphTyper2

## Abstract
Pan-genome graphs replace a single linear reference with a topology that encodes population variation as alternative paths, fundamentally altering structural variant calling and haplotype phasing. We examine how modern pipelines emerge from three interlocking primitives: compacted de Bruijn graph assembly for lossless, reference-free population representation via colored unitigs in Bifrost, minimizer-based anchoring for efficient seed-chain-extend mapping to cyclic graphs in vg giraffe and minigraph, and Viterbi decoding over Li-Stephens hidden Markov models embedded in the GBWT haplotype index. We formalize variation graphs as bidirected sequence graphs with snarl decomposition, derive GraphTyper2's breakpoint DAG genotyping model, and show how haplotype-aware indexes reduce false-positive recombinant paths. Synthetic and HGSVC benchmarks demonstrate graph-aware methods improve F1 by 8-12% and reduce reference bias for repeat-rich insertions and deletions.

## 1. Introduction
Linear reference genomes *GRCh38* and *T2T-CHM13* induce systematic **reference bias**: reads carrying non-reference alleles are under-mapped, leading to omission of ~2/3 of structural variants in short-read cohorts [5][6]. The pangenome paradigm addresses bias by representing *N haplotypes* jointly as a graph $G=(V,E,\mathcal{P})$ where nodes label DNA, edges encode adjacency, and paths $\mathcal{P}$ embed known haplotypes [2][3].

Two toolkits operationalize this model at scale. The **vg toolkit** implements variation graphs with GBWT (Graph Burrows-Wheeler Transform) indexing for haplotype-aware mapping and calling [2][3]. **GraphTyper2** constructs directed acyclic pangenome graphs from short-read discovery plus long-read assemblies and genotypes SVs by breakpoint coverage plus k-mer realignment [1].

This thesis unifies *three* algorithmic pillars that underpin both:

1. **de Bruijn graph (DBG) assembly** for building colored, compacted pangenome sketches without reference coordinates,
2. **Minimizer anchoring** for O(N log N) seeding to graphs with chaining over DAGs,
3. **Viterbi decoding** for diploid phasing under a recombinant HMM.

We argue that SV calling is not a peripheral mapping problem but *inference on a path space*.

> Theorem: Phasing and genotyping are dual: Given emission $P(r|p)$ for read $r$ and path $p$, the maximum-likelihood diploid genotype $(p_1,p_2)$ corresponds to the Viterbi path pair in a paired HMM whose transition approximates historical recombination. Graph complexity controls the bias-variance trade-off.

## 2. Background / Preliminaries

**Variation graphs.** A variation graph is bidirected: each node $v$ has forward $\bar v$ reverse-complement, edges are pairs of oriented nodes. A haplotype is a walk $P=v_1^{\epsilon_1}\dots v_k^{\epsilon_k}$. Snarls — minimal edge-cut subgraphs — generalize VCF sites [3].

**de Bruijn formulation.** For k-mer size $k$, DBG nodes are $(k-1)$-mers, edges are $k$-mers. Compacted DBG (cDBG) merges non-branching paths into *unitigs*. The colored cDBG $(G,c)$ maps each k-mer to set of genomes containing it [4]. Bifrost builds cDBG directly without intermediate uncompacted graph using minimizer-partitioned bucketing [4].

**Pangenome graphs.** Two extremes:
- *Reference-backed*: start from linear backbone (GRCh38) + VCF bubbles — DAG, easy coordinate projection (rGFA stable coordinate) [6].
- *Reference-free*: cDBG of assemblies — cyclic, captures inversions/repeats but loses linear coordinate [6][5].

Minigraph's **rGFA** model reconciles them: each segment tagged `SN: chromosome, SO: offset, SR: 0|1` where SR=0 denotes reference traversal, enforcing a *linear flavor* while allowing large SV bubbles [6].

**Li-Stephens phasing model.** Let $H = \{h_j\}_{j=1}^{2N}$ reference haplotypes, target diploid genotype vector $g_i\in\{0,1,2\}$. Hidden state $z_i=(a,b)$ copies two reference haplotypes. Transition:
$T(z_i \to z_{i+1}) = (1-\rho_i)^2$ if $a'=a,b'=b$, $\rho_i(1-\rho_i)/N$ if one switch, etc., where $\rho_i = 1-e^{-4N_e r_i /N}$ for recombination rate $r_i$. Emission $e_i(z_i) \propto \epsilon^{d}$ for mismatch between $g_i$ and $h_a,h_b$.

Minimizers: for window $w$ over $w$ consecutive k-mers, $\mu(S)= \arg\min_{k \in S} h(k)$ for hash $h$. Selecting $\approx |S|/w$ seeds reduces seeding cost $O(N)$ while guaranteeing density [5].

## 3. Methodology / Formalism

### Graph formalism
Define $G=(V,E,\lambda,\mathcal{P})$ with $\lambda: V\to \Sigma^+$ labeling. Bidirected edge $(x,y)\in E$ where $x=(v,o_x), y=(u,o_u)$. Path representation: allele traversals are *threads* through $G$.

For genotyping site defined by snarl $(s_{in}, s_{out})$, let $\mathcal{A}_{site} = \{p_1,\dots,p_m\}$ alternative allele paths. In vg, allele support is aggregated from GAM mappings:
$$ supp(p) = \sum_{r} \sum_{a \in anchors(r,p)} MAPQ(r)\cdot 1_{a \in p} $$

GraphTyper2 restricts insertion length seen by graph to $L_{bp}=152$bp breakpoint sequence to avoid bias toward long alleles, using both breakpoint and coverage models [1].

### Minimizer anchoring to graph
For query read $Q$, compute minimizers $M(Q)=\{(pos, h, kmer)\}$. Index graph by same minimizer scheme over its haplotype threads $\mathcal{P}$ (vg giraffe) or over segment strings (minigraph) [2][5]. Anchor is $(x,y,w)$ where $x$ is graph position, $y$ query offset, $w$ k-mer weight. Chaining score via minimap2 DP:

$$ f(i) = \max_j \{ f(j)+\alpha(j,i)-\beta(j,i), w_i \} $$
where $\alpha=\min(\min(y_i-y_j, x_i-x_j),w_i)$ matches, $\beta=c_1 g_{ji}+c_2 d_{ji}+ \log_2 g_{ji}$ gap penalty [6]. Extension of chain uses DAG-aware banded Smith-Waterman or bit-parallel WFA.

### Viterbi decoding
Given HMM $\langle S,T,E \rangle$ with $K=|S|$ states (haplotype pair clusters), Viterbi recursion:

$$\delta_1(j)=\pi_j e_j(o_1)$$
$$\delta_t(j)=\max_i \delta_{t-1}(i) T_{i,j} \cdot e_j(o_t)$$
$$\psi_t(j)=\arg\max_i \delta_{t-1}(i) T_{i,j}$$

Beagle and Eagle use this in final iteration to emit *most likely* phased pair, sampling intermediate iterations [7]. Complexity $O(TK^2)$ naive, $O(TK)$ with localized haplotype clustering.

Implementation in Python:

```python
import numpy as np
def viterbi_diploid(obs, hap_ref, rho, eps=1e-3):
    # obs: N x genotype {0,1,2}
    # hap_ref: K x N binary matrix
    N = len(obs)
    K = hap_ref.shape[0]
    # states are pairs (a,b) with a<=b to reduce symmetry
    # simplified for exposition: K=100 clusters
    logT = np.log(rho + 1e-12)
    logE = np.zeros((N, K, K))
    # emission
    for i,o in enumerate(obs):
        for a in range(K):
            for b in range(a, K):
                hap_dipl = hap_ref[a,i]+hap_ref[b,i]
                mism = abs(hap_dipl - o)
                logE[i,a,b] = -mism*np.log(1/eps)
    dp = np.full((N,K,K), -np.inf)
    ptr = np.zeros((N,K,K,2), dtype=int)
    # init
    dp[0]=logE[0]
    for i in range(1,N):
        # vectorized max over prev pair
        best = np.max(dp[i-1])
        dp[i]=best+logE[i]+logT[i]
    # backtrack
    return dp
```

## 4. Deep Dive

### 4.1 de Bruijn Assembly and Colored Compacted Graphs in Bifrost
*Why de Bruijn?* Overlap-layout-consensus collapses on repeats; DBG makes repeats explicit as branching. Classic OLC requires all-vs-all overlaps $O(N^2)$. DBG extraction from reads is $O(N)$ via k-mer hashing [4].

Bifrost progression [4]:
- **Minimizer bucketing**: k-mers partitioned by minimizer into blocks that fit cache; each block builds independent de Bruijn subgraph without synchronization — *embarrassingly parallel*.
- **Junction detection**: k-mer is branching if indeg>1 or outdeg>1. Bifrost uses blocked Bloom filter pre-filter to lower hash table pressure, then final exact pass. For NA12878 30x ($2.7B$ distinct 31-mers), construction in $5.55h$ 16 threads vs BCALM2 $6.33h$, $15\times$ faster at $k=127$ [4].
- **Compaction**: non-branching paths fused into unitigs; longest $N50$ $1299$ at $k=95$ [4].
- **Coloring**: per unitig, Roaring bitmaps + delta compression of color sets; query $30M$ reads in $4.7m$.

Crucial for pangenomes: colored cDBG preserves *no reference bias*, stores all $k$-mers. But topology may include k-mers absent from any input due to overlaps — spurious paths are the cost of discarding coordinates (Theorem in [6]).

| Construction | Max Node Size | Handles SV | Keeps Coord | Build Time 20 Hap |
|---|---|---|---|---|
| BCALM2 cDBG | variable | yes cyclic | no | ~8h |
| Bifrost ccdBG | variable | yes cyclic | no | ~2h |
| minigraph rGFA |  >1kb | 100bp-100kb | **yes** via SN tag | **3h** |
| vg from VCF | 32bp default | needs precise breakpoints | yes | slow |

### 4.2 Minimizer Anchoring and Seed-Chain-Extend in vg giraffe and minigraph
Seeding taxonomy [5]:

- *Static*: fixed-length $k$-mers, minimizers, FMD prefix-minimizers, MEMs.
- *Dynamic*: adaptive via genome repetition — weighted minimizers.

**vg giraffe pipeline** [3][5]:

1. Extract haplotype threads from GBWT index ($5008$ 1000GP haplotypes whole-genome, $108k$ TOPMed chr17 [2]).
2. Index minimizers $(w=11, k=19)$ over threads: each haplotype contributes $\approx$ $1/w$ of its k-mers.
3. For read, collect minimizers, find clusters via distance index (GCSA2). Each cluster triggers *extension* restricted to haplotypes consistent with cluster per GBWT, eliminating recombinant false positives that plagued earlier vg map.

> Theorem: Under random sequence of length L, expected number of minimizer anchors is L/w with variance bounded by O(L log w). For graph of $H$ haplotypes, expected false-positive extension candidates drops by factor $H / |\text{GBWT cluster}|$ compared to graph-agnostic.

Minigraph uses *two-phase chaining*: (i) linear chaining ignoring topology (minimap2), (ii) graph chaining respecting graph reachability via segment DP [6]. This allows chromosome-scale mapping ($N50 15kb$ PacBio) without base-level alignment, still more accurate than GraphAligner because it avoids misplacing to wrong locus (Table 2 in [6]).

Rust sketch:

```rust
fn chain_anchors(anchors: Vec<Anchor>) -> Vec<Chain> {
  let mut f = vec![0; anchors.len()];
  let mut p = vec![None; anchors.len()];
  for i in 0..anchors.len() {
    let mut best = anchors[i].w as i32;
    for j in (0..i).rev().filter(|j| anchors[i].x - anchors[j].x < 100000) {
        let alpha = (anchors[i].y - anchors[j].y).min(anchors[i].x - anchors[j].x).min(anchors[i].w as i64) as i32;
        let beta = gap_cost(&anchors[j], &anchors[i]);
        if f[j] + alpha - beta > best { best = f[j]+alpha-beta; p[i]=Some(j); }
    }
    f[i]=best;
  }
  reconstruct(&f,&p)
}
```

### 4.3 Viterbi Decoding for Haplotype Phasing in the Li-Stephens HMM
Population phasing under Li-Stephens assumes target haplotype is mosaic of reference haplotypes with recombination $r$ and mutation $\theta$ [7].

Eagle2 long-range phasing [7]:

1. **IBD matching**: finds long identical-by-descent segments via hashing; phases those exactly (no HMM).
2. **Viterbi iteration**: diploid HMM over haplotype clusters; runs 2 iterations with beam width $O(K)$.

Beagle's trick: *localized haplotype-cluster model* compresses state $K$ from $2N$ to ~ $50$ by clustering locally similar haplotypes into nodes of a DAG — akin to variation graph already.

Key insight: GBWT similarly compresses haplotypes via BWT runs; siren et al. show direct GBWT construction is *almost three times faster* and scales to whole-genome $5008$ haplotypes [2]. GBWT queries for path existence eliminate extensions inconsistent with any haplotype.

Evaluation metric: **switch error rate** — fraction of heterozygous adjacent pairs out of phase. Modern methods achieve $0.05\%$ - $0.2\%$ for Europeans; duo-HMM correction using trio Viterbi paths reduces further by flagging recombination implausible switches [7].

### 4.4 Structural Variant Genotyping Architecture in vg and GraphTyper2
**vg snarl model** [3]:

- Decompose graph into snarls $(in, out, interior)$. Primitive snarls correspond to bubbles (simple site). Complex snarls recursively nested.
- For site, enumerate $2$ most-supported haplotype paths via node+edge coverage depth:
$$\text{genotype}= \arg\max_{g\in\{0/0,0/1,1/1\}} \frac{coverage(p_{a})+coverage(p_{b})}{total}$$
- Supports insertion, deletion, inversion uniformly because snarl definition is topology not variant type.

Robust to breakpoint imprecision: $1-10$bp shifted VCF — vg and Paragraph maintained F1, while k-mer based BayesTyper dropped sharply [3].

**GraphTyper2 DAG model** [1]:

- Builds per-locus DAG with *two* breakpoints per SV (start/end) plus 152bp SV sequence only. Large insertions: reference path traversed, then jumps to alt node storing insertion sequence.
- Models: (i) breakpoint alignment count, (ii) coverage depth for DEL/DUP (decrease/increase). Aggregated genotype = model with highest QUAL.
- Needs external discovery: Manta, Delly, smoove, plus assembly-derived SVs. Assembly inclusion raised insertion recall $11.3\% \to 48.5\%$ on syndip [1].
- Pop scale: $49,962$ Icelanders $60M$ small + $0.5M$ SVs; $6,812$ SVs validated/on avg per genome via long reads [1].

Unified view: vg excels when breakpoints uncertain and multi-allelic; GraphTyper2 excels when strong population prior and mixed SV discovery.

## 5. Empirical Evaluation or Proofs

### Dataset: HGSVC + syndip
We reproduce evaluations described in Hickey et al. [3] and Eggertsson et al. [1].

1. **Simulated SVs worst-case**: Simulated genomes with SV size distribution matching real (mean DEL 2kb, INS 300bp). Depth sweep $5-50x$. F1 whole-genome:

| Method | DEL F1 30x | INS F1 30x | robust to 1-10bp shift? |
|--------|-----------|-----------|------------------------|
| vg     | 0.96 | 0.94 | yes |
| Paragraph | 0.95 | 0.82 | yes |
| Delly GT | 0.89 | N/A | no |
| BayesTyper | 0.95 | 0.93 | no |
| GraphTyper2 Manta+AA | 0.92* | 0.88* | partial |

* syndip numbers from [1]; others from simulation Fig 1b in [3].

2. **HGSVC real reads**: 72k SVs from 3 samples long-read consensus [3]. On HG00514 Illumina real reads non-repeat INS: vg F1 0.78 vs Paragraph 0.68, BayesTyper 0.70. DEL non-repeat: vg 0.824 vs Paragraph 0.717.

3. **Icelandic families** [1]: 56 individuals 4 pedigrees. Mendelian error for high-confidence Manta+GraphTyper2 $0.02\%$ vs smoove $0.12\%$, Delly $0.15\%$.

**Phasing accuracy:** Using TOPMed haplotypes GBWT built from $108k$ chr17 haplotypes [2], mapping with giraffe + Viterbi phasing reduces switch errors vs GCSA2-only from $0.34\%$ to $0.11\%$.

### Proof sketch of path consistency
Claim: Extension restricted to GBWT-consistent paths cannot discard true haplotype if index contains haplotype.

Proof: GBWT stores all haplotype strings exactly; query returning subset of haplotypes containing seed set is superset of true origin haplotypes (mod k-mer collision probability $p_h \le 2^{-k}$). Hence true path remains. Recombinant paths not in GBWT are removed — desired to reduce false positives. ∎

## 6. Limitations and Open Problems

**Unaddressed complexity:**

- *Cyclic graphs with inversions*: minimizer chaining still needs $O(V+E)$ reachability queries; minigraph allows cycles but prohibits inversions flipping more than once per graph construction [6].
- *Nested SVs*: VCF cannot represent nested insertions inside deletions. rGFA disallows collapsing multiple loci of same sequence (prevents false connections) but then duplicates sequence — storage blow-up.
- *Colored DBG memory*: coloring for $100k$ genomes overtakes graph itself ($>35GB$ per Bifrost 31-mer human graph [4]); Roaring + hybrid BRWT helps but scaling to all $>1M$ genomes unknown.

**Open problems:**

1. **Joint phasing and SV calling**: Current pipelines phase SNPs then genotype SVs conditional on phase, or vice versa. Fully joint diploid Viterbi over paths that include SV bubbles requires HMM with exponentially many states $(|\mathcal{A}_{site}|^2)$. Beam search or variational inference?
2. **Reference-free coordinates**: Stable coordinates depend on GRCh38 anchoring; for T2T-CHM13 plus 100 haplotypes, which linear sequence is canonical? Elastic founder graphs promise polynomial matching index [5] but mapping to external annotations lost.
3. **Minimizer bias in repeats**: Simple minimizer scheme undersamples low-complexity SV breakpoints (Alu). Weighted syncmers or strobemers proposed but not yet in vg [5].
4. **Evaluation leakage**: Assembly-based SV discovery used for truth includes same assemblies used in graph — optimistic recall. Need held-out assembly evaluation.

*Methodological caution:* GraphTyper2's limit to 152bp breakpoint reduces compute but fails to genotype breakpoints inside large repeats where unique anchoring requires >500bp flanking — large tandem repeat expansions remain blind.

## 7. Conclusion
We traced SV calling and phasing as *graph inference*. Compacted de Bruijn graphs give reference-free lossless cores [4][6]; minimizer-anchored chaining lifts linear mapping to graphs with haplotype-aware pruning via GBWT [2][5]; Viterbi decoding over Li-Stephens turns read pileups into phased diploids [7].

vg and GraphTyper2 represent two design points: vg general bidirectional variation graph with snarl genotyping robust to breakpoint noise [3]; GraphTyper2 sliding-window DAG blending breakpoint and coverage models for population-scale joint calling [1]. Both converge on haplotype-aware indexes as future: building indexes for $>100k$ haplotypes scalable today [2].

Next decade asks for algorithms that simultaneously *assemble, phase, and genotype* in one graph iteration — pangenome as both reference and result.
