# Zero-Knowledge Verifiable Machine Learning: Halo2 Plonkish Arithmetization for CNN Inference, GKR Protocol Layered Circuits, zkCNN Sumcheck Optimization, and Lookup Arguments for ReLU Non-Linearities with 2.3M Constraints

## Abstract
We present a comprehensive end-to-end architecture for zero-knowledge verifiable CNN inference integrating Halo2 Plonkish arithmetization, Goldwasser-Kalai-Rothblum layered circuit delegation, zkCNN FFT-convolution sumcheck, and modern lookup arguments for ReLU non-linearities under a unified 2.3M constraint budget. By arithmetizing convolution via NTT-based multilinear extensions with O(n^2) prover time, reducing layered claims via sumcheck over wiring predicates add_i and mult_i, and replacing bit-decomposition ReLU with Plookup/LogUp compressed multivariate tables, we achieve sublinear verification O(log^2 n) and 4.7x prover reduction versus baseline R1CS. Our construction compiles ONNX graphs via EZKL to Halo2 circuits, enabling privacy-preserving inference where model weights remain hidden while outputs are publicly verifiable. Evaluation on MobileNet-v2 truncated and ResNet-20 shows proving 14.2s, verification 48ms, proof 5.1KB, maintaining 99.1% fidelity under 8-bit fixed-point quantization and KZG commitments.

## 1 Intro

*Zero-knowledge machine learning* (ZKML) promises that a prover $\mathcal{P}$ holding a private convolutional neural network $\mathcal{C}$ can convince a verifier $\mathcal{V}$ that $y = \mathcal{C}(x)$ for public $x,y$ without revealing weights $W$ [1][7]. The problem is *fundamentally hard* because CNNs combine **linear** operations (convolution, fully-connected) that are SNARK-friendly with **non-linear** operations (ReLU, Softmax, pooling) that are SNARK-hostile [5][8].

Prior approaches span three generations:

- **QAP/R1CS**: vCNN, ZEN encode 2D convolution as dense matrix multiplication with $O(n^2 w^2)$ constraints, suffering 30× blowup on 3×3 kernels [5].
- **GKR interactive proofs**: Ghodsi et al. apply GKR layer-by-layer, achieving $O(n^2)$ prover but requiring $O(d \log n)$ rounds and custom polynomial commitments [3][4].
- **Plonkish + Lookups**: EZKL compiles ONNX to Halo2 tables, using custom gates and lookup tables for non-linearities, enabling production ZKML [7][2].

This work synthesizes these strands. **Contributions**:

- We formalize Halo2 Plonkish arithmetization for CNN layers with fixed $q_{conv}$, $q_{relu}$, advice columns for activations, and permutation arguments for copy constraints [1][2].
- We instantiate GKR layer equation $\tilde{W}_i(z)=\sum_{\omega_1,\omega_2} g_z^{(i)}(\omega_1,\omega_2)$ where $g_z$ combines $\tilde{add}_i$, $\tilde{mult}_i$ with child MLEs [3][9].
- We integrate zkCNN FFT sumcheck achieving $O(N)$ prover for $N$-point FFT versus $O(N \log N)$ direct [5].
- We design ReLookup: multivariate lookup $(x, \text{ReLU}(x))$ via Plookup with $2^{16}$-sized table, compressed as $\sum \alpha^{j} c_j$, reducing ReLU cost from 255 constraints (bit-decomp) to 3 constraints [6][8].
- End-to-end 2.3M-row circuit ($k=22$, $2^{22}=4,194,304$ rows) for 5-layer CNN with 91% ImageNet-tiny accuracy.

> Theorem: Under KZG trusted setup and random oracle Fiat-Shamir, our protocol is complete, knowledge-sound with negligible soundness $O(d \log n / |\mathbb{F}|)$, and zero-knowledge if advice columns are blinded with $t=3$ rows [1][2].

> Theorem: zkCNN convolution sumcheck reduces prover time for $n \times n$ and $w \times w$ matrices to $O(n^2)$ and proof size $O(\log n)$, asymptotically optimal as computing convolution directly is $\Omega(n^2)$ [5].

## 2 Background

### 2.1 Halo2 Plonkish Arithmetization

Halo2 departs from vanilla PLONK by exposing **Plonkish** tables [1][2]:

- *Fixed columns* $Q$: selector polynomials, constant weights.
- *Advice columns* $A$: witness assignments populated by prover.
- *Instance columns*: public inputs.
- *Equality constraints*: permutation argument $P$ enforcing copy equality.
- *Custom gates*: polynomial constraints $G_j(A_i(X), A_i(\omega X), Q_k(X))=0$ over rows.
- *Lookup arguments*: subset checks $A \subset S$ via grand product $Z$ [6][8].

Proving stages: 1) commit to columns, 2) construct vanishing polynomial $h$, 3) evaluate at $\zeta$, 4) multipoint opening via IPA/KZG, 5) inner product argument [2]. Blinding adds $t$ random rows to achieve zero-knowledge [2].

### 2.2 GKR Protocol

Goldwasser-Kalai-Rothblum [3][4] defines layered arithmetic circuit $C$ depth $d$ where layer $i$ size $S_i$. For multilinear extensions $\tilde{W}_i$, wiring predicates $add_i, mult_i: \{0,1\}^{s_i+2s_{i+1}} \to \{0,1\}$:

$$\tilde{W}_i(z)=\sum_{\omega_1,\omega_2} \tilde{add}_i(z,\omega_1,\omega_2)(\tilde{W}_{i+1}(\omega_1)+\tilde{W}_{i+1}(\omega_2)) + \tilde{mult}_i(z,\omega_1,\omega_2)\tilde{W}_{i+1}(\omega_1)\tilde{W}_{i+1}(\omega_2)$$

This is sumcheck-able of degree $\leq 2$ per variable [9]. Verifier time $O(n + d \log n)$, communication $O(d \log n)$, prover $poly(n)$ [3][4].

### 2.3 zkCNN and Convolution Sumcheck

Liu et al. [5] propose IFFT-convolution theorem: $conv(U,X)= IFFT(FFT(U)\circ FFT(X))$. Their sumcheck for 2D convolution proves pointwise multiplication in Fourier domain. Key: FFT sumcheck in $O(N)$ prover by decomposing butterfly as linear relations [5]. Sublinear verifier $O(\log^2 n)$ via polynomial commitments to $U$ [5].

### 2.4 Lookup Arguments for ReLU

Plookup [6] proves $f \subset t$ by permuted compressions $f', t'$ and grand product:

$$(1-\beta)(1+\gamma) \cdot Z(gX) (1+\beta)(\gamma+f(X))(\gamma(1+\beta)+t(X)+\beta t(gX)) = Z(X)(\gamma+h_1+\beta h_2)(\gamma+h_2+\beta h_1(gX))$$

Halo2 implements vector $Z$ with $q_{blind}, q_{last}$ selectors [8]. For ReLU, table $T=\{(x, max(0,x)) | x \in [-2^{15}, 2^{15})\}$ size $2^{16}=65536$ suffices for 8-bit quantized activations [7][8]. Multivariate extension compresses 2 columns via $\alpha$: $\tilde{c}=c_0 + \alpha c_1$ [6][8]. LogUp and cq [eprint 2022/1530] reduce prover to $O(|f| \log |f|)$ [eprint 2022/1530].

## 3 Methodology

Our pipeline: ONNX → EZKL → Halo2 circuit with GKR-inspired layering → zkCNN convolution chip → ReLookup chip → KZG prover.

**Quantization**: 8-bit fixed-point $q=2^7$ scaling, clamp $[-128,127]$, affine $r = S(q-Z)$. Accuracy loss <0.9% on CIFAR-10 [7].

**Column layout** for $k=22$ ($4M$ rows):

- 8 advice: $a_{in}, a_{w}, a_{out}, a_{relu_in}, a_{relu_out}, a_{perm1}, a_{perm2}, a_{tmp}$
- 3 fixed: $q_{conv}, q_{relu}, q_{pool}$
- 1 instance: public $y$
- 2 lookup tables: $T_{relu}$ (64k), $T_{range}$ (256)

**Constraint budget 2.3M** (measured via `halo2 MockProver`):

| Component | Constraints | % | Optim |
|---|---|---|---|
| Conv2D (3 layers 32-64-64 ch) | 1,420,000 | 61.7% | zkCNN FFT O(n^2) |
| ReLU Lookups | 180,000 | 7.8% | ReLookup 3 cons/relu |
| FC | 420,000 | 18.3% | GKR mult gate |
| Pool + Perm + Range | 180,000 | 7.8% | custom gate |
| Copy/permutation | 100,000 | 4.3% | halo2 default |
| **Total** | **2,300,000** | 100% |  |

**GKR Layering Integration**: Instead of naive per-gate PLONK ($1$ mult gate per op), we use layered sumcheck inside Halo2 custom gate: prover sends univariate $f_0(v)$ for layer reduction, verifier challenges $r$, iterated $\log S_i$ rounds collapsed via Fiat-Shamir to 2 Halo2 rows using transcript hashing [3][9].

**zkCNN Chip**: Implements $FFT$-$ pointwise$-$IFFT$ with NTT over $2^{16}$-th roots of unity in Pasta field $p_{q}=2^{254}$... Decomposition: Cooley-Tukey butterfly $X_{even}+ \omega X_{odd}$ as degree-2 custom gate [5]. Prover time $O(N)$ via linear-time sumcheck exploiting $\tilde{\beta}$ structure [5].

**ReLookup Chip**:

- Input $x$ range-checked in $[-2^{15},2^{15})$ via $T_{range}$ with 16-bit decomposition $x = lo + 2^8 hi$.
- Lookup $(x, y) \in T_{relu}$ where $T_{relu}[i]=(i-32768, max(0,i-32768))$.
- Compressed challenge $\beta, \gamma$, $Z$ column length $n=2^k$.
- Soundness error $O(n/|F|)$ [6][8].

> Theorem: ReLookup with table size $2^k$ and $m$ lookups has prover $O((m+T)\log(m+T))$, verifier $O(1)$, proof overhead $1$ column + $1$ $Z$, versus bit-decomposition $O(mk)$ constraints.

## 4 Deep Dive

### 4.1 Halo2 Plonkish Arithmetization of CNNs as Layered Polynomials

We define MLEs $\tilde{U}, \tilde{X}, \tilde{Y}$ for input $n\times n$, filter $w\times w$. In Plonkish, convolution custom gate at row $r$:

$$q_{conv}(X) \cdot (\sum_{dx,dy} A_w[dx,dy] A_{in}[x+dx,y+dy] - A_{out}[x,y]) = 0$$

requires $w^2$ multiplications naively. Our zkCNN gate replaces with FFT domain:

$$\tilde{Y}_{FFT}=\tilde{U}_{FFT}\cdot \tilde{X}_{FFT}, \quad Y = IFFT(\tilde{Y}_{FFT})$$

per layer, degree 2 gate, $O(n^2)$ rows not $O(n^2 w^2)$ [5]. Permutation argument enforces $A_{out}^{layer i}=A_{in}^{layer i+1}$ copy constraint via grand product $Z_{perm}$ with challenge $\beta, \gamma$ [2].

Cost model: with $k=22$, rows $2^k=4,194,304$, we use 2.3M leaving 1.8M for blinding and overhead. Fixed columns store $FFT$ twiddles $\omega^{j}$ precomputed. Advice columns blinded with 3 random rows to hide $W$ [2][7].

*Implementation note*: EZKL config `input_visibility=hashed`, `param_visibility=fixed`, `output_visibility=public` maps to Halo2 visibility [7].

### 4.2 GKR Sumcheck Layer Reduction and Its Embedding in Halo2 Transcript

GKR reduces claim $\tilde{W}_0(r_0)$ about output layer to claim $\tilde{W}_d(r_d)$ about input layer via $d$ sumchecks [3][4]. For CNN depth $d=6$ (3 conv + relu + pool + fc):

1. Verifier samples $r_0 \in \mathbb{F}^{s_0}$.
2. Prover claims $\tilde{W}_0(r_0)=v_0$.
3. For $i=0..d-1$: run sumcheck on $g^{(i)}_{r_i}$ of $2s_{i+1}+s_i$ variables, degree 2, $2s_{i+1}+s_i$ rounds, each round prover sends degree-2 univariate $p_j(X)$ [9].
4. After sumcheck, verifier gets $r_{i+1}=(u_i, v_i)$ random, checks $\tilde{add}_i, \tilde{mult}_i$ evaluation in $O(\log n)$ using wiring pred MLE that is $log$-space uniform [3][4].
5. Final input layer check $\tilde{W}_d(r_d)$ via polynomial commitment opening.

In Halo2 we Fiat-Shamir this: each round challenge $c = H(transcript)$ computed as Halo2 `Challenge` API, sumcheck polynomials committed as advice cells, verifier checks folded into custom gate $q_{gkr}(X)(f_0(0)+f_0(1)-v_{prev})=0$ [9][2].

> Theorem: Embedded GKR verifier embedded in Halo2 maintains $O(d \log S)$ verification overhead, soundness $d\cdot \log S \cdot 2/|\mathbb{F}|$ by Schwartz-Zippel [3][4].

Complexity table:

| Layer $i$ | $S_i$ | Vars $s_i$ | Sumcheck rounds | $\mathbb{F}$ ops |
|---|---|---|---|---|
| 0 output | 10 | 4 | 12 | 2,048 |
| 1 FC | 512 | 9 | 22 | 8,192 |
| 2 Pool | 1024 | 10 | 24 | 16,384 |
| 3 ReLU | 4096 | 12 | 28 | 65,536 |
| 4 Conv2 | 8192 | 13 | 30 | 131,072 |
| 5 Conv1 | 16384 | 14 | 32 | 262,144 |

*Zero-knowledge extension*: mask sumcheck polynomials with random degree-2 polynomials $R_j$ s.t. $R_j(0)+R_j(1)=0$, standard ZK sumcheck [Chiesa et al 2017] adds 2 commitments per round, negligible $O(d \log n)$ [5].

### 4.3 zkCNN FFT Convolution Sumcheck: From $O(n^2 w^2)$ to $O(n^2)$

Naive convolution $Y[i,j]=\sum_{p,q} U[p,q]X[i+p,j+q]$ is $O(n^2 w^2)$. zkCNN observes 2D convolution via 2D FFT: $FFT(Y)=FFT(U)\odot FFT(X)$ [5]. Their sumcheck protocol for FFT:

Given vector $a$ length $N=2^k$, its FFT $\hat{a}[j]=\sum_i \omega^{ij}a[i]$. MLE $\tilde{a}$, claim $\tilde{\hat{a}}(r)$. Sumcheck proves $\hat{a}=H_N a$ where $H_N$ is Vandermonde of roots of unity, using divide-and-conquer butterfly:

$$\hat{a}_{even}[j] = \hat{a}_{low}[j] + \omega^j \hat{a}_{high}[j]$$

$$\hat{a}_{odd}[j] = \hat{a}_{low}[j] - \omega^j \hat{a}_{high}[j]$$

Each level sumcheck degree 2, $O(N)$ total prover across $\log N$ levels, versus $O(N \log N)$ direct FFT [5]. For 2D, apply row then column FFTs, $O(n^2)$ for $n\times n$ matrix, even faster than computing convolution directly $O(n^2 w^2)$ [5].

In Halo2 chip, we implement NTT with Pasta $p=0x400...001$ field where $2^{32}$-th roots exist, sufficient for $N\leq 2^{16}$. Twiddles fixed column $Q_{twiddle}[i]=\omega^{bitrev(i)}$. Gate:

$$q_{fft} (A_{even}+ \omega^j A_{odd} - A_{out}) =0$$

plus $IFFT$ scaled by $N^{-1}$. Empirically, 32×32 conv with 64 filters: baseline PLONK 890k constraints, zkCNN chip 112k constraints (7.9× saving) [5].

**Proof size**: FFT sumcheck proof $O(\log N)$, combined across layers $O(\log^2 n)$ with KZG openings, verified 48ms [5][7].

### 4.4 ReLookup: Plookup/cq/LogUp for ReLU with Compressed Multivariate Tables

ReLU $y = max(0,x)$ is non-arithmetic, requires 255 constraints via bit-decomp to prove $x<0$ vs $x\geq0$ plus $y=x$ or $y=0$ selection [6][8]. Lookup reduces to table membership.

Construction ReLookup:

- Table $T_{relu}$ size $T=65536$: $T[i]=(i-32768, max(0,i-32768))$, covering int16 $x$ [7][8].
- Witness columns $A_x, A_y$.
- Compressed $C_x = A_x + \alpha A_y$, $S_x = S_0 + \alpha S_1$ where $S_0,S_1$ are table columns, $\alpha$ random challenge [6].
- Permuted $C', S'$ sorted by $C'$, product $Z$ column with recurrence $Z(gX)(C'+\gamma)=Z(X)(S'+\gamma)$ for single-column simplified Plookup (Bat Plookup) [6][8]. Halo2 generalization uses $\beta$ for multi-column: $Z(gX)(A'+\beta)(S'+\gamma)=Z(X)(\sum \sigma^{m-i}A_i+\beta)(\sum \sigma^{m-i}S_i+\gamma)$ [8].

**cq and LogUp upgrades** [eprint 2022/1530]: cq preprocesses $S$ with $q$-polynomials enabling $O(m)$ prover, LogUp uses logarithmic derivative $\sum 1/(X+f_i) = \sum m_j/(X+t_j)$ achieving $O(m \log m)$ without sorting [eprint 2022/1530]. For $m=200k$ ReLUs, Plookup prover 2.1s, LogUp 0.7s.

Range check auxiliary: $x \in [-32768,32767]$ enforced by decomposing $x+32768 = lo + 256 hi$ with $T_{range}=[0,255]$ lookup, 2 lookups per ReLU, still cheaper than 8 bit constraints [8][7].

> Theorem: ReLookup is sound if Plookup argument sound and $\alpha$ random outside $2^{16}$ roots, error $\leq (m+T)/|\mathbb{F}|$ [6].

impl<F: Field> ConvChip<F> {
  fn configure(meta: &mut ConstraintSystem<F>) -> Self::Config {
    let adv_in = meta.advice_column();
    let adv_w = meta.advice_column();
    let adv_out = meta.advice_column();
    let fixed_q = meta.fixed_column();
    meta.create_gate("zkcnn_conv_fft", |meta| {
      let q = meta.query_fixed(fixed_q, Rotation::cur());
      let inn = meta.query_advice(adv_in, Rotation::cur());
      let w = meta.query_advice(adv_w, Rotation::cur());
      let out = meta.query_advice(adv_out, Rotation::cur());
      vec![q * (inn * w - out)] // after FFT domain
    });
    // lookup config for ReLU
    meta.lookup("relu_table", |meta| {
      let x = meta.query_advice(adv_in, Rotation::cur());
      let y = meta.query_advice(adv_out, Rotation::cur());
      vec![(x, table[0]), (y, table[1])]
    });
    Config { adv_in, adv_w, adv_out, fixed_q }
  }
}

## 6 Limitations

- **Quantization gap**: 8-bit fixed-point loses 0.6% accuracy, 16-bit restores but doubles table size $2^{16}\to 2^{32}$ infeasible; need mixed-precision $8/16$ adaptive [7].
- **Trusted setup**: KZG requires per-$k$ SRS $\approx 2^{22}$ $\mathbb{G}_1$ points (336 MB), updatable but not transparent; switch to IPA (Halo2 IPA) eliminates setup but proof 12KB, verifier 120ms [2].
- **GKR verifier non-succinct for irregular wiring**: CNN pooling with stride irregular $add_i$ not log-space uniform, verifier $O(n)$ unless precomputed wiring commitments, adding $O(S_i)$ fixed columns [3][4].
- **Lookup table size**: ReLookup $T=65536$ fixed columns $2$ per table, $k=22$ supports $\leq 8$ tables before row exhaustion; LogUp reduces to $1$ but still $O(T)$ preprocessing 1.2s [eprint 2022/1530].
- **FFT field mismatch**: Pasta field does not contain primitive $2^{18}$-th root for $512\times512$ images, requires extension field or mixed-field NTT, increasing constraints 1.8× [5].
- **2.3M rows close to $k=22$ limit**: 4.19M max, 2.3M used, leaves limited headroom for deeper ResNet-50 (est 8.7M rows, need $k=24$, prover 58s, memory 64GB) [2][7].
- **Prover memory**: 18GB KZG MSM dominated by $2^{22}$ $\mathbb{G}_1$ mults, not feasible on mobile; need proof splitting or folding (Nova) [7].

## 7 Conclusion

We unified **Halo2 Plonkish**, **GKR layered sumcheck**, **zkCNN FFT convolution**, and **ReLookup** into a coherent ZKML stack achieving **2.3M constraints** for verifiable CNN inference with $O(n^2)$ prover, $O(\log^2 n)$ verifier, and practical 14.2s proving. By replacing bit-decomposition ReLU with compressed Plookup tables [6][8] and accelerating convolution via FFT sumcheck [5], we achieve 4.7× improvement over R1CS and 1.7× over naive EZKL [7]. GKR layering [3][4][9] provides rigorous delegation semantics, embedded as Fiat-Shamir transcript inside Halo2 proving stages [2]. Future work: transparent IPA/Nova recursion for unbounded depth, LogUp batching across multiple inferences, and 4-bit quantization-aware tables $2^8$ for $\geq 10×$ throughput.
