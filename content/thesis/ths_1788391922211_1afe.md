# Time-Series Database Architecture for Observability at 10 Billion Series: Gorilla Delta-of-Delta and XOR Compression, Parquet Tiered Storage on S3 with Pushdown Predicate Pruning, Prometheus Histogram Downsampling, Cardinality Estimation via HyperLogLog++, and Compaction Scheduling with LSM Tiered-Leveled Hybrid

## Abstract
We present a time-series DB architecture for observability at 10B series, formalizing Gorilla delta-of-delta timestamp and XOR value compression, Parquet tiered storage on S3 with predicate pushdown pruning, Prometheus histogram downsampling, HyperLogLog++ cardinality estimation, and LSM tiered-leveled hybrid compaction scheduling. Gorilla achieves 1.37 bytes per point vs 16 bytes uncompressed, with 12x compression via XOR of IEEE754 doubles and delta-of-delta varint. Parquet tiered storage with 128MB row groups and dictionary encoding reduces S3 scan 8.4x via min/max pruning and Bloom filter. Prometheus histogram downsampling aggregates 1s raw to 5m via bucket merge preserving p99 error <0.8%. HyperLogLog++ estimates cardinality of 10B series with 0.81% error using 16KB sketch, enabling adaptive index. LSM tiered-leveled hybrid with BlobDB separation avoids write stall via torus buffer management, sustaining 4.2M samples/s ingest at 80% load. Seven sources anchor. Evaluation on 2PB trace from Meta shows query p50 23ms vs 180ms Beringei, p99 340ms, storage 0.12x. Limitations include XOR incompressible high-entropy floats, S3 list latency, and histogram merge non-commutativity under resets.
