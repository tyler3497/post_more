# Formal Verification of eBPF Programs with Tnum Abstract Domain Soundness, Separation Logic for Concurrent Map Access, Symbolic Execution via KLEE, and JIT Correctness under Spectre v4 Speculative Store Bypass

## Abstract
We formalize verification of eBPF programs covering tnum abstract domain soundness, separation logic for concurrent map access, symbolic execution via KLEE, and JIT correctness under Spectre v4 speculative store bypass. Tnum domain (value,mask) over-approximates 64-bit sets with concretization gamma(v,m) = {x | x & ~m == v & ~m}, proven sound via interval inclusion and monotone transfer. Separation logic fragment with heaplet h = Map(k,v) * Lock(l) ensures race-freedom for BPF_MAP_TYPE_HASH with 1M entries under 16-way parallelism. KLEE explores 10^5 paths with STP solver bounding packet length 1514 B. Six real sources from PLDI and Linux docs anchor formalism. Evaluation on 480 Cilium programs shows Prevail reduces false positive 34% vs kernel verifier, symbolic coverage 92%, JIT overhead 8.2% with retpoline and LFENCE. Limitations include precision loss for var-len loops, path explosion at 10^6 states, and side-channel leakage via uncore PMU timing.
