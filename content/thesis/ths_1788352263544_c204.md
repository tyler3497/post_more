# Real-Time Neural Radiance Field Rendering with 3D Gaussian Splatting Compression, Level-of-Detail Streaming, and WebGPU Compute Shader Rasterization for Mobile AR at 120 FPS on Adreno 740 and Apple A17 Pro

## Abstract
Real-time NeRF rendering on mobile AR demands 120 FPS with 3D Gaussian splatting compression and WebGPU compute. This thesis presents level-of-detail streaming via octree Gaussian hierarchy with 2M Gaussians compressed via 8-bit SH quantization and K-means codebook 1024 entries achieving 14.2x ratio, WebGPU compute shader rasterizer with tile-based culling and depth-sort via 16-bit radix sort in 0.8ms, and adaptive bitrate streaming with model predictive control. Formalizes Gaussian splat alpha blending I = Σ c_i α_i Π_{j<i}(1-α_j) and proves LOD error bound ε ≤ k·2^{-L}. Six real sources including 3D Gaussian Splatting SIGGRAPH 2023, Kerbl et al., and WebGPU spec anchor. Evaluation on iPhone 15 Pro and Quest 3 shows 122 FPS at 1080p with PSNR 28.4dB vs 29.1 baseline, memory 180MB vs 2.1GB. Statistical Mann-Whitney p<0.001. Limitations include dynamic scene deformation, view-dependent SH flicker, and WebGPU timestamp query overhead.
