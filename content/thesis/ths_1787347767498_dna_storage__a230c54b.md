def continual_learning_step(spikes, weights, lr=0.01):

### 4.2 Algorithmic Core

**Three-factor learning:** Pre * Post * Modulator M (dopamine, surprise, error). Eligibility trace e accumulates pre-post coincidence with tau_e=200ms. Weight update Δw = η * M * e * homeostatic.

```haskell
threeFactor w e m = w + eta * m * e * homeostaticScaling w
  where eta = 0.01
        homeostaticScaling w' = 1 - (w' - wTarget)/wTarget * 0.01
```

**STDP window:**

```
W(Δt) = A+ * exp(-Δt/tau+)  if Δt>0
        -A- * exp(Δt/tau-)   if Δt<0
A+=0.1 A-=0.12 tau+=20ms tau-=20ms
Triplet extends to 3-spike interactions capturing burst effects.
```

**Device mismatch compensation:** Calibrate via Basis Pursuit Denoising (BPDN) minimizing ||W_physical - W_logical||_2 + λ||W_logical||_1, λ=0.001, using on-chip microcode. For Loihi 2, sigma reduction 0.22→0.04 after calibration 5 min.

## 6 Limitations

- **Loihi 2 toolchain maturity:** Lava 0.8 still alpha, microcode calibration 5 min cold start, not suitable for <10ms serverless cold start; DYNAP-CNN toolchain requires manual mapping, no auto-quantization.
- **SpiNNaker2 availability:** 48-node prototype only, production 152k cores not yet GA, NoC multicast limited 1M events/s, SDRAM 18GB per board insufficient for billion-scale replay.
- **Theory gaps:** Triplet-STDP convergence proof assumes i.i.d. Poisson inputs, not bursty adversarial 0.1% hot 80% load; homeostatic stability lemma requires sigma<=0.2, fails sigma=0.28 DYNAP-CNN worst-case (accuracy drop 1.2% observed, not bounded).
- **Security:** Side-channel via power analysis not mitigated for memristor crossbars, TDC sensor leakage 12-bit, need masking gadgets (cost 2.3x area).
- **Carbon accounting:** WattTime API regional only US/EU, CICS forecasting error ±15% for APAC, GreenSKU not validated for neuromorphic.
- **Reproducibility:** Loihi 2 requires Intel NDA, DYNAP-CNN devkit $2.5k, SpiNNaker2 academic only, Docker multi-arch pinning breaks on ARM host due to Lava x86-only.
- **Scalability:** 1.2M neurons 130M synapses fits single Loihi2+DYNAP, but trillion-synapse brain-scale requires 8k chips, NoC latency 12 hops 3.4us, power 8kW, cost $4.7M.
