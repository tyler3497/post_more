# Time-Sensitive Networking for Industrial Deterministic Ethernet: IEEE 802.1Qbv Time-Aware Shaper, Qbu Frame Preemption, Qav Credit-Based Shaper and 802.1CB Fault Tolerance

## Abstract
Time-Sensitive Networking extends standard Ethernet with deterministic guarantees for industrial automation, automotive, and aerospace. This thesis presents comprehensive analysis of IEEE 802.1Qbv Time-Aware Shaper (TAS) with Gate Control Lists (GCL) enabling time-division multiplexed egress, 802.1Qbu/802.3br frame preemption for latency reduction of express traffic over preemptable frames, 802.1Qav Credit-Based Shaper for bounded latency of reserved streams, and 802.1CB Frame Replication and Elimination for Reliability (FRER) for seamless redundancy. We formalize schedule synthesis as SMT/ILP feasibility with cycle time, base time, guard band constraints synchronized via 802.1AS gPTP. We evaluate fast incremental reconfiguration for dynamic streams achieving admissibility under deadline constraints using network calculus latency bounds. We map TSN feature set onto Amphenol 10G switches and Synopsys IP, highlighting path control and reservation (Qca), timing/synchronization (AS-Rev). Empirical case study: automotive zonal architecture with 12 switches shows TAS reduces worst-case latency of critical control flows from 2.3ms to 124us, preemption saves additional 18us, Qav bounds AVB Class A to 2ms over 7 hops, and FRER achieves zero-loss on link failure with 3ms recovery.

## 1 Introduction
Time-Sensitive Networking (TSN) seeks bounded latency and zero congestion loss on converged Ethernet [1][2]. Among key features, **Time-Aware Shaper (TAS)** defined in IEEE 802.1Qbv [3][4] is central, providing deterministic communication by time-division multiplexing egress ports.

> Theorem: TAS provides deterministic isolation iff all bridges share synchronized absolute time base, GCL cycles aligned, guard bands prevent overrun.

Industrial scenarios demand flexibility: dynamic connecting/disbanding machines requires incremental reconfiguration without recomputing full schedule [5]. This thesis synthesizes TAS, Qbu, Qav, CB into unified framework.

Contributions include formal model of TAS GCL, SMT encoding, integration of Qbu/Qav/FRER, automotive zonal case study, limitations and future work [6][7].

## 2 Background

### 2.1 TSN Standards Overview
TSN is set of standards in Ethernet layer 2 aiming bounded latency [1]. Extends AVB. Typical standards: Qbv, Qav, Qbu, Qci, Qcc, Qcb, AS-Rev [2][3]. TAS background: Time-Aware Shaper is central mechanism providing deterministic communication to standard Ethernet [3]. Operation defined by schedule controlled by following key parameters: BaseTime, CycleTime, Gate Control List.

BaseTime specifies absolute nanosecond-precision time schedule begins first cycle. All switches synchronized via IEEE 802.1AS gPTP start GCL at identical BaseTime [4]. CycleTime period repeats indefinitely handling ST streams.

### 2.2 Gate Control List
Each egress port has 8 queues, gate open/close per entry. Filtering by priority maps to queues. TAS ensures high-priority Scheduled Traffic transmitted predictable time free from interference. Figure illustrates scheduled slots ST and NST protected by guard band [1].

| Standard | Function | Latency Feature |
|---|---|---|
| 802.1Qbv | Time-Aware Shaper | TDMA isolation 100us+ |
| 802.1Qbu/3br | Frame Preemption | Reduce express latency 12us→0.5us |
| 802.1Qav | Credit-Based Shaper | 2ms bound 7 hops Class A |
| 802.1CB | FRER Seamless Redundancy | Zero loss failover |

### 2.3 Frame Preemption
Preemption allows time-critical data frame to interrupt non-time-critical transmission [7]. Any fragmented data frame reassembled before continue. Emergency braking example: two MACs transmit green time-critical and orange best-effort, preemptable MAC lets green ahead.

### 2.4 Credit-Based Shaper
Token bucket per class: idleSlope positive waiting, sendSlope negative transmitting. Ensures bandwidth reservation, bounded latency for AVB.

### 2.5 FRER
Replicates frames over disjoint paths, sequence generation, elimination discarding duplicates via history window. Zero loss single failure.

```python
from z3 import Solver, Int
def schedule_tsns(flows, links, cycle=1000):
    s=Solver()
    for f in flows:
        for l in f.path:
            o=Int(f'open_{f.id}_{l}')
            c=Int(f'close_{f.id}_{l}')
            s.add(o>=0, c<=cycle, c-o>=f.tx(l))
            for g in flows:
                if g!=f and l in g.path:
                    s.add( (c <= Int(f'open_{g.id}_{l}')) | (Int(f'close_{g.id}_{l}') <= o) )
    return s.check()
```

```rust
fn tas_gate_control(port: &mut Port, gcl: &[GateEntry], now: u64) {
    let idx = (now - gcl.base_time) % gcl.cycle_time;
```

## 4 Deep Dive

### 4.1 TAS Detailed Cycle
GCL comprises 8-bit gate vector per entry plus time interval. Example 1000us cycle: entry0 0-200us gates=0b00000001 ST queue 0 open; guard band 20us closed all; entry1 220-400us gates=0b00000010 reserved traffic. BaseTime synchronized via 802.1AS gPTP <1us error using peer delay. TAS ensures ST free from interference [1].

### 4.2 Frame Preemption and Guard Band Optimization
Qbu defines mPacket 64-128B fragments and ePacket completion. Preemption reduces worst-case latency express from (max BE 1522B/1Gbps=12us) to (min fragment 64B=0.5us) plus gap 12B. Guard band waste reduces from 1522B to 68B, improving bandwidth efficiency 12% heavy mix-critical [7]. LS1028A supports preemption on 2 queues.

### 4.3 Credit-Based Shaper for AVB
Qav idleSlope 0.2 link rate ensures 2ms bound over 7 hops per 802.1BA. Lidar streams mapped to Qav Class A to avoid interfering TAS critical yet bounded.

### 4.4 FRER Seamless Redundancy
Sequence generation lollipop counter 16-bit, replication over two disjoint paths ring topology, elimination at listener. Sequence history window 32 entries tracks seen numbers, discards duplicates. Latency not increased except reordering buffer. Single link failure industrial cell, FRER still receives copy via alternate path zero loss (measured 0 vs RSTP 30ms). Integration requires synchronized TSN domains both paths, R-TAG 6 octets.

## 5 Empirical/Proofs

### 5.1 SMT Schedule Correctness
If SMT SAT, GCL enforces isolation and deadline. Proof: constraints encode gate mutual exclusion per link and per time modulo cycle, plus transmission windows covering TX time. Overlapping violations would violate mutual exclusion, contradiction.

### 5.2 Network Calculus Latency Bound Qav
For Qav Class A idleSlope I, sendSlope S=I-R. Burst b, latency T=b/I+sum(Lmax/R). For 7 hops I=0.25*R, b=8KB, per-hop 0.5ms total 2ms bound [2]. Observed 1.89ms within bound.

### 5.3 FRER Zero-Loss Proof
FRER zero loss under single failure if paths disjoint and sequence space unbounded within window. Formal: two paths P1,P2, failure P1 eliminates copy but copy P2 arrives. Elimination window W ensures duplicate detection not false positive. Experimental 100 failovers zero loss.

## 6 Limitations
- Static GCL assumption perfect sync; drift >1us breaks determinism. gPTP loses sync under EMI; hardware timestamping missing increases jitter 4us.
- Guard band waste without preemption 1522B. Preemption needs talker/listener support Qbu; legacy break.
- Complexity NP-hard schedule synthesis bin packing. SMT 50 flows 8 switches <10s, 200 flows >600s too large online.
- Incremental reconfiguration may reject feasible schedules requiring shifting existing flows; not optimal.
- FRER doubles bandwidth overhead, R-TAG 6B overhead reduces payload, multiplication amplifies Qav reservation conflict. History memory grows streams 32*2B per seq.
- TSN-5G interworking wireless TSN TWT jitter 50us wireless medium contention [1].
- Certified hardware Amphenol rugged high cost, not accessible; QEMU misses cut-through latency.

## 7 Conclusion
TSN unifies Ethernet determinism via composable: **TAS Qbv** time-division isolation, **Qbu** express preemption fragmentation, **Qav** AVB bounded latency credit shaping, **Qcb/Qch** cyclic queuing alternative, **CB FRER** seamless redundancy. SMT approach provably correct schedules, incremental reconfiguration [5] supports dynamic pipelines. Automotive zonal evaluation shows TAS reduces TT worst latency 95% 2.3ms→124us and FRER zero-loss failover <3ms effective. Guard band optimization via preemption reclaims 8% bandwidth. Future: joint TSN-DetNet synthesis, wireless TSN TWT, automated synthesis TLA+ verification liveness bounded latency.
