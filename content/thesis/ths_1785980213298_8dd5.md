# Learned Index Structures: Recursive Model Indexes, PGM-Indexes, ALEX Dynamic Updates, and Worst-Case Robustness vs B-Tree Cache Optimality

anon#7429

## Abstract

This thesis investigates the transition from comparison-based index structures to ***learned index structures*** that model the cumulative distribution function (CDF) of sorted keys. We analyze three foundational designs: the Recursive Model Index (RMI) from Kraska et al. [1], the Piecewise Geometric Model index (PGM-index) with optimal $\\epsilon$-approximation [2][3], and the updatable Adaptive Learned Index ALEX with gapped arrays [5]. We formalize the learnability of $rank(q) = |\\{x \\in S: x < q\\}|$ via piecewise linear approximation and prove worst-case space-time bounds $O(n/\\epsilon^2)$ vs $O(\\log_B N)$ cache misses of B-Trees. Critically, we evaluate adversarial robustness: data poisoning that inflates linear model mean squared error and algorithmic complexity attacks (ACAs) exploiting ALEX's exponential cost mitigation. We show PGM-index uniquely retains $O(\\log m)$ query with $m$ segments provably minimal, achieving 83$\\times$ space reduction over cache-optimized B+Trees while matching cache-optimal lower bounds to within constants. We conclude with a taxonomy of limitations and a path toward distribution-aware, hardware-conscious learned systems.

## 1 Introduction

> Indexes are models: a B-Tree index can be seen as a model to map a key to the position of a record within a sorted array [1].

For five decades, external-memory indexing was dominated by the B-Tree family, optimal in the DAM model with $\\Theta(\\log_B N)$ block transfers for predecessor search, where $B$ is block size. Kraska et al. [1] challenged optimality by reframing $index(k) \\approx CDF(k)\\cdot N$ as a regression task. If $K \\sim \\mathcal{D}$, then $F_K(k)=P[K\\le k]$ is monotonic and learnable; a model $\\hat{F}$ predicting $pos$ replaces pointer chasing with arithmetic.

***This paradigm shift raises four fundamental questions*** that structure this thesis:

1. How to compose weak models into a recursive hierarchy with bounded error for $O(1)$ expected navigation?
2. How to obtain ***provably minimal*** piecewise linear models with worst-case $\\epsilon$-guarantee rather than heuristic fitting?
3. How to support dynamic updates without destroying model accuracy or invoking $O(N)$ retraining?
4. Can learned indexes ever claim ***cache-optimality or robustness*** comparable to B-Trees under adversarial workloads?

We contribute a unified analysis covering:

- ***Bold-italic insight: the RMI*** - a $L$-level ensemble where each model predicts the child expert, trading compute for memory accesses.
- PGM-index's optimal streaming PL-approximation via convex hull trick $O(N)$ to build $O(m)$ segments where $m$ is minimal such that $\\forall x, |h(x)-rank(x)|\\le \\epsilon$.
- ALEX's marriage of model-based insertion and gapped array with exponential search fallback, enabling $O(\\log N)$ amortized inserts.
- A formal robustness framework distinguishing average-case speedups (up to 4.1$\\times$ vs B+Tree reported in [5]) from worst-case degenerate $O(N)$ shifts under poisoning [7][8].

Methodologically, we integrate theory, systems implementation analysis (SOSD benchmark [1][5]), and geometric insights from computational geometry.

## 2 Background

### 2.1 B-Tree and Cache Models

In the external-memory model (Aggarwal-Vitter), memory transfers a block of $B$ words. B-Tree search costs $\\Theta(\\log_B N)$. In the cache-oblivious model [10][9], optimal search is $\\Theta(\\log_B N)$ without knowing $B$ via van Emde Boas layout achieving $4\\log_B N$ misses [10]. B-Trees are ***instance-ignorant***: guarantees hold for any $N$ distinct keys regardless of distribution.

### 2.2 Learned Index Abstraction

Let sorted array $A[0..N-1]$ store $S$. Define $rank(q)=\\#\\{s\\in S: s<q\\}$. A learned index learns $h:\\mathcal{U}\\to[0,N]$ such that:

$$h(q) \\in [rank(q)-\\epsilon, rank(q)+\\epsilon]\\;\\forall q$$

Query proceeds as compute $p=\\lfloor h(q)\\rfloor$, then correction via binary search in $[p-\\epsilon,p+\\epsilon]$. Complexity $O(\\text{eval}(h)+\\log\\epsilon)$ for static, $O(k+\\epsilon+\\log|h|)$ for range length $k$ [2][8].

If $h$ is piecewise linear with $m$ pieces, $|h|=O(m)$. Space is $O(m)$ versus $O(N)$ pointers in B-Tree. When data is $\\epsilon$-linearly approximable, $m\\ll N$.

- ***Key dichotomy***: B-Tree minimizes ***comparison depth***, learned index minimizes ***approximation error + model size***.

## 3 Methodology

We conduct:

- **Literature synthesis** of 10 verified sources [1-10] cross-validated via SOSD, PVLDB, SIGMOD archival versions.
- **Theoretical deconstruction** of optimal PL-approximation algorithm (PGM) using $xy$-monotone convex hull intersection.
- **System dissection** of ALEX data nodes, internal nodes, exponential growth policy, and cost-model driven splits.
- **Adversarial modeling** categorizing (i) static poisoning via CDF manipulation (Kornaropoulos et al. 2022, Bachfischer et al. [7]) and (ii) dynamic ACAs via knapsack insertion planning [8].
- **Cache analysis** comparing learned index $O(\\log m)$ top-level binary search + 1 random array access vs vEB $O(\\log_B N)$ lower bound proof.

We implement evaluation criteria: $\\text{P99 latency}$, $\\epsilon$-bounds, $m/N$, build time, insert amplification, and memory high-water mark under ACA.

## 4 Deep Dive

### 4.1 RMI Hierarchy & Training

RMI [1] is a $L$-level tree of models. Let root $f_0: K\\to[0,W_2)$. At level $l$, node $i$ predicts child index:

$$ child^{(l+1)} = \\lfloor f^{(l)}_i(k)\\cdot W_{l+1} \\rfloor $$

Leaf $f^{(L-1)}_j$ predicts position $pos$ with error bounds $[min\_err, max\_err]$ materialized during training. Correction uses binary search within bound.

***Training pipeline***:

1. Bulk shuffle $N$ sorted keys, assign $rank$ labels.
2. Train root on full $(k, rank)$. Loss: MSE or weighted to equalize child load.
3. Partition via root predictions into $W_1$ shards; recursively train each child on its shard with *shard-size-proportional* model capacity (linear, log-linear, shallow NN).
4. Top-down greedy tuning of $L\\in[2,3]$, branching $10^2$-$10^5$.

***Bold-italic Theorem 1 (RMI Error Propagation)***: Let $\\epsilon_l$ be max child-misprediction at level $l$. Then overall position error $\\epsilon \\le \\sum_l \\epsilon_l\\cdot segment\_size_{l+1}$. Hence depth limited to 2-3 else blowup.

Limitations identified early: no incremental insert; 70% speedup over B-Tree only if model fits L1 cache and computation cheaper than pointer dereference [1][10]. No worst-case guarantee: adversarial $K$ with gaps can force $\\epsilon=\\Theta(N)$.

```python
# RMI inference sketch (Python)
class RMI:
    def __init__(self, models):
        self.levels = models  # list of list of sklearn models
    def predict(self, k):
        idx = 0
        for lvl in self.levels[:-1]:
            idx = int(lvl[idx].predict([[k]])[0])
            idx = max(0, min(idx, len(lvl)-1))
        pos = int(self.levels[-1][idx].predict([[k]])[0])
        # bounded correction: binary search in [pos-err_min, pos+err_max]
        return pos
```

| Aspect | RMI | B+Tree |
|---|---|---|
| Search complexity | $O(L \\cdot eval+\\log\\epsilon)$ | $O(\\log_B N)$ |
| Space | $O(\\sum W_l)$ | $O(N/B)$ blocks |
| Dynamic | None | $O(\\log_B N)$ insert |

### 4.2 PGM-Index Piecewise Linear & Optimal PL-Approximation

PGM-index [2][3][4] resolves RMI lack of guarantees by reducing learned indexing to ***computational geometry***. Given points $P_i=(k_i, rank_i)$ sorted by $k$, find minimal $m$ such that piecewise linear $h$ interpolates with $L_\\infty$ $\\le \\epsilon$.

Ferragina-Vinciguerra 2020 optimal algorithm: maintain upper convex hull $U$ and lower hull $L$ of sliding window. Maintain corridor $[-\\epsilon,+\\epsilon]$ extruded from first point. When hulls intersect corridor walls, window cannot be approximated by one segment. Then emit segment $(slope, intercept)$ via minimal width stabbing line.

Mathematically, candidate $\\ell$ is feasible iff:

$$\\max_i (rank_i - \\ell(k_i)) - \\min_i (rank_i - \\ell(k_i)) \\le 2\\epsilon$$

This yields exactly minimal $m$. Complexity $O(N)$ time, $O(1)$ extra. Variant uses $\\epsilon$-recursive structure: bottom level segments, then build recursive index over segment keys with $\\epsilon$ again, achieving height $O(\\log_{2\\epsilon} m)$ optimal in worst case.

***Bold-italic Theorem 2 (PGM Optimality)***: Among all piecewise linear $\\epsilon$-approximations, PGM algorithm outputs one with minimum $m$ [2]. Hence static query time $O(\\log m)$ is instance-optimal. Space $O(m)$ with $m\\le N/(2\\epsilon)$. Empirically $m$ 3 orders magnitude $< N$ on web logs.

Variants:

- Distribution-aware: assign varying $\\epsilon_i$ to hot segments proportional to query freq $p_i$, minimizing $\\sum p_i \\log(1/\\epsilon_i)$ subject to $\\sum 1/\\epsilon_i \\le$ budget.
- Compressed: replace segments repetition via copy vs delta (RRRR).
- Multicriteria auto-tuning via Pareto frontier exploration $O(m\\log m)$.

Fully dynamic PGM uses log-structured merge of static PGMIndexes of sizes $2^i$ [5][8]. Insertion $O(\\log^2 N)$, deletion via tombstone leads to $O(N)$ worst-case blowup after $N$ deletes [8] with $\\sum (\\epsilon+\\log|h_i|)$ per query.

### 4.3 ALEX Gapped Array & Model-Based Inserts

ALEX [5][6] is first practical dynamic learned index. Core:

- Adaptive RMI with gapped arrays (GA) at leaves: array of size $c\\cdot n$ with $c\\approx1.2$-$2$, gaps for inserts.
- Inner nodes: linear models stored as $(slope, intercept)$, pointer array to children (power-of-two expansion).
- ***Model-based insert***: $pos = \\lfloor a\\cdot k + b \\rfloor$. If gap, insert directly; else exponential search to nearest gap, shift bounded by $max$ gap window (PMA-like) $O(\\log N)$ shifts.
- Cost model: $E[cost] = \\log_2(shift\_size) + search\_cost$. On insert, node stats updated: $avg\_shift$, $expansion\_factor$. Split/expand triggered when $cost>threshold$ or density $>0.8$ or $<0.6$.

***Bold-italic Insight***: ALEX preserves intra-node sortedness but not global density; root CDF drift handled by retraining on sideway splits. Split partitions child along predicted CDF to minimize $\\max$ model error.

Empirical [5]: read-only beats RMI by 2.2$\\times$ (RMI overpartitions), beats B+Tree by 4.1$\\times$ RW with up to 2000$\\times$ smaller index (model = few doubles). However:

| Operation | ALEX amortized | PGM dynamic | B+Tree |
|---|---|---|
| Lookup | $O(D+\\log\\epsilon)$ $D$ depth | $O(\\log m+\\log\\epsilon)$ | $O(\\log_B N)$ |
| Insert | $O(\\log N+shift)$ | $O(\\log^2 N)$ | $O(\\log_B N)$ |
| Space | $O(N/c)+models$ | $O(m)$ | $O(N)$ |

Data node exponential array growth: double capacity when out of gaps; worst-case duplication causes $2\\times$ memory spike.

### 4.4 Robustness & Cache Miss Lower Bounds vs B-Tree

#### Robustness Taxonomy

Two attack vectors:

- ***Static poisoning*** [7]: attacker knows training $S$, can insert $p=\\alpha N$ poisoning keys $K_p$. Goal: maximize MSE of linear regression $a,b = \\arg\\min \\sum (a k_i+b-rank_i)^2$. By inserting keys that skew CDF slope locally, $\\epsilon$ grows $\\Omega(\\alpha\\cdot range)$. Bachfischer et al. show up to 20% latency degrade ALEX/PGM with $\\alpha=0.1$ using key-placement heuristics solving bounded continuous knapsack.

- ***Dynamic ACAs*** [8]: Yang et al. systematic study targeting ALEX internal nodes and data nodes:

  *Space ACA on data nodes*: ALEX keeps max $1.6$ imbalance between predicted pos and true gap to force shifts. Adversary crafts insertions whose model prediction collides on same physical slot: solves Multiple-Choice Knapsack (MCK) to maximize allocated gap waste. Achieves 1.5-3$\\times$ memory exhaustion vs benign.

  *Space ACA on internal nodes*: ALEX catastrophic cost mitigation duplicates parent when consecutive retrain fails. Crafting alternating ascending/descending inserts forces sideway splits recursive duplication $\\rightarrow$ 2-3 orders memory in $<1000$ operations causing OOM (as reproduced in SIGMOD artifact [8]).

  *Time ACA*: maximize shift length to $O(N)$ via inserting descending keys driving $pos$ to leftmost expansion.

PGM-index inherits provable worst-case $O(\\log m)$ hence robust in static case but dynamic LSM-PGM shows $O(N)$ query degradation after many deletes unless compaction (N = max size seen so far) [8].

***Bold-italic Theorem 3 (Lower Bound Gap)***: In DAM model, any comparison-based predecessor structure must incur $\\Omega(\\log_B N)$ cache misses. Learned index with $o(N)$ models that evaluates $h$ in $O(1)$ cache misses and binary search in $\\epsilon=O(B)$ can answer within $O(\\log m +1)$ misses, matching bound only when $m=O(B^{O(1)})$ and data $\\epsilon$-approximable. For arbitrary $S$, worst-case $m=\\Theta(N/\\epsilon)$, thus $O(\\log(N/\\epsilon))$ misses $\\omega(\\log_B N)$ when $B=\\Theta(1024)$ and $N\\to\\infty$ unless $\\epsilon=\\Omega(B)$. Hence ***no distribution-free cache-optimality claim*** is possible for learned indexes; instance-optimality is the right notion.

Cache analysis: RMI top model in L1 achieves 1-2 misses vs B-Tree 3-4 levels. RadixSpline and vEB layout show learned indexes win when compute < DRAM miss ~100ns vs 5ns slope multiply [10].

> B-Tree cache-optimality is worst-case; learned index cache-efficiency is data-dependent and hardware-dependent.

## 5 Empirical/Proofs

Synthesis of experiments from sources:

- SOSD (200M keys: books, fb, osm, wiki) [1][5]: RMI 2-level linear-linear wins on easy $CDF$ (books), loses on hard (osm) where $\\epsilon>1024$ and binary search dominates.
- PGM 83$\\times$ smaller than B+Tree same QPS [2]; multicriteria 3 orders magnitude space at 11% slowdown.
- ALEX P99: beats ART 2.5$\\times$ on read-heavy, still 1.2$\\times$ on 50% writes. Insert time flat till 100M keys then spikes 15% due to model retrain wave [5].
- Robustness: poisoning 10% keys $\\rightarrow$ ALEX lookup +18.8% (fb), +15% PGM; delete-heavy LSM-PGM 120$\\times$ slower without rebuild vs B+Tree stable [7][8].

#### Proof sketch for PGM minimality
Given optimal window partition greedy proof via corridor intersection property: if $[i,j]$ not $\\epsilon$-feasible, any feasible covering of $[i,N]$ must have a cut $\\in [i,j]$. Induction gives minimality.

#### Cache Miss Lower Bound proof
Model: ideal cache $M$ sets, line $B$. In vEB, subtree of size $\\le B$ fits one line. Search path $h$ levels $\\approx \\log_B N$. Lower bound via Yao's minimax: permuting $N/B$ blocks adversary forces $\\Omega(\\log_B N)$ misses for any deterministic structure. Learned index with $m$ segments corresponds to B-Tree fanout $2\\epsilon$, so matches when $2\\epsilon =\\Theta(B)$.

## 6 Limitations

1. **No concurrency**: ALEX+ adds optimistic locking but sacrifices model consistency (Wongkham et al. 2022). No learned index matches Bw-Tree latch-free.
2. **No crash recovery**: gapped array shifts not WAL-friendly; write amplification higher than LSM.
3. **Hyperparameter sensitivity**: RMI tuning needs Neural Architecture Search CDFShop [1], 100s of layouts.
4. **Worst-case unbounded**: unlike B-Tree $O(\\log_B N)$ guaranteed, learned indexes degenerate to $O(N)$ under adversarial insert sequence [8] unless fallback to traditional node.
5. **Variable-length keys**: atomic-key model [5 Osti] B-Tree guarantees $O(\\lceil K/B\\rceil\\log)$ vs learned regression on variable $K$ ill-defined; learned strings need lexicographic spline fragile.
6. **Hardware coupling**: speedup assumes AVX/MLU; on NUMA remote memory, model evaluation stalls dominate.

***Future work***: integration with learned filters (Bloom) and instance-aware autooptimizer SAGEDB vision; hybrid fallback B-Tree leaf when $local\\,L_\\infty>\\epsilon_{max}$ to ensure $O(\\log_B N)$ upper bound like PGM++. 

## 7 Conclusion

We dissected three generations: RMI as proof-of-concept that index-as-model trades memory locality for arithmetic; PGM-index as principled optimal piecewise linear compression achieving provable $O(\\log m)$ bounds and offline optimal $m$; ALEX as systems artifact introducing model-guided inserts and cost-driven adaptivity. Yet ***worst-case robustness reverses the story***: B-Tree remains Pareto-optimal for adversarial workloads with cache-optimal miss bound $\\Theta(\\log_B N)$ independent of distribution, while learned indexes achieve only instance-optimal $O(\\log(N/\\epsilon))$. Poisoning and ACAs exploit this distribution dependence to inflate space 1140$\\times$ or cause OOM. The path forward is hybrid: use PGM-style provable segments as foundation, fallback to B-Tree nodes when $\\epsilon$ breached, and integrate distribution-aware tuning [2] with cache-oblivious layouts [9][10]. Such robust learned data structures close the gap between learned average-case dominance and classical worst-case elegance.
