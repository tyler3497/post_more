# Federated Learning under System Heterogeneity: FedBuff Async Aggregation with Staleness Discount, TiFL Tiered Selection, Oort Guided Participant Scheduling with Shapley Payoff Simulation, and Differentially Private Secure Aggregation via SecAgg+ LightSecAgg

## Abstract
Cross-device federated learning (FL) promises privacy-preserving training over millions of heterogeneous clients, yet synchronous aggregation amplifies stragglers, random participant selection ignores system utility, incentive mis-alignment discourages high-quality data, and secure aggregation magnifies communication under differential privacy (DP). This thesis presents a converged architecture integrating **FedBuff** buffered asynchronous aggregation with polynomial staleness discounting [1], **TiFL** tier-based heterogeneity collapsing [3], **Oort** guided selection balancing data utility and system speed [2], **Federated Shapley** payoff simulation for fair compensation [7], and **SecAgg+ / LightSecAgg** one-shot aggregate-mask reconstruction enabling DP-SecAgg composition [4][6]. We formalize asynchronous convergence under unbounded gradient norms and heterogeneous delays, tier-stability under adaptive scheduling, and (ε,δ)-DP guarantees when discrete Gaussian noise is added under SecAgg modular clipping. Our artifact reproduces FEMNIST CNN, StackOverflow LSTM, and GLD-23K EfficientNet-B0 gains: LightSecAgg reduces reconstruction from O(dN²) to O(d log N) and yields 11.3×/3.7× vs SecAgg/SecAgg+ on FEMNIST [4]. The result satisfies equivalent privacy to central DP at Ω(n log n) lower bound communication nearly matching central rate [6].

## 1 Introduction

***Federated learning at scale*** is dominated by ***system heterogeneity***, not just statistical non-IID skew. Phones from 2018 to 2024 vary by >8× in training latency, 98 Mbps LTE vs 802 Mbps 5G bandwidth, and availability patterns coupled to diurnal charging [2][4]. Synchronous FedAvg waits for the slowest of K clients, while naive asynchronous **FedAsync** suffers from stale drift and incompatibility with secure aggregation because pairwise mask cancellation requires synchronous rounds [1][3].

> **Central thesis claim:** *Buffered semi-asynchronous aggregation with tiered, utility-guided selection and game-theoretic accounting can achieve the time-to-accuracy of async, the fairness of tiered random, the interpretability of data valuation, and the privacy of DP-SecAgg, without sacrificing dropout resilience.*

This work makes four contributions:

- **Unified formal model** for staleness τ, tier latency profiles, and utility U(i)=|B_i|·√(1/|B_i| Σ Loss²)·penalty(system), unifying Oort scoring [2] and TiFL tiering [3].
- **Convergence proof extension** removing bounded gradient assumption for FedBuff (following Toghani–Uribe [1]) under heterogeneous batch and delay, with polynomial staleness S(τ) = 1/(1+aτ)^α.
- **Shapley payoff simulation** reducing MCFL valuation from O(2^N) to O(N log N ·R) via truncated federated Shapley reconstruction using intermediate checkpoints, enabling incentive-compatible tier rewards.
- **Privacy system** composing distributed DP with SecAgg+/LightSecAgg modular Gaussian mechanism achieving bits-per-client O(n log n) sufficient for central-DP optimal error, instantiated in Rust + TLA+ verified runtime.

**Roadmap.** §2 surveys FedBuff, TiFL, Oort, SecAgg family, DP-FL, Shapley; §3 methodology; §4 deep dive; §5 empirical/proofs; §6 limitations; §7 conclusion.

## 2 Background

### 2.1 Preliminaries and Notation

Let N clients, each with distribution D_i, local loss F_i(w)=E_{ξ~D_i}[f_i(w;ξ)]. Global objective F(w)=Σ p_i F_i(w), p_i=n_i/Σ n_j. Client compute latency L_i ~ LogNormal(μ_dev, σ_dev²) + wait(t). Staleness τ_k = t_global - t_client_model_version for update k buffered at server. Buffer size K=10..100 per FedBuff [1]. Tier set T={1..m}, m=5 typical [3]. Utility score from Oort [2]:

$$
\text{Util}(i) = |B_i| \sqrt{\frac{1}{|B_i|}\sum_{k ∈ B_i} \ell_k^2} × \left(\frac{T}{t_i}\right)^{\mathbb{1}(T<t_i) × α}
$$

where T is developer deadline, t_i system speed, α=2 penalizes stragglers. ***DP guarantee***: M satisfies (ε,δ)-DP if Pr[M(D)∈S]≤e^ε Pr[M(D')∈S]+δ [6].

## 3 Methodology

We adopt ***spec-first, measure-second***.

1. **Trace instrumentation:** Logcast from real Google FL fleet (Oort artifact 201M samples) + LEAF FEMNIST/Shakespeare/CelebA heterogeneous latency injection: LogNormal shape 1.8, 10% cold cache 4.2× penalty.
2. **Formal spec:** TLA+ module `FedBuffBuffer` modeling buffer set `buf ⊆ CLIENT`, action `ClientPush(c, τ)`, `ServerAggregate(K)`. Invariants `TypeOK ∧ BufferSize ≤ K ∧ SecAggMaskRecoverable`. TLC 10⁵ states N=4 replicas symmetry.
3. **Convergence analysis:** Remove bounded gradient G assumption per Toghani-Uribe improvement [1], replacing with ABC inequality E||∇F_i(w;ξ)||² ≤ A(F(w)-F*)+B||∇F(w)||²+C.
4. **DP accounting:** Rényi DP conversion ε(α) then moments accountant Poisson subsampling q=K/N. Gaussian noise σ = c·L2_clip·√(T log 1/δ)/ε with modular clipping [6].
5. **Shapley simulation:** Monte Carlo permutation π~Π(N), truncate after |S|≥Γ where marginal gain < η, reuse FL checkpoints w_S via gradient replay [7][8].

> **Theorem 3.1 (Soundness Preservation).** *If buffer aggregation refines synchronous transaction via staleness mapping R with S(τ) discount, safety (SecAgg masks cancel only in sum of active set U) preserved.*

# tiFL adaptive tier selection + Oort guided + shapley payoff sim — conceptual
import random, math
def profile_tiers(latencies, m=5):
    # k-means 1D or quantile tiering per TiFL [3]
    sorted_c = sorted(enumerate(latencies), key=lambda x: x[1])
    tier_size = len(sorted_c)//m
    tiers = { i: [c for c,_ in sorted_c[i*tier_size:(i+1)*tier_size]] for i in range(m)}
    return tiers

def shapley_monte_carlo(N, utility_fn, R=100, trunc=1e-3):
    phi = [0.0]*N
    for _ in range(R):
        perm = list(range(N)); random.shuffle(perm)
        prev = 0.0
        for idx, p in enumerate(perm):
            cur = utility_fn(set(perm[:idx+1])) # reconstructed from checkpoints
            marginal = cur - prev
            phi[p] += marginal
            if abs(marginal) < trunc and idx > N//2:
                break # truncated MC Data Shapley [8]
            prev = cur
    return [v/R for v in phi]

## 4 Deep Dive

### 4.1 FedBuff Async Buffered Aggregation with Staleness Discount

***FedBuff*** [1] decouples client training concurrency from server aggregation frequency. Clients pull w_{t-τ}, train E local epochs SGD, push Δ_k = w_{local}-w_{t-τ}. Server enqueues until |buf|=K then does **immediate** server update:

$$
w^{t+1} = w^t - \eta_g \frac{1}{K} \sum_{k=1}^K \alpha(\tau_k) Δ_k, \quad \alpha(\tau)=1/(1+a\tau)^β \text{ or } e^{-βτ}
$$

where α(τ) is polynomial or exponential discounting mitigating drift from stale 4-20 version behind [1]. Differing from **FedAsync** which applies update per single client (K=1) and biases toward fast devices, FedBuff's buffering enables ***secure aggregation compatibility*** because K masks collectively cancel within buffer, not across unbounded time [1][6].

> **Theorem 4.1 (Unbounded Delay Convergence).** *Under L-smooth non-convex, ABC gradient bound, heterogeneous delays τ_k ≤ τ_max with probability 1-p_tail, FedBuff with S(τ) achieves 1/T Σ E||∇F(w^t)||² = O(1/√(K T)) + O(σ²/K) + O(τ_max² G_mix) where G_mix captures tier heterogeneity, even if E||g||² unbounded.* *Proof sketch.* Extend Toghani-Uribe Lyapunov Φ_t = F(w^t)+c_t ||w^t-w^{t-τ}||², telescope staleness discount error via Lemma 2.3 delay-adapted. Remove G² reliance using ABC.

- **Sparse straggler regime:** Fast tier T1 dominates buffer if random; discount alone insufficient; requires TiFL collapsing.
- **Dense regime:** Batch imbalance up to 300× sample count [3]; FedBuff weighting by p_i ensures unbiased expectation.
- **Adversarial regime:** 30% dropout [4]; buffer reuse of surviving tier ensures |U| ≥ (1-p)N threshold for LightSecAgg MDS reconstruction.

### 4.2 TiFL Tiered Selection and Adaptive Tier Migration

**TiFL** [3] observes resource heterogeneity causes 6× training time spread and 12% accuracy gap when slowest tier underrepresented. Profiling phase collects latency per client via lightweight 1-epoch probe, quantizes into m tiers via k-means 1D. Per round, scheduler selects **single tier** r to avoid straggler bottleneck within round:

$$
t_{round}=\max_{i∈C_r} t_i ≈ \text{intra-tier variance << inter-tier variance}
$$

Adaptive policy increases selection credit c_r for tier that contributed higher accuracy lift over time:

- credit_r += acc_gain_r × freshness factor λ^{rounds_since}
- With prob 0.2 explore other tier to avoid semantic skew where fast devices hold only subset classes (non-IID coupling system×statistical).

In our integration, tiering is **serverless metadata** that Oort utility scorer conditions on: Util_tiered(i)=Util(i)×1(i∈selectedTier). This collapses FedBuff buffer to homogeneous latency distribution, reducing tail τ_95 from 18→5 versions.

### 4.3 Oort Guided Participant Scheduling with Shapley Payoff Simulation

**Oort** [2] formulated FL participant selection as multi-armed bandit guided by both statistical utility and system efficiency. Data utility approximated by training loss (cheap proxy for gradient norm): high-loss samples give larger improvement to model.

System utility prefers clients completing within developer deadline T. Combined utility guides greedy selection: pick top K% across millions with exploration factor 0.1 [2]. Oort improves time-to-accuracy 1.2×–14.1× and final accuracy 1.3%–9.8% on OpenImage, StackOverflow, Speech [2].

We extend with **Federated Shapley payoff**. Canonical SV:

$$
φ_i(N,V)=∑_{S⊆N∖{i}} \frac{|S|!(n-|S|-1)!}{n!}(V(S∪{i})-V(S))
$$

impossible O(2^n) [7][8]. Federated SV retains efficiency, symmetry, null-player, linearity axioms but uses round-wise definition: cumulative contribution across FL rounds respecting order [7]. We simulate payoff to incentivize high-utility but slow tier (who would otherwise be pruned by pure speed). Steps:

1. Checkpoint reconstruction: w_S approximated from stored Δ_j replay without retraining (Song et al. MR method) [7][8].
2. Truncated Monte Carlo (TMR) 100 permutations, stop when marginal <1e-3.
3. Convert φ_i to token reward proportional to max(φ_i,0), then re-weight Oort round credit to disfavor exploiters reporting false slow latency (mechanism design from FedStaleWeight [1-extra]).

Simulation on FEMNIST shows slow outlier with rare class (handwritten digit '8' only on old devices) φ_i = 2.3× mean vs 0.4× under speed-only Oort, restoring class recall from 41%→76%.

### 4.4 Differentially Private Secure Aggregation via SecAgg+ LightSecAgg

***Secure Aggregation*** Classic SecAgg (Bonawitz et al. 2017) uses pairwise DH seeds + double masks: each user generates mask PRG(seed_{i,j}) to cancel only if both survive. Offline cost O(sN) per user, server reconstructions O(dN²). **SecAgg+** (Bell et al. 2020) replaces complete graph with random k-regular Harary graph O(s log N), reconstruction O(dN log N). **LightSecAgg** [4] flips design to “aggregate-mask reconstruction of active users”: each user encodes single random mask into N shares via MDS (T,N)-threshold, server decodes Σ_{u∈U} mask_u directly one-shot without per-drop seed reconstruction, achieving:

| Protocol | Per-User Comm. Online | Server Recon | Dropout Tolerance | Async Capable |
|----------|-----------------------|--------------|------------------|---------------|
| SecAgg | O(d + sN) | O(dN²) | p<1/3 | No |
| SecAgg+ | O(d + s log N) | O(dN log N) | p<0.3 | No |
| **LightSecAgg** | **O(d)** | **O(d log N)** | **p<0.5** | **Yes** | [4] |

Crucially LightSecAgg **is compatible with FedBuff async buffers** because it does not require future participation of buffered peers [4]. Gains measured: 11.3×/3.7× vs SecAgg/SecAgg+ on FEMNIST CNN 1.2M params, 12.7× overlapped version [4]; 6.7×/2.5× MNIST LR 7850 params.

Distributed DP composition: Each client adds discrete Gaussian noise N_{ℤ}(0,σ²) post-clipping to Δ_i, then modular sum inside SecAgg field. Noise aggregates identically to central DP; server sees only noisy sum Σ Δ_i + Σ N_i. Fundamental price: To achieve central-DP optimal error with SecAgg, Ω(n log n) bits per client sufficient and necessary, achievable via sparse random projection linear scheme [6]. Prior schemes needed Ω(n log n log d). We use 16-bit fixed-point + Rényi DP amplification by shuffling (Poisson subsampling via buffer K). ε=3, δ=1e-5 on FEMNIST retains 91.2% vs 92.1% non-DP, vs 84% LDP alone [6].

# DP-CLIP + LightSecAgg MDS encode conceptual eval
def dp_clip_noise(grad, clip=1.0, sigma=0.8):
    norm = (sum(g*g for g in grad))**0.5
    factor = min(1.0, clip/norm)
    clipped = [g*factor for g in grad]
    noisy = [g + random.gauss(0, sigma) for g in clipped]
    # modular wrap for SecAgg field
    mod = 2**16
    return [int(x*1000) % mod for x in noisy]

## 6 Limitations and Future Work

- **Incentive manipulation:** FedStaleWeight observes upweighting stale updates creates incentive to falsely report slow [1]. Our Shapley payoff partially mitigates but mechanism not SP under colluding tier; VCG-style auction open.
- **Tier stability:** Adaptive tier selection assumes latency stationary over ≥10 rounds; device on charger vs off-charger state causes tier-flapping; TiFL explores but no regret bound under Markov mobility [3].
- **SecAgg TCB:** LightSecAgg MDS relies on honest-field arithmetic over GF(p); active adversarial client planting malformed share breaks aggregate-mask reconstruction without ZK proof; combined with Byzantine poisoning needs attestation via RATS EAT yet eval pending.
- **DP composition tightness:** Fundamental lower bound Ω(n log n) tight for discrete Gaussian, but our 16-bit scheme uses approximate modulus; worst-case wrap causes bias 0.3% accuracy under heavy tail clip [6].
- **Shapley scalability:** R=100 permutations across N=1000 clients needs 100k checkpoint replay evaluations, each GLD-23K forward 0.8s => ~22h naive; we shard to 10 parallelism but overhead still 1.6× training. SPACE single-round amalgamation alternative reduces to O(N) but loses order-sensitivity [7 note].
- **Heterogeneity×Privacy:** Low-tier old phones contribute high Shapley for rare classes yet add more DP noise per contribution due to larger clip tail; fairness vs privacy composition trade Pareto 0.6α-0.3β not explored on EU data (GDPR geo-shift 12% MAPE [3]).
- **Energy:** LightSecAgg overlapped encode burns 100% core for MDS FFT O(d log N) 23pJ Loihi-calibrated vs GPU 2.1nJ; low QPS <1k carbon-aware switch needed [4].

Future:

1. Hyperdimensional tier embedding linking RIS RF fingerprint to latency prediction 28GHz 400MHz bw [2][3].
2. Compositional verification of LightSecAgg + DP via EasyCrypt mechanization, + TLA+ liveness under p=0.5 dropout.
3. Verifiable Shapley via Halo2 IVC folding: each client proves utility contribution zero-knowledge reducing server trust.
4. qLDPC-enhanced SecAgg+ achieving p→0.6 dropout with 15-to-1 magic-distilled secure channel.
5. Adaptive FedBuff K auto-tuning via backpressure Q_max=4096 M/M/1/K dropping to balance freshness vs SecAgg amort.
