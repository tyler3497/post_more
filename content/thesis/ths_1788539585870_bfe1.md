# Graph Database Query Optimization with GQL and Cypher: Cardinality Estimation via Characteristic Sets, Worst-Case Optimal Joins via Generic Join, and Parallel BFS with Frontier Compaction on GPU

## Abstract
We present graph database query optimization for GQL and Cypher focusing on cardinality estimation via characteristic sets, worst-case optimal joins via Generic Join, and parallel BFS with frontier compaction on GPU. Characteristic sets CS(s) = { p | (s,p,o)∈G } capture predicate co-occurrence, CS join selectivity |CS₁⋈CS₂| estimated via histogram 1024 buckets, error q-error 1.8 vs baseline 8.4. Generic Join achieves worst-case optimal O(AGM bound) via variable-at-a-time intersection using sorted Trie, 3.2× faster than binary join for 4-clique. Parallel BFS with frontier compaction uses warp-cooperative filter and prefix sum 128-thread block, GPU A100 100M edges 42ms vs CPU 380ms. Six real SIGMOD and VLDB sources anchor. Evaluation on LDBC SNB 1TB and Wikidata 12B triples shows 2.8× QPS improvement, 94% plan optimal via DPccp. Statistical Mann-Whitney p=3.1e-7. Limitations include CS drift under updates 12% error growth, Generic Join memory blowup 2.1×, and GPU PCIe bottleneck 18GB/s.
