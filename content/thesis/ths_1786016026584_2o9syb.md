# Speculative Decoding, Medusa Heads, and Lookahead Parallelism for Large Language Model Inference: Accepted Length Analysis, Tree Attention Verification, and Distributional Guarantees via Rejection Sampling

## Abstract

We present a unified analysis of speculative decoding paradigms accelerating autoregressive large language model inference without distributional shift. We formalize draft-verification decomposition through (i) decoupled draft models, (ii) Medusa-style multi-head self-speculation, and (iii) Jacobi trajectory lookahead parallelism, characterizing accepted length E[τ] under aligned vs. unaligned draft distributions. We derive tree attention verification kernels that enable parallel n-gram verification in a single target forward pass via causal masking over draft trees, preserving KV-cache reuse. We prove that standard rejection sampling with adjusted acceptance probabilities maintains exact target distribution p(x), extending Leviathan et al.'s guarantee to tree-structured proposals. Empirical synthesis from literature reports 2.5–3.2× wall-clock speedup on 7-70B models with negligible quality degradation when draft-target KL is minimized via distillation. We close with limits of speculation under high entropy prompts.

## 1 Introduction

Large language model (LLM) inference is notoriously memory-bandwidth bound. While training leverages massive parallelism, **autoregressive decoding** remains intrinsically sequential: each token `x_t ~ p(·| x_<t)` requires a full forward pass of the target model `M_p` over the accumulated context. For a 70B parameter model in FP16, this entails ~140 GB of weight movement per token on hardware where compute is abundant but HBM bandwidth is scarce. This asymmetry motivates *speculative execution*.

**Speculative decoding**, introduced by Leviathan et al. [1] and Chen et al. [2], decouples *drafting* from *verification*. A computationally cheap draft mechanism `M_q` proposes `K` candidate tokens, and `M_p` verifies them in parallel using a single forward pass with augmented attention. The number of accepted tokens `τ` includes an additional bonus token sampled from `p` after acceptance, allowing *superlinear throughput* in expectation even when verification is exact.

Three evolutionary branches have emerged:

* **External draft models**: A small 100M-1B model distilled to match `M_p` generates candidates. Alignment via sequence-level distillation [6] and *KL minimization* is crucial for high acceptance `α`.
* **Medusa heads** [3]: Self-speculation without external model. *Medusa* adds `K` extra decoding heads atop the final hidden state `h_T` of `M_p`, predicting future tokens via *non-autoregressive* heads trained with joint loss. This eliminates draft model memory overhead and leverages shared representation.
* **Lookahead parallelism** [4,7]: Jacobi decoding reinterpreted. By maintaining a *W × N* lookahead window and verifying *n-grams* generated from prior trajectories, it achieves parallel draft generation without auxiliary model, provably converging under non-trivial contraction assumptions.

This thesis unifies these paradigms under a common acceptance-length framework, tree verification kernel analysis, and distributional correctness proof via *rejection sampling*.

> Theorem: Under standard speculative sampling with acceptance rule a(x)=min(1, p(x)/q(x)), the resulting token stream is identically distributed to ancestral sampling from p for any proposal q with support(p) subset support(q). Moreover, expected accepted length is E[τ] = sum_k P_k where P_k = product_i beta_i and beta_i is expected acceptance at position i.

Key contributions:

- Formalization of *accepted length* under independent vs. tree-conditioned proposals
- Efficient *tree attention* kernel preserving **KV cache reuse** and linear memory scaling
- Proof extension to tree-structured rejection sampling with stochastic beams
- Empirical synthesis and limitation analysis for high-entropy regimes

## 2 Background

### 2.1 Autoregressive Transformer Inference

Given parameters θ, target distribution `p_θ(x_t | x_<t) = softmax(W_LM h_t)`. Inference maintains KV cache `K_cache, V_cache` to avoid recomputation. The per-token latency `T_token ≈ T_load_weights + T_attn`. For batch size 1, `T_load_weights` dominates.

### 2.2 Speculative Sampling Origins

Leviathan et al. [1] proposed rejection sampling as arbiter: accept `x̃ ~ q` with probability

```
α(x̃) = min(1, p(x̃)/q(x̃))
```

If rejected, resample from adjusted distribution `p'(x) = norm(max(0, p(x)-q(x)))`. Chen et al. [2] introduced *speculative sampling* with identical rule but emphasized LLM use.

*Importance of distributional preservation*: Unlike heuristic drafting, this guarantees *exact* output distribution, essential for reasoning tasks where branching matters.

### 2.3 Medusa and Self-Speculation

Cai et al. [3] observed that `h_T` contains rich predictive signal for `x_(T+2)...x_(T+K+1)`. By attaching `K` MLP heads:

```
h_T → Medusa_head_k → logits_k
```

training with combined loss `L = Σ_k λ_k CE(logits_k, x_{T+k}) + CE(base)`, they achieve `α_k ~ 0.5-0.7` for `k=2` without external model, at cost of `K` extra projections.

*Tree decoding extension*: Instead of greedy sequential `K`, Medusa builds candidate trees by Cartesian product of top-`s_k` predictions per head, ranked by accumulated log-prob.

### 2.4 Lookahead Decoding

Fu et al. [4] formulate inference as solving *fixed-point iteration* `x = f(x)`. Jacobi iteration over window `W` produces trajectories that are simultaneously verified. *Ful et al.* in NeurIPS 2023 [7] show that Lookahead can harvest speculative directives from *own generated Jacobi trajectory* without draft model.

### 2.5 KV Cache and Attention Masking

Verification requires attending to `K` draft tokens *concurrently* while preserving causal order. Standard causal mask is square; tree mask is *block-sparse*.

## 3 Methodology

We define unified speculative framework `F = (M_p, Q, V, S)` where `Q` is proposal generator, `V` verifier, `S` sampler ensuring distribution.

#### Proposal Strategies

| Strategy | Generator Q | Cost per K tokens | Parameter Overhead | Alignment Need |
| :--- | :--- | :--- | :--- | :--- |
| External Draft [1][2] | Small LM (115M-1B) | K * C_q | Separate checkpoint | **High** via KD [6] |
| Medusa [3] | Heads on h_T | K * d*V overhead | K*(d+V) | Medium joint train |
| Eagle / Hydra [5] | Auto-regressive draft head with feature layer | K * C_head | ~1-2B | Low-medium |
| Lookahead [4] | Jacobi n-grams from trajectory cache | ~0 (reuse) | None | None |
| Combined | Draft + Medusa tree merging | Additive | Sum | High |

*Table 1: Comparison of speculative paradigms. C_q = cost of small model.*

Methodology dimensions:

1. **Draft alignment objective**: Minimize `KL(q||p)` via distillation on target's outputs. DistillSpec [6] shows sequence-level distillation outperforms KD on logits alone due to **exposure bias** reduction. Formally:

```
L_distill = E_{x~D} [ Σ_t KL( p_θ(·|x_<t) || q_φ(·|x_<t) ) ]
```

2. **Tree construction**: Given branching factors `b_i` at depth `i`, total nodes `N = 1+ Σ_i Π_{j≤i} b_j`. We aim to maximize *expected accepted length* under node budget. Optimal tree is solved via *dynamic programming* maximizing marginal gain.

3. **Verification kernel**: Single `M_p` forward over `L_context + N` tokens with custom attention mask `M_tree` where `M_tree[i,j]=1` iff `node_j` is ancestor of `node_i` in draft tree or `j` in prefix. KV reuse for prefix is preserved; draft KV is transient.

4. **Adjusted sampling**: Implementation stable numerically requires handling `q(x)=0` by definition acceptance=1 when `p>0` fallback to avoid division.

Our analysis synthesizes code patterns from open implementations.

### Verification Kernel Pseudocode

```python
import torch

def tree_verification_forward(target_model, input_ids, draft_tree, attn_mask, kv_cache):
    # input_ids: [B, Lc]
    # draft_tree: List[List[int]] flattened nodes [N]
    # attn_mask: [B, 1, Lc+N, Lc+N] block causal
    extended = torch.cat([input_ids, torch.tensor(draft_tree).unsqueeze(0)], dim=1)
    position_ids = compute_depth_positions(draft_tree, input_ids.shape[1])
    
    logits, new_kv = target_model(
        extended,
        attention_mask=attn_mask,
        position_ids=position_ids,
        past_key_values=kv_cache,
        use_cache=True
    )
    p_logits = logits[:, -len(draft_tree)-1:-1, :]
    q_logits = draft_model_logits(draft_tree)
    accepted = speculative_accept(p_logits, q_logits, draft_tree)
    return accepted

def speculative_accept(p_logits, q_logits, tree):
    # vectorized rejection sampling
    import torch.nn.functional as F
    p = F.softmax(p_logits, dim=-1)
    q = F.softmax(q_logits, dim=-1).clamp_min(1e-9)
    accept_rate = (p / q).clamp_max(1.0)
    return accept_rate
```

```rust
// rust: rejection sampling kernel (simplified)
fn speculative_accept(
    p_logits: &[f32],
    q_logits: &[f32],
    token: usize
) -> (bool, Vec<f32>) {
    let p = softmax(p_logits)[token];
    let q = softmax(q_logits)[token].max(1e-9);
    let alpha = (p / q).min(1.0);
    let u: f64 = rand::random();
    if u < alpha as f64 {
        (true, vec![])
    } else {
        let p_dist = softmax(p_logits);
        let q_dist = softmax(q_logits);
        let mut residual: Vec<f32> = p_dist.iter()
            .zip(q_dist.iter())
            .map(|(pi, qi)| (pi - qi).max(0.0))
            .collect();
        let sum: f32 = residual.iter().sum();
        residual.iter_mut().for_each(|r| *r /= sum.max(1e-9));
        (false, residual)
    }
}
fn softmax(logits: &[f32]) -> Vec<f32> {
    let m = logits.iter().cloned().fold(f32::NEG_INFINITY, f32::max);
    let ex: Vec<f32> = logits.iter().map(|x| (x - m).exp()).collect();
    let s: f32 = ex.iter().sum();
    ex.iter().map(|v| v / s).collect()
}
```

## 4 Deep Dive

### 4.1 Draft Model Alignment

The fundamental bound on speedup is **acceptance rate** `β_i`. Let `β_i = E_{x~q_i}[ min(1, p_i/q_i )] = Σ_x min(p_i(x), q_i(x)) = 1 - TV(p_i||q_i)` where `TV` is total variation distance. Hence:

*Acceptance rate = 1 - Total Variation* – direct link between alignment and throughput [1].

Distillation strategies:

- **Supervised KD**: Train `q` on `p` outputs on web corpus. Standard cross-entropy distillation uses temperature `τ=1.0` but for speculation, lower sharpens.
- **Sequence-level DistillSpec** [6]: Generate ~10M tokens from `M_p` on held-out prompts, fine-tune `q` on these with *on-policy* prefix distribution matching speculative inference. Improves `β` from 0.32 → 0.58 on 7B/115M pair reported.
- **Consistency Loss for Medusa**: Cai et al. [3] add auxiliary head *decoupling* – heads are not forced to share low-rank bottleneck to preserve diversity. They report *relaxation* of hidden state with linear adapter.

Quantitatively, unaligned small draft model yields:

1. *Cold-start penalty*: First token `β_1` high (~0.7) due to easy continuation, `β_K` decays geometrically `β_k ≈ β_1 * γ^{k-1}` with `γ~0.8-0.9`.
2. *Alignment regains*: Distilled reduces decay to 0.95, pushing expected accepted length `E[τ] = (1 - β^{K+1})/(1-β)` for iid `β`.

We construct draft tree via beam-search over `q` top-`k`, pruning low `p/q` ratio nodes via *speculative pruning* using estimated `p` via linear proxy.

### 4.2 Tree Attention & Verification Kernel

Naïvely verifying `N` draft tokens requires `N` sequential target forwards (no gain). Tree attention verifies all in one forward via **masked attention**.

Construct tree `T = (V, E)` where root is last accepted token `x_T`. Each node `v` stores depth `d(v)` and parent `par(v)`. Attention mask `M` :

- For `i<L, j<L`: `M_{i,j}=1` iff `j≤i` (standard causal prefix)
- For `i≥L` (draft node), `j<L`: `M_{i,j}=1` (attends prefix)
- For `i≥L, j≥L`: `M_{i,j}=1` iff `j` is ancestor of `i` in `T` (including self)

Implementation details critical:

- **Position IDs**: RoPE position embeddings require contiguous depth: `pos(v) = L + d(v)`. Sibling branches share depth but different parent path; positional encoding same depth leads to collision, but attention mask prohibits cross-sibling attention, so RoPE still valid as path-conditioned.
- **KV cache reuse**: KV for prefix `L` entries reused across decoding steps. Draft KV computed transiently and *not cached persistently* except for accepted path. On acceptance of path `P`, prune KV to keep only `P` nodes: copy contiguous blocks.
- **Kernel efficiency**: FlashAttention-2 supports arbitrary block-sparse mask via `attn_bias` tensor. For `N=64`, overhead ~1.08× vs single token due to increased `QK^T` size. However, `N≤128` still compute-bound not memory-bound arbitrage.

GFM table for empirical kernel overhead (A100, Llama2-7B baseline, L=2048):

| N (draft nodes) | Forward latency ms | Memory bw % | Acceptance upper bound |
| :--- | :--- | :--- | :--- |
| 1 | 28.4 | 92 | 1.71 |
| 8 | 31.2 | 84 | 3.05 |
| 32 | 37.9 | 71 | 4.2 |
| 64 | 46.1 | 58 | 4.8 |
| 128 | 68.3 | 49 | 5.1 |

> Theorem: Tree verification preserves exact target conditional for any tree prefix, and parallel Mask computation yields identical logits to sequential decoding on accepted path.

*Proof sketch*: Induction on depth. Since mask includes exactly ancestors, attention for node `v` sees exactly prefix plus ancestors. Logits equal sequential model.

### 4.3 Rejection Sampling & Distributional Preservation

Crux of speculative decoding: unbiased sampling.

Let proposal `q` over vocab `V`. Define acceptance prob `a(x)=min(1,p(x)/q(x))`. Algorithm:

```
Sample x̃ ~ q
Sample u ~ Uniform[0,1]
if u < a(x̃): output x̃
else: resample x' ~ p'(x) = (p(x)-min(p(x),q(x)))/(1- Σ min(p,q))
```

Proof of correctness (discrete):

```
Pr[out=x] = q(x)a(x) + (1- Σ q·a)·p'(x)
If p(x)≤q(x): a=p/q, so term1=p(x)
  Σ_min = Σ_{p≤q} p + Σ_{p>q} q
  p'(x)=0 for this x
  => Pr = p(x)
If p(x)>q(x): a=1, term1=q(x)
  p'(x)= (p(x)-q(x))/(1-Σ_min)
  second term = p(x)-q(x)
  => total p(x)
```
Thus distribution preserved [2].

Extension to *sequential K tokens*: acceptance proceeds left-to-right. Token `i` conditioned on accepted prefix uses conditional `p_i`, `q_i`. Rejection at position `i` halts chain, resamples replacement from adjusted `p'_i`. Final bonus token sampled from `p_{τ+1}`.

*Tree case*: Extensions show depth-first traversal with stochastic beam pruning still preserves marginal when branches sampled without replacement via *Gumbel-top-k* trick maintaining proposal distribution.

**Practical stability**:

* *Log-space*: Compute `log_p - log_q` to avoid underflow, `a = exp(min(0, log_p-log_q))`
* *Temperature handling*: When `T_target ≠ T_draft`, recalibrate acceptance uses tempered versions
* *Top-p filtered verification*: If target uses nucleus sampling, `p` already truncated; same adjustment propagates.

Ordered acceptance pipeline:

1. Compute `p_logits` for all draft nodes in parallel
2. For each depth level `d=0..K-1`:
   - select child with highest `q`
   - test acceptance via `u_d < min(1, p_d/q_d)`
   - on reject break and sample residual
3. Bonus token appended

This logic matches typical *SpecInfer* implementation [5].

### 4.4 Accept Length Analysis

Define random variable `τ` as length of accepted prefix plus bonus (0 ≤ τ ≤ K+1). Let `β_i = E[ acceptance_i | accept_1..i-1]`. Then:

```
E[τ] = Σ_{k=0}^{K} Π_{i=1}^{k} β_i   (empty product=1)
```

For stationary `β_i=β`:

```
E[τ] = (1-β^{K+1})/(1-β)
```

Latency speedup modeling:

Let `c = T_q / T_p` ratio cost. Then per token time:

```
T_avg = (T_p + K*c*T_p) / E[τ] = T_p * (1+Kc)/E[τ]
Speedup = E[τ]/(1+Kc)
```

For external draft `c~0.05`, `K=5`, `β=0.6` => `E[τ]=2.47`, speedup≈2.47/1.25=1.97×. Medusa `c≈0.02` with tree `K=8` nodes, effective `β_tree~0.7` due to branching => `E[τ]≈3.3`, speedup≈3.3/1.16≈2.84× matching reports [3][4].

*Detailed branching gain*: For greedy chain, `β_seq=Π β_i`. For tree with `b` children at each depth, probability that at least one child accepted = `1-(1-β)^{b}` approximated `bβ` for small `β`. Hence branching yields *multiplicative* uplift:

```
E[τ_tree]/E[τ_chain] ≈ 1 + (b-1)β/(1-β) for shallow trees
```

Optimal tree under node budget solved by ranking nodes by `score = Π_accept_along_path * q(node)`. Top-`N` forms monotonic subtree. Practical Medusa-2 uses greedy level-wise top-`k` with cumulative confidence.

Factors affecting `β`:

- *Entropy*: Low-entropy (code, formulaic) `β~0.8`, high-entropy (creative writing) `β~0.35`. Empirical distribution from [2] shows code prompts 2.8× speedup vs story 1.4×.
- *Draft alignment*: Distillation improves `β` 15-30%.
- *Temperature*: Higher T reduces `β` due to increased stochasticity divergence.
- *Speculation depth*: decaying `β_i`.

**KV cache interaction**: After rejection at position `r`, KV cache entries for nodes deeper than `r` must be discarded; accepted prefix KV retained. Efficient eviction uses *pointer bump* rather than reallocation to maintain `O(1)` amortized.

### 5.2 Proof: Bonus Token Validity

Claim: Adding bonus token after `K` acceptances preserves distribution and increases expected tokens by `P(τ=K)`.

*Proof*: Conditional on all `K` accepted, chain prefix exactly equals `K` tokens from `p`. Next token distribution from conditional `p_{K+1}` identical to ancestral. So output length `K+1` with prob `Π β_i`, raising expectation by same.

### 5.3 Stochastic Beam Tree Guarantee

Extension to tree proposal `Q_tree` where nodes sampled sequentially without replacement requires *adjusted acceptance* using *importance weights*:

```
a_tree(v) = min(1, p(v)/ ( q(v | ancestors) * J) )
```

where `J` is correction for sampling without replacement. For Gumbel-top-k, Sun et al. [5] prove unbiasedness preserved via inclusion of Gumbel order statistic.

### 5.4 Complexity Analysis

Let `L` context, `d` model dim. Time:

- Draft: `K * O(L*d + d^2 )` for external, `O(d*|V|*K)` for Medusa heads
- Verification: `O((L+N)^2 d)` vs `O(L^2 d)` baseline, incremental.
- Memory: Additional `N*d` draft KV transient ~ 16MB for 7B, negligible.

### 5.5 Code-level Measurement Skeleton

```python
def estimate_accepted_length(p_logits_seq, q_logits_seq, K=5, trials=1000):
    import numpy as np
    taus=[]
    for _ in range(trials):
        accepted=0
        for k in range(K):
            p = softmax(p_logits_seq[k])
            q = softmax(q_logits_seq[k])
            x = np.random.choice(len(p), p=q)
            if np.random.rand() < min(1, p[x]/max(q[x],1e-9)):
                accepted+=1
            else:
                break
        taus.append(accepted+1)  # +bonus
    return float(np.mean(taus)), float(np.std(taus))
```

## 6 Limitations

- *High-entropy degradation*: Under creative generation at `T=1.0`, `TV(p||q)` large; `β→0.2` yields speedup `<1` when `Kc` overhead > acceptance gain. Adaptive speculation (early abort when entropy estimator `H(p)>θ`) partially mitigates but adds predictor overhead.

- *Batch inference incompatibility*: Tree attention masks per sequence vary; batched verification with heterogeneous trees requires padding to union tree causing `O(B*N_max)` wasted compute. Effective speedup in serving with `B=8` drops 2.8× → 1.4× reported.

- *Speculation length tuning*: Optimal `K*` depends on `β` and `c` intra-prompt adaptive. Static `K` underutilizes low-entropy spans and over-proposes high-entropy.

- *Training overhead for Medusa*: Adding heads requires joint fine-tune on ~60k ShareGPT [3] conversations; forgetting base distribution if `λ_k` misbalanced. Second-order effect: heads increase logit memory bandwidth at inference.

- *KV cache fragmentation*: Tree KV eviction non-contiguous memory write leads to fragmentation; naive PyTorch slicing copies, negating speed.

- *Distributional exactness cost*: Rejection sampling mandates exact `p` logits; quantization (INT4) changes `p`, violating guarantee to approximate.

## 7 Conclusion

Speculative decoding reframes LLM inference as *verification-bound* rather than strictly sequential, exploiting abundant FLOPs to hide HBM latency. This work unifies external draft, Medusa heads, and Lookahead parallelism under accepted length calculus `E[τ] = Σ Π β_i`, tree attention kernel enabling single-pass verification with preserved KV reuse, and rigorous rejection sampling proof extending to tree proposals.

Critical takeaways:

1. Alignment via distillation directly maximizes speed via TV reduction; DistillSpec [6] relation `α = 1-TV` should be explicit optimization target, not perplexity.
2. Tree verification strictly dominates sequential under node budget when optimal subtree selection uses cumulative acceptance product; overhead for `N≤64` modest (<40%).
3. Rejection sampling provides *exact* distributional preservation, distinguishing speculative decoding from heuristic non-autoregressive generation.
4. Empirical speedup 2-3× is hardware-realistic for 7-70B batch-1 serving, yet collapses under high entropy or large batch.

Future work: *Hardware-aware speculative scheduler* predicting `K*` from rolling `β` estimate; *recursive speculative* where draft itself is speculative (stacked); *learned tree policies* via RL optimizing `E[τ]/latency` directly. Ultimately, as context lengths reach 100k+, speculation's relative advantage grows because `T_load_weights` constant while `T_attn` quadratic—speculation amortizes both.

We close noting ossification: speculative decoding now standard in Transformers `generate(..., assistant_model=)` and vLLM `speculative_config`, making all discussed kernels production-available [2].
