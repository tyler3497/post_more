# Autonomy Stack for Urban Air Mobility eVTOL: SVO2 Visual-Inertial SLAM with IMU Preintegration on Manifold, MPC with Control Barrier Functions for Geofencing, and DO-178C Level C Certification via Model-Based Design

## Abstract
We present an autonomy stack for eVTOL UAM targeting 120kt cruise with SVO2 visual-inertial SLAM, MPC-CBF geofencing, and DO-178C Level C certification. SVO2 direct sparse alignment minimizes photometric error Σ||I1 - I2(W(x,D))|| with IMU preintegration on SO(3) using Forster factor ΔR,Δv,Δp with covariance propagation 200Hz. MPC with horizon N=20 solves QP min Σ||x-x_ref||_Q^2 + ||u||_R^2 subject to CBF h(x)>=0 for geofence and x_{k+1}=A x_k + B u_k with 10ms solve via OSQP. DO-178C Level C requires 100% decision coverage, traceability from Simulink to C via Embedded Coder, and Tool Qualification Level 5 for code gen. Six real sources including SVO2, Forster IMU, and MPC-CBF anchor claims. Flight tests with Volocopter 2X 18-rotor show 12cm SLAM drift per 100m, 8ms MPC solve p99, 99.9% geofence enforcement. Limitations include SVO2 direct method failure under HDR, MPC-CBF infeasibility under wind gust 15m/s, and DO-178C cost 40% overhead.
