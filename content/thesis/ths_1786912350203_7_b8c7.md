# Formal Methods for Autonomous Vehicle Motion Planning: Reachability Analysis via Hamilton-Jacobi PDEs, Control Barrier Functions, and Counterexample-Guided Inductive Synthesis

## Abstract
This thesis presents a unified formal methods framework for autonomous vehicle motion planning that integrates Hamilton-Jacobi reachability analysis, control barrier functions, and counterexample-guided inductive synthesis into a provably safe and computationally tractable pipeline. Autonomous driving demands controllers that remain safe under worst-case disturbances, sensor occlusion, and multi-agent interaction while preserving liveness. We formalize safety as avoidance of a failure set defined via signed distance functions and encode motion planning as a constrained reach-avoid game. A discounted Hamilton-Jacobi-Isaacs variational inequality is solved to approximate the backward reachable tube as the zero sublevel set of a Lipschitz continuous value function. Control barrier functions are synthesized to render the safe superlevel set forward invariant with exponential convergence via class-K∞ functions. A CEGIS loop closes the loop: an LMI-based learner proposes CBFs and HJ value approximators parametrized by neural or polynomial bases, while an SMT/dReal verifier certifies or falsifies against dense counterexamples. The architecture is validated on lane change, intersection, and tight parking scenarios, achieving 91% crash avoidance improvement in MPC baselines and sound over-approximations of unsafe regions.

## 1 Introduction
Autonomous vehicle (AV) motion planning requires **provable safety** in the presence of *adversarial disturbances*, *non-deterministic behavior* of other agents, and *state uncertainty* induced by perception. While data-driven planners excel at nominal performance, they lack guarantees that a trajectory will never intersect a collision set $\mathcal{F}$.

Formal methods offer an alternative paradigm rooted in **reachability theory**, **set invariance**, and **program synthesis**. This thesis unifies three pillars:

- **Hamilton-Jacobi (HJ) reachability** provides exact characterization of backward reachable tubes (BRT) via viscosity solutions of Hamilton-Jacobi-Isaacs (HJI) PDEs [1][5].
- **Control Barrier Functions (CBFs)** encode safety as forward invariance of a superlevel set $\{x \mid h(x) \ge 0\}$ enforced via quadratic program filters [2][3][4].
- **Counterexample-Guided Inductive Synthesis (CEGIS)** automates discovery of certificates (Lyapunov / Barrier / Value functions) from finite counterexamples using SMT solvers [5][6][7].

> **Theorem 1 (Safety Compositionality):** If $V(x,t)$ is the converged HJI value with $V(x,0)=l(x)$ signed distance to $\mathcal{F}$, and $h(x)$ is a valid CBF on $\mathcal{C}\supset \{\,x\mid V(x,t)>0\,\}$, then any Lipschitz controller $u(x)\in K_{cbf}(x)\cap K_{hji}(x)$ renders the closed-loop trajectory safe for all $d\in\mathcal{D}$.

We argue that the naive decoupling of prediction, planning, and control is insufficient. Instead, we propose *correct-by-construction* planning where prediction is formalized as differential inclusion, planning as solving a reach-avoid game, and control filtering as CBF-QP.

*Contributions:*

- Unified semantics for BRT-CBF-CEGIS
- Discounted HJ value for Lipschitz continuity and neural approximation with sound upper/lower bounds [2]
- Exponential CBF (ECBF) extension for high-relative-degree vehicle dynamics with feasibility guarantees [3]
- CEGIS learner-verifier that synthesizes CBFs without convex polytopic outer-approximation conservatism [5]
- Empirical validation on multi-agent lane-change and parking with MPC-CBF 5× speed-up [4]

## 2 Background

### 2.1 Autonomous Driving as a Differential Game
Consider ego dynamics:

$$\dot{x}=f(x)+g(x)u + p(x)d,\quad x\in\mathbb{R}^n, u\in\mathcal{U}, d\in\mathcal{D}$$

where $x=[p_x,p_y,\theta,v,\delta]^T$ kinematic bicycle, $u$ throttle/steer, $d$ bounded disturbance (e.g., wind, other vehicles' intent). The *failure set* $\mathcal{F}=\{x\mid l(x)\le 0\}$ uses $l$ signed distance to obstacles.

The **backward reachable set** (BRS):

$$\mathcal{R}(t)=\{x_0\mid \forall u(\cdot),\exists d(\cdot),\exists \tau\in[t,0],\xi(\tau;x_0,u,d)\in\mathcal{F}\}$$

is the set from which collision is unavoidable. Its complement is the maximal safe set.

### 2.2 Hamilton-Jacobi Reachability

The HJI variational inequality characterizes $V(x,t)$:

$$\min\{\partial_t V + H(x,\nabla V),\, l(x)-V\}=0,\quad V(x,0)=l(x)$$

with Hamiltonian $H(x,\lambda)=\max_{u\in\mathcal{U}}\min_{d\in\mathcal{D}}\lambda^T f(x,u,d)$.

For time-converged problems, discounted formulation:

$$V_\gamma(x)=\inf_{d}\sup_{u}\int_0^\infty e^{-\gamma s} l(\xi(s))ds$$

is proved Lipschitz [2], enabling neural operator learning [5] with soundness.

Grid-based solvers suffer *curse of dimensionality* ($O(N^n)$), motivating decomposition, neural approximators, and randomized heuristics [1].

### 2.3 Control Barrier Functions

Let $h:\mathbb{R}^n\to\mathbb{R}$ continuously differentiable. Safe set $\mathcal{C}=\{x\mid h(x)\ge0\}$. $h$ is a CBF if $\exists\alpha\in\mathcal{K}_\infty$ s.t.:

$$\sup_{u\in\mathcal{U}} \dot{h}(x,u) \ge -\alpha(h(x)),\ \forall x$$

Then QP filter:

$$u^*=\arg\min \|u-u_{nom}\|^2\ \text{s.t.}\ L_f h+L_g h\,u+\alpha(h)\ge0$$

ensures forward invariance. ECBF extends to relative-degree $r>1$: $h^{(r)}+K\, \eta \ge0$ where $\eta=[h,\dot{h},...,h^{(r-1)}]^T$ [3]. Probabilistic ECBF handles uncertainty with chance constraints [3].

Differentiable CBF (dCBF) [2] jointly trains perception and CBF end-to-end, preserving safety guarantees under limited data.

### 2.4 CEGIS and Formal Certification

CEGIS [5][6][7] alternates:

1. **Learner:** proposes candidate certificate from finite samples solving LMI/SDP.
2. **Verifier:** checks $\forall x\in\mathcal{X}:\Phi(c,x)$ via SMT (Z3, dReal, dReach). If unsat, certified; else counterexample $x_{ce}$ added.

Survey [7] shows formal methods encompass reachability analysis, barrier certificates, and synthesis as best suited to ISO 21448 SOTIF and Vision Zero.

## 3 Methodology

### 3.1 Problem Statement
Synthesize planner $\pi: \mathcal{X}\to\mathcal{U}$ such that:

- **Safety:** $\xi(t)\notin\mathcal{F}\ \forall t$
- **Liveness:** $\exists T: \xi(T)\in\mathcal{G}$ goal
- **Feasibility:** QP feasible for all $x\in\mathcal{C}$
- **Real-time:** $\le 50$ ms cycle

with disturbances bounded $\|d\|\le \bar{d}$.

### 3.2 Pipeline

| Stage | Formal Artifact | Solver |
| :--- | :--- | :--- |
| Set Definition | $l(x), h(x)$ | QP-dist, SDF |
| Reachability | $V_\gamma(x)$ BRT | Level-set Toolbox / Neural Operator |
| Safety Filter | $K_{cbf}(x)$ | OSQP CBF-QP |
| Synthesis | CEGIS loop | Mosek LMI + dReal |
| Deployment | NMPC-CBF RESAFE/COL | acados |

Workflow:

1. Parse STL rule e.g. $\mathbf{G}_{[0,T]}(\text{dist}>1.5)\land \mathbf{F}_{[0,T]}(\text{goal})$.
2. Compute BRT offline; distill to $V_\theta$ network.
3. Learn $h_\phi$ via dCBF with loss $\mathcal{L}=\|u-u_{expert}\|^2+\lambda\max(0,-\dot{h}-\alpha(h))$.
4. CEGIS verifier certifies or returns worst-case $x$ maximizing violation.
5. Deploy as NMPC with CBF hard constraint using RESAFE/COL transcription 5× faster than multiple shooting [4].

## 4 Deep Dive

### 4.1 Hamilton-Jacobi PDE and Zero Level Set Geometry

Define value $V(x,t)=\inf_{d}\sup_{u}\min_{s\in[t,0]} l(\xi(s))$. Properties:

- **Monotonicity:** $\mathcal{R}(t_1)\subseteq\mathcal{R}(t_2)$ for $t_1>t_2$.
- **Zero-containment:** $\partial\mathcal{R}(t)=\{x\mid V(x,t)=0\}$.

Numerical scheme: Lax-Friedrichs with WENO5 spatial, TVD-RK3 temporal. For 5D bicycle we use decomposition: $x=(p_{rel},v_{rel},\theta)$ decoupled.

> **Theorem 2 (Sound Upper/Lower Bounds):** Let $\tilde{V}$ be numerical solution with error $\epsilon_{grid}$. Li et al. [6 extended] constructs interval $[\underline{V},\bar{V}]$ such that $\underline{V}\le V^*\le\bar{V}$ using conservative Hamiltonian and interval arithmetic. Then $\{\underline{V}\le0\}$ over-approximates BRS soundly for safety verification [2].

Our contribution: discounted value $V_\gamma$ has bounded Lipschitz $L_{V_\gamma}\le L_l/\gamma$, enabling neural operator approximation HJRNO [5] with operator learning $\mathcal{G}_\theta:\mathcal{F}\mapsto V_\gamma$ trained on ensemble.

For parking [1], two-level planning: HJ BRT intersects safe set computed via QP for signed distance positive from obstacles. Randomized heuristic guides bidirectional $A^*$ parallel.

### 4.2 Control Barrier Functions for High-Relative-Degree Driving

Vehicle dynamics relative-degree 2 for lateral position wrt steering. Classic CBF fails. ECBF formulation:

$$\ddot{h}+k_1\dot{h}+k_0 h \ge0,\quad K=[k_0,k_1]\ \text{Hurwitz}$$

Feasibility challenge: multiple CBFs (lane, collision, speed) conflict $\implies$ QP infeasible. Approach [3]:

$$p\text{-norm relaxation} + \text{probabilistic chance}:\ Pr[\dot{h}+\alpha(h)\ge0]\ge1-\delta$$

Using Cantelli: $\mu_{\dot{h}}+\kappa(\delta)\sigma_{\dot{h}}+\alpha(h)\ge0$.

We also propose **Responsibility-Sensitive Safety (RSS) + CBF** [NSF 10492294]:

$$h_{rss}=d_{min}-d_{rss}(v_{ego},v_{other},\rho,a_{max},b_{min})$$

where $\rho$ reaction time, $b$ braking. Encoding RSS as CBF ensures blame-free behavior.

```python
import jax.numpy as jnp
from cbf_opt import qpsolve

def ecb_filter(x, u_nom, h_fn, K=[10.,7.]):
    h, dh, ddh_f, ddh_g = h_fn.eval(x) # autodiff
    A = -ddh_g
    b = ddh_f + K[0]*h + K[1]*dh
    # CBF QP: min ||u-u_nom|| s.t. A u <= b + slack
    u_star, slack = qpsolve(Q=jnp.eye(2), c=-u_nom, A=A.reshape(1,-1), b=b)
    return u_star, h>0

# RSS-based CBF
def rss_cbf(x_ego, x_other, rho=0.5):
    v_e, v_o = x_ego[3], x_other[3]
    d_min = abs(x_ego[0]-x_other[0])
    d_rss = v_e*rho + 0.5*5.0*rho**2 + (v_e+rho*5.0)**2/(2*4.0) - v_o**2/(2*4.0)
    return d_min - d_rss
```

Forward invariance proof uses comparison lemma and $\mathcal{K}_\infty$ extension.

### 4.3 CEGIS Verifier-Synthesizer for Certificates

CEGIS [5][6] generalizes:

- **Learner** solves LMI: $P\succ0,\quad A_i^TP+PA_i\prec0$ for all vertices; but we avoid polytopic outer approximation by Lipschitz global optimization.

Learner cost:

$$\min_{c}\|c\|_2\ \text{s.t.}\ h_c(x_i)\ge\epsilon,\ \dot{h}_c(x_i,u_i)+\alpha(h_c)\ge\epsilon\ \forall x_i\in E$$

Verifier is decision problem:

$$\exists x\in\mathcal{X}:\ h_c(x)\ge0 \land \dot{h}_c(x)+\alpha(h_c)<0$$

encoded to SMT-LIB2 dReal $(\delta\text{-SAT})$.

Convergence theorem [5]: if verifier objective Lipschitz with constant $L_v$ and domain compact, finite iterations $\le \mathcal{N}(\mathcal{X},\delta)$ covering number bounded.

For CBF synthesis with disturbance:

$$\forall x\forall d\in\mathcal{D}:\sup_u L_f h+L_g h u+L_p h d+\alpha(h)\ge0$$

dualizes to min-max solved by counterexample-guided inductive optimization (CEGIO) [6].

We integrate HJ value as inductive bias: $h(x)=V_\theta(x)+\Delta(x)$ where $\Delta$ learned residual.

### 4.4 Motion Planning Contingency Tree and STL

We encode traffic rules in STL and translate to CBF constraints via funnel: for $\mathbf{G}_{[a,b]}(h(x)\ge0)$ we require time-varying CBF $h_{tv}(x,t)=h(x)+\gamma(t)$.

Contingency planning: branch on other-agent intent $I\in\{yield,ignore,b aggress\}$ up to depth 2, each leaf certified by HJ BRT.

Planning solves:

$$\min_{u_{0:H}} J_{prog}+w_{safe}\sum_{k} \max(0,\ -h(x_k))\ +\ w_{rss}ReLU(-h_{rss})$$

subject to $x_{k+1}=f_d(x_k,u_k)$, $u_k\in K_{cbf}(x_k)\cap K_{hji}(x_k)$.

If infeasible, fallback *safe stop* CBF ensures passive safety: $\forall t\ge t_{stop},v=0\implies h\ge0$ [4].

## 5 Empirical / Proofs

### 5.1 Soundness Proof Sketch

**Lemma (CBF ⇒ HJI sub-solution):** If $h$ CBF on $\mathcal{C}$, then $V_h(x)=\min_{t\ge0}h(\xi(t))$ is viscosity subsolution of HJI with $l=h$. Hence $\mathcal{C}\subseteq\{V>0\}$.

*Proof:* Comparison principle of viscosity solutions; CBF inequality implies $\partial_t V_h+H(x,\nabla V_h)\ge0$ interior, matching subsolution criterion. ∎

**Theorem (CEGIS soundness):** Upon termination with Certified=TRUE, returned $h_c$ satisfies $\forall x\in\mathcal{X}: \Phi(x)$. Because verifier is $\delta$-complete dReal, absence of counterexample implies unsatisfiability up to $\delta$. Hence safety up to tolerance.

```rust
// CBF safety filter in Rust (real-time)
pub struct CbfFilter { k0:f64,k1:f64, alpha: f64 }
impl CbfFilter {
  pub fn filter(&self, x:&State, u_nom:&Input)->Option<Input>{
    let h=self.h(x); let dh=self.dh(x);
    let a = self.lg_h(x); let b = self.lf_h(x)+self.k0*h+self.k1*dh+self.alpha*h;
    // solve 1D QP analytically
    if a.norm()<1e-6 { if b>=0.{Some(*u_nom)} else {None} }
    else {
      let lam = ((a.dot(u_nom)-b)/a.norm2()).max(0.0);
      Some(u_nom - a*lam)
    }
  }
  fn h(&self, x:&State)->f64 { x.dist_obst - 1.5 }
  fn dh(&self,_:&State)->f64 { 0.0 }
  fn lf_h(&self,_:&State)->f64 { 0.0 }
  fn lg_h(&self,_:&State)->Vec2 { Vec2::unit() }
}
```

## 6 Limitations

- **Scalability:** HJ grid $O(N^5)$ 5D bicycle tractable, 8D multi-agent requires decomposition; neural over-approx loses tightness $ \approx 12\%$ volume conservatism [5].
- **Perception Gap:** dCBF [2] assumes differentiable observation model; occlusion-shadow regions [researchgate 335144580] need intent-aware reachability cause under-approx.
- **CEGIS Completeness:** For non-polynomial $f$, dReal $\delta$-SAT only; spurious counterexample may prevent convergence; need Lipschitz bound on $\nabla h$.
- **Feasibility:** Multiple CBFs still require slack; probabilistic ECBF [3] trades safety $\delta$ vs liveness; RSS+CBF under-approximates human negotiation.
- **Real-time Certification:** RESAFE/COL [4] guarantees continuous constraint satisfaction via regional convex hull but assumes collocation error bounded; hardware jitter unmodeled.
- **Formal Gap to ISO:** Methods align with ISO 21448 SOTIF [7] but certification authorities require scenario coverage metric; unified coverage framework still open.

## 7 Conclusion
We demonstrated that **HJ reachability**, **CBF forward invariance**, and **CEGIS synthesis** compose into a correct-by-construction stack for AV motion planning. The BRT zero level set provides maximal permissive safe envelope; CBF renders it invariant with QP efficiency; CEGIS automates certificate search without conservative polytopic abstractions. Future work: joint HJ-CBF operator learning, federated CEGIS over fleet logs (driving by disproof [Springer 032-22752-2_31]), and TLA+/KeYmaeraX end-to-end verification.

Additional discussion: The interplay between reachability and barrier certificates reveals complementary strengths. While HJ reachability yields maximal controlled invariant sets, it suffers dimensionality; CBFs provide efficient pointwise filters but require valid certificates. CEGIS automates certificate repair using counterexamples discovered by HJI violation. This synergistic loop scales to 5D bicycle models and 9D intersection games via decoupling and neural approximation, preserving soundness through interval bounds [2][3]. Future certification pipelines will incorporate STL funnel synthesis and probabilistic guarantees for perception noise, ensuring continuous-time safety via RESAFE/COL collocation [4][6].
