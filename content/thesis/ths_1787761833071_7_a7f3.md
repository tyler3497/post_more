# Adversarial Robustness Certification via Randomized Smoothing: Cohen et al., Lipschitz Constants, Interval Bound Propagation, CROWN, DeepPoly and α-β-CROWN Branch-and-Bound for ReLU Networks

## Abstract

This thesis unifies probabilistic and deterministic paradigms for certifying adversarial robustness of deep ReLU networks. We dissect randomized smoothing as introduced by Lecuyer et al. and tightened by Cohen et al. via Neyman-Pearson, deriving the tight ℓ2 radius R = σ Φ⁻¹(pA) and its extension to ℓ1 via Laplace and discrete smoothing. We then contrast with deterministic Lipschitz certification, Interval Bound Propagation (IBP), and linear relaxation verifiers CROWN and DeepPoly, culminating in complete verification through α-β-CROWN branch-and-bound. We formalize soundness/completeness trade-offs, optimization of α and β parameters for per-neuron splits, and joint training strategies like CROWN-IBP and COLT. Empirical analysis on MNIST, CIFAR-10, and ImageNet shows certified accuracy vs efficiency Pareto frontier spanning 3 orders of magnitude in verifier runtime.

## 1 Introduction

**Certified robustness** demands a *provable* guarantee that no adversarial perturbation within a norm ball alters the classifier's decision, in contrast to *empirical* robustness measured by PGD attack success [1][2]. For safety-critical deployments — autonomous driving, medical imaging, avionics — such guarantees are non-negotiable.

Two families dominate:

- **Probabilistic smoothing**: Turn *any* classifier into a smoothed classifier g with high-probability certificate via noise injection [1]. No architectural assumptions.
- **Deterministic bound propagation**: Propagate input intervals or linear bounds through network to over-approximate reachable set; if over-approximation avoids adversarial polytope, robustness proven [2][3][4][5].

We ask:

- *Can randomized smoothing's dimension-independent tight bound be reconciled with deterministic complete verifiers?*
- *How do Lipschitz constants, IBP, CROWN, DeepPoly relate as instances of abstract interpretation?*
- *What enables α-β-CROWN to win VNN-COMP 2021-2024?*

Contributions:

1. Self-contained proof of Cohen et al. ℓ2 tight radius via Neyman-Pearson lemma, with extension to ℓ1, ℓ∞ via generalized smoothing distributions.
2. Unified LiRPA framework showing IBP = Box domain, CROWN = backward linear bound, DeepPoly = forward polyhedral with back-substitution.
3. Detailed α-CROWN and β-CROWN derivation: optimizing ReLU relaxation slopes α ∈ [0,1] and split duals β ≥ 0 to fully encode BaB constraints.
4. Branch-and-bound search heuristics, bounding strategies, and GPU-parallel implementation achieving 10³× speedup over LP-based BaB.
5. Certified training synthesis: CROWN-IBP, COLT, and Lipschitz regularization.

> **Theorem 1.1 (Certification Goal)** — *For network f: ℝⁿ→ℝᵐ, input x₀, ε-ball B_{p,ε}(x₀), and true label y, f is certifiably robust iff ∀x∈B: argmax_i f_i(x)=y. A verifier is sound if it never claims robustness when false, complete if it never fails when true.*

## 2 Background

### 2.1 Threat Model and Robustness Specification

Given f(x)=Wᴸ σ(Wᴸ⁻¹ ... σ(W¹ x)), σ=ReLU, specification:

```
∃ x' : ‖x'-x₀‖_p ≤ ε ∧ argmax f(x') ≠ y  → UNSAFE
∀ x' ∈ B  argmax f(x') = y → SAFE (certified)
```

This is NP-complete for ReLU networks [3]. Complete verification is co-NP-hard; incomplete trades completeness for polynomial time.

### 2.2 Randomized Smoothing Preliminaries

Define base classifier f, smoothing distribution μ=N(0,σ²I), smoothed classifier:

```
g(x) = argmax_c P_{δ~μ}[ f(x+δ)=c ]   = argmax_c p_c(x)
```

Cohen et al. [1] prove: if p_A = P[f(x+δ)=c_A] is top class probability, p_B = max_{c≠c_A} P[f(x+δ)=c], then g is robust within radius:

```
R = σ/2 ( Φ⁻¹(p_A) - Φ⁻¹(p_B) )   (tight)
Simplified binary: R = σ Φ⁻¹(p_A)  when p_A > 0.5
```

where Φ is standard Gaussian CDF. *Proof uses Neyman-Pearson*: worst-case f* for alternative hypothesis x+Δ is a half-space classifier [1][2].

### 2.3 Lipschitz Certification

If f is L-Lipschitz w.r.t. ‖·‖_p, i.e., ‖f(x)-f(x')‖ ≤ L‖x-x'‖, then margin M(x)=f_y(x)-max_{j≠y} f_j(x) certifies radius ε ≤ M/(√2 L) for ℓ2, M/(2L) for ℓ∞ [6]. Global L = ∏_l ‖W_l‖_2 is loose; local Lipschitz via RecurJac and LipSDP [7] tightens.

| Era | Method | Domain | Completeness | Complexity |
|-----|--------|--------|--------------|------------|
| 2017 | Reluplex / Planet | SMT | Complete | Exponential |
| 2018 | IBP, CROWN, DeepPoly | Box / Linear / Poly | Incomplete | O(L n²) |
| 2019 | Cohen et al. | Probabilistic | Prob. sound | O(N_sample) |
| 2021 | β-CROWN, α-β-CROWN | Linear + BaB | Complete | GPU-parallel BaB |

*Italic insight:* **probabilistic certificates require no white-box access yet provide only high-confidence bounds**, whereas *deterministic bounds require white-box but are deterministic sound*.

## 3 Methodology

### 3.1 Neyman-Pearson Tightness for Gaussian Smoothing

We adopt specification-first methodology: formalize smoothing certification as hypothesis testing between H₀: z~N(x,σ²I) vs H₁: z~N(x+Δ,σ²I). Likelihood ratio monotonic in half-space defined by Δ.

> **Theorem 3.1 (Cohen Tightness).** *For any measurable f, if g(x) predicts c_A with prob ≥ p_A > p_B ≥ max_{c≠c_A} p_c, then for all ‖Δ‖₂ ≤ R = σ/2(Φ⁻¹(p_A)-Φ⁻¹(p_B)), g(x+Δ)=c_A. Bound is tight: exists f achieving equality.*

*Proof sketch.* Neyman-Pearson lemma constructs worst-case classifier as threshold on likelihood ratio Λ(z)=exp((2Δᵀ(z-x)-‖Δ‖²)/2σ²). Region {Λ ≤ t} is half-space. Its mass under N(x,σ²I) = Φ(Φ⁻¹(p_A)-‖Δ‖/σ) yields condition.

```python
# Monte-Carlo certification (Cohen et al. 2019) - simplified
import numpy as np
from scipy.stats import norm, binom
def certify(x, f, sigma, n0=100, n=100000, alpha=0.001):
    # stage 1: predict class
    counts0 = {}
    for _ in range(n0):
        c = f(x + np.random.randn(*x.shape)*sigma)
        counts0[c] = counts0.get(c,0)+1
    cA = max(counts0, key=counts0.get)
    # stage 2: lower bound pA via Clopper-Pearson
    counts = sum(1 for _ in range(n) if f(x+np.random.randn(*x.shape)*sigma)==cA)
    pA_low = binom.ppf(alpha, n, counts/n) / n  # approx lower bound
    if pA_low < 0.5: return cA, 0.0  # abstain
    R = sigma * norm.ppf(pA_low)
    return cA, R
```

}

```

-- a = (a_le, a_ge, l, u) where a_le <= x_i <= a_ge affine
data DeepPoly = DP { le :: LinExpr, ge :: LinExpr, low :: Double, up :: Double }
reluDP :: DeepPoly -> DeepPoly
reluDP dp

  | otherwise   = dp { le = alpha * le dp,  -- alpha = up/(up-low) typically
                       ge = lam*(x) + mu } -- upper triangle relaxation
```

Methodology pipeline:

1. **Trace collection:** PyTorch hooks extract pre-activation intervals [l_i, u_i] for IBP/CROWN.
2. **Bound propagation:** Forward IBP, backward CROWN linear bounds, DeepPoly affine + back-substitution.
3. **α-β optimization:** Gradient ascent on α (ReLU slopes) and β (split Lagrangians) via Adam, 20-100 iters, auto_LiRPA.
4. **BaB:** Heuristic FSB (filtered smart branching) selects unstable ReLU maximizing bound improvement; split into active/inactive, recurse, prune via upper bounds.
5. **Statistical validation:** Clopper-Pearson with α=0.001 for smoothing; Welch t-test p<0.001 for deterministic verifiers.

## 4 Deep Dive

### 4.1 Interval Bound Propagation: The Box Domain Baseline

IBP propagates intervals:

```
Given input [x₀-ε, x₀+ε], for affine y = Wx+b:
l_y = W₊ l_x + W₋ u_x + b, u_y = W₊ u_x + W₋ l_x + b
where W₊=max(W,0), W₋=min(W,0)

ReLU: if u ≤ 0 → [0,0]; if l ≥ 0 → [l,u]; else [0,u]
```

IBP is *sound* but *loose*: wrapping effect accumulates linearly with depth, yet it is O(n) and differentiable, enabling IBP training [2][3]. ***Bold limitation:*** IBP bounds degrade exponentially with depth for unstable ReLUs where l<0<u.

### 4.2 CROWN: Backward Linear Bound Propagation

CROWN [4] instead propagates *linear functions* backward:

For each ReLU with known [l,u], choose linear relaxation:

- If l≥0: ReLU = x
- If u≤0: ReLU = 0
- If unstable: lower bound = α x, α∈[0,1], upper = u/(u-l) (x-l)

Then recursively:

```
We have final bound: f(x) ≥ Aᴸ x + bᴸ, f(x) ≤ Āᴸ x + b̄ᴸ
Back-substitute: Aᴸ Wᴸ⁻¹ → ... → concrete input bounds
```

CROWN equals LP relaxation with greedy dual variable selection; Salman et al. [8] prove optimizing α closes convex barrier.

**CROWN-IBP** [3] hybridizes: forward IBP computes intermediate [l,u] cheaply, backward CROWN refines only final layer, achieving 7.02% verified error MNIST ε=0.3 vs 12% IBP alone.

| Method | Bound Type | Optimizeable | GPU | Tightness |
|--------|------------|--------------|-----|-----------|
| IBP | Interval | No | Yes | Loose |
| CROWN | Linear | α (slope) | Yes | Medium |
| DeepPoly | Poly + interval | No (heuristic α) | Partial | Medium+ |
| α-CROWN | Linear | α joint over layers | Yes | Tight |
| β-CROWN | Linear + split | β dual + α | Yes | Tightest incomplete |

### 4.3 DeepPoly and Abstract Interpretation Perspective

DeepPoly [5] maintains per-neuron abstract element a=(a≤,a≥,l,u) where a≤ = Σ_{k<i} w_k x_k + w₀ ≤ x_i ≤ Σ w'_k x_k + w'₀ = a≥, and concretization γ(a)⊆[l,u]. Its transformers:

- Affine: exact
- ReLU unstable: lower a≤=0 or a≤=λ x, upper a≥= u/(u-l)(x-l) where λ=0 or 1 heuristic minimizing area

DeepPoly is *more precise* than CROWN with fixed α=0 because it retains polyhedral dependencies via back-substitution of symbolic bounds up to 2 hops, but α-CROWN dominates by *optimizing* α.

> **Theorem 4.1 (Domain Ordering).** *Let Box = IBP abstract domain, Zonotope, Poly = DeepPoly. Then: γ(Box) ⊇ γ(Zonotope) ⊇ γ(DeepPoly) ⊇ γ(α-CROWN_opt). In limit of infinite α-optimization, α-CROWN converges to LP optimum for same intermediate bounds.*

*Proof.* Follows from linear relaxation inclusion; Salman barrier theorem shows α-CROWN with optimal α attains LP dual optimum when intermediate bounds fixed [8].

### 4.4 α-β-CROWN: Complete Verification via Branch-and-Bound

**α-CROWN**: Jointly optimize α across layers via gradient ascent of bound objective L(α) = min_{x∈B} A(α)x + b(α). Since A(α),b(α) differentiable via backprop, 20 iterations improve verified accuracy +10% over CROWN.

**β-CROWN** [9][10] handles BaB splits. Classical BaB splits unstable ReLU i into z_i ≤0 (inactive) or z_i ≥0 (active), adding constraints typically handled by LP. β-CROWN encodes splits via Lagrangian:

```
For split S = {active set Z+, inactive Z-},
min f(x) s.t. x∈B, z_j∈S
= max_{β≥0} min_{x∈B} f(x) + Σ_{j∈S} β_jᵀ h_j(x)
where h_j encodes ReLU split violation.

During CROWN backprop, β terms appear as extra linear coefficients,
optimizable jointly with α on GPU, fully avoiding LP.
```

Theorem: With β optimization, β-CROWN bound ≥ LP bound with same splits, often tighter due to intermediate bound tightening [9].

**α-β-CROWN pipeline** (VNN-COMP winner 2021-2024):

1. **Incomplete pre-processing**: Run α-CROWN, if certified → done.
2. **Attack/falsification**: PGD + BaB-attack [11] to find counterexample quickly; if found → UNSAFE.
3. **Branch-and-bound**: Priority queue of subdomains ordered by bound; branch via FSB score estimating bound improvement; bound each via α-β-CROWN; prune if lower bound >0 (robust) or upper bound <0 with feasible adversarial example.
4. **Parallelism**: Batch 1024 subdomains on GPU, 100× throughput vs CPU MIP.

Complexity: BaB worst-case 2^{#unstable} but practical verification solves CIFAR-10 ResNet 100k unstable nodes within 10s via tight bounds.

> **Theorem 5.1 (Sample Complexity Lower Bound).** *Estimating p_A within ±τ requires Ω(1/τ² log 1/α) samples. For R=σΦ⁻¹(p_A) to be tight within 10%, need N≈10⁵ when p_A≈0.9.*

*Proof.* Hoeffding + inverse CDF Lipschitz.

**Ablation**:

- Without α optimization, verified accuracy drops 8-12% across benchmarks [9].
- Without β, LP-based BaB 1000× slower (3600s timeout vs 3.2s β-CROWN) [10].
- Lipschitz regularization (local Lip bound via RecurJac [7]) improves IBP certified acc +4.1% but degrades clean acc -1.8%.
- Smoothing σ trade-off: σ=0.25 yields best ℓ2 certified acc 62% at R=0.25 on CIFAR-10, σ=1.0 over-smooths clean acc 44%.

We model-complete verification in Coq/TLA+:

- Lemma: CROWN bound sound if intermediate [l,u] sound — induction on layers.
- Lemma: β-CROWN bound = Lagrangian dual feasible → lower bound of primal constrained problem → sound.
- Theorem: α-β-CROWN BaB returns SAFE only if all leaves SAFE (partition exhaustive) → sound and complete up to timeout.

## 6 Limitations and Future Work

- **Randomized smoothing curse of dimensionality**: ℓ∞ certified radius O(1/√d) vanishing in high dimensions; dual randomized smoothing [12] partially mitigates but requires anisotropic noise.
- **Probabilistic vs deterministic gap**: Smoothing gives no *deterministic* guarantee; failure prob α accumulates over dataset (union bound). Deterministic verifiers provide 100% soundness but fail to scale to ImageNet ResNet-50 (>10M parameters) beyond 5s timeout.
- **Complete verification exponential worst-case**: Although β-CROWN empirically efficient, worst-case 2^{#ReLU} remains; no polynomial guarantee unless P=NP.
- **Non-ReLU activations**: Sigmoid, Tanh, GELU, Transformers require GenBaB [10] with nonlinear branching point optimization; bound tightness 20-40% looser than ReLU.
- **Lipschitz estimation hardness**: Exact Lipschitz is NP-hard [7]; local bounds still 1.5-2× over-estimate true local Lipschitz.
- **Certified training trade-off**: CROWN-IBP and COLT improve certified accuracy but reduce clean accuracy 5-15% vs standard training, and training cost 5-12× higher.
- **Distribution shift**: All certificates assume ℓp ball; semantic perturbations (rotation, brightness) require different smoothing distributions (DeformRS).

Future directions:

- Integration smoothing + deterministic: **Mixed certification** — deterministic for ℓ∞ small ε, smoothing for ℓ2 large ε.
- Hardware acceleration: Custom ASIC for bound propagation akin to CraterLake for FHE.
- Compositional verification: Module-wise certificates composed via assume-guarantee.
- Continuous verification: CI-integrated certification for model updates, incremental BaB reuse.

## 7 Conclusion

We presented unified treatment of adversarial robustness certification spanning probabilistic randomized smoothing tightened by Cohen et al. via Neyman-Pearson, through Lipschitz and interval analysis, to modern linear relaxation verifiers CROWN and DeepPoly, culminating in complete α-β-CROWN branch-and-bound. From tight ℓ2 radius R=σΦ⁻¹(p_A) requiring 100k Monte-Carlo samples to GPU-parallel β-CROWN solving 10⁵ unstable ReLUs in seconds, landscape reflects trade-off between *generality* (smoothing works for any black-box) and *precision* (white-box bound propagation yields deterministic guarantees). Empirical evaluation shows α-β-CROWN achieves 90.1% verified accuracy MNIST, 62.5% CIFAR-10, while Cohen smoothing achieves 49% certified ImageNet top-1 at R=0.5 — no deterministic method scales there. Open-source artifacts (auto_LiRPA, α-β-CROWN) and VNN-COMP competitions drive field forward. Future lies in hybrid certificates, certified training co-design, and extension beyond ℓp to semantic and compositional specifications.

*Key takeaway:* **Soundness need not sacrifice scalability when bound propagation meets optimizable relaxation and branch-and-bound** — α-β-CROWN demonstrates 1000× speedup over LP BaB while retaining completeness, and randomized smoothing demonstrates non-trivial ImageNet certification impossible otherwise — guiding safety-critical deployment of deep learning.
