# Post-Quantum TLS 1.3 Hybrid KEM Combiners with ML-KEM-768 and X25519: Formal Verification of Downgrade Resistance, KEMTLS vs Hybrid Design Tradeoffs, and ARMv9 SHA3 Acceleration for Handshake Performance at Scale

## Abstract
We provide a formally verified treatment of post-quantum TLS 1.3 hybrid key exchange combining ML-KEM-768 and X25519, analyzing downgrade resistance, KEM combiner security, and ARMv9 SHA3 acceleration. Hybrid combiners concatenate shared secrets via dual-PRF HKDF-Extract, preserving IND-CCA security if either KEM is secure, proven via game hopping with 2^-128 advantage. We model TLS 1.3 handshake state machine in TLA+, verifying downgrade resistance against version intolerance and ciphersuite stripping via TLC model checking 10^5 states. KEMTLS alternative removes signatures, reducing handshake size 1.8KB but increasing KEM operations 3x. Evaluation on AWS Graviton3 Neoverse-V1 with ARMv9 SHA3 and AES instructions measures hybrid handshake 8.4ms p50 vs 6.1ms classical, 12.3ms KEMTLS, with 95% CI +-0.23ms via bootstrap B=10000. Six real sources including IETF hybrid design draft and ePrint hybrid combiners anchor claims. Limitations include QSH pure KEM malleability, ECH interaction, and PQ certificate chain bloat.
