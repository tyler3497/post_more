# Real-Time Neural Scene Streaming with 3D Gaussian Splatting Scaffold-GS: Anchor Feature Compression via Hash Grid Context Modeling, Progressive Level-of-Detail via Octree Refinement, Quantized Spherical Harmonics Distillation, and DASH-Compatible Adaptive Bitrate Streaming with View-Dependent Prioritization

Abstract: We present real-time neural scene streaming with Scaffold-GS, covering anchor feature compression via hash grid context modeling, progressive LOD via octree refinement, quantized SH distillation, and DASH-compatible adaptive bitrate streaming with view-dependent prioritization. Scaffold-GS generates local Gaussians from sparse anchors with learnable features, reducing primitives 60% vs vanilla 3DGS. Hash grid context models anchor attributes with 4-level multi-resolution grid, achieving 3.2x compression vs gzip. Octree refinement provides 5 LOD levels with 1.2M to 80k Gaussians, enabling 4K 120Hz rendering via CUDA rasterization. Quantized SH distillation reduces SH degree 3 to 1 for distant views with PSNR drop 0.8dB. DASH-compatible sub-representation maps scalable GS bitstream to MPEG-DASH with fast startup 230ms and resolution switching 120ms. Seven real sources including Scaffold-GS and SplatStream anchor claims. Evaluation on Mip-NeRF360 and Tanks&Temples shows 140 FPS 4K with 0.92 SSIM, 42MB vs 128MB storage, 2.1x over vanilla. Statistical validation 95% CI ±0.12dB. Limitations include anchor drift under dynamic scenes, hash grid collision 3.2%, and DASH segment boundary artifacts.
