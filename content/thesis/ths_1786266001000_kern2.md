# Kernelized Efficient Attention via FAVOR+ and Structured State Space Duality: Performers, Retentive Networks, Mamba-2 SSD, and Griffin Gated Linear Recurrence for Long Context

## Abstract
We present a unified analysis of kernelized and state-space surrogates for softmax attention that achieve *linear* time and memory in sequence length while preserving content-based reasoning. Starting from the Fast Attention Via Positive Orthogonal Random Features (FAVOR+) estimator underlying Performers, we connect its positive random feature map for the softmax kernel to the semiseparable matrix duality that subsumes modern linear recurrences. Retentive Networks, Mamba's selective state-space model, Mamba-2's Structured State Space Duality (SSD), and Griffin's RG-LRU gated linear recurrences all admit a common representation as masked kernel attention with data-dependent decay. We formalize the equivalence between parallel, recurrent, and chunkwise forms, characterize variance and stability of orthogonal random features versus deterministic gating, and derive hardware implications for long-context scaling to 1M+ tokens. Empirical synthesis across language, retrieval, and associative recall benchmarks shows 2-8x speedup at matched perplexity with strict O(L) inference state.

## 1 Introduction

The Transformer [Vaswani et al. 2017] scales as *O(L^2 d)* in time and *O(L^2)* in space due to explicit materialization of the *L × L* attention matrix *A = exp(QK^⊤ / √d)*. This quadratic bottleneck, tolerable at *L=512*, becomes prohibitive at *L=32k-1M* contexts demanded by code, genomics, and long-document reasoning. Three distinct research lines attack this from orthogonal angles yet converge mathematically.

First, *kernelization*: softmax attention is a kernel smoother with kernel *K(q,k)=exp(q^⊤k)*. If *K(q,k)=𝔼[φ(q)^⊤ φ(k)]* for a finite feature map *φ: ℝ^d → ℝ^r_ +*, then attention reduces to *Q' (K'^⊤ V)* with *Q',K' ∈ ℝ^{L×r}*, achieving *O(L r d)* time [1]. The Performer introduces FAVOR+ [1][2] to make this unbiased and positive, using trigonometric or positive random features with orthogonalization.

Second, *retention and linear recurrence*: by replacing softmax normalization with data-independent or scalar decay *γ* and adding *D* or *γ*-masking, attention factorization becomes a linear RNN: *S_n = γ S_{n-1} + K_n^⊤ V_n*, *O_n = Q_n S_n* [3]. This yields three isomorphic views: parallel (*O = (QK^⊤ ⊙ D) V*), recurrent (*O(1)* inference), and chunkwise (*O(L)* training with *O(1)* memory per chunk).

Third, *structured state-space duality*: Dao and Gu [5] show that selective SSMs and masked linear attention are both instances of *semiseparable* matrices *M_{ji}= C_j^⊤ A_{j:i} B_i*. Selective discretization makes *A_t, B_t, C_t* input-dependent, recovering content-aware forgetting while preserving a dual quadratic form that can be computed via block-decomposed matrix multiplication for 2-8× speed [5][6].

This thesis unifies these via kernelized efficient attention, culminating in Griffin's hybrid gated linear recurrence + local attention [4] that extrapolates beyond training length while matching Llama-2 with 6× fewer tokens.

> **Theorem 1 (Unified Duality):** Every causal linear attention or selective SSM with state *h_t ∈ ℝ^n*,
> *h_t = a_t h_{t-1} + B_t u_t*, *y_t = C_t^⊤ h_t*,
> corresponds to a lower-triangular semiseparable kernel matrix *M* where *y = M u*, and *M* admits both *O(L^2)* materialization and *O(L)* recurrent evaluation. If *a_t = γ* is constant, *M_{ji}=γ^{j-i} K_j^⊤ Q_i* recovering RetNet retention.

Contributions:

1. We derive FAVOR+ variance bounds with orthogonal vs i.i.d. features and contrast with deterministic exponential gating variance-free but bias-limited regimes.
2. We formalize SSD as block-diagonal factorization of semiseparable matrices governing Mamba-2's speedups.
3. We analyze RG-LRU gating in Hawk/Griffin as real-diagonal *A_t* with learnable *tanh* damping, enabling stable long-context extrapolation.
4. We provide hardware-aware parallel scan vs. chunkwise algorithms and a comparative table of complexity, state size, and expressiveness.

Additional desiderata satisfied in this synthesis:

- **Full kernel coverage**: unbiased positive estimation and bias-variance control
- **State-optimal inference**: *O(1)* per-token decoding with bounded memory
- **Hardware co-design**: tensor-core utilizable dual form for SSD

## 2 Background

### 2.1 Softmax Attention and Kernel Formulation

Let *Q,K,V ∈ ℝ^{L×d}*. Bidirectional attention:

```
Att(Q,K,V) = D^{-1} A V,  A = exp(QK^⊤ /√d), D = diag(A 1_L)
```

Unidirectional:

```
Att→ = D~^{-1} Ã V, Ã = tril(A)
```

Time *O(L^2 d)*, space *O(L^2 + Ld)*. Kernel trick: if *K(x,y)=𝔼[φ(x)^⊤ φ(y)]* and *φ>0*, then

```
ÂV = diag^{-1}(Q' (K'^⊤ 1)) * [Q' (K'^⊤ V)], Q'=φ(Q), K'=φ(K)
```

in *O(L r d)* for *r≪L*.

Classical random Fourier features approximate RBF kernels with sin/cos, but they can be negative, causing unstable training for softmax approximations because denominator estimation may approach zero [1]. FAVOR+ solves with *positive* features:

> *Definition (PRF):* For *w∼𝒩(0,I_d)*, 
> `φ_pos(x) = exp(w^⊤ x - ‖x‖^2/2)` ensures `𝔼[φ_pos(x)^⊤ φ_pos(y)] = exp(x^⊤ y)`.

Orthogonal RFs reduce variance by sampling *w* matrices via QR orthogonalization [1].

### 2.2 Structured State Spaces and HiPPO

Continuous-time SSM [7]:

```
ż(t)= A z(t)+ B u(t)
y(t)= C z(t)+ D u(t)
```

Discretized with *Δ* via zero-order hold:

```
z_k = Ā z_{k-1} + B̄ u_k
y_k = C̄ z_k
Ā = exp(Δ A), B̄ = (ΔA)^{-1}(exp(ΔA)-I) ΔB
```

HiPPO [Gu et al. 2020] initializes *A* to orthogonalize history with respect to Legendre measure, yielding long-range memory. S4 [7] imposes Normal Plus Low-Rank (NPLR) structure to compute convolution kernel *K̄ = C̄ B̄, C̄ Ā B̄, ...* in *O(L log L)* via Cauchy kernel. S5 generalizes to MIMO.

Mamba [6] makes Δ,*B*,*C* functions of *x_t*, breaking LTI and enabling content-based reasoning. Hardware-aware selective scan fuses kernels in SRAM to avoid HBM traffic.

### 2.3 Long-Range Arena and Efficiency Desiderata

*Tay et al. 2021* defines six tasks requiring *L=1k-16k*. Efficient transformers (Sparse, Linformer, Reformer) retain only 60-70% of Transformer performance, while S4 achieves 86% average [7]. Criteria for successor: training parallelism, *O(1)* inference per token, subquadratic memory, associative recall.

## 3 Methodology

### 3.1 FAVOR+ Estimator

We formalize the Performer layer:

```python
import torch, math
def favor_plus_features(X: torch.Tensor, W: torch.Tensor, ortho: bool=True):
    # X: (L, d), W: (r, d) sampled N(0,1) then orthogonalized
    # positive feature map for softmax kernel exp(Q K^T)
    # φ(x) = exp( -||x||^2/2 ) * exp( W x )
    # unbiased for exp(x^T y) = E[ φ(x)^T φ(y) ]
    L, d = X.shape
    r = W.shape[0]
    X_norm = -0.5 * (X**2).sum(dim=-1, keepdim=True)  # (L,1)
    Q_proj = X @ W.T  # (L, r)
    Phi = torch.exp(X_norm + Q_proj) / math.sqrt(r)
    return Phi  # (L, r)
# attention: Qp, Kp from Q,K; then
# KV = Kp.T @ V  # (r, d_v)
# Z = 1 / (Qp @ (Kp.T @ torch.ones_like(...)))
# Out = Z * (Qp @ KV)
```

Orthogonalization: *W_ortho = QR(W_gauss)*, row-orthogonal. [1] proves for *RBF* and softmax kernels, orthogonal ensemble yields lower MSE and uniform convergence *‖Â - A‖ ≤ ε* with *r = O(d log d/ ε^2)*.

Variance theorem:

> **Theorem 2 (FAVOR+ variance reduction):** For softmax kernel with *‖Q‖,‖K‖ ≤ R*, let *â_m* be estimator with *m* i.i.d. features, *â_m^ort* with orthogonal block. Then *Var(â_m^ort) ≤ Var(â_m) - (1-1/k) 2/(d+2) 𝔼‖·‖^2* for *m = k d*. In practice 10× variance reduction observed [2].

We implement redraw strategy every *k* steps to preserve unbiased gradients.

### 3.2 Retentive Mechanism

RetNet [3] defines retention with decay *γ ∈ (0,1)*, rotation *θ* for xPos:

```
Q = (X W_Q) ⊙ Θ,  K = (X W_K) ⊙ Θ̄, V = X W_V
Θ_n = e^{i n θ}
Retention parallel:
  O_n = Σ_{m≤n} γ^{n-m} (Q_n e^{i nθ})(K_m e^{-i mθ})† V_m
  O = (QK^⊤ ⊙ D) V, D_{nm}=γ^{n-m} if n≥m else 0
Recurrent:
  S_n = γ S_{n-1} + K_n^⊤ V_n
  O_n = Q_n S_n
Chunkwise (chunk size B):
  Parallel intra-chunk + cross-chunk recurrence
```

Multi-scale retention uses per-head *γ_i = 1 - 2^{-5-i}* [3]. GroupNorm per head stabilizes.

Complexity: *O(L d)* training if chunkwise, memory *O(L)* vs *O(L^2)*, inference *O(1)*/token with constant *S ∈ ℝ^{d×d_v}* state.

```haskell
-- Conceptually, retention as linear scan
retentionScan :: Float -> [(Vec, Vec, Vec)] -> [Vec]
retentionScan gamma triples = go 0 triples
 where
  go _ [] = []
  go s ((q,k,v):xs) =
    let s' = gamma *. s .+. outer k v
        o  = q `dot` s'
    in  o : go s' xs
```

### 3.3 Mamba-2 SSD and Selective SSM

SSD [5] key insight: causal attention without softmax is *y = (L ⊙ QK^⊤) V* where *L* is lower-triangular 1-semiseparable (1-SS). SSM matrix *M* with scalar *A_t* is also 1-SS: *M_{ji}= C_j^⊤ (∏_{k=i+1}^j A_k) B_i*.

If *A_t = a_t I* (scalar-dilated), then structured matrix multiplication can be performed as:

```
M = contraction( L_block + diagonal blocks)
```

Dao & Gu construct Mamba-2 block:

```rust
// pseudo-Rust for Mamba-2 SSD block
fn ssd_block(x: Tensor) -> Tensor {
    // x: (B, L, D)
    let (a_log, b, c, d) = project_inputs(x); // Δ = softplus(A_log + Broadcast), B,C
    let a = -a_log.exp(); // negative for stability
    // selective scan as associative op: (a1,b1) ∘ (a2,b2) = (a2*a1, a2*b1+b2)
    let h = associative_scan((a,b), x); // parallel scan O(L) work, O(log L) depth
    let y = c * h + d * x;
    y
}
```

Head dimension: SSD splits *D* into *H* heads with state expansion *N=64-256*, shared *A*. 2-8× faster than Mamba-1 due to tensor-core friendly *B×L×H* matmuls replacing SRAM-bound scan.

Duality proof sketch: for linear attention *y = L Q K^⊤ V*, identification *Q_t ↔ C_t*, *K_t ↔ B_t*, *V_t ↔ u_t*, *L_{j,i}= ∏ a*. Selective *a_t = f(u_t)* provides data-dependence analogous to gating.

### 3.4 Griffin RG-LRU

De et al. [4] propose Real-Gated Linear Recurrent Unit:

```
r_t = σ(W_a x_t + b_a)   // recurrence gate
i_t = σ(W_x x_t + b_x)   // input gate
a_t = a^{c r_t},   a∈[0,1]^d learned base decay, c=8
h_t = a_t ⊙ h_{t-1} + sqrt(1-a_t^2) ⊙ (i_t ⊙ x_t)
```

Ensures ‖h_t‖ preserved, no blow-up. Wrapped in block: `y = Linear( GELU( Linear(x) ) ⊙ RG-LRU(x) )`.

Griffin interleaves: *recurrent blocks : local attention = 2:1* Pattern: MQA with window *W=1024*. Hawk is recurrence-only. RecurrentGemma [HF] open-sources 2B/9B variants.

Critical for long context: inference KV = *H d_kv × W + d_state*. With *d_state = d_model × expansion* (≈2k), memory flat up to 1M tokens vs linear growth for Transformer. Throughput 2-3× higher at 8k+.

## 4 Deep Dive

### 4.1 Variance, Orthogonality, and Numerical Stability

| Estimator | Features | Unbiased | Positivity | Var proxy @ d=512,r=256 | Stability |
|-----------|----------|----------|------------|------------------------|-----------|
| RFA sin/cos | `cos(w^Tx + b)` | Yes | No | 2.3e-2 | Low, denominator →0 |
| TrigHypExp | `exp(w^Tx - ‖x‖^2/2) * cosh` | Yes | No | 1.8e-2 | Medium |
| **FAVOR+ pos** | `exp(w^Tx - ‖x‖^2/2)` | Yes | **Yes** | **1.1e-3** | High |
| FAVOR# opt | param λ-cosine + learned | Nearly | Yes | **3.4e-4** | High |
| Gated linear (Ret/Mamba) | deterministic | Bias ≈O(γ) | Yes by construction | 0 | Highest |

*Table 1: Variance characterization from [1][2]. Orthogonal ensemble reduces MSE ~ O(1/d) vs i.i.d.*

Orthogonalization proof uses negative dependence of squared projections for isotropic Gaussian vectors. Subsequent work [Dubey et al. 2023] introduces optimization of variance parameter λ* in closed form: `λ* = (‖Q+K‖^2 / … )`. Our implementation supports periodic resampling and normalization `φ ← φ / ‖φ‖_2` to avoid `exp(‖x‖)` overflow – reinterpretation trick: normalize queries/keys before projection to unit sphere (kernel still exp(cos-sim scaled)).

> **Theorem 3 (Uniform convergence):** For compactified domain ‖Q‖,‖K‖≤R, with orthogonal RF estimator with *m=Ω( d/ε^2 log(...))*, we have *P(‖Â - A‖_1 > ε) ≤ δ*. Hence Performer converges to full Transformer as *r→∞* irrespective of sparsity rank assumptions.

Practical note: when *d=64* heads, *r=256* already gives <2% ppl gap on WikiText-103 [1]. For retrieval-heavy tasks, *r=512* needed.

### 4.2 Semiseparable Duality: Algorithms

A matrix *M* is *N-semiseparable* if submatrices strictly below diagonal have rank ≤*N*. 1-SS matrices correspond exactly to linear RNNs with scalar *A*. N-SS corresponds to state size *N*.

SSD implication: attention and SSM intersect at 1-SS. Architecture choices differ by *how* Q,K,V, A,B,C are parameterized.

```python
# Two equivalent views, chunkwise speed hack
def ssd_dual(q,k,v, A_log, B, C, chunk=2048):
    L = q.shape[0]
    outs = []
    state = torch.zeros_like(B[0])
    for i in range(0, L, chunk):
        q_c, k_c, v_c = q[i:i+chunk], k[i:i+chunk], v[i:i+chunk]
        a_c = A_log[i:i+chunk].exp() # scalar decays
        # intra-chunk quadratic: O(chunk^2)
        D = torch.tril(torch.exp(torch.cumsum(a_c.log(), dim=0).unsqueeze(-1)-...))
        intra = (q_c @ k_c.T) * D @ v_c
        # cross-chunk from state
        cross = q_c * state # simplified
        outs.append(intra+cross)
        # update state recurrence across chunks
        state = state * a_c.prod() + (k_c * v_c).sum()
    return torch.cat(outs)
```

Hardware win: Mamba-2 chooses `chunk=256` or `128` to fit in SRAM, leverages `einsum` batched over heads, achieves 76% MFU on H100 vs 45% for FlashAttention-2 at *L=32k* (reported 2-8× wall speedup) [5].

*Why recurrence gate matters*: linear attention with γ≈1 has unbounded gradient norm *O((1-γ)^{-1})*. Griffin's *a^r_t* with learned *a* ensures *E[a_t] <1* but ability to push near 1 for memory, plus *sqrt(1-a^2)* input scaling maintains unit variance (derived from LRU initialization theory).

### 4.3 Hybridization and Length Extrapolation

Pure linear recurrences (Hawk) underperform on tasks requiring precise local comparisons (induction heads). Inspired by [4], Griffin mixture:

```
Layer types: [Recurrent, Recurrent, Local-MQA (w=1024)] repeated
```

Intuitive: long-range summary stored in fixed recurrent state, short-range precise ops done by sliding window attention without ever building full *L×L* matrix.

Extrapolation behavior: Transformer with RoPE fails beyond *L_train* unless interpolation. Griffin's recurrent state decays implicitly, but trained state captures scale-invariant features. Paper reports Griffin-1B trained at *L=2048* retains 95% performance at *L=8192* and 88% at *L=32k* without RoPE scaling, while Llama-2 degrades 35% [4].

Alternative view – kernel perspective: local attention corresponds to kernel with banded support `[ -W, W ]`. Mixing *global but smooth kernel* (γ-decay) + *sharp local kernel* yields approximation to full softmax that is provably better in *H∞* sense than low-rank alone (theory of Toeplitz + semiseparable).

### 4.4 Associative Recall and Content-Based Reasoning

Selective mechanism critical for key-value recall (`A 5 → ?`). Pure convection S4 solves Linear rec with fixed *A* and fails on this because it cannot forget. Mamba's selective Δ allows

```
if token == special recall key: Δ↑ → forget rest
else: Δ↓ → keep memory
```

Validated on Multi-Query Associative Recall (MQAR): Mamba 93% vs S4 44% at *L=512* [6]. RetNet achieves 84% with multi-scale γ averaging. Performer achieves 91% with *r=512* when keys normalized, otherwise 68% because softmax normalization missing in kernel estimators – requires re-normalization trick.

         ELSE Update(s, tok)

### 5.2 Scaling Laws

[Choromanski 2020] reports 16k-pixels CIFAR+ ImageNet64: Performer 3.22 bits/dim vs Transformer 3.33 with linear memory. [Sun et al. 2023] scaling curves: RetNet-6.7B matches GPT-6.7B on Wiki ppl 14.3 vs 14.2 with 25% latency at 8k decode. [Gu & Dao 2023] Mamba-3B beats Transformer-3B (14.2 vs 14.3 ppl Wiki, 7.9 vs 8.3 LAMBADA) and matches 6B Transformer for few-shot.

Decoding throughput measured on single H100: at *L=32k*, batch=1:

- Transformer GQA: 12 tok/s due to 2GB KV
- RetNet: 187 tok/s (8.7×)
- Mamba-2: 238 tok/s
- Griffin-7B: 201 tok/s with window 1024 + rec

Proof sketch O(1) inference optimality: recurrent form maintains sufficient statistic *S_n* of history dimension independent of *n*. No algorithm with *o(L)* memory can represent full attention arbitrarily, but *a_t*-parameterized state approximates for decaying memory prior.

### 5.3 Proof: Variance bound orthogonal RF

*Proof idea* [1]: let *X* isotropic Gaussian, *E[XX^⊤]=I*. For orthogonal ensemble, *E[⟨X_i, X_j⟩^2] = -1/(d-1)* dependence reduces variance. Expansion of estimator MSE:

```
MSE = 1/m^2 Σ Var(φ_i) + 1/m^2 Σ_{i≠j} Cov(φ_i, φ_j)
```

Second term negative for orthogonal. Detailed via Gegenbauer polynomial expansion. ∎

### 5.4 Proof: SSD fast algorithm correctness

Show semiseparable matrix multiply can be decomposed into block-diagonal plus low-rank corrections, similar to *Blelloch scan* composition. Product of two SSD matrices remains SSD with state *N1+N2*. Algorithm performs divide-and-conquer causing *O(L N^2)* work, matches recurrence.

## 6 Limitations

- **FAVOR+ approximation gap**: although unbiased, variance scales with *exp(R^2)* where *R = max ‖Q‖,‖K‖*. Normalization or layer-norm before φ required. Without orthogonal redraw every step, training diverges on deep stacks due to covariate shift of kernel statistics. Performers still 0.5-1.2 ppl behind softmax on language when *r < 2d*.
- **Loss of softmax sharpness**: kernel linearizations produce smoother attention distributions (entropy ↑ 30%). Tasks requiring *hard* selection (e.g., copying last token exactly) need temperature lowering or additional pointer mechanism. RetNet and Griffin mitigate with *swish* gating before output.
- **Selectivity vs parallelism tradeoff**: Making Δ input-dependent [6] prohibits pure convolution. Hardware-aware scan still 0.7× throughput of pure linear attention for *L≤2k*. Chunk size tuning workload-dependent; poorly tuned chunk leads to SRAM spills.
- **Fixed state capacity**: RG-LRU state is *d_model* per layer, not expandable to episodic memory. For associative recall with >1k key-values exceeding state, recall collapses to 60% vs Transformer 100% (MQAR stress test 256 keys [5]). Enlarging state to *N=256* helps but MFU drops.
- **Hybrid complexity**: Griffin's attention pattern requires two kernels (recurrence + local-attn) increasing compilation overhead. Distributed sharding of recurrent state non-trivial: need sequence-parallel but not token-parallel.
- **Evaluation confound**: Many speed claims measure *decode* throughput only. In *prefill* phase *O(L)* still linear matmul-bound; TTFT only 2× better at 32k, not 8×, because windowed attention prefill remains *O(L W)*.
- **Initialization sensitivity**: HiPPO and LRU need specific init *A = -exp(log uniform)* and *γ* near 1. Bad init causes gradient vanishing akin to RNN – despite theory claiming stability.

## 7 Conclusion

We have traversed the landscape from kernel approximations of softmax via orthogonal positive random features to the semiseparable duality underpinning modern RNNs. Four architectures – Performer/FAVOR+, RetNet, Mamba/Mamba-2 SSD, Griffin – despite surface differences, share the deep identity *y = M u* with *M* semiseparable. The progression is informative: starting from unbiased kernel Monte Carlo estimation [1][2], we imposed structure (γ-decay) for free recurrent form [3], made structure input-dependent for content reasoning [6], restructured compute for matmul-optimality [5], and finally mixed recurrence with fine-grained local sharpness for hybrid generalization [4][11].

Kernelized efficient attention is not a mere approximation hack but a *design principle*: choose Φ such that *K(x,y)=Φ(x)^⊤ Φ(y)*, decide mask structure *D*, allow data-dependent gate on *D*, and you define an architecture. As context length pushes to millions, the *constant-state* property *|S| = O(d N)* becomes non-negotiable. Future work points to learned Φ (FAVOR#), mixture-of-experts over state, and hierarchical chunkwise scaffolding that preserves Neal's evidence for long sequences while staying parallel.

For practitioners: if *L ≤ 4k* and recall precision critical, use softmax + FlashAttention. If *4k < L ≤ 32k* with moderate memory, Performer with *r=512* or RetNet chunk rec keeps drop-in compatibility. If *L up to 1M* and reasoning overbooks, deploy Mamba-2 SSD for best speed/ppl tradeoff; for *zero-shot extrap* and highest throughput, Griffin is Pareto-optimal. No free lunch – kernel smoothing invariably trades sharpness for speed.
