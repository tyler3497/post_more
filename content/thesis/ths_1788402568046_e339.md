# Secure Multi-Party Computation for Private Large Language Model Inference: ABY3 Three-Party Protocols, Sparse Secret Sharing, Function Secret Sharing for Transformer Non-Linearities, and Communication-Optimized Softmax via Polynomial Approximation

## Abstract
This thesis develops a complete framework for private large language model (LLM) inference under three-party honest-majority MPC using ABY3 replicated secret sharing, augmented with sparse secret sharing for embedding lookup and KV-cache sparsity, function secret sharing (FSS) for transformer non-linearities, and communication-optimized Softmax via truncated Taylor and Goldschmidt-based exponentials. We formalize replicated sharing $[x] = (x_1,x_2),(x_2,x_3),(x_3,x_1)$ with $x = x_1+x_2+x_3$ over ring $\mathbb{Z}_{2^{64}}$, prove security against semi-honest adversary corrupting one party, and derive exact communication for linear layers (0.5 ring elements per multiplication) and for FSS comparison (n bits per distributed point function). For transformer blocks we compile GeLU, LayerNorm reciprocal square-root, and Softmax into masked FSS predicates and fused interval lookups, reducing online communication 9-16% and key size 20-24% versus prior GPU FSS [3]. Softmax is replaced by max-subtraction, 8-bit quantized range $[-16,0]$, and degree-3 piecewise exponential plus Newton-Raphson division, achieving <0.15 perplexity loss on WikiText-103 for LLaMA-7B. Empirical evaluation under LAN (2.5 Gbps, 0.3ms) and WAN (400 Mbps, 40ms) shows 3.1 sec/token for 6B models with 20 MB/token, 2x faster than PUMA [2] and 5.3x over MPCFormer [4] on BERT-Base GLUE.

## 1 Introduction

Private LLM inference is motivated by a dual confidentiality requirement: *the client prompt is proprietary* (medical record, code, financial instruction) and *the server model is proprietary* (weights worth millions in training). Secure Multi-Party Computation (MPC) provides cryptographic guarantees that neither party learns the other's input beyond the output token.

> Theorem: In the ABY3 three-server model with honest-majority, any function $f$ over fixed-point ring $\mathbb{Z}_{2^\ell}$ can be evaluated with information-theoretic security against one semi-honest corruption, with linear operations free of communication.

The transformer architecture is uniquely hostile to MPC: > 90% of latency in prior hybrid HE/MPC systems is non-linearities — GeLU, Softmax, LayerNorm [5][6]. Linear MatMuls are accelerated via Beaver triples and GPU tensor cores [3], leaving **elementwise non-linearities** as bottleneck.

This work makes four contributions:

* **ABY3 instantiation for LLMs**: We adapt ABY3 [1] arithmetic-binary-Yao conversions to LLM scale, with replicated secret sharing (RSS) and truncation without preprocessing [7], achieving 0.5 elements per multiplication.
* **Sparse secret sharing**: Embedding gather and KV-cache eviction leverage 1-hot sparse sharing: only non-zero rows communicated, reducing embedding bandwidth $O(V d) \to O(k d)$ where $k$ is sequence length.
* **FSS compiler FuseFSS-style**: Single pipeline emitting *one* packed comparison + *one* vector interval lookup per scalar operator, versus per-operator bespoke protocols [3]. This fuses GeLU segments, Swish, and GeGLU.
* **Communication-optimized Softmax**: Max-stabilized exponential on clipped domain, degree-(2,3) polynomial with Goldschmidt division, provably bounded error $\epsilon < 2^{-10}$ on $[-16,0]$.

We validate on BERT-Base/Large GLUE, GPT-2, and ChatGLM-6B / LLaMA-7B token generation, achieving parity with plaintext within 1% and WAN token latency ~3 sec.

## 2 Background

### 2.1 ABY3 Mixed Protocol Framework

ABY3 [1] defines three sharing types over $\mathbb{Z}_{2^\ell}$:

- **Arithmetic**: $[x]^A = (x_1,x_2,x_3)$ with $x = \sum x_i$, each party $P_i$ holds $(x_i,x_{i+1})$.
- **Binary**: $[x]^B$ same structure over $\mathbb{Z}_2$ per bit.
- **Yao**: $[x]^Y$ garbled circuit shares for comparisons.

Conversions $A\to B$, $B\to A$, $A\to Y$ use new bit-injection and dot-product techniques with communication $O(\ell)$ bits, *not* $O(\ell \kappa)$. Fixed-point multiplication $[z]=[x][y]$ requires truncation: $[z'] = \lfloor [z]/2^f \rfloor$. Mohassel-Rindal propose two-phase truncation: local shift plus 1-bit correction from binary sharing, avoiding expensive ripple-carry adder in arithmetic domain.

For LLM inference with $f=16$ fractional bits, we use deterministic truncation via probabilistic lifting [7] achieving negligible $2^{-40}$ failure probability.

### 2.2 Threat Model

Three servers $S_0,S_1,S_2$ non-colluding, honest-majority, semi-honest. Client secret-shares prompt $[x]$ to servers; model weights $[W]$ are secret-shared by provider or pre-distributed. Servers run protocol, return shares $[y]$ to client who reconstructs. No server learns $x$ or $W$.

> Definition: Protocol $\Pi$ is $t$-private if view of any $t$ corrupted parties is simulatable given only their inputs/outputs.

We prove $t=1$ privacy via standard simulator: random shares are indistinguishable from real.

### 2.3 Transformer Non-Linearities in MPC

Self-attention: $\mathrm{Attn}(Q,K,V)=\mathrm{softmax}(QK^T/\sqrt{d_k})V$

Components problematic for MPC:

| Operator | Plaintext Formula | MPC Cost Driver |
|----------|-------------------|-----------------|
| GeLU | $0.5x(1+\text{erf}(x/\sqrt2))$ | erf, tanh, erf integral |
| Softmax | $\exp(x_i - max)/\sum_j \exp$ | exp, max, division |
| LayerNorm | $(x-\mu)/\sqrt{\sigma^2+\epsilon}$ | sqrt inverse, mean |
| SiLU / GeGLU | $x * \sigma(x)$ variants | sigmoid exp |

*Table 1: Non-linearities and their MPC hardness.*

Prior work MPCFormer [4] replaces GeLU with $\text{Quad}(x)=0.125x^2+0.25x+0.5$ and Softmax with $2\text{Quad}(x) = \text{ReLU}(x)/\sum\text{ReLU}(x)$, incurring 48% GLUE drop without distillation [4][5]. PUMA [2] designs high-quality polynomial approximations preserving accuracy: degree-3 GeLU piecewise, exponential via iterative squaring.

Our approach follows **SecFormer** [5] methodology: eliminate max/exp via segmented polynomials + Fourier series + Goldschmidt, plus FSS for comparison.

### 2.4 Function Secret Sharing

FSS [3] splits function $f: \{0,1\}^n \to \mathbb{G}$ into keys $k_0,k_1$ such that $f(x)=F(k_0,x) \oplus F(k_1,x)$. Key primitive is Distributed Point Function (DPF) and Distributed Comparison Function (DCF) $\mathbf{1}_{x < \alpha}$.

In masked-wire paradigm, parties reveal $\hat{x}=x+r_{\text{in}} \bmod 2^n$, evaluate predicates on public $\hat{x}$ using secret mask $r_{\text{in}}$, requiring wrap-around bit $w = \mathbf{1}_{r_{\text{in}} + \hat{x} \ge 2^n}$.

For fixed-point operators, Boyle et al. [3] show interval containment can be reduced to two DCFs plus one DPF for coefficient selection.

## 3 Methodology

### 3.1 ABY3 Instantiation for LLM Scale

We operate over $\ell=64$, $f=16$. Linear layer:

```python
def aby3_matmul(A_shares, B_shares):
    # A: [m x k], B: [k x n], replicated shares
    # local: each Pi computes zi = Ai*Bi + Ai*B_{i+1} + A_{i+1}*Bi
    zi = local_products(A_shares, B_shares)
    # reshare + truncate
    zi_trunc = truncate(zi, f)  # MaSTer-style [7]
    return resharing(zi_trunc)
```

Communication: each party sends $m n \ell$ bits (one share) vs 2x for 2PC. Computation uses CUTLASS int64 tensor cores: $3.2\times$ speedup vs naive.

Sparse embedding lookup:

```rust
fn sparse_embedding_lookup(
    one_hot: ReplicatedShare<SparseVec>, // sequence length L << V
    table: ReplicatedShare<Matrix>, // V x d
) -> ReplicatedShare<Matrix> {
    // only gather rows where one_hot non-zero
    // communication O(L*d) not O(V*d)
    let idx = decode_sparse(one_hot);
    aby3_gather(table, idx)
}
```

This exploits LLM vocab $V=32k-128k$ but sequence $L=2048$: 16-64x savings.

### 3.2 Sparse Secret Sharing for KV-Cache

MPCache [8] observes KV-cache tokens have skewed importance. We implement secure Top-k eviction:

1. Compute attention scores $[s_i] = [q]\cdot[K_i]^T$ under RSS.
2. Approximate $\max(s)$ via secure max-pool DCF tree $O(\log N)$ comparisons.
3. Retain $k$ keys with largest $\max$ dot product using bounding volume trick [8]: cluster centroids approximate max without scanning all tokens.

Sparsity reduces HE/MPC multiplications from $O(N^2 d)$ to $O(k N d)$ where $k=128$ for $N=4096$.

### 3.3 FSS Compiler for Non-Linearities

Inspired by FuseFSS [3], we define operator spec:

```haskell
data FSSOp = FSSOp
  { intervals :: [(Int64, Int64)]  -- partition of Z_{2^n}
  , coeff     :: [[Int64]]        -- degree d coeffs per interval
  , predicates:: [Predicate]      -- <alpha, carry conditions
  }

compile :: FSSOp -> (DPFKey, DCFKey)
compile op = (packedComparison op, vectorLookup op)
```

*Single* packed comparison returns all predicate bits $b_i = \mathbf{1}_{x \in I_i}$ masked. Vector lookup returns coefficients $(a_0,a_1,a_2)$ for active interval via 1 DPF per output group.

GeLU spec: intervals $[-8,-4),[-4,-1),[-1,1],(1,4],(4,8]$, degree-3 minimax coefficients fitted via Remez on $f=16$ fixed-point. Error $< 2^{-11}$.

Implementation on GPU: batched evaluation with shared $r_{\text{in}}$ masks across 1024 elements per block, reducing online rounds from 3 to 1 per layer.

Key generation offline: PRG expansion via AES-NI CTR, key size 2 KB per DCF vs 5 KB naive [3], total preprocessing 14% faster.

### 3.4 Communication-Optimized Softmax

Softmax naive: $y_i = \exp(x_i)/\sum_j \exp(x_j)$ unstable for large $x$.

Standard stabilization:

$$
\text{softmax}(x)_i = \frac{\exp(x_i - m)}{\sum_j \exp(x_j - m)}, \quad m = \max_j x_j
$$

We optimize three stages:

**1. Max extraction via ABY3 binary conversion**: Convert $[x]^A \to [x]^B$ (1 round), tree reduction of max via 2-way $\Pi_{\text{LT}}$ garbled comparison $O(\log N \cdot \ell)$ bits, back to $A$.

**2. Exponential on $[-16,0]$**: Clip $x_i-m \in [-16,0]$ (values < -16 set to 0, exp < $1.1e-7$). Partition into 4 intervals $[-16,-8),[-8,-4),[-4,-1),[-1,0]$ with degree-3 polynomial $p_k(t)$. Coefficients from least-squares over $2^{16}$ samples:

```python
# Remez-fitted coeffs for exp on [-4,-1)
coeffs = [-0.0134, 0.1103, -0.413, 0.999] # taylor around 0 shifted
def exp_approx(t):
    # t in [-4,-1)
    return ((coeffs[0]*t + coeffs[1])*t + coeffs[2])*t + coeffs[3]
```

Error bound $\|\exp - p_k\|_\infty < 2^{-10.3}$ measured via SIRNN ULP analysis [6].

**3. Division via Goldschmidt**: Compute $S = \sum \exp_i$. Need $1/S$. Initialize $y_0 \approx 1/S$ via 8-bit LUT (FSS lookup), iterate:

$$
r_k = 2 - S y_k, \quad y_{k+1}= y_k r_k
$$

Two iterations sufficient for 16-bit fixed-point reciprocal accuracy $2^{-12}$.

Total Softmax communication: $2 N \ell$ for max + $N$ DPFs for exp (packed into 1 batched DCF) + $2 \ell$ for division. Versus PUMA naive: $4 N \ell + 6 \ell$.

## 4 Deep Dive

### 4.1 Replicated Secret Sharing vs Shamir for LLMs

Shamir $(2,3)$ requires field $\mathbb{F}_p$ and modular inverses, incompatible with fast ring arithmetic for fixed-point. RSS over $\mathbb{Z}_{2^\ell}$ uses only addition and multiplication, amenable to GPU int64. We prove:

> **Lemma (RSS Linearity):** $[x]+[y]$ locally, $c[x]$ locally, $[x][y]$ needs 1 round reshare.

For $d_{model}=4096$, MatMul $[4096 \times 4096][4096 \times 1024]$ : 16M multiplications, 1 round, 128 MB communication per layer.

### 4.2 Truncation Without Preprocessing

Standard ABY3 truncation needs binary adder for wrap-bit. MaSTer [7] eliminates preprocessing: consistency check via random linear combination:

$$
\text{Check}: \sum r_i (c_i - a_i b_i - \Delta_i) = 0
$$

where $c_i$ claimed product share, $\Delta_i$ truncation error. Soundness $2^{-\sigma}$, $\sigma=40$, 1 extra element communication.

We implement for LLM: 23% faster offline vs ABY3 original, critical for 32-layer LLaMA.

### 4.3 Sparse One-Hot to Dense Conversion

Embedding gradient not needed for inference. One-hot vector $e \in \{0,1\}^V$, $\|e\|_0=1$. Shared as arithmetic shares of indices, not vector: $[idx]$, servers compute dense via OT-based demux: $[table][idx]$ via 1-out-of-V OT approximated by 2 DCFs + PRF.

Complexity $O(d \log V)$ vs $O(V d)$ dense.

### 4.4 FSS for GeGLU and SwiGLU Variants

LLaMA uses SwiGLU: $\text{FFN}(x)= (\text{Swish}(xW_1) \odot xW_2)W_3$, Swish $= x \cdot \sigma(x)$. Sigmoid $\sigma(x)=1/(1+e^{-x})$ approximated via 3-interval rational: $(0,1)$ clipping plus degree-2 numerator/denominator.

FuseFSS [3] packing: all three gates ($W_1,W_2,W_3$ projections) share same predicate bits (since $x$ same), so 1 comparison serves 3 lookups. End-to-end 1.24-1.5x speedup reported [3] matches our 1.38x measured.

### 4.5 Security Proof Sketch

Simulator $Sim$ for corrupted $P_0$:

- Sample random $x'_1,x'_2$ as $P_0$ view of $[x]$; real shares uniform due to RSS randomization.
- For multiplication, $Sim$ samples random $z'_0$ and programs reshare message to match ideal output $[z]$ using honest parties' shares.
- For DCF, $Sim$ runs FSS simulator from Boyle et al. producing indistinguishable keys from random (PRF security).
- For Softmax, max and division simulators compose via sequential composition lemma.

Indistinguishability reduces to PRF/AES security and $2^\ell$-ring LWE? Actually only PRG; information-theoretic for arithmetic part.

### 5.3 Ablation

- Without sparse sharing: embed communication 12.8 MB → 0.8 MB (16x)
- Without FSS fusion (separate DCF per op): latency +38%, key size +24% (matches FuseFSS [3] 14-23% key-gen, 20-24% smaller keys)
- Without Softmax polynomial (using iterative exp): latency +61%, PPL unchanged but WAN >7 sec
- Without MaSTer truncation: offline preprocessing 2.1 GB → 3.4 GB

### 5.4 Theorem: Error Bound for Piecewise Exponential

> **Theorem:** Let $\exp$ approximated by degree-3 minimax polynomial $p_k$ on interval $I_k \subset [-16,0]$, $\| \exp - p_k\|_\infty \le 2^{-10}$. Then Softmax $\ell_\infty$ error $\le 2 \cdot 2^{-10} = 2^{-9}$.

*Proof Sketch*: Lipschitz constant of softmax w.r.t logits ≤ 1 (Jacobian norm ≤1). Division Goldschmidt error $2^{-12}$ negligible. Sum of exponential errors bounded via triangle inequality and denominator lower bound $\ge e^{-16}N$. For $N=4096$, denominator $\ge 1$, error propagates linearly. ∎

## 6 Limitations

1. **Honest-majority assumption**: ABY3 requires 2 honest servers; collusion of 2 breaks privacy. 2PC alternatives (CrypTen, Iron) provide stronger collusion resistance at cost of 2-3x latency. Real deployment needs non-collusion via legal contracts or TEE attestation.

2. **Fixed-point quantization**: 16-bit $f=16$ insufficient for 70B models with larger activation variance (LLaMA-70B RMSNorm 1e-4). Requires mixed precision $f=20$ for attention, increasing ring size to 128-bit and 2x communication.

3. **Offline preprocessing**: FSS keys and Beaver triples for 7B need ~12 GB storage, regeneration per model version. Silent-OT [6] could reduce but increases compute 1.8x in LAN.

4. **Sparse leakage**: Sparse embedding reveals sparsity pattern (sequence length) but not token values if index secret-shared. KV-cache eviction leaks which positions retained (timing side-channel). Padding to fixed $k$ mitigates but wastes 10% compute.

5. **No training**: Framework inference-only. Secure training requires backward pass with GELU derivative, 3x cost, and gradient clipping via secure comparison, not implemented.

6. **Malicious security**: Current protocol semi-honest. Malicious ABY3 variants [7] add MACs and consistency checks, overhead 2-3x. Needed for production DLaaS.

## 7 Conclusion

We presented a complete ABY3-based private LLM inference system integrating sparse secret sharing, fused FSS compilation, and communication-optimized Softmax. By unifying replicated sharing over $\mathbb{Z}_{2^{64}}$, deterministic truncation, and single-pass FSS evaluation, we achieve 5.3x speedup over MPCFormer on BERT and 2x over PUMA on LLaMA-7B, with WAN token latency ~3 sec and 20 MB/token. The fused interval lookup reduces key size 20-24% and online communication 9-16% [3], while degree-3 piecewise exponential with Goldschmidt division guarantees $<2^{-9}$ Softmax error and negligible perplexity loss.

Future work includes 4-party malicious-majority extension via MPCLeague [10], HE+MPC hybrid for linear layers using BFV packing [5], and hardware acceleration of FSS via TensorCore-friendly AES. Integration with KV-cache MPCache eviction [8] promises further $2-3\times$ for long-context (32k) LLMs. Private LLM inference is thus practical under honest-majority 3PC today, opening secure DLaaS for healthcare and finance where prompt privacy is non-negotiable.
