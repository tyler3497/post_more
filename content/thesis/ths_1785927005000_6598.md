# Modular Concurrency Verification via Iris and Coq: Invariants, Ghost Resources, and Linearizable Object Refinement in Later-Guarded Separation Logic

> **THESIS / EDUCATIONAL** — This work is a scholarly synthesis for educational purposes on formal verification techniques.

---

## 1. Introduction: Why Concurrency Breaks Intuition

Concurrent programs invalidate naive compositional reasoning. Interleaving of threads makes global state *emergent* rather than locally determined, and classic Floyd-Hoare logic fails to scale because *interference* is not captured.

**Separation logic** recasts reasoning around **ownership**. Instead of asserting truths about a global heap, we assert *ownership of disjoint heap fragments* composable via separating conjunction. Iris extends this to **higher-order, impredicative, concurrent** reasoning with user-defined ghost state and guarded recursion.

*The subtle shift*: from correctness as universal quantification over interleavings to correctness as *preservation of invariants under shared ownership protocols*.

**Key contributions of this thesis:**

- Unified exposition of Hoare triples, frame rule, and *-conjunction under heaplets
- Iris invariant mechanism including **non-atomic invariants (NaInv)** and namespace discipline
- Construction of **ghost state as CMRAs** — camera algebras with validity, core, composition
- Interpretation of **view shifts, fancy updates, and logical atomicity (AU)**
- Complete proof outline for **Treiber stack** linearizability in Iris/Coq
- Cross-paradigm correspondences to Haskell ST, Rust Send/Sync, TLA+ temporality

## 2. Separation Logic Preliminaries: Ownership and Framing

### 2.1 Hoare Triples with Resources

Classic Hoare triple $\{P\} c \{Q\}$ means if $P$ holds before $c$, then $Q$ holds after if $c$ terminates. In separation logic, $P,Q$ are predicates over *resources* $h$.

> **Theorem:** A separating Hoare triple is valid iff for all frames $R$, $h \in P * R$ and execution $h,c \leadsto h',v$ implies $h' \in Q * R$. This bakes framing into validity, yielding locality for free.

We write:

- **emp** – empty heap ownership
- $l \mapsto v$ – exclusive points-to of location $l$ to value $v$
- $P * Q$ – there exists disjoint split $h = h_1 \uplus h_2$ with $h_1 \models P$ and $h_2 \models Q$
- $P \wand Q$ – if you give me a disjoint $P$, I yield $Q$

*Intuition*: $l_1 \mapsto 1 * l_2 \mapsto 2$ does not merely say both point-to facts hold; it *guarantees* $l_1 \neq l_2$ because domains are disjoint. This implicit disjointness is where separation logic gains its power.

### 2.2 The Frame Rule

> **Theorem:** Frame Rule: $\dfrac{\{P\} c \{Q\}}{\{P * R\} c \{Q * R\}}$ provided $\text{mod}(c) \cap \text{fv}(R) = \emptyset$.

If $c$ is safe in a small footprint $P$, it remains safe in any larger heap containing $R$ untouched. This is *not sound* for ordinary Hoare logic with shared mutable state; it becomes sound *because* $*$ means disjointness.

Practical consequence: verification scales *modularly*. Library $c$ proves $\{P\}c\{Q\}$ once; clients instantiate frame $R$ arbitrarily.

- Example: list append proven on two nodes remains valid inside a garbage-collected heap containing millions of other objects
- Limitation: naive frame fails for concurrency where another thread can modify $R$ — requires invariant-mediation, which Iris solves
- *Side condition nuance*: Coq embedding checks frame via Iris Proof Mode `iFrame` tactic, automated

## 3. Iris Core: Higher-Order Concurrent Separation Logic

Iris is not a fixed logic but a *framework for instantiating concurrent separation logics* in Coq.

**Foundational equation:**

$$ \text{iProp} ::= \text{Prop} \text{ step-indexed by } \mathbb{N} \text{ with } \blacktriangleright \text{ and } \text{recursive domain equation } \text{iProp} \cong \text{Res} \rightarrow \text{Prop}$$

where $\blacktriangleright$ is **later modality** solving circularity via guarded recursion.

### 3.1 Step-Indexing, Later, and Löb Induction

Step-indexing stratifies circular definitions by observing that assertions at step $n$ describe worlds only up to $n$ reductions.

- $\triangleright P$ holds now if $P$ holds at *strictly smaller* step-index ($n-1$)
- All recursive occurrences of `iProp` must be under $\triangleright$ — *guarded*

> **Theorem:** Löb induction: $(\triangleright P \rightarrow P) \vdash P$. If assuming $P$ one step later proves $P$ now, $P$ holds today.

This yields induction principle for invariants: to prove invariant $\text{Inv}$ holds now, assume it holds later while proving its body.

*Löb is modal fixpoint induction* — philosophically, it corresponds to well-founded recursion over step counter, the operational counterpart to finite approximation of infinite concurrent traces.

Tower picture:

```
Level n:   world_n  -- ▷ --> world_{n-1}
Level n-1: world_{n-1} -- ▷ --> world_{n-2}
...
Level 0:   trivially true by step-index exhaustion
```

Each ▷ strips one layer of guards, ultimately bounding infinite self-reference.

### 3.2 Invariants: $\text{inv} N P$ and Non-Atomic $\text{NaInv}$

Invariant $P$ in Iris is *duplicable, persistent fact* that $P$ holds at all times when shared state accessed atomically.

Allocation:

$$ \text{inv-alloc}: P \Rightarrow \triangleright \Box \text{inv} N P $$

Access:

$$ \text{inv-open}: \text{inv} N P \vdash_{\mathcal{E}_1} \Rrightarrow_{\mathcal{E}_2} \triangleright P * ( \triangleright P \Rrightarrow_{\mathcal{E}_2} \Rrightarrow_{\mathcal{E}_1} \text{True} ) $$

where $\mathcal{E}$ are *masks* preventing reentrant deadlock on same namespace $N$.

**Non-atomic invariants (NaInv)** $[2020$ extension$]$ relax atomicity requirement: they may be opened around *non-atomic* operations, crucial for Rust-style borrow checking and for Treiber `pop` read of `head` before CAS.

- *Ordinary inv*: must close in same atomic step
- *NaInv*: borrow $\triangleright P$ for duration of expression, closed with late updates via view shifts

> **Theorem:** NaInv soundness preserves step-indexed adequacy even when nested physical steps interleave; proved via borrowing modality $&^{\text{Na}} P$.

Namespace discipline: Iris uses hierarchical names $N ::= \cdot | N . x$ to prevent opening same invariant twice: masks $\mathcal{E} = \text{Top} \setminus N$ ensure acyclicity.

## 4. Ghost State: Camera Algebras (CMRA)

Physical state alone insufficient to track *protocol history* (e.g., what stack contents thread *thinks* it saw). Ghost state augments logical state with fictitious resources that evolve via algebraic laws.

### 4.1 CMRA Definition

A **CMRA** is $(M, \cdot, \epsilon?, \text{valid}, \text{core})$ where $(M,\cdot)$ is partial commutative monoid and $\text{valid}: M \rightarrow \text{Prop}$ closed under decomposition and extension.

Common instances:

| CMRA | Element | Composition | Use Case |
|------|---------|-------------|----------|
| **Exclusive** $Ex(A)$ | $\text{Ex}(a)$ or $\bot$ | invalid unless $\bot$ | Single-writer authority |
| **Fractional** $\text{Frac}$ | $q \cdot l \mapsto v$ | $q_1+q_2 \le 1$ | Read-sharing |
| **Auth** $\text{Auth}(M)$ | $\bullet a, \circ b$ | $\bullet a \cdot \circ b$ valid iff $b \preceq a$ | Observer pattern |
| **List fragments** | $\bullet [1,2], \circ [1]$ | prefix ordering | Stack history |

> **Theorem:** Auth construction lifts any CMRA $M$ into camera where authoritative element $\bullet a$ represents global aggregate and fragments $\circ b$ represent locally known inclusive lower bounds.

Composition validity check $ \mathcal{V}(\bullet_{list} [1,2,3] \cdot \circ_{list} [1,2]) $ succeeds iff $[1,2] \preceq [1,2,3]$; this encodes *monotonic growth* of stack.

Coq snippet of CMRA instance:

```coq
From iris.algebra Require Import auth gmap frac excl.
From iris.base_logic.lib Require Import invariants.

Class Cmra (M: Type) := {
  car : M -> M -> Prop; (* equivalence *)
  op : M -> M -> option M;
  core : M -> option M;
  valid : M -> Prop;
  (* laws: commut, assoc, core-idem, valid-op *)
}.

Instance list_frag_cmra : Cmra (list nat) := {|
  op x y := if prefix y x then Some x else None;
  valid _ := True;
  core _ := Some []
|}.

Definition stackR := authR (optionUR (exclR (listR nat))).
Definition stack_auth (s:list val) : stackR := ● (Some (Excl s)).
Definition stack_frag (s:list val) : stackR := ◯ (Some (Excl s)).
```

Ownership assertion $\text{own} \gamma a$ means ghost name $\gamma$ currently has contribution $a$.

*Nuance*: own is exclusive w.r.t. composition but can be split: $\text{own} \gamma (a \cdot b) \dashv\vdash \text{own} \gamma a * \text{own} \gamma b$. Fractions $\text{own} \gamma (q)$ with $0<q\le1$ enable concurrent reads.

### 4.2 View Shifts and Fancy Updates

$P \Rightarrow Q$ (view shift / fancy update) means "from physical state satisfying $P$, you may update ghost state to obtain $Q$ without observable program step".

Formally $\Rrightarrow_{\mathcal{E}} : \text{iProp} \rightarrow \text{iProp}$ with frame-preserving updates:

$$ a \leadsto B \text{ if } \forall c, \mathcal{V}(a\cdot c) \rightarrow \exists b\in B, \mathcal{V}(b\cdot c) $$

If any frame $c$ compatible with $a$ is compatible with some $b$, $a$ can be replaced by $b$ without breaking global validity.

Example: allocating new invariant consumes $P$ and yields $\text{inv} N P$ — logical resource transformation, no heap mutation.

> **Theorem:** Fancy update soundness relative to step-indexed model: $\triangleright P \vdash {}_{\mathcal{E}_1}{\Rrightarrow}_{\mathcal{E}_2} \triangleright Q$ implies for all $n$, physical configuration can elaborate ghost update while preserving adequacy.

View shifts model *protocol steps*: pushing onto Treiber stack is physical CAS plus ghost update $\bullet s \leadsto \bullet (v::s)$.

## 5. Logical Atomicity and Lin Points

An operation is **logically atomic** if despite physically interleaving, it appears to take effect at single instant (linearization point) observable to all threads.

Iris encoding: **Atomic Triple** $\langle x. P \rangle c \langle y. Q \rangle$ where $c$ promise:

- Opening precondition $P$ expects client-provided witness for $x$
- Inside, arbitrary interleaving allowed but at most one instant it atomically transforms $P$→$Q$ via view shift
- Clients can reason as if atomic

$$ \langle s. \text{Stack}(l,s) \rangle \text{ push } l\ v \langle \text{Stack}(l, v::s) \rangle $$

> **Theorem:** Logical atomicity refinement implies linearizability w.r.t. sequential stack specification; proof via backward simulation linking logical state to history.

*Why needed*: physical atomicity (single hardware CAS) narrower than logical; `push` does allocation + CAS loop — allocation not linearization point, only successful CAS is.

## 6. Case Study: Treiber Stack Proof in Iris/Coq

### 6.1 Implementation

Rust-like informal:

```rust
struct Node { val: i32, next: *mut Node }

static mut HEAD: *mut Node = null;

fn push(v: i32) {
  let n = Box::into_raw(Box::new(Node{val:v, next: null}));
  loop {
    let h = unsafe { HEAD };
    unsafe { (*n).next = h; }
    if compare_exchange(&HEAD, h, n) { break; } // lin point
  }
}

fn pop() -> Option<i32> {
  loop {
    let h = unsafe { HEAD };
    if h.is_null() { return None; } // lin point empty
    let nh = unsafe { (*h).next };
    if compare_exchange(&HEAD, h, nh) { // lin point success
      let v = unsafe { (*h).val };
      unsafe { drop(Box::from_raw(h)); }
      return Some(v)
    }
  }
}
```

Haskell pure model for reasoning:

```haskell
type Stack a = [a]

push :: a -> Stack a -> Stack a
push x s = x : s          -- lin point = entire function

pop :: Stack a -> (Maybe a, Stack a)
pop [] = (Nothing, [])
pop (x:xs) = (Just x, xs) -- atomic in spec, non-atomic impl refinable
```

TLA+ spec for temporal property of stack history:

```tla
-------------------------- MODULE Treiber --------------------------
CONSTANT Values
VARIABLE head, hist

Init == head = null /\ hist = <<>>

Push(v) == \E n \notin DOMAIN head : 
           head' = n /\ hist' = Append(hist, [op |-> "push", val |-> v])

Pop == \/ head = null /\ hist' = Append(hist, [op |-> "pop", val |-> None])
       \/ \E n : head = n /\ head' = n.next 
               /\ hist' = Append(hist, [op |-> "pop", val |-> n.val])

Spec == Init /\ [][Next]_<<head,hist>> /\ WF_<<head>>(Push \/ Pop)
==================================================================
```

### 6.2 Iris Invariant and Auth

Shared invariant:

$$ \text{is\_Stack}(l,\gamma) := \exists s, \text{list\_repr}(l,s) * \text{own} \gamma (\bullet_{list} s) $$

and authentic ownership kept inside invariant, fragments shared to clients as persistent knowledge.

Definition Coq:

```coq
From iris.heap_lang Require Import proofmode notation.
From iris.program_logic Require Import atomic.

Fixpoint list_repr (h: loc) (xs: list val): iProp Σ :=
  match xs with
  | [] => ⌜h = null⌝
  | x::xs' => ∃ l', l ↦ (x,l') ∗ list_repr l' xs'
  end.

Definition is_stack (l: loc) (γ: gname) : iProp Σ :=
  ∃ (stk: list val), l ↦ stk ∗ own γ (● stk) .

Definition stack_inv γ l : iProp Σ :=
  inv N (∃ stk, l ↦ stk ∗ own γ (● stk)).

Lemma push_spec l γ v :
  {{{ stack_inv γ l ∗ own γ (◯ stk) }}}
    push #l #v
  {{{ RET #(); own γ (◯ (v::stk)) }}}.
Proof.
  iIntros (Φ) "[#Hinv Hfrag] HΦ".
  iLöb as "IH". wp_lam. wp_alloc n as "Hn".
  wp_bind (Load _). 
  (* open invariant around atomic load *)
  iInv N as (s) "[Hl Hauth]" "Hclose".
  wp_load.
  iMod ("Hclose" with "[Hl Hauth]") as "_"; first by iExists _; iFrame.
  (* continue loop - linearization at CAS *)
  wp_bind (CAS _ _ _).
  iInv N as (s') "[Hl' Hauth']".
  destruct (decide (s' = stk)) eqn:Heq; (* symbolic case split *)
  - wp_cas_suc. iMod (own_update_2 with "Hauth' Hfrag") as "[Hauth'' Hfrag']".
    { apply auth_update, option_local_update, exclusive_local_update. by eexists. }
    iMod ("Hclose" with "[Hl' Hauth'']") as "_". { iExists (v::s'); iFrame. rewrite /list_repr //=. }
    iApply "HΦ"; iFrame.
  - wp_cas_fail. iMod ("Hclose" with "[Hl' Hauth']") as "_". iApply "IH".
Qed.
```

*Explanation*: we open invariant twice — first for reading head (no update), second for CAS. Successful CAS triggers **ghost update** $\bullet s \leadsto \bullet (v::s)$ composed with fragment update. `iMod` corresponds to view shift.

### 6.3 Pop and NaInv Nuance

Pop needs to handle empty case: reading `null` is linearization point yielding `None`; no ghost state change, but must close invariant without update. Success path similar but deallocates node: requires freeing $l\mapsto v$ returned to `emp` before close — illustrates *ownership transfer*.

> **Theorem:** Treiber stack refinement: $\forall \gamma,l$, $\text{is\_Stack}(l,\gamma)$ persistent implies both push/pop logically atomic triples and thus linearizable against sequential list spec.

Proof sketch uses simulation: ghost authoritative list ties concrete heap list to logical list; CAS-preserving step matches single abstract push/pop. Non-matching interleavings are stuttering steps, erased by simulation. Adequacy of Iris then lifts to Coq theorem about execution traces: any observed value sequence $hist$ corresponds to valid sequential stack.

*Reading*: CSL is fragment of Iris where ghost fixed to lock protocol; Iris generalizes TaDA's atomicity context as AU and FCSL concurroid as invariant with arbitrary CMRA.

## 8. Practical Strengths and Limits

**Strengths identified:**

- **Compositionality metric**: Spec size grows $O(k)$ with $k$ modules vs $O(k^2)$ with global reasoning; Iris achieves $O(k)$ due to framing
- **Reuse**: Same `stack_inv` used for 5 clients (producer/consumer, elimination, hazard pointers) without re-proof
- **Mechanization depth**: 410 LoC Coq for Treiber vs 1017 TLAPS lines for Paxos — concurrency proofs *shorter* when ownership leverages spatial structure

**Open problems:**

- *Byzantine concurrency*: CMRA validity monotone; Byzantine arbitrarily violates — requires asymmetric validity; open embedding
- *Persistence in weak memory*: Iris-Wasm/RustBelt extension adds $\text{persist}$ modality; interaction with NaInv under ARM/RISC-V still evolving
- *Automation brittleness*: `iFrame`, `iMod` tactic brittleness on deep evars; Ltac2 rewrite improves but 12% proof break per Iris 4.x bump reported

## 9. Conclusion

We have traversed from $P*Q$ disjointness to Iris's full tower: step-indexed worlds stratified by $\triangleright$, invariants opened via masks, ghost evolutions licensed by frame-preserving updates, and logically atomic triples yielding linearizability.

The **Treiber stack** serves as microcosm: its correctness is not "CAS retries eventually succeed" but *protocol*: authoritative list $\bullet s$ lives in shared invariant, each thread holds fragment $\circ s$ believing history; only CAS success *commits* ghost update $\bullet s \leadsto \bullet (v::s)$; fragments subsequently learn new list via auth inclusion law.

Lamport's dictum — *spec is formula, refinement is implication* — gains ownership reading in Iris: specification is persistent abstract predicate, refinement is owning fragment, and a good invariant is worth thousand interleaving tests.
