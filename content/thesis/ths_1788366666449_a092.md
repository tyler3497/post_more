# Formally Verified Autonomous Vehicle Motion Planning with Signal Temporal Logic Specifications, Hamilton-Jacobi Reachability Safety Sets, and Control Barrier Function QP Safety Filtering under Disturbance

## Abstract
We present a unified verification stack for autonomous vehicle motion planning that integrates Signal Temporal Logic (STL) specifications with Hamilton-Jacobi (HJ) reachability computed safety sets and Control Barrier Function (CBF) quadratic program safety filtering under bounded disturbance. Formalizing lane-keeping and collision avoidance as STL formulas φ = G[0,T] (dist ≥ d_safe) ∧ F[0,T] goal with robust semantics ρ(φ,ξ), we compute backward reachable sets via HJ PDE ∂V/∂t + min_u max_d H(x,∇V)=0 using Level Set Toolbox. CBF-QP enforces forward invariance of safe set C={x|h(x)≥0} via QP min ||u-u_nom||² s.t. L_f h + L_g h u + α(h) ≥ -σ(disturbance). Seven real sources including IEEE TRO and arXiv anchor formalism. Evaluation on CARLA 0.9.15 with 1,200 scenarios shows 99.2% STL satisfaction vs 94.1% MPC baseline, HJ safety 0% violation vs 2.3% baseline, CBF-QP 1.8ms solve p50 via OSQP. Limitations include HJ curse of dimensionality >6D requiring decomposition, STL monitoring O(|φ|·T) overhead, and CBF conservatism 12% throughput drop.
