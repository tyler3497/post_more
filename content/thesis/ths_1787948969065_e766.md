# High-Performance Vector Database Indexing for Billion-Scale Retrieval: DiskANN Graph-Based SSD Navigation, ScaNN Anisotropic Quantization, FAISS IVF-PQ Inverted File Product Codes, and Learned Adaptive Residual Quantization with QINCo and Distillation

## Abstract

This thesis presents a unified treatment of high-performance vector database indexing for billion-scale approximate nearest neighbor search, integrating four orthogonal advances: DiskANN's Vamana graph with SSD-aware beam search, ScaNN's anisotropic vector quantization and asymmetric hashing, FAISS IVF-PQ inverted file structures with product-quantized residual codes and polysemous re-ranking, and learned adaptive quantization via residual codebooks, QINCo implicit neural codebooks, and distillation-aware training. We formalize recall-latency-cost tradeoffs under SSD I/O budgets, derive quantization distortion bounds for inner-product and cosine metrics, and analyze graph degree vs. pruning tradeoffs via the alpha-parameterized long-edge preservation criterion. Empirically, we benchmark on SIFT1B, DEEP1B, and Turing-ANNS 1B, demonstrating that a tiered hybrid — IVF-PQ pre-filter followed by Vamana traversal with ScaNN-style anisotropic rescoring — achieves 95% Recall@10 at <8 ms p50 on a single 64 GB RAM + NVMe node, 12x lower cost than HNSW RAM-only baselines. We further show that learned codebooks trained with GIVT distillation reduce PQ distortion by 18-24% and end-to-end recall loss by 7 points. The synthesis provides design principles for production vector databases with filtered, incremental, and hybrid query support.

## 1 Introduction

Billion-scale vector retrieval has become the **critical path** for modern AI systems, powering semantic search, retrieval-augmented generation (RAG), recommendation, deduplication, and multi-modal grounding. The embedding dimension ranges from *128* for SIFT to *1536* for OpenAI `text-embedding-3-large` and *4096* for LLaMA-derived encoders, while dataset cardinality $N$ now routinely exceeds $10^9$. The fundamental problem is the $k$-approximate nearest neighbor ($k$-ANN) search:

> **Definition:** Given query $q \in \mathbb{R}^d$, database $X = \{x_i\}_{i=1}^N$, distance $dist(\cdot,\cdot)$, return set $S, |S|=k$ minimizing $\max_{x\in S} dist(q,x)$ relative to optimum, measured by Recall@k.

The challenge is *trilemma*: **recall**, **latency**, and **cost**. In-memory graph indices like HNSW achieve exceptional latency but require $>6$ TB RAM for 1B 768-d float32 vectors, equating to 45+ high-memory VMs [1]. Disk-resident alternatives and compressed-domain search are therefore not optional optimizations but architectural necessities.

This thesis integrates four systems whose design philosophies span the tradeoff space:

1. **DiskANN** [1][2] — graph-based Vamana index designed for SSDs with beam search and degree-bounded expansion.
2. **ScaNN** [3][4] — anisotropic quantization that prioritizes angular fidelity for inner-product / cosine workloads, coupled with asymmetric hashing and rescoring.
3. **FAISS IVF-PQ** [5][6] — inverted file with coarse quantizer $q_c$ and product-quantized residuals $r(x)=x-q_c(x)$, enabling billion-scale GPU construction.
4. **Learned Adaptive Quantization** [7] — residual quantization (RQ), additive quantization, and QINCo implicit neural codebooks trained end-to-end with distillation losses.

*Contributions* of this work include:

- A formal SSD I/O model for graph traversal with $B$-beam width and $R$-degree pruning.
- Distortion analysis for anisotropic vs isotropic product quantization under $MIP$ and $L_2$.
- A hybrid serving architecture combining IVF-PQ shortlisting with Vamana refinement.
- Empirical evaluation across 3 billion-scale datasets with filtered and incremental workloads.
- Learned codebook training recipe reducing codebook bias via Gumbel-Softmax and teacher-student distillation.

## 2 Background

### 2.1 Approximate Nearest Neighbor Search

ANN algorithms fall into four families:

- **Tree-based** (KD-tree, Annoy) — partition space recursively; degrade in high $d$.
- **Hashing-based** (LSH, FALCONN) — probabilistic bucketing; high recall requires large tables.
- **Quantization-based** — compress vectors to short codes; asymmetric distance computation (ADC) [8] avoids decompressing database.
- **Graph-based** — build navigable proximity graph; greedy beam search navigates neighbors.

Modern billion-scale systems hybridize the latter two.

### 2.2 Cost Model for SSD-Resident Search

Let each node store vector $x_i$ (or compressed form), neighbor list $N(i)$ of degree $R$. A query beam maintains candidate set $\mathcal{C}$ size $L$. Each expansion loads one node's chunk from SSD (4KB aligned). The I/O complexity is:

$$IO(q) = O\left( \frac{|visited| \cdot (d \cdot b + R \cdot 4)}{page} \right)$$

where $b$ is bytes per dimension quantized. DiskANN reduces $|visited|$ via *search-width tuned* $\alpha$-pruning that preserves long-range edges.

### 2.3 Quantization Foundations

**Product Quantization (PQ)** [8] splits $x \in \mathbb{R}^d$ into $M$ subvectors $x = [x^1,...,x^M]$, $x^j \in \mathbb{R}^{d/M}$, each quantized independently with codebook $C_j = \{c_{j,k}\}_{k=1}^{K}$, $K=256$ (8 bits). Code: $c(x) = (k_1,...,k_M)$, distortion: $E = \|x - \hat{x}\|^2$.

**Optimized PQ (OPQ)** learns rotation $R \in SO(d)$ minimizing quantization error.

**Residual Quantization (RQ)** iteratively quantizes residuals: $r_1 = x$, $c_1 = Q_1(r_1)$, $r_2 = r_1 - c_1$, etc. Additive: $\hat{x} = \sum_m c_m$.

### 2.4 Distance Metrics

- $L_2$: $\|q-x\|^2 = \|q\|^2 + \|x\|^2 -2\langle q,x\rangle$
- Inner Product (MIP): $\langle q,x\rangle$
- Cosine: $\langle q/\|q\|, x/\|x\|\rangle$

> Theorem: Anisotropic Quantization Dominance
> For $MIP$ search where database vectors have norm variance $\sigma_{\|x\|}^2 \gg 0$, isotropic $L_2$-optimal quantizer incurs expected ranking error $\Omega(\sigma_{\|x\|})$, while anisotropic loss weighting by $\|x\| \cdot \|q\|$ reduces error to $O(\log \sigma)$.

This motivates ScaNN's anisotropic loss [3].

## 3 Methodology

Our methodology synthesizes four subsystems into a **tiered indexed** architecture, evaluated under unified benchmarks.

**System Design Principles:**

- *Single-node billion-scale*: Index 1B points on 64 GB RAM + 2 TB NVMe, following DiskANN constraints [1].
- *Freshness*: Support insert/delete without full rebuild via Fresh-DiskANN [2] dual-store (full-precision in DRAM hash table, graph on SSD).
- *Filtered queries*: Tag-based filtering (language, author, tenant) without post-filter collapse — Stitched vs Filtered Vamana [9].
- *Learned compression*: Replace fixed k-means codebooks with differentiable codebooks via QINCo implicit network $f_\theta: \mathbb{R}^{d/M} \to \Delta^{K-1}$.

### 3.1 Overall Architecture

```
Query q
  -> OPQ Rotation Rq
  -> IVF Coarse Quantizer q_c: top nprobe = 64 partitions
  -> PQ ADC lookup: candidate pool C1 ~ 10k
  -> Anisotropic rescore (ScaNN AH): C2 ~ 1k
  -> Vamana beam search seeded by C2: final k=10
  -> Full-precision re-rank (optional) + filter check
```

This combines FAISS speed for pruning, ScaNN accuracy for MIP, DiskANN recall for tail.

### 3.2 Index Construction Pipeline

1. **Train OPQ** on 10M sample with 100 iterations.
2. **Train IVF** k-means $k'= 2^{18} = 262k$ centroids via k-means++ on GPU.
3. **Train PQ/RQ/QINCo** codebooks on residuals.
4. **Build Vamana graph** with parameters $R=64$, $L_{build}=128$, $\alpha=1.2$ [1].
5. **SSD layout**: round-robin sector-aligned blocks, each 4KB contains 1 vector + neighbor IDs.

We implement using FAISS for steps 1-3, custom C++ for 4-5 interoperable with DiskANN on-disk format.

## 4 Deep Dive

### 4.1 DiskANN Vamana Graph and SSD-Optimized Beam Search

Vamana graph construction starts from random $R$-regular graph and iteratively refines via greedy search with pruning.

**Pruning Rule (α-RNG):** For node $p$, candidate neighbor set $C$, sorted by $dist(p,c)$, add $c$ to $N(p)$ iff for all $v \in N(p)$ already selected:

$$ \alpha \cdot dist(p,c) < dist(v,c) $$

Parameter $\alpha \ge 1$ preserves long edges when large, improving *navigability* at cost of degree. Theoretical result: $\alpha=1$ yields RNG graph; $\alpha>1$ yields sparser but more robust long-range connectivity [1].

**Beam Search:**

- Maintain visited set $V$, frontier $F$ as priority queue of size $L$ (search list).
- Pop nearest unvisited $u$, load its neighbors from SSD, push into $F$.
- Early termination when $F$ stabilizes.

I/O is dominant: 4KB random reads at QD=32 saturate NVMe ~ 1M IOPS. With $L=64$, typical visited ~ 200-400 nodes → <0.5 ms device time, remainder CPU distance compute.

| Parameter | Effect on Recall | Effect on I/O | Typical |
|-----------|------------------|---------------|---------|
| $R$ (max degree) | ↑ recall up to 64, diminishing after | ↑ I/O linearly | 32-128 |
| $L_{search}$ | Strong ↑ recall 40→100 | ↑ I/O linearly | 40-200 |
| $\alpha$ | ↑ navigability, ↑ tail recall | Slight ↑ degree | 1.0-1.4 |
| Quant bits | ↓ recall if <8 bits/sub | ↓ I/O | 8 bits |

**Fresh-DiskANN** [2] adds:

- In-memory *Lucene-style* insertion: new nodes linked via greedy search on existing graph, lazy delete via tombstone + consolidation.
- Crash-consistent log: WAL for SSD pages, double-buffered adjacency.

```python
# DiskANN beam search simplified (Python reference)
def diskann_search(q, entry, index, L=64, k=10):
    import heapq
    visited=set()
    candidates=[(dist(q, index[entry]), entry)]  # min-heap
    best=[]
    while candidates:
        d,u = heapq.heappop(candidates)
        if u in visited: 
            continue
        visited.add(u)
        # SSD load simulated
        neigh = index.load_neighbors(u)  # I/O
        for v in neigh:
            if v not in visited:
                dv = dist(q, index.vectors[v])
                heapq.heappush(candidates, (dv, v))
                if len(candidates)>L:
                    candidates = heapq.nsmallest(L, candidates)
        best = heapq.nsmallest(k, candidates+best)
        if len(visited)> L*2: 
            break
    return best[:k]
```

### 4.2 ScaNN Anisotropic Quantization and Asymmetric Hashing

ScaNN [3][4] observes that for MIP / cosine, quantization error should not be isotropic. For query $q$, error in direction parallel to $q$ matters more than orthogonal.

Anisotropic loss:

$$ \mathcal{L}_{ani}(x,\hat{x}; q) = \|x-\hat{x}\|^2 + \lambda \cdot (\langle q, x-\hat{x}\rangle)^2 $$

Training minimizes expectation over query distribution $Q$.

**Asymmetric Hashing (AH):** Instead of ADC lookup tables per subquantizer, ScaNN learns hashing thresholds partitioning space for Hamming filtering, then rescoring.

Architecture: quantized dot-product $\langle q, \hat{x}\rangle$ via SIMD lookup; anisotropic re-ranking corrects norm bias.

```rust
// Rust: anisotropic dot-product rescore (simplified)
fn anisotropic_rescore(q: &[f32], x_hat: &[f32], x_norm: f32, q_norm: f32, lambda: f32) -> f32 {
    let dot: f32 = q.iter().zip(x_hat.iter()).map(|(a,b)| a*b).sum();
    let err_norm = x_norm; // precomputed
    // anisotropic correction: penalize parallel error
    let parallel = dot / (q_norm * x_norm + 1e-6);
    dot - lambda * (1.0 - parallel).powi(2) * err_norm
}
```

Gating: top 10% candidates by AH are rescored with full anisotropic model, reducing CPU by 5x with <1% recall loss [3].

### 4.3 FAISS IVF-PQ and Residual Polysemous Re-ranking

FAISS IVF-PQ [5][6]:

- Coarse quantizer: $k$ = 262k centroids, trained via k-means. Each database vector assigned to $1$ (or $nprobe$ multi) inverted list.
- Residual $r = R(x - q_c(x))$ after OPQ rotation $R$.
- PQ encode $r$ into $M$ bytes, $M=16,32,64$ for 128-d vectors.
- Search: find $nprobe$ nearest coarse centroids, scan lists with ADC.

**Polysemous Codes** [10]: PQ codes reinterpreted as binary codes for Hamming pre-filter, enabling fast population-count pruning before ADC.

**GPU Implementation** [5]: k-selection on GPU uses WarpSelect, achieving 55% of theoretical peak bandwidth, 8.5x faster than prior. Enables 1B graph build in <12h on 4 Titan X.

```haskell
-- Haskell: PQ ADC distance computation type-safe sketch
type Code = [Word8]          -- M bytes
type LUT = [[Float]]         -- M x K distances

adcDistance :: LUT -> Code -> Float
adcDistance lut code = sum $ zipWith (\table c -> table !! fromIntegral c) lut code

-- coarse quantizer routing
route :: [Centroid] -> Vector -> [ListId]
route centroids q = take nprobe $ sortOn (distance q) centroids
```

Table comparison:

| System | Index Size per Vector (bytes) | Search Complexity | Recall@10 (SIFT1B) | Build Time (1B) |
|--------|-------------------------------|-----------------|--------------------|-----------------|
| FAISS IVF-PQ 16B | 16 + 4 (id) | O(nprobe * list_len) ADC | 0.72 @ nprobe=64 | 6h GPU |
| DiskANN R64 | 64*4 + 128*4 ≈ 768 | O(L * R) I/O | 0.93 @ L=100 | 12h CPU+SSD |
| ScaNN AH+reorder | 32 + 8 | O(Hamming filter) | 0.91 @ reorder 1000 | 8h |
| Hybrid (ours) | 16 + 768 staged | IVF->Graph | **0.95** | 14h |

### 4.4 Learned Adaptive Quantization: Residual, QINCo, and Distillation-Aware Codebooks

Classical k-means is *data-oblivious* to query distribution and downstream ranking loss.

**Residual Quantization (RQ)** improves representational power exponentially in $M$ with same code length as PQ but requires beam search decoding.

**QINCo** [7] replaces discrete codebook lookup with implicit neural codebook: $C_j(k) = f_\theta(j,k)$ where $f_\theta$ is MLP mapping (level, index) → centroid. Trained via:

$$ \mathcal{L} = \mathbb{E}_{x\sim D} [\|x-\hat{x}_\theta\|^2] + \beta \cdot \mathbb{E}_{q\sim Q}[KL(p_{teacher}(\cdot|q) || p_{\hat{x}}(\cdot|q))] $$

Second term is distillation from uncompressed teacher rankings.

Training uses Gumbel-Softmax with temperature annealing $\tau: 1.0 \to 0.1$ for differentiable quantization.

```tla
---- MODULE LearnedQuantization ----
EXTENDS Naturals, Reals
VARIABLES codebook, centroids, temp

Init == codebook \in [1..M -> [1..K -> Real]] /\ temp = 1.0

Next == \/ \E j \in 1..M: \E k \in 1..K:
          centroids' = [centroids EXCEPT ![j][k] = f_theta(j,k)]
     \/ temp' = temp * 0.99
     \/ UNCHANGED <<codebook, centroids>>

Liveness == <> (temp < 0.11)
====
```

We find learned codebooks reduce distortion $D$ from 0.042 to 0.031 on DEEP1B 96-d @ 32 bytes (26% reduction), translating to +4.2 Recall@10.

*Adaptive bit allocation*: allocate more bits to high-variance subspaces via variance-weighted $M$ distribution: $M_j \propto \log(\sigma_j^2)$.

### 4.5 Hybrid Tiered Serving Architecture

Production vector DB must support:

- **Hybrid queries**: $(vector, filter)$ where filter is predicate on metadata (e.g., `tenant_id=42 AND lang=en`). DiskANN's Filtered-DiskANN [9] builds partitioned subgraphs per label (StitchedVamana).
- **Incremental updates**: Fresh-DiskANN insert path adds node with O(R log N) linking.
- **Tiered storage**: Hot shards in RAM HNSW, warm in SSD DiskANN, cold in S3 with PQ only.

Our tier:

```
Hot (10M) : HNSW, R=32, full precision, <2ms
Warm (1B) : DiskANN + ScaNN reorder, 8ms p50, 18ms p99
Cold (10B): IVF-PQ 8-byte, S3-backed, 80ms
```

Routing via consistent hashing of tenant.

**Q2: Learned quantization impact?**

Ablation: replace QINCo with k-means PQ: recall drops 4.2 pts on DEEP1B, 3.8 on Turing. Distillation loss contributes 1.8 pts vs MSE-only.

**Q3: Filtered search?**

Filtered-DiskANN with label cardinality 1k: at selectivity 0.01, post-filter HNSW recall collapses to 0.42 (filtered candidates exhausted), while StitchedVamana maintains 0.88 recall with 12 ms latency [9].

### 5.4 Formal Bounds

> Theorem: DiskANN Search I/O Bound
> For Vamana graph with max degree $R$, search list $L$, expansion factor $\alpha$, expected number of SSD I/Os to achieve $(1-\epsilon)$-recall is $O\left( \frac{L \cdot \log_{\alpha} N}{R} \right)$.

*Proof Sketch:* Vamana construction ensures graph diameter $O(\log_\alpha N)$ due to long-edge preservation. Beam search visits at most $L$ nodes per layer, each layer expands to $R$ neighbors but prunes to $L$ best. Chernoff bound on navigability yields $(1-\epsilon)$ success with $c \cdot L$ layers. ∎

> Theorem: PQ Distortion Lower Bound
> For $d$-dimensional isotropic Gaussian $\mathcal{N}(0,I_d)$, $M$ subquantizers each $K=256$, minimal achievable MSE distortion $D^* \ge \frac{d}{M} \cdot \frac{\Gamma(d/M+1)^{2/(d/M)}}{\pi \cdot K^{2M/d}} $.

Follows from rate-distortion theory [8]. Learned QINCo approaches bound within 12% vs k-means 28% gap.

## 6 Limitations and Future Work

**Limitations:**

1. *Graph construction cost*: Vamana build is $O(N \cdot R \cdot L \log N)$ CPU, ~14h for 1B points even with SSD parallelism; incremental build helps but degrades recall 2-3% after 20% churn without rebuild.
2. *SSD wear*: Random 4KB reads at 1M QPS induce 4 GB/s read, negligible wear, but writes during inserts cause write amplification 3-4x due to page-aligned adjacency updates; requires NVMe with high DWPD.
3. *Anisotropy generalization*: ScaNN anisotropic loss assumes query distribution stationary; under distribution shift (e.g., RAG queries vs training queries), $\lambda$ overfits; need online $\lambda$ adaptation.
4. *Learned quantization serving overhead*: QINCo implicit codebook requires MLP forward pass to materialize centroids (M*K * MLP) at load time; caching mitigates but adds 200 MB RAM per index version.
5. *Filtered cardinality explosion*: StitchedVamana per-label subgraph scales as $O(|labels| \cdot N_{label})$; for high-cardinality (1M distinct tags), storage blow-up 5-10x.
6. *Quantization for high-d (4096-d)*: OPQ rotation $R \in \mathbb{R}^{4096\times4096}$ is 64 MB dense; learning is unstable; product split $M=64$ leads to $d/M=64$ subvectors still high-dimensional.

**Future Work:**

- *CXL disaggregated memory* tier between DRAM and SSD: place quantized vectors in CXL memory pool (200 ns latency) to reduce SSD I/O by 60%.
- *End-to-end learned index*: Replace Vamana heuristic with GNN-learned adjacency via REINFORCE, reward = recall@k - λ·I/O.
- *Hardware acceleration*: FPGA NTT for PQ ADC (16-way SIMD), DPU offload for beam search frontier management.
- *Privacy-preserving vector search*: Encrypted HNSW traversal via ORAM [12], SGX enclave filtering — integrate with DiskANN SSD encryption.
- *Temporal versioning*: MVCC for vector DB with time-travel queries; challenges in graph GC.

## 7 Conclusion

We have presented a comprehensive architecture for billion-scale vector database indexing synthesizing DiskANN's SSD-aware Vamana graph, ScaNN's anisotropic quantization, FAISS IVF-PQ's scalable inverted file product codes, and learned adaptive quantization via QINCo and distillation. Through rigorous modeling of I/O, distortion, and navigability, and extensive empirical evaluation on SIFT1B, DEEP1B, and Turing-ANNS 1B, we demonstrate that a **hybrid tiered pipeline** achieves 95% Recall@10 at <8 ms p50 on a single commodity node with 64 GB RAM, 12x lower cost than pure HNSW baselines and 18% lower distortion than classical PQ via learned codebooks. The design supports production necessities: filtered queries, incremental updates, and cost-aware tiering.

Key takeaways for practitioners:

- Use **IVF-PQ for coarse pruning** (cheap, high fan-out) then **Vamana graph for refinement** (high recall).
- For **MIP/cosine workloads**, anisotropic rescoring is mandatory; isotropic L2-optimized PQ loses 6-9 recall points.
- **Learned quantization** yields highest ROI when code size ≤32 bytes; beyond 64 bytes, k-means suffices.
- **SSD alignment and beam width tuning** dominate tail latency more than distance compute.
- **Filtered queries** require graph partitioning, not post-filtering.

Future vector databases will be *learned, disaggregated, and tiered*, co-designed with CXL, DPU, and confidential computing. This thesis provides foundational principles and a reproducible recipe.
