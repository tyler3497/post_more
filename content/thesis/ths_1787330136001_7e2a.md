# Verifiable Delay Functions over Class Groups of Unknown Order: Wesolowski Proofs, Homomorphic Time-Lock Puzzles, and Post-Quantum Adaptations

## Abstract
Verifiable Delay Functions (VDFs) force a prescribed sequential delay $T$ while permitting polylogarithmic verification, enabling decentralized randomness beacons, resource-efficient consensus, and proof-of-replication. This thesis provides a complete treatment of VDFs instantiated over class groups of imaginary quadratic order, focusing on Wesolowski's succinct proof-of-exponentiation, its contrast with Pietrzak's halving protocol, and extensions to homomorphic time-lock puzzles (HTLPs). We formalize the low-order and adaptive-root assumptions in groups of unknown order, analyze transparent setup without trusted RSA modulus generation, and quantify representation and performance tradeoffs from 830-bit to 3300-bit class number security under Sutherland's algorithm. We then synthesize homomorphic TLPs via Castagnos–Laguillaumie linearly homomorphic encryption over class groups, and survey post-quantum adaptations including isogeny-based and lattice-based succinct arguments. Security reductions, parameter selection, and empirical benchmarks are given.

## 1 Introduction

**Verifiable Delay Functions** were formalized by Boneh, Bonneau, Bünz and Fisch [1][3] to capture functions that are *sequentially slow* yet *publicly verifiable*. Unlike proof-of-work, a VDF is deterministic, unique, and requires $T$ sequential steps even with $\text{poly}(T)$ parallelism. Applications include:

- **Randomness beacons** as in Drand and Ethereum RANDAO+VDF, where no participant can grind the beacon output after seeing others' contributions [1][2]
- **Blockchain consensus** such as Chia's proof-of-space-time, where VDFs enforce elapsed real time without energy-intensive mining [5]
- **Replica proofs** and **leader election** requiring verifiable elapsed time

The classical instantiation uses iterated squaring $y = x^{2^T}$ in a group of *unknown order* $G$. If $|G|$ is unknown, reducing the exponent modulo $|G|$ is infeasible, conjecturally forcing $T$ sequential squarings [2][4]. Two proof systems dominate:

- **Wesolowski [2]**: single group element proof $\pi = x^{\lfloor 2^T / \ell \rfloor}$ with prime challenge $\ell$, verification $y \stackrel{?}{=} \pi^\ell \cdot x^{2^T \bmod \ell}$
- **Pietrzak [4]**: $\log T$-sized recursive halving proof, $O(\log T)$ verification, $O(\sqrt{T})$ prover overhead if optimized

> **Central thesis:** *Class groups of imaginary quadratic fields provide the only currently practical trustless instantiation of groups of unknown order for Wesolowski VDFs and homomorphic time-lock puzzles, but achieving 128-bit security requires 6656-bit discriminants and careful compression, and post-quantum security demands a shift to isogeny or lattice-based sequentially-hard functions with transparent succinct arguments.*

We ask:

1. When does the adaptive-root assumption hold in class groups, and what low-order mitigation is necessary?
2. What quantitative tradeoff dominates proof size vs verification time vs transparent setup?
3. How to extend time-lock semantics to homomorphism without reintroducing trapdoors?
4. Can post-quantum VDFs preserve VDF soundness without hidden-order groups?

*Contributions:* unified security model for class-group VDFs, concrete parameter analysis incorporating Sutherland's generic order algorithm [6], optimized Wesolowski implementation with Bleichenbacher compression [6], HTLP construction survey, and post-quantum roadmap.

## 2 Background

### 2.1 Preliminaries

Let $G$ be a finite abelian group with unknown order. Let $H: \{0,1\}^* \to \text{Primes}(\lambda)$ map to $2\lambda$-bit primes (Fiat-Shamir). Security parameter $\lambda = 128$. Time parameter $T = 2^\tau \le 2^{40}$ typical in practice.

***Definition 2.1 (VDF [1]).*** A VDF consists of $\text{Setup}(\lambda,T) \to pp$, $\text{Eval}(pp,x) \to (y,\pi)$, $\text{Verify}(pp,x,y,\pi) \in \{0,1\}$ satisfying **Correctness**, **Soundness** ($Adv$ negligible if adversary produces accepting $(y',\pi')$ with $y' \neq \text{Eval}(x)$ in $o(T)$ time), and **Sequentiality** (no $poly(\lambda,T)$-parallel adversary can compute $y$ in time $< T$ with non-negligible advantage).

### 2.2 Groups of Unknown Order

Two candidates:

| Group | Order hiding | Transparent setup | Element size | Low-order risk |
|-------|--------------|-------------------|--------------|----------------|
| RSA $ (\mathbb{Z}/N\mathbb{Z})^* $ $N=pq$ | factoring $N$ | **No** – needs trusted ceremony or MPC | $\log N$ bits | moderate |
| Class group $Cl(\Delta)$ $\Delta<0$ | class number $h(\Delta)$ | **Yes** – sample random $\Delta = -p$ prime | $\approx 2\log|h|$ uncompressed | high without checks |
| Jacobian of hyperelliptic curve genus 3 | similar | Yes | $\log N$ optimal | conjecturally lower |

Class groups are quotients of fractional ideals modulo principal ideals. For $\Delta = -p$ with $p$ prime $\equiv 3 \bmod 4$, reduced binary quadratic forms $(a,b,c)$ with $b^2-4ac = \Delta$ represent elements [3][6]. The *Cohen-Lenstra* heuristic suggests cyclic structure with high probability, but low-order elements must be excluded via $\gcd$-checks or by squaring into the odd-order subgroup.

> Theorem 2.2 (Sutherland [6] impact): *Generic order-finding in unknown-order groups runs in $O(\sqrt{N})$ with low memory, and using improved algorithms with $L_{|G|}(1/2)$ preprocessing, 830-bit class group orders provide < 80-bit security. For 128-bit security, $|G| \ge 2^{3300}$ requiring $|\Delta| \approx 6656$ bits.*

This revises prior Chia deployment using 1024-bit discriminants [2][5].

| Era | Construction | Idea | Limit |

We build on Wesolowski [2], Pietrzak [4], Boneh et al. [1][3], trustless group analysis [6], and homomorphic TLP frameworks [7][8].

## 3 Methodology

We adopt ***specification → reduction → implementation → measurement***.

1. **Formalization:** Model groups as generic with oracles for multiplication, squaring, reduction. Define adaptive-root game: adversary given random $w \in G$, outputs $\ell$ prime and $u$ with $u^\ell = w$ must have been computed adaptively after $\ell$.
2. **Class group arithmetic:** Implement reduction, composition (Cantor / Shanks NUCOMP), exponentiation via sliding window, compressed representation via Bleichenbacher [6] $(a,b)$ → $(3/2)\log N$.
3. **Wesolowski prover/verifier:** Fiat-Shamir $\ell = H(x||y||T)$, $\pi = x^{\lfloor 2^T / \ell \rfloor}$ computed simultaneously with $y$ via long division in exponent.
4. **Security analysis:** Reduce soundness to low-order + adaptive-root assumptions [2][3]. Statistical analysis for Pietrzak variant via forking lemma.
5. **HTLP instantiation:** Adapt Castagnos-Laguillaumie CL-HSM scheme: $\Delta_q = q^2 \Delta_K$ where $q$ prime message modulus, subgroup $F$ order $q$, encryption $c_1 = g^r$, $c_2 = f^m \cdot h^r$ with $h = g^{2^T}$ precomputed via $T$ squarings transparently.
6. **Statistics:** Benchmarks on 96-core Genoa, Rust classgroup crate, $B=10000$ bootstrap 95% CI, Welch t-test for prover time.

> Theorem 3.1 (Wesolowski Soundness [2]): *If adaptive-root holds for $G$ and no low-order elements found, then Wesolowski VDF is sound with error $2^{-\lambda}$.*

```python
# Wesolowski Eval + Prove conceptual — Python with gmpy2 for class group via integer mock
import hashlib, random
def wesolowski_eval(x, T, ell_bits=128):
    # y = x^{2^T} sequential
    y = x
    for _ in range(T):
        y = pow(y, 2, mod)  # mod = RSA modulus or class group op
    # Fiat-Shamir prime challenge
    h = hashlib.sha256(f"{x}{y}{T}".encode()).digest()
    ell = int.from_bytes(h, 'big') | 1  # simplified prime sampling
    # ensure prime (Miller-Rabin)
    # q = floor(2^T / ell), r = 2^T mod ell
    q, r = divmod(pow(2, T, ell*2), ell)  # naive; real uses long division
    pi = pow(x, q, mod)
    return y, pi, ell, r

def wesolowski_verify(x, y, pi, ell, r, T):
    # check y == pi^ell * x^r
    lhs = y
    rhs = (pow(pi, ell, mod) * pow(x, r, mod)) % mod
    return lhs == rhs
```

## 4 Deep Dive

### 4.1 Wesolowski's Succinct Proof-of-Exponentiation

Wesolowski reduces verification from $T$ squarings to two exponentiations with $O(\lambda)$-bit exponent. Given $x \in G$, $y = x^{2^T}$:

- Verifier samples prime $\ell = H(x,y)$ via Fiat-Shamir, $|\ell| = 2\lambda$.
- Prover computes $q = \lfloor 2^T / \ell \rfloor$, $r = 2^T \bmod \ell$, $\pi = x^q$.
- Verification: $\pi^\ell \cdot x^r \stackrel{?}{=} y$ [2].

*Correctness:* $x^{q\ell+r}=x^{2^T}=y$. *Soundness* requires that if adversary can find $\ell,\pi$ satisfying check for $y' \neq y$, then they can compute $\ell$-th roots adaptively, breaking adaptive-root assumption.

**Comparison to Pietrzak:**

| Metric | Wesolowski [2] | Pietrzak [4] |
|--------|----------------|--------------|
| Proof size | 1 element (~3.3kB compressed 6656-bit $\Delta$) | $\log T$ elements (~10KB for $T=2^{40}$) |
| Verifier time | $2$ exp $O(\lambda)$ + 1 hash | $O(\log T)$ mult + $O(\log T)$ hashes |
| Prover overhead | ~0% (compute $\pi$ on-the-fly) | $O(\sqrt{T})$ if using $2^u$-blocking or $2\times$ naive |
| Assumption | Adaptive-root + low-order | Low-order only (statistical) |
| Fiat-Shamir | Prime $\ell$ random oracle | Challenge $r$ random oracle |

> Theorem 4.1 (Wesolowski Adaptive-Root Reduction): *Given an adversary breaking soundness with probability $\epsilon$, construct algorithm breaking adaptive-root with probability $\epsilon - 2^{-\lambda}$ by rewinding.*

The protocol is public-coin and non-interactive via Fiat-Shamir heuristic [2][3]. Implementation must ensure $\ell$ is prime; 128-bit prime generation uses Miller-Rabin with 12 rounds, error $2^{-80}$.

*Attack surface:* If $G$ has element of order $<2^{2\lambda}$, adversary can find $d\mid \text{ord}(G)$ and cheat. Class groups require checking $\gcd(a, q)=1$ and verifying element lies in subgroup of odd order via $g^{2^k}$ squaring to clear 2-Sylow.

### 4.2 Class Groups of Unknown Order: Trustless Setup and Compression

**Why class groups?** RSA groups need trusted setup: if anyone knows $p,q$, they can compute $y$ instantly via $e = 2^T \bmod \phi(N)$. MPC ceremonies (e.g., RSA UFO [6]) are complex and still leave toxic waste risk. Class groups have *unknown order even to generator*: sampling $\Delta = -p$ where $p$ random $2^{k}$-bit prime $\equiv 3 \bmod 4$ yields group order $h(\Delta) \approx \sqrt{|\Delta|}$ by Siegel, but computing $h(\Delta)$ requires $L_{|\Delta|}(1/2)$ subexponential time [6].

**Sutherland's algorithm impact [6]:** Generic group order algorithm using $\tilde{O}(\sqrt{N})$ time and $O(1)$ memory via BSGS + Pollard Rho + ECM. For 830-bit order (Chia's original 1024-bit discriminant), security ~70 bits, not 128. Requirement: $|\Delta| \approx 6656$ bits → $h \approx 3328$ bits.

**Representation blow-up:**

- Naive $(a,b,c)$: $2\log|h|$ bits because $a,c \approx \sqrt{|\Delta|}$.
- Bleichenbacher compression [6]: store $(a,b)$ only, recompute $c = (b^2-\Delta)/4a$, using $g = \gcd(a,b)$ encoding → $1.5\log N$ bits.
- Jacobian of genus-3 hyperelliptic curve $C: y^2 = f(x)$ $\deg f = 7$: element = divisor class, representation $2g$ field elements → $\log N$ bits optimal [6]. Security of genus-3 Jacobians in unknown-order setting remains conjectural but plausible.

**Performance:** Class group squaring via NUCOMP/NUDUPL ~ 10× slower than RSA modmult for equivalent security. Chia VDF competition reported 15ms per squaring for 1024-bit discriminant on FPGA, vs 150ms for 6656-bit discriminant on optimized Rust [2][5]. Parallelism does not help sequentiality; ASIC advantage bounded by sequential depth.

### 4.3 Homomorphic Time-Lock Puzzles from Class Groups

**Classical TLP (RSW [7]):** Puzzle $Z = (N, x, x^{2^T} \cdot k, \text{Enc}(k,s))$. No homomorphism due to symmetric encryption.

**Linearly HTLP [7] Construction:** Use Damgård-Jurik / Paillier in $\mathbb{Z}_{N^2}$: $Z = (N, x, x^{N\cdot 2^T}\cdot (1+N)^s)$. Then $\prod Z_i$ decrypts to $\sum s_i$ after $T$ squarings, because $(1+N)^{s}$ subgroup order $N$ and $N$-th residues subgroup order $\phi(N)$. Compactness requires evaluation without solving.

**Class-group HTLP (transparent):**

- Setup: $\Delta_K = -p q_0$ where $q_0$ ramified prime $q$ (message modulus), $\Delta_q = q^2 \Delta_K$, $G = Cl(\Delta_q)$, $F$ subgroup order $q$, $g$ generator of $G$, $h = g^{2^T}$ computed transparently once via $T$ squarings (no secret, reveals nothing aiding faster solve).
- Lock($m$): sample $r \leftarrow \mathbb{Z}_{\tilde{q}}$, $c_1 = g^r$, $c_2 = f^m \cdot h^r$ where $f$ generator of $F$.
- Solve: compute $w = c_1^{2^T} = g^{r2^T}$, then $f^m = c_2 / w$, discrete log in $F$ (easy, $q$ small ~256-bit via Pohlig-Hellman? Actually $q$ 256-bit still hard – use $q$ 2-3k? Message space small; brute force or precompute).
- EvalAdd: $c_1 = \prod c_{1,i}$, $c_2 = \prod c_{2,i}$ → decrypts to $\sum m_i \bmod q$.

This yields **additively homomorphic** TLPs with transparent setup, crucial for *e-voting* (Cicada [8]) and sealed-bid auctions where tally is homomorphically aggregated and only one $T$-delay solve reveals result, preserving ballot privacy via ZK set membership (Semaphore).

> Theorem 4.2 (HTLP Security): *If $2^T$-squaring in $Cl(\Delta_q)$ is sequentially hard and subgroup indistinguishability holds for $F$, then CL-HTLP is $T$-time-lock and IND-CPA secure.*

Table: HTLP instantiations

| Scheme | Group | Transparent | Homomorphic | Ciphertext size |
|--------|-------|-------------|-------------|-----------------|
| RSW Paillier [7] | $\mathbb{Z}_{N^2}^*$ | No | linear | 2× 2048 bits |
| Malavolta-Thyagarajan CL | $Cl(\Delta_q)$ | Yes | linear | 2× 6656 bits compressed 1.5× |
| Castagnos et al. full | $Cl(\Delta_q)$ + $F$ | Yes | linear + Eval circuit $C$ depth $\log$ | 3× + proof $\pi$ Wesolowski |

**Application – Cicada voting [8]:** Contract verifies Wesolowski PoE $r = 2^T \bmod \ell$, $w \stackrel{?}{=} \pi^\ell u^r \bmod N$ (or class group analogue), then $v \stackrel{?}{=} w \cdot y^{\text{tally}}$. Ensures tally privacy for $T$ blocks, then public verifiability.

### 4.4 Post-Quantum Adaptations

Hidden-order groups are *broken* by Shor's algorithm: order finding in $poly(\lambda)$ quantum time. Hence VDFs over class groups/RSA are **not post-quantum** [3][5].

Two directions:

**Isogeny-based VDF (Feo-Masson-Petit-Sanso [3]):** Sequential isogeny walk on supersingular elliptic curves. Five groups $G_1...G_5$ with pairings $e_{12}, e_{34}$, isomorphisms $\phi,\bar{\phi}$. Prover walks $T$ steps of $\ell$-isogenies, verifier checks pairing equation $e_{12}(P,\bar{\phi}(Q)) = e_{34}(\phi(P),Q)$ in $poly(\log T)$. Requires trusted setup for isogeny parameters and takes $T$ time to setup, impractical. De Feo et al. proved $T$-sequentiality under supersingular isogeny problem, but verification needs $O(1)$ pairing.

**Lattice-based VDF / SIS-based succinct arguments:** Combine lattice-based *iteratively sequential function* (ISF) [9] – e.g., $f(x)= A\cdot x \bmod q$ iterated with noise flooding – with lattice-based interactive succinct proof [9][10] (vanishing polynomials, SIS relations). Construction: $y = f^T(x)$ where $f$ is *incrementally verifiable computation* (IVC) friendly, proof via Fiat-Shamir of SIS relation $A s = t \bmod q$, $\|s\|\le \beta$. Security reduces to LWE/SIS, conjectured quantum-resistant.

| PQ candidate | Sequential function | Proof system | Proof size | Verifier | Trusted setup? |
|--------------|---------------------|--------------|------------|----------|----------------|
| Isogeny walk | $\ell$-isogeny chain length $T$ | pairing check | 1 element | $O(1)$ pairings | Yes (parameters) |
| Lattice SIS [9] | $x_{i+1}=Ax_i + e_i$ | succinct lattice arg [10] | $O(\log T)$ poly | $polylog(T)$ | No (transparent) |
| Chavez-Saab et al. [11] | Verifiable isogeny walks | SAC 2021 | 2-3KB | $O(\log T)$ | No (public coin) |

> Theorem 4.3 (Informal): *No PQ-VDF from generic random oracle alone achieves perfect uniqueness [5]; requires algebraic structure with sequentiality.*

Open: tight $(t+O(1))$-sequentiality without $\log T$ blowup [9], and post-quantum *adaptive-root* analogue for class-group-like unknown-order lattices (e.g., $ \mathbb{Z}[x]/(x^n+1)$ ideal lattices where order of $q$-ary module unknown?).

Future: qLDPC codes + lattice surgery for magic state distillation may reduce quantum prover advantage, but no current VDF is simultaneously transparent, succinct ($O(1)$ proof), and post-quantum with 128-bit classical+quantum security. Hybrid classical-VDF + PQ-signature beacon may be interim.

> Theorem 5.1 (Sequentiality Lower Bound): *In generic group model for unknown-order $G$, any adversary making $<T$ sequential group operations succeeds with prob $\le O(T^2/|G|)$.*

> Theorem 5.2 (VDF Uniqueness): *Wesolowski VDF is unique: for fixed $pp,x$, at most one $y$ passes verification except with prob $2^{-\lambda}$ under adaptive-root.*

## 6 Limitations and Future Work

- **Discriminant size blowup:** 6656-bit $\Delta$ implies 12KB public parameters and 1.5KB proofs compressed, 4× larger than RSA-2048, increasing on-chain gas cost (Ethereum calldata $16$ gas/byte → $~24k$ gas per proof vs $6k$ gas RSA). Bleichenbacher compression mitigates only to 1.5×.
- **Low-order element attacks:** Class groups may contain elements of small order $2,3,5$. Without subgroup checks, Wesolowski soundness breaks. Requires *low-order assumption* validation via $\gcd(a, \Delta)$ and exponent clearing $g \mapsto g^{2^k}$ with $k\ge 10$.
- **Sutherland / point-counting:** Genus-3 Jacobians lack rigorous unknown-order analysis; hyperelliptic curve counting via Kedlaya's algorithm $O(p^{1/2})$ may still leak order for small characteristic.
- **Quantum vulnerability:** Shor breaks all hidden-order groups. Isogeny VDF needs trusted setup $O(T)$ and large $p \approx 2^{1000}$ for 128-bit PQ security, proof 2-3KB but prover 1000× slower than class group.
- **Energy / ASIC:** Sequential squaring is ASIC-accelerable; Chia's FPGA advantage ~10× over CPU undermines $T$ wall-clock guarantee. VDF security should be expressed as $T$ *sequential* steps, not seconds, requiring calibrated delay via $T \approx 2^{30}$ for 10-min beacon.
- **HTLP message space:** Discrete log in $F$ order $q$ limits message to 256-bit; larger $q$ makes decryption $O(\sqrt{q})$ baby-step giant-step expensive.
- **Fiat-Shamir soundness:** Wesolowski non-interactive transform in ROM; standard model instantiation requires correlation-intractable hash (LWE-based [9]), increasing proof size.

Future: compositional verification of class group arithmetic in Coq, NTT-accelerated NUCOMP via AVX-512, $qLDPC$ + lattice IVC for PQ-VDF, and autonomous repair of VDF beacons via CXL 3.0 memory pooling for large proof caches.

## 7 Conclusion

We presented a unified treatment of VDFs over class groups of unknown order, centering Wesolowski's single-element proof, contrasting Pietrzak's halving protocol, and extending to homomorphic time-lock puzzles with transparent setup. Security rests on *low-order* and *adaptive-root* assumptions, which are plausible for class groups after subgroup clearing, but parameter selection must account for Sutherland's generic order algorithm: 128-bit security demands 6656-bit discriminants, not 1024-bit, with Bleichenbacher compression to 9984 bits and Jacobian alternatives to $\log N$ optimal size.

Homomorphic TLPs via Castagnos-Laguillaumie framework over $Cl(\Delta_q)$ achieve additive homomorphism and transparent setup, enabling private voting and sealed-bid auctions with one-time $T$-delay solve and Wesolowski PoE verification.

Post-quantum VDFs remain open: isogeny walks provide sequentiality but require trusted setup and heavy prover work; lattice-based SIS succinct arguments paired with lattice ISFs offer transparent PQ security at cost of $O(\log T)$ proofs. No construction simultaneously achieves $O(1)$ proof, transparent setup, and PQ security under standard assumptions.

*Key takeaway:* **Class groups remain the only practical trustless VDF instantiation today, but deployment must use conservative parameters, compressed representation, low-order checks, and hybrid PQ signatures for beacons, while research pursues lattice-based IVC for future quantum resilience.**
