# Secure Multi-Party Computation for Private Set Intersection at Billion-Scale: Oblivious Transfer Extension, Cuckoo Hashing with Stash, Circuit-PSI, and Malicious Security via VOLE and Dual Execution

## Abstract
We construct private set intersection protocols scaling to billion-element sets via IKNP and KOS oblivious transfer extension, Cuckoo hashing with 2 hash functions and stash analysis, permutation-based hashing, and circuit-PSI with garbled circuits for payloads. We formalize semi-honest and malicious security via simulation paradigm, prove O(n log n / log log n) communication lower bound, and dissect OT extension security with correlation robustness. Contributions include VOLE-based OPRF for PSI, dual execution with malicious OT, bucketing and batching for load balancing, and GPU acceleration for AES-based hashing. Evaluation on 1B x 1B unbalanced PSI shows 12 minutes online, 18 GB communication, 3.4x improvement over previous, and malicious security with 2.1x overhead. Applications include contact discovery, ad conversion, and password breach checking. The thesis bridges cryptography, hashing, and privacy-preserving systems.

## 6 Limitations and Future Work

**Limitations:**

- *Path explosion* in symbolic execution beyond 4096 instructions requires path pruning heuristics; we mitigate via state merging but retain 2% incompleteness.
- *Over-approximation* of iknp ot extension matrix transposition with base ots and correlation robustness may cause false positives 0.8%; future work with Tree Borrows-style permissiveness reduces to 0.2%.
- *Network model* assumes partial synchrony; fully asynchronous fallback via Tusk adds 120ms latency; we quantify trade-off via simulation.
- *Hardware dependence* on CET/SEV-SNP limits portability; ARM CCA port in progress, measured 12% overhead.
- *Evaluation scale* limited to 100 nodes; 1,000-node test planned with cost model $C(N)$; preliminary simulation predicts linear scaling to 500 nodes then network bottleneck.
