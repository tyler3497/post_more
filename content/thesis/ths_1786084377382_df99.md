# Causal Inference in Observational Studies: Double Machine Learning, Synthetic Controls, and Sensitivity Analysis via Partial Identification

## Abstract
Observational causal inference requires estimating counterfactual contrasts under violations of randomization, high-dimensional confounding, and aggregate intervention regimes where only one unit is treated. This thesis unifies **three modern pillars**: *double/debiased machine learning (DML)* for Neyman-orthogonal estimation of low-dimensional treatment parameters with machine learning nuisance estimators; *synthetic control methods (SCM)* for counterfactual imputation in comparative case studies; and *formal sensitivity and partial identification* via Rosenbaum Γ-bounds, design sensitivity, and Manski monotone bounds. We derive the orthogonal score construction, cross-fitting algorithm, and √N-asymptotics of DML, formulate SCM as constrained simplex regression with penalized, augmented, and synthetic difference-in-differences extensions, and characterize worst-case Rosenbaum sensitivity and Imbens–Manski confidence regions for interval-identified ATE. An integrated decision hierarchy shows how practitioners can move from point identification under conditional unconfoundedness to credible interval identification when unmeasured confounding cannot be ruled out. Simulation and California Prop 99 replication illustrate the bias-variance trade-offs. The framework makes explicit what must be believed to claim causality.

## 1. Introduction

The *fundamental problem of causal inference* [Holland 1986] is that we never observe both potential outcomes \(Y_i(1), Y_i(0)\) for the same unit \(i\). In randomized experiments, the assignment mechanism solves the missing data problem in expectation. In observational studies, assignment \(D_i \in \{0,1\}\) is **non-ignorable** without conditioning.

We face three intertwined difficulties:

1.  **High-dimensional confounding:** \(X_i \in \mathbb{R}^p\), \(p \gg N\) or \(p\) growing with \(N\), renders parametric propensity/outcome models misspecified.
2.  **Aggregate treatment:** only one treated unit (e.g., California enacts tobacco control), \(J\) donor units, \(T_0\) pre-periods.
3.  **Unmeasured confounding:** even after rich adjustment, \(U_i\) may persist, breaking \(Y(d) \perp D \mid X\).

> **Theorem (Identification Trilemma):** Under only \(Y = D Y(1) + (1-D)Y(0)\) and bounded outcomes, point identification of \(ATE = \mathbb{E}[Y(1)-Y(0)]\) is impossible without further assumptions. Any point estimator implicitly encodes a belief about either (a) ignorability, (b) functional form overlap, or (c) treatment assignment mechanism.

This thesis systematizes modern responses:

* **DML** [1][2]: remove regularization bias and overfitting bias via Neyman orthogonality + cross-fitting.
* **SCM** [3][4][5]: construct synthetic counterfactual as convex combination of donors.
* **Sensitivity / Partial ID** [6][7][8][9]: when point identification fails, characterize the *sharp identification region* under credible weakenings.

Unlike textbook reviews, we emphasize interaction: DML synthetic controls, Rosenbaum sensitivity for DML, and DML estimation of bounds.

## 2. Background

### 2.1 Potential Outcomes

For unit \(i\), potential outcomes \(Y_i(1), Y_i(0)\), observed outcome \(Y_i = D_i Y_i(1)+(1-D_i)Y_i(0)\). Covariates \(X_i\).

Standard assumptions:

* **SUTVA:** No interference, one version of treatment.
* **Overlap:** \(0 < e_0(x) := P(D=1\mid X=x) < 1\) for almost all \(x\).
* **Conditional Ignorability:** \( \{Y(1),Y(0)\} \perp D \mid X\).

Under these, \(ATE = \mathbb{E}[ \mu_1(X) - \mu_0(X)]\) where \(\mu_d(x)=\mathbb{E}[Y\mid D=d,X=x]\). Also \(ATE = \mathbb{E}[ DY/e_0(X) - (1-D)Y/(1-e_0(X))]\) inverse propensity weighting.

With high-dimensional \(X\), estimating \(\mu_d\) or \(e_0\) via ML introduces bias due to regularization.

### 2.2 Historical Gaps

* Classical semiparametrics required Donsker conditions on nuisance estimators — fails for random forests, neural nets.
* Difference-in-differences requires parallel trends across all controls; SCM relaxes by learning weights.
* Rosenbaum's work [6][7] showed that \(p\)-values from matched studies are fragile; sensitivity parameter \(\Gamma\) quantifies required hidden bias to explain away effect.
* Manski [8] inverted the program: instead of assuming point identification, derive **worst-case bounds** that are *by construction* credible.

| Method | Target | Core Assumption | Failure Mode |
| :--- | :--- | :--- | :--- |
| IPW / regression | ATE | Ignorability + overlap | ML bias, extreme weights |
| DML | ATE, ATTE, LATE | Neyman orthogonal PLR / IRM | Poor nuisance convergence \(o(N^{-1/4})\) violated |
| Synthetic Control | ATT at \(T > T_0\) for treated unit | Convex hull + factor model | Poor pre-fit, linear extrapolation |
| Rosenbaum Γ | \(p\)-value robust to \(U\) | Bounded odds ratio logit model | Conservative if heterogeneity in bias |
| Manski Bounds | Identification region \([LB,UB]\) | Bounded support / monotone | Wide intervals unless MTS+MTR+MIV |

### 2.3 Notation

\(W_i = (Y_i,D_i,X_i) \sim P\). Nuisance \(\eta_0 = (g_0,m_0)\). Parameter of interest \(\theta_0 \in \mathbb{R}^{d_\theta}\) low-dimensional.

## 3. Methodology

### 3.1 Double Machine Learning Framework

Chernozhukov et al. [1] consider structural parameter solving moment:

$$\mathbb{E}[ \psi(W; \theta_0, \eta_0)] = 0$$

where \(\psi\) is **Neyman orthogonal**: \(\partial_\eta \mathbb{E}[\psi(W;\theta_0,\eta_0)][\eta-\eta_0] = 0\).

Two canonical models:

* **Partially Linear Regression (PLR):** 
  $$Y = D\theta_0 + g_0(X) + \zeta, \, \mathbb{E}[\zeta\mid D,X]=0$$
  $$D = m_0(X) + V, \, \mathbb{E}[V\mid X]=0$$
* **Interactive Regression Model (IRM / ATE):**
  $$Y = g_0(D,X)+\zeta, \quad D \text{ binary, } \mathbb{E}[\zeta\mid D,X]=0$$

Orthogonal score for PLR:

$$\psi(W;\theta,\eta) = \{ Y - D\theta - g(X) \} \{ D - m(X) \}$$

For IRM (doubly-robust):

$$\psi = g(1,X)-g(0,X) + \frac{D(Y-g(1,X))}{e(X)} - \frac{(1-D)(Y-g(0,X))}{1-e(X)} - \theta$$

**Cross-fitting algorithm** to remove overfitting:

1. Partition \(N\) into \(K\) folds \(I_k\)
2. For each \(k\), learn \(\hat\eta_{0,k}\) on \(I_k^c\)
3. Solve \(\frac1N\sum_{k}\sum_{i\in I_k}\psi(W_i;\theta,\hat\eta_{0,k})=0\)
4. Cluster-robust variance: \(\hat\sigma^2 = \hat J_0^{-1} (\frac1N\sum \psi\psi^\top) (\hat J_0^{-1})^\top\)

Result: \(\sqrt{N}(\hat\theta - \theta_0) \xrightarrow{d} N(0,\sigma^2)\) if \(\|\hat\eta-\eta_0\|_{L2} = o(N^{-1/4})\) and orthogonality holds [1][2].

### 3.2 Synthetic Control Methods

Context: \(J+1\) units, \(T\) periods, unit 1 treated at \(T_0+1\). \(Y_{it}^N\) untreated potential, \(Y_{it}^I\) treated.

**Assumption:** Factor model \(Y_{it}^N = \delta_t + \theta_t Z_i + \lambda_t \mu_i + \varepsilon_{it}\).

SCM chooses weights \(W=(w_2,\dots,w_{J+1})^\prime\) in simplex:

$$W^* = \arg\min_{W} \| X_1 - X_0 W \|_V \quad \text{s.t. } w_j \ge 0, \sum w_j =1$$

where \(X_1\) predictor vector for treated, \(X_0\) donors, \(V\) importance matrix [3][5].

Synthetic counterfactual: \(\hat Y_{1t}^N = \sum_{j=2}^{J+1} w_j^* Y_{jt}\).

Treatment effect: \(\hat \alpha_{1t} = Y_{1t} - \hat Y_{1t}^N\) for \(t>T_0\).

**Inference by placebo:** Permute treated unit among donors, compute RMSPE ratio \(r_j = (\text{post-MSE} / \text{pre-MSE})^{1/2}\). Exact permutation p-value: \(p = \sum_j \mathbf{1}[r_j \ge r_1] / (J+1)\).

Modern extensions [4]:

* **Penalized SCM:** \( \min \|Y_1^{pre} - Y_0^{pre} W\|_2^2 + \lambda \|W\|_2^2\)
* **Augmented SCM:** bias correction via outcome model \(\hat m\): \(\hat Y_{1t}^{aug} = \sum w_j Y_{jt} + (\hat m(X_1)-\sum w_j\hat m(X_j))\)
* **Synthetic DiD (SDID):** \(W\) + time weights \(\lambda_t\) doubly robust.

### 3.3 Rosenbaum Sensitivity and Design Sensitivity

Matched design: \(I\) pairs matched on \(X\). Under true randomization, odds of treatment within pair =1. Under hidden bias \(u_{ij}\in[0,1]\):

> **Sensitivity Model:** $\log \frac{\pi_{ij}}{1-\pi_{ij}} = g(x_{ij})+\gamma u_{ij}$, $\Gamma=e^\gamma \ge 1$

Implication for pair \(i\) with exactly one treated:

$$\frac{1}{1+\Gamma} \le P(Z_{i1}=1\mid \mathcal{F},\mathcal{Z}) \le \frac{\Gamma}{1+\Gamma}$$ [6]

Given test statistic \(T=\sum_i T_i\), worst-case p-value upper bound under \(H_0\):

$$p^+(\Gamma)= \sup_{\pi\in[1/(1+\Gamma),\Gamma/(1+\Gamma)]^I} P_{ \pi}(T\ge t^{obs})$$

Report \(\Gamma^\star = \inf\{\Gamma: p^+(\Gamma) > \alpha\}\): minimum bias to overturn.

**Amplification** [7]: Decompose \(\Gamma = (\Delta \Lambda +1)/(\Delta+\Lambda)\) where \(\Delta\) relates \(U\) to treatment, \(\Lambda\) to outcome. Provides interpretable hidden confounder strength.

**Design sensitivity** \(\tilde\Gamma\): as \(I\to\infty\), \(p^+(\Gamma)\to0\) if \(\Gamma<\tilde\Gamma\), \(\to1\) otherwise. Different test statistics have different \(\tilde\Gamma\) — heavy-tail robust tests often higher.

### 3.4 Manski Partial Identification

Assume bounded outcome \(Y\in [y_{min},y_{max}]\). Law of total probability:

$$E[Y(d)] = E[Y\mid D=d]P(D=d) + E[Y(d)\mid D\neq d]P(D\neq d)$$

Unobserved second term \(\in [y_{min}, y_{max}]\) => **No-assumption bounds**:

$$[E[Y|D=d]P(D=d)+y_{min}P(D\neq d), \; E[Y|D=d]P(D=d)+y_{max}P(D\neq d)]$$ [8]

Sharp but wide — width = \((y_{max}-y_{min})P(D\neq d)\).

Tightening via:

* **MTS:** \(E[Y(d)\mid D=0]\le E[Y(d)\mid D=1]\) if selection positive — e.g., trainees have lower baseline earnings.
* **MTR:** \(Y_i(1)\ge Y_i(0)\) a.s. — treatment not harmful.
* **MIV:** Instrument \(Z\) monotone: \(z_1\le z_2 \Rightarrow E[Y(d)\mid Z=z_1]\le E[Y(d)\mid Z=z_2]\).

MTS+MTR+MIV intersection can cut width by 60-80% while remaining more credible than point identification.

Confidence interval for \(ATE\in[LB,UB]\) using Imbens-Manski [9]: \(CI = [ \widehat{LB} - c_\alpha \hat\sigma_{LB}, \widehat{UB}+c_\alpha\hat\sigma_{UB}]\) where \(c_\alpha\) solves \( \Phi(c_\alpha + (\widehat{UB}-\widehat{LB})/\max\sigma) - \Phi(-c_\alpha)=1-\alpha\). Uniform coverage of interval, not just bounds.

## 4. Deep Dive

### 4.1 Neyman Orthogonality and Cross-Fitting in DML

> **Definition (Neyman Orthogonality):** Score \(\psi\) satisfies \( \mathbb{E}[\partial_\eta \psi(W;\theta_0,\eta_0)]=0\). Intuition: first-order variation in nuisance does not transmit to moment.

Why regularization bias kills naïve ML Plug-in:

* Naïve: \(\hat\theta = (D' D)^{-1} D'(Y-\hat g(X))\) where \(\hat g\) lasso. Then \(\hat g - g_0 = O(\sqrt{s\log p/N})\) correlated with \(D\), bias \(O(1)\), fails \(\sqrt{N}\)-rate.
* Orthogonalization: residualize both \(Y\) and \(D\) on \(X\). Frisch-Waugh logic but with ML.

Cross-fitting removes own-observation bias: \(E[ (\hat g(X_i)-g_0(X_i))\cdot\varepsilon_i \mid \text{fold}] \neq0\) without sample splitting.

**Rate condition:** \( \|\hat g-g_0\|_{L2} \cdot \|\hat m-m_0\|_{L2}=o(N^{-1/2})\). Allows one nuisance fast \(N^{-1/2}\), other \(N^{-1/4}\); both random forest typical \(N^{-1/3}\) sufficient when product.

#### Practical diagnostics

* Check overlap histogram of \(\hat e(X)\).
* Check nuisance RMSE via cross-validated \(R^2\).
* Stability: vary \(K=2,5,10\) folds; estimate should be stable.

### 4.2 Synthetic Control as Constrained Optimization and Augmented Variants

#### Geometry

Simplex restricts interpolation — no extrapolation beyond convex hull. This ensures interpretability but introduces bias if \(X_1\) outside hull. Doudchenko & Imbens [4] show SCM = regression with:

* L1 sparsity via simplex + non-negative (like lasso with nuclear norm)
* No intercept unless augmented.

Optimization formulation:

$$\min_{W} \frac1{T_0}\sum_{t=1}^{T_0}(Y_{1t}-\sum_{j}w_jY_{jt})^2 + \zeta \|W\|_2^2 \quad s.t.\; W\in\Delta$$

Solve via quadratic programming (OSQP) or via entropic mirror descent.

**Augmented** correction:

Let \(\hat m_t\) outcome model (ridge) learned on donors. Then residual \( \hat r_{jt}=Y_{jt}-\hat m_t(X_j)\). Reweight residual.

This is DML-like: double robustness holds — consistent if either \(W\) balances \(X\) *or* outcome model correct.

**Synthetic DiD** derivation:

$$\hat\tau^{sdid}= \arg\min_{\tau,\mu,\alpha,\beta} \sum_{i,t} \hat\omega_i \hat\lambda_t (Y_{it} - \mu - \alpha_i - \beta_t - D_{it}\tau)^2$$

Where \(\hat\omega\) donor weights to match pre-trends, \(\hat\lambda\) time weights to match donor histories. Nests DID (uniform weights) and SC (time weights uniform pre).

### 4.3 Rosenbaum Bounds and Design Sensitivity

**Numerical example:**

196 matched pairs testing Smoking → Lung Cancer. Observed test statistic \(T=110\), null expectation \(E[T]=98\). For \(\Gamma=1\), p=0.01. For \(\Gamma=1.5\), worst-case p=0.04. For \(\Gamma=2.2\), p=0.07 → \(\Gamma^\star=2.1\). Is hidden confounder doubling odds plausible? Domain judge.

Recent work [7] generalize from max bias to quantile bias: only \(k\) pairs have bias \(\Gamma_k\). More robust — allows few outliers.

Python/R implementation pattern:

* Compute matched rank scores.
* For given \(\Gamma\), compute upper bound via separable algorithm (Rosenbaum 2004): maximize p by greedy allocation of bias to pairs with largest contribution to statistic.
* Discrepancy between normal approximation vs exact enumeration matters for small \(I\).

> **Theorem (Design Sensitivity Ranking):** For symmetric heavy-tailed outcomes, Wilcoxon’s signed rank test has design sensitivity strictly larger than sign test’s. Hence for large samples with strong hidden bias but moderate true effect, Wilcoxon more resilient.

Evidence factors: factor treatment into several stages (e.g., go to high school, go to college) each tested with independent sensitivity — combination reduces sensitivity.

### 4.4 Partial Identification and Manski–Pepper Monotone IV Bounds

**Monotone Treatment Selection formal:**

Assume \(E[Y(d)\mid D=1] \ge E[Y(d)\mid D=0]\) — selected group has weakly better counterfactuals. Then upper bound on \(ATE\) tightens.

Derivation:

$$E[Y(1)] \in [E[Y|D=1]P(D=1)+E[Y|D=0]^{LB} P(D=0),\; E[Y|D=1] ]$$

under MTS alone: treatment mean of treated optimistic.

**Monotone Treatment Response:**

If \(Y(1)\ge Y(0)\), then \(ATE\ge0\) and \(E[Y(1)] \ge E[Y]\). Combined MTS+MTR yields bounds Boole-type.

**MIV Example:** instrument \(Z\) = parents income, monotonic w.r.t. child wage potential. Even if \(Z\) fails exclusion, monotone version weaker.

Manski-Pepper bound for each \(z\):

$$LB(z) = \sum_{x\le z}E[Y|Z=x]P(Z=x), \text{ adjusted}$$

$$UB(z) = \sum_{x\ge z}E[Y|Z=x]P(Z=x)$$

Intersection across \(z\) sharpens.

**DML for bounds:** When bounds involve \(E[Y|D,X]\), estimate via ML with cross-fitting; inference needs adjustments for moment inequalities (Chernozhukov-Hong-Tamer).

## 5. Empirical Study and Proofs

### 5.1 DML Theoretical Guarantees Sketch

> **Theorem (Chernozhukov et al. 2018 [1]):** Under bounded moments, Neyman orthogonality, cross-fitting \(K\ge2\) fixed, and product rate condition, \(\sqrt{N}(\hat\theta_{DML} - \theta_0) \to N(0,\sigma^2)\) uniformly over P in class, with consistent variance estimator.

*Proof sketch:*

1. Decomposition \(\sqrt{N}(\hat\theta-\theta_0)= -J_0^{-1} \frac1{\sqrt{N}}\sum\psi(W_i;\theta_0,\eta_0) + R_N + r_N\).
2. Orthogonality makes derivative term second-order: \(R_N=O(\|\hat\eta-\eta_0\|^2)\).
3. Cross-fitting makes empirical process term \(r_N=o_p(1)\) via sample splitting (conditional independence).
4. Apply Lindeberg CLT to leading term.

### 5.2 Synthetic Control Asymptotic Bias

> **Proposition (Abadie et al. 2010 [3]):** Under factor model with bounded weights and \(T_0\to\infty\), bias \(\mathbb{E}[\hat\alpha_{1t}-\alpha_{1t}]\to0\) if pre-fit perfect. If perfect pre-fit impossible, bias bounded by excess factor imbalance \( \| \sum w_j\mu_j - \mu_1 \|\).

Proof idea: writing \(Y_1^{pre}-Y_0^{pre}W = \lambda^{pre}(\mu_1-\mu_0W)+noise\). Minimizing objective reduces factor distance but not zero due to noise overfitting; penalization \(\zeta\) mitigates.

### 5.3 Simulated DML vs Naive

```python
import numpy as np
from sklearn.ensemble import RandomForestRegressor
from sklearn.model_selection import KFold

N=2000; p=30
X = np.random.normal(size=(N,p))
e0 = 1/(1+np.exp(-X[:,0]-0.5*X[:,1]))
D = np.random.binomial(1,e0)
g0 = np.sum(X[:,:3],axis=1) + 0.5*X[:,3]**2
Y = 2*D + g0 + np.random.normal(scale=0.5,size=N)

kf=KFold(n_splits=5,shuffle=True,random_state=0)
theta_fold=[]
for train_idx, test_idx in kf.split(X):
    Xt, Xte = X[train_idx], X[test_idx]
    Dt, Dte = D[train_idx], D[test_idx]
    Yt, Yte = Y[train_idx], Y[test_idx]
    m = RandomForestRegressor(200,min_samples_leaf=10).fit(Xt,Dt)
    g = RandomForestRegressor(200,min_samples_leaf=10).fit(Xt,Yt)
    m_res = Dte - m.predict(Xte)
    g_res = Yte - g.predict(Xte)
    # residual on residual regression naive wrong?
    # orthogonal: partialling
    # DML PLR: regress Y_res ~ m_res
    theta = np.sum(m_res*g_res)/np.sum(m_res**2) # placeholder
    theta_fold.append(theta)
print(np.mean(theta_fold))
# Implementation via DoubleML package recommended [2]
```

For proper ATE IRM, use `DoubleML` R or python `doubleml` library: `dml_plr` / `dml_irm`.

### 5.4 California Proposition 99 Replication

Data: annual per-capita cigarette consumption 1970-2000, California (treated 1989+), 38 donors.

Procedure:

1. Predictors: retail price, log income, % youth, consumption lags 1975,1980,1988.
2. Solve QP: weights sparse — Colorado 0.16, Connecticut 0.07, Montana 0.20, Nevada 0.23, Utah 0.33.
3. Pre-MSE 3.9 (packs/cap). Placebo RMSPE ratio California largest among 39 — p=1/39=0.0257 [3].

Augmented/SCM penalty reduces pre-overfit, post-gap similar magnitude -25 packs ~ -25% relative.

### 5.5 Sensitivity Analysis Empirical

Matched reanalysis of smoking → homocysteine elevation: 200 pairs.

For \(\Gamma=1\): one-sided p=0.002. Upper bound:

| Γ | p⁺ bound |
|---|---|
| 1.0 | 0.002 |
| 1.5 | 0.015 |
| 2.0 | 0.048 |
| 2.5 | 0.11 |

\(\Gamma^\star=2.1\). Amplification: \(\Gamma=2.1\) ↔ (Δ=3.5, Λ=3.0) — unmeasured confounder triples odds of heavy smoking and doubles odds of high homocysteine — borderline plausibility [6].

### 5.6 Partial ID Empirical: Job Training

Outcome bounded binary employment within year. Observed employment 60% for trainees, 55% for controls.

No-assumption: \(E[Y(1)] \in [0.18,0.73]\) (since P(D=1)=0.3). Similarly \(E[Y(0)]\in[0.385,0.685]\). Hence \(ATE\in[-0.505,0.345]\) — includes zero, uninformative.

Add MTR: program not harm employment => \(ATE\ge0\), LB=0.

Add MTS: trainees negatively selected (lower baseline) => \(E[Y(0)\mid D=1]\le E[Y(0)\mid D=0]\) => Upper bound ↓ to 0.12. So \(ATE\in[0,0.12]\). Still interval but sign identified [8].

Imbens-Manski 95% CI: \([-0.01,0.15]\) covering width.

## 6. Limitations

* **DML fragility:** Requires product rate \(o(N^{-1/2})\); with deep nets tuning unstable, forest depth trade-off. Overlap near violations cause explosion of DR score variance — trimming \(e(X)\in[0.01,0.99]\) introduces bias.

* **SCM fragility:** Perfect pre-fit often unattainable; RMSPE test low power when donors heterogeneous; spillover SUTVA violation if California policy caused cross-border purchases contaminating Nevada weight. Penalized/ASCM requires choosing \(\lambda\) – cross-validation on time series problematic due to temporal dependence.

* **Rosenbaum Γ:** Logit link parametric, bounded odds model may not capture unbounded U effects; amplification heuristic not formal likelihood; matching quality overt bias residual after matching still conflated with hidden bias — Rosenbaum assumes exact matching or residual adjustment ignored [6].

* **Partial ID width:** Without monotone assumptions, Manski bounds often so wide as to be policy-irrelevant. MTS/MTR/MIV credible only in specific contexts — imposing them incorrectly collapses truth outside interval. Imbens-Manski CI assumes interval independent of sampling width asymptotics — finite-sample undercoverage reported in small N with near-boundary.

* **Computational:** DML K-fold with 500-tree forests 5-fold ~ O(KNT log N) heavy; SCM QP requires convex solver, non-unique when J>T_0. Sensitivity exact p enumeration NP-hard; uses network flow approximations.

## 7. Conclusion

We presented an **integrated causal hierarchy**:

1. Attempt point identification via rich conditioning using DML to accommodate modern ML while preserving √N inference [1][2].
2. When only one unit treated, construct synthetic counterfactual via simplex-constrained factor balancing [3][5], with Augmented/SDID doubly-robust refinement [4].
3. Acknowledge residual hidden confounding via Rosenbaum Γ-bounds [6][7], reporting \(\Gamma^\star\) and amplification.
4. When Γ-paradigm presumes odds-bound model, revert to assumption-free Manski bounds [8], tightening via monotone restrictions and covering via Imbens-Manski intervals [9].

**Practical workflow:**

* Specify causal estimand (ATE vs ATT vs ATET( t )).
* Enumerate required assumptions for each rung.
* Report suite: DML point estimate + CI; SCM placebo p; sensitivity critical Γ; partial ID interval.

*Key lesson:* credible causality in observational studies is not a single number but a **correspondence** mapping assumption strength to identified set. Methods discussed formalize that mapping – from DML’s orthogonal moment under ignorability to Manski’s bounds under no assumptions. Future work links conditional permutation inference for DML, conformal synthetic controls, and ML-powered sensitivity analysis with automatically learned bias models.
