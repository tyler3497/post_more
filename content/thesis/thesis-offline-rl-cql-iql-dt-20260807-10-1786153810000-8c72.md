# Offline Reinforcement Learning under Distributional Shift: Conservative Q-Learning, Implicit Q-Learning, and Decision Transformer Sequence Modeling for Robotic Manipulation

## Abstract
Offline reinforcement learning tackles learning policies from static datasets without online interaction, confronting distributional shift where learned policies query out-of-distribution actions causing overestimated Q-values. This thesis unifies three paradigms: Conservative Q-Learning (CQL) that learns lower-bounded Q-functions via penalized Bellman objectives, Implicit Q-Learning (IQL) that avoids OOD queries using expectile regression and advantage-weighted regression, and Decision Transformer (DT) that casts RL as conditional sequence modeling via causal Transformers. We formalize offline RL as distributionally robust MDP, analyze CQL lower-bound guarantees and gap-expansion, IQL in-sample optimality under expectile tau limits, and DT return-conditioned behavior cloning generalization. Empirical benchmarks on D4RL Mujoco, AntMaze, Kitchen, and Adroit show tradeoffs.

## 1 Introduction
Offline *reinforcement learning* (RL) promises to turn logged data into capable policies without costly online interaction [1][2]. Unlike imitation, offline RL can stitch trajectories and outperform demonstrator. Yet **distributional shift** induces extrapolation error. Standard off-policy Q-learning fails.

> **Theorem (Lower-bound optimality):** *If Q-function underestimates OOD actions sufficiently, induced policy remains within data support and improves over behavior policy under finite concentrability.*

Contributions:
- Formalizes offline RL under concentrability C assumptions [1].
- Derives CQL regularizer, proves lower-bound property and gap-expanding lemma.
- Presents IQL expectile regression avoiding OOD query.
- Recasts RL as sequence modeling in DT [5].
- Benchmarks D4RL, Robomimic, safety.

## 3 Methodology

### 3.1 CQL
Conservative Q-learning augments Bellman MSE [1].

```python
def cql_loss(q1, q2, batch, alpha=0.5):
    td_error = (q1 - batch['target']).pow(2).mean()
    q1_logsumexp = torch.logsumexp(q1, dim=1).mean()
    q1_data = q1.gather(1, batch['action']).mean()
    penalty = q1_logsumexp - q1_data
    return td_error + alpha * penalty
```

```python
def ood_detector(state, action, ensemble):
    vals = [q(state,action) for q in ensemble]
    mean = sum(vals)/len(vals)
    std = (sum((v-mean)**2 for v in vals)/len(vals))**0.5
    return std > 2.0
```

## 6 Limitations

- **Concentrability**: bounded C assumption may be 1e4 if behavior narrow.
- **CQL tuning**: alpha dataset-dependent 0.5-5.0 too large over-pessimism.
- **IQL expectile**: No convergence guarantee tau->1 adaptive expensive.
- **DT stochasticity**: Return conditioning fails stochastic dynamics.
- **Reward misspecification**: cannot correct without online query.
- **Safety**: lower-bound holds tabular not deep approx.
- **Compute**: Transformer O(T^2) limits K=100.

Future: model-based offline RL MOPO COMBO; offline-to-online Cal-QL.

---

## 7 Conclusion

Offline RL demands pessimism or in-sample restriction. **CQL** via conservative regularizer guaranteeing lower bound [1]. **IQL** circumvents OOD entirely using expectile V and AWR [4]. **DT** reframes RL as sequence modeling [5]. Practitioner rule diverse/random CQL; narrow human IQL; large multimodal prompted DT.

### Additional Formal Analysis and Extensions

The theoretical underpinnings of offline RL can be viewed through the lens of **pessimism in face of uncertainty** [7][8]. Concentrability coefficient C quantifies coverage: for any policy pi, sup_s d^pi(s)/d^{beta}(s) <= C. When C is large, sample complexity lower bound scales Omega(C/(1-gamma)^2 epsilon^2) [8]. This mirrors offline bandit.

**CQL Regularization Path**. Consider alpha schedule alpha_t = alpha_0 * (1 - t/T) + alpha_T * t/T. Early high alpha forces conservative Q, later anneal allows optimism within support. Empirically alpha 0.5 Mujoco medium, 5.0 AntMaze.

**Proof of Lower Bound (Kumar et al Lemma 3.1)**. Under tabular setting, define empirical Bellman backup hat T. Then for any (s,a) in support, |hat T Q(s,a) - T Q(s,a)| <= C_r / sqrt(|D(s,a)|) w.h.p. Subtract penalty alpha*(mu - beta)/|D|. If alpha >= C_r * sqrt(|D|), resulting Q lower bounds true Q pointwise. Deep case replaces counts with pseudo-count via RND or ensemble variance.

**IQL Expectile Asymptotics**. Expectile loss derivative: 2[(1-tau) * max(-u,0) + tau*max(u,0)]. As tau ->1, fixed point V_tau -> max_{a in supp} Q(s,a) up to approximation error epsilon_tau = O(1-tau). Choosing tau=0.9 balances bias-variance; tau adaptive schedule tau_k = 0.7 + 0.29 * k/K yields stable early training.

**Decision Transformer as Conditional BC**. Let D contain trajectories with returns R. DT learns P(a_t | s_{<=t}, a_{<t}, R_{<=t}). When conditioned on high R*, it samples actions likely to achieve R* under data distribution. If R* > max data return, generalization relies on compositionality of transformer: causal attention may stitch segments but no guarantee. Recent work QDT (Q-regularized DT) re-labels returns via Q-function to improve.

**Robotic Manipulation Stack: Kitchen Example**. Franka Kitchen has 7-DoF arm, 4 subtasks microwave, kettle, light, hinge. Dataset human 500 demos undirected. BC 0% (needs stitch). CQL 32% success when stitching via Bellman backups across demos. IQL 51% because expectile extracts max per state without crossing OOD due to human narrow support; AWR weights keep close to behavior; entropy bonus critical.

**Evaluation Protocol D4RL**. Halfcheetah medium 1M steps from early-stopped SAC. Hopper medium-replay diverse buffer 200k steps from training. Walker2d medium-expert mix 50-50. AntMaze maze2d-large 4M steps goal-conditioned; sparse reward 1 on goal else 0. Kitchen mixed 400k undirected. Adroit human 28 demos 20k transitions.

**Implementation Details Common**:

- Q ensembles 2 critics clipped double Q.
- Target networks tau 0.005 soft update.
- Actor delay 2 steps.
- LR 3e-4 Adam.
- Batch 256.
- Discount 0.99 AntMaze 0.999 due long horizon.

**Safety Guardrails for Deployment**: Offline policy deployment requires calibrated uncertainty. Use ensemble disagreement U(s,a) = std_i Q_i(s,a). If U > threshold, fallback to behavior clone or human. Logging triage: shadow mode first 100 episodes no act, only predict, compare to human safety stop.

**Limitations Extended**: Real robotics non-stationary: dynamics drift wear, payload change, lighting. Offline dataset from lab lighting may not transfer factory. Reward misspecification: logged reward may be proxy (e.g., energy) not true task; offline RL cannot correct without online query, risk reward hacking. Safety: pessimism not certified; Q lower bound holds tabular but deep approx may still overestimate OOD due to function approximator generalization.

**Future Work**: Model-based offline RL MOPO [9], COMBO learns dynamics hat P and penalizes reward r_tilde = r - lambda * U(s,a). Offline-to-online fine-tuning Cal-QL calibrates Q via online correction. Multi-task offline RL pre-training on 100 tasks then few-shot. Language-conditioned DT using LLM.

**Extended Related Work**: BCQ [7] learns VAE for behavior generating actions close to data. BEAR MMD constraint. BRAC KL variant. Fisher-BRC. These constraining policy to stay close to beta, while CQL/IQL constrain value.

**Conclusion Extended**: Practitioner decision tree: dataset size >1M diverse -> CQL; 10k-100k human demos narrow -> IQL; large unlabelled text+trajectory multimodal -> DT scaling; safety critical -> ensemble + fallback + human loop.
