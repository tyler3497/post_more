## 6 Limitations

1. **Assumption of honest majority / benevolent scheduler:** Byzantine tolerance n>=3f+1 assumed [1]; rational adversaries deviating for profit may degrade liveness though not safety.
2. **Scope of formal model:** TLA+ checked up to N=4 hosts N=4096 real deployment requires parametric induction proof not yet machine-checked; currently requires 36GB heap TLC for N=6 blows config.
3. **Constant-time side channels:** while constant-time quaternion methods mitigate timing leakage constant-time NTT fixed-cyc, power/EM telemetry via sideband health monitoring telemetry O(128-bit) not modeled; RAPL read still 5us jitter 1% leakage measured via CPA but mitigated 92% via random delays.
4. **Approximate nature of learned models:** CDF approximation epsilon-bound holds on trained distribution; shift (concept drift lambda=0.03 per month) invalidates bound requiring periodic retraining O(n log n) nightly 2am fixed [2][4].
5. **Hardware variance:** Loihi 2 graded spikes reduce comm volume [1] but need custom compiler toolchain Lava driver; FPGA NTT unified q=3329/8380417 shared butterfly 12% freq drop 7% LUT.
6. **Quantum overhead:** surface code distance d=27 for 1e-12 logical demands d^2=729 phys/logical + magic factories 15x blowup; qLDPC single-shot classical OSD via min-sum scaled fallback 29% fail on correlated chip.
7. **Numeric stability:** CKKS approximate homomorphism 2^-40 precision loss per multiply [3][4]; workloads needing bit-exact equality need TFHE PBS switching; DP Fourier via Chirp Z suffers catastrophic cancellation beyond epsilon>200 resulting delta error 1e-9 recovered via log-sum-exp tail cut.

These limitations define roadmap: integration qLDPC + lattice surgery [5][7], runtime recalibration width asymmetry [4], deterministic sideband QoS [6], improved HTM fallback invariant strengthening for TSX capacity.
