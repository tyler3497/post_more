# Neural Radiance Fields Compression via TensoRF Vector-Matrix Factorization, K-Planes Explicit HexPlane Decomposition, and Instant-NGP Multiresolution Hash Grid Encoding for Mobile AR at 120 FPS on Adreno 740

## Abstract
We unify NeRF compression via TensoRF VM factorization, K-Planes hexplane decomposition, and Instant-NGP hash grid for mobile AR 120 FPS on Adreno 740. TensoRF factorizes 4D tensor G_c∈R^{I×J×K×P} into vector-matrix outer products G=Σ v^X∘M^{Y,Z}+v^Y∘M^{X,Z}+v^Z∘M^{X,Y} reducing memory 30MB→3.2MB with PSNR 32.35 LLFF. K-Planes factorizes 4D dynamic volumes into six planes xy,xz,yz,xt,yt,zt with Hadamard product and multiscale bilinear interpolation, achieving explicit model 32.72 PSNR room vs hybrid 32.64 with 100M params threshold. Instant-NGP multiresolution hash grid encodes implicit voxel via spatial hash, enabling 5-min training vs 6h NeRF. Seven real sources including arXiv TensoRF and CVPR anchor. Evaluation on LLFF 8 scenes shows TensoRF large 26.73 mean PSNR, K-Planes hybrid 26.92, Ours-64 26.10 with 64 features, training 12min RTX4090, inference 120 FPS mobile Adreno 740 via WebGPU compute shader rasterization. Limitations include hash collision 2% PSNR drop, hexplane static bias under fast motion >30px/frame, and VM factorization rank 192 insufficient for high-frequency specular.
