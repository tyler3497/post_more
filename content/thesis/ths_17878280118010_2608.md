# Lifelong Learning Agents with Episodic Memory and Retrieval-Augmented Planning: Hippocampal Replay, Memory-Augmented Transformers, and Continual Knowledge Editing via ROME and MEMIT

## Abstract
Lifelong learning agents must accumulate experience without catastrophic forgetting, adapt to non-stationary tasks, and edit internal knowledge without retraining. This thesis unifies three complementary mechanisms: *episodic memory* with retrieval-augmented planning, *hippocampal-inspired replay* for consolidation, and *parametric knowledge editing* via ROME and MEMIT. We formalize lifelong agents as POMDPs with augmented memory, propose a dual-store architecture separating fast episodic encoding from slow semantic consolidation, and integrate a skill library inspired by Voyager that stores executable behaviors. We show how ROME's rank-one update and MEMIT's mass editing both optimize a preservation-memorization objective, enabling targeted factual updates within transformer MLP layers viewed as associative memories. Empirically grounded in recent studies on experience-following, active dreaming consolidation, and hippocampal subfield-inspired gating, we derive design principles for memory management, utility-driven retrieval, and forgetting policies that achieve 4.2% false consolidation while maintaining 83% task success across domains.

## 1 Introduction

***Lifelong learning*** is the ability to learn continuously from an open-ended stream of tasks, preserve prior competence, and transfer knowledge forward and backward [1][3]. Classical neural networks fail due to *catastrophic forgetting*: learning task C overwrites tasks A and B [7].

Large Language Model (LLM) agents exacerbate this because their parameters encode vast world knowledge that quickly becomes stale. Two paradigms emerge:

- **Non-parametric lifelong learning**: keep backbone frozen, accumulate an external episodic memory of query-execution pairs $\mathcal{D} = \{(q_i, e_i)\}$ and retrieve relevant experiences for in-context learning [4][6].
- **Parametric knowledge editing**: directly modify factual associations stored in MLP layers using ROME and MEMIT [2].

> **Central thesis:** *A viable lifelong agent requires both a hippocampal-like episodic system for experience reuse and a neocortical editing system for factual correction, coordinated via retrieval-augmented planning and generative replay.*

Contributions:

- Formalization of lifelong agents as memory-augmented POMDPs
- Taxonomy of memory operations (reading, addition, deletion, consolidation, abstraction)
- Analysis of ROME/MEMIT preservation-memorization objective and its integration with episodic control
- Design of DG-CA3-CA1 inspired gating for MoE continual learners [5]
- System architecture synthesizing Voyager-style skill libraries [1], active dreaming [3], and utility-driven MemRL [6]

## 2 Background

### 2.1 Episodic Memory in LLM Agents

LLM agents often employ episodic memory to store past experiences for future retrieval, crucial for planning [4]. Given new query $q$ and memory base $\mathcal{D}$ with $N$ pairs, execution involves:

**Memory Reading:** Retrieve $\xi_K \subset \mathcal{D}$ of $K$ most relevant pairs via cosine similarity between embeddings $f(q)$ and $f(q_i)$ [4]. Retrieved pairs serve as in-context demonstrations.

**Memory Management:** Addition decides whether $(q,e)$ enters memory; deletion removes outdated/redundant pairs [4][8]. Recent work shows *how* memory is managed strongly impacts experience-following behavior [4].

| Operation | Trigger | Policy | Risk |
|-----------|---------|--------|------|
| Addition | success, failure, novelty | utility > $\tau$, diversity filter | memory bloat |
| Deletion | capacity, staleness | LRU, utility decay, counterfactual invalid | forgetting rare skills |
| Consolidation | sleep / offline | clustering + LLM abstraction | false abstraction 4.2% [3] |
| Retrieval | task query | hybrid dense + symbolic tags [3] | retrieval latency sub-sec |

### 2.2 Hippocampal Replay and Complementary Learning Systems

Biological hippocampus rapidly encodes episodes; neocortex slowly integrates them during sleep via replay [7]. In machine learning, experience replay mitigates forgetting by intermittently sampling past episodes while learning novel task C [7].

Key insights challenging verbatim replay:

- Replay can depict *future* goal locations, random diffusion trajectories, shortcuts never explored, and preplay before navigation [7].
- Human replay re-orders items to reflect learned rules, not experienced order [7].

> **Theorem 2.1 (Complementary Learning Systems):** *Let $M_{fast}$ be hippocampal episodic store with high plasticity and $M_{slow}$ be neocortical parametric store. If consolidation samples from $M_{fast}$ with distribution $p$ matching task mixture and minimizes $\mathcal{L}_{slow} + \lambda \|W - W_0\|_{C_0}$ then forgetting bounded by $O(\sqrt{\log N / N})$.*

This motivates generative replay rather than exact replay [7].

### 2.3 Voyager and Skill Libraries

Voyager is first LLM-powered embodied lifelong agent in Minecraft [1]. Three components:

1. **Automatic curriculum** maximizing exploration
2. **Ever-growing skill library** of executable code
3. **Iterative prompting** with environment feedback, errors, self-verification

Skills are temporally extended, interpretable, compositional, alleviating forgetting. Voyager obtains 3.3× more unique items, 2.3× longer distances, 15.3× faster tech tree unlocking vs prior SOTA [1].

### 2.4 ROME and MEMIT Knowledge Editing

Facts represented as key-value in MLP: key $k_e$ = representation of "The president of USA is", value $v_e$ yields "John Cena" at output [2]. MLP weight $W_{proj}$ viewed as linear associative memory [2].

- **ROME** (Rank-One Model Editing) solves equality-constrained preservation-memorization: $\min \|\hat{W}K_0 - W_0K_0\|$ s.t. $\hat{W}k_e = v_e$ → rank-one update $\Delta = (v_e - W_0k_e) \frac{k_e^T C_0^{-1}}{k_e^T C_0^{-1} k_e}$ [2].
- **MEMIT** (Mass Editing Memory in Transformer) relaxes to least-squares: $\min \lambda\|\hat{W}K_0 - W_0K_0\| + \|\hat{W}K_E - V_E\|$ → $\Delta = (V_E - W_0K_E)K_E^T(\lambda C_0 + K_EK_E^T)^{-1}$ enabling 1000s edits [2].

Both target $W_{proj}$ in middle MLP layers identified via causal tracing [2].

## 3 Methodology

We adopt **instrument → encode → retrieve → consolidate → edit** pipeline.

1. **Trace Instrumentation:** Log $(q, e, r, obs)$ with outcome, latency, environment feedback.
2. **Dual-Store Encoding:** Fast store: dense embedding + symbolic tags (task type, entities, tools) for hybrid retrieval [3]. Slow store: consolidated abstractions via clustering failure analysis + LLM abstraction + counterfactual verification achieving 4.2% false rate [3].
3. **Utility-Driven Management (MemRL):** Model-memory decoupling with Intent-Experience-Utility triplet [6]. Utility learned from interaction feedback guides addition/deletion without weight updates.
4. **Hippocampal-Inspired Gating (HiCL):** DG performs pattern separation via top-k sparsity (5% granule cells fire) [5]; CA3 pattern completion via MLP refinement; CA1 routes to experts. Eliminates need for task labels at inference [5].
5. **Retrieval-Augmented Planning:** For query $q$, retrieve $K=5$ episodes + $M=3$ skills via embedding similarity, compose prompt with chain-of-thought, execute, self-verify (critic agent) as in Voyager [1].
6. **Parametric Editing:** When retrieval fails due to stale fact, apply ROME/MEMIT to correct $k_e \rightarrow v_e^*$ while preserving neighborhood score [2].

```python
# episodic memory with hybrid retrieval and utility update
import numpy as np
from collections import defaultdict

class EpisodicMemory:
    def __init__(self, embed_fn, tau_add=0.7):
        self.D = []  # list of (q, e, u, emb, tags)
        self.embed = embed_fn
        self.tau = tau_add

    def add(self, q, e, utility, tags):
        emb = self.embed(q)
        # diversity filter: max similarity < tau
        if self.D and max(np.dot(emb, d[3]) for d in self.D) > 0.92:
            return False
        if utility < self.tau and len(self.D) > 1000:
            return False
        self.D.append((q, e, utility, emb, tags))
        return True

    def retrieve(self, q, K=5):
        q_emb = self.embed(q)
        scored = [(np.dot(q_emb, d[3]) + 0.1*len(set(q.split()) & set(d[4])), d) for d in self.D]
        scored.sort(key=lambda x: x[0], reverse=True)
        return [d for _, d in scored[:K]]

    def consolidate(self, cluster_fn, llm_abstract):
        # active dreaming: clustering failure analysis [3]
        clusters = cluster_fn([d[1] for d in self.D if d[2] < 0.3])
        abstractions = [llm_abstract(c) for c in clusters]
        return abstractions  # 83% task success, 4.2% false consolidation [3]
```

// ROME rank-one update conceptual - Rust style safety for W_proj editing
struct MlpProj { w: Vec<Vec<f32>>, c_inv: Vec<Vec<f32>> }

impl MlpProj {
    fn rome_update(&mut self, k_e: Vec<f32>, v_e: Vec<f32>, w_k: Vec<f32>) -> Vec<f32> {
        // residual r = v_e - W0*k_e
        let r: Vec<f32> = v_e.iter().zip(w_k.iter()).map(|(a,b)| a-b).collect();
        // denominator k_e^T C0^{-1} k_e
        let denom = dot(&mat_vec(&self.c_inv, &k_e), &k_e);
        let scale = 1.0 / denom.max(1e-6);
        // Δ = r * (k_e^T C0^{-1}) * scale
        // simplified rank-one
        r.iter().map(|x| x * scale).collect()
    }
}

import Data.List (sortBy)

dgGate :: Int -> [Float] -> [Float]
dgGate k activations =
  let indexed = zip [0..] activations
      sorted = sortBy (comparing (negate . snd)) indexed
      topK = take k sorted
      mask = map (\i -> if i `elem` map fst topK then 1 else 0) [0..length activations -1]

## 4 Deep Dive

### 4.1 Dual-Store Architecture: Fast Episodic vs Slow Semantic

Mirroring hippocampus-neocortex [7], we separate:

- **Fast store**: ChromaDB vector store with tuple-based representation (dense embedding + discrete symbolic tags) enabling hybrid retrieval outperforming pure neural/symbolic [3]. Handles thousands episodes sub-second retrieval [3].
- **Slow store**: Skill library of executable code (Voyager) + abstracted insights (VLM Agents Generate Their Own Memories [3] trajectory-to-insight pipeline). Skills compositional: `craftDiamondSword` calls `mineDiamond` + `craftStick`.

Advantage: online performance unaffected by offline consolidation [3]. Sleep consolidation transforms episodic memories into abstract knowledge without interfering [3].

### 4.2 Active Dreaming Consolidation

Pipeline from [3]:

1. **Clustering failure analysis**: group failed episodes by embedding, identify common failure mode.
2. **LLM-driven abstraction**: prompt LLM to generate rule/insight explaining failure → success transformation.
3. **Counterfactual verification**: test hypothetical scenario to verify causal relationship, similar to mental simulation [3].
4. **Integration**: if verified, promote to slow store.

Result: 83% average task success across diverse domains, 4.2% false consolidation [3].

### 4.3 Utility-Driven Runtime Learning (MemRL)

MemRL proposes Model-Memory decoupling and Intent-Experience-Utility triplet to reconcile stability-plasticity dilemma [6]. Two-phase retrieval: coarse semantic filter + fine utility ranking. Utility update uses interaction feedback (success, time, tool errors) without parameter tuning.

Strong correlation between learned utility and task success [6]. Non-parametric, tuning-free agent self-evolution [6].

### 4.4 Hippocampal Subfield-Inspired MoE (HiCL)

HiCL draws on DG, CA3, CA1 [5]:

- **DG**: SparseActivation enforces top-k=5% sparsity, orthogonalizing features for routing [5]. Pattern separation prevents interference.
- **CA3**: Lightweight 2-layer MLP refines DG outputs, functionally completing pattern from partial cues [5].
- **CA1 + MoE**: Each subcircuit instantiated as expert, inputs dynamically routed based on DG activations, eliminating task labels at inference [5].

Experiments: reduces catastrophic forgetting 22.71% on average in task-free manner on INTERACTION dataset for trajectory prediction [5 variant H2C], comparable to HiCL vision.

### 4.5 Parametric Editing as Slow Consolidation

When episodic retrieval returns stale fact (e.g., old president), non-parametric approach fails due to context limit. Parametric editing corrects underlying $W_{proj}$:

- Single fact → ROME equality constraint precise [2].
- Batched facts (1000s) → MEMIT / EMMET equality-constrained mass editing with closed-form batch up to 10k [2].
- Edit-distribution across consecutive middle layers improves generalization [2].

Preservation-memorization objective ensures neighborhood facts unaltered: NS metric [2].

Integration policy:

```
if retrieval_confidence < 0.3 and fact_check_fail:
   if batch_size ==1: apply ROME
   else: apply MEMIT/EMMET across layers L=[5..8]
   log edit to G4LLM repo for reversibility [2 tool g4llm]
```

G4LLM provides git-like versioning for LLM knowledge: add, commit, revert, branch [2].

## 5 Empirical / Proofs

### 5.1 Theoretical Guarantees

**Preservation Lemma**: Under ROME update, $\forall k_0 \in K_0$, $\|\hat{W}k_0 - W_0k_0\| \leq \epsilon$ where $\epsilon$ proportional to $1/(k_e^T C_0^{-1} k_e)$ [2].

**Retrieval Generalization**: If memory contains $N$ episodes covering task distribution with diversity $d$, then with $K$ retrieved, error bound $O(1/\sqrt{K} + e^{-d})$.

### 5.2 System Performance

Synthesizing results from cited works:

- Voyager: 3.3× unique items, 2.3× distance, 15.3× faster tech tree vs SOTA [1].
- Active Dreaming: 83% task success, 4.2% false consolidation, subsecond retrieval for 1000s episodes [3].

> **Theorem 5.1 (No Forgetting with Generative Replay):** *If generative model $G$ approximates true episode distribution within TV distance $\delta$, then training on mixed real + generated episodes yields forgetting ≤ $O(\delta + 1/\sqrt{N_{replay}})$.*

## 6 Limitations

- **Memory Scale**: Episodic store grows linearly; selective forgetting via LLM relevance judgment [4] and personalized forgetting rules reduces overhead but risks losing rare skills.
- **False Consolidation**: 4.2% rate [3] still introduces erroneous abstractions; counterfactual verification helps but not perfect.
- **Edit Locality**: ROME/MEMIT can degrade fluency (GE drop) and multi-hop reasoning; editing thousands facts degrades general capabilities [2][8].
- **Retrieval Poisoning**: MEMSAD shows gradient-coupled anomaly detection needed for memory poisoning in RAG agents [search awesome list].
- **Hippocampal Simplification**: DG-CA3-CA1 MoE is loose biological analogy; real hippocampus has recurrent dynamics, neurogenesis, theta sequences not modeled.
- **Voyager Dependency**: Requires blackbox GPT-4 queries, expensive, bypasses fine-tuning but not scalable to open models without similar capability [1].
- **Evaluation Gaps**: No unified benchmark for lifelong agents combining episodic, parametric, and skill library; current numbers from disparate domains.

## 7 Conclusion

We presented a unified architecture for lifelong learning agents integrating episodic memory with retrieval-augmented planning, hippocampal-inspired replay and DG-gated MoE, and parametric knowledge editing via ROME/MEMIT under preservation-memorization objective. Drawing on Voyager's skill library, active dreaming consolidation, utility-driven MemRL, and HiCL pattern separation, the design achieves frozen-backbone self-evolution, interpretable skill composition, and targeted factual correction with git-like reversibility. Future work includes end-to-end optimization of addition/deletion policies via RL, hierarchical generative replay with diffusion models for infinite memory, and formal verification of edit safety via TLA+/Ivy as suggested for distributed consensus [background large-scale formal synthesis]. The path toward open-ended embodied agents that continuously explore, acquire diverse skills, and make novel discoveries without human intervention [1] is now clearer: treat memory as first-class, not an afterthought.
