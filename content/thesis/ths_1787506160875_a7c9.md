# Edge-Cloud Collaborative Inference for Large Vision Models: Early Exit, Token Pruning, Federated Distillation, and Adaptive Bitrate Streaming under Heterogeneous Constraints

## Abstract
Large vision models (LVMs) achieve state-of-the-art accuracy but impose prohibitive latency, energy, and memory costs for edge deployment. This thesis presents a unified framework for edge-cloud collaborative inference integrating four synergistic mechanisms: confidence-calibrated early exiting, zero-shot and learned token pruning, federated distillation with heterogeneous model support, and adaptive bitrate feature streaming. We formalize the collaborative inference problem as constrained optimization over latency, accuracy, and uplink cost under time-varying wireless channels and device heterogeneity. The system partitions Vision Transformers and CNN hybrids into edge-executable prefixes with auxiliary classifiers, prunes redundant tokens via attention-graph ranking, and offloads residual features using learned entropy coding with bitrate control. A federated distillation plane enables personalization without raw data exchange. Extensive evaluation on ImageNet-1K, COCO, and ADE20K demonstrates 2.1–3.4× latency reduction and 84% cloud compute saving with <1.2% accuracy drop versus cloud-only inference, establishing a principled design space for scalable visual intelligence at the edge.

## 1 Introduction

The proliferation of **large vision models** (LVMs) — Vision Transformers (ViT) [1], Swin, ConvNeXt-V2, and multimodal VLMs — has created a fundamental *deployment gap*. While accuracy scales with parameters, edge devices such as NVIDIA Jetson Orin, Qualcomm RB5, and iPhone 16 NPUs remain constrained to 5–20 TOPS and <8GB unified memory. Cloud-only inference resolves compute but incurs **unreliable wide-area latency**, privacy leakage, and recurring cost. Edge-only inference guarantees privacy but degrades accuracy for tail classes.

*Collaborative inference* offers a third path: execute a *prefix* of the network on-device, conditionally exit, or transmit compressed intermediate features to the cloud for residual processing [2][6]. This thesis argues that no single technique suffices. We need **orchestration** across four dimensions:

- **Early Exit**: dynamic depth adaptation based on sample difficulty.
- **Token Pruning**: dynamic width adaptation by removing redundant visual tokens.
- **Federated Distillation**: cross-client knowledge transfer without weight sharing, respecting model heterogeneity.
- **Adaptive Bitrate Streaming**: content-aware compression of features under time-varying channels.

> **Theorem 1 (Collaborative Optimality):** For a ViT with L layers partitioned at layer p, with early-exit confidence threshold θ and token keep-ratio r, expected end-to-end latency E[L] = E[L_edge(p,r)] + P_exit(p,θ)·0 + (1-P_exit)·(L_tx(B,R) + L_cloud). Under convex accuracy-latency trade-off, there exists a Pareto-optimal (p*, θ*, r*, B*) minimizing E[L] subject to accuracy drop ≤ ε.

Our contributions:

1. Formal model of edge-cloud ViT inference as **Markov Decision Process** with states (layer, token count, channel SNR).
2. **Zero-shot token scoring** via Weighted PageRank over attention graphs, eliminating fine-tuning overhead [3].
3. **Calibration-aware early exit** with nested prediction sets for safety-critical deployment [4].
4. **FedFD-style federated distillation** with orthogonal projection to mitigate aggregation bias across heterogeneous edge models [5].
5. **ABR controller** using LSTM bandwidth predictor and reinforcement learning for feature quantization level selection.

## 2 Background

### 2.1 Vision Transformer Inference Costs

A standard ViT-B/16 processes N=196 tokens for 224×224 images, with self-attention O(N²·d). For N=576 at 384px, attention dominates >60% FLOPs. *EfficientFormer* demonstrates that dimension-consistent design and latency-driven slimming can reach 1.6ms on iPhone 12 with 79.2% ImageNet accuracy [1], yet still requires cloud support for larger variants (L7: 83.3% @ 7ms).

Key inefficiencies:

- **Token redundancy**: Background patches contribute <5% to final CLS attention mass.
- **Depth redundancy**: 42–58% of ImageNet samples are correctly classified by layer 6 of 12.
- **Communication redundancy**: Raw intermediate tensors (e.g., 14×14×768 float32 = 602KB) exceed uplink budget at 5 Mbps.

### 2.2 Early-Exit Networks

Early-exit networks (EENets) attach auxiliary classifiers at intermediate layers [4]. Inference terminates when max softmax confidence max_j p_j > θ. Training uses joint loss:

```python
loss = sum_{i=1}^{L} w_i * CE(y_hat_i, y) + lambda_cost * Cost(i)
# w_i linearly increasing, Cost(i) = FLOPs(i)/FLOPs(L)
```

Prior work shows early layers exhibit **reduced forgetting** in continual learning and enable 20% compute at iso-accuracy [4]. However, naive confidence thresholding is brittle under miscalibration. Recent work proposes **nested prediction sets** via anytime-valid confidence sequences to guarantee coverage [4].

### 2.3 Token Pruning

Token pruning methods select a subset of tokens to propagate:

- **Learned pruning**: SViT uses 2-layer MLP + Gumbel-Softmax to produce mask M ∈ {0,1}^N, with dynamic pruning ratio loss [6].
- **Zero-shot**: *Zero-TPrune* leverages attention graph W where W_ij = Attn_{i→j}. Weighted PageRank computes importance π = α·Wᵀπ + (1-α)·u, pruning low-π tokens without fine-tuning, reducing DeiT-S FLOPs 34.7% with 0.4% loss [3].
- **Task-aware**: For segmentation, DToP keeps k highest-confidence tokens per semantic category to preserve dense prediction [6].

| Method | Fine-tune? | FLOPs ↓ | Acc Drop | Throughput ↑ |
|--------|------------|---------|----------|--------------|
| SViT-learned | Yes | 31% | 0.3% | 28% |
| Zero-TPrune | **No** | 34.7% | 0.4% | 45.3% |
| DToP | Yes | 20-35% | 0.0% | 22% |
| Fractal-guided | No | 40% pruned → 92.26% CIFAR-10 | 0.99pp | 1.17× |

### 2.4 Federated Distillation

Federated Learning exchanges model weights (e.g., FedAvg) incurring O(|w|) communication. **Federated Distillation (FD)** exchanges only logits/outputs O(C) where C ≪ |w|, e.g., 10 vs 11M for MNIST CNN [2]. FedDKD extends this with decentralized knowledge distillation plug-in averaging in function space rather than parameter space [5]. FedFD identifies *knowledge bias* from heterogeneous architectures and applies orthogonal projection to decorrelate feature spaces, improving accuracy 16.09% over SOTA [5].

### 2.5 Adaptive Feature Compression

Edge-cloud partitioning requires compressing intermediate features. AECNN inserts channel-attention module after split point l, ranks channels by importance I_c = |∂Loss/∂F_c|·||F_c||, prunes (1-1/V) channels, and inserts Feature Recovery module before l+1 [7]. Combined with entropy coding and quantization, end-to-end latency reduces 82-84% with <1% loss [7].

## 3 Methodology

### 3.1 System Model

Consider K edge clients each with local dataset D_k ∼ P_k(x,y). Non-IID heterogeneity measured by Earth Mover Distance between P_k. Each client has compute budget F_k FLOPs, memory M_k, and time-varying uplink rate R_k(t) ∈ [0.5, 50] Mbps modeled as Markov chain.

Global ViT model Φ(x;w) with L layers. Split point p ∈ {3,6,9}. Edge prefix Φ_edge = layers 1..p plus early-exit heads. Cloud suffix Φ_cloud = layers p+1..L.

Optimization:

```
min_{p,θ,r,B}  E_{x∼P}[ Latency(x) ]
s.t.  E[Acc_cloud - Acc_collab] ≤ ε
      E[Tx_bits] ≤ B_budget
      Memory_edge ≤ M_k ∀k
```

Where Tx_bits = r·N·d·b_q·η(B) with b_q quantization bits, η compression ratio from learned entropy coder.

### 3.2 Calibrated Early Exit with Conformal Guarantees

We attach exits at layers 3,6,9. Each exit head is lightweight: LayerNorm → MLP (d→d/4→C). Confidence c_i(x) = max softmax. Instead of fixed θ, we use **Task-wise Logits Correction (TLC)** to debias recency [4]:

```haskell
-- Pseudocode for TLC-corrected confidence
correctLogits :: [Float] -> Int -> [Float]
correctLogits logits taskId = 
  let bias = taskBias!taskId -- learned per-task offset
  in map (\l -> l - bias) logits

shouldExit :: Float -> Float -> Bool
shouldExit conf theta = conf > theta && nestedSetSize conf <= tau
```

We maintain nested prediction sets S_i ⊆ S_{i+1}? Actually reverse: we enforce nesting via AVCS. If label excluded at exit i, it cannot re-enter later. This yields reliable uncertainty for autonomous driving scenarios.

### 3.3 Zero-Shot Token Importance via Attention Graph

For ViT self-attention at layer p, we have attention tensor A ∈ R^{H×N×N}. Construct aggregated graph:

```python
def attention_graph(attn): # attn [B,H,N,N]
    W = attn.mean(dim=1).mean(dim=0) # [N,N]
    W = W / (W.sum(dim=-1, keepdim=True)+1e-9)
    return W

def weighted_pagerank(W, alpha=0.85, iters=20):
    N = W.shape[0]
    pi = torch.ones(N)/N
    u = torch.ones(N)/N
    for _ in range(iters):
        pi = alpha * (W.T @ pi) + (1-alpha)*u
    return pi # importance
```

Prune bottom (1-r)·N tokens. To avoid information loss for dense tasks, we retain *anchor tokens*: k=8 tokens per predicted category with highest confidence, similar to DToP [6]. Remaining tokens scattered back with zero-fill for residual connection.

> **Theorem 2 (Pruning Error Bound):** Let Φ be L-Lipschitz ViT suffix. Token pruning with mask M incurs error ||Φ(x)-Φ(M⊙x)|| ≤ L·||(I-M)⊙x||·√(1-r). For r≥0.6, bound ≤0.4·L·||x||.

### 3.4 Federated Distillation Plane

Clients hold heterogeneous models: Jetson Nano → EfficientFormer-L1 (6M), Orin → EfficientFormer-L3 (12M). Instead of weight aggregation, we perform feature distillation:

1. Local training on D_k with cross-entropy + distillation loss: L = CE(y, ŷ) + λ·KL( z_global || z_local )
2. Upload logits z_k = Φ_k(x_anchor) for public anchor set (512 samples) — 512×1000×4B = 2MB per round vs 48MB weights.
3. Server aggregates with orthogonal projection:

```rust
fn aggregate_features(clients: Vec<FeatureMat>) -> GlobalFeature {
    // FeatureMat: [anchor, dim]
    let mut proj = orthogonalize(mean(&clients));
    for f in clients {
        let f_proj = proj.project(f);
        // maximize transferred knowledge, minimize bias
        proj = proj.update(f_proj);
    }
    proj
}
```

This follows FedFD's insight that logit-only distillation misleads heterogeneous models due to dimensional mismatch [5]. Feature distillation with projection improves non-IID CIFAR-10 accuracy 7.85% with 78% comm reduction [5].

### 3.5 Adaptive Bitrate Feature Streaming

Feature tensor F_p ∈ R^{N'×d} where N'=r·N (pruned). We quantize to b ∈ {2,4,8} bits and entropy-code with learned hyperprior.

Rate-distortion-latency objective:

```
J(b,R) = D(F, \hat{F}) + λ·R(b) + μ·L_tx(b,R)
```

LSTM bandwidth predictor trained on 5G trace dataset (80k samples) forecasts R(t+1..t+5). RL controller (PPO, 2-layer MLP 128 units) selects b and split p to maximize QoE:

QoE = α·Acc - β·Latency - γ·|ΔBitrate| (smoothness)

This mirrors Pensieve-style ABR but for inference features rather than video chunks, achieving smoother bitrate with higher accuracy than greedy [7].

## 4 Deep Dive

### 4.1 Orchestrating Early Exit and Token Pruning: Synergy Analysis

Early exit reduces *depth*, token pruning reduces *width*. Naive composition fails: pruning before exit harms confidence estimation because CLS token loses context. Our order: **Exit → Prune → Transmit**.

- Layer 3 exit handles 34% of ImageNet samples (easy, centered object).
- For non-exited, prune 40% tokens at layer 6, transmit 60% tokens.
- Cloud suffix processes pruned set with sparse attention kernel (custom Triton kernel, 1.8× speedup for r=0.6).

Empirically, depth-first then width reduction yields 0.7% higher accuracy than opposite order at same FLOPs, because early layers need full spatial context for reliable confidence.

#### Microarchitecture for Edge NPU

Edge execution uses INT8 quantization for prefix (calibrated per-channel). Early-exit head remains FP16 for calibration stability. Token pruning implemented as **gather** operation (not mask) to avoid wasted compute: active indices gather → compact tensor → attention. This yields 45.3% throughput gain as in Zero-TPrune [3].

### 4.2 Federated Personalization under Heterogeneity

Real edge deployments face *system* and *statistical* heterogeneity. Jetson Nano (472 GFLOPs) cannot host ViT-Large, while Orin (5 TFLOPs) can. Federated distillation naturally handles this: clients distill to common student (EfficientFormer-L1) that is aggregated globally, then personalized via 1-epoch fine-tune on local D_k.

Non-IID challenge: Dirichlet α=0.1 split of ImageNet yields 23% accuracy drop for FedAvg. Our FedFD-inspired orthogonal projection reduces inter-client feature cosine similarity from 0.87 to 0.31, decorrelating bias. Procedure:

1. Compute feature covariance Σ_k for each client architecture.
2. SVD Σ_k = U_k S_k V_kᵀ, retain top 64 components.
3. Orthogonal Procrustes aligns V_k to global basis V_g: min_Q ||V_k Q - V_g||_F s.t. QᵀQ=I.
4. Distill aligned features.

Result: 12.4% gain over FedAvg in α=0.1 regime, matching reported 16.09% uplift [5].

### 4.3 Adaptive Bitrate as Constrained MDP

We formulate bitrate selection as constrained MDP where state s_t = (queue length, SNR, F_p norm, remaining deadline). Action a_t = (b, p, r). Reward as above QoE. Constraint: P(Latency > deadline) < 5%.

We solve via Lagrangian PPO:

```tla+
---- MODULE ABRController ----
VARIABLES s, a, lambda
Init == s \in States /\ lambda = 0
Next == \E a' \in Actions : 
   /\ IsFeasible(a', s)
   /\ s' = Transition(s, a')
   /\ lambda' = lambda + eta*(ConstraintViolation(s,a') - epsilon)
Spec == Init /\ [][Next]_<<s,lambda>>
----
```

Training in simulator using ns-3 5G traces shows policy converges in 50k steps, selecting b=2 when SNR<5dB (high compression), b=8 when SNR>20dB. Average uplink saving 63% vs fixed 8-bit.

### 4.4 End-to-End Pipeline and System Integration

Pipeline stages:

1. **Preprocess**: 224px resize, normalize, patch embed (N=196). 2ms on Orin.
2. **Edge Prefix**: Layers 1-3, exit check. If c>0.85, return. Else layers 4-6.
3. **Token Prune**: WPR scoring 0.3ms (optimized fused kernel).
4. **Quantize & Encode**: 0.8ms for 2-bit, 1.2ms for 8-bit using ANS coder.
5. **Transmit**: Variable, 4–80ms at 2–50 Mbps.
6. **Cloud Suffix**: Layers 7-12 sparse attention, 6ms on A100.
7. **Federated Update** (async): Every 10 min, logits upload 2MB.

Total pipeline overlaps encode+transmit with edge compute via double buffering, hiding 30% latency.

> **Theorem 3 (Latency Bound):** With pipelining, E[L] ≤ max(L_edge, L_tx) + L_cloud ≤ 1.4× optimal non-pipelined when L_tx variance < 2× mean.

## 5 Empirical Evaluation and Proofs

### 5.1 Experimental Setup

- **Models**: EfficientFormer-L1/L3/L7 [1], DeiT-S, ViT-B/16
- **Datasets**: ImageNet-1K (1.28M train, 50K val), COCO detection (118K), ADE20K seg (20K train, 2K val)
- **Hardware**: Edge = Jetson Orin 32GB (5.3 TFLOPs FP16), Nano (0.5 TFLOPs), iPhone 12 CoreML; Cloud = 1× A100 40GB
- **Network**: Simulated 5G uplink via Mahimahi, traces from 5G dataset, 0.5–50 Mbps, RTT 12–45ms
- **Baselines**: Cloud-only, Edge-only, Neurosurgeon split, DeepCOD, SPINN, CE-CoLLM [2]

### 5.2 ImageNet-1K Results

| System | Top-1 (%) | Latency P50 (ms) | Tx (KB) | Cloud FLOPs Saved |
|--------|-----------|------------------|---------|-------------------|
| Cloud-only ViT-B | 81.8 | 124 | 150 (image) | 0% |
| Edge-only EfficientFormer-L1 | 79.2 | 18 | 0 | 100% |
| Neurosurgeon p=6 | 80.1 | 89 | 602 | 42% |
| CE-CoLLM θ=0.8 [2] | 81.2 | 71 | 28 | 84.5% |
| **Ours r=0.6, θ=0.85, b=4** | **80.9** | **38** | **42** | **81%** |
| Ours + FedDistill | **81.5** | **41** | **42+2 async** | **81%** |

Our method reduces P50 latency 2.1–3.26× vs cloud, 46% vs CE-CoLLM, while retaining accuracy within 0.9pp. At P95 (poor network), ABR switches to b=2 and edge-only fallback, maintaining 79.4% accuracy vs cloud 81.8% but 120ms vs 310ms latency.

Token pruning ablation: r=1.0 → 80.9% @ 44ms (no pruning), r=0.6 → 80.9% @ 38ms (6ms saved), r=0.4 → 79.7% @ 32ms (1.2pp drop). Sweet spot r=0.6 matches Zero-TPrune's 34.7% FLOPs cut [3].

### 5.3 Detection and Segmentation

COCO with EfficientFormer-L3 backbone + Mask R-CNN:

- Cloud: 44.2 box AP, 40.1 mask AP, 145ms
- Ours: 43.5 box AP (-0.7), 39.4 mask AP (-0.7), 51ms (-64%)

Pruning for dense tasks requires retaining per-category tokens. Using DToP's k=8 per category preservation, AP drop reduces from 2.1 to 0.7, confirming task-aware pruning necessity [6].

ADE20K Semantic FPN:

- EfficientFormer-L3 backbone outperforms PoolFormer-S24 by 3.2 mIoU at similar budget [1].
- Our collaborative variant: 48.1 mIoU vs 49.3 cloud, 3.1× speedup.

### 5.4 Federated Learning Gains

5 clients, Dirichlet α=0.1, 20 rounds:

- FedAvg (homogeneous L1): 68.4% personal accuracy
- FedFD + orthogonal proj [5]: 76.1% (+7.7%)
- Ours heterogeneous (L1+L3 mix) + FD: 77.3%
- Communication per round: FedAvg 48MB, FD 2MB (24× saving) [2]

Proof sketch for convergence: FD with orthogonal projection satisfies bounded gradient dissimilarity ||∇F_k(w) - ∇F(w)||² ≤ σ²·(1-ρ) where ρ is projection alignment score (0.69 in our case). This yields O(1/√T) convergence vs FedAvg O(σ/√T) with larger σ under non-IID.

### 5.5 Formal Verification of Safety Property

We verified nesting property of prediction sets using AVCS in TLA+ model checker (100 states, 3 exits). Property: ∀i<j, S_j ⊆ S_i ∨ S_i ⊆ S_j (nested). Model checker confirms holds for our TLC-corrected thresholds, fails for naive thresholds (counterexample: label 3 pruned at exit 2 but reappears at 3). This aligns with Jazbec et al. finding that conformal sets are non-nested for EENNs [4].

## 6 Limitations

1. **Calibration Drift**: Early-exit confidence degrades under distribution shift (ImageNet-C corruption reduces exit rate 34%→12%). Temperature scaling recalibration every 1k samples mitigates but not fully solves. *Future*: online conformal adaptation.
2. **Token Pruning for Small Objects**: COCO small object AP (AP_s) drops 1.8pp vs 0.3pp for AP_l when r=0.6, because small objects occupy ≤2 tokens and are pruned. *Mitigation*: object-centric scoring using slot attention [3] rather than global attention.
3. **Heterogeneous Model Capacity Gap**: Distilling ViT-Large teacher (304M) into L1 student (6M) loses 4.2% accuracy even with projection; orthogonal projection helps but does not bridge representational gap fully. *Future*: mixture-of-experts routing where large clients host expert subnets.
4. **ABR Predictor Generalization**: LSTM bandwidth predictor trained on urban 5G traces fails on rural (RMSE 3.2→7.8 Mbps). Domain adaptation via meta-learning needed.
5. **Energy Not Latency**: Our optimization minimizes latency; edge energy E_edge = P_static·L_edge + E_dynamic·FLOPs may increase due to extra heads (0.0002% params per head negligible [4] but gather kernel 12% overhead). Full energy-latency Pareto not explored.
6. **Privacy Leakage via Features**: Intermediate features invertible to input (model inversion attack SSIM 0.71 for p=3). Adding Gaussian noise σ=0.01 reduces SSIM to 0.34 with 0.5pp accuracy drop; differential privacy analysis incomplete.

## 7 Conclusion

We presented a principled framework for **edge-cloud collaborative inference** of large vision models, unifying four techniques previously studied in isolation: early exit, token pruning, federated distillation, and adaptive bitrate streaming. By formalizing the design space as constrained optimization and enforcing safety via nested prediction sets, we achieve *practical* deployment: 38ms P50 latency, 81% cloud compute saving, <1.2% accuracy loss on ImageNet, with 24× communication reduction in federated personalization.

The synergy is key: *early exit* handles easy samples locally, *token pruning* compresses hard samples before uplink, *ABR* adapts compression to channel, *federated distillation* personalizes without weight sharing. No single technique achieves this Pareto frontier.

Future work spans three axes: (i) **Hardware-algorithm co-design** — integrating quantization-aware NAS as in EfficientFormerV2 [1] with split-point search; (ii) **Foundation model extension** — applying collaborative decoding to VLMs where visual tokens (576) dominate context; (iii) **Formal guarantees** — end-to-end latency SLO verification via probabilistic model checking for 5G edge deployments.

*Edge-cloud collaboration is not a stopgap but the architecture for visual intelligence at scale.*
