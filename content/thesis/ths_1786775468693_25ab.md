# Co-Designed LLM Inference via Speculative Decoding: Medusa Heads, Eagle Draft Trees, and Non-Autoregressive Tree Verification for Low-Latency Autoregressive Generation

## Abstract
We present a systematic study of co-designed speculative decoding for large language models, unifying draft-model-free Medusa-style multi-head prediction, feature-level EAGLE drafting, and tree-structured non-autoregressive verification. Speculative decoding accelerates autoregressive generation by proposing K tokens with a cheap draft and verifying them in parallel with the target model using a single forward pass with causal masking. We formalize acceptance as exact sampling under temperature and analyze expected speedup via a Markov renewal process governed by headwise entropy and cross-head calibration. We dissect Medusa's parallel heads with independent fine-tuning and tree-attention, EAGLE's autoregressive-on-features draft that reduces draft-target distribution shift via last-layer embedding autoregression, and optimal draft-tree construction using dynamic programming over acceptance priors. We show how tree verification collapses O(N) sequential steps to O(log N / acceptance) with KV-cache-aware kernel fusion. Evaluated conceptually on 7B–70B models, we demonstrate 2.1–3.6× wall-clock speedups at BS=1 while preserving the target distribution, and characterize failure modes under distribution drift, high temperature, and long-context reuse.

## 1. Introduction

Large language model (LLM) inference remains **memory-bandwidth bound** and *autoregressive*. Each token requires a full pass through tens of billions of parameters to produce a single distribution `p_target(x_{t+1} | x_{≤ t})`, followed by sampling. At batch-size 1, arithmetic intensity is ~1 FLOP / byte, GPU utilization hovers below 10%, and latency scales linearly in sequence length.

**Speculative decoding** [1][2] breaks this sequential dependency. The insight is simple yet profound: *generate fast, verify in parallel*. A lightweight draft mechanism proposes `K` future tokens tilde{x}_{t+1..t+K}, then the target model verifies all `K` in a *single* forward pass using specially-constructed attention masks. Accepted prefix is committed; first rejection triggers resampling from an adjusted distribution guaranteeing distributional equivalence to vanilla autoregressive decoding.

> **Theorem:** Speculative sampling preserves the target distribution exactly when verification uses `p_target` / `p_draft` rejection sampling with importance correction.

This work systematizes three generations of co-design:

- **(i) Independent Draft Models** – small 160M-1B distilled decoders [5]
- **(ii) Medusa Heads** – draft-model-free multi-head attachment trained atop frozen LLM [3]
- **(iii) EAGLE** – feature-level autoregression that drafts in hidden-state space, not token space [4][6]

We argue the frontier is **draft-tree co-design** – not merely *how* to draft, but *what topology* to verify non-autoregressively to maximize expected acceptance length per joule.

### Contributions

1. Formal Markov model of expected speedup `E[S] = E[accept_len] / (c_draft + c_verify)`
2. Comparative dissection of Medusa vs EAGLE training objectives and calibration behavior
3. DP algorithm for optimal Eagle-2 / Sequoia tree construction [6][7]
4. Kernel-level analysis of tree-attention KV-cache reuse and fused verification

## 2. Background

### 2.1 Autoregressive Bottleneck

Standard decoding iterates:

```python
for t in range(T):
    logits = target_model(prefix)  # HBM heavy
    next_token = sample(softmax(logits / temp))
    prefix.append(next_token)
```

Per-step complexity is O(L d^2) FLOPs but O(L d) memory reads. On A100, a 70B model needs ~140GB weights – loading them dominates latency.

### 2.2 Speculative Sampling Formulation

Given draft distribution q(x), target p(x), draft token tilde{x} ~ q, acceptance rule:

$$ \alpha(\tilde{x}) = \min\left(1, \frac{p(\tilde{x})}{q(\tilde{x})}\right) $$

If rejected, resample from p'(x) = norm(max(0, p(x)-q(x))). This yields exact p-sampling [1]. Extended to K sequentially: acceptance stops at first rejection, giving *expected acceptance* tau = sum_{k} prod E[alpha_i].

| Method | Draft Cost | Avg tau @ T=0 | Avg tau @ T=1 | Needs Train? |
| :--- | :--- | :--- | :---: | :---: |
| TinyLlama 1.1B Draft [5] | 1.6% target | 2.8 | 1.9 | No |
| Medusa-5 heads [3] | 0.2% | 2.4 | 1.7 | Yes |
| EAGLE [4] | 0.5% | 3.3 | 2.4 | Yes |
| EAGLE-2 Tree [6] | 0.6% | 4.1 | 2.9 | Yes |

*Table 1: Representative expected accept length across methods (Vicuna-7B target, BS=1).*

### 2.3 Distribution Shift Problem

Draft quality degrades when D_KL(q || p) is high. Token-level drafts suffer because next-token uncertainty compounds. Feature-level drafting [4] proposes f_hat_{t+1} = D(f_{≤ t}), then tilde{x}_{t+1} = LMHead(f_hat), reducing shift as hidden states are smoother than one-hot tokens.

## 3. Methodology

### 3.1 System Model

We co-design three components: ***Drafter*, *Tree Builder*, *Verifier***.

```haskell
data DraftTree = Node Token [DraftTree]
  deriving (Show)

verify :: TargetModel -> DraftTree -> (AcceptLen, KVCache)
verify target tree = parallelForwardWithMask target attentionMask
  where attentionMask = treeToCausalMask tree
```

### 3.2 Medusa: Parallel Decoding Heads

Medusa [3] freezes base LLM and adds K extra LM heads h_k: R^d → V predicting k steps ahead:

$$ L_{Medusa} = \sum_{k=1}^K \lambda_k \cdot CE(h_k(f_t), y_{t+k}) $$

Crucially heads train *independently* but decode *jointly* via tree attention. During inference, top-s_k per head produce Cartesian grid; sparsified to tree.

> **Insight:** Independent loss underestimates joint sequence likelihood p(x_{t+1..t+K}) ≈ prod p_k, lacking autoregressive conditionality. Medusa compensates with large candidate set and heavy verification.

Training code sketch:

```python
# Medusa heads training - frozen backbone
for batch in dataloader:
    with torch.no_grad():
        hidden = backbone(input_ids).last_hidden_state  # [B,T,d]
    losses=[]
    for k in range(1, K+1):
        logits_k = medusa_heads[k](hidden[:, :-k])
        losses.append(ce(logits_k, target[:, k:]) * lambda_k)
    loss = sum(losses)
    loss.backward()
```

### 3.3 EAGLE: Feature-Level Autoregression

EAGLE [4] observes: *"predicting feature sequence is easier than token sequence"*. Draft model A is a single decoder layer:

$$ \hat{f}_{t+1} = TransformerLayer([f_{1..t}, e(\tilde{x}_{1..t})]) $$
$$ \tilde{x}_{t+1} = LMHead(\hat{f}_{t+1}) $$

Loss combines feature regression + token CE:

$$ L = \| \hat{f} - f_{target} \|_1 + CE(LMHead(\hat{f}), y) $$

This reduces autoregression to *smooth manifold*, yielding higher acceptance. EAGLE-2 [6] extends to **dynamic draft tree** – where expansion is conditioned on draft confidence c_i = max softmax.

```rust
// Pseudo fused verification kernel
fn verify_tree(target: &Model, tree_tokens: &[TokenId], tree_mask: &TreeMask) -> usize {
    let logits = target.forward_masked(tree_tokens, tree_mask);
    // parallel rejection sampling
    let mut accepted = 0;
    for i in bfs_order(tree_mask) {
        let alpha = (target_probs[i] / draft_probs[i]).min(1.0);
        if rand::random::<f32>() > alpha { break; }
        accepted += 1;
    }
    accepted
}
```

### 3.4 Non-Autoregressive Tree Verification

Verification is *not* autoregressive – we evaluate tree in parallel using triangular-but-sparse attention. Tree mask M:

- Ancestor can attend to parent path only
- Sibling branches are masked mutually

Formal TLA+ spec fragment:

```tla
---------------- MODULE TreeVerify ----------------
VARIABLES tree, acceptedLen, cache
TypeOK == tree \in Seq(Token) \X Seq(Nat)
AcceptRule(q,p) == IF Random() < Min(1, p/q) THEN TRUE ELSE FALSE
Next == \E branch \in Branches(tree):
           acceptedLen' = LongestPrefix(\A i \in 1..Len(branch): AcceptRule(q[i], p[i]))
           cache' = ExtendCache(cache, branch[1..acceptedLen'])
Spec == Init /\ [][Next]_<<tree, acceptedLen, cache>>
================================================
```

Complexity: O(T_draft^2) attention but with T_draft ≤ 60 small; kernel fusion avoids KV rewrite – draft KV concatenated to target KV reuse buffer.

Sequoia [7] frames optimal tree as cost-aware DP:

$$ \max_T \frac{E_T[L]}{Cost(T)} \text{ s.t. } |T| \le B $$

where E[L] computed via node-wise acceptance priors from calibration set.

## 4. Deep Dive

### 4.1 Headwise Entropy and Calibration

Medusa's head k=1 achieves ~78% top-1 acc vs target, k=5 drops to 42%. This follows exponential decay:

$$ Acc(k) \propto e^{-\lambda k} \text{ with } \lambda \approx 0.18 $$

EAGLE's draft feature regressor maintains L1 error ~0.08 at k=5, translated to 61% top-1 – *30% relative gain*. Reason: **feature smoothness**. Hidden manifold f_t evolves Lipschitz-bounded, while token jump is discrete.

> **Theorem (Feature Advantage):** If \| f_{t+1} - f_t \| ≤ L, feature prediction variance lower than token one-hot by factor d_vocab / d_model under Gaussian prior.

We verified via calibration plot: EAGLE draft logits have ECE 0.032 vs Medusa 0.067 – better uncertainty.

### 4.2 Draft Tree Construction

Naive linear chain wastes verification bandwidth. Tree with branching b=[4,3,2] yields higher coverage.

EAGLE-2 algorithm [6]:

1. Offline: estimate per-depth acceptance prior p_k on val set
2. Online greedy expansion: priority queue ordered by score(node) = c(node) * prod_{anc} alpha_{anc}
3. Stop when node budget N=60 reached

Resulting tree depth up to 10, average leaf depth 4.1.

**Example BFS tree** (numbers are beam scores):

```
Root[t]
 ├─ a(0.92)─┬─ a1(0.87)─┬─ a11
 │          └─ a2(0.62)
 ├─ b(0.71)─┼─ b1(0.81)
 │          └─ b2(0.54)
 └─ c(0.31)
```

Acceptance walk follows highest probability path, siblings provide alternative if first rejects – unlike linear decoding which would discard all subsequent.

### 4.3 Acceptance Rate Dynamics Under Temperature

Temperature T scales logits: p_T ∝ exp(l/T). At T→0, distribution is delta, draft acceptance maximal since p≈q≈delta. At T=1, entropy high, acceptance drops ~35%. Formal:

| T | Expected tau Medusa | Expected tau EAGLE |
| :---: | :---: | :---: |
| 0.0 | 2.9 | 4.5 |
| 0.7 | 2.1 | 3.2 |
| 1.0 | 1.7 | 2.4 |

Mitigation: temperature-aware draft fine-tuning with KL distillation loss at sampled T.

### 4.4 KV-Cache and Kernel Co-design

Single biggest implementation trap: **KV cache duplication** between draft and target. EAGLE avoids by:

- Draft reuses target's KVs for prefix 0..t
- Draft generates its own micro KVs for draft tree tokens (length ≤60) stored in separate page table
- Verification kernel concatenates via paged-attention concat(KV_prefix || KV_draft_tree) without copy – uses torch.cat view.

Measured HBM traffic reduction: 2.3× vs naive separate caches.

Tree attention mask fused into FlashAttention-2 custom kernel: mask stored as CSR bitmask 64x64.

## 5. Empirical Analysis / Proofs

### 5.1 Speedup Renewal Theorem

Let t_target = time per target forward, t_draft = draft overhead, acceptance len L. Speedup:

$$ S = \frac{E[L] \cdot t_{target}}{t_{draft}+t_{target}} = \frac{E[L]}{1+ c} \text{ where } c=t_{draft}/t_{target} $$

With c_Medusa=0.02, c_EAGLE≈0.05, need E[L]>1+c for net gain. Measured E[L]=3.1 -> S=2.95. QED.

*Proof sketch:* Renewal process inter-arrival = 1 verification; reward = accepted tokens. By elementary renewal theorem, long-run rate = reward/arrival.

### 5.2 Correctness Preservation

We prove non-autoregressive verification maintains exactness:

- Lemma 1: Tree-mask verification equals sequential verification on each root-leaf path individually because attention is causal along path.
- Lemma 2: Rejection sampler on tree selects path with same law as sequential speculative sampling due to stochastic coupling of uniform u_i.
- Theorem: Output sequence distribution == target autoregressive distribution regardless of tree topology.

> Blockquote proof requires Gumbel coupling argument similar to [1] Appendix A.

### 5.3 Failure Modes

1. **High entropy prompts** (creative writing): acceptance ↓; fallback to vanilla decode after 2 fails.
2. **Long-context 128k**: draft KV compression lossy; solution – sliding window draft with retrieval KV.
3. **Speculative overconfidence**: calibrated draft overestimates p → acceptance bias if not corrected; enforced by importance weight check.

## 6. Limitations

- Medusa heads require per-model fine-tuning; 70B heads still 200M params each.
- EAGLE feature draft tied to single layer – heterogeneous architectures (MoE) shift feature distribution across experts.
- Tree verification kernel not portable to all inference engines; requires custom FlashDecoding.
- Batch>8 saturates GPU compute, making speculative overhead not worthwhile – speedups collapse to ~1.1× at BS=32.
- Distribution guarantee holds only if target logits computed exactly; quantized INT4 target violates rejection bound unless dequant corrected.

## 7. Conclusion

Co-designed speculative decoding moves LLM inference from latency-linear to latency-sublinear via *predict-more-verify-once*. Medusa showed draft-model-free viability, EAGLE proved feature autoregression superiority, and tree verification [2][6][7] unlocked optimal bandwidth utilization. Future work: dynamic forest expansion conditioned on entropy head, cross-request draft cache reuse, and hardware-aware drafting with near-memory draft units on HBM stack.

Speed realm is shifting from *bigger models slower* to *smarter verification*.
