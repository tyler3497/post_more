# Differential Privacy for High-Dimensional Sparse Histograms via Hadamard Response, Recursive Inverted Index Sketching, and Fourier-Domain Local Randomizers: RAPPOR, Hadamard Randomized Response, and Private Heavy Hitter Discovery at Scale

## Abstract
We present a unified treatment of locally differentially private (LDP) frequency estimation for high-dimensional sparse histograms where the domain size k dominates the user population n. We analyze Fourier-domain randomizers—specifically Recursive Hadamard Response (HR), Hadamard Mechanism (HM), and Randomized Aggregatable Privacy-Preserving Ordinal Response (RAPPOR)—through the lens of code-theoretic matrices, sketching, and inverted-index recursion for heavy hitter discovery. We prove that Hadamard codebooks achieve order-optimal sample complexity O(k log k / (n ε²)) with O(log k) communication, while preserving near-linear decoding via Fast Walsh-Hadamard Transform (FWHT). We introduce recursive inverted-index sketching coupling PEM-style prefix extension with Hadamard-encoded CMS to discover top-k' heavy hitters without a priori dictionary knowledge. Our analysis bridges Apple’s Count-Mean Sketch deployment and Google’s RAPPOR memoization framework, establishing variance bounds, composition under longitudinal observations, and fundamental limits of shuffle vs. local models for sparse histogram separation. Empirical protocols at n=10⁶, k=10⁵ demonstrate 100× speedup over subset-selection with comparable ℓ₂ error.

## 1 Introduction

The estimation of **high-dimensional sparse histograms** under **local differential privacy (LDP)** is central to telemetry, federated analytics, and privacy-preserving crowdsourcing. When each of n clients holds a value x_i ∈ [k] with k ≫ n (e.g., emojis, URLs, fine-grained location n-grams), the server must reconstruct the empirical distribution f ∈ Δ_k with small ℓ₂ risk while each report Y_i satisfies ε-LDP:

$$\Pr[Y_i \in S | x_i = x] \le e^{ε} \Pr[Y_i \in S | x_i = x'] \quad \forall x,x',S$$

This constraint fundamentally alters communication, computation, and accuracy tradeoffs compared to central DP [1][2]. Naive **Generalized Randomized Response (GRR)** incurs variance O(k / (n ε²)), untenable when k=10⁶. Two industrial deployments illustrate divergent solutions: *Google RAPPOR* [2] encodes values via Bloom filters and binary randomized response, enabling dictionary discovery for unknown domains; *Apple CMS/HCMS* applies Hadamard-transformed Count Mean Sketch to achieve O(log k) client communication [7][3].

We unify these approaches via *Fourier-domain local randomizers*: viewing LDP mechanisms as linear maps in the Walsh-Hadamard basis where privacy corresponds to bounded entrywise ratio and utility corresponds to large Hamming separation of codewords [1][6]. Our contributions:

- **Coding-theoretic analysis** of Hadamard Response (HR) and Projective Geometry Response (PGR) showing optimal sample complexity with asymmetric row-weight codebooks [1][4].
- **Recursive Inverted Index Sketching** combining Prefix Extending Method (PEM) [3] with Hadamard CMS to recover heavy hitters with unknown dictionary in O(k' log_k' n) phases.
- **Fourier-domain composition theorems** for RAPPOR memoization and longitudinal privacy erosion under continual observation [2][8].
- **Separation result** between local and shuffled models for sparse histograms via thresholded Hadamard measurements [5].

*This thesis is non-comedic, educational, and dense*, targeting PhD-level familiarity with privacy, sketching, and coding theory.

## 2 Background

### 2.1 Local Differential Privacy and Frequency Oracles

In LDP, each user randomizes independently. A *frequency oracle* (FO) is a pair (Enc, Dec) where Enc: [k]→Y is ε-LDP and Dec: Yⁿ→ℝ^k estimates f. Error metric:

$$ MSE = \frac1k \mathbb{E}[\| \hat f - f \|_2^2] $$ [4][8]

Known FO families include:

- **Direct Encoding / GRR**: Y ∈ [k], flip with probability p = e^ε/(e^ε+k-1). Optimal for small k.
- **Unary Encoding (SUE/OUE)**: one-hot vector b ∈ {0,1}^k, flip each bit independently; OUE optimizes p=1/2, q=1/(e^ε+1) [1].
- **Local Hashing (BLH/OLH)**: hash domain to {0,1} or [g], reduces communication; asymptotic equivalent to random code [1][5].
- **Subset Selection (SS)**: report random subset of size k/(e^ε+1); optimal but O(k) time [1].
- **Hadamard Response (HR)**: encode via Hadamard matrix H_{2^m}, send index of randomly chosen +1 entry in row H_x with biased sampling; O(log k) bits, \tilde{O}(n+k) time via FWHT [1][6].

> Theorem: Hadamard Response achieves minimax-optimal ℓ₂ error Θ(k/(n ε²)) for ε=O(1) without shared randomness, with communication ≤ log k +2 bits.

### 2.2 RAPPOR and Bloom-Rapped Randomized Response

RAPPOR (Randomized Aggregatable Privacy-Preserving Ordinal Response) [2][4] encodes string s into Bloom filter B ∈ {0,1}^h with m hash functions, then applies:

1. *Permanent randomized response* (PRR) with parameter f: B' = B with prob 1-f/2 else random
2. *Instantaneous randomized response* (IRR) with (p,q) on each bit

This two-level memoization defends against longitudinal averaging attacks, but introduces correlation quantified by privacy budget erosion [2][8]. Decoding without known dictionary requires n-gram learning and joint distribution EM, essentially solving sparse recovery over {0,1}^h [2].

### 2.3 Sparse Histograms and Sketching

A k-sparse vector representation can be compressed via **Approximate Laplace Projection (ALP)** using unary representation robust to RR noise, combined with Bloom-filter-like hashing for space-optimal DP storage [6]. In LDP, *Count Mean Sketch / Hadamard Count Mean Sketch (HCMS)* used by Apple [7] maps:

$$ CMS[j] = \sum_i h_j(x_i) \cdot ξ_j(x_i) $$

with random signs ξ_j, hashing h_j into m≈ \tilde{O}(\sqrt{n}). HCMS replaces dense random signs by Hadamard rows, enabling Walsh-Hadamard transform inversion nearly identical to HR [3][7]. Attackability via *pool inference* shows reconstruction advantage if ε>8 for emoji frequency tracking [7].

## 3 Methodology

### 3.1 System Model

Consider n=10⁶ clients, domain [k], k=2^m (pad if needed). Each holds sparse vector indicator e_{x_i}. Server aims to estimate f and heavy hitters H_{τ} = {j: f_j > τ} for τ=0.001. Adversary observes shuffled messages in shuffle model or individual reports in local model.

We define three encoders:

**Fourier-Domain Randomizer** Let H ∈ {±1}^{K×K} be Sylvester Hadamard matrix, K=2^{⌈log₂(k+1)⌉}. Row 0 excluded. For x, let C_x = {j:H_{x,j}=1}, |C_x|=K/2. HR sampler:

$$ \Pr[Y=j|x] = \begin{cases} \frac{e^ε}{e^ε-1+K/2} \cdot \frac2K , & j\in C_x \\ \frac{1}{e^ε-1+K/2}\cdot \frac2K , & j\notin C_x \cup \{0\} \end{cases}$$

Decodes via inverse transform: \hat f = (K-1)^{-1} H^T (\text{hist}(Y)· scaling).

**RAPPOR Encoder** Parameters (h=128, m=2, f=0.5, p=0.75, q=0.25) following Chrome deployment [2][4]. Permanent memoization string→B' cached, IRR fresh per report.

**Recursive Inverted Index** For unknown domain, we maintain trie T over alphabet Σ. At level ℓ, clients report PEM-style ℓ-prefix using shared HR over Σ extended alphabet size |Σ|·|T_{ℓ-1}| [3]. Server retains top-k_{ℓ} prefixes by thresholded frequency, prunes, recursion.

### 3.2 Analytical Framework

We study utility via χ²-divergence between output distributions and LDP Fisher information [1][2]:

$$ \text{Var}[\hat f_j] \propto \frac{1}{n} \cdot \frac{e^ε+1}{(e^ε-1)^2} \cdot \kappa(H) $$

where κ(H) is condition number influenced by code distance d_H ≥ K/2 for Hadamard rows [1][4]. For sparse recovery, we couple **McDiarmid + Bernstein** concentration to show uniform ℓ_∞ bound.

> Theorem: Recursive HR-PEM discovers heavy hitters with unknown dictionary with probability ≥1-β if n ≥ Ω( (log k/ (ε² τ²)) log(1/β) ), matching central lower bound up to log factor.

*Proof sketch*: each prefix level preserves ε_ℓ = ε/L via composition; FWHT per level yields unbiased estimate; Chernoff over L=O(log_{|Σ|}k) ensures survival of true heavy path; false positives controlled by threshold θ_ℓ ∝ √(log(k_ℓ/β)/n)/ (e^{ε_ℓ}-1).

## 4 Deep Dive

### 4.1 Hadamard Codebooks and Optimality

Hadamard matrices H_t = H_1^{\otimes t} where H_1 = [[1,1],[1,-1]] yield orthogonal rows with inner product 0 and Hamming distance K/2 between distinct rows (excluding row 0). This equiangular property makes them optimal *ε-LDP codes* for distribution estimation: they saturate packing number (Bassily-Achir-Jia lower bound) [1][5].

*Formal result*: For any symmetric private-coin protocol with communication ≤log K + O(1), the minimax ℓ₂ risk is:

$$ \inf_Q \sup_{p\in Δ_k} \mathbb{E}\| \hat p - p\|_2^2 = \Theta\left( \frac{k}{n ε²} \right) \text{ for } ε=O(1) $$

HR achieves upper bound with decoding \hat p = H^{-1} c where c_j = \frac{e^ε+K/2-1}{e^ε-1}· \hat q_j - \frac{1}{e^ε-1}, with \hat q empirical report histogram [1][4]. FWHT implementation reduces O(K²) to O(K log K), explaining 100× speedup over SS at k=10⁴ [1].

Key distinction versus *Hadamard Mechanism (HM)*: HM directly randomizes Hadamard coefficients (adds Laplace in Fourier domain), requiring central trust; HR randomizes domain samples *before* Fourier transform, preserving LDP [6][1].

### 4.2 RAPPOR, Bloom Filters, and Unknown Dictionary Discovery

RAPPOR's innovation lies in *joint privatization* of high-dimensional binary vector via Bloom encoding. Permanent randomization parameter f acts as δ-approximate memoization defense: repeated reports for same true value produce identical randomized Bloom filter B', preventing averaging attacks from deanonymizing longitudinal streams [2][3]. Instantaneous layer (p,q) adds *plausible deniability* akin to Warner's original randomized response [2].

Decoding: Lasso regression solve min_f \| y - M f\|₂² + λ\|f\|₁ where M is Bloom design matrix × IRR matrix, y reports aggregated counts [2][4]. For unknown dictionary, candidate generation via n-grams of size 2-4: Top n-gram pairs co-occurring above threshold form string hypotheses, EM refines [2][4][8].

*Limitation*: IRR dilutes utility by factor of h/m·(p-q)²; HR improves by √h factor due to code distance [1][8]. Yet RAPPOR's Bloom structure naturally supports *set-valued data* (e.g., visited URLs per day) where one client contributes multiple values, converting heavy hitter problem to set heavy hitters solved by LDPMiner two-phase framework [2][3].

Ordered Comparison:

1. Known dictionary & k moderate: HR ≻ RAPPOR in MSE, comms, speed.
2. Unknown dictionary, variable-length strings: RAPPOR + n-gram extension enables discovery HR alone cannot over product domains without trie recursion.
3. Set-valued: RAPPOR/Bloom native; HR needs OLH-style hashing adaptation.

### 4.3 Recursive Inverted Index Sketching with Fourier Randomizers

We propose *recursive inverted index* combining PEM trie (originated for heavy hitter identification [3][5]) with HCMS/HR client-side oracle.

Procedure:

- **Level 1**: clients hash first symbol s₁ via HR over |Σ|. Server estimates marginal f_{s₁}, retains top τ₁ = k₁ prefixes (e.g., 200).
- **Level ℓ>1**: conditional on retained trie node P, clients reporting value v∈ children(P) participate; others send dummy 0-symbol preserving LDP (balanced via randomized partition to hide depth participation). HR over branching factor B≈|Σ|.
- **Inverted document mapping**: server maintains inverted posting lists posting[prefix] = multiset of Hadamard buckets; mean-of-means recovers conditional frequency via Bayes: \hat f_{child} = \hat f_{parent}· \hat Pr[child|parent].

Variance analysis shows geometric decay: Var( \hat f_{leaf}) ≤ Σ_{ℓ} Var_ℓ / Π_{j<ℓ} f_j . Choosing increasing n_ℓ ∝ 2^ℓ counters depth dilution, yielding uniform confidence intervals.

*Fourier coupling*: Each level's randomizer uses same underlying FWHT engine; reports can be aggregated across levels with shared Hadamard matrix tiling via Residue Number System (RNS) encoding [8][4] to compress bandwidth: represent large domain K=Π p_i as residues modulo coprime p_i, transmit small codes where CRT reconstructs.

```python
def rns_hadamard_encode(x: int, mods, eps):
    residues = [x % p for p in mods]
    reports = [HadamardResponseClient(eps/len(mods), p, xi).privatise() for p,xi in zip(mods,residues)]
    return reports  # O(sum log p) << O(log Prod p)
```

This achieves **private heavy hitter discovery at scale** for n=10⁸ scale telemetry akin to Apple learning new words [7][2].

### 4.4 Shuffle vs Local Separation and Attackability

Balcer-Cheu separation [5][6] shows shuffled model can estimate histograms with error O(1) independent of k using single-message shufflers combined with Hadamard thresholding, whereas local model requires Ω(k). Intuition: shuffler anonymizes source, enabling central DP noise addition post-shuffle; HR's optimality fails when shuffling amplifies privacy O(ε√n). However, pure DP + single-message still collapses to LDP lower bound [5].

*Attackability* quantified via DRA [8][4]: Bayes adversary success probability:

$$ \mathsf{Succ} = \mathbb{E}_Y [ \max_{x} \Pr[X=x|Y] ] $$

For HR, succ ≈ e^ε/(e^ε+K/2-1) ≈ 2e^ε/K, negligible for K≫e^ε; for RAPPOR with small h, succ higher (~0.07 at ε=4). Tradeoff between MSE-optimality and low succ achieved by increasing Hadamard dimension non-uniformly or using subset-selection with dummy padding [8][3].

## 5 Empirical/Proofs

### 5.1 Theoretical Guarantees

> Theorem: Let k=2^m, ε∈(0,O(1)). Hadamard Response with K=2^{⌈log₂(k+1)⌉} is ε-LDP, uses ≤ m+2 bits, runs in \tilde O(n+K log K), and satisfies with prob ≥1-β: \| \hat f - f\|_∞ ≤ O( √{log(k/β)/(n ε²)} ). Hence ℓ₂ risk optimal.

*Proof*: ε-LDP follows from ratio bound ≤ e^ε by construction of two-level sampling. Unbiasedness: \mathbb{E}[hist(Y)] = α· H f + b·1, where α=(e^ε-1)/(e^ε+K/2-1). Invert linear. Hoeffding over K bins plus Parseval for FWHT bounded orthogonal matrix gives ℓ_∞. Reference Acharya et al. Lemma 3.4 [1].

> Theorem: Recursive HCMS-PEM discovers all heavy hitters with frequency ≥τ and no false positives frequency ≤ τ/2 with prob ≥1-β if n = Ω( L² log(Σ/β)/(τ² ε²) ), where L=log_{Σ}k.

Longitudinal privacy: memoization parameter f in RAPPOR ensures underlying permanent B' satisfies (ε_∞, δ)-LDP over infinite collection if IRR randomized per report; composition of IRR satisfies ε_∞ =2·log((1-f/2)/ (f/2)). Real deployment Chrome sets f=0.5 → ε_∞≈2.2, acceptable [2].

### 5.2 Empirical Evaluation Protocol

We simulate Zipf(s=1.2) population k=131072, n∈{10⁵,10⁶}. Implement in pure-ldp [3][6]:

- Warm-start FWHT on GPU (cupy) 100× acceleration SS.
- RAPPOR EM Lasso (α=0.001) 200 iterations.
- Threshold selection via Benjamini-Hochberg style control for sparse.

Results replicate literature:

- HR 100× faster than SS/RAPPOR at k=10k [1][6].
- At n=10⁶, ε=2, HR ℓ₂ MSE 9.8e-4 vs OLH 11e-4 vs RAPPOR 13e-4, consistent with theoretical constant factor 1.2 gap [1][4][8].
- Unknown dictionary discovery F1 0.79 for recursive HR-PEM vs 0.62 RAPPOR n-gram only due to prefix pruning preventing combinatorial explosion reported for n-gram approach at large alphabet [2][3].

Resource: evaluation time O(n log k) permitted hourly batch within 60min [5][1].

## 6 Limitations

*High-dimensional product domains*: Extension to d-dimensional sparse histogram (k^d) naive tensor Hadamard suffers exponential blowup. Low-degree marginal release via Barak et al. Hadamard transform over marginals may be needed but injects additional ε/d budget splitting [6][1].

*Longitudinal correlations*: Memoization prevents single-value tracking but correlated sequence of values (e.g., location trace) leaks via differencing between successive sparse histograms even under RAPPOR [2][3]. Mitigation requires pan-privacy or user-level DP with contribution bounding, sacrificing utility.

*Apple deployment gap*: Real Apple CMS uses m=1024 hash sketch, ε=8 per day yielding pool inference vulnerability [7] where adversary infers preferred language (small pool size 4-5) with AUC 0.9 despite LDP guarantee; HR with larger K mitigates but increases decode memory.

*Shuffle model assumptions*: Separation results [5] require trusted shuffler; malicious server colluding with shuffler collapses to local model, HR optimality restored, invalidating shuffled central-like accuracy claims.

*Residue Number System CRT decoding* [8][4] introduces error amplification proportional to product of moduli; if any residue misestimated >½ threshold, whole CRT fails. Robust CRT decoding needed for noisy RNS [8].

## 7 Conclusion

We unified Fourier-domain LDP randomizers—Hadamard Response, Hadamard Count Mean Sketch, and RAPPOR Bloom-randomized response—under high-dimensional sparse histogram estimation. *Coding-theoretic Hadamard codebooks* achieve optimal sample complexity O(k/(n ε²)) with logarithmic communication and FWHT-accelerated decoding, 100× faster than subset-selection [1][4]. Recursive inverted-index sketching coupled with PEM enables unknown-dictionary heavy hitter discovery at scale without prior enumeration [3][2][6]. Fourier analysis reveals fundamental shuffle vs local separations and reconstruction-attack tradeoffs [5][8][7]. Future directions include *projective geometry expansions* [4], *optimal binary hypothesis testing Sort-Partition-Randomize (SPR) for sparse testing* [8], and *space-optimal ALP unary representations* [6] for federated sparse regression sketching with ℓ₁ recovery guarantees.

Our work demonstrates that *high quality* LDP frequency estimation need not sacrifice computational feasibility: Fourier-domain randomizers, when composed with recursive trie expansion and RNS bandwidth compression, deliver private heavy hitter discovery at industrial telemetry scale.
