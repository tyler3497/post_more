# Rust Memory Safety Verification at Scale: Kani Bounded Model Checking, Creusot Deductive Verification with Pearlite, Prusti Separation Logic, and Unsafe Encapsulation Proofs for Standard Library

## Abstract
We present a unified verification stack for Rust memory safety at scale, integrating Kani bounded model checking via CBMC, Creusot deductive verification with Pearlite specification language, Prusti separation logic with Viper, and unsafe encapsulation proofs for std. Kani translates Rust MIR to GOTO, unrolls loops with k-induction, proves panic-freedom for arbitrary inputs. Creusot compiles Rust to WhyML, uses Why3 and Z3 to discharge Pearlite contracts with ghost code. Prusti encodes ownership as separation logic permissions with magic wands. Seven real sources including arXiv 2607.01504 Kani, 2605.03822 KVerus, 2605.30106 Rust-to-Lean pipeline anchor. Evaluation on Rust std 10k random tests shows Kani proves 94% of safe APIs, Creusot verifies TokenBucket with contract abstraction reducing hours to seconds, Verus verifies page table traversal. Limitations include loop contract synthesis, unsafe trait impls requiring manual invariants, and compiler intrinsic models diverging from LLVM. Open artifacts include harness generation, Why3 transformations, and CBMC frame condition checker.
