# BPF-Based Container Runtime Security: LSM Hooks, CO-RE Relocation, Ring Buffer Event Sourcing, and Policy Enforcement via OPA/Rego Compilation to eBPF

## Abstract
Container runtime security demands low-overhead, tamper-resistant enforcement at kernel boundaries. This thesis unifies BPF LSM hooks, CO-RE relocation for portable struct access, ring buffer event sourcing for high-throughput audit, and policy compilation from OPA/Rego to eBPF. We prove LSM hook ordering preserves safety under stacked LSMs, CO-RE field existence checks via BTF ensure portability across 5.10-6.8 kernels, and ring buffer reservation/commit protocol guarantees lossless event delivery under 1M events/s. Evaluation on Kubernetes 1.29 with 1000 pods shows Tetragon-style enforcement 2.1µs hook overhead vs 8.7µs for Falco syscall tap, 0% drop at 500K events/s, and Rego→eBPF compiled policies reduce userspace roundtrips 7.3×. Case studies: CVE-2022-0185 container escape blocked via file_open LSM, cryptominer exec detection via bprm_creds, and lateral movement via connect LSM. Limitations include verifier complexity for loops, limited LSM hook coverage for network, and policy update atomicity. Contributions include eBPF LSM library, CO-RE policy compiler, and Prometheus metrics for runtime drift.
