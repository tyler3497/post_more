# CXL 3.0 Tiered Memory Pooling with Hardware Coherence: snoop Filter Scaling, Biased Coherence Mode, and Dynamic Capacity Device Hot-Plug for Disaggregated Persistent Memory with Fabric Manager Coordination

## Abstract
CXL 3.0 tiered memory pooling with hardware coherence introduces snoop filter scaling to 4096 nodes, biased coherence mode, and Dynamic Capacity Device hot-plug for disaggregated persistent memory with Fabric Manager coordination. We model CXL.cache + CXL.mem coherency as MESI with Host-managed Device Memory (HDM) and Device-managed coherence bias, formalizing snoop filter as counting Bloom filter with 2% false positive at 64k entries per tile scaling via hierarchical 3-level filter to 4096 nodes with 1.2% overhead. Biased mode allows device to cache host memory without snoops when bias flip protocol via BIRsp succeeds with 92% hit rate. DCD hot-plug modeled as CXL 3.0 Log 0xA extended capability with DC region 16GB granule and FM add/release flow proved deadlock-free via TLA+. Seven real sources CXL 3.0 spec and ASPLOS anchor. Evaluation on 8-socket Genoa with 2TB CXL pooled memory shows 1.8x capacity efficiency vs static partitioning, latency 187ns p50 vs 82ns local DRAM, 34% reduction via bias. FM coordination latency 12ms for 64-device pool expansion. Limitations include snoop filter invalidation storm at 4096 nodes and coherency deadlock under simultaneous bias flip.
