# Homotopy Type Theory: Univalence, Higher Inductive Types, and the Cubical Computational Interpretation

## Abstract

Homotopy type theory (HoTT) reinterprets Martin-Löf identity types as path spaces, endowing dependent type theory with a homotopical semantics in which types are spaces, terms are points, and proofs of identity are paths. This paper surveys the logical and computational anatomy of the theory's two pillars — Voevodsky's univalence axiom, which identifies the identity type of the universe with the type of equivalences, and higher inductive types (HITs), which internalize spaces such as the circle — and traces how the original axiomatic formulation, which destroys canonicity, was superseded by cubical type theories in which univalence and HITs compute. We compare the De Morgan cubical set model of Cohen, Coquand, Huber, and Mörtberg [5] with the cartesian cubical theory of Angiuli, Brunerie, Coquand, Favonia, Harper, and Licata [6] and its computational realization, examine the semantic roots of the program from Hofmann–Streicher through Awodey–Warren [3] to Voevodsky's simplicial model [2], and evaluate which canonicity and normalization theorems have been recovered. The synthesis clarifies what remains open: general HIT schemas, homotopical correctness of every cubical variant, and scalable implementations.

## 1. Introduction

For most of the twentieth century, the logical identity of a mathematical object was a *proposition*: either `a = b` holds or it does not. Martin-Löf's intensional type theory broke with this picture by making identity a *type* — the identity type `Id_A(a, b)` — whose inhabitants are *proofs* of equality. For decades this was regarded as a technical curiosity, until a series of results revealed that identity types carry an entire hidden geometry. The groupoid model of Hofmann and Streicher showed that proofs of identity admit the structure of a groupoid: they compose, invert, and satisfy coherence laws. Awodey and Warren then proved that intensional type theory is sound in *every* Quillen model category, exhibiting identity types as path objects in complete generality [3]. Finally, Voevodsky constructed a model of type theory in Kan simplicial sets [2] and observed that this model validates a stunning further principle: **univalence**, the assertion that identifications of types coincide with equivalences of types.

Univalence and **higher inductive types** — inductive definitions that generate not only points but also paths — jointly constitute homotopy type theory. Together they permit a *synthetic* style of homotopy theory, developed entirely inside type theory, in which spaces are not built from sets of points but axiomatized by their universal properties [1]. The celebrated computation `π₁(S¹) ≃ ℤ` was the first fruit of this program [4].

Yet the axiomatic formulation has a notorious defect: *axioms block computation*. Postulating univalence as an axiom introduces closed terms of natural-number type with no specified reduction behavior, destroying **canonicity** — the guarantee that every closed term of base type evaluates to a canonical value. The second act of the story is therefore computational: the cubical type theories of Cohen et al. [5] and Angiuli et al. [6], in which univalence is a *theorem* with computational content, derived from a primitive interval and Kan filling operations. This paper gives a unified account of the logical design, the semantics, and the computational recovery.

## 2. Background

### 2.1 Martin-Löf identity types

The identity type is introduced by a single formation rule and a single constructor, together with the eliminator `J` (path induction):

```haskell
-- Formation and introduction
Id  :: A -> A -> Type
refl :: a -> Id A a a

-- Elimination: path induction (the J rule)
J :: (C : (x y : A) -> Id A x y -> Type)
  -> ((x : A) -> C x x (refl x))
  -> (x y : A) -> (p : Id A x y) -> C x y p
```

The crucial fact is that `J` only ever eliminates into a motive depending on *both* endpoints and the path — it captures the principle that to prove something about an arbitrary identification, it suffices to consider reflexivity. From `J` one derives **transport**, the workhorse of the theory:

```haskell
transport :: (P : A -> Type) -> Id A a b -> P a -> P b
transport P p = J (\x y _ -> P x -> P y) (\x -> id) _ _ p
```

Intensionality means that `Id_A(a,b)` may contain *many* distinct inhabitants even when `a` and `b` are definitionally equal — the theory does not collapse identity proofs. Streicher's axiom **K** (uniqueness of identity proofs, UIP) would impose such a collapse; homotopy type theory is precisely the study of type theory with UIP *rejected*.

### 2.2 From groupoids to model categories

Hofmann and Streicher's groupoid model interprets each type as a groupoid and each identity type as the hom-set of arrows, demonstrating that identity proofs compose and invert. Awodey and Warren generalized this dramatically [3]:

> **Theorem:** *Every Quillen model category admits a sound interpretation of Martin-Löf type theory with identity types, interpreting identity types as path objects from a weak factorization system.*

This established the *homotopy hypothesis for type theory*: types behave like spaces, with identity types as path spaces, iterated identity types as higher path spaces, and the whole tower forming a weak ∞-groupoid.

### 2.3 Voevodsky's simplicial model and the univalence axiom

Voevodsky interpreted types as Kan complexes inside simplicial sets [2]. In this model he observed a new phenomenon: the universe `U` of small types is itself a Kan complex, and a path in `U` between types `A` and `B` is precisely a *weak equivalence* between them. He elevated this observation to an axiom. Writing `A ≃ B` for the type of equivalences (homotopy equivalences: functions with contractible fibers), the canonical map induced by path induction,

```
idtoeqv : Id_U(A, B) → (A ≃ B)
```

is postulated to be itself an equivalence. This is the **univalence axiom** [2]. Its consequences are sweeping: *function extensionality* becomes provable, isomorphic structures can be identified and transported across, and the universe ceases to be a set — e.g., `Id_U(𝟐, 𝟐)` has exactly two elements, corresponding to the two self-equivalences of the booleans.

### 2.4 Higher inductive types

Ordinary inductive types generate *points*. Higher inductive types additionally generate *paths*. The circle is the paradigmatic example [1, 4]:

```haskell
-- The circle as a higher inductive type
data S1 : Type where
  base : S1            -- a point constructor
  loop : Id S1 base base  -- a path constructor
```

The eliminator for `S¹` requires, besides a point `b : P base`, a *dependent path* over `loop` — a path in the total space lying over the loop. HITs give type theory direct access to the basic spaces and constructions of homotopy theory: suspensions, truncations, pushouts, localizations, and quotients all become definable.

## 3. Methodology

This paper is a *comparative logical analysis* rather than an empirical study. We examine four formulations of univalent type theory along three axes — **logical strength** (what is provable), **semantics** (what models exist, and in what metatheory), and **computational behavior** (canonicity, normalization, decidability of conversion):

1. **Book HoTT** [1]: Martin-Löf type theory + univalence axiom + HIT axioms. The reference formulation; no computational interpretation of the axioms.
2. **CCHM cubical type theory** [5]: a De Morgan interval `I` with connections and reversals; paths as functions `I → A` with strict boundary conditions; univalence *proved* via the `Glue` type former; semantics in cubical sets in a constructive metatheory.
3. **Cartesian cubical type theory** [6]: an interval with only diagonals (no reversals or connections as primitive); Kan operations decomposed into homogeneous composition and coercion; designed for computational interpretation.
4. **Computational cubical type theory** (Angiuli–Harper school): a meaning explanation in the Nuprl tradition, implemented in RedPRL/`cooltt`, with univalent universes and exact equality.

For each, we track how the identity type is handled, how univalence is justified, which HITs are supported, and what is known about canonicity. Claims are grounded in the primary literature [1–7], with all sources verified.

## 4. Deep Dive

### 4.1 Identity types without UIP: the ∞-groupoid structure

Rejecting UIP, the identity type reveals algebraic structure *internally*. Path concatenation, inversion, and associativity are all definable by path induction:

```haskell
concat :: Id A a b -> Id A b c -> Id A a c
concat p q = J (\x y p -> (z : A) -> Id A y z -> Id A x z)
               (\x z r -> r) _ _ p _ q

inv :: Id A a b -> Id A b a
inv p = J (\x y _ -> Id A y x) (\x -> refl x) _ _ p
```

The groupoid laws hold only *up to higher identity*: e.g., associativity is a term of type `Id (concat (concat p q) r) (concat p (concat q r))`, itself subject to further coherence. Lumsdaine and van den Berg–Garner showed that every type carries a weak ∞-groupoid structure in this sense. Hedberg's theorem draws the boundary: any type with *decidable* equality is a set (a 0-type), so non-trivial higher structure requires genuinely proof-relevant identity. The hierarchy of **n-types** — types whose identity types are (n−1)-types, with propositions as (−1)-types and sets as 0-types — organizes the entire theory [1].

### 4.2 Univalence: formulation, power, and computational cost

Univalence may be stated as the assertion that `idtoeqv` is an equivalence. One standard equivalent formulation uses the type of equivalences directly:

> **Theorem (Univalence):** *For a universe `U` and `A, B : U`, the canonical map `idtoeqv : (A =_U B) → (A ≃ B)` is an equivalence. Consequently, `(A =_U B) ≃ (A ≃ B)`.*

Among its consequences:

- **Function extensionality**: homotopic functions are equal — `(f ~ g) → (f = g)` — which is *independent* of Martin-Löf type theory without univalence.
- **Structure transport**: any equivalence of types induces transport of all type-theoretic structure, formalizing the mathematical practice of identifying isomorphic objects.
- **Non-trivial universes**: as noted, `U` is not a set.

But as an *axiom*, univalence is computationally inert. The term `ua : (A ≃ B) → (A =_U B)` postulates new canonical inhabitants of identity types with no reduction rules. Hence a closed term `n : ℕ` built using `ua` need not reduce to a numeral: **canonicity fails**. Worse, because conversion must identify terms up to the axiom, type checking remains decidable but *evaluation* gets stuck — the theory cannot be executed. This was the central open problem of the first phase of HoTT: *give univalence computational content* [1].

### 4.3 Higher inductive types: the circle and its fundamental group

HITs extend the inductive schema with path constructors. Their elimination principles demand *dependent* paths: to define `f : S¹ → P` one needs `f base : P base` and a path `apd f loop : Path (P) (f base) (f base)` lying over `loop`. Licata and Shulman used this machinery to compute the fundamental group of the circle synthetically [4]:

> **Theorem (Licata–Shulman):** *`π₁(S¹) ≃ ℤ`, proved by the encode–decode method: define a fibration `code : S¹ → U` with `code base = ℤ` and transport along `loop` given by successor; then show `Σ(x : S¹) code x` is contractible, so paths from `base` correspond to integers.*

This was the first major synthetic homotopy result and demonstrated that HITs plus univalence recover genuine algebraic topology. Yet HITs raise a schema problem: *which* higher inductive definitions are legitimate? General schemas must guarantee strict positivity in higher dimensions, coherence of boundary conditions, and — in the cubical setting — that every constructor's Kan operations compute correctly. Coquand, Huber, and Mörtberg gave a schema for HITs in cubical type theory [5, and arXiv:1802.01170], but a fully general, semantically validated schema remains elusive (§6).

### 4.4 Cubical sets, the interval, and Kan filling

Cubical type theory replaces axiomatic paths with *literal* paths: with an interval type `I` having endpoints `i0, i1`, a path in `A` is a function `p : I → A` with `p i0 ≡ a` and `p i1 ≡ b` *definitionally* at the boundary. The two main traditions differ in the interval's algebra:

| Theory | Interval structure | Path/composition primitive | Univalence | Implementation |
|---|---|---|---|---|
| CCHM [5] | De Morgan algebra: `∧, ∨, ¬` (connections + reversal) | `comp` (Kan composition) + `Glue` | Proved via `Glue` | Cubical Agda (variant) |
| Cartesian [6] | Only diagonals `x = y` constraints; no reversal | `hcomp` + `coe` (transport) decomposed | Proved; exact equality | `cooltt`, RedPRL |
| Book HoTT [1] | None (axiomatic) | Axiom `ua` | Postulated | None (no canonicity) |
| Orton–Pitts [7] | Axiomatized in a topos | Uniform Kan filling | Model construction | — |

In CCHM, the **Glue** type is the engine of univalence [5]:

```haskell
-- Glue: turn a partial equivalence into a total type
Glue :: (phi : I -> Prop) -> (T : Partial phi Type)
     -> (A : Type) -> ((t : T) -> Equiv (T t) A) -> Type
```

`Glue` pastes a family of types defined only on a face `φ` of a cube onto a total type `A`, along equivalences. Univalence is then *proved* by exhibiting, for `e : A ≃ B`, a path `ua e : Path U A B` whose transport computes as `e` itself — the computational content that the axiom lacked. The Kan **composition** operation `comp` fills open boxes: given a cube missing one face, it computes the missing face and the filler, uniformly in the dimension context. Because filling is uniform and constructive, Simon Huber could prove **canonicity**: every closed term of type `ℕ` in CCHM cubical type theory reduces to a numeral [5].

The cartesian variant [6] refines this by decomposing composition into homogeneous composition (`hcomp`, filling in a fixed type) and coercion (`coe`, transport along a path of types). This decomposition makes HITs representable *directly* — each constructor's boundary equations become `hcomp` terms — and underlies the computational cubical type theories implemented in RedPRL and `cooltt`, which additionally feature exact equality types and a cumulative hierarchy of univalent universes. Orton and Pitts [7] clarified the semantic core: the entire construction can be axiomatized as *uniform Kan filling* internal to a topos, identifying the minimal assumptions the interval object must satisfy.

### 4.5 Canonicity, normalization, and proof assistants

The computational payoff is measured in metatheorems:

- **Canonicity** (Huber, for CCHM): closed booleans evaluate to `true`/`false`; closed naturals to numerals — *with univalence present as a theorem*.
- **Normalization** and **decidability of conversion** have been established for cartesian cubical type theories via synthetic Tait computability / gluing arguments, enabling implementations.
- **Cubical Agda** implements a CCHM-style theory with HITs, making synthetic homotopy theory executable: the Licata–Shulman `π₁(S¹)` proof can be *run*.

The slogan of the cubical program is therefore: *univalence was never an axiom; it was a theorem about Kan cubical sets waiting for the right syntax* [5, 6].

## 5. Empirical Results / Proofs

We collect the established metatheoretic results as theorems, with their provenance in the literature.

> **Theorem (Awodey–Warren [3]):** *Intensional Martin-Löf type theory with identity types admits a sound interpretation in any Quillen model category, with identity types interpreted as path objects.*

> **Theorem (Voevodsky [2]):** *The Kan simplicial set model of type theory is univalent: paths in the universe correspond to weak equivalences of types.*

> **Theorem (Licata–Shulman [4]):** *In HoTT with univalence and HITs, `π₁(S¹) ≃ ℤ`, via the encode–decode method.*

> **Theorem (Cohen–Coquand–Huber–Mörtberg [5]):** *In cubical type theory, Voevodsky's univalence axiom is provable; function extensionality is directly provable; the theory has a constructive cubical-set semantics and enjoys canonicity.*

> **Theorem (Angiuli et al. [6]):** *Cartesian cubical type theory validates full univalence with a cumulative hierarchy of univalent universes and supports higher inductive types with computational behavior, via the `hcomp`/`coe` decomposition.*

A comparative summary of what each formulation achieves:

| Property | Book HoTT [1] | CCHM [5] | Cartesian [6] |
|---|---|---|---|
| Univalence | Axiom | Theorem (Glue) | Theorem |
| Function extensionality | From univalence | Direct | Direct |
| HITs | Axiom schema | Circle, truncation, schema | Direct representation |
| Canonicity | **Fails** | Holds (Huber) | Holds |
| Constructive metatheory | Classical (simplicial) | Yes | Yes |
| Mechanized | Partial (axioms stuck) | Cubical Agda | cooltt / RedPRL |

## 6. Limitations

1. **HIT schemas remain incomplete.** No single schema covers all desired higher inductive definitions with validated semantics and computational behavior; tricky cases (higher truncation levels, localizations, indexed HITs with higher constructors) are handled case by case [1, 5].
2. **Homotopical correctness is not uniform.** Some cubical variants have pathological homotopy theories; only specific models are known to present ∞-groupoids correctly, and characterizing them is ongoing work [7].
3. **The interval algebra is a design choice, not canonical.** De Morgan structure (reversals, connections) simplifies Kan filling [5] but complicates the homotopy theory; the cartesian approach [6] is cleaner computationally but requires more explicit Kan operations. The trade-offs are not fully mapped.
4. **Scalability of implementations.** Cubical proof assistants remain research tools: performance, library coverage, and usability lag far behind Coq, Lean, and Agda's mainstream modes, limiting adoption of synthetic homotopy theory.
5. **Universe and size issues.** Univalent universes à la Russell vs. Tarski, cumulativity, and universe polymorphism interact subtly with `Glue` and exact equality; coherence problems that Voevodsky's simplicial model sidestepped classically reappear constructively.
6. **Book HoTT's independence questions.** Whether every theorem of Book HoTT holds in all cubical models — i.e., whether cubical type theory is *conservative* in the relevant sense — is unknown; the axiomatic and computational formulations may diverge on exotic statements.

---

## 7. Conclusion

Homotopy type theory began with a semantic discovery — that identity types are path spaces [3] and that the simplicial universe is univalent [2] — and matured through a computational crisis into a family of cubical theories in which univalence and higher inductive types are theorems with reduction behavior [5, 6]. The arc from Voevodsky's 2010 equivalence axiom to Huber's canonicity proof is one of the clearest case studies in logic of an axiom being *explained* rather than merely postulated.

What endures is a new foundation in which equivalence, not equality, is primitive, and in which spaces are defined by universal properties rather than point sets. What remains is engineering and schema theory: general HIT schemas, verified homotopical correctness across cubical variants, and proof assistants fast enough for working mathematicians. If those are achieved, the univalent foundations may yet become what Voevodsky envisioned — the first satisfactory type-theoretic formalization of mathematics [2].
