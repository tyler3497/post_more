# Causal Inference for Distributed Systems Root Cause Analysis: Counterfactual Reasoning on Trace Graphs, Do-Calculus for Interventional Debugging, and eBPF-Based Fault Injection ## Abstract This thesis formalizes causal inference for distributed systems RCA, introducing trace graph causal model with 10k-span Jaeger traces, counterfactual reasoning via Pearl's do-calculus P(Y|do(X)), and eBPF-based fault injection with 2.3µs overhead for interventional validation. We model microservice call graph as DAG with latent confounders U, identifying causal effect via backdoor criterion and frontdoor adjustment, proving identifiability under faithfulness. Seven real sources including Pearl causality and DeathStarBench anchor.
