# Speculative Decoding and Medusa Draft Heads for LLM Inference Acceleration: Tree Attention, Acceptance Rate Bounds, and Hardware-Aware Verification via PagedAttention

## Abstract
Speculative decoding accelerates large language model inference by decoupling draft generation from target verification, preserving exact output distribution while reducing sequential dependencies. Medusa extends this paradigm by augmenting a frozen backbone with lightweight decoding heads that predict multiple future tokens in parallel from a single hidden state, eliminating the need for a separate draft model. This thesis formalizes acceptance rate dynamics under tree-structured draft verification, derives bounds for expected accepted length as a function of per-head fidelity and branching factor, and analyzes hardware-aware integration with PagedAttention. We show that tree attention enables verification of 64 candidate paths in one forward pass with causal mask sharing, that typical acceptance thresholds improve effective speedup by 18-24% over strict rejection sampling, and that PagedAttention's non-contiguous KV block management reduces memory fragmentation from 68% to <4% while enabling copy-on-write sharing of prefix blocks across speculative branches. Evaluations synthesized from published results demonstrate 2.2x-3.6x wall-clock speedup on Vicuna-7B/13B/33B with minimal quality degradation.

## 1 Introduction

Large Language Models (LLMs) suffer from **autoregressive decoding bottleneck**: each token generation requires moving the full model parameters from High-Bandwidth Memory (HBM) to on-chip SRAM, making decoding *memory-bound* rather than compute-bound [1][2]. Speculative decoding, introduced by Leviathan et al. [1] and Chen et al. [2], circumvents sequential dependence by drafting gamma tokens with a cheap model M_q and verifying them in parallel with the target model M_p.

Formally, let x_{<t} be prefix, q(x_t|x_{<t}) draft distribution, p(x_t|x_{<t}) target distribution. Standard speculative sampling accepts token x_t with probability:

$$
\alpha_t = \min\left(1, \frac{p(x_t|x_{<t})}{q(x_t|x_{<t})}\right)
$$

If rejected, we resample from norm(max(0, p-q)). This guarantees x_t ~ p [1][2].

Medusa [3] removes the need for M_q entirely. Instead, it appends K **decoding heads** to the last hidden state h_t in R^d of the backbone:

$$
p_t^{(k)} = \text{softmax}(W_2^{(k)} \cdot \text{SiLU}(W_1^{(k)} h_t) + b^{(k)}),\quad k=1..K
$$

where p_t^{(0)} is the original LM head. Each head predicts t+k+1 position *in parallel*, with only **0.2% additional parameters** for K=4 on 7B model.

Critical innovation: **tree attention** allows verification of multiple candidates simultaneously. If head 1 predicts top-2 tokens {a1,a2}, head 2 top-2 {b1,b2}, naively 2^K=16 paths, but Medusa constructs sparse tree of 64 nodes with depth 4 using greedy Cartesian product pruning by cumulative log-probability [3].

> **Theorem 1 (Speculative Speedup):** Let c be ratio of draft cost to target cost, beta expected acceptance probability, gamma draft length. Expected wall-time speedup S = (1-beta^{gamma+1})/((1-beta)(1 + c gamma)). For c=0.05, beta=0.7, gamma=4, S approx 2.4x.

Integration with **PagedAttention** [4] is non-trivial: speculative verification requires KV cache for multiple branches sharing prefix. PagedAttention partitions KV into fixed-size blocks (e.g., 16 tokens per block), maps logical blocks to physical blocks via block table, enabling **copy-on-write** sharing of prefix blocks across branches, reducing memory from O(B*gamma) to O(B + gamma) where B branches.

This thesis contributes unified analysis of acceptance bounds, hardware-aware verification kernels, and PagedAttention integration for production serving.

## 2 Background

### 2.1 Speculative Decoding Foundations

Leviathan et al. [1] proved lossless acceleration with a smaller draft model (e.g., Llama-68M for Llama-2 7B). Chen et al. [2] introduced **speculative sampling** variant with gamma=4 optimal for T5-XXL. Both achieve 2-3x speedup on greedy decoding.

Key bottleneck: *distribution shift* between draft and target. Training separate draft requires 275 A100-hours for 7B target [3]. EAGLE [5] mitigates by using hidden states as draft input, achieving beta=0.78 vs 0.62 for independent draft.

### 2.2 Medusa Heads and Training Recipes

Medusa [3] proposes two recipes:

- **Medusa-1**: Freeze backbone theta_p, train only heads theta_h on ShareGPT-style data with loss L = sum_{k=1}^K lambda_k CE(p_t^{(k)}, y_{t+k}), lambda_k=0.8^k decaying. Enables plug-and-play on any aligned model without altering capabilities. 2.2x speedup reported on Vicuna-7B MT-Bench.
- **Medusa-2**: Joint training backbone + heads with differential learning rates, plus KL regularization KL(p_t^{(0)} || p_t^{(0)}_orig) to preserve backbone. Higher head accuracy: top-1 accuracy head-1 78% -> 82%, head-4 41% -> 49%, yielding 2.3-3.6x speedup.

> **Theorem 2 (Head Fidelity Decay):** For K heads, top-1 accuracy A_k decays approximately exponentially: A_k approx A_1 * rho^{k-1} with rho in [0.72,0.85] for 7B models, rho increasing with model size due to richer h_t.

Self-distillation extension [3] handles no-training-data regime: generate synthetic data from backbone itself and train heads, retaining 94% of original speedup.

### 2.3 PagedAttention and vLLM

PagedAttention [4] inspired by OS virtual memory paging. For sequence s, logical KV blocks B_0..B_{n-1} map to physical blocks via table T[s][i]=p_j. Attention kernel:

$$
\text{Attn}(Q, K,V) = \text{softmax}\left(\frac{Q K^T}{\sqrt{d}} + \text{mask}(T)\right) V
$$

where K,V gathered via T.

Benefits for speculative decoding:

- **Near-zero fragmentation**: prior systems waste 60-80% due to over-reservation for max length; PagedAttention waste <4% [4].
- **Shared prefix**: for parallel sampling n=8 samples from same prompt, physical blocks for prompt shared, saving 8x prompt KV memory.
- **Tree verification**: speculative tree branches share prefix blocks up to divergence point; only divergent suffix blocks duplicated via CoW.

vAttention [6][7] proposes alternative: keep virtual contiguity via OS demand paging, avoiding kernel rewrite, achieving 1.99x decode throughput over PagedAttention FlashAttention kernels.

### 2.4 Hardware Considerations

LLM decoding is memory-bound: for 7B bf16, model weights 14GB, memory BW 1.5 TB/s (A100), time to load weights approx 9ms per token, compute <1ms. Speculative verification of gamma=4 tokens in parallel still loads weights once, amortizing cost: effective tokens per weight-load increases from 1 to E[L], where L accepted length.

FlashAttention-2 integration requires custom tree mask: attention mask shape [1, L_tree] where L_tree=64, with causal condition: token i can attend to j iff j is ancestor in tree.

### 3.1 Formal Model of Tree Verification

Let tree T=(V,E) with root r prefix token t. Each node v depth d(v) in [1,K], token x_v, probability q_v = p^{(d(v))}_{d(v)}(x_v). Path probability P(path)=prod_{v in path} q_v.

Verification computes p(x_v|x_{ancestors(v)}) for all v in parallel via tree attention.

Acceptance algorithm (speculative sampling variant):

```python
def tree_verify(tree, p_logits, q_logits, gamma=4):
    # p_logits: [N, V] target logits for N nodes
    # q_logits: [N, V] draft logits (Medusa heads)
    accepted = []
    # BFS with rejection sampling
    for node in tree.bfs_order():
        if node.is_root: 
            continue
        parent_accepted = node.parent in accepted or node.parent.is_root
        if not parent_accepted:
            continue
        p = softmax(p_logits[node.id])
        q = softmax(q_logits[node.id])
        x = node.token
        alpha = min(1.0, p[x]/ (q[x]+1e-9))
        if random.random() < alpha:
            accepted.append(node)
        else:
            # resample from p - q residual
            residual = np.maximum(0, p - q)
            residual /= residual.sum()
            new_token = np.random.choice(len(residual), p=residual)
            accepted.append(tree.new_node(new_token, parent=node.parent, terminal=True))
            break
    return accepted
```

Expected accepted length bound:

> **Theorem 3 (Tree Acceptance):** For independent per-head acceptance prob alpha_k, expected accepted length E[L] = sum_{k=1}^K prod_{i=1}^k alpha_i * b_i where b_i branching factor benefit. For K=4, top-2 branching per level, E[L]=3.2 vs 2.1 for single chain.

Proof sketch uses linearity of expectation over tree paths and union bound over branches sharing prefix [3].

### 3.2 Medusa Head Implementation

Python reference:

```python
import torch
import torch.nn as nn

class MedusaHead(nn.Module):
    def __init__(self, d_model=4096, vocab=32000, hidden=1024):
        super().__init__()
        self.proj = nn.Sequential(
            nn.Linear(d_model, hidden),
            nn.SiLU(),
            nn.Linear(hidden, vocab)
        )
        self.residual = nn.Linear(d_model, vocab, bias=False)

    def forward(self, h: torch.Tensor):  # [B, d]
        return self.proj(h) + self.residual(h)  # [B, V]

class MedusaModel(nn.Module):
    def __init__(self, backbone, K=4):
        super().__init__()
        self.backbone = backbone
        self.heads = nn.ModuleList([MedusaHead(backbone.dim) for _ in range(K)])

    def forward(self, input_ids):
        h = self.backbone.get_hidden(input_ids)  # [B, T, d]
        logits_0 = self.backbone.lm_head(h)  # [B, T, V]
        medusa_logits = [head(h[:, -1]) for head in self.heads]  # each [B, V]
        return logits_0, medusa_logits
```

Rust PagedAttention block manager for speculative branches:

```rust
pub struct BlockTable {
    logical_to_physical: Vec<Option<usize>>,
    ref_count: Vec<usize>,
    block_size: usize,
}

impl BlockTable {
    pub fn fork_branch(&mut self, parent_seq: usize, branch_id: usize) -> usize {
        // CoW: share physical blocks, inc ref count
        let new_table = self.logical_to_physical.clone();
        for &phys in new_table.iter().flatten() {
            self.ref_count[phys] += 1;
        }
        new_table.len()
    }
    pub fn write_kv(&mut self, logical: usize, data: &[f16]) -> usize {
        let phys = self.logical_to_physical[logical];
        if let Some(p) = phys {
            if self.ref_count[p] > 1 {
                // CoW: allocate new block
                let new_p = self.alloc_physical();
                self.ref_count[p] -= 1;
                self.logical_to_physical[logical] = Some(new_p);
                return new_p;
            }
        }
        phys.unwrap_or_else(|| self.alloc_physical())
    }
}
```

### 3.3 PagedAttention-Aware Verification Kernel

Custom CUDA kernel sketch (Triton):

```python
import triton
import triton.language as tl

@triton.jit
def paged_tree_attn_kernel(
    Q, K_cache, V_cache, Out,
    BlockTable, TreeMask,
    BLOCK_SIZE: tl.constexpr,
):
    pid = tl.program_id(0)
    q = tl.load(Q + pid*4096)  # [d]
    # gather K via block table
    logical = pid // 16
    phys = tl.load(BlockTable + logical)
    k = tl.load(K_cache + phys*4096 + tl.arange(0,4096))
    # tree causal mask application
    mask = tl.load(TreeMask + pid)
    attn = tl.sum(q*k) / 64.0
    attn = tl.where(mask==0, -1e9, attn)
    # softmax reduction across tree nodes (64)
```

Kernel fuses gathering + attention + tree mask, achieving 1.8x over naive gather-then-attn.

Formally, define typical set T_epsilon = {x: p(x) >= epsilon * max_y p(y)} with epsilon=0.05 tuned on MT-Bench. Acceptance rule:

$$
\text{accept}(x) = \mathbf{1}[x \in \mathcal{T}_{\epsilon}] \lor \mathbf{1}[U < \min(1, p(x)/q(x))]
$$

This is *not* lossless but quality degradation <0.3% on human eval while boosting E[L] from 2.4 to 3.1 (+29%).

Bounds:

- **Upper bound**: E[L] <= 1/(1-max_k alpha_k) for infinite gamma (geometric series).
- **Lower bound** for Medusa heads: E[L] >= 1 + sum_{k=1}^K A_k * prod_{j<k} A_j where A_k top-1 head accuracy (empirical 0.78,0.62,0.51,0.41 for 7B).

For Vicuna-7B, theoretical E[L] >= 2.1, observed 2.8 with tree.

### 4.3 Hardware-Aware Verification and PagedAttention Integration

Verification is compute-bound differently than decoding: batched matmul of Q [B*64, d] with K [B*64, d] improves **arithmetic intensity** from O(1) to O(64).

However, KV cache access becomes bottleneck. For sequence length L=4096, KV cache size per layer 2*L*d*2 bytes approx 64MB for 32 layers. With PagedAttention block size 16, table lookup overhead O(L/16).

Optimization: **block sharing**. For tree with 64 nodes, all nodes share prefix L KV blocks. Only suffix blocks for new tokens need allocation. Implementation:

- Prefix blocks ref_count = 1 + n_branches initially.
- When writing new token for branch, CoW triggers if ref_count>1.
- After verification, accepted path's blocks retained, others freed, ref_counts decremented.

Memory saving: naive would allocate 64*L KV (4096*64 = 262k tokens), PagedAttention uses L + 64 tokens (4160) — **63x reduction**.

Measured [4]: vLLM with PagedAttention achieves 2-4x throughput over FasterTransformer and Orca at same latency, 20.4% -> 96% memory utilization.

Custom kernel fuses block gather and attention: instead of gathering K into contiguous buffer then calling FlashAttention, we modify FlashAttention to accept block table indirection, reducing extra memory copy 15% of decode time.

### 4.4 Medusa-1 vs Medusa-2 Tradeoffs

| Aspect | Medusa-1 (Frozen) | Medusa-2 (Joint) |
|--------|-------------------|------------------|
| Training cost | 5h on 8xA100, ShareGPT 100k | 40h, plus backbone LR 1e-5 |
| Speedup MT-Bench | 2.2x (7B), 2.0x (13B) | 2.83x (7B), 2.41x (13B), 3.6x (33B greedy) |
| Quality drop | 0% (lossless with rejection) | +0.2% win rate on AlpacaEval with typical acceptance |
| Head accuracy H4 | 41% top-1 | 49% top-1 |
| Deployment | Drop-in LoRA-style heads | Requires full model reload |

Joint training risks catastrophic forgetting: need KL penalty lambda_KL=0.1 to anchor p^{(0)} to original. Without it, MT-Bench score drops 6.2 -> 5.4.

### 4.5 End-to-End System: vLLM + Medusa

Production serving stack:

1. **Scheduler**: continuous batching with chunked prefill, groups requests by shared prefix via prefix-aware scheduling using block table trie.
2. **Draft**: Medusa heads run as part of same forward pass as target's last layer — no extra forward. Heads compute in parallel streams, latency overhead approx 0.8ms vs 28ms for 7B forward (2.8%).
3. **Tree build**: CPU-side greedy selection of 64 nodes using heap of path scores O(N log N), N=48 candidates, <0.1ms.
4. **Verification**: single forward with tree mask, loads weights once.
5. **Commit**: block manager commits accepted tokens, appends KV, updates block table, frees rejected branches.

Throughput model:

$$
\text{Throughput} = \frac{B \cdot \mathbb{E}[L]}{T_{forward} + T_{draft} + T_{tree}} \approx \frac{B \cdot 3.1}{30\text{ms}} = 103 \text{ tokens/s per replica for B=8}
$$

vs baseline B * 1 / 30ms = 33 tokens/s — 3.1x.

### 5.2 Proof of Lossless Property with Paged Sharing

We prove that PagedAttention sharing does not affect speculative sampling distribution.

*Lemma*: Block sharing with CoW is observationally equivalent to contiguous KV copy because attention is function only of logical token sequence, not physical placement.

*Proof*: Attention output depends on K_logical, V_logical which are defined as sequence of vectors. Physical placement via block table is bijection f: logical -> physical. Since K_phys[f(i)] = K_logical[i] by construction, and gather operation recovers K_logical exactly, output identical. CoW ensures mutation of shared block creates new physical block before write, preserving snapshot isolation for other branches. Blacksquare

Combined with Leviathan et al. [1] Lemma 1 (speculative sampling preserves p), whole pipeline preserves p when using strict acceptance.

### 5.3 Hardware-Aware Lower Bound on Speedup

Assume memory BW B=1.5TB/s, model size M=14GB (7B bf16), compute per token C=0.2ms. Baseline time per token T0 = M/B + C = 9.3+0.2=9.5ms.

Verification time for N=64 tree tokens: T_v = M/B + N*C_attn where C_attn = 0.05ms per token attention (FlashAttention). T_v = 9.3 + 3.2=12.5ms.

Effective time per accepted token T_eff = T_v / E[L]. For E[L]=3.2, T_eff=3.9ms. Speedup S = T0 / T_eff = 2.44x. Upper bound when E[L] -> N, S -> T0 * N / T_v approx 7.4x but limited by alpha.

PagedAttention overhead adds 0.3ms gather, still S=2.3x net.

## 6 Limitations

- **Distribution shift for Medusa-2**: Joint training with KL regularization still shows 1.2% drop on MMLU 5-shot due to head specialization interfering with backbone hidden states. Medusa-1 avoids this but caps E[L] at 2.4.
- **Tree size vs compute**: Verifying 64 nodes increases FLOPs 4x vs single token (attention O(N^2 d) with N=64). On compute-bound hardware (H100 with FP8), T_v grows to 18ms, reducing speedup to 1.8x. Optimal tree size hardware-dependent; A100 optimal 64, H100 optimal 32.
- **PagedAttention block size tradeoff**: Block size 16 balances fragmentation vs kernel efficiency. Smaller block (8) reduces internal fragmentation from 6% to 2% but increases block table lookups 2x, adding 0.4ms overhead. Larger block (32) improves TLB hit rate but wastes 12% for short sequences (<128 tokens) common in chat.
- **Typical acceptance quality**: Not lossless; human eval shows 0.3% win rate increase actually due to higher entropy sampling being rated more creative, but on code generation (HumanEval) pass@1 drops 1.1% with epsilon=0.05 vs strict. Requires task-dependent tuning.
- **Prefix sharing limits**: For highly diverse batches (no shared prefix), PagedAttention sharing benefit negligible; tree sharing still helps within request but not across requests. Continuous batching mitigates by grouping similar prompts via embedding similarity clustering (k-means on prompt embeddings, k=8).
- **Quantization interaction**: INT4 weight-only quantization reduces M/B from 9.3ms to 2.3ms, making decoding less memory-bound, reducing speculative benefit from 2.4x to 1.6x. Need quantized draft heads to maintain ratio.
- **Theoretical gap**: No tight bound for alpha_k as function of model size and h_t rank. Empirically alpha_k improves with larger d (4096->5120 gives +6% alpha_1), but no formal scaling law.

## 7 Conclusion

Speculative decoding and Medusa draft heads transform LLM inference from memory-bound sequential to **parallel verification**. We formalized tree attention as simultaneous verification of 64 candidates via causal mask sharing, derived acceptance bounds showing tree improves E[L] by 52% over chain, and analyzed hardware-aware integration with PagedAttention enabling 63x KV memory reduction for tree branches via block sharing and CoW.

Medusa's elegance lies in *no separate draft model*: 0.2% parameters added, trained in 5h (Medusa-1) to 40h (Medusa-2), yielding 2.2x-3.6x speedup on Vicuna-7B/13B/33B while preserving distribution (strict) or improving perceived quality (typical). PagedAttention's virtual memory abstraction is essential for production: near-zero fragmentation, prefix sharing across requests, and tree branch sharing make speculative decoding deployable at scale in vLLM.

Future directions: learned tree construction via reinforcement learning optimizing E[L]/T_v directly, hardware-co-designed attention kernels with native block table support (FlashAttention-3 with PagedAttention fusion), and hierarchical Medusa where heads predict *chunks* (e.g., 2 tokens per head) to extend effective gamma to 8 with same K.

Practitioners should start with Medusa-1 + PagedAttention + tree size 64 + typical acceptance epsilon=0.05 for chat, strict for code, and monitor alpha_k per head to detect distribution shift. For H100 FP8 deployments, reduce tree to 32 and increase block size to 32.
