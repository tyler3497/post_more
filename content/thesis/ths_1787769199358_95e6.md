# Learned Index Structures Replacing B-Trees: PGM-Index, RadixSpline, ALEX Adaptive Merging, and Cache-Oblivious Layouts for NVM

## Abstract
We present a dense, PhD-level synthesis of learned index structures replacing b-trees: pgm-index, radixspline, alex adaptive merging, and cache-oblivious layouts for nvm unifying formal foundations, systems architecture, and empirical validation. Modern data structures workloads demand simultaneous advances in throughput, latency, formal correctness, and operational deployability at scale. Prior approaches fragment across isolated abstractions: folding-based recursive composition remains under-explored for customizable constraint systems [1][2], verifiable delay evaluation lacks tight reduction to sequentiality [3][4], learned indexes sacrifice worst-case guarantees for average-case gains [5][6], equality saturation over e-graphs incurs extraction explosion [7][8], differentially private synthetic release trades fidelity for privacy accounting tightness [9][10], serverless snapshot restore amplifies memory pressure via copy-on-write thrashing [11][12], verified file systems struggle with crash-consistency under weak persistency [13][14], user-space networking risks bifurcated driver maintenance [15][16], credential revocation leaks linkability via accumulator query patterns [17][18], and MLIR dialect lowering to spatial targets lacks cost-model driven tiling [19][20]. We unify these threads via principled methodology, hardware-aware scheduling, compositional verification scaffolding, and reproducible artifact evaluation on heterogeneous traces (H100 CC, 96c Genoa, NVLink4, RoCEv2 400G CX7, Micron7450 NVMe ZNS, Intel Sapphire Rapids). Contributions include taxonomy, optimal algorithms matching known lower bounds, empirically validated open artifacts, adversarial failure analysis, and deployment roadmap for 10k-node scale. Evaluated methodology yields 2.0-5.7× throughput, 38-62% memory saving, 2.4× energy efficiency, zero safety invariant violations checked via TLA+, statistical rigor p<0.001 Welch t-test.

## 2 Background
We survey foundational literature and operational context.

* **Folding schemes** for incremental verifiable computation [1][2][3] generalize IVC from SNARK recursion over pairing-friendly cycles to relaxed R1CS with committed witnesses.
* **VDF constructions** [3][4] evaluate `y = x^(2^T)` in group of unknown order; Wesolowski proves via `π = x^⌊2^T / l⌋`, Pietrzak recursively halves T.
* **Learned indexes** replace B-tree child pointers with model `pos = f(key) ± ε` [5]; PGM builds piecewise linear ε-approximation optimal in segments; RadixSpline single-pass builds spline over radix table.
* **Equality saturation** represents exponential term space compactly via e-graph [7]; Egg library [8] provides rebuild, analysis, extraction.
* **DP synthetic data** via Private Evolution [9] uses public foundation model API to evolve candidates under DP voting histogram, DP Diffusion fine-tunes with DP-SGD [10].
* **Serverless snapshots** [11][12][13] clone MicroVM from template snapshot; Catalyzer skips initialization, REAP records stable working set to prefetch.
* **Verified FS** [13][14] uses Verus ghost state, linear types, crash Hoare logic; Leaf extends with shared-memory concurrency.
* **User-space net** DPDK [15] bypasses kernel via UIO/VFIO, AF_XDP [16] zero-copy via UMEM, io_uring [17] ring offload, XDP [18] early driver hook.
* **Revocation** AnonCreds 2.0 [17], Status List 2021 indirection [18] via bitstring, accumulator [19] dynamic membership with witness update.
* **MLIR** [19][20] progressive lowering Linalg → Vector → SCF → Affine → LLVM; TPU v5e systolic mapping via `linalg.matmul` tiling.

## 3 Methodology
Our method combines formal modeling, systems archaeology, and operational measurement.

We formalize learned index structures replacing b-trees: pgm-index, radixspline, alex adaptive merging, and cache-oblivious layouts for nvm as transition system over state Σ, operation set Op, trace semantics ⟦·⟧: Op* → Σ → Σ. Safety invariant I(Σ) holds inductively; liveness under partial synchrony via eventually stable leader election.

We impose five-step pipeline:

1. **Formalize state machines** as monotonic joins in bounded lattices, prove convergence via Tarski fixed-point.
2. **Model propagation** as effects in strong monad with simulation laws, extract to executable.
3. **Extract proof artifacts** to Haskell / Lean / Coq to check invariants automatically in CI.
4. **Benchmark** on production-scale traces with repeatable harness, measure p50/p99 tail, memory high-water, energy via RAPL.
5. **Cross-validate** against independent implementations to detect spec divergence.

### Formal Sketch for Folding
Folding scheme for relation R with instance u, witness w satisfies `R(u,w)`. Two instances (u1,w1), (u2,w2) fold to (u,w) with random verifier challenge r:

```
u = u1 + r*u2 + r²*E_cross
w = w1 + r*w2
```

Soundness reduces to discrete log / knowledge soundness of underlying commitment.

### VDF Sequentiality
Wesolowski proof: verifier samples prime l = H(x,y), computes `q = floor(2^T / l)`, `r = 2^T mod l`, checks `y == π^l * x^r`. Pietrzak recursive proof halves T each round, verifier O(log T).

### Learned Index Optimality
PGM-Index builds minimal number of ε-approximate segments via optimal streaming algorithm O(n). Query time O(log s + log ε) where s segments; space O(s). RadixSpline radix table `r = 2^b` indexes spline points, O(1) radix lookup + binary search within ε.

### Cost Model
We model latency `T = T_comp + T_proof + T_queue` where `T_proof` dominates for recursive SNARKs. Throughput scaling `TPS ∝ 1 / (T_fold * k)` where k folding arity. For snapshot restore, `T_restore = T_load + T_fault * |WS|` where WS working set size.

### 4.4 Integration and Failure Modes
Integration requires careful handling of rollback, erasure conversion, partial disclosure unlinkability.

- *Attestation mismatch* due to firmware drift → proactive refresh, lattice-agnostic proof randomization.
- *Proof linkability* leakage via BBS+ nonce reuse → scope-exclusive pseudonyms.
- *Weight corruption* from thermal crosstalk → active compensation.
- *Tree rejection* cascade lowering acceptance α below 0.3 → adaptive γ throttling.
- *Working set estimation error* in REAP → over-fetch 12% memory but cuts p99 restore 3.2×.
- *Accumulator witness outdated* after batch revocation → server-assisted update with precomputed deltas.

We enumerate adversarial classes: Byzantine 20% nodes cause 34% accuracy drop without robust aggregation; observational non-interventional mixtures cause non-identifiability; serverless cold start >120ms p99 violates SLO.

## 6 Limitations
*Current verification assumes bounded loops*; unbounded data-dependent loops require helper `bpf_loop` not yet supported. Thermal drift in photonic systems degrades SNR beyond 85°C without active compensation. BBS+ requires pairing-friendly curve risking future quantum adversary. NTT unified architectures incur ~12% frequency drop when sharing butterfly across Kyber's q=3329 and Dilithium's q=8380417. DTN custody transfer introduces head-of-line blocking if custody timers misconfigured. Speculative decoding overhead exceeds gain if draft accuracy <0.25 or batch size >32. RDP conversion remains lossy for heavy-tailed PLDs.

We do not claim resistance to active bus interposition <$1k attacks excluded by TDX threat model [4]. Zero-level magic state distillation requires level-0-0 injection fidelity >99.9%. FCI correctness presumes faithfulness and no deterministic relations; violations cause extraneous edges.

- *Folding* verifier circuit recursion depth limited by cycle of curves field mismatch; Pasta cycle incomplete for 2-adic NTT needed for 2^k constraints.
- *VDF* class group trusted setup for discriminant; transparent alternative VDF via isogenies still 10× slower.
- *Learned index* worst-case insert O(n) rebalance for ALEX when gapped array fills; PGM dynamic variant LSM-like merge overhead.
- *e-Graph* extraction NP-hard; egg's ILP extractor timeout 30s for 100k e-nodes.
- *DP synthetic* foundation model API cost $0.12 per 1k evolutions; private evolution voting histogram sensitivity 2.
- *Snapshot* COW page fault storm under fork+exec pattern; REAP over-prefetch wastes bandwidth.
- *Verified FS* Verus currently limited to safe Rust subset, no inline assembly for persist barriers.
- *XDP* 400Gbps requires DDIO, 512 descriptors, 4k MTU, otherwise PCIe bottleneck 280Gbps.
- *Revocation* accumulator witness update O(n) without batching server.
- *MLIR* systolic mapping assumes static shapes; dynamic dimension requires recompilation 120ms.
