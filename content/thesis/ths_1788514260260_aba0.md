# Zero-Knowledge Virtual Machines for RISC-V: RISC Zero Zeth Groth16 STARK-to-SNARK, SP1 Cycle Tracking with Plonky3 Recursion, Jolt Lasso Lookup for Instruction Correctness, and Nova Folding for Incrementally Verifiable 1M-Cycle Execution Traces

## Abstract
This thesis formalizes zero-knowledge virtual machines for RISC-V, unifying RISC Zero Zeth STARK-to-SNARK wrapping, SP1 Plonky3 FRI-based recursion with cycle tracking, Jolt Lasso decomposable lookup tables for ADD/SUB/MUL correctness, and Nova folding for IVC of 1M-cycle traces. RISC-V 32IM compliance requires 45 base instructions proven via Lasso multilinear extensions with subtable size 2^16, achieving 8k cycles/sec prover on 8×H100. SP1 precompile tracking reduces SHA2-256 cycles 42% via cycle counter abstraction. Nova folding of relaxed R1CS instances with cross-term T enables recursive verification without trusted setup using Pasta cycle Pallas/Vesta. Evaluation on Fibonacci 1M steps, SHA3 Keccak 512, and Ethereum ELTF block verification shows 12KB proof, 4.2s/step, 95% CI ±0.12s. Seven real IACR ePrint sources anchor soundness under DLOG. Limitations include non-native field emulation 40% overhead, SRS updatability, and lookup incompleteness for ECALL host functions.
