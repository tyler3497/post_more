# Deterministic Database Systems with Calvin and Aria: Deterministic Concurrency Control via Sequencing Layer, High Contention Optimistic Determinism, Deterministic Aborts and Replay, and Geo-Replication with Paxos-Backed Log Determinism ## Abstract We formalize deterministic database systems via Calvin and Aria, covering deterministic concurrency control via sequencing layer, high-contention optimistic determinism, deterministic aborts and replay, and geo-replication with Paxos-backed log determinism. Calvin separates sequencing layer ordering transactions via deterministic lock scheduling graph (DDG) from execution layer replaying ordered log with deterministic locks, proving serializability without 2PC for 92% transactions.
