# Differential Privacy for High-Dimensional Data: Gaussian Mechanism Composition, Private PAC Learning, DP-SGD Moments Accountant, and Matrix Mechanism for Linear Queries

## Abstract
We present a unified treatment of differential privacy in high dimensions through four complementary lenses: the Gaussian mechanism and its compositional calculus, private PAC learning with representation dimension, differentially private stochastic gradient descent with moments accountant, and the matrix mechanism for workload-adaptive linear queries. We formalize (ε,δ)-DP and its relaxations (Rényi DP, zero-concentrated DP, f-DP) and derive tight bounds for Gaussian noise calibration via ℓ₂-sensitivity. We characterize private learnability: while every finite concept class is privately learnable with O(log|C|) samples, proper private learning separates from VC dimension, with point and threshold functions requiring Ω(b) samples for domain {0,1}ᵇ. For deep learning, we analyze DP-SGD's per-sample clipping, Poisson subsampling amplification, and moments accountant that tracks the log-moment generating function of privacy loss to yield O(qε√T)-DP with orders-of-magnitude tighter accounting than advanced composition. Finally, we develop the matrix mechanism where a workload W is factored as W=LA via strategy A, answering A with independent noise and reconstructing Wx with correlated error minimized by semidefinite programming. Together these mechanisms illuminate the privacy-utility-computation Pareto frontier for high-dimensional analytics.

## 1 Introduction

High-dimensional data — *genomics*, *embeddings*, *user histograms* — exacerbates privacy risk: **reconstruction attacks** succeed with O(n) linear queries, and membership inference thrives on overparameterized models. Differential privacy (DP) [1][2] offers a rigorous semantic guarantee: for all neighboring datasets $x,x'$ differing in one record and all measurable $S$,

$$ \Pr[\mathcal{M}(x) \in S] \le e^{\epsilon} \Pr[\mathcal{M}(x')\in S] + \delta $$

with $\epsilon>0$ controlling *distinguishability* and $\delta$ allowing $o(1/n)$ failure.

This thesis synthesizes four pillars for high-dimensional DP:

- **Gaussian Mechanism**: Why $\ell_2$-sensitivity enables dimension-independent noise scaling critical for vectors, gradients, and embeddings.
- **Private PAC Learning**: What concept classes remain learnable under privacy, and why *representation dimension* $RepDim(C)$ not $VC(C)$ characterizes sample complexity.
- **DP-SGD + Moments Accountant**: How per-example clipping, Gaussian noise, and tight composition enable single-digit $\epsilon$ deep learning on MNIST/CIFAR [3].
- **Matrix Mechanism**: How to answer a *workload* $W$ of $m$ linear queries by answering a *strategy* $A$ with independent noise, then reconstructing $W$ via $W A^\dagger$, optimizing $A$ to minimize total mean squared error.

> Theorem: (Gaussian Mechanism Calibration). Let $f: \mathcal{X}^n \to \mathbb{R}^d$ have $\ell_2$-sensitivity $\Delta_2 = \max_{x\sim x'} \|f(x)-f(x')\|_2$. Then $\mathcal{M}(x)=f(x)+\mathcal{N}(0,\sigma^2 I_d)$ with $\sigma \ge \frac{\Delta_2 \sqrt{2\ln(1.25/\delta)}}{\epsilon}$ is $(\epsilon,\delta)$-DP for $\epsilon\in(0,1)$ [1].

High-dimensional impact: unlike Laplace mechanism scaling as $O(d^{3/2})$, Gaussian scales as $O(\sqrt{d})$ in $\ell_2$ error — essential when $d=10^6$.

## 2 Background

### 2.1 Definitions

- **Neighboring**: $x\sim x'$ differ by one record (unbounded DP) or substitution (bounded DP). We use unbounded for histograms.
- **Sensitivity**: $\Delta_1 = \max \|f(x)-f(x')\|_1$, $\Delta_2 = \max \|f(x)-f(x')\|_2$.
- **$(\epsilon,\delta)$-DP**: as above. Pure $\epsilon$-DP corresponds to $\delta=0$.
- **Rényi DP**: $D_\alpha(\mathcal{M}(x)\|\mathcal{M}(x')) \le \epsilon(\alpha)$ for order $\alpha>1$ [5].
- **zCDP**: $D_\alpha \le \rho\alpha$ linear in $\alpha$ [6].

### 2.2 Composition Taxonomy

| Composition | Bound | Tightness | Subsampling Amplification? |
|-------------|-------|-----------|----------------------------|
| Basic | $\epsilon_{tot}=k\epsilon$, $\delta_{tot}=k\delta$ | Loose | No |
| Advanced [1] | $\epsilon_{tot}= \sqrt{2k\ln(1/\delta')}\epsilon + k\epsilon(e^\epsilon-1)$, $\delta_{tot}=k\delta+\delta'$ | Moderate | Yes via lemma |
| Moments Accountant [3] | $\delta=\min_\lambda \exp(\alpha(\lambda)-\lambda\epsilon)$ where $\alpha(\lambda)=\log \mathbb{E}[e^{\lambda L}]$ | Tight | Yes: $O(q)$ amplification |
| RDP [5] | $\epsilon_{RDP}(\alpha)=\sum_i \epsilon_i(\alpha)$, convert to $(\epsilon,\delta)$ via $\delta = \exp((\alpha-1)(\epsilon_{RDP}-\epsilon))$ | Tightest (standard) | Yes: $q^2\alpha$ bound |

$L$ is privacy loss RV: $L^{(o)} = \log \frac{\Pr[\mathcal{M}(x)=o]}{\Pr[\mathcal{M}(x')=o]}$.

### 2.3 PAC Learning

PAC: concept $c: X\to\{0,1\}$, distribution $D$, error $err_D(h,c)=\Pr_{x\sim D}[h(x)\neq c(x)]$. Class $C$ PAC-learnable if $\exists$ algorithm using $m=O(VC(C)/\alpha)$ samples outputting $h$ with error $\le\alpha$ w.p. $\ge 1-\beta$.

Private PAC: algorithm $\mathcal{A}$ is $(\epsilon,\delta)$-DP *and* PAC accurate [4].

Representation dimension $RepDim(C)$ [7]: smallest $k$ s.t. $\exists$ distribution $\mathcal{P}$ over hypothesis classes $\mathcal{H}_i$ each of size $\le 2^k$ where for all $c\in C, D$, $\Pr_{\mathcal{H}\sim\mathcal{P}}[\exists h\in\mathcal{H}: err_D(h,c)\le 1/4]\ge 3/4$.

> Theorem: (Beimel-Nissim-Stemmer). Sample complexity of pure $\epsilon$-DP PAC learning is $\Theta(RepDim(C))$ [7].

Separation: $VC(Point_b)=1$ but $RepDim(Point_b)=\Theta(b)$ for domain $\{0,1\}^b$, implying $\Omega(b)$ private samples for proper learning [2][4].

## 3 Methodology

We formalize mechanisms and prove privacy.

### 3.1 Gaussian Mechanism

Given $f$, output $f(x)+\mathcal{N}(0,\sigma^2 I)$. Privacy proof uses tail bound of Gaussian: privacy loss $L \sim \mathcal{N}(\frac{\Delta_2^2}{2\sigma^2}, \frac{\Delta_2^2}{\sigma^2})$. Requiring $\Pr[L>\epsilon]\le\delta$ yields $\sigma$ condition. For $\epsilon<1$, analytic Gaussian mechanism [8] improves constant to $\sigma = \frac{\Delta_2}{2\epsilon}(\sqrt{\Phi^{-1}(...)})$.

High-dimensional effect: $\mathbb{E}[\|noise\|_2^2]=d\sigma^2$, so MSE scales linearly in $d$, but $\ell_\infty$ error scales $\sigma\sqrt{2\log d}$.

Implementation:

```python
import numpy as np

def gaussian_mechanism(f_x: np.ndarray, sensitivity_l2: float, epsilon: float, delta: float) -> np.ndarray:
    # (epsilon,delta)-DP Gaussian mechanism - Dwork Roth 2014
    assert 0 < epsilon < 1 and 0 < delta < 1
    sigma = np.sqrt(2 * np.log(1.25 / delta)) * sensitivity_l2 / epsilon
    return f_x + np.random.normal(0, sigma, size=f_x.shape)

def analytic_gaussian_sigma(sens, eps, delta):
    # Balle & Wang 2018 analytic calibration - tighter
    import mpmath as mp
    lo, hi = 0.0, 10*sens/eps
    for _ in range(40):
        mid = (lo+hi)/2
        # delta(eps) = Phi(Delta/2sigma - eps sigma/Delta) - e^eps Phi(-Delta/2sigma - eps sigma/Delta)
        lo = mid  # placeholder - actual check uses mp.erfc
    return hi
```

### 3.2 Composition via Moments

Moments accountant [3] tracks $\alpha_{\mathcal{M}}(\lambda)=\max_{x\sim x'} \log \mathbb{E}_{o\sim\mathcal{M}(x)}[\exp(\lambda L(o))]$.

Composition: $\alpha_{\mathcal{M}_{1:k}}(\lambda)\le\sum_i \alpha_{\mathcal{M}_i}(\lambda)$. Conversion: $\mathcal{M}$ is $(\epsilon,\delta)$-DP for $\delta=\min_\lambda \exp(\alpha(\lambda)-\lambda\epsilon)$.

For Gaussian mechanism with sampling probability $q=L/N$, Abadi et al. prove:

$$ \alpha(\lambda) \le \frac{q^2 \lambda(\lambda+1)}{(1-q)\sigma^2} + O(q^3\lambda^3/\sigma^3) $$

for integer $\lambda\le\sigma^2\ln(1/q\sigma)$. Numerically integrated via log-sum-exp.

Haskell type-level tracking of privacy budget:

```haskell
{-# LANGUAGE DataKinds, KindSignatures #-}

import GHC.TypeLits

  Pure :: DP 0 0

  Compose :: DP e1 d1 -> DP e2 d2 -> DP (e1+e2) (d1+d2)

-- Advanced composition tracked at type level

advancedComp m k = undefined -- uses theorem: eps' = sqrt(2k ln(1/d'))*eps + k eps (e^eps-1)

-- RDP conversion
rdpToDP :: Double -> Double -> (Double, Double) -- alpha, epsilon_RDP -> (epsilon_DP, delta)
rdpToDP alpha epsRDP = (epsRDP + log (1/delta)/(alpha-1), delta) where delta=1e-5
```

### 3.3 DP-SGD

Algorithm (Abadi et al. [3]):

1. Sample batch $B_t$ via Poisson sampling $q=L/N$ or fixed-size shuffling (amplification approximated).
2. For $x_i\in B_t$, compute $g_t(x_i)=\nabla_\theta \ell(\theta_t; x_i)$.
3. Clip: $\bar g_t(x_i)=g_t(x_i)/\max(1,\|g_t(x_i)\|_2/C)$.
4. Add noise: $\tilde g_t = \frac1L (\sum_i \bar g_t(x_i) + \mathcal{N}(0,\sigma^2 C^2 I))$.
5. Update $\theta_{t+1}=\theta_t - \eta_t \tilde g_t$.

Privacy accounting uses moments accountant with $T$ steps.

```python
def dp_sgd_step(params, batch, C, sigma, lr):
    grads = [torch.autograd.grad(loss_fn(params, x,y), params) for x,y in batch]
    clipped = []
    for g in grads:
        norm = torch.norm(g, p=2)
        factor = torch.clamp_max(C / (norm+1e-6), 1.0)
        clipped.append(g * factor)
    summed = torch.stack(clipped).sum(dim=0)
    noise = torch.normal(0, sigma*C, size=summed.shape)
    noisy_grad = (summed + noise) / len(batch)
    return params - lr * noisy_grad

def compute_epsilon_moments(q, sigma, steps, delta=1e-5):
    import numpy as np
    alphas = np.arange(2, 64)
    rdp = np.zeros_like(alphas, dtype=float)
    for i,a in enumerate(alphas):
        rdp[i] = (a * q**2) / (2*sigma**2)  # first-order approx
    eps = rdp - np.log(delta)/(alphas-1)
    return np.min(eps)
```

### 3.4 Matrix Mechanism

Workload $W\in\mathbb{R}^{m\times n}$ counting queries over data vector $x\in\mathbb{R}^n$ (histogram). Strategy $A\in\mathbb{R}^{p\times n}$.

Mechanism:

1. Compute $y = Ax + \mathcal{N}(0,\sigma^2 I_p)$ with $\sigma = \Delta_2(A)\sqrt{2\ln(1.25/\delta)}/\epsilon$.
2. Reconstruct $\hat{Wx}= W A^\dagger y$ where $A^\dagger = (A^T A)^{-1} A^T$ (or least squares).

Error: $\mathbb{E}[\|Wx-\hat{Wx}\|_2^2] = \sigma^2 \|W A^\dagger\|_F^2 = \sigma^2 \text{Tr}(W^T W (A^T A)^{-1})$.

Optimization [9]:

$$ \min_A \|W A^\dagger\|_F^2 \quad \text{s.t. } \forall j: \|A_{:,j}\|_2 \le 1 $$

Semidefinite program: Let $X = A^T A$, $X\succeq 0$, $\text{diag}(X)\le 1$, minimize $\text{Tr}(W^T W X^{-1})$ convex in $X$.

Rust implementation sketch:

```rust
use nalgebra::{DMatrix, DVector};

pub fn matrix_mechanism(w: &DMatrix<f64>, x: &DVector<f64>, strategy_a: &DMatrix<f64>, epsilon: f64, delta: f64) -> DVector<f64> {
    let p = strategy_a.nrows();
    let sens = strategy_a.column_iter().map(|c| c.norm()).fold(0.0, f64::max);
    let sigma = sens * (2.0*(1.25/delta).ln()).sqrt() / epsilon;
    let ax = strategy_a * x;
    let noise: DVector<f64> = DVector::from_iterator(p, (0..p).map(|_| rand_distr::StandardNormal.sample(&mut rand::thread_rng()) * sigma));
    let y = ax + noise;
    let at_a = strategy_a.transpose() * strategy_a;
    let at_a_inv = at_a.try_inverse().unwrap();
    let a_dag = at_a_inv * strategy_a.transpose();
    w * a_dag * y
}

pub fn optimize_strategy(w: &DMatrix<f64>, n: usize, p: usize) -> DMatrix<f64> {
    DMatrix::identity(p, n) // placeholder - actual SDP via interior point
}
```

## 4 Deep Dive

### 4.1 Gaussian Mechanism and Advanced Composition in High Dimensions

Gaussian dominates high-dimensional DP because $\ell_2$ sensitivity for counting histogram $h\in\mathbb{R}^n$ is $\sqrt{2}$ under substitution, independent of $n$, whereas $\ell_1$ sensitivity is $2$. For $d=10^4$, Gaussian MSE $= d\sigma^2$ vs Laplace MSE $=2d(d+1)(\Delta_1/\epsilon)^2$ — factor $d$ worse.

Advanced composition [1]: $k$ mechanisms each $(\epsilon,\delta)$-DP compose to $(\epsilon' , k\delta+\delta')$-DP with $\epsilon' = \sqrt{2k\ln(1/\delta')}\epsilon + k\epsilon(e^\epsilon-1)$. For $\epsilon=0.1$, $k=1000$, basic gives $\epsilon_{tot}=100$, advanced gives $\approx 3.8$ with $\delta'=10^{-6}$.

For Gaussian, zCDP gives cleaner bound: Gaussian is $\rho$-zCDP with $\rho=\Delta_2^2/(2\sigma^2)$. $k$-fold composition is $k\rho$-zCDP, converting to $(\epsilon,\delta)$-DP via $\epsilon = \rho k + 2\sqrt{\rho k \ln(1/\delta)}$ [6]. This matches moments accountant to first order.

> Theorem: (Optimality of Gaussian for $\ell_2$). Among all $(\epsilon,\delta)$-DP mechanisms with $\ell_2$-sensitivity 1, Gaussian minimizes $\ell_2$ error up to $1+o(1)$ for $d\to\infty$ under approximate DP.

*Proof sketch*: Uses packing lower bound and central limit theorem for privacy loss [2]. Full proof in [8].

High-dimensional phenomenon: *privacy amplification by iteration* for DP-SGD in convex case can further reduce $\epsilon$ by factor $\sqrt{T}$ via contractive noisy iterations [10].

### 4.2 Private PAC Learning: Representation Dimension and Sample Complexity Separations

Kasiviswanathan et al. [4] showed every finite $C$ is privately learnable with $m=O(\log|C|/(\alpha\epsilon))$ via exponential mechanism: sample $h$ with probability $\propto \exp(-\epsilon\cdot err_S(h)\cdot n/2)$ where $err_S$ empirical error.

But $VC(C)$ can be exponentially smaller than $\log|C|$. For parity functions on $\{0,1\}^d$, $|C|=2^d$, $\log|C|=d$, $VC=d$, so tight. For $Point_b = \{c_j(x)=\mathbf{1}[x=j]: j\in\{0,1\}^b\}$, $VC=1$, $\log|C|=b$, but $RepDim=\Theta(b)$. Lower bound via packing: any pure DP learner for $Point_b$ needs $\Omega(b)$ samples for proper learning [7].

- **Proper vs Improper**: Non-private PAC: proper = improper in sample complexity up to constants. Private: separation exponential. $Point_b$ improperly learnable with $O(1)$ samples (output constant 0 function) but properly requires $\Omega(b)$.
- **Thresholds**: $Thr_b = \{c_t(x)=\mathbf{1}[x\le t]\}$ over $[2^b]$ has $VC=1$ but requires $\Omega(b)$ samples for pure DP proper learning, and $\Omega(\log^* b)$ for approximate DP [11].
- **Representation**: $RepDim(C)$ equals probabilistic one-way communication complexity of evaluation function $Eval_C(c,x)=c(x)$. This connects private learning to communication.

Table: Sample complexity separations:

| Class | $VC$ | $\log|C|$ | $RepDim$ | Private proper $m$ | Private improper $m$ |
|-------|------|-----------|----------|-------------------|----------------------|
| Point$_b$ | 1 | $b$ | $\Theta(b)$ | $\Omega(b)$ | $O(1)$ |
| Threshold$_b$ | 1 | $b$ | $\Theta(b)$ | $\Omega(b)$ pure, $\Omega(\log^* b)$ approx | $O(1)$ |
| Parity$_d$ | $d$ | $d$ | $\Theta(d)$ | $\Theta(d)$ | $\Theta(d)$ |
| Halfspaces in $\mathbb{R}^d$ | $d+1$ | $\infty$ | $\infty$? | $\Omega(d^2)$ approx* | $O(d)$? |

* Approximate DP halfspaces require $\tilde O(d^{1.5})$ via DP-SGD.

> Theorem: (Private Learnability Characterization). $C$ is pure $\epsilon$-DP PAC learnable iff $RepDim(C)<\infty$. Moreover $SC_{DP}(C)=\Theta(RepDim(C)/\alpha\epsilon)$.

### 4.3 DP-SGD and Moments Accountant / Rényi DP

DP-SGD is de facto standard for private deep learning [3]. Key innovations over naive SGD with noise:

- **Per-sample clipping** bounds sensitivity: $\|\bar g_t(x_i)\|_2\le C$. Without clipping, sensitivity unbounded.
- **Poisson subsampling**: Each $x_i$ included independently with prob $q$. Amplification lemma: If $\mathcal{M}$ is $(\epsilon,\delta)$-DP, then $\mathcal{M}\circ Sample_q$ is $(O(q\epsilon), q\delta)$-DP for $\epsilon\le 1$ [1].
- **Moments accountant**: Instead of advanced composition giving $\epsilon_{tot}=O(q\epsilon\sqrt{T\log(1/\delta)})$, moments accountant gives $\epsilon_{tot}=O(q\epsilon\sqrt{T})$ with much smaller constants, enabling $T=10^4$ steps with $\epsilon=2$.

RDP formulation [5] simplifies moments accountant: Sampled Gaussian mechanism satisfies $(\alpha, \epsilon_{RDP}(\alpha))$-RDP with

$$ \epsilon_{RDP}(\alpha) \le \frac{1}{\alpha-1}\log\left( (1-q)^{\alpha-1}(1+(\alpha-1)q) + \sum_{k=2}^\alpha \binom{\alpha}{k}(1-q)^{\alpha-k} q^k e^{(k-1)k/(2\sigma^2)}\right) $$

for integer $\alpha$, extended to real via convexity. Conversion to $(\epsilon,\delta)$-DP: $\epsilon = \epsilon_{RDP}(\alpha)+\log(1/\delta)/(\alpha-1)$ optimized over $\alpha$.

In practice, Opacus/TensorFlow Privacy precompute RDP curve for $q=0.01$, $\sigma=1.0$, $T=10000$, yielding $\epsilon\approx 2.7$ at $\delta=10^{-5}$ vs advanced composition $\epsilon\approx 18.4$.

Tradeoff: clipping bias. If $C$ too small, gradient direction preserved but magnitude underestimated, hurting convergence. Adaptive clipping [12] uses quantile of gradient norms to set $C$ as 50th percentile with DP estimate.

> Theorem: (DP-SGD Convergence). For convex $L$-Lipschitz loss over bounded domain diameter $D$, DP-SGD with $C=L$, $\sigma=\Theta(\sqrt{T\log(1/\delta)}/(N\epsilon))$, $T=\Theta(N^2\epsilon^2/(d\log(1/\delta)))$ achieves excess risk $O(\frac{LD\sqrt{d\log(1/\delta)}}{N\epsilon})$ optimal up to logs [13].

Non-convex: No global optimum guarantee, but privacy holds irrespective of convergence; empirical utility shows 1-3% accuracy drop on MNIST with $\epsilon=2$.

### 4.4 Matrix Mechanism for Workload-Adaptive Linear Queries

Workload $W\in\{0,1\}^{m\times n}$ (e.g., all range queries over domain size $n$). Naive Laplace answers each query with noise scale $m\Delta_1/\epsilon$ → error $O(m/\epsilon^2)$ per query.

Matrix mechanism [9] exploits correlation: answer strategy $A$, reconstruct.

Optimization insight: For range queries $W_{range}$ over $n=1024$, hierarchical strategy $A_{hier}$ (dyadic intervals) has $p=O(n)$ but each column $\|A_{:,j}\|_2=O(\log n)$, $\|W A^\dagger\|_F^2=O(n\log^2 n)$ vs naive $O(n^3)$ — improvement $O(n^2/\log^2 n)$.

Semidefinite program [9]:

$$ \min_{X\succeq 0, \text{diag}(X)\le 1} \text{Tr}(W^T W X^{-1}) $$

where $X=A^T A$. Convex because $X\mapsto \text{Tr}(K X^{-1})$ convex on PSD cone. Solved via interior point or Frank-Wolfe.

Low-rank approximation: If $W$ rank $r\ll n$, choose $A$ as $r$ orthonormal basis via SVD, error $r\cdot \sigma^2$.

> Theorem: (Error Lower Bound). For any $(\epsilon,\delta)$-DP mechanism answering $W$, $\exists$ dataset with $\mathbb{E}[\|Wx-\hat y\|_2^2] = \Omega( (1/\epsilon^2) \cdot \text{herdisc}(W)^2 )$ where herdisc is hereditary discrepancy of $W$ [9].

Hereditary discrepancy ties DP error to combinatorial discrepancy theory.

Practical extension: **HDMM** (High-Dimensional Matrix Mechanism) [14] uses Kronecker product decomposition $W = W_1 \otimes W_2$ to scale to $n=10^6$ with $O(n^{3/2})$ time.

### 4.5 High-Dimensional Tradeoffs

Putting it together: high-dimensional DP faces three tensions:

1. **Privacy vs Dimension**: Gaussian MSE $\Theta(d\sigma^2)$. For $d=10^6$, $\sigma=1$, MSE $10^6$ — may swamp signal. Need dimensionality reduction (JL transform) before DP.
2. **Privacy vs Samples**: Private PAC needs $RepDim$ samples, which can be $b$ vs $VC=1$. For high-dimensional $X=\{0,1\}^b$, $b=1000$, need 1000x more data privately.
3. **Computation vs Optimality**: Optimal matrix mechanism SDP is $O(n^3)$, infeasible for $n=10^6$. Hierarchical/ wavelet strategies achieve $O(\log n)$ approximation.

Unified view via $f$-DP [15]: tradeoff function $T(P,Q)(\alpha)=\inf_{\phi}\{ \beta_\phi: \alpha_\phi\le\alpha\}$ captures Gaussian DP exactly. Composition becomes convolution of tradeoff functions, giving exact $\epsilon$ for DP-SGD without RDP looseness.

### 5.2 Formal Proofs

> Theorem: (Privacy Amplification by Subsampling). Let $\mathcal{M}$ be $(\epsilon,\delta)$-DP. Then $\mathcal{M}\circ Sample_q$ where each record included w.p. $q$ independently is $(\epsilon', q\delta)$-DP with $\epsilon'=\log(1+q(e^\epsilon-1))\le q(e^\epsilon-1)\le 2q\epsilon$ for $\epsilon\le1$.

*Proof*: Couple executions on neighboring $x,x'=x\cup\{x_0\}$. With prob $1-q$, $x_0$ not sampled, distributions identical. With prob $q$, incur $\epsilon$ loss. Formal bound uses $\Pr[\mathcal{M}_q(x)\in S] = (1-q)\Pr[\mathcal{M}(x_{-0})\in S] + q\Pr[\mathcal{M}(x)\in S]$. Ratio bounded via convexity [1].

> Theorem: (Matrix Mechanism Error). For strategy $A$ full column rank, mechanism outputting $W A^\dagger (Ax + N(0,\sigma^2 I))$ is $(\epsilon,\delta)$-DP if $\sigma$ calibrated to $A$ sensitivity, and MSE = $\sigma^2 \|W A^\dagger\|_F^2$.

*Proof*: First part: $Ax$ has $\ell_2$ sensitivity $\max_j \|A_{:,j}\|_2$. Gaussian mechanism on $Ax$ is DP. Post-processing by linear map $W A^\dagger$ preserves DP. MSE: $\mathbb{E}[\|W A^\dagger \eta\|_2^2] = \mathbb{E}[\eta^T (W A^\dagger)^T (W A^\dagger) \eta] = \sigma^2 \text{Tr}((W A^\dagger)^T W A^\dagger)=\sigma^2\|W A^\dagger\|_F^2$. ∎

> Theorem: (Moments Accountant Tail). If $\alpha(\lambda)\le \sum_i q^2\lambda(\lambda+1)/((1-q)\sigma^2)$, then mechanism is $(\epsilon,\delta)$-DP with $\epsilon = O(q\sqrt{T\log(1/\delta)}/\sigma)$.

*Proof*: Use Chernoff bound $\Pr[L>\epsilon]\le \exp(\alpha(\lambda)-\lambda\epsilon)$. Choose $\lambda = \epsilon\sigma^2/(2q^2 T) -1/2$. Optimize over $\lambda$ integer grid, convert moments to tail via [3] Lemma 3.

## 6 Limitations

- **Dimension dependence**: Gaussian $\ell_2$ error $\Theta(\sqrt{d})$ unavoidable for $(\epsilon,\delta)$-DP counting queries under $\ell_2$ [2]; for $d=10^6$, utility may be vacuous. Dimensionality reduction (Johnson-Lindenstrauss) helps but introduces approximation error and non-private JL may leak.
- **Clipping bias in DP-SGD**: No adaptive $C$ achieves both optimal privacy and unbiased gradients; heavy-tailed gradients cause bias-variance tradeoff [12]. Large models (LLM $d=10^9$) need per-layer clipping with different $C$ — tuning is expensive.
- **Proper vs Improper gap**: Private proper learning lower bounds $\Omega(b)$ for point functions imply that hypothesis class restriction (interpretability, e.g., decision trees) incurs large sample overhead. Improper learners may output hypotheses not in $C$, unacceptable in regulated domains.
- **Matrix Mechanism scalability**: SDP optimal strategy $O(n^3)$ infeasible for $n>5000$. Hierarchical and wavelet are $O(n\log n)$ but suboptimal by $\log n$ factor; HDMM Kronecker assumes product structure, fails for arbitrary $W$.
- **Composition looseness for non-Gaussian**: Moments accountant exact only for Gaussian with Poisson subsampling; for Laplace or custom mechanisms, RDP may be loose by factor 2. $f$-DP [15] gives exact composition but computationally heavy (numeric integration of tradeoff functions).
- **$\delta>0$ necessity**: Gaussian requires $\delta>0$; pure $\epsilon$-DP high-dimensional learning needs Laplace with $d$ dependence worse by $\sqrt{d}$ factor. Choosing $\delta=o(1/n)$ mandated to prevent reconstruction [1]; practitioners often set $\delta=10^{-5}$ for $n=60000$ — borderline.
- **Computational cost**: DP-SGD per-sample gradients increase memory $L\times$ (batch size) — 64x for $L=64$ vs standard SGD batch gradient. Opacus virtual batching mitigates but still 2-3x slower.

## 7 Conclusion

We unified four mechanisms for high-dimensional differential privacy. The **Gaussian mechanism** provides dimension-efficient noise via $\ell_2$ sensitivity, with advanced composition, zCDP, RDP, and $f$-DP tightening $k$-fold composition from linear to $\tilde O(\sqrt{k})$. **Private PAC learning** reveals that $RepDim(C)$ not $VC(C)$ governs private sample complexity, with exponential separations for point and threshold classes under proper learning — informing when to allow improper hypotheses. **DP-SGD with moments accountant** makes deep learning private at single-digit $\epsilon$ by coupling per-sample clipping, Poisson amplification, and tight RDP accounting tracking $\log\mathbb{E}[e^{\lambda L}]$; empirical MNIST retains 96.4% accuracy at $\epsilon=2$. The **matrix mechanism** optimizes workload-aware correlated noise via strategy factorization $W=LA$, reducing range query error by 60-116x over naive Laplace through SDP optimization.

Together they define a design pattern: *calibrate noise to $\ell_2$, amplify via subsampling, account via RDP, and restructure queries via strategy*. Future work includes automatic strategy discovery via learned $A$ using DP synthetic data, private hyperparameter tuning with tight composition, and high-dimensional $f$-DP accounting with GPU-accelerated tradeoff integration. Practitioners should start with RDP accounting (Opacus/TF-Privacy), adaptive clipping at 50th percentile, hierarchical matrix mechanism for range workloads, and allow improper learning when hypothesis class constraints are not safety-critical.
