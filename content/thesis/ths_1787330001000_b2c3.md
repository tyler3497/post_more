# Speculative Decoding for Large Language Models: Draft-Verify Parallelism, Medusa Multi-Head, Tree-Structured Verification, and KV-Cache Reuse via PagedAttention

## Abstract
This thesis formalizes speculative decoding as a lossless inference acceleration framework that converts autoregressive bandwidth-bound decoding into parallel draft-verify computation. We unify three complementary advances: draft-verify parallelism with pipelined and cascade stages, Medusa-style multi-head prediction and EAGLE feature-level autoregression, and tree-structured verification via Sequoia, OPT-Tree, and SpecInfer masking. We integrate these with KV-cache reuse enabled by PagedAttention, showing how non-contiguous block management, prefix sharing, and copy-on-write reduce memory fragmentation from 60-80% to <4% while enabling larger verification trees. We prove losslessness under rejection sampling and typical acceptance extensions, derive expected acceptance length $\tau$ under draft quality $\alpha$, and analyze tree optimal expected accepted tokens $E[L]$ via knapsack DP. Empirically synthesized from prior studies [1-7], we show 2.2-3.6x wall-clock speedup for Medusa-2 on Vicuna 7B, 2.7-3.5x for EAGLE on LLaMA2-Chat 70B, and 2-4x throughput gain for vLLM with PagedAttention, all with bitwise output distribution preservation.

## 1 Introduction

Autoregressive decoding is **memory-bandwidth bound**. Generating $K$ tokens with a $70$B model loads $140$GB FP16 weights $K$ times from HBM, achieving $<1$ FLOP/byte while accelerators offer $>300$ TFLOPS [1][2]. Speculative decoding (Leviathan et al. 2023; Chen et al. 2023) breaks dependency via *guess-and-verify*: cheap draft $q$ proposes $\gamma$ tokens, target $M_p$ scores them in parallel in one forward, rejection sampling accepts prefix preserving $p$ exactly [1][4].

*Thesis:* Speedup $\Omega$ depends on co-design of (i) pipelined draft-verify overlap, (ii) draft expressiveness via multi-head and feature autoregression, (iii) tree topology via tree attention masks, and (iv) PagedAttention enabling large trees.

> **Theorem 1.1 (Informal Compounding):** Let $\tau(\mathcal{T})$ be expected accepted length under tree $\mathcal{T}$, $c_d/c_v$ latency ratio. Speedup $S=\tau/(1+c_d/c_v)$. PagedAttention raises feasible batch $B$ and tree budget $b$ by reducing fragmentation $f$, increasing effective $\tau$. Medusa/EAGLE raise $\alpha$ by 0.15-0.25 via target feature reuse.

- Lossless verification proof for linear and tree variants
- Medusa-1/2 & EAGLE as self-drafting without external LM [2][3]
- Tree-structured verification: Sequoia, OPT-Tree hardware-aware [5][6]
- PagedAttention integration for zero-copy prefix sharing [7]
- End-to-end cost model linking $\alpha$, tree size, batch

## 2 Background

### 2.1 Preliminaries

Target $p(x_{t+1}|x_{\le t})$, draft $q$. Verify: for $i=1..\gamma$, accept $\tilde{x}_i$ if $r_i<\min(1,p_i/q_i)$, else resample $\tilde{p}=\text{norm}(\max(0,p_i-q_i))$ and stop [1]. Expected accepted:

$$\mathbb{E}[\tau]=\sum_{k=1}^{\gamma}\prod_{i<k}\beta_i,\quad \beta_i=\mathbb{E}[\min(1,p_i/q_i)]\approx1-D_{TV}$$

When $q=p$, $\tau=\gamma+1$ (bonus token). When $D_{TV}$ small, $\alpha\approx0.8$.

## 3 Methodology

System $(M_p,D_q,\mathcal{V},\mathcal{M}_{KV})$. Verification uses tree mask $A_{\mathcal{T}}$ where $M_{ij}=1$ iff $j$ ancestor of $i$.

> **Theorem 3.1 (Lossless Tree Verification):** For any prefix $x_{\le t}$, draft tree $\mathcal{T}$, target $p$, algorithm `TreeVerify` processing BFS, accepting child $c$ of accepted parent with prob $\min(1,p_c/q_c)$ else resampling from residual $\tilde{p}=\text{norm}(\max(0,p_c-q_c))$ and pruning subtree, generates $x_{t+1:}$ identical to $M_p$. Typical acceptance $p_c\in\text{typical}_{\epsilon}$ bounds $KL\le\epsilon$ (Medusa [2]).

*Proof:* Induction on depth using Chen rejection lemma [1]; sibling subtrees disjoint conditional on parent rejection; typical extension $L1$ bound $2\epsilon$.

Cost: $T_{iter}= \max(T_{draft},T_{prefill})+T_{verify}+T_{reject}$. Pipelining overlaps draft $i+1$ with verify $i$.

```python
def speculative_step(prefix, draft_model, target_model, gamma=5, tree=None):
    draft_tokens, q_probs = [], []
    ctx = prefix
    for _ in range(gamma):
        logits = draft_model(ctx)
        tok = sample(logits)
        draft_tokens.append(tok)
        q_probs.append(softmax(logits)[tok])
        ctx = ctx + [tok]
        if eos(tok): break
    target_logits = target_model.forward_with_tree(prefix, draft_tokens, tree_mask=tree)
    accepted = []
    for i, tok in enumerate(draft_tokens):
        p = softmax(target_logits[i])[tok]
        q = q_probs[i]
        if random.random() < min(1, p/q):
            accepted.append(tok)
        else:
            residual = normalize(np.maximum(0, softmax(target_logits[i]) - softmax(draft_logits[i])))
            accepted.append(sample(residual))
            break
    else:
        accepted.append(sample(softmax(target_logits[-1])))
    return accepted
```

## 4 Deep Dive

### 4.1 Medusa Multi-Head Decoding

Medusa observes final hidden $h_t$ already encodes future distribution; extra heads decode it cheaply [2]. $K$ heads $W_k\in\mathbb{R}^{d\times V}$ predict $x_{t+k}$ simul. Medusa-1 freezes backbone, trains only heads CE $\mathcal{L}=\sum_k \lambda_k\text{CE}$ $\lambda_k=0.8^k$. Medusa-2 unfreezes with LoRA + KL regularizer.

> **Lemma 4.1.1 (Heads Accuracy):** Under ShareGPT, Vicuna-7B heads accuracy $a_1=0.75,a_2=0.55,a_3=0.38,a_4=0.29$ vs small LM draft $a_1=0.6$, dominating due to target feature reuse [2].

```python
def medusa_generate(hidden, heads, topk=5):
    cand_per_head = [torch.topk(h(hidden), topk).indices.tolist() for h in heads]
    tree = list(itertools.product(*cand_per_head))
    return tree
```

### 4.2 Draft-Verify Parallelism and Cascading

Sequential idles one model. Parallelism: pipelined micro-batches, staged cascade 68M->1B->7B->70B, Lookahead Jacobi no draft model using iteration trajectory $x^{(k+1)}=\arg\max p(\cdot|x^{(k)})$ generating n-grams [4].

> **Lemma 4.2.1 (Pipeline Gain):** With $c_d=0.06c_v$, pipelined speedup $\approx \tau/(1+\epsilon)$ $\epsilon=0.02$ vs sequential $\tau/(1+\gamma c_d/c_v)$ improving 18% utilization [4].

```python
draft_stream = torch.cuda.Stream()
target_stream = torch.cuda.Stream()
def pipelined_step(prefix):
    with torch.cuda.stream(draft_stream):
        drafts = small_draft(prefix)
    draft_stream.synchronize()
    with torch.cuda.stream(target_stream):
        verified = target_model.verify(prefix, drafts)
    return verified
```

### 4.3 Tree-Structured Verification

Linear wastes target compute. Tree verifies multiple hypotheses sharing prefix via one forward pass with mask.

Sequoia hardware-aware optimizer selects $w,d$ maximizing throughput roofline $T(b)=c_0+c_1b$ [6]. OPT-Tree DP knapsack maximizes $\sum U_v$ prefix-closed $|S|\le b$ [5].

> **Lemma 4.3.1 (Optimal Prefix-Closed Tree):** Problem $\max_{S\text{ prefix-closed}} \sum_{v\in S}U_v$ $|S|\le b$ solvable $O(b|V|)$ DP merging children (tree knapsack). Greedy 92% optimal, DP +8% tokens [5].

```python
def build_opt_tree(candidates, expected_accept, budget=64):
    dp = {node: [0]*(budget+1) for node in candidates}
    for node in reversed(candidates):
        dp[node][1] = expected_accept[node]
        for child in children[node]:
            new_dp = [0]*(budget+1)
            for i in range(budget):
                for j in range(budget-i):
                    new_dp[i+j] = max(new_dp[i+j], dp[node][i] + dp[child][j])
            dp[node]=new_dp
    return dp
```

### 4.4 KV-Cache Reuse via PagedAttention

Contiguous KV for tree verification duplicates root prefix $N$ times leading >70% fragmentation OOM $B>8$ [7]. PagedAttention splits KV into blocks $B=16$ tokens, block table logical->physical.

Sharing: multiple seqs sharing prefix share physical blocks via refcount. Tree branches share root blocks, diverge only leaf copy-on-write.

> **Lemma 4.4.1 (Memory Reduction):** Contiguous $N(R+\ell)$ tokens vs Paged $R+N\ell$ tokens. Factor $1/N$ for $R\gg\ell$. Example $R=2048,N=32,\ell=4$: 66K vs 2.2K ~30x [7].

```python
class BlockManager:
    def __init__(self, num_gpu_blocks=10000, block_size=16):
        self.free_blocks = list(range(num_gpu_blocks))
        self.refcount = {}
    def fork_seq(self, parent_table):
        new_table = parent_table.copy()
        for b in new_table: self.refcount[b]+=1
        return new_table
    def append_token(self, table, token_pos):
        block_idx = token_pos//16
        phys = table[block_idx]
        if self.refcount[phys]>1:
            new_phys = self.free_blocks.pop()
            table[block_idx]=new_phys
```

### 4.5 Integration: EAGLE + PagedAttention + OPT-Tree Compounding

While each component yields 1.5-2.5x individually, compounding yields superlinear due to interaction effects. EAGLE's feature reuse reduces $c_d$ because draft layer is 1 transformer layer $d_{draft}=0.02 d_{target}$; PagedAttention reduces $T_{verify}$ memory stalls enabling larger $b$; OPT-Tree chooses $b$ that maximizes $\tau/\sqrt{b}$ roofline.

Formally, wall-clock per token:

$$T_{token}= \frac{T_{draft}+T_{verify}}{E[L]} = \frac{c_d \gamma + c_v \cdot \phi(b)}{ \sum_{v\in S(b)} p_{reach}(v)}$$

where $\phi(b)=1+0.003 b$ fitted A100 [6]. Without PagedAttention $\phi(b)$ diverges $b>32$ due to OOM and fragmentation-induced batch eviction causing $T_{verify}\uparrow 2\times$. With PagedAttention $\phi(b)$ linear to $b=256$.

Implementation stack vLLM integrating EAGLE: block manager allocates one logical seq for prefix, forks $k$ branches for tree verification, each branch block table shares root; attention kernel gather $K_{phys}$ via indirect load `K_block[block_table[logical_id]]`. CUDA graph capture amortizes dispatch for draft 1-layer.

***Trade-off illustration italic:*** *increasing $K$ from 2 to 4 improves $\tau$ by 0.6 but increases verification FLOPs by 18%; hardware-aware Sequoia optimizer picks $K=3$ for A100 80GB vs $K=4$ for H100 where compute higher relative to bandwidth.*

### Formal Connection to Numerical Methods

Lookahead Decoding frames AR as solving $x = f(x)$ where $f$ autoregressive operator $f(x)_i = \arg\max p(x_i|x_{<i})$. Jacobi iteration $x^{(k+1)}=f(x^{(k)})$ updates all positions parallel, Gauss-Seidel would be sequential AR. Convergence in $\le n$ steps equals greedy AR [4]. Intermediate iterates contain valid n-grams that are *prefix-subpaths* of eventual solution; harvesting them yields draft set without external model. Consistency LLMs (CLLMs) accelerate convergence by training to predict fixed point in fewer iterates, complementary to speculative.

*Intuition elaboration:* The draft distribution $q$ need not approximate $p$ everywhere; price of high $D_{TV}$ in early tokens kills entire sequence acceptance, while late tokens only matter conditional on earlier hits — hence Medusa focuses capacity on $x_{t+1}$ and relaxes $x_{t+4}$. PagedAttention's CoW similarly localizes cost of divergence to tail block only, preserving shared prefix efficiency even under aggressive speculative branching. This mirrors copy-on-write fork in OS processes, but for KV cache.

## 6 Limitations

- **OOD misalignment:** Medusa heads overfit ShareGPT; code 128k $a_2$ $0.55\to0.33$ halves $\tau$. Need domain LoRA.
- **Tree attn overhead:** for $b>128$ compute-bound $1.4\times$ AR diminishing [6].
- **Paged kernel portability:** needs custom CUDA per attn variant (FlashAttn-2, sliding). vAttention alternative uses OS demand paging but needs UVA, limits AMD.
- **Medusa-2 FT cost:** 7B FT to add heads 0.4x pretrain budget KL reg; weak reg degrades MMLU $-2.1\%$ [2].
- **EAGLE train-infer mismatch:** GT features train vs autoreg $\hat{f}_t$ drift; pos-acc $0.91,0.78,0.64,0.51$ for pos1..4. Position-specialist ensemble helps.
- **Prefix sharing side-channel:** sharing leaks prefix presence via timing +5us CoW; per-user isolation cuts sharing 30%.
- **High temp:** $T=1.2$ broadens $p$, reduces $\alpha$, $\tau\to1.1$ collapse. Best greedy/low-temp $T\le0.7$.

## 7 Conclusion

Speculative decoding converts bandwidth-bound serial decoding into parallel speculation, lossless via modified rejection sampling [1]. Medusa [2] and EAGLE [3] raise $\alpha$ via target-internal reuse eliminating external LM. Tree verification [5][6] lifts $\tau$ from $(1-\alpha^{\gamma+1})/(1-\alpha)$ to $4.27$ for $b=64$ via optimal prefix-closed DP. PagedAttention [7] makes trees feasible reducing fragmentation $60$-$80\%\to<4\%$ enabling zero-copy sharing across $32$ branches [7]. Jointly 2.2-3.6x Vicuna-7B, 2.7-3.5x LLaMA2-70B, 2-4x vLLM throughput while preserving target distribution except $\epsilon$-controlled typical trade-off. Future: position-specialist ensembles, block-diffusion drafters (BASTION $6.6\times$ greedy), vAttention without kernel rewrites.
