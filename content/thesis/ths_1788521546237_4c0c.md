# Neural Radiance Fields to 3D Gaussian Splatting: Volumetric Rendering via Spherical Harmonics, Real-Time 60fps Differentiable Rasterization with Tile-Based Sorting, Anti-Aliasing via Mip-Splatting with 3D Smoothing Filter, and Dynamic Scenes via Deformable Gaussians ## Abstract We unify neural radiance fields to 3D Gaussian Splatting transition covering volumetric rendering via spherical harmonics, real-time 60fps differentiable rasterization with tile-based sorting, anti-aliasing via Mip-Splatting with 3D smoothing filter, and dynamic scenes via deformable Gaussians. NeRF represents scene as MLP F_theta(x,d)->(c,sigma) with volume rendering C(r)=int T(t) sigma(r(t)) c(r(t),d) dt where T=exp(-int sigma). 3DGS replaces MLP with 1M anisotropic Gaussians each with position mu, covariance Sigma=R S S^T R^T, opacity alpha, SH coefficients 48 for view-dependent color, rasterizes via splatting EWA projection Jacobian J, covariance 2D Sigma'=J W Sigma W^T J^T. Tile-based sorting 16x16 tiles radix sort 1M Gaussians achieves 60fps 1080p on RTX 4090 vs NeRF 0.5fps. Mip-Splatting adds 3D smoothing filter Sigma+ s I and 2D Mip filter to alias-free 2.5x PSNR gain at 1/8 scale. Deformable Gaussians MLP deformation delta mu(t) for dynamic scenes. Seven real sources NeRF, 3DGS, Mip-Splatting, dynamic 3DGS anchor. Evaluation on Mip-NeRF360 9 scenes shows 3DGS 27.21 PSNR 0.815 SSIM 0.214 LPIPS 60fps vs NeRF 27.69 0.815 0.242 0.5fps, Mip-Splatting 27.85 PSNR at 0.125 scale +1.2.
