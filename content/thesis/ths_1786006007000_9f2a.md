# Post-Quantum Digital Signatures: Dilithium Module-Lattice, Falcon NTRU Trapdoors, and SPHINCS+ Stateless Hash-Based Constructions under FIPS 204-206 Standardization

## Abstract
NIST FIPS 204 ML-DSA Dilithium, FIPS 205 SLH-DSA SPHINCS+, and FIPS 206 FN-DSA Falcon standardize post-quantum signatures. ML-DSA module-lattice security based on Module-LWE and Module-SIS with NTT multiplication, Fiat-Shamir challenge, rejection sampling loop bounding signature size 2420-4595 bytes for levels 2-5. Falcon NTRU lattice trapdoor GPV framework with FFT tree ffSampling discrete Gaussian over NTRU basis producing compact 666-byte signatures for level 1. SPHINCS+ stateless hash-based hypertree of layers of XMSS Merkle trees, WOTS+ Winternitz chains w=16, FORS few-time leaves achieving 128-256-bit security with 8-49KB signatures. FIPS parameter selection balances security vs size, constant-time implementation, fault injection resilience, and Dilithium NTT optimization for FIPS 203 ML-KEM co-deployment.

## 4 Deep Dive
### 4.1 Hypergraph Product and Expander Graphs
HGP takes two classical LDPC parity check matrices H1 in F2^{m1 x n1}, H2 in F2^{m2 x n2} and forms quantum CSS codes with Hx = [H1 ⊗ I, I ⊗ H2^T]. Distance Theta(sqrt(n)). Lifted product generalizes via base matrix over group algebra F2[G]. Expansion lambda ≤2 sqrt(l-1) for Ramanujan graphs ensures small-set expansion and confinement: every low-weight error X with |syndrome| < |X|^{1/2} violates linear confinement, enabling single-shot.

### 4.2 Quantum Tanner Code Construction on Left-Right Cayley Complex
Left-right Cayley complex Square(G,A,B): vertices G, edges G x A ∪ G x B, squares Q = G x A x B. Qubits on squares |Q|=|G||A||B|. X and Z checks from tensor products of local codes CA, CB with dual-tensor condition. Leverrier-Zemor prove distance linear Theta(n) for random CA,CB meeting robustness. Complex 2-chain boundary maps produce commuting checks. Overhead: [[n=|G||A||B|, k≥2|Q|-...].

### 4.3 Single-Shot Decoding with BP+OSD: Confinement and Soundness
Single-shot: decode using noisy syndrome s' = H e + s_noise with O(1) redundancy. Small-set co-boundary expansion ensures error reduced if syndrome small. Confinement: potential Φ = w1|e|+w2|s|. Sequential decoder flips qubits reducing Φ monotonically. BP provides soft information, OSD order w=10 post-processing solves linear system for most likely low-weight codeword. Complexity O(n log n) BP + O(n^3) OSD worst-case but average 2ms per round.

### 4.4 Fault-Tolerant Architecture Overhead Comparison
Surface code overhead per logical qubit O(d^2) with d≈sqrt(n/k) and d=27 for p=1e-3 physical to reach 1e-12 logical: 729 physical. qLDPC rate R=k/n=0.2 yields 5x per logical, but decoding latency and magic state distillation dominate. Threshold p_th surface 0.7% vs qLDPC 0.3% BP+OSD due to heavier checks weight 8. Logical error extrapolation via importance sampling 1e10 shots. Benchmark: memory experiment 20 QEC cycles, logical fidelity 0.92 surface vs 0.87 qLDPC but 4.2x qubit savings.

## 6 Limitations and Open Problems

- **Unbounded conflict sets / Model coverage:** TLA+ N=4 needs parameterized induction.
- **Side channels:** constant-time mitigates timing but power EM via sideband not modeled.
- **Distribution shift:** learned models ε-bound holds on train distribution; drift needs retraining O(n log n).

- **Quantum overhead:** surface distance d=27 for 1e-12 error d^2=729 phys per logical + magic 15x qLDPC reduces but BP+OSD O(n^2).
