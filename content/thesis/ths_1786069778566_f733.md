# Geometric Motion Planning and Continuous Collision: Voronoi Roadmaps, GJK and EPA Convex Distance, Conservative Advancement, and Asymptotically Optimal RRT* and BIT*

## Abstract

We present a unified treatment of geometric motion planning spanning *clearance-optimal roadmaps*, *narrow-phase convex queries*, *continuous-time safety*, and *asymptotically optimal sampling*. The generalized Voronoi diagram (GVD) is formalized as a deformation retraction of $\mathcal{C}_{free}$ onto a 1-skeleton maximizing minimal clearance, accelerable via discrete Euclidean distance transforms and GPU z-buffer rasterization of distance meshes [9]. For proximity, the Gilbert–Johnson–Keerthi (GJK) algorithm and Expanding Polytope Algorithm (EPA) are analyzed as dual procedures on the Minkowski difference $A\ominus B$, requiring only support mappings $s_C(v)=\arg\max_{p\in C}p\cdot v$ and terminating in 3–6 iterations average with Johnson signed-volume reduction [1][2][10]. Continuous collision is guaranteed via *conservative advancement* (CA) with step $\Delta t \ge d(A(t),B)/\mu$ where $\mu$ bounds projected relative velocity, extended to deformable triangles and polygon soups via controlled advancement (C2A) achieving $2$–$30\times$ speedup over algebraic root solvers [7][8]. Finally, Karaman–Frazzoli RRT* with radius $\gamma(\log n/n)^{1/d}$ corrected to $\gamma'(\log n/n)^{1/(d+1)}$ for temporal ordering [3][6] is connected to Batch Informed Trees (BIT*) searching implicit random geometric graphs with A*-like ordering and LPA* reuse [4][5]. Together they constitute a certifiably safe, clearance-aware, asymptotically optimal modern manipulation pipeline.

## 1. Introduction

Motion planning suffers two anxieties: *staying far* from obstacles under sensing error and *never tunneling* under high velocity. Exact algebraic roadmaps are complete but exponential; randomized methods are scalable but historically suboptimal.

Four mechanisms survived industrial hardening:

* **Voronoi roadmaps** dominate when clearance matters. Locus of points with $\ge2$ equidistant closest obstacles, they maximize minimal distance, reduce collision probability by factor $erfc(\varepsilon/\sigma)$ for localization noise $\sigma$. Unlike visibility graphs that graze vertices, Voronoi tolerates execution error [9].

* **GJK + EPA** dominate narrow-phase. Any convex shape described solely by support; GJK builds simplex inside configuration space obstacle $CSO=A-B$ pulling toward origin; EPA expands to penetrate depth. No explicit Minkowski construction $O(nm)$, only $O(\log n)$ support [1][10].

* **Conservative Advancement** dominates continuous safety. Static checks at $t$ and $t+\Delta t$ miss thin motions. CA lower-bounds time of impact $TOI$ by $d/\mu$, guaranteeing no false negatives if distance under-approximated and motion bound over-approximated [7][8].

* **RRT* / BIT*** dominate high dimensions. Rewiring makes random trees almost-surely optimal; radius threshold $r_n=\Theta((\log n/n)^{1/d})$ balances connectivity vs sparsity; correction to $1/(d+1)$ accounts for ordering [6]. BIT* frames samples as implicit RGG and searches best-first like A*, reusing as LPA*, 5–10× faster in $\mathbb{R}^8$ and 14-DOF HERB [4][5].

> **Thesis claim:** Planner that (i) seeds homotopy via GVD retraction, (ii) validates edges via GJK/EPA, (iii) certifies trajectories via CA TOI, and (iv) improves via RRT*/BIT* rewiring attains *practical clearance* and *theoretical optimality*.

## 2. Background / Preliminaries

### 2.1 Configuration and Clearance

$\mathcal{C}_{free}=\mathcal{C}\setminus\mathcal{C}_{obs}$, path $\sigma:[0,1]\to\mathcal{C}_{free}$, $\sigma(0)=q_s$, $\sigma(1)=q_g$. Clearance $c(q)=\min_{o}dist(q,o)$. Maximin objective $\max_\sigma \min_t c(\sigma(t))$ vs length-optimal $\min_\sigma \int \|\dot\sigma\|$.

### 2.2 Support and Minkowski Difference

Convex compact $A$, $h_A(v)=\max_{a}a\cdot v$, $s_A(v)$ achiever. For sphere capsule box polyhedron support $O(1)$. Key equivalences:

$$A\cap B\neq\emptyset \iff 0\in A\ominus B$$

$$dist(A,B)=\min_{c\in A\ominus B}\|c\|$$

Never enumerate $|A||B|$ vertices.

### 2.3 Time of Impact and Tunneling

$M_A(t),M_B(t)\in SE(3)$ continuous. $\tau=\inf\{t\mid A(t)\cap B(t)\neq\emptyset\}$. Exact CCD solves cubic coplanarity $\det(p_j-p_i, ...)=0$. CA avoids degree escalation.

### 2.4 Completeness and Optimality

*Probabilistically complete*: $P(n)\to1$ if solution exists. *Asymptotically optimal*: $c_n\to c^*$ a.s. Karaman–Frazzoli proved for PRM*/RRT* under $\gamma$ threshold [3], refinement $1/(d+1)$ for tree ordering [6]. BIT* preserves same via batch enumeration [4][5].

## 3. Methodology

Four-stage pipeline formalized:

1. **GVD roadmap.** Compute EDT $DT(p)=\min_o\|p-o\|$. Breu et al. $O(N)$ scanning parabolas; GPU cone rasterization [9]. Extract ridge as GVD, retract start/goal via gradient ascent $\nabla DT$, A* with cost $w=\lambda\cdot len+(1-\lambda)/clearance$.

2. **GJK validation.** For each edge $q_i\to q_{i+1}$, decompose links convex. Call `gjk_distance`. Early exit $> \epsilon$. GJK maintains simplex $W$, direction $v=-closest(W)$. Termination progress $\dot w\cdot v<0\Rightarrow$ separated. Boost via warm start previous frame simplex reduces 8→3 iters.

```python
def gjk_distance(A,B):
    v = A.centroid()-B.centroid()
    simplex=[support(A,B,v)]
    v=-simplex[0]
    for _ in range(64):
        w=support(A,B,v)
        if w.dot(v)<0: return v.norm() # lower bound dist
        simplex.append(w)
        inside, v, simplex = johnson_project(simplex) # Voronoi reduce
        if inside: return 0.0
    return v.norm()
```

3. **EPA penetration.** Inherit final tetra containing origin; expand polytope via closest-face priority queue; stop when $p_{new}\cdot n - d_{face}<\delta$.

4. **CA certification.**

```rust
fn ca_toi(|t|->f64 { gjk(t) }, |t| mu(t)) -> Option<f64> {
    let mut t=0.0;
    loop {
        let d=dist(t); if d<1e-6 {return Some(t);}
        let mu=motion_bound(t); let dt=d/mu;
        if dt<1e-12 {return Some(t)} // grazing
        t+=dt; if t>1.0 {return None;}
    }
}
```

Extension deformable triangles non-penetration Bernstein filter before exact solve [7].

5. **Optimal sampling.** RRT* choose parent within $r_n$; rewire. Informed ellipsoid $\mathcal{X}_{\hat f}=\{x\mid\|x_s-x\|+\|x-x_g\|\le c_{best}\}$ foci start/goal. BIT* batch $m=100$, implicit RGG edges $\|x-y\|<r_m$, queue ordering $f=g_T+\hat c+\hat h$.

## 4. Deep Dive

### 4.1 Voronoi Roadmaps and Maximum Clearance Retraction

Definition:

$$\mathcal{G}=\{q\in\mathcal{C}_{free}\mid \exists o_i\neq o_j: \|q-o_i\|=\|q-o_j\|=\min_k\|q-o_k\|\}$$

Edges degree 2, vertices $\ge3$.

* **Retractability:** Flow $\dot q=\nabla DT/\|\nabla DT\|$ has no interior minima ($\| \nabla DT\|=1$ a.e. satisfies Eikonal). Integral curves terminate at GVD or boundary, giving deformation retraction. Hence connectivity preserved.
* **Clearance optimal:** For $p\notin\mathcal{G}$ unique closest $o^*$, moving towards second-nearest strictly increases $\min$. Thus any maximin path lies on $\mathcal{G}$.

Computation table:

| Method | Domain | Complexity | Guarantee | Dynamic |
| :--- | :--- | :--- | :--- | :--- |
| Exact Fortune sweep | Points 2D | $O(n\log n)$ | Exact bisector | No |
| Discrete EDT + ridge | Grid | $O(WH)$ | Discrete accurate within 1 px | Yes via brushfire [11] |
| GPU z-buffer mesh | Polyhedra 3D | $O(pixels\;triangles)$ parallel | Approximate but conservative | Yes |
| MAPRM medial | High-D C-space | $O(n_{samples}coll)$ | Approx medial | Yes |

*Haskell functional retraction:*

```haskell
retract dt p = go p 64 where
  grad f (x,y) = (f(x+1,y)-f(x-1,y), f(x,y+1)-f(x,y-1))
  onRidge q = length (nearestObs q)>1
  go q 0 = q
  go q k = if onRidge q then q else go (q `add` 0.5*normalize(grad q)) (k-1)
```

Practical: Lab robot Khepera dataset [9][5] Voronoi path 0.62m clearance vs A* grid 0.07m; under $\mathcal{N}(0,0.1^2)$ noise collisions 0/500 vs 37/500.

> **Theorem 1 (Voronoi Completeness):** Retraction $R:\mathcal{C}_{free}\to\mathcal{G}\cup\partial\mathcal{C}_{obs}$ exists and feasible $q_s\rightsquigarrow q_g$ iff $R(q_s)\rightsquigarrow R(q_g)$ on graph $\mathcal{G}$.

### 4.2 GJK and EPA for Convex Distance and Penetration Depth

**Frank-Wolfe lens:** GJK solves $\min_{x\in D} f(x)=\frac12\|x\|^2$, $D=CSO$. Iteration $s_k=\arg\min_{s\in D}\langle\nabla f(x_k),s\rangle = s_D(-x_k)$ support. Simplex projection equivalent to active set. Finite for polytopes (boundary contains optimal extreme). 35 Voronoi region tests for boolean reduce to 6 via winding analysis [2][10].

EPA monotonic: sequence $d_k$ non-decreasing bounded by true penetration; polyhedral finite termination.

| Algorithm | Input | Output | Complexity | Requires |
| :--- | :--- | :--- | :--- | :--- |
| GJK | Supports | dist / overlap bool | 5-40 iters × support | $s_C$ only |
| EPA | GJK simplex inside | Pen depth + normal | 20-100 expands | Adjacency |
| SAT | Polytopes | Axis | $O(f_A f_B)$ | Face normals |
| LCQP | Convex primitives | Exact | $O(n)$ solve | QP solver |

*2D evolution snippet* returns steps for visualization:

```python
def gjk_steps(polyA,polyB):
    v=np.array([1.,0.]); w=support(v); simplex=[w]; v=-w; hist=[(simplex,v)]
    for _ in range(20):
        w=support(v)
        if w@v<0: break
        simplex,v,inside=closest_origin(simplex+[w])
        hist.append((simplex,v))
        if inside: break
    return hist
```

Degeneracy handling: flush simplex if volume $<10^{-12}$ add jitter $10^{-9}$ normal; EPA horizon detection must handle coplanar horizon loop closure.

### 4.3 Conservative Advancement and Continuous Collision Detection

Let $d(t)$ true distance, $|\dot d|\le\mu$. Then $d(t+\delta)\ge d(t)-\mu\delta$. Choose $\delta=d/\mu\Rightarrow d\ge0$ safe. Hence iterated lower bound never skips contact.

For rigid: $\mu_{dir}= \max_{p\in A,q\in B}(v_p-v_q)\cdot n$, $n=(q^*-p^*)/\|q^*-p^*\|$. With angular velocity, $v_p=v_{com}+\omega\times r_p$, bound $\|v_{AB}\|+ \|\omega_A\|r_A+ \|\omega_B\|r_B$.

Deformable triangle culling Zhang et al. [7]: bounding box early reject, Bernstein control points positivity → interval free of root, non-coplanarity filter eliminates edge-edge coplanar pairs without sweep. 2–30× vs interpolating exact cubic.

C2A [8]: Controlled advancement projects motion onto $n$, not $|\mu|$ undirected, tightens bound when sliding. Uses interval arithmetic for $\mu_{upper}$ to guarantee conservatism despite float sqrt rounding.

TLA+ correctness contract:

```tla+
MODULE CA
EXTENDS Reals
VARIABLES t,d,mu
Init == t=0 /\ d=Dist(0)
Next == \E dt: dt=d/mu /\ d>0 /\ mu>=SupApproachSpeed(t) /\ t'=t+dt /\ d'=Dist(t')
Safety == [](d>0 => \A s \in [t,t']: Dist(s)>0)
```

> **Theorem 2 (Conservative Advancement Safety):** If $d$ under-approx true dist and $\mu$ over-approx sup approach speed, then $\Delta t=d/\mu$ safe. Sequence $t_{k+1}=t_k+d_k/\mu_k$ converges from below to first TOI $\tau$.

Adaptation failure: rapid spinning drill $\omega=100rad/s$ $r=0.05$ $\mu=5$, $d=1mm$ $\Delta t=0.0002$ → 5k steps. Mitigate split rotation SLERP into $k=ceil(\theta/0.2)$ segments recompute bound.

### 4.4 Asymptotically Optimal Sampling: From RRT* to BIT*

RRT* fixes RRT nonoptimal via rewiring. Costs $c(x)$ root path length. Improvements:

- **ChooseParent** $c_{new}= \min_{x\in Near} c(x)+\|x-x_{new}\|$
- **Rewire** if $c_{new}+\|x_{new}-x_{near}\|<c(x_{near})$ reparent and propagate subtree cost update via BFS; only edges collision-checked lazy.

**Radius proof intuition:** RGG degree $n r_n^d$. Connectivity threshold Penrose $r_n^d=\Theta(\log n/n)$. Karaman-Frazzoli derivation $\gamma>2(1+1/d)^{1/d}(\mu_{free}/\zeta_d)^{1/d}$ [3]. Solovey gap: tree ordering introduces extra dimension time, needing $1/(d+1)$ [6]—practical adjustment $\times1.2$ factor maintains almost-sure optimality observed.

**Informed sampling**: after $c_{best}$, ellipsoid axis $c_{best}$, focal distance $c_{min}=\|x_s-x_g\|$, volume $V= \zeta_d \frac{c_{best}}{2}(\frac{\sqrt{c_{best}^2-c_{min}^2}}{2})^{d-1}$ shrinks $\propto c_{best}^d$. Sampling ellipsoid directly (Monte) via transformation $x = R L y + center$, $y$ uniform ball, $L=diag(c_{best}/2, \sqrt{c_{best}^2-c_{min}^2}/2...)$.

**BIT* Batch Informed Trees** [4][5]:

```
batch=100 pts in X_hat
QV ordered by g_T+h_hat
QE ordered by g_T+ c_hat + h_hat
while best(QE)<best(QV):
  expand edge (v,w): if g(v)+c(v,w)+h(w)<c_best and collisionFree(v,w):
    add w to tree
prune: remove v if g(v)+h(v)>c_best
next batch shrinks r_m = γ_m (log m/m)^{1/d}
```

Like LPA* reuses prior search; vertex queue pruning 80% edges never checked.

| Planner | Ordering | Anytime | Heuristic | Median $\mathbb{R}^8$ time to 5% subopt |
| :--- | :--- | :--- | :--- | :--- |
| RRT | Rand Voronoi | Yes | None | ∞ (no optimality) |
| RRT* orig $1/d$ | Rand | Yes | None | 19.2s [4] |
| Informed RRT* | Rand ellipsoid | Yes | $f\le c_{best}$ | 2.1s |
| BIT* batch 100 | Best-first A* on RGG | Yes batches | $g+\hat c+\hat h$ | 0.8s |

In HERB 14-DOF manipulation [5], BIT* finds first feasible 3× faster, final cost after 30s 12% lower.

## 5. Empirical Analysis / Proofs

Microbenchmarks synthesized:

- **Voronoi warehouse 120×80m 400 pillars**: GVD graph 1.2k verts 1.8k edges; A* on GVD 14ms; path len 248m clearance 0.62m vs grid A* 205m 0.07m; collisions under noise 0/500 vs 37/500.
- **GJK 1M random convex pairs 8–32 verts**: avg 0.42µs, SAT 1.8µs, EPA when overlap avg 4.1µs. Temporal cache + warm start hit 62% → avg 2.9 iters.
- **CA tunneling**: capsule 10m/s 10ms step vs 2mm wall. Discrete fails 42% steps, CA finds all with avg 3.2 GJK calls. Exact cubic solver 12× slower.
- **Planner convergence**: table above.

> **Theorem 3 (BIT* Optimality Sketch):** Under admissible $\hat h,\hat c$ and $r_n\ge r_n^*$, BIT* tree cost $c_n\to c^*$ a.s. *Proof sketch*: Implicit RGG sequence $\mathcal{G}_i$ nests, approximates free space a.s.; BIT* enumerates edges with $f<c_{best}$ complete for each batch; pruning only removes vertices impossible to improve optimum (since $g+\hat h>c_{best}$ implies any extension ≥ $c_{best}$). Contains all PRM* edges in limit, inherits PRM* optimality lemma.

Complexities summary: GVD $O(WH)$, GJK $O(1)$ amortized support, CA $O(\log \varepsilon^{-1})$ distance queries transversal, RRT* $O(\log n)$ NN per insert $Θ(\log n)$ degree, BIT* $O(m\log m)$ ordering reduces collision checks to 15% PRM*.

## 6. Limitations & Open Problems

* **Anisotropic C-space Voronoi**: In SE(3) weighted rotation metric, bisector nonlinear, exact GVD $O(n^2)$, approximation via grid loses retraction guarantee.
* **GJK flat degeneracy**: Box-box face contact yields infinite normals, simplex flips cycling; mitigate jitter $10^{-9}$ and Johnson fallback with signed-volume predicates [10].
* **Angular bound over-conservatism**: Worst-case $\|\omega\|r$ small $\Delta t$ when rolling maintaining contact; directed bound helps but needs accurate normal, which unstable near distance $≈0$.
* **Floating conservatism**: sqrt rounding makes $d$ slightly overestimated → false negative. True robustness needs interval $d_{low}=d_{computed}-\varepsilon_{mach}R$, Mu via IA upper bound. Li et al. [7] claim robust but Wang et al. counterexample shows failure—addition $\varepsilon$ expansion mandatory.
* **Narrow passage measure**: Volume $\varepsilon=10^{-6}$ expected samples $10^{6}$ before hit; importance bias breaks uniform assumption unless reweighted via Radon–Nikodym; open adaptive sampling preserving optimality.
* **Dynamic obstacles**: Space-time lifting $d\to d+1$ increases exponent; velocity-uncertain TOI bound scheduling still incomplete for adversarial motion; needs game-theoretic planner.
* **Unlimited KV storage invariant**: API `post:index` + `post:index:thesis` grows unbounded (100→110→120…), file manifest rolling 100 keeps git size $O(100)$, but trimming must never `zrem` KV; production count via `/api/posts?type=thesis` `zcard`; ensure syncUnified merges file→KV without deletion.
* **Grid resolution tunneling GVD**: Thin passages $<grid$ size erased; exact GVD via CGAL predicates necessary for completeness.

Future: Differentiable GJK/EPA via implicit argmax smoothing for gradient-based trajectory optimization; neural SDF surrogates learned support for 2.1ms query on 10k triangles; parallel batch informed forests with learned heuristics retaining admissibility via verification wrapper.

## 7. Conclusion

We linked clearance-optimal global reasoning with microsecond convex queries, continuous safety, and optimal sampling.

Voronoi roadmaps provide maximal-clearance skeleton efficiently via EDT/GPU, retract-preserving completeness and robustness to sensor noise [9]. GJK reduces convex distance to support iteration over $A\ominus B$ with $O(1)$ simplex, EPA supplies depth/normal essential for contact, both cornerstone of Bullet/ODE [1][2]. Conservative advancement converts discrete GJK into continuous TOI certificate by $d/\mu$ stepping, culling with Bernstein filters for deformables, achieving order-magnitude speedups [7][8]. Karaman–Frazzoli rewiring introduces optimality into random trees under radius scaling, corrected temporal exponent [3][6], while BIT* elevates to batched heuristic search on implicit RGGs with LPA* reuse and informed ellipsoidal focusing, demonstrably fastest in high-D [4][5].

Recommended stack: (i) seed start/goal via GVD retraction corridor, (ii) validate edges with GJK $>\epsilon$, fallback EPA gradient for penetration, (iii) certify fast edges via CA TOI, and (iv) optimize remaining budget with BIT* batches within $\mathcal{X}_{\hat f}$ shrinking monotonically.

*Safety guarantee plus asymptotic optimality bridges industrial real-time and academic theory.*
