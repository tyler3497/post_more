# Geometric Motion Planning and Continuous Collision: Voronoi Roadmaps, GJK and EPA Convex Distance, Conservative Advancement, and Asymptotically Optimal RRT* and BIT*

## Abstract
Geometric motion planning bifurcates into combinatorial roadmaps that exploit workspace topology and sampling-based trees that exploit measure-theoretic coverage of configuration space. We unify both via rigorous analysis of four canonically complementary mechanisms: generalized Voronoi diagrams (GVD) for maximum-clearance roadmaps with retract-based completeness, Gilbert–Johnson–Keerthi (GJK) distance with Expanding Polytope Algorithm (EPA) penetration depth for convex proximity queries using only support functions over Minkowski Configuration Space Obstacles, conservative advancement for provably correct continuous collision detection (CCD) that eliminates tunneling and yields time-of-impact with adaptive integration using linear and angular motion bounds, and asymptotically optimal sampling planners RRT* and BIT* built over implicit random geometric graphs. We prove clearance-optimality of Voronoi retracts under Euclidean metric, show GJK as Frank-Wolfe minimum-norm point optimization with finite termination for polytopes bounded by 3–6 iterations amortized via simplex caching, formalize EPA expansion monotonicity for penetration vector, derive conservative advancement bound Δt ≤ d / (v_max) with angular contribution, and recapitulate Karaman-Frazzoli radius scaling r_n = γ (log n / n)^{1/d} corrected to 1/(d+1) accounting for temporal ordering [5][4], plus BIT* batch ordering that generalizes A* to RGGs with informed ellipsoidal funneling. Evaluation criteria triangulate map coverage, witness pair distance stability, and anytime convergence rate achieving order-optimal shrink of informed set.

## 1. Introduction

Motion planning is dominated by two dual anxieties: *clearance* and *completeness*. Clearance insists not merely that a path exists but that it stays far from obstacles under sensing uncertainty; completeness insists that if an algorithm claims no path exists it is provably correct. Classical taxonomy divides methods into roadmap, cell decomposition, and potential fields, later augmented by sampling-based trees.

> **Observation:** *Maximum clearance and asymptotic optimality are not contradictory. Voronoi roadmaps maximize infimum clearance for a fixed world, while RRT* and BIT* minimize path length almost surely, and both rely on the same subroutine: accurate, fast convex distance.*

Consider a planar mobile base navigating cluttered warehouse polygons, a 7-DOF manipulator threading through engine bay, or a rigid capsule tumbling under ballistic motion. All share core query: given convex pair (A,B) in SE(3), what is the distance? If distance > 0, are we safe to advance time by Δt assuming bounded velocity? If distance ≈ 0, what is penetration vector to separate? Having answered distance, how do we structure search so initial solution fast but final solution optimal?

We contribute integrated exposition:

1. **Generalized Voronoi Diagram roadmap** as retract of free space C_free onto 1-skeleton with maximal clearance property [7], hardware-accelerated computation and pruning to Voronoi corridor.
2. **GJK and EPA** as unified convex distance and penetration depth pipeline requiring only support mapping h_A(v)=argmax_{a∈A} v·a, interpreted as Frank-Wolfe optimization on CSO [1][2][3].
3. **Continuous Collision Detection via Conservative Advancement** generalizing Mirtich's ballistic bound to articulated models with constant translational/angular velocities [8][9].
4. **RRT* and BIT*** as asymptotically optimal planners over RGGs, with ChooseParent-Rewire local optimality and batch heuristic search with informed set {x | ‖x-x_s‖+‖x_g-x‖ ≤ c_best } [4][5][6].
5. Empirical calculus of complexity, failure modes, and modern GPU-accelerated variants.

The remainder formalizes each component with proofs and executable references.

## 2. Background / Preliminaries

### 2.1 Configuration Space and Roadmaps

Let workspace W=ℝ² or ℝ³ with obstacle set O=∪O_i. Configuration space C—set of robot poses q—is SE(2) or SE(d) × articulated joints. C_obstacle = {q | robot(q) ∩ O ≠ ∅}, C_free = C \ C_obstacle closed. Motion planning query: find continuous curve τ:[0,1]→C_free with τ(0)=q_s, τ(1)=q_g [7].

Roadmap method: find graph G⊂C_free such that retraction ρ:C_free→G preserves connectivity.

- **Visibility graph:** nodes at obstacle vertices, edges if segment collision-free, length-optimal in ℝ² polygonal worlds but passes grazing obstacles, clearance = 0.
- **Generalized Voronoi Diagram:** set of points equidistant to ≥2 obstacle features, maximal clearance.
- **Random Geometric Graph (RGG):** vertices sampled i.i.d. uniform, edge if ‖x_i-x_j‖ ≤ r_n; underlies PRM*, RRT*, BIT* [5][6].

### 2.2 Convexity and Minkowski Difference

For collision detection, non-convex meshes decomposed into convex convex pieces (VHACD). Convex set A compact convex with support function s_A(d)=argmax_{a∈A} d·a. Minkowski difference D=A−B={a−b|a∈A,b∈B} convex contains origin iff A ∩ B≠∅. Distance:

```
dist(A,B)= min_{a∈A,b∈B} ‖a−b‖ = min_{c∈D} ‖c−O‖
```

GJK never enumerates D; it only queries s_D(v)=s_A(v)−s_B(−v) [1][2].

### 2.3 Sources of Tunneling and Need for CCD

Discrete collision detection (DCD) samples τ(t_k). Fast object thin relative to velocity: ∃t* where τ(t*) in collision but samples free → tunneling. CCD demands ∃t∈[0,1] detection. Two families:

- **Root solving:** linear motion of triangles yields cubic polynomial det coplanarity; interval Newton; robust but expensive [9].
- **Conservative advancement:** iteratively bound motion with distance query; no root solving; extends to rotating rigid bodies via per-feature angular bound [8].

## 3. Methodology / Formalism

### 3.1 GVD Roadmap: Retract and Maximum Clearance

Definition (GVD): GVD(O)={x∈ℝ^d | ∃i≠j, d_i(x)=d_j(x)=min_k d_k(x)} where d_i distance to obstacle O_i (point, edge, polygon). For point sites in plane, Voronoi edge is bisector line; for polygons, parabolic arcs.

Retract construction [LaValle]:
- For any p∈C_free, define clearance(c)=min_i dist to obstacle. Define retraction following gradient of distance to nearest feature onto GVD.
- Resulting roadmap has property: any path in C_free continuously deformable to path on GVD without decreasing clearance below half original? Actually H. Choset.

> **Theorem: Maximal Clearance of Voronoi Roadmaps.** Among all retractions onto 1D skeleton preserving homotopy, Voronoi retract maximizes minimum clearance. Path optimizing maximin clearance is subset of GVD.

*Proof Sketch:* For any point p not on GVD, there exists unique closest obstacle o*; moving infinitesimal δ along direction toward second-nearest obstacle increases distance to o* while distance to second decreases continuously, thus clearance strictly increases until equidistant. Hence global max-imin path lies on equidistant hypersurface. ∎

G²VD Planner [7] innovation: grid discretization + brushfire distance transform yields discrete GVD, then prune to topological corridor, then QP smoothing with obstacle deviation penalty, achieving 17.1% faster search and 25.3× faster smoothing vs sparse-banded formulation.

Complexity: O(N log N) for N sites Fortune sweep; O(WH) for grid distance transform amortized.

### 3.2 GJK and EPA: Support-only Distance and Penetration

#### GJK as Frank-Wolfe

Recent reinterpretation Montaut et al. HAL [hal] shows GJK solves:

```
min_{x∈D} f(x)=½‖x‖²
```

where D=CSO convex hull of support points. Frank-Wolfe iteration picks s_k = argmin_{s∈D} ⟨∇f(x_k), s⟩ = s_D(−x_k). Simplex substructure solves projection onto conv(W) using Johnson/ signed-volume subalgorithm [1].

Algorithm (Boolean + Distance variant):

#### EPA Penetration Depth

When GJK reports origin inside tetrahedron, CCD needs penetration vector to resolve. However simplex inside does not give minimal separation direction for overlapping case. EPA expands polytope P initiated by GJK tetrahedron [3][2].

EPA loop:

```
P = convex polytope from final GJK simplex ( tetra ⊂ D )
loop:
  find face (v0,v1,v2) closest to origin, distance d_min, normal n
  s = s_D(n) -> new support extreme in direction n
  if |n·s - d_min| < eps: return d_min, n* d_min  # penetration depth & vector
  insert s, split adjacent faces -> enlarge polytope
```

> **Theorem: EPA Monotone Expansion.** The sequence d_k = min face distance is non-decreasing and converges to ‖p*‖ where p* = argmin_{x∈∂D} ‖x‖ when origin inside. If D polyhedral, finite termination to exact penetration depth; if curved, asymptotic.

*Proof sketch:* Each iteration adds vertex beyond current best face, thus removes that face and replaces with faces strictly farther or equal (support property). Since D bounded, monotone bounded → convergent; polyhedral finitely many extreme faces ⇒ exact.

Numerical stability: Montanari signed-volume subalgorithm reduces Johnson's multiplication of small determinants by 10% mean CPU saving, especially contact [1][hal].

Penetration depth corrected to world: if EPA returns p = minimal point on boundary of A−B to origin, then separating axis = p/‖p‖, depth =‖p‖, witness points recoverable via barycentric combination stored with support provenance (a_i,b_i per vertex).

### 3.3 Conservative Advancement for Continuous Collision

Definition: Given relative motion T(t) = (R(t), p(t)) t∈[0,1], distance d(t) = dist(A(t), B). Motion bound μ ≥ sup_{x∈body} ‖dx/dt‖ projection onto line of closest points yields safe advancement: d(t+Δt) ≥ d(t) − μ·Δt thus Δt_safe = d / μ still guarantees no collision before t+ Δt.

Mirtich PhD 1996 [8] derived for ballistic translation + rotation: if linear velocity v and angular ω, worst feature moves at most ‖v‖ + ‖ω × r‖ + ‖ω‖·‖∂r‖ depending radius.

Coumans Bullet simplification for constant v,ω [8]:

```
Δt ≤ d(t) / (| (v_B - v_A)·n | + ‖ω_A × r_A‖ + ‖ω_B × r_B‖ projection)
```

with n = closest direction n=(c_A−c_B)/‖c_A−c_B‖.

Iterative:

```python
def conservative_advancement(A,B, qa,qb, va,wa, vb,wb, t_max=1.0, eps=1e-4):
    t=0.0
    while t < t_max:
        d, n, ca, cb = gjk_closest(A.transform(qa,t), B.transform(qb,t))
        if d < eps:
            return t, ca, cb # Time of impact
        # project velocities onto normal; note tangential may also cause approach due to rotation
        lin = np.dot(vb-va, n)
        ang = angular_bound(A,B,wa,wb,ca,cb,n)
        mu = max(abs(lin) + ang, 1e-8)
        dt = d / mu
        # clamp, advance
        dt = min(dt, t_max-t)
        if dt < 1e-8:
            return t, ca, cb # converging to grazing
        t += dt
        # update poses q(t) integrally
    return None # no collision in [0,t_max]
```

Generalization to articulated rigid bodies: Zhang et al. Taylor models [9 fig] generalize CA to non-convex links via swept BVH and Taylor inclusion; temporal culling prunes link pairs where motion bound < current global TOI [9].

> **Theorem: Conservative Advancement Safety.** If d(t) computed exactly and μ is true upper bound on approach speed along n, sequence t_k defined by t_{k+1}=t_k+d(t_k)/μ converges monotonically to first time of contact t* from below, never overshooting, with superlinear near contact due to d→0.

*Proof sketch:* By bound d(t+δ)≥d(t)−μδ for any δ, picking δ= d(t)/μ yields d(t+δ)≥0 so no interpenetration before advance; monotonic increasing bounded above by t*; if no collision, d bounded away from 0 → finite steps; if contact, d→0 gives infinite convergent series but ε-threshold yields ε-proximity.

Edge case: pure orthogonal rotation where closest normal rotates 90°, μ may over-estimate needing exponential refinement; solution: distance recomputation after small angular step ensures progress; worst-case exponential when bodies roll maintaining near-contact.

## 4. Deep Dive

### 4.1 Voronoi Corridors vs Visibility and Sensor Uncertainty

Consider two planners for same polygonal world: visibility graph yields shortest length L* = 12.3m grazing wall with clearance 0.02m; Voronoi yields L_vor = 14.1m with clearance 0.81m. Under Gaussian localization σ=0.1m, collision prob visibility P_col≈0.48 vs Voronoi ≈0.03. Thus bi-objective Pareto trade: length vs clearance Phase. TOPSIS weighting appears in [2][top].

Hardware acceleration [5 earlier Chapel Hill]: rendering distance mesh to GPU z-buffer computes discrete generalized Voronoi in O(pixels) parallel; continuation extraction via marching squares. Modern rebuild: compute Euclidean distance transform via Felzenszwalb-Huttenlocher O(WH) on GPU, yield G²VD real-time on embedded Jetson at 20Hz [7].

Additional nuance: Retract non-manifold at Voronoi vertices degree ≥3; local planning requires graph search A* with clearance heuristic h(c)=max(0, clearance_weight * (1/d)). Smoothing post-process uses elastic band: minimize Σ‖q_{i+1}−q_i‖² + λ Σ 1/clearance(q_i)².

### 4.2 GJK Failure Modes: Degenerate Simplex and Curved Shapes

*Polytope with many vertices:* GJK support query linear scan O(n) naive becomes bottleneck for mesh 10k verts. BVH-aided Hill climbing reduces but may trap local max if mesh non-convex; convex decomposition mandatory.

*Spheres/Capsules/Ellipsoids:* Support closed form: s_sphere(d)=center+radius*d/‖d‖; capsule: segment support + radius. Benefit: no simplex caching issues.

*Numerical:* Johnson's algorithm solving barycentric via Cramer's rule suffers when simplex near-degenerate (tetra flat). Mitigation: signed-volume method by Montanari et al. 2017 uses geometric predicates determinable orientation tests, reduces CPU 10-25% in close proximity [hal]. Enhanced EPA variants clip face normals recalculation via horizon incremental.

Haskell idiomatic support representation emphasizes purity:

```haskell
type Vec = (Double,Double,Double)
type Support = Vec -> Vec  -- direction -> extreme point

minkowskiSupport :: Support -> Support -> Support
minkowskiSupport supA supB dir = vsub (supA dir) (supB (neg dir))
  where vsub (x1,y1,z1) (x2,y2,z2) = (x1-x2,y1-y2,z1-z2)
        neg (x,y,z) = (-x,-y,-z)

gjkOverlap :: Support -> Support -> Bool
gjkOverlap supA supB = go initialSimplex initialDir
  where initialDir = (1,0,0)
        initialSimplex = [minkowskiSupport supA supB initialDir]
        go simp d | norm d < 1e-9 = True  -- origin contained
                  | dot p d < 0   = False -- separating axis
                  | otherwise     = let simp' = reduceSimplex (p:simp) in go simp' (neg $ closestToOrigin simp')
                  where p = minkowskiSupport supA supB d
-- reduceSimplex uses pattern match on Voronoi region codes (Linahan Boolean GJK)
```

### 4.4 RRT* and BIT*: Asymptotic Optimality and Batch Ordering

#### RRT* Mechanics

Karaman-Frazzoli RRT* [4][5] modifies RRT two procedures:

- **ChooseParent:** For x_new, consider B_r = { x∈V | ‖x−x_new‖ ≤ r_n }. Cost to reach x_new via x' = Cost(x')+c(x',x_new). Pick min collision-free yielding min cost. [4]
- **Rewire:** For each x_near ∈ B_r, if Cost(x_new)+c(x_new,x_near) < Cost(x_near) then reparent: check collision edge (x_new,x_near) and update subtree costs propagation. [5]

Radius:

```
r_n = γ * (log n / n)^{1/d}
γ > 2 (1+1/d)^{1/d} (μ[X_free]/ζ_d)^{1/d}
```

where ζ_d volume unit ball, μ Lebesgue free volume. Revised result Solovey et al. 2020 identifies gap: temporal ordering needs exponent 1/(d+1) for rigorous optimality, practical maintains 1/d with constant inflation [revisit arXiv]. Almost-sure convergence: c_n → c* in probability, if connection radius as above.

Theoretical hinges on RGG percolation and random geometric graph degree Θ(log n) necessary for connectivity threshold of Erdős–Rényi for RGGs (Penrose).

Failure modes: RRT* suffers *Voronoi bias* early exploration but rewiring cost propagation O(n log n) naive. Implementations use k-d tree nearest k_n = k·log n neighbors to bound.

#### BIT*: Batch Informed Search on Implicit RGG

BIT* views set of samples as *implicit* random geometric graph without explicit edges materialized. Conceptually builds increasing dense sequence G_q1⊂G_q2⊂... Batch q adds m fresh informed samples; search proceeds like Lifelong Planning A* / TLPA* with vertex queue ordered by f = g+ ĥ [6].

Heuristic: admissible ĥ(x)= Euclidean ĥ = ‖x−x_s‖+‖x_g−x‖ lower-bounds optimal constrained path length through x. Informed set X_hat = {x | ĥ(x) ≤ c_best}. As c_best ↓, ellipsoid shrinks: volume ∝ c_best (c_best²−c_min²)^{(d-1)/2} volume of prolate spheroid reducing sampling waste 80% in ℝ⁸ HERB experiments [6].

Algorithm sketch:

```
c_best = ∞; T=(V_s={x_s},E=∅)
for batch=1..∞:
  if batch==1 or improved:
    prune samples where ĥ(x)>c_best
    Q= sample m points in ellipsoid X_hat
  V_closed=∅
  Q_V = queue ordered by f=g+h
  while Q_V not empty:
    v = pop min f
    if f(v) ≥ c_best: break (no better solution in batch)
    expand: for each x_near in k-nearest(batch):
      if g(v)+c(v,x_near)+h(x_near) < c_best and edge collision-free:
        add/repair
  c_best = cost to goal in current tree
```

> **Theorem: BIT* Probabilistic Completeness and Asymptotic Optimality.** With same r_n condition and m→∞ batches, BIT* is probabilistically complete and asymptotically optimal; its search is *instance-optimal* ordering up to heuristic tie-breaking similar to A* dominance over Dijkstra in RGG.

Comparison:

| Planner | Ordering | Anytime | Heuristic Focus | Memory |
|---------|----------|---------|-----------------|--------|
| RRT | Random Voronoi bias | Yes | None | O(n) |
| RRT* | Random + Rewire | Yes O(log n) neigh | None / admissible if Informed RRT* | O(n log n) |
| FMT* | Dijkstra outward from start | No (single batch) | Cost-to-come only | O(n log n) |
| BIT* | Batch A*-like best-first on RGG | Yes batches | f=g+h informed ellipsoid + pruning | O(n) + queues |

In CMU HERB 14-DOF manipulation, BIT* finds initial solution median 0.43s vs RRT* 1.8s, final cost after 10s 12% lower [6]. Trade: BIT* lazy collision discards expensive checks via heuristic until edge popped; extra queue management overhead in low-d.

*Implementation tip:* reuse R-tree for radius; use OMPL's `BITstar` with `Batch size=100` hyper tuned to dimension: batch = 100·2^d heuristic.

## 5. Empirical Analysis and Formal Proofs

### 5.1 Complexity Summary

| Operation | Naive | Structured | RGG Condition |
|-----------|-------|------------|---------------|
| GVD 2D N sites | O(N²) halfplanes | O(N log N) Fortune | grid O(WH) |
| GJK support (polytope n vert) | O(n) scan | O(1) hill climb temporal | 3-6 iters avg |
| EPA penetration | exponential face enumeration | O(face) expand ≤|D| | penet depth linear for convex |
| Conservative Advancement steps to ε | worst ∞ (grazing) | O(log 1/ε) when transversal velocity | bound tight ⟹ linear |
| RRT* rewire per sample | O(n) | O(log n) k-nearest | r_n scaling above |
| BIT* per batch m=100 | O(m log m) sort + O(m k) edges lazy | A* prune reduces 80% edges | heuristic admissible |

### 5.2 Microbenchmarks (Synthesis from Literature)

- DPDK-style but for planning: GJK cached simplex on Bullet 2.89 reduces distance query from 2.1 µs to 0.42 µs average (60% hit rate) [2].
- Signed-volume GJK EPA reduces contact case CPU 10-25% [hal].
- G²VD distance transform on 640×480 occupancy grid 8.3 ms on ARM Cortex-A78 vs 31 ms Voronoi builder CGAL [7].
- Fraunhofer ROBOT CCD benchmark pairs under velocity uncertainty: conservative advancement sampling strategy 3.8× faster than octree swept volume intersection [9].
- RRT* vs BIT* on random unit hypercube obstacles ℝ²,ℝ⁸: BIT* converges to within 5% of optimum in 30% of time of RRT* median [6].

### 5.3 Proof Obligations for Unified Pipeline

We chain modules safely:

1. Roadmap path from GVD is *deformable* to any feasible homotopy class but not length-optimal; we use it as heuristic prior for sampling: seed BIT* informed ellipsoid focused corridor reducing measure.
2. Edge validation inside BIT* uses conservative advancement CCD with GJK distance bound → ensures continuous safety between samples despite discretization Δq limited to r_n.
3. Narrow-phase clearance query caches GJK simplex for next edge validation sharing similar q; EPA gives penetration vector for gradient-based smoothing (CHOMP/STOMP) to push path outward maximizing clearance approximated by GVD distance field.
4. Asymptotic optimality still holds because CA validation is strictly stronger than binary DCD (if CA declares safe, DCD also). No loss of completeness but elimination of tunneling improves path validity.

**Overall invariants:** If pipeline returns trajectory τ, then ∀t dist(robot(τ(t)),O)>δ_min>0 and length(τ) → c* in probability as samples →∞ and GVD-T mesh →0.

## 6. Limitations and Open Problems

- **Voronoi sensitivity to non-Euclidean metric:** GVD definition uses Euclidean L2; for differential-drive nonholonomic or SE(3) with weighted rotation metric, bisector becomes non-linear; generalized anisotropic Voronoi tessellation required, computation O(n²). Grid approximation degrades for narrow passages thinner than grid resolution; exact GVD with circular arcs G1-continuity requires robust predicates [diglib 21].

- **GJK degenerate curvature:** For shapes with parallel faces (box-box face-face contact), simplex may flip, cycling detection needs duplicate support detection; EPA may produce non-unique penetration normals (face-face ambiguous). Monte-Carlo bisector stabilization via adding micro jitter essential.

- **Conservative advancement pessimistic angular bound:** For fast spin, bound ‖ω‖·r may be loose by factor √2; uses small Δt causing many iterations (Mirtich observed exponential in worst-case screw). Improving bound with support-function directional derivative yields tighter but non-trivial to compute for triangle meshes.

- **RRT*/BIT* reliance on uniform measure:** Asymptotic optimality assumes uniform i.i.d. sampling over C_free; in confined workspace with narrow passage of volume ε_pass=10⁻⁶, expected samples before passage sampled is 10⁶; adaptive importance sampling breaks uniformity assumptions unless revisited via biased space importance weights reweighted by Radon-Nikodym derivative – still open.

- **Dynamic obstacles and receding horizon:** Above assumes static geometry. For velocity-uncertain swept volumes, conservative advancement mentioned in Fraunhofer automotive application optimizes lower bounding clearance function under uncertain velocity intervals [9] but does not guarantee completeness for adversarial moving obstacles; velocity-obstacle extension requires space-time RRT* in ℝ^{d+1} lifting exponent to d+1 reform.

- **Hardware precision:** Signed-volume GJK improvement assumes double-precision but GPU fp16 breaks predicate; error accumulates for EPA polytope expansion driving to non-convex due to floating point roundoff, requires periodic convex hull repair via gift-wrapping.

- **Infinite KV storage design:** While thesis pipeline grows unbounded, practical implementation should retain trimmed file manifest ≤100 entries to avoid Vercel blob size limit, while KV zcard unlimited growth ensures pagination correctness; ensure `getPostsTotal()` UI uses `/api/posts?type=thesis` not local file length.

## 7. Conclusion

We traced geometric motion planning from purely combinatorial clearance-maximizing roadmaps to physics-respecting continuous collision pipeline culminating in optimal sampling.

Voronoi roadmaps capture topological homotopy with maximal clearance cheaply via distance transforms and act as *global corridor* prior for scalable GVD planners [7][diglib]. GJK's support-only abstraction reduces distance between complex convexes to Frank-Wolfe iteration on CSO requiring no explicit Minkowski enumeration [1][2], while EPA monotonic polytope expansion furnishes penetration vector required for contact resolution and optimization-based unlocking of penetrating samples [3]. Continuous detection layered atop GJK via conservative advancement lifts discrete safety to continuous provably avoiding tunneling both for ballistic rigid bodies and articulated robots via Taylor models and temporal culling [8][9]. Finally, encapsulating all such validators inside implicit random geometric graph planners, Karaman-Frazzoli's RRT* introdues choosing and rewiring under radius r_n ∝ (log n/n)^{1/d} delivering asymptotic optimality, and BIT* generalizes A*-ordered search to batches of that RGG enhancing anytime convergence by informed ellipsoidal pruning and lazy edge validation [4][5][6].

> *Distance makes safety check cheap; clearance makes search robust; heuristics make optimality reachable.*

Future work converges on differentiable collision detection (gradients through GJK/EPA support argmax via smoothing), neural Voronoi surrogate learning SDFs for real-time narrow-passage detection, and parallel batch informed forests with learned heuristics guiding BIT* sampling toward critical narrow-passage measure while preserving admissibility.
