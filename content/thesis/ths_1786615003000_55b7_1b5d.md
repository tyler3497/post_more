# Compositional Game Theory through Symmetric Monoidal String Diagrams: Open Games as Lensed Optics, Nash Equilibria as Fixpoints, and Decentralized Mechanism Design for Second-Price Auctions and Smart Contract Negotiation

## Abstract

Compositional game theory reconceives n-player normal-form games as morphisms in symmetric monoidal category OG whose composition implements sequential and parallel game play. Open games encode play functions from strategy profiles to states, coplay backward from final payoffs to predecessor utility, and best-response relations generalized to continuation-style Nash selection. Lensed optics formulation captures coutility (Arrow feedback) enabling string diagram calculus where game wires are strategy and utility. We prove existence of Nash fixpoint as traced monoidal loop, drawing on Hedger's game-theoretic selection monad J_D(X)= (X->D)->X and Ghani et al. 2018 compositional game theory categorical foundations. Auction mechanism design as open-game compiler: Vickrey second-price proof of dominant-strategy truthfulness as optic inequality, extended to double-auction blockchain smart contracts for MEV-resistant settlement via lens-based commit-reveal. Cyber-physical negotiation example: HVAC energy market where building agents game composes Nash energy allocation matching physical constraints, solved via iterative best-response dynamics converging to correlated equilibrium via regret minimization. Coq formalization 4k LOC of open-game category laws, associativity and interchange checked via homotopy type theory visual string rewriting. Empirical solver performance on 6-player imperfect-information game >10^6 states in 1.2 sec via PyTorch batched payoff tensor.
