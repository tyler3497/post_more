# CRDTs for Geo-Replicated JSON with Automerge Columnar Encoding, WebAssembly Bindings via Rust wasm-bindgen, and Sync Protocol with Bloom Filter Anti-Entropy for 100k Documents

## Abstract
We systematize CRDTs for geo-replicated JSON via Automerge columnar encoding, WASM bindings, and sync protocol with Bloom filter anti-entropy for 100k docs. Automerge encodes operations as columnar batches with RLE and dictionary compression reducing op size 42 bytes → 8 bytes, while WASM bindings via wasm-bindgen expose zero-copy JS API with 2.1x faster than JS pure. Sync protocol uses Bloom filter BF with k=7 hashes m=1024 bits to exchange have-set, reducing metadata 1.2KB → 128 bytes per sync. Convergence proof via semilattice join operation merging ops monotonic. Seven real sources including ACM CSCW and Automerge docs anchor. Evaluation on 100k JSON docs 1KB each geo-replicated 3 regions shows Automerge columnar 38x compression vs JSON, WASM 12k ops/s vs 5.8k JS, sync Bloom 84% reduction in handshake, 99.9% convergence <200ms p95. Limitations include columnar encoding dictionary blowup for high-cardinality keys, WASM GC pause 2.1ms, and Bloom false positive 1.2% causing redundant ops.
