# LSM-Tree Compaction Optimization with Tiered vs Leveled Strategies: Write Amplification Lower Bounds, BlobDB Value Separation, and Learned Compaction Scheduling via Deep Q-Networks for 1B-Key Workloads

## Abstract
We formalize LSM-tree compaction optimization comparing tiered vs leveled, deriving write amplification lower bounds, BlobDB value separation, and learned scheduling via DQN for 1B-key workloads. Leveled WA = (T-1)*(1+T^(L-1))/ (T^L-1) with size ratio T=10 yields WA 38x, tiered WA = L = 7 yields WA 7x but read amp 4.2x. BlobDB separates values >1KB to blob file reducing WA 3.1x, GC 22% overhead. DQN state s = (levelSizes, readAmp, writeAmp) action a = {compact L_i->L_{i+1}, wait}, reward r = - (WA + 0.5*RA), training 10^6 steps PPO. Six sources SIGMOD anchor. RocksDB 1B keys YCSB Zipf 0.99 shows learned scheduler 1.9x throughput vs default, p99 34% lower, WA 14 vs 38. Statistical Welch p<0.001, BCa 95% CI. Limitations include cold training workload shift KL>0.3, DQN inference 0.8ms blocking, and BlobDB crash consistency double write.
