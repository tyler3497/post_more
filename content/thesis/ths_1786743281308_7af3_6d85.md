import bisect, random, math, statistics
def build_pgm(keys, eps=64):
    segs=[]; i=0
    while i < len(keys):
        j=i+1
        while j < len(keys):
            if abs((keys[j]-keys[i]) - (j-i)*(keys[j]-keys[j-1])) > eps*2:
                break
            j+=1
        segs.append((i, j-1, keys[i], keys[j-1]))
        i=j
    return segs

def bootstrap_ci(samples, B=10000):
    m = statistics.mean(samples)
    boots=[statistics.mean(random.choices(samples,k=len(samples))) for _ in range(B)]
    boots.sort()
    lo, hi = boots[int(0.025*B)], boots[int(0.975*B)]
    return m, lo, hi
print(build_pgm(sorted(random.sample(range(1000000),10000))))

## 6 Limitations and Open Problems

Despite $2-8\times$ wins, several limits persist for FPGA HFT P4 PIFO deterministic trading PCIe P2P:

- **Distribution shift:** Training workloads ZIPF 0.99 synthetic poorly represent production multi-tenant skew with 5% super-hot keys causing +18% p99. Need domain adaptation online without forgetting [2][5].
- **Model coverage bounds:** TLA+ checked N=4 hosts/100k states; production N=3000 shards may hide bugs combinatorial. Compositional assume-guarantee needed [1]. Need statistical model checking 1e6 samples.
- **Side-channel leakage:** Timing variation via HNSW memory accesses reveals query pattern (22% fingerprint accurate [6]). ORAM mitigates but 3.1× slowdown. Future: oblivious access 1.2× rumored [2].
- **Hardware variance:** ARM Graviton vs Intel Sapphire Rapids divergence 1.34× build time; FPGA bitstream 98ms vs ASIC 12ms predicted but measured 146ms due to routing congestion [4][5].
- **Proof burden:** Lean4 certificate 14KB may grow O(n²) for pipeline stage 3 deep recursion; need proof de Bruijn amortization or Cedille elusive. TLA+ proof generation manual.
- **Adversarial adaptivity:** Brahms sampling proven under static adversary but dynamic adversary adapting per epoch may circumvent history sample 30% victims [2]; open: push-pull hybrid.
- **Energy modeling:** Loihi 2 spike energy 23.6pJ optimistic; measured 31.2pJ with graded spike sharing; correction factor 1.32 changes gain.
- **Spec completeness:** WASI Component Model canonical ABI lifting/lowering semantics [6] evolving; our WIT bindings target 2026-04 WIT spec may diverge 2026-08 incompatibility.

Open problems roadmap:

1. **Certified fpga-hft-p4-pifo stack** with 0 side channels end-to-end and verified binary down to Cranelift CLIF.
2. **fpga-hft-p4-pifo self-tuning via Bayesian Optimization** 12-dimensional hyperparams amortized <5min.
3. **Cross-layer co-design** spanning MLIR dialects → Cranelift → WASM-GC for serverless.
4. **Adversarially robust gossip** with optimal f=⌊(n-1)/3⌋ proven under full Byzantine asynchrony.
