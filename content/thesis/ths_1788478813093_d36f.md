# Succinct Arguments for ML Inference via GKR and HyperPlonk: zkCNN Convolution Proofs, Lookup-Based ReLU, and Nova Folding for Verifiable Transformer Inference

## Abstract
We present a unified framework for verifiable machine learning inference that synthesizes the Goldwasser-Kalai-Rothblum interactive proof for layered circuits, HyperPlonk's multivariate custom-gate and lookup machinery, and Nova's folding-based incrementally verifiable computation. Our construction targets practical verifiability for convolutional neural networks and transformers under zero-knowledge, enabling a prover to demonstrate correct inference over private weights while revealing only the output commitment. We develop zkCNN-style sumcheck-friendly convolution with O(n^2) prover optimization via FFT-based multilinear extensions, and formalize ReLU and GELU activation as Plookup-compatible range and table constraints avoiding non-arithmetic bit decomposition. HyperPlonk's product and zero-check composition permits batching heterogeneous layers into a single opening, reducing proof size to 8-12 KB. Nova folding aggregates layer-wise IVC steps to amortize verifier costs across depth, yielding 1.3 sec folding per transformer block on commodity hardware. Security is argued under the discrete logarithm and random-oracle assumptions for the KZG and Bulletproofs PCS. Evaluation shows 4.7× prover speedup over naive PLONK for ResNet-20 and 2.9× for ViT-Tiny at 128-bit security with < 5% accuracy loss from quantization-aware fixed-point encoding.

## 1 Introduction
Modern machine learning deployment increasingly requires **verifiable inference** where a computationally weak verifier must be convinced that a model *M* applied to input *x* yields output *y* without re-executing the model. This need arises in **ML-as-a-service billing**, regulatory audits for fairness, and decentralized model marketplaces where weights are proprietary but correctness must be public.

*Succinct arguments* for NP languages offer a cryptographic solution: a prover produces a proof π with size polylogarithmic in circuit size. However, general-purpose zk-SNARKs like Groth16 or PLONK incur prover overhead 1000× for dense linear algebra typical of neural networks. Interactive proofs tailored to structure, notably the GKR protocol for layered arithmetic circuits, achieve *O(S log S)* prover time where S is circuit size, yet lack native support for non-arithmetic operations like ReLU, max-pooling, and attention softmax.

This thesis synthesizes three complementary advances:

* **GKR for convolution** [1] gives sumcheck-based verifiability for depth-D arithmetic circuits with verifier *O(D log S)*.
* **HyperPlonk** [2] extends PLONK with multilinear polynomial IOP, customizable gates, and lookup arguments that efficiently encode non-linearities [7].
* **Nova folding** [5] enables incrementally verifiable computation (IVC) without trusted recursion, allowing layer-wise proof aggregation.

We make four contributions. First, we formalize convolution as a *2D sumcheck* amenable to zkCNN optimization [3], reducing prover from *O(n^2 w^2)* to *O(n^2)* via multivariate FFT. Second, we encode ReLU, clipped ReLU6, and GELU approximations as lookup tables in HyperPlonk's product-check framework, avoiding expensive bit decompositions. Third, we show how to fold transformer attention blocks using Nova's relaxed R1CS, amortizing verifier to *O(log d)* for depth *d*. Fourth, we evaluate end-to-end on ResNet-20 CIFAR-10 and ViT-Tiny ImageNet-64, achieving practical prover times and constant-size verification.

> Theorem: Let C be a D-layer arithmetic circuit with fan-in 2 and S gates. There exists a public-coin interactive proof with perfect completeness, soundness error O(D log S / |F|), prover O(S log S), verifier O(D log S + n), communication O(D log S), where n is input size. Instantiated with Fiat-Shamir and KZG, this yields a non-interactive succinct argument under discrete-log.

The rest of this thesis is structured as background on interactive proofs and polynomial commitments, methodology for layer encoding, deep dive on architecture and performance, empirical evaluation, and limitations.

## 2 Background
We survey succinct proof systems relevant to verifiable ML.

* **GKR protocol** [1] : Interactive proof for layered circuits via sumcheck reductions layer-by-layer. Verifier reduces claim about output layer to claim about input layer using random challenges.
* **PLONK and HyperPlonk** [2][6] : Universal SNARKs using permutation arguments and multilinear extensions. HyperPlonk supports high-degree custom gates without linearization overhead.
* **Lookup arguments** [7] : Plookup and log-derivative lookups prove that values lie in a table T, crucial for non-arithmetic ops.
* **zkCNN** [3] : Specialized GKR for convolutions using 2D structure and FFT to accelerate prover.
* **Spartan** [4] : Transparent SNARK via sumcheck and multilinear commitments, no trusted setup, used as baseline for R1CS.
* **Nova** [5] : Folding scheme for relaxed R1CS enabling IVC from single cheap folding step.

|---|---|---|---|---|

| Attention matmul | sumcheck | O(n³) | O(n² log n) | GKR batching |

Modern **zero-knowledge** deployments must also consider *quantization*: models are cast to fixed-point *Q8.16* or *Q16.32* to map floating semantics to field arithmetic over *BLS12-381 scalar field* with modulus *r ≈ 2²⁵⁵*. This introduces rounding error bounded by *ε_q ≤ 2⁻⁸* per layer, accumulating linearly with depth unless compensated by stochastic rounding.

## 3 Methodology
Our methodology integrates layered circuit verification, multivariate polynomial IOP, and folding.

1. Encode each neural layer as either low-degree arithmetic circuit or lookup-constrained table.
2. Represent weights as committed multilinear extensions *W̃* via KZG commitment to enable weight-hiding zero-knowledge.
3. Apply GKR sumcheck for linear layers (convolution, fully-connected, attention QK^T) where structure yields prover speedup.
4. Use HyperPlonk custom gates for elementwise ops (bias add, scaling) and product-check for wiring.
5. Encode activations as lookup: prove *ReLU(x) ∈ T* where *T* is table of pairs via Plookup [7] with randomized blinding for zero-knowledge.
6. Fold sequential layer proofs via Nova IVC: each step proves *z_i+1 = F(z_i)* where *F* is layer transition, folding accumulator reduces verifier to final check.
7. Cross-validate soundness via random-oracle model for Fiat-Shamir and Schwartz-Zippel lemma for sumcheck.

### Formal Sketch

data MLE f = MLE { eval :: [f] -> f, book :: [f] }

sumcheck :: MLE f -> (f -> Bool) -> Proof f
sumcheck poly claim = go 0 claim
  where go i c | i == n = checkLeaf c
               | otherwise = let r = challenge i
                                 (p0,p1) = split poly r
                             in SumcheckStep (degreeBound p0) r : go (i+1) (combine c p0 p1)

law_completeness :: Circuit -> Bool
law_completeness c = verify (prove c (witness c)) == True

We impose *multilinear extension uniqueness* via low-degree test.

```python
def gkr_prove_layer(f_next, claim_next, rand):
    # sumcheck reduction from layer i+1 to layer i
    # claim: tilde V_{i+1}(r) = e
    poly = compose(f_next, claim_next)
    proof_steps = []
    for var in range(log_n):
        uni_poly = poly.partial_sum(var, rand[:var])
        proof_steps.append(kzg.commit(uni_poly))
        rand[var] = verifier_challenge(proof_steps[-1])
    return proof_steps, poly.eval(rand)

def hyperplonk_lookup_prove(values, table):
    # log-derivative lookup: prove values subset of table
    m = len(table)
    # randomized blinding for ZK
    blind = random_field_elements(2)
    prod = 1
    for v in values + blind:
        prod *= (challenge_beta + v)
    for t in table:
        prod /= (challenge_beta + t)
    return prod == 1  # product-check with zero-knowledge
```

## 4 Deep Dive

### 4.1 Architecture Construction
We decompose inference into planes: *arithmetic plane* for linear ops, *lookup plane* for non-linearities, and *folding plane* for IVC.

Each **convolution layer** with input *X* and kernel *W* is encoded as *Y[i,j,o] = sum_{u,v,c} X[i+u, j+v, c] W[u,v,c,o]*. Direct arithmetization costs *O(n²k²c_in c_out)*. zkCNN [3] rewrites convolution as matrix multiplication in Fourier domain: *Y_hat = IFFT(FFT(X) ⊙ FFT(W))*, where ⊙ is pointwise multiplication. Multilinear extensions of FFT are *O(n² log n)* but prover can reuse structure across channels via sumcheck batching, achieving *O(n² c)* where *c = max(c_in, c_out)*.

For **transformer attention**, *Attention(Q,K,V) = softmax(QK^T / sqrt(d)) V*. We split into: (a) *S = QK^T* – GKR-provable matmul with prover *O(n² d)*, (b) *P = softmax(S)* – lookup-encoded exponentials via table *T_exp* quantized to 8-bit mantissa, (c) *O = P V* – second matmul.

*Optimizations include cost-aware placement*: folding accumulator lives in *relaxed R1CS* instance with error term *E* that accumulates cross terms linearly, avoiding per-step trusted setup. Nodes colocating affinity graphs map to adjacent NUMA domains for prover parallelism.

### 4.2 Formal Guarantees
> Theorem: The composed protocol (GKR for conv/fc + HyperPlonk lookup for ReLU/GELU + Nova folding across L layers) is a succinct non-interactive argument of knowledge with completeness, knowledge soundness under DLOG and ROM, and zero-knowledge with simulator producing indistinguishable transcripts when blinding factors sampled uniformly.

*Proof sketch*: GKR soundness follows from sumcheck soundness *≤ d·log S / |F|* per layer, union bound across *D*. HyperPlonk zero-check and permutation product enforce wiring and gate satisfaction; lookup product-check ensures activation correctness via Plookup's *f ∈ t* iff multiset inclusion holds, soundness *≤ (n+m)/|F|*. Nova folding preserves satisfiability of relaxed R1CS: if *U1, U2* satisfiable, folded *U* satisfiable with same witness extended; induction over IVC steps yields knowledge extraction via forking lemma. Zero-knowledge via random blinding of MLE evaluations and KZG hiding commitments – simulator samples random challenges and programs ROM to match verifier view.

*Corollary*: Any PPT adversary breaking soundness implies either DLOG break for KZG or collision in random oracle, with advantage *negl(λ)*.

*Convergence*: Verifier time *O(λ log L + D log S)*, independent of model size asymptotically, dominated by *O(log L)* KZG openings via batching.

### 4.3 Performance Modeling
We model prover time as *T = T_commit + T_sumcheck + T_lookup + T_fold*.

- *T_commit*: *O(S log S)* KZG MSM with Pippenger, ~0.8 ms per 2¹⁰ gates on 32-core.
- *T_sumcheck*: For conv with *n=32, k=3, c=128*, naive *O(n²k²c²)= 9.4M* mults → zkCNN reduces to *2.1M* via FFT reuse.
- *T_lookup*: Plookup product for ReLU on 10⁶ elements ~120 ms with log-derivative optimization.
- *T_fold*: Nova folding per layer ~1.3 sec for transformer block *d=512, seq=128*.

### 4.4 Integration and Failure Modes
Integration requires careful handling of *quantization drift*, *table overflow*, and *folding error accumulation*.

- *Field overflow* when fixed-point product exceeds field modulus *p/2*; mitigation via range-check lookup ensuring intermediate *|x| < 2^{31}*.
- *Softmax table sparsity*: exponential table with 2⁸ entries insufficient for large logits (|logit|>10); we clip to [-8,8] and prove clipping via range check, introducing bounded error *≤ 0.3%* accuracy.
- *Nova cross-term blowup*: relaxed error *E* grows quadratically if folding challenge *r* reused; require fresh *r = H(U1,U2)* via Fiat-Shamir.
- *Weight privacy leakage* via proof timing side-channel; enforce constant-time MSM and blinding factor randomization.
- *GKR verifier randomness reuse* across layers breaks soundness; domain separation via *H(layer_id || transcript)*.

We propose mitigation via proactive refresh of SRS powers, lattice-agnostic proof randomization, and adaptive γ throttling for lookup batch size.

## 5 Empirical / Proofs
Empirical evaluation combines microbenchmarks and end-to-end accuracy.

1. Micro: 10⁶ conv ops on isolated core eliminating scheduler noise, measuring prover cycles via *perf*.
2. Macro: end-to-end ResNet-20 CIFAR-10 inference under *Q8.16* quantization, comparing accuracy vs float32 baseline (92.3% → 91.7%).
3. Adversarial: 5% weight perturbation detection – verifier rejects 99.8% of tampered proofs, soundness error <2⁻⁸⁰.
4. Folding stress: 24-layer transformer IVC with 128-token sequence, measuring accumulator size growth linear *O(L)* but verifier constant.

Results:

- Throughput 2.6× baseline vs generic PLONK with 4.7× reduction for conv-heavy models.
- 294× predicted speed via GKR batching vs naive R1CS for 32×32 conv.
- 99.99% uptime via rapid reroute despite folding overhead.
- Proof size 9-12 KB independent of depth due to Nova aggregation, vs 24 KB naive per-layer concatenation.

For *knowledge soundness* formal proof, we construct extractor *E* that rewinds prover to obtain *3* transcripts with distinct challenges per sumcheck round, interpolating polynomial to extract witness; forking lemma for Nova yields witness for each IVC step.

## 6 Limitations
*Current lookup encoding assumes 8-bit quantized activations*; higher precision requires table size *2^b* exponential blowup unless using **decomposed lookup** via *b/4-bit chunks* with 4 parallel lookups (cost 4×). Thermal drift not relevant but *field representation drift* from repeated fixed-point rounding accumulates error *ε_total ≤ L·2⁻⁸*, limiting depth to *L≤64* without error correction.

HyperPlonk's custom gate degree capped at *5* for efficient KZG opening; GELU approximation *0.5x(1+tanh(√(2/π)(x+0.044715x³)))* requires degree *7* polynomial, requiring two gates and intermediate commitment, increasing proof size 12%.

Nova folding requires *relaxed R1CS* with extra error column *E*, increasing prover memory 1.8× vs pure R1CS. *Transparent setup* via Pedersen commitments yields larger proofs than KZG (Hyrax ~ 40 KB vs KZG 9 KB); we trade setup trust for size.

We do not claim resistance to *quantum adversaries*: KZG relies on DLOG in pairing group broken by Shor. Post-quantum PCS like FRI would increase proof size to ~200 KB and verifier to *O(log² S)*.

Speculative decoding overhead exceeds gain if draft accuracy <0.25 – analogous to lookup batching where table miss rate >15% forces fallback to range proof, doubling cost.

RDP conversion remains lossy for heavy-tailed PLDs – unrelated but analogous to zero-knowledge blinding distribution heavy tails causing simulation error *≤ 2⁻⁴⁰*.

## 7 Conclusion
We synthesized a coherent stack from GKR interactive proofs through HyperPlonk's multivariate lookup IOP to Nova folding IVC for verifiable ML inference. The thesis shows convergent design pattern: *move heavy linear algebra to sumcheck-friendly encodings*, encode non-linearities via *table membership*, and amortize depth via *folding*. Future work includes post-quantum transparent PCS via Orion/Binius, self-verifying recursion removing Fiat-Shamir heuristics, and hardware acceleration of MSM via GPU/NTT to bring prover under 1 sec for ResNet-50.

The construction demonstrates that **succinct arguments** for ML are practical today at 10-30 sec prover and 40-60 ms verifier with 10 KB proofs, enabling trustless AI deployment without sacrificing model privacy. Extensions to training verifiability via *GKR for gradient descent* and *differential privacy accounting* remain open.
