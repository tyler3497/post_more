```python
# NFA to DFA subset construction minimization
from collections import deque
def eclosure(nfa, states):
    stack=list(states); closure=set(states)
    while stack:
        s=stack.pop()
        for ns in nfa.get(s,{}).get('eps',[]):
            if ns not in closure:
                closure.add(ns); stack.append(ns)
    return frozenset(closure)

def subset_construction(nfa, start):
    start_closure=eclosure(nfa,{start})
    dfa={}; queue=deque([start_closure])
    seen={start_closure}
    while queue:
        cur=queue.popleft()
        for c in ['a','b']:
            nxt=set()
            for s in cur:
                for ns in nfa.get(s,{}).get(c,[]):
                    nxt.update(eclosure(nfa,{ns}))
            nxt_f=frozenset(nxt)
            if nxt_f and nxt_f not in seen:
                seen.add(nxt_f); queue.append(nxt_f)
            dfa[(cur,c)]=nxt_f
    return dfa
```

### 4.3 Composition, Pipelining, and Runtime Interaction

***Composition, Pipelining, Runtime Interaction***: eBPF/XDP data-path integration.

- XDP program types DRV runs driver early before skb alloc, zero-copy, 10M pps feasible.
- BPF maps: HASH LRU for 5-tuple flow table entry FlowState NEW ESTABLISHED DETECTED CLOSED, LRU eviction timeout 60s, max 1M entries.

> **Lemma 4.3 (Flow Table Isolation).** *Per-flow state isolation via LRU HASH ensures New->Established->Closed GC no cross-flow pollution.*

```python
# eBPF/XDP flow matching stateful pipeline
flow_table = {}
def xdp_process(pkt):
    key = (pkt.src_ip, pkt.src_port, pkt.dst_ip, pkt.dst_port, pkt.proto)
    state = flow_table.get(key, 'New')
    if b'union' in pkt.payload.lower() and b'select' in pkt.payload.lower():
        state = 'IntrusionDetected'
        return 'XDP_DROP'
    flow_table[key]='Established'
    return 'XDP_PASS'
```
