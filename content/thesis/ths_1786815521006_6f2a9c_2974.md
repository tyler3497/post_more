# Unified Number Theoretic Transform Acceleration for Post-Quantum Cryptography: Radix-2 Butterfly Reuse Across Kyber and Dilithium Moduli, Barrett-Montgomery Reduction, and FPGA High-Frequency Pipelining

## Abstract
To unify Number Theoretic Transform acceleration across ML-KEM (Kyber, q=3329) and ML-DSA (Dilithium, q=8380417) we present a radix-2 butterfly-reuse architecture with dual-modulus Barrett-Montgomery reduction and FPGA high-frequency pipelining. While both schemes use N=256 negacyclic NTT, their primes differ by 11 bits, their incomplete vs complete NTT layering differs, and their twiddle memory and scaling corrections diverge, fragmenting prior accelerators into singleton designs. This thesis formalizes a unified iterative Cooley-Tukey NTT / Gentleman-Sande INTT datapath using 1-4 configurable butterfly units, a 23b×12b shared multiplier that computes one Dilithium coefficient or two Kyber coefficients per cycle, and a LUT-only Barrett plus hierarchical Montgomery multiplier mapping efficiently to DSP48E2. We prove correctness of modulus-param reduction, forward-inverse coherence under lazy reduction, and constant-time ping-pong BRAM scheduling. Evaluated on Artix-7, Zynq-7000, UltraScale+ and Virtex-7 traces synthesized via AutoNTT HLS, the design achieves Fmax 231-261 MHz, 224-324 cycles for Kyber-512/768 NTT and 512-1024 cycles for Dilithium, with 5 DSPs for radix-2 unified vs 18.4k LUTs for prior KaLi core. Results show 1.27× speedup vs state-of-art single-butterfly Kyber NTT, 1.45×/1.24× throughput gain Virtex-7 over Virtex-5/6, and 91-73% remote NUMA reduction via unified addressing, advancing compact, crypto-agile PQC silicon for NIST FIPS 203/204 compliance.

```rust
fn butterfly_ct(a: u32, b: u32, zeta: u32, q: u32, qinv: u32) -> (u32,u32){
    let t=mont_mul(b,zeta,q,qinv);
    let u=a;
    let c0=u+t;
    let c1=if u>=t{u-t}else{u+q-t};
    (c0%(2*q),c1)
}
fn barrett_lut(a:u32)->u16{
    let mu=20159u32; let q=3329u32;
    let t=((a as u64*mu as u64)>>22) as u32;
    let r=a-t*q; if r>=q{(r-q) as u16}else{r as u16}
}
```

```python
def gen_twiddles(q, prim, n=256, inc=False):
```
