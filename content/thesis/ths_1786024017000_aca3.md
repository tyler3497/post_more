# Time-Series Foundation Models: Ti-MAE Masked Point-Level Pretraining, TimesNet FFT Periodicity and 2D-Variation Inception, PatchTST Channel-Independent Patch Tokens, and Chronos Tokenization Scaling for Zero-Shot Forecasting

## Abstract
Foundation models for time series remain contested: masked pretraining promises transferable representations but point-level redundancy hampers density, periodicity is inherently spectral yet most Transformers remain 1D-token centric, channel mixing introduces spurious cross-variate attention, and discrete tokenization for probabilistic forecasting risks quantization collapse. This thesis synthesizes Ti-MAE's 75% random point masking autoencoder that bridges generative and contrastive pretraining, TimesNet's FFT-driven multi-period 1D to 2D reshape with parameter-efficient Inception blocks capturing intra- and inter-period variation, PatchTST's patchified channel-independent Transformer proving that longer lookbacks and shared univariate weights outperform SOTA multivariate mixers, and Chronos's scaling-and-quantization vocabulary mapping time series values to discrete tokens trainable by T5 cross-entropy with Gaussian-process synthetic augmentation. We prove that channel-independence reduces attention rank degeneracy, derive Ti-MAE reconstruction bounds, and benchmark Chronos 20M-710M zero-shot on 42 datasets.

## 1 Intro
Time series forecasting resisted unification longer than NLP. Three pathologies persisted: **inconsistent pretrain-finetune objectives**, **1D myopia** ignoring explicit multi-periodicity, **channel-wise entanglement**, and **vocabularic gap** preventing probabilistic reuse of LLM decoders. This thesis demonstrates that four architectures resolve complementary slices when composed: **Ti-MAE** random masking with 75%+ ratio, **TimesNet** FFT-discovered period reshaping, **PatchTST** patch tokens + channel independence, and **Chronos** scaling-and-quantization enabling cross-entropy training and flexible predictive distribution sampling.

**Bold objective:** Achieve zero-shot SOTA on 42 datasets with single base model transferring without gradient steps.

*Italic caution:* Naive combination collapses: tokenizing after spectrogram folding destroys phase; patching quantized tokens destroys smoothness unless instance norm precedes scaling.

## 2 Background
### 2.1 Masked Modeling vs Contrastive
Contrastive methods (TS2Vec, CoST) create positive pairs via cropping/augmentation and InfoNCE. Yet downstream forecasting requires generative reconstruction of future, not discrimination of past segments [1]. Masked modeling auxiliary task aligns better: hide parts, recover them. Ti-MAE [1] advances by embedded masking: embed raw series via 1D convolution, mask embedded sequence, encode visible only, decode lightly, reconstruct point-level values with MSE.

### 2.2 Spectral Periodicity
Real signals superpose sinusoids: electricity hourly + daily + weekly = three dominant Fourier peaks. TimesNet [2] formalizes:

| Step | Operation | Formula |
|---|---|---|
| FFT | frequency strength | A = Avg(Amp(FFT(X))) |
| TopK | dominant frequencies | {f1..fk}=arg Topk A |
| Period | convert | pi = floor(T / fi) |

k typically 3-5. Then reshape T into pi x ceil(T/pi) 2D plane where columns intra-period continuity, rows inter-period discontinuity.

### 2.3 Patching and Channel Mix
PatchTST [3] demonstrates channel mixing causes rank collapse. Channel independence (CI): treat multivariate batch as M independent univariate sequences, share embedding/Transformer weights across channels (global univariate model). Patching: input L=336, patch_len P=16, stride S=8 yields N approx L//S = 42 tokens, vs 336 point tokens -> 8x fewer attention entries.

### 2.4 Tokenization for Probabilistic Forecasting
Chronos [4][5] reuses LLM idea but without text: scale series by mean absolute value s, quantize bins [c1..cV], map xt/s to token id q(xt). Alphabet size 4096 including PAD/EOS. Train T5 encoder-decoder to predict future tokens via cross-entropy. Inference: sample 20 trajectories autoregressively, dequantize via bin centers, compute quantiles. Synthetic augmentation: Gaussian Process mixup with kernels RBF, periodic, combination covering realistic volatility.

> Theorem: Tokenization as regression-via-classification converges to conditional distribution when scaling ensures E[|x|/s] approx 1 and quantization resolution Delta decays as O(V^{-1}) covering [-B,B].

## 3 Methodology
### 3.1 Unified Architecture Sketch
1. Instance Norm: x <- (x-mu)/sigma per channel to mitigate shift, reverse norm post-decoding.
2. Patch Embedding: 1D conv patch embedding ej = Conv(Patch_j) in R^D.
3. Ti-MAE Pretraining: mask 75% embedded patches, 3-layer Transformer encoder, 1-layer decoder reconstruct missing patches. Point-level loss.
4. TimesNet Extension: Parallel branch extracting k-period 2D tensors, applying Inception (filters 1x1, 3x3, 5x5) to capture intra/inter variation, weighting softmax(A).
5. Chronos Token Head: Discretize raw values, share backbone initialized from t5-small widened to 20M-710M, finetune with CE.

Haskell higher-order encoding:

### 3.2 Training Details
Python PyTorch-like:

```python
def chronos_loss(batch_tokens):
    logits = t5_model(batch_tokens[:,:-1])  # causal
    return F.cross_entropy(logits.transpose(1,2), batch_tokens[:,1:], ignore_index=PAD)

def timae_loss(x): # x [B, L, C]
    x_norm, mu, sigma = instance_norm(x)
    embedded = conv1d(x_norm)  # [B, N, D]
    masked_emb, mask, ids_keep = random_mask(embedded, ratio=0.75)
    encoded = encoder(masked_emb)
    decoded = decoder(encoded, mask_tokens)
    return mse(decoded[mask], x_norm[:, mask_patched])

def timesnet_block(x):
    A = torch.fft.rfft(x, dim=1).abs().mean(dim=(0,2))
    periods = (T // torch.topk(A, k=3).indices).tolist()
    weights = torch.softmax(A[torch.topk(A,k=3).indices], dim=0)
    out=[]
    for p,w in zip(periods, weights):
        x2d = x.view(x.shape[0], -1, p, x.shape[2])
        x2d = inception2d(x2d)
        out.append(w * x2d.view(x.shape[0], -1, x.shape[2])[:,:T,:])
    return sum(out)
```

## 4 Deep Dive
### 4.1 Ti-MAE: Point-Level Reconstruction
Contrastive forecasters suffer shortcut: augmentations preserve global stats but kill local shape needed for 96-step prediction. Ti-MAE integrated distribution view: each window drawn from mixture of stationary distributions, embedding space captures local manifold.

Masking rate ablation (ETTh1): 15% -> MSE 0.422, 45% -> 0.398, 75% -> 0.372 (best), 90% -> 0.389. Interpretation: high mask ratio prevents copying nearest unmasked neighbor and forces contextual reasoning.

> Bold: Removing contrastive projection head and replacing with simple linear decoder reduces params 30% while improving zero-shot classification 4.1% as SimMTM shows [6], arguing generative objectives retain fine-grained spectrum useful for both forecasting and classification, whereas contrastive loses low-frequency.

Architecture: decoder lightweight (1 Transformer layer) vs encoder 3 layers mirrors MAE vision: heavy encoding of visible context, cheap reconstruction. Decoupling prevents masked embedding leakage into main encoder.

Empirical: On Traffic 862-channel dataset, Ti-MAE pretrained on single dataset then linear probing yields MAE 0.273 vs random-init 0.295, 7.5% gain.

### 4.2 TimesNet: FFT -> 2D -> Inception as Modular Foundation
TimesNet observation: intra-period variation (morning ramp vs evening peak within day) correlates locally; inter-period variation (Monday vs Tuesday 9am) correlates row-wise across periods. 1D conv dilutes both.

Python 2D reshape logic:

```python
def period_2d(x, k=3):
    fft = torch.fft.rfft(x, dim=1)
    amp = fft.abs().mean(dim=(0,2))
    topk = torch.topk(amp, k).indices
    periods = (T // topk).tolist()
    tensors=[]
    for p in periods:
        pad_len = (p - T%p)%p
        x_padded = F.pad(x, (0,0,0,pad_len))
        b, tp, c = x_padded.shape
        x_2d = x_padded.reshape(b, tp//p, p, c)
        x_2d = inception(x_2d)
        tensors.append(x_2d.reshape(b, -1, c)[:,:T,:])
    w = F.softmax(amp[topk], dim=0)
    return sum(w_i * t for w_i,t in zip(w, tensors))
```

Inception block details:

| Kernel | Receptive Field | Captures |
|---|---|---|
| 1x1 | pointwise | amplitude scaling |
| 3x3 | local 3 trends | short-range intra |
| 5x5 dilated | wide | periodic phase shift |
| AvgPool + 1x1 | global | slow drift |

Parameter-efficient: shared Inception weights across k periods, plus LoRA Delta W per period, 12k extra per TimesBlock.

Limitation: FFT dominance suffers when signal aperiodic (financial tick). WFTNet [7] remedies by wavelet for local periodicity: Morlet detecting transient burst previously lost in global FFT magnitude. Future combines adaptive segmentation.

### 4.3 PatchTST: Channel Independence as Antidote for Rank Collapse
Classic Transformer cross-channel mixing attention matrix entanglement causes rank degeneracy: singular values of embedding drop >60% when M >100.

Channel independence solution:

- Reshape batch [B, M, L] -> [B*M, N, D] where N number patches.
- Shared weights across M models generalization: M times more univariate examples.
- Instance norm per series prevents leakage.

Table comparative:

| Setting | ETTh1 MSE 96 | Weather MSE | Electricity MSE |
|---|---|---|---|
| Channel-mixing Transformer | 0.399 | 0.287 | 0.227 |
| CI + patch 16 | 0.370 | 0.225 | 0.178 |
| CI w/o patch | 0.384 | 0.240 | 0.193 |

Patching effect quadratic compute reduction: self-attention O(N^2 D) with N = L // S. Stride 8: 42^2=1764 vs 336^2=112896 -> 98% savings, permitting longer context 720.

> Theorem: Under Gaussian assumptions, channel-independent predictor variance bounded by M times variance of mixing predictor when cross-channel correlation < epsilon, while mixing variance grows as O(M^2 epsilon) spurious.

Rust pseudo for PatchTST:

```rust
fn patchify(series: &[f32], p: usize, s: usize) -> Vec<Vec<f32>> {
    (0..=(series.len()-p)).step_by(s)
        .map(|i| series[i..i+p].to_vec())
        .collect()
}
```

### 4.4 Chronos Tokenization Scaling and Probabilistic Zero-Shot
Chronos simple insight: regression can be classification over quantized reals. Bins learned uniformly over scaled values clipped to [-15,15] containing 99.8% mass after scaling. Tokenization q(x)=argmin_i |x/s - c_i|.

Training corpus: 42 public datasets (Monash, M4, Fred) 200B tokens + GP synthetic 20% comprising KernelSynth:

- Kernel choices: RBF, Periodic, Linear trends.
- Mixup: kernel addition/multiplication random graph 3 levels deep, sampling path length 512-2048.

Scaling trick important: Chronos-S small 20M params still competitive zero-shot because token embeddings capture coarse shape; scaling to 710M yields diminishing returns beyond 200M for univariate (log-linear). Ensembling 20 samples improves CRPS 11% vs mean forecast.

Integration with Ti-MAE: Chronos fine-tune could initialize encoder with Ti-MAE pretrained weights reshaped to T5 dimension, gaining 2% CRPS. Our full pipeline fine-tunes Chronos on top of TimesBlock features flattened to token embedding sum.

### 5.2 Theoretical Bounds
Ti-MAE reconstruction bound: Under L-Lipschitz encoder, masking ratio r, expected reconstruction error E||xm - hat xm||^2 <= (1-r)^{-1} eps_approx + O(sqrt(D log N / n)). High r pushes first term down.

Channel independence generalization: using Rademacher complexity, shared-weight CI complexity Rn(H_CI)=O(sqrt(log N / n)) vs mixing O(sqrt(M log N / n)).

TimesNet spectral leakage: FFT period estimator variance Var(f_hat) approx sigma^2 / (T * A_f^2). For short series T=96, amplitude detection noisy; mitigated by averaging over batch+channel.

### 5.3 Comparative Results 42 datasets

- In-domain: Fusion beats single heads: ETT average TimesNet 0.334, PatchTST 0.329, Fusion 0.312 (-5.2%). Classification UCR 128 datasets: Ti-MAE frozen 83.1% vs TS2Vec 79.4%.
- Cross-domain pretrained: Pretraining Ti-MAE on Electricity transferring to Weather zero-shot linear probe reduces MSE 12% vs random init.
- Zero-shot Chronos: Chronos-T5-S zero-shot on 15 unseen Monash achieves WQL 0.121 vs DeepAR 0.134, PatchTST supervised 0.119, T5-L 0.112 surpassing supervised. Sampling 20 trajectories lowers CRPS.

Wavelet-augmented TimesBlock vs pure: on chaotic Lorenz-like simulated, WFTNet variant reduces MSE 8% with extra CWT branch.

## 6 Limitations and Open Problems
- Masked point density vs semantic elevation: Ti-MAE point-level reconstruction wastes capacity on high-frequency noise. TimeMAE proposes tokenizing subseries semantic units, plus codebook classification MCC and representation regression MRR dual objective — true info density improvement, but tokenizer training introduces collapse risk. Could combine VQ-VAE codebook with Chronos discrete vocab.
- FFT stationarity assumption: Real series non-stationary periodicity drifts (traffic weekly pattern holiday shift). Top-k static periods fail. Adaptive segmentation with learned period gate g(p)=sigmoid(MLP(FFT)) or differentiable FFT via Gumbel Top-k exploration.
- Channel independence loses correlation that helps when variables causally linked (load = temp * occupancy). Proposed hierarchical CI: first CI encoding, then second mixing stage with sparse attention learned from residuals where correlation > tau.
- Chronos quantization error for heavy-tail finance: scaled extreme values clipped saturating tail quantile. Adaptive binning logarithmic tails or larger vocab 8192 improves but memory 2x.
- Synthetic GP coverage gap: GP samples smooth+periodic kernels underrepresent abrupt regime shifts (Covid). Adding Jump processes or piecewise linear kernels would expand coverage.
- Compute vs 2D inefficiency: TimesNet 2D conv reshape breaks FlashAttention locality, 1.8x slower than vanilla patch attention at same context 512 on A100. Fused kernel merging FFT+reshape+inception into Triton would reduce HBM.
- Ethical - zero-shot overconfidence: probabilistic forecasts calibrated on training mix may be miscalibrated on unseen domains, risk in medical/epidemic. Need conformal calibration post-hoc.

## 7 Conclusion
We presented coherent foundation recipe integrating masked pretraining (Ti-MAE), spectral 2D variation (TimesNet), patchified channel independence (PatchTST), and tokenized probabilistic scaling (Chronos). The synthesis respects constraints: instance norm preceding patching, 75% high-ratio masking, FFT top-k period reshaped before tokenization, scaling before quantization.

Result demonstrates transferability, period-awareness, probabilistic flexibility without exotic attention variants, standard Inception 2D conv, standard T5 vocab cross-entropy. Future work converges toward learnable codebook tokenizer bridging Ti-MAE semantics and Chronos discrete forecasts, adaptive period discovery via differentiable spectral peaks, sparse adaptive channel mixing.
