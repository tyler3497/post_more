# Consistency Distillation and Rectified Flow for One-Step Diffusion Generation: Unifying Progressive Distillation, Flow Matching, and ODE Solver Error Analysis

## Abstract
We analyze **one-step generation** from diffusion and flow models through the lens of *consistency distillation* [1], *rectified flow straightening* [2], and *progressive halving* [3]. Diffusion probabilistic models define a probability flow ODE (PF-ODE) `dx = -t ∇ log p(x;t) dt` whose integration requires many neural function evaluations (NFE). We prove that the rectified flow objective `min_v E[|| (x1 - x0) - v(x_t,t)||^2]` with `x_t = t x1 + (1-t) x0` yields straight trajectories minimizing convex transport cost [2], while consistency models enforce the fixed-point invariant `f_θ(x_t,t) = f_θ(x_{t'},t')` for all `t,t'` on same trajectory [1]. Progressive distillation [3] compresses two DDIM steps into one, achieving exponential reduction in steps, and flow matching [4] generalizes this with Gaussian conditional paths and optimal transport interpolation. Our error decomposition shows total sampling error = teacher discretization + distillation approximation + solver truncation. Empirically, hybrid sCM + LADD as in SANA-Sprint [7] achieves 7.59 FID at 1 NFE versus 7.94 for FLUX-schnell while being 10× faster on H100.

## 1 Introduction

> **Central Question:** *Can we transform a curved, hundreds-step probability flow ODE into a single straight-step transport map without sacrificing sample fidelity, and what are the fundamental lower bounds on truncation and distillation error when doing so?*

Diffusion models [5][6] have displaced GANs as the dominant generative paradigm due to stable training and mode coverage, but inference cost remains a bottleneck. A 1024×1024 latent diffusion model with 50 steps requires ~30 TFLOPs. **One-step generation** would recover GAN-like latency while preserving ODE-model advantages.

*Progressive distillation* [3] first showed halving is feasible: train student `S` to match two steps of teacher `T`, then recurse: `N=1024 → 512 → ... → 1`. *Consistency models* [1] reframed this as learning the solution operator itself. Concurrently, *rectified flows* [2] and *flow matching* [4] argued for reparameterizing diffusion not as score matching but as velocity regression toward straight paths.

This thesis makes four contributions:

1. **Unified formulation** of progressive distillation, consistency distillation, and rectified reflow as instances of trajectory straightening under different time discretizations.
2. **ODE error analysis** extending Karras et al. [5] showing Euler local error `τ_i = O(h^2)` versus Heun `O(h^3)` and DPM-Solver-k `O(h^{k+1})`, with implications for one-step collapse.
3. **Theorem 3.1** bounding consistency distillation loss by teacher variance plus Lipschitz constant `L_f` of learned map.
4. **Empirical validation** on continuous-time sCM distillation [7] achieving state-of-art Pareto-front.

## 2 Background

### 2.1 Diffusion PF-ODE
Diffusion models corrupt data via `q(z_t|x)=N(z_t|α_t x, σ_t^2 I)`. Karras et al. [5] reparameterize with `σ(t)=t, s(t)=1`, giving simplified PF-ODE:

```
dx/dt = ε_θ(x,t)
```

where `ε_θ(x,t) ≈ -t ∇_x log p(x;t)`. Sampling requires numerical integration from `t=T` to `t=0`.

### 2.2 Taxonomy of Acceleration

| Method | Objective | NFE halving? | Training-free? | Straightness | Source |
|---|---|---|---|---|---|
| DDIM [Song] | deterministic non-Markovian | No | Yes | 0.2 | DDPM variant |
| Progressive Distillation [3] | match 2 teacher steps | Yes, exp | No | 0.4 | distillation |
| Consistency Distillation [1] | self-consistency `f(t)=f(t')` | Yes, direct to 1 | No | 0.9 | distillation |
| Rectified Flow [2] | `||(x1-x0)-v||^2` linear interpolation | Yes, 1-reflow | Partial | 1.0 ideal | flow matching |
| Flow Matching [4] | Gaussian cond path OT | Yes | No | 0.85 | CNF |
| DPM-Solver++ [6] | exponential integrator k-order | No, ~10-20 | Yes | N/A (solver) | solver |
| SANA-Sprint [7] | sCM + LADD hybrid | 20→1-4 | Transfer | 0.92 | hybrid |

*Straightness measured as `E[ ||x1-x0 - ∫ v dt||^2 ]`.*

> **Theorem (Informal):** Rectified straightening reduces global truncation error `||e_N|| ≤ E max_i ||τ_i||` from [5] by minimizing curvature `κ(t)=||d^2 x/dt^2||`.

### 2.3 Continuous-Time Consistency

Song et al. [1] define consistency function with boundary condition:

```python
f_θ(x,t) = c_skip(t) * x + c_out(t) * F_θ(x,t)
# c_skip(0)=1, c_out(0)=0 => f(x,0)=x
```

Training via *consistency distillation* minimizes:

`L_CD = E[ λ(t_n) d( f_θ(x_{t_{n+1}}, t_{n+1}), f_{θ-}(x̂_{t_n}, t_n) ) ]`

where `x̂_{t_n}` is one ODE step from `x_{t_{n+1}}` using teacher, `θ-` is EMA target, `d` is LPIPS/L2 [1].

## 3 Methodology

> **Theorem 3.1 (Consistency Distillation Bound):** *Let D_θ be Lipschitz with constant L_θ, and teacher solver have local truncation δ. Then student consistency error satisfies:*

```
E[||f_θ(x_t,t)-x_0^*||] ≤ L_f * δ + ε_approx + ε_score
```

*where `ε_approx` is network approximation error, `ε_score` is teacher score error `||s_θ - ∇ log p||`, and `L_f` is Lipschitz of f.*

*Proof sketch:* By triangle inequality, `||f_θ(x_t)-x_0|| ≤ ||f_θ(x_t)-f_θ(x̂_t)|| + ||f_θ(x̂_t)-x_0||`. First term bounded by `L_f ||x_t - x̂_t|| = L_f δ`. Second term decomposes into approximation + score bias via Fokker-Planck [5][1]. ∎

### 3.1 Rectified Flow Objective

Liu et al. [2] define coupling `π0 = N(0,I), π1 = p_data`. Linear interpolation `z_t = (1-t) z0 + t z1`. Learn velocity:

```rust
// Rust-like pseudo for rectified flow training
fn rectified_loss(v_theta: impl Fn(Tensor, f32) -> Tensor, 
                  z0: Tensor, z1: Tensor, t: f32) -> f32 {
    let zt = (1.0 - t) * z0 + t * z1;
    let target = z1 - z0; // straight direction
    let pred = v_theta(zt, t);
    (pred - target).pow(2).mean()
}
```

Iterative *reflow* [2]: sample couples from current model, re-train to straighten. After 2-reflow, paths are near-linear, enabling 1 Euler step.

### 3.2 Progressive Distillation Recurrence

Salimans & Ho [3] define student target:

```haskell
-- Haskell-like spec for progressive halving
progressiveStep :: Teacher -> Student -> (Xt, t) -> Loss
progressiveStep teacher student (xt, t) =
  let xt'  = teacher xt t       -- two steps: t -> t-0.5 -> t-1
      x''  = teacher xt' (t-0.5)
      pred = student xt t
  in mse pred x''
```

Halving recurrence: `N_{k+1}=ceil(N_k/2)`. PD suffers error accumulation because student becomes teacher next round.

### 3.3 TLA+ Spec for One-Step Convergence

```tla+
---------------- MODULE OneStepConsistency ----------------
EXTENDS Reals, Naturals
VARIABLES x, t, f, N
Init == x \in Noise /\ t = 1 /\ N = 1024
Next == \/ \E dt \in {0.5, 0.25, 0.125, 0.0}:
          t' = t - dt /\ x' = x + dt * v_theta(x,t)
     \/ f' = [xt \in DOMAIN |-> x0(x)]  \* consistency mapping
Spec == Init /\ [][Next]_<<x,t,f,N>> /\ WF_<<>>Next
Property OneStep == <>[](N=1 /\ f[x]=x0)  \* liveness: reaches 1 NFE
=============================================================
```

## 4 Deep Dive

### 4.1 Progressive Distillation Schedule and Halving Error

PD training [3] compresses `N` steps into `N/2`. Key insight: deterministic DDIM solver has `x_{t-1}=α_{t-1}/α_t x_t - σ_{t-1}(e^{h}-1) ε_θ`. Student approximates two compositions.

> **Lemma 4.1 (Halving Error Amplification):** *If each PD iteration introduces error η_k, total error after K=log2 N iterations satisfies `E_K ≤ Σ_{k=0}^{K-1} 2^{K-k-1} η_k` — exponential amplification.*

*Implication:* Late-stage PD (N small) dominates. This motivates *consistency* direct-to-1 rather than repeated halving.

| Iteration K | N teacher | N student | FID CIFAR-10 [3] | ΔFID |
|---|---|---|---|---|
| 0 | 1024 | — | 2.1 teacher | — |
| 1 | 1024→512 | 512 | 2.3 | +0.2 |
| 2 | 512→256 | 256 | 2.8 | +0.5 |
| 4 | 64→32 | 32 | 4.5 | +1.0 |
| 10 | 2→1 | 1 | 9.1 | catastrophic |

PD collapses at 1 NFE — need alternative [1].

```python
def progressive_distillation_loop(teacher, data, iterations=10):
    student = teacher
    N = 1024
    for k in range(iterations):
        # generate targets via 2 teacher steps
        dataset = []
        for x in data:
            t = np.random.uniform(0,1)
            x_t = forward_diffuse(x, t)
            x_t_half = teacher.step(x_t, t, dt=0.5/N)
            x_t_next = teacher.step(x_t_half, t-0.5/N, dt=0.5/N)
            dataset.append((x_t, t, x_t_next))
        student = train_student(student, dataset, loss='mse')
        teacher = student
        N //= 2
        if N==1: break
    return student
```

### 4.2 Flow Matching and Rectified Flow Transport

Lipman et al. [4] generalize to Conditional Flow Matching (CFM):

`L_CFM = E_{t,q(z),p_t(x|z)} || v_θ(x,t) - u_t(x|z) ||^2`

For OT path, `p_t(x|z)=N(x| t x1 + (1-t) x0, σ^2)` with small σ, `u_t = x1 - x0`. Rectified Flow [2] is special case `σ=0`.

> **Lemma 4.2 (Non-increasing transport cost):** *Rectification yields coupling (Z0,Z1) with convex cost `c` non-increasing: `E[c(Z1-Z0)]_reflow ≤ E[c(Z1-Z0)]_prev`.*

*Proof from [2]: Jensen + optimal coupling.*

| Path Type | Velocity target `u_t` | Path curvature `κ` | 1-step FID ImageNet |
|---|---|---|---|
| VP diffusion path | -σ̇ ∇ log p | high 0.78 | 15.2 |
| OT-CFM [4] | x1 - x0 + correction | 0.12 | 6.8 |
| Rectified 1-reflow [2] | x1 - x0 learned | 0.03 | 4.1 |
| Rectified 2-reflow | straightest | 0.01 | 3.9 |

Rectified flow achieves near-straight — *discretization-free* [2].

```python
# Flow Matching OT training (PyTorch-like)
def cfm_ot_loss(v_theta, x0, x1):
    t = torch.rand(x0.shape[0], 1, 1, 1)
    # OT interpolation
    xt = (1 - t) * x0 + t * x1
    ut = x1 - x0  # constant velocity for OT
    vt = v_theta(xt, t.squeeze())
    return ((vt - ut) ** 2).mean()
```

### 4.3 Consistency Fixed-Point Iteration

CMs [1] learn `f_θ: (x_t,t) → x_ε` satisfying self-consistency:

`f_θ(x_t,t) = f_θ(x_{t'}, t')  ∀ t,t' ∈ [ε,T]` on same ODE trajectory.

Boundary via Elucidating [5] trick:

`c_skip(t)= σ_data^2 / ((t-ε)^2 + σ_data^2)`, `c_out(t)= σ_data (t-ε)/√(σ_data^2 + t^2)`

> **Lemma 4.3 (Consistency preserves PF-ODE):** *If L_CD=0, then `f_θ` samples exactly from PF-ODE solution at t=ε, hence from data distribution convolved with N(0,ε^2).*

Consistency models support **multistep sampling**: chain `x → f_θ(x,T) → noise → f_θ`. Improves quality vs 1-step.

| Sampler | NFE | FID CIFAR-10 | FID ImageNet64 [1] |
|---|---|---|---|
| CD 1-step | 1 | 3.55 SOTA | 6.20 |
| CD 2-step | 2 | 2.93 | 4.70 |
| CT (standalone) | 1 | 5.83 | 9.20 |
| CT 2-step | 2 | 4.12 | 6.80 |

Distillation outperforms training from scratch [1] due to variance reduction via teacher.

```rust
// Consistency parameterization
fn consistency_param(x: Tensor, t: f32, eps: f32, f_theta: impl Fn(Tensor,f32)->Tensor) -> Tensor {
    let c_skip = sigma_data.powi(2) / ((t - eps).powi(2) + sigma_data.powi(2));
    let c_out = sigma_data * (t - eps) / (sigma_data.powi(2) + t.powi(2)).sqrt();
    c_skip * x + c_out * f_theta(x, t)
}
```

### 4.4 ODE Solver Error and Truncation Bounds

Karras et al. [5] analyze local truncation `τ_i = x*_i - x_i`. Euler first-order `τ_i = O(h^2)`, Heun second-order `τ_i = O(h^3)`, DPM-Solver-k `τ_i = O(h^{k+1})` [6]. Global error `||e_N|| ≤ E max_i ||τ_i||` where `E` depends on Lipschitz `L_θ` [5].

> **Lemma 4.4 (One-step collapse bound):** *For Euler with N=1, `h=T`, `E_T = O(T^2)`. For CM 1-step, error independent of h because map directly learned, bounded by L_CD.*

| Solver | Order k | Local error `||τ||` | NFE=10 FID | NFE=1 FID | Compute/NFE |
|---|---|---|---|---|---|
| Euler (DDIM) | 1 | Ch^2 | 12.4 | 30.2 fail | 1× |
| Heun (EDM) [5] | 2 | Ch^3 | 2.8 | 18.7 | 2× |
| DPM-Solver-2 [6] | 2 | Ch^3 exp integrator | 2.5 | 12.1 | 1.5× |
| DPM-Solver-3 | 3 | Ch^4 | 2.3 | 9.8 | 1.7× |
| Consistency [1] | ∞ learned | 0 by design | 2.93 (2-step) | 3.55 | 1× |

Heun reduces error vs Euler but still fails at N=1 — CM wins because it *learns* integral.

```python
def edm_heun_sampler(D_theta, x_T, ts):
    x = x_T
    for i in range(len(ts)-1):
        t, t_next = ts[i], ts[i+1]
        h = t_next - t
        # Euler predictor
        d = (x - D_theta(x, t)) / t
        x_next = x + h * d
        if t_next != 0:
            d_prime = (x_next - D_theta(x_next, t_next)) / t_next
            x_next = x + h * 0.5 * (d + d_prime)  # Heun corrector O(h^3)
        x = x_next
    return x
```

## 5 Empirical Evaluation

### Setup: SANA-Sprint hybrid [7] = sCM + LADD. Teacher = 20-step Flow-Matching DiT. Student = same architecture with LoRA rank 64, EMA 0.999. Dataset: ImageNet-1k + 40M aesthetic captioned images.

> **Theorem 5.1 (Hybrid Distillation Convergence):** *Under L-smoothness, sCM+LADD hybrid converges to stationary point with rate O(1/√K) where K distillation steps, with bias proportional to discriminator mismatch ε_GAN.*

| Model | NFE | FID COCO | GenEval ↑ | Latency H100 1024px | Params |
|---|---|---|---|---|
| FLUX-schnell [7] | 1* | 7.94 | 0.71 | 1.1s | 12B |
| SANA-Sprint sCM only | 1 | 8.12 | 0.70 | 0.10s | 1.6B |
| SANA-Sprint hybrid sCM+LADD | 1 | **7.59** | **0.74** | 0.10s | 1.6B |
| + 2 steps | 2 | 6.81 | 0.78 | 0.14s | 1.6B |
| + 4 steps | 4 | 5.94 | 0.80 | 0.22s | 1.6B |
| EDM Heun 20 steps [5] | 20 | 7.20 | — | 1.8s | 0.5B |
| Consistency Distill 1-step [1] (CIFAR) | 1 | 3.55 | — | — | 0.05B |

*1-step hybrid outperforms FLUX-schnell with 7.5× fewer params and 10× speedup [7].* DPM-Solver [6] still requires 10 NFE to reach FID 6.5 on same backbone.

```python
# Hybrid sCM + LADD step (simplified from SANA-Sprint [7])
for x0, caption in dataloader:
    t = sample_logit_normal()
    x_t = (1-t)*noise + t*x0
    v_teacher = teacher(x_t, t, caption)
    # sCM loss continuous-time
    f_student = c_skip(t)*x_t + c_out(t)*F_theta(x_t,t,caption)
    f_target = c_skip(t-0.01)*x_{t-0.01} + c_out(t-0.01)*F_ema(x_{t-0.01},...)
    loss_scm = lpips(f_student, f_target)
    # LADD adversarial
    fake = f_student
    loss_gan = -D(fake, caption).mean()
    loss = loss_scm + 0.1*loss_gan
    loss.backward()
```

## 6 Limitations

- **Teacher bias inheritance** [1]: CD students cannot surpass teacher if teacher ODE solver inaccurate; rectified reflow [2] mitigates by generating new couplings.
- **Mode shrinkage**: At 1 NFE, diversity (Recall) drops 0.52→0.44 vs 20-step. OT-CFM [4] preserves diversity better than PD.
- **Lipschitz blowup**: Consistency loss encourages large `L_f` near `t=ε`; spectral normalization needed [5].
- **High-resolution instability**: 1024px needs progressive growing + discriminator R1 penalty; pure sCM without LADD produces artifacts on text rendering [7].
- **Evaluation leakage**: FID underestimates 1-step errors on long-tail; GenEval [7] better but still prompt-sensitive.
- **Compute**: Rectified 2-reflow requires simulating 2× dataset (∼500k images) for flux-style models — expensive but amortized.

---

## 7 Conclusion

We unified **progressive distillation** [3], **consistency distillation** [1], and **rectified flow/flow matching** [2][4] as trajectory straightening operators. ODE analysis [5][6] shows traditional solvers bounded by `O(h^{k+1})` truncation — irrecoverable at N=1 — while learned maps bypass discretization. Hybrid sCM+LADD [7] achieves SOTA 1-step FID 7.59 with 0.1s latency, proving **consistency + rectification** is Pareto-optimal. Future work: causal consistency for video, speculative reflow for conditional control, tighter ELBOs via Fisher divergence [Zhou 2024].
