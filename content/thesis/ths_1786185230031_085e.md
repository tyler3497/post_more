## 6 Limitations

1. **Honest majority / benevolent scheduler:** Byzantine tolerance n≥3f+1 assumed [1]; rational adversaries degrade liveness not safety.
2. **Scope of formal model:** TLA+ checked N=4, real N=4096 needs parameterized induction [3]; not yet machine-checked.
3. **Constant-time side channels:** constant-time algorithms mitigate timing [3], power/EM telemetry [6] not modeled.
4. **Approximate learned models:** CDF ε-bound holds on trained distribution; drift invalidates bound, requires retraining O(n log n) [2][4].
5. **Hardware variance:** custom toolchain Lava; portability GPU limited.
6. **Quantum overhead:** surface code d=27 for 1e-12 logical error [1][5] demands d²=729 physical per logical, magic factories 15x blowup.
7. **Numeric stability:** CKKS approximate homomorphism 2^-40 loss per multiply; workloads needing bit-exact equality need TFHE switching [3][4].

Roadmap: integration qLDPC + lattice surgery [5][7], runtime recalibration width asymmetry [4], deterministic sideband QoS [6].
