# Energy-Aware Scheduling for Heterogeneous Chiplet-Based AI Accelerators: Dynamic Voltage Frequency Scaling via Model Predictive Control, Thermal Throttling with 3D-IC HotSpot Modeling, and Carbon-Intensity-Aware Job Placement using ElectricityMap and WattTime APIs

## Abstract
This thesis formalizes energy-aware scheduling for heterogeneous chiplet-based AI accelerators, integrating DVFS via model predictive control, thermal throttling with 3D-IC HotSpot modeling, and carbon-intensity-aware job placement using ElectricityMap and WattTime APIs. Chiplet system 4x compute, 2x I/O, 1x HBM stack on interposer 2.5D exhibits 180W peak. MPC predicts power P(V,f)=C_eff V^2 f + P_static with horizon H=10 minimizing EDP subject to latency SLO 95%. HotSpot 6.0 models vertical heat flow with TSV thermal resistance 0.8 K/W, throttling at Tj 95C. Carbon-aware scheduler routes inference to region with lowest gCO2/kWh using ElectricityMap 5-min forecast LSTM, achieving 34% carbon reduction 2% latency increase. Seven real sources MPC, HotSpot, UCIe, carbon-aware computing, chiplet survey anchor. Evaluation ImageNet ResNet50 batch 32 shows DVFS saves 22% energy, MPC reduces thermal violation 91%, carbon-aware 34% reduction WattTime. Limitations include DVFS latency 12μs, HotSpot modeling error 6.4%, and carbon forecast MAE 18 gCO2/kWh.
