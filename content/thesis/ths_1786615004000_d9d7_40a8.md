# Spatio-Temporal Graph Neural Forecasting of Multi-Variant Epidemic Waves via Evolving Dynamic Adjacency, Self-Exciting Hawkes Dynamics, and Differentiable SEIR-Compartment Coupling

## Abstract

We propose TGN-HEIR, a temporal graph neural architecture for county-level multi-variant epidemic forecasting unifying three modeling viewpoints: graph-level contagion via evolving adjacency from mobility flows, self-exciting Hawkes process for superspreader clustering, and compartmental SEIR physical prior as differentiable regularizer. Dynamic graph topology derived from SafeGraph/Meta movement 20M daily edges learned via continuous-time TGN with memory modules (GRU memory update) and time-encoding Fourier features per Rossi et al. 2020. Hawkes kernel λ_i(t)=μ_i+∑_{j} α_{ij} exp(-β_{ij}(t-t_j)) captures overdispersion k<0.2 observed in COVID-19 (SARS-CoV-2) where 20% events cause 80% transmission. SEIR coupling: TGN latent predicts β(t), σ(t), γ(t) per region-variant via MLP with ODE solver differentiable through dopri5 adjoint method, penalizing violation of compartment conservation via PINN loss. Evaluated on CDC line list 2.3M records 2020-2023 for Delta/Omicron/BA.5 multi-variant wave competition modelled as Lotka-Volterra competition on graph, achieving 18% lower MAE at 28-day horizon vs STGODE, DeepWalk-TEMP, and naive SEIR. Epidemiological insight: learned α_{ij} adjacency correlates 0.71 with airborne hub centrality; ablation removal of Hawkes raises peak timing error 2.4 days; second-wave anticipation improvement attributed to variant-specific cross-immunity edges learned.
