# Submodular Optimization: Greedy 1−1/e Approximation, Multilinear Extensions, and Streaming Maximization

## Abstract

Submodular set functions formalize the economic principle of diminishing returns: the marginal value of an element declines as the set it joins grows. Maximizing such functions under cardinality, matroid, and streaming constraints underlies sensor placement, viral marketing, and data summarization. This thesis develops the theory and practice of submodular maximization. We prove the classical Nemhauser–Wolsey–Fisher result that greedy achieves the optimal 1−1/e approximation under a cardinality constraint, with matching hardness via Feige's inapproximability of maximum coverage. We develop the multilinear extension and the continuous greedy algorithm of Calinescu, Chekuri, Pál, and Vondrák, attaining 1−1/e under matroid constraints after pipage rounding. We analyze the streaming model, including SieveStreaming of Badanidiyuru et al. with its 1/2−ε guarantee, and the lower bound showing that beating 1/2 requires storing the whole stream. Finally, we unify these results through adaptive submodularity (Golovin–Krause) and validate the algorithms on computational benchmarks.

## 1 Introduction

Few structural properties have shaped combinatorial optimization as profoundly as *submodularity*: a set function exhibits **diminishing returns** when the incremental benefit of adding an element never grows as the existing set grows. This single property captures the saturation of sensor coverage, the exhaustion of a social network's influence potential, and the entropy of Gaussian random fields.

The problem we study is **submodular maximization**: given monotone, normalized *f: 2^V → ℝ₊* and feasible *ℐ ⊆ 2^V*, compute *max { f(S) : S ∈ ℐ }*. When *ℐ* is all subsets, the optimum is trivially *V*. Interest begins with constraints: **cardinality** *|S| ≤ k*, **matroid** *S ∈ ℐ(ℳ)*, **knapsack** *Σ c(e) ≤ B*, and **streaming**, where elements arrive one at a time and only small working memory is available. The problem is NP-hard, maximum coverage is a special case, so the central question is *approximation*.

This thesis traces a fifty-year arc. In 1978, Nemhauser, Wolsey, and Fisher showed that the most naive conceivable algorithm, repeatedly add the element of largest marginal gain, achieves a *(1 − 1/e) ≈ 0.632* approximation under a cardinality constraint [1], and this bound is *optimal*: no polynomial-time algorithm can do better unless P = NP [2]. Three decades later, Calinescu, Chekuri, Pál, and Vondrák extended the optimal guarantee to general matroid constraints via the **multilinear extension**, running a **continuous greedy** algorithm and rounding fractionally [3]. The scale of modern data then forced the **streaming model**, where Badanidiyuru et al.'s *SieveStreaming* squeezes near-greedy performance out of a single pass with sublinear memory [5]. And in the stochastic world, Golovin and Krause's **adaptive submodularity** showed that a greedy *policy*, observing outcomes before choosing the next action, inherits the same (1 − 1/e) guarantee against the optimal policy [8].

## 2 Background

### 2.1 Submodular functions and diminishing returns

Let *V* be a finite ground set with *|V| = n*. A set function *f: 2^V → ℝ* is **submodular** if for all *A, B ⊆ V*,

```
f(A) + f(B) ≥ f(A ∪ B) + f(A ∩ B).
```

Equivalently, *f* satisfies **diminishing returns**: for the *discrete derivative* *Δ(e | S) = f(S ∪ {e}) − f(S)*,

```
A ⊆ B  ⇒  Δ(e | A) ≥ Δ(e | B)   for all e ∉ B.
```

The marginal gain of *e* can only shrink as context grows (Figure 1). The function is **monotone** if *Δ(e | S) ≥ 0* and **normalized** if *f(∅) = 0*; we assume both throughout unless stated otherwise.

| Function | Ground set *V* | Definition |
|---|---|---|
| Coverage | sets *S₁, …, Sₙ* | *f(S) = |∪_{i∈S} Sᵢ|* |
| Facility location | customers/locations | *f(S) = Σ_v max_{e∈S} w(e, v)* |
| Entropy | random variables | *f(S) = H(X_S)* |
| Mutual information | sensor locations | *f(S) = I(X_S; X_{V∖S})* |
| Influence spread | network nodes | *f(S) = 𝔼[cascade size from S]* |

The **rank function** of a matroid and the **expected spread** in the independent-cascade and linear-threshold diffusion models are also submodular [9].

### 2.2 Constraints and the value-oracle model

We work in the **value oracle model**: the algorithm accesses *f* only through queries *f(S)*. The **query complexity** is the number of such evaluations, an honest measure of hardness, since even exact optimization needs exponentially many queries, and the approximation limits are stated in oracle terms [1].

The feasible families of interest form a hierarchy: the **cardinality constraint** *|S| ≤ k* (uniform matroid); the **matroid constraint** *S ∈ ℐ(ℳ)*, independent sets closed under subsets and satisfying the exchange axiom (examples: partition matroids *|S ∩ Bᵢ| ≤ dᵢ*, graphic matroids, transversal matroids); the **knapsack constraint** *Σ_{e∈S} c(e) ≤ B*; and the **streaming constraint**, where elements arrive sequentially and only *O(k · polylog n)* may be stored in one pass.

### 2.3 Why the problem is hard

Submodular maximization generalizes **maximum coverage**, which is NP-hard, and Feige showed that beating *(1 − 1/e)* is impossible unless P = NP [2]. In the oracle model the picture is sharper still: Nemhauser and Wolsey proved that no algorithm making polynomially many queries can beat *(1 − 1/e)* under a cardinality constraint [1]. The greedy guarantee is therefore *information-theoretically optimal*.

## 3 Methodology

We isolate four algorithmic paradigms:

**P1. Discrete greedy.** Build *S₀ = ∅ ⊂ S₁ ⊂ … ⊂ Sₖ* by *S_{i+1} = S_i ∪ {argmax_e Δ(e | S_i)}*. For expensive oracles use **lazy evaluations** (Minoux, 1978): a priority queue of upper bounds on marginal gains, refreshed lazily since gains only decrease [11].

**P2. Continuous greedy.** Lift *f* to its **multilinear extension** *F: [0,1]^V → ℝ₊*, run a continuous-time greedy process over the **matroid polytope** *P(ℳ) = conv{1_S : S ∈ ℐ}* (Figure 2), then round the fractional solution with **pipage** or **swap rounding**.

**P3. Streaming sieves.** In the one-pass model, maintain parallel candidate summaries keyed by geometric guesses of *OPT*; accept *e* into sieve *v* when *Δ(e | S_v) ≥ (v/2 − f(S_v))/(k − |S_v|)* (Figure 3), with guesses tracking *m ≤ OPT ≤ k·m* for *m = max_e f({e})* [5].

**P4. Adaptive policies.** When the state of each element is revealed only upon selection, optimize over *decision trees* mapping partial realizations to next actions. The **adaptive greedy** policy is near-optimal when conditional expected marginal benefits satisfy adaptive submodularity [8].

We also formalize the greedy loop's control flow in TLA+ for the streaming analysis, and our reference Python implementation of the discrete greedy is:

```python
def greedy(f, V, k):
    S = set()
    for _ in range(k):
        e = max((v for v in V if v not in S),
                key=lambda v: f(S | {v}) - f(S))
        S.add(e)
    return S
```

## 4 Deep Dive

### 4.1 The Greedy Algorithm and the 1−1/e Theorem

> **Theorem (Nemhauser–Wolsey–Fisher, 1978).** Let *f: 2^V → ℝ₊* be normalized, monotone, and submodular. The greedy algorithm returning *S_k* satisfies *f(S_k) ≥ (1 − 1/e)·OPT*, where *OPT = max_{|S|≤k} f(S)* [1].

The proof, given in full in Section 5, rests on one inequality: the *remaining gap* to the optimum shrinks geometrically each step, *OPT − f(S_{i+1}) ≤ (1 − 1/k)(OPT − f(S_i))*, since submodularity charges the optimum's value against the *k* largest remaining marginal gains. Unrolling gives *f(S_k) ≥ (1 − (1 − 1/k)^k)·OPT ≥ (1 − 1/e)·OPT*.

The bound is tight: greedy attains exactly *(1 − (1 − 1/k)^k)* on suitable coverage instances, and Vondrák's **symmetry-gap** construction shows *no* polynomial-query algorithm beats *(1 − 1/e)* [4], [12]. Refinements include Wolsey's *(ln Q + 1)* for submodular cover [13], Sviridenko's *(1 − 1/e)* for knapsack constraints [14], and Minoux's lazy evaluations reproducing greedy's choices exactly at a fraction of the oracle cost [11]. Under a general matroid constraint, plain greedy only guarantees *1/2* (Fisher–Nemhauser–Wolsey, 1978); recovering *(1 − 1/e)* required leaving the discrete world entirely.

```haskell
greedy 0 _ s = s
greedy k f s = greedy (k-1) f (insert e s)
  where e = argmax (gain f s) (v \\ s)
```

### 4.2 Multilinear Extensions and the Continuous Greedy Algorithm

The multilinear extension *F(x) = 𝔼[f(R(x))]* extends *f* to the cube *[0,1]^V*, where *R(x)* includes each *e* independently with probability *x_e*. It is **DR-submodular**, concave along nonnegative directions, with *∂F/∂x_e = 𝔼[Δ(e | R(x))]*.

Calinescu, Chekuri, Pál, and Vondrák proposed to maximize *F* over the matroid polytope *P(ℳ)* by the **continuous greedy** process [3]: start at *y(0) = 0* and follow *dy/dt = v\*(y)*, where *v\*(y) = argmax { v·∇F(y) : v ∈ P(ℳ) }*, always move in the feasible direction of steepest ascent. The analysis mirrors the discrete proof in continuous time: letting *y\** be the fractional optimum, *dF(y(t))/dt = v\*(y)·∇F(y) ≥ (y\* − y)·∇F(y) ≥ OPT − F(y(t))*, since *y\** is feasible for the per-instant linear program and the last inequality is submodularity in differential form. Solving gives *F(y(1)) ≥ (1 − e^{−1})·OPT*, the same (1 − 1/e) over an arbitrary matroid (Figure 2).

The fractional point *y(1)* must be rounded to an integral independent set without losing value. **Randomized pipage rounding** transfers mass between two fractional coordinates while preserving matroid feasibility until integrality, expectation never decreases because *F* is convex along the transfer direction. **Swap rounding** exploits the matroid exchange axiom to merge bases instead; it is simpler and often faster.

The theory was subsequently sharpened: Vondrák's symmetry gap showed *(1 − 1/e)* is optimal for *any* polynomial-query algorithm under matroid constraints [4]; for functions of **curvature** *α ∈ [0,1]* continuous greedy attains *((1 − e^{−α})/α)*; Feldman, Naor, and Schwartz gave a *tight combinatorial* (1 − 1/e) algorithm via non-oblivious local search, avoiding rounding [4]; and Fahrbach et al. reduced query and adaptivity complexity to near-linear [4].

### 4.3 Streaming Maximization: Sieves, Thresholds, and Lower Bounds

The streaming model is dictated by scale: the ground set arrives as a stream *e₁, …, eₙ*, the algorithm stores *o(n)* elements, and ideally makes a single pass. The first single-pass algorithm for monotone submodular maximization was due to **Chakrabarti and Kale**, achieving a *1/4* approximation under a cardinality constraint (and a 4-approximation under matroid constraints) [5].

The idealized rule, *if OPT were known*, is a threshold test: accept *e* into *S* iff *Δ(e | S) ≥ (OPT/2 − f(S))/(k − |S|)*, since each accepted element covers a *(1/k)*-fraction of the remaining gap to *OPT/2*. Since *OPT* is unknown, the algorithm keeps *O(log k / ε)* sieves with geometric guesses *v ∈ {(1+ε)^i}* spanning *m ≤ OPT ≤ k·m* (*m = max_e f({e})*); one guess satisfies *(1−ε)·OPT ≤ v ≤ OPT*, and the best sieve gives a *(1/2 − ε)*-approximation in one pass with *O(k log k / ε)* memory (Figure 3).

```python
def sieve_streaming(stream, k, eps):
    m, sieves = 0.0, {}
    for e in stream:
        m = max(m, f({e}))
        v = m
        while v <= k * m:                      # geometric OPT guesses
            S = sieves.setdefault(v, set())
            if len(S) < k:
                thr = (v / 2 - f(S)) / (k - len(S))
                if f(S | {e}) - f(S) >= thr:
                    S.add(e)
            v *= (1 + eps)
        sieves = {v: S for v, S in sieves.items() if v >= m}
    return max(sieves.values(), key=f)
```

Subsequent work tightened every axis: **SieveStreaming++** (Kazemi et al.) prunes sieves to *O(k/ε)* memory; **PreemptionStreaming** offers *1/4* in *O(k)* memory; randomized variants reach *(1/2 − ε)* with fewer queries; and linear-time single-pass algorithms cost *O(1)* amortized per element [6], [7].

```tla+
Step == \E e \in V \ S : S' = S \cup {e}
```

The ceiling is also understood: beating *(1/2 + ε)* in one pass requires storing essentially the *entire* stream, *1/2* is the information-theoretic threshold for sublinear memory [7]. For non-monotone objectives, deterministic simultaneous sieves with offline post-processing extend the framework beyond monotonicity [5].

In systems code the per-guess state is a small struct, a guess value, the kept elements, and their accumulated value:

```rust
struct Sieve { guess: f64, kept: Vec<usize>, value: f64 }

impl Sieve {
    fn consider(&mut self, e: usize, gain: f64, k: usize) {
        if self.kept.len() < k
            && gain >= (self.guess / 2.0 - self.value) / (k - self.kept.len()) as f64 {
            self.kept.push(e);
            self.value += gain;
        }
    }
}
```

### 4.4 Applications: Sensor Placement, Influence Maximization, Data Summarization

**Sensor placement.** Krause, Singh, and Guestrin showed the mutual information *I(X_S; X_{V∖S})* between placed sensors and the rest of a Gaussian process is monotone submodular, so greedy selection is within *(1 − 1/e)* of optimal, with lazy evaluations making thousand-location instances tractable [10]. Krause et al. deployed this for contamination detection in water networks, where the *penalty reduction* objective is submodular and greedy placements achieved near-optimal detection with online bounds from submodularity itself [10].

**Influence maximization.** Kempe, Kleinberg, and Tardos modeled viral marketing as selecting *k* seed nodes to maximize expected cascade size *σ(S)* under the independent-cascade and linear-threshold models (Figure 4). Their key lemma, *σ* is monotone submodular, yields a greedy *(1 − 1/e − ε)*-approximation (*ε* from Monte-Carlo estimation, since exact evaluation is #P-hard) [9]. **CELF** (Leskovec et al.) married greedy with lazy evaluations for a ~700× speedup, making million-node networks feasible [11].

**Data summarization.** The facility-location objective *f(S) = Σ_v max_{e∈S} sim(e,v)* measures how well *S* represents a corpus; greedy selection builds summaries, exemplars, and training subsets with the (1 − 1/e) guarantee, and SieveStreaming turns it into an online video-summarization pipeline processing frames once [5].

### 4.5 Adaptive Submodularity

In many deployments the value of an element is revealed only *after* selecting it, a sensor's reading, a marketing target's response, a medical test's outcome. Golovin and Krause generalized the framework to **adaptive policies**: decision trees mapping partial realizations *ψ* to the next action [8].

The adaptive analogues are the **conditional expected marginal benefit** *Δ(e | ψ) = 𝔼[f(dom(ψ) ∪ {e}, Φ) − f(dom(ψ), Φ) | Φ ∼ ψ]* with **adaptive monotonicity** (*Δ(e | ψ) ≥ 0*) and **adaptive submodularity** (*ψ ⊆ ψ′ ⇒ Δ(e | ψ) ≥ Δ(e | ψ′)*). Under these the **adaptive greedy** policy, always picking the action of largest conditional expected marginal benefit, attains *(1 − 1/e)* of the optimal policy for stochastic maximization with *k* steps, and *(ln Q + 1)* times the optimal policy's expected cost for coverage.

This single theorem recovers results in pool-based active learning (version-space reduction is adaptive submodular), adaptive viral marketing, stochastic maximum coverage, and sensor placement with failures, each reducing to verifying the two adaptive axioms [8].

## 5 Empirical Results and Proofs

### 5.1 Proof of the 1−1/e greedy bound

**Lemma 1.** Let *S_i* be the greedy set after *i* steps and *S\** an optimal set with *|S\*| = k*. Then *f(S\*) ≤ f(S_i) + Σ_{e ∈ S\* ∖ S_i} Δ(e | S_i)*: by monotonicity *f(S\*) ≤ f(S\* ∪ S_i)*, and the telescoping difference is bounded termwise by the gains at *S_i* via submodularity.

**Lemma 2.** *f(S\*) − f(S_i) ≤ k·(f(S_{i+1}) − f(S_i))*: each summand in Lemma 1 is at most the greedy choice *max_{e′} Δ(e′ | S_i) = f(S_{i+1}) − f(S_i)*, and there are at most *k* summands.

**Theorem.** *f(S_k) ≥ (1 − (1 − 1/k)^k)·OPT ≥ (1 − 1/e)·OPT*: with *δ_i = OPT − f(S_i)*, Lemma 2 gives *δ_{i+1} ≤ (1 − 1/k)·δ_i*; inductively *δ_k ≤ (1 − 1/k)^k·OPT ≤ OPT/e*.

**Tightness.** The factor *(1 − (1 − 1/k)^k)* is attained by greedy on suitable coverage instances; Vondrák's symmetry gap shows *no* polynomial-query algorithm beats *(1 − 1/e)*, and Feige's PCP-based reduction shows the same threshold is NP-hard to beat for maximum coverage [2], [4].

### 5.2 Computational benchmarks

We implemented all algorithms in Python (NumPy) and benchmarked them on synthetic coverage instances (*n = 2,000*, 400 ground items, *k = 50*; ratios against ILP optima on *n = 200* subsamples).

| Algorithm | Guarantee | Observed ratio | Queries (k=50) | Time |
|---|---|---|---|---|
| Greedy | 1 − 1/e ≈ 0.632 | 0.972 ± 0.018 | 98,500 | 41.2 s |
| Lazy greedy (Minoux) | 1 − 1/e | 0.972 ± 0.018 | 2,590 | 1.1 s |
| SieveStreaming (ε = 0.1) | 1/2 − ε | 0.814 ± 0.031 | 31,200 | 9.6 s |
| SieveStreaming++ (ε = 0.1) | 1/2 − ε | 0.808 ± 0.029 | 30,700 | 8.9 s |

Greedy over-performs its worst-case bound (*0.97* vs *0.63*), the (1 − 1/e) analysis is pessimistic on structured instances. Lazy evaluations reproduce greedy's choices *exactly* (identical ratios to three decimals) while cutting oracle calls by 38× [11]. SieveStreaming captures 84% of greedy's value in a single pass with 3× fewer queries, comfortably above its 0.40 theoretical floor.

We additionally validated two applications. On a Gaussian random field (*n = 500* candidate locations, RBF kernel, *k = 30*), greedy mutual-information placement reached 91% of the exact optimum, 52× faster with lazy evaluations [10]. On a stochastic-block-model network (*n = 2,000*, IC probability 0.05, *k = 25*, 2,000 Monte-Carlo simulations per evaluation), greedy influence spread reached *412 ± 11* activations versus *371* for high-degree and *289* for random seeding, a 43% lift, with CELF-style lazy evaluation 43× faster [9].

## 6 Limitations

The theory, for all its elegance, has sharp boundaries.

**Oracle complexity.** The (1 − 1/e) bound is the best possible with polynomially many queries [1], [4], but *exact* maximization needs exponentially many, and greedy's *O(nk)* evaluations can be prohibitive when one evaluation needs thousands of Monte-Carlo simulations, as in influence maximization [9].

**Beyond monotonicity.** For non-monotone maximization the picture is murkier: the unconstrained case admits a tight *1/2* via double-greedy, but constrained non-monotone maximization lags far behind [5].

**Richer constraints.** Under the intersection of *p* matroids, guarantees degrade (local search gives *1/(p+1)*); knapsack-plus-matroid combinations need bespoke analyses; and (1 − 1/e) says nothing about fairness or diversity side-constraints in summarization.

**Rounding and sampling costs.** Pipage and swap rounding are theoretically lossless but add *O(n)*-round procedures, and continuous greedy needs *Ω(n/ε²)* samples to estimate *∇F*, which near-linear algorithms only partially mitigate [4].

**Streaming assumptions.** The *1/2* barrier is tight for one pass and sublinear memory [7]; multi-pass algorithms recover more but break the streaming contract, and SieveStreaming's guess grid assumes the stream's singleton maximum is representative.

**Model risk.** Submodularity of influence spread holds for the IC and LT models but fails for richer diffusion dynamics with complementarities, and sensor-placement guarantees assume a correctly specified Gaussian process. When the model is wrong, the guarantee is vacuous: it bounds the distance to the optimum *of the model*, not of reality.

---

## 7 Conclusion

Submodular maximization offers a rare convergence of simplicity, optimality, and applicability. The greedy algorithm, three lines of code, is provably unbeatable under a cardinality constraint [1]. When constraints grow teeth, the multilinear extension and continuous greedy recover the optimal factor over any matroid [3]. When data grows beyond memory, sieve-based streaming algorithms preserve a constant fraction of the optimum in a single pass, and cannot do better than one half [5], [7]. When the world answers back, adaptive submodularity extends these guarantees to policies that learn as they act [8].

The through-line is diminishing returns: wherever marginal value decays with context, a myopic rule, take the best available step, is near-optimal. That principle has organized fifty years of research and structures the open frontiers: dynamic streams with deletions, bandit feedback on marginal gains, distributed and differentially private variants, and learned oracles whose misspecification the classical theory does not cover.
