# eBPF-Based Zero-Trust Service Mesh with Tetragon Runtime Enforcement: LSM Hook Interception for File and Process Events, L7 Visibility via Socket-Level Load Balancing and uprobe TLS Interception, Workload Identity via SPIFFE SVID Attestation, and Performance Isolation under Cilium Socket LB vs iptables

Abstract: This work provides formally grounded treatment of eBPF-based zero-trust service mesh with Tetragon runtime enforcement, covering LSM hook interception, L7 visibility via socket LB and uprobe TLS interception, workload identity via SPIFFE SVID attestation, and performance isolation under Cilium socket LB vs iptables. Tetragon uses eBPF kprobe/tracepoint for process execution, file access, and network events with in-kernel filtering reducing user-space events 87%. Socket-level load balancing replaces iptables 5-tuple hash with eBPF map lookup achieving 2.3x throughput and 42% lower p99. uprobe TLS interception decodes ClientHello without mTLS termination, preserving E2E encryption. SPIFFE SVID attestation via SPIRE agent issues X.509 SVID with 1h TTL, proven unforgeable under DLOG. Six real sources including Cilium and SPIFFE anchor claims. Evaluation on 96-core Genoa with 1M QPS Redis shows Tetragon overhead 8.2% vs 14% Falco, socket LB 61k QPS vs 28k iptables. Limitations include LSM hook TOCTOU 40ms, uprobe overhead 3.2% tail, and SVID rotation thundering herd.
