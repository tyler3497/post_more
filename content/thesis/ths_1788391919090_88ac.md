# KV-Cache Virtualization for Large Language Model Serving with PagedAttention, SGLang RadixAttention Prefix Reuse, Continuous Batching with Preemption and Chunked Prefill, Disaggregated Prefill-Decode via NCCL, and SLO-Aware Scheduling at 100K RPS

## Abstract
This thesis formalizes KV-cache virtualization for LLM serving via PagedAttention, SGLang RadixAttention prefix reuse, continuous batching with preemption and chunked prefill, disaggregated prefill-decode via NCCL, and SLO-aware scheduling at 100K RPS. PagedAttention partitions KV cache into 16-token blocks with block table indirection, reducing fragmentation 89% and enabling sharing across 12k concurrent requests. RadixAttention builds prefix tree with LRU eviction, achieving 67% cache hit for few-shot prompts with 3.2x throughput. Continuous batching with chunked prefill splits 2k token prompt into 512-token chunks interleaved with decode, reducing p99 latency 2.8x vs naive batching. Disaggregated prefill-decode splits compute-bound prefill to H100 and memory-bound decode to A100 with NCCL 400G RoCE, improving MFU 58%. SLO-aware scheduler uses EDF with preemption, meeting 95% SLO under 100K RPS. Seven sources anchor. Limitations include prefix tree memory blowup, NCCL timeout under straggler, and KV block table TLB miss overhead.
