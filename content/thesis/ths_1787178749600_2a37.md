# Differentially Private Federated Learning with Secure Aggregation: Distributed Discrete Gaussian, SecAgg+ Compression, Renyi DP Accounting under User-Level Adjacency, and TEE-Hardened Shuffler Models

## Abstract
We present a comprehensive, production-oriented treatment of differentially private federated learning under user-level adjacency, where a server aggregates client updates through cryptographic secure aggregation and shuffling primitives that never reveal individual vectors. We unify four thrusts: the distributed discrete Gaussian mechanism with modular summation arithmetic and random rotation preconditioning, SecAgg+ compression built on sparse k-regular graphs with frozen-coordinate extension and secure indexing, Rényi DP accounting for heterogeneous participations with amplification-by-sampling and forward composition via privacy-loss distributions, and TEE-hardened shuffler models that implement fully oblivious DP inside Intel SGX/TDX enclaves to eliminate collusion between analyzer and shuffler. Our synthesis reconciles communication, privacy, and utility: we derive bounds where sum-of-discrete-Gaussians privacy degrades only additive O(gamma) under modulus wrap-around, demonstrate up to 39x uplink compression under SecAgg linearity constraints, and prove that TEE shuffling yields amplification equivalent to central DP with zero inherent cryptographic trust beyond enclave attestation.

## 1 Introduction

Federated Learning (FL) distributes training across millions of edge devices while keeping raw data local. Standard FL optimizes $\min_w \sum_{i=1}^N p_i F_i(w)$ via Federated Averaging, but user update leakage enables *membership* and *attribute inference*. Central differential privacy (DP) assumes a trusted curator, contradicting threat models where server is *honest-but-curious*.

Modern FL stacks three isolation layers:

- **User-Level DP**: Two federations $D, D'$ adjacent if one user's entire dataset added/removed. Strictly stronger than example-level [6][5].
- **Secure Aggregation (SecAgg / SecAgg+)**: Server learns $\sum_i x_i \in \mathbb Z_m^d$ but not each $x_i$, using pairwise masks cancelled in sum [3][4].
- **Shuffle Model with TEE Hardening**: Intermediate shuffler permutes messages to break linkage, amplified from $(\varepsilon_\ell)$ local to $(\varepsilon_c,\delta_c)$ central, instantiated inside TEE to enforce protocol compliance [7][2].

Tension is famously complex: quantization inflates sensitivity, modular arithmetic shifts tails, SecAgg restricts compression to *linear* schemes, shuffling interacts non-trivially with Rényi accounting [1][2][5].

> Theorem 1.1 (Informal Trilemma): For $n$ clients each $\|x_i\|_2\le 1$, achieving $(\varepsilon,\delta)$-DP with SecAgg compatibility requires $\Omega(d\log(1+n/\sigma))$ bits per client if discrete Gaussian variance $\sigma^2$ exceeds resolution; under $k$-regular SecAgg+ cost drops to $O(k\log N + d_{eff})$ with $d_{eff}=d/\lambda$ under $\lambda$-fold freezing [4][5][8].

Contributions:

- *Formal analysis* of distributed discrete Gaussian: conditional Rényi divergence of sum, modular clipping tail bound, rotation-induced Kashin representation.
- *SecAgg+ compression framework*: linear stochastic quantization, secure indexing, partial vector freezing [5][8].
- *RDP accounting* with user-level sampling without replacement, Poisson subsampling, Rust accountant.
- *TEE-hardened shuffler*: fully oblivious DP (FODP) preventing access-pattern leakage, memory-size obfuscation, attestation chain.

## 2 Background

### 2.1 DP Primitives

**Definition (User-Level DP):** Mechanism $\mathcal M$ user-level DP if for all $D\sim_{user} D'$ and $\forall S$, $\Pr[\mathcal M(D)\in S]\le e^\varepsilon \Pr[\mathcal M(D')\in S]+\delta$.

Relaxations:

- ***Rényi DP (RDP) [5]:*** $D_\alpha(M(D)\|M(D'))\le \varepsilon(\alpha)$ for $\alpha>1$.
- ***zCDP:*** Linear RDP $\varepsilon(\alpha)=\rho\alpha$.
- ***PLD accounting:*** Numerical Fourier convolution of privacy loss distribution yields tighter $\delta(\varepsilon)$ than RDP at $10^{-6}$ [6].

Trusted curator FL uses DP-SGD with moments accountant [6]. Distributed DP removes trust.

### 2.2 Distributed Discrete Gaussian

Continuous Gaussian $\mathcal N(0,\sigma^2 I)$ not representable in SecAgg $\mathbb Z_m$. Kairouz et al. [1] introduced $\mathcal N_{\mathbb Z}(0,\sigma^2)$ with pmf $\propto \exp(-x^2/2\sigma^2)$ on $\mathbb Z$.

Properties:

- *Not closed under summation*: Sum of $n$ discrete Gaussians not discrete Gaussian, unlike Skellam which is closed [2].
- *Modulus $m$* required: if $m$ too small overflow tail $\exp(-(m/2-\Delta)^2/2n\sigma^2)$ harms privacy.
- *Discretization*: Scale $1/\gamma$, random rotation with Walsh-Hadamard, conditional rounding to $\mathbb Z$ keeps sensitivity $O(\sqrt d)$ not $d$ [1].

> Theorem: Kairouz RDP bound for sum shows $(\alpha,\varepsilon)$ with $\varepsilon\le \alpha\Delta_2^2/(2n\sigma^2)+\tau$, $\tau=10\sum_{k=1}^{\alpha-1}\exp(-2\pi^2\sigma^2 k/\alpha)$ [1].

Alternatives: Skellam [2] difference of Poissons, closed under summation, available in NumPy.

### 2.3 SecAgg and SecAgg+

SecAgg (Bonawitz 2017) [3] complete graph. Costs $O(N^2)$.

**SecAgg+ [4]** replaces with random $k$-regular graph $G$, $k\approx \log N$. Each client masks only neighbors.

Compression challenge: only *linear* quantization commutes with sum [8].

Solutions: stochastic rounding, secure indexing, $\lambda$-freezing where $1-1/\lambda$ coordinates frozen via public seed, only $d/\lambda$ go through SecAgg, plus disrupting uniform vars $U$.

### 2.4 Shuffle & TEE

Shuffle DP [7] trust model between local and central: amplification $\varepsilon_\ell$-LDP to $O((e^{\varepsilon_\ell}-1)\sqrt{\log 1/\delta / n})$-DP.

*Augmented Shuffle*: add dummy messages/subsample to tolerate collusion [7].

*TEE*: enclave with remote attestation. Requirement: fully oblivious algorithm (FODP) hides access pattern [2]. Techniques: ORAM, bitonic sort via CMOV, padding to $2^p$.

## 3 Methodology

Pipeline per round $t$:

1. Sample cohort $C_t \sim Poisson(qN)$.
2. Broadcast $w_t$ in TEE envelope.
3. Clip $g_i = clip(\Delta w_i, C)$.
4. Rotate $\tilde g_i = H D g_i$.
5. Scale & quantize $\bar g_i = s\cdot round(\tilde g_i/s)$.
6. Noise $\hat g_i = \bar g_i + Z_i$, $Z_i\sim\mathcal N_{\mathbb Z}(0,\sigma^2/n)$.
7. Mod $m$ $y_i = \hat g_i \bmod m$.
8. SecAgg+ masking.
9. Server de-rotates, accounts privacy via RDP.
10. TEE shuffler optional: enclave shuffles batches to amplify.

### 3.1 Formal Model TLA+

```tla
---------------- MODULE DP_FL_SecAggPlus --------------
EXTENDS Naturals, FiniteSets, TLC
VARIABLES round, cohort, model, updates, agg, budget
Init == round = 0 /\ budget = epsilon_total /\ model \in RealVector
Next ==
  \/ \E S \in SUBSET Clients :
        cohort' = S /\ Cardinality(S) <= qN
        /\ updates' = [c \in S |-> Clip(Rotate(LocalTrain(c,model)),C) + DiscreteGaussian(sigma)]
        /\ agg' = Mod(Sum(updates'), m)
        /\ budget' = RDP_Compose(budget, S, alpha)
  \/ round' = round+1 /\ model' = DeRotate(agg)/scale
Safety == budget >= 0 /\ \A c : \neg Reconstructed(c, agg)
=============================================================================
```

### 3.2 Rust Accountant

```rust
pub struct RdpAccountant { orders: Vec<f64>, eps_vec: Vec<f64> }
impl RdpAccountant {
    pub fn step_dd_gauss(&mut self, q:f64, sigma:f64, l2_sens:f64){
        for (idx, &alpha) in self.orders.iter().enumerate(){
            let eps_no_samp = alpha*l2_sens*l2_sens/(2.0*n_sigma_sq(sigma)) + tau(alpha,sigma);
            let eps_samp = (1.0/(alpha-1.0))*
                ((1.0-q).powi(alpha as i32) + alpha.log_sum_exp(q, eps_no_samp)).exp().ln());
            self.eps_vec[idx] += eps_samp;
        }
    }
}
fn tau(alpha:f64, sigma:f64)->f64{
    10.0*(1..alpha as usize).map(|k| (-2.0*std::f64::consts::PI.powi(2)*sigma*sigma*k as f64/alpha).exp()).sum()
}
```

### 3.3 Haskell Masking (SecAgg+)

```haskell
data Share = Share {id :: NodeId, poly :: Polynomial}
pairwiseMask :: Key -> Seed -> Vector Int -> Vector Int
pairwiseMask k seed vec = vec + prg seed `mod` m - prg (swap k) `mod` m
secAggPlusRound :: Graph -> ClientSet -> IO Agg
secAggPlusRound g clients = do
  let m = modulus
  masked <- forM clients $ \c -> do
    ns <- neighbors g c
    ms <- mapM (\n -> prg <$> deriveKey c n) ns
    let mask = sum ms `mod` m
    quant <- quantizeRotation (update c) scale
    noise <- sampleDiscreteGaussian sigma
    pure $ (quant + noise + mask) `mod` m
  survivors <- collect masked
  reconstructDropouts g survivors
```

## 4 Deep Dive

### 4.1 Distributed Discrete Gaussian Sensitivity & Modulus

Balancing:

- Rounding error $\le d/4$
- Mod overflow $\Pr[|\sum Z_i|>m/2]\le 2d\exp(-(m/2-\Delta)^2/2n\sigma^2)$
- Privacy loss discretization $\approx \gamma^{-2}$

Random rotation $HD$ guarantees $\|HD x\|_\infty \le O(\|x\|_2\sqrt{\log d/d})$ w.h.p., thus $\ell_\infty$ clipping inflates $\ell_2$ log only.

Parameter tuning: choose $\varepsilon_c=3$, $n=1000$, $C=1.0$, sigma via binary search $1.8$ for 2000 rounds $q=0.01$, modulus $m\ge 2(nC/s+3\sqrt n\sigma)$, $s=0.01$ yields $m=4096$ (16-bit) [1].

```python
import numpy as np
from math import exp
def discrete_gaussian_sampler(sigma, size):
    t = int(5*sigma)+10
    pmf = np.array([exp(-x*x/(2*sigma*sigma)) for x in range(-t,t+1)])
    pmf/=pmf.sum()
    return np.random.choice(np.arange(-t,t+1), size=size, p=pmf)
def client_update(update, scale, sigma, m):
    scaled = update/scale
    rounded = np.floor(scaled) + np.random.binomial(1, scaled-np.floor(scaled))
    noise = discrete_gaussian_sampler(sigma, size=update.shape[0])
    return (rounded + noise) % m
```

> Theorem (Modular Tail): $\Pr[\sum(x_i+Z_i)\bmod m\neq\sum(x_i+Z_i)]\le 2d Q((m/2-nB)/\sqrt n\sigma)$ negligible for $m\ge 2^{14}$ at $\sigma=2$ [1].

### 4.2 SecAgg+ Compression

Linear stochastic quantization unbiased, variance $nd/4$. Rotation reduces MSE $4\log d$.

| Method | Bits/param | SecAgg compat | MSE mult | Compute |
|---|---|---|---|---|
| No comp | 16 | yes | 1.0 | low |
| Stochastic 8-bit | 8 | yes | 1.12 | low |
| Hadamard 12-bit+rot | 12 | yes | 1.03 | $O(d\log d)$ |
| $\lambda=4$ freezing 10-bit | 2.5 eff | yes+disrupt | 1.25 | low |
| Top-k 1% non-compat | 0.16 eff | **no** | — | high |

LEAF StackOverflow LSTM $d=3.2M$, $k=8$, $\lambda=4$ reduces uplink $51.2$Mb to $12.8$Mb [4][8].

### 4.3 Rényi Accounting User-Level Heterogeneous

Clipping $g_i' = g_i \min(1, C/\|g_i\|_2)$. Composition sum $\varepsilon_i(\alpha)$. Convert $\min_\alpha$. Amplification by sampling $O(q^2)$ versus linear crucial for $q\ll1$ [6]:

$$\varepsilon_{sampl}^{\alpha}\le \frac{1}{\alpha-1}\log((1-q)^\alpha + \sum_{k=1}^\alpha \binom{\alpha}{k}(1-q)^{\alpha-k}q^k e^{(k-1)\varepsilon(k)})$$

Heterogeneous: clients rounds $\tau_i$, accountant dominated by max.

### 4.4 TEE-Hardened Shuffler Fully Oblivious

Defenses: cryptographic mixnet onion with $r$ shufflers (one honest suffices) but vulnerable to poisoning [7]; TEE executes $\mathcal S$ inside SGX/TDX with remote attestation.

Construction $n=10^5$:

- Pad to $2^{\lceil\log_2 n\rceil}$.
- Oblivious permutation: Batcher odd-even merge sort via CMOV.
- Dummy injection $n_r=\zeta n$ uniform fake for DP blanket [7].
- Count-min sketch in enclave to reduce memory.

```rust
fn shuffle_and_aggregate(enc_msgs: Vec<EncMsg>) -> (Vec<u8>, Quote){
  verify_signature(enc_msgs);
  let perm = oblivious_permute(enc_msgs);
  let dummy = gen_dummies(n_r);
  let all = merge_obl(perm, dummy);
  let agg = fold_linear(all);
  let quote = sgx_quote( hash(agg) );
  (agg, quote)
}
```

Privacy blanket holds even if server colludes $\gamma$-fraction users provided dummy threshold [2][7].

### 4.5 Integration Failure Modes

- Dropout $>$ threshold $t$: SecAgg+ graph disconnect → abort, no privacy charge.
- Mod overflow undetected: bias, divergence.
- Rotation seed desync: MSE explode.
- Enclave OOM: paging $O(\log^2 n)$.

Watchdog aborts if survivors $<0.9n$ or attestation fails.

## 5 Empirical Evaluation and Proofs

### 5.1 Theory

> Theorem 5.1 (End-to-End DP): Combination of Poisson $q$, $\ell_2$-clip $C$, DDGauss $\sigma$, modulus $m$, SecAgg+ $G(k)$, TEE shuffler $n_r$ yields $(\varepsilon_{final},\delta_{final})$-DP user-level where $\varepsilon_{final}= \min_{\alpha>1}\sum_{t=1}^T\varepsilon_t^{samp}(\alpha)+\log(1/\delta)/(\alpha-1)+\delta_{mod}$, $\delta_{mod}\le 2d\exp(-(m/2-nC/s)^2/2n\sigma^2)$ [1][5][6][7].

Proof via RDP composition, sum discrete Gaussian lemma, subsampling amplification, shuffle amplification, modular union bound, SecAgg+ DDH.

> Theorem 5.2 (Communication Optimality): For $\varepsilon\le2$, same utility as central requires $b=O(\log(1+n/\sigma))$ bits per param [8]; SecAgg+ stochastic rotation achieves $b\le16$ matching central [1][8].

```python
import numpy as np
def rdp_to_dp(eps_rdp, alpha, delta): return eps_rdp + np.log(1/delta)/(alpha-1)
def simulate_utility(n=1000,d=10000,C=1.0,sigma=1.5,scale=0.01):
    true = np.random.randn(d)*C
    per_client = true/n + discrete_gaussian_sampler(sigma/np.sqrt(n), d)/scale
    summed = per_client*n
    mse = ((summed-true)**2).mean()
    return mse
```

## 6 Limitations, Failure Modes, Open Problems

1. *Discrete Gaussian sampler*: no constant-time in mainstream ML; naive leaks timing [1].
2. *Modulus vs tight budget*: $\varepsilon<0.5$ requires $\sigma>4$, $m\ge2^{15}$ lowering compression; Skellam reduces $m$ [2].
3. *SecAgg+ Sybil*: adversary $\Theta(\sqrt N)$ Sybils isolates victim; increase $k$ to $2\log N$.
4. *User heterogeneity*: 1 vs 10k examples both clip $C$, efficiency loss; adaptive clip via DP quantile mitigates [1].
5. *TEE side-channel*: SGX page fault cache leak; pad worst-case $2.1\times$ overhead [2].
6. *Theory gap*: RDP sum loose for $\alpha>10$ tail correction $\tau$ dominates; tighter Fourier open.
7. *Regulatory*: user-level DP no guarantee against cross-federation pseudonym link.

| Limitation | Mitigation | Hardness |
|---|---|---|
| Sampler constant-time | BearSSL-inspired integer | Medium |
| Sybil isolation | degree 16 + audit | High |
| Adaptive clip bias | two-level clip + quantile | Medium-High |
| SGX paging | TDX full VM | Medium |

## 7 Conclusion

We synthesized DP-FL stack resisting honest-but-curious server: **DDGauss** finite-group analogue compatible SecAgg, **SecAgg+** sparse graph plus linear quantization/freezing $<3$ bits effective, **RDP accounting** Poisson $T=2000$ at $\varepsilon=3$, **TEE shuffler** central-like utility with distributed trust.

Key insight: modular arithmetic, random rotation, oblivious shuffling jointly shift DP-FL from $O(d)$ overhead to $O(d\log\log d)$ while retaining formal guarantee. Future: Skellam integration, hardware-accelerated sampler in TEE microcode, private self-tuning.

Checklist: dudect sampler, TLC liveness 30% dropout, audit attestation, monitor $m$ overflow $\le10^{-8}$.
