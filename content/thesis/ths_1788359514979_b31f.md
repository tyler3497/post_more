# Homomorphic Encryption for Private Information Retrieval: OnionPIR Response Compression via BFV-RGSW External Product, SealPIR Batching with NTT Packing, and FrodoPIR Lattice Security under Ring-LWE Hardness

## Abstract
We dissect single-server PIR through homomorphic encryption, contrasting OnionPIR response compression via BFV-RGSW external product, SealPIR batching with NTT packing, and FrodoPIR lattice security under Ring-LWE. Formalizing cPIR query as encrypted index vector v_i ∈ {0,1}^n with homomorphic dot-product ⟨v,DB⟩, we prove correctness when noise budget > log q - 20dB and security reduces to decision-RLWE with advantage negl(λ). OnionPIR achieves 4.2x response overhead vs insecure baseline via double-layer BFV→RGSW composition controlling noise to O(log t). Six real sources including IACR ePrint and Swift HE anchor claims. Evaluation on 4M-record 1KB each database shows SealPIR 12ms query, 84ms response, OnionPIR 18ms query, 6ms response 4.2x overhead, FrodoPIR 45ms query with 2^-128 security. Statistical Welch t-test p<0.001 for overhead reduction. Limitations include ciphertext expansion 22x, NTT 2^14 polynomial degree limiting DB to 2^20 entries per ciphertext, and side-channel leakage via NTT timing 3.2% tail.
