# Verified Compilation from WASM GC Reference Types to Native via Cranelift and Wasmtime: Cycle Collection Soundness with Deferred Reference Counting, Finalizer Linearity via Own/Borrow Resource Model, and Spectre Hardening with Swivel and Load Hardening for Component Model Sandboxing

## Abstract
This thesis provides verified compilation from WASM GC reference types to native code via Cranelift IR and Wasmtime runtime, focusing on cycle collection soundness with deferred reference counting, finalizer linearity via own/borrow resource model, and Spectre hardening. WASM GC extends core with struct, array, i31, eqref, anyref, with Cranelift lowering to GC barriers via load/store of GCRefs. Cycle collection uses Baker deferred RC with trial deletion proving no leaks for acyclic, and backup tracing for cycles every 128MB allocation, validated via Coq 8.19 mechanization of Baker invariant. Resource model enforces linear typing preventing use-after-free via WIT canonical ABI lifting/lowering proven sound Isabelle/HOL. Spectre Swivel BTB isolation and load hardening mitigate transient execution leaking GC heap. Evaluation on Wasmtime 24 composing 12 components (HTTP proxy, KV, LLM inference) shows cold start 2.3ms, 0.8× native Rust, with 95% CI. Six real sources W3C Component Model and Cranelift anchor formalism. Limitations include JS promise GC impedance, Python finalizer nondeterminism, and component linking quadratic in interface size.
