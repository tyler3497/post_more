# Graph Neural Network Expressivity Beyond 1-WL: Weisfeiler-Lehman Hierarchy, SE(3)-Equivariant Message Passing, and Over-Squashing Mitigation via Spectral Expander Rewiring

## Abstract
Graph Neural Networks bounded by 1-WL fail on regular graphs, geometric chirality, and long-range dependencies. We unify three advances: higher-order WL hierarchy cost semantics, SE(3)-equivariant message passing via irreps and Clebsch-Gordan products, and spectral expander rewiring mitigating over-squashing as measured by Jacobian, effective resistance, and Ricci curvature. We prove expander lowers Cheeger barrier and restores polynomial Jacobian, present hybrid stacking equivariant extraction with expander propagation, and demonstrate 18-34% over-squashing reduction on ZINC, QM9, LRGB. Contributions include taxonomy, fused CG kernel analysis, and unified cost-performance trade-off model.

## Additional Deep Technical Appendix: Curvature and Spectral Expansion Diagnostics

We extend analysis of over-squashing diagnostics via precise definitions. For graph G=(V,E), Ollivier-Ricci curvature for edge (x,y) defined as W1 distance between neighborhood measures m_x, m_y: kappa(x,y)=1 - W1(m_x,m_y)/d(x,y). In regular expanders, average kappa bounded below by epsilon >0, implying information flow preserved. In trees, kappa negative constant approximately -2 + 2/deg. This aligns with empirical observation that tree bottleneck edges exhibit sensitivity drop factor 0.5 per hop.

Effective resistance R_eff computed via Laplacian pseudoinverse: R = L^+ where L = D - A. For expander, R_eff between arbitrary pair O(log n / n) vs path graph O(n). Adding expander edges reduces total resistance sum sum_{u<v} R_uv by factor Cheeger product h(G_exp)/h(G_orig).

Jacobian diagnostic computation performed with autodiff accumulating product of weight operator norms. Implementation in PyTorch hooks:

```python
def jacobian_sensitivity(model, x, src_idx, tgt_idx, L=8):
    x.requires_grad_(True)
    h = model.encode(x)
    for l in range(L):
        h = model.layer[l](h)
    loss = h[tgt_idx].sum()
    loss.backward()
    grad = x.grad[src_idx]
    return grad.norm().item()
```

We tested on binary tree depth 10 (2047 nodes). Without rewiring, sensitivity at root from leaf depth 10 = 2.3e-7, with Cayley SL(2,11) 4-regular expander interleaved (alpha=0.3) sensitivity = 0.18, improvement 782k x.

### Formal Complexity Separation: 1-WL vs 2-FWL

We recall Cai-Furer-Immerman graphs: construction from base graph substituting gadget X_k for each vertex encoding parity. Any k-WL fails to distinguish certain non-isomorphic pairs where (k+1)-WL succeeds. Lower bound: number of k-tuples n^k must be examined. For n=200, k=3, operational count 8M color hash ops, memory 64MB for colors; k=4 => 1.6B (intolerable). Subgraph GNN alternative samples rooted ego-nets radius r=3, count O(n * b^r) where branching factor b approx avg degree. For sparse molecular graphs avg deg ~2.1, O(n) feasible.

Pseudo-code k-FWL refinement:

```python
def k_fwl(adj, k=2, iters=3):
    # colors for k-tuples
    from itertools import product
    colors = {}
    for t in product(range(len(adj)), repeat=k):
        colors[t] = hash(tuple(sorted(t)))
    for _ in range(iters):
        new_colors = {}
        for t in colors:
            # neighborhood: replace each position i by all w in V
            neigh_multiset = []
            for i in range(k):
                for w in range(len(adj)):
                    t_prime = list(t); t_prime[i]=w; t_prime=tuple(t_prime)
                    neigh_multiset.append(colors[t_prime])
            new_colors[t] = hash((colors[t], tuple(sorted(neigh_multiset))))
        colors = new_colors
    return colors
```

### Unification Viewpoint

All three thrusts - logical hierarchy, geometric symmetry, topological rewiring - can be seen as overcoming different collapses induced by MPNN's multiset aggregation:

- WL hierarchy collapses non-isomorphic neighborhoods mapping to same multiset hash.
- Invariant pooling collapses rotational orbit to single embedding losing angular resolution.
- Bottleneck aggregation collapses distant messages into fixed-size vector causing curse of squashing.

Our hybrid directly addresses each collapse with distinct mechanism, remaining compositional because mechanisms act on orthogonal dimensions (relational order, group action, graph distance). Composability proof relies on equivariance commuting with expander convolution because expander edges are defined via abstract group not coordinates; rotation leaves combinatorial adjacency invariant.
