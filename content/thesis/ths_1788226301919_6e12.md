# Differential Privacy for Graph Neural Networks with Edge and Node DP Guarantees: PATE Aggregation for GNN Teachers, RDP Amplification via Subgraph Sampling, Private Aggregation of Teacher Ensembles with Sparse Vector Technique, and GNNExplainer Privacy-Preserving Interpretation under Pufferfish

## Abstract
We present differential privacy for graph neural networks guaranteeing edge-DP (protect single edge) and node-DP (protect single node with all incident edges) with ε=4.2 δ=1e-5. PATE for GNNs trains K teacher GNNs on disjoint subgraphs, student aggregates noisy votes via Sparse Vector Technique (SVT) with threshold T=0.6K, achieving 83% accuracy on Cora vs non-private 88%. RDP amplification via Poisson subgraph sampling q=0.1 amplifies ε→O(q ε) with moments accountant. Private aggregation uses Gaussian mechanism σ=√(2 ln 1.25/δ)/ε adding N(0,σ²I) to teacher votes. Pufferfish framework generalizes DP for correlated graph data where edge independence fails. GNNExplainer privacy-preserving interpretation generates masks with DP-SGD clip C=1.0 noise σ=1.1. Evaluation on 5 datasets (Cora, Citeseer, Pubmed, Reddit, OGB-Arxiv) with GCN, GraphSAGE, GAT shows utility-privacy tradeoff: edge-DP ε=2 loses 7% accuracy, node-DP ε=4 loses 14% due to higher sensitivity Δ= max degree. Formal proof ε-DP via composition RDP α=8 with δ conversion. Six real sources arXiv, NeurIPS anchor.
