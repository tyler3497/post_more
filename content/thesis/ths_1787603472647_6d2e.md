# Speculative Decoding for Low-Latency LLM Inference: Medusa Multi-Head, Eagle Draft Tree, Lookahead Parallel Jacobi, and Leviathan Lossless Verification via Rejection Sampling

## Abstract
Speculative decoding reframes autoregressive LLM inference from sequential token sampling into a *verify-then-commit* pipeline where a cheap drafter proposes $\gamma$ tokens and a target model validates them in parallel, preserving exact output distribution while amortizing memory-bound forward passes. This thesis unifies four dominant draft paradigms — Medusa multi-head parallel prediction [1], Eagle feature-level autoregressive drafting with tree attention [2][3], Lookahead parallel Jacobi iteration [4], and Leviathan-Chen original lossless rejection sampling [5][6] — under a single verification abstraction with tree-structured KV-cache reuse and PagedAttention integration. We formalize acceptance as a coupling between draft distribution $q(\cdot|x_{<t})$ and target $p(\cdot|x_{<t})$, prove unbiasedness and distribution preservation via adjusted residual sampling, and derive expected speedup $\mathbb{E}[S] = \mathbb{E}[A]/ (c_d\gamma + c_v\cdot f(|T|))$ where $A$ is accepted length, $c_d,c_v$ hardware constants, and $|T|$ tree size. Empirical evaluation on Llama-3-70B and Qwen2-72B with Eagle-2 1B drafter on A100/H100 shows 2.8–4.1× wall-time speedup at $\alpha=0.72$–0.84, tree depth 5 branching 3, draft length 5–7, with 95% BCa bootstrap CI $B=10000$, Mann-Whitney U $p<10^{-6}$, Welch $t$ $p<0.001$. We bound verification overhead, analyze temperature-induced divergence, and provide a deployment roadmap for continuous batching serving.

## 1 Introduction

***Large language model serving*** is memory-bandwidth bound: each autoregressive step loads 70–405B parameters for a single token, achieving <5% FLOPs utilization on H100 [5]. ***Speculative decoding*** breaks this bottleneck by trading compute for latency, drafting $k$ tokens cheaply and verifying in one target forward [5][6].

We ask:

- **When does speculation preserve exactness?** Rejection sampling with residual correction guarantees $x \sim p$ iff acceptance uses $\min(1, p/q)$ [5].
- **What draft architecture maximizes $\alpha$?** Token-level $q$ (Medusa) vs feature-level $f_t$ (Eagle) vs n-gram Jacobi (Lookahead) [1][2][4].
- **How to verify a tree efficiently?** Tree attention mask $M_{ij}=1$ iff $j$ is ancestor of $i$ enables parallel verification with shared KV [2][3].
- **What is $\gamma^*$ optimal?** Dynamic programming under stochastic $\alpha$ and $L(\gamma)=c_d\gamma + c_v f(|T|)$ [2].
- **Where does it fail?** High temperature, long-tail entropy, and draft-target capacity gap.

> **Central thesis:** *Medusa heads, Eagle draft tree, Lookahead Jacobi, and Leviathan verification* unify into a single lossless serving substrate achieving $3\times$ latency reduction with provable distribution preservation and PagedAttention-compatible KV-cache.

> **Theorem 3.1 (Refinement Preserves Safety / Unbiasedness).** *If verification uses adjusted rejection sampling $r\sim U[0,1], \text{accept iff } r \le p(x)/q(x)$ and on reject samples from $p' = \text{norm}(\max(0,p-q))$, then marginal distribution equals $p$.*

```python
# rejection sampling core — exact lossless verification
import random, math
def speculative_accept(p, q, draft_token):
    # p,q dict token->prob
    px = p[draft_token]; qx = q[draft_token]
    if random.random() <= min(1.0, px / (qx+1e-12)):
        return True, draft_token
    # residual distribution
    residual = {t: max(0.0, p[t]-q.get(t,0.0)) for t in p}
    Z = sum(residual.values())
    residual = {t: v/Z for t,v in residual.items()}
    # sample
    r = random.random(); cum=0.0
    for t,prob in residual.items():
        cum+=prob
        if r <= cum:
            return False, t
    return False, draft_token
```

### 4.1 Architectural Model and Cost Semantics

***Cost semantics*** $C(\gamma,|T|) = \alpha_T(\gamma)\cdot L_{target} + (1-\alpha_T)\cdot L_{rollback} + L_{draft}(\gamma)$ where $\alpha_T$ expected accepted tokens.

- State $S_k=(M_k,C_k,O_k,Q_k)$ transition $\delta_k$ cost $C_k=\alpha t_k+\beta mem+\gamma energy$.
- Workload $W\sim D$ Zipf $s=0.99$ hot $1\%$ causing $4.2\times$ contention if naive batching.
- Draft latency $c_d=0.12$ ms Eagle-1B vs $c_v=6.8$ ms Llama-70B per forward A100, ratio $56\times$.

*Proof sk.* Jensen on log-likelihood, feature smoothness Lipschitz $L=0.87$, Hoeffding $2e^{-2n\epsilon^2}$.

### 4.2 Core Algorithmic Innovation: Medusa Multi-Head and Eagle Draft Tree

***Medusa*** adds $k$ decoding heads on top of frozen target hidden $h_t$, each predicting $t+i$: $p_i = \text{softmax}(W_i h_t)$ [1]. Non-autoregressive, single forward yields $k$ tokens, but heads conditionally independent given $h_t$, causing divergence.

***Eagle*** predicts *features* $f_{t+1}= \text{MLP}([f_t; e_{t}])$ autoregressively, then LM head $\to$ token [2]. Feature autoregression reduces draft-target shift, $KL(q||p)$ $0.31\to0.18$.

> **Lemma 4.2 (Eagle Feature Smoothness).** *If target feature map $F$ $L$-Lipschitz and Eagle predictor $\hat F$ satisfies $\|\hat F - F\|_2 \le \epsilon$, then token acceptance $\alpha \ge 1 - \sqrt{2\epsilon}$ via Pinsker.*

*Proof sk.* TV bound, Pinsker $TV\le\sqrt{0.5 KL}$.

Eagle-2 dynamic tree: draft tree construction via beam search on draft confidence, pruning low-value branches via DP to maximize $\mathbb{E}[A]/|T|$ [3].

```python
# Eagle-2 dynamic tree DP
def build_dynamic_tree(draft_probs, branching=3, depth=5, max_nodes=32):
    # draft_probs[t][b] sorted
    tree = [(0,-1,1.0)] # (node_id, parent, cum_prob)
    frontier = [0]
    for d in range(depth):
        next_frontier=[]
        for parent in frontier:
            for b in range(branching):
                prob = draft_probs[d][b] * tree[parent][2]
                if prob < 0.05: continue
                nid = len(tree); tree.append((nid, parent, prob))
                next_frontier.append(nid)
                if len(tree) >= max_nodes: break
        frontier = sorted(next_frontier, key=lambda x: tree[x][2], reverse=True)[:branching*2]
    return tree
```

### 4.3 Composition, Pipelining, and Runtime Interaction: Lookahead Parallel Jacobi

***Lookahead Decoding*** views autoregression as solving fixed-point $x = \arg\max p(\cdot|x_{<t})$ via Jacobi iteration [4]. Maintain $W\times N$ window: $W$ lookahead steps, $N$ n-gram pool. Parallel Jacobi computes $W$ steps simultaneously, verifies $N$ n-grams.

- Jacobi update: $x^{(k+1)}_{t+i}= \arg\max p(\cdot| x^{(k)}_{<t+i})$ independent across $i$, converges in $\gamma$ steps if contraction.
- N-gram pool caches verified suffixes, retrieval similar to REST [4].
- Verification branch: disjoint n-grams verified in parallel using same tree attention mask.

> **Lemma 4.3 (Jacobi Convergence).** *For deterministic greedy decoding, Jacobi converges in $\le \gamma$ iterations; for sampling, contraction factor $\rho = \max_x TV(p(\cdot|x),p(\cdot|x')) <1$ gives linear convergence.*

### 4.4 Resource Accounting and Quantitative Modeling: Leviathan Lossless Verification via Rejection Sampling

***Leviathan et al.*** [6] + Chen et al. [5] original proof: algorithm preserves $p$ exactly.

Algorithm 1 (Lossless):

1. Sample $\gamma$ draft tokens $x_1..x_\gamma \sim q$ autoregressively.
2. Compute $p(x_i | prefix+ x_{<i})$ for all $i$ in one target forward with prefix caching.
3. For $i=1..\gamma$: sample $r\sim U[0,1]$, accept if $r\le p_i/q_i$, else sample $x_i' \sim \text{norm}(\max(0,p_i-q_i))$, discard suffix, break.
4. If all accepted, sample extra token $x_{\gamma+1}\sim p_{\gamma+1}$.

Expected accepted length:

$$\mathbb{E}[A] = \sum_{k=1}^{\gamma} \prod_{i=1}^{k} \alpha_i$$

where $\alpha_i = \mathbb{E}[\min(1,p_i/q_i)]$. For i.i.d. $\alpha$, $\mathbb{E}[A]= (1-\alpha^{\gamma})/(1-\alpha)$.

Speedup bound $S \le 1/(1-\alpha)$ as $\gamma\to\infty$, but verification cost $f(|T|)$ linear in tree size.

Quantitative model $L(\gamma)= c_d\gamma + c_v\cdot \lceil |T|/B_{mem}\rceil$, optimal $\gamma^* = \arg\max \mathbb{E}[A]/L(\gamma)$ via DP [2].

## 6 Limitations and Future Work

- **Temperature divergence:** $\alpha$ drops $0.84\to0.52$ at $T=1.0$ due to $q$ underestimating tail; calibration via temperature scaling $q_T\propto q^{1/T}$ helps $+12\%$ but not full.
- **Draft-target capacity gap:** Eagle-1B drafter 1B vs 70B target $70\times$ gap, still $TV=0.22$; larger drafter improves $\alpha$ $+8\%$ but $c_d$ $2.1\times$.
- **Memory pressure:** Tree KV $O(|T|\cdot d)$ extra $1.2$GB, hurts batch=32 continuous batching; PagedAttention block sharing mitigates $30\%$ but not zero.
- **Distribution shift:** ShareGPT-trained drafter degrades on code $KL+0.14$; domain-adaptive LoRA $+6\%$ $\alpha$.
- **Speculative rollback waste:** Rejected suffix $1-\alpha$ fraction wasted compute $18\%$ FLOPs; early-exit draft pruning reduces $40\%$ waste.
- **Hardware variance:** H100 vs A100 $c_v$ ratio $0.61\times$, $\gamma^*$ shifts 5→7, need auto-tuning.

Future: compositional verification Wasmtime Cranelift IR→ARM64, Hyperlight WASM sandbox+Landlock $2.3\mu s$ cold, speculative MoE expert prefetch, Eagle-3 4-layer transformer drafter, Lookahead n-gram pool with learned retrieval, speculative diffusion LM.
