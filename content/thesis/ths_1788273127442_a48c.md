## Abstract
This thesis formalizes compiler superoptimization via equality saturation, building on egg e-graphs with union-find and congruence closure, sketch-guided enumeration pruning 10^12 candidates to 10^4, verified lifting with Alive2 SMT encoding in Z3, and learned cost model via XGBoost for LLVM IR and Cranelift targeting x86-64 and AArch64. E-graph maintains equivalence classes E_c with e-nodes f(E_{c1},...,E_{ck}), saturation via rewrite rules R: 128 algebraic (x+0→x), 64 strength-reduction, 32 vectorization, iteration until fixpoint or 10k nodes. Sketch-guided synthesis uses partial program with holes ??, enumerates completions bounded depth 3, prunes via observational equivalence on 100 random inputs, 1000× reduction. Alive2 encodes LLVM IR semantics to SMT-LIB, proves refinement ∀input, 99.2% verification success, counterexample 0.8% unsound rewrites filtered. Cost model XGBoost 200 trees depth 8 trained on 1M basic blocks perf counters IPC, predicts cycles 94% correlation, replaces -O3 heuristic 12% speedup geomean. Evaluation on LLVM 17 500k functions 8h search, 4.2% mean speedup SPEC CPU 2017, 9% FP, 18% vectorized loops, 0 miscompilations after Alive2, 95% CI ±0.3%. Limitations include e-graph blowup 10k→100k nodes exponential, SMT timeout 12%, and cost model transfer across microarchitectures.
