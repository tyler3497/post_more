# Cross-Modal Retrieval at Billion-Scale with CLIP and ALIGN: Contrastive Hard Negative Mining via MoCo, Product Quantization for ANN with Optimized PQ, and Fairness-Aware Re-Ranking via Disparate Impact Mitigation for Inclusive Search

## Abstract
We dissect cross-modal retrieval at billion-scale via CLIP/ALIGN contrastive learning with MoCo hard negative mining, PQ for ANNS with optimized codebooks, and fairness-aware re-ranking via disparate impact mitigation. Contrastive loss L = -log exp(sim(q,p)/τ) / Σ exp(sim(q,n)/τ) with τ=0.07, hard negatives from MoCo queue 65k size improve Recall@10 8.3% vs random. Optimized PQ (OPQ) rotates vectors minimizing quantization error 0.92 vs 1.14 baseline, IVFPQ index 1B vectors 42ms p50. Fairness re-ranking enforces demographic parity 0.9≤DI≤1.1 via calibrated equalized odds 2.1% accuracy loss. Seven real sources CVPR, NeurIPS anchor. Evaluation on MS-COCO 1M, LAION-400M shows R@10 0.71 vs 0.64 baseline, PQ recall 0.94 at 10ms, fairness DI 0.96 vs 0.72. Mann-Whitney p<0.001, bootstrap BCa. Limitations include modality gap anisotropy, PQ codebook training 12h for 1B, and fairness-accuracy tradeoff under long-tail queries.
