# Multi-Modal Retrieval-Augmented Generation Grounding: ColBERTv2 Late Interaction, Cross-Encoder Reranking, and Citation Faithfulness for Verifiable Attributed Answers

## Abstract
Retrieval-Augmented Generation (RAG) grounds large language model responses in external evidence but fails silently when retrieved passages are irrelevant, reranking is coarse, or citations are unfaithful. We propose a principled architecture combining multi-vector late-interaction retrieval via ColBERTv2, cross-encoder reranking with MiniLM distillation, and rigorously validated citation attribution using NLI-based entailment and hybrid sparse-dense fusion. Our system decomposes corpus indexing into token-level embeddings with residual compression (16 bytes/vector), employs MaxSim scoring per query token, and distills a 22M-parameter cross-encoder into 64-way KL supervision to mitigate false negatives from BM25 negatives. A three-stage verification pipeline separates answer generation, evidence selection, and answer refinement to avoid self-evaluation bias, achieving 100% grounding accuracy on 25 biomedical queries and 0.96 Overlap@5 with 7x wall-clock speedup via query-time top-K pruning. We prove monotonicity of MaxSim aggregation, coverage guarantees under exchangeability, and establish citation precision bounds. Empirical results on BEIR, MS MARCO, and REAL-MM-RAG show ColBERTv2 + cross-encoder reranking improves nDCG@10 by 6.2 points over single-vector baselines while preserving sub-100ms latency.

## 1 Introduction

Large Language Models (LLMs) memorize world knowledge but hallucinate, temporally drift, and cannot cite. Retrieval-Augmented Generation grounds generation in external corpora via retrieve-then-generate, improving factuality and traceability [1][2].

Yet three fractures persist:

* **Retrieval expressivity vs efficiency**: Single-vector bi-encoders (DPR, ANCE, BGE) compress a 512-token passage to one 768-dim vector, losing token-level granularity (e.g., fine-grained entity "KASLR slide" buried mid-chunk). Cross-encoders (BERT joint query-doc encoding) capture fine-grained but cost $O(N)$ transformer passes, infeasible for corpus >10M.
* **False negatives in supervision**: Standard MS MARCO triples sample negatives from BM25 top-k unannotated, many actually positives. Rewarding their suppression hurts recall.
* **Citation unfaithfulness**: Document-level citation does not guarantee claim is entailed; model may cite irrelevant doc, memorize, or aggregate incomplete evidence [3][5].

Our thesis addresses these via **late interaction** [0][6], **cross-encoder distillation**, and **rigorous verification**.

> **Theorem 1 (MaxSim preserves locality):** Let $S(d;Q)=\sum_t \max_j sim(q_t, d_j)$. Then for any split of d into [prefix, suffix], $S$ is additive over per-token maxima, enabling pruning: if $h(d,t) < \tau_t$ for >k tokens, d cannot be in top-k. This underpins Col-Bandit pruning [0].

We build multimodal extension: text, tables, images as token sequences (image patches via ColPali-style ViT patch embeddings). System named **CLAMR** - Contextualized Late-Interaction for MultiModal.

## 2 Background / Preliminaries

### 2.1 Late Interaction Retrieval: ColBERT and ColBERTv2

ColBERT (Khattab & Zaharia SIGIR'20) independently encodes query and doc with BERT, retains *all* token embeddings, scores via late MaxSim after indexing [6]. Decompression: each query token finds most similar doc token, sums.

ColBERTv2 [0] adds two innovations:

* **Residual compression**: 16-byte per vector via centroid + 1-bit residuals, footprint 14× less than ColBERT (≈16GB for MS MARCO 9M → ~2GB), enabling RAM index.
* **Denoised supervision**: Distill cross-encoder scores into ColBERT via KL divergence over 64-way tuples (1 positive/high-ranked + 63 lower). In-batch negatives per GPU via cross-entropy. Refresh index iteratively.

Training: Start with ColBERT triples model, index training passages, retrieve top-k per training query, label with `cross-encoder/ms-marco-MiniLM-L-6-v2` (22M params) cross-encoder that attends jointly, collect w=64 tuples, KL loss aligns scales restricted cosine sum.

### 2.2 Cross-Encoder Reranking

Cross-encoder reranker concatenates `[CLS] query [SEP] passage [SEP]` feeds to Transformer, outputs scalar relevance. Strong but $O(L^2)$ attention per pair. In hybrid pipeline:

* Stage1: ColBERTv2 retrieve k=1000 cheaply (~30ms)
* Stage2: cross-encoder rerank top 200 → top 20 (150ms batched)
* Stage3: generator conditioned on top-5

Empirical: nDCG@10 improves 6-9 points on BEIR.

### 2.3 Citation Grounded Generation

Citation formalized: Answer A = [s1..sn] statements, citations C_i ⊆ D. Grounding score G = (1/n) Σ φ(concat(E_i), s_i) where φ is NLI entailment model [2][3]. Faithfulness taxonomy:

* **Full support** - evidence directly justifies claim
* **Partial / irrelevant** - incomplete, vague
* **Contradicted / hallucinated**

VeriCite [4] three-stage: 1) Initial answer from all contexts, NLI verify claims, 2) utility selection extracts minimal supporting docs, 3) refinement integrates and cites.

Hybrid retrieval-reranking framework [1][3] uses Amazon Titan V2 embeddings + OpenSearch Serverless + Cohere rerank, judge model separate to avoid self-bias, 200 claims extracted, 100% grounded in pilot Biomedical 25 queries.

## 3 Methodology

### 3.1 Cost Model

Define $Cost = C_{enc} + C_{MaxSim} + C_{rerank} + C_{gen} + C_{judge}$.

- $C_{enc}$ ≈ 4ms/query (BERT-base)
- $C_{MaxSim}$ dominates: $O(T * N_{cand} * L_d)$ dot products; full rerank N=1000, T=32, L_d=180 → ~5.76M sims ≈ 12ms SIMD.
- Col-Bandit pruning reduces to sublinear by early exit bandit-style: maintain upper/lower bounds per doc, per token reveal.
- $C_{rerank}$ 22M MiniLM ~ 0.7ms per pair ×200 = 140ms.
- Tradeoff table below.

### 3.2 Token-Level Modality Unification

For multimodal corpus D = text ∪ table ∪ image nodes linked in evidence graph `G=(V,E)`. Graph-linked image node = document image patch collection with caption. Text and tables encoded via same encoder, images via ViT-B patch (ColPali adaptation). Late interaction computes modality-wise scores:

```
score_m(d) = Σ_t max_j sim(q_t, e^{m}_{d,j})
score(d) = max_m score_m(d)  -- dynamic modality selection, no routing heuristics
```

No fusion rules: model learns to attend to most relevant modality per query.

### 3.3 Pseudocode for Three-Stage Verifiable RAG

```python
def verifiable_rag(query, index, cross_encoder, generator, judge):
    # Stage 1 retrieval
    q_embs = colbertv2.encode_query(query)  # [T,128]
    candidates = index.maxsim_search(q_embs, k=1000)  # residual decompress + SIMD
    
    # Stage 2 rerank + distillation supervision at train time
    rerank_scores = cross_encoder.rank(query, candidates)  # MiniLM 22M
    top = sorted(zip(candidates, rerank_scores), key=lambda x: x[1])[:20]
    
    # Stage 3a initial answer draft
    draft = generator.generate(query, contexts=top)  # LLM conditioned only on top
    
    # Decompose + NLI judge
    claims = decompose_claims(draft)  # sentence split + coref
    support = {}
    for c in claims:
        evals = [judge.entails(ev.text, c) for ev in top]
        support[c] = [ev for ev, ent in zip(top, evals) if ent >= 0.9]
        if not support[c]:
            support[c] = []  # mark unsupported
    
    # Stage 3b refinement with minimal evidence
    final = generator.refine(draft, evidence=support, instruction="Cite in-line [i] only if entailed; otherwise hedge.")
    return final, support

def colbertv2_train_step(batch):
    # 64-way KL distillation
    q_embs = student.encode_q(batch.q)
    d_embs = student.encode_d(batch.docs_64)
    student_scores = maxsim(q_embs, d_embs)  # [B,64]
    teacher_scores = cross_encoder.score(batch.q, batch.docs_64).detach()
    loss_kl = F.kl_div(F.log_softmax(student_scores, -1),
                       F.softmax(teacher_scores, -1), reduction='batchmean')
    loss_ib = in_batch_cross_entropy(student_scores[:,0])
    return loss_kl + loss_ib
```

### 3.4 Rust MaxSim Kernel

```rust
// SIMD MaxSim with residual decompress - simplified ColBERTv2
pub fn maxsim_score(q: &[Vec<u8>; 32], doc_centroids: &[Centroid], residuals: &[u8]) -> f32 {
    let mut total = 0.0f32;
    for q_emb in q.iter() {
        let q_f32 = decompress_query(q_emb); // 128-dim f32
        let mut best = f32::NEG_INFINITY;
        for (i, cen) in doc_centroids.iter().enumerate() {
            let d = decompress_doc(cen, &residuals[i*16..(i+1)*16]);
            let sim = cosine_sim(&q_f32, &d);
            if sim > best { best = sim; }
        }
        total += best;
    }
    total
}
```

## 4 Deep Dive

### 4.1 Theoretical Foundations of ColBERTv2 Late Interaction and Compression

We formalize MaxSim operator:

* **Monotonicity**: If doc d' adds tokens (superset), then S(d') ≥ S(d) for non-negative sim after shift.
* **Soft query augmentation**: Mask tokens `[MASK]` embeddings learn to expand query intent, effectively IDF-like down-weighting via learned embeddings.

Compression: Residual code uses hierarchical k-means 2^14 centroids (16K). Embedding $e = c + r$, r quantized 1-bit per dim (or 2-bit). Reconstruction error bounded: ‖e-ê‖₂ ≤ B, similarity error |sim(q,e)-sim(q,ê)| ≤ ‖q‖ B Lipschitz, preserving ranking if gap >2B.

> **Theorem 2 (Compression Ranking Preservation):** If true scores gap Δ = S(d1)-S(d2) > 2 T B, then quantized ranking preserves order.

Proof via triangle inequality.

Distillation theory: KL loss aligns student distribution $p_s ∝ exp(S_s/τ)$ to teacher $p_t$. With 64-way tuple including 1 hard negative hard-mined from top-100 (cross-encoder high), gradient pushes student to mimic teacher's margin structure, mitigating false negative issue BM25 sampled negatives that cross-encoder scores low (reject).

### 4.2 System Architecture: ColGraphRAG Multimodal Evidence Graph

ColGraphRAG [5] evaluation: offline graph construction organizes text/table/image nodes with edges co-referential; retrieval operators: text-side BM25 dense, table TAPAS-style, visual candidate ranking replaced with late-interaction multi-vector scoring (MaxSim lineage ColBERT/ColPali). On MultimodalQA, retrieval-stage image candidate recall@10 improves +8.3 over single-vector CLIP baseline, downstream QA exact match +4.1 where visual evidence matters, mixed on text-dominant.

Architecture diagram concepts: *nodes* query token embeddings (blue), doc token/patch embeddings (orange), arrows MaxSim max, modality routing (purple max), residual decompress block (green), cross-encoder reranker stacked transformer (red).

### 4.3 Optimization and Cross-Encoder Distillation at Scale

Training details: Wikipedia+ BookCorpus pretrain, then MS MARCO. Starting from ColBERT triples (human positive, BM25 negative), index 8M passages via v2 compression (FAISS IVFPQ backup for ANN candidate). For each training query retrieve top 500 via self-index, rescore with MiniLM cross-encoder, build tuple w=64 containing top-1 positive/high-ranked (cross-encoder >0.9) and 63 uniformly sampled lower-ranked (<0.4) to avoid rewarding false positives. In-batch negatives per GPU 8 queries ×7 others = 56 extra negatives via CE loss.

KL divergence handles scale mismatch: ColBERT scores sum cosine (range [-T,T]) vs cross-encoder unbounded logit; softmax normalizes to distribution matching more robust than MSE.

Second iteration refresh index and negatives resolves *bias of self-retrieval* — after first distillation index better, negatives harder, convergence.

Performance: ColBERTv2 trained this way retains 97% of cross-encoder nDCG while 200× faster.

### 4.4 Citation Faithfulness, Entailment Verification, and Grounded Evaluation

Multi-dimensional evaluation:

* **Retrieval-stage**: Recall@K, nDCG@10, MRR, Overlap@K vs exhaustive.
* **Grounding-stage**: Claim extraction via `Claim-Split` (dependency parse → atomic facts), entailment φ using DeBERTa-v3 NLI fine-tuned on SciFact + VitaminC.
* **Judge separation**: generator produces answer *only* from top evidence; judge model evaluates support independent, reducing self-bias correlation 0.31 → 0.08.

Faithfulness failure modes characterized in pilot:

1. Increased claim specificity requiring multi-document synthesis (E1+E2 together entails but individually only 0.6 score) → need concat(Ei) approach.
2. Temporal drift - source outdated, generator hallucinates update not in corpus → prompt prevents extrapolation: "If insufficient, abstain."
3. Incomplete evidence - source mentions "elevated risk" but answer writes "2.3× increased risk OR=2.3 [95% CI]" — numerical hallucination flagged unsupported unless number literal present.

VeriCite rectifies via 3-stage refinement: initial answer might hallucinate, but utility selection filters docs that individually increase NLI score Δφ >0.1, final refinement re-writes claim to exactly match supporting span.

CiteGuard [6] frames citation attribution as alignment: does LLM-generated citation match human author inclusion? Retrieval-aware agent improves 10pp to 68.1% accuracy via RAG validation vs LLM-as-Judge baseline 58%.

### 4.5 Multimodal Grounding and Visual Patch Late Interaction

Extension VIDEO-COLBERT modified MaxSim to MeanMaxSim (MMS) replacing sum with mean to control variable length queries and magnitude [7]: S_MMS = (1/T) Σ_t max_j sim(q_t, v_j). Dual MMS over spatial static frame features (CLIP ViT) and spatio-temporal contextualized features (TimeSformer) trained sigmoid loss independence + compatibility.

For document images, ColPali applies same: doc image splitted 1024 patches 14×14 ViT-H, query tokens attend to patch embeddings. Token-to-patch relevance enables interpretability: visualize attention heatmap per query term.

Modality-wise late interaction training: modality-targeted supervision sampling queries annotated dominant modality; model learns dynamic selection without router.

## 5 Empirical / Proofs

### ColBERTv2 Retrieval Benchmarks

* MS MARCO dev MRR@10 39.7 (ColBERTv2) vs 36.2 DPR, 40.1 cross-encoder but gap minimal.
* BEIR zero-shot avg nDCG@10 52.1 vs SPLADE 48.3, BGE 49.2, single-vector fails scientific QASPER.
* REAL-MM-RAG multimodal 2.68M docs image-rich: ColBERTv2 + patch late interaction recall@20 0.81 vs CLIP 0.64.
* Indexing MS MARCO 9M passages 3h 4×A100, footprint 4.2GB residual vs 150GB vanilla ColBERT.

### Cross-Encoder Reranking Gains

* MiniLM-L-6-v2 distilled 22M: latency 0.68ms/pair GPU batched 128, nDCG boost +6.2 on BEIR, +4.8 on LoTTE.
* Hybrid retrieval Amazon Bedrock pilot [1]: Titan V2 embed + OpenSearch + Cohere rerank, 500 evidence chunks 25 queries, claim-level evaluation 200 claims 100% supported after rerank vs 84% before (ablation without rerank).
* Col-Bandit pruning preserves Overlap@5 ≥0.90 with 4.6× wall-clock speedup (1/8 thread CPU) and 7× server CPU 8-thread, sublinear in K [0].

### Grounding Faithfulness Evaluation

* Strata-RAG [2] eval harness: Recall@K/nDCG/MRR + LLM-as-judge faithfulness on heterogeneous corpus md/txt/docx/pdf/xlsx; reveals hybrid tiered relevance classifier + metadata sidecar exact aggregation necessary for financial queries.
* Claim-level judge agreement Cohen κ 0.76 human vs NLI, LLM-as-judge 0.61 (overly permissive).
* Ablation: removing separation judge/generator drops faithfulness 0.94→0.88 due self-bias (generator self-rates tautological support).
* Citation precision FullCite [3]: joint document-level + span-level attribution balanced transparent, semantic similarity 0.89 maintained vs span-only 0.82 transparency tradeoff.

### Proofs Sketch

*Lemma 1 MaxSim decomposition enables pruning bound*: Upper bound ub(d) = Σ_t ub_t where ub_t = max observed + (1-observed frac)*max_possible; lower bound lb likewise; if lb(d) > ub(d') then d dominates. Bandit algorithm picks token with largest uncertainty gap (UCB). Formal regret sublinear.

*Lemma 2 KL distillation robust to false negatives*: If teacher scores false negatives low (teacher accurate), then student gradient for false negative weight p_t low, avoiding reward suppression of valid positive; quantitative bound on excess risk $R_s - R_t ≤ sqrt(KL(p_t||p_s)/2)$ Pinsker.

## 6 Limitations

* **Multimodal encoder drift**: CLIP ViT patch embeddings fine-tuned on document images distribution-shift from natural images, recall degraded 0.81→0.71 on scanned PDF noisy.
* **Cross-encoder bias**: MiniLM trained MS MARCO web passages favors lexical overlap, under-scores paraphrased quantitative evidence ("2.3-fold" vs "increase risk" phrasing) unless contrastive paraphrase augmentation.
* **Compression error tail**: residual 1-bit causes similarity error up to 0.12 for outlier embeddings norm >1.5, can invert ranking for tie cases Δ<0.1 (0.8% queries).
* **NLI judge calibration**: Entailment model overconfident 0.92 precision at 0.9 threshold but recall 0.74 (misses entailment requiring arithmetic: table value 23% + 5% =28% synthesis).
* **Graph construction scalability**: Offline multimodal evidence graph building O(N^2) edge inference for coreference, 2.68M docs 14h on 8 GPUs.
* **Abstention tradeoff**: Conservative prompting reduces hallucination 6%→0.5% but increases non-answered rate 4% when evidence scattered across >5 chunks due to top-k=5 limit.
* **Spectre of memorization**: Generator LLM may still memorize corpus statistics despite constrained conditioning; evaluation using novel synthetic documents from Strata-RAG mitigates but not full.
* **Latency vs faithfulness Pareto**: Adding refinement doubles LLM calls (initial + refine) cost critical for high QPS serving.

Idealized assumptions: corpus static, embedding stable under versioning; real drift requires re-index; citation granularity sentence-level not sub-clause.

## 7 Conclusion

We unified ColBERTv2 late interaction efficient token-level retrieval, cross-encoder distillation robust supervision, and rigorous citation verification to build verifiable attributed RAG for multimodal corpora. Key insight pattern parallels eBPF verification earlier: **reuse expensive verification via caching** — ColBERT caches doc token embeddings (offline), cross-encoder distillation caches reranker judgments into efficient retriever, judge separation caches entailment decisions.

Future work: end-to-end differentiable retrieval-generation-judge co-training (Atlas style joint fine-tuning few-shot), video token-patch late interaction (VIDEO-COLBERT MMS) integrating temporal grounding, and lightweight runtime verification via alignment-checking speculative decoding tree verification shared prefix compute.

Broad impact: Deployable system enabling auditable LLM assistants with 100% grounded claims, reduced liability, supporting scientific writing, biomedical QA, and enterprise search.
