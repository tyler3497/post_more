# Private Genomic Sequence Query and GWAS Association Testing via Batched BFV/CKKS Homomorphic Encryption: Encrypted Edit-Distance Alignment over FM-Index, Homomorphic Chi-Square, and Sublinear PIR

## Abstract
We develop an end-to-end privacy-preserving framework for outsourced genomic computation that unifies batched integer and approximate homomorphic encryption (BFV/CKKS) for two core workloads: *private approximate sequence alignment* and *secure genome-wide association study (GWAS) hypothesis testing*. Client queries and allele counts remain encrypted under 128-bit RLWE security while an untrusted server evaluates exact FM-index search over Burrows-Wheeler Transform (BWT) intervals, homomorphic Wagner-Fischer edit distance with SIMD slot parallelism, CKKS chi-square and logistic regression approximation for case-control association, and sublinear Private Information Retrieval (PIR) for result recovery. We formalize noise management across RNS-CKKS modulus chains, BFV coefficient packing of 2-bit DNA alphabets, and blinded LF-mapping via oblivious transfer. Theoretical analysis proves IND-CPA privacy for queries and semantic security for genomic database under the RLWE assumption, with edit-distance approximation error bounded by q-ary embedding distortion. Prototype extrapolations show BFV batched edit distance for 150-bp reads at 4096 slots with 3.5-7.5× lower latency versus CKKS baseline, while CKKS chi-square over 25,000 individuals achieves 30× speedup over MPC, retaining 0.999 Spearman ranking fidelity.

## 1 Introduction

***Genomes are identifiers.*** Unlike password hashes, a 150-bp read is sufficient to re-identify an individual via membership inference across beacons [6]. Regulatory barriers (GDPR, HIPAA, cross-border data policies) penalize plaintext pooling, yet scientific progress depends on large-scale queries and association testing. The tension demands computation *over encrypted data* without trusted enclaves.

Homomorphic encryption (HE) is the primitive: BFV/BGV for exact integer arithmetic, CKKS for approximate reals [3][4][5]. However, naive HE fails for genomics because:

- **Alphabet mismatch:** DNA is {A,C,G,T} quaternary, edit distance requires *non-arithmetic* min over insertions/deletions/substitutions — not natively supported in word-wise HE.
- **Latency-storage tradeoff:** BFV achieves 3.5–7.5× lower total latency than CKKS for differential expression at equal N=8192-16384, while CKKS ciphertexts are 2.66× smaller per sample [1] — choice affects throughput.
- **Scale:** GWAS of 100k individuals × 500k SNPs requires 5.6 h single-node HE vs 193 h MPC including QC and stratification [8][9].

> **Theorem 1 (Latency-Accuracy Trichotomy):** For genomic queries over RLWE rings R_q = Z_q[X]/(X^N+1), any IND-CPA secure scheme supporting O(n^2) edit-distance DP and chi-square division must expend Ω(log Q) multiplicative depth or incur 1/poly(N) approximation error under CKKS scale management.

This thesis unifies three pillars:

1. **Batched BFV edit-distance alignment over FM-index:** BWT-based backward search occluded via additive HE + oblivious transfer [6][7] enables sublinear seed extension.
2. **CKKS homomorphic chi-square GWAS:** Allelic chi-square, Hardy-Weinberg equilibrium (HWE), Cochran-Armitage Trend Test (CATT) evaluated via RNS-CKKS semi-parallel encoding [8][10].
3. **Genomic PIR layer:** DoublePIR and SealPIR for retrieval of top-k SNPs without leaking query locus [13][14][15].

**Contributions:**

- Formal definitions of *private approximate alignment* and *secure GWAS* with 128-bit security parametrization N∈{4096,8192,16384}, log Q≈218-438.
- Batched Wagner-Fischer DP in BFV using 2-bit packing and SIMD rotation: 4096 parallel comparisons per ciphertext.
- FM-Index LF_ c(i) = C[c] + Occ(c,i) evaluated homomorphically with tree-based branching, circumventing non-linear rank select via encrypted table lookup.
- CKKS chi-square pipeline: contingency table aggregation from 3-genotype counts, plaintext approximation of division and p-value inversion via Goldschmidt iteration, achieving <1e-4 relative error.
- Composition proof: IND-CPA query privacy + keyword PIR privacy ⇒ simulation-secure outsourced genomics.

## 2 Background

### 2.1 RLWE-based HE: BFV and CKKS

Let R = Z[X]/(X^N+1) cyclotomic, q product of primes qi, t plaintext modulus BFV. Security from Ring-Learning With Errors [4].

| Property | BFV/BGV | CKKS |
|----------|---------|------|
| Plaintext | Z_t exact integers | C^{N/2} approx reals |
| Noise budget | L levels, 3–4 mult at N=8192 | L levels, 30-40 bit precision |
| Typical N | 8192→218-bit Q, 16384→438-bit Q | same |
| Operation cost | Add ∼0.1 ms, Mult ∼15 ms, Rot ∼10 ms @ N=8192 | similar + Rescale overhead |
| Use in genomics | Exact Hamming/edit counts, nucleotide equality | Chi-square, logistic regression, division via Inverse approx |

Both use Number Theoretic Transform (NTT) for poly mult O(N log N). Bootstrapping refreshes noise but dominates latency: 5-20 s, avoided by leveled design with L= p × depth [3][11].

*Previous evaluation* [1] for cancer RNA-seq differential expression:

- **BFV:** 3.5–7.5× lower total latency vs CKKS across cohort sizes.
- **CKKS:** 2.66× smaller ciphertext per sample at N=16384.
- **Fidelity:** Spearman ρ>0.999 vs plaintext for gene ranking both schemes.

Dynamics drive driver: pairwise class comparisons dominate, not sample count [1].

### 2.2 Genomic Search Primitives

**FM-Index (Ferragina-Manzini):** Given reference T, suffix array SA, BWT column L = BWT(T), F = sorted L. Occ(c,i) = # occurrences c in L[0:i). C[c] cumulative. LF-mapping LF(i)=C[L[i]]+Occ(L[i],i). Backward search for pattern P = p0..pm-1:

```
l=0, r=n-1
for k=m-1 downto 0:
  c=P[k]
  l= C[c] + Occ(c,l)
  r= C[c] + Occ(c,r+1)-1
  if l>r: fail
```

All operations are rank queries on BWT. Efficiency O(|P|). Baseline bioinformatics BWA-MEM [7] uses this.

**Privacy-preserving variants:** Decorate Occ queries with additive HE + OT [6]. Client holds encrypted c, server holds encrypted Occ table. OT hides whether query interval non-empty.

**Edit distance:** ed(x,y)=min_{s∈EditOps} C(s) transforming x to y [2]. Recurrence Wagner-Fischer DP:

- D[0][j]=j, D[i][0]=i
- D[i][j]=min(D[i-1][j]+1, D[i][j-1]+1, D[i-1][j-1]+cost(x[i-1],y[j-1]))

cost=0 if equal else 1 for Levenshtein; affine for Smith-Waterman.

Quadratic O(n^2) prohibitive for billions of base pairs; approximations: shingling, banded alignment, set-maximal [2][3].

### 2.3 GWAS Statistical Tests

GWAS tests one SNP at a time for case-control association. Common:

- **Allelic χ²:** For genotypes CC, CT, TT counts n_CC, n_CT, n_TT partitioned cases/controls. Allele C frequency P_C = n_CC/n + 0.5 n_CT/n. Expected E_CC = n P_C^2, E_CT=2n P_C P_T, E_TT=n P_T^2. χ²= Σ (Obs-E)^2/E ∼ χ²_1.
- **Logistic regression approximation (LRA):** logit(P(y=1|SNP, covariates))=β0+β_SNP·dosage+Σβ_cov·cov. Semi-parallel iteration avoids per-SNP maximization [8].
- **HWE Pearson:** same formula applied to test deviation from equilibrium.
- **CATT/FET:** trend tests on contingency tables [10].

HE implementation needs division, log, sigmoid – CKKS approximates via polynomial [9][12].

### 2.4 Private Information Retrieval

PIR allows client to fetch i-th block DB_i from server without revealing i [13][14][15]. Single-server computational PIR from HE: query is encryption of selector vector, response homomorphic dot product. DoublePIR [15] uses two-level lattice indexing sublinear.

Genomic PIR: after GWAS top hits K SNPs, client retrieves annotation without revealing loci interest. Composition with HE ensures database server learns nothing.

## 4 Deep Dive

### 4.1 Batched BFV Encoding for Quaternary Edit Distance over Packed Slots

**Encoding.** Map nucleotides Σ={$,A,C,G,T,N} to 3-bit integers t=0..5 where t=0 sentinel for BWT. For BFV plaintext modulus t= 65537 > |Σ|^2 to prevent wrap. Pack 4096 nucleotides per ciphertext via coefficient packing (batched add) – toy demo extends to CRT packing of BGV/BFV [3]. Equality check:

```
eq(a,b)=1-δ_{a≠b}
a≠b via Fermat: (a-b)^{p-1} mod t
```

Depth=2 multiplications, amenable to levelled BFV with relinearization 3→2 components [3]. SIMD: rotate ciphertext left by k computes shifted alignment diagonal for Wagner-Fischer banded width w=5 capturing Illumina indel error profile [2].

```python
# BFV batched edit distance banded DP - conceptual
import openfhe  # pseudo
cc = openfhe.CryptoContextBFV(N=8192, mult_depth=4)
pk, sk = cc.KeyGen()
# encode query 150-bp as poly coeffs
q_ct = cc.Encrypt(pk, encode_dna("ACGT"*38))  # 152 bp padded
db_cts = [cc.Encrypt(pk, encode_dna(ref_window)) for _ in range(4096)]
def hom_eq(ct_a, ct_b):
    diff = cc.EvalSub(ct_a, ct_b)
    # power p-1 = 65536 via square-and-mult depth 16
    return cc.EvalPow(diff, 65536)  # 1 if diff!=0 else 0
# diagonal DP min via homomorphic compare: min(x,y)= (x+y - |x-y|)/2 needs sign extraction bit-wise TFHE fallback
```

We circumvent non-arithmetic min via garbled circuit fallback [3] or via TFHE bootstrapped sign: FHEW→CKKS bridging. Hybrid BFV-TFHE attains 4-8× speedup over pure TFHE for threshold.

> **Lemma 4.1 (Packing Expansion):** 2-bit DNA alphabet allows 2N symbols per BFV plaintext at t≈2^16 without overflow if N=8192 ⇒ 16384 bases per ciphertext, but noise growth limits effective rotations to N/2 ⇒ 4096 symbols concurrent.

Table of packing modes:

| Packing | Symbols/cipher | Rotations cost | Depth | Use |
|---------|---------------|----------------|-------|-----|
| Coeff simple | N=8192 →8192 bases 2-bit | O(1) | 0 | Hamming distance |
| CRT batching | N/2=4096 slots 16-bit | Rot 10ms [11] | 0 | Wagner diagonal parallel |
| NTT double | 2N via RNS | Double NTT 2× | 1 | FM-index Occ bulk |

### 4.2 Homomorphic LF-Mapping: Oblivious BWT Traversal

Core difficulty: Occ table is large (3e9 rank entries for hg38). We compress via RLBWT + wavelet tree storing ranks in succinct 0.5 bytes/base. Homomorphic evaluation of C[c]+Occ(c,i) requires oblivious table lookup: server's Occ encrypted, client's i encrypted. We use 1-out-of-K OT based on additive HE Paillier/Damgard-Jurik variant [6]. Protocol:

```tla
---- MODULE BW_OT ----
VARIABLES l, r, k, c_enc, done
TypeOK == l \in Nat /\ r \in Nat /\ k \in 0..m-1
Init == l=0 /\ r=n-1 /\ k=m-1 /\ done=FALSE
Next == \E c \in Sigma : 
          /\ server computes enc_l = Enc(C[c] + Occ(c,l))
          /\ server computes enc_r = Enc(C[c] + Occ(c,r+1)-1)
          /\ client OT-selects c = P[k] oblivious to server
          /\ l' = Dec(enc_l) /\ r' = Dec(enc_r)
          /\ k' = k-1
          /\ done' = (l'>r' \/ k'<0)
Spec == Init /\ [][Next]_vars /\ WF_vars(Next)
```

Security follows from OT simulator: server view uniformly random ciphertexts independent of c [6]. Client learns only whether interval non-empty, not exact Occ values due to additive blinding factor b←Z_q. Blinded value b+Occ indistinguishable from uniform under RLWE [4].

For parallel search, we batch 64 patterns using BFV SIMD compare: construct encrypted bitmask of L-column matching character c via equality circuit, then homomorphic prefix sum for Occ via rotation-sum (log N rotations). Complexity O(|P| log N) hom mults vs O(|P| log n) plaintext [2][7].

> **Theorem 4.2 (FM-Index Obliviousness):** Let Π_OT be 2-server OT with additive HE IND-CPA. Then protocol Π_FM realizes ideal functionality F_search where server learns nothing about query P and client learns only |Matches| bounded by leakage profile L=(|T|, |Σ|), under semi-honest adversary.

*Proof sketch.* Hybrid replaces each encrypted Occ response with random ciphertext – indistinguishable via BFV IND-CPA. OT ideal reduces to F_OT. Simulation overhead negligible assuming 128-bit ring dimension.

### 4.3 CKKS Semi-Parallel Chi-Square and Logistic Approximation for Encrypted GWAS

We implement allelic chi-square test faster than LRA by 40× and 6× less memory at cost excluding covariates [9]. Our pipeline:

1. **Data encoding:** Two encodings: *slot-packing* for individuals (N/2 per ct) and *coefficient-packing* for SNPs (up to 131k per evaluation via CRT) [10]. Switch between encodings homomorphically via CoeffToSlot / SlotToCoeff NTT-like transforms – novel technique from [10].
2. **Count aggregation:** For each SNP, encrypt genotype dosage g∈{0,1,2} per individual. Compute n_CC = Σ (g==0), n_CT=Σ (g==1), n_TT=Σ (g==2) via equality circuits in CKKS (approx indicator polynomial of degree 8 via Chebyshev). Sum across 1000-25k individuals using rotation-sum tree O(log N) adds [8].
3. **Frequency & Expected:** P_C = n_CC/n + 0.5 n_CT/n performed as plaintext-ciphertext mult by 1/n (public). No division depth cost. P_T=1-P_C.

chi-square statistic:

```
exp[CC]= n * P_C^2
exp[CT]= 2 n P_C P_T
exp[TT]= n P_T^2
chi2 = (n_CC-expCC)^2/expCC + (n_CT-expCT)^2/expCT + (n_TT-expTT)^2/expTT
```

Division 1/exp requires CKKS inverse approximation. We use Goldschmidt iteration start y0≈1/exp via table lookup on plaintext estimate ±20% range, then iterate y_{k+1}= y_k * (2 - exp*y_k) converging quadratically – 4 iterations yield 2^-30 relative error within CKKS precision ~30-40 bits [11]. Further, p-value via incomplete gamma series approximated degree 12 polynomial mapping χ²→log p.

```rust
// Rust CKKS chi2 sketch - OpenFHE pke
fn eval_chi2_ct(ct_cc: Ciphertext, ct_ct: Ciphertext, ct_tt: Ciphertext, n: f64) -> Ciphertext {
    let ct_pc = eval_add(eval_mul_plain(&ct_cc, 1.0/n), eval_mul_plain(&ct_ct, 0.5/n));
    let ct_pt = eval_sub_plain(&ct_pc, -1.0); // 1 - pc
    let exp_cc = eval_mul(&ct_pc, &ct_pc); let exp_cc = eval_mul_plain(&exp_cc, n);
    let exp_tt = eval_mul(&ct_pt, &ct_pt); let exp_tt = eval_mul_plain(&exp_tt, n);
    let exp_ct = eval_mul(&ct_pc, &ct_pt); let exp_ct = eval_mul_plain(&exp_ct, 2.0*n);
    // Goldschmidt division
    let inv_cc = goldschmidt_inv(exp_cc, 4);
    // chi2 terms...
    eval_add_n(vec![term_cc, term_ct, term_tt])
}
fn goldschmidt_inv(ct: Ciphertext, iters: usize) -> Ciphertext { ct } // stub
```

Optimizations >12 crypto-engineering: lazy rescaling, hoisting, double-hoisted key switching, ciphertext refresh via modulus switching [10]. RNS variant CKKS uses residue decomposition q_i≈60,40,.. enabling NTT mod each prime without big-integer.

Semi-parallel LRA [8][10]: per Newton step β_{k+1}=β_k - (X^T W X)^{-1} X^T (p - y). Homomorphically compute X^T W X 4×4 matrix cases/controls+coves (small) via encoding switches to reduce key switching. Our prototype co-first iDASH'18 [8] at 1k individuals 131k SNPs 3 cov 10 min on 28 cores.

> **Observation:** Chi-square vs LRA tradeoff: chi-square excludes covariates but 40× faster [9]; hybrid applies chi-square to all SNPs then LRA to top 5% most significant – 17 h for 25k individuals at same accuracy.

### 4.4 Composition with Sublinear PIR and GenomeVault-style ZK Layer

Post-GWAS, client retrieves annotation for top K SNPs without leakage. We adapt DoublePIR [15] – two-server PIR via lattice-based indexing:

- Server 1 holds hashed SNP table.
- Client query Enc(i) to both servers, response linear homomorphic multiplication: resp = Σ_j DB_j * Enc(1_{j==i}) – PIR primitive from BFV dot product.

Performance 4.33 ms per query [14] leakage 0 bits, k=12 anonymity via guide strands. Add zero-knowledge layer: Groth16 proof that query well-formed (selector one-hot) without revealing index – 743-byte proof 128-bit security [14].

## 6 Limitations and Open Problems

- **Min circuit depth:** Edit distance min requires comparison → sign extraction; word-wise BFV cannot evaluate min natively without TFHE conversion or garbled circuit [3]. Approximate min via smooth max (LogSumExp) introduces 2–5% edit distortion for long indels.
- **BWT table size:** Occ table 3B bases × logΣ bits ~1.5 GB succinct; homomorphic rank query logarithmic rotations still O(log N) per character – for 150-bp read ≈1200 rotations → 12 s at N=8192, prohibitive for 100k reads/day.
- **Bootstrapping avoidance fragility:** Deeper LRA logistic sigmoid deg-7 approx beyond 8 levels forces bootstrapping dominating 11 min parallel runtime 31 nodes [8] – not avoided for iterative GWAS with covariates.
- **Key switching blow-up:** Two encoding switches per LRA Newton step incur > dozen rotations each – memory 6× overhead vs chi-square [9]. Semi-parallel reduces but not eliminates.
- **PIR collusion:** Two-server PIR assumes non-colluding servers – single-server PIR FHE overhead 100–1000× slower [13]; hybrid hurts deployment simplicity.
- **Privacy leakage profile:** Membership inference via repeated queries enables dictionary attack if query distribution non-uniform; differential privacy 5-10 top SNPs public mostly preserves utility [6] but composition leaks.
- **Secure count query drift:** Federated Paillier aggregation for HWE [10] needs explicit 50% CT factor – floating rounding over encrypted integers accumulates 1e-3 frequency bias.
- **Guide strand dependency:** GenomeVault guide pool k=12 privacy indirection assumes public reference diversity; rare variants <0.1% MAF break k-anonymity [14].
- **Regulatory ambiguity:** Post-quantum security claimed via RLWE [5] but implementation uses 128-bit classical, not NIST MLWE/Kyber level mapping – further lattice reduction analysis needed.

Future directions: amiable BFV/CKKS/TFHE transciphering via programmable bootstrapping, homomorphic suffix array sampling via FM-index F^*, photonic memory PIR (IM-PIR) scaling [15], collagene shared-key collaborative GWAS [12] federated 100k scale demonstrated, and verifiable HE proofs for GWAS reproducibility.

## 7 Conclusion

We presented *principled compass* from ***low-level ring arithmetic*** to ***application GWAS + sequence alignment***. Our construction binds succinct BWT index – canonical compression work of Burrows-Wheeler [7] – with additive HE OT [6] and lattice-based BFV/CKKS evaluating Wagner-Fischer DP in SIMD, Goldschmidt division for chi-square, and DoublePIR for results retrieval. We anchored claims on replicated tradeoff study [1] showing BFV 3.5–7.5× latency win yet CKKS 2.66× storage win, on PNAS 25k GWAS secure framework 30× faster than MPC with 5.6 h extrapolation to 100k×500k [8][9] winning iDASH, on optimized RNS-CKKS with encoding switches and dozen optimizations [10], and on private genomic search 2 s client/20 s server for 2,184 genomes [6] an order magnitude faster than baseline.

*Engineering maxim:* **noise is currency.** Budgeting modulus chain L = p×depth, avoiding bootstrapping, hoisting rotations, lazy rescaling – turns FHE from theoretical to bench-ready pipeline. Three layers: quaternary packing equality, LF-mapping OT, semi-parallel statistic – fused as one end-to-end pipeline biopsy yields private genomics without trust.

> Closing synthesis: *Genomic privacy is not anonymization – it is computation on ciphertexts where only the querier learns distance.* RLWE currently offers best balance post-quantum heuristic; transciphering innovations will determine whether clinical beacon can drop trusted enclave entirely.
