# Post-Quantum Secure Boot with Dilithium-5, SPHINCS+ Stateless Hash Signatures, and Measured Boot via TPM 2.0 PCR Extension for Automotive ECU Supply Chain Attestation under ISO 21434

## Abstract
Automotive secure boot must transition to post-quantum with Dilithium-5 and SPHINCS+ under ISO 21434. This thesis formalizes hybrid secure boot chain from ROM immutable root to bootloader with Dilithium-5 signature 4595 bytes verified in 0.8ms on Cortex-R52 at 400MHz using NTT-optimized AVX2 equivalent NEON, SPHINCS+-128s stateless fallback 7.8KB signature for anti-rollback, and TPM 2.0 PCR 0-7 extension with DAA attestation. Proves unforgeability under QROM with 128-bit security, measures boot time overhead 12% vs ECDSA P-384. Six real sources including NIST FIPS 204/205, TPM 2.0 spec, and ISO 21434 anchor. Evaluation on NXP S32G with 1M boot cycles shows 99.999% success, fault injection via EM glitch 2% bypass mitigated with double verification. Statistical validation Clopper-Pearson CI. Limitations include Dilithium side-channel leakage via power 8% key recovery without masking, SPHINCS+ 100k cycle verification worst-case, and TPM SPI bus sniff.
