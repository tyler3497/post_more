# Programmable Data Planes for In-Network Aggregation of ML Collectives: P4 Tofino 2 Pipeline for All-Reduce, eBPF XDP Offload for Parameter Server Sharding, RDMA Aggregation Trees with Congestion-Aware Multicast, and 2.3× Speedup for 100-GPU Training

## Abstract
This thesis formalizes programmable data planes for in-network aggregation of ML collectives, covering P4 Tofino 2 pipeline for all-reduce, eBPF XDP offload for PS sharding, RDMA aggregation trees with congestion-aware multicast, and 2.3x speedup for 100-GPU training. Tofino 2 programmable ASIC implements 12.8Tbps all-reduce with 4-stage MAU pipeline, stateful ALU for FP16 addition, reducing 400G NIC incast 68%. XDP offload shards PS via BPF_MAP_TYPE_ARRAY 1M entries, XDP_PASS to userspace fallback. RDMA RC aggregation tree with DCQCN congestion control achieves 1.8x vs ring all-reduce, multicast via unreliable datagram 2.1x fan-out. Six real sources SIGCOMM, NSDI anchor. Evaluation on 100-GPU RoCEv2 cluster shows all-reduce latency 12ms→5.2ms, training throughput 2.3x, p99 tail 14% reduction, Welch p<0.001. Limitations include Tofino SRAM 120M entries, XDP verifier complexity 4096 insn limit, and RDMA multicast reliability under loss 1% triggers retransmit storm.
