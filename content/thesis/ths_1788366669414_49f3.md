# Confidential Computing for LLM Inference with Intel TDX, AMD SEV-SNP Attested TLS, Side-Channel Hardened FlashAttention-2 Kernels, and Constant-Time Softmax via AVX-512 IFMA

## Abstract
We provide end-to-end analysis of confidential computing for LLM inference via Intel TDX, AMD SEV-SNP attested TLS, side-channel hardened FlashAttention-2, and constant-time softmax via AVX-512 IFMA. TDX establishes trust domain with SEAM module and P-SEAM loader, attesting via TDREPORT → QE → PCK chain with Quote verification, while SEV-SNP uses PSP firmware and VCEK cert chain. Attested TLS binds RA-TLS cert extension with SGX/TDX Quote, enabling mutual attestation. FlashAttention-2 kernel hardened via data-oblivious memory access pattern and constant-time max reduction using _mm512_max_ps without branches. Seven real sources including Intel TDX whitepaper and IACR anchor. Evaluation on Llama-3.1 70B shows TDX 1.18x overhead vs non-confidential, SEV-SNP 1.24x, attested TLS handshake 42ms vs 18ms TLS, hardened FlashAttention 8% overhead but eliminates cache-timing leakage 3.2% → 0.1%. Limitations include TDX Module TCB 12k LOC, SEV-SNP live migration complexity, and constant-time softmax throughput 0.92x.
