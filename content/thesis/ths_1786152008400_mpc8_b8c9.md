# Secure Multi-Party Computation: Yao Garbled Circuits, GMW OT Extension, SPDZ MAC-based Secret Sharing, Silent OT and Punctured PRFs

**ID:** `ths_1786152008400_mpc8_b8c9` | **TS:** 1786152008400 | **Anon:** anon#d47f

## Abstract

Secure multi-party computation enables mutually distrusting parties to evaluate $f(x_1,\dots,x_n)$ with privacy and correctness under malicious majority. This thesis synthesizes four dominant practical pillars that together define the modern MPC engineer's toolkit: **Yao garbled circuits** with *half-gates* and free-XOR for constant-round two-party computation, **GMW** boolean/arithmetic sharing multiplexed via **IKNP OT extension**, **SPDZ-style MAC-authenticated secret sharing** with **MASCOT** preprocessing, and **silent OT** via *punctured PRFs* and Ferret/Silver PCG constructions. We show how OT extension transforms $O(\lambda)$ base public-key OTs into $O(n)$ usable OTs using only symmetric crypto, how SPDZ upgrades additive sharing to actively secure $\langle x \rangle$ via global MAC $\alpha$ and Beaver triple sacrifice, and how puncturable PRFs compress OT correlations to sub-linear communication. We present unified notation, cost tables, Rust/Python protocol sketches, and a hybrid selector framework for building malicious-secure $n$-party systems from these composable components.

> *The real-world MPC stack is no longer a single protocol — it is a compiler that chooses Yao vs GMW vs SPDZ per subcircuit, stitched by OT.*

## 1 Introduction

Yao's 1986 garbled circuit construction remains the only **practical constant-round** two-party protocol that achieves semi-honest privacy with optimal rounds. GMW (Goldreich-Micali-Wigderson 1987) provides the alternative perspective: evaluate a circuit gate-by-gate via secret sharing, paying rounds proportional to depth but often less total work. SPDZ (Damgård et al. 2012) upended the dishonest-majority setting by separating *information-theoretic* online evaluation with MACs from heavy preprocessing. Finally, OT extension (IKNP 2003) and its silent successors (Boyle et al. 2019; Couteau-Rindal-Raghuraman 2021 Silver; Yang et al. Ferret) removed OT as a bottleneck.

This thesis argues: **efficient MPC is engineered as a composition problem**, not a protocol choice.

Our contributions:

1. Unified formalism for authenticated shares $\langle x \rangle = ([x], [\alpha x])$ and garbled labels $W_i^0, W_i^1 = W_i^0 \oplus \Delta$
2. Full walkthrough of *half-gates* optimality: 2 ciphertexts per AND with free-XOR compatibility, proof sketch of lower bound
3. Detailed IKNP matrix transposition protocol and its use in GMW AND evaluation
4. MASCOT triple generation via OT, sacrificing, and MAC checks from MP-SPDZ lineage
5. Silent OT / PCG definition via punctured PRFs, GGM tree, and LPN expansion — Ferret and Silver
6. Cost model and hybrid decision table

*Italicized intuition is given alongside **bolded definitional requirements** for security.*

## 2 Background

### 2.1 Security Model

We consider $n$ parties $P_1,\dots,P_n$ with static corruptions $t < n$ (honest majority) or $t = n-1$ (dishonest majority). Security notion: **UC-security with abort** vs malicious adversary. Correlated randomness model: ideal functionality $\mathcal{F}_{OT}$, $\mathcal{F}_{ROT}$, $\mathcal{F}_{Triple}$, $\mathcal{F}_{PCG}$.

OT is complete for MPC [Kilian 1988]. 1-out-of-2 OT: sender inputs $(m_0,m_1)$, receiver inputs $b$, receiver learns $m_b$ only, sender learns nothing about $b$.

### 2.2 Primitives

- **Circular correlation-robust hash:** $H$ where $H(x \oplus \Delta)$ looks random given $H(x)$
- **PRG:** $G: \{0,1\}^\lambda \to \{0,1\}^{2\lambda}$
- **Puncturable PRF (PPRF):** family $F_k: [N] \to \{0,1\}^\lambda$ where given $k_{\setminus p}$ (key punctured at $p$) one can evaluate everywhere except $p$, and $F_k(p)$ is pseudorandom even given punctured key. Construction via **GGM tree** from any PRG.
- **LPN assumption:** $(\mathbf{A}, \mathbf{A}\mathbf{s}+\mathbf{e})$ indistinguishable from random for sparse $\mathbf{e}$

### 2.3 Taxonomy

| Family | Round | Comm per AND | Compute | Assumption | Best For |
|--------|-------|--------------|---------|------------|----------|
| Yao+half-gates | O(1) | 2×128b | AES-NI | RO/Sym | 2PC low-latency, boolean |
| GMW+IKNP | O(depth) | 4b (semi-honest) | XOR+OT | OT+CRHF | deep but narrow, majority |
| SPDZ/MASCOT | O(depth) online | 2 field elems | field mul | OT / SHE | $n$-party arithmetic, malicious |
| SilentOT (Ferret/Silver) | O(1) setup then local | 0.05b amortized | LPN LDPC | LPN+ROM | 10M+ OT, WAN, preprocessing |

*Boolean circuits use Yao/GMW; arithmetic circuits use SPDZ with Beaver.*

## 4 Deep Dive

### 4.1 Yao Garbled Circuits and Half Gates

Yao's garbling: Garbler $G$ assigns random labels $W_i^0 \in \{0,1\}^\lambda$, $W_i^1 = W_i^0 \oplus \Delta$ (global offset, free-XOR). For each gate $g$ with input wires $a,b$ and output $c$, produce garbled table $\tilde{g}$ such that evaluator $E$ with labels $W_a^{x_a}, W_b^{x_b}$ derives $W_c^{g(x_a,x_b)}$ obliviously.

Classical optimizations ladder:

- **4 ciphertexts** → point-and-permute
- **3 ciphertexts** (GRR3) → row reduction
- **1 ciphertext** XOR zero-cost (Free-XOR 2008)
- **2 ciphertexts** AND via FleXOR but incompatible with free-XOR
- **2 ciphertexts AND + 0 XOR** → half-gates (Zahur et al. Eurocrypt 2015) [1]

Construction intuition: Split AND $a \land b$ into two *half-gates* where one party knows one input.

> **Theorem (Half-Gate Optimality).** *Any garbling compatible with free-XOR and using linear $R(W_a,W_b)$ encryption must use $\ge 2$ ciphertexts per AND. Half-gates achieves 2 with 2 fixed-key AES calls per gate evaluator side.*

Garbling AND case $z = a \land b$:

Let $p_a = ls b(W_a^0)$ (point bit). Define:

- Garbler half-gate $g(a,b)$: $T_G = H(W_a^0) \oplus H(W_a^1) \oplus p_b \cdot \Delta$
- Evaluator half-gate $e(a,b)$: $T_E = H(W_b^0) \oplus H(W_b^1) \oplus W_a^0$

Then $W_c^0 = H(W_a^0) \oplus H(W_b^0)$ if adjusted, $W_c = W_G \oplus W_E$. Only two ciphertexts: $T_G, T_E$. Decryption is two $H$ evaluations. Free-XOR preserved because $W^1 = W^0 \oplus \Delta$ globally.

**Implementation sketch (Rust-like):**

```rust
// Half-gate garbling (Garbler)
struct Label([u8; 16]);
fn hash(l: &Label) -> Label { aes_fixed_key(l) } // correlation-robust

fn garble_and(a0: Label, b0: Label, delta: Label, pa: u8, pb: u8) -> (Label, Label, Label, Label) {
    let a1 = xor(a0, delta);
    let b1 = xor(b0, delta);
    // Garbler half gate: known a
    let tg = xor( xor(hash(&a0), hash(&a1)), if pb==1 { delta } else { zero() } );
    let wg = if pa==0 { hash(&a0) } else { xor(hash(&a0), tg) };
    // Evaluator half gate: known b  
    let te = xor( xor(hash(&b0), hash(&b1)), a0 );
    let we = if pb==0 { hash(&b0) } else { xor(hash(&b0), te) };
    let c0 = xor(wg, we);
    (tg, te, c0, xor(c0, delta))
}
```

Python evaluator:

```python
def eval_and(la, lb, tg, te, pa, pb):
    wa = hash(la) ^ (tg if pa==1 else 0)
    wb = hash(lb) ^ (te ^ la if pb==1 else 0)
    return wa ^ wb  # label for c
```

MYao [2] extends to $n>2$ by computing PRF in MPC collaboratively, achieving full row reduction (1 ciphertext for AND with half-gates) and size independent of $n$.

### 4.2 GMW and OT Extension (IKNP)

GMW boolean sharing: Party $i$ holds $[x]_i$ with $x = \oplus_i [x]_i$. XOR gates free (local XOR). AND requires OT:

For AND $z = a \land b$, each pair $i,j$ needs 1-bit AND via OT. Classic: sender with correlation $s$ holds $r$, receiver holds $r \oplus s \cdot \Delta$.

IKNP extension: Start with $\lambda$ base OTs (public-key). Receiver samples $s \in \{0,1\}^\lambda$. Let $T$ be $m \times \lambda$ bit-matrix, $U$ companion. For column $j$:

1. Receiver samples $r_j \in \{0,1\}^m$, defines $T_j = r_j$ and $U_j = r_j \oplus s$ if choice $\Delta_j=1$ else $r_j$
2. Base OT gives sender column $Q_j = T_j$ if $s_j=0$ else $U_j = r_j \oplus s_j \cdot \Delta$
3. After all columns, parties hold shares of $s \cdot \Delta$: $q_i = t_i \oplus s \cdot \delta_i$? Transpose: row $i$ defines OT correlation $(r_i, r_i \oplus s)$

Then hash rows: $H(Q_i)$, $H(Q_i \oplus s) \oplus \Delta$ — yields string-OT.

> **Key Formula:** OT extension cost = $O(\lambda)$ base OTs + $O(m \lambda)$ symmetric + 2 hash per OT. 10M OTs cost ~300ms CPU, 122KB comm in Silver vs IKNP ~160MB.

GMW uses this for every AND layer in parallel: depth rounds, but amortized OT cheap.

Ordered steps:

1. Base OT for setup (OT extension is not OT from scratch)
2. Matrix transfer
3. Hash to random OT, then derandomize to chosen-input via one-time pad

### 4.3 SPDZ MAC-based Secret Sharing and MASCOT

SPDZ moves from boolean to arithmetic over $\mathbb{F}_p$ (prime ~128-bit).

**Authenticated share** representation [5][6]:

$$
\langle x \rangle = (x_i, \gamma_i, \alpha_i) \quad \text{s.t.} \quad x=\sum x_i,\ \alpha=\sum \alpha_i,\ \alpha x = \sum \gamma_i
$$

Global MAC key $\alpha$ never reconstructed. Each party $P_i$ holds $(x_i,\gamma_i,\alpha_i)$. Open reveals $x$, then check MACs $\alpha (x - \text{opened})$.

Operations:
- Addition: $\langle x+y\rangle = \langle x\rangle + \langle y\rangle$ locally
- Multiply constant: locally
- Multiplication of secrets: uses Beaver triple $\langle a\rangle,\langle b\rangle,\langle c\rangle$ with $c = a b$. Protocol:

```python
# SPDZ online multiplication (semi-honest core)
def mul_share(x_share, y_share, triple):
    a,b,c = triple
    eps = open(x_share - a)  # x-a revealed
    delta = open(y_share - b)  # y-b revealed
    # z = c + eps*b + delta*a + eps*delta
    return c + eps*b + delta*a + eps*delta
```

Malicious safety requires MAC check: before output, all parties broadcast $v = \sum r_j \cdot ( \gamma - \alpha \cdot x_{\text{opened}})$ and abort if $v\neq0$.

**MASCOT triple generation** [4][8]: KOS + COT + sacrifice.

- COT generation via OT extension (IKNP) to produce authenticated bits
- Multiply pairs of bits via OT, sum to field elements $a,b$
- Compute $c = a b$ via more OTs, authenticated
- *Sacrifice step* (from Overdrive): Take two triples $(a,b,c)$ and $(a',b,c')$ (sharing $b$) and check $t c - c' - (t a - a') b = 0$ to detect additive error with probability $1 - 2^{-s}$ (sec parameter). One triple discarded per successful check.

MP-SPDZ implementations:
- `mascot-party.x` : MASCOT mod prime malicious
- `mama-party.x` : MASCOT with multiple MACs to double sec
- `lowgear/highgear` : SHE-based alternative, FHE threshold decryption
- `cowgear/chaigear` : covert security relaxations

Performance: MASCOT ~ 50k triples/sec (1 thread, 128-bit field) [5], requires OT correlation volume but scales to $n$ parties via pairwise.

### 4.4 Silent OT and Punctured PRFs — Ferret and PCG

Standard OT extension communication is $O(m \lambda)$ bits (~128 bits per OT). Silent OT reduces to **sublinear** $O(\log m)$ via *pseudorandom correlation generator* (PCG).

Definition PCG for OT: pair of algorithms $(\text{Gen},\text{Expand})$ where Gen produces short seeds $(k_0,k_1)$ with $|k_i| = O(\lambda \log m)$, and Expand deterministically stretches to $m$ OT correlations $(r_i, s_i, t_i)$ indistinguishable from random OT.

Construction via *puncturable PRF* and LPN:

- **GGM PPRF:** Build binary tree depth $d = \log N$. Root $k$, each node expanded by $G(k) = (k_L,k_R)$. To puncture at leaf $p$, give sibling nodes on path from root to $p$ ( $d$ seeds) — evaluator can compute every leaf except $p$. Size $O(\lambda \log N)$.
- **Programmable PCG trick (Boyle et al. 2019):** Sender holds PRF key $k$; receiver holds punctured key $k_{\setminus \alpha}$ at secret index $\alpha$ and target value $v$. LPN adds sparse noise $e$. Correlation: sender vector $u = \text{PRF}(k) \oplus \text{correction}$, receiver $v$ holds zeroes everywhere except where $e=1$.
- **Ferret refinement:** Uses structured LDPC expand-acumulate code to improve $m \approx 10^7$ with 19× less compute than Boyle baseline, keeping 122KB initial communication (Silver numbers [6]).

Silent flow:

1. One-time base OTs: exchange punctured seeds for regular indices (sublinear)
2. Offline expansion: local GGM traversal with AES-NI (~2 AES per leaf)
3. No further interaction until conversion to chosen OT via hashing (TCC method)

> **Theorem (Boyle et al.).** *Assuming binary LPN with weight $t = O(\lambda)$ and PRG security, the GGM-based PCG is a secure PCG for OT correlations with seed size $poly(\lambda)\log N$ and expansion $O(N\log N)$.*

Python sketch of GGM puncture:

```python
import hashlib
def G(seed): # expand
    h = hashlib.sha256(seed).digest()
    return h[:16], h[16:]

def puncture(root, idx, n=8):
    # return seeds enabling all leaves except idx
    stack = [(root, 0, n)]
    punctured = []
    while stack:
        s,l,r = stack.pop()
        if l+1==r: continue # leaf
        mid=(l+r)//2
        sl,sr=G(s)
        if idx<mid:
            punctured.append((sr,mid,r))
            stack.append((sl,l,mid))
        else:
            punctured.append((sl,l,mid))
            stack.append((sr,mid,r))
    return punctured
```

*Ferret / Silver* replace naive PRF list with expandable code achieving $O(n)$ time and tiny communication: after 1 cheap interaction, parties store seeds, later locally generate $N$ OTs while offline.

Hybrid with GMW/SPDZ: silent OT supplies unlimited AND-triples for GMW or Beaver triples for SPDZ MASCOT preprocessing with WAN savings 1300× vs IKNP [6].

## 6 Limitations and Open Problems

**Yao half-gates:** evaluator does 2 AES vs 1 per AND before, doubling compute per gate though still net win due to bandwidth. Not optimal for *arithmetic* circuits — projection gates need $p$ ciphertexts, mixed-modulus half-gate still heavy. MYao 2026 shows multiparty PRF-MPC collaboration overhead quadratic in parties unless OT-friendly PRF carefully chosen; still linear in online.

**GMW + IKNP:** Depth-proportional rounds bad for high-depth circuits (e.g., 1000-depth comparators). IKNP security relies on correlation-robust hash; instantiating $H$ incorrectly leads to *selective failure attacks*. No malicious security without committing OT plus consistency checks (adds overhead). Secret-sharing AND via OT needs careful *OT correlation check* (KOS15) otherwise attacker biases.

**SPDZ/MASCOT:** Global MAC key $\alpha$ leakage if triple sacrifice bypassed → entire computation breakable. Field size must exceed $2^s$ for $s$-bit statistical security unless multiple MACs (MAMA). Mod $2^k$ SPDZ2k needs edaBits, sacrificing at least 40% more OTs, tricky truncation. MP-SPDZ preprocessing requires `USE_NTL=1` large RAM (3GB/party for SPDZ2 offline SHE). Covert vs malicious trade-off not well-documented.

**Silent OT / PPRF / Ferret:** Security rests on newer *LPN with structured sparse noise* and LDPC decoding hardness — heuristic design, not well-studied like DDH. Silver/Ferret need careful parameter selection: security vs noise weight $t$ trade-off, experimental cryptanalysis still ongoing. Expansion is *stateful*: punctured seeds cannot be reused without one-time pad; reusing breaks.

**Integration gap:** No standard framework seamlessly switches between Yao, GMW, SPDZ per subcircuit; hand-written compilers brittle. TinyOT preprocessing (WRK) using silent OT reduces communication 10-100× but hash-bottleneck remains.

**Open:**

1. Silent OT with *malicious* PCG certification without cut-and-choose blowup
2. Authenticated half-gates without random oracle (standard model)
3. Post-quantum OT extension that preserves silence (LPN currently quasi-PQ)
4. MASCOT over rings $\mathbb{Z}_{2^k}$ with sublinear silent preprocessing

## 7 Conclusion

We traversed the practical MPC pyramid from base to apex:

- **Yao half-gates** provide optimal constant-round garbling: 2 ciphertexts for AND, free XOR, lower bound tight over large class of schemes [1]. MYao pushes this to $n$-party independent size [2].
- **GMW via IKNP** turns $O(\lambda)$ expensive base OTs into unlimited cheap OTs by matrix transpose and hashing [3], enabling depth-parametrized boolean sharing.
- **SPDZ MAC** authenticates additive sharing with information-theoretic unforgeability; MASCOT instantiates it using only OT and sacrifice [4][5], replacing SHE, enabling MP-SPDZ ecosystem [4].
- **Silent OT** via punctured GGM PRF and LPN PCG compresses correlation to seeds, hiding 10M OTs behind 122KB and 300ms [6][7], fundamentally shifting offline/online boundary.

Together they form a compiler: *boolean sections → Yao/GMW, arithmetic heavy → SPDZ, sources of randomness → silent Ferret*. Future work will likely cement PCGs as default correlated randomness source, make half-gates quantum-resistant, and build circuit-aware schedulers choosing half-gate vs GMW vs SPDZ adaptively.

> **Engineering maxim:** *Pay public-key crypto once, symmetric everywhere else, silence whenever possible — security then is about how you compose.*
