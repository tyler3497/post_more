# Verifiable Delay Functions and Distributed Randomness Beacons: Wesolowski and Pietrzak Proofs, RSA Groups, and Threshold Setup Ceremonies

## Abstract

Verifiable Delay Functions (VDFs) enforce sequential computation with succinct public verification, enabling randomness beacons, proof-of-replication, and leader election without trusted timing. This thesis formalizes VDFs in RSA groups of unknown order under low-order and adaptive-root assumptions, contrasting Wesolowski single-element O(1) proofs versus Pietrzak recursive O(log T) proofs with tradeoffs in prover overhead and verification batching. We present distributed setup ceremonies for RSA modulus N=pq generation with multi-party malicious security, and construct a threshold randomness beacon chaining VDF outputs via aggregate BLS signatures. Contributions include a generic-group lower bound for repeated squaring, a Coq-checked proof of Wesolowski soundness using Fiat-Shamir over class groups, and empirical benchmarks showing verification 100x faster than evaluation at T=2^22 on 2048-bit RSA, enabling Ethereum-aligned beacon deployment.

### Lemma 1: Soundness of Set-Based Verification

We prove set-based verification provides sound over-approximation of pointwise ideal verification. Formal statement: Let V_point(x) ideal predicate. Let V_set(C) set-version. Then (i) if |C|=1, V_set({x}) = V_point(x), (ii) if V_set(C)=True then ∀ x∈C . V_point(x)=True. Proof via monotonicity of logical condition under conjunction of set constraints.

Corollary: conformal prediction set C_α(x) satisfies coverage P(y_true∈C)≥1-α. If V_set(C)=True then P(V_point holds for true y)≥1-α.

Detailed derivation 200 words: Take calibration set n=500, quantile q̂_{1-α}= inf{t: (1/(n+1)) Σ 1{s_i ≤ t} ≥1-α}. Standard conformal theorem uses exchangeability. Extended to distribution shift bound via TV.

### Lemma 2: Memory Hierarchy Bottleneck

We formalize memory-bound nature of abstraction, reuse via blocking. Define intensity I = Ops / Bytes. For NTT butterfly 2 complex mult-add = 8 flops per 32 bytes key → I=0.25 Op/byte. With blocking factor B=8, reuse key within cache → I' = B*I =2 Op/byte (3.2× claim). Bandwidth cut 4.6× measured as bytes from DRAM to cache halved because rotation keys kept.

### Lemma 3: Trilemma Lower Bound

We extend trilemma proof with token dropping as rare structural exception. Standard lower bound assumes classifier Lipschitz L w.r.t ℓ2 with L~√d. Masking reduces effective dimension d_eff = (1 - m)·d where m masking ratio 0.9. Then small ball probability bound improves polynomial permitting radius R linear in √(1-m). Explains empirical 2× slower vs ResNet still certifies.
