# Autonomous Database Index Selection: Learned Cost Models, What-If Call Optimization, Reinforcement Learning with HypoPG, and Workload Forecasting ## Abstract This thesis provides a rigorous, artifact-evaluable treatment of autonomous database index selection: learned cost models, what-if call optimization, reinforcement learning with hypopg, and workload forecasting, synthesizing database systems and self-tuning foundations with 2026 systems practice. We formalize cost models $C(N)=\alpha T+\beta E+\gamma S+\delta P$, invariants $Inv=TypeOK \land Safety \land Liveness$, and coherence protocols spanning autonomous DB index selection, drawing on 7 authoritative sources including arXiv preprints, IETF/IEEE standards, USENIX OSDI/NSDI, ACM SIGCOMM/SOSP, and domain venues.
