# Privacy-Preserving Contact Discovery: PIR, OPRF, Signal Private Contact Discovery, Oblivious Dictionary, Circuit-PSI and Homomorphic Label-PSI for Billion-User Scale

## Abstract

Contact discovery maps a client's address book to the set of registered users without revealing non-member contacts, yet naive hashing leaks social graphs at Internet scale. This thesis systematizes the cryptographic migration from trusted-hardware enclave designs to pure-cryptography protocols that achieve sublinear communication for billion-user databases. We analyze Private Information Retrieval with preprocessing for cuckoo-filter PSI, 2HashDH OPRFs from RFC 9497, Signal's SGX-based and ORAM-hardened contact discovery, oblivious dictionary constructions from FHE and OKVS, and Circuit-PSI and Label-PSI that enable secret-shared payloads and homomorphic post-processing. We prove simulation security against semi-honest servers, evaluate communication versus compute tradeoffs for 1024-contact clients against 67M–1B server entries, and present a hybrid architecture combining rate-limited OPRFs with doubly-oblivious Path ORAM and labeled homomorphic PSI that preserves functionality for messaging metadata while resisting enumeration and side-channel leakage.

## 1 Introduction

**Privacy-preserving contact discovery** is the gateway predicate for every end-to-end encrypted messenger. A user holds set $C = \{c_1, ..., c_m\}$ with $m \approx 2^{10}$, a service holds $S$ with $|S| \approx 2^{26}$ to $2^{30}$, and the client must learn $C \cap S$ *without* revealing $C \setminus S$ [1][3]. Naive upload of `SHA256(phone)` fails catastrophically: phone numbers inhabit a $\approx 34$-bit space, vulnerable to rainbow tables and to correlation via truncated hashes [1].

The tension manifests across three axes:

- **Functionality:** modern messengers need not only membership bits but *labels* – public keys, routing hints, username proofs – demanding *Label-PSI* not just PSI [5][6].
- **Scale:** per-client linear scans over $N=10^9$ are infeasible on mobile radios; we require $O(m \log N)$ communication [3][4].
- **Trust model:** hardware enclaves (Intel SGX) provide remote attestation but impose vendor TCB and microarchitectural side-channel risk, pushing the field toward OPRF and FHE-based oblivious dictionaries [1][2].

> **Theorem 1 (Ideal Contact Discovery):** An ideal functionality $\mathcal{F}_{CD}$ receives $C$ from client, $S$ from server, outputs $I=C\cap S$ and associated labels $L(I)$ to client and $|C|$ or $\bot$ to server, leaking nothing else. Real-world protocols realize $\mathcal{F}_{CD}$ up to statistical distance $2^{-40}$ under rate limiting.

This thesis unifies five generations:

1. **Enclave-based PIR with oblivious hash tables** – Signal's 2017 design [1]
2. **PIR-PSI hybrids** – Demmler et al. 2018 preprocessing PIR + PSI [3]
3. **OPRF-based 2HashDH** – Jarecki-Krawczyk-Rosu standardization RFC 9497 [4]
4. **Oblivious Dictionary / OKVS / OMR** – FHE-encoded dictionaries for message retrieval [7]
5. **Circuit-PSI and Label-PSI** – secret-shared intersection and homomorphic payload computation [5][6]

We contribute a taxonomy, formalisms, and a billion-scale hybrid blueprint.

## 2 Background

### 2.1 Threat Model and Definitions

Semi-honest server, malicious client enumeration limited by rate-limiter. Client privacy requires *obliviousness*: server's view $View_S(C)$ indistinguishable for any $C, C'$ of equal size. Server privacy requires *payload hiding* beyond intersection. Forward secrecy of contact queries via blinded OPRFs [4].

* **PIR:** Client retrieves $DB[i]$ without server learning $i$ [3].
* **OPRF:** Client obliviously evaluates $F_k(x)=H_2(x, H_1(x)^k)$ where $k$ is server secret [4].
* **PSI:** Two-party computation of intersection only.
* **Circuit-PSI:** Outputs additive shares $\langle b_i \rangle$ where $b_i=1$ iff $x_i \in Y$ for downstream MPC [5].
* **Label-PSI:** Intersection plus label $l_j$ associated with server element [6].
* **Oblivious Dictionary / OKVS:** Encoding of key-value map where encoding leaks nothing about keys if values random [7][5].

### 2.2 Signal's Evolution

Signal's original private contact discovery used **truncated hash bucketing** with SGX enclave processing [1]. Clients sent encrypted contacts over a Noise-secured channel terminating *inside* enclave; remote attestation verified `MRENCLAVE` equals published open-source measurement. Inside enclave, an *oblivious hash table* avoids branch-dependent memory accesses:

> **Enclave oblivious invariant:** For every query, every cache line of hash table is accessed, comparison done in constant-time `memcmp`, result write touches same line irrespective of match [1].

In 2022 Signal migrated to **Path ORAM** to reduce linear scan $O(N)$ to $O(\log^2 N)$ per batch while maintaining doubly-oblivious memory trace [2]. ORAM stash and position map remain in enclave; external memory accesses are rerandomized.

## 3 Methodology

### 3.1 PIR-PSI Construction

We follow Demmler-Rindal-Rosulek-Trieu [3]:

- Server preprocesses $S$ into $2$ Cuckoo hash tables $T_0,T_1$ with $k$ hash functions.
- Client with $C$ size $m=1024$ computes cuckoo positions for each $c_i$.
- Offline: server builds $\ell$ PIR databases, each $D_j$ = bitvector of presence.
- Online: client issues batch PIR queries for positions; server replies with single-bit answers; client reconstructs intersection.

Communication $4.28$ MiB for $67$M entries, $1.36$ sec multi-threaded [3]. We extend to **doubly-opportunistic PIR** with client hints (TreePIR) for sublinear server compute [3].

### 3.2 OPRF 2HashDH Instantiation

Per RFC 9497 [4] on `ristretto255` or `P-256`:

```python
# Client - 2HashDH OPRF
import hashlib, secrets
from curve import hash_to_group, mul, inv

r = secrets.randbelow(order)
H = hash_to_group(phone.encode())  # RFC9380
blinded = mul(H, r)
# Server
evaluated = mul(blinded, k_server)
# Client unblind
N = mul(evaluated, inv(r))  # = k*H
out = hashlib.sha256(b"Signal-CDS-2024" + N.to_bytes()).hexdigest()
```

Security: **OMDH** and **q-DL** in AGM. Rate-limiting via token bucket prevents enumeration of $10^{10}$ space. Threshold variant: $k = k_1+k_2+k_3$ additive shares across three CDS servers; no single server can offline brute force [4].

### 3.3 Oblivious Dictionary from FHE

We formalize **Oblivious Dictionary** as OKVS with statistical indistinguishability if values uniform [7][5]. Construction uses **Fully Homomorphic Encryption** (BFV/BGV) to encode dictionary payloads:

- Server encodes $(y, label_y)$ into polynomial $P$ where $P(H(y)) = Enc(label)$.
- Client sends homomorphic encryption of $x$ queries.
- Server homomorphically evaluates `EQ` circuit via Frobenius and returns ciphertexts that decrypt to label iff match.

Leakage: only size. Compared to naive FHE PSI [6] with $O(N_y \log N_x)$ communication, our sparse OKVS variant reduces to $O(N_y)$ [5].

### 3.4 Circuit-PSI and Homomorphic Label-PSI

Circuit-PSI functionality $\mathcal{F}_{cPSI}$ [5]:

```
Receiver X={(xi,~xi)}_n, Sender Y={(yj,~yj)}_m
Output shares ai, bi s.t. if xi=yj then ai+bi = (0,~xi,~yj) else (1,0,0)
```

We use **Batched OPPRF** from [5]: sender programs PRF to map its set to 0, random otherwise; receiver queries; equality test via garbled circuits or VOLE-PSI.

Label-PSI extension: sender homomorphically encrypts labels under BFV with receiver's key; circuit outputs *encrypted* label share. Homomorphic post-processing enables private routing table computation without revealing which contacts matched.

## 4 Deep Dive

### 4.1 Signal Private Contact Discovery v1 and v2

v1: SGX + oblivious hash table [1] achieves $>1$B users by batching $N_{batch}=4096$ requests, amortizing ECALL overhead. Side-channel defenses: disable HT, flush L1 on enclave exit, constant-time `cmov`, **write-only** result cache line. Attestation: IAS quote binds `MRENCLAVE` to ECDSA.

v2: **Path ORAM** layer [2] replaces linear scan $O(N_{reg})$ with $O(\log N)$ tree accesses. Each ORAM block = 16 users. Position map $2^{28}$ entries stored recursively. Obliviousness proof via simulation of access pattern independent of query. Performance: 40ms p95 vs 180ms linear for $N=10^8$; CPU savings 6x.

*Tradeoff table:*

| Design | Comm. | Server Compute | Trust Assumption | Label Support |
|--------|-------|--------------|------------------|---------------|
| Truncated Hash | $O(m)$ | $O(m)$ | semi-honest | no |
| SGX Linear | $O(m)$ | $O(N)$ | SGX + Intel | yes |
| SGX + ORAM | $O(m \log N)$ | $O(m \log^2 N)$ | SGX + ORAM | yes |
| PIR-PSI | $O(m \log N)$ | $O(N)$ offline, $o(N)$ online | DLP/OT | limited |
| OPRF PSI | $O(m)$ | $O(m+N)$ | OMDH | yes via extra round |
| Circuit-PSI | $O(m+n)$ | $O(m+n)$ | OT + OKVS | full MPC |

### 4.2 OPRF Security and Deployment Hardening

2HashDH proof in UC with $\mathcal{F}_{OPRF}$ leakage $\le \log_2 Q /2$ bits due to Cheon attack [4]. Mitigations: rotate $k$ every 24h, cap $Q=10^6$/key, use `P-384` for 128-bit residual. Signal's CDSI uses 3-server threshold OPRF, each runs in separate jurisdiction; client secret-shares blinding across them. This matches Privacy Pass architecture [4].

Enumeration resistance: phone numbers low-entropy; OPRF alone insufficient. Signal composes OPRF with **rate-limiting + attestation + proof-of-ownership** via SMS OTP before OPRF query allowed. This binds $C$ to owned numbers, not adversary-chosen dictionaries.

### 4.3 Oblivious Dictionary, OKVS and OMR Unification

**Definition:** An OKVS is *doubly oblivious* if for random values $Encode(K,V)$ is indistinguishable from random [5]. Construction via **PaXoS** (Probe-and-XOR-of-Strands) solves $M x = v$ where $M$ sparse 2-regular bipartite graph; failure $\approx 2^{-40}$ with $1.23n$ size.

We lift OKVS to **Oblivious Dictionary for CD**: server holds map `phone -> sealed_sender_key`. It encodes map into OKVS with random masking; clients retrieve via OPPRF decoding. Unlike PIR, no per-query public-key op after setup.

FHE-based variant [7] enables *key-private* message retrieval: clue key = FHE pubkey, detector scans board evaluating AND of FHE ciphertexts homomorphically. Cost ~$3.36 per million messages scanned [7] – comparable to ORAM CDS.

### 4.4 Circuit-PSI for Post-Intersection Payloads

Circuit-PSI shines when intersection alone insufficient. Example: private group membership proof, sealed sender certificate issuance only for contacts.

Protocol from Hao et al. 2023 [5] achieves **sublinear communication** for unbalanced sets: $1.84$–$48.86\times$ reduction vs prior garbled-circuit PSI, via **sparse OKVS** and VOLE.

Homomorphic Label-PSI adds BFV layer:

```
ct_label = BFV.Encrypt(pk_client, label_y)
share = OPPRF_decode(x_i) XOR Hash(y_j)
ct_out = ct_label * share  # homomorphic mul by 0/1
```

Client decrypts; server learns nothing. Enables private *FindMyFriends* key exchange.

### 4.5 Billion-Scale Architecture Synthesis

Proposed hybrid for $10^9$ users:

1. **Enrollment:** User registers, server inserts $OPRF(phone)$ into cuckoo filter.
2. **Discovery:** Client blinds $m=1000$ contacts via 2HashDH, threshold servers evaluate, client derives tokens.
3. **PIR retrieval:** Tokens used as PIR keys to fetch labels from OKVS-encoded dictionary sharded across 64 nodes.
4. **Circuit extension:** For mutual-contact or blocked-contact logic, shares fed into GMW circuit inside enclave or via MPC.

Quantitative: $m=1024$, $N=1B$, $O(m)=32$KB OPRF up+down, PIR $12.5$MB for 5k vs 16M example [6] scaling to ~80MB for 1B – acceptable over WiFi, heavy on cellular, thus ORAM-enclave fallback.

## 5 Empirical / Proofs

### 5.1 Security Proofs Sketch

**Lemma 1 (OPRF Obliviousness):** Under OM-DH, server view $r*H(x)$ uniformly random in group, independent of $x$ [4].

*Proof.* $r$ uniform scalar, $H(x)$ group element, scalar mul by random permutation.

**Lemma 2 (OKVS Obliviousness):** If values uniform, PaXoS encoding statistically hides keys [5].

**Theorem 2 (Circuit-PSI Realizes $\mathcal{F}_{cPSI}$):** Simulator programs OPPRF outputs to fake $0$ for intersection slots, random otherwise; indistinguishability via PRF security and OT.

> **Corollary:** Hybrid CDS realizes $\mathcal{F}_{CD}$ with leakage $|C|$ only, assuming SGX integrity or OPRF threshold non-collusion.

### 5.2 Performance Evaluation

Based on prototypes [3][5][6][7]:

- PIR-PSI 67M: 1.36s wall, 4.28 MiB [3]
- VOLE-PSI 1M: ~16s [5]
- Sparse OKVS encode 1M: 20s init, 40μs query [5]
- BFV Label-PSI 5k×16M: 36s online, 71s offline, 12.5MB [6]
- FHE OMR scan: $3.36 per 1M msgs [7]

Memory: OKVS table $1.23\times$ overhead vs hash table, but obliviousness free.

Horizontal scaling: PIR shards linearly; OPRF stateless, embarrassingly parallel; ORAM requires sticky position map – shard by prefix.

### 5.3 Side Channels and Auditing

SGX attacks (Foreshadow, Plundervolt) break confidentiality; Signal's mitigation: migrate to **AMD SEV-SNP** or pure crypto fallback [2]. Constant-time coding verified via `ctgrind` and `dudect`. Remote attestation transparency log append-only; reproducible builds ensure `MRENCLAVE` matches GitHub source [1].

## 6 Limitations

- **Phone number entropy:** OPRF without rate-limit still brute-forceable by colluding servers with $2^{34}$ trials. Requires OTP binding and IP reputation [1][4].
- **Revocation and churn:** User deletion requires OKVS re-encode $O(N)$; incremental OKVS via cuckoo filter delta update leaks churn pattern.
- **Label size:** Homomorphic Label-PSI ciphertext expansion $\approx 10\times$; large labels (e.g., X3DH prekeys 96B) inflate to ~1KB ciphertext, prohibitive for $m=1000$.
- **SGX TCB:** Intel microcode, ME, IAS still trusted; open-source alternatives (Keystone, OpenEnclave) lack performance [2].
- **Circuit-PSI round complexity:** 2–3 rounds vs 1-round OPRF PSI, increases mobile tail latency on lossy networks.
- **Post-quantum:** 2HashDH relies on DL; migration to **lattice OPRF** (e.g., Boneh et al.) needed for PQ; no RFC yet.
- **Regulatory:** Metadata-free design conflicts with lawful access demands; server cannot prove non-membership to third party.

## 7 Conclusion

We charted the evolution from SGX-oblivious hash tables to threshold OPRFs, OKVS oblivious dictionaries, and circuit-PSI with homomorphic labels. Each step trades trust for cryptography: enclaves fastest for billion-scale today [2], OPRF PSI gives pure-crypto membership with $O(m)$ communication [4][3], and sparse-OKVS circuit-PSI unlocks arbitrary post-intersection MPC at $1.8$–$48\times$ savings [5]. Label-PSI via BFV [6] and compact FHE OMR [7] completes functionality for encrypted messengers that must distribute keys without learning social graph.

Future work: **post-quantum OPRF from Module-LWE**, updatable OKVS with forward-secure puncturing, and formal verification of constant-time ORAM in Rocq. The hybrid enclave-crypto design – OPRF for privacy, ORAM for scale, Circuit-PSI for extensibility – is the most defensible path to private contact discovery for $10^9$ users.
