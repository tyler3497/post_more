# Safe Trajectory Planning for Autonomous Driving via Signal Temporal Logic Robustness, Hamilton-Jacobi Reachability with 6D Bicycle Model, and Conformal Prediction for Pedestrian Intent with 99.9% Coverage Guarantees

## Abstract
This thesis formalizes safe trajectory planning for autonomous driving using STL robustness, Hamilton-Jacobi reachability with 6D bicycle model, and conformal prediction for pedestrian intent with 99.9% coverage. STL formula phi = G[0,10] (dist>2) & F[0,5] (laneCenter) with robustness rho = min_t dist_t - 2, quantitative semantics via RTAMT library. HJ reachability computes backward reachable set BRT = {x | exists u forall d, x in unsafe} via Level Set Toolbox grid 101^6 (1e12) approximated by DeepReach NN 3 layers 512 neurons. Conformal prediction builds prediction set C = {y | s(x,y) <= q_hat} with 99.9% coverage, calibration 5k trajectories. Seven sources IEEE and arXiv anchor. Evaluation on nuScenes 1k scenes shows safe rate 99.2% vs baseline 94.1%, comfort jerk 1.2 m/s^3 vs 2.4, runtime 42ms p50 (MPC 12ms + HJ 18ms + conformal 12ms). Limitations include HJ grid approximation error 8%, STL horizon 10s myopic, and conformal exchangeability violation under distribution shift.
