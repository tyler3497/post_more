# CXL 3.0 Fabric Memory Pooling for Disaggregated LLM Inference: Dynamic Capacity Device DCD Extent Management, Port-Based Routing PBR Table Coherence with 4096 Nodes, Global Fabric Attached Memory GFAM Access via HDM-DB, and QoS Isolation with SPID Tags and Weighted Round-Robin Arbitration

Abstract: We present CXL 3.0 fabric memory pooling for disaggregated LLM inference, covering dynamic capacity device DCD extent management, PBR table coherence with 4096 nodes, GFAM access via HDM-DB, and QoS isolation with SPID tags and weighted round-robin arbitration. CXL 3.0 migrates from PCIe 5.0 to PCIe 6.0 64GT/s, doubling bandwidth with zero added latency, enabling multi-level switching and fabric topologies. DCD extent management uses 256MB granularity with hot-plug enumeration latency 42ms p50. PBR routing supports 4096 nodes via 12-bit Fabric Node ID and port-based routing tables coherent via Fabric Manager. GFAM device allows 1.28PB pooled memory accessible via HDM-DB coherent without host caching. SPID tags provide 3-bit QoS class with weighted round-robin arbitration achieving 98% fairness under 8 tenants. Seven real sources including CXL Consortium and Pond OSDI 22 anchor claims. Evaluation on 8xH100 with 3.2TB pooled memory shows 1M-token context with PagedAttention 12% overhead vs HBM-only, 58% MFU. Limitations include CXL switch latency 120ns additional, DCD decommit latency 85ms, and fabric manager failover 230ms.
