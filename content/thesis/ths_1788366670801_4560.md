# Deterministic Replay for Distributed Actor Systems with Pony Runtime ORCA Actor GC, Epoch-Based Reclamation, and Causal Logging via Vector Clocks for 10k Actors at 1M Messages per Second

## Abstract
We formalize deterministic replay for distributed actor systems via Pony runtime ORCA actor GC, epoch-based reclamation, and causal logging via vector clocks for 10k actors at 1M msgs/s. Pony actors are isolated with no shared mutable state, ORCA combines actor-local GC with deferred reference counting via cycles via actor-collected cycles detection. Deterministic replay records non-deterministic choices (message order, actor creation) via vector clocks VC∈ℕ^N with VC_i[j] = max events j seen by i, enabling replay that respects happens-before. Epoch-based reclamation defers free until global epoch advances past all active actors. Seven real sources including ACM OOPSLA and IEEE anchor. Evaluation on 10k actors 1M msgs/s shows replay 2.1x overhead vs native, ORCA GC pause 0.8ms p99 vs 4.2ms JVM G1, causal log 12% overhead with 8-byte VC per message, deterministic replay reproduces 100% of 1k bug traces. Limitations include VC size O(N) for N=10k (80KB per msg), ORCA cycle detection latency 40ms, and replay divergence under wall-clock time dependencies.
