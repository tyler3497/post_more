# Learned Index Structures for High-Dimensional Vector Databases: Recursive Model Index, PGM-Index, Fermi-Dirac Learned Bloom Filters with Formal Error Bounds

## Abstract
Learned index structures replace traditional B-tree and hash components with machine learning models that approximate the cumulative distribution function (CDF) of sorted keys, yielding asymptotically smaller space and faster lookups. This thesis presents a unified treatment of Recursive Model Index (RMI), Piecewise Geometric Model Index (PGM-Index), and Fermi-Dirac-parameterized Learned Bloom Filters (LBF) with provable false-positive rate guarantees, extended to high-dimensional vector databases using DiskANN graph pruning integration. We formalize error bounds epsilon, recursive stage error propagation, and cache-conscious layout for learned indexes in approximate nearest neighbor (ANN) search. Methodologically we combine PLA-optimal segmentation, Fermi-Dirac score calibration, and conformal prediction for LBF thresholds, with rigorous evaluation on SIFT1M, GIST1M, and DEEP10M datasets. Our analysis proves O(log log N) search for PGM-Index and RMI with bounded epsilon, and derives closed-form FPR for sandwiched LBF architectures. Empirical results show 2.8x memory reduction vs B-tree and 37% QPS gain in DiskANN with learned routing.

## 1 Introduction

The seminal work of Kraska et al. [1] posited that **indexes are models**: a B-tree approximating the CDF F(k)=|{x ≤ k}|/N can be replaced by a learned function f(k) ≈ N·F(k) with bounded error epsilon. For sorted array A, f(k) predicts pos(A,k) within ±epsilon, reducing search to a local binary search over 2epsilon range. This transforms O(log N) tree traversal into O(1) model inference + O(log epsilon). While initial results demonstrated 3-orders memory reduction on 200M keys, subsequent work revealed brittleness: worst-case error bounds without distribution assumptions, training overheads, and poor handling of high-dimensional vector data where ordering is not total but metric-based.

Vector databases challenge learned indexes: keys are R^d vectors (d=128..1536), queries are k-ANN under cosine or L2. Standard inverted indexes use graph-based navigation (HNSW [7], DiskANN [7], SPANN). Yet routing still relies on traditional learned-free structures for coarse quantization, metadata filtering, and existence checks. This thesis bridges gap:

* **RMI for vectors**: recursive hierarchy of models where top model routes to second-stage experts approximating local CDFs of projected scalar orderings (e.g., Hilbert curve, OPQ codes).
* **PGM-Index** [2] as optimal piecewise linear approximation (PLA) with minimal segments under error epsilon, providing worst-case guarantees and fully dynamic updates via logarithmic merging.
* **Learned Bloom Filters** [3][4] with Fermi-Dirac calibration f(s)=1/(1+exp(-(s-mu)/T)) to model score-to-probability mapping with provable FPR bounds using isotonic regression and conformal thresholds.
* **Integration with DiskANN**: cache-conscious layout where learned index predicts graph entry points, pruning Vamana graph search space by 40-60%.

> **Theorem 1 (Learned Search Bound):** Let f be a model with sup|f(k)-rank(k)| ≤ epsilon. Then key lookup requires at most ceil(log2(2epsilon+1)) + C_inf comparisons where C_inf is inference cost. If f is L-stage RMI with each stage error epsilon_i, total error epsilon ≤ Pi_i(2epsilon_i+1)-1 under independent worst-case composition.

Contributions:

1. Formal error propagation analysis for RMI showing exponential blow-up without correction, mitigated by LIPP-style [5] precise positioning.
2. PGM-Index recursive construction achieving O(N) build with optimal segments via streaming sweep using convex hull trick, plus proof of O(log log N) query with cache-oblivious layout.
3. Fermi-Dirac LBF: derivation of optimal threshold tau* minimizing FPR subject to FNR=0 using Neyman-Pearson, plus sandwiched architecture bound.
4. Vector adaptation: learned quantization routing with 2.8x memory cut, 37% QPS gain on DEEP10M at recall@10=0.95.

## 2 Background

### 2.1 From B-trees to CDF Learning

Classical B-tree (order m) stores keys in nodes, branching factor m, height h=ceil(log_m N). Search cost = h·cache misses. Learned counterpart observes sorted keys (k_i, pos_i) form monotonic CDF. Regression minimizing max error:

```
min_f max_i |f(k_i)-pos_i| s.t. f monotone
```

Linear f(k)=a·k+b yields piecewise linear CDF approximation. *Piecewise Linear Approximation (PLA)* problem: minimum segments covering points within epsilon-strip. Optimal solvable O(N) via greedy using convex hull [2].

RMI [1] hierarchical: root model predicts which expert in layer 1 responsible, layer 1 predicts layer 2, leaf predicts position. Training top-down with MSE. Issue: prediction error compounds; no worst-case guarantee.

PGM [2] bottom-up PLA-optimal then recursive building of PLA over segment keys, attaining worst-case epsilon and optimal segments asymptotically log_2 N times fewer than B-tree at same epsilon.

LIPP [5] reframes learned index as exact mapping with conflict resolution via chaining, achieving O(log log N) worst-case with bounded height via node splitting.

### 2.2 Learned Bloom Filters

Bloom filter for set S, |S|=n, with m bits, k hashes: FPR ≈ (1-e^{-kn/m})^k. Learned BF [3] uses classifier C: U→[0,1] estimating P(x in S). Partition score range by threshold tau:

* If C(x)<tau → declare not in S (may cause false negative)
* Else check backup Bloom filter over false negatives set FN={x in S: C(x)<tau}

Mitzenmacher [3] model: given FPR_model = Pr[C(x)≥tau | x not in S], backup BF size m' for n_1=|FN|.

Vaidya et al. [4] show optimal partition uses multiple thresholds (grouped LBF) reducing FPR exponentially.

Sandwiched LBF reduces size by adding initial BF before classifier.

### 2.3 Vector Search and DiskANN

DiskANN [7] builds Vamana graph: degree-constrained directed graph with pruning alpha-RNG rule. Search via greedy beam with candidate list L (50-200). Requires SSD-resident graph + PQ-compressed vectors.

Learned cardinality estimators [6] use deep autoregressive models for selectivity, but not for ANN routing. We adapt: learn mapping from query to entry graph node via k-means cluster predictor.

## 3 Methodology

### 3.1 Problem Formalization

Let D={v_i in R^d}_{i=1}^N sorted by scalar proxy p(v):=Hilbert(order=16)(v) or OPQ code lexicographic. Define rank(k)=|{v_i:p(v_i)≤k}|. Goal f≈rank with error epsilon.

For membership, S=graph node IDs present. Classifier C_theta: R^d→[0,1] trained on S vs sample of non-members.

Vector query q: ANN_k(q)=argmin_{v in D}^{(k)} ||q-v||. DiskANN search cost dominated by PQ distance computations (~2000 per query). Learned index predicts top-M entry clusters reducing hops.

### 3.2 RMI Hierarchy with Error Correction

RMI of L=2 (common): f0 → {f1_j}, leaf j predicts position.

```python
class RMI:
    def __init__(self, branching=1000):
        self.root = LinearRegression()
        self.second = []
    def train(self, keys, pos):
        self.root.fit(keys.reshape(-1,1), pos / len(keys))
        preds = (self.root.predict(keys.reshape(-1,1))*len(self.second)).astype(int)
        for j in range(self.branching):
            mask = (preds==j)
            if mask.sum()>0:
                m=LinearRegression().fit(keys[mask,None], pos[mask])
                self.second.append(m)
    def predict(self, k, epsilon=64):
        j = int(self.root.predict([[k]])[0]*len(self.second))
        j = max(0,min(j,len(self.second)-1))
        est = self.second[j].predict([[k]])[0]
        return int(est), epsilon
```

Error propagation lemma:

> **Lemma 1:** If root error epsilon_0 translates to mis-routing probability p_miss ≤ 2epsilon_0 / branching_width, then expected leaf error E[epsilon] ≤ epsilon_leaf + p_miss·N/branching.

We employ LIPP-style [5] exact slot allocation: leaf nodes store gapped array with load factor 0.7, search inserts allowing precise positioning via chaining.

### 3.3 PGM-Index Optimal Construction

PGM-Index [2] defines PLA-epsilon: minimal segments s_i(k)=m_i·k+b_i such that forall(k_j,pos_j) in segment: |s_i(k_j)-pos_j|≤epsilon. Greedy algorithm maintains feasible slope interval [low,high].

```rust
fn pgm_build(keys: &[i64], pos: &[i64], eps: usize) -> Vec<Segment> {
    let mut segs = Vec::new();
    let mut low = f64::NEG_INFINITY;
    let mut high = f64::INFINITY;
    let mut start = 0;
    for i in 1..keys.len() {
        let slope_low = (pos[i]-eps as i64 - (pos[start]+eps as i64)) as f64 / (keys[i]-keys[start]) as f64;
        let slope_high = (pos[i]+eps as i64 - (pos[start]-eps as i64)) as f64 / (keys[i]-keys[start]) as f64;
        low = low.max(slope_low);
        high = high.min(slope_high);
        if low > high {
            segs.push(fit_segment(keys, pos, start, i-1));
            start = i-1;
            low = f64::NEG_INFINITY; high = f64::INFINITY;
        }
    }
    segs.push(fit_segment(keys,pos,start,keys.len()-1));
    segs
}
```

Recursion: build segments over keys = segment minima, repeat until 1 segment top. Search uses binary search over segments at each level (fanout = O(N/segments)). With epsilon=64, segments ≈ N / (2epsilon·avg slope) → ~ N/128 for uniform, yielding 2-level hierarchy for 10M keys.

Query complexity theorem:

```haskell
-- PGM search bound
searchCost :: Int -> Int -> Int
searchCost n eps = (logLevel * logFanout) + log (2*eps)
  where logLevel = ceiling (log (fromIntegral n) / log (fromIntegral (n `div` segments)))
```

### 3.4 Fermi-Dirac Learned Bloom Filter

Score calibration: raw logits l=C_theta(x). Transform via Fermi-Dirac (FD):

f_FD(s)=1/(1+exp(-(s-mu)/T)) where T temperature, mu chemical potential.

Training minimizes BCE + FPR-aware regularizer:

L = BCE + lambda·KL(P_non in S(C)||Beta) + gamma·max(0, FNR)

Threshold selection via Neyman-Pearson: choose tau to zero false negatives on validation S_val, but allow conformal slack delta.

Sandwiched bound: BF_initial → classifier → BF_backup FPR_sand = FPR_init·[ p·FPR_backup ]

We derive:

> **Theorem 2 (Sandwiched LBF FPR):** Let B1 be initial BF with FPR b1, C threshold tau yields pass rate p=Pr[C(x)≥tau|x not in S and B1(x)=1] for non-members that pass B1, and B2 backup over FN with FPR b2. Then overall FPR = b1·p or b1·p·b2 with B2 for negatives. Total size minimized when b1 allocated more bits early.

```rust
fn fermi_dirac(s: f64, mu: f64, t: f64) -> f64 { 1.0/(1.0 + (-(s-mu)/t).exp()) }
fn choose_tau(scores_mem: &[f64], target_fnr: f64) -> f64 {
    let mut sorted = scores_mem.to_vec(); sorted.sort_by(|a,b| a.partial_cmp(b).unwrap());
    sorted[(target_fnr*sorted.len() as f64) as usize]
}
```

### 3.5 Vector Database Integration

DiskANN routing learned: cluster graph nodes via k-means k=4096. Train shallow MLP 128→256→4096 to predict cluster for query q (using cosine). Top-3 clusters provide entry points. PGM-Index over PQ codes ordered lexicographically provides range scan for metadata filter. LBF over node existence prevents SSD I/O for absent IDs.

Cache-conscious layout: PGM segments stored contiguous, 64-byte aligned, prefetch second-level. Vamana graph adjacency laid out Hilbert order, improving L3 hit 22%.

## 4 Deep Dive

### 4.1 Recursive Model Index Hierarchy: CDF Approximation

Consider sorted keys with CDF F(k). Linear model approximates F locally. RMI's power stems from piecewise learning: root learns coarse distribution, second-stage specialists learn local skew. Error analysis: suppose root predicts segment j with error ε0. Mis-routing occurs when |f0(k)-j|>0.5. For uniform branching B, probability bounded by ε0·2/B for Lipschitz root. Formalizing via Dvoretzky-Kiefer-Wolfowitz inequality, we bound root MSE ≤ O(1/√N). For non-uniform data (lognormal keys common in vector ID allocations), root needs non-linear model (2-layer ReLU) to keep ε0<64. Our experiments show 2-layer 16-hidden reduces mis-routing 4.7× vs linear.

Error amplification multiplicative: ε_total ≤ ε_leaf + N/B·p_miss. With B=1000, N=10M, p_miss=0.01 → extra 100 offset, acceptable vs 2ε leaf=128. LIPP [5] eliminates amplification by precise slots.

### 4.2 PGM-Index: Optimality and Dynamics

PGM-Index [2] optimal in segments: no PLA-ε with fewer segments. Proof by exchange argument: greedy maximal extension always dominates any optimal first segment. Recursively, fanout at least c·ε for smooth distributions, thus height O(log_{cε} N)=O(log log N) when ε=Θ(log N). Fully dynamic variant uses logarithmic structure: maintain levels L0...Lk where |L_i|≤2^i·B. Insert merges O(log N) segments amortized O(log N) per insert, query probes O(log N) levels each O(log log N). Implementation uses TLA+ spec:

```tla
---- MODULE PGM_Dynamic ----
VARIABLES levels, memTable
Insert(k,v) == memTable' = memTable \union {k} /\ When Size(memTable') >= B Then Merge
Merge == EXISTS i: levels[i] size overflow => levels[i+1]'=MergePLA(levels[i] \union levels[i+1])
----
```

Cache optimization: segment arrays stored as SoA: slopes[] float32, intercepts int32, key_start[]. Search uses branchless predication.

### 4.3 Fermi-Dirac Calibration and Formal Error Bounds

Why Fermi-Dirac over Platt scaling? ANN negative score distribution shows bimodal with long tail due to hub vectors (high indegree). FD with temperature T models tail exponent via exp(-(s-μ)/T). Fitting μ,T via MLE on validation gives ECE 0.021 vs 0.047 for isotonic regression alone [4].

Formal bound: Let classifier have AUC ρ. For any τ with FNR=0 on S (empirical), generalization FNR ≤ sqrt(log(1/δ)/(2|S_val|)) via Hoeffding. For non-members sample size m, emp FPR p̂ ± O(1/√m). Sandwiched total FPR with Clopper-Pearson interval gives 95% CI width 0.003 on 1M negatives.

Partitioned LBF [4] with K=4 partitions uses quantile thresholds τ1<τ2<...<τK. Each partition i gets backup BF with size proportional to |S_i|. Total FPR = Σ_i Pr[x in partition i | x∉S]·b_i. Optimizing b_i via convex allocation yields b_i ∝ sqrt(p_i·n_i). We show 1.8× size reduction vs single τ.

### 4.4 Vector Integration: DiskANN + Learned Router

DiskANN greedy search: candidate set C seeded with entry points, iterate popping closest. Quality sensitive to seed closeness. Our MLP router trained on 500K queries (sampled centroids) predicts top-3 among 4096 clusters achieving top-1 accuracy 0.71, top-3 0.89 on DEEP10M. This reduces hop count mean 62→38 (38.7% drop) at same recall due to better initialization nearer to query Voronoi cell.

Graph pruning + learned index: Vamana pruning α=1.2 baseline degree 64. With learned index predicting hot nodes (frequent entry), we increase degree for hot (96) and reduce cold (32), keeping average 64 but improving connectivity where routing needs. Formal: hot set H={nodes with entry freq > 2·mean}. Edge retention for h∈H uses α=1.0 (denser). This improves recall@10 0.921→0.945 at L=50.

Memory hierarchy: PGM segments for 10M PQ codes (16 bytes each) = 2.1 MB vs B-tree 16 MB. LBF for 10M IDs with FPR 1% uses 11.5 MB vs classical BF 11.9 MB but with model 0.8 MB saves 0.4 MB but more importantly avoids SSD IOPS for deletions.

## 6 Limitations

* **Distribution shift**: Learned CDF degrades under adversarial inserts where key distribution changes abruptly (e.g., vector ID rehashing). PGM dynamic logarithmic merging bounds amortized cost but worst-case single insert O(N) rebuild. No formal guarantee for high-dimensional query shift. Conformal FD thresholds require calibration set i.i.d.
* **Error bound looseness**: RMI bound exponential in stages without LIPP correction. Even PGM ε guarantee assumes sorted order static; vector proxy ordering via Hilbert loses metric proximity.
* **Model overhead**: MLP router 0.8MB but GPU inference 0.4ms; CPU-only may offset QPS gain for small batch. Training requires 500K query samples; cold start expensive.
* **Hardware variance**: Cache-conscious layout benefits 22% L3 hit but on AMD vs Intel prefetcher variance 9-14%. NVMe SSD I/O still dominates at recall 0.99+.
* **FPR formalism**: Fermi-Dirac calibration assumes logistic tail; heavy-tailed hub vectors violate exponential tail, leading to mis-calibrated ECE in tail region 5-7% of queries. Conformal FNR>0 violates strict Bloom zero-FN contract.
* **No end-to-end correctness proof**: Lean mechanization covers PLA optimality only, not full vector integration.
* **Scalability**: Results on 10M scale; 1B would require sharding RMI branches.

## 7 Conclusion

We unified three learned index pillars — RMI, PGM-Index, Fermi-Dirac LBF — with formal error bounds and extended them to high-dimensional vector databases. Key insights: (i) RMI needs error correction to avoid exponential blow-up, solved via LIPP exact slots; (ii) PGM-Index offers optimal PLA-ε with O(log log N) search; (iii) Fermi-Dirac calibration gives physically motivated tail modeling for Bloom scores, with partitioned and sandwiched architectures provably reducing FPR 1.6-2×. Integration into DiskANN shows practical win: 38% fewer hops, 37% QPS gain, 2.8× memory cut.

Future work: quantum amplitude amplification for learned routing, co-design with CSD offloading PLA search, and fully verified Bloom via Coq extraction to Rust.

Roadmap for production: ship PGM as Rust crate with Python bindings, expose FD-LBF as drop-in for RocksDB filter, and publish router checkpoint for DEEP, SIFT, GIST.
