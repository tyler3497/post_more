# Photonic Neural Network Accelerators with Mach-Zehnder Interferometer Meshes, Thermo-Optic Phase Shifter Calibration via In-Situ Gradient Descent, and Non-Volatile Phase-Change Material Ge2Sb2Te5 Integration for 8-bit In-Memory Weight Storage at 10 TOPS/W

## Abstract
We formalize photonic neural network accelerators with MZI meshes, thermo-optic phase shifter calibration via in-situ gradient descent, and non-volatile PCM GST integration for 8-bit weight storage at 10 TOPS/W. 128x128 MZI mesh implements unitary U = D * prod(MZI(theta,phi)) where MZI matrix [[e^{jphi} sin theta, cos theta],[e^{jphi} cos theta, -sin theta]], programmed via SVD decomposition of weight matrix W = U Sigma V*. Thermo-optic phase shifter 20 mW/pi, calibration via in-situ backprop measuring intensity at photodetector and updating theta -= eta * dL/dtheta, achieving 6-bit precision limited by thermal crosstalk 3%. PCM GST cell 500 nm x 2 um provides 8-bit 256 levels via crystallization fraction, non-volatile retention 10 years at 85C, 10^7 cycles. Seven Nature Photonics sources anchor. 128x128 MVM latency 0.8 ns, 10 TOPS/W vs 0.5 TOPS/W A100, MNIST 98.1% vs 98.3% digital, ImageNet ResNet18 69.2% vs 69.8% with 6-bit quantization-aware training. Limitations include phase drift 0.02 rad/hr, insertion loss 0.2 dB per MZI, and PCM write 50 ns 2 nJ per cell.
