# Learned Query Optimization for Cloud Data Warehouses: Bao Hints, Neo Deep Reinforcement Learning, CardBench Benchmarking, and Hybrid Traditional-Learned Cost Models for Snowflake-Scale Workloads

## Abstract
We dissect learned query optimization for cloud warehouses, analyzing Bao hint sets steering traditional optimizer, Neo deep RL replacing optimizer via Tree-CNN latency prediction, CardBench benchmark for cardinality estimation, and hybrid traditional-learned cost models. Bao learns to choose among 48 hint sets via Thompson sampling, achieving 1 hr convergence vs Neo 24 hrs pretraining, handling schema/data/workload changes. Neo uses Tree-CNN to predict latency from plan tree, avoiding cardinality estimation errors. CardBench provides thousands queries over 20 real-world databases, evaluating instance-based, zero-shot, fine-tuned setups. Six real sources including arXiv 2004.03814 Bao, 2408.16170 CardBench, 2312.06357 FOSS self-learned doctor, 2502.05256 learned offline BO. Evaluation on JOB benchmark shows Bao 35 queries 25% savings, FOSS 78 queries, Balsa 45, training 9.23 hrs, optimization 170 ms. Zero-shot CE accuracy drops sharply with joins, fine-tuning reduces overhead. Limitations include Bao limited hint space missing optimal plans, Neo poor schema change handling, and CardBench synthetic workload bias.
