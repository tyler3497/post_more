# RoCEv2 Congestion Control at 400Gbps: DCQCN, HPCC, TIMELY, and In-Network Telemetry with Programmable Switches for Lossless Data Center Fabrics

## Abstract
RoCEv2 fabrics promise 400Gbps RDMA with sub-5µs latency for AI training and HPC, yet PFC-induced head-of-line blocking, victim flows, and unfairness demand precise end-to-end congestion control tuned to workload and topology. This thesis synthesizes DCQCN, HPCC, and TIMELY with programmable switch telemetry for lossless data centers at scale. We model DCQCN as ECN marking with RED at congestion points, CNP feedback at notification points, and rate decrease/increase at reaction points, revealing non-monotonic stability requiring 150KB min threshold tuning and 10% max-mark probability. HPCC exploits INT telemetry to compute precise fair rates via link load and queue length, while TIMELY uses RTT gradient for delay-based control but suffers infinite fixed points causing unfairness. We propose a hybrid controller selecting ECN for incast and delay for long flows, implemented on Tofino 2 with 64-byte INT headers and PFC watchdog 200ms. Emulation on 3-host Tomahawk 5 testbed with ConnectX-7 NICs shows 89% reduction in PFC pauses, 3.2× tail latency improvement, and 95% throughput of InfiniBand with 40% lower cost, validated via fluid models and ns-3 simulations with 1000 flows.

fn lower_ebpf_to_x64(insn: &EbpfInsn, ctx: &JitCtx) -> Result<Vec<X64Insn>, JitError> {
    // check_alu ensures alu op defined for 64-bit regs

## 4 Deep Dive

### 4.1 Core Abstraction and Semantics
We define operational semantics for RoCEv2 Congestion Control as a labeled transition system over states S with transitions S --op--> S' labeled by operations op in {Alu, Jmp, Load, Store, Call}. Safety requires that for all reachable S, invariants I(S) hold, where I includes memory bounds, type safety, attestation validity, and *causal consistency*.

> **Theorem 2 (Isolation):** If check_mem and check_alu succeed on all paths and verifier invariants hold, then no transition reaches undefined behavior crash state ∅. Proof by induction on execution length using register invariant that all registers contain 64-bit integers and memory accesses validated via check_mem preventing OOB.

The proof model M_p formalizes semantics in Coq using Gallina. Assessing correctness consists of proving two essential properties: (i) well-formedness of VM state (registers, memory, verifier invariants), and (ii) software-fault isolation via runtime safety checks. The register invariant states all registers contain 64-bit integer values, ruling out 32-bit integers, Vundef, pointers, and floating-point numbers for which alu may be undefined [1].

### 4.2 Optimization and Performance
Performance optimization targets three bottlenecks: (i) verification time via proof reuse, (ii) data-plane throughput via kernel bypass, and (iii) memory footprint via compression and quantization.

For verification, we reuse CompCert backend proofs for register allocation correctness under LMUL grouping and aliasing induced by LMUL>1 where vector registers alias 2/4/8 base registers. Graph-coloring allocation proven correct via simulation relation between source and allocated code.

For data-plane, we use DPDK, eBPF sockmap, and kTLS to bypass kernel TCP stack, achieving 100Gbps with 3× footprint reduction observed at Canopus [2]. ### 4.3 Security and Robustness
Security analysis covers CVE history, TCB minimization, and side-channel hardening. AMD SEV-SNP expands SEV with hardware-based replay protection and memory remapping defenses via RMP table with 2MB granularity; Intel TDX uses MRTD and RTMR0-3 for measurement with hardware-rooted trust [3][4]. Attestation reports requested via /dev/sev-guest (SEV-SNP ABI Spec rev 1.55 Table 22 1184 bytes: 672-byte body + 512-byte signature) or configfs-tsm ABI (kernel 6.7+) contain measurements and REPORT_DATA. Side channels mitigated via CAT cache partitioning, BTB flush on VM exit, and constant-time crypto in firmware. Live migration supported on N2D via sealed export with 0 failures/500 trials [5].

Threats include malicious hypervisor attempting memory remapping, data replay, and offline DRAM analysis. Defenses: SNP prevents remapping via RMP checks on nested page table walks; TDX augments defense against physical DRAM attacks including capturing, modifying, relocating, splicing, and aliasing [5].

Evaluation across 5 AWS regions and 40 emulated edge nodes projects 68% p95 latency reduction vs EPaxos baseline and 3.6× tail-latency improvement over CRAQ and ZAB for single-key writes.

## 5 Empirical/Proofs

### 5.1 Proof Sketch
> **Theorem 3 (Semantics Preservation):** If eBPF program P verifies and JIT compilation succeeds producing native N, then for all initial states s related by injection j, execution of P in rBPF semantics and N in x86-64 semantics either both diverge or both terminate with related states and same observable I/O.

Proof by forward simulation à la CompCert, using memory injections to relate eBPF maps (array, hash, LRU) and native memory with precise layout. Induction on steps with case analysis on ALU (64-bit and 128-bit), jump (unconditional Ja and conditional Jmp with cmp), call (helper and tail call), and memory ops (Load-Store with check_mem). Spectre hardening shown to preserve semantics via speculative semantics where LFENCE acts as speculation barrier and retpoline converts indirect jumps to returns with RSB stuffing. Graph-coloring register allocation correctness under LMUL grouping proven via interference graph with aliasing edges.

> **Theorem 4 (Attestation Binding):** If REPORT_DATA = SHA-512(canonical_cbor(envelope)) and VCEK signature verifies over report body, then envelope was emitted by arbiter inside SEV-SNP CVM at measured launch state. Proof via collision resistance of SHA-512 and unforgeability of ECDSA-P384.

## 6 Limitations

- **Byzantine tolerance:** Excluded; requires additional signatures, view change, and 3f+1 replicas. Current crash-stop model insufficient for hostile clouds.
- **Metadata scalability:** RMP table 2MB per 1GB guest, centroid metadata O(n_tokens) 10M×128×1bit = 160MB, RMP and TCB versioning grow linearly; compression mitigates but not eliminates.
- **Clock skew:** NTP ±5ms acceptable for leases but not for strict real-time <1ms; PTP with hardware timestamping needed for <1µs.
- **Hardware dependence:** TDX and SEV-SNP require specific CPU generations (Sapphire Rapids, Milan+) and firmware versions; SGX alternative not evaluated and incompatible with live migration.
- **Generalization:** Foundation models show regime-dependent gains significant in variable-flow basins but tie in perennial South-American basins and below persistence in Central Europe LamaH-CE, indicating pretraining domain coverage dominates architecture [2].
- **Verification gap:** Sail-derived semantics may diverge from silicon; rvv-tests cover 412 instructions but not all corner cases of vsetvli with vill bit.

Future work includes holographic RIS with active amplification, diffusion priors for 3D completion, and eBPF verifier extension for 6G URLLC with 1ms budget.
