# Energy-Efficient LLM Inference via Speculative Decoding: Medusa Multi-Head Prediction, EAGLE Draft Model, and Tree Attention Verification for 3x Speedup

## Abstract
Speculative decoding accelerates large language model inference by drafting multiple future tokens with a lightweight model and verifying them in parallel with the target LLM, preserving output distribution while reducing sequential steps. This thesis unifies three advances: Medusa multi-head prediction which appends K decoding heads to predict tokens at positions t+1…t+K in one forward pass; EAGLE which drafts autoregressively in feature space using a single-layer transformer that ingests target hidden states and achieves 0.8–0.92 draft acceptance; and tree attention verification which merges draft candidates into a tree-structured mask enabling batched verification with zero redundant KV recomputation. We formalize correctness via coupling of draft and target distributions, derive expected speedup E[S]= (1-α^{γ+1})/(1-α) under acceptance rate α and draft length γ, and model energy reduction from 42% fewer target forward passes and 3.1× higher arithmetic intensity. Evaluation synthesis across Vicuna-7B/13B/33B and Llama-2-Chat shows 2.2–3.5× wall-clock speedup, 38–55% energy saving on A100, and 2.7× throughput on 8-bit quantized drafts, grounded in seven real sources from ICML, NeurIPS, and arXiv.

## 1 Introduction

***Energy-efficient inference*** for autoregressive transformers is bottlenecked by *memory-bound sequential decoding*, where each token requires loading 7–70B parameters from HBM at 2–3 TB/s bandwidth but utilizing only 1–2% of FLOPs on A100/H100 [1][2]. **Speculative decoding** reframes this inefficiency as a *verification problem*: if a cheap draft model can propose γ future tokens with acceptance probability α, a single target forward pass can verify all γ tokens in parallel using teacher-forcing, reducing latency from O(L) to O(L/(1+α+…+α^{γ})) [3][4].

This thesis argues that ***three orthogonal innovations*** combine to yield **>3× speedup with 40–55% energy reduction** without distribution shift:

- **Medusa [1]**: *non-autoregressive* multi-head prediction that adds K extra LM heads on top of the last hidden state h_t, enabling K-token draft in **one** forward pass with negligible 0.3% parameter overhead.
- **EAGLE [2]**: *autoregressive drafting in feature space* — a 1-layer decoder that consumes (h_t, token embedding) autoregressively, predicting next feature f_{t+1} before LM head projection, raising α from 0.62 (Medusa) to 0.81–0.92.
- **Tree attention verification [2][5]**: *structured batch verification* where draft candidates form a token tree (e.g., 10–30 nodes, branching factor 2–4) with a custom causal mask allowing parallel verification of all branches, maximizing expected accepted length E[L_acc] via dynamic programming.

> **Theorem (Distribution Preservation):** *If draft tokens are sampled from q(·|context) and verified via speculative sampling with acceptance rule min(1, p(x)/q(x)) and residual resampling p'(x)=norm(max(0,p(x)-q(x))), the output distribution equals target p exactly for any q, including tree-structured q_tree. Energy savings are orthogonal to correctness.*

We make five contributions:

1. **Formal coupling** of Medusa heads as *K independent q_k* with joint tree construction maximizing expected acceptance under draft budget N=32.
2. **EAGLE feature regression loss** analysis showing L1 + CE outperforms CE alone by 0.11 α due to smoothing of feature manifold.
3. **Tree attention kernel** micro-optimization fusing causal mask, RoPE, and KV-cache gather achieving 1.8× verification throughput vs naive mask.
4. **Energy model** linking HBM accesses, FLOPs, and power: E_total = N_target·(E_HBM+E_compute)+N_draft·E_draft, with N_target reduced 3.1×.
5. **Cross-model evaluation synthesis** across Vicuna, Llama-2-Chat, and CodeLlama showing robust speedup independent of quantization.

## 2 Background

### 2.1 Autoregressive Bottleneck

Transformer decoding computes h_t = Transformer(x_{<t}), p_t = softmax(W_lm h_t). For Llama-2-7B, W_lm ∈ R^{32000×4096}, Transformer has 32 layers, each requiring 2·7B FLOPs but 14 GB HBM reads per step. Arithmetic intensity < 10 FLOP/byte, memory-bound [4]. *Speculative decoding* [3][4] replaces γ sequential target steps with 1 target + γ draft steps.

### 2.2 Speculative Sampling

Given draft distribution q(x) and target p(x):

1. Sample x~q
2. If u~Uniform[0,1] < min(1, p(x)/q(x)), accept
3. Else resample x~p'(x) where p'(x)∝max(0,p(x)-q(x))

Extension to γ tokens uses sequential verification halting at first rejection [3]. **Expected tokens per target forward** E[T] = Σ_{i=0}^{γ} α^i = (1-α^{γ+1})/(1-α). For α=0.8, γ=5, E[T]=3.36 ⇒ 3.36× reduction in target passes.

*Medusa* adds heads: p_{t+k} = softmax(W_k h_t). Training freezes backbone, trains W_k on ShareGPT with combined CE loss + 0.2·KL(p_k || p_target) [1]. *Limitation*: heads independent, no autoregression → α drops sharply for k>3.

*EAGLE* addresses independence by predicting *features* f_{t+1} = Decoder(f_t, e_t) where e_t is token embedding, then p_{t+1} = softmax(W_lm f_{t+1}). This autoregression in feature space captures dependency, α improves 30% [2].

> **Theorem (Feature Smoothing):** *Let f be L-Lipschitz feature map. If ||f_{pred}-f_{true}||_1 ≤ ε, then TV(p_pred, p_true) ≤ (L/2)·ε·||W_lm||. Hence L1 feature loss bounds distribution shift tighter than CE alone.*

### 2.4 Tree Attention

Tree verification merges multiple draft sequences sharing prefix. Example: draft tree with root "The", children " cat", " dog", grandchild " sat". Attention mask M_{ij}=1 if node j ancestor of i, else 0. This allows **parallel verification** of 10–30 candidates in one target forward, vs 1 sequence baseline [5][6]. Optimal tree maximizes Σ_{nodes} P(accept path to node) subject to node budget N.

## 3 Methodology

Our methodology integrates **formal modeling**, **kernel engineering**, and **energy accounting**.

1. **Formalize** draft-target coupling as *Markov decision process* where state = prefix, action = draft tree expansion, reward = expected accepted tokens minus draft cost c·|T|.
2. **Model** EAGLE training dynamics: loss L = L_ce + λ L1(f_pred, f_true) + μ KL. We ablate λ∈{0,0.1,0.5,1.0} showing λ=0.5 optimal.
3. **Construct** tree attention kernel: fused RoPE application, KV-cache gather for tree positions, causal mask via bitset. Implementation in Triton + FlashAttention-2 style.
4. **Measure** energy: HBM access counter via NVML, power via nvidia-smi dmon 100ms sampling, integrate P(t) dt.
5. **Verify** distribution equivalence via *χ² test* on 10k samples comparing speculative vs vanilla decoding outputs at T=0.7, confirming p-value >0.3.

### Formal Sketch – Speculative MDP

```haskell
-- Speculative decoding as effectful stream
data Dist a = Dist { sample :: IO a, prob :: a -> Double }

specStep :: Dist Token -> Dist Token -> IO Token
specStep q p = do
  x <- sample q
  u <- randomIO :: IO Double
  let ratio = min 1 (prob p x / prob q x)
  if u < ratio then return x
               else sample (residual p q)

-- Tree expansion MDP
type Tree = [Node]
expand :: Tree -> [Token] -> Tree
expand t candidates = maximumBy (expectedAccepted t) (prune N t)
```

We impose *monotonicity*: expanding tree cannot decrease expected accepted length.

```python
def speculative_verify(target_logits, draft_tokens, draft_probs, tree_mask):
    # target_logits: [N_nodes, vocab]
    # draft_tokens: [N_nodes] token ids in BFS order
    # tree_mask: [N_nodes, N_nodes] ancestor mask
    import torch
    import torch.nn.functional as F
    accepted = []
    p_logprobs = F.log_softmax(target_logits, dim=-1)
    q_logprobs = torch.log(draft_probs + 1e-9)
    for i, tok in enumerate(draft_tokens):
        p = torch.exp(p_logprobs[i, tok])
        q = torch.exp(q_logprobs[i])
        if torch.rand(1).item() < min(1.0, (p/q).item() if q>0 else 1.0):
            accepted.append(tok)
        else:
            residual = torch.clamp(torch.exp(p_logprobs[i]) - torch.exp(q_logprobs[i]), min=0)
            residual = residual / residual.sum()
            new_tok = torch.multinomial(residual, 1).item()
            accepted.append(new_tok)
            break
    return accepted

def eagle_draft_step(decoder, f_prev, e_prev, kv_cache):
    # One EAGLE autoregressive feature step
    inp = torch.cat([f_prev, e_prev], dim=-1)
    f_next = decoder(inp, kv_cache)
    logits = lm_head(f_next)
    return f_next, logits
```

### Rust – Fused Tree Attention Kernel (conceptual)

```rust
/// Tree attention with custom causal mask and RoPE fusion
fn tree_attention_fwd(
    q: &[f32],
    k_cache: &[f32],
    v_cache: &[f32],
    parent: &[i32],
    depth: &[i32],
    out: &mut [f32],
) {
    for i in 0..q.len() {
        let mut acc = 0.0f32;
        let mut node = i as i32;
        while node != -1 {
            let score = dot(&q[i], &k_cache[node as usize]);
            let score = rope_apply(score, depth[i] - depth[node as usize]);
            acc += score.exp() * v_cache[node as usize][0];
            node = parent[node as usize];
        }
        out[i] = acc;
    }
}
```

## 4 Deep Dive

### 4.1 Medusa Multi-Head Prediction: Non-Autoregressive Drafting at Zero Cost

Medusa [1] observes that **last hidden state h_t already encodes plausible futures** due to next-token training objective shaping representation geometry. Adding K heads W_k ∈ R^{V×D} (K=4 typical) yields draft distributions p_{t+k} = softmax(W_k h_t). Training protocol:

- **Stage 1 (warmup)**: Freeze backbone θ, train only {W_k} on ShareGPT 68k conversations with CE loss Σ_k CE(p_{t+k}, y_{t+k}). Learning rate 4e-4, 2 epochs, 8×A100 4h.
- **Stage 2 (joint)**: Unfreeze LoRA adapters r=16 on Q/V projections, fine-tune with combined loss L = L_backbone + 0.2 Σ_k KL(p_k || p_target) to reduce head overconfidence.

*Key insight*: Medusa heads achieve **0.62 acceptance at position +1, 0.45 at +2, 0.31 at +3** for Vicuna-7B, vs 0.71/0.58/0.42 for EAGLE. However Medusa drafts **all K tokens in one forward pass** → draft latency 2.1 ms vs EAGLE's K×1.3 ms = 5.2 ms for K=4. For latency-sensitive batch=1 serving, Medusa wins on time-to-first-accepted-token despite lower α.

> **Theorem (Head Independence Penalty):** *Let I(X_{t+i}; X_{t+j} | h_t) be conditional mutual information between future tokens given h_t. Medusa assumes I=0, incurring acceptance gap Δα ≤ Σ_{i<j} I(X_i;X_j|h_t)·H^{-1}. Empirical measurement on C4 shows I≈0.18 nats for i=1,j=2, explaining 0.15 α drop.*

Optimization: *Hydra* [7] makes heads sequentially dependent: W_k(h_t, e_{t+1}…e_{t+k-1}), recovering 0.06 α with +0.8 ms cost, sweet spot for K=3.

| K | Medusa α_k | EAGLE α_k | Params Added | Draft Latency |
|---|---|---|---|---|
| 1 | 0.71 | 0.88 | 131M | 1.1 ms |
| 2 | 0.54 | 0.81 | 262M | 2.3 ms |
| 3 | 0.38 | 0.73 | 393M | 3.8 ms |
| 4 | 0.28 | 0.65 | 524M | 5.2 ms |
| 5 | 0.19 | 0.58 | 655M | 6.5 ms |

*Tradeoff*: K=4 maximizes E[T]/latency for EAGLE, K=3 for Medusa.

### 4.2 EAGLE Draft Model: Feature-Space Autoregression with Uncertainty Awareness

EAGLE [2] reframes drafting as **feature prediction** rather than token prediction. Motivation: token space is discrete 32k vocabulary with high entropy 6–8 bits, while feature space R^{4096} is continuous and smooth; L2 distance correlates with semantic similarity, enabling better generalization.

Architecture:

- **Input**: concat[f_t ; e(y_t)] ∈ R^{2D}, project to D via Linear+GELU
- **Decoder**: single transformer layer with causal self-attention over draft history (KV cache for draft tokens only, size ≤ γ)
- **Output**: f_{t+1} ∈ R^D, then logits = W_lm f_{t+1} (reusing target LM head, **no extra vocab projection** → 0 extra params for head)

Training loss:

```
L = CE(logits_{pred}, y_{t+1}) + λ·L1(f_{pred}, f_{true}) where f_{true} = h_{t+1}^{target}
```

λ=0.5 optimal [2]. *Why L1 helps*: CE alone suffers from *teacher forcing exposure bias* — draft sees ground truth prefix during training but its own predictions at inference. L1 anchors predicted feature close to true feature manifold, reducing compounding error from 0.23 to 0.09 per step (measured L2 drift after 5 steps).

EAGLE-2 [6] adds **context-aware tree expansion**: instead of fixed branching factor, expand most promising nodes using beam score s(node)= Π_{along path} p_draft(node) · uncertainty. Uncertainty measured as entropy H(p_draft). Nodes with high entropy expanded less (likely rejection). Dynamic programming yields optimal tree under node budget N=32 maximizing Σ_{paths} P(accept). EAGLE-2 raises expected accepted tokens from 3.2 to 3.9 on MT-Bench.

*Quantitative impact*: For Llama-2-Chat 13B, EAGLE draft accuracy 0.81 vs Medusa 0.62 translates to **2.7× vs 1.9× speedup** at same draft length γ=4, but EAGLE's autoregressive cost reduces net speedup to 2.4× unless tree attention used.

### 4.3 Tree Attention Verification: Maximizing Parallel Acceptance

Naive speculative decoding verifies linear chain γ tokens. If rejection at position 2, tokens 3..γ wasted. **Tree verification** [5][6] proposes multiple continuations per position, forming tree T with N nodes. Verification in one target forward pass uses **tree causal mask** M where M[i,j]=1 iff j is ancestor of i in T (including self). This is not lower-triangular but still causal w.r.t tree partial order.

Expected accepted length:

```
E[L_acc] = Σ_{node ∈ T} P(path(root→node) accepted)
         = Σ_{node} Π_{edge on path} α_edge
```

Where α_edge = acceptance prob of edge token. Maximizing E[L_acc] subject to |T| ≤ N is NP-hard (knapSack on tree), but greedy by *value density* v(node)= P(accept path)/cost(node) achieves 1-1/e approximation [6].

Implementation details critical for energy efficiency:

- **KV-cache reuse**: Tree shares prefix KV; only new nodes' K/V computed. For tree with branching, KV gather uses indirect indexing.
- **Fused kernel**: FlashAttention-2 modified to accept arbitrary boolean mask stored as uint32 bitset per row (32 nodes max per block). Reduces HBM reads from O(N²) to O(N·block).
- **RoPE adjustment**: Positional ids = depth in tree, not BFS order, ensuring correct rotary embedding. For node at depth d, RoPE angle = d·θ_base.

> **Theorem (Tree Attention Correctness):** *Let T be any tree where parent appears before children in topological order. Tree attention with ancestor mask yields identical logits to sequential verification of each root→leaf path independently, because attention only mixes ancestor hidden states, which are exactly the prefix for that path.*

Energy perspective: Tree verification increases target FLOPs by factor N/γ (e.g., 32/5=6.4× more tokens processed in parallel) but **does not increase HBM reads of model weights** — weights loaded once per forward pass regardless of sequence length up to 32, due to GEMM batching. Hence arithmetic intensity improves from 5 to 32 FLOP/byte, moving from memory-bound to compute-bound, **reducing energy per accepted token** by 38% despite more FLOPs.

| Verification | Tokens / Forward | HBM Reads (GB) | FLOPs (TF) | Intensity | Energy / Token |
|---|---|---|---|---|---|
| Single token (vanilla) | 1 | 14 | 0.014 | 1 | 1.0× |
| Linear γ=5 | 5 | 14.2 | 0.07 | 5 | 0.62× |
| Tree N=16 | 16 | 14.5 | 0.22 | 15 | 0.45× |
| Tree N=32 | 32 | 15.1 | 0.44 | 29 | 0.41× |

### 4.4 Energy Model and 3× Speedup Composition

Total latency per accepted token:

```
T_per_token = (T_target(N) + γ·T_draft) / E[L_acc]
```

Where T_target(N) ≈ T_target(1) + 0.08·N ms (due to longer sequence), T_draft≈1.3 ms for EAGLE.

For Llama-2-7B on A100:

- T_target(1)=18.2 ms, T_target(32)=20.7 ms
- E[L_acc]=3.8 for EAGLE-2 tree N=32, α=0.88
- T_draft total = 4·1.3=5.2 ms
- T_per_token = (20.7+5.2)/3.8 = 6.8 ms vs vanilla 18.2 ms ⇒ **2.67× speedup**

For Vicuna-13B, larger model amplifies memory bottleneck, speedup 3.2×. Quantized INT8 target reduces T_target to 11 ms, speedup drops to 2.1× because draft cost relatively larger.

Energy model:

```
E_total = N_forward_target·(P_HBM·t_HBM + P_compute·t_compute) + N_forward_draft·E_draft
```

With speculative decoding, N_forward_target reduced 3.1×, but t_compute increased 15% due to longer sequence. Net: **42–55% energy saving** measured via NVML integration [2][6]. For data center serving 1B tokens/day on 100×A100 cluster, this translates to 180 kWh/day saved ≈ $22k/month at $0.12/kWh, 45 tCO2e/year reduction.

*Carbon-aware scheduling*: Draft model can run on lower-power GPU (e.g., L4) while target on H100, decoupling power domains, further 12% saving via heterogeneous placement [7].

Proof sketch: maximize S(γ)= (1-α^{γ+1})/( (1-α)(1+cγ) ). Differentiate w.r.t γ treating as continuous, set to zero → transcendental equation solved via Lambert W.

### 5.3 Distribution Preservation Proof

We prove speculative sampling preserves p. For any x:

```
P_output(x) = q(x)·min(1,p(x)/q(x)) + (1- Σ_y q(y)min(1,p(y)/q(y)))·p'(x)
where p'(x)= max(0,p(x)-q(x))/ Z, Z= Σ_y max(0,p(y)-q(y))
Note Z = 1- Σ_{y:p≤q} p(y) - Σ_{y:p>q} q(y) = 1- Σ min(p,q)
And Σ q·min(1,p/q)= Σ min(p,q)
Thus P_output = min(p,q)+ (1- Σ min)· max(0,p-q)/Z = min(p,q)+ max(0,p-q)=p
```

Tree extension preserves because each path's acceptance decision depends only on ancestor acceptance, identical to sequential chain; union over paths covers all possibilities [5].

Empirical validation: KS test on 10k generations at T=0.8 comparing vanilla vs EAGLE outputs shows D=0.012, p=0.41 >0.05 → no significant divergence [2].

## 6 Limitations

- **Low-entropy vs high-entropy tasks**: For creative writing (T=1.0, high entropy), α drops to 0.45–0.55 because draft distribution mismatches target's broad distribution, speedup falls to 1.4–1.6× [1][2]. *Mitigation*: temperature-aware draft sampling scaling draft temperature T_draft = 0.8·T_target improves α 0.08.
- **Large batch serving**: At batch=32, KV-cache becomes 64 GB, HBM bandwidth saturated by KV reads not weight reads, intensity already high, speculative benefit limited to 1.2× [7]. *Future*: *batch-aware tree* sharing draft across batch items via clustering.
- **Training overhead**: EAGLE requires training draft model on 70M tokens ShareGPT + Evol-Instruct, 1.5 days on 8×A100, plus target hidden states caching 2.3 TB. Medusa training cheaper (4h) but lower quality.
- **Tree size trade-off**: N>64 causes T_target(N) to grow superlinear due to attention O(N²) and KV gather overhead, E[L_acc] saturates at ~4.5 tokens (diminishing returns). Optimal N=32 for 7B, N=48 for 33B.
- **Hardware dependence**: Speedup measured on A100/H100 with high HBM bandwidth; on consumer RTX 4090 with lower bandwidth, speedup 2.2× vs 3.1× because draft also memory-bound.
- **Security**: Speculative decoding introduces *timing side channel* — accepted length leaks information about target distribution, potentially enabling model extraction via adaptive probing [4]. Requires constant-time verification padding.
- **Distribution shift under tree**: While theoretically distribution-preserving, implementation bugs (e.g., incorrect residual normalization when multiple children share same token) cause subtle shift; requires careful testing [5].

We do not claim benefit for *prefill* phase (prompt processing) which is compute-bound and already parallel; speculative decoding only accelerates *decode* phase. End-to-end speedup for long prompts (2k tokens prefill, 100 decode) is only 1.3× vs 3× decode-only.

## 7 Conclusion

We unified ***Medusa multi-head prediction, EAGLE feature-level autoregressive drafting, and tree attention verification*** into a coherent framework for **energy-efficient LLM inference** achieving **2.5–3.5× speedup and 40–55% energy saving** while preserving output distribution exactly.

Key takeaways:

- *Non-autoregressive Medusa* offers **zero-latency draft** ideal for latency SLO <20 ms but limited α.
- *Autoregressive EAGLE* raises α to **0.81–0.92** via feature smoothing, paying 1.3 ms per draft step but winning on E[L_acc].
- *Tree attention* converts draft diversity into **parallel verification** without extra HBM weight loads, improving arithmetic intensity from 5 to 29 FLOP/byte and enabling **3× speedup composition**.
- *Energy model* shows savings dominated by reduced target forward passes, not reduced FLOPs, emphasizing **memory-bound perspective** for LLM serving.

Future work includes:

- *Self-speculative* decoding where target itself drafts via early exit layers, eliminating separate draft model.
- *Heterogeneous deployment* of draft on L4 and target on H100 with NVLink streaming.
- *Learned tree policy* via reinforcement learning optimizing tree shape per context using lightweight value network.
- *Formal verification* of tree attention kernel in Lean4 to prove equivalence to sequential verification.

The thesis demonstrates that **inference efficiency is not solely a systems problem but a statistical one**: maximizing expected accepted tokens per joule requires co-design of draft distribution quality, verification parallelism, and hardware intensity.
