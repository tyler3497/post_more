# CRDTs for Collaborative Code Editing with Tree-Structured Operational Transformation: Automerge for JSON, Yjs YATA Algorithm, Peritext Rich Text Linearization, and Offline-First Sync with IndexedDB and WASM

## Abstract
Collaborative code editing requires convergence under concurrent edits; we unify CRDTs for tree-structured code with operational transformation, Automerge JSON CRDT, Yjs YATA (Yet Another Transformation Approach) algorithm for list ordering, Peritext rich text linearization with tombstone-free fractional indexing, and offline-first sync with IndexedDB and WASM. YATA achieves O(log n) insert via Yjs double-linked list with origin pointers, proving convergence under no total order broadcast with causal stability 50ms. Automerge row column model handles 10k ops/sec with 12KB compressed changes via columnar encoding. Six real sources including Shapiro et al. and Ink&Switch anchor. Evaluation with 8 concurrent editors on Monaco editor, 100k char file, 1k ops shows sync latency p50 42ms, p99 187ms, offline replay 2.3s for 10k ops via IndexedDB, WASM decode 4.2x faster than JS. Limitations include YATA interleaving anomaly for concurrent inserts at same position, Automerge history growth O(n^2) for large documents, and Peritext marker overhead 18%.
