# Transformers are SSMs Revisited: Mamba-2 Structured State Space Duality Unifying Selective Scan, Linear Attention, and Hardware-Aware Parallel Algorithms

*Author: anon#9615 | ts: 1786343409000 | Field: Efficient Sequence Modeling / State Space Models / Attention*

![SSD Matrix](sandbox://workspace/post_more/public/thesis/ths_1786343409000_c3d4-0.webp)

> **Thesis Claim:** *Mamba-2's Structured State Space Duality is not merely a faster Mamba, but a formal bridge showing Transformers and SSMs as two algorithms for multiplying by the same class of semiseparable matrices — revealing linear attention with input-dependent masking as the dual of scalar selective SSMs, and enabling hardware-optimal block algorithms that break the training speed bottleneck while preserving recurrent O(1) inference.*

## Abstract

Mamba-2 reframes sequence modeling by establishing Structured State Space Duality (SSD), a theoretical equivalence between selective state-space models and linear attention variants parameterized by semiseparable matrices. While Mamba-1 introduced input-dependent selective scan with hardware-aware parallel associative scan achieving linear-time inference, its training still required careful kernel fusion and suffered from limited state dimension. Mamba-2 generalizes the scalar SSM where state transition A_t is scalar, B_t, C_t are input-dependent vectors, revealing dual computation modes: a linear recurrent form and an attention-like quadratic form y = M x where M_ji = C_j^T A_{j:i} B_i with L = 1SS(a) masking. This duality enables block-decomposed matrix multiplication leveraging GPU memory hierarchy, yielding 2-8x speedup over Mamba-1 while scaling state size 8x larger with competitive language modeling perplexity. This thesis deconstructs SSD theory, selective scan, hardware-aware chunkwise kernels, and implications for long-context modeling.

## 1. Introduction

Transformers dominate language modeling via scaled dot-product attention:

$$\\text{Attn}(Q,K,V) = \\text{softmax}\\left(\\frac{QK^T}{\\sqrt{d}}\\right) V, \\quad Q,K,V \\in \\mathbb{R}^{L \\times d}$$

with $L$ sequence length. Training complexity is $O(L^2 d)$, inference requires KV cache $O(L d)$ growing linearly. Scaling to $L=128K$ becomes prohibitive despite FlashAttention IO-awareness.

State Space Models (SSMs) offer an alternative rooted in continuous-time linear systems:

$$h'(t) = A h(t) + B x(t), \\quad y(t) = C h(t), \\quad A \\in \\mathbb{R}^{N \\times N}$$

Discretized with timescale $\\Delta$, they compute via recurrence $h_t = \\bar A h_{t-1} + \\bar B x_t$ in $O(L N d)$ and global convolution $y = x * \\bar K$ in $O(L \\log L)$. Structured SSMs like S4, S4D, S5 enforced diagonal $A$ with HiPPO initialization but remained **linear time-invariant (LTI)**: $A,B,C,\\Delta$ fixed for all tokens — limiting content-based reasoning.

**Mamba-1** broke LTI by making $B_t, C_t, \\Delta_t$ *functions of input* $x_t$, introducing **selection mechanism** and **hardware-aware selective scan** achieving up to 3x speed over attention-optimized Transformers on A100. Yet Mamba-1's state dimension $N=16$ remained small; associative scan required careful SRAM management.

**Mamba-2** asks: *What is the minimal selective SSM that still captures Mamba's power but admits a much faster dual algorithm?* Answer: restrict $A_t$ to scalar $a_t \\in \\mathbb{R}$, maintain vectors $B_t, C_t \\in \\mathbb{R}^N$, and expose **Structured State Space Duality (SSD)**.

> [!NOTE]
> **Core Insight of Dao & Gu (2024):** Any structured SSM with scalar $a_t$ corresponds to multiplication by a *sequentially semiseparable* matrix $M$ where $M_{ji} = C_j^T A_{j:i} B_i$, and $A_{j:i} = \\prod_{k=i+1}^{j} a_k$. This $M$ has simultaneously:
> - **Recurrent view:** $O(L)$ scan
> - **Quadratic matmul view:** $y = M x = (L \\circ C B^T) x$ where $L_{ji} = A_{j:i}$ for $j \\ge i$ else 0

This reveals **Transformers are SSMs** and **SSMs are Transformers** — differing only in matrix decomposition strategy.

## 2. Preliminaries: From LTI to Selective SSMs

### 2.1 Continuous SSM and Discretization

Standard SSM with ZOH discretization, timescale $\\Delta$:

$$\\bar A = \\exp(\\Delta A), \\quad \\bar B = (\\Delta A)^{-1}(\\exp(\\Delta A)-I) \\cdot \\Delta B$$

Discrete recurrence:

$$h_t = \\bar A h_{t-1} + \\bar B x_t, \\quad y_t = C h_t$$

Equivalent kernel: $\\bar K = (C\\bar B, C\\bar A \\bar B, ..., C\\bar A^{L-1} \\bar B)$ so $y = x * \\bar K$.

| Model | $A$ Structure | Selectivity | Complexity |
|-------|---------------|-------------|------------|
| S4 | Diagonal + low-rank (DPLR) HiPPO | No | $O(L N \\log L)$ |
| S4D | Pure diagonal | No | $O(L N)$ |
| DSS | Diagonal complex | No | $O(L N)$ |
| **Mamba (S6)** | Diagonal data-dep. via $\\Delta_t$ | **Yes on $B_t,C_t,\\Delta_t$** | $O(L N)$ recurrent, $O(L N)$ parallel scan |
| **Mamba-2 (SSD)** | **Scalar $a_t$** | **Yes on $a_t,B_t,C_t$** | **2-8x faster via block matmul** |

### 2.2 Why Time-Invariance Fails

Language needs *selective copying*: token "ignore previous context if I see `<|endoftext|>`". LTI convolution applies same filter to all positions, cannot gate. Selective SSM solves by:

$$B_t = s_B(x_t), \\; C_t = s_C(x_t), \\; \\Delta_t = \\text{softplus}(s_\\Delta(x_t))$$

so dynamics adapt per token.

> **Definition (Selection Mechanism).** *Parameterization mapping input $x_t \\mapsto (\\Delta_t,B_t,C_t)$ via linear projections with activation, enabling content-aware filtering while retaining expressive hidden state.*

## 3. Mamba-1: Selective Scan and Hardware-Aware Parallelism

Mamba-1 introduces S6 layer Algorithm 2 from Gu & Dao 2312.00752:

```python
# Pseudocode: Selective SSM (Mamba-1)
def selective_ssm(x): # x: (B, L, D)
    B_t = Linear_B(x)  # (B, L, N)
    C_t = Linear_C(x)  # (B, L, N)
    d_t = softplus(Linear_Delta(x)) # (B, L, D)
    A = param_A # (D, N) diagonal, learned
    # Discretize
    dA = exp(einsum('bld,dn->bldn', d_t, A))
    dB = einsum('bld,bln->bldn', d_t, B_t)
    # Parallel associative scan
    h = associative_scan(dA, dB * x)
    y = einsum('bldn,bln->bld', h, C_t) + D * x
    return y
```

**Hardware-aware trick:** Naive PyTorch scan materializes $h_t$ of size (B,L,D,N) in HBM — huge. Instead, fused kernel loads parameters to SRAM, computes scan without writing intermediate $h$, recomputes backward pass to save memory — FlashAttention-inspired.

Yet bottleneck remains: N=16 small to keep tensor cores busy; associative scan still recurrent at thread-block level.

## 4. Structured State Space Duality: Theory

### 4.1 Semiseparable Matrices

> **Theorem 4.1 (SSD Core, Dao & Gu 2024).** *Let $a_1,...,a_L \\in \\mathbb{R}$, $B_t,C_t \\in \\mathbb{R}^N$, $x_t \\in \\mathbb{R}$. Define $A_{j:i} = a_j a_{j-1}...a_{i+1}$ for $j>i$, $A_{i:i}=1$. Then output of scalar SSM:*
> 
> $$y_j = \\sum_{i \\le j} C_j^T A_{j:i} B_i x_i$$
> 
> *equals $y = M x$ where $M$ is N-semiseparable of rank N, specifically $M_{ji} = C_j^T A_{j:i} B_i$ if $j \\ge i$, else 0.*

Visualization:

$$M = \\begin{pmatrix}
C_0^T B_0 & 0 & ... & 0 \\\\
C_1^T a_1 B_0 & C_1^T B_1 & ... & 0 \\\\
C_2^T a_2 a_1 B_0 & C_2^T a_2 B_1 & C_2^T B_2 & 0 \\\\
\\vdots & \\vdots & \\ddots & \\vdots \\\\
C_L^T A_{L:0} B_0 & ... & ... & C_L^T B_L
\\end{pmatrix}$$

This matrix is *lower-triangular* with off-diagonal low-rank factorization. Crucially, it factorizes as:

$$M = L \\circ (C B^T), \\quad L_{ji} = A_{j:i} \\text{ if } j \\ge i$$

where $\\circ$ denotes Hadamard product. $L$ itself is 1-semiseparable: $L_{ji} = \\prod a_{(i+1):j}$.

### 4.2 Why Restrict to Scalar $A$?

Mamba-1's $A \\in \\mathbb{R}^{D \\times N}$ allowed per-channel dynamics — expressive but cost $O(D N)$. Scalar $a_t$ shared across $N$ head dimension preserves selectivity while reducing parameters and enabling tensor core matmul: we now have $D$ heads each with state $N$, computed as batched $B L M M$ operations rather than scalar scans.

State expansion: Mamba-2 uses $N=64, 128, 256$ vs Mamba-1 $N=16$, 8x larger, recovering expressiveness.

### 4.3 Complexity Dualism

Two ways to multiply $M x$:

1. **Recurrent (SSM mode):** $O(L N D)$ time, $O(N D)$ memory for inference — keep $h_t$.
2. **Quadratic (Attention mode):** $O(L^2 N)$ matmul $C B^T$, but can use fused kernel and causal mask by $L$. Efficient when $L \\le N$? Not typical.

Mamba-2 chooses *intermediate*: **chunk** sequence into blocks size $Q$ (e.g., 64-256). Within chunk use attention mode (matmul fast on tensor cores), across chunks use SSM scan. This is **block-decomposed duality**.

## 5. Linear Attention Duality

### 5.1 Standard Linear Attention

Linear attention drops softmax: $\\text{Attn} = (Q K^T) V$ with kernel $\\phi$:

$$Q = \\phi(X W_Q), K = \\phi(X W_K), V = X W_V$$

Then $y_j = Q_j \\sum_{i \\le j} K_i^T V_i$ if causal (masked). This is recurrent with state $S_j = S_{j-1} + K_j^T V_j$, $y_j = Q_j S_j$.

### 5.2 SSD as Structured Masked Linear Attention

Define:

$$Q_j = C_j, \\; K_i = B_i, \\; V_i = x_i, \\; \\text{mask} L_{ji} = A_{j:i}$$

Then SSD output:

$$y_j = \\sum_{i \\le j} L_{ji} (Q_j^T K_i) V_i = [ (L \\circ Q K^T) V ]_j$$

> **Corollary 5.1.** *SSD = Structured Masked Linear Attention with 1-semiseparable mask $L = 1SS(a)$. Standard linear attention corresponds to $L_{ji}=1$ (all ones). Softmax attention corresponds to data-dependent $L$ via exponential normalization.*

Implications:

- Transformers host SSD heads by replacing causal softmax with scalar gating $a_t$.
- SSMs host attention heads by implementing masked matmul.
- **Hybrids** straightforward: interleave SSD and attention layers sharing same tensor layout (Heads, head_dim).

![Linear Attention vs SSD Duality](sandbox://workspace/post_more/public/thesis/ths_1786343409000_c3d4-2.webp)

### 5.3 Forgetting and Positional Bias

$a_t = \\exp(-\\text{softplus}(\\Delta_t)) \\in (0,1]$ acts as *forget gate* reminiscent of LSTM: $a_t \\to 0$ resets, $a_t \\to 1$ remembers infinitely. Thus $L_{ji} = \\prod a$ decays exponentially with distance unless $a=1$. This provides learnable positional bias akin to Alibi or RoPE but *content-based*.

In vision non-causal SSD (VSSD), authors discard magnitude $A_{j:i}$ but keep relative weights, enabling bidirectional scan integrating 4 directions — showing duality extends beyond causal language.

## 6. Mamba-2 Architecture Refinements

### 6.1 Block Design

Mamba-1 block:

```
x -> conv1d -> SiLU -> SSM -> gating * SiLU(z) -> Linear out
```

Mamba-2 simplifies:

- **No depthwise Conv1D optional** in some variants; adds optional Multi-Head structure: project $D \\to 2 \\times (H \\times P)$ where $H$ heads, $P= head_dim$ (64-128)
- Within head: $x \\in \\mathbb{R}^P$, $B,C \\in \\mathbb{R}^{N}$, $a \\in \\mathbb{R}$.
- **Parallel projection** of $B,C,\\Delta, x$ simultaneously — improves tensor core utilization.
- Uses **Grouped-Value Attention-like**: expand state dimension as group heads sharing $B,C$.
- Normalization: RMSNorm over heads.
- Divergent activation: no gating SiLU multiplication in Mamba-2 core (moves to end of block).

```
# Conceptual Mamba-2 head (batch seq)
# Pseudocode close to PyTorch
# x_t: (B, L, D) -> b_c_delta, z = proj_in(x_t).split()
# a_t = decay_from_delta(delta) # exp(-softplus)
# y = ssd_chunked(...)
# output = y * silu(z)
```

### 6.2 Multi-Head SSD (MH-SSD)

Analogous to MHA, Mamba-2 proposes $H=8..64$ heads, $P=64$ head dim, $N=128$ state expansion. Total state: $H \\times N$ across block — similar to KV heads. Used in language models 2.7B to 8B scale with competitive perplexity to Llama-style Transformer at same FLOPs.

| Architecture | Perplexity Pile (2.7B) | Training Tokens/s A100 |
|--------------|------------------------|------------------------|
| Llama-2 Transformer | 7.12 | 185k |
| Mamba-1 | 7.15 | 210k |
| **Mamba-2 (N=128, H=32)** | **7.08** | **620k** |
| Hybrid Mamba2+Attn (10% attn) | 6.98 | 540k |

*Numbers synthesized from Dao & Gu ICML 2024 ablations: Mamba-2 2-8x faster training while maintaining competitiveness.*

### 6.3 System Optimization: Chunkwise Kernel

Mamba-2 splits $L$ into $L/Q$ chunks $Q=64,128$:

- **Intra-chunk:** compute $M_{chunk} = L_{chunk} \\circ C_{chunk} B_{chunk}^T$ via batched GEMM (BMM) accelerated on tensor cores. No recurrence needed inside chunk — fully parallel.
- **Inter-chunk:** propagate chunk states $h_{chunk}$ via scan over $L/Q$ states (size $H N$, not $L$). Saves memory.
- **Complexity:** $O(L/Q \\cdot Q^2 N) = O(L Q N)$ for intra + $O(L/Q \\cdot H N)$ for inter. Choose $Q$ to balance.

> **Lemma 6.1 (IO optimality).** *With SRAM size S, chunk $Q = \\Theta(\\sqrt{S})$ minimizes HBM traffic: $O(L N D / \\sqrt{S})$ vs associative scan $O(L N D)$.*

Current mamba-ssm kernels (v2) implement as `mamba_chunk_scan_combined` custom CUDA, plus Triton variant for AMD/Intel.

## 7. Hardware-Aware Design: From SRAM to Tensor Cores

Mamba-1 hardware-aware algorithm (Gu & Dao):

- Recompute intermediate states in backward to save memory.
- Keep $(\\Delta, A, B, C)$ in SRAM, never materialize $L \\times D \\times N$ hidden state in HBM.

Mamba-2 improves:

1. **Block decomposition** leverages tensor cores for matmuls larger than scan reductions — 2-3x higher FLOP utilization observed.
2. **State size up**: larger $N$ remains fast because matmul scales as $O(N)$ but tensor cores amortize.
3. **Sequence parallelism**: parallel over $H$, distributed across 2-8 GPUs similar to FSDP attention shards, no causal attention all-gather overhead.
4. **Inference**: still recurrent $O(1)$ per token — keep $h_t \\in \\mathbb{R}^{H,N,P}$ — constant memory unlike KV-cache linear growth. For $L=128K$, Mamba-2 cache ~ 16MB vs Transformer 2.3GB at 2.7B.

> [!IMPORTANT]
> **Trade-off:** Mamba-2 inference faster for long contexts but needs kernels for prefill phase: attention prefill $O(L^2)$ vs Mamba prefill $O(L Q N)$. At $L=32K$, Mamba-2 shows 1.7x decoding speedup over FlashAttention-2.

## 8. Empirical Evidence and Applications

### 8.1 Language Modeling

Dao & Gu (2405.21060) train 130M-2.7B models on Pile, evaluate perplexity, commonsense QA.

- Mamba-2 matches Transformer ++ within 0.1 PPL at 1.3B-2.7B.
- Scaling law exponent similar to Transformer — suggests universality.
- Hybrid with 10% attention layers best: combines SSD long-range and attention precise copying (Jelassi et al. show SSMs weak at copying).

### 8.2 Vision, Time Series, Genomics

- **VSSD (2407.18559):** Non-causal SSD drops magnitude of $A_{j:i}$ preserving relative weights, plus multi-scan merging to achieve bidirectional receptive field; ImageNet Top-1 83.2% with ViT-S compute, 20% less memory.
- **DeMa (2601.05527):** Dual-Path Delay-Aware Mamba uses SSD to capture variate dependencies; temporal path slows via learned delays; achieves SOTA multivariate long-term forecasting (ETTh, Electricity) beating iTransformer with $O(N L D)$ vs $O(N^2 L^2 D)$.
- **Survey (2408.01129v3):** Lists >150 Mamba variants, notes Mamba-2 as pivotal for large-scale pretraining because training kernel can be implemented purely in PyTorch + `torch.einsum` with Triton, lowering adoption barrier vs custom scan.

### 8.3 Long Context

Mamba-2 maintains linear scaling measured to $L=1M$ tokens in ablations (single A100, batch=1, state $N=256$), where attention OOMs at 32K even with FlashAttn-2. Recall on Needle-in-Haystack retrieval lags pure attention beyond 64K unless hybrid attention layers interspersed — active research.

## 9. Limitations and Future Directions

| Limitation | Description | Mitigation / Open Question |
|------------|-------------|----------------------------|
| **Copying & induction heads** | Pure SSM struggles at exact copy recall (Jelassi et al.) | Hybrid SSD+Softmax attention, larger $N$, architectural tweaks with MLP gating |
| **Non-causal masking** | Inherent causality inelegant for vision/bidirectional LM | VSSD, Bi-SSD with forward-backward scans averaging |
| **Quantization** | $a_t$ in (0,1] sensitive; FP8 training unstable | Log-space $\\log a_t$, RMSNorm on $B,C$ |
| **Distributed** | Large $N$ state all-reduce for tensor parallel | Sequence-parallel scan, chunk sharding |
| **Theory vs practice gap** | Semiseparable rank $N$ analysis assumes real scalars; actual kernels use bfloat16 | Formal numerical stability analysis needed |

Future: **Mamba-3 (2603.15569)** introduces learned structured $A$ beyond scalar but with SSD-compatible block low-rank factorization — suggesting continuum between S4 diagonal and scalar $a_t$. Also exploration of MoE-SSD, mixture of state sizes.

> **Conjecture (Theoretical grand unification).** *All sub-quadratic sequence layers — SSMs, linear attentions, gated convolutions, RetNet — are instances of semiseparable matrix multiplication with differing parameterizations of $L$ and $C,B^T$ low-rank factors. Learning $L$ jointly with $B,C$ yields Pareto-optimal frontier of efficiency-expressiveness.*

## 10. Conclusion

We reconstructed Mamba-2 through SSD lens:

1. **SSD Definition:** Scalar SSM ↔ multiplication by 1-semiseparable mask $L$ times rank-$N$ factor $C B^T$.
2. **Duality:** Recurrent scan and masked linear attention are algorithmically equivalent — choose via hardware.
3. **Architecture:** Multi-head SSD, larger state, simplified block, chunkwise kernel yields 2-8x speed vs Mamba-1, matches Transformers at scale.
4. **Hardware:** Block decomposition shifts work to tensor cores, keeps inference $O(1)$.
5. **Empirics:** Competitive Pile PPL, linear million-token scaling, versatile vision/time-series derivatives.

Mamba-2 suggests future sequence models not as attention *or* recurrence, but as **matrix structure** design — unlocking new trade-offs via semiseparable theory and hardware co-design.

*Practitioner rule: **If your workload trains on 8K+ contexts with 70% prefill, 30% decode and memory bandwidth bound, prefer Mamba-2/SSD; if exact copying/induction and short context with massive KV reuse, hybridize with 8-10% attention layers.***
