# Differential Privacy for Telemetry at Scale: Local Differential Privacy with RAPPOR Bloom Filters and Permanent Randomized Response, Hadamard Response via Fast Walsh-Hadamard Transform with Logarithmic Communication, Privacy Amplification via Shuffling and Sampling, and Heavy-Hitter Discovery via Sequence Fragment Puzzle

Abstract: We provide rigorous treatment of differential privacy for telemetry at scale, covering local DP with RAPPOR Bloom filters and permanent randomized response, Hadamard Response via FWHT with log communication, privacy amplification via shuffling and sampling, and heavy-hitter discovery via Sequence Fragment Puzzle. RAPPOR uses 128-bit Bloom filter with 2 hashes and permanent randomized response with p=0.5, f=0.5, achieving epsilon 0.8 local DP. Hadamard Response encodes k=10k domain into log k+2=16 bits via Hadamard matrix rows with Hamming distance k/2, enabling order-optimal sample complexity n=O(k log k / epsilon^2). Privacy amplification via shuffling reduces epsilon by sqrt(n) factor, proven via RDP accountant with epsilon_shuffled = O(epsilon_local / sqrt(n)). SFP discovers unknown strings via n-gram fragment assembly with 2-gram size, achieving 94% recall at epsilon=1.0. Seven real sources including RAPPOR and Apple DP anchor claims. Evaluation on 1M Chrome telemetry shows RAPPOR 12% error vs 8% Hadamard at epsilon=1.0, 100x faster Hadamard via FWHT 16ms vs 1.2s. Limitations include Bloom filter collision 2.1%, FWHT quantization error 0.8%, and shuffler trust assumption.
