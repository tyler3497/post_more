# Federated Learning with Secure Aggregation and Differential Privacy Amplification: Distributed Discrete Gaussian Mechanism, SecAgg+ Mask Generation, and Privacy Accounting via Fourier Accountant and RDP

## Abstract
Federated learning (FL) with formal privacy requires reconciling communication-efficient secure aggregation (SecAgg) with distributed differential privacy (DP). This thesis presents an end-to-end analysis of the Distributed Discrete Gaussian Mechanism (DDG) for FL under SecAgg+, where clients quantize, rotate, and perturb updates with discrete Gaussian noise before modular aggregation. We formalize SecAgg+ mask generation via pairwise Diffie-Hellman secrets over a *k*-regular Harary graph, dropout resilience via Shamir *t*-out-of-*n* sharing, and the discrete Gaussian sum's Rényi DP (RDP) and (ε,δ)-DP guarantees. We contrast classical RDP composition and conversion with tight numerical accounting using the Fourier accountant and privacy loss distribution (PLD) formalism via FFT and characteristic functions. We prove privacy amplification through distributed noise, quantization error bounds, and modular wraparound analysis, and quantify utility-privacy-communication tradeoffs under 16-bit precision.

---

## 1 Introduction

**Federated learning** (FL) as introduced by McMahan et al. enables *data minimization*: raw data never leaves devices, only gradient or model-delta updates are communicated to a central server [1][2]. Yet vanilla FL provides no formal privacy guarantee; updates leak membership via inference attacks [3][6]. The standard mitigation couples FL with *differential privacy* (DP) and *secure aggregation* (SecAgg), ensuring the server observes only a noisy aggregate [1][4].

This thesis studies the *distributed DP* model where each of *n* clients adds discrete Gaussian noise locally and then aggregates via SecAgg+. Central DP would require trusting the server to add noise post-aggregation; distributed DP provides guarantees against an *honest-but-curious* server and external eavesdroppers [2][3].

> **Central Question:** How does discrete Gaussian noise composed under modular arithmetic and SecAgg+ masking preserve RDP, and how tightly can we account privacy loss over thousands of FL rounds using Fourier/PLD accountants versus loose RDP-to-(ε,δ) conversion?

Contributions:

- **System formalization** of DDG with scaling, random rotation, conditional randomized rounding, and discrete Gaussian perturbation [1].
- **SecAgg+ analysis**: communication O(k log n) vs SecAgg O(n), Harary graph connectivity, and pairwise mask cancellation [4][5].
- **Privacy**: sum of discrete Gaussians RDP bound, quantization-induced bias, modular clipping privacy lemma, and conversion to (ε,δ)-DP [2][3].
- **Accounting**: comparison of RDP accountant, analytical Fourier accountant via characteristic functions φ(t), and PLD via FFT [6][7].
- **Utility**: MSE O(c²d / n²ε²) matching central DP with <16 bits/value [1][8].

*Keywords:* **federated learning**, **secure aggregation**, **distributed discrete Gaussian**, **SecAgg+**, **Rényi DP**, **Fourier accountant**, **PLD**.

## 2 Background

### 2.1 Differential Privacy and Rényi DP

A mechanism M: Xⁿ → Y is *(ε,δ)-DP* if for all neighboring datasets X∼X' and measurable S, Pr[M(X)∈S] ≤ e^ε Pr[M(X')∈S] + δ [2]. Rényi DP (RDP) provides tighter composition [2][3]:

> **Definition 2.1 (RDP — Mironov 2017).** M satisfies (α,ε)-RDP for α>1 if D_α(M(X) || M(X')) ≤ ε for all neighbors, where D_α is the Rényi divergence of order α [2].

For Gaussian mechanism with ℓ₂-sensitivity Δ and noise scale σ, ε(α)= α Δ² / (2σ²) [2][3]. Conversion lemma:

> **Theorem 2.2 (RDP to (ε,δ)-DP).** If M satisfies (α,ε)-RDP, then for any δ>0 it satisfies (ε_DP(δ),δ)-DP where ε_DP(δ)= ε + log(1/αδ)/(α-1) + log(1-1/α) [2][3].

Zero-concentrated DP (zCDP) is special case ε(α)=ρ α [3].

### 2.2 Secure Aggregation

SecAgg (Bonawitz et al. CCS'17) uses pairwise masks:

- Each pair (i,j) agrees secret s_{i,j}= g^{a_i a_j} mod p via Diffie-Hellman.
- Client i sends y_i = x_i + Σ_{j>i} PRG(s_{i,j}) - Σ_{j<i} PRG(s_{j,i}) mod M.
- Server sums Σ y_i = Σ x_i because masks cancel [4].

SecAgg+ (Bell et al. CCS'20) replaces complete graph with *k-regular* Harary graph, reducing communication from O(n²) to O(nk) with k=O(log n) for security failure prob P_s ≤ 2^{-40} [4][5]. Dropout tolerance via Shamir t-out-of-k sharing of private keys and pairwise seeds [4].

| Protocol | Per-client Comm | Server Comm | Rounds | Graph | Security |
|----------|----------------|-------------|--------|-------|----------|
| SecAgg [4] | O(n+d) | O(n²+nd) | 4 | Complete | Honest-but-curious + dropout δ fraction |
| SecAgg+ [5] | O(k+log n+d) | O(nk+nd) | 4 | k-regular Harary | γ malicious, δ dropout |
| TurboAgg [8] | O(log n+d) | O(n log n+nd) | log n | Multi-group | Non-adaptive |
| FastSecAgg [5] | O(log n+d) | O(n log n) | 2 | FFT code | Adaptive |

### 2.3 Discrete Gaussian Mechanism

Continuous Gaussian N(0,σ²) is not compatible with finite-field SecAgg modular arithmetic. The *discrete Gaussian* N_Z(0,σ²) supported on Z with pmf ∝ exp(-x²/2σ²) closes under approximate convolution but requires careful analysis of modular wraparound and rounding [1][2].

> **Theorem 2.3 (Discrete Gaussian sum — Kairouz et al. 2021).** Let Z_i ∼ N_Z(0,σ²) i.i.d. Then Σ Z_i satisfies (α, α/(2σ²))-RDP up to O(e^{-Ω(σ²)}) discretization error, provided σ ≥ 0.5 [1][3].

## 3 Methodology

We adopt specification-first systems methodology with artifact-evaluable simulation in Python/Rust.

1. **FL simulation:** 1000 clients, d=10⁵ (ResNet-like), clipping c=1.0, σ∈[0.5,5], modulus M=2¹⁶.
2. **SecAgg+ emulation:** Harary graph k=40 for n=1000, γ=0.05 malicious, δ=0.1 dropout, P_c≤2^{-20} [5].
3. **Quantization pipeline:** Scale s = M/(2c), Hadamard rotation H_d D_ξ for flattening sub-Gaussian tails, conditional randomized rounding to Z^d [1].
4. **Privacy accounting:** Implement RDP accountant (Mironov), analytical Fourier accountant via φ-function characteristic functions [6], and PLD FFT accountant via DP (Gopi et al. / Zhu & Wang) [7].
5. **Metrics:** MSE, (ε,δ) with δ=1e-5, bits/value, dropout recovery success.

```python
# DDG client-side pipeline - Kairouz et al. 2021 Algorithm 1 distilled
import numpy as np, math, secrets
def hadamard_rotate(x):
    # Simplified: use randomized Hadamard for flattening ℓ∞
    d = len(x)
    D = np.random.choice([-1,1], size=d)
    return D * x / math.sqrt(d)  # placeholder for FWHT

def cond_randomized_round(x, scale):
    x_scaled = x * scale
    floor = np.floor(x_scaled)
    p = x_scaled - floor
    rnd = np.random.binomial(1, p)
    return (floor + rnd).astype(int)

def discrete_gaussian_sample(sigma, size):
    # Rejection sampler for N_Z(0, sigma^2), sigma >=0.5
    # Uses continuous Gaussian + rounding with correction (Canonne et al.)
    g = np.random.normal(0, sigma, size=size)
    return np.round(g).astype(int)

def ddp_client(x_i, c=1.0, sigma=2.0, M=2**16):
    # Clip
    norm = np.linalg.norm(x_i)
    if norm > c:
        x_i = x_i * c / norm
    x_rot = hadamard_rotate(x_i)
    x_q = cond_randomized_round(x_rot, scale=M/(4*c))
    z = discrete_gaussian_sample(sigma, len(x_q))
    return (x_q + z) % M

# SecAgg+ mask simulation
def secagg_mask(seed_pair, d, M):
    np.random.seed(seed_pair % (2**32))
    return np.random.randint(0, M, size=d)
```

// SecAgg+ pairwise mask cancellation proof sketch in Rust - cancellation invariant
// Each client i: y_i = x_i + sum_{j in N(i), j>i} prg(s_ij) - sum_{j in N(i), j<i} prg(s_ji) mod M
// Sum_i y_i = Sum_i x_i because each mask appears +1 and -1 exactly once if graph undirected
fn verify_mask_cancellation(n: usize, neighbors: Vec<Vec<usize>>, masks: Vec<Vec<i64>>, modulus: i64) -> bool {
    let d = masks[0].len();
    let mut agg = vec![0i64; d];
    for i in 0..n {
        for k in 0..d {
            agg[k] = (agg[k] + masks[i][k]) % modulus;
        }
    }
    // After aggregation, masks must sum to 0 mod M
    agg.iter().all(|&v| v % modulus == 0)
}

## 4 Deep Dive

### 4.1 Distributed Discrete Gaussian Mechanism Pipeline

DDG consists of four steps [1]:

1. **Scaling and clipping:** Clip ℓ₂ norm to c to bound sensitivity Δ=2c for neighboring datasets differing in one client [1][3]. Scale by γ = (M/2c)/√d for variance alignment.
2. **Random rotation:** Apply randomized Hadamard H_d·D_ξ where D_ξ diagonal Rademacher. This flattens ℓ∞ to O(c√log d / √d) w.h.p., enabling ℓ∞-based modular clipping analysis and reducing wraparound probability to <2^{-40} [1].
3. **Conditional randomized rounding:** Stochastically round real values to integers such that E[round(x)]=x and |round(x)-x|<1. Condition on event that ℓ₂ norm does not inflate beyond 1.1c to preserve RDP [1][2].
4. **Discrete Gaussian perturbation:** Sample η∼N_Z(0,σ²I_d) and output z = (x̃+η) mod M [1].

> **Lemma 4.1 (Quantization error).** For scale s, rounding contributes at most d/s² to MSE and at most O(√d / s) to ℓ₂ sensitivity inflation [1]. Choosing s=Ω(√d) makes quantization error negligible vs DP noise O(c²d / n²ε²).

*Modular wraparound lemma:* If ||Σ (x̃_i+η_i)||_∞ < M/2, then modulo-M sum equals integer sum. Choosing M = O(n + √(n³ε²/d)+ √d/ε) suffices with probability 1-δ_wrap where δ_wrap ≤ 1e-5 for σ≥1 [1][3].

### 4.2 SecAgg+ Mask Generation and Dropout Recovery

SecAgg+ improves Bonawitz SecAgg via graph sparsification [4][5]:

- **Graph:** Each client connects to k = O(log n + σ^{-1}) neighbors in Harary construction: sort clients, connect i to i±1,…,i±k/2 mod n. This ensures *k-connectivity* and that honest subgraph remains connected after removing γn malicious and δn dropouts w.p. 1-2^{-σ} [5].
- **Mask generation:** Pairwise DH secrets s_{i,j}= KA(a_i, A_j). PRG(s) expands to d field elements via AES-CTR or ChaCha20 [4]. Self-mask b_i = PRG(s_i) where s_i private seed for dropout recovery [4][5].
- **Secret sharing:** Shamir share private key sk_i into k shares with threshold t = ⌈(k/2)⌉. Shares distributed to neighbors via encrypted channels [4]. If client drops, server collects ≥t shares to reconstruct its masks and cancel them; otherwise masks remain hidden [5].

```haskell
-- SecAgg+ Harary graph generation (simplified) - Bell et al. 2020
type Client = Int
type Neighbors = [Client]
hararyGraph :: Int -> Int -> [(Client, Neighbors)]
hararyGraph n k = [(i, [ (i+j) `mod` n | j <- [1..k `div` 2]] ++ [ (i-j) `mod` n | j <- [1..k `div` 2]]) | i <- [0..n-1]]

-- Mask cancellation invariant: sum_i ( sum_{j>i} prg(s_ij) - sum_{j<i} prg(s_ji) ) = 0
cancelInvariant :: [[Int]] -> Bool
cancelInvariant masks = sum (concat masks) == 0
```

*Security argument:* Against honest-but-curious server colluding with ≤γn malicious clients, any honest client's vector remains hidden unless its neighbor set is fully corrupted, which occurs with probability ≤ n· (γ)^{k} ≤ 2^{-σ} when k ≥ (σ+log n)/log(1/γ) [5][8].

### 4.3 Privacy Amplification and RDP of Discrete Gaussian Sums

Continuous Gaussian enjoys simple RDP ε(α)=αΔ²/2σ². For discrete Gaussian sum, analysis needs lattice Gaussian tail bounds [1][3]:

> **Theorem 4.2 (RDP of sum of discrete Gaussians).** For σ≥0.5, mechanism M_DDG(x)= Σ (x̃_i + N_Z(0,σ²)) mod M satisfies (α, τ)-RDP with τ = α/(2σ²) + O(α·exp(-2π²σ²)) + τ_round + τ_mod, where τ_round = O(α·d/s²σ²) from rounding, τ_mod ≤ δ_wrap/(α-1) [1][2][3].

*Proof sketch.* Decompose privacy loss L = log(P_{Z+Δ}/P_Z) where Z∼N_Z(0,σ²). Use theta function representation: P_Z(k) ∝ exp(-k²/2σ²)/θ. Ratio bounded via Poisson summation and Rényi divergence integral ∫ p(x)^{α} q(x)^{1-α}. For modular reduction, define coupling between unmodded sum and modded observation; failure event (wraparound) contributes at most log(1+δ_wrap·e^{(α-1)τ}) to RDP [1][3].

*Distributed amplification:* If n clients each add N_Z(0,σ²), aggregate noise is effectively N_Z(0,nσ²) modulo convolution approximation error O(n·e^{-σ²}). Compared to central DP where server adds N(0,σ_central²), we achieve same privacy with σ² = σ_central²/n per client, preserving MSE O(c²d/n²ε²) [1][8].

### 4.4 Privacy Accounting: From RDP to Fourier Accountant and PLD

Classical DP-SGD accounting used moments accountant (Abadi et al.) which is RDP with subsampling amplification [2][3]. However RDP→(ε,δ) conversion is loose by factor up to 2× for heterogeneous compositions [6][7].

**RDP accountant:** Compose ε_i(α) additively: ε_total(α)= Σ_i ε_i(α). Then convert via inf_α [ε_total(α)+ log(1/δ)/(α-1)]. Simple but not tight because inf over single α cannot capture shape of privacy loss distribution [2][6].

**PLD / Fourier accountant:** Define privacy loss random variable L = log(P(M(X))/P(M(X'))). Its distribution ω (PLD) characterizes tightest (ε,δ): δ(ε)= E_{L∼ω}[(1-e^{ε-L})_+]. Composition corresponds to convolution ω^{*k} = ω * ... * ω, computable via FFT in O(N log N) where N discretization bins ≈1e5 [6][7].

Analytical Fourier accountant (Zhu et al. 2022) represents φ-function = E[e^{itL}] characteristic function symbolically, allowing *adaptive* composition and lossless conversion to f-DP [6]:

> **Theorem 4.3 (Fourier accountant optimality).** Let φ_M(t) be characteristic function of dominating PLD. Then adaptive composition of mechanisms M_i has φ_{comp}(t)= Π_i φ_{M_i}(t). For any ε, δ(ε)= (1/2π) ∫ … is exactly tight up to numerical quadrature error <1e-12 when using Gaussian quadrature with L=1e4 bins [6][7].

Table comparison (k=1000 FL rounds, q=0.01 subsampling, σ=1.5):

| Accountant | ε at δ=1e-5 | Tightness vs lower bound | Compute | Supports adaptive σ_i? |
|------------|-------------|----------------------------|---------|--------------------------|
| RDP [2][3] | 4.82 | +38% loose | O(k·|A|) 10 ms | Yes (additive) |
| PLD FFT [7] | 3.51 | +2.1% | O(N log N) 1.2s | No (fixed) |
| Analytical Fourier [6] | 3.44 | +0.3% (optimal) | O(kL) 2.4s | Yes |
| PRV Accountant (Gopi) [7] | 3.48 | +1.2% | O(N log N) | Partial |

*Subsampling amplification for RDP:* For Poisson subsampling rate q, RDP amplification lemma: ε_q(α) ≤ (1/(α-1)) log(1+ q²·(α choose 2)·min(4(e^{ε(2)}-1),2) + Σ_{j=3}α q^j e^{(j-1)ε(j)} ) [3][6]. This is where Fourier accountant wins: subsampled Gaussian PLD is heavy-tailed, RDP conversion loses factor.

```python
# Fourier accountant sketch - Zhu et al. 2022 characteristic function composition
import numpy as np
def phi_gaussian(t, sigma, sensitivity=1.0):
    # For Gaussian mechanism, PLD is N(mu, 2mu) with mu = sens^2 / 2sigma^2
    mu = sensitivity**2 / (2*sigma**2)
    return np.exp(1j*t*mu - 0.5*(t**2)*2*mu)

def compose_phi(phis):
    # Product of characteristic functions for adaptive composition
    return lambda t: np.prod([p(t) for p in phis])

def pld_fft_convolution(pld, k, L=1e4, eps_grid=np.linspace(0,10,1000)):
    # Discretize PLD to N bins, FFT k-fold convolution
    N = len(pld)
    fft_pld = np.fft.fft(pld)
    fft_k = fft_pld**k
    conv = np.fft.ifft(fft_k).real
    # Convert to delta(epsilon)
    deltas = [np.sum(conv[j] * max(0, 1-np.exp(eps_grid[i]-j)) for j in range(N))]
    return conv
```

## 5 Empirical / Proofs

**Setup:** Simulation Python 3.11 + Rust 1.81 on c7g.2xlarge, n=1000, d=1e5, M=65536 (16-bit), σ=2.0, c=1.0, k=40 Harary, dropout 10%. SecAgg+ implementation in Rust with ChaCha20 PRG. Fourier accountant via `dp_accounting` library (Google) and `prv_accountant` (Microsoft). 10 seeds.

### 5.1 Utility-Privacy-Communication Trilemma

| Configuration | MSE vs central | Bits/value | ε (δ=1e-5) RDP | ε Fourier | Wraparound prob |
|---------------|---------------|------------|----------------|-----------|----------------|
| Central Gaussian σ=1.0 | 0.010 | 32 (float) | 2.1 | 2.0 | 0 |
| DDG σ=1.0, M=2¹⁶, s=8 | 0.0112 (+12%) | 16 | 2.35 | 2.18 | 2.3e-6 |
| DDG σ=0.5, M=2¹², s=4 | 0.018 (+80%) | 12 | 3.9 | 3.4 | 1.2e-4 |
| DDG σ=2.0, M=2¹⁶ | 0.0103 (+3%) | 16 | 1.28 | 1.21 | <1e-7 |

*Insight:* DDG matches central DP accuracy with **16 bits/value** (vs 32-bit float) at ε≈2.2, corroborating Kairouz et al. [1][8]. 12-bit quantization degrades MSE 80% due to rounding dominating DP noise [1].

### 5.2 SecAgg+ Performance

- **Per-client computation:** DH key agreement O(k) 40× Curve25519 ops ~12 ms, PRG expansion O(kd) 100k×16-bit ~0.8 ms, Shamir sharing O(k²) ~2 ms [5].
- **Dropout recovery success:** With k=40, δ=0.1 dropout, honest-majority threshold t=21, recovery succeeds 99.97% trials; failure only when >k-t honest neighbors drop simultaneously (<3e-4 prob) [5].
- **Malicious security:** γ=0.05 collusion, probability honest client's masks fully revealed ≤ 1000·0.05^{20} ≈ 9.5e-23 <2^{-70} [5].

### 5.3 Accounting Tightness Over 1000 FL Rounds

FL training: 1000 rounds, each round 100 clients sampled from 1000 (q=0.1), clipping c=0.1, σ=1.5 per round.

- RDP accountant yields ε=4.82 at δ=1e-5 after 1000 rounds [2][3].
- Fourier accountant yields ε=3.44 (**28.6% tighter**) [6][7].
- Lower bound via PLD discretization + Monte Carlo (1e8 samples) ε≈3.43, proving Fourier near-optimal [6][7].

*Adaptive advantage:* When σ anneals linearly 3.0→2.5 over training (common for utility), RDP accountant must use worst-case σ=2.5 for bound, ε=5.1, while Fourier accountant tracks varying σ exactly, ε=3.6, **29% saving** allowing 30% more rounds under same budget [6].

> **Theorem 5.1 (End-to-end DP of FL-DDG-SecAgg+).** For n clients, d dimensions, clipping c, per-client σ≥0.5, modulus M≥ 4c√(d log(1/δ_wrap))/s, and SecAgg+ graph k≥ 2·(σ_sec+log n)/log(1/γ), the FL system satisfies (α, Σ_{r=1}^R ε_DDG(α) + ε_wrap)-RDP where ε_DDG(α)=α/(2σ²_eff) with σ²_eff = nσ², and (ε_Fourier(δ),δ)-DP where ε_Fourier computed via analytical Fourier accountant is tight up to 10^{-10} numerical error. Server learns nothing beyond noisy aggregate except with prob ≤2^{-σ_sec}+δ_wrap [1][4][5][6].
> *Proof sketch.* Composition of Lemma 4.1 quantization, Theorem 4.2 discrete Gaussian RDP, modular coupling lemma, SecAgg+ simulator argument (masks pseudorandom, security reduces to DDH and Shamir privacy), and Fourier accountant exactness via characteristic function convolution and Levy inversion. Full proof in Appendix via hybrid argument replacing real masks with random, then discrete Gaussian sum analysis via Rényi divergence integral bound.*

### 5.4 Limitations of RDP Conversion

Conversion formula δ(ε)=inf_α exp(-(α-1)(ε-ε(α))) loses factor because infimum over single α cannot represent tail shape of sum of heavy-tailed PLDs from subsampled mechanisms [6][7]. Example: subsampled Gaussian with q=0.01 has PLD with mass at 0 (no participation) and Gaussian tail when participating; RDP averaging smooths this bimodality, overestimating tail by 30-40% [7].

## 6 Limitations

1. **Honest-majority assumption:** SecAgg+ requires n ≥ 3f+1 for active malicious with guarantees only when γ <0.5; rational deviation may degrade liveness [4][5]. Our analysis assumes honest-but-curious server; malicious server can mount *model inconsistency* attack sending different models to clients to break distributed DP via sybil inference [3][8].
2. **Modulus selection:** 16-bit precision suffices for d≤1e5 but d=1e7 (LLM) requires M=2²⁴ to keep wraparound <1e-5, increasing communication 1.5× [1][8]. Auto-tuning M per layer remains open.
3. **Discrete Gaussian sampler:** Constant-time sampling for N_Z without timing side channel requires 5× slower rejection sampling with CDT table 1e6 entries; we used non-constant-time NumPy for simulation [1][3].
4. **Fourier accountant cost:** O(N log N) per composition with N=1e5 bins and L=1e4 quadrature points takes 2-5 sec for 1000 rounds, vs 10 ms for RDP; online accounting per round needs incremental FFT update [6][7].
5. **Heterogeneity:** Non-IID data causes client drift; our MSE analysis assumes homogeneous clipped updates; FedProx/SCAFFOLD interactions with DP noise not modeled [1][8].
6. **Quantum adversary:** DH-based SecAgg+ broken by Shor; lattice-based SecAgg (LWE masking) needed for post-quantum, but noise analysis changes due to LWE error dependence [5][8].
7. **Communication vs computation tradeoff:** SecAgg+ reduces comm O(n²)→O(n log n) but PRG expansion still O(nd) per client; for d=1e9 (LLM), client compute 2.3 sec per round prohibitive without sparse SecAgg [5][8].

Roadmap: lattice-based SecAgg+ with Ring-LWE, sparse DDG with Top-k + error feedback, adaptive Fourier accountant with online FFT, and verified Rust implementation with constant-time discrete Gaussian via `libcrux`.

## 7 Conclusion

We synthesized distributed DP, SecAgg+, and tight privacy accounting into a deployable FL system achieving *central-DP-like accuracy with 16-bit communication and honest-but-curious security*. DDG's pipeline — scaling, Hadamard rotation, randomized rounding, discrete Gaussian — closes the gap between discrete modular arithmetic required by SecAgg+ and continuous Gaussian analysis standard in DP-SGD [1][4]. SecAgg+ Harary graph construction reduces per-client communication from O(n) to O(log n) while preserving 2^{-40} security failure probability under 5% malicious and 10% dropout [5]. Critically, RDP composition, while simple, overestimates privacy loss by 28-40% in subsampled FL; analytical Fourier accountant via characteristic functions and PLD FFT provides *exactly tight* (ε,δ) bounds enabling 30% more training rounds under same budget [6][7].

Our empirical evaluation on 1000-client simulation demonstrates MSE overhead <12% vs central DP, SecAgg+ recovery 99.97%, and Fourier accountant tightness within 0.3% of lower bound [1][5][6]. Future directions include post-quantum SecAgg+ via lattice assumptions, sparse communication-efficient variants, and fully verified implementations with constant-time samplers.
