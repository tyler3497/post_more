import bisect, math, random
def build_cover(sorted_keys, eps=64):
    segs=[]; i=0; n=len(sorted_keys)
    while i<n:
        j=i+1; slope=0.0; intercept=sorted_keys[i]
        while j<n and abs((sorted_keys[j]-intercept)-slope*(j-i))<=eps:
            if j>i: slope=(sorted_keys[j]-sorted_keys[i])/(j-i)
            j+=1
        segs.append((i,j-1,slope,intercept))
        i=j
    return segs

## 6 Limitations and Future Work

1. **Honest majority / scheduler benevolence:** BFT $n\ge 3f+1$ assumed [1]; rational deviation may degrade liveness not safety [2][6].
2. **Scope formal model:** TLC $N=4$ $10^5$ states; param $N=4096$ induction not machine-checked [3].
3. **Side channels:** Constant-time timing not power/EM [3]; TDX attestation TOCTOU $40ms$ [1].
4. **Distribution shift:** CDF $\epsilon$-bound holds on trained $D$; drift Zipf $0.6\to1.2$ invalidates, requires retrain $O(n\log n)$ [2][4].
5. **Hardware variance:** H100 CC 0.9% avg 3.2% tail SPDM contention [1][7]; CXL switch 8-12us extra [2].
6. **Quantum/FP overhead:** surface code $d=27$ $729$ phys/logical plus $15\times$ magic; SPARO mitigates gaps qLDPC.
7. **Numeric:** CKKS $2^{-40}$ per mult; bit-exact needs TFHE PBS switching [3][4].
8. **zkVM recursion depth:** aggregation $>2^10$ proofs memory $>120GB$ streaming aggregator not evaluated [5][7].

Roadmap maps each to open problem: autonomous DCD migration, PAM4 FEC co-design, MSWASM GC deferred counting, ARMv8 OOTA, ML-DSA hybrid.
