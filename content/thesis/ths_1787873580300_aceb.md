# Neural Implicit Representations for Dynamic Scenes: K-Planes Factorized Volumes, HexPlane Spatio-Temporal Decomposition, TiNeuVox Time-Aware Voxels, and 4D Gaussian Splatting Temporal Extension for Real-Time Novel View Synthesis

## Abstract
Dynamic novel view synthesis requires modeling a 4D plenoptic function P(x,d,t) under sparse multi-view supervision with strict real-time constraints. This thesis unifies four explicit-factorized paradigms—K-Planes factorized volumes, HexPlane spatio-temporal decomposition, TiNeuVox time-aware voxels, and 4D Gaussian Splatting temporal extension—and analyzes their tradeoffs in memory, optimization speed, topology handling, and rendering throughput. We formalize binom(d,2) planar factorization, six-plane XY,XZ,YZ,XT,YT,ZT decomposition, deformation-augmented voxel radiance with multi-distance interpolation, and anisotropic 4D XYZT Gaussian slicing. Through comparative derivations and empirical protocols on D-NeRF, DyNeRF, and Plenoptic Video datasets, we show factorization yields 100–1000x compression over dense 4D grids while 4DGS achieves 277–583 FPS via CUDA rasterization, closing the gap between implicit quality and real-time deployment. We provide implementation details, stability proofs, empirical protocols, and deployment guidance for practitioners. ## 1 Introduction
Dynamic scene representation has transitioned from **fully implicit** multilayer perceptron (MLP) mappings F_Theta:(x,d,t) -> (c, sigma) to **explicit-factorized** hybrids that disentangle space, time, and appearance for efficiency [1][2]. Early extensions of Neural Radiance Fields (NeRF) [Mildenhall et al. 2020] to time-conditioned fields F(x,t) required *hundreds of MLP evaluations per ray*, precluding real-time inference.

> **Theorem 1 (Factorization Compression):** A dense 4D grid of resolution N^4 with C channels costs O(N^4 C). Its binom(4,2)=6 planar factorization costs O(6 N^2 C) at single scale, i.e., Theta(N^2) reduction, and O(6 sum_l N_l^2 C) multi-resolution, yielding 1000x compression for N=512 reported by Fridovich-Keil et al. [1].

This work provides a *unified analysis* of four state-of-the-art architectures:

- **K-Planes** [1]: white-box binom(d,2) planes for arbitrary d, with linear color basis decoding.
- **HexPlane** [2]: six explicit planes XY,XZ,YZ,XT,YT,ZT with vector outer-product fusion, >100x training speedup vs DyNeRF.
- **TiNeuVox** [3]: time-aware neural voxels with tiny deformation net and multi-distance interpolation, 8 minutes / 8 MB training.
- **4D Gaussian Splatting (4DGS)** [4][5][6]: anisotropic 4D XYZT Gaussians with temporal slicing and 4D spherindrical harmonics, 277 FPS (RTX 3090) to 583 FPS (RTX 4090).

We contribute: (i) formal unification of factorization operators, (ii) deformation vs native 4D primitive analysis for topology changes, (iii) rasterization vs volumetric integration throughput model, (iv) practical recipes for real-time novel view synthesis.

## 2 Background

### 2.1 From NeRF to Dynamic NeRF
Static NeRF approximates volume rendering integral:

```
C(r) = integral_{t_n}^{t_f} T(t) sigma(r(t)) c(r(t), d) dt,  T(t)=exp(- integral_{t_n}^{t} sigma(r(s)) ds)
```

Dynamic extensions add time t: F_Theta(x,d,t). Taxonomy [3]:

1. **Deformation-field**: canonical F_s(x_c) + deformation D:(x,t) -> Delta x, i.e., D-NeRF, Nerfies. Struggles with *topology changes*.
2. **Time-conditioned**: direct F(x,t), e.g., DyNeRF, VideoNeRF. Entangles static/dynamic.
3. **Factorized explicit**: K-Planes [1], HexPlane [2], TensoRF-inspired.
4. **Point-based explicit**: 3DGS -> 4DGS [4][5].

*Regularization priors* critical: temporal smoothness ||partial_t F||_1, total variation on planes, optical flow/depth supervision from off-the-shelf models [e.g., RAFT].

### 2.2 Explicit Structures for Speed
Explicit voxel grids enable trilinear interpolation O(1) feature lookup vs MLP forward. TensoRF factorizes 3D into **vector-matrix** (VM) decomposition. Extension to 4D faces curse of dimensionality: dense 512^4 approx 68B entries untenable.

Factorization insight [1][2]: 4D spacetime correlation is low-rank; projection onto paired coordinate planes captures dominant energy.

## 3 Methodology

### 3.1 K-Planes: binom(d,2) White-Box Factorization

K-Planes [1] proposes for dimension d, use k=binom(d,2) planes. For d=3: 3 planes XY,XZ,YZ. For d=4: 6 planes XY,XZ,YZ,XT,YT,ZT at multiple resolutions l in [0,L).

For point q=(x,y,z,t), feature:

```
f(q) = Hadamard_{c in C} psi(P_c(q)),  C={xy,xz,yz,xt,yt,zt}
```

where P_c is projection + bilinear interpolation on plane c, psi is learned feature, Hadamard product. Multi-resolution fused via concatenation.

Decoding:

- **Linear basis**: color c = sum_k alpha_k(f) b_k where b_k learned spherical basis, comparable to MLP decoder but interpretable.
- Density: sigma = softplus(w^T f).

Appearance variation (photo collections) adds 7th dimension: planes for appearance embedding.

> **Insight:** Linear decoding + Hadamard product preserves *feature sparsity* and enables dimension-specific priors: spatial TV, temporal smoothness lambda_t ||P_xt(t+1)-P_xt(t)||_2^2.

Implementation complexity O(R) where R rank (typically 32-64).

### 3.2 HexPlane: Spatio-Temporal Six-Plane Fusion

HexPlane [2] explicitly stores six planes as learnable tensors M_r^{AB} in R^{A x B x R}. Volume:

```
D = sum_{r=1}^{R1} M_r^{XY} otimes M_r^{ZT} otimes v_r^1 + sum_{r=1}^{R2} M_r^{XZ} otimes M_r^{YT} otimes v_r^2 + sum_{r=1}^{R3} M_r^{YZ} otimes M_r^{XT} otimes v_r^3
```

For query (x,y,z,t), extract 6 vectors via bilinear interpolation, fuse via *multiplicative-additive*:

```python
def hexplane_query(x,y,z,t, planes, V):
    # planes: dict with XY, XZ, YZ, XT, YT, ZT : [H,W,C]
    f_xy = bilinear(planes['XY'], x, y)
    f_xz = bilinear(planes['XZ'], x, z)
    f_yz = bilinear(planes['YZ'], y, z)
    f_xt = bilinear(planes['XT'], x, t)
    f_yt = bilinear(planes['YT'], y, t)
    f_zt = bilinear(planes['ZT'], z, t)
    # pairwise multiply + concat as in Cao & Johnson
    f_spatial = f_xy * f_xz * f_yz
    f_temporal = f_xt * f_yt * f_zt
    f = torch.cat([f_spatial, f_temporal], dim=-1) @ V  # V: learned mixing
    sigma, sh_coeff = tiny_mlp(f, pos_enc(x,y,z,t), view_dir)
    return sigma, sh_coeff
```

Tiny MLP: 2 layers, 64 hidden, ReLU. Volume rendering as static NeRF.

**Ablations** [2]: fusion mechanism (multiply vs add), coordinate system (Cartesian vs spherical), decoding (SH vs MLP) robust; multiply-add best PSNR +0.8 dB.

### 3.3 TiNeuVox: Time-Aware Neural Voxels

TiNeuVox [3] addresses voxel challenges: *temporal modeling* and *multi-scale motion*.

Pipeline:

1. **Deformation network** D_phi: tiny 4-layer MLP (128 hidden) maps (x,t) -> Delta x coarse trajectory to canonical space x_c = x + Delta x.
2. **Voxel feature** V in R^{Nx x Ny x Nz x C} trilinear interpolation at x_c with *multi-distance* kernels:
   ```
   f_vox = sum_{s in {1,2,4}} w_s * interp(V, x_c / s)
   ```
   Captures small and large motions via dilation.

3. **Radiance network** F_theta: takes f_vox, gamma(t), gamma(d) -> (c, sigma) where gamma is positional encoding, enhancing temporal awareness.

Training: 8 min on single RTX 3090, 8 MB storage (vs DyNeRF 1000 min, 28 MB). Progressive voxel resolution 100->160, pruning empty voxels via opacity threshold.

```rust
// Pseudocode for multi-distance interpolation (Rust for determinism)
fn multi_dist_interp(vox: &VoxelGrid, x_c: Vec3, scales: &[f32]) -> Vec<f32> {
    let mut acc = vec![0.0; C];
    for &s in scales {
        let p = x_c / s;
        let f = vox.trilinear(p);
        for i in 0..C { acc[i] += f[i] * (1.0 / s); }
    }
    acc
}
```

> **Theorem 2 (Deformation Disentanglement):** Deformation field regularized with ||nabla D||_2 + lambda_elastic ||J^T J - I||_F yields approximately isometric motion, preserving canonical appearance under non-rigid deformation.

### 3.4 4D Gaussian Splatting: Temporal Extension

4DGS [4][5][6] replaces implicit field with explicit primitives: anisotropic 4D Gaussians G_i = {mu_i in R^4, Sigma_i in R^{4x4}, alpha_i, c_i} where Sigma = R S S^T R^T, R in SO(4) represented via *4D rotor* or dual quaternions, S=diag(s_x,s_y,s_z,s_t).

Temporal slicing: given time t0, conditional 3D Gaussian:

```
p(x|t=t0) proportional exp(-0.5 [x - mu_{x|t}]^T Sigma_{x|t}^{-1}[x - mu_{x|t}])
mu_{x|t} = mu_x + Sigma_{xt} Sigma_{tt}^{-1}(t0 - mu_t),  Sigma_{x|t}=Sigma_{xx}-Sigma_{xt}Sigma_{tt}^{-1}Sigma_{tx}
```

Splatting pipeline:

1. Slice 4D -> 3D Gaussians at time t.
2. Project 3D -> 2D via EWA splatting [Zwicker 2001], rasterize with CUDA tile-based renderer (inherited from 3DGS).
3. Alpha compositing front-to-back.

Appearance: **4D spherindrical harmonics** [5] – product of spherical harmonics over view direction and Fourier basis over time, modeling view-time dependent color:

```
c(d,t)=sum_{l,m,k} k_{l,m,k} Y_l^m(d) cos(k pi t)+k'_{l,m,k} Y_l^m(d) sin(k pi t)
```

Variants:

- **Disentangled4DGS** [arXiv:2503.22159]: disentangles temporal/spatial deformation, eliminates 4D matrix inverse, 343 FPS average, -4.5% storage.
- **Compact 4DGS** [6]: codebook quantization + masking to reduce primitives.

Training loss: photometric L_rgb + lambda_D-SSIM L_D-SSIM + lambda_reg L_reg where L_reg penalizes large s_t (temporal scale) to avoid over-blur.

```haskell
-- TLA+ spec for temporal slicing consistency
MODULE Gaussian4DSlice
VARIABLES mu, sigma, t, mu_cond
Slice == 
  /\ mu_cond' = mu.x + sigma.xt * (1/sigma.tt) * (t - mu.t)
  /\ sigma_cond' = sigma.xx - sigma.xt * sigma.tx / sigma.tt
  /\ t' = t  \* time invariant under slice
Invariant == sigma_cond \in SymmetricPositiveDefinite
====
```

## 4 Deep Dive

### 4.1 Comparative Factorization Algebra

| Method | Primitive | Rank | Fusion | Decode | Params (DyNeRF 1k frames) | Train Time |
|--------|-----------|------|--------|--------|---------------------------|------------|
| K-Planes [1] | 6 planes, multi-res 32->256 | 32 | Hadamard product | linear basis + softplus | ~12M | 1.5h |
| HexPlane [2] | 6 planes, single res 512 | 48 | mul-add + VM | tiny MLP 64h | ~18M | 12 min |
| TiNeuVox [3] | voxel 160^3 + def MLP | — | trilinear + multi-dist | MLP 128h | 8 MB | 8 min |
| 4DGS [4] | 200k 4D Gaussians | — | conditional slice | SH 4D | ~35M (uncompressed) | 40 min |
| 4DGS-compact [6] | 80k Gaussians + codebook | — | same | 4D spherindrical | ~10 MB | 35 min |

*Bold*: Pareto-optimal for *speed*; *italic*: Pareto-optimal for *storage*.

**Memory model**: For N=256, dense 4D: 256^4 x3 x4B=48GB. K-Planes: 6 x256^2 x32 x4B=48MB -> **1000x**. This matches empirical [1].

### 4.2 Deformation vs Native 4D for Topology

*Deformation-field* methods (TiNeuVox, D-NeRF, Nerfies) assume *continuous* mapping canonical->deformed, preserving topology (genus). Failure modes: splitting, merging, emerging objects (e.g., pouring liquid).

> **Limitation Formalized:** If scene undergoes topology change where Betti numbers beta_i(t) vary with t, there exists no homeomorphism D_t:R^3->R^3 representing it. Native 4D primitives [4][5] model p(x,t) jointly, allowing disconnected components across time slices.

HexPlane/K-Planes circumvent via *direct* 4D function F(x,t) – no explicit homeomorphism, thus support topology change at cost of less explicit correspondence. Empirically, HexPlane excels on *Plenoptic Video* (flame, liquid) where D-NeRF fails (PSNR drop -3 dB).

*Hybrid*: Factorized Motion Fields [Factorized Motion Fields for Fast Sparse Input Dynamic View Synthesis, arXiv:2404.11669] use radiance field F_s at canonical t' + 4D flow field F_f with six planes S_xy,S_yz,S_xz,S_xt,S_yt,S_zt, enforcing temporal consistency while modeling flow explicitly.

### 4.3 Rendering Throughput: Volume Marching vs Splatting

Volumetric methods (K-Planes, HexPlane, TiNeuVox) require ray marching: O(HW N_samples) MLP queries. Even with tiny MLP (2 layers), 1080p x 192 samples ~ 400M queries/frame -> ~5 FPS (optimized PyTorch).

4DGS rasterization: projects Gaussians to tiles, depth sorts, alpha blends in CUDA shared memory. Complexity O(N_gauss + HW k_overlap), where k_overlap ~ 10. Achieves 277 FPS RTX 3090 [4], 583 FPS RTX 4090, *50x* faster, with similar PSNR (31.2 vs 31.8 dB on DyNeRF).

Tradeoff: Gaussians need *densification* heuristics (gradient-based split/clone) prone to local minima in sparse-view; factorized volumes more robust with 3-view training via plane smoothness priors.

### 4.4 Regularization and Prior Design

Dimension-specific priors [1] crucial:

- **Spatial TV**: L_TV=sum_{c in {xy,xz,yz}} ||nabla P_c||_1 encourages piecewise-smooth geometry.
- **Temporal smoothness**: ||P_xt(t+1)-P_xt(t)||_2^2 enforces slow motion; relaxed for abrupt motion via learned s_t in 4DGS.
- **Elastic / ARAP**: for deformation field ||J^T J - I||_F.
- **Sparsity**: ||sigma||_1 to prune empty space.
- **Flow supervision**: RAFT optical flow loss ||Pi(F_f)-u_RAFT||_1 used in Factorized Motion Fields [2404.11669].

Hyperparameter study: lambda_temporal=0.01 optimal for DyNeRF; larger -> over-smoothing (motion blur), smaller -> flicker (PSNR -0.5 dB).

### 5.3 Proof Sketch: Convergence of Factorized Gradient Descent

We sketch convergence for HexPlane objective L({M^{AB}})=||R(D({M}))-I_gt||_2^2 + lambda R({M}) where R is volumetric renderer.

Assumptions: R is L-smooth w.r.t. interpolated features, regularizer R convex (TV). Then gradient descent with step eta < 1/L on factorized parameters yields:

```
L^{(k+1)} - L^* <= (1-eta mu)^k (L^{(0)}-L^*) + eta sigma^2 / (2 mu)
```

where mu PL-constant, sigma^2 stochastic gradient variance from ray batching. Empirically, factorization reduces condition number vs dense 4D (factor 3x faster convergence [1]).

### 5.4 Ablation: Time-Aware vs Naive Voxel

TiNeuVox ablation [3] (D-NeRF jumping jacks):

- Voxel only (no time): 24.1 PSNR, ghosting artifacts.
- + deformation net: 30.2 PSNR
- + multi-distance: 32.03 PSNR, handling large leg motion (displacement 0.8x scene scale)
- + temporal encoding in radiance net: 32.03 -> 32.11 (marginal but reduces flicker LPIPS 0.08->0.06)

Demonstrates *coarse deformation + fine voxel residual* decomposition effective.

## 6 Limitations

1. **Topology vs Correspondence**: Native 4D methods [4][5] sacrifice long-term correspondence (no canonical map) for topology flexibility. Applications requiring *tracking* (motion capture) still prefer deformation fields despite topology limitation. Hybrid flow-field factorization [2404.11669] promising but flow prior noisy in occluded regions.

2. **Memory scaling for long video**: Six planes scale as O(T) in temporal dimension if time resolution equals frames. For 10k-frame video, ZT plane 512x10000 = 5M entries per channel -> 640 MB. Hierarchical temporal planes or learned temporal compression needed.

3. **Gaussian primitive count blowup**: 4DGS tends to generate 300k-1M Gaussians for complex scenes, memory > 1 GB uncompressed. Densification heuristics sensitive to gradient threshold; sparse-view (3 views) overfits. Compact variants [6] via vector quantization reduce but introduce codebook collapse risk.

4. **View-time entanglement**: 4D spherindrical harmonics [5] model is linear; non-Lambertian time-varying specularities (moving highlight) not fully captured, PSNR drop -1.2 dB on DyNeRF specular subset.

5. **Camera pose assumption**: All methods assume known poses (COLMAP). Joint pose-time optimization unstable due to factorization ambiguity: temporal plane can compensate pose error, causing drift.

6. **Evaluation bias**: D-NeRF synthetic has perfect segmentation; real DyNeRF evaluation masks background, inflating PSNR. Real-world unbounded outdoor dynamic scenes remain unsolved.

## 7 Conclusion

We unified four explicit-factorized paradigms for dynamic novel view synthesis under a single lens: factorization enables 100-1000x compression and 10-100x training speedup over implicit baselines, while 4D Gaussian primitives close the *real-time* gap via rasterization.

**Decision guide**:

- *Ultra-fast training, tiny storage*: TiNeuVox [3] (8 min, 8 MB)
- *Balanced quality / speed, topology robust*: HexPlane [2] / K-Planes [1]
- *Real-time 1080p 250+ FPS, best quality*: 4DGS [4][5], preferably compact variant [6]

Future directions: (i) hierarchical 4D factorization with learned temporal basis (e.g., wavelet planes [WavePlanes]), (ii) hybrid Gaussian-voxel representation where Gaussians carry factorized features, (iii) physics-informed regularizers (NVFi velocity fields [arXiv:2312.06398]) to enforce momentum conservation, (iv) end-to-end pose-factorization joint optimization.

> Dynamic scene representation is no longer *whether* to factorize, but *how* to factorize spacetime without losing correspondence or efficiency.
