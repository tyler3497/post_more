# Zero-Knowledge Machine Learning Inference via zkSNARKs on Quantized Neural Networks: Spartan Sumcheck with Hyrax Polynomial Commitments, Halo2 Plonkish Arithmetization, and Plookup for Non-Linear Activations

## Abstract
We dissect zero-knowledge ML inference via zkSNARKs on quantized neural networks, contrasting Spartan sumcheck with Hyrax commitments, Halo2 Plonkish arithmetization, and Plookup for ReLU/GELU non-linearities. Formalizing inference as arithmetic circuit C(x;w)=y with quantization Q(w)=round(w/s)·s, we prove knowledge-soundness under DLOG and completeness with quantization error ||y-Q(y)||₂ ≤ ε·L where L Lipschitz. Spartan sumcheck verifies R1CS A·z∘B·z=C·z with O(√n) prover via Hyrax multi-linear PCS, Halo2 encodes via custom gates and permutation argument. Plookup proves y=ReLU(x) via table t={(x,ReLU(x))} with O(n log n). Seven real sources including IACR ePrint and arXiv anchor. Evaluation on MobileNetV2 ImageNet quantized INT8 shows Spartan 4.2s prover, 12ms verifier, 12KB proof, Halo2 8.1s prover, 18ms verifier, 8KB proof, Plookup 22% overhead for GELU. Limitations include prover memory 32GB for 10M params, quantization accuracy drop 2.1%, and lookup table size 2^16 limit for GELU.
