# Neural Implicit Surface Reconstruction via Signed Distance Fields: NeuS, VolSDF, Neuralangelo Progressive Hash Grids, and Differentiable Marching Cubes

## Abstract
Neural implicit surface reconstruction seeks to recover high-fidelity watertight geometry from sparse multi-view RGB supervision by representing shape as the zero-level set of a learned signed distance function (SDF). This thesis synthesizes four foundational advances: NeuS unbiased SDF-to-density weighting for occlusion-aware first-order unbiased volume rendering, VolSDF Laplace-CDF density mapping with principled bound analysis, Instant-NGP multiresolution hash encoding extended by Neuralangelo via numerical gradients and progressive coarse-to-fine activation for high-frequency SDF recovery on DTU and Tanks and Temples, and differentiable isosurface extraction via DMTet and FlexiCubes Dual Marching Cubes for end-to-end mesh optimization. We derive the opacity and transmittance formulations, analyze eikonal regularization and mean-curvature priors under numerical differentiation, and formalize topology-capable gradients through tetrahedral and cubic lattices. Empirical synthesis across 15 DTU scans shows Chamfer-Voxel F1 improvements of 24-41% over vanilla NeRF meshing, while hash-grid variants scale sub-logarithmically in memory with O(T) lookup. We conclude with limitations of view-dependent appearance entanglement and future directions in 3D Gaussian hybrids.

## 1. Introduction

Reconstructing **explicit surfaces** from *implicit neural fields* has emerged as the dominant paradigm for multiview 3D reconstruction, superseding classical Poisson and TSDF fusion pipelines that required dense depth. While **Neural Radiance Fields (NeRF)** [1] demonstrated photorealistic novel view synthesis via volumetric density sigma(x) and radiance c(x,d), extracting surfaces via thresholding sigma yields biased, bumpy manifolds lacking topological guarantees [2].

The signed distance function **SDF** f: R^3 -> R, defined as f(x)=(-1)^{1_Omega(x)} min_{y in dOmega} ||x-y||, offers a principled alternative: its zero-level set S={x|f(x)=0} is watertight, its gradient nabla f gives the outward normal n, and |nabla f|=1 almost everywhere (Eikonal). Learning f_theta under volume rendering unifies *robust optimization* of NeRF with *geometric precision* of implicit surfaces [3][4].

> **Theorem 1 (Unbiased Surface Localization):** A volume rendering weight w(t) is unbiased if its maximum along a ray coincides with the first zero-crossing of f(t) under first-order approximation of f. NeuS satisfies this; naive sigma=phi_s(f) does not [3].

This thesis examines four pillars:

- **NeuS** unbiased logistic rendering and Phi_s-derived opacity [3].
- **VolSDF** Laplace CDF conversion and error-bound analysis [4].
- **Neuralangelo** extension to **Instant-NGP** multiresolution hash grids H_l with *numerical gradients* nabla_epsilon and *progressive resolution activation* [5][6].
- **Differentiable marching** — DMTet tetrahedral deformation [7] and FlexiCubes Dual Marching Cubes [8] for end-to-end mesh supervision.

Contributions are taxonomic, analytic, and synthetic across forward rendering.

## 2. Background

### 2.1 Volume Rendering Preliminaries

Classical emission-absorption model along ray p(t)=o+tv, t in [t_n,t_f]:

C(o,v)= integral_{t_n}^{t_f} T(t) sigma(p(t)) c(p(t),v) dt,  T(t)=exp(- integral_{t_n}^{t} sigma(u) du)

Discretized with quadrature:

hat C = sum_{i=1}^N T_i alpha_i c_i,  alpha_i = 1-exp(-sigma_i delta_i),  T_i=prod_{j<i}(1-alpha_j)

NeRF parameterizes sigma directly — no surface prior.

### 2.2 Signed Distance Functions

SDF satisfies:

1. f(x)=0 iff x in S
2. ||nabla f||=1 (Eikonal equation)
3. Second-order: mean curvature H = Delta f /2 near surface

Regularizers:

- **Eikonal**: L_eik = E_x (||nabla f||-1)^2 [3][4][9]
- **Curvature**: L_curv = E_x |nabla^2 f(x)| computed via discrete Laplacian when analytical Hessian of hash interpolation is zero [5].

### 2.3 Multiresolution Hash Encoding

Instant-NGP [6] defines L=16 levels, resolution N_l = floor(N_min b^l), b=exp((ln N_max-ln N_min)/(L-1)), each level hash table T_l in R^{2^{19} x F}, F=2. Feature for x: trilinear interpolation of hashed corners:

h(x)= concat_{l=1}^L interp(x, T_l[ hash(floor(x N_l)) ])

Complexity O(L), memory O(L*T), lookup O(1). Crucially, hash collisions are resolved implicitly via gradient averaging — distinct from dense grids.

| Method | Representation | Density Mapping | Hash Levels | Regularizer | Mesh Extraction |
|--------|----------------|-----------------|-------------|-------------|---------------|
| NeRF | MLP sigma | exp | 0 | None | MC on sigma threshold |
| NeuS | MLP SDF | Logistic Phi_s slope / unbiased weight | 0-8 | Eikonal | MC on SDF |
| VolSDF | MLP SDF | Laplace CDF | 0 | Eikonal + bound loss | MC |
| Neuralangelo | Hash+SDF MLP | NeuS variant alpha_i | 16x 2^{22} | Num grad eikonal + curvature | MC |
| DMTet | Deformable tet SDF | Explicit surface loss | — | Def. reg. | Differentiable MT |
| FlexiCubes | SDF + flex params | QEF dual vertex | 14-16 | Flex weight decay | **Dual** MC |

## 3. Methodology

### 3.1 NeuS Unbiased Formulation

NeuS observes that naive sigma(f) yields bias: weight w(t)=T sigma peaks *before* f=0 if f decreasing. NeuS defines **S-density** phi_s(f)= s e^{-sf}/(1+e^{-sf})^2, derivative of sigmoid Phi_s(f)=1/(1+e^{-sf}).

Discretized opacity:

alpha_i = max( (Phi_s(f_i)-Phi_s(f_{i+1}))/Phi_s(f_i), 0 )   (NeuS-3)

Proof sketch unbiased: with linear f(t) near zero-cross t*, w(t) monotonic increasing before t* and decreasing after if nabla f dot v <0, maximum at t*. Learnable sharpness s annealed: 1/s -> 0 concentrates w.

```python
def neus_alpha(f_i, f_ip1, s_inv, eps=1e-6):
    import torch
    phi_s = lambda x: torch.sigmoid(x / s_inv)
    denom = phi_s(f_i).clamp_min(eps)
    numer = phi_s(f_i) - phi_s(f_ip1)
    return torch.clamp(numer / denom, min=0.0)

# progressive annealing of s_inv
s_inv_sched = torch.linspace(0.3, 0.01, steps=100000)
```

### 3.2 VolSDF Laplace Transformation

VolSDF [4] proposes alternative:

sigma(f)= { (1/(2 beta)) exp(f/beta) if f<=0, (1/beta)(1-0.5 exp(-f/beta)) if f>0 } with beta->0+

This corresponds to density of Laplace distribution on SDF. Bound tightness: Let D be distance to surface; error bound |hat C - C*| <= O(beta) for bounded radiance. Learnable alpha,beta control concentration analogous to s but derived from generative model p(D|f) ~ Laplace.

> **Observation:** VolSDF density is *asymmetric* — interior (f<0) density decays exponentially slower, encouraging inside filling, whereas NeuS is symmetric logistic.

### 3.3 Neuralangelo: Hash Grids + Numerical Gradients + Progressive LOD

Neuralangelo [5] marries Instant-NGP encoding with NeuS volumetric rendering. Two critical fixes:

**A. Numerical Gradients for Higher-Order Derivatives:**

Analytic grad of hash feature partial h / partial x is piecewise constant (zero second derivative) due to trilinear interpolation. Eikonal requires nabla f, curvature requires nabla^2 f. Analytical yields spiky artifacts. Instead:

nabla_epsilon f(x) approx [ (f(x+eps e_x)-f(x-eps e_x))/(2 eps), ... ]

Similarly Laplacian nabla^2 f approx sum_d (f(x+eps e_d)+f(x-eps e_d)-2f(x))/eps^2. epsilon scheduled from coarse cell size to fine. This *smooths* SDF optimization, preventing hash grid collisions from dominating normal.

```rust
fn sdf_grad_num<F>(f: F, x: Vec3, eps: f32) -> Vec3
where F: Fn(Vec3)->f32 {
    let dx = (f(x.add(Vec3::new(eps,0.0,0.0))) - f(x.sub(Vec3::new(eps,0.0,0.0)))) / (2.0*eps);
    let dy = (f(x.add(Vec3::new(0.0,eps,0.0))) - f(x.sub(Vec3::new(0.0,eps,0.0)))) / (2.0*eps);
    let dz = (f(x.add(Vec3::new(0.0,0.0,eps))) - f(x.sub(Vec3::new(0.0,0.0,eps)))) / (2.0*eps);
    Vec3::new(dx,dy,dz)
}
```

**B. Progressive Coarse-to-Fine:**

Activate hash resolutions level-by-level when epsilon equals its cell size. Starting with L_active=4 (DTU) or 8 (large scenes), enable next l every 5k iterations. Weight decay on inactive levels prevents domination. Prevents fine grids learning high-freq noise before coarse shape converged — analogous to SAPE positional encoding annealing.

TLA+ sketch of schedule fairness:

```tla
---- MODULE Progressive ----
VARIABLES active, eps
Init == active=4 /\ eps= coarseSize
Next == \/ /\ active < 16
           /\ eps <= cellSize[active]
           /\ active' = active+1
           /\ eps' = eps*0.5
        \/ /\ eps' = eps*0.95
           /\ UNCHANGED active
Spec == Init /\ [][Next]_<<active,eps>>
====
```

### 3.4 Differentiable Isosurface Extraction

Classical Marching Cubes (MC) is *not* differentiable due to hard case table. Two differentiable successors:

**DMTet [7]**: Deformable tetrahedral grid (V,T) — vertices v_i+Delta v_i predicted by MLP, SDF s_i per vertex. Marching Tetrahedra — each tet (4 vertices) has 2^4=16 cases, surface triangles interpolate zero-cross via:

v_iso = (v_a s_b - v_b s_a)/(s_b - s_a)

Losses direct on mesh: Chamfer L_cd, normal consistency, adversarial. Jointly optimizes topology via s_i sign and geometry via Delta v.

**FlexiCubes [8]**: Builds on *Dual Marching Cubes* — extract quad per cell dual vertex via Quadratic Error Function (QEF) minimization. Introduces flexible parameters per cube edge:

- alpha in [0,1] edge interpolation weight,
- beta edge splitting weight,
- gamma cube deformation scalar (21 scalar per cell).

Learned jointly with SDF field F. Gradients flow via automatic differentiation through QEF solve (linear system A^T A x = A^T b). Generates manifold meshes, optionally adaptive tetrahedra.

| Feature | DMTet | FlexiCubes |
|---------|-------|------------|
| Cells | Tetrahedra | Cubes dual |
| Vert freedom | Interpolated only | QEF + flexible weights |
| Topology change | Via s sign | Via s + flexible connectivity |
| Memory | O(V_tet) | O(V_cube x21) |
| Best for | Generative shape synthesis | Gradient-based optimization from images |

## 4. Deep Dive

### 4.1 SDF vs Density Field: Why Zero-Level Sets Matter

Density sigma>=0 lacks inside/outside semantics — iso-value selection heuristic (tau=10?) yields disconnected components. SDF imposes signed ordering, Eikonal forces metric gradient, producing closed manifolds. Empirical: NeuS DTU Chamfer 0.49 mm vs NeRF 1.15 mm [3].

*List of SDF advantages:*

- **Watertightness** via sign.
- **Normal defined everywhere:** n=nabla f / ||nabla f||.
- **Collision-free offset surfaces:** f+delta for shelling.
- **Boolean CSG:** min/max composition differentiable.

*Trade-offs:*

1. Eikonal costly — extra backward.
2. Requires foreground masking for large unbounded scenes unless combined with NeRF++ background.
3. Hash grids break second-order analytic — need numerical grads at 6x SDF eval cost.

### 4.2 NeuS Unbiased Weight Derivation

Assume single planar surface crossing at t*, f(t)= -<n,v> (t-t*) near t* linear. Define rho(t)=max(-f'(t)/f(t),0) derived from Phi_s. Then:

w(t)= rho(t) exp(- integral_0^t rho)= -dT/dt

Set derivative w'(t*)=0 yields max at zero-cross. Contrast naive sigma(f) where:

T sigma = exp(- integral sigma) sigma

Maximum *precedes* t* by Delta approx beta ln 2, inducing *bias* proportional to SDF scale. NeuS eliminates first-order bias, remaining second-order O(kappa delta^2) from curvature kappa.

> **Theorem 2 (First-Order Unbiasedness):** If f linear near intersection, NeuS weight w(t) attains strict maximum at t=t*. Proof via logistic derivative monotonicity — see [3] Lemma 1.

### 4.3 Progressive Hash Grids Coarse-to-Fine Mechanics

Neuralangelo progressive schedule:

- **Phase 0 (0-5k):** epsilon= 2x coarse voxel, L_act=4, shape coarse blob.
- **Phase 1 (5-15k):** epsilon -> level 8 cell, L_act=8, medium details emerge.
- **Phase 2 (15-50k):** Full 16 levels, epsilon decays to 0.5x finest, high-freq chiseling.
- **Regularization:** L_curv active only after 30k to preserve sharp edges early.

Haskell-like schedule controller:

```haskell
data Schedule = Schedule { eps :: Float, active :: Int }
progress :: Schedule -> [Schedule]
progress s
  | active s >= 16 = []
  | otherwise = let s' = s { eps = eps s * 0.8, active = active s + 1 }
                in s' : progress s'
```

Memory scaling: 2^{22} entries x16 x8-dim float16 = ~512 MB hash table, vs dense 2048^3 grid ~32 GB. Lookup O(1) hashed indexing uses spatial hash h(x,y,z)=((x * p1) XOR (y * p2) XOR (z * p3)) mod T, p_i large primes [6].

### 4.4 Differentiable Marching Cubes Flux and Topology Gradients

Classic MC non-differentiability sources:

1. Case table lookup — discrete.
2. Binary topology inside/outside — partial sign non-differentiable at zero.

Differentiable relaxations:

- **DMTet soft-sign**: Treat SDF s_i continuous, interpolation gradient d v_iso/d s_a = -(v_b-v_a) s_b/(s_b-s_a)^2 well-defined away from s_a approx s_b, clamped with epsilon.
- **FlexiCubes dual QEF**: Solve argmin_x sum_i (n_i^T (x-p_i))^2 where planes (p_i,n_i) from edge crossings. QEF solution differentiable via implicit differentiation: d x = (A^T A)^{-1} (...) . Extra weights alpha,beta allow vertices to slide along edges to preserve features — FlexiCubes beats DMTet on sharp edges Chamfer -18% [8].

Connection to rendering: Once mesh extracted differentiably, deferred shading via Nvdiffrast enables photometric loss:

L_rgb = || I_render(M(theta), T_phi) - I_gt ||_1 + lambda_LPIPS LPIPS

where M(theta) mesh from SDF theta, texture T_phi MLP. Gradients backprop through rasterizer to theta, enabling end-to-end inverse rendering without volume sampling — 10x faster inference.

## 5. Empirical Results / Proofs

### 5.1 Proof Sketch: VolSDF Error Bound

Let radiance field bounded |c|<=C_max, beta>0. VolSDF density corresponds to Laplace CDF Psi_beta. Then expected opacity discrepancy:

|alpha_VolSDF - 1_{t>=t*}| <= exp(-|f|/beta)

Integrating along ray, error in color |hat C - C_surface| <= 2 C_max * O(beta) as beta->0 recovers surface rendering. NeuS analogous but with logistic scale s^{-1}=beta.

### 5.2 Benchmark Synthesis (Aggregated from Sources [3][4][5][7][8])

We synthesize reported numbers for DTU 15 scans (Chamfer down mm):

- NeRF+MC: 1.05-1.32 (baseline)
- NeuS [3]: **0.72** mean, 0.49 best scan 24 (low bias)
- VolSDF [4]: **0.86** mean, tradeoff sharper bound but symmetric interior filling slower
- Neuralangelo [5]: **0.40** mean, 0.28 best — 2x improvement via hash capacity, PSNR 31.2 dB vs NeuS 29.8 dB
- NeuS2 (hash-accel): 0.45 mean, 9 min training vs Neuralangelo 31 min — efficiency vs quality Pareto [10]

BlendedMVS large-scale: Neuralangelo recall @2mm 68.4% vs NeuS 51.2%.

**Ablation — Numerical Gradients**: Neuralangelo ablation w/o numerical grad -> Chamfer +23% and visible ripple due to zero Hessian of trilinear hash. With numerical grad + curvature lambda=0.05, roughness (mean curvature variance) down 41%.

**Ablation — Progressive**: All-resolutions-at-once Chamfer 0.61 vs progressive 0.40 — early fine-grid noise prevents coarse convergence, analogous to frequency bias in positional encoding.

**Topology**: DMTet tetrahedral deformation reduces self-intersection rate from MC 4.7% to 0.8% on ShapeNet animals [7]. FlexiCubes feature preservation F1 @5deg normal threshold 0.83 vs DMTet 0.71 [8].

Python empirical Chamfer approximation:

```python
import torch
def chamfer(p, q):
    dist = torch.cdist(p,q)
    return dist.min(dim=1)[0].mean() + dist.min(dim=0)[0].mean()

def eikonal_loss(grad):
    return ((grad.norm(dim=-1)-1)**2).mean()
```

### 5.3 Compute / Memory Scaling

Hash lookup dominates SDF MLP (2-layer 64-wide). For N_samp=1024 per ray, batch B=4k rays, SDF evals ~4M / iter; numerical grad 6x -> 24M evals / iter — main overhead of Neuralangelo vs analytic. FlexiCubes extra parameters 21x voxels: for 128^3 grid ~44 M scalars, but trainable per optimization, not stored per scene after convergence.

## 6. Limitations

1. **Appearance-Geometry Entanglement:** View-dependent radiance MLP c(x,d,n,feature) can bake shading as texture to compensate SDF errors — relighting fails. Inverse rendering extensions (NeuS-PIR [11]) decouple material/illumination but increase optimization fragility.

2. **Unbounded / Open Surfaces:** SDF defined globally requiring watertightness; open garments need UDF or occupancy o(x) in [0,1]. Hybrid NeRF++ background for unbounded — SDF foreground + density background segmentation leakage.

3. **Hash Grid Spectral Bias:** Multiresolution hash accelerates but introduces collision artifacts as high-freq noise — progressive schedule mitigates not eliminates. Training instability with large epsilon decay — need gradient clipping ||nabla f||<=10.

4. **Differentiable Extraction Resolution Limit:** DMTet tet grid ~100^3 effective; FlexiCubes 128^3 — fine thin structures < voxel size lost despite deformation Delta v <=0.5 cell. Subdivision hierarchy partially recovers but memory exponential.

5. **Metric-Chasing:** DTU Chamfer biased to diffuse objects with masks; real-world RGB-only video (Tanks and Temples) evaluation via LiDAR partial, occlusion handling heuristic.

6. **Numerical Gradient Cost:** 6x SDF eval for each eikonal/curvature — Neuralangelo 6-hour training on 1 GPU vs NeuS 8-12 h but with smaller MLP, still > Instant-NGP NeRF 5-min [6].

*Ordered priorities for future work:*

1. Combine 3D Gaussian Splatting planar constraints with SDF UDF hybrid for real-time mesh conversion.
2. Learn collision-free hash by spatial adaptive masks [12].
3. Self-supervised depth regularization from SfM sparse points [13].

## 7. Conclusion

Neural implicit SDF reconstruction unifies robust volumetric optimization with geometric surface priors. ***NeuS*** solved bias via Phi_s-derived unbiased weights; ***VolSDF*** offered Laplace probabilistic grounding and explicit bounds; ***Instant-NGP*** multiresolution hash memory-compute tradeoff unlocked high capacity; ***Neuralangelo*** harnessed it for SDF by numerical differentiation and coarse-to-fine activation to stabilize second-order regularizers; ***DMTet*** and ***FlexiCubes*** closed loop via differentiable isosurface allowing mesh-space losses and deferred shading. Together pipeline: h(x) -> f_theta(x) -> (f,n,H) -> alpha_i -> hat C and backprop to mesh M via MT/DMC. Challenges of entanglement, open surfaces, and compute remain. Future lies in adaptive hash encodings, hybrid Gaussian-mesh representations, and generative SDF priors for single-view inference.
