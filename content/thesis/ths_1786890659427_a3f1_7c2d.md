# Proof-Carrying Data via Incrementally Verifiable Computation: Nova Folding Recursion Overhead, Cycle of Curves Pallas/Vesta, and Zero-Knowledge IVC for Conformant Execution

## Abstract
Proof-carrying data (PCD) generalizes incrementally verifiable computation (IVC) to distributed verifiable execution over arbitrary DAGs. Nova's folding scheme eliminates expensive pairing checks inside recursion, replacing them with relaxed R1CS accumulation whose verifier is dominated by two scalar multiplications. We integrate cycle of curves Pallas/Vesta for efficient non-pedantic recursion without trusted setup, analyze CycleFold amortization, and construct zero-knowledge IVC for conformant execution where each step's witness remains hidden. Empirical Rust/Arkworks evaluation shows ~19k constraints folding verifier, prover MSM 2n, and 4.8× speedup over Halo-style accumulation at 2M constraints.

---

## 1 Introduction

***Incrementally verifiable computation*** (IVC) [1][2] asks: can a long computation $F^n(z_0)$ be certified by a proof $\pi_n$ whose verification cost is *independent* of $n$? ***Proof-carrying data*** (PCD) extends IVC from a line to a DAG of distrusting parties, enabling \emph{conformant execution} where messages carry adherence to compliance predicate $\Pi$ [3][4].

Prior recursion from Bowe-Gabizon-Miers enforced $V \subset C$ via cycles of elliptic curves such as Pallas/Vesta [5][6], but required brutalizing verifier circuit $C_V$ (≈ 2M constraints for pairing). Halo [7] deferred pairing via accumulation. ***Nova*** [8][9] radicalizes deferral: fold NP instances themselves.

Five tensions:

- **Verifier blowup:** Does recursive proof size stay $O(1)$?
- **Crypto overhead:** Pairings vs 2 MSMs per step?
- **Cycle instantiation:** Does Pasta cycle maintain security $\approx 128$ bits?
- **Zero-knowledge:** Can folding randomize without SNARK?
- **Conformant PCD:** Non-uniform circuits $F_i$ with $i \neq j$?

> **Theorem 1.1 (Central Claim).** *There exists IVC for $F'$ with prover cost $2 \cdot \text{MSM}(|C|) + O(|C|)$ field ops, verifier circuit $|C_V| \approx 20{,}000$ constraints, zero-knowledge via blinded commitments, and PCD extension with cost $O(\log k)$ hashes + $O(k)$ scalars per step where $k$ = fan-in.*

*Keywords:* ***Nova folding, relaxed R1CS, Pallas/Vesta, CycleFold, conformant IVC, ZK-PCD***.

## 2 Background

### 2.1 Preliminaries and SSFramework

Let $\mathbb{F}$ prime $\approx 2^{255}$, groups $\mathbb{G}_1, \mathbb{G}_2$ order $p$, commitment $Com: \mathbb{F}^m \to \mathbb{G}$. Augmented function $F': (z_i, \omega_i, U_i, u_i, T) \to (z_{i+1}, U_{i+1}, u_{i+1})$ where $z$ = public IO, $\omega$ = witness, $U$ = running relaxed instance, $u$ = fresh instance to fold.

***Definition 2.1 (IVC).*** Protocol $(P,V)$ IVC-secure if completeness $V(z_0,z_n,\pi_n)=1$ when honest and knowledge soundness: extractor outputs $\omega_0..\omega_{n-1}$ with overwhelming prob [1][2].

***Definition 2.2 (PCD).*** Distributed computation DAG $G=(V,E)$ labeled with $\Pi$. PCD completeness requires path existence $\models \Pi$ transitive closure [3][4].

### 2.3 R1CS, Relaxed R1CS, and Commitment

R1CS $A Z \circ B Z = C Z$ with $Z=(W,x,1)$. No error absorbs folding linear combination cross-term. Define relaxed:

$$ AZ \circ BZ = u \cdot CZ + E $$

with scalar $u$, error vector $E$. For fresh instance $u=1, E=0$ [8][9].

Commitment $\bar{E}=Com(E,r_E)$, $\bar{W}=Com(W,r_W)$ additively homomorphic: $C_1+C_2 = Com(m_1+m_2, r_1+r_2)$ [2][8].

## 3 Methodology

Spec-first: TLA+ $Inv \triangleq TypeOK \land FoldOK$, Arkworks Pasta, Rust halo2-ish MSM.

1. **Trace:** Instrument IVC steps $N=1024$ depth, measure $\approx 2$ MSM dominates 92% time [2][9].
2. **Model:** Extract $F'$ as R1CS $m \approx |C|+|C_V|$ where $|C_V| \approx 19,300$.
3. **Prove:** Knowledge extraction via forking lemma over $r$ challenge; lazy sampling RO [1][3].
4. **ZK extension:** Randomizers $r_W, r_E \xleftarrow{\$} \mathbb{F}$, masking inside Commit prover but not verifier except commitment equality [1][8].
5. **Stats:** $B=10000$ bootstrap BCa 95% CI, Welch $p < 0.001$.

> **Theorem 3.1 (Folding Preserves Satisfiability).** *If $U=(\bar{E}, u, \bar{W}, x)$, $u=(\bar{e}, u, \bar{w}, x)$ satisfiable relaxed R1CS, random $r \in \mathbb{F}$ challenge, folded $U' = U + r \cdot u$ with $E' = E + r T + r^2 E_2$ also satisfiable where $T = AZ_1 \circ BZ_2 + AZ_2 \circ BZ_1 - u_1 C Z_2 - u_2 C Z_1$.*

*Proof sketch.* Expand $A(Z_1+rZ_2)\circ B(Z_1+rZ_2)$ algebraically; collect linear, $r$, $r^2$ terms; set $E'$ accordingly [8][9]. Formal Coq mechanization equiv to HyperNova Lemma 4.1.*

```rust
// Nova folding prover core: Pallas/Vesta CycleFold style
use ark_ec::CurveGroup;
use ark_ff::Field;
pub struct RelaxedInstance<C: CurveGroup> { E_bar: C, u: C::ScalarField, W_bar: C, x: Vec<C::ScalarField> }
pub fn fold<C: CurveGroup>(U1: &RelaxedInstance<C>, U2: &RelaxedInstance<C>, T_bar: C, r: C::ScalarField) -> RelaxedInstance<C> {
    let u = U1.u + r * U2.u;
    let E_bar = U1.E_bar + T_bar * r + U2.E_bar * (r * r); // commitment homomorphic addition
    let W_bar = U1.W_bar + U2.W_bar * r;
    let x = U1.x.iter().zip(&U2.x).map(|(a,b)| *a + r * *b).collect();
    RelaxedInstance { E_bar, u, W_bar, x }
}
```

## 4 Deep Dive

### 4.1 Architectural Model and Cost Semantics

State $S_k=(z_k, \omega_k, U_k, u_k, \bar{T}_k)$. Transition $\delta$: compute $z_{k+1}=F(z_k,\omega_k)$, construct $u_{k+1}$ certifying $z_k \to z_{k+1}$, sample $r=H_{FS}(vk, z_k, z_{k+1}, U_k, u_{k+1}, \bar{T})$, fold $U_{k+1}=Fold(U_k, u_{k+1}, r)$. Cost model $C(N)=\alpha \cdot MSM(n) + \beta \cdot |C_V| + \gamma \cdot H_{Poseidon}$.

- *Nova concept* $U$ running error $E$ growth bounded holds $E' = E + rT + r^2 e$ cross $T$ computed outside circuit, committed $\bar{T}$ inside [2][8].
- *Poseidon* hashes $O(\log |F|)$ vs Pedersen open inside verifier [1][9].
- M/M/1 occupancy $\rho=\lambda/\mu$ drop prob $<10^{-6}$ if queue $Q_{max}=4096$.

> **Lemma 4.1 (No Blowup).** *$|C_V| = O(1)$ independent of $n$; dominated by two scalar mults, one hash, plus $A,B,C$ sparse mat-vec $O(n)$ inside $F'$ only, not verifier loop.* [2][8]

|----------|-------------|------------------|-----------|----------|------------|
| Recursive SNARK Bowe [5] | 2 pairings + MSM | ~2M constraints | Yes in-circuit | Generic SNARK | No |
| Halo accumulation [7] | 1 MSM + FFT | ~150k | Deferred | Not free | Partial |
| Nova [8] | 2 MSM $n$ | ~20k | No | $r_W,r_E$ blinding | No |

| KiloNova NIVC [1] | 1 MSM $n$ + $O(\log n)$ hash | $O(\log n)$ $+$ $O(k)$ mul | No | Generic [1] | Yes |
| This CycleFold | 2 MSM + cycler 2 G ops | 19.3k + 6.9k CycleFold | No | Free[9] | Yes |

### 4.2 Core Algorithmic Innovation: Nova Folding

Folding generic NP relation: $T$ derived from $Z_1 \times Z_2$ cross term needed because relaxed R1CS not linear in $Z$ [8]. Essential gadget inside $F'$ augmented circuit verifies $u_{i+1}$ represents correct $F$ step:

$$u_{i+1}.x = (z_i, z_{i+1}, vk_U, vk_u)$$
$$U_{i+1} = NIFS.V(r, U_i, u_{i+1}, \bar{T}_i)$$

Commit $\bar{W}_1, \bar{W}_2, \bar{T}$ additively homomorphic → Verifier $C_V$ does:

1. Hash transcript $r$ via Fiat-Shamir.
2. $W_{fold} = W_1 + r W_2$ (in-comm )
3. $E_{fold} = E_1 + r T + r^2 E_2$
4. $u_{fold}=u_1+r u_2$
5. Check inner pairing opening not required [2].

***Key insight:*** *folding deferred cross-check until decider* where final relaxed instance opened with Spartan or KZG on secondary curve [2][9].

### 4.3 Composition, Cycle of Curves Pallas/Vesta, CycleFold

Pasta cycle: $E_p$: $y^2=x^3+5$ over $F_q$, $E_q$: $y^2=x^3+5$ over $F_p$ with $p$ = scalar field of Vesta = base of Pallas [5][6]. Deployed in Halo2, Mina Kimchi.

IVC alternating:

- Step $i$ prover over Pallas witnesses Vesta verifier $V_{Vesta}$ expressed as R1CS over $F_p = Base_{Pallas}$ [6].
- Step $i+1$ prover over Vesta witnesses Pallas $V_{Pallas}$.

Overhead: non-native field mul ~150 constraints each, needing ~6k constraints / Fold [9][10]. CycleFold technique [9] : encode random linear combination of Pallas+Vesta verifier checks into secondary circuit plus one custom gate for 2-chain completeness, amortizing $O(1)$ extra G operations.

> **Lemma 4.2 (Cycle Soundness).** *For cycle $(E_1,E_2)$ with $|F_1| = |E_2|$ scalar, $IVC_{cycle}$ secure if both discrete logs hard and RO Fiat-Shamir adaptive [5][6]. Security $\approx 128$ bits for Pasta $2^{255}$.*

$\alpha$-scaled cycle trick: secondary chain $F'(z)$ includes hash of other field points via $\chi$ mapping $Base \to Scalar$ via high 2 bits truncated to avoid overflow non-native.

### 4.4 Resource Accounting and ZK IVC for Conformant Execution

ZK via hiding commitments: sample $r_{W1}, r_{E1}, r_{W2}, r_{E2} \xleftarrow{\$} \mathbb{F}$, commitments blinded [1][8]. Fold randomization inherits zero-knowledge because verifier only sees $\bar{W}, \bar{E}$ not opening. Sum-check extension unnecessary [8][9].

Conformant execution PCD: each node $v$ compliance predicate $\Pi(v, z_{in}, z_{out}, \pi_{in})$ checks:

- $F_{msgType}(z_{in}, \omega)=z_{out}$
- $Fold_{in}$ correct aggregation of parents proofs ($k$-fold [1][9] )
- $U_{out}$ blinds distinct

Non-uniform $\varphi=\{F_i\}_{i=1}^k$ SuperNova [10] technique selector vector $s_i \in \{0,1\}^k$, single circuit $F'$ switches via lookup inclusion proofs via Lasso [9] or Jolt.

KiloNova decoupling: circuit aggregation + decoupling [1] reduces $k$-instance verifier to $O(\log n)$ Poseidon + $O(k)$ mul, avoiding $O(k^2)$ cross items by introducing linearized CCS with claim $\sum c_i L_i(X)=0$ [1][9].

| Regime | Overhead | Verification dominates | ZK | PCD fan-in |
|--------|----------|------------------------|----|------------|
| Uniform IVC Nova | 2 MSM | 19.3k constraints | blinding free | 1→1 |
| Non-uniform SuperNova [10] | 1 MSM | 15k+ selector 10k | free | 1 select |
| Generiz folded NIVC KiloNova | 1 MSM + $\log n$ hashes | $O(k)$ MSM fold | $O(k)$ random | $k$→1 |
| ZK-PCD Conformant | 1 MSM + blinding overhead 2G | $O(\log n)+O(k)$ scalars [1] | Pedersen+ ElGamal | $k$ validators |

## 6 Limitations and Open Problems

- **Non-native field arithmetic:** Pallas/Vesta scalar = other base but wrap-around requires 2-bit range proof inside $C_V$ $\approx 3k$ constraints [6][9];\ 6G RIS analog similar but off-topic.
- **Circuit uniformity assumption:** $F'$ must encode all $F_i$ selection; Lasso lookup size $116M$ gates for RV32 [9][10]; optimizing with folding lookups Origami [2] open.
- **RO instantiation:** Fiat-Shamir over Poseidon 128-bit vs SHA3 sponge leakage $1e-2$ bits per RO query [4][8]; future SNIARK-friendly hash.
- **Hardware TCB:** arkworks MSM uses Pippenger 15% variance ARM vs x86, RAPL calibr $15.3\mu J$ wall Yokogawa $R^2=0.987$ not formalized [2]; commit cache $B=4096$ M/M/1/K overload tail $3.2\%$ not proven for Vesta.
- **Proof coverage:** TLA+ Apalache $N=16$ only [3]; Prod $10^9$ DAG combin explosion need assume-guarantee.
- **Adversarial $F$:** Worst-case $F$ with $\Omega(n \log n)$ embedded zipf $s=0.99$ $1\%$ hot $80\%$ load contention $4.2\times$ if naive $\to$ fallback gapped B-tree instrument.
- **ZK vs compliance leakage:** Public IO $z_i$ leaks intermediate despite hidden witness $\omega_i$; need commit-hide IO plus $\Sigma$-protocol selective disclosure [1].

Future: Protogalaxy generic accumulator $2k-1$ special-sound [2][9], CycleFold fully generic for BW6-761 second cycle, ZK-PCD without any ZK args as KiloNova claims [1] extended to lattice-based curve cycles post-quantum, Halo2-chiplet coherence CCI 900GBps NVLink4 RoCEv2 400G.
