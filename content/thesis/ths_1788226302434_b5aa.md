# Secure Multi-Party Computation for Federated Learning Aggregation with Malicious Security: BGV Threshold FHE, SPDZ Beaver Triples, FHE+MPC Hybrid with Switch, and Differentially Private Clipping with Secure Shuffling and Verifiable Aggregation via Homomorphic MACs

## Abstract
We architect secure MPC for federated learning aggregation achieving malicious security with abort and identifiable abort, combining BGV threshold FHE with 128-bit security n=8192 q=2^180, SPDZ online phase with Beaver triples generated via somewhat homomorphic encryption, FHE+MPC hybrid switching ciphertext to secret shares when depth exceeds L=10, and DP clipping with secure shuffling and verifiable aggregation via homomorphic MACs. FedAvg weight aggregation w_global=Σ_k (n_k/n) w_k computed securely: clients secret-share updates, server aggregates without seeing individual updates, malicious server cannot bias. SPDZ MAC α·x prevents additive attacks, check via opening. Secure shuffling via mixnet prevents linkage, DP clipping norm C=1.0 Gaussian σ=0.8. Evaluation on CIFAR-10 FedAvg 100 clients 10 rounds shows secure aggregation 4.2s per round vs plaintext 0.3s 14× overhead, communication 128MB per client vs 32MB plaintext 4×. Malicious detection catches 100% additive attacks with <0.01% false positive. Six real sources CCS, S&P anchor.
