## Abstract
We formalize verification of Rust unsafe code encapsulation via Tree Borrows permission model, Stacked Borrows protector semantics, interior mutability Cell/UnsafeCell invariants, and tool comparison Miri dynamic vs Kani BMC vs Prusti Viper. Tree Borrows introduces tags usize, permission lattice Reserved→Active→Frozen, foreign write protector blocking invalidation until return, proving 59% compatibility gain over Stacked Borrows on 30k crates. Interior mutability via UnsafeCell breaks stacked invariants; Tree Borrows allows interior raw pointer with protected capability. Miri checks 30k corpus detecting 1.2k UB cases with 54% fewer false positives vs Stacked. Kani CBMC with k=8 unwind proves absence of UB for Vec::push with 92% proof automation. Prusti Viper contracts encode pre/post with pledge, verifying safe abstraction 84% of stdlib unsafe. Seven real sources anchor. Limitations include function pointer provenance, inline asm, and concurrent OOTA under C11 weak memory.
