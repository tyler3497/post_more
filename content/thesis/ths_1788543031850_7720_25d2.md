def build_cover(sorted_keys, eps=64):
    segs=[]; i=0; n=len(sorted_keys)
    while i<n:
        j=i+1; slope=0.0; intercept=sorted_keys[i]

## 6 Limitations

1. **Honest majority / benevolent scheduler:** BFT bound n≥3f+1 assumed [1]; rational deviation may degrade liveness not safety [2][6].
2. **Scope of formal model:** TLC checked N=4 processes 1e5 states; parameterized N=4096 proof via induction not machine-checked [3].
3. **Side channels:** Constant-time mitigations timing leakage [3]; power/EM telemetry via sideband health [6] not modeled; TDX attestation TOCTOU 40ms window [1].
4. **Distribution shift:** CDF rank ε-bound holds on trained D; drift Zipf 0.6→1.2 invalidates, requires periodic retrain O(n log n) background [2][4].
5. **Hardware variance:** H100 CC TC 0.9% overhead avg but 3.2% tail under SPDM contention [1][7]; CXL switch 8-12µs extra [2].
6. **Quantum/FP overhead:** Surface code distance d=27 for 1e-12 logical 729 phys/logical plus 15x magic factories; SPARO [5][7] mitigates gaps with qLDPC.
7. **Numeric:** CKKS 2^-40 precision per mult; bit-exact equality needs TFHE programmable bootstrap switching [3][4].
8. **zkVM recursion depth:** aggregation >2^10 proofs memory >120GB requires streaming aggregator not yet evaluated [5][7].
