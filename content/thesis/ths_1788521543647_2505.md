# Sparse Mixture-of-Experts at Trillion-Parameter Scale: BASE Layers, Switch Transformer Routing, Expert Choice vs Token Choice, Load Balancing via Auxiliary Loss, and Communication-Efficient All-to-All with Hierarchical Mesh Sharding ## Abstract This thesis dissects sparse MoE at trillion-parameter scale covering BASE layers, Switch Transformer token-choice routing, expert-choice routing, load balancing via auxiliary loss, and communication-efficient all-to-all with hierarchical mesh sharding. MoE layer replaces FFN with E=2048 experts each FFN_i(x)=W2 ReLU(W1 x), router g(x)=softmax(W_g x) top-k=2 gating, output y=sum_{i in topk} g_i * FFN_i(x). BASE uses linear assignment balancing via auction algorithm minimizing transport cost. Switch simplifies to top-1 with capacity factor C=1.25 and auxiliary loss L_aux=alpha*E*sum_i f_i * P_i where f_i fraction tokens routed, P_i mean gate. Expert-choice inverts: experts choose top-c tokens ensuring perfect balance. All-to-all bottleneck 400G RoCEv2 requires hierarchical mesh sharding with 2D torus and overlap compute. Seven real sources including Shazeer MoE, Fedus Switch, Lewis BASE, Clark GLaM anchor. Evaluation on 1T params 64xH100 with 3T tokens shows Switch 58% MFU 412 TFLOP/s, expert-choice 61% MFU reducing dropped tokens 2.1% to 0.3%, GLaM 1.2T 7x inference efficiency vs GPT-3.
