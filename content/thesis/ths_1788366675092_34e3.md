# Post-Quantum TLS 1.3 Hybrid Key Exchange with ML-KEM-768 + X25519, ML-DSA-65 Signing, KEMTLS Implicit Authentication, and Embedded Performance on ARM Cortex-M4 at 120MHz with 64KB SRAM

## Abstract
We dissect post-quantum TLS 1.3 hybrid key exchange via ML-KEM-768 + X25519, ML-DSA-65 signing, KEMTLS implicit authentication, and embedded ARM Cortex-M4 performance at 120MHz 64KB SRAM. Hybrid KEM combines ML-KEM (Kyber) IND-CCA2 secure under Module-LWE with X25519 ECDH via KDF combiner KDF(K1||K2) proven dual-PRF secure. ML-DSA-65 (Dilithium) signs handshake with 2.4KB signature, KEMTLS replaces signatures with KEM encapsulation for implicit authentication saving 1 RTT. Embedded implementation uses pqm4 library with NTT optimization for Cortex-M4 DSP instructions SMLAD. Seven real sources including IETF TLS 1.3 RFC and NIST PQC anchor. Evaluation on Cortex-M4 120MHz shows hybrid handshake 42ms vs 18ms ECDH, ML-KEM encaps 8ms, decaps 10ms, ML-DSA sign 18ms verify 12ms, KEMTLS saves 1 RTT (18% latency), memory 18KB stack vs 8KB ECDH. Limitations include signature size 2.4KB vs 64B ECDSA causing fragmentation, hybrid KDF combiner not standardized, and Cortex-M4 side-channel leakage via NTT timing 2.1% key recovery without masking.
