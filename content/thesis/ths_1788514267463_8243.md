# Photonic-Electronic Co-Design for Quantum LDPC Decoding: Belief Propagation on Mach-Zehnder Interferometer Mesh with Thermal Crosstalk Compensation via Dithering, Phase-Change Material Weight Storage, and Integration with Surface Code Lattice Surgery for Magic State Injection at 10μs Cycle Time

## Abstract
We present photonic-electronic co-design for quantum LDPC decoding, mapping belief propagation with ordered statistics decoding (BP+OSD) to Mach-Zehnder interferometer MZI mesh with 128×128 programmable phase shifters, thermal crosstalk compensation via dithering feedback loop reducing phase error 12°→0.8°, and phase-change material Ge2Sb2Te5 weight storage with 4-bit non-volatile 10^6 cycles endurance. Quantum LDPC bivariate bicycle code [[144,12,12]] achieves threshold 0.7% via single-shot decoding, 2.4× overhead reduction vs surface code distance 15 with p_L 2e-12 for Shor 2048-bit factoring requiring 20M physical qubits at 10μs cycle on superconducting qubits. Integration with lattice surgery merge-split for Clifford gates and magic state injection via 15-to-1 distillation factory yields 8k constraints/sec prover. Evaluation on photonic simulator with 10^7 Monte Carlo shots via Stim+PyMatching MWPM shows logical error p_L≈0.1*(100p)^{(d+1)/2} scaling, p=1e-3→p_L=2e-9 at d=11. Seven authoritative sources Nature Photonics and PhysRevLett anchor. Limitations include MRR thermal drift 85°C, cosmic ray bursts, and photonic DAC 8-bit quantization.
