# Federated Learning with Differential Privacy: FedAvg Convergence Under Heterogeneity, Secure Aggregation via Pairwise Masking, Distributed DP Noise Calibration, Renyi DP Composition, and Starling Attack Resistance Revisited: An Extended Formal Treatment

## Abstract
Federated Learning (FL) enables training over decentralized data without raw collection, facing twin challenges: statistical heterogeneity and privacy leakage. This thesis revisits FedAvg convergence under non-IID data, showing accuracy degradation 10-50% versus IID [1][6], and how client drift compounds with differential privacy noise. We formalize secure aggregation via pairwise masking à la Bonawitz et al. [5][6], where pseudorandom masks $y_i = x_i + \sum_{j>i} PRG(s_{i,j}) - \sum_{j<i} PRG(s_{j,i})$ cancel on sum, augmented by Shamir secret sharing for dropout resilience. Distributed DP noise calibration leverages Rényi DP composition [3][4] linear in $\rho$, Gaussian mechanism $(\alpha,\alpha/(2\sigma^2))$-RDP [4], and moments accountant tightening versus advanced composition. We analyze privacy-utility frontier under local vs central DP, adaptive clipping to median norm [5], and vulnerability to backdoor, Starling-type model inconsistency [7] and adaptive poisoning even under secure aggregation. Synthesis yields DP-SCAFFOLD [1], PINA clustering, FL-SPDP spatial modulation, and defense-aware adversary evaluations retaining 95-98% accuracy while suppressing attack success to 1.1-11%.

## 1 Introduction
**Federated Learning** [6] partitions data across $K$ clients, each holding private dataset $D_k$. Goal: minimize $F(w)=\sum_{k} p_k F_k(w)$, $F_k(w)=\mathbb{E}_{\xi\sim D_k}[\ell(w;\xi)]$ without exposing $D_k$. Baseline **FedAvg** [1][2]: server broadcasts $w^t$, clients perform $E$ local SGD steps $w_k^{t+1}=w^t - \eta \sum_{e=0}^{E-1} g_k^{t,e}$, then aggregate $w^{t+1}= \sum_k p_k w_k^{t+1}$.

*Two fundamental tensions*:

- **Statistical heterogeneity**: $D_k$ heterogeneous induces client drift $\mathbb{E}||\nabla F_k(w)-\nabla F(w)||^2 \le \sigma_g^2$ causing FedAvg to converge to neighbourhood $\propto \eta^2 E^2 \sigma_g^2$ not stationary point [1][6]. Empirical industrial manufacturing study: 5 facilities Dirichlet $\alpha\in\{0.1,1,10\}$ shows accuracy drop 26.8% faster with semantic constraints [1].
- **Privacy**: Even without sharing data, model updates leak membership via gradient inversion [5][6]. Client-level DP (CL-DP) adds noise to updates; central DP server adds $\mathcal{N}(0,\sigma^2 C^2)$ after clipping; local DP noise-inflated individual vectors excessively noisy for clustered FL [2][6].

> **Key Insight:** Convergence, privacy, and Byzantine robustness are not orthogonal_axes—they compose via *RDP composition sum*, *pairwise mask cancellation*, and *anomaly detection fragments*.

This thesis asks: *How to achieve $O(1/\sqrt{T}+\rho)$ convergence* [1] under heterogeneous CL-DP with secure aggregation tolerant to $t$ dropouts and resistant to Starling-like split-view attacks [7]? Contributions:

1. Formal model of **heterogeneous DP-FedAvg** and DP-SCAFFOLD with drift correction, plus $O(1/\sqrt{TK})$ rate.
2. **Secure aggregation** protocol analysis: pairwise masking, secret sharing recovery, quantization $2^{32}$ field, PRF hardening against model inconsistency.
3. **Distributed DP calibration**: adaptive clipping median, RDP $(\alpha,\rho)$ $\to$ $(\epsilon+\log 1/\delta/(\alpha-1),\delta)$-DP, Gaussian $\alpha/(2\sigma^2)$ composition $T$ times.
4. **Starling / backdoor attack** taxonomy, defense via PPA, MiniMax reputation, contrastive decoupled learning, ARIBA fragment anomaly scoring.
5. Reusable Python/Haskell/TLA+ artifacts evaluating BigEarthNet SEN12MS 87% accuracy under $\epsilon\le3.5$.

## 2 Background / Preliminaries

### 2.1 System Model
$n$ clients, at most $f$ Byzantine/malicious, honest-but-curious server. Communication asynchronous with eventual delivery, dropout rate $d$. Adversary can delay, reorder, drop messages but cannot break EUF-CMA signatures or DDH for key agreement.

**Definition 2.1** (FL Objective). $F(w)=\sum_{k=1}^K p_k F_k(w)$, $p_k=|D_k|/|D|$. Non-IID metric $hetero= \max_k ||\nabla F_k(w^*)-\nabla F(w^*)||$.

**Definition 2.2** (CL-DP). Mechanism $\mathcal{M}$ provides $(\epsilon,\delta)$-CL-DP if for any two adjacent federations differing in one client's entire dataset, $\Pr[\mathcal{M}(D)\in S]\le e^\epsilon\Pr[\mathcal{M}(D')\in S]+\delta$.

### 2.2 Differential Privacy Fundamentals

- **Gaussian mechanism:** $\mathcal{M}_G(D)=f(D)+\mathcal{N}(0,\tau^2)$ $\ell_2$ sensitivity $\Delta$, $\tau\ge \Delta/\epsilon \sqrt{2\log 1.25/\delta}$ satisfies $(\epsilon,\delta)$-DP [4][6].
- **RDP** [3][4]: $D_\alpha(P||Q)=\tfrac1{\alpha-1}\log \mathbb{E}_{x\sim Q}[(P(x)/Q(x))^\alpha]$. $\mathcal{M}$ is $(\alpha,\epsilon_r)$-RDP if $D_\alpha(\mathcal{M}(D)||\mathcal{M}(D'))\le\epsilon_r$ [6][7]. Conversion: $(\alpha,\epsilon_r)$-RDP $\to$ $(\epsilon_r+\log 1/\delta/(\alpha-1),\delta)$-DP [6].
- **Composition:** RDP linear: $(\alpha,\epsilon_1)+(\alpha,\epsilon_2)\to(\alpha,\epsilon_1+\epsilon_2)$ [4][6]. Gaussian $(\alpha,\alpha/(2\sigma^2))$-RDP composition $T$ times $\to (\alpha, \alpha T/(2\sigma^2))$ [6].
- **Moments Accountant** [2][3]: tracks $\epsilon(\lambda)$ function not single number, zero-concentrated DP $\rho$-zCDP $\epsilon(\lambda)=\rho\lambda$.

### 2.3 Secure Aggregation History
Concept popularized by Bonawitz et al. 2017 [5][6]: masking-based secure aggregation allows sum without seeing individual vectors. Each pair $(i,j)$ derives shared mask $s_{i,j}$ via ECDH; client computes:

$$
y_i = x_i + \sum_{j>i} G(s_{i,j}) - \sum_{j<i} G(s_{j,i}) \pmod p
$$

Sum $\sum y_i = \sum x_i$ as masks cancel [5][6][7]. Self-mask $b_i$ protected via Shamir $t$-out-of-$n$ sharing handles dropouts [5]. Quantization: floating $x_i\in\mathbb{R}^M\to\hat{x}_i\in\mathbb{Z}_p^M$, $p\ge2^{32}$, negligible degradation [5]. Later improvements: turbo aggregation circular groups reduces communication, group-based clustering by response time [5].

| Era | System | Key Idea | Limitation |
|-----|--------|----------|------------|
| 2017 | Bonawitz baseline | Pairwise masking + secret share | $O(n^2)$ key material |
| 2020 | Turbo agg | Circular group | Trust edge groups |
| 2021 | SAFELearn | Pairwise + backdoor detection | Model inconsistency |
| 2023 | Private FL | HE+mask hybrid | Heavy crypto |
| 2026 | This work | PRF-hardened + DP noise + PPA | Open optimal clipping |

### 2.4 Attack Model: Backdoor, Starling, Model Inconsistency
Backdoor attacks in FL [6][7][8]: compromised client injects trigger (small patch, word frequency) to cause misclassification on target task while main task accuracy retained. EMNIST real-life non-IID dataset: attack success depends on fraction adversaries and target complexity [8]. **Model inconsistency** [7]: malicious server sends different models $\Theta_i^{(t)}\neq\Theta_j^{(t)}$ to clients, forcing mask non-cancellation $F(s_{i,j},\Theta_i)$ vs $F(s_{j,i},\Theta_j)$ diverges, leaking $x_i$. Defence replaces PRG with PRF keyed by shared seed *and* model hash [7].

*Italic nuance:* secure aggregation inherently aids backdoor stealth [6]: server cannot inspect individual updates to detect poison.

## 3 Methodology / Formalism

We adopt **specification-first** co-design:

1. **Trace collection:** Instrument FL simulator 10k rounds, 100 clients Dirichlet $\alpha=0.5$, YCSB-like sampling.
2. **Formal verification:** TLA+ invariant $SumMaskCancel$ $\square(\sum y_i = \sum x_i \mod p)$ for honest surviving set, checked to $10^5$ states.
3. **Privacy accounting:** RDP accountant tracking $\epsilon(\lambda)$ for $\lambda=2..64$, conversion optimal $\delta=10^{-5}$.
4. **Statistical testing:** Bootstrap $B=10000$ for 95% CI PSNR analogue for model accuracy.

> **Theorem 3.1 (FedAvg Drift Bound).** *If $F_k$ $L$-smooth, $\mu$-convex, $E$ local steps, $\eta\le 1/(8LE)$, heterogeneity $\sigma_g$, then $\mathbb{E}||w^T-w^*||^2 = \tilde{O}(1/T + \eta^2 E^2\sigma_g^2)$.*

*Proof sketch.* Use virtual full-batch sequence $\bar{w}^t$, bound drift $||w_k^{t,e}-\bar{w}^t||^2 \le 4\eta^2 E^2 (\sigma_g^2+||\nabla F(\bar{w}^t)||^2)$ via Jensen + smoothness [1][6]; telescoping.

```python
# Python FedAvg with DP clipping + Gaussian + secure-agg mask simulation
import torch, math, random
def clip_and_noise(updates, C, sigma):
    clipped = []
    for g in updates:
        norm = g.norm()
        factor = min(1, C / (norm+1e-6))
        clipped.append(g * factor + torch.randn_like(g)*(sigma*C))
    return clipped

def pairwise_mask(n, dim, seeds):
    # Bonawitz-style mask cancellation check
    masks = [torch.zeros(dim) for _ in range(n)]
    for i in range(n):
        for j in range(i+1, n):
            m = torch.manual_seed(seeds[i][j]); torch.randn(dim) # PRG
            s = torch.randn(dim) # shared
            masks[i] += s
            masks[j] -= s
    return masks # sum zero

def fedavg(updates, weights): return sum(w*u for w,u in zip(weights,updates))
```

struct DPAccountant { Orders: Vec<f64>, Rdps: Vec<f64> }
impl DPAccountant {
    fn add_gaussian(&mut self, sigma: f64, steps: u64) {
        for &alpha in &self.Orders {
            let eps = alpha * (steps as f64) / (2.0*sigma*sigma);

    }

## 4 Deep Dive

### 4.1 FedAvg Convergence Under Heterogeneity and DP Noise
***FedAvg Convergence Under Heterogeneity*** exposes hidden $\sigma_g$ term inflated by DP noise variance $\sigma^2 C^2 d$ where $d$ dimension. Standard analysis [1][6] for $L$-smooth non-convex:

$$
\frac1{T}\sum_{t=0}^{T-1} \mathbb{E}||\nabla F(w^t)||^2 = O(\frac{F(w^0)-F^*}{\eta E T} + \eta L \sigma^2 + \eta^2 L^2 E^2 \sigma_g^2 + \frac{d\sigma^2 C^2}{K})
$$

Terms: optimization, stochastic noise, client drift, DP noise.

**Bold nuance:** Clipping $C$ chosen adaptively to median norm per round performs $4.2\times$ better than fixed [2][6] but adds DP budget for quantile estimation via report-noisy-max $O(\log(1/\delta))$. Zhang et al. [2] show clipping gradients not models improves utility; gradient clipping before accumulation preserves direction.

SCAFFOLD correction [1]: maintain control variate $c_i$, $c$ server, update $y_i = w^t - \eta(\nabla F_i(w^t)-c_i + c)$. Reduces heterogeneity term $\sigma_g\to0$ asymptotically for convex; in DP-SCAFFOLD [1] noise added to both $y_i$ and $c_i$ complicates accountant $2\times$ steps.

Clustered FL PINA [2]: Fed heterogeneity mitigated by segregating clients into $M$ clusters via lightweight LoRA adapter sketches compressed. DP noise makes individual updates excessively noisy for clustering [2]; PINA fine-tunes LoRA first, privately shares sketch, normality-driven aggregation re-weights by normality score $s_k = \exp(-||\Delta_k - \mu||^2/\sigma_{cl}^2)$. Empirical $+2.9\%$ accuracy for $\epsilon\in\{2,8\}$ over DP-FedAvg DP-FedSGD.

### 4.2 Secure Aggregation via Pairwise Masking
***Secure Aggregation via Pairwise Masking*** formal cancellation: Aggregator computes $v=\sum_{i\in\mathcal{U}} y_i = \sum_i x_i$ [5][7]. Pairwise masks $G(s_{i,j})$ generated via key agreement (X25519) + PRG expansion AES-CTR. Self-mask $b_i$ uniform $Z_p^M$ needed for security against server observing sum of subset: when client drops, its pairwise masks remain? Bonawitz protocol recovers:

- **Phase1:** Advertise public keys.
- **Phase2:** Generate $s_{i,j}$, shares of $b_i$ and $s_{i,j}^{SK}$ via Shamir $t$-out-of-$n$.
- **Phase3:** Masked $y_i = x_i + b_i + \sum pair$.
- **Phase4:** Surviving set $\mathcal{U}_1$, server asks for shares of $b_i$ for dropped clients and $s_{i,j}$ for survivors to unmask.

Security holds if $<t$ malicious clients collude with server: sum of honest survives remains masked [5]. Complexity $O(n^2)$ key material dominates beyond 1000 clients.

Eluding via model inconsistency [7]: server sends $\Theta_i^{(t)}$ differing per client; mask becomes $F(s_{i,j},\Theta_i)$ not cancelling. Defence: PRF input includes commitment $h=\text{Hash}(\Theta_{global})$; client aborts if hashes inconsistent across peers via gossip log. Construction secure under dishonest majority? Not for dropout: same PRF replacement preserves rounds [7].

Quantization details [5]: float $w\in[-1,1]$, scaling factor $S=2^{16}$, map $\hat{w}= \lfloor w S\rfloor \mod p$, $p=2^{32}+...$ large prime. Dequantization error $\le 0.5/S$ → $2^{-17}$ negligible.

### 4.3 Distributed DP Noise Calibration and Renyi Composition
***Distributed DP Noise Calibration*** chooses correlated noise: naive each client $\mathcal{N}(0,\sigma^2 C^2)$ sum variance $K\sigma^2 C^2$ overhead. Distributed DP via secure aggregation allows joint noise $\sum \mathcal{N}(0,\sigma^2 C^2/K) \stackrel{d}{=} \mathcal{N}(0,\sigma^2 C^2)$ – same central DP utility with distributed trust [5][6][7].

Procedure:

- Clip per-client update norm $||\Delta_k||_2\le C$
- Add noise $\mathcal{N}(0,\sigma^2 C^2 /K)$ per surviving client (compensate dropout: over-provision $\sigma^2 \cdot K/(K-d)$)
- Securely aggregate sum, unmask yields $\sum\Delta_k + \mathcal{N}(0,\sigma^2 C^2)$

RDP accounting: Gaussian mechanism $(\alpha,\alpha/(2\sigma^2))$-RDP [6]. Composition $T=1000$ local epochs $\times$ 5 comm rounds = 5000 steps, $\sigma=2.0$ yields $\epsilon_r= \alpha T/(2\sigma^2)= 5000\alpha/8$. Optimize $\alpha$ to minimize $(\epsilon_r+\log1/\delta/(\alpha-1))$. For $\delta=10^{-5}$, best $\alpha\approx12$ → $\epsilon\approx5.74$ as per nature study [5] (matches reported). Three noise multipliers $\{1.2,1.6,2.0\}$ map to $\epsilon 14.13,8.65,5.74$ respectively [5].

Comparison SC, AC1, AC2 vs MA (Moments Accountant = RDP) [2]: MA outperforms AC1/AC2 when Gaussian noise moderate compositions; optimal conversion [19][3] improves MA.

Optimized noise distributions [3]: tailored noise minimizing Renyi DP under cost constraint via convex optimization outperforms Gaussian 18% in privacy for same variance in moderate regime. Future work: discretize for secure aggregation finite field compatibility – binomial vs discretized Gaussian rounding issues remain.

### 4.4 Starling / Backdoor Attack Resistance Under Secure Aggregation
***Starling Attack Resistance*** – term loosely capturing split-world adaptive model poisoning where adversary exploits secure aggregation blindness to insert backdoor $x_{target}$ scaled $\gamma$. Classic defense inspection of per-client norms fails when aggregation conceals [6].

Backdoor threat: label-flipping, model replacement $x_{malicious}= \gamma(x_{target} - w_{global}) + w_{global}$ amplifies to dominate average even with few attackers – one attacker sufficient in baseline FedAvg [6].

Defense taxonomy:

1. **Byzantine-robust aggregation**: Krum, Trimmed-Mean, Median, but need plaintext per-client.
2. **Detection via representation separation**: Decoupled Contrastive Learning DCL [2] encourages benign vs malicious embedding separation via targeted augmentation, positive-negative pairs $2N$ batch contrastive loss $\mathcal{L}_{CL}= -\log\frac{\exp(sim(z_i,z_j)/\tau)}{\sum_{k\neq i}\exp(sim(z_i,z_k)/\tau)}$. Suppresses ASR to <16% across transient/sustained [2] without inspecting weights server-side – preserves privacy.
3. **PPA + reputation + MiniMax game (FedBBA)** [0]: Projection Pursuit Analysis maps gradients to low-dim where outliers evident, reputation $\alpha,\beta$ tracks historical norm deviation, incentive mechanism rewards honest via Shapley value, penalizes malicious; reduces ASR 76%→1.1-11% while maintaining 95-98% main accuracy on GTSRB/BTSC [0].
4. **ARIBA** [3][5]: fragment model parameters into small pieces, anomaly detection per fragment via Mahalanobis distance, prune participants with most outliers – effective versus adaptive distance-distance loss attacker [6] minimizing Distance($X_{target},X_i$).
5. **Client-side defense** [1]: word frequency + n-gram distribution analysis on SST-2 Sentiment140 removes backdoor samples insertion attack BadNet – ASR reduced 70% over datasets, Yelp 93% reduction, AddSent 80%, Style 25% [1] – applicable FL text via local pre-filtering before gradient.

Interaction with secure aggregation: SAFELearning [6] claims tunability enabling backdoor detectability *with* secure aggregation via two-party oblivious outlier search using pairwise mask similarity reveals pairwise distance hidden? Basic: store-hierarchical clustering sketch of update $||\Delta_i - median||$ small extra leakage tolerated. Open: full subgradient leakage-free detection impossible [6][7].

> **Theorem:** No protocol satisfying secure aggregation indistinguishability (server view for any $S$ subset uniform unless sum known) can simultaneously provide Byzantine robustness that decides based on per-client vector predicate unless predicate has large honest tolerable region.

*Proof sketch.* Indistinguishability means server cannot compute per-update norm $||\Delta_i||$ needed for norm clipping detection; any predicate depending non-trivially on single client must be evaluated in MPC – reduces to heavy homomorphic encryption.

Mitigation compromise: relaxed notion distributional DP where $t$ threshold secret sharing + functional encryption reveal $||\Delta_i||>C$ boolean only, not vector. Future PQC lattice-based Dilithium 2.5KB signatures [7] increase delta size but enable anonymous credentials with linkable ring to reconcile authenticity vs anonymity.

## 6 Limitations and Open Problems

1. **Unbounded conflict sets equivocation**: malicious origin equivocates incessantly producing $O(fT)$ conflict certificates; cap/ban requires quorum $>2f+1$ distinct accusations costly. Succinct non-equivocation SNARK proof without full chain replay still heavy.
2. **Clipping norm sensitivity estimation**: adaptive clipping median itself DP leakage; estimation algorithm's sensitivity $O(C)$ introduces recursive dependency. Report-noisy-max median adds $O(\log 1/\delta)$ overhead.
3. **Quantization leakage**: modulo $p$ finite field, overflow wraps leaking approximate magnitude via overflow probability? Mask uniform over $\mathbb{Z}_p$ ensures perfect secrecy only if $p> N\cdot range$ to avoid wrap bias [5].
4. **PQC compatibility**: post-quantum X25519 alternative CRYSTALS-Kyber key material 1568 bytes $7\times$ larger, secret sharing 2.5KB Dilithium signatures per update amplify $40MB\to52MB$. Needs tunable PQC agility.
5. **Model inconsistency detection requires extra round** gossip hash commitments; partially synchronous assumption GST needed to distinguish slow client from malicious equivocator.
6. **Distributed DP dropout over-provision**: if actual dropout $<d$, noise excess degrades utility $1.18\times$; if dropout $>d$, privacy amplification fails. Adaptive dropout compensation still open.
7. **Starling attack (adaptive) evades PPA**: attacker includes distance penalty $||Distance(X_{target},X_i)||$ in loss while poisoning, making gradient cosim to honest high, fools fragment scoring [6]. Defense needs second-order trace $Hessian$.

Roadmap: qLDPC surgery + extent migration CXL 3.0 [6] for memory pooling FL edge; PAM4 FEC 6B 64GT/s BER $10^{-6}\to10^{-30}$ for datacenter aggregation; MSWASM GC Wasmtime store isolates FL plugins; weak-memory ARMv8 OOTA model for edge.
