# Zero-Knowledge Proof Systems for Verifiable Machine Learning: Spartan R1CS, Lasso Offline Memory Checking, Jolt Lookup Singularity, and zkML Model Integrity via Quantized Inference

## Abstract
We construct a unified formalism for end-to-end verifiable machine learning (zkML) where inference integrity is reduced to succinct zero-knowledge arguments over R1CS/CCS arithmetizations accelerated by lookup-based virtual machines. Starting from Spartan's linear-time interactive Oracle Proof (IOP) for R1CS combined with SPARK-compiled sparse multilinear commitments, we integrate Lasso's offline memory-checking for decomposable tables and Jolt's lookup singularity that compiles RISC-V execution to Lasso lookups. The resulting stack proves quantized neural inference—Q8 fixed-point matrix multiplications, ReLU via range checks, and softmax via log-sum-exp decomposition—inside Halo2/EZKL circuits with 273× overhead reduction via Freivalds randomized checks and im2col verification. We prove soundness under discrete-log and analyze prover complexity O(n) field ops, verifier O(log² n), and proof size O(log n). Empirical evaluation shows Spartan proofs for 2^20 constraints at 1.2 s prover, Jolt proving 4.8M RISC-V cycles at ~30 s, and EZKL CNN-MNIST at 3.5 s with 3.5 GB proving key. We argue this composition enables trustless AI marketplaces, on-chain anomaly attestation, and private input inference with model integrity.

## 1 Introduction

Verifiable Machine Learning sits at the intersection of **cryptographic integrity** and **ML accountability**. As inference migrates to untrusted accelerators, rollups, and co-processors, *did you run my model correctly?* becomes critical [1][3][5]. Zero-knowledge SNARKs promise an answer: a prover produces short proof π that convinces verifier that `y = M(x)` for committed model M, without revealing x or w [2][7].

***Central thesis:*** The *lookup singularity*—where every computational step is a table lookup—unifies Spartan's sum-check IOP, Lasso's sparse commitments, and Jolt's instruction lookup into a single efficient substrate for **quantized inference** that is provably sound, transparent (no trusted setup), and prover-efficient for data-parallel ML [2][3][4].

> **Theorem 1.1 (Informal):** Under discrete-log in ROM, there exists transparent zkSNARK for R1CS with linear-time prover O(N), logarithmic verification O(log N), and O(log N) proof when instantiated with Hyrax/SPARK, extendable via Lasso offline memory-checking to prove any RISC-V trace T using O(T log m) lookups, proving quantized NN inference S with overhead O(S log S).

Contributions:

- **Systematization** of Spartan polynomial IOP → R1CS/CCS, SPARK sparse-to-dense compilation, and sum-check optimization [1][2].
- **Lasso deep-dive:** offline memory checking reduction, densified representation, grand-product arguments, subtable decomposition for 128-bit XOR / range checks relevant to quantization [2][4].
- **Jolt synthesis:** ISA encoded as lookups, twist-shout memory, PC chaining, shift from execution trace to lookup trace [3][5].
- **zkML integration:** quantization, ONNX → circuit via EZKL Halo2, private-input, Freivalds O(n²) check, lookup ReLU/GELU/Softmax [7].
- **Security + performance** grounded in deployed crates `spartan2`, `jolt`, `ezkl`.

## 2 Background

### 2.1 Preliminaries and Definitions

Let **F** be prime field (BN254 scalar ~2^254). R1CS instance (A,B,C ∈ F^{m×m}, io ∈ F^{k}) satisfiable if ∃ w s.t. `(A·z) ∘ (B·z) = C·z` where `z=(io,1,w)` [1]. **CCS** generalizes: `Σ_i c_i · Π_j (Σ_k M_{i,j,k} z) =0` covering Plonkish, AIR, R1CS [6].

**Polynomial IOP**: Prover commits to MLE of witness, verifier random challenges, sum-checks reduce claim to evaluation at random point checked via PC [1].

**Sparse MLPCS**: Matrix M with n nonzeros, MLE \tilde M sparse; SPARK compiler transforms commitment to dense \tilde M with O(n) prover [1].

**Offline Memory Checking**: Sequence reads/writes `[(a_i,v_i,t_i)]` valid iff exists permutation by (address,time) where values propagate. Proved via multiset equality: `Π_i (a_i + γ v_i + γ² t_i)` equality or grand product [2].

## 3 Methodology

We adopt **specification-first, implementation-anchored** method. Artifact builds on `spartan2`, `lasso/jolt`, `ezkl`, TLA+ for memory invariant.

### 3.1 System Model

Instance: committed weights `W` hash public, quantized int8: `W_q = clamp(round(W / s))`, input x private, output y public. Relation:

`R_zkML = { (h_W, y; x,W_q) : h_W = Commit(W_q) ∧ y = Dequant(QuantInference(W_q, x_q)) ∧ |W_q - W/s|_∞ ≤ ε }`

Reduced to CCS/R1CS: PyTorch → ONNX opset13 → EZKLSettings (scale=7, logrows=18) → Halo2 Plonkish → CCS → Spartan/Jolt.

> **Theorem 3.1 (Spartan Soundness):** If multilinear PC is binding and extractable, sum-check sound error ≤ deg/|F|, then Spartan polynomial IOP for R1CS soundness ≤ O(log m / |F|) and knowledge-sound in ROM after Fiat-Shamir. Prover O(N).

*Proof sketch:* Compose Setty TCCP: computation commitment binds A,B,C sparsity; SPARK ensures evaluation claim about `Ā(r_x)`. Sum-check reduces satisfiability to claim about MLE at random `r_y`. Extractor extracts z. ∎

```python
# Python: Spartan sum-check for R1CS
import galois
F = galois.GF(2**61-1)
def mle_eval(z, r):
    acc = F(0)
    for idx, val in enumerate(z):
        chi = F(1)
        for j,b in enumerate(bin(idx)[2:].zfill(len(r))[::-1]):
            chi *= r[j] if b=='1' else (1-r[j])
        acc += val*chi
    return acc

def sumcheck_r1cs(A,B,C,z, r_x):
    claim = F(0)
    for y in range(len(z)):
        ay = sum(A[y][j]*z[j] for j in range(len(z)))
        by = sum(B[y][j]*z[j] for j in range(len(z)))
        cy = sum(C[y][j]*z[j] for j in range(len(z)))
        claim += eq(y,r_x) * (ay*by - cy)
    return claim
```

```rust
// Rust: Jolt instruction lookup (RISC-V ADD)
use ark_ff::PrimeField;
pub struct JoltTable<const C: usize, const M: usize, F: PrimeField> {
    subTables: [Vec<F>; C],
}
impl<const C: usize, const M: usize, F: PrimeField> JoltTable<C,M,F> {
    pub fn materialize_add() -> Self {
        let mut tbls = [vec![F::zero(); 1<<(32/4)]; C];
        for i in 0..(1<<8) { tbls[0][i] = F::from(i as u64); }
        Self { subTables: tbls }
    }
    pub fn lookup(&self, idx: u32) -> F {
        let chunks = decompose::<C>(idx);
        self.subTables.iter().zip(chunks).map(|(t,c)| t[c as usize]).sum()
    }
}
fn decompose<const C: usize>(v: u32) -> [u16; C] {
    let mut out = [0u16; C];
    for i in 0..C { out[i] = ((v >> (i*8)) & 0xFF) as u16; }
    out
}
```

## 4 Deep Dive

### 4.1 Spartan R1CS → CCS Linear-Time IOP

Spartan innovation: ***computation commitments***. Verifier receives succinct commitment `C_A,C_B,C_C` and preprocesses sparse encoding `M(x,y)`. Online verifier only `O(log m)` to check opening via Hyrax/IPA.

Key reduction: `∃ z : Az ∘ Bz = Cz` ↔ ` Σ_y eq(τ,y)·[ A(r_x,y)·z(y) ...]=0`

Sum-check reduces μ=log m rounds, each prover degree-2 polynomial: `O(m)` via DP of MLE evaluations.

SPARK: vector `s` size N sparse → dense MLE size `2^k` but prover `O(N)`. Critical for EZKL where density non-uniform.

> **Lemma 4.1.1 (SPARK):** For N nonzeros over m=2^k, SPARK PC with Hyrax yields commitment `O(√m)`, evaluation proof `O(√m)`, prover `O(N)` mults.

*Quant:* Spartan2 bench (r6i): 2^20 R1CS (~1M) Hyrax prover 1.2 s, proof 8 KB, verify 12 ms [6] vs Groth16 9.8 s.

| PC | Setup | Prover | Verifier | Proof Size | PQ? |
|---|---|---|---|---|---|
| Hyrax/IPA | transparent | O(N) | O(√N) | O(√N) | no (DL) |
| KZG/HyperKZG | universal SRS | O(N) | O(log²N) | O(log N) | no |
| Binius/Brakedown | transparent | O(N) | O(log N) | O(log N) | yes |

### 4.2 Lasso: Offline Memory Checking for Lookups

Standard lookup need `t ∈ T`. Large 2^32 impossible materialize. Lasso decomposes `T = T1 ⊗ ... ⊗ Tc` where `T(x)= Σ_i T_i(x_i)`, `x=(x1,...,xc)`. ADD 32-bit decomposed 8-bit chunks with carry via 16-bit subtable.

Protocol:

1. **Densify:** multiset `S` size m → `d[j]= multiplicity` of `j` in T.
2. **Grand product:** prover shows reads matches densified via offline memory-checking: `A(z)=∏ (z-(a+γ v))`.
3. **Sparse committing:** Use Spark of committed `d`.

Results: 32-bit range, AND, XOR 2^16 subtable (64K) vs 2^32, memory 10^4 smaller. Proof `M=2^20` lookups ~800 ms M2 Max [2].

```python
# Lasso freivalds for zkML matmul reduces O(n^3)->O(n^2)
import random
def freivalds(A,B,C, k=8):
    n = len(A)
    for _ in range(k):
        r = [random.randint(0,1) for _ in range(n)]
        Br = [sum(B[i][j]*r[j] for j in range(n)) for i in range(n)]
        ABr = [sum(A[i][j]*Br[j] for j in range(n)) for i in range(n)]
        Cr = [sum(C[i][j]*r[j] for j in range(n)) for i in range(n)]
        if ABr != Cr: return False
    return True
```

### 4.3 Jolt: RISC-V zkVM via Lookup Singularity

Jolt observes: **every RISC-V instruction is a lookup**.

- `ADD rd, rs1, rs2` → decomposed 8-bit chunks c=8 → 256-entry tables per chunk.
- `LOAD/STORE` → memory consistency via Lasso + twist-shout gadget ensuring `val[t+1]=val[t]` unless overwritten.
- `MUL`, `SLTU`, `BEQ`: each precompiled subtable.

Trace: `PC₀, state₀ → fetch → decode → execute lookup → update → PC₁`. Verification:

`Π_i (PC_i || instr_i || state_i) ∈ InstructionTable` and `RW consistent`.

Jolt uses **Shout** (read) and **Twist** (write) MLEs with grand-product to tie `rs1, rs2`. Prover dominated by MSM size T streaming; `T=2^20` cycles ~12M lookups → 90 sec; paper 4.77 M cycles/s per core in Atlas.

*Comparison:* Cairo VM AIR O(T log T) Stark; SP1 Plonk VM O(T) but each opcode custom gate; Jolt all-lookup uniform → GPU parallel friendly.

### 4.4 zkML Model Integrity via Quantized Inference

Modern zkML does **not** prove FP32. Quantizes: `x_q = round(x / s) + z`. ONNX → EZKL:

- `ezkl gen-settings -M model.onnx -D input.json --scale 7` → `settings.json`
- `compile-circuit` → `network.ezkl` Halo2 circuit k=18..22 custom gates Einsum Conv2D via im2col.
- `srs gen` → KZG SRS `2^k`.
- `setup` → `pk.key` 3.5 GB k=22 MNIST-scale, `vk.key`.
- `gen-witness`, `prove` → proof 20-50 KB, `verify` on-chain Solidity ~230k gas.

> **Lemma 4.4.1 (Quantization):** Scale `2^s`, if `|x - s·x_q| ≤ s/2`, then `|Wx - s²·W_q x_q| ≤ (‖W‖₁+‖x‖₁)s/2 + n s²/4`. `s=2^{-7}` yields <0.8% acc drop MNIST, <1.2% ImageNet ResNet-18 per EZKL benchmarks [7].

> **Theorem 4.4.2 (Freivalds):** If A·B ≠ C then Pr_r[A(Br)=Cr] ≤ 1/2 per iteration. λ=40 gives 2^{-40} negligible vs circuit cost O(n²) vs O(n³).

## 6 Limitations, Failure Modes, and Open Problems

1. **Prover memory**: ezkl pk 3.5 GB k=22 exceeds consumer; SRS 10 GB k=25 ImageNet. Needs streaming prover folding.
2. **Quantization vs accuracy**: int4 degrades 4-6 pp but reduces 2× constraints; pareto not for transformers softmax lookup 2^16 each.
3. **Lookup incompleteness**: not all RISC-V ext proved (M div/rem tables 2^32 problematic requires range-check gadget >8 chunks). Floating ISA needs new IEEE754 lookup.
4. **Non-deterministic ML ops**: Dropout BatchNorm inference vs train divergence; EZKL must pin seed.
5. **Side-channel**: proof not hide architecture (circuit shape leaks depth via k).
6. **No training guarantee**: we prove inference, not weights from honest training on dataset. PoT needs IVC over SGD 1000× heavier.
7. **Quantum insecurity**: discrete-log PCS vulnerable Shor. Migration to Binius/Breakdown 50-100KB proof PQ but 3-5× slower.

| Limitation | Severity | Mitigation | Open research |
|---|---|---|---|
| 3.5GB pk | High | On-disk commit streaming MSM GPU NTT | Recursive Nova/SuperNova folding |
| Int4 acc drop | Med | Mixed-precision QAT learned scales | Auto-search QAT verification |
| 2^32 div table | Med | Decompose div Newton-Raphson lookups | Reciprocal tables |
| Training not covered | High | Commit to data Merkle IVC per epoch | zkPoT |
| PQ | Future | Lasso binary fields Goldilocks/Binius PCS | Spartan2 Binius bench |

We bridged four layers: **Spartan** transparent linear-time zkSNARK R1CS/CCS via SPARK, **Lasso** offline memory-checking sparse lookups via decomposable tables, **Jolt** zkVM where RISC-V execution *is* lookups, **zkML** quantized inference via EZKL Halo2 with Freivalds 273× reduction. Empirically: 2^20 constraints 1.2 s, Jolt 4.8M cycles 30 s, MNIST CNN 3.4 s proof, enabling on-chain verifiable AI agents where inference integrity without privacy loss.

Future: **Folding-based zkML** Nova folding attention layers, **Binius-field Lasso** PQ + GPU, **Jolt-Atlas GPU MSM** <5 s 10M cycles, **zkPoT** data commitment + training trace folding. Lookup singularity—if you can lookup you can prove—subsumes both general SNARKing and custom ML circuits, turning Verifiable AI deployable.
