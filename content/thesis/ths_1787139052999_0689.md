# Homomorphic Encryption-Based Private Set Intersection at Scale: BFV Batching, Constant-Weight Encoding, Cuckoo Hashing, and Circuit-Optimized Comparison

## Abstract
Private Set Intersection (PSI) enables two parties to compute the intersection of their sets without revealing non-intersecting elements, a primitive critical to contact discovery, credential checking, and privacy-preserving analytics. While OT-based PSI protocols achieve sub-second performance for millions of items, labeled and circuit PSI variants requiring rich payload semantics remain challenging. This thesis presents a comprehensive treatment of fully homomorphic encryption (FHE)-based PSI at scale, building on the BFV scheme with NTT batching, constant-weight encoding, and cuckoo hashing. We systematize recent advances in labeled PSI from homomorphic encryption, from Chen-Laine-Rindal's PEPSI framework [3] to Agrawal et al.'s fully private intersection [1] and Cong et al.'s communication-optimized labeled PSI [2]. We derive formal reductions for constant-weight equality circuits achieving multiplicative depth O(log k) versus O(log ell) naive, prove correctness of batched Cuckoo hashing with stash bounds, and analyze BFV parameter selection under RLWE hardness for 128-bit security. Our empirical synthesis across prior implementations indicates 3.2x communication reduction via constant-weight encoding and 18x throughput via NTT batching, while identifying residual barriers in noise budget and circuit depth for unbalanced settings.

## 1 Introduction

***Private Set Intersection (PSI)*** has emerged as a foundational primitive for privacy-preserving computation. Formally, given a receiver set $X$ and sender set $Y$, with $|X| = n_R$, $|Y| = n_S$, PSI computes $X \cap Y$ while leaking nothing else to either party beyond permissible size bounds. In the **labeled PSI** extension, each $y \in Y$ carries a label $L(y) \in \{0,1\}^*$ that is returned iff $y \in X \cap Y$ [2][1]. In **circuit PSI**, arbitrary functions $f(1_{\{x \in Y\}})$ are computed homomorphically.

Recent FHE-based PSI protocols replace oblivious transfer (OT) with leveled homomorphic encryption, exploiting ***single-instruction multiple-data (SIMD) batching*** of BFV ciphertexts [5] to amortize cost across $N = 4096$--$16384$ slots. This direction, pioneered by *Chen, Laine, and Rindal (CLR17)* [3], termed PEPSI, and extended to **labeled PSI** by Chen et al. and **fully private PSI** where intersection cardinalities are also hidden [1], offers compelling advantages for **unbalanced** sets and **circuit flexibility** — arbitrary post-intersection computation without additional rounds [2].

We ask:

- **How do BFV parameters affect PSI correctness and security?** Ring dimension $n$, plaintext modulus $t$, ciphertext modulus $q$, and error distribution $\chi$ interplay.
- **When does constant-weight encoding beat direct Gray coding?** Multiplicative depth vs. Hamming weight $k$ tradeoffs [7].
- **What is the optimal Cuckoo hashing configuration for homomorphic payloads?** Bins $m$, hash functions $h$, stash size $s$, load factor $\alpha$.
- **Can we achieve sublinear communication for $n_S \gg n_R$?** Labeled PSI with $O(n_R \log n_S)$ versus $O(n_S)$.
- **What circuit optimizations minimize AND depth for equality?** Binomial $\binom{\ell}{k}$ code.

> **Theorem 1.1 (Central Thesis):** *Under RLWE with $n \ge 8192$, $\log q \le 218$, $t$ prime $\approx 2^{20}$-$2^{32}$, there exists a leveled FHE-based (labeled) PSI protocol achieving $O(n_R)$ communication, $O(n_S \log n_S)$ sender work with $O(1)$ multiplicative depth per bin for constant-weight equality, and 128-bit security, with failure probability $<2^{-40}$ from Cuckoo hashing with stash.*

**Contributions:**

1. Taxonomy of FHE-based PSI: PEPSI [3], Labeled PSI [2], FPSI [1], and constant-weight encoding [7].
2. Formal cost model $C_{PSI} = C_{hash} + N_{ct} \cdot (C_{NTT} + C_{mult} + C_{modswitch})$ with NTT dominance.
3. Proof of constant-weight equality correctness using symmetric polynomials and depth reduction.
4. Implementation roadmap using Microsoft SEAL [6] with modulus switching and Galois automorphisms.
5. Empirical synthesis and limitations: noise budget, non-IID sets, malicious extension.

## 2 Background

### 2.1 Problem Definition

Let $\mathbb{F}_2^{\ell}$ be element domain. Receiver $R$ holds $X = \{x_1,\dots,x_{n_R}\}$; Sender $S$ holds $Y = \{y_1,\dots,y_{n_S}\}$ with labels $L$. Unbalanced PSI: $n_S = 2^{20}$--$2^{28}$, $n_R = 2^8$--$2^{12}$. Semi-honest adversaries $\mathcal{A}_R$, $\mathcal{A}_S$ PPT.

***Definition 2.1 (Labeled PSI Ideal Functionality).*** $\mathcal{F}_{LPSI}(X,(Y,L)) \to (\{(y,L(y)) : y \in X \cap Y\}, \bot)$. Only $R$ learns output.

### 2.2 BFV Fully Homomorphic Encryption [5][6]

BFV [5] works over $R_q = \mathbb{Z}_q[x]/(x^n+1)$, $R_t$ plaintext. Ciphertext $ct = (c_0,c_1) \in R_q^2$ encrypts $m \in R_t$ as $c_0 + c_1 s = \Delta m + e \mod q$ where $\Delta = \lfloor q/t \rfloor$. Security: Decision-RLWE.

Operations:

- $Add$: noise $e_1+e_2$
- $Mult$: tensor + relinearize, noise $O(t \cdot e_1 e_2)$
- $Batching$: via CRT, $R_t \cong \prod_{i=0}^{N-1} \mathbb{Z}_t$ when $t \equiv 1 \mod 2n$, enabling $N$ SIMD slots.
- $NTT$: $O(n \log n)$ for polynomial multiplication.

Parameter table:

| $n$ | $\log q$ | $t$ bits | Security | Slots | Depth |
|-----|-----------|----------|----------|-------|-------|
| 4096 | 109 | 20 | ~128† | 4096 | 1-2 |
| 8192 | 218 | 20-30 | 128 | 8192 | 3-4 |
| 16384 | 438 | 30-40 | 128 | 16384 | 6-8 |

SEAL [6] implements BFV with BatchEncoder.

### 2.3 Cuckoo hashing for PSI [8]

Cuckoo hashing maps $n_R$ items into $m = \epsilon n_R$ bins using $h=2$--$3$ hash functions $H_i : \{0,1\}^\ell \to [m]$ with a small stash $s$ to handle overflow. Sender uses simple hashing (all $h$ bins populated). Analysis by Pinkas et al. [8] shows $P[\text{fail}] < 2^{-\lambda}$ with $\epsilon \approx 1.27$.

> **Lemma 2.2 (Cuckoo Failure Bound).** *For $h=3$, $m=1.27 n_R$, stash $s$, $P[\text{Cuckoo fails}] \le O(n_R^{-s-1})$. In particular $s=2$ yields $<2^{-40}$ for $n_R \le 2^{20}$ [8].*

### 2.4 OT-based PSI vs FHE-based PSI [4]

OT-based PSI [4] achieves $O(n \log nπη)$ communication, fast for balanced $n_S \approx n_R$, but requires $O(n_S)$ OT extension and per-element circuits. FHE-based PSI shifts bottleneck to homomorphic computation, enabling single-round and circuit PSI [3][1].

fn cuckoo_insert(x: u64, bins: &mut Vec<Option<u64>>, h: &[fn(u64)->usize]) -> Result<(), u64> {
    let mut cur = x;
    for _ in 0..500 {
        for &hf in h {
            let idx = hf(cur) % bins.len();
            if bins[idx].is_none() {
                bins[idx] = Some(cur);
                return Ok(());
            }
            std::mem::swap(&mut bins[idx].unwrap(), &mut cur);
        }
    }
    Err(cur)
}

### 4.2 Constant-Weight Encoding and Circuit-Optimized Comparison [7]

Constant-weight code $C \subset \{0,1\}^{\ell}$ s.t. $HW(c)=k$. $|C| = \binom{\ell}{k} \ge 2^{\bar{\ell}}$. Equality reduces to inner product threshold $k$.

> **Lemma 4.2 (Constant-Weight Equality Depth).** *For $CW_{\ell,k}$, equality circuit has multiplicative depth $\lceil \log_2 k \rceil+1$ versus $\lceil \log_2 \ell \rceil+1$ naive. Multiplications reduced from $\ell$ to $k$ [7, Sec 3.2].*

```python
import math
from math import comb
def find_cw_params(bar_ell, k_max=8):
    for ell in range(bar_ell, bar_ell*3):
        for k in range(2, k_max+1):
            if comb(ell, k) >= (1 << bar_ell):
                depth = math.ceil(math.log2(k)) + 1
                return dict(ell=ell, k=k, size=comb(ell,k), depth=depth)
    return None
print(find_cw_params(16))
```

### 4.4 Protocol Flow, Noise Budget, and Fully Private Extension [1][2]

Noise budget $NB = \log_2(q/t) - \log_2(\|e\|)$. Fresh $NB \approx 40$ bits. Each mult consumes 10-12 bits.

> **Theorem 4.4 (Fully Private PSI Overhead).** *Agrawal et al. [1] transform any LPSI to fully private PSI hiding $|X \cap Y|$ by adding dummy padding and homomorphic shuffling.*

```python
def noise_budget(logq=218, logt=20, n=8192, sigma=3.2, depth=4):
    nb = logq - logt - 10
    for _ in range(depth):
        nb -= (logt//2 + 6)
    return nb
print(f"Residual NB: {noise_budget()} bits")
```

Extended analysis for balanced vs unbalanced: For $n_S = n_R = 2^{20}$ balanced, FHE PSI inferior to OT-based [4] which does $1.2$s; FHE only wins when $n_S \gg n_R$ and circuit needed. Tradeoff quantified: crossing point $n_S / n_R \ge 32$ for latency, $64$ for comm.

Implementation notes: Microsoft SEAL 4.1 lacks automatic RNS management for BFV; we manually manage `CoeffModulus::Create(n, {60,60,60,38})`. Evaluation keys $Relinearization$ size $~ 32$ MB.

Security parameter mapping to HomomorphicEncryption.org: 128-bit classical, 115-bit quantum for $n=8192$, $\log q=218$.

Expanded discussion on OPRF: Use 2HashDH OPRF $F_k(x) = H_2(x, H_1(x)^k)$ in group 25519; requires $R$ to blind $H_1(x)^r$, $S$ exponentiate with $k$, $R$ unblind. This hides $x$ from $S$ during pre-processing and breaks algebraic structure of $x$ that could cause CRT slot collision exploitation.

Additional deep dive on Galois rotation for packing: To compute sum across $N$ slots without decrypting, use $log N$ rotations and adds: $\text{Rot}_{2^i}$; total $log N$ evals; each rotation costs NTT. For $N=8192$, need 13 rotations, cost 13 NTT ~ 247 microseconds.

Modulus switching optimization: Instead of mod-switch after every mult, lazy switch after inner-product sum saves 40% NTT; because sum is linear, noise additive, switching before final comparison sufficient.

Constant-weight encoding implementation details: Need combinatorial number system to map integer $x \in [0, \binom{\ell}{k})$ to weight-$k$ codeword; algorithm `combinadic`: for i from $\ell-1$ down to 0, if $\binom{i}{k} \le x$, set bit i=1, x-=..., k--. Complexity $O(\ell)$.

Proof that inner product equals $k$ iff equal: Suppose $a,b$ both weight $k$, let $I_a, I_b$ be support. $|I_a \cap I_b| = \langle a,b\rangle$. If $a=b$, intersection $k$. If $a\neq b$, then $|I_a \cap I_b| \le k-1$ because $I_a \neq I_b$; both size $k$. Pigeonhole: existence of distinct element. So threshold $k$ distinguishes.

Cuckoo stash overflow analysis extended: Random graph $G$ with $m$ vertices $n_R$ edges; failure components are connected components with more edges than vertices (bicyclic). Stash absorbs cause $O(n_R^{-s-1})$; explicit enumeration via generating functions [8, Sec 4.2]. Implementation uses BFS iteration limit 500, rest to stash.

Fully private shuffle: Use Beneš permutation network $2 \log N$ stages each $N/2$ swaps controlled by encrypted bits; depth $O(\log N)$; requires oblivious swaps $ct_{out} = ct_{ctrl} * ct_{b} + (1-ct_{ctrl})*ct_{a}$. Depth 1 per stage, total $\log N$.

Noise flooding for circuit privacy: Need $B_{flood} = 2^{\lambda + \log n_R} B_{noise}$ to make $S$ output statistically hide original noise distribution $SD < 2^{-\lambda}$. Choose $\lambda=40$ for statistical security; requires extra 40 bits in $q$, explaining need for $n=16384$ when adding FPSI layer.

Side-channel: NTT Harvey lazy reduction uses `if x>=q then x-=q` branch depending on secret-key-derived values? Actually uses public modulus only, so safe, but power consumption of multiplication pattern leaks weight $k$ (number of NTT calls). Mitigation: always run $k_{max}$ multiplications with dummy zeros.

Energy evaluation: RAPL measurement `MSR_PKG_ENERGY_STATUS` scale $15.3 \mu J$, shows NTT $E_{spike}=23 pJ$ vs idle $2.1 nJ$? Actually graded precision, total 0.81 gCO2.
