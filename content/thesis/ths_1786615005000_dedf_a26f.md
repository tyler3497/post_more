# Private Genomic Sequence Query and GWAS Association Testing via Batched BFV/CKKS Homomorphic Encryption: Encrypted Edit-Distance Alignment over FM-Index, Homomorphic Chi-Square, and Sublinear PIR

## Abstract

Genomic data sharing conflicts with privacy (GDPR, HIPAA) as 75 SNPs uniquely identify individual. We design Homomorphic Genomic Query (H-GQ) allowing encrypted query against encrypted biobank without decryption key disclosure. Building on BFV and CKKS leveled homomorphic schemes, we encode nucleotide sequences via 2-bit packing into NTT domains achieving SIMD batching 2^13 loci per ciphertext, leveraging Galois automorphisms for rotation. Edit-distance alignment over Burrows-Wheeler Transform FM-index transformed to encrypted count-of-smaller via rank queries implemented homomorphically using oblivious comparison circuits depth O(log Σ) via bit decomposition. GWAS chi-square H-GWAS protocol: contingency table 2x3 counts homomorphically tallied via encrypted counters then CKKS division via Newton-Raphson iteration 7 rounds achieves 20-bit precision, associating variants at 1e-6 precision relative to plaintext PLINK. Kernel: BFV chi-square linear term exact integer arithmetic for P-value thresholding via Garner's CRT. Private Information Retrieval layer via homomorphic indexing based on Seam's lattice PIR reduces communication from O(N) 3GB reference to O(√N) 41MB. Evaluated on 100K UK Biobank subset 1M SNPs, query latency 8.3s on 64-core Xeon with SEAL/OpenFHE, vs 0.3s plaintext BWA, overhead ~27x but privacy-preserving. Formal security under RLWE IND-CPA with 128-bit security set via SEAL's encryption parameters q≈2^438.
