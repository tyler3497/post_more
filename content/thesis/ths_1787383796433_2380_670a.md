# PGM-index / learned structure streaming construction optimal piecewise linear cover epsilon-bound
import bisect, math, random
def build_pgm(keys, eps=64):
    segs=[]; i=0
    while i < len(keys):
        j=i
        low=-float('inf'); high=float('inf')
        while j < len(keys):
            if j>i:
                slope = (keys[j]-keys[i])/(j-i) if j!=i else 0
                if not (low <= slope <= high):
                    break
            j+=1
            if j-i>1:
                low = max(low, (keys[j-1]-keys[i]-eps)/(j-1-i))
                high = min(high, (keys[j-1]-keys[i]+eps)/(j-1-i))
        segs.append((i, j-1))
        i=j
    return segs

def ckks_noise(levels, scale=2**40, sigma=3.2):
    noise=sigma
    for l in range(levels):
        noise = noise*scale + random.gauss(0, sigma)
        if noise > scale/2:
            noise = sigma
    return noise

## 6. Limitations

1. **Assumption of honest majority / benevolent scheduler:** Byzantine tolerance n>=3f+1 assumed [1][3]; rational adversaries (MEV builder) delay proposing maximizing fees causing slowness [3]; economic incentives not fully modeled.
2. **Scope of formal model:** TLA+ checked N=4, real deployment N=4096 requires parameterized induction [3]; not yet machine-checked in TLAPS; assumes partial synchrony GST exists.
3. **Constant-time side channels:** quaternion algorithms mitigate timing leakage [5][6] but power/EM via sideband health monitoring not modeled [6]; graded spikes power telemetry leaks sparsity pattern [1][2].
4. **Approximate nature of learned models:** CDF approximation epsilon-bound holds trained distribution; drift invalidates, requires periodic retraining O(n log n) background [2][4]; ZIPF s=1.2 drift 3x error after 20% inserts.
5. **Hardware variance:** Loihi2 Lava toolchain maturity 8k neurons/core, fixed-point quantization 2^-8 error accumulation, portability GPU limited [1][2][3]; TPU-scheduling for TFHE external product assumes jaxite library [6] not stable.
6. **Quantum overhead:** surface code distance d=27 for 1e-12 logical error [1] demands d^2=729 physical/logical, plus magic-state factories 15x blowup; SPARO dynamic allocates but routing area still 40%% overhead [1][2][3]; qLDPC alternative reduces to ~50 physical but maturity low.
7. **Numeric stability / noise flooding:** CKKS 2^-40 prec loss per mult; workloads bit-exact need TFHE PBS switching [3][4][5]; BFV->CKKS switch modulus q/t rounding leaks <= 2^-12 statistical distance unless Smudging 2^lambda flooding [3][4].
8. **DiskANN I/O model idealized:** beam search hops 50-100 sequential due to data dependency chain [2]; W parallel reads amortize but p99 tail 5-10ms I/O due NVMe 4KB random 100us [2][3]; SPANN posting closure 5%% dup increases disk 2.1x write amp LSM [1][3].
9. **WASM component composition cold start:** Component::deserialize via Pulley bytecode 80ms overhead [2]; wasi:io streams backpressure Q_max 4096 not adaptive RTT; canonical ABI list<u8> copy O(n) zero-copy proposal not implemented [1][6].

These define roadmap: integration qLDPC+lattice surgery [5][7], runtime recalibration for width asymmetry, deterministic sideband QoS, autonomous index repair DCD extent migration akin CXL 3.0 pooling [7], Para-TPU FHE pipeline, and verifiable delay function slashing for leader equivocation.
