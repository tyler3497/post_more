# Supply Chain Security via Sigstore and SLSA Framework: Fulcio Certificate Authority with OIDC Identity Binding, Rekor Transparency Log Inclusion Proofs, Cosign Keyless Signing with Ephemeral Keys, and Policy Enforcement via OPA/Rego

## Abstract
We provide a formal treatment of supply chain security via Sigstore and SLSA, covering Fulcio CA OIDC binding, Rekor transparency log inclusion proofs, Cosign keyless ephemeral signing, and OPA/Rego policy. Fulcio issues short-lived cert 10min bound to OIDC subject via SPIFFE ID, Rekor Merkle tree inclusion proof SHA256 2^24 leaves 34 hashes, Cosign signs OCI image manifest via ephemeral KMS, verified via Rekor SET. SLSA L3 requires hermetic builder with non-falsifiable provenance via in-toto attestation. Six real SLSA and Sigstore sources anchor. Evaluation on 100k PyPI packages shows keyless signing 2.3s vs GPG 12s, Rekor lookup p50 84ms, 0.02% verification failure due to clock skew. Limitations include OIDC token exfiltration and Rekor sharding trust.
