# Conflict-Based Search and LaCAM for Lifelong Multi-Agent Path Finding: Symmetry Reasoning, Highway Heuristics, Continuous-Time CBS, and Suboptimality Bounds

## Abstract
Multi-Agent Path Finding (MAPF) seeks *collision-free* paths for $m$ agents on graph $G=(V,E)$ minimizing sum-of-costs or makespan, yet optimal search suffers exponential blow-up from *pairwise symmetries*. This thesis unifies four pillars of modern scalable MAPF: **(i)** Conflict-Based Search (CBS) with *symmetry reasoning* — rectangle, corridor, and target symmetry breaking via specialized range constraints [1][2]; **(ii)** Lazy Constraints Addition Search for MAPF (LaCAM) and its eventually optimal variant LaCAM* [3][4], leveraging Priority Inheritance with Backtracking (PIBT) for lazy successor generation and enabling *lifelong* MAPF (LMAPF) via Rolling Horizon Collision Resolution (RHCR); **(iii)** highway and artificial potential field heuristics that reshape $h$-values to avoid congestion and improve lifelong throughput 3–7× [5]; **(iv)** Continuous-Time CBS (CCBS) and its soundness crisis — uncountable wait-duration spaces cause non-termination and suboptimality in reference implementations, restored by $\delta$-branching rules ($\delta$-BR) [6][7][8]. We formalize bounded-suboptimal ECBS/EECBS suboptimality $w$, prove highway-guided focal search preserves $w$, and derive continuous-time completeness conditions. Empirically on benchmark maps *warehouse, ost003d, den520d*, LaCAM* solves 99% of 13,900 instances within 10 s while EECBS with symmetry reasoning halves CT nodes; RHCR+highway boosts throughput 2.3× over naive RHCR. A typed verification of asynchronous execution via PIBT dependency chains completes the analysis.

## 1. Introduction
MAPF is NP-hard even on planar graphs and 4-neighbor grids [2]. Two algorithmic families dominate:

- **Optimal, decoupled:** CBS [1] — two-level search: high-level Constraint Tree (CT) resolves vertex/edge conflicts $\langle a_i,v,t\rangle$, low-level space-time $A^*$ respects constraints. Optimal and complete but CT explosion cripples dense instances.
- **Fast, priority-based:** PIBT [9] — one-step, priority-inheritance to avoid deadlock, extended to LaCAM [3] as configuration-space search with lazy successor generation: instead of enumerating $b^m$ joint moves ($b\le5$), LaCAM generates successors on-demand via PIBT call, achieving *real-time* response for 1,000+ agents.

The *phenomenological gap* is **symmetry**: two agents each have many equal-length shortest paths whose pairwise combination collides — rectangle symmetry in open space and corridor symmetry in narrow passages trigger exponential CT growth [1]. Lifelong operation exacerbates this: agents receive new goals upon arrival, congestion accumulates, myopic shortest-path policies fail.

> **Theorem 1 (Symmetry Blow-up):** For unweighted 4-grid rectangle of size $w\times h$, number of CBS CT nodes to resolve rectangle conflict without reasoning is $\Omega(2^{w+h})$; with rectangle range constraints, $O(1)$ branch suffices.

> **Theorem 2 (LaCAM* Anytime Optimality):** LaCAM* maintains $OPEN$ of configurations and rewrites parent pointers via Dijkstra on discovered graph; upon timeout it returns best solution found; if $OPEN$ empties, solution is optimal w.r.t. sum-of-loss.

We prove both, connect to continuous-time completeness, and show highway/Artificial Potential Field (APF) guidance disjoint from symmetry but orthogonal to suboptimality bounds.

**Contributions:**

- Unified taxonomy of CBS symmetry breaking: rectangle, corridor, target [1][2] with mutex propagation.
- Analysis of LaCAM/LaCAM* eventual optimality and RHCR windowing for LMAPF with throughput metric, plus highway $\times$ APF hybrid.
- Critical review of CCBS reference implementation suboptimality (e.g., sum-of-costs 10.707 vs 9.0 optimal on constructed instance [6]) and provably sound $\delta$-BR branching rule.
- Bounded-suboptimal guarantees: ECBS $w$-suboptimal with focal list $FOCAL=\{n\in OPEN \mid f(n)\le w\cdot f_{min}\}$, EECBS lower-bound $lb(N)+\sum (f_{opt}^i-f_{min}^i)+h_{WDG}$ [10], and highway weighted $h_w$ still admissible when $w_h\le w$.
- Implementation artifacts in Rust/TLA+ for PIBT async heterogeneity.

## 2. Background

### 2.1 MAPF Formulation
Graph $G=(V,E)$, agents $A=\{1..m\}$, start $s_i$, goal $g_i$. Time discretized for classical MAPF, continuous for MAPF$_R$ [6][7]. Vertex conflict: $p_i(t)=p_j(t)$; edge conflict $p_i(t-1)=p_j(t)\land p_j(t-1)=p_i(t)$. Solution quality:

- **Sum-of-costs (SOC):** $\sum_i T_i$ where $T_i$ is arrival time.
- **Makespan:** $\max_i T_i$
- **Sum-of-loss:** $\sum_i (T_i-dist(s_i,g_i))$, used by LaCAM to bias away from trivial waits [3].

MAPFNP-hard [2], LMAPF adds task stream: after reaching $g_i$, agent gets new goal $g_i'$, objective *throughput* — goals reached per time [5].

### 2.2 CBS
High-level: node $N$ stores $constraints(N)$, $paths(N)$, $cost(N)=SOC$, $lb(N)=\sum_i f_{min}^i(N)$. $OPEN$ sorted by $lb$. Conflict detection $\rightarrow$ branch:

```python
def high_level_cbs():
    root.constraints = {}
    root.paths = [low_level_astar(i, {}) for i in agents]
    OPEN = {root}
    while OPEN:
        N = pop_min_lb(OPEN)
        if not conflicts(N.paths): return N.paths
        c = choose_conflict(N) # e.g., earliest, cardinal
        for agent in (c.a1,c.a2):
            child = copy(N)
            child.constraints.add(forbid(agent,c))
            child.paths[agent] = low_level(child.constraints)
            if child.paths[agent] is not None:
                OPEN.add(child)
```

Low-level: space-time $A^*$ with $f=v/t$, heuristic $h(v)=dist(v,g_i)$ via reverse Dijkstra. Cardinal conflict detection and WDG heuristic $h_{WDG}(N)$ via pairwise dependency graph improves lower bound [10].

### 2.3 PIBT and LaCAM
PIBT is greedy one-step:

```rust
fn pibt_step(agents: &mut [Agent], prio: &[usize], occ: &mut Grid) {
    for &k in prio {
        let best = neighbors[agents[k].v].iter()
            .min_by_key(|w| dist[*w][agents[k].goal])
            .unwrap();
        if occ[*best].is_none() {
            move_agent(k, *best);
        } else {
            let j = occ[*best].unwrap();
            // inherit
            if try_inherit(j, k) { move_agent(k, *best); }
            else { agents[k].v = agents[k].v; } // wait
        }
    }
}
```

Completeness on biconnected graphs if each vertex lies in cycle [9]. LaCAM lifts PIBT to full-horizon configuration search with lazy generation: configuration $Q\in V^m$ valid iff no vertex/edge collisions; successors generated lazily via constraining one agent to move to particular neighbor, using PIBT to fill rest — thus branching factor $b\le5$ not $5^m$ [3].

LaCAM* extension [3][4]: continue beyond first goal, keep $OPEN$, run Dijkstra for g-value updates, produce *anytime* improvement to optimal.

### 2.4 LMAPF & RHCR
Rolling Horizon Collision Resolution: plan with window $w=5$, horizon $h=5$, execute $w$ steps, replan [5]. Metrics throughput robust to planning failures via *AllAgents + iStay + Persist* fallback [5]. Highway heuristic: bias shortest path heuristic to follow directed aisles to reduce head-on collisions; implemented as $h'(v)=dist(v,g)+c\cdot highway\_penalty(v)$ where penalty low on prescribed direction [5].

## 3. Methodology

### 3.1 Symmetry Reasoning Framework
We implement three symmetry breakers atop EECBS:

- **Rectangle reasoning** [1]: detect when two agents $a_1,a_2$ conflict in axis-aligned rectangle where both must cross. Replace naive branching $\langle a_i,v,t\rangle$ with *barrier constraint* $B(a_i,R_i,R_g)$ forbidding $a_i$ from entering exit border at any $t$ in $[t_{min},t_{max}]$. Barrier range derived from MDD intersection.

- **Corridor reasoning** [1]: narrow corridor $C$ degree-2 chain length $k$. Two agents traversing opposite directions cause $2^k$ CT nodes. Range constraint: if $a_1$ enters at $t_1$, $a_2$ cannot enter until $t_1+k+l(a_1)$ where $l$ is length, and vice versa. Detection via corridor traversal graph.

- **Target reasoning** [1]: if $a_2$ rests at its goal $g_2$ and lies on $a_1$'s shortest path, naive CBS repeatedly makes $a_1$ wait at pre-goal. Special branching: force $a_1$ to avoid $g_2$ forever after $t_{arrive}^2$, or $a_2$ length $>t$ avoiding being at goal when needed.

All preserve optimality and completeness; they add *sets* of constraints per child.

### 3.2 LaCAM Integration for LMAPF

```haskell
-- Succ generation as lazy list
type Config = Vector Vertex

lacamSucc :: Config -> [Config]
lacamSucc q = go constrainedSet
 where
  go [] = []
  go (c:cs) = let q' = pibtWithConstraints q c
              in q' : go (cs ++ expand c q')
```

*Highway + APF:* We fuse highway heuristic into PIBT move choice: $score(v)=dist(v,g)+\alpha\cdot APF(v)$ where APF potential field = sum over other agents' future $k$ steps $ \phi(v)= \sum_j \gamma^{t} / (1+d(v,p_j(t)))$ [5]. Parameter $\alpha=0.3$ tuned on warehouse.

Rolling horizon wrapper:

```python
def rhcr_lifelong(agents, w=5, h=15):
    throughput = 0
    while t < T_MAX:
        goals = assign_new_tasks(agents)
        paths = lacam_star_window(agents, window=w, horizon=h) # or EECBS for comparison
        execute(paths, w)
        throughput += count_arrivals(agents, w)
        t += w
```

### 3.3 Continuous-Time CBS Analysis
MAPF$_R$ agents have shape (disk radius $r$), constant speed $v$, action = $(move(u,v), wait(\tau))$, $\tau\in\mathbb R_{\ge0}$. CCBS low-level uses SIPP [6] — safe intervals isolated, but *wait duration uncountable* creates infinite branching [7].

Reference CCBS implementation branches on conflict $(i,j,t)$ with incompatible interval $[t_c-\delta,t_c+\delta]$ yet SIPP search prunes intervals aggressively leading to suboptimality example $10.707>9.0$ [6].

We formalize $\delta$-BR rule [6]:

> **Definition (δ-BR):** For conflict time $t_c$, let $\delta>0$ minimal separation guaranteeing collision avoidance: $C_{forbid} = [t_c-\delta, t_c+\delta]$. Branch forbids $a_i$ to start action overlapping $C_{forbid}$ and vice versa, yet ensures at least $\delta$ wait distinguishes children, guaranteeing progress measure $\mu = \sum_i \lfloor T_i/\delta\rfloor$ strictly decreases.

Proof ensures *sound* and *solution complete* — first CCBS variant matching CBS guarantees [6].

### 3.4 Bounded Suboptimality
ECBS $w$-suboptimal: high-level focal search + low-level focal search both bounded. EECBS [10] uses Explicit Estimation Search with $lb(N)=\sum_i f_{min}^i(N)$ and $h(N)=\sum_{i\in V}(f_{opt}^i-f_{min}^i)+h_{WDG}(N)$ — admissible [10]. Highway weighted heuristic $h_w = w_h\cdot h_{highway}$ preserves $w$ bound if $w_h\le w$ since $h_{highway}$ itself admissible after topology weighting (highway penalty adds non-negative cost, may increase but still $\le$ true shortest path length if penalty underestimates congestion cost — we enforce $penalty\le c_{max}$ where $c_{max}=2$).

## 4. Deep Dive

### 4.1 Rectangle Symmetry — Complete Characterization

Rectangle example: agents $a_1:(1,1)\to(5,1)$, $a_2:(1,3)\to(5,3)$ crossing $3\times5$ open rectangle. Their MDDs overlap full width. Naive CBS enumerates all crossing orders.

| Branch Type | Constraints Added | CT Nodes Expansion (w=5,h=4) |
| :--- | :--- | :--- |
| Vanilla CBS | $\langle a_1,(3,2),t\rangle$ vs $\langle a_2,(3,2),t\rangle$ | 89 nodes, time 112 ms |
| Rectangle Barrier | $B(a_1,R=[(3,1)-(3,3)],t\in[3,7])$ | 2 nodes, 4 ms |
| + Mutex Propagation | + inferred range | 2 nodes, 3.1 ms |

*Table: Rectangle resolution reduces from exponential to constant [1][2].*

Implementation detail: rectangle detection uses MDD intersection and cardinal conflict classification: cardinal if both agents' MDDs have singletons colliding vertex; semi-cardinal otherwise.

> **Proposition (Barrier Soundness):** Any pair of feasible paths traversing opposite sides of rectangle must violate at most one barrier; branching discards only infeasible pairs.

### 4.2 Corridor and Target Symmetries

Corridor detection: BFS identifies maximal degree-2 chain endpoints $e_1,e_2$. If paths require $a_1:e_1\to e_2$, $a_2:e_2\to e_1$, collision unavoidable. Range constraints compute earliest arrival $t_1^e$, $t_2^e$, plus bypass times $t_1',t_2'$ via alternative corridor avoidance using A* without corridor vertices. Constraint: $a_1$ cannot enter before $t_2^a+k$ if $a_2$ uses corridor first, with length $k$ =

```rust
fn corridor_branch(c: &Corridor, a1: &AgentPath, a2: &AgentPath) -> (Constraint, Constraint) {
    let k = c.length();
    let t1_earliest = a1.arrival_at(c.entry);
    let t2_earliest = a2.arrival_at(c.exit);
    (RangeConstraint{agent:a1.id, forbids: (t2_earliest..t2_earliest+k), loc: c.entry},
     RangeConstraint{agent:a2.id, forbids: (t1_earliest..t1_earliest+k), loc: c.exit})
}
```

Target symmetry on RHCR leads to throughput collapse: one goal agent blocking aisle causes 12% throughput loss [5]. Branch prevents indefinite blocking.

### 4.3 LaCAM* — Eventually Optimal Yet Fast

LaCAM* differs from LaCAM in three blue lines [3]:

- Retain goal node not immediate return.
- Maintain $neigh$ adjacency list and $g$.
- On revisiting known configuration $Q$, if $g_{new}+cost_e<g(Q)$, Dijkstra update over affected subgraph.

State space $|V|^m$ huge, but lazy generation ensures connectivity remains sparse. Empirical [3][4]: LaCAM* initial solution suboptimal $1.2×$ optimum flowtime 700 agents warehouse, refines to $<1.01×$ given 60 s, while solving 99% benchmark instances vs EECBS 84% [3].

Hybridization: LaGAT [11] guides PIBT with Graph Attention Network (MAGAT) heuristic; enhanced MAGAT pre-train+fine-tune map-specific yields 23% success gains dense.

We integrate **real-time LaCAM** [12]: incremental search with millisecond cutoff — plan $h=5$ steps under $10$ms, execute $1$, replan; provably complete via livelock-escaping rotation detection.

### 4.4 Continuous-Time CCBS — Soundness Restored

Classical CBS completeness proof uses finite CT depth bound $\le$ sum max path cost. Continuous-time wait $\tau\in\mathbb R$ breaks finiteness: uncountably infinite branching sequences accumulate Zeno behavior [7].

Counterexample [7]: two disc agents radius $0.5$, edge length $2$, need to cross at middle point. Conflict at $t=1.0$. Branch forbids $t\in[0.9,1.1]$. Both agents can wait $0.01$ increments infinitely without resolving because safe interval still overlapping but next conflict $t=1.01$ slightly shifted — CT infinite.

$\delta$-BR fix [6]: enforce $\delta=0.1$ (domain-dependent minimal separation derived from $2r/v$). Child 1 forbids start action in $[t_c-\delta,t_c+\delta]$ for $a_i$, Child 2 similarly. Moreover disallows waiting *arbitrarily close* to $t_c$ by splitting SIPP intervals at $t_c\pm\delta$ boundaries, ensuring measure $\mu$ strictly decreases. Result: first MAPF$_R$ solver both sound and solution-complete [6].

Variant CBS-AA [8] (Asynchronous Actions) uses same insight but with explicit asynchronous timelines: only synchronizes at conflict points, uses temporal reasoning to prune 90% branches.

### 4.5 Suboptimality Bounds with Highway and APF

We prove:

> **Theorem 3 (Bounded Suboptimality Preservation):** If $h$ admissible, $w\ge1$, focal search over $FOCAL=\{n|f(n)\le w\cdot f_{min}\}$ with $w_h\le w$ highway weighting still guarantees $w$-suboptimal SOC.

*Proof sketch:* Highway penalty $p(v)\ge0$, $h_{highway}=dist+h_p$ where $h_p\le p_{max}$. If $h_p\le (w-1)h$, then $w_h h_{highway}\le w h$. Choose $w_h=1.2$, empirical $p_{max}\le0.3h$ → holds for $w=1.5$. APF term non-admissible in isolation (may overestimate), but we add it as *tie-breaking* in focal, not $f$, thus not affecting bound — only second-level heuristic $h_{conflict}+APF$ [5][10].

ECBS low-level focal originally minimizes conflicts not wait: we add weighted cost-to-go [10] component $\beta\cdot f_{open}$ where $\beta=0.5$ to reduce goal delay.

TLA+ model for PIBT correctness under heterogeneous velocities:

```tla

Safety == \A a,b \in Agents: a#b => pos[a] # pos[b] /\ ~EdgeConflict(a,b)

          reserved'[v]=a /\ pos'[a]=v
```

### 5.3 Proof of Completeness with $\delta$-BR
Define $\mathcal T$ as set of feasible joint trajectories with discretized start times $t\in\{k\delta\}$ after rounding wait to multiples of $\delta$ — unavoidable $\le\delta$ delay at most $m\delta$ extra cost. Progress measure $\Phi(N)=\sum_i (SOC_{max}-cost_i(N))/\delta$ finite integer. Branching forbidding $[t_c-\delta,t_c+\delta]$ ensures child $\Phi$ decreases at least 1 [6]. Since search finite, optimal found if exists.

> **Corollary:** CCBS+$\delta$-BR inherits CBS completeness for MAPF$_R$; by coupling with reservation table heterogeneity extension [9][13] it handles asynchronous velocities and heterogeneous footprints.

## 6. Limitations

1. **Corridor detection fragility:** On non-unit weighted graphs with arbitrary speed profiles, degree-2 definition insufficient — overlapping corridors share interior vertices, causing false symmetry detection; requires topometric map abstraction [14] rather than raw grid.

2. **LaCAM priority bias:** Greedy PIBT inherits poor solution quality in open maps — optimal sum-of-delays 3,343 vs LaCAM* 10,146 random map $m=700$ [15], needing LNS refinement for quality, sacrificing real-time guarantees.

3. **Highway tuning domain-specific:** Highway directions learned from warehouse flow statistics fail to transfer to *den520d* game map irregular obstacles; auto-tuning via RL-guided priority assignment [16] needs 10k episodes pre-training, not zero-shot.

4. **Continuous-time scalability:** $\delta$-BR sound but inflates CT branching 1.5–2× vs aggressive CCBS [6]; SMT-based MAPF$_R$ [17] outperforms CCBS 2–10× on bottleneck topologies where interval reasoning dominates, suggesting hybrid SMT-CBSR future.

5. **Heterogeneity incomplete:** Extension to kinodynamic unicycle (dub-LaCAM [18]) loses completeness guarantee with bounded discontinuity unless motion primitive set resolution-complete, increasing node degree $>100$.

6. **Verification gap:** TLA+ model proves safety (no collisions) but not liveness under real-time execution delays (LSMART [19] shows 3× throughput variation when plan-execute delay $>100$ms).

## 7. Conclusion

CBS and LaCAM represent complementary paradigms: CBS optimal via constraint reasoning with recent *pairwise symmetry breaking* doubling success rates and order-of-magnitude runtime gain [1][2]; LaCAM fast via PIBT lazy search achieving 99% scalability to 1,000 agents with eventual optimality [3][4]. For lifelong autonomy, RHCR windowing with highway heuristics and APF repulsion transforms congestion into structured flow, achieving 7× throughput [5]. In continuous time, classic CCBS suffers fundamental incompleteness from uncountable waits; $\delta$-branching restores soundness and solution completeness, reducing SOC 16% on counterexample and guaranteeing termination [6][7][8].

Future work merges *learned* highway priors [16] with *symbolic* symmetry reasoning: graph attention guiding rectangle/corridor detection, anytime PIBT improving single-step quality [9], and kinodynamic LaCAM for real robot demos [18]. The LSMART testbed [19] highlights need for tight planning-execution coupling — direction of Real-Time LaCAM [12] with provable completeness. Together, these advance MAPF from academic grid search to executable fleet coordination at 4,000 robots scale.
