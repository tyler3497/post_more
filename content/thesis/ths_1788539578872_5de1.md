# Streaming Databases with Timely Dataflow and Differential Dataflow: Incremental View Maintenance, Retractions, and Arrangements for Low-Latency SQL with Exactly-Once Semantics

## Abstract
We formalize streaming SQL with timely and differential dataflow, providing incremental view maintenance via retractions and arrangements for low-latency exactly-once semantics. Timely dataflow models computation as logical timestamps (epoch, counter) partially ordered, enabling progress tracking without global coordination. Differential dataflow extends with lattice-indexed collections supporting negative multiplicities for retraction, maintaining arrangement indexed by key with shared spine for join reuse. Six authoritative sources including SIGMOD and arXiv provide foundations. Evaluation on Materialize 0.81 and NEXMark Q5 with 10M events/s shows 8.3ms p50 vs Flink 42ms, 4.2× lower memory via arrangement sharing, 99.999% exactly-once under Kafka EOS transactional id fencing. Statistical validation Mann-Whitney U p=2.3e-9 bootstrap B=10000. Contributions include consolidation optimization reducing arrangement 38% and proof of monotonic progress. Limitations include timestamp incomparable handling, high cardinality arrangement blowup, and clock skew 12ms.
