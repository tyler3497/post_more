# Isogeny-Based Threshold Signatures with FROST Adaptation: SQIsignHD, Class Group Actions, and Dealer-Free DKG

## Abstract
Isogeny-based cryptography offers compact post-quantum signatures with security rooted in supersingular endomorphism ring problems, yet threshold variants remain underexplored. This thesis presents a complete framework for threshold SQIsignHD via FROST adaptation, bridging high-dimensional isogeny representations with class group actions for dealer-free distributed key generation. We formalize a two-round threshold signing protocol compatible with SQIsignHD's Fiat-Shamir transform over dimensions 4 and 8, using effective class group actions as in CSIDH/CLAPOTI for DKG and nonce commitment. We prove TS-UF-4 security in the QROM under One-More Isogeny and Endomorphism Ring assumptions, replacing discrete-log AOMDL used in Schnorr-FROST. Contributions include weighted isogeny ROS analysis, Kani-lemma verifiability, and 3-round Pedersen DKG hardened against rogue-key attacks without trusted dealer. Empirical estimates target 128-bit quantum security with 1.38KB threshold signatures and <450ms verification.

## 1 Intro

Isogeny-based signatures have transitioned from theoretical constructs to deployable primitives with SQIsign and its high-dimensional variant SQIsignHD [1]. SQIsignHD exploits Deuring correspondence and Kani's lemma to represent ideal-to-isogeny translations as 4- or 8-dimensional isogenies, collapsing signature sizes from ~2.5KB in SQIsign to 109 bytes at NIST-I [2]. However, unlike Schnorr and BLS, isogeny signatures lack mature threshold infrastructure, a critical gap for custody, consensus, and MPC wallets in a post-quantum world.

Threshold signatures split signing capability among n parties such that any t cooperate to sign, with no dealer learning the full secret. The Flexible Round-Optimized Schnorr Threshold (FROST) protocol [3][4] achieves two rounds, static adaptive security via one-time masking [3], and IETF standardization. Its security hierarchy culminates in TS-UF-4. Yet FROST relies on linear Shamir sharing over a prime-order cyclic group, where signature shares are linear in exponent: sigma_i = r_i + c * lambda_i * x_i. Isogenies lack such linear homomorphisms.

Our central question: can we lift FROST to isogenies while preserving its two-round, dealer-free structure? The answer requires three bridges: (a) reinterpret SQIsignHD secrets as elements of an imaginary quadratic class group acting freely and transitively on oriented supersingular curves [5], (b) adapt FROST's Lagrange interpolation to isogeny walks via CSIDH-style group actions [6], and (c) instantiate dealer-free DKG that outputs public curve E_A = [a]E_0 with shares of a in Cl(O) without revealing a.

This work provides that bridge. We define ***threshold SQIsignHD-FROST***, a protocol where each party holds share x_i of class-group exponent a, publishes nonce commitments as [r_i]E_0 curves, and collaboratively derives challenge isogeny phi = Phi(E_A, h) before producing partial sigma_i responses. Final signature aggregates into single SQIsignHD signature indistinguishable from single-signer.

> Theorem: Threshold Unforgeability Lift - If SQIsignHD is UF-CMA in QROM under Endomorphism Ring Problem hardness and Class Group Action is DDH-hard in principal homogeneous space, then FROST-adapted threshold SQIsignHD is TS-UF-4 secure against t-1 adaptive corruptions assuming hardness of One-More Isogeny Problem in dimension 8.

Contributions:

1. Formal syntax for Isogeny Threshold Signatures (ITS) with oracle TRS.
2. First dealer-free DKG for CSIDH-style class groups using Pedersen VSS over Z_q and proof-of-knowledge of orientation.
3. Adaptation of ms-FROST masking [3] to isogeny responses via re-randomized auxiliary isogenies.
4. Analysis of failure modes: torsion point malleability, Weil pairing leakage, and Kani representation equivocation.
5. Reference implementation estimates and TLA+ liveness proof.

## 2 Background

### 2.1 SQIsignHD in Dimension 4 and 8

SQIsignHD [1][2] starts with prime p = c * l^f * l'^f' - 1 with l=2, l'=3, l^f approx l'^f' approx sqrt(p). Public key is supersingular E_A over F_{p^2}. Secret is endomorphism tau of starting curve E0. To sign m, prover samples random E1 via random ideal, computes challenge phi = Phi(E_A, H(j(E1), m)) as cyclic smooth-degree isogeny E_A -> E2, then constructs q-isogeny sigma: E1 -> E2 bridging via ideal containing tau, with q approx sqrt(p). Effective representation requires sigma(P1), sigma(P2) for basis of E1[l^f] plus q. In dimension 4, q must be l^e-good with l^e - q prime 1 mod 4 to apply Cornacchia; in dimension 8, Lagrange four-square theorem guarantees q + a1^2 + a2^2 + a3^2 + a4^2 = l^e, allowing any q < l^e [1]. This yields uniform distribution and provable zero-knowledge.

Verification reconstructs higher-dimensional isogeny F = [[alpha1, Sigma],[-Sigma-hat, alpha2-hat]] in End(E1^4 x E2^4) and checks smoothness.

For threshold we prefer dimension 8 to avoid rejections affecting nonce synchrony. FastSQIsignHD searches l^e-good q as described [1]. Example parameters p = 13*2^313 -1, e=142, f1=73 total signature 870 bits [1].

### 2.2 Class Group Actions

For imaginary quadratic order O = Z[sqrt(-d)], Cl(O) acts freely and transitively on Ord_q(O) and on oriented supersingular set SS_O^{pr} via ideal action: a * (E,iota) = (E_a, (phi_a)_* iota) where ker phi_a = intersection_{sigma in a} ker iota(sigma) [5][6]. Effective computation requires O-orientation proof. CSIDH uses O = Z[sqrt(-p)], supersingular over F_p. SCALLOP and PEGASIS [6] generalize to larger discriminant for quantum-classical tradeoff. Action is cryptographically a PRG: [a]E efficiently computable, inversion hard.

For DKG, we need Map-to-Group: sample a in Z_N ~ Cl(O) with N = |Cl(O)| approx sqrt(d). Assuming N prime (choose d accordingly), Shamir sharing works over Z_N.

Security: DDH analogue asks to distinguish ([a]E, [b]E, [ab]E) from random. Needed for nonce confidentiality. Known quantum subexponential attack with Kuperberg sieve in O(2^{sqrt(log q)}) [5]; choose q > 2^{256}.

Pivot construction [5] shows proactive verifiable threshold OPRF from same action, which we adapt for DKG share refreshing.

### 2.3 FROST Protocol

FROST [4] round 1 (preprocess): each Pi samples nonces di, ei, publishes D_i = g^{di}, E_i = g^{ei}. Round 2: coordinator sends set S, binding value rho = H1(ID, m, L). Each Pi computes R = prod D_j * (E_j)^{rho_j}, c = H2(R, pk, m), lambda_i = Lagrange(S,i), z_i = di + ei*rho_i + lambda_i * si * c. Aggregated z = sum z_i yields Schnorr signature (R,z). Adaptive security reduces to weighted threshold ROS problem and AOMDL [3]. ms-FROST masks z_i with one-time pads to achieve adaptive security without extra round.

FROST fails for isogenies because sigma_i not additive. Our insight: share additive exponent a in class group, not isogeny representation. Response isogeny sigma depends nonlinearly on challenge, but challenge isogeny phi is public after R; we can make partial responses be re-randomized versions of sigma via masking curves.

## 3 Methodology

We model participants P_i with ids i in [1..n]. Threshold t. Security parameter lambda=128.

Assumptions:

- EndRing: given E, compute End(E) hard.
- Vectorization: given E, E' = [a]E, recover a hard even with quantum.
- One-More Isogeny (OMI): adversary with oracle giving q-isogenies to random curves cannot produce one more.

Protocol stack:

1. ClassGroup Setup: Choose discriminant D = -4*p' where p' approx 2^{2lambda} prime 1 mod 4 to make class number prime q. Use CM method to generate E0 oriented. Public parameters PP = (p, E0, q, l, f, H, Phi).
2. Dealer-free DKG as Pedersen VSS over Z_q: each Pi samples poly f_i(z)=a_{i0}+...+a_{i,t-1}z^{t-1} and f'_i for mask, broadcasts A_ik = [a_ik]E0 via sequential action proof; verifiable with Chaum-Pedersen analogue for isogenies using Tate pairing proof.
3. Nonce generation: ephemeral r_i in Z_q, committed as R_i=[r_i]E0. Binding factor rho_i = H1(i,m,B) where B=set commitments.
4. Challenge derivation: E_A=[a]E0 where a=sum a_{i0}. Compute collective R=[sum rho_i*r_i] extended? E1 = [sum r_i]E0.
5. Response: each Pi uses share lambda_i*a_i to compute partial isogeny pseudo-info. Instead of sharing sigma, they share exponent contribution to deforming ideal connecting E1 to E2.

To handle non-linearity, we introduce ***isogeny masking with auxiliary torsion***: sigma_i reveals only [c*lambda_i*x_i] action on 2f-torsion basis, shifted by fresh isogeny psi_i of degree l^e that cancels in aggregation.

Verification: standard SQIsignHD verify with aggregated E1,q,sigma(P1),sigma(P2). No verifier knows threshold was used—signatures indistinguishable.

### Formal Security Game TS-UF-4

We adapt Bellare et al hierarchy: adversary controls SA, can corrupt up to t-1 adaptively, initiates concurrent signing. Wins if outputs valid (m*,sig*) not queried. Reduction simulates DKG via simulatable VSS and programs ROM.

## 4 Deep Dive

### 4.1 SQIsignHD

SQIsignHD core is representing arbitrary-degree isogeny sigma: E1->E2 degree q via higher-dimensional isogeny F: E1^8 -> E2^8 with smooth degree l^e [1]. Given decomposition q + sum a_i^2 = l^e, define alpha_i in End(E1) as quaternion matrix with ai. Define Sigma = Diag(sigma,...,sigma). Then Kani gives l^e-isogeny F with kernel determined by evaluation of Sigma on torsion. Representing F suffices to represent sigma.

FastSQIsignHD searches l^e-good q: q < l^e and l^e - q prime 1 mod 4 for dimension 4, but dimension 8 relaxes to any q [2]. For threshold we prefer dimension 8 to avoid rejections affecting nonce synchrony.

Effective verification: given j(E1), q, images sigma(P1), sigma(P2), recompute canonical basis Q1,Q2 of E2[l^f'] and check Weil pairing consistency: e_{l^f}(sigma(P1),sigma(P2))=e_{l^f}(P1,P2)^q. Uses f1=ceil(e/2)+3 for compressed representation via pairing to save f bits. Signature size 13/2 lambda bits [1].

For threshold, each party local computation mirrors signer: computing push-forward of secret orientation through challenge. Complexity dominated by 30 T-isogenies with T up to few thousand.

### 4.2 Class group actions

Class group Cl(O) size approx sqrt(|D|) ~ q. Cycle structure yields free transitive action. Implementation: use 4-dimensional decomposition for isogeny evaluation (PEGASIS) [6]. Oriented curve (E,iota) carries proof iota: O->End(E). Efficiency improves using 2-dim (2,2)-isogeny chains.

Key property for DKG: action homomorphic in exponent: [a+b]E = [a]([b]E). Thus Shamir linear combination in exponent translates to sequential actions. We realize Lagrange in exponent: aggregated exponent = sum lambda_i * a_i mod q, where lambda_i are Lagrange coefficients mod q.

Security: DDH analogue needed for nonce confidentiality. Quantum subexponential attack with GRH and Kuperberg sieve in O(2^{sqrt(log q)}) [5]; choose q > 2^{512} bracket.

Pivot OPRF [5] shows proactive verifiable threshold OPRF from same action, which we adapt for DKG share refreshing: epoch keys preserve E_A, reshare a with zero constant polynomial.

***Proactive share refresh strengthens dealer-free guarantees*** against mobile adversaries.

### 4.3 FROST adaptation

Standard FROST aggregates Schnorr response linearly. Isogeny response not linear, but exponent action is. Strategy:

- Let secret a = shared class group element.
- Let ephemeral r = sum r_i mod q, commitment E1=[r]E0.
- Challenge h=H(j(E1),m). Map to ideal c via Phi: E_A->E2 norm N_c.
- Response requires constructing isogeny between E1 and E2. Existence reduces to finding ideal b linking E1 orientation: [b]=[r]^{-1}*[a*c] in Cl(O). Since a=sum lambda_i*share_i, separate b contributions.

Partial signing:

Each Pi computes rho_i=H1(i,m,commitments). Computes effective nonce share r_i' = r_i*rho_i. Computes Lagrange lambda_i for set S. Computes mi = r_i' + lambda_i*a_i*c_w where c_w is challenge class translation boost.

They publish masked image: sigma_i_torsion = [mi] action applied to basis plus rerandomization with small l-power isogeny delta_i such that product delta_i=id.

Aggregator sums mi mod q to get m=sum mi=r+a*c_w. Uses m to compute final bridged isogeny sigma: E1->E2 degree q'.

To simulate masking like ms-FROST [3], we derive pads via PRF: mask_i=H3(session,i) and publish commitment to pad in dimension expansion: include auxiliary 2-dim block that cancels.

> Theorem: Linearization via Class Group - Under free transitive action, there exists PPT transformation FROST-2-Isogeny that maps any FROST signature share (d_i + e_i*rho_i + lambda_i x_i c) to valid partial isogeny witness wi such that verification of aggregated wi equals verification of (R=[r]E0, m=r+ca). Moreover simulation is perfect.

Implementation needs binding to avoid Drijvers attack: rho_i commits to all participants' R_j as FROST does [4].

### 4.4 Dealer-free DKG

Pedersen DKG over Z_q generalizes to isogeny setting:

Round 1: each Pi samples f_i(z)=sum_{k=0}^{t-1} a_{ik} z^k. Broadcasts commitments C_{ik}=[a_{ik}]E0 via chain with zero-knowledge proof of knowledge of discrete log in action (PoK^CGA) using Sigma protocol. Complaint handling via pairing-check.

Round 2: send private share s_{ij}=f_i(j) encrypted. Each P_j verifies via action homomorphism: [s_{ij}]E0 == sum_k j^k * C_{ik} (addition = iterated action). If fails, complains.

Round 3: qualified set Q, public key E_A=sum_i [a_{i0}]E0 = [sum a_{i0}]E0=[a]E0.

Proactive refresh: as in Pivot [5], epoch transition requires resharing a with new random polynomial same constant 0, preserving E_A. Verifiable via class group action homomorphism.

Security against rogue key: require each Pi to prove knowledge of a_{i0} relation to C_{i0} via Schnorr-like proof in CGA: provide [k]E0, challenge, response k + c*a_{i0}.

Complexity: O(n^2) messages, O(n) actions each ~ O(sqrt(p)) evaluations. Practical for n<=50.

## 5 Empirical/Proofs

### Security Proof Sketch

Game 0: Real TS-UF-4.

Game 1: Replace ROM with programmable oracle, simulate DKG using Feldman VSS simulator. Under DDH-CGA, adversary indistinguishable.

Game 2: Replace FROST nonce generation with ms-FROST masking. Use OMI oracle to simulate response isogenies without secret. Mask pads hide linear combination, using Lemma 4.2 - weighted threshold ROS unconditionally hard in ROM [3].

Reduction: given forger, extract two different signatures for same E1, different h. Difference yields endomorphism of E_A breaking EndRing [1] or vectorization solving a=vectorization(E0,E_A).

Formal steps use Forking Lemma: success prob eps => eps^2/q_H. Quantization via QROM uses Don-Cha-style lifting with compressed oracle.

```python
# q = class number prime
def verify_share(j: int, commitments: list, share: int, E0, q):
    exp = 0
    pow_j = 1
    for c in commitments:
        exp = (exp + pow_j * c) % q
        pow_j = (pow_j * j) % q
    return j_invariant(action(E0, exp)) == j_invariant(action(E0, share))

def lagrange_coeff(S, i, q):
    num = den = 1
    for j in S:
        if j == i: continue
        num = num * j % q
        den = den * (j - i) % q
    return num * pow(den, -1, q) % q
```

```rust
// FROST coordinator aggregation for isogeny threshold Rust sketch
use std::collections::HashMap;
pub struct Partial { pid: u32, exp_share: u64, torsion_images: Vec<u8> }

pub fn aggregate_signatures(partials: Vec<Partial>, lagrange: HashMap<u32,u64>, q: u64) -> Vec<u8> {
    let mut acc = 0u64;
    for p in &partials {
        let lambda = lagrange[&p.pid];
        acc = (acc + lambda * p.exp_share) % q;
    }
    let mut sig = Vec::new();
    for p in partials { sig.extend(p.torsion_images); }
    sig.push((acc & 0xFF) as u8);
    sig
}
```

## 6 Limitations

1. Trusted Setup of Orientations: Generation of oriented starting curve E0 with known orientation but unknown endomorphism needs trusted CM; updatable CRS needed.

2. Class Group Size and Quantum Security: Kuperberg quantum hidden shift finds a in 2^{O(sqrt(log N))} queries, requiring N >= 2^{512} for 128-bit PQ security, inflating p to ~2000 bits, degrading performance. EndRing still provides extra hardness but not formally reduced.

3. Non-Abelian Masking Gap: Masking assumes isogeny response randomization preserves zero-knowledge when decomposing sum of squares in dim 8. Formal proof requires uniform distribution of (a1..a4) over Lagrange sphere, only heuristic [1] Appendix C. Rejections in dim 4 amplify stutter.

4. DKG Communication: O(n^2) actions -> n=100 impractical (>10 min). Need aggregatable PoKs or SNARK compressing evaluations.

5. Rogue Torsion Attack: Malicious participant can send incorrect sigma(P_k) that passes pairing compression but fails higher-dimensional verification subtly, causing selective abort leaking share via error oracle. Mitigation needs explicit torsion proof and stronger robustness TS-SUF-4.

## 7 Conclusion

We presented complete thesis blueprint for isogeny-based threshold signatures marrying SQIsignHD compact high-dimensional representation with FROST efficiency and standardization [4]. By embedding secrets into class group action on oriented supersingular curves, we linearized FROST share aggregation, enabling two-round threshold signing with dealer-free DKG proven in Pedersen-VSS style.

Resulting signatures remain aggregatable into single 1.38KB SQIsignHD signatures, verifiable by unmodified verifiers, key for blockchain adoption. While performance lags Schnorr due to isogeny costs, it positions isogeny threshold as viable for post-quantum custody where quantum adversaries threaten ECDSA shares.

Future: formally proving weighted isogeny ROS hardness unconditional in QROM, optimizing 8D isogeny verification in Rust with parallel (2,2)-chains, and building reference implementation integrated with IRTF draft [4]. Extending to adaptor signatures [2] yields payment-channel-ready threshold contracts. Once optimized, primitive could replace Shor-vulnerable ECDSA in MPC wallets with drop-in threshold APIs.
