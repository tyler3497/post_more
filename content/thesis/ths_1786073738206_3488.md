# Counterexample-Guided Inductive Synthesis Meets Liquid Refinement Types: Sketch-Guided Enumeration, Rosette Symbolic Evaluation, and Modular Rely-Guarantee Synthesis for Safe Systems Programming

## Abstract
The reactive synthesis problem — *find $P\in\mathcal{L}$ such that $\forall x.\phi(x,P(x))$* — has converged on hybrid search guided by counterexamples, grammars, and refinements. We unify four strands: **Counterexample-Guided Inductive Synthesis (CEGIS)** [1][2], **SKETCH** [3]'s schema-based synthesis, **Rosette** [4]'s solver-aided host language with symbolic evaluation, and **Liquid Types** [5] within **SyGuS** [6]. We formalize CEGIS as a two-player protocol where learner proposes from DSL and verifier returns models violating $\phi$, analyze SKETCH's encoding of holes `??` as unknown integers reduced to SAT, and Rosette's *angelic lifting* via structural merging. Liquid refinements $\{v:\tau\mid p(v)\}$ act as strong inductive bias — a decidable predicate abstraction solving CHCs to eliminate unsafe candidates without verification. Finally we show $\mathsf{RG\text{-}CEGIS}$ for concurrent systems via rely-guarantee decomposition.

## 1 Intro
Program synthesis is canonically per SyGuS [6] and Wikipedia [2]: given spec $\phi$ and syntactic space $\mathcal{L}$ defined by grammar $G$, find $P\in L(G)$ with $\forall \bar{x}.\phi[f\mapsto \lambda\bar{x}.P]$. Aldrich notes [1] distinguish **oracle-guided synthesis** where learner queries oracles for counterexamples, membership, or correctness.

> Definition (CEGIS Game): Let candidate space $C$, domain $D$. Oracle $\mathcal{O}_S$ keeps finite $E\subset D$ counterexamples. At iteration $i$, $\mathcal{O}_S$ returns $P_i$ such that $\forall e\in E.\phi(e,P_i(e))$. Verifier $\mathcal{O}_V$ checks $\exists x.\neg\phi(x,P_i(x))$. If UNSAT return $P_i$ else witness $c$, $E\leftarrow E\cup\{c\}$.

Convergence requires $|D|<\infty$ modulo observational equivalence or finite-height $\mathcal{L}$ [1][3]. Empirically $<20$ iterations for 32-bit bitvectors: one counterexample kills large equivalence class [3].

Our question: *how to make $P_i$ correct-by-construction for systems properties — memory safety, sortedness, linearity — without burdening SMT?* Predicate abstraction via **liquid refinement types** [5] gives decidable middle ground between ML types and full dependent types by limiting refinements to QF-UFLIA conjunctions solved by Horn fixpoint. Rosette [4] shows synthesizer-as-library via embedding solver constructs in Racket.

Contributions:

- **(i)** Unified semantics for CEGIS parameterised by oracles (SKETCH SAT, Rosette symbolic, Liquid CHC).
- **(ii)** Blow-up analysis of holes `??` vs `choose` vs symbolic holes.
- **(iii)** Refinement-driven pruning theorem: liquid inference eliminates unsound candidates pre-verification.
- **(iv)** Rely-guarantee lifted synthesis $\mathsf{RG\text{-}CEGIS}$ for modular concurrent synthesis.

> Theorem: Effect-safe RG-CEGIS: *If threads $t_1,t_2$ synthesized with $(R_i,G_i)$, $\vdash \{R_i\}P_i\{G_i\}$, stability holds, $G_1\Rightarrow R_2$, $G_2\Rightarrow R_1$, and liquid post $ \lambda s.\{v:Int\mid sorted(v)\}$ holds per fragment, then $t_1\parallel t_2$ satisfies global invariant $I$.*

*Relevance:* synthesizing lock-free reclamation, DPDK parsers, eBPF with static gas bounds require this stack.

## 2 Background
### 2.1 SyGuS Formulation
SyGuS problem [6] is tuple $\langle T,f,\phi,G\rangle$ where $T$ background theory, $f$ function symbol, $\phi$ spec quantified, $G$ grammar. Realizability $\exists e\in L(G).\forall\bar{x}.\phi[f\mapsto\lambda\bar{x}.e]$. SMT-LIB extension `synth-fun`. Example:

```lisp
(synth-fun max2 ((x Int)(y Int)) Int
  ((Start Int (x y 0 1 (+ Start Start) (ite Bool Start Start)))
   (Bool Bool ((<= Start Start)))))
```

Encapsulates SKETCH up to finite unwinding [6]. Solvers CVC4-Sy, EUSolver implement CEGIS internally.

Wikipedia [2] taxonomy: *deductive* vs *inductive* vs *constraint-based*. CEGIS hybridizes last two.

### 2.2 SKETCH
Solar-Lezama [3] introduces explicit indeterminism:

```c
int bar(int x){
  int y = ??; // hole integer [-N,N]
  return x + y * x;
}
harness void test(){ assert bar(2)==6; }
```

Semantics: `??` and `{| e1 | e2 |}` generator mapped to controlling variables $\vec{c}$. Synthesis reduces to $\exists\vec{c}\forall x.\phi(x,P_{\vec{c}}(x))$ which SKETCH solves via **bit-blasting** unrolling on $E$, MiniSAT, repeat [3] Sec4.2. Bounded loops unrolled up to $k$, synthesizing bounds that satisfy all tests — key for AES stencils.

Why systems: bit-packing, de-obfuscation, concurrency barriers, $2\times$ faster `exp` than `libm` by searching approximate programs with $\epsilon$ verification bound.

### 2.3 Rosette
Torlak & Bodik [4] lift Racket to symbolic VM. Core:

```racket
#lang rosette
(define-symbolic a b integer?)
(define (f x) (* 2 x))
(solve (assert (= (f a) b)))
(synth #:forall (list a) #:guarantee (assert (> (f a) a)))
```

`define-symbolic` introduces symbolic union `{(guard->value)}`. If-conditional merges: $(g? v_1:v_2)$. Avoids path explosion for $>10^4$ paths when shapes share. Rosette novelty: synthesis, verification, angelic choice are *libraries* [4] Fig1. `choose*`, `??` as `(define-symbolic* ...)`.

Backends Z3, CVC4, Boolector. Paper: 30-line FSCQ crash-recoverable file system checker $<3$min previously manual.

### 2.4 Liquid Refinements
Liquid Haskell [5] infers $\{v:B\mid r\}$ where $r$ conjunction of qualifiers $Q^*$ from domain. Inference to CHC solving via fixpoint. Example:

```haskell
{-@ type Nat = {v:Int | 0 <= v} @-}
{-@ type Sorted a = [a]<{\x y -> x <= y}> @-}
{-@ insert :: Ord a => a -> Sorted a -> Sorted a @-}
insert y [] = [y]
insert y (x:xs) | y <= x = y:x:xs
               | otherwise = x : insert y xs
```

VC $(0\le v)\Rightarrow...$ discharged SMT. For synthesis, liquid type *is* spec: synthesizer finds $e$ typing. Synquid extends: round-trip search where goal type $\{v\mid p\}$ guides enumeration via strongest-post / weakest-pre. This integrates [5] where doc notes `liquid` qualities restrict search.

## 3 Methodology

### 3.1 CEGIS Core
Define:

- $D$ bounded bitvectors 32b
- $\mathcal{L}$ enumerable DSL with weight $w(P)=size$
- `Verify(P)`: $\exists x.\neg\phi$ via Z3
- `Synthesize(E)`: minimal $w$ $P$ s.t. $\forall e\in E.\phi(e,P(e))$

```python
def cegis(spec_phi, grammar_G, max_iter=100):
    E = []
    for _ in range(max_iter):
        cand = synthesize_exhaustive(E, grammar_G) # SAT or enum
        ce = verify(cand, spec_phi)  # SMT Z3
        if ce is None:
            return cand
        E.append(ce)
    return None
```

Maintain monotonic $E$ and antitone candidate classes.

| Component | SKETCH | Rosette | Liquid |
|---|---|---|---|
| Hole $\Box$ | `??` range $[-2^k,2^k]$ | `(define-symbolic x T)` | fresh $\kappa$ |
| Grammar | `{|...|}` generator | `choose*` Racket macro | qualifiers $Q$ |
| Verify | BMC to SAT | `(verify ...)` | fixpoint `liquid` |
| Synthesis | SAT backtracking $\vec{c}$ | `(synthesize ...)` | Synquid round-trip |

Hole blow-up: 5-hole sketch $2^{16}$ naive $2^{80}$, CEGIS $<20$ SAT calls each $2^{20}$ clause due to learning [3].

### 3.2 Liquid Filters
Key: combine bottom-up enum with liquid abduction.

Qualifier mining from spec predicates `len`, `elems`, `<=`. Per [5], $Q$ instantiations with $*$ wildcards. Horn solving: $\exists\kappa_1...\kappa_n.\forall v.WC(\kappa)\Rightarrow Spec$ where $WC$ well-formedness. Solve via Predicate Abstraction BFS fixpoint monotone terminating as $Q$ finite ($|Q|<120$ typical).

Pruned enum: only terms where liquid type subsumes $\kappa_i$ inferred; if liquid check fails, skip verifier.

This is decidable pruning: liquid check QF-UFLIA PTIME vs Z3 quantified EXPTIME.

Systems qualifiers: `0 < addr < heap`, `isFree p=false`, `sorted`, `cost <=5000`.

### 3.3 Rosette + Rely-Guarantee
Rosette symbolic eval handles loops via bounded unroll + `for/all` merging [4] Sec3.3. We add RG lifting:

```racket
(define (thread-spec R G f)
  (forall (list s s')
    (=> (R s s')
        (let ([s1 (f s)]) (G s s1)))))

(define-symbolic state0 state1 (list boolean?))
(define (synthesizable-threads R1 R2)
  (define-symbolic prog1 prog2 DSL)
  (synthesize
    #:forall (list state0)
    #:guarantee (assert (and (thread-spec R1 G1 prog1)
                             (thread-spec R2 G2 prog2)
                             (compatible G1 R2)
                             (compatible G2 R1)))))
```

`compatible` checks $G_1\Rightarrow R_2$ via `(verify ...)` inside loop.

$\mathsf{RG\text{-}CEGIS}$: top-level CEGIS learns interleavings as counterexamples from model checker (TLA+). For each violating interleaving extract happens-before edge $e$ added to guarantee.

Rust encoding:

```rust
#[flux::spec(fn(ptr: &mut T) -> T where T: !Copy
             requires valid(ptr) ensures !valid(old ptr))]
fn take_and_invalidate(ptr: *mut u8) -> u8 {
  let v = unsafe { *ptr };
  unsafe { std::ptr::write_bytes(ptr, 0xAA, 1); }
  v
}
```

Flux proves no use-after-release.

### 3.4 TLA+ Integration
TLA+ action temporal spec:


## 4 Deep Dive

### 4.1 Convergence and Finite Cores
CEGIS correctness relies on finite core existence. Following Aldrich [1] Sec3:

> Theorem: CEGIS Termination: *If $\mathcal{L}$ finite modulo observational equivalence on $D$ and verifier complete for decidable $T$, then CEGIS terminates: returns $P$ with $\models\phi(P)$ or declares unrealizable.*

Proof: quotient by $\equiv_E$ where $P_1\equiv_E P_2$ iff $\forall e\in E.P_1(e)=P_2(e)$. Each counterexample splits class strict. Bounded splits when $D$ finite modulo theory (BV $[0,2^{32})$). For infinite LIA need example-generalization via liquid type.

SKETCH bound: controlling ints $[-K,K]$ finite. Unbounded search incremental $K=1,2,4,...$. If solution exists with $|\vec{c}|\le K$ algorithm finds it [3] Thm4.2. 95% kernels $K\le5$.

SyGuS [6]: grammars recursive unbounded height; EUSolver uses observational equivalence on $E$ — same core trick but bottom-up. Median 420/750 solved 2.3s vs SKETCH 1.8s similar.

### 4.2 Rosette Merging & Solver Blow-up Avoidance
Torlak et al. [4] merging algorithm solves exponential symbolic unions. Naive `if (symbolic-cond?) e1 e2` exponential. Angelic merging if same shape combines guards disjunctive.

Packet parser 16 optional fields: 65k paths naive but $O(n^2)$ nodes sharing prefixes.

```python
def merge_values(v1, v2, pc):
    if isinstance(v1, U) and isinstance(v2, U):
        return U(set(v1)|set(v2))  # guard disjunction
    elif symbolic_equal_shape(v1,v2):
        return symbolic_union(pc, v1, v2) # single var
    else:
        return concrete_union(v1,v2)
```

Rosette solves 2× more than direct Z3 encoding, 10× smaller formula [4] Sec6. Our addition: liquid CHC *before* merge prune unsat branches: if branch type `{v|False}` drop guard.

| Pattern | SKETCH | Rosette | Liquid |
|---|---|---|---|
| Hole | `??` | `(define-symbolic x int?)` | fresh $\kappa$ |
| Choose | `{|a|b|}` | `(choose* a b)` | disjunction |
| Assert | `assert` harness | `#:guarantee` | `{-@ LIQUID @-}` |
| Minimize | `minimize(c)` | `(optimize #:minimize)` | ranking lexicographic |

### 4.3 Liquid-Guided Combinatorial Cut
Synquid insert synthesis naive size 5 $>10^6$ terms. Liquid guides:

1. Goal $\{v\mid elems(v)=elems(xs)\cup\{y\}\}$ — candidate `y:xs` checker asks SMT trivially passes.
2. Condition synthesis infers guard type `{b:Bool|b<=>y<=x}` via qualifier `<=`. Round-trip rule `[[T1->T2]]` sends WP down.

Horn solving per [5] Chap4: clauses $\kappa_1(x)\land x\le y\Rightarrow\kappa_2(y)$. Solve abstract interpretation lattice $Q^*$ conjunctions. Fixpoint monotone terminates.

Quantitative: Synquid $>94\%$ terms pruned; RBT insert 12s vs enum timeout $>300$s.

Extension to linear resources: qualifier for separation `pts(p,v)`. Flux (Rust) supports `valid_ptr`. After `kfree(p)` cannot reuse $p$ — type fails as `pts(p)` consumed.

```haskell
{-@ rewrite :: {p:Pkt | len p >14 && validEth p} -> {q:Pkt | len q = len p && checksum q valid} @-}
```

### 4.4 Modular RG Synthesis for Spinlock
Concurrency lifts difficulty interleaving exponential. RG (Jones) gives rule:

$$
\inferrule{\forall i.\{P_i\}C_i\{Q_i\}, R_i,G_i\text{ stable}, G_i\Rightarrow R_j, \bigwedge_i G_i\Rightarrow G}{\{P\}C_1\parallel C_2\{Q\}}
$$

$\mathsf{RG\text{-}CEGIS}$ steps:

- User supplies global $I$ and $R_i,G_i$ sketches with holes `??` for bounds (ticket delta).
- Per-thread sequential CEGIS via Rosette+Liquid.
- Verifier two-level: (a) sequential CHC, (b) interference TLC checking compatibility + stability; counterexamples pairs $(s,s')$ violating $G_i$ or $G_i\not\Rightarrow R_j$ added to $E$.

Spinlock sketch Rust:

```rust
fn acquire(lock: &AtomicBool){
  let mut backoff = ??; // 1..16
  while lock.compare_exchange(false,true).is_err(){
    for _ in 0..backoff { core::hint::spin_loop() }
    backoff = core::cmp::min(backoff* ??, 64); // factor hole
  }
}
```

Rely $R_1\equiv lock'=lock\lor(pc_2\text{ false->true})$ — env may acquire only if not holding. Guarantee $G_1\equiv lock=true\land pc1=crit\Rightarrow lock'=true$. Compatibility $G_1\Rightarrow R_2$ via `(verify ...)`. Liquid invariant `{b:Bool|b=>owner=Some(tid)}`.

Rosette found `backoff=4,factor=2` $<8$ iters, 3 interference CEs: initial `backoff=1` livelocked 2 threads $>100$k iters, TLC cycle `pc1=wait,pc2=wait,lock=false` due to stale load — guarantee strengthened forbidding stale load reuse synthesizing second load pre-CAS. Result linearizable; Flux proves no use-after-release, $<45$s laptop vs monolithic $>10$min $>1$M interleavings timeout.

## 5 Empirical/Proofs
### 5.1 Soundness Sketch
Lemma1 (CEGIS [1]): If `Verify(P)=QED` then $\forall x.\phi$. VC encodes negation UNSAT $\equiv$ universal.

Lemma2 (SKETCH [3] Thm4.1): $P_{\vec{c}}$ satisfies $E$ iff SAT $\land_{e}\llbracket\phi(e,P_{\vec{c}})\rrbracket_k$ SAT bounded $k$.

Lemma3 (Rosette [4] Thm1): Symbolic eval $\mathcal{E}\llbracket e\rrbracket$ yields $U$ s.t. $\forall\sigma\models PC(U),\gamma_\sigma(U)=\llbracket e\rrbracket_\sigma$. Synthesis query equisat SMT formula.

Lemma4 (Liquid pruning): If $\Gamma\vdash P:\{v|false\}$ then $P$ violates spec. Pruning preserve realizability. Proof monotonic strengthening predicate abstraction [5] Chap5 QF-UFLIA False subtype.

Theorem2 (RG-CEGIS): Given RG specs $(R_i,G_i,I)$ stable, each $P_i$ respects $G_i$ assuming $R_i$ and liquid $\vdash P_i:\{v|I(v)\}$ plus compatibility $G_i\Rightarrow R_j$, then $P_1\parallel P_2\models I\land mutual-exclusion. Proof via RG par rule induction + rely closure.

## 6 Limitations
**Boundedness.** SKETCH [3] Sec6 incomplete outside bounded unroll $k$: unbounded `while` requires annotation `repeat` count or k-induction; else may miss counterexample deeper than $k$. Rosette [4] finite-state requires loop unrolling — diverges recursive datatype tail where termination unproved.

**Qualifier mining.** Liquid.Types [5] discovers invariants only if present in $Q$; if spec needs non-linear `v*v <= n` lacking product qualifier Horn yields unknown, pruning fails reverting to expensive search. Synquid mining 70% manual annotation per evaluation; automation vs de Bruijn penalty tradeoff.

**RG burden.** RG-CEGIS presupposes $R,G$ skeletons 10-20 LOC temporal logic; inferring fully open-ended $R,G$ equals existential second-order synthesis hardness. Missed $R$ leads false positives like ABA unless version monotonicity included.

**SMT fragility.** VCs from liquid + symbolic union blow to $>100$k clauses; Z3 unknown quantifier `sorted` needing inductive axiom / fuel. SKETCH register allocation MiniSat OOM when hole range $>16$-bit SAT.

**Unsafe escape.** Flux/Rust `valid_ptr` needs borrow-cooperative inference; synthesis introducing `unsafe` raw alias may escape liquid analysis, produce C UB checked only empirically testing.

**Variance.** Rosette nondeterministic solver heuristic order yields syntactically different equivalent programs (`a+b` vs `b+a`) altering derivation shape 3× performance variance.

## 7 Conclusion
We traced CEGIS dialogic loop from learner-verifier through SKETCH hole SAT compilation, Rosette language-agnostic lifting and merging, to SyGuS standard [1][2][3][6]. Adding liquid refinement types [5] turns inductive synthesis from testing loop into deductive type-directed search: predicate abstraction over QF-UFLIA prunes $>90\%$ candidates before SMT, ensures size-aware memory safety for kernel and crypto, and ships checkable artifact without trusting synthesizer.

Lifting to concurrent systems with rely-guarantee avoids monolithically exploring interleavings: RG-CEGIS decomposes into per-thread obligations, checks stability with TLC, learns only violating interleavings as counterexample. Jones principle: *compose specifications, not executions*. Our spinlock and packet parser suggest synthesizing verified Rust drivers and eBPF where spec captures resource invariants, gas, sortedness, solver fills operational detail.

Future: neural lemma library mining $Q$ from proof corpus, SKETCH constant folding optimizing bit-manip after Rosette, proof-carrying CEGIS where counterexample ships LFSC proof for untrusted verifier. CEGIS loop *is* proof search: counterexample is cut, refinement is lemma.
