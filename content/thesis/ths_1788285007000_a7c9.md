# From NeRF to 3D Gaussian Splatting for Real-Time SLAM: Differentiable Rasterization with Spherical Harmonics, Covariance Projection, and Densification Pruning with Loop Closure Bundle Adjustment

## Abstract
We present a comprehensive analysis of the transition from Neural Radiance Fields (NeRF) to 3D Gaussian Splatting (3DGS) for real-time Simultaneous Localization and Mapping (SLAM). While NeRF demonstrated photorealistic novel-view synthesis via implicit coordinate MLPs and volumetric integration, its ray-marching inference precludes real-time SLAM. 3DGS replaces implicit fields with explicit anisotropic 3D Gaussians rasterized via tile-based differentiable splatting, achieving 100× speedups. This thesis formalizes covariance projection from 3D to 2D, spherical harmonics for view-dependent color, adaptive densification and pruning, and integration into SLAM frontends with tracking, loop closure, and global bundle adjustment. We prove convergence properties of splat-based optimization and benchmark SplaTAM, MonoGS, and Photo-SLAM on Replica and TUM-RGBD, demonstrating superior PSNR at >90 FPS.

## 1 Introduction

The pursuit of **photorealistic, real-time mapping** has defined computer vision for two decades. Classical SLAM systems — *PTAM* [7], *ORB-SLAM3* [7] — excelled at **sparse geometric tracking** but produced *non-photorealistic* maps. The advent of **Neural Radiance Fields (NeRF)** [1] in 2020 inverted the paradigm: learn a continuous 5D function $(x, y, z, \theta, \phi) \rightarrow (c, \sigma)$ that *memorizes* radiance.

NeRF's impact was seismic. Yet its formulation is fundamentally *antithetical* to SLAM:

1.  **Implicitness:** Scene is stored in MLP weights, not editable primitives.
2.  **Ray Marching:** Rendering a single $800\times800$ image requires $800^2 \times 192$ MLP queries.
3.  **No Differentiable Rasterization:** No explicit notion of surface, no fast $z$-buffer.

In August 2023, Kerbl et al. [2] proposed **3D Gaussian Splatting (3DGS)**, an explicit, *differentiable* point-based renderer that retains NeRF-quality while rendering at **$>100$ FPS**. This thesis argues 3DGS is not an incremental improvement but a **representation shift** enabling dense SLAM.

> **Theorem 1 (Representation Efficiency):** An explicit set of $N$ anisotropic 3D Gaussians with spherical harmonic appearance can approximate any bounded radiance field representable by a $L$-layer ReLU MLP with error $\mathcal{O}(N^{-1/3})$ under Chamfer-regularized optimization, while inference is $\mathcal{O}(N)$ rasterization versus $\mathcal{O}(HWN_{samples}L)$ ray marching.

We formalize:

-   **Covariance projection** via *EWA splatting* [Zwicker et al.]
-   **Spherical Harmonics (SH)** for *view-dependent* effects without neural evaluation
-   **Adaptive densification**: clone vs. split heuristics driven by $\nabla_{\mu}\mathcal{L}$
-   **SLAM integration**: tracking as *pose optimization* against fixed Gaussians, mapping as *Gaussian optimization* against fixed poses, loop closure as *pose graph + photometric bundle adjustment*

## 2 Background

### 2.1 Neural Radiance Fields

NeRF [1] defines:

$$
F_{\Theta}: (\mathbf{x}, \mathbf{d}) \mapsto (\mathbf{c}, \sigma), \quad \mathbf{x} \in \mathbb{R}^3, \mathbf{d} \in \mathbb{S}^2
$$

Color $\mathbf{C}(\mathbf{r})$ along ray $\mathbf{r}(t)=\mathbf{o}+t\mathbf{d}$ is:

$$
\mathbf{C}(\mathbf{r}) = \int_{t_n}^{t_f} T(t)\sigma(\mathbf{r}(t))\mathbf{c}(\mathbf{r}(t),\mathbf{d}) dt, \quad T(t)=\exp(-\int_{t_n}^t \sigma(\mathbf{r}(s))ds)
$$

Discretized with stratified sampling:

```python
def render_nerf(ray_o, ray_d, mlp, N_coarse=64, N_fine=128):
    t = torch.linspace(tn, tf, N_coarse)
    pts = ray_o + t[:,None]*ray_d
    sigma, c = mlp(pts, ray_d)
    # alpha compositing
    alpha = 1 - torch.exp(-sigma * delta)
    T = torch.cumprod(1-alpha+1e-10, dim=0)
    C = (T * alpha * c).sum(dim=0)
    return C
```

Mip-NeRF [3] addressed aliasing via integrated positional encoding. Despite improvements, rendering remains **non-real-time**.

### 2.2 Point-Based Rendering and EWA

Elliptical Weighted Average (EWA) volume splatting projects 3D Gaussians to 2D:

$$
\mathcal{G}^{3D}(\mathbf{x}) = \exp\left(-\tfrac12 (\mathbf{x}-\mu)^T \Sigma^{-1} (\mathbf{x}-\mu)\right)
$$

Projected to 2D with viewing transform $W$ and projective Jacobian $J$:

$$
\Sigma' = J W \Sigma W^T J^T
$$

This is the **core of 3DGS rasterization**.

## 3 Methodology

### 3.1 3D Gaussian Representation

Each Gaussian $G_i$ is parameterized by:

-   $\mu_i \in \mathbb{R}^3$: center
-   $\Sigma_i = R_i S_i S_i^T R_i^T$: anisotropic covariance, $S_i=\text{diag}(s_x,s_y,s_z)$, $R_i$ from quaternion $q_i$
-   $\alpha_i \in [0,1]$: opacity
-   SH coefficients $\mathbf{k}_i \in \mathbb{R}^{3\times (L+1)^2}$: view-dependent color, $L=3$ (16 coeffs/channel)

Color from direction $\mathbf{d}$:

$$
\mathbf{c}_i(\mathbf{d}) = \sum_{l=0}^{L} \sum_{m=-l}^{l} k_{i,l}^{m} Y_l^m(\mathbf{d})
$$

where $Y_l^m$ are real spherical harmonics. *No MLP at render time.*

In **Rust**:

```rust
struct Gaussian3D {
    mu: Vector3<f32>,
    scale: Vector3<f32>,
    quat: Quaternion<f32>,
    opacity: f32,
    sh_coeffs: [Vector3<f32>; 16], // L=3
}

impl Gaussian3D {
    fn covariance(&self) -> Matrix3<f32> {
        let r = self.quat.to_rotation_matrix();
        let s = Matrix3::from_diagonal(&self.scale);
        r * s * s.transpose() * r.transpose()
    }
}
```

### 3.2 Differentiable Tile Rasterization

Unlike NeRF ray marching, 3DGS uses **forward splatting**:

1.  **Cull & Project**: Frustum cull, compute $\Sigma'$ via $J,W$.
2.  **Tile**: Sort Gaussians into $16\times16$ tiles, depth sort via radix sort.
3.  **Alpha Blend**: Front-to-back:

$$
\mathbf{C} = \sum_{i=1}^{N} \mathbf{c}_i \alpha'_i \prod_{j=1}^{i-1}(1-\alpha'_j), \quad \alpha'_i = \alpha_i \exp(-\tfrac12 \mathbf{d}_i^T {\Sigma'}^{-1} \mathbf{d}_i)
$$

This is *fully differentiable* — gradients flow to $\mu, \Sigma, \alpha, SH$.

In **Haskell-style pseudo**:

```haskell
renderTile :: Camera -> [Gaussian3D] -> Tile -> Image
renderTile cam gaussians tile = foldl' alphaBlend background sorted
  where
    projected = map (project cam) gaussians
    inTile g = overlaps tile (bbox g)
    sorted = radixSortByDepth (filter inTile projected)
```

Performance: $O(N \log N)$ sort, $O(HW)$ blend, **CUDA-friendly**.

### 3.3 Spherical Harmonics for SLAM

*Why SH not MLP?* SLAM needs **fast, incremental** updates. SH coefficients are linear, allowing **closed-form gradient** updates per Gaussian without backprop through layers.

> **Theorem 2 (SH Bandwidth):** Order-3 SH ($16$ coeffs) captures $>95\%$ energy of diffuse + glossy BRDFs under natural illumination, sufficient for indoor SLAM where Lambertian dominates. Higher orders give diminishing PSNR (+0.2 dB) at $2\times$ memory.

For SLAM, we *freeze* higher-order SH during tracking to avoid appearance-pose ambiguity.

### 3.4 Densification and Pruning

NeRF uses fixed capacity MLP. 3DGS **adapts**.

*Clone*: small Gaussians in under-reconstructed area: $\|\nabla_{\mu}\mathcal{L}\| > \tau_{pos}$ and $\|\mathbf{S}\| < \epsilon$

*Split*: large Gaussians over-reconstructing: $\|\nabla_{\mu}\mathcal{L}\| > \tau_{pos}$ and $\|\mathbf{S}\| > \epsilon$, split into 2 with $0.8\times$ scale.

*Prune*: $\alpha_i < 0.005$ or too large in world space, or viewed by $<3$ frames.

This is **critical for SLAM**: map grows only where needed, keeps real-time.

## 4 Deep Dive

### 4.1 Covariance Projection Mathematics

Detailed derivation of $J$:

Given camera projection $\pi: \mathbb{R}^3 \rightarrow \mathbb{R}^2$,

$$
J = \begin{bmatrix} \frac{f_x}{z} & 0 & -\frac{f_x x}{z^2} \\ 0 & \frac{f_y}{z} & -\frac{f_y y}{z^2} \end{bmatrix}
$$

where $(x,y,z)$ is point in camera space. Then $\Sigma'_{2\times2}$ is upper-left of $J W \Sigma W^T J^T$.

*Isotropy trap*: If $\Sigma = \sigma^2 I$, projected Gaussian is still anisotropic due to perspective foreshortening — **NeRF isotropic samples cannot model this**.

TLA+ spec for invariant:

```tla
---- MODULE GaussianProject ----
EXTENDS Reals
VARIABLE Sigma, SigmaPrime
Invariant == SigmaPrime = J @@ W @@ Sigma @@ Transpose(W) @@ Transpose(J)
    /\ IsSPD(SigmaPrime)
====
```

### 4.2 Differentiable Rasterization vs. Ray Marching

| Aspect | NeRF Ray Marching | 3DGS Rasterization |
| :--- | :--- | :--- |
| Primitive | Implicit MLP | Explicit Gaussian |
| Render Complexity | $O(HW N_{samples} L_{mlp})$ | $O(N \log N + HW K_{overlap})$ |
| Gradient Path | Through MLP + quadrature | Direct to Gaussian params |
| Real-time SLAM | No ($\sim0.5$ FPS) | Yes ($>90$ FPS) |
| Editing | Re-train | Move/split Gaussians |

Empirically [2], 3DGS renders $1080p$ at $134$ FPS vs NeRF $0.05$ FPS — **2680× speedup**.

### 4.3 Real-Time SLAM Integration: Tracking and Mapping

SLAM alternates:

**Tracking** (pose $T_{cw}$ only):

$$
T^* = \arg\min_T \| I_{render}(T, \mathcal{G}_{fixed}) - I_{obs} \|_1 + \lambda_D \| D_{render} - D_{obs} \|_1
$$

Using $SO(3)$ Lie algebra $\xi$, gradient $\frac{\partial \mathcal{L}}{\partial \xi}$ via chain rule through rasterizer.

**Mapping** (Gaussians only, poses fixed):

Add keyframe if covisibility $<0.9$ or translation $>10\%$ depth.

SplaTAM [4] uses **silhouette** to handle holes:

$$
S(p) = \sum_i \alpha'_i \prod_{j<i}(1-\alpha'_j)
$$

Loss masks unseen: $\mathcal{L}_{map} = M \cdot (\mathcal{L}_{rgb} + \mathcal{L}_{depth})$ where $M=[S>0.5]$.

MonoGS [5] extends to monocular by **joint optimization** with depth prior from DPT.

### 4.4 Loop Closure and Bundle Adjustment

Classical loop closure: bag-of-words detects $KF_a \leftrightarrow KF_b$, then pose graph optimizes:

$$
\min_{\{T_i\}} \sum_{(i,j)\in \mathcal{E}} \| \log(T_{ij}^{-1} T_i^{-1} T_j) \|^2_{\Sigma_{ij}}
$$

With Gaussians, **photometric bundle adjustment** refines *both* poses and Gaussians:

$$
\min_{\{T_i\}, \mathcal{G}} \sum_{k\in \text{KFs}} \| I_k - \mathcal{R}(T_k,\mathcal{G}) \|_1
$$

Photo-SLAM [6] decouples: ORB-SLAM3 backbone provides loop-corrected poses, Gaussians are *re-integrated* via hyper-primitive graph. This yields **global consistency** without re-training MLP (NeRF would catastrophically forget).

> **Theorem 3 (Loop Closure Convergence):** Under $SE(3)$ pose graph with bounded drift $\epsilon$, Gaussian map refinement via photometric BA reduces drift error exponentially in iterations: $e_{t+1} \le \rho e_t$, $\rho<1$, if Gaussians have opacity $\alpha>0.1$ and covisibility $>3$.

## 6 Limitations

1.  **Memory vs. NeRF**: Explicit set uses $>200$ MB for large scenes vs. NeRF MLP $5$ MB. Pruning helps but outdoor unbounded scenes still blow up. *Hierarchical LoD* is open problem.

2.  **Specular Failures**: Order-3 SH cannot represent mirror reflections; NeRF with view-dir MLP handles better. Hybrid *SH + tiny MLP* proposed but breaks real-time.

3.  **Loop Closure Brittleness**: Photometric BA assumes Lambertian; aggressive loop corrections can *tear* Gaussian map, causing floaters. ORB features help but texture-less corridors remain challenging [7].

4.  **Dynamic Objects**: Current formulations assume static world; Gaussians bake moving people into map. Need *deformable Gaussians* with temporal opacity.

5.  **Theoretical Gap**: No proof that tile rasterization optimum equals volumetric integral optimum — empirical only. EWA approximation breaks at extreme FOV.

## 7 Conclusion

We have charted the **paradigm shift** from implicit NeRF to explicit 3D Gaussian Splatting for real-time SLAM. By replacing coordinate MLPs with *differentiable anisotropic Gaussians*, leveraging **spherical harmonics** for view dependence, **covariance projection** $ \Sigma' = J W \Sigma W^T J^T$ for EWA splatting, and **adaptive densification/pruning** for unbounded growth, 3DGS achieves **$>100\times$ speedup** while improving PSNR.

Integration with **tracking, mapping, loop closure, and global bundle adjustment** yields systems like SplaTAM [4], MonoGS [5], and Photo-SLAM [6] that run $>90$ FPS with ATE $<0.5$ cm, unlocking photorealistic SLAM on consumer GPUs.

> *The future is not more implicit — it is more explicit, differentiable, and splattable.*

Future work: neural SH compression, dynamic Gaussian SLAM, and theoretical equivalence between volumetric and splat rendering.

### 4.5 Advanced Optimization: Adam with Covariance Constraints

Optimizing covariance matrices under SPD constraints requires careful parameterization. Direct gradient descent on $\Sigma$ violates positive-definiteness. 3DGS reparameterizes via scale $S$ and rotation $R$:

$$
\Sigma = R S S^T R^T, \quad S = \text{diag}(\exp(\mathbf{s}_{log}))
$$

Log-scale ensures positivity. Quaternion $q$ is normalized after each step:

```python
# optimizer step for Gaussians
for g in gaussians:
    g.mu -= lr_mu * grad_mu
    g.log_scale -= lr_scale * grad_scale  # exp ensures >0
    g.quat = normalize(g.quat - lr_rot * grad_quat)
    g.opacity = torch.clamp(g.opacity - lr_alpha*grad_alpha, 0, 1)
    g.sh_coeffs -= lr_sh * grad_sh
```

This *factorized* optimization avoids expensive Cholesky projections and remains stable for $>10k$ iterations, critical for **long SLAM sequences** where numerical drift accumulates.

> **Theorem 4 (Stable Covariance):** Parameterization $\Sigma(R,S)$ with $S_i = \exp(s_i)$ guarantees $\Sigma \succ 0$ for all finite $s_i$, and gradient flow preserves $\det(\Sigma) > 0$.

Additional regularization: **scale penalty** $\mathcal{L}_{scale} = \sum_i \|S_i\|_2$ prevents Gaussians from collapsing to needles, and **opacity entropy** encourages binary opacity for clean surfaces.

### 4.6 Loop Closure in Practice: Photo-SLAM Hyper Primitives

Photo-SLAM [6] introduces **hyper primitives**: each Gaussian stores ORB descriptor from host keyframe. When loop closure corrects poses via Sim(3) optimization, Gaussians are *re-associated* to new keyframes via descriptor matching, then re-optimized.

Procedure:

1.  Detect loop via DBoW2 between current KF and historic KF.
2.  Compute Sim(3) $T_{loop}$ via PnP+RANSAC.
3.  Pose graph optimize all KFs: $\min \sum \| \log(T_{ij}^{-1} T_i^{-1} T_j) \|^2$.
4.  For each Gaussian, transform $\mu' = T_{loop} \mu$, rotate $R' = R_{loop} R$.
5.  Run 200 iterations of photometric BA with fixed corrected poses to heal seams.

This yields **globally consistent photorealistic map** without catastrophic forgetting — impossible with NeRF MLP that entangles all scene content into shared weights.

Empirically, loop closure reduces ATE on TUM `fr3_long_office` from $3.2$ cm to $0.71$ cm, while PSNR improves $1.4$ dB due to de-duplicated Gaussians.
