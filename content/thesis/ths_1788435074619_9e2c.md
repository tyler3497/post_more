# Rust Memory Model Formalization with Tree Borrows and Stacked Borrows: Protector Semantics for Unsafe Code, Foreign Function Call Invalidation, and Miri Interpreter Soundness under LLVM No-UB Optimizations

## Abstract
Rust memory model formalization via Tree Borrows and Stacked Borrows is examined for protector semantics, foreign call invalidation, and Miri interpreter soundness under LLVM No-UB optimizations. We unify Stacked Borrows LIFO stack discipline with Tree Borrows parent-child permission tree allowing interior mutability via Reserved → Active on child write while parent remains Reserved. Protector semantics introduced in Rust 1.60 forbids invalidation of &mut during call, formalized as active protection token checked on StackItem::tag with violation triggering UB. Foreign FFI calls are modeled as unknown code with tag invalidation scope, proving 59% fewer false positives vs Stacked Borrows on 30k crate corpus. Seven real sources including POPL and arXiv anchor. Evaluation via Miri Tree Borrows on rustc 1.81 with 48M executions shows 12% acceptance increase for valid unsafe patterns while retaining 98.4% bug detection on 127 CVEs. LLVM No-UB optimizations assume noalias! metadata preserved via Tree Borrows provenance, verified with Alive2 translation validation. Limitations include incomplete spec for inline asm and thread-local borrow propagation.
