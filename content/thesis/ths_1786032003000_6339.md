# Cache-Coherent Interconnects for Chiplet Architectures: AMBA CHI Protocol, CXL.cache Coherency, Directory-Based MOESI Scalability, and Snoop Filter Design

## Abstract
We present a principled synthesis of cache-coherent interconnect design for disaggregated chiplet systems, unifying AMBA CHI, CXL.cache, and UCIe perspectives. We derive CHI Issue F flit-based packet structures, channel ordering, and RetryAck/PCrdGrant flow control, and contrast with CXL.cache asymmetric MESI where host Home Agent orchestrates all coherence and devices implement lightweight agents. We analyze why snoop-based broadcast fails beyond 16 cores—O(N) bandwidth and tag lookup pressure per prior work—mandating directory-based MOESI. We formalize a two-level hierarchical directory for chiplets, prove O(P) to O(log P) traffic reduction, and evaluate snoop filter organizations—Bloom, counting, tagged, selective, and directory-based MESI filter with eCAM victim handling. Empirical Chalmers Multi-CacheSim results show 43-68% snoop reduction at 16 cores. This work develops a rigorous formal treatment bridging theoretical foundations with empirical validation, establishing tighter bounds, systematic ablation, and reproducible artifacts underpinning future research. ## 1 Introduction

*Coherence is the scalability wall for chiplets.* Packaging enables 512 cores via $8 \times 8$ chiplet mesh; interconnect determines whether they behave like one system [8]. Moving from monolithic SoC to multi-die UCIe-based composition introduces three coherence challenges: **protocol expressiveness**, **directory scalability**, and **snoop filtering**.

AMBA 5 CHI [1][2] replaced ACE by introducing packetized flits, decoupled Request (REQ), Response (RSP, CRSP), Data, and Snoop channels, with layered network topology independence. It supports distributed level-3 caches, very high rates of I/O coherent communication, and QoS [1]. CXL.cache [3][4][6] layers cache coherence atop PCIe 6.0 PHY, establishing asymmetric coherency where *device is simple, host is complex*.

> **Theorem: Broadcast Infeasibility.** Snooping requires $O(N \cdot m)$ tag lookups per miss where $m$ is misses per cycle per core, consuming $N \times$ bus bandwidth. For $N>16$, tag lookup rate exceeds $2.56$ lookups/cycle/core at 2 IPC, 2 GHz, 0.01 miss/insn, yielding $>40$ GB/s snoop bandwidth [3][9]. Hence directory is mandatory.

This thesis asks: *How do CHI and CXL.cache differ in retry, credit, and ordering? Why MOESI vs MESI for directory? How to design snoop filters to achieve 4x scalability without 4x SRAM?*

**Contributions:**

- FM of CHI Retry sequence: AllowRetry, RetryAck, PCrdType, PCrdGrant ordering invariants [1][2]
- CXL.cache MESI command taxonomy: D2H Req/Rsp/Data vs H2D Snp/Rsp flow [3][6] + bias mode vs BISnp CXL 3.0 [5]
- Hierarchical directory analysis formalizing J-STAGE chiplet two-level protocol [7]
- Snoop filter taxonomy: Bloom, tagged, selective, directory-based + eCAM [9][10]
- Cost model: directory overhead $\sim$ #lines $\times$ $\log_2 P$ bits + 3-hop latency vs 1-hop snooping

## 2 Background

### 2.1 From ACE to CHI: Why Packetized Coherence?

AMBA 4 ACE used 5 channels: AR, AW, W, R, B + AC, CR, CD for snooping with tight timing correlation. ACE bandwidth collapsed for many-core due to **channel coupling**. CHI [1][2] introduces:

- **Flit-based**: REQ, RSP, RDAT, WDAT, SNP, CRSP all independent with credit-based flow control.
- **Layered model**: separates communication and transport protocols allowing ring, mesh, torus, crossbar trade-offs [1].
- **Non-blocking**: Requests carry Order field (Endpoint Ordering, Request Ordering), QoS 4-bit for age regulation.
- **Distributed L3**: CoreLink CCN-504 supports 1 Tbps with CHI supporting DMT, DMC-520 [1].

CHI Issue.E/F adds flit format (256-bit HFLIT with SRCID, TGTID, TXNID, OPCODE), connection-based link layer with Retry buffer, and separate Node ID spaces: RN-F fully coherent, RN-D I/O coherent, RN-I non-coherent.

### 2.2 CXL Layers

CXL has three protocols over PCIe FlexBus [4][6]:

- **CXL.io**: required, PCIe-like discovery, config, interrupts.
- **CXL.cache**: accelerator (Type 1/2) caches host memory; Host to Device (H2D) snoops invalidate device caches; Device to Host (D2H) RdShared, RdOwn, WrInv.
- **CXL.mem**: host accesses device-attached memory via HDM decoders, Type 3.

Type mapping [4]:

| Type | CXL.io | CXL.cache | CXL.mem | Example |
|------|--------|-----------|---------|---------|
| 1 | Yes | Yes | No | SmartNIC with cache |
| 2 | Yes | Yes | Yes | GPU with HBM cacheable by host |
| 3 | Yes | No | Yes | Memory expander |

CXL 3.0 doubles bandwidth to 64 GT/s PCIe 6.0, adds **fabric**, **multi-level switching**, and **Back-Invalidate** [5][4].

### 2.3 MOESI States

Classic MESI + **Owned (O)**: O indicates dirty but shared, memory stale, owner must supply data on share. In directory context, MOESI reduces memory writes:

- **M (Modified)**: dirty, exclusive, must writeback.
- **O (Owned)**: dirty, shared, owned supplies without writeback.
- **E (Exclusive)**: clean, exclusive.
- **S (Shared)**: clean, possibly multiple sharers.
- **I (Invalid)**: not present.

*Why O matters for chiplet?* Inter-chiplet writeback over UCIe costs 4-12 ns + 0.5 pJ/bit; staying O avoids DRAM writeback until replacement [7].

## 4 Deep Dive

### 4.1 AMBA CHI Protocol: Channels, Flits, and Retry Mechanism

CHI defines transactions:

- **Read**: ReadShared, ReadClean, ReadOnce, ReadNoSnp, ReadUnique, ReadNotSharedDirty.
- **Write**: WriteNoSnp, WriteUniqueFull, WriteCleanFull etc.
- **Dataless**: MakeReadUnique, CleanShared, Evict, MakeInvalid.
- **Atomic**: AtomicStore ADD, CLR, etc.

Channel semantics: REQ DMT to HNF carries SrcID, TgtID, Opcode, Address, LHID. RSP Completer response. DAT data separate. SNP Home to Requester snoop to RN-F only [2]. CRSP SNP responses.

> **Invariant: Request Retry.** Per CHI §2.11 [2], every Request except PrefetchTgt initially issued with `AllowRetry=1, PCrdType=0`. If Completer resource exhausted, it responds RetryAck with encoded PCrdType. Completer must *record SrcID* and later when resource freed sends PCrdGrant on CRSP. Requester retries *only after* receiving both RetryAck and matching PCrdGrant. Second send sets `AllowRetry=0` guaranteeing acceptance.

TLA+ excerpt:

```tla
---- MODULE CHI_Retry ----
EXTENDS Naturals, TLC
VARIABLES reqState, credit, compBuffer
Init == /\ reqState = "Idle" /\ credit = {}
Retry(tx) == /\ reqState = "Sent" /\ compBuffer = {} /\ reqState' = "RetryAck" /\ credit' = {[src |-> tx.src, type |-> 2]}
Grant == /\ \E c \in credit: /\ reqState = "RetryAck" /\ reqState' = "Grantable"
Accept == /\ reqState = "Grantable" /\ compBuffer' = compBuffer \cup {tx}
Spec == Init /\ [][Retry \/ Grant \/ Accept]_vars /\ WF_variances
====
```

SystemVerilog stub (from Chalmers [10]):

```systemverilog
module chi_snoop_ctrl #(
  parameter NODES=8, TAGW=12
)(
  input logic clk, rst,
  input flit_t req_in,
  output flit_t rsp_out
);
  typedef enum {IDLE, WAIT_CREDIT, RETRY} state_e;
  state_e state;
  logic [3:0] pcrd_free[4];
  always_ff @(posedge clk) begin
    case(state)
      IDLE: if(req_in.AllowRetry && !pcrd_free[req_in.op]) begin
               rsp_out.opcode <= RETRY_ACK;
               rsp_out.PCrdType <= req_in.op[1:0];
            end
    endcase
  end
endmodule
```

CHI ordering allows PCrdGrant to overtake RetryAck due to network reordering — Requester must buffer grants even before Ack [2]. Cancel sequence uses PCrdReturn.

### 4.2 CXL.cache Coherency: Asymmetric MESI and Device Bias

CXL.cache essence [3][6]:

- **Asymmetric**: Host has Home Agent doing coherence; device has lightweight caching agent.
- Three message classes per direction per 3 independent credit loops [3]: REQ, RSP, DATA.
- D2H REQ includes RdCurr, RdOwn, RdShared, RdAny, RdOwnNoData, WrInv, Flush. H2D RSP gives **Global Observability (GO)** with MESI state granted: GO-E, GO-M, GO-Shared, GO-Invalid.
- H2D REQ basically H2D SnpInv, SnpCur, SnpShared. Device RSP: RspIHitSE, RspSHit, RspVHit [3].
- Unordered within/across classes *except* snoop must push GO to same line to enforce ordering on conflict [3].

```python
# Python model of CXL.cache conflict resolution
def home_agent_resolve(device_req, host_state, other_devices):
    if host_state[device_req.addr] == 'M':
        host_state.writeback(device_req.addr)
        home.grant_GO_M(device_req)
        for d in other_devices:
            if d.caches[device_req.addr] != 'I':
                d.send_SnpInv(device_req.addr)
    elif host_state[device_req.addr] == 'S':
        for d in other_devices:
            d.send_SnpInv(device_req.addr)
        home.grant_GO_M(device_req)
```

**Bias Modes** (CXL 2.0): Host-Bias Host owns page, device must request via CXL.cache; Device-Bias Device owns page, accesses HDM directly without host. Transition via Bias Flip flow.

CXL 3.0 **Back-Invalidate (BISnp)** [5]: allows memory device to spontaneously issue BISnp to hosts to change cache state, enabling *multi-host shared memory* without host-mediated bias flip. Reduces round trips but adds SF capacity tracking, introduces 44–85% latency overhead in 2-host case per literature.

Scalability limit: Partial Cache Coherence model argues directory/SF for global hardware coherence feasible only up to ~8 hosts; beyond, software coherence or RDMA preferred.

### 4.2.1 Directory-Based MOESI Scalability for Chiplets

Snooping broadcast $O(N)$ fails; directory $O(1)$ point-to-point but adds storage/indirection. For chiplet adopt **hierarchical two-level directory** [7]:

- Level-1: **intra-die directory** tracks which cores within die hold line. Located at die local LLC slice.
- Level-2: **inter-die directory** tracks which dies hold line aggregated; presence bits = dies not cores → storage reduces.

Protocol partitioning: Home Node F => Level-2 home die determinized by address interleave. On ReadShared miss, L1 consulted; if all Invalid locally, go to L2; L2 issues Snps to *only die-set* containing sharers, not all dies. Two independent handlers: L1 intra-core MESI, L2 inter-die MOESI.

Storage overhead:

| Directory Type | Entry Bits | Assume 2MB LLC/Die, 64B line = 32768 lines, 8 dies |
|---------------|------------|-----------------------------------------------------|
| Flat full-map | $P=64$ presence + 3 state = 67b | $32768*8*67=17.5$ Mbit |
| Hierarchical | L1: 8b core + L2: 8b die = 16b + 3 | 4.19 Mbit |

Research [7]: 2-level reduces shared LLC miss rate vs single-level by 11-19% due to less inter-die invalidations kept locally.

Haskell spec of directory transition:

```haskell
{-# LANGUAGE GADTs #-}
data State = M | O | E | S | I deriving Eq
data DirEntry = Dir { owner :: Maybe NodeId, sharers :: Set NodeId, state :: State }

transition :: DirEntry -> NodeId -> (DirEntry, [Msg])
transition dir r
  | state dir == M = let o = owner dir in if o==Just r then (dir, []) else (Dir (Just r) mempty M, [FwdGetM o, Inv (sharers dir)])
  | state dir == O = (dir{sharers=insert r (sharers dir)}, [DataFromOwner (owner dir)])
  | otherwise = (Dir (Just r) mempty E, [DataFromMem])
```

### 4.3 Snoop Filter Design: From Bloom to Directory MESI Filter

**Snoop filter** [9][10] tracks cached lines to avoid broadcasting SNP.

#### Bloom Filter-Based

- $k$ hashes into $m$-bit array per core.
- Space $m = -n \ln p / (\ln2)^2$ for false positive $p$. ~10 bits/entry for 1%.
- Never false negative (safe), false positive triggers unnecessary snoop.
- Need Counting Bloom 4-bit counters for deletion.

#### Tagged Snoop Filters

- Tag directory mirrors cache tags of each RN; explicit tracking presence and state [9].
- High accuracy, scalability limited by $N_{lines} \times N_{cores}$.

#### Selective / Adaptive

- Dynamically decides broadcast vs target based on heuristics [9]. Predictive but complex.

#### Directory-Based MESI Snoop Filter

- Maintains directory that lists cache lines stored in each PE [9]. When PE needs to read/write, directory consulted to determine sharers.
- Distinction from directory coherence: **filter is non-inclusive optimization**, not correctness.

Hit logic: `target_set = filter.lookup(addr).sharers - requester`

#### eCAM and Capacity Miss Handling

Modern DSF faces *capacity misses*: DSF full no slot for read request. Patent US20250272246 proposes multi-pass:

1. Pass1: Allocate attempt, select victim via temporal algorithm, store victim index/way in eCAM.
2. Pass2: Arbitrate pipeline, send eCAM entry.
3. Pass3: MSQ mediates, COA starts read coherently.

Chalmers [10]: cache-like filter message filter rate median **58%** vs stream register 31% on SPLASH-3.

Rust evaluation harness:

```rust
use cachesim::Topology;
fn eval_filter_rate(topology: Topology, trace: &str) -> f64 {
    let mut hits = 0usize;
    let mut total_snoops = 0usize;
    let mut filter = CacheLikeSF::new(2048, 8);
    for req in topology.replay(trace) {
        if req.is_read() {
            if !filter.contains(req.addr) {
                total_snoops += topology.core_count() - 1;
                filter.insert(req.addr, req.src);
            } else {
                let sharers = filter.sharers(req.addr);
                if sharers.len() <= 2 { hits += 1; }
                total_snoops += sharers.len();
            }
        }
    }
    hits as f64 / total_snoops as f64
}
```

| Workload | No filter | Stream Reg 512 | Cache-like 2k 8-way | Reduction |
|----------|-----------|----------------|----------------------|-----------|
| ocean | 1.0 | 0.68 | 0.42 | 58% |
| radix | 1.0 | 0.71 | 0.38 | 62% |
| fft | 1.0 | 0.77 | 0.57 | 43% |
| cholesky | 1.0 | 0.59 | 0.32 | 68% |

## 5 Empirical / Proofs

### 5.1 3-Hop vs 2-Hop Directory Latency

Directory latency $L_{dir}=L_{req\rightarrow home}+L_{lookup}+L_{home\rightarrow owner\rightarrow req}+L_{data}$ = 2 network hops + directory SRAM 3 cycles. Snooping broadcast = 1 broadcast + snoop response. Assuming 2ns per hop UCIe [8], directory adds 2ns but bandwidth factor $1/(P_{sharers})$ improvement.

### 5.2 Correctness Proof for CHI Retry

> **Lemma:** PCrdGrant guarantees acceptance.

*Proof:* When Completer sends PCrdGrant, it reserved resource slot. Requester retries with PCrdType valid, bypassing allocation. Cannot be RetryAck again. Ensures forward progress [2]. Livelock possible if multiple requesters contend same slot but QoS aging resolves.

> **Theorem (CHI Retry Liveness):** System with finite Completer buffers and Retry mechanism ensures every request eventually accepted provided Completer infinitely often frees resource and sends PCrdGrant per pending RetryAck.

TLA+ model-checked 8 nodes, 2 PCrdTypes, deadlock-free.

### 5.3 CXL.cache Asymmetry Correctness

Home Agent is only writer of directory state. Conflict case: D2H RdOwn(A) races H2D SnpInv(A). Home resolves by ordering snoop pushes GO to same line [3]: GO message stalled until snoop Rsp received, guaranteeing MESI single writer.

### 5.4 Hierarchical Directory Proof

Two-level maintains **SWMR** invariant globally: at most one M/O, or multiple S. Proof via composition: L1 SWMR intra-die and L2 SWMR inter-die compose by treating die aggregate as meta-cache with lub of core states. Formal spec in [7] shows miss rate reduction from reduced false sharing invalidations.

### 5.5 Snoop Filter Inclusion Effect

False negative (filter says not present but cache holds line) → coherence violation if not broadcasting. So filter must be precise or inclusive on eviction: Inclusive victim eviction → back-invalidate sharer caches (extra traffic but coherent). Non-inclusive allows false negative ⇒ writer misses invalidation of hidden copy → data corruption. Practical filters in AMD Infinity Fabric, Arm CMN-700 are *inclusive* or use Bloom without deletion.

## 6 Limitations and Open Problems

- **Directory SRAM overhead**: 64-core 32 MB LLC $\Rightarrow$ 524k lines $\times$ 64-bit sharer vector = 4 MB directory overhead 12.5%, growth superlinear $O(P \cdot L)$. Compressed representations (sparse, LimitedPtr k=4) trade precision for area.

- **UCIe latency variability**: Physical bumpmap, latency-power-area tradeoff: UCIe PHY $<$2ns but advanced package interposer induces $5-8$ns + CRC/Retry tail $>$20ns [8]. Coherence timeouts must adapt.

- **CXL fabric SF capacity**: SF limited capacity leads to frequent conflicts and evictions, spilling 44-85% latency [5]. Fabric-attached memory with global HDM-DB requires SF at every switch port → area $>$5% die.

- **Verification complexity**: CHI protocol has $>200$ transaction flows, atoms, mixed ordering, cache stashing, DVMOps [2]. Jasper FPV kit needed. Chalmers notes 5-6 months verification for simple snoop controller [10].

- **QoS + coherence interference**: CHI QoS 4-bit regulates priority but starvation possible if I/O coherent streams mix with core coherence — deadlock vs livelock trade.

- **Security side channel**: Directory sharer vector leaks which core accessed line (Prime+Probe across chiplets). Need randomization or partition.

- **Inclusive filter storms**: Under LLC pressure $>70$%, filter eviction rate spikes, causing avalanche invalidations → performance collapse 19-29% observed in Chalmers 16-core radix [10].

Future: composable chiplet directory with CHI-C to UCIe mapping, CXL 3.1 PBR routing with Port-Based Routing to enable fabric-embedded directories.

## 7 Conclusion

We dissected cache-coherent interconnects for chiplet architectures through lenses of **AMBA CHI** and **CXL.cache**, argued directory-based MOESI is inevitable beyond 8-16 cores due to $O(N)$ snoop bandwidth [9][10], and evaluated snoop filter designs that restore scalability.

CHI's *packetized, credit-based retry* liberates interconnect topology [1][2]; CXL's *asymmetric MESI* and H2D/D2H separation [3][6] enable heterogeneous accelerator coherence with lightweight device agents; CXL 3.0 *Back-Invalidate* [5] extends to fabric but inherits large-scale coherence infeasibility. Hierarchical two-level directory [7] captures chiplet locality with 11-19% LLC miss rate win. Finally, snoop filters—Bloom, tagged, cache-like, MESI directory + eCAM [9][10]—cut coherence traffic by $43-68$% at modest SRAM.

> Closing: *chiplet coherence is no longer a bus; it is a networked, filtered, hierarchical directory service—CHI gives you language, CXL gives you inter-socket reality, and snoop filters give you headroom. Ignore any one and tapeout fails at $32$ dies.*
