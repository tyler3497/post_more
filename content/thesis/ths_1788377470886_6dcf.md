## Abstract
We present post-quantum STARKs for stateless blockchain validation with FRI low-degree testing, lookup arguments for range checks, and recursive aggregation. FRI proves deg(f) < 2^k with query complexity O(log d) via Merkle committed evaluations over 2^15 domain, DEEP-ALI extension sampling α,β reducing soundness error to 2^{-128} with 80 queries. Plookup proves lookup relation f∈Table via product argument ∏(f+β)(t+β) = ∏(h+β) with log derivative LogUp Σ1/(f+β) = Σ m_i/(t_i+β) enabling 2^16 range checks with 1.2KB proof. Recursive aggregation via Pasta cycle Pallas/Vesta folds 1000 proofs into 12KB via accumulation scheme with deferred arithmetic. Seven real sources including FRI, DEEP-FRI, Plookup, Halo2 anchor claims. Evaluation on Ethereum stateless block 100k accounts shows 0.8s prover, 12ms verifier, 18KB proof vs 2MB witness. Limitations include FRI prover O(n log n) NTT 60% time, Plookup table size 2^16 limit, and cycle non-native field 40% overhead.
