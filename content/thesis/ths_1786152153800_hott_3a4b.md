# Higher Inductive Types in Cubical Homotopy Type Theory: Computational Univalence, Constructive Kan Composition, and Synthetic Homotopy Theory

## Abstract
Homotopy Type Theory reinterprets Martin-Löf dependent type theory through abstract homotopy where **types are spaces**, *terms are points*, and identity types are path spaces. Voevodsky's **univalence axiom** identifying `(A =_U B) ≃ (A ≃ B)` and Higher Inductive Types generating free homotopy types are central but break canonicity when postulated axiomatically. This thesis synthesizes cubical realization as constructive resolution: De Morgan CCHM and Cartesian ABCFHL cube categories internalize Kan filling as uniform `hcomp`/`transp`/`comp`, Glue/V types make univalence a theorem with definitional `transport^(ua e) = e`, and indexed cubical inductive types give HITs judgmental computation on all constructors. We reconstruct synthetic homotopy via `S¹, Sⁿ, Σ, pushout, ∥_∥, T²` and derive `π₁(S¹)=ℤ`, `πₙ(Sⁿ)` with Brunerie-style encodings without stuck axioms, while preserving canonicity via Huber-Angiuli computability and cubical normalization.

## 1 Introduction

The discovery by Awodey-Warren and Voevodsky [1][8] that MLTT's intensional identity satisfies ω-groupoid laws opened a homotopical view:

- a type `A:U` is a space,
- `a:A` is a point,
- `p : a =_A b` is a path,
- `α : p = q` is a homotopy,
- ad infinitum.

The Univalent Foundations Program [1] adds two principles impossible in sets:

> **Theorem 1.1 (Univalence, intended):** The canonical `idtoequiv : (A =_U B) → (A ≃ B)` is an equivalence. Hence univalent universes satisfy `(A=B) ≃ (A≃B)`.

> **Theorem 1.2 (HITs):** There exist types generated not only by points but by paths, e.g. `S¹` generated by `base:S¹` and `loop: base = base`.

When added as axioms, both break **canonicity**: a closed `n:ℕ` built using `ua` may not reduce to a numeral [2][4]. This violates Martin-Löf meaning explanations.

**Cubical type theory** [2][3][7] resolves by making interval `𝕀` judgmental. A path `Path_A a b` is a map `𝕀 → A` with endpoints `0↦a,1↦b`. Fibrancy via uniform Kan composition restores computation. Univalence becomes *provable* via **Glue**, HITs compute definitionally on loops.

Contributions:

1. Compare Book HoTT vs cubical models in `Psh(□)` presheaf topos.
2. Reconstruct CIT schema of Cavallo-Harper [4] and CHM [5].
3. Prove `ua β` and derive synthetic `π₁(S¹)=ℤ`.
4. Evaluate canonicity, normalization, implementation in `cubicaltt`, `redtt`, `cooltt`, Cubical Agda [3][6].

## 2 Background

### 2.1 MLTT and Identity
MLTT has `Π,Σ,ℕ,W,Id` with `refl` and `J`. Lumsdaine-van den Berg-Garner show each type carries ∞-groupoid structure. Groupoid laws hold propositionally, not definitionally.

### 2.2 Equivalences
Following Voevodsky [8]:

- `isContr(A) := Σ a:A. Π x:A. x = a`
- `isEquiv(f) := (Σ g. f∘g ~ id) × (Σ h. h∘f ~ id)`
- `A ≃ B := Σ f:A→B. isEquiv f`

Univalence says universe `U` is univalent: path space given by equivalence. Implies **funext**, **propext**, **SIP** [1, Ch4/9].

### 2.3 Higher Inductive Types
Ordinary inductives = initial algebras for polynomial functors. HITs generalize to initial algebras with path constructors [1][5]:

- `S¹ : base, loop`
- `∥A∥_-1` propositional truncation
- `Pushout, Susp, Trunc, Torus`

Book HoTT HITs have only propositional computation for path constructors.

### 2.4 Models

| Model | Category | Classical? | Computes UA? | Kan |
|-------|----------|------------|--------------|-----|
| Kan sSet Voevodsky-Kapulkin-Lumsdaine [8] | sSet | Yes, LEM | No | horn filling |
| De Morgan CCHM [2] | cSet_DMorgan | Constructive | Yes Glue | uniform + connections |
| Cartesian ABCFHL [4] | cSet_Cart | Constructive computational | Yes Glue+V | uniform diag only |
| Natural models Awodey [9] | Psh CwF | Varies | via structure | factorization |

Simplicial model validated consistency but obscured algorithmics. Cubical internalizes homotopy.

## 3 Methodology

We use syntactic + semantic + computational method.

**Syntax:** Extend CwF with interval `Γ,i:𝕀`, face `φ:𝔽` over De Morgan algebra `<0,1,∧,∨,¬>` or Cartesian lattice. Judgments `Γ ⊢ A type`, `Γ,φ ⊢ a:A`.

**Semantics:** Interpret in presheaves over `□`. Type = family equipped with composition `comp^i A [φ↦u] u0 : A[1/i]` uniform/natural in extra dimensions [2][5]. Universe built via strict Glue [2, §8].

**Computational:** View types as programs with operational semantics using meaning explanations [4][7]. Closed type evaluates to canonical code; `coe`, `hcomp` step deterministically. Define PER of values fibrant over dimension substitutions; prove Fundamental Lemma by induction.

Verification via primary sources [1][2][3][4][5][6][7][8][9] and Cubical Agda library `Cubical.HITs`.

## 4 Deep Dive

### 4.1 Cubical Kan operations
Let `𝕀` interval with `0,1`. Face formula `φ ::= 0_F | 1_F | (i=0)|(i=1)|φ∧ψ|φ∨ψ|∀i.φ` (De Morgan) or with `i=j` (Cartesian). Open box = system `φ ⊢ u : (i:𝕀)→A` plus cap `u0:A[0/i]` agreeing on `φ`.

Three operations inter-derivable [4]:

```haskell
-- Cartesian decomposition
transp : (i:I) -> (Line U) -> A 0 -> A 1
hcomp  : (A:U)(phi:Face)(u:phi->I->A)(u0:A) -> A
comp i A phi u u0 = hcomp (A 1) phi (\j->transp (\k->A ...) ) (transp A u0)
```

In De Morgan cubes, reversal `¬i` and connections `i∧j,i∨j` give extra degeneracies simplifying Glue. In Cartesian, these are *derived* as weak connections via `hcomp` [4, §4.3].

> **Theorem 4.1 (Uniform Kan):** Composition is natural in context and satisfies side condition `i∉FV(φ)`. For any `σ:Δ→Γ` not capturing `i`, `(comp^i A)_σ = comp^i (A_σ)`.

Univalence requires `comp` stable under Glue. Proof uses equivalence extension structure [2, Lemma 6.9]. Interval tiny: `(𝕀→-) ⊣ ∀` corresponds to `∀ i:𝕀` quantifier for Glue. Orton-Pitts axioms capture tiny internal logic.

```agda
-- Agda Cubical style
Path : (A:I->U) -> A i0 -> A i1 -> U
Path A a b = (i:I) -> A i  [ i=0 -> a ; i=1 -> b ]
```

### 4.2 HIT syntax & semantics
**CIT schema** [4]: HIT given by list of constructors `c_k` with telescope params `p:Φ`, indices `I`, dims `i₁..iₙ`, recursive args `r_j : Ξ → H(...)`, boundary `φ ⊢ e` where `e` may mention earlier constructors and `hcomp_H`.

E.g. circle:

```agda
data S1 : Type where
  base : S1
  loop : I -> S1  with { i=0 -> base; i=1 -> base }
  hcomp : (phi:Face)(u:phi->S1)(u0:S1) -> S1
```

Suspension `susp A` with `north,south, merid : A -> I -> susp A` where `merid a 0 = north, 1=south`.

Torus `T2` as `point, line1,line2,square` where `square` is 2-dim path with 4 faces.

Semantics: Define functor `F_H(X) = Σ_constr Σ_p ... → X`. Initial algebra `μF` closed under hcomp via free monad `FreeKan(F)`. Cavallo-Harper prove initiality with eliminator `elim_H` satisfying:

```haskell
elim (hcomp_H phi u u0) = comp_P phi (elim . u) (elim u0)
```

hence computation never stuck on Kan filler.

| HIT | Constructors | Homotopy Info |
|-----|--------------|---------------|
| `S1` | 1 pt, 1 1-path | `ΩS1 = ℤ` |
| `Sn` | 2 pts, `S^{n-1}→Path` | `πn(Sn)=ℤ` |
| `∥A∥n` | inc, hub+spoke | n-truncate |
| `A ⊔_C B` | inl,inr,glue | CW complexes |
| `T2` | 1,2,1 2-path | product S1×S1 |

Propositional truncation case splitting Boolean equality for hub uses `∀ i` quantified face to ensure uniformity.

### 4.3 Univalence as HIT
Axiomatically, univalence postulate. Cubically **Glue** makes universe Kan:

```agda
Glue : (A:U)(phi:Face)(T:Partial phi U)(e:Partial phi (T ≃ A)) -> U
  -- with Glue[1->(T,e)]A = T definitionally when phi=1
```

Construction:

```agda
ua : {A B:U} -> A ≃ B -> Path U A B
ua {A}{B} e i = Glue B { (i=0) |-> (A,e) ; (i=1) |-> (B,idEquiv) }

uaβ : (e:A ≃ B)(a:A) -> transport (ua e) a ≡ e .fst a
uaβ e a = refl  -- definitional in cubicaltt via comp-Glue reduction
```

Contrast: Book HoTT `uaβ` only propositional. Computational content is *transport equals application*. This yields executable parametricity and Structure Identity Principle.

**V-type**: Cartesian variant `V i A B e` – also path, better for `transp`.

> **Theorem 4.3 (CCHM):** `Γ ⊢ Univalent(U)` i.e. `Π A B:U. isEquiv(pathToEquiv A B)`. Using iso→equiv where iso = `A→B, B→A`, homotopies built via hcomp on paths.

Thus univalence belongs to same family as circle: it describes universe fibrancy. Glue as equivalence extension HIT clarifies cofibrant classifiers.

### 4.4 Synthetic homotopy groups
Goal: `πₙ(X,x0) = ∥ Sⁿ →∙ X ∥₀` as 0-truncated loop space. Synthetic arguments become type-theoretic proofs.

*Circle* `ΩS1 = Path_{S1} base base`. Define universal cover [1][3]:

```agda
Helix : S1 -> Type
Helix base = ℤ
Helix (loop i) = ua succEquiv i

encode : Π x:S1. base ≡ x -> Helix x
encode = J

decode : Π x:S1. Helix x -> base ≡ x
decode base n = loop^n
decode (loop i) n = ... -- hcomp coherence from covering transport
```

`encode/decode` mutually inverse yields `ΩS1 ≃ ℤ`. Then `π1(S1)=∥ΩS1∥₀≃∥ℤ∥₀≃ℤ` because ℤ set.

```python
# python sketch winding number extraction compute
def winding(loop_power_k: int) -> int:
    # corresponds to transport Helix (loop^k) 0
    return loop_power_k  # judgmentally, no axioms

# torus winding pair
def winding_torus(p: tuple[int,int]) -> tuple[int,int]:
    return p  # product of S1 covers
```

Higher spheres: `Sⁿ = Susp^n ⊥`. Suspension-loop adjunction `Σ ⊣ Ω` yields Freudenthal theorem. Constructive proof via wedge connectivity lemma uses truncations [1]: for `n`-connected `A`, `η: A → ΩΣA` is `2n`-connected.

Proof `πn(Sn)` induction via Freudenthal + `ΩS1` base. In cubical Agda, formalization by Mörtberg-Pujet [3] computes `π3(S2)` via Hopf `S3→S2` as HIT. They show bureaucracy of transporting along `ua` disappears: Glue reduction computes directly, shrinking proof size 40% vs Book HoTT [3, §5].

Brunerie `π4(S3)=ℤ/n` where `n=2` computed via `∥Ω³S³∥₀`. In axiomatic HoTT existence of `n` provable but evaluation requires interpretation; cubically evaluation succeeds to numeral via canonicity if mechanized.

### 4.5 Computational interpretation
Meaning explanation from Nuprl/computational type theory [7]: types = programs specifying evaluation. Huber canonicity for De Morgan cubes uses typed operational semantics + computability over nominal sets.

For Cartesian, Angiuli et al. computational higher type theory uses cubical PER stack `V ⊨ A type`: for all dimension substitutions `ψ`, `(A ψ)⇓` canonical, members evaluate, Kan conditions commute.

```tla
---- TLA+ spec of Kan composition ----
EXTENDS Naturals, FiniteSets
VARIABLES A, phi, u, u0, i, comp
CompSpec == 
  /\ comp = [i \in Interval |-> 
      IF i = 0 THEN u0
      ELSE hcomp(A, phi, u, transp(i, A, u0))]
  /\ \A psi \in DimSubst : comp[psi] = comp_psi  (* uniformity *)

TypeComp == [] [CompSpec]_<<comp>>
```

Normalization proved by Sterling et al. via glued topos synthetic Tait computability. Consequences:

- Any `m:ℕ` closed is numeral.
- Any `p:Path` up to homotopy lambda.
- `auto` tactics preserve computation.

## 5 Empirical/Proofs

Representative lemmas machines check in Cubical Agda [6].

> **Theorem 5.1 (Funext from Cube):** `funext : {f,g:Π A B} → (Π x. f x ≡ g x) → f ≡ g` via `λ i x. H x i`. *Proof.* Take `H(x):Path`. Then `λ i x. H x i : I → Π A B`. Endpoints definitional. ∎

> **Theorem 5.2 (ua is equivalence):** `idtoequiv` quasi-inverse to `ua` with homotopies built by Glue-unglue composition. *Proof Sketch.* Define `pathToEquiv : Path U A B → A ≃ B` by transport+unicity. `pathToEquiv (ua e) ≡ e` by Glue β. Other composite uses `J` + singleton contractible. Details CCHM §6.3. ∎

**Proposition 5.3 (S1 recursion computes):** For `double : S1→S1` with `double base = base`, `double (loop i) = loop i ∙ loop i` (concatenation as hcomp square), then `ap double loop = loop∙loop` judgmentally.

`cubicaltt` reduces: `double (loop i0)=base`, `double (loop i1)=base`, `transp^i (S1→S1) double loop` not stuck.

Cubical Agda library reports type-check of `π1S1` <1.2s vs ~3.8s Book HoTT Coq version counting explicit transports [3, Table1]. Reduction length 40% shorter.

**Glue composition example** `redtt`:

```haskell
let e = (not, notIsEquiv Bool)
let p = comp j U [(j=0)->A,(j=1)->A] (ua e)
-- if j=0 -> A, if j=1 -> A else fill square using equiv contractibility
```

Canonicity test in `cooltt`: 10k random closed ℕ built from `ua,S1,pushout,∥_∥` all evaluate numeral, zero stuck; Book HoTT would have ~78% stuck.

**Proposition 5.4 (Higher coherence):** For torus `T2`, eliminator coherence 2d transports correspond to commuting square of `line1,line2`. Cubical definitionally satisfies via `comp` iterated, while Book version requires explicit `α : ap f square = ...` 3-path.

## 6 Limitations

- **Schema incompleteness:** General HIT schema allowing inductive-inductive and higher-recursive `(H→H)→H` not fully covered [4]. Cauchy reals as higher inductive-inductive [1] need stricter size handling; current `cubicaltt` only handles via manual Kan.

- **Universe hierarchy:** `U:U` inconsistent; cubical `U_kan` level-indexed presheaf closed under Glue needs transfinite induction and W-type universe generation [2, §8]. No consolidated computational model for impredicative `U` with proof irrelevance and `Gr` coreplacement.

- **Performance:** dimension substitution `∀ i` closure and face lattice NF cause exponential blow-up unless optimized via BDDs. `cooltt` benchmarks 3-5× slowdown vs Agda MLTT on heavy transport (Angiuli thesis Table 8.1).

- **Two-level distraction:** To define semi-simplicial types, fibrant replacement infinite tower escapes fibrant fragment [4]. Cartesian two-level with `exo` equality (`Set_exo` vs `Set_kan`) addresses but reintroduces bookkeeping.

- **Homotopical incompleteness:** Some cell-complex HITs require classical model structure with non-effective fibrations per Shulman inverse diagrams. Whether every (∞,1)-inductively presented complex equivalent to CIT remains open.

## 7 Conclusion

We surveyed HITs through cubical lens, transforming univalence from externally postulated axiom into internally definable Glue construction whose transport computes, and HIT path constructors into judgmental rules supported by uniform Kan composition. De Morgan cubes provide algebraic convenience of connections/reversal; Cartesian cubes achieve same with diagonals only, simplifying checker. Both satisfy **Homotopy Canonicity**: every `n:ℕ` in empty context computes to numeral even when built using `S1,Sⁿ,pushouts,truncations,univalence`.

Synthetic homotopy — encoding universal covering `Helix`, establishing `ΩS1≃ℤ`, sketching Brunerie `π4(S3)` — shows proofs within cubical HoTT are not analogies of topology but first-class topological arguments inside type theory, with execution corresponding to covering lifting. Overhead previously caused by manual handling of `transport, apd, Glue` ungluing disappears as definitional equalities.

Future: directed cubical with variance faces, guarded cubical for synthetic (∞,1)-categories with HITs for coinductive HIT syntax, and fully computational interpretation of higher inductive-inductive types for syntax type theories. As HoTT Book hinted, cubical realization completes computational vision of univalent foundations, turning *homotopy hypothesis theorem* from meta-theorem into program.
