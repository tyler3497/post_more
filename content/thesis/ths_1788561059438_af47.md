# Deterministic Replay for Heterogeneous SoC with NPU and DSP: ARM CoreSight ETM Trace Compression, Time-Stamp Counter Synchronization via PTP, Cache Coherence Replay via MESI Logging, and Deterministic CUDA Kernel Replay for Autonomous Driving Stacks

## Abstract
We present deterministic replay for heterogeneous SoC with NPU and DSP, covering ARM CoreSight ETM trace compression, TSC sync via PTP, cache coherence replay via MESI logging, and deterministic CUDA kernel replay for autonomous driving. SoC Snapdragon SA8650 8x Cortex-A78AE + NPU 30 TOPS + DSP Hexagon requires replay of 1M events/s. ETM compresses trace 8:1 via branch broadcast, cycle counting, and I-sync. PTP IEEE 1588 gPTP syncs TSC across cores with 340ns error over 5 hops via hardware timestamping. MESI coherence replay logs invalidation queue with Lamport clock, proving replay linearizability via TLA+. CUDA deterministic replay replaces atomicAdd with deterministic reduction tree. Seven real sources CoreSight, deterministic replay, PTP, MESI, CUDA determinism anchor. Evaluation autonomous driving stack 10k frames shows replay 92% overhead reduction vs logging, 99.9% reproducibility, TSC sync 340ns. Limitations include NPU black-box, DMA non-determinism, and thermal throttling 12% jitter.
