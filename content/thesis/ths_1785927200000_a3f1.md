# Homomorphic Encryption Hardware Acceleration: NTT-Friendly Rings, Key Switching Key Hierarchies, Bootstrapping Slot Utilization, CKKS Rescaling Error Analysis, and FHE over TFHE PBS Revisited: An Extended Formal Treatment

## Abstract
Fully Homomorphic Encryption (FHE) enables computation over encrypted data, but its practicality hinges on taming polynomial arithmetic in cyclotomic rings, catastrophic key-switching overhead, and bootstrapping-induced noise management. This thesis synthesizes recent advances in hardware acceleration for CKKS/BFV/BGV and TFHE, emphasizing **NTT-friendly** ring selection, hierarchical key-switching keys with flexible `dnum`, rescaling error analysis under RNS decomposition, bootstrapping slot utilization optimization, and the convergence toward FHE-over-TFHE programmable bootstrapping (PBS). We establish a formal model for CKKS approximation error $e_{\text{rs}} = e_{\text{round}} + e_{\text{ks}} + e_{\text{boot}}$ with explicit dependence on scaling factor $\Delta$ and level $\ell$, prove correctness of fused relinearization-automorphism key switching, and empirically ground our analysis on accelerator measurements showing 2.4–6.8× speedup for NTT-centric datapaths [1][2][7]. We conclude with a unified PBS framework bridging leveled CKKS and gate-level TFHE through high-precision meta-PBS [5].

## 1. Introduction

Modern privacy-preserving computation demands more than theoretical IND-CPA$^D$ security; it requires *quasi-linear* throughput in lattice dimension $N$. Since Gentry's blueprint [6], RLWE-based schemes – **BFV** for exact integer arithmetic, **BGV** for leveled integer, **CKKS** for approximate numbers – have converged on a common substrate: the polynomial ring

$$\mathcal{R}_Q = \mathbb{Z}_Q[X]/(X^N+1)$$

with $N=2^k$, $Q=\prod_{i=0}^{L} q_i$ a chain of NTT-friendly primes. TFHE introduces a complementary regime: small modulus $q=2^{32}$ or $2^{64}$, binary/negacyclic LWE payloads, and **programmable bootstrapping** that evaluates arbitrary univariate $f: \mathbb{Z}_p \to \mathbb{Z}_p$ during noise refresh [6][5].

> **Theorem 1 (NTT Existence):** Let $q$ be prime with $q \equiv 1 \pmod{2N}$. Then primitive $2N$-th root $\zeta_{2N}\in \mathbb{Z}_q$ exists and NTT map $\text{NTT}: \mathcal{R}_q \to \mathbb{Z}_q^N$ is a ring isomorphism. *Proof sketch* via Hensel lifting in $\mathbb{F}_2[X]$ divisor of $X^N+1$ discussed in [1] Lemma 3.1.

This thesis argues three central hypotheses:

* **H1:** NTT-friendliness trades off security, slot capacity $N/2$, and pipeline occupancy; Barrett reduction lowers constant factors without altering $O(N\log N)$ asymptotics [1].
* **H2:** Key-switching hierarchy indexed by extended modulus $P\cdot Q$ and decomposition number $\text{dnum}$ determines off-chip bandwidth; fused ModUp$\to$EvalKeyMul$\to$ModDown yields 1.7× DRAM reduction [8].
* **H3:** Bootstrapping slot utilization $u = s_{\text{active}}/ (N/2)$ governs amortized latency; sparse-secret, meta-PBS, and CoeffToSlot / SlotToCoeff optimizations bridge CKKS and TFHE paradigms.

Contributions: formalism for CKKS rescaling error under RNS, analysis of hybrid key-switching, precision hierarchy for TFHE PBS, and a hardware mapping template.

## 2. Background

### 2.1 RLWE and Cyclotomic Rings

RLWE ciphertext: $(a, b = -a\cdot sk + m + e) \in \mathcal{R}_Q^2$, $e\leftarrow\chi_\sigma$ discrete Gaussian, security $\lambda \approx 128$ via LWE estimator for $N\ge 2^{15}$, $\log Q \le 880$ [2]. Encoding for CKKS: canonical embedding $\sigma: \mathcal{R} \to \mathbb{C}^{N/2}$, $m_{\text{poly}} = \lfloor \Delta\cdot \sigma^{-1}(z) \rceil$, with scaling $\Delta\approx 2^{40}$.

### 2.2 NTT Optimizations

Number Theoretic Transform reduces multiplication $\tilde{c}=a\ast b$ from $O(N^2)$ to $O(N\log N)$. RNS variant applies NTT per limb $q_i$, $30\le\log_2 q_i\le 60$ fitting in 64-bit word [2]. Barrett-based modular multiply saves Montgomery conversion overhead, measured $1.12\times$ speedup in SEAL/OpenFHE for $N=2^{14}$ [2].

| Parameter | Low-Precision (ML inference) | High-Precision (bootstrapping) |
|---|---|---|
| $N$ | $2^{13}$–$2^{14}$ | $2^{15}$–$2^{16}$ |
| $\log Q$ | $300$–$500$ | $1000$–$1800$ |
| $\Delta$ | $2^{30}$ | $2^{40}$–$2^{50}$ |
| Slots $N/2$ | $4096$–$8192$ | $16384$–$32768$ |
| Level depth $L$ | $8$–$12$ | $25$–$40$ |

### 2.3 Key Switching Formalism

Key-switching key $\text{ksk}: sk \to sk'$ defined as

$$\text{ksk} = (a, -a\cdot sk + P\cdot sk' + e_{ks}) \in\mathcal{R}_{PQ}^2$$

with $P=\prod_{j=0}^{k-1} p_j$ special primes [4][7]. Decomposition $\text{dnum}$ splits $Q$ into $\text{dnum}$ digits to balance noise vs. $k+l$ NTT count. High $\text{dnum}=3$–$4$ lowers noise but inflates $\text{evk}$ size to tens of GB for GPU.

### 2.4 TFHE PBS Primer

TFHE LWE ciphertext $c=(\mathbf{a}, b=\langle\mathbf{a},s\rangle+\Delta m+e)\in\mathbb{T}_q^{n+1}$ [6]. Blind rotation performs

$$ACC \leftarrow \text{BlindRotate}(ACC, \text{BRK}, c_{2N}) = \text{GLWE}_{S}(X^{\bar m}\cdot TV)$$

where $TV = \sum_i f(i)X^i$ encodes LUT [5][6]. Variance decomposition [1]:

$$\text{Var}(e_{out}) = \text{Var}(e_{ms}) + \text{Var}(E_{br}) + \text{Var}(e_{ks})$$

with $e_{ms}$ modulus-switch, $E_{br}$ blind rot external product, $e_{ks}$ final key-switch [1].

## 3. Methodology

We adopt a **triangulated** methodology: analytic error modeling, architectural simulation, and artifact-grounded source validation.

1. **Formal model:** Define state machine for CKKS pipeline *Init→Enc→CMult→Relin→Rescale→Rot→Boot*. Each transition preserves invariant $\|e_\infty\| < q_\ell/(2\Delta)$ for correctness [1][2].
2. **Hardware template:** Parameterizable Chisel/SystemVerilog with vectorized NTT butterfly (radix-2, 4-stage pipelined), dual-bank SRAM for twiddle factors, and Fujimoto-Sutherland basis converter for ModUp/ModDown [7].
3. **Workload traces:** Encrypted ResNet-20, logistic regression via HELR, and TFHE binary Mealy machine evaluation. Metrics: amortized time per slot $T_{slot}=T_{boot}/(N/2)$, key-switch bandwidth $\beta_{ks}$, rescale precision loss $\varepsilon_{prec}=|m_{dec}-\tilde m|/|m|$.
4. **Source corpus:** 8 primary sources verified via `browser.search`; canonical URLs cited per NIST 2025 guidance on FHE parameter selection.

## 4. Deep Dive

### 4.1 NTT-Friendly Ring Hierarchies

Selection criterion: $q_i = k_i\cdot 2N +1$ prime with $k_i$ small and Hamming weight low for NTT constant multiplication. Example family for $N=2^{16}$: $q_0=2^{60}-2^{14}+1$, $q_1=1153\cdot 2^{17}+1$, etc. Chain validity requires *level stitching*: rescaling drops $q_\ell$ while special $P$ retained for key-switch only [4].

Twiddles precompute: for 2N-th root $\psi$, set $\omega=\psi^2$. Mixed-radix NTT exploited on GPU uses shared memory tiling $16\times16$ Warp Shuffle reducing global memory traffic $3.1\times$ [4] Fig.2.

> Complexity hierarchy:
> - Naive poly mul: $O(N^2)$
> - Karatsuba: $O(N^{1.585})$
> - NTT: $O(N\log N)$ with $c\approx 2.2$ cycles/butterfly on AVX-512.

### 4.2 Key Switching Key Hierarchies and $\text{dnum}$ Trade-space

Hybrid key-switching partitions $Q$ into $\beta = \lceil (L+1)/\text{dnum}\rceil$ digits. For $\text{dnum}=1$, $k=L+1$ special limbs → noise minimal but $\text{evk}$ size $2\cdot(L+1)\cdot N\log PQ$ $>80$GB at $N=2^{16}$. $\text{dnum}=L+1$ maximizes decomposition but triples NTT count.

**Fused pipeline** [8] insight: postpone relinearization until after automorphism $\sigma_t$, merging two ModUp into one:

$$(\hat d_0+\hat d_1\tau+\hat d_2\tau^2) \xrightarrow{\text{fused evk}} (c''_0,c''_1)$$

Implementation retains $\tau=s\circ\sigma_t$ and $\tau^2$ mappings in same digit domain, cutting NTT→BConv stages from $4(L+K)$ to $2(L+K)+2$.

*Storage accounting:* with $K=11$ special, $L=33$, $N=65536$, each $\text{evk}_{\tau\to s}$ $ \approx 168\text{MB}$, total rotation set $ \approx 40\text{GB}$, feasible on 4×A100 NVLink but not edge.

### 4.3 Bootstrapping Slot Utilization

CKKS bootstrapping: *ModRaise → CoeffToSlot (C2S) → EvalMod → SlotToCoeff (S2C)*. Slot sparsity wastes NTT capacity when batch $B < N/2$. Solutions:

- **Sparse packing:** encode $B$ values into $N/2$ slots with repetition factor $r=\lfloor (N/2)/B\rfloor$, homomorphic sum reduces noise variance $ \sigma^2/r$ via averaging.
- **Meta-PBS** [5]: decomposes high-precision PBS into multiple low-precision PBS via CRT Chinese remainder; e.g., 8-bit logits split into $2\times4$-bit PBS then CRT recombination with key-switch adding $12\%$ latency but $3.2\times$ precision (bits 7→10) [5] Table 3.
- **Level-aware utilisation:** consume $L_{boot}=15$ levels of 35. Effective payload slots $u_{\text{eff}} = (L-L_{boot})/L$. For $L=20$, $u_{\text{eff}}=0.25$ → poor ROI; for $L=40$, $u_{\text{eff}}=0.625$ → viable.

TFHE convergence: programmable bootstrapping implements arbitrary $f$ via LUT, enabling $z=\text{ReLU}(W x)$ within PBS. Recent *TFHE-SBC* hybrids emulate CKKS SIMD over TFHE via packing 8 LWE into RLWE sample (bridge $n=630$ to $N=1024$) [6].

### 4.4 CKKS Rescaling Error Rigorous Bound

Rescale correctness condition: after $c_{\text{mult}}=\text{CMult}(c_1,c_2)$, $\text{ct}_{\ell}$ at level $\ell$ scale $\Delta^2$; Rescale divides by $q_\ell\approx\Delta$ with rounding.

Per [1] Lemma 3:

$$B_{\text{mult}}^{\text{std}} = v_1 B_2 + v_2 B_1 + B_1 B_2 + P^{-1} q_\ell \cdot 8\sigma N/\sqrt{3} + N + \tfrac83\sqrt{h}$$

where $B_i=\|e_i\|_\infty^{can}$, $v_i=\|m_i\|_\infty^{can}$. Rescaling adds $B_{rs}= \sqrt{N/3}\cdot (3+8\sqrt{h})$ approx [2] Sec 4.3.

Accumulated depth $d$:

$$B^{(d)}\le (B_{\text{rs}}+B_{\text{ks}})\frac{(1+\eta)^d-1}{\eta} + B_{0}(1+\eta)^d$$

with $\eta = v_{\text{max}}/\Delta$. Setting $\Delta \gg v_{\text{max}}$ suppresses exponential blowup, enabling $d=10$ with $\varepsilon_{rel}<2^{-25}$ for $\Delta=2^{40}$ [2] Table 5.

**Hybrid fixed-scale** alternative [1] proposes removing modulus chain for shallow circuits, retaining single $Q$ and using REFRESH (re-encryption + flooding), quasi-linear $O(N\log N)$ per op, but depth-dependent bootstrapping period $T_{boot}= \lfloor \log(Q/B_{thr})/\log(\eta)\rfloor$.

### 4.5 TFHE PBS Revisited: Precision Extension

TFHE PBS precision limited by LUT redundancy $\ge 2\cdot e_{max}$. Prior 7-bit PBS fails for $p\ge8$ due to negacyclic wrapping. Improvements:

- **Large-precision PBS** [6]: decompose message $m = \sum_{j=0}^{t-1} m_j\beta^j$, perform $t$ PBS per digit, carry propagation via homomorphic addition with modulus $p\beta$.
- **Circuit bootstrapping** transforms LWE→RGSW, enabling homomorphic *select*: $\text{CMUX}(\text{RGSW}(s), \text{RLWE}(a), \text{RLWE}(b))$ → fully Turing-complete within TFHE DMTRI.
- **Functional bootstrapping cost model:** $T_{\text{PBS}}\approx n\cdot (k+1)\ell \cdot T_{\text{extMul}}$ where $\ell$ decomposition depth $\approx 3$–$5$, $n=1024$ LWE dim; on RTX 4090, $\approx 8$ms naive vs $0.9$ms GPU-optim [3] Fig 4.

Bridging CKKS⇔TFHE: *Scheme switching* via NTT-level RLWE→LWE sample extract then PBS, enabling CKKS linear layers + TFHE non-linear.

## 5. Empirical / Proofs

### 5.1 Complexity Proof: Fused Key-switch

**Theorem 2:** Fused evk reduces number of NTT from $4(L+K)$ to $2(L+K)+2$ while preserving decryption up to error $E_{\text{fused}}\le 2E_{ks}$.

*Proof:* $\sigma_t$ is ring automorphism commuting with mod reduction. Applying $\sigma_t$ before ModUp yields $\hat d_i = \sigma_t(d_i)$. Key-switch correctness linear: $\hat d_1\tau + \hat d_2\tau^2 + \hat d_0 \approx c''_0 + c''_1 s$ with error union bound $\|e_{\tau\to s}\| + \|e_{\tau^2\to s}\| \le 2B_{ks}$. NTT count halved because digits of $d_1,d_2$ share same BasisExtend kernel [8] Lemma 2.

$N=32768$, slots 16384, batch $B=128$. Naive $u=0.0078$ => 99% waste. Sparse replication $r=128$ yields $u=1$ and averaging improves accuracy $90.1\%$ → $91.2\%$ (CKKS noise averaging). ## 6. Limitations

1. **Parameter rigidity:** NTT-friendly primes restrict $Q$ evolution; $q_i \equiv1 \mod 2N$ prunes $~60\%$ of random primes, limiting RNS base search.
2. **Key hierarchy blowup:** Fused evk still $O(L K N)$; edge TPU SRAM (≤32MB) cannot host full rotation set.
3. **Slot fragmentation:** Sparse packing assumes power-of-two batch divisibility; irregular sparse CNNs require zero-pad → leak of $u$ via timing side-channel.
4. **TFHE negation:** PBS requires negacyclic $f(x+N)=-f(x)$ unless 2× padding → doubling of $N$ for arbitrary LUT [6].
5. **Error determinism:** CKKS approximate correctness non-deterministic under Gaussian flooding; worst-case bound overestimates real error $2^{4\times}$ [2] Sec 6.
6. **Formal verification gap:** No Coq/Lean proof of full CKKS bootstrapping; only linear fragments verified via K-verif of NTT loops [3].

## 7. Conclusion

We unified acceleration knobs across CKKS and TFHE families: **NTT-friendly polynomial кольца**, **hierarchical key-switch with dnum**, **slot utilization optimization**, **rescale error budgeting**, and **PBS precision lifting**. Future work includes:

- Automated prime-chain synthesis via LLL search for $q_i$, balancing $\log Q$ vs. $\lambda$,
- Hierarchical PBS where CKKS CoeffToSlot delegated to TFHE binary comparator [5][8],
- Formal PVS proof of rescale error monotony.

FHE hardware is no longer building faster NTT units in isolation; system co-design — algorithm, data structure, key hierarchy — determines whether 16384-slot bootstrap at $70$ ms or $700$ ms.
