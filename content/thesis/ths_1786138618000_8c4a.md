# Time-Sensitive Networking and Deterministic Networking for 5G URLLC: IEEE 802.1Qbv Scheduling, DetNet PREOF, and Bounded Latency Guarantees

*Author: anon#8427 | ts: 1786138618000 | id: ths_1786138618000_8c4a | Field: Deterministic Networking / 5G URLLC / TSN*

## Abstract

Deterministic communication for cyber-physical fusion demands both *time-based isolation* on links and *service-layer protection* across paths. This thesis unifies **IEEE 802.1Qbv Time-Aware Shaper (TAS)** gate control scheduling, **IETF DetNet PREOF** (Packet Replication, Elimination, Ordering) and **3GPP 5G URLLC** enhanced with TSN translators for bounded latency guarantees. We formalize Qbv as periodic Gate Control List (GCL) synthesis under 802.1AS synchronization error ≤1 µs, analyze PREOF's effect on packet loss probability *P_loss → Π P_i* and reordering ambiguity handled by Packet Ordering Function (POF) buffering with parameter *POFMaxDelay* ≥ path delay divergence, and model 5G as logical TSN bridge with DS-TT/NW-TT translating residence time. We prove a compositional latency bound *L_e2e ≤ L_TSN + L_5G + L_DetNet + Σ Δ_sync* and evaluate scheduling NP-hardness, guard-band fragmentation, and PREOF state complexity. The result is an architecture and calculus for *deterministic* <1 ms 99.9999% reliable flows across heterogeneous L2/L3/5G domains.

*Keywords: IEEE 802.1Qbv, TAS, GCL, DetNet, PREOF, POF, URLLC, bounded latency, TSN-5G integration*

## 1 Introduction

> ***Best-effort must become bounded-effort when control loops close over networks.***

Traditional Ethernet delivers statistical multiplexing; it cannot deliver *determinism*. For closed-loop motion control at 125 µs–1 ms cycles, **industrial automation, smart grid protection, and autonomous vehicle platooning require latency jitter <10% of period and packet loss <10⁻⁶–10⁻⁹** [7][8]. The IEEE TSN Task Group extends 802.1Q via sub-standards Qav, Qbu, Qbv, Qci, Qch; the IETF DetNet WG extends this determinism to L3 via RFC 8655/8938/8964 [5][11]; 3GPP Rel-16/17 models the 5G System (5GS) as a *virtual TSN bridge* to interwork [7].

**Thesis claim:** No single mechanism suffices. **Qbv TAS** provides *per-hop egress isolation*, **DetNet PREOF** provides *per-flow service resilience and ordering*, and **5G URLLC** provides *wireless time-critical access with centralized scheduling*. Their composition, when engineered under a common timing domain, yields end-to-end bounded latency.

The three primitives:

1. **IEEE 802.1Qbv** – *link-level TDMA* via periodic gate opening for 8 priority queues [3][9][10].
2. **DetNet PREOF** – *service sub-layer 1+N redundancy* with elimination and ordering to achieve zero loss [4][6][11].
3. **5G URLLC** – *centralized gNB scheduler* with mini-slots (0.5 ms → 0.071 ms sub-slots), slot preemption, and 1e-9 HRLLC trajectory [8].

This thesis contributes (i) formal model of Qbv GCL synthesis including guard bands and unscheduled end-systems, (ii) rigorous PREOF state machine for POF with advanced path-dependent *POFMaxDelay_i*, (iii) 5G-TSN bridge integration latency calculus, (iv) end-to-end theorem.

## 2 IEEE 802.1Qbv Time-Aware Shaper Scheduling

### 2.1 TAS Model

Per egress port, 8 FIFO queues *q∈{0..7}* each associated to VLAN priority code point (PCP). A **Gate Control List** is a periodic schedule of *K* entries:

```
GCL = { (T_k, gate_vector_k) }_{k=0..K-1}, gate_vector ∈ {0,1}⁸, cycle = h = Σ T_k
```

Entry *k* holds for duration *T_k* where queue transmission gates **open/closed** as bitmask [9][10]. When gate closed, frames remain buffered; when open, eligible queues drain FIFO per IEEE 802.1Q strict priority within open set. After *K* entries schedule repeats – creating **TDMA on Ethernet** [2][3].

> IEEE Std 802.1Qbv-2015 defines managed objects `adminGateStates`, `operGateStates`, `AdminControlList`, `OperControlList`, and `AdminCycleTime` extending 802.1Q bridge management, plus time references derived from 802.1AS-Rev.

Synchronization prerequisite: **802.1AS gPTP** achieves <1 µs syntonization across bridges. Without synchrony, windows drift causing interference [1][3].

### 2.2 Scheduling Synthesis as Constrained Optimization

Let stream set *S = {s_i = (period_i, size_i, deadline_i, route_i)}*. Joint routing+scheduling problem:

- Variables: offsets *φ_i ∈ [0, period_i)*, GCL windows per hop.
- Constraints:
  - *Frame isolation*: if two streams share egress queue on same link, their open windows **non-overlapping** or guard band protected.
  - *Precedence*: arrival *A_{h+1} = D_h + propagation + Φ_sync_error*
  - *GCL caps*: many switches limit entries to 8–512; fragmentation reduces deployability [9][10].
  - *Unscheduled end-systems*: off-the-shelf sensors lack Qbv; then treat as *worst-case ingress delay* bounded via Network Calculus [3].

NP-hard reducible to bin-packing / job-shop. Recent approaches: ILP, SMT, CP, genetic (2PDGA achieves 92.9% CAP@8 compliance at 42.1 µs median with Phase II merging reducing entries 7.7% [9]).

| QoS Mechanism | Isolation Granularity | Requires Sync | GCL Entries | Protects vs |
|---------------|----------------------|---------------|-------------|-------------|
| 802.1Qav CBS | Bandwidth | No | 0 | Congestion |
| 802.1Qbu Preemption | Frame | Optional | 0 | Lower-prio interference |
| 802.1Qbv TAS | Time window | Yes | K per port | All BE / mixed critical |
| 802.1Qci PSFP | Stream ingress | Yes | per stream sGCL | Non-conformance |

Table: TAS trades entries for perfect temporal isolation [2][9].

### 2.3 Guard Bands and Preemption

Without **802.1Qbu frame preemption**, a max-size 1522B frame at 1 GbE blocks 12.2 µs. To guarantee window, scheduler inserts **guard band** = max interferer transmission time, wasting bandwidth. With preemption, guard reduces to 127B fragment (~1 µs) [3]. Tradeoff:

```
Efficiency_loss = Σ_guard / h   vs   determinism_gain
```

P4-TAS implementation validates programmable data-plane realization of tGCL/sGCL in Tofino [9].

```c
// conceptual gate control - TAS evaluation per tick (Heusler simplified)
struct gcl_entry { uint32_t duration; uint8_t gate_mask; };
struct gcl_entry oper_gcl[] = { {5000, 0b00000001}, {12000, 0b00000010}, {3000, 0b00000000} };
uint32_t cycle = 20000; // ns

bool is_gate_open(int q, uint64_t now_ns) {
  uint64_t t = now_ns % cycle;
  for (int i=0; i<3; i++) {
    if (t < oper_gcl[i].duration) return (oper_gcl[i].gate_mask >> q) & 1;
    t -= oper_gcl[i].duration;
  }
  return false;
}
```

*This models hardware `gate driver` core generating gate vector per cycle* [10][9].

## 3 DetNet PREOF: Replication, Elimination, Ordering

### 3.1 Architecture per RFC 8655 / 8938 / 8964

DetNet decomposes data plane into **service** and **forwarding** sub-layers [5][11]. PREOF lives in service sub-layer:

- **PRF** – replicates packet, adds sequencing: `SeqNum` (28-bit DN sequence) in DetNet CW. Sequence added once near source.
- **PEF** – eliminates duplicates based on sequence history window; implements former IEEE 802.1CB FRER logic but at L3 [6][11].
- **POF** – restores order; defined for first time below L4 in IETF [4].

```
                +--------------E1----+    |            |
  +----+       |               |    +---R3---+        |          +----+
  |src |------R1           +---+             |        E3----O1---+ dst|
  +----+       |           |                 E2-------+          +----+
               +----------R2                 |
                            +-----------------+
  R: replication (PRF)  E: elimination (PEF)  O: ordering (POF) [4][6]
```

Service protection relies on **maximally disjoint paths** (SRLG-disjoint) via PCE / controller. Loss probability on compound flow with *N* replicas over independent paths with loss *p_i*:

***P(e2e loss) = Π_i p_i*** → e.g., *p=1e-4* with *N=2 → 1e-8*; meets 5-nines [11].

### 3.2 POF Algorithm Formalization

Replication induces **reordering** when path delays differ: `Δ = |d_max - d_min|`. DetNet application may not tolerate out-of-order: single reorder interpreted as 3× errors causing fail-safe transition [4].

**Basic POF** [4] state:

- `POFLastSent`: seq of last forwarded in-order packet.
- Buffer: conditional delay buffer.
- Parameters:
  - `POFMaxDelay ≥ Δ` – max reordering hold.
  - `POFTakeAnyTime` – reset acceptance window, derived from PEF RECOVERY_TIMEOUT + inter-frame + Δ.

Algorithm pseudocode (extracted from [4]):

```python
def pof_recv(pkt):
    seq = pkt.seqnum
    if seq <= POFLastSent + 1:  # in-order (modulo with wrap handling)
        forward(pkt)
        POFLastSent = seq
        # drain any now in-order buffered
        drain()
    else:
        buffer(pkt, deadline=now+POFMaxDelay)

def on_timer():
    # timeout → accept out-of-order to respect bounded latency
    for b in buffered_sorted():
        if now >= b.deadline:
            forward(b)
            POFLastSent = b.seq  # skip gap -> gap stays loss
```

Properties:

- **No sync required between PREOF nodes** – POF local [4].
- Adds burstiness – conditional buffering only delays out-of-order [4].
- Increases latency by ≤`POFMaxDelay` for reordered subset; in-order packets 0 extra.

**Advanced POF** for tight delay budget at POF where `remaining_delay_budget < POFMaxDelay`. Extension: path identification via ingress interface / FlowID, then path-dependent `POFMaxDelay_i` ensures packet on longest path forwarded immediately (last-chance) [4].

> ***Theorem – Bounded POF Overhead.*** For Δ = max path divergence and `POFMaxDelay = Δ + ε`, the additional latency for any packet through POF ≤ Δ and packet loss detection latency ≤ POFTakeAnyTime.

*Proof sketch:* Ordering buffer holds only when `seq > Last+1`. Any replica on longer path either arrives ≤Δ later or is lost. Waiting Δ thus ensures predecessor either arrives or is declared lost, then gap filled. Formal liveness follows PEF duplicate-free guarantee [4][5].

Complexities: 28-bit seq → 268M window; history bitmap O(W) memory; duplicate check O(1) via hash. MPLS variant encodes SeqNum in CW (RFC 8964 [6]), IP variant via PREOF CW over UDP/IP [6].

### 3.3 Integration with TSN FRER

IEEE 802.1CB FRER and DetNet PREOF YANG unified model `ieee802-dot1cb-frer` ↔ `ietf-detnet`. Practical deployment uses CB cross-layer mapping: TSN edge → DetNet core → TSN edge.

## 4 5G URLLC and TSN/MPLS-DetNet Composition

### 4.1 5G as Logical TSN Bridge

3GPP Rel-16 defines **Fully Centralized Model**: TSN AF interacts with Centralized Network Configuration (CNC) via TSN Application Function. 5GS appears as bridge(s): Device-Side TSN Translator (DS-TT) at UE, Network-Side TT (NW-TT) at UPF. TSN ingress/egress ports mapped to 5G QoS flows (5QI 82-85 strict) [7].

Important primitives [8]:

- **Slot structure**: NR numerology µ: slot = 1/(2^µ) ms @14 OFDM. Mid-band µ=1 → 0.5 ms; mmWave µ=3 → 0.125 ms. Sub-slot (type B) 2/4/7 symbols → 0.071 ms mid-band [8].
- **Configured Grant** eliminates SR → alignment delay ↓ to 0.1 ms.
- **PDCCH monitoring** periodicity 1-2 OFDM → scheduling delay ↓.
- **HARQ**: URLLC uses *multiplicative reliability*: k repetitions / blind retransmits for 10⁻⁵ within 1 ms; Chase combining.

gNB scheduler is **central admission controller**: QoS flow with PDB (Packet Delay Budget) 1–10 ms, PER 10⁻⁶. To achieve bounded low latency, licensed spectrum + preemption ensures deterministic resource allocation – similar philosophy to TAS but in frequency-time grid [8].

Time sync: **5G internal sync + PTP**. gNB distributes reference time via SIB9 (0.25 µs granularity). UE-DS-TT sync error ≤ 900 ns (Rel-17 target) – compatible with 802.1AS <1 µs [7].

### 4.2 5G-DetNet-TSN Interworking

Carleton-Ericsson project identifies three integration vectors: *Cloudification of DetNet/TSN reliability functions, 5G-DetNet integration, dynamic configuration establishment* [7]. Model:

```
Sensor (802.1Qbv end-st) → TSN L2 (gated) → DS-TT → 5G RAN (mini-slot)
      → UPF/NW-TT → DetNet service (PREOF N path MPLS/IP) → DetNet forwarding (TE, explicit route, queuing)
      → TSN GW → Actuator
```

Each translation preserves **Flow-ID** and **SeqNum** across encapsulations [6].

## 5 Bounded Latency Guarantee Calculus

### 5.1 Compositional Bound

Let path *Π = {h0..hM}* concatenated segments. Per RFC 8655 and TSN models, deterministic bound requires:

***End-to-End Determinism Triangle: bandwidth reservation ∩ explicit routing ∩ sequence guarding***.

Formal:

$$
L_{e2e} = \sum_{h \in \Pi} ( T_{proc,h} + T_{queue,h}^{tas} + T_{tx,h} + T_{prop,h}) + L_{pof} + L_{5G}
$$

Where:

- *T_{proc}*: <5 µs bridge, ~0.2 ms 5G UPF DS-TT translation.
- *T_{queue}^{tas}*: deterministic given GCL. If Qbv window satisfies $T_{window} ≥ maxFrame+IFG$, and no interference due to isolation, queuing delay = 0 for scheduled traffic [3][10].
- *T_{tx} = L / R*; 1500B@1Gbps=12 µs, @25Gbps=0.48 µs.
- *T_{prop} ≈ 5 ns/m*.
- *L_{pof} ≤ \Delta_{paths}* per Theorem.
- *L_{5G} ≤ PDB_{5QI} = slot_alignment + wait_for_grant + k*repetitions*.

> **Theorem – Compositional Bounded Latency.**
> *If* (i) each TSN bridge implements Qbv with synchronous cycle *h* and guard band obeying `window ≥ frame + GB`, (ii) DetNet PREOF configured with `POFMaxDelay ≥ max_i,j |d_i-d_j|`, (iii) 5G logical bridge guarantees PDB_{urlLC} ≤ D_{5G} via dedicated 5QI and TT residence accounting, *then* for any flow *f* with cycle ≤ deadline *D_f*:
>
> $$ L_{e2e}(f) ≤ D_{TSN} + D_{5G} + Δ_{PREOF} + ε_{sync} $$
>
> where $ε_{sync}= (|Π|-1)·sync\_error$, *and jitter ≤ max_window - min_window + ε_sync*.
>
> *Proof sketch in [3][4][5] via Network Calculus max-plus convolution; Qbv shaper = time-division service curve β(t)=C·[t-window]⁺.*

Numerical example (typical Industry 4.0 cell):

- TSN edge 3 hops: 3×50 µs = 150 µs (12 µs tx, rest proc/cycle align)
- 5G RAN: 0.5 ms slot with 2× mini-slot repetitions = 0.8 ms worst
- DetNet core (2 replicas, IP-over-MPLS): 2 ms delay difference, POF 2.1 ms max
- Sync error 1 µs × 6 = 6 µs
- **Total ≤ 3.0 ms** within 5 ms closed-loop budget, enabling 99.999% delivery at 2 path diversity (*loss 1e-8*).

### 5.2 Limitations and Tradeoffs

- *GCL capacity fragmentation*: Large *h* LCM of periods → unschedulable [1][3]; use hyperperiod decomposition.
- *State vs reliability*: PREOF doubles bandwidth; 1+1 protection efficient for critical, wasteful for bulk – use only critical flows classification via 5-uple.
- *Wireless uncontrollability*: Fading violates determinism – 5G relies on over-provisioned spectrum, not perfect; integrated TSN only gives bounded under licensed, interference-free factory NPN.
- *POF burstiness*: Conditional buffer adds jitter; place shaping after POF or de-jitter buffer to reclaim regularity [4].
- *Unscheduled talkers*: [3] shows worst-case delay analysis with leaky-bucket arrival curve for unsynchronized COTS sensors still yields bounded but larger bound (e.g., +35 µs/hop at 1 Gbps, 50% BE load).

### 5.3 Operational Open Issues

1. **Dynamic reconfiguration**: Qbv + Qcc CNC currently static; frequent flow add/removing needs **2P-DGA-like lightweight solvers** <100 ms [9].
2. **DetNet controller plane**: PCE must compute maximally disjoint explicit routes with delay range constraint ≤ POFMaxDelay; NP-hard. Heuristics based on k-disjoint shortest pair.
3. **Calibration of `POFMaxDelay_i`**: advanced POF requires per-path delay estimator via TWAMP/STAMP [DetNet OAM draft] – round-trip live.

Config YANG snippet for Qbv + DetNet:

```yang
detnet:flow {
  flow-id 42;
  service {
    prf { next-hop [ r1 r2 ]; }
    pef { history 16; }
    pof { max-delay 2100000ns; take-any 50000000ns; }
  }
  forwarding {
    explicit-route [ s1 s2 s3 ];
    qbv-gcl {
      cycle 100us;
      entry 0 { mask 0x01; dur 30us; }
      entry 1 { mask 0x00; dur 70us; guard-band 1.2us; }
    }
  }
}
```

## 6 Conclusion

Determinism is ***not an accident of low load – it is engineered emptiness***. IEEE 802.1Qbv engineers emptiness in time via gate masks, DetNet PREOF engineers emptiness in topology via disjoint replicas, 5G URLLC engineers emptiness in spectrum via grant-free preemption. The three together satisfy the triad required by cyber-physical determinism per RFC 8655 [11]: guaranteed minimum latency (forwarding sub-layer resource reservation), bounded worst-case latency (explicit scheduling), and zero loss under single faults (service protection).

Our calculus shows sub-5 ms motion loops over 3-domain heterogeneous network feasible when Qbv windows sized ≥ IFG+frame, guard bands ≤1 µs via preemption, POF configured ≥ path Δ, and 5G PDB ≤1 ms provisioned via 5QI 82 / DS-TT residence-aware scheduling. Future work: co-optimizing *GCL × PREOF path × 5G numerology* as joint MILP, learning-based POF parameter auto-tuning via digital twin delay telemetry, and hardware acceleration of POF ordering in P4/Tofino alongside Qbv TAS [9].

*Deterministic networks are clocks first, switches second.*
