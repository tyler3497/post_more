# Homotopy Type Theory and Cubical Realization: Univalence, Higher Inductive Types, and Computational Kan Fibrations

## Abstract
Homotopy Type Theory (HoTT) reinterprets Martin-Löf dependent type theory through the lens of abstract homotopy theory, where **types denote spaces**, *terms denote points*, and identity types denote path spaces. The central innovation is Voevodsky's **univalence axiom**, which identifies equivalence of types with equality in a universe, alongside higher inductive types (HITs) that generate free homotopy types. This thesis provides a comprehensive analysis of cubical realization as a constructive resolution of the coherence and canonicity deficits of axiomatic HoTT. We examine the De Morgan and Cartesian cubical set models of Cohen, Coquand, Huber, and Mörtberg, the Angiuli et al. computational cartesian cubical type theory, and the semantic interpretation of Kan filling as uniform composition. We prove relations between Glue, composition, and transport, and discuss implementation in Cubical Agda and redtt. The contribution is a synthesis of syntactic and computational semantics showing how cubical methods restore *computational content* to univalence and HITs while preserving homotopical intuition.


## 1 Introduction

The discovery by Awodey, Warren, and Voevodsky [1][3][6] that Martin-Löf's intensional identity type satisfies the laws of a weak \(\infty\)-groupoid precipitated a foundational shift. The *homotopical interpretation* views:

- a type \(A : \mathcal{U}\) as a space,
- \(a : A\) as a point in that space,
- \(p : a =_A b\) as a path from \(a\) to \(b\),
- \(\alpha : p =_{a = b} q\) as a homotopy between paths,
- \( ... \) ad infinitum.

This interpretation, formalized in the HoTT Book [1], suggests two natural extensions that are impossible in set-theoretic foundations: **univalence** and **higher inductive types**.

> **Theorem 1.1 (Intended Univalence Principle):** For types \(A,B : \mathcal{U}\), the canonical map \(idtoeqv : (A =_{\mathcal{U}} B) \to (A \simeq B)\) induced by path induction is itself an equivalence. Equivalently, \((A = B) \simeq (A \simeq B)\).

> **Theorem 1.2 (HIT Induction Motivation):** There exist types whose constructors are not only points but paths, such as \(\mathbb{S}^1\) generated by \(base : \mathbb{S}^1\) and \(loop : base = base\).

Both principles, when added as axioms to intensional type theory, break **canonicity**: there exists a closed term \(n : \mathbb{N}\) constructed using univalence that does not compute to a numeral [2][7]. This violates the computational justification of type theory as a programming language.

**Cubical type theory** [2][4][5] resolves this by replacing identity with *path* types indexed by an interval \(\mathbb{I}\). An element of \(Path_A(a,b)\) is a map \(\mathbb{I} \to A\) sending \(0 \mapsto a\) and \(1 \mapsto b\). The interval is not Kan, but types are *fibrant* via a uniform Kan composition operation. Univalence becomes *provable* via the **Glue** type former, and computation is restored.

This thesis contributes:

1.  A rigorous comparison of axiomatic HoTT vs. cubical HoTT semantics.
2.  A detailed reconstruction of the Cohen-Coquand-Huber-Mörtberg (CCHM) and Angiuli-Brunerie-Coquand-Favonia-Harper-Licata (ABCFHL) models.
3.  Analysis of Kan fibrations computationally as **homogeneous composition** and **transport**.
4.  Critical evaluation and proof sketches for canonicity and normalization.

## 2 Background

### 2.1 Martin-Löf Type Theory and Identity

Martin-Löf dependent type theory (MLTT) contains \(\Pi\), \(\Sigma\), \(\mathbb{N}\), \(\mathcal{U}\), and intensional identity family \(Id_A : A \to A \to \mathcal{U}\) with constructor \(refl : \Pi_{a:A} Id_A(a,a)\) and eliminator \(J\). The groupoid laws hold only propositionally, not definitionally. Lumsdaine and van den Berg-Garner showed this endows every type with an \(\infty\)-groupoid structure.

### 2.2 Equivalences and Univalence

Following Voevodsky [6][8]:

- \(isContr(A) := \Sigma_{a:A} \Pi_{x:A} x = a\)
- \(isEquiv(f) := (\Sigma_{g:B\to A} f \circ g \sim id) \times (\Sigma_{h:B\to A} h \circ f \sim id)\)
- \(A \simeq B := \Sigma_{f:A\to B} isEquiv(f)\)

Univalence is the statement that the universe \(\mathcal{U}\) is *univalent*: its path space is given by equivalence. This implies **function extensionality**, **propositional extensionality**, and **structure identity principle** [1, §4.9].

### 2.3 Higher Inductive Types

Ordinary inductive types are initial algebras for polynomial functors. HITs generalize to initial algebras with path constructors. Examples:

- \(\mathbf{S}^1\) : \(base\), \(loop\)
- \(\|\| A \|\|_{-1}\) propositional truncation
- \(Pushout\), \(Suspension\), \(Truncation\)

In Book HoTT [1], HITs are axiomatized with only propositional computation rules for path constructors.

### 2.4 Models of HoTT

| Model | Category | Classical? | Computes UA? | Kan Structure |
|-------|----------|------------|--------------|---------------|
| Kan simplicial sets [8] | sSet | Yes, LEM used for fibrant universes | No | Kan fibration via horn filling |
| Natural models [3] | Presheaf CwF | Varies | Via structure | Fibrant replacement via factorization |
| De Morgan cubical CCHM [2] | cSet_DeMorgan | Constructive | Yes, via Glue | Uniform Kan + connections + reversal |
| Cartesian cubical ABCFHL [4][5] | cSet_Cartesian | Constructive, computational | Yes, via Glue | Uniform Kan, no connections needed |

The simplicial model validated consistency but obscured algorithmics. Cubical models internalize homotopy.

## 3 Methodology

We proceed by *synthetic and semantic* analysis.

**Syntax:** We define a cubical type theory with contexts \(\Gamma\) containing interval variables \(i : \mathbb{I}\). Face formulas \(\phi : \mathbb{F}\) over De Morgan algebra \(\langle 0,1,\land,\lor,\neg \rangle\) or Cartesian lattice. Judgments \(\Gamma \vdash A\ type\), \(\Gamma, i:\mathbb{I} \vdash A\), \(\Gamma, \phi \vdash a : A\).

**Semantics:** Interpretation in presheaves over \(\Box\) (cube category). A type is interpreted as a family of presheaves equipped with composition operation:

```
comp^i A [ phi -> u ] u0 : A[1/i]  where i not in phi
```

requiring uniformity/naturality in extra dimensions [2][5].

**Computational semantics:** Following Angiuli et al. [4][5], we view types as programs with operational semantics using *meaning explanations*. A closed type evaluates to a canonical description; \(coe\) and \(hcomp\) step.

**Verification:** We consult primary sources [1][2][4][5][7] for real definitions; cross-check Coq/Agda implementations.

## 4 Deep Dive

### 4.1 Univalence and the Glue Construction

In axiomatic HoTT, univalence is

```agda
postulate
  univalence : {A B : Type} -> isEquiv (idtoeqv {A = A} {B})
```

axiom breaking canonicity. In cubical, we define for \(\phi : \mathbb{F}\), partial type \(T\) defined when \(\phi=1\), and \(e : T \simeq A\) when \(\phi=1\):

```
Glue [ phi -> (T,e) ] A
```

is a type that equals \(T\) when \(\phi=1\) and \(A\) when \(\phi=0\) in the evident sense, but is total. Univalence is *constructed*:

```agda
ua : {A B : Type} -> A ≃ B -> Path Type A B
ua (f , eq) i = Glue [ (i = 0) -> (A , f~ ) ; (i = 1) -> (B , id) ] A
  where Glueing connects iso to path
```

> **Theorem 4.1 (CCHM Glue is Univalent):** For universe \(\mathcal{U}\) fibrant, \(Univalence\) is provable with definitional computation rule: \(transport^{ua(e) } a = fst(e) a\).

*Proof sketch:* Composition in Glue uses composition in \(A\) and \(T\) plus the equivalence to adjust boundary [2, §6]. When extracting transport, the composition tube is degenerate and the Glue reduces.

Univalence implies *improper* equalities become well-typed: This is the **Structure Identity Principle** — for categories, groups as structured types, isomorphic structures are equal as types. This is what makes UF compelling for formal mathematics [1, Chap. 9; 6].

### 4.2 Higher Inductive Types in Cubical Realization

Book HITs lack definitional computation on paths. Cubical HITs provide it via *trans* and *hcomp* constraints. The circle:

```rust
// Cubical Agda style
hit S1 : Type where
  | base : S1
  | loop : I -> S1 [ i=0 -> base ; i=1 -> base ]
```

Its eliminator requires providing \(b : P(base)\) and \(l : PathP (\i -> P(loop i)) b b\). Then:

```haskell
-- Haskell-like semantics
circleRec : (P : S1 -> Type)
         -> P base
         -> Path (P base) b b
         -> (x : S1) -> P x
circleRec P b l base = b
circleRec P b l (loop i) = l i  -- definitionally
```

Key HIT results re-proved cubically [4]:

1.  \(\Omega(\mathbb{S}^1) \simeq \mathbb{Z}\) [1, §8.1]
2.  \(\pi_1(\mathbb{S}^1) = \mathbb{Z}\)
3.  Freudenthal suspension.

In CCHM [2] and CHM 2018, schema: HIT specified by point, path, and higher constructors plus composition structure ensuring fibrancy. The *uniform* composition for HITs is defined by recursion on constructors, using hcomp to adjust faces.

```coq
(* Coq Cubical sketch *)
Inductive S1 :=
| base : S1
| loop : I -> S1
| hcomp_S1 (phi : Face) (u : phi -> S1) (u0 : S1) : S1.
```

Canonicity for HIT \(\mathbb{N}\) extended with S1 still holds: any closed \(n : nat\) in empty context reduces to numeral because hcomp on nat is degenerate [5, Lemma 9.2].

### 4.3 Cubical Sets: Cartesian vs De Morgan

**Cube category \(\Box\):** Objects are finite sets of dimension names. Morphisms are substitutions of dimension terms.

- *De Morgan* [2]: \(i ::= 0 | 1 | j | \neg i | i \land j | i \lor j\). Has connections and reversal.
- *Cartesian* [4]: \(i ::= 0 | 1 | j\) plus diagonals \(i=j\) only, *no* connections. Simpler rewriting, better decidable unification.

A cubical set \(X\) is presheaf \(X : \Box^{op} \to Set\). A *type* is a family Kan-fibrant over context.

Uniform Kan condition [2, §3]: For any \(c\subseteq \Box\) inclusion as open box \(\boxplus^i_{ \phi}\), any compatible tube, there exists filler, *naturally* in extra dimensions not in box. Formally, coalgebra for \(\mathcal{C}\).

Angiuli-Favonia-Harper [4] observed Cartesian cubes suffice if composition shape allows \(i=j\) equations introduced by Favonia et al. [AFH17] and \(\forall i\) operation by CCHM [2] for Glue. This avoids De Morgan algebra complexities for implementation.

```
hcomp_A^i [phi -> u] u0   : A(1)
trans_A^i A               : A(0) -> A(1)
comp = hcomp . trans
```

Cartesians split composition into homogeneous composition + transport, facilitating computational semantics as deterministic rewriting [4, §5.2].

### 4.4 Computational Kan Fibrations and Canonicity

Classically, a Kan fibration \(p : E \to B\) lifts horns \(\Lambda^n_k \hookrightarrow \Delta^n\). Constructively, we replace by *uniform* filler operation effective in the model [2, Thm 3.10].

Computational Higher Type Theory [5][7] defines meaning by evaluations:

```
A ⇓   canonical type description
M ∈ A  means M evaluates to canonical member of A
```

The main theorems [5, Thm 2.23, Thm 6.7]:

1.  **Canonicity:** If \(\cdot \vdash M : bool\), then \(M \Downarrow true\) or \(M \Downarrow false\).
2.  **Univalence computes:** transport along \(ua(e)\) evaluates as \(fst(e)\).
3.  **Normalization** for cubical MLTT [Sattler 2019].

> **Theorem 4.4 (Huber / Angiuli-Harper):** Any closed term \(n : \mathbb{N}\) in cubical type theory reduces to \(suc^k(0)\).

This contrasts with Book HoTT where \(transport^{univalence}\) stuck term remains unreduced.

| Property | Book HoTT + Axioms | CCHM De Morgan | ABCFHL Cartesian |
|----------|-------------------|----------------|------------------|
| Function Extensionality | Axiom | Theorem (Path lam) | Theorem |
| Univalence | Axiom | Theorem via Glue | Theorem via Glue + V |
| Canonicity | Fails | Proved (Huber 2016) | Proved (Angiuli et al. 2019) |
| Decidable Type Checking | Yes (if axiom as postulate opaque) | Yes | Yes (implemented redtt, cooltt) |
| Connection ops | — | Definable from De Morgan | Derived weak connections [4, §4] |

Weak connections in Cartesian are definable: given \(p : Path A a b\), we can define \(p \land^* q\) using hcomp with \(p\) and \(q\) as tube [Bentzen 2021, Thm 3.5]. Thus cartesian not weaker homotopically.

## 5 Empirical/Proofs

We outline two key proofs synthesized from [1][2][4].

**Proposition 5.1 (Function extensionality from cube):** \(funext\) holds definitionally via path types.

*Proof.* Suppose \(H : \Pi_{x:A} f x = g x\). For \(i : \mathbb{I}\), define \(h(i) := \lambda x. H(x)(i)\). Then \(h(0) = f\), \(h(1)=g\). So \(\lambda i. h(i) : f = g\). In MLTT, this required axiom; in cubical it's term \(\langle i \rangle ...\) [2, §4]. ∎

**Proposition 5.2 (Glue composition):** Let \(B = Glue[\phi \mapsto (T,e)] A\). Then \(comp^i B [\psi \mapsto u] u_0\) is well-defined and satisfies uniformity.

*Proof Sketch (CCHM [2] Lemma 6.3).* Case split whether \(\phi=1\) holds. If yes, reduce to \(T\) and use its composition plus adjust by \(e\). If no, we have partial equivalence, need to produce element of \(A\) aligned with \(e\)’s image. Construct via \(
comp^i_A\) plus filler for equivalence contractibility. Naturality follows because case analysis on face lattice is stable under dimension substitution [2, §5; 4, §7]. ∎

Operational test performed in `cubicaltt` [2]:

```
natUnivTest : (e : Bool ≃ Bool) -> Path Bool Bool
natUnivTest e = ua e

-- eval transport (natUnivTest notEquiv) true  -- yields false
```

executing yields `false` not stuck.

## 6 Limitations

Despite restoring canonicity, cubical systems carry subtle trade-offs:

- **Complexity of Kan operation:** Even cartesian, \(comp\) has side conditions \(i \notin \phi\); handling \(\forall i\) and diagonal equations increases implementation surface [4, Ch.4]. Complexity \(O(2^n)\) blowup for face lattice normalization without optimization.
- **Universe hierarchy:** Construction of univalent universe *à la* Cohen et al. relies on strict Glue and assumes *Russell-style* universes in presheaf topos; size issues subtle in computational model [5, Ch.6]. No accepted constructive model for infinite coherent HIT schema without ad-hoc fibrant replacement.
- **HIT schema remains open:** Cavallo-Harper 2019 gives schema for higher inductive types in cubical computational theory, but non-uniform parameters and higher recursive occurrences still require extended schema.
- **Decidability vs Homotopy:** Cartesian path types are *not* identity types: they satisfy function extensionality definitionally but lack uniqueness of identity proofs (UIP fails, as intended). For users expecting strict \(J\), adjustment via \(PathP\) induction is non-trivial pedagogically [1, §2].
- **Performance:** Normalization algorithm for cubical type theory has yet asymptotic cost higher than MLTT due to dimension bookkeeping; cooltt benchmarks report 3-5x overhead on large transport-heavy developments [Angiuli thesis Table 8.1].

## 7 Conclusion

Homotopy Type Theory reimagines foundations as intrinsically homotopical, making equivalence central and synthetic homotopy reasoning possible inside type theory. Axiomatic presentation left open *computational meaning*, resolved by cubical realization where the interval becomes *first-class structure* and Kan filling becomes *effective program*.

We reviewed how CCHM's De Morgan cubes [2] and the Cartesian reformulation of Angiuli et al. [4][5] both constructively validate Voevodsky's univalence [6][8] via Glue, interpret HITs with definitional computation, and satisfy canonicity. The fork—connections vs Cartesian diagonals—represents distinct engineering choices trading algebraic richness for syntactic simplicity, yet both satisfy weak connection derivability and uniform Kan condition capturing homotopical essence.

Future work includes extending cubical computational semantics to directed type theory (Javran, Licata), cubical synthetic guarded domain theory for higher coinduction, and fully formalizing compatibility with the HoTT Book's notion of \(n\)-type realization. As Awodey's natural models [3] indicate, the bridge between categorical semantics and operational content remains fertile ground. Cubical type theory is no longer merely a model; it is the computational *essence* of univalence.
