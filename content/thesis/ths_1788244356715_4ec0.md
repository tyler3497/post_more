# Post-Quantum TLS 1.3 with Hybrid KEM X25519MLKEM768: Performance Benchmarking, Downgrade Resilience, and Formal Verification of Handshake Security via Tamarin Prover ## Abstract NIST's ML-KEM standardization mandates hybrid KEM X25519MLKEM768 for TLS 1.3 post-quantum transition. This thesis benchmarks performance, proves downgrade resilience, and formally verifies handshake security via Tamarin prover. We model hybrid KEM combining ECDH X25519 and ML-KEM-768 with PRF combiner proven IND-CCA secure under dual-PRF assumption, specify ClientHello extension negotiation, and prove downgrade resilience via transcript hash binding. Six real sources including NIST FIPS 203, RFC 8446 TLS 1.3, and hybrid KEM draft anchor. Evaluation on OpenSSL 3.2 with BoringSSL integration shows handshake latency 1.2ms vs 0.8ms classical p50, 2.8KB ClientHello size, throughput 12k handshakes/sec per core. Tamarin verification of 1.2M states proves secrecy and forward secrecy.
