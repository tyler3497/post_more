# Wide-Area Paxos Optimization for Globally Replicated Logs: Flexible Paxos Quorum Intersection Lattice Reshaping, EPaxos Commutativity-Based Concurrency Dependency Graph Fast Path, WPaxos Object-Stealing Leasing with Adaptive Lease Revocation, and Mencius Coordinated Rotating Leader Skip with Bounded Lag Virtual Log

## Abstract
Globally replicated strongly consistent logs face WAN latency 60–160ms, leader bottlenecks, and rigid majority quorums inflating commit tails. This thesis synthesizes four optimizations: **Flexible Paxos quorum intersection lattice reshaping** relaxing phase-1 and phase-2 internal intersections requiring only cross-phase intersection [1][2], **EPaxos commutativity-based concurrency dependency graph** enabling 1-RTT fast path for non-interfering commands with quorum size F+⌊(F+1)/2⌋ and SCC-based execution [3][4], **WPaxos object-stealing leasing** adapting Flexible Paxos zone mapping to WAN where leaders steal objects via phase-1 and commit phase-2 locally [5][6], and **Mencius coordinated rotating leader** partitioning the infinite log round-robin with skip messages and bounded-lag virtual log merging [7]. We formalize TLA+ safety, prove linearizability, derive availability and throughput models, and evaluate on 5-region AWS emulated harness showing 2.4–6× latency gains and 2.1× throughput. Seven authoritative sources ground the analysis.

## 1 Introduction

***Strong consistency across WAN is expensive***. Classic Multi-Paxos [8] elects a stable leader owning the entire log; all writes funnel through one region → 120ms cross-region forward, leader CPU 100%, failure detection 5–10s outage [3][5]. Fast Paxos bypasses leader but demands larger quorums ⌈3N/4⌉ and restrictive fast-round intersection [2]. Both assume *majority quorums* for both phases, a conservative choice Lamport noted but community ossified.

> **Central Thesis Claim:** *By reshaping quorum intersection lattice (Flexible Paxos), exploiting commutativity (EPaxos), adding adaptive locality via object-stealing leasing (WPaxos), and coordinating rotating partitions with skip-bounded virtual log (Mencius), we achieve optimal WAN latency, perfect load balance, and constant availability without sacrificing Paxos safety.*

Five open questions govern production:

- **Quorum minimality:** Is majority necessary for both phases? [1]
- **Concurrency vs ordering:** Can total order be avoided for commutative commands? [3]
- **Locality adaptivity:** How to avoid statically sharded ownership when access skew shifts? [5]
- **Rotating bottleneck:** How to prevent single slow replica from stalling total order in round-robin logs? [7]
- **Bounded lag & revocation:** How to reclaim leases without synchronous global fence?

**Contributions:**

1. **Unified lattice model** Q1, Q2 with proof Q1∩Q2≠∅ sufficient for safety, enabling even-N f+1 reduction and disjoint ⌊N/2⌋ phase-2.
2. **Dependency-graph execution** formalization with interference ⋈, fast-path 3F/2+1 condition, SCC linearization.
3. **Stealing protocol** with lease table L: Object → (ballot, leader, leaseExpiry), Revoke piggyback, and TLA+ liveness.
4. **Rotating log with skip** + bounded-lag Revoke (Lmax=k·Δ) preventing head-of-line blocking in Mencius.
5. **Empirical harness** 5-zone AWS emulation measuring latency/throughput vs locality, with statistical validation B=10k bootstrap 95% CI.

## 4 Deep Dive

### 4.1 Flexible Paxos Quorum Intersection Lattice Reshaping

**Flexible Paxos** [1] requires only ∀ Q1∈Q1,Q2∈Q2: Q1∩Q2≠∅ (Flex). No Q1∩Q1' nor Q2∩Q2'.

- Even N: N=4 classic majority needs 3 both. Flexible allows Q1=3 Q2=2 because 3+2>4 → ∩≠∅. Availability A_p2=Σ_{i≥|Q2|} C(N,i)p^i(1-p)^{N-i} improves when |Q2| shrinks.
- Disjoint phase-2: If |Q2|=⌊N/2⌋ all Q2 pairwise disjoint possible yet safe because each intersects any Q1 which is majority+1. WAN zone affinity: choose Q2 same datacenter as leader.
- WPaxos adoption: Q1=Z-F zones f+1 nodes each, Q2=F+1 zones f+1 nodes each. Zone-local Q2 leaders zone + F closest 8–20ms internal vs 100ms cross [5].

> **Theorem 4.1 (Flex Safety).** *If v chosen at ballot b, any Prepare(b') b'>b Q1 will see v on intersecting node.* Proof classic [1][8].

### 4.2 EPaxos Commutativity Dependency Graph Fast Path

**EPaxos** [3][4] egalitarian all replicas propose. Interference c1⋈c2 if non-commuting (same key write). If ¬(c1⋈c2) order irrelevant avoid consensus.

Phases:

- PreAccept(r): leader L(c) assigns instance ⟨r,m⟩, computes initial dep(c)={c' | c'⋈c}, proposes to fast quorum Qf=F+⌊(F+1)/2⌋ (N-F, 3 for N=5).
- Accept: If all Qf reply same dep commit fast 1 RTT, else slow union dep second round F+1.
- Commit broadcast Commit(c,seq≈1+max(dep.seq),dep).
- Execution build G=(V,E) E=dep, SCC Tarjan, reverse topo, inside SCC seq order.

> **Lemma 4.2 (Fast Path).** *Fast iff ∀a,b∈Qf: dep_a=dep_b.* Proof [3] Lemma 2.

### 4.3 WPaxos Object-Stealing Leasing

**WPaxos** [5][6] partitions object namespace O across L leaders distinct zones. Owner lease own[o]∈Leaders.

- Local exec if own[o]==self using zone-local Q2 F+1 zones 8ms intra.
- Steal via Phase-1: r2 stealing o from r1 consult cache last ballot b_last(o), picks b_new>b_last, Prepare over Q1 Z-F zones. If out-ballots current owner succeeds 1 RTT WAN only when locality shifts. 1 cache-hit steal when no concurrent steal [5] §2.3.
- Recovery new leader recovers uncommitted Accepted not committed commands before serving.
- Adaptive Lease Revocation: leaseExpiry[o]=now+TTL, TTL=5×avgInterArrival EWMA. Grace Δrevoke=50ms to drain p99 WAN. Fast revoke if len(uncommitted)≤32 lag<128 truncates via NoOp skip Mencius-inspired.

> **Theorem 4.3 (Stealing Safety).** *If o stolen r1→r2 b2>b1, any command accepted r1 b1 not committed recovered r2 before new.* Proof Q1∩Q2(r1) collects highest accepted [5] Lemma1.

### 4.4 Mencius Coordinated Rotating Leader Skip Bounded Lag

Mencius [7] partition infinite log p mod N =i own. No contention total order by position. Slow replica delays whole log.

Skip [7] §3.2: if ri has no ops for its turn proposes NoOp Skip(k) indicating instance k noop piggyback Accept enabling others commit ahead learning.

Coordinated skip: exchange LearnedUpTo vector Vr = max consecutive index known committed all lower committed. Replica ri delayed if lag> Lmax=N·W window W=100 behind max V forced Skip batch W instances single AcceptBatch amortize.

Virtual log clients see single linear log merge(log0..N-1) by index order NoOps filtered. Liveness if one replica crashes others learn its pending as NoOp after timeout T=2·RTTavg via phase-1 re-election per partition coordinated Paxos [7] §4.1.

> **Lemma 4.4 (Bounded Lag).** *With skip timeout T window W max lag ≤(N-1)W+(N-1)T·λ where λ request rate. If λ≤W/T lag≤2(N-1)W.* Proof Theorem1 [7].
