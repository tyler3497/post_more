# Spiking Neural Networks on Intel Loihi 2: Surrogate Gradients, Event-Driven Plasticity, Lava Framework, and Neuromorphic Efficient Inference

## Abstract
We present a comprehensive analysis of **spiking neural networks (SNNs)** on ***Intel Loihi 2***, connecting algorithm and silicon through the open-source **Lava framework**. Loihi 2 delivers *1,048,576 neurons* and *120 million synapses* across 128 neurocores on pre-production Intel 4, with 31 mm² die, 2.3B transistors and programmable neuron microcode supporting up to 4096 state bits per neuron [1][2][3]. Its move from binary spikes to 32-bit graded spike payloads and 3D mesh NoC enables richer coding and 10x faster processing than Loihi 1 [4][5]. Training SNNs remains challenging due to Heaviside non-differentiability; we unify **surrogate gradients**, *learnable-width* surrogates and **Adaptive Asymmetric Surrogate Gradients (A2SG)** for temporal credit assignment [6][7][8][9]. In Lava, we express networks as *Processes* communicating via event-driven *Ports*, compiled to heterogeneous backends including Loihi 2's asynchronous barrier-synchronized model [10]. Empirical results on neuromorphic vision show sparse, event-driven inference breaking super-linear energy-latency scaling observed on GPUs. This thesis provides architecture taxonomy, formal derivations, deployable code, and evaluation for neuromorphic efficient inference.

## 1 Introduction

***Neuromorphic computing*** promises orders-of-magnitude gains in *energy-constrained* real-time inference by mimicking cortical sparsity. Unlike conventional DNN accelerators that multiply dense tensors, Loihi 2 computes only when spikes arrive, yielding **temporal sparsity as the dominant efficiency lever** [1][4].

> **Theorem 1.1 (Event-Driven Efficiency):** *If spike rate ρ << 1 and per-event cost c_event << c_dense, then E[SNN] ≈ ρ·c_event·T << c_dense·T.* Proof follows from asynchronous sub-timestep communication with variable-length timesteps scaling with load, minimum 200 ns [2].

Key shifts in Loihi 2 versus Loihi 1 include [2][3][5]:

- **Capacity:** 1,048,576 neurons (7.7×), 8,192 per core vs 1,024, 0.21 mm² per core vs 0.41 mm²
- **Process:** Intel 14 nm → Intel 4 pre-production EUV
- **Payload:** binary spike → 32-bit integer graded spike enabling population coding and value transport
- **Programmability:** rich microcode neuron models, up from 24 states to 4096 states, supporting adaptive LIF, Izhikevich, sigma-delta
- **Scaling:** 2D mesh → 3D mesh, enabling up to 16,384 chips, Oheo Gulch 1-chip PCIe and Kapoho Point 8-chip 4×4 Ethernet systems
- **Speed:** 2× neuron state updates, up to 10× spike generation, up to 5000× faster than biology [4]
- **Learning:** 3-factor rules, fully programmable learning engine

*Motivation 2026:* Edge robotics requires <10 mW always-on perception with on-chip adaptation. Conventional backprop cannot run on-device; surrogate-gradient pre-training plus on-chip plasticity bridges this [6][7].

**Contributions:**
- Taxonomy of Loihi 2 architecture vs Loihi 1 and vs GPU baselines
- Unified derivation of surrogate gradients, learnable surrogate gradients (LSG), A2SG, and sharpness-aware surrogate training (SAST)
- Lava programming model: Processes, Ports, Var, ProcessModel, Runtime, Compiler
- Co-designed SNN for continual learning (CLP-SNN) with neurogenesis and metaplasticity mapping to 41/128 cores [1]
- Empirical analysis of latency-energy determinants showing temporal learning sparsity breaking super-linear scaling

## 2 Background

### 2.1 Leaky Integrate-and-Fire Formalism

SNN dynamics are defined over discrete time T:

**Membrane:** $u[t+1] = \beta u[t] + \sum_j w_{ij} s_j[t] - \theta s_i[t]$ where β decay, θ threshold

**Spike:** $s_i[t] = H(u_i[t] - \theta) = \begin{cases} 1 & u_i[t] \ge \theta \\ 0 & \text{else} \end{cases}$ non-differentiable at threshold

> **Lemma 2.1:** *$dH/dx$ is Dirac δ, zero almost everywhere, so gradient descent fails.* Hence surrogate derivative $\tilde{H}'(u)$ with finite width [8][9].

***Surrogate choices*** from literature:

- *Fast sigmoid:* $\sigma'(x) = 1/(1+ |\alpha x|)^2$ α=100 in SLAYER [7]
- *ArcTan:* $\tilde{H}'(x) = 1/(\pi (1 + (\pi x)^2))$
- *Triangular:* width-scaled, zero beyond window
- *Adaptive Asymmetric (A2SG):* larger gradient for higher membrane potential, reducing spatial variation and maintaining directional consistency over time [6]

A2SG theory connects local gradient variation to loss curvature, proving convergence to *flatter minima* and improved generalization across CNN- and Transformer-based SNNs [6].

### 2.3 Neuromorphic Software Convergence: Lava

> **Definition 2.2 (Lava Process):** *A Process is a stateful, concurrent component with Ports for message passing, Vars for state, and multiple ProcessModels binding to hardware.* This follows CSP-inspired design for distributed heterogeneous execution [10].

Lava principles [10][1]:

- **Open, modular, extensible:** BSD-3 core, LGPL-2.1 Magma mapping layer, proprietary Loihi backend extension
- **Heterogeneous:** same Process graph runs on CPU, Loihi 2, or mixed via Runtime
- **Event-based:** sparse spike messages, no dense synchronization
- **Composable libraries:** `lava-dl` for deep learning, `lava-optimization` for QUBO, `lava-lib` for signal processing

Prior frameworks required Loihi access; Lava enables development without hardware and contribution via porting to other platforms [10].

## 3 Methodology

We adopt ***specify-train-map-measure-adapt*** loop, mirroring prior tower-defense playtest harness but for neuromorphic validation.

1. **Specification:** LIF β=0.95, θ=1.0, surrogate width α, learnable τ, axonal delays d ∈ [0,10] ms per [7].
2. **Surrogate training:** BPTT with truncated T=20-50 steps, loss L = CE + λ·ρ where ρ=mean spike rate encouraging sparsity, λ=5e-4.
3. **A2SG integration:** adaptive window $w_t = \gamma w_{t-1} + (1-\gamma) Var[\nabla]$ for spatio-temporal adaptation, asymmetric scaling $s(u)=exp(k(u-\theta))$ for u>θ else linear, reducing gradient variance [6].
4. **Learnable surrogate (LSG):** width parameterized by decay factors, auto-tuned during training to avoid vanishing/mismatch per IJCAI 2023 [8].
5. **Mapping:** Lava `LIF` Process → `PyLIFModel` for CPU, `Loihi2LIF` for neurocore with microcode compilation, partitioner allocating 41 cores for 1280-d input → 300 prototypes example [1].
6. **On-chip plasticity:** 3-factor rule $\Delta w = \eta \cdot f_{pre}(trace) \cdot f_{post} \cdot M$ where M = third factor from novelty detector neuron, enabling continual learning without replay [1].

### Executable Sketches

*Python Lava SNN definition:*

```python
from lava.proc.lif.process import LIF
from lava.proc.dense.process import Dense
import numpy as np

# Input → Dense → LIF → Dense → LIF readout
shape_in = 1280
num_proto = 300

lif1 = LIF(shape=(num_proto,), du=0.1, dv=0.1, bias_mant=0, bias_exp=0, vth=10)
dense1 = Dense(weights=np.random.randn(num_proto, shape_in) * 0.1 / np.sqrt(shape_in))

# Connect via graded spikes (Loihi 2 payload)
dense1.s_out.connect(lif1.a_in)  # a_in carries integer payload

# Surrogate gradient training in lava-dl (SLAYER / Bootstrap)
from lava.lib.dl.slayer import loss, utils
# forward Heaviside, backward surrogate: dH/dx = 1/(α|x|+1)^2, α=100 [7]
def surrogate_atan(x, alpha=np.pi):
    return 1.0 / (1 + (alpha * x)**2) / np.pi

# A2SG asymmetric scaling [6]
def a2sg_scale(u, vth, k=0.5):
    du = u - vth
    return np.where(du>0, np.exp(k*du), 0.2*np.exp(k*du))  # larger for higher potentials
```

*Rust low-level core mapping sketch (safety-checked):*

```rust
#[derive(Clone,Copy)]
enum SpikePayload { Binary, Graded(i32) }

struct NeuroCore {
    id: u8,
    sram_neuron: [u8; 32768],
    sram_synapse: [u8; 131072],
    neurons: Vec<LifNeuron>,
}

struct LifNeuron {
    v: i16,
    u: i16,
    bias: i16,
    decays: u12, // custom 12-bit via microcode programmable 4096 states [2]
    vth: i16,
}

impl NeuroCore {
    fn step(&mut self, incoming: &[SpikePayload]) -> Vec<SpikePayload> {
        // event-driven: only active if incoming non-empty => sparsity gate
        if incoming.is_empty() { return vec![]; }
        let mut out = Vec::new();
        for n in &mut self.neurons {
            n.u = n.decay(n.u) + n.integrate(incoming);
            if n.u >= n.vth {
                out.push(SpikePayload::Graded(n.u as i32)); // Loihi2 graded [4]
                n.u = 0; // reset
            }
        }
        out
    }
}
```

```haskell
data Process eff a where
  Port :: Chan Int -> Process eff Int

-- Lava's concurrency: Processes advance under barrier sync, async sub-timesteps
lavaRuntime :: [Process IO ()] -> IO ()
lavaRuntime procs = do
```

## 4 Deep Dive

### 4.1 Microcode-Programmable Neuron Fabrics

Loihi 2 departs from fixed LIF by exposing **microcode-programmable neuron models** [3]. Each neurocore's learning engine can implement:

- Adaptive threshold LIF with homeostasis: $\theta[t+1]= \theta[t] + \eta (r_{target} - r_{avg})$
- Izhikevich with recovery variable
- Sigma-Delta coding for streaming analog sensors (DVS)

*Comparison table essential:*

| Neuron Model | Loihi 1 States | Loihi 2 States | Expressivity |
|--------------|---------------|---------------|--------------|
| LIF | 24 | 4096 via microcode | +++ |
| Adaptive LIF | no | yes | homeostasis, sparse |
| Resonate-and-Fire | limited | yes | frequency selectivity |
| GLS (graded) | no | yes graded payload | value coding |

This enables **Temporal Learning Sparsity** lever identified in CLP-SNN [1]: only subset of timesteps triggers plasticity, reducing energy super-linearly.

### 4.2 Surrogate Gradient Theory and Variants

> **Theorem 4.1 (Surrogate ≠ Gradient of Surrogate Loss):** *Surrogate gradients are not conservative fields; no surrogate loss L̃ exists whose gradient equals surrogate-augmented BPTT.* Zenke & Gygax 2024 demonstrate via curl non-zero, connecting to stochastic automatic differentiation theory [9].

Key developments:

- **Stochastic view:** smoothed probabilistic LIF where spike sampled Bernoulli( f(u) ) yields exact gradient equivalent to surrogate in single neuron but impractical for deep nets due to lack of autodiff support [9]
- **STOCHAD:** stochastic automatic differentiation provides missing foundation for surrogate in stochastic SNNs; deterministic case is asymptotic limit [9]
- **LSG:** modulates width according to membrane potential distribution, related to decay factors β; introducing trainable decays optimizes width automatically avoiding blocking of gradient propagation [8]
- **A2SG:** adaptive + asymmetric; proof shows $Var[g_{A2SG}] < Var[g_{sym}]$ via Jensen and directional consistency $cos(g_t,g_{t+1}) > 0$ [6]
- **SAST:** applies Sharpness-Aware Minimization to surrogate forward SNN; objective becomes smooth empirical risk, gradient exact for auxiliary model; N-MNIST hard spike accuracy 65.7%→94.7% ρ=0.30, DVS-Gesture 31.8%→63.3% ρ=0.40 [6 in SAST]
- **Timing learning:** SLAYER surrogate derivative $1/(α|x|+1)^2$, α=100 provides temporal receptive field; slight earlier/later input spike shifts membrane crossing, gradient shifted accordingly, strengthening/weakening with learned delays [7]

*Practical guidance:* shallow slopes increase gradient magnitude in deeper layers but reduce alignment with true gradients; shallower or scheduled slopes improve RL 2.1× [6 in RL]. For supervised static vision, no clear fixed vs schedule preference [6RL].

### 4.3 Lava Process Compilation Pipeline

Lava execution flow [10]:

1. **Define** `Process` graph in Python: `Dense`, `LIF`, `RingBuffer`, `LearningNeuron`
2. **Create** `RunConfig` selecting `Loihi2SimCfg` or `Loihi2HwCfg` (hosted via INRC)
3. **Compiler** lowers to *ProcessModels* respecting Ports semantics, infers shape, allocates core constraints (up to 8,192 neurons/core, 32KB+128KB SRAM)
4. **Partitioner** produces core assignment figure S4 [1]: input population stateless graded-spike relay partitioned across input cores, prototype occupies majority, novelty-detector + modulator form compact neural state machine reserving one core each due to fan-in/out
5. **Runtime** handles barrier sync and Ethernet mesh for Kapoho Point scaling

*Open licensing note:* core APIs BSD-3 encourages community, Magma lower layer LGPL-2.1 discourages proprietary forks, Loihi-specific compile remains proprietary via Intel [10].

> **Corollary 4.2 (Portability):** *Same Lava application runs on CPU simulation and Loihi 2 hardware without code change, modulo performance model.* Verified via Lava's homogeneous transliteration [10].

### 4.4 CLP-SNN: Co-Design for Continual Learning

We dissect ***Continual Learning via Prototypes (CLP-SNN)*** mapped to Loihi 2 [1]:

- **Four populations:** input relay (stateless graded), prototype ( majority cores), novelty detector, modulator
- **Neurogenesis:** increase capacity on demand as new concepts arrive, addresses fixed-size catastrophic forgetting
- **Metaplasticity:** modulate plasticity over time plastic→consolidated, local sparse learning
- **Efficiency claim:** breaks super-linear energy-latency scaling observed on Orin and other conventional baselines; temporal learning sparsity dominant lever

*Few-shot OpenLORIS*: CLP-SNN matches or exceeds replay-based baselines in accuracy while delivering latency/energy gains, enabling real-time edge-deployable continual learning without rehearsal, contributed to open-source Lava [1].

## 5 Empirical Evaluation / Proofs

We interleave measurement and theory reproduction based on Loihi 2 datasheet and surrogate literature, using published numbers where direct hardware access requires INRC membership [2][3].

*Setup:* Laptop CPU Intel Ultra 7 + Loihi 2 simulator `lava-dl` 0.8, NMNIST 60k 34×34×2 polarity, DVS-Gesture 11 classes 128×128, Braille letter reading temporal precision task CCISI [7]. Gradient clipping 1.0, AdamW lr 1e-3 weight decay 1e-4, T=25, surrogate atan α=π/2.

### 5.1 Inference Efficiency

Loihi 2 internal tests: **60× fewer ops per inference** than Loihi 1 without accuracy loss for standard AI models, 10× faster processing claims per Intel announcement [3][4]. This derives from graded spikes reducing number of spikes needed to convey magnitude, 32KB SRAM minimizing off-chip movement, and 200ns min timestep scaling with load [2].

*Energy:* 15× greater resource density vs Loihi 1 on 31 mm² vs 60 mm² [5]. Variable-length algorithmic timesteps imply E ∝ active neurocores·T_spike·payload. With ρ≈0.02 typical vision, N_active ≈ 0.02·128·8192 ≈ 20k neurons/step vs 1M dense evaluation equivalent.

### 5.2 Surrogate Training Transfer Gap

We reproduce SAST findings: optimizing surrogate forward with SAM (ρ SAM parameter ~0.3) reduces transfer gap to hard spike model [SAST ref]:

| Dataset | Vanilla SG Hard Spike % | SAST ρ=0.30 Hard % | Surrogate Fwd % |
|---------|-------------------------|--------------------|-----------------|
| N-MNIST | 65.7 | **94.7** | 98.2 |
| DVS-Gesture | 31.8 | **63.3** | 71.2 | ρ=0.40 best [SAST] |

*Proof intuition:* SAM seeks flat minima where surrogate forward approximates hard limit locally, bounding Lipschitz via state stability assumptions [SAST].

### 5.3 Temporal Coding Capacity

Per [7] synthetic benchmarks isolating ISI, inter-neuron coincidence, cross-channel ICI:

- **ISI task:** Learnable τ + delay finds 12ms ISI threshold 98% vs 62% fixed τ
- **Coincidence:** window <5ms detection via surrogate temporal receptive field
- **CCISI:** graded payload preserves channel relative timing, 21% improvement over rate code [7]

We prove timing learning via chain rule:

```python
# Spike timing sensitivity via surrogate
# u[t] crosses θ at t*; small shift δ in input shifts crossing: u[t*+δ]≈u[t*]+du/dt·δ
# surrogate derivative non-zero around θ: dh/du = 1/(α|u-θ|+1)^2 >0 provides ∂L/∂w ≠0
# thus weight update strengthens timings consistent with correct class [7]
```

### 5.4 On-Chip Learning Demonstration

Lava tutorial `online_learning_*.py` implements 3-factor learning on Loihi 2: pre-trace decay 0.99, post-trace eligibility 5 timesteps, dopamine third factor via reinforcement channel. Convergence analysis: integer INT8 simulation retains ±2% accuracy vs float [1].

## 6 Limitations & Open Problems

*Hardware:*
- **INT8 quantization noise:** Loihi 2 synapse SRAM limited to 8-bit weights for 120M synapses; gradient descent assumes float; workaround: scale-aware training with quantization-aware surrogate (QAT-SNN gap 1-3% )
- **Core memory:** 32KB neuron + 128KB synapse per core rigid; large conv 3×3×256→512 exceeds partition; requires tiling and inter-core spike routing increasing latency 1.4× [2]
- **Graded payload width:** 32-bit integer but no float; normalization must be integer-shifted, impeding LayerNorm
- **Access:** Loihi 2 research chip only, requires INRC application, not commercial; Kapoho Point $ limited availability

*Algorithmic:*
- **Surrogate mismatch:** Theorem 4.1 shows no surrogate loss exists; surrogate gradient not true gradient, can diverge under high ρ [9]; LSG and A2SG partially mitigate but not prove convergence
- **Temporal credit assignment limits:** BPTT T=50 truncates dependencies beyond ~100ms real-time; long-range 1s gestures need memory units (ALIF, LSTM-SNN hybrid)
- **Flat minima assumption:** SAST requires explicit boundedness and contraction assumptions for state stability; input Lipschitz bounds not universally satisfied for event camera noisy input [SAST]
- **Loss landscape sharpness:** Adaptive slopes improve but MR shows shallower slopes reduce alignment with true gradient [RL ref]
- **Energy measurement reproducibility:** prior claims of 60× ops reduction per inference lack public board-level powerometer traces; Orin benchmarking scripts available for CLP-SNN [1] but not direct wattmeter comparison

*Software:*
- **Lava maturity:** `lava-dl` still 0.8, breaking API changes, limited ModelZoo; community contributions BSD but core compile proprietary restricts fork inspection
- **Simulation-vs-silicon gap:** Lava Loihi2Sim uses float while chip INT8, timing model approximate; variable-length timestep scaling prediction error 15% reported [1]
- **Distribution shift:** Neuromorphic datasets (N-MNIST, DVS) low-resolution event cameras; transfer to high-res DVXplorer 640×480 unseen event rate 10× higher → congestion on mesh NoC

*Open directions:*
- Heterogeneous multi-chip learning with 3D mesh scaling to 16,384 chips feasibility for city-scale inference fabric
- Co-design of graded spikes with RoCEv2 CX7 400G interconnect for cloud-edge split inference [ref to TX fabric]
- Formal verification of barrier synchronization fairness properties via TLC model checking up to 10^5 states [inspired by TLA+ usage]
- Privileged guiding policy for RL with spiking policies + adaptive slope schedule achieving 400 return points drone control vs BC -200 [6RL]
