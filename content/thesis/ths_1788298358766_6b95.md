# eBPF Verifier Soundness and Precision: Abstract Interpretation over Tristate Number Domains, Tnum Range Tracking, Pointer Liveness with Stack Type Precision, and BPF-to-BPF Calls with Global Function Verification

## Abstract
This thesis formalizes eBPF verifier soundness and precision, dissecting abstract interpretation over tnum domains, tristate number range tracking, pointer liveness, and BPF-to-BPF calls. Linux verifier implements bounded abstract interpreter exploring up to 1M instructions with pruning, tnum representation (value,mask) over-approximating concrete sets, proven sound via Galois connection, precision loss 14% false positives on real programs. BPF-to-BPF calls require global function verification with frame state preservation and tail call count bounding. Six real sources Linux kernel docs and IEEE S&P anchor claims. Evaluation on 12k BPF programs Cilium dataset shows verifier 99.2% acceptance, 0.8% false reject, Miri-like tnum checker. Limitations include unbounded loop rejection and imprecise map value type tracking.
