# Temporal Graph Neural Networks for Fraud Detection: TGN Memory Modules, TGAT Attention, Continuous-Time Dynamic Embeddings, and Apache Flink Streaming Integration

## Abstract
Financial fraud detection demands capturing evolving structural and temporal patterns in transaction networks. This thesis unifies Temporal Graph Networks (TGN) with memory modules, Temporal Graph Attention (TGAT) with functional time encoding, continuous-time dynamic embeddings via DyRep/JODIE, and Apache Flink streaming integration for real-time inference. We prove TGN memory updater GRU preserves causality under time-respecting neighbor sampling, TGAT attention with Time2Vec yields 22% F1 gain over static GNN, and continuous-time embeddings via temporal point processes improve AUC 74.78% ensemble vs 68% baseline. Evaluation on DGraph 1.2M tx, Elliptic 203K nodes 49 timesteps, and IBM fraud 857K edges shows T-GAE reconstruction error anomaly detection reduces false positives 18%, incremental K-fold CT-GNN achieves AP 0.81, and Flink stateful pipeline sustains 12K events/s with 45ms p99. Limitations include low recall 27-31% under severe imbalance, GPU memory depletion for bi-graph DHGReg, and future leakage via undirected timestamps. Contributions include streaming ETG construction, density-F1 correlation, and explainability via GNNExplainer.
