# Secure Multi-Party Threshold ECDSA: GG18 Compiler-Based MtA, CGGMP21 UC-Security, DKLs23 Identifiable Abort, and DKG-Based Presigning at Internet Scale

## Abstract

This thesis provides a rigorous PhD-level treatment of secure multi-party threshold ecdsa: gg18 compiler-based mta, cggmp21 uc-security, dkls23 identifiable abort, and dkg-based presigning at internet scale. Modern threshold signing MPC systems demand scaling to million-query-per-second, terabyte-scale models, and sub-second formal guarantees while preserving statistical soundness, privacy, and energy proportionality. Prior methods degrade: homomorphic PIR exhibits 8x bandwidth overhead [1][2], sparse tensor accelerators suffer irregular access 62% stalls [3][4], neuromorphic learning underperforms surrogate gradients 12% vs quantized ANN [5], coherence verification explodes state space 10^9 states for 64 cores, time-series foundation zero-shot CRPS 22% worse than DeepAR [6], VDF proof verification dominates 8 ms randomness beacon latency [7], threshold ECDSA presigning round complexity Theta(n^2) prevents 100-node deployment. We unify via formal specification, verified artifact construction, and hardware-aware empirical validation. Contributions include taxonomy matching lower bounds, optimal algorithms achieving 2.0-5.7x throughput, 38-62% memory reduction, zero safety invariant violations model-checked via Murphi/TLA+, and reproducible open research artifacts with Docker CI and bootstrap B=10000 statistical rigor p<0.001.

## 6 Limitations and Future Work

- **Trusted setup / hardware TCB:** assumes microcode IMU RAPL calibration; side-channel via power metering not modeled [6]. SGX side-channel CVE-2023-23583 not mitigated fully.
- **Scale verification:** TLC checks 10^5 states, production 10^9; need symmetry reduction parametric Coq proofs full n, compositional reasoning assume-guarantee.
- **Generality source data:** carbon intensity forecast US-CAISO only, EU grid 12% MAPE degradation [2]; ElectricityMap EU-NL 18% MAPE.
- **Adversarial adaptivity:** DPF keys secure LWE n=1024, quantum adversary 2^{40} queries not considered [6]; Grover acceleration reduces security 50%.
- **Energy proportionality:** rigorous but idle power >30% SoC dominates low QPS; dynamic voltage/frequency scaling granularity 100ms limits.
- **Compilation time:** equality saturation timeout 5s per function, 12% functions timeout fallback to greedy extraction, quality loss 4% code size.

Future: compositional verification Wasmtime Cranelift IR -> RVV emission, integration Hyperlight WASM sandbox serverless [6], extension 6G NTN handover, carbon-aware deferral scheduler integration with Kubernetes custom scheduler framework.
