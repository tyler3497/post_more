## Abstract
This thesis formalizes Linux io_uring completion ordering and CQE overflow semantics using TLA+ temporal logic and Kani Rust verifier bounded model checking. We model the single-producer single-consumer ring buffer with head/tail monotonic counters, memory ordering via smp_load_acquire and smp_store_release, and prove linearizability of io_uring_enter submission and completion reaping under concurrent SQPOLL kernel thread.
