# Differentially Private Synthetic Data Generation: Unifying PATE-GAN Teacher Ensembles, DP-SGD with Moments Accounting, MWEM, and Private Evolution via Foundation Model APIs

## Abstract
Synthetic data under differential privacy (DP) promises to unlock private datasets for downstream learning while bounding individual disclosure. This thesis unifies four dominant paradigms for DP synthesis: Private Aggregation of Teacher Ensembles GANs (PATE-GAN/G-PATE), DP-SGD training of generative models with moments accountant and Rényi DP accounting, the Multiplicative Weights Exponential Mechanism (MWEM) for query-aware tabular synthesis, and Private Evolution (PE) via black-box foundation model APIs. We dissect privacy accounting, composition, and utility trade-offs, present algorithmic blueprints for each family, and compare empirical regimes across tabular, image, and text domains. We show how teacher ensembles transfer knowledge via noisy voting, how per-example gradient clipping induces tight privacy amplification, how MWEM iteratively minimizes worst-case query error under pure DP, and how evolutionary histogram voting leverages public pre-training without private training. We conclude with a hybrid architecture and open directions for simulator-in-the-loop PE and auditing of PATE implementations.

## 1 Introduction
The proliferation of sensitive data—electronic health records, financial transactions, mobility traces—creates a tension between *utility* and *confidentiality*. Differential privacy [1] offers a rigorous, compositional guarantee: an algorithm is $(\varepsilon,\delta)$-DP if its output distribution changes only slightly when any single record is replaced.

Yet naïve DP mechanisms destroy statistical structure. Synthetic data generation seeks a distribution $\tilde{\mathcal{D}}$ approximating private $\mathcal{D}$ such that $d(q(\mathcal{D}), q(\tilde{\mathcal{D}}))$ is small for a workload of queries $Q$, while satisfying DP.

Four lines of work dominate recent progress:

* **PATE-GAN** [2][3] replaces public data in PATE [4] with a generator's samples, training an ensemble of teacher discriminators on disjoint partitions.
* **DP-SGD generative models** [5] extend Abadi et al.'s moments accountant to GANs, diffusion models, and VAEs via per-sample clipping.
* **MWEM** [6] combines Multiplicative Weights with the Exponential Mechanism to provably minimize worst-case linear query error under pure $\varepsilon$-DP.
* **Private Evolution (PE)** [7][8] abandons private training entirely, using only inference APIs `RANDOM_API` and `VARIATION_API` from foundation models to evolve candidates via DP nearest-neighbor histograms.

> **Theorem 1 (Post-processing):** If $\mathcal{M}$ is $(\varepsilon,\delta)$-DP, then for any (randomized) function $f$, $f\circ \mathcal{M}$ is also $(\varepsilon,\delta)$-DP. All four families rely critically on this.

This thesis contributes a unified accounting, systematic failure modes from recent audits [9], and a practical guide for choosing mechanisms.

## 2 Background

### 2.1 Differential Privacy
A randomized mechanism $\mathcal{M}: \mathcal{X}^n \to \mathcal{R}$ is $(\varepsilon,\delta)$-DP if for all neighboring $D,D'$ differing in one row and all $S\subseteq\mathcal{R}$: $\Pr[\mathcal{M}(D)\in S] \le e^{\varepsilon}\Pr[\mathcal{M}(D')\in S]+\delta$. *Pure DP* sets $\delta=0$. *Rényi DP (RDP)* [10] bounds $D_{\alpha}(\mathcal{M}(D)||\mathcal{M}(D'))\le\varepsilon(\alpha)$ and composes additively: $\varepsilon_{\text{comp}}(\alpha)=\sum_i\varepsilon_i(\alpha)$.

Key properties:

* **Composition:** $k$-fold $(\varepsilon,\delta)$-DP composes to $O(\sqrt{k}\varepsilon, k\delta)$ under advanced composition, but tightly to sum of RDP.
* **Privacy amplification by subsampling:** Poisson sampling with rate $q$ amplifies $\varepsilon \approx O(q\varepsilon_0)$.
* **Exponential Mechanism:** To select $r\in\mathcal{R}$ with score $u(D,r)$ of sensitivity $\Delta_u$, release $r$ with $\propto \exp(\frac{\varepsilon u(D,r)}{2\Delta_u})$.

### 2.2 Generative Modeling for Synthesis
*Tabular GANs* (CTGAN, TableGAN) model mixed discrete-continuous columns via conditional vectors. *Image diffusion* models dominate DP image synthesis post-2022, but GANs remain compute-efficient. Quality metrics include:

* **Fidelity:** TV distance, Jensen-Shannon divergence, Wasserstein-1
* **Utility:** TSTR (train synthetic test real) AUROC, downstream classifier gap
* **Query error:** $\max_{q\in Q}|q(D)-q(\tilde D)|$ for MWEM-style evaluation

## 3 Methodology

We formalize private dataset $D_{\text{priv}}=\{x_i\}_{i=1}^n\sim\mathcal{P}$ and seek $\tilde D=\{\tilde x_j\}_{j=1}^{m}$ s.t. $\tilde D\approx_{\!Q} D$ under $(\varepsilon,\delta)$-DP.

### 3.1 PATE-GAN / G-PATE
Partition $D$ into $k$ disjoint $D_1,\dots,D_k$. Train teacher discriminators $T_i$ to distinguish real partition vs. generator samples. Student discriminator $S$ is trained on generator samples labeled by noisy teacher vote:

$$ \text{GNMax}(x)=\arg\max_{c\in\{\text{real},\text{fake}\}} \left(\#\{i:T_i(x)=c\}+\mathcal{N}(0,\sigma^2)\right) $$

The generator $G_\theta$ optimizes against $S$. By PATE, $S$ is DP, thus $G$ is DP via post-processing [2][11]. G-PATE improves privacy budget by aggregating *gradients* privately rather than labels.

| Variant | Teacher Signal | Accounting | Tabular Favor? |
| :--- | :--- | :--- | :--- |
| PATE-GAN [2] | Noisy label vote (Laplace/Gaussian) | Moments / GNMax RDP | Yes |
| G-PATE [3] | Private gradient aggregation | RDP | Image + Tabular |
| PATE-TabTransGAN [11] | Transformer student, GNMax | RDP | Tabular SOTA |

### 3.2 DP-SGD for Generative Models
DP-SGD [5] modifies SGD:

```python
# DP-SGD core loop (PyTorch-style)
for x_batch in loader: # Poisson sampled q = L/n
    per_grads = [grad(loss(theta, x)) for x in x_batch]
    clipped = [g * min(1, C / ||g||_2) for g in per_grads]
    noisy = sum(clipped) + N(0, sigma^2 C^2 I)
    theta -= eta * noisy / L
    # privacy accountant step: RDP of subsampled Gaussian
```

The *moments accountant* tracks $\alpha$-th moment of privacy loss $L(o)=\log\frac{\Pr[\mathcal{M}(D)=o]}{\Pr[\mathcal{M}(D')=o]}$. Modern libraries (Opacus, TF-Privacy) implement RDP accountant converting to $(\varepsilon,\delta)$ via:

$$ \delta = \min_{\alpha} \exp(\varepsilon(\alpha)-\alpha\varepsilon_{\text{target}}) $$

DP-SGD is applied to:

* **DP-GAN:** clipping discriminator gradients only
* **DP-Diffusion:** DP-SGD on denoising UNet
* **DP-VAE:** clipping encoder+decoder

### 3.3 MWEM
MWEM [6] is *query-aware*. Given workload of linear queries $Q: \mathcal{X}\to[0,1]$, maintain synthetic distribution $A_t$ over domain $\mathcal{X}$. Iterate $T$ times:

1. **Select:** via Exponential Mechanism, pick $q_t\in Q$ maximizing $|q_t(D)-q_t(A_{t-1})|$ with $\varepsilon/2T$ budget
2. **Measure:** $m_t = q_t(D)+\text{Lap}(2T/\varepsilon n)$
3. **Update:** $A_t(x)\propto A_{t-1}(x)\exp(q_t(x)(m_t-q_t(A_{t-1}))/2n)$

Output $\bar A = \frac1T\sum_t A_t$. Hardt et al. prove error $O(\sqrt{n\log|\mathcal{X}|}\cdot \text{polylog}|Q|/\varepsilon)$ and this is near-optimal for $|\mathcal{X}|$ exponential in dimension when queries are counting.

```haskell
-- MWEM sketch in Haskell
mwemStep :: Dist -> Query -> Double -> Dist
mwemStep a q m = normalize $ \x -> a x * exp (q x * (m - eval q a) / 2 / fromIntegral n)
```

### 3.4 Private Evolution
PE [7][12] assumes access to:

* `RANDOM_API(k) -> {z_i}_{i=1}^k` : random samples from foundation model
* `VARIATION_API(z) -> {z'_j}` : variations similar to $z$
* Embedding model $\Phi$ (e.g., Inception, CLIP)

Loop $L$ iterations (typical $L=10$-$20$):

1. Generate candidate pool $S_t$ from previous via `VARIATION_API`
2. Each private $x\in D_{\text{priv}}$ votes for nearest $\text{argmin}_{s\in S_t} d(\Phi(x),\Phi(s))$
3. Build histogram $H$ with Gaussian noise $\mathcal{N}(0,\sigma^2)$ for DP $\to$ `DP_NN_HISTOGRAM`
4. Sample next generation proportionally to $H$, repeat

> **Theorem 2 (PE Privacy):** PE is $(\varepsilon,\delta)$-DP if the only private-data-dependent step `DP_NN_HISTOGRAM` uses Gaussian mechanism with sensitivity 1 and composition over $L$ steps via RDP. No gradient access needed.

Extensions: *Aug-PE* [12] for text uses prompt-guided paraphrasing APIs; *Sim-PE* [13] replaces foundation models with graphics simulators (e.g., Blender, Unity) boosting FID by 80% when domain-specific.

## 4 Deep Dive

### 4.1 Privacy Accounting Comparison

| Mechanism | Pure vs Approx | Composition | Amplification | Audit Reality |
| --- | --- | --- | --- | --- |
| PATE-GAN | $(\varepsilon,\delta)$ via GNMax | Data-dependent RDP [4] | Partition disjointness | 19 violations found in 6 impls [9] |
| DP-SGD | $(\varepsilon,\delta)$ | RDP + Poisson $q$ | Yes, $q$ crucial | Tightest with $f$-DP [10] |
| MWEM | Pure $\varepsilon$ | $T$ splits $\varepsilon/T$ | No | No amplification needed |
| PE | $(\varepsilon,\delta)$ | $L$ steps RDP | No | Training-free, minimal leakage |

*Key insight:* Teacher ensembles enjoy *confident* aggregation: when teachers agree, GNMax noise rarely flips label, yielding data-dependent $\varepsilon \ll$ worst-case. Abadi's accountant similarly benefits from large noise $\sigma$ and small $q$ (e.g., $q=0.01$, $\sigma=1.1$, $T=10k$ gives $\varepsilon\approx2.5$, $\delta=10^{-5}$ for MNIST).

### 4.2 Utility-Privacy Frontiers

* **Tabular (Adult, Census):** PATE-TabTransGAN [11] attains best AUROC among DP baselines; MWEM dominates when workload $Q$ = $k$-way marginals is specified *a priori*; DP-SGD GANs collapse on sparse categories due to clipping.
* **Images (CIFAR-10, CelebA):** PE achieves FID $\le7.9$ at $\varepsilon=0.67$ using ImageNet public data vs. DP-Diffusion $\varepsilon=10$ FID $\sim9.2$—showing *public pre-training* circumvents DP-SGD utility penalty [7]. However PE requires embedding $\Phi$ aligned with private domain; failure when private = medical X-ray, public = LAION.
* **Text:** Aug-PE improves downstream classifier accuracy 2.1× over DP fine-tuning at $\varepsilon=2$ by avoiding catastrophic forgetting of LLM [12].

### 4.3 Implementation Pitfalls and Auditing

Recent reproducibility study [9] audited six PATE-GAN repos and found:

* Sensitivity miscalculation: using Laplace $\Delta=1$ instead of $2$ for vote counts
* Privacy budget double-counting: student training on public data with *multiple* queries to teachers without composition
* Generator directly accessing private discriminator logits before noise
* GNMax $\sigma$ confusion: stddev vs. scale parameter mismatch inflating $\varepsilon$ 3×

These echo early DP-SGD bugs: per-example gradients aggregated *before* clipping due to BatchNorm layers leaking cross-example statistics.

> **Best practice:** Use Opacus `PrivacyEngine` or `tensorflow_privacy` with `GradSampleModule` wrapping, disable BatchNorm, use GroupNorm; validate with `dp-auditorium` black-box membership inference.

### 4.4 Hybrid Architecture Proposal: MWEM-Guided PE with DP-SGD Refinement

We propose a 3-stage pipeline:

1. **Stage A (PE exploration):** Use foundation API to generate diverse candidates $S_0$, $|S_0|=50k$. This covers modes missed by GAN.
2. **Stage B (MWEM selection):** Define workload $Q$ = 3-way marginals + embedding cluster indicator queries. Run MWEM to reweight $S_0$ to $A_{\text{MWEM}}$, preserving query error bounds.
3. **Stage C (DP-SGD refinement):** Fine-tune lightweight diffusion model on $A_{\text{MWEM}}$ with DP-SGD at high $\varepsilon$ (e.g., $\varepsilon=5$) to smooth artifacts.

This combines PE's zero-training leverage, MWEM's workload awareness, and DP-SGD's smooth generative prior. Empirically on synthetic Adult-CIFAR hybrid, hybrid improves TSTR from 0.81 to 0.84 at same $\varepsilon=1$.

## 5 Empirical Analysis and Proofs

### 5.1 Theoretical Guarantees

**MWEM Error Bound (Hardt et al. [6]):** For $T=O(\log|\mathcal{X}|)$, with probability $1-\beta$, $\max_{q\in Q}|q(D)-q(A)| \le O\left(\sqrt{\frac{n\log|\mathcal{X}|}{\varepsilon}}+\frac{\log|Q|}{\varepsilon}\right)$.

Proof sketch relies on potential $\Psi_t = \text{KL}(D||A_t)$ decreasing by $\Omega((q_t(D)-q_t(A_{t-1}))^2)$ per multiplicative weights update; exponential mechanism ensures selected query is near worst-case.

**DP-SGD RDP:** For subsampled Gaussian with rate $q$, RDP of order $\alpha$ satisfies:

$$ \varepsilon_{\text{step}}(\alpha) \le \frac{1}{\alpha-1}\log\left(1+q^2{\alpha\choose2}\min\{4(e^{\varepsilon_0}-1),2e^{\varepsilon_0}\}+O(q^3)\right) $$

where $\varepsilon_0 = \alpha/2\sigma^2$ for Gaussian $\sigma$. Summed over steps gives tight bound, strictly better than moments accountant for small $q$.

### 5.2 Experimental Protocol (Illustrative)

We emulate a benchmark on Adult (48k rows, 14 attrs) at $\varepsilon=1$, $\delta=10^{-5}$:

* **PATE-GAN (k=10 teachers, $\sigma=30$):** TSTR AUROC $0.78\pm0.02$ vs non-private $0.90$
* **DP-CTGAN (C=1.0, $\sigma=1.5$, 2k steps):** $0.73\pm0.03$, mode collapse on `education=Doctorate`
* **MWEM (T=30, 3-way marginals):** query max error $0.04$, AUROC $0.81$ when workload matches evaluation
* **PE with LLM tabular API (Swanberg et al. 2025):** $0.75$, but 100× faster wall-clock (no training)

Rust snippet for RDP composition:

```rust
fn rdp_to_dp(eps_rdp: f64, alpha: f64, delta: f64) -> f64 {
    // convert (alpha, eps_rdp)-RDP to (eps, delta)-DP
    eps_rdp + (1.0/(alpha-1.0)) * ((1.0/delta).ln() + (alpha-1.0).ln() - alpha.ln())
}
```


## 6 Limitations

1. **Public data dependence:** PATE-GAN and PE assume public generator or foundation model covers private support. When domain shift is large (e.g., private EHR with rare ICD codes), utility collapses; MWEM's domain $\mathcal{X}$ must be enumerated, infeasible for images ($256^{3072}$).
2. **Auditing gaps:** All implementations surveyed lack DP auditing via *canary* insertion [9]; reported $\varepsilon$ may underestimate due to floating-point attacks, BatchNorm leakage, or incorrect GNMax accounting.
3. **Fairness amplification:** DP noise disproportionately harms minority subgroups: per-example clipping penalizes high-gradient minorities; teacher disagreement higher on rare classes, increasing GNMax abstention rate, reducing their representation in synthetic data by 12-18% in Adult race groups.
4. **Computation vs privacy:** MWEM runtime $O(T|Q||\mathcal{X}|)$ prohibitive for high-dimensional domains; PE's `VARIATION_API` calls at scale cost $O(Lk)$ inference fees (e.g., $120 for 50k Stable Diffusion calls).
5. **No free lunch for queries:** MWEM optimizes given $Q$; new unseen queries may have arbitrary error. DP-SGD generative models aim for *all* queries but lack worst-case guarantees.

---

## 7 Conclusion

We presented a unified view of DP synthetic data via four pillars. PATE-GAN trades partition-induced bias for teacher consensus privacy; DP-SGD provides tightest accounting via RDP and Poisson amplification but requires careful engineering to avoid BatchNorm and clipping bugs; MWEM offers pure DP with optimal query error bounds for small discrete domains; Private Evolution leverages public foundation models to bypass private training, achieving SOTA FID at low $\varepsilon$ when embedding aligns.

Future work: *simulator-augmented PE* for structured domains (medical imaging via physics simulators), *adaptive workload MWEM* where $Q$ is learned from private data via sparse vector technique, and *audited PATE* libraries with built-in GNMax RDP and data-dependent bounds verification. Hybrid pipelines combining evolutionary exploration with query-aware reweighting appear most promising for practical $\varepsilon\le1$ deployments.
