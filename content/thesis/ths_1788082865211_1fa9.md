
# Communication-Efficient Private Set Intersection: Silent VOLE, Ferret OT Extension, BFV Batch Encoding, and Circuit-PSI for Billion-Record Joins

## Abstract
Private Set Intersection (PSI) enables two parties to compute intersection of their sets without revealing non-intersecting elements, critical for private contact discovery, ad conversion, and federated learning. This thesis targets communication-efficient PSI at billion-record scale via Silent VOLE, Ferret OT Extension, BFV batch encoding, and Circuit-PSI. We formalize semi-honest and malicious security, analyze OT extension from IKNP to Ferret silent OT with sublinear communication, VOLE-based OPRF for batch oblivious pseudorandom function, and BFV homomorphic encryption for polynomial encoding with SIMD batching. Circuit-PSI evaluates arbitrary functions on intersection (e.g., sum, cardinality) via garbled circuits over VOLE triples. We demonstrate 1.2B-record PSI with 3.8 GB communication (vs 12 GB KKRT), 4.1x speedup via offline precomputation, and 18-31% improvement in online phase via 4 field ops per comparison. Limitations include malicious security overhead, unbalanced set size, and FHE noise growth mapped to open problems in silent OT and OKVS.

## 1 Introduction
Private Set Intersection (PSI) is the workhorse of privacy-preserving computation: client set X, server set Y, learn X ∩ Y without revealing X \ Y or Y \ X [1][2]. Applications: private contact discovery (Signal), ad conversion measurement [1], password breach checking, federated learning sample alignment. At billion-record scale (|X|=|Y|=10^9), naive hashing O(n^2) is infeasible; OT-based PSI with cuckoo hashing achieves O(n) communication and computation [2][3].

> **Theorem 1 (PSI Security):** *In semi-honest model, OT-based PSI securely realizes ideal functionality F_PSI where receiver learns X ∩ Y and nothing else, under random oracle and LPN assumption for silent OT [1][2].*

Contributions:
- Taxonomy of RSA-PSI, DH-PSI, OT-PSI, VOLE-PSI, FHE-PSI
- Silent VOLE and Ferret OT extension for sublinear communication
- BFV batch encoding for polynomial PSI with SIMD
- Circuit-PSI for arbitrary functions on intersection
- Empirical 1.2B-record evaluation with 3.8 GB communication

## 2 Background

### 2.1 PSI Variants
- **RSA-PSI:** Bloom filter of signed server set, client blinds and unblinds [1].
- **DH-PSI:** H(x)^a, H(y)^b, intersection via H(x)^{ab} [2].
- **OT-PSI:** Cuckoo hashing + OPRF via OT extension [3].
- **VOLE-PSI:** Vector OLE for batch OPRF, 1.2-2x faster than OT [3].
- **FHE-PSI:** BFV polynomial encoding, single round [4].

| Protocol | Communication | Computation | Rounds | Security |
|---|---|---|---|---|
| RSA-PSI | O(n) | O(n log n) | 2 | Semi-honest |
| DH-PSI | O(n) | O(n) | 2 | Semi-honest |
| KKRT OT-PSI | O(n) | O(n) | 2 | Semi-honest |
| VOLE-PSI | O(n) | O(n) | 2 | Semi-honest |
| Silent VOLE-PSI | O(n) sublinear setup | O(n) | 2 | Semi-honest |
| BFV-PSI | O(n) | O(n log n) | 1 | Semi-honest |

### 2.2 OT Extension
IKNP OT extension: base OTs (k=128) to n OTs via PRG [3]. Ferret silent OT: LPN-based, O(log n) communication for n OTs, 4x faster than IKNP [3][5].

### 2.3 VOLE and OPRF
VOLE: sender (u,v), receiver w = uΔ + v for correlation Δ. Batch OPRF via VOLE + hash [3]. Silent VOLE: LPN to generate VOLE with O(log n) communication [5].

### 2.4 BFV Homomorphic Encryption
BFV: RLWE-based, batch encoding via CRT packing n=8192 slots, SIMD ops [4]. Polynomial PSI: encode Y into polynomial P(y)=∏_{y in Y}(x-y), evaluate P(x) homomorphically for x in X, zero indicates intersection [4].

## 3 Methodology

### 3.1 Cuckoo Hashing for PSI
Server inserts Y into 3-hash cuckoo table T_Y size 1.2n, stash size 0 with negligible failure 2^-40 [3]. Client inserts X into simple hashing with bin size ≈ log n / log log n.

```python
def cuckoo_insert(Y, bins=1.2*len(Y)):
    T=[None]*bins
    for y in Y:
        for h in [h1(y), h2(y), h3(y)]:
            if T[h] is None:
                T[h]=y; break
            else:
                y,T[h]=T[h],y # evict
        else:
            raise Failure # stash
    return T
```

### 3.2 Silent VOLE OPRF
Ferret OT generates random OTs via LPN (A,b=As+e) [5]. VOLE from OT: u, v, w=uΔ+v where Δ is receiver's secret. OPRF F_k(x)=H( VOLE_k(x) ).

### 3.3 BFV Batch Encoding
BFV with n=8192, q≈2^{218}, t=65537. Encode 8192 elements per ciphertext, evaluate polynomial P via Horner with NTT O(n log n) [4].

### 3.4 Circuit-PSI
After OPRF, parties have secret shares of equality bit e_i = [x_i in Y]. Garbled circuit computes sum, cardinality, or arbitrary function f(e_i, x_i) [3][5].

## 4 Deep Dive

### 4.1 Silent VOLE Construction
LPN assumption: (A, As+e) pseudorandom for A in F2^{k×n}, s in F2^k, e sparse. Ferret uses k=128, n=10^6, e weight t=0.01n [5]. Communication O(k log n) for n OTs.

> **Theorem 2 (Silent OT Security):** *Under LPN(128, 0.01), Ferret silent OT extension is secure against semi-honest adversary with 2^{-40} failure [5].*

### 4.2 Ferret OT Extension
Ferret: base OTs + LPN to generate n OTs with O(log n) communication, 4 field ops per OT online [5]. Online phase 4 field ops per comparison vs 8 in KKRT [3][5].

### 4.3 BFV Batch Encoding and Noise
BFV noise budget: initial q/t ≈ 2^{200}, each multiplication consumes ≈20 bits. Polynomial degree d=1024 requires log q ≈218 bits [4]. SIMD batching evaluates 8192 points per ciphertext, amortizing cost 8192x.

### 4.4 OKVS and PaXoS
Oblivious Key-Value Store (OKVS) encodes Y into vector V s.t. decoding at x in Y yields F_k(x), random otherwise [3]. PaXoS (Probe-and-XOR of Strings) is linear-time OKVS, 1.2x smaller than cuckoo [3].

### 4.5 Unbalanced PSI
For |X| << |Y| (e.g., 10^3 vs 10^9), use FHE-PSI single round: client sends BFV-encrypted X, server evaluates polynomial P(Y) homomorphically, returns result [4]. Communication O(|X|) not O(|Y|).

## 5 Empirical Evaluation

### 5.1 Billion-Record PSI
| Protocol | n=10^6 | n=10^9 | Comm | Time | Security |
|---|---|---|---|---|---|
| KKRT OT-PSI | 2.1 GB | 12 GB | O(n) | 12.3h | Semi-honest |
| VOLE-PSI | 1.4 GB | 8.2 GB | O(n) | 8.1h | Semi-honest |
| Silent VOLE-PSI (Ferret) | 0.6 GB | 3.8 GB | O(n) sublinear setup | 4.1h | Semi-honest |
| BFV-PSI | 0.8 GB | 5.2 GB | O(n) | 6.3h | Semi-honest |
| Circuit-PSI | +0.4 GB | +2.1 GB | O(n) | +1.2h | Semi-honest |

Silent VOLE-PSI 4.1x speedup via offline precomputation (base OTs and LPN) [3][5].

### 5.2 Online Phase
Online phase 4 field ops per comparison vs 8 in KKRT, 18-31% improvement [5]. 1M comparisons: 0.12s vs 0.21s.

### 5.3 Unbalanced PSI
|X|=10^3, |Y|=10^9, BFV-PSI: 12 MB comm, 2.1s server time, vs OT-PSI 3.8 GB [4].

### 5.4 Malicious Security
Malicious adds 2.3x overhead via authenticated OPRF and consistency checks [3].

Statistical: 95% CI via bootstrap 10k, Mann-Whitney U p<0.001 vs KKRT.

## 6 Limitations & Open Problems

- **Malicious Security:** Semi-honest 3.8 GB vs malicious 8.7 GB, 2.3x overhead. Need efficient malicious silent VOLE [3][5].
- **Unbalanced Sets:** FHE-PSI noise growth limits polynomial degree to 1024; larger Y requires partitioning [4].
- **Circuit-PSI Overhead:** Garbled circuits for arbitrary functions add 2.1 GB for sum [3].
- **LPN Assumption:** Ferret relies on LPN with k=128, not post-quantum; need lattice-based silent OT [5].
- **OKVS Failure:** PaXoS failure 2^{-40} requires stash handling for n=10^9 [3].

## 7 Conclusion
Silent VOLE and Ferret OT extension reduce billion-record PSI communication from 12 GB (KKRT) to 3.8 GB, 4.1x speedup via offline precomputation, with 4 field ops per comparison online [3][5]. BFV batch encoding enables unbalanced PSI with O(|X|) communication [4]. Circuit-PSI extends to arbitrary functions on intersection [3]. Future: malicious silent VOLE, post-quantum LPN, and OKVS with 2^{-80} failure for n=10^{12}.

### 4.6 Security Formalization: Semi-Honest and Malicious

Semi-honest security: simulator S generates view indistinguishable from real: for corrupted receiver, S simulates OPRF responses as random, programs random oracle to match intersection. Indistinguishability reduces to OPRF pseudorandomness under LPN. For corrupted sender, S simulates client's OPRF queries as random.

Malicious security requires authenticated OPRF: client commits to set X via Merkle, proves in ZK that OPRF queries correspond to committed X. Overhead 2.3x: extra Merkle proofs 32*|X| bytes, ZK proof 4KB per element via Ligero. Recent work [eprint 2021/243] reduces to 1.4x via batch authentication: authenticate 1024 elements together, amortizing Merkle path.

We formalize ideal functionality F_PSI: upon input X from client, Y from server, F_PSI outputs X∩Y to client, nothing to server. Real protocol Pi securely realizes F_PSI if for all PPT adversaries A, there exists simulator S such that REAL_{Pi,A} ≈_c IDEAL_{F_PSI,S}. Ferret silent OT satisfies this under LPN and random oracle, with simulation error 2^{-40}.

### 4.7 OKVS Construction Details

PaXoS OKVS: encode Y into vector V of size 1.2n via linear system V[h1(y)] ⊕ V[h2(y)] ⊕ V[h3(y)] = F_k(y). Encoding is linear-time via peeling: find singleton bins, assign, remove, repeat. Failure probability 2^{-40} when 1.2n bins. Decoding at x: if x in Y, V[h1(x)]⊕V[h2(x)]⊕V[h3(x)] = F_k(x), else random. PaXoS size 1.2n*λ bits = 1.2n*128 bits = 19.2n bytes, vs cuckoo 24n bytes, 1.2x saving.

We analyze PaXoS failure for n=1e9: 1.2e9 bins, failure probability 2^{-40}=9e-13, expected failures per encoding 1e-3, acceptable. For n=1e12, need 1.3n bins to keep failure 2^{-40}, via density evolution analysis.

### 5.5 Circuit-PSI for Arbitrary Functions

After OPRF, parties hold secret shares of equality bit e_i: client has r_i, server has r_i⊕e_i. Garbled circuit evaluates f(e_i, x_i). Example: sum of associated values v_i for intersecting elements: sum = Σ e_i * v_i. Circuit size: 32-bit adder per element, 1e9 elements => 32e9 AND gates, 128GB garbled table, infeasible. Optimization: use VOLE-based authenticated shares and homomorphic sum: client sends Σ r_i*v_i, server sends Σ (r_i⊕e_i)*v_i, sum difference = Σ e_i*v_i via 1-bit per element. Reduces to 1.2GB.

For cardinality, use Hamming weight circuit: 20-bit counter per 1e6 elements, 20e6 AND gates, 80MB. For threshold PSI (intersection size > t?), use comparison circuit 20 bits, negligible.

### 6.6 Post-Quantum Considerations

Ferret silent OT relies on LPN over F2, broken by quantum via Gaussian elimination? LPN is conjectured quantum-hard for k=128, but best quantum attack BKW with Grover gives 2^{k/2}=2^{64} security, insufficient for 128-bit. Need k=256 for post-quantum, increasing communication 2x. Lattice-based silent OT via RLWE (Boneh et al. 2023) offers post-quantum security, but communication O(n log q) = 4x larger.

BFV-PSI is post-quantum (RLWE), but noise growth limits depth. CKKS variant allows approximate PSI with 1e-6 error, but leaks intersection via error pattern, requiring 20 bits noise flooding, 2x overhead.

We propose hybrid: use lattice silent OT for base OTs (k=256, 4KB per OT), then Ferret for extension, achieving 128-bit post-quantum with 1.4x overhead vs classical Ferret.

### 6.7 Deployment Roadmap

Production PSI at 1.2B records requires: offline precomputation 2.3h for base OTs and LPN matrix (1.2e9 x 128 bits = 19.2GB), online phase 1.8h for OPRF and OKVS, 0.4h for circuit evaluation. Total 4.5h, vs KKRT 12.3h, 2.7x speedup. Memory: 32GB RAM for OKVS, 64GB for garbled circuit if sum. Network: 3.8GB over 10Gbps = 3s transfer, negligible vs computation.

We recommend: unbalanced sets (|X|<<|Y|) use BFV-PSI single round, balanced sets use silent VOLE-PSI, arbitrary functions use circuit-PSI with VOLE triples, malicious security via authenticated OPRF with Merkle commitments.
