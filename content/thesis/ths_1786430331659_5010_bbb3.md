1. **Assumption boundaries:** n >= 3f+1 BFT honest majority [1] re rational adversary degrades liveness not safety; shard ratio k=64 under async vs n=100 may fork [2][3].

2. **Formal model scope:** TLC checked N=4 1e6 states; N=4096 parameterized induction open [4]; hardware heavy-hex crosstalk modeled as depolarizing 1e-3 simplistic vs real Hamiltonian ZZ.

3. **Side channels:** constant-time quaternion [3] mitigates timing, not power/EM via sideband health 6B FEC trailer [6]; TEE RAK leakage via SGX L1TF mitigated via microcode SVN check but residual tau [4][5].

4. **Learned model drift:** CDF epsilon-bound valid on train D; shift KL(D||D')>0.2 invalidates [2][4]; periodic retrain O(n log n) 4.3x slower for RMI vs PGM O(n) [2].

5. **Hardware variance:** HBM3 820GB/s vs 460GB/s GDDR6 variance across Blackwell vs A100; CXL 3.0 64GT/s 6B FEC BER 1e-6->1e-12 [6] not yet silicon production.

6. **Cryptographic parameter selection:** lattice n=1024, q=12289 LWE security 128b via lattice-estimator 0.292 beta BKZ cost model; switch to n=2048 doubles key size 7KB->28KB t-norm.

7. **Numeric stability CKKS:** approximate 2^-40 loss per mul need TFHE PBS LUT switching [4]; modulus chain L=30 bootstraps ~10.2s per 64k slot [3].

Roadmap: qLDPC +15/1 overhead [5][7], runtime CXL DCD extent 256MB migration [6], deterministic sideband QoS SPDM [6], automated schema lens inference via SMT CHC [4][5].
