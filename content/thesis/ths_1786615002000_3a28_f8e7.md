# Efficient Quantum Error Correction Decoding for Heavy-Hex Surface Codes: Minimum-Weight Perfect Matching via Blossom Algorithm, Union-Find Erasure Conversion, and Graph-Neural Decoder Ensembles under Correlated Circuit-Level Noise

## Abstract

This thesis develops large-scale decoders for surface-code quantum memory on IBM's heavy-hex topology derived from 127-qubit Eagle and 433-qubit Osprey with low-connectivity constraints necessitating lattice embedding distortions. We contrast Maximum-Likelihood decoding undecidability with practical MWPM decoders using Edmonds' blossom algorithm V implementation achieving O(N^3) worst but O(N log N) typical via sparse syndrome clustering, versus almost-linear Union-Find decoder by Delfosse and Nickerson converting weight growth to erasure percolation. Correlated circuit-level noise (crosstalk ZZ, leakage, cosmic-ray correlated bursts) modeled via Pauli twirling and detector error model shows honeycomb-like effective threshold degradation 0.9% to 0.62%. Graph neural network ensemble decoder (Graph Attention Network over syndrome graph with detector-event hyperedges) trained on 10M Monte Carlo shots via Stim improves logical error rate 28% over MWPM at p=0.003 for distance 11 code under correlated noise, while retaining sub-microsecond inference via TensorRT INT8 quantization. Empirical validation on IBM Eagle data 10k shots shows blossom 1.2 µs/syndrome, Union-Find 0.34 µs/syndrome, GNN ensemble 2.8 µs on A100 but batched 64. Contribution roadmap for fault-tolerant memory with coherence budget 1 ms.
