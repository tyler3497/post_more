# Grid-to-Place Transformation via Continuous Attractor Readouts: Boundary Vector Integration, Phase Precession, and Predictive Map Learning in MEC-LEC-Hippocampal Loops

## Abstract
The transformation from periodic entorhinal grid activity to punctate hippocampal place fields constitutes a central puzzle of spatial cognition. This thesis unifies continuous attractor dynamics in medial entorhinal cortex (MEC), boundary vector cell (BVC) anchoring, theta phase precession, and successor representation learning to explain how place cells inherit, refine, and predict spatial structure. We formalize toroidal attractor networks that integrate velocity to sustain hexagonal grids, show how subicular BVCs and MEC border cells reset accumulated path integration error via allocentric distance-direction inputs, and derive how phase precession emerges from recurrent asymmetry or interference to enable compressed theta sequences for spike-timing-dependent plasticity. We reconcile MEC-LEC integration with the hippocampus as a predictive map, where grid eigenvectors span the successor representation and LEC contextual inputs gate non-spatial reorganization. Simulations demonstrate sparse competitive coding converts summed grid, BVC, and latent context inputs into single-peaked place fields that remap coherently with grid realignment.

## 1. Introduction

When *John O'Keefe and Jonathan Dostrovsky* reported hippocampal neurons firing only when a rat occupied a particular platform region in 1971 [2], they established the **place cell** as evidence for a *cognitive map*. Three decades later, *Hafting, Fyhn, Molden, Moser and Moser* revealed its entorhinal complement: the **grid cell**, firing at vertices of a periodic hexagonal lattice tiling the environment independent of landmarks, scaled dorsoventrally, and persistent in darkness [1]. The discovery argued that MEC implements path integration, while hippocampus performs sensory-bound localization — a loop, not a hierarchy.

> **Central Question:** How does the mammalian MEC-LEC-hippocampal circuit convert high-dimensional velocity + boundary + object cues into a low-dimensional predictive spatial code that is simultaneously **metric**, **self-correcting**, and **composable** for planning?

Three historical gaps motivate this synthesis:

1. *Dead reckoning is insufficient.* Pure integration of self-motion accumulates error superlinearly; continuous attractors drift without sensory reset, bounded to ~10-100 m or ~1-10 min even with optimized network size [4].
2. *Boundary determinants dominate.* Stretching a box stretches place fields along the stretch axis — behavior predicted if place firing is thresholded sum of *boundary vector cells* tuned to distance/direction to edges [3,7], not grids alone.
3. *Temporal codes carry computation.* Both place and grid cells show **theta phase precession** — firing at progressively earlier theta phase across a traversal [6]. Precession compresses behavioral sequences (~seconds) into theta sequences (~100 ms), enabling STDP to learn successor representations [5].

This thesis argues that *grid-to-place is not a feedforward transform but an iterative MEC ↔ hippocampus ↔ subiculum loop* where:

- **MEC II/III** provides a *continuous attractor metric* via toroidal bump dynamics
- **Subiculum / parasubiculum BVCs and MEC border cells** provide *allo-centric anchoring* correcting drift
- **CA1/CA3** performs **competitive sparse coding** of MEC+LEC into unimodal place fields
- **Theta-phase dynamics** learns *predictive maps* SR = (I - γT)⁻¹, whose eigenvectors resemble grids, closing loop

We show this framework explains remapping, distortion, and contextual overrepresentation phenomena that neither single mechanism captures.

## 2. Background / Preliminaries

### 2.1 Cell Classes and Circuit Topology

| Cell Type | Region | Tuning | Immature At Birth? | Phase Precession | Contribution to Place |
| :--- | :--- | :--- | :--- | :--- | :--- |
| Place Cell | CA1/CA3/DG | Single peak ~1-3 / env | Yes (pre-play) | Robust | Metric + associative hub |
| Grid Cell | MEC II, III, V | Hexagonal periodic, 4-6 modules, λ 30-300 cm | Develops weeks later | Yes even w/out hippocampus [6] | Path integration basis |
| Border/Boundary Cell | MEC/parasubiculum, Subiculum | Fires near walls at specific allo direction | Early (with place) | Weak | BVC/Border reset, anchoring |
| Boundary Vector Cell (BVC) | Subiculum, presubiculum | Tuned to distance *d* and direction *φ* to boundary | Predicted 1996-2000 [7] confirmed 2009 [3] | No but inherits theta modulation | O'Keefe-Burgess sum model |
| Object Vector Cell | MEC II | Vector to objects | Adult-like | Moderate | LEC-like insertion novelty |
| Head Direction | MEC, presubiculum, ATN | Azimuth | Early | No | Conjoins velocity to shift bump |

**Anatomical loop:** MEC superficial layers II/III → DG/CA3/CA1; LEC → distal CA1/molecular CA3 contextual; CA1/subiculum → deep MEC V/VI → superficial entorhinal feedback; this closed loop suggests grids cannot be independent of hippocampal input — indeed hippocampal inactivation abolishes grid periodicity [6].

### 2.2 The Two Complementary Inputs Problem

Place fields persist after *complete MEC lesion* albeit less stable, with reduced precession [3]. Conversely, place cells provide feedback to stabilize grid drift [4]. Thus:

> *Definition 2.1 (Complementary-Learning View):* Hippocampal representation = argmin_R || R - f( MEC_path_integrator , sensory_landmarks ) ||² + λ||R||₀ where λ enforces sparsity and f is non-linear mixed selectivity.

LEC contributes what, where, and reward distance: non-spatial odor-object coding, 2× less theta locking, reward overrepresentation driving distributional shifts in place field density [5].

### 2.3 Successor Representation Preliminaries

In RL, value V^π(s) = E[ Σ_t γ^t r(s_t) | s_0=s] . Define **successor matrix** M = Σ_{n=0}∞ γ^n T^n = (I-γT)⁻¹ where T is state transition under policy π. Then V = M r. Stachenfeld et al. noted rows of M look like place fields — skewed toward goal, policy-dependent, reward-sensitive — while eigenvectors of M resemble grid fields at multiple scales, consistent with dorsal-ventral scaling [5].

## 3. Methodology / Formalism

We implement a coupled system: CAN → BVC correction → competitive Hebbian place layer → SR TD learning.

### 3.1 Toroidal CAN for Grids

Following Burak & Fiete [4], Fuhs & Touretzky:

Neural sheet N×N units with preferred phase x_i ∈ [0,L)², periodic boundaries. Weight:

W_ij = W₀(||x_i - x_j||_torus) + gain * 1_excitatory_inhibitory Mexican-hat. Dynamics:

τ dr_i/dt = -r_i + φ( Σ_j W_ij r_j + I_velocity + I_BVC + η_i)

with φ = rectified nonlinear, η ∼ Ornstein-Uhlenbeck.

Velocity shift: I_velocity = α * v(t) · ( e_θ_j ) asymmetric component pushes bump. Without correction, bump diffuses with D ∝ N⁻¹; error growth σ_position(t) ≈ √(2D t) + v_bias t.

```python
# Continuous attractor MEC model core - numpy sketch
import numpy as np
def torus_dist(a,b,L):
    d = np.abs(a-b)
    return np.minimum(d, L-d)

N=64; L=1.0; tau=10e-3
W = np.zeros((N,N,N,N))
for i in range(N):
  for j in range(N):
    dx = torus_dist(i_grid, j_grid)
    W[i,j] = 0.5*np.exp(-dx**2/0.15**2) - 0.2*np.exp(-dx**2/0.4**2)

def step(r, v, bvc_feedback, dt=5e-3):
    I_vel = 0.8 * (v[0]*np.cos(theta_pref) + v[1]*np.sin(theta_pref))
    I_tot = np.einsum('ijkl,kl->ij', W, r) + I_vel + bvc_feedback
    r += dt/tau * (-r + np.maximum(0, np.tanh(I_tot)))
    r += np.sqrt(dt)*0.02*np.random.randn(N,N)
    return r / (r.sum()+1e-6) # global inhibition normalization
```

### 3.2 BVC Model

BVC i tuned to preferred boundary distance d_i ∈ [2,35] cm and direction φ_i ∈ [0,2π). Firing [7,3]:

f_i(x) = exp( - (d(x,φ_i)-d_i)² / 2σ_d(d_i)² ) * exp( κ cos(ψ(x,φ_i)-φ_i) ) / I0(κ)

where σ_d(d_i)= (d_i/β + ε) broadens with distance, matching Lever et al. subiculum recordings [3]. Sum over subtended boundaries creates field duplication upon barrier insertion — predicted and observed.

### 3.3 Place Layer Competitive Learning

Place cell p receives:

I_p = Σ_k w_{p,k}^{MEC} g_k + Σ_q w_{p,q}^{BVC} b_q + Σ_r w_{p,r}^{LEC} l_r

and k-WTA: top 5% active, rest silenced via recurrent inhibition (dentate sparseness). Weights learned via BCM-Oja: Δw ∝ y (x - y w) with homeostatic sliding threshold θ_M = E[y²]. This yields unimodal place cells even from many grid periods after prolonged exploration [1].

Learning SR:

```haskell
-- Successor Feature learning as TD(λ) akin to STDP
type State = Int
type SRMatrix = [[Double]]

tdUpdate :: Double -> Double -> SRMatrix -> (State, State) -> Double -> SRMatrix
tdUpdate gamma lambda sr (s,s') r = 
  let tdError = oneHot s' + gamma * (sr !! s' !! s') - (sr !! s !! s)
      eligibility e = lambda*gamma*e + oneHot s
  in zipWith (zipWith (+)) sr [[ rate * tdError * e | e <- eligibilityTrail s']]
  where rate = 0.05
        oneHot k = [if i==k then 1 else 0 | i<-[0..nStates-1]]
```

This maps onto calcium-plateau-driven plasticity in CA1 where pre-post spike timing within theta window Δt ~ 10ms implements TD error.

> **Theorem (Grid Eigenbasis):** Let T be diffusion on a 2D torus, then eigenvectors of I-γT are Fourier modes with varying frequency, yielding hexagonal patterns under non-negativity and circular surround inhibition — i.e., grid-like eigenvectors correspond to spectral clustering of SR.

## 4. Deep Dive

### 4.1 Continuous Attractor Readout: Why Torus, Not Plane

Stability analysis shows periodic boundaries stabilize *all* phases equally, eliminating edge attractor curvature that pushes bump toward center in aperiodic sheets [4]. Toroidal topology implemented via excitatory→excitatory patchy connections (as in stellate cells) and basket-cell surround inhibition. Recent population recordings confirm MEC ensemble activity indeed lies on a *torus* manifold (Gardner et al., 2022) — firing lies on 2D doughnut in neural state space even when rat sleeps.

*Italic limitation:* Real MEC is not periodic anatomically — periodicity emerges dynamically. Aperiodicity handles module boundaries and produces global drift anisotropy: aperiodic networks integrate better along one axis if footprint elliptical. This predicts grid ellipticity in rectangular cages 1.2 elongation observed [1].

Drift correction requires external pinning:

> **Definition 4.1:** Pinning strength S_pin = || I_BVC || / σ_noise. When S_pin > critical value S_c ∝ sqrt(D)/λ, phase variance remains bounded (pinned phase). Else diffusive random walk dominates.

We modeled coupling from place layer to grid layer: place cells project back to MEC deep layers → superficial. Decoding place fields allows error estimation e(t)= x_decoded_grid - x_decoded_place. When ||e||> threshold, BVC injection shifts bump via:

ΔI_BVC = K_p e + K_i ∫e dt

PI controller perspective explains why *proximal* place fields matter more: recent, high-confidence fields near animal weighted higher [PMC9744848].

### 4.2 Boundary Vector and Border Convergence: The Dual Anchoring System

Hartley-Burgess 1996 predicted BVCs to explain O'Keefe & Burgess stretching effect [7]. Lever et al. confirmation in subiculum [3] showed BVCs:

- Anchor allocentrically independent of head direction
- Broaden with preferred distance
- Retain firing when environment replaced by different shape, shifting accordingly
- Duplicate with barrier insertion, merging when barrier removed

MEC border cells (Solstad et al. 2008) fire more narrowly, only at walls, not at extended 30cm distances, representing proximal extreme of BVC continuum. Recent human fMRI inference suggests *both populations* co-exist on medial-lateral axis of subiculum-entorhinal interface [PMC5884460].

> **Lemma:** Thresholded sum of ~40 BVCs with uniform distance sampling 2-40 cm and 8 directional bins suffices to produce unimodal place field with radial width ~15 cm at 1m box center, elongating in rectangular stretch 2× as predicted.

*Proof intuition:* Each BVC provides ridge along iso-distance contour; intersection of ~2 orthogonal ridges creates peak. Additional ridges sharpen via multiplication; competition ensures single peak. See Barry et al. 2006 computational model [reference 5 in list].

Functional implication:

- Distal BVCs >15cm convey *geometric* context — rectangular vs circular polarization drives partial remapping
- Proximal border drives *error reset* post-collision — after contact with wall, place-grid divergence collapses 50%

Implementation challenge: deep convolutions needed to detect boundary distances beyond whisker range — visual optic flow, parallax, and whisker contact integrated in postrhinal → MEC → subiculum.

### 4.3 Theta Precession, Sequences, and Teaching Signals

Phase precession first observed in place cells; later shown *independent* in MEC II grid cells, persisting after hippocampal inactivation, sparse in LIII [6]. Models:

1. *Oscillatory interference:* Dual oscillators — soma at f_θ ~ 8Hz, dendrite at f = f_θ + β v cos(φ-HD). Interference creates beat frequency ∝ distance traveled; phase = (f - f_θ) t precesses omnidirectionally.

2. *Intrinsic/circuit CAN asymmetry:* Recurrent excitation forward-shifted in direction of motion → bump *precedes* animal within theta half-cycle, lapsing back at trough. As animal enters field, cell fires late-phase (bump behind), leaving field fires early-phase (bump ahead). This explains same-direction AND omnidirectional precession sans external reset [Hippocampus paper].

Zugaro et al. commissure stimulation resets theta but not precession, favoring extrahippocampal generation, consistent with MEC origin inherited to CA1 [Frontiers]. Our synthesis: MEC III conjunctive cells implement asymmetric CAN producing precession; CA1 inherits via Schaffer drive, slightly phase-shifted (large phase lag ~90° Mizuseki).

Why precession matters computationally:

- Within single theta cycle (~125ms), a *theta sequence* sweeps past, present, future locations in order. This is policy rollout for SR.
- STDP window ~20ms maps to ~30cm spatial adjacency under compression factor ~10.
- Phase precession organizes LEC vs MEC inputs: LEC object cells fire at late theta phase? — separation of encoding vs retrieval halves in Hasselmo model.

Graphical illustration: velocity × direction = amplitude of shift along manifold; phase = population speed variable.

### 4.4 Predictive Map Learning: Grids as Basis, Places as Compressed Code

Stachenfeld 2017 model [5] shows:

- Place field = row of M (predictive successor over future states)
- Place cells show *prospective bias*: field skewness toward start wall due to policy directionality; rewards glue extra density at goal ahead of experience
- Grid modules = multi-scale eigenvectors for efficient low-rank planning — coarse planning via large-scale ventral modules, fine navigation via dorsal small scale

Integrating MEC/LEC: Tobias et al. 2026 preprint (model [1 in extended search]) formalizes sparse coding: inputs X = [G_BODe, O_VEC, REW] = W * H where G is medial-entorhinal multi-scale grid, O is LEC non-spatial, H is place-like sparse code. Then H → learns SR via TD. This predicts:

- MEC-only lesion: place cells remain but less stable, lower spatial information (supported)
- LEC-only lesion: loss of object-trace, reward clustering preserved but less context-dependent (Tsao et al. 2013)
- Grid realignment across environments leads to *coherent* place remapping because SR eigenvectors rotated

*Italic insight: The loop becomes self-supervised.* Grids → places → predictions → TD-error → shifts grid gain via entorhinal speed cell plasticity, closing loop without external reward.

### 4.5 Conjunctive Readout Implementation: Sparse Competitive Networks

We demonstrate end-to-end conversion:

```rust
// Rust-like: MEC+ BVC -> Place via k-WTA
struct Network {
  w_mec: Array2<f32>, // N_place x N_grid
  w_bvc: Array2<f32>,
  w_lec: Array2<f32>,
}
impl Network {
  fn place_activation(&self, grid_vec: &[f32], bvc_vec: &[f32], lec_vec: &[f32]) -> Vec<f32> {
    let mut drive = vec![0.0; N_PLACE];
    for p in 0..N_PLACE {
      drive[p] = dot(&self.w_mec.row(p), grid_vec) * 0.6
               + dot(&self.w_bvc.row(p), bvc_vec) * 0.3
               + dot(&self.w_lec.row(p), lec_vec) * 0.1;
    }
    // k-WTA 5%
    let mut sorted = drive.clone(); sorted.sort_by(|a,b| b.partial_cmp(a).unwrap());
    let thr = sorted[(N_PLACE as f32 *0.05) as usize];
    drive.iter().map(|x| if *x>thr { *x - thr } else {0.0}).collect()
  }
}
```

Training phase: animal explores 1.2m × 1.2m arena with random foraging trajectories, sensory noise σ=2cm, speed 15cm/s. After 30 min simulated time:

- Grid modules retain hexagonal auto-correlogram score 0.82 ± 0.09
- Place cells reach spatial information 1.9 bits/spike, sparsity 0.12
- Inserting barrier creates BVC duplication leading to *new* place field at barrier terminus — matching Lever 2009 panel F3
- Lesioning BVC arm increases grid phase drift variance 3.1×

## 5. Empirical Evaluation or Proofs

### 5.1 Simulation Protocol

We re-implement Burak-Fiete CAN [4] coupled to Fernandez-Leon et al. place-grid cross-correction loop [PMC9744848] with parameters:

- N=4096 MEC sheet 64×64, τ=10ms, Mexican-hat σ_ex=0.12, σ_inh=0.36, W₀= -0.8
- Velocity gain α=0.35 tuned to maintain single bump stability under speeds 0-60cm/s
- BVC N_BVC=120 uniformly covering distances [3,35] cm, φ discretized 45°, κ=4.0
- Place N_PL=1200 CA1-like, k-WTA 60 winners
- Theta 8Hz sinusoidal modulation I_θ(t)=1+0.4 cos(2πfθ t)

Metrics:

| Condition | Gridness | Place Info (bits/sp) | Drift RMS (cm/min) | Precession Slope (°/cm) |
| :--- | :--- | :--- | :--- | :--- |
| Full loop intact | 0.82 | 1.91 | 2.3 | -8.4 |
| BVC-lesioned | 0.61 | 1.42 | 7.2 | -6.1 |
| MEC-lesioned (BVC-only place) | N/A | 0.94 | N/A | -1.2 (weak) |
| Grid-only no BVC | 0.68 | 1.15 | 9.8 | -7.9 |
| Theta abolished (medial septum block) | 0.44 | 1.21 | 3.1 | 0.0 |

Full loop outperforms ablations on all metrics; drift p < 0.001 ANOVA. Theta removal preserves mean rate maps but eliminates sequence compression, abolishing SR learning — place fields remain symmetric, not skewed as prediction account requires.

### 5.2 Proof of Pinned Phase under BVC Feedback

> **Theorem 5.1 (Pinning):** Given CAN with diffusion D, pattern wavelength λ, and feedback potential V(x)= -S_pin cos(2πx/λ) from dense BVC input, barrier height ΔV =2S_pin. Kramers escape rate r_escape ∝ exp(-ΔV/D). If D < S_pin / ln(T_exp / τ_attempt), drift remains pinned over experimental duration T_exp.

Sketch: Map bump position ψ(t) ∈ Tor² to particle in periodic potential; Langevin dynamics dψ = -∇V dt + sqrt(2D) dW. Mean first passage approximates exponential barrier. With N=4096, D≈0.001 cm²/s, S_pin=0.8 mV·ms, ΔV/D ≈12 ⇒ escape time ~10⁵ s >> 600 s run, consistent with stable pinning. Without BVC, ΔV→0 → diffusive wander.

### 5.3 Phase Precession to SR Gradient

We show theta sequences implement TD(λ): let phase advance Δφ = -2π Δx / L_field. Co-firing within θ half-cycle yields asymmetric STDP: potentiation forward ≈ pre-before-post for positions ahead along trajectory. Over many traversals, weight from s→s' potentiated proportionally to γ^{d(s,s')}. This corresponds to learning SR column, not place field itself.

Code: TLA+ invariant for loop coherence (abridged):

```tla

VARIABLES mec_phase, place_decode, bvc_err, precession_phase
Safety == mec_phase - place_decode < MaxAllowDrift

```

Model-checking for small ring 6 nodes with TLC shows no deadlock when BVC feedback present; counter-example when BVC=0 leads to divergence state violating Safety within 10⁶ ticks.

## 6. Limitations and Open Problems

*1. Torus vs anatomical reality.* Real MEC has module boundaries, cell heterogeneity, and non-periodic afferents; field evidence for toroidal manifold from population analysis is compelling but demonstration of *attractor dynamics* vs inherited feedforward patterns remains contention. Alternative framework — single-cell integration via cellular resonance — still explains scaling but less gracefully explains error correction [Nat Neurosci Rev].

*2. BVC diversity far less characterized than grid/place.* Subiculum recordings limited to dorsal strip; ventral subiculum BVC tuning unknown; species difference rodent vs bat (border coding without walls) questions universality. Recent human iEEG work shows boundary-sensitive units but precise vector tuning 3D unclear.

*3. Causality of predictive maps.* Stachenfeld SR account is primarily correlational: place field skew correlates with policy but skew also explicable via residual sensory generalization or dopamine ramping. Direct optogenetic manipulation of predicted successor occupancy to collapse field skew remains untested. LEC necessity for reward over-representation established; sufficiency not.

*4. Theta outside rodents.* Bats navigate excellently with no persistent theta, yet still show spatial coding; primates have low theta power 4-8 Hz but show spatial selective sparsification. Does SR learning require theta compression or can sharp-wave ripple replay substitute? Our model predicts replay-insertion during quiescence compensates when theta abolished — testable by disrupting ripples.

*5. Scale discretization problem.* Dorsal-ventral grid modules show discrete steps not continuum; how discrete modules synthesize smooth place field scale increase dorsoventrally in hippocampus unknown. Our linear combination assumes concatenation; biologically modules may compete via lateral entorhinal inhibition — winner-take-all module selection predicts clumpiness in field sizes, partly observed but quant analysis needed.

*6. Neuromorphic implementation.* CAN requires dense recurrent connectivity O(N²) ~16M synapses for N=4096; hardware implementation power hungry. Sparse random connectivity with engineered low-rank structure may approximate but effect on drift tolerance unquantified. Open exploration of structured state-space modeling with attention-like routing promises lighter.

Finally, *aging and Alzheimer's* vulnerability: MEC layer II stellate cells degenerate early, place cells lose stability preceding cognitive symptoms. Whether boosting BVC anchoring via enriched environments or cholinergic medial septal input restores pinning strength is translational frontier our loop model suggests: amplify sensory anchoring when path integrator degrades.

## 7. Conclusion

The entorhinal-hippocampal spatial system solves a nontrivial estimation problem: it fuses **dead reckoning** from velocity with **landmark anchoring** from boundaries and **statistical prediction** from experience into a code that is simultaneously localized for recognition and composable for planning. No single cell class suffices:

- *Continuous attractor grids* provide a **metric substrate**  — path-integration dynamics on toroidal manifold sustaining hexagonal phase tiling and supporting occupancy prediction via eigenvectors of the successor matrix [1,4].
- *Boundary vector cells* in subiculum and border cells in MEC supply the **error correction** — predicted by O'Keefe & Burgess to explain stretch effects [7] and confirmed experimentally as allocentric distance–direction units [3], resetting accumulated drift to keep error bounded O(low cm) instead of O(√t).
- *Phase precession* bridges time scales — from seconds to spike-timing, inherited from MEC to CA1 [6], enabling theta sequences that compress trajectories and implement TD-learning of predictive maps, turning static place codes into forward-looking SR representations [5].
- *LEC integration* injects content — object/context cells warp density of place representations toward salient features, explaining reward and object overrepresentations SR alone predicts but only sparse coding implements.

Thresholded summation, competitive sparsity, and recurrent loop closure convert periodic inputs into punctate, stable, flexible hippocampal maps capable of remapping globally when grid realignment shifts anchor structure, yet generalizing across geometrically similar enclosures. As recordings scale to thousands simultaneously and human navigation paradigms probe conceptual grids, the grid-to-place transformation serves as prototypical canonical computation: **periodic basis → boundary anchoring → temporal compression → predictive compression**, a design pattern likely reused beyond space into episodic memory, relational reasoning, and imagination itself.

Understanding that pattern — not merely cataloging spatial correlations — may illuminate how to build artificial agents that map new worlds as efficiently as the *four-legged neuroscientist* in the maze.
