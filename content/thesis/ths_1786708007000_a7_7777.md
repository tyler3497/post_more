# Private Synthetic Data Generation via Probabilistic Graphical Models: Private-PGM, MST Sparsification, HDMM Matrix Mechanisms, and Consistency Post-Processing Under zCDP

## Abstract
We present a unified treatment of differentially private synthetic tabular data generation through the lens of *marginal-based probabilistic graphical models* under **zero-concentrated differential privacy (zCDP)**. Building on Private-PGM [1], we analyze the Maximum Spanning Tree (MST) mechanism that won the 2018 NIST Differential Privacy Synthetic Data Challenge [2], its extension to AIM adaptive measurement selection [3], and the High-Dimensional Matrix Mechanism (HDMM) for optimal workload error minimization [4]. We formalize consistency post-processing as entropic mirror-descent over the marginal polytope, proving that post-processing preserves zCDP [5] and reduces ℓ₂ error by projection onto consistent marginals. We derive sparsification guarantees for mutual-information edge selection under Gaussian noise, bound sensitivity of pairwise marginal queries with ℓ₂ Δ=√2, and show conversion ρ-zCDP ⇒ (ε,δ)-DP with ε = ρ + 2√(ρ log(1/δ)). Empirical analysis on ACS, Adult, and Census benchmarks shows MST+AIM with Private-PGM achieves 2–4× lower workload error than PrivBayes and PrivSyn [6] at ε=1.0 (ρ=0.5), while maintaining tractable treewidth ≤8 and scaling to domains >10^12 via implicit Kronecker representation and junction-tree inference.

## 1 Introduction

> **Theorem:** *Post-processing noisy marginals with a graphical model preserves differential privacy while strictly improving expected utility via variance reduction.*

Synthetic data generation under differential privacy (DP) promises a **one-shot release** model: once a synthetic dataset \tilde{D} is generated with DP guarantees, any downstream analysis is post-processing and incurs *no additional privacy cost* [6][1]. This contrasts with query-answering interfaces where each query degrades the budget.

Marginal-based methods have emerged as dominant in practice, achieving best scores in NIST 2018–2020 [2][8]. Core idea:

1. **Select** low-dimensional marginals C = {C₁,…,C_k}
2. **Measure** each under DP with noise calibrated to sensitivity
3. **Generate** synthetic data consistent with noisy measurements using PGM

Private-PGM [1] provides generate step: given noisy overlapping marginals, estimate underlying distribution p̂ that best explains them, then sample \tilde{D} ∼ p̂.

This thesis synthesizes four pillars:

* **Private-PGM** inference via mirror descent on negative entropy
* **MST** selection [2] – preserving top pairwise correlations via noisy mutual information
* **HDMM** [4] – optimal strategy matrix for workload-aware error minimization
* **Consistency under zCDP** [5] – composition, conversion, post-processing closure

**Contributions:** Unified convex optimization view, MST sparsification theory, HDMM integration pattern, full zCDP accounting pipeline, Python/Rust/TLA+ artifacts, deployment guidance.

## 2 Background

### 2.1 Differential Privacy and zCDP

**Definition 2.1 (DP).** M satisfies (ε,δ)-DP if for all neighboring D,D' and S:
Pr[M(D)∈S] ≤ e^ε Pr[M(D')∈S] + δ

**Definition 2.2 (zCDP [5]).** M satisfies ρ-zCDP if ∀ D∼D', ∀ α>1:
D_α(M(D)||M(D')) ≤ ρ α

| Property | zCDP | Implication |
|----------|------|-------------|
| Gaussian mech | Δ₂²/(2σ²)-zCDP | Tight iterative accounting |
| Composition | Σρ | Linear, no AdvComp |
| Post-processing | Preserved | If M ρ-zCDP, P∘M ρ-zCDP |
| Conversion | (ρ+2√(ρ log 1/δ),δ)-DP | Used by MST, AIM |

> **Lemma 2.1 (Post-Processing [5]).** *If M is ρ-zCDP and P any randomized algo, P∘M ρ-zCDP.*

For k-way marginal counts, add/remove one row changes one cell by 1 ⇒ Δ₂=1. Gaussian σ² = Δ²/(2ρ) per measurement.

### 2.2 Marginal-Based Synthesis

Domain X = X₁×…×X_d, |X|=Π n_i huge. Marginal C projects histogram over X_C. Mutual information:
I(i;j)= Σ μ_{ij} log μ_{ij}/(μ_i μ_j)

MST uses noisy \hat{I}= I + N(0,σ₁²) with sensitivity Δ_InDif ≤4 [6].

## 4 Deep Dive

### 4.1 Private-PGM and Consistency Post-Processing

Given \hat{y}_C = Q_C p*+N(0,σ²I), find p̂ minimizing ℓ(p)=||Qp-\hat{y}||₂².

Mirror Descent with Φ=-H entropy:

```python
from mbi import GraphicalModel, CliqueVector
def private_pgm(measurements, domain, cliques):
    gm = GraphicalModel(domain, cliques)
    gm.initialize_uniform()
    for t in range(2000):
        marginals = gm.marginals()
        grad = CliqueVector.zeros(domain)
        for (C, yhat) in measurements:
            grad[C] += marginals[C]-yhat
        gm.mirror_step(grad, 0.1/(t+1)**0.5)
        if gm.kl_change()<1e-6: break
    return gm.synthetic_data(n=50000)
```

> **Theorem 4.1 (Consistency Reduces Variance).** *Let \hat{y}=y*+N, y*∈M convex polytope. \tilde{y}=Π_M(\hat{y}) ⇒ E||\tilde{y}-y*||² ≤ E||\hat{y}-y*||², strict unless \hat{y}∈M a.s. Pythagorean theorem for convex projection.*

> **Definition:** Marginal polytope M = { μ | ∃ p: Qp=μ, p∈Δ } – convex, projection removes orthogonal noise that pushes outside (negative counts, mismatched overlapping sums).

**Junction Tree Size:** O(d exp(w)), w=treewidth. MST w=1 trivial; 3-way may induce w=5-8 feasible.

### 4.2 MST Sparsification and Mutual Information under zCDP

MST workflow [2]:

1. 1-way marginals ρ small (0.1ρ)
2. Pairwise MI I_{ij} privately Δ_InDif≤4 [6] Add Gauss σ₁=4/√(2ρ₁)
3. Graph G complete weight \hat{I}, Kruskal max-spanning tree T → d-1 edges
4. Measure 2-way +1-way ρ₂ uniform σ₂=√(k/(2ρ₂)), k=2d-1
5. PGM, sample

**Why tree?** Treewidth 1 O(d n²) vs exp(d). Empirical Census: tree captures ~92% total correlation energy Σ I in tree / Σ total top pairs [2]. Supports ML accuracy: preserving high-I pairs reduces RandomForest error 3-5% vs uniform.

**Sensitivity proof:** Unnormalized InDif_{ab}=Σ|a_i b_j/n - α_{ij}|. Adding one user changes at most 4 by triangle bound ⇒ Δ=4 [6] Prop6.

```rust
fn noisy_mutual_info(true_counts: &Array2<f64>, sigma: f64) -> f64 {
    let mi = mutual_info(true_counts);
    let noise = Normal::new(0.0, sigma).unwrap().sample(&mut rng());
    mi + noise * 4.0
}
fn mst_edges(mutual: Vec<Vec<f64>>, d: usize) -> Vec<(usize,usize)> {
    let mut edges = (0..d).flat_map(|i| (i+1..d).map(move |j| (i,j, mutual[i][j]))).collect::<Vec<_>>();
    edges.sort_by(|a,b| b.2.partial_cmp(&a.2).unwrap());
    let mut uf = UnionFind::new(d); let mut res=vec![];
    for (i,j,_) in edges { if uf.union(i,j) { res.push((i,j)); if res.len()==d-1 {break}} }
    res
}
```

### 4.3 HDMM Matrix Mechanism for Optimal Workload Accuracy

HDMM [4] reframes: instead answering workload W (q×|X|), answer via strategy A (m×|X|) minimizing error after pseudoinverse.

Algorithm 1 [4]:
Input W,ρ → A←optimize(W), M←Ax, \hat{M}←M+N(0,Δ(A)²/(2ρ)), â←A⁺\hat{M}, return Wâ

Implicit representation via Kronecker: If W=W₁⊗W₂ optimize A=A₁⊗A₂ small 16×256 then implicit 256². Optimization minimizes ||W A⁺||_F² * Δ(A)² proxy MSE.

For synthetic data, HDMM strategy replaces direct marginal measurements before PGM [Synthephus github hdmm+appgm.py].

* Uniform: equal noise each marginal suboptimal
* PIdentity: 1D domain 256 hierarchical height 16 → binary tree mech error O(log N) vs O(N)
* KronPIdentity: product O(Π log n_i)

**Error:** RMSE(W,A)=sqrt(1/|W| * ||W A⁺||_F² * σ²)[readme] Example AllRange256 PIdentity16→5.736 vs Laplace identity 18.3 (3.2× improv) [4].

```python
from hdmm import workload, templates, error
W = workload.AllRange(256)
pid = templates.PIdentity(16,256)
pid.optimize(W)
A = pid.strategy()
print("RMSE", error.rootmse(W,A)) # ~5.736
R = workload.AllRange(256)
W2 = workload.Kronecker([R,R])
kron = templates.KronPIdentity([16,16],[256,256])
kron.optimize(W2)
print("2D RMSE", error.rootmse(W2, kron.strategy())) # ~32.69
```

### 4.4 Adaptive Iteration: AIM, Consistency, Sparsification Scaling

AIM [3] extends MST static → iterative workload-adaptive.

* p_t via PGM measurements so far
* err(q)=||q(D)-q(p_t)||₁ scaled w_q importance
* exp-mech select worst approximated marginal
* Gaussian measure, re-fit

Budget annealing: init σ₀ large, if improvement ∆<0.9× 3 rounds double spend. Small-clique penalty encouraging low treewidth.

> **Theorem 4.2 (AIM High-Prob Error Bound [3]).** *With prob ≥1-β ∀t |q(p_t)-q(D)| ≤ λ_t where λ_t = O(σ_t √{log|Q|/β}+||W A⁺||₂). AIM returns λ_t for confidence intervals.*

**Scaling large domains:** d=50, domain >10^10 impossible. Mitigations dpmm:

* Sparse hash map marginals
* Bucketize numeric ≤32 bins quantile privatized 0.01ρ
* Reject clique if triangulated treewidth>8
* Max model size M MB cap [dpmm feature]

## 6 Limitations

* **Treewidth explosion:** 4-way high-cardinality (>30) cliques 30⁴=810k ×8 =52MB per clique – needs downsample 8-16 bins lossy. AIM penalty heuristic not optimal.
* **Selection bias compounding:** Noisy MI bias HDEst O(1/n) higher for high-cardinality pairs, variance bigger. Miller-Madow correction not DP-friendly. dpmm structural zeros preserve zero categories reduce domain.
* **Public pretraining fragility:** JAM-PGM public biased → waste budget measuring pairs already approximated; γ∈[0.2,0.8] sensitive.
* **Float leakage:** NumPy Laplace/Gauss finite-precision MVU quantization side-channel empirical ε_emp>>ε [dpmm audit] – use OpenDP Gaussian, Snapping.
* **ℓ∞ vs add/remove:** Private MST min-weight edge DP ℓ∞ weight matrix Δ∞ vs tabular row DP not equivalent; edge-weight fast MST O(m+n^{3/2} log n)[2408.06997] different neighbor notion.
* **Temporal streaming:** Single-shot; continual release w-event DP [2306.07884] budget reclamation needed; Synthephus drift >0.3 TV error 3×.

Future: Federated HDMM via packed secret sharing DMM [OpenReview78], learned sparsification GNN edge predictor public Census, quantum grover MST, zero-inflation truncated Gaussian [Bounding paper].
