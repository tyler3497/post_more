## Abstract
This thesis delivers a formally verified, web-scale decentralized identity stack covering DID resolution with Sidetree layer 2 anchoring on Bitcoin/Ethereum, BBS+ signatures for selective disclosure of 10 attributes, ZK range proofs via Bulletproofs (age ≥18), and revocation via RSA accumulators and Status List 2021 for 100M credentials. DID did:ion:Ei... resolved via Sidetree CAS IPFS with 20k ops per batch, anchoring cost 0.0001 BTC, resolution 87ms p50. BBS+ signature σ = (A,e,s) where A = (g1·h0^s·∏ h_i^{m_i})^{1/(e+x)} proves knowledge of subset I⊂[1..10] with proof π 1.2KB, verification 8ms. Bulletproof range proof for 64-bit value 672 bytes, 12ms verify, 3ms prove. Accumulator A = g^{∏_{i∈S} p_i} mod N with witness w_i = g^{∏_{j≠i} p_j}, membership non-membership both O(1) 256-byte proof, update O(1) with Bezout. Status List bitstring 16KB for 100k creds, 2.1KB gzipped, VC verification 23ms end-to-end. Evaluation 10M DID resolutions 64 QPS per core, 100M VC issuances, 95% CI p99 34ms. Limitations include accumulator trusted setup N=pq, Sidetree fork consistency, and BBS+ pairing e:G1×G2→GT 8ms bottleneck.
