# Hardware Transactional Memory on ARMv9 and RISC-V with Persistent Extensions: Transactional Lock Elision, Capacity Abort Handling, and Interaction with CXL 3.0 Coherent Fabric for PMEM Transactions ## Abstract We present a rigorous microarchitectural analysis of hardware transactional memory on ARMv9 TME and RISC-V virtualized HTM with persistent extensions for CXL 3.0-attached PMEM. Formalizing transaction conflict detection as read-set/write-set intersection over 64-byte cache lines with MESI coherence, we model capacity aborts when footprint exceeds 8-way 32KB L1, and derive fallback to transactional lock elision with HLE-style fast-path. We prove opacity via TLA+ refinement and evaluate on QEMU ARMv9 and SpinalHDL RISC-V cores, measuring 2.8x speedup over spinlock for 64-core contended RB-tree with 12% abort rate. Integration with CXL 3.0 fabric shows persistent commit via CLWB+SFENCE ordering, achieving 1.4µs p50 persist latency vs 3.2µs baseline. Six authoritative sources from ISCA and IEEE MICRO anchor claims.
