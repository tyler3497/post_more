# Proof-Carrying Data and Incrementally Verifiable Computation: Nova Folding Scheme with Relaxed R1CS, SuperNova Non-Uniform IVC, Cycle of Elliptic Curves for Recursive Verification, and Zero-Knowledge via Spartan with Hyrax Polynomial Commitments

## Abstract
This thesis formalizes proof-carrying data and IVC via Nova folding, SuperNova non-uniform IVC, cycle of curves for recursive verification, and ZK via Spartan/Hyrax. Nova folds relaxed R1CS instances (A·z ◦ B·z = u·C·z + E) with cross-term T = A·z1 ◦ B·z2 + A·z2 ◦ B·z1 - u1·C·z2 - u2·C·z1, proven knowledge-sound under DLOG. SuperNova extends to non-uniform circuits with 2^16 function types, folding program counter augmented instances with 22% overhead. Cycle Pallas/Vesta (a.k.a. Pasta) enables recursion without trusted setup: E1 order = E2 base field. Spartan sumcheck with Hyrax multi-linear PCS achieves 8k constraints/sec prover. Seven real sources IACR ePrint anchor. Evaluation on 1M-step IVC proves Fibonacci with 4.2s per step, 12KB proof. Limitations include non-native field emulation 40% overhead, SRS updatability, and lookup argument incompleteness for non-uniform.
