# Homomorphic Secret Sharing for Low-Degree Polynomials: Function Secret Sharing with Distributed Point Functions, Beaver Multiplication Triples via OT Extension, and Quasi-Linear Silent OT for Secure Aggregation at Billion Scale

## Abstract
Homomorphic Secret Sharing (HSS) enables low-communication secure computation by splitting inputs into shares that support local homomorphic evaluation of restricted function classes followed by succinct reconstruction. This thesis develops a unified construction for low-degree polynomials using Function Secret Sharing (FSS) instantiated via Distributed Point Functions (DPFs), Beaver multiplication triples generated through Oblivious Transfer (OT) extension, and quasi-linear Silent OT based on the Ferret paradigm for billion-scale secure aggregation. We present a two-server model where clients secret-share one-hot and heavy-hitter vectors via incremental DPFs, servers evaluate degree-2 and degree-$d$ polynomials under FSS, and correlated randomness is provisioned through Silent OT with $O(n \log n)$ LPN encoding. Our analysis demonstrates that combining DPF key size $O(\lambda \log N + |G|)$ with Silent VOLE extension achieves sublinear server-to-server communication for $10^9$ client inputs, while preserving malicious security via sketch-based verification as in Prio [6]. We prove security under the random oracle model and LPN assumption, provide asymptotic costs, and evaluate concrete performance for private telemetry aggregation. The construction bridges theory of HSS for RMS programs [7] with practical private aggregation systems.

## 1 Introduction
Secure aggregation at internet scale demands cryptographic primitives that simultaneously minimize client upload, server interaction, and verification overhead. Traditional secret-sharing based aggregation requires linear reconstruction, while fully homomorphic encryption incurs prohibitive computational cost for billion-client deployments.

*Homomorphic Secret Sharing* offers a middle path: shares of an input $x$ can be locally evaluated on a function $f$ from a restricted class $\mathcal{F}$, producing output shares that reconstruct to $f(x)$ without interaction [7]. When $\mathcal{F}$ includes low-degree polynomials, this primitive underpins private heavy-hitters, private information retrieval, and privacy-preserving machine learning.

This work synthesizes three lineages:

- **Function Secret Sharing (FSS)** [1][2] and its instantiation as **Distributed Point Functions (DPFs)** [3], providing compact keys for point and interval functions with domain $2^n$.
- **Beaver multiplication triples** generated via **OT extension** [4], enabling degree elevation from linear to quadratic and beyond without per-multiplication base OTs.
- **Silent OT and Ferret OT extension** [5] using Learning Parity with Noise (LPN) over expand-accumulate codes to produce $10^7$–$10^9$ random OTs from $O(\lambda)$ seed communication, quasi-linear in computation.

We show that their composition yields a **two-server HSS for low-degree polynomials** suitable for **Prio-style secure aggregation** [6] at billion scale. Clients emit DPF keys that simultaneously secret-share their input and its powers; servers non-interactively multiply shares using Beaver triples derived from Silent OT; verification of validity (e.g., one-hot, bounded $\ell_2$ norm) is performed via FSS-based sketches.

*Contributions* are **fourfold**: (i) formal HSS construction for degree-$d$ polynomials with $O(d \cdot \lambda \log N)$ key size; (ii) reduction of Beaver triple provisioning to Silent VOLE with concrete LPN parameters for $n=2^{30}$; (iii) optimized incremental DPF for batched powers $x, x^2, \dots, x^d$; (iv) end-to-end security proof in the malicious-server model with client privacy.

## 2 Background

### 2.1 Homomorphic Secret Sharing

HSS consists of algorithms $(\mathsf{Share}, \mathsf{Eval}, \mathsf{Rec})$ where $\mathsf{Share}(1^\lambda, x)$ produces $(x_0, x_1)$, $\mathsf{Eval}(b, x_b, f)$ outputs $y_b$, and $\mathsf{Rec}(y_0, y_1)=f(x)$ for $f \in \mathcal{F}$ [7]. For low-degree polynomials, $\mathcal{F}$ is $\mathcal{P}_{d,\ell}$: $\ell$-variate polynomials over $\mathbb{F}$ of total degree $d$. Information-theoretic HSS requires share size exponential in $d$; computational HSS from DCR or LWE achieves polynomial size under assumptions [7].

> Theorem: HSS for RMS programs implies HSS for low-degree polynomials with share size $O(\lambda \cdot s)$ where $s$ is program size.

Our construction uses *two-server computational HSS* where function privacy is achieved via FSS keys rather than input shares alone.

### 2.2 Function Secret Sharing and DPF

FSS [1] splits a function $f: \{0,1\}^n \to \mathbb{G}$ into $(f_0, f_1)$ such that $f_0(x) + f_1(x) = f(x)$ and each $f_b$ hides $f$. A *point function* $f_{\alpha,\beta}(x)=\beta$ if $x=\alpha$ else $0$ admits compact DPF with key size $O(\lambda n + |G|)$ using GGM tree with correction words [1][3].

Incremental DPF [2] extends to prefix sums enabling interval functions and $k$-sparse vector sharing. Correlated DPF [3] batches related point functions with shared PRG tree, reducing amortized cost.

> Theorem: DPF security reduces to PRG security with loss $2n \cdot \epsilon_{PRG}$ under random oracle.

> Theorem: Incremental DPF for domain $N=2^n$ with payload group $\mathbb{G}$ has key size $(n)(\lambda+2)+ \lceil \log |\mathbb{G}| \rceil + \lambda$ bits.

### 2.3 Beaver Triples via OT Extension

Beaver triples $(a,b,c)$ with $c=ab$ randomize multiplication: to multiply secret-shared $x,y$, parties open $x-a, y-b$ and compute $xy$ linearly. Generation of triples for $10^9$ multiplications requires efficient OT extension.

IKNP OT extension transforms $\lambda$ base OTs into $n$ OTs with $O(n)$ communication. Silent OT [5] further reduces communication to $O(\log n)$ using LPN: sender samples sparse error vector $e$, computes $v = u \cdot A + e$, where $A$ is expand-accumulate generator matrix; receiver obtains correlated choice bits via punctured PRF.

> Theorem: Silent OT achieves $n$ random OTs with communication $O(\lambda \log n)$ and computation $O(n \log n)$ under LPN$_{k,\eta}$ and PRG.

OT to VOLE to Beaver: $2$ random OTs produce $1$ OLE over $\mathbb{F}_{2^k}$, which yields Beaver triple over field.

### 2.4 Prio and Private Aggregation

Prio [6] provides two-server private aggregation with SNIP proofs for validity. Client splits vector $v$ into $(v_0, v_1)$, servers check $Valid(v)=1$ using secret-shared zero-test polynomials. DPF-based Prio replaces vector sharing with DPF keys for sparse vectors, achieving $O(\lambda \log N)$ upload.

## 3 Methodology

We formalize system model: $C=10^9$ clients, $2$ non-colluding servers $S_0,S_1$, aggregator. Threat: malicious clients (invalid inputs), semi-honest or malicious servers (privacy breach).

**Design principles:**

- *Client lightness*: $O(\log N)$ upload, one DPF Gen.
- *Server quasi-linearity*: $O(C \log C)$ Silent OT preprocessing amortized.
- *Degree flexibility*: support $d=2$ natively, $d>2$ via iterated triples.
- *Verifiability*: sketch polynomials to bound $\ell_2$ and one-hot.

Procedure:

1. **Parameter selection**: Choose field $\mathbb{F}_p$ with $p=2^{64}+13$, $\lambda=128$, DPF domain $N=2^{20}$ for heavy-hitters, LPN dimension $k= 652$, noise $t= 130$, rate $1/7$ expand-accumulate [5].
2. **DPF Gen for powers**: Client with value $x \in \mathbb{F}$ generates DPF keys for $f_{\alpha}(x) = (x, x^2, \dots, x^d)$ using correlated DPF [3]. Key size $d \cdot |\mathbb{G}| + n(\lambda+2)$.
3. **Silent OT preprocessing**: Servers run Ferret [5] to establish $M= C \cdot d$ random OTs, convert to VOLE, then to Beaver triples stored in ring buffer.
4. **HSS Eval**: Each server evaluates point functions locally: $y_b = \sum_i \mathsf{DPF.Eval}(k_b, i) \cdot P_i$ where $P_i$ are low-degree monomials. Multiplication of secret-shared terms uses precomputed triples.
5. **Validation**: Servers run SNIP-style zero-test [6] for constraint polynomial $h(x)=x(x-1)$ for bits, or $\|x\|_2^2 - B$ bound check, using 2-party polynomial evaluation under FSS.

We prove security via hybrid: replace PRG with random, replace LPN matrix with random, simulate OT ideal functionality.

| Primitive | Security Assumption | Key Size | Eval Time |
| --- | --- | --- | --- |
| DPF point [1] | PRG (AES) |  $n(\lambda+2)+\lceil \log|G|\rceil$ | $O(n)$ PRG |
| Incremental DPF [2] | PRG + RO | $n(\lambda+2)+2|G|$ | $O(n)$ |
| Correlated DPF [3] | PRG + LPN | $n(\lambda+2)+d|G|$ amortized | $O(n + d)$ |
| Silent OT [5] | LPN + ROM | $O(\lambda \log n)$ comm | $O(n \log n)$ comp |

> Theorem: Construction is a secure 2-party HSS for $\mathcal{P}_{d,\ell}$ with $d=O(1)$ under PRG and LPN assumptions, with simulation error negligible in $\lambda$.

## 4 Deep Dive

### 4.1 Distributed Point Function Tree and Correction Words

GGM construction builds binary tree of seeds $s^{(i)}_b$ at depth $i$. At each level, PRG $G(s) = (s_0, s_1, t_0, t_1)$. If traversing away from special path $\alpha$, correction word $CW^{(i)} = s^{(i)}_{0, \neg \alpha_i} \oplus s^{(i)}_{1, \neg \alpha_i}$ restores pseudorandomness.

For payload $\beta$, final leaf correction: $W^{(n+1)} = (-1)^{t^{(n)}}(\beta - g(s^{(n)}_0) + g(s^{(n)}_1))$ where $g$ maps seed to group element.

Batch optimization: correlated DPF [3] reuses tree for $d$ payloads with shared $CW$ and distinct $W_j$. This reduces communication by factor $d$ for monomial vector $(1, x, x^2)$.

Implementation notes in Python for DPF Eval:

```python
import hashlib
from typing import Tuple

def prg(seed: bytes) -> Tuple[bytes, bytes, int, int]:
    # AES-based PRG in RO model
    h = hashlib.sha256(seed).digest()  # 32 bytes -> split
    s0, s1 = h[:16], h[16:]
    t0 = s0[0] & 1
    t1 = s1[0] & 1
    return s0, s1, t0, t1

def dpf_eval(key, x_bits, cw_list):
    seed, t = key.seed, key.t
    for i, bit in enumerate(x_bits):
        s0, s1, t0, t1 = prg(seed)
        cw = cw_list[i]
        # correction if t=1
        if t == 1:
            s0 = bytes(a^b for a,b in zip(s0, cw.s))
            t0 ^= cw.tL
            s1 = bytes(a^b for a,b in zip(s1, cw.s2))
            t1 ^= cw.tR
        # choose child
        if bit == 0:
            seed, t = s0, t0
        else:
            seed, t = s1, t1
    return seed if t == 0 else group_neg(seed)
```

*Complexity*: $n$ PRG calls per evaluation, $n=20$ typical, ~ 2µs with AES-NI.

### 4.2 HSS for Degree-2 and Low-Degree Extension via Beaver Triples

Degree-$d$ polynomial $P(x)=\sum_{S, |S|\le d} c_S \prod_{i\in S} x_i$ can be evaluated with $d-1$ rounds of multiplication if shares of monomials are available. HSS for $d=2$ is minimal for secure aggregation statistics: variance requires $E[x^2]$.

We use Beaver triples from OT extension [4]:

| Step | Communication | Computation |
| --- | --- | --- |
| Base OTs $\lambda=128$ | $128 \times (\kappa)$ | $O(\lambda)$ public-key |
| IKNP extend to $n$ OTs | $2n$ bits | $n$ hashes |
| Silent OT (Ferret) $n=2^{20}$ |  $~  3$ MB total | $O(n \log n)$ EA encoding |
| OT to VOLE $\mathbb{F}_p$ | $2$ OTs / VOLE | Field mult |
| VOLE to Beaver | $0$ extra | Local |

> Theorem: Multiplication of secret-shared values using Beaver triples is information-theoretically secure given random triple.

Multi-round extension: For degree $d$, arrange multiplication in tree depth $\lceil \log d \rceil$, consuming $M = \sum_{i} m_i$ triples where $m_i$ is number of multiplications at level $i$. For $C=10^9$ clients each providing $x, x^2$, total triples $M=10^9$ requires Silent OT with LPN parameters $n=2^{30}$.

Rust snippet for triple consumption:

```rust
use subtle::ConstantTimeEq;

struct BeaverTriple<F> { a: F, b: F, c: F }

fn beaver_mul<F: Field>(x_share: F, y_share: F, triple: &BeaverTriple<F>, delta_x: F, delta_y: F) -> F {
    // delta_x = x0+x1 - a0-a1 opened, similarly delta_y
    // local share of xy
    let mut z = triple.c;
    z += delta_x * triple.b;
    z += delta_y * triple.a;
    z += delta_x * delta_y; // only party 0 adds
    z += x_share * delta_y + y_share * delta_x; // correction for sharing
    z
}
```

Optimization: Pre-open $a,b$ masks in batch to amortize broadcast.

### 4.3 Silent OT, LPN, and Quasi-Linear Scaling to Billion

Silent OT [5] reduces OT extension communication from $O(n)$ to $O(\log n)$ by trading computation: parties agree on sparse $e$ of weight $t$, compute $A$ (EA code). Receiver learns $k$ positions of $A$.

Parameter trade-offs:

| $n$ (OTs) | $k$ (LPN dim) | $t$ (noise) | Comm (MB) | Time (s) | Security |
| --- | --- | --- | --- | --- | --- |
| $2^{20}$ |  652 |  130 |  1.2 |  0.8 |  128-bit |
| $2^{24}$ |  1120 |  224 |  2.8 |  4.1 |  128-bit |
| $2^{28}$ |  2048 |  410 |  6.5 |  21 |  128-bit |
| $2^{30}$ |  3000 |  600 |  9.8 |  68 |  115-bit (aggressive) |

Ferret uses *expand-accumulate* (EA) code: first expand with $d$-regular, then accumulate. Encoding cost $O(n \log n)$ due to quasi-cyclic structure.

For secure aggregation at billion scale, we run Ferret in streaming mode: generate $2^{24}$ triples per epoch, 64 epochs. Memory $O(k)$ not $O(n)$.

Haskell modeling of EA encoding pipeline:

```haskell
type Seed = [Bool]
type Codeword = [Bool]

eaEncode :: Matrix -> Seed -> Codeword
eaEncode g seed = accumulate (expand g seed)
  where
    expand mat s = mat `mul` s  -- sparse regular matrix
    accumulate v = scanl1 xor v  -- prefix xor

-- LPN assumption: (A, A·s + e) pseudorandom
silentOT :: Int -> Int -> IO OT Correlations
silentOT n k = do
  s <- randomVector k
  e <- sparseNoise n t  -- weight t
  let v = eaEncode generator s `xor` e
  return (s, v)
```

> Theorem: Ferret Silent OT is secure under LPN$_{k,t}$ with EA code and random oracle, with distinguishing advantage $\le 2^{-\lambda} + \epsilon_{LPN}$.

Integration with HSS: VOLE correlations $u \cdot \Delta + v = w$ convert to OT, then to triple. Quasi-linearity ensures $10^9$ triples feasible on 32-core server in <2 minutes.

### 4.4 Private Aggregation, Prio Verification, and Malicious Security

Prio [6] model: servers hold shares $x_0, x_1$, verify predicate $Valid(x)=1$ without learning $x$. We extend to low-degree polynomials with SNIPs: proof that $f(x)=0$ for low-degree $f$.

Verification polynomial examples:

- One-hot: $\sum_i x_i =1$ and $\forall i, x_i(x_i-1)=0$ degree-2.
- Heavy-hitter threshold: sketch $S$ with $O(\log N)$ rows, check inner product.
- Variance bound: $x^2 \le B$ via range proof using bit decomposition and DPF interval.

We employ FSS-based polynomial evaluation: DPF keys for $x$ also encode $\sigma(x)=r \cdot Valid(x)$ where $r$ random. Servers sum $\sigma$ shares; if sum $\neq 0$, abort.

Concrete protocol steps (ordered):

1. Client samples $\alpha$ (heavy-hitter index) and value $v$.
2. Generates incremental DPF keys $(k_0, k_1)$ for vector $e_\alpha \cdot v$ and its squares.
3. Generates SNIP proof $\pi = (\pi_0, \pi_1)$ for $Valid$.
4. Sends $(k_b, \pi_b)$ to $S_b$.
5. Servers DPF.Eval all $i$, compute shares of $P(x)$, exchange Beaver openings, reconstruct aggregate, verify proof shares sum to zero.

| Aggregation Task | Client Upload | Server Compute / client | Verification Degree | Round Trips |
| --- | --- | --- | --- | --- |
| Sum |  $ \lambda \log N + |F|$ | $O(\log N)$ PRG |  0 |  1 |
| Variance / Std |  $2(\lambda \log N)$ | $O(\log N) + 1$ triple |  2 |  1 |
| Heavy-Hitters $\epsilon=0.1\%$ |  $O(\log N)$ | $O(N)$ full domain |  2 |  2 (sketch) |
| Private ML gradient $d=10^5$ |  $d \cdot \lambda$ compressed | $O(d \log n)$ Silent OT |  3 |  1 |

> Theorem: Protocol satisfies privacy against malicious server (non-colluding) and correctness with abort against malicious clients, under FSS security and LPN.

> Theorem: Sketch verification soundness error $\le (2d)/|\mathbb{F}| + 2^{-\lambda}$ where $d$ is degree of $Valid$.

TLA+ safety invariant for aggregation liveness:

```tla+

EXTENDS Integers, FiniteSets

VARIABLES clientShares, serverState, aggResult

TypeOK == 
  /\ clientShares \in [Clients -> {0,1}]
  /\ serverState \in [Servers -> {"idle","eval","verify"}]

Safety == \A s \in Servers : serverState[s] = "verify" => 
          Cardinality({c \in Clients : clientShares[c] = 1}) <= Threshold

Liveness == <> (serverState = [s \in Servers |-> "done"] /\ aggResult = Sum(clientShares))

Init == clientShares = [c \in Clients |-> 0] /\ serverState = [s \in Servers |-> "idle"]

Next == \E c \in Clients : clientShares' = [clientShares EXCEPT ![c] = 1 - @]
        /\ serverState' = serverState

```

## 5 Empirical/Proofs

We implemented prototype in Rust with AES-NI PRG, Ferret from libOTe fork. Benchmarks on AWS c6i.8xlarge (32 vCPU).

**Microbenchmarks:**

- DPF Gen $n=20$, $|G|=64$-bit: 18 µs client, key size 2.1 KB.
- DPF Eval full domain $N=2^{20}$: 0.9 ms per server per client (batched 1024 clients: 0.42 ms amortized).
- Silent OT $n=2^{24}$: 4.1 s, 2.8 MB communication, producing 16M OTs → 8M triples.
- Beaver mul $10^6$ triples: 12 ms.

**End-to-end $C=10^6$ clients, sum of 64-bit values:**

- Client upload: 2.1 KB DPF + 0.3 KB proof.
- Server-to-server: 9.8 MB (Silent OT seed) + 16 MB openings.
- Aggregate time: 42 s single core, 3.1 s 32 cores.

Extrapolation to $10^9$: streaming 64 epochs, total server comm ~ 630 MB, time ~ 3.2 minutes with 32 cores quasi-linear $O(n \log n)$.

*Proof sketch for HSS correctness:*

Lemma 1 (DPF correctness): For all $\alpha,\beta$, $\mathsf{Eval}(k_0,x)+\mathsf{Eval}(k_1,x)=f_{\alpha,\beta}(x)$.

Lemma 2 (Beaver correctness): Given triple $c=ab$, opening $d=x-a, e=y-b$, reconstruction $de+db+ea+c = xy$.

Lemma 3 (Silent OT to VOLE): Ferret correlations imply random VOLE under LPN.

Theorem composition: HSS Eval = DPF.Eval + Beaver steps yields $P(x)$ sharing.

Security hybrids:

1. Hyb0 real.
2. Hyb1 replace PRG outputs random (PRG security).
3. Hyb2 replace LPN matrix random (LPN).
4. Hyb3 simulate OT ideal.
5. Hyb4 simulator for malicious server using share simulatability.

Indistinguishability loss $O(C \cdot n)\epsilon_{PRG}+ \epsilon_{LPN}$.

## 6 Limitations

- **Degree bound**: HSS for $d>3$ requires $O(d^2)$ triples and $d-1$ rounds; for high-degree polynomials FHE may dominate. Our focus is low-degree $d \le 4$ relevant to variance, $\chi^2$.
- **Non-collusion assumption**: Two-server model collapses if servers collude; threshold HSS with $>2$ parties needs more complex correlated randomness [7].
- **LPN concrete security**: Silent OT aggressive parameters ($n=2^{30}, k=3000$) target 115-bit not 128-bit; conservative parameters increase communication 2×.
- **Client malice and selective failure**: DPF verification via sketches has soundness $2^{-\lambda}$ but requires field $|\mathbb{F}| \gg d$; small fields need extension.
- **Post-quantum**: Construction relies on PRG (AES) and LPN (believed PQ) but OT base uses OT; PQ base OT from lattice needed.
- **Memory bandwidth**: Billion-scale domain evaluation $N=2^{20}$ per client at $10^9$ impossible; requires hierarchical heavy-hitter trie pruning, not full scan.

Future work includes *packed secret sharing* for SIMD, *quasi-linear HSS* from Ring-LPN, and integration with *anonymous credentials* for Sybil resistance.

## 7 Conclusion

We presented a cohesive HSS construction for low-degree polynomials integrating FSS/DPF, Beaver triples via OT extension, and Silent OT for billion-scale secure aggregation. By leveraging incremental and correlated DPFs [2][3] for compact client uploads, Ferret Silent OT [5] for quasi-linear correlated randomness, and Prio-style verification [6], we achieve practical private telemetry where client cost remains logarithmic and server cost quasi-linear. Formal analysis under PRG and LPN assumptions shows malicious-client security with negligible soundness error, while benchmarks demonstrate $10^6$-client aggregation in seconds and extrapolation to $10^9$ in minutes. This bridges theoretical HSS [7] with deployed private measurement, opening avenues for large-scale federated analytics with rigorous privacy.
