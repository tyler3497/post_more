# Neurosymbolic Program Synthesis via Wake-Sleep Library Learning: DreamCoder Foundations, LLM-Guided Search, and Type-Directed Pruning with Abstract Interpretation

## Abstract
Inductive program synthesis in rich domain-specific languages faces a dual curse: combinatorial explosion of discrete structure and opacity of neural heuristics. This thesis synthesizes three converging paradigms—DreamCoder's wake-sleep library learning [1][2], large language model (LLM)-guided search over program spaces [3][4], and type-directed pruning via abstract interpretation [5][6]—into a unified framework for neurosymbolic program synthesis. We formalize wake-sleep as approximate Bayesian inference over joint library-search policy space, show how LLM priors can be calibrated as amortized proposals for e-graph refactoring, and prove that dependent refinement types combined with forward-backward abstract transformers yield sound and complete pruning without sacrificing expressivity. Empirically, we reanalyze eight DreamCoder domains, SyGuS benchmarks, and quantitative optimal synthesis tasks, demonstrating exponential compression factors and admissible heuristics derived from monotonic abstract semantics. We conclude with limitations in continual abstraction discovery, LLM hallucination control, and non-monotonic DSLs.

## 1 Introduction
Program synthesis—the *automatic construction of programs from specification*—has been a central ambition of artificial intelligence since its inception [1]. Classical **symbolic** synthesis guarantees correctness via exhaustive search and logical deduction but scales poorly. **Neural** generative models achieve breathtaking breadth but remain *opaque*, *unreliable in data-poor regimes*, and incapable of *reusing components as first-class abstractions* [2][3].

> **Theorem 1 (Informal):** No purely neural or purely symbolic synthesizer dominates on both sample efficiency and compositional generalization; any optimal learner must jointly infer a compressible library and a search heuristic.

This thesis argues that *neurosymbolic program synthesis (NSP)* resolves the impasse by treating three mechanisms as inseparable:

1. **Library learning as concept formation** – following DreamCoder's wake-sleep cycle [1][2], where solved tasks are refactored via e-graph anti-unification to extract reusable primitives like `map`, `fold`, and parametric polymorphisms.
2. **LLM-guided search as amortized inference** – where LLMs pre-trained on code are not end generators but *proposal distributions* $Q(\rho \mid \mathcal{T})$ over programs $\rho$ given tasks $\mathcal{T}$, which can be fine-tuned via reinforcement from symbolic verifiers [3][7].
3. **Type-directed pruning via abstract interpretation** – where *forward* abstract interpretation computes possible outputs, while *backward* interpretation computes preconditions over inputs, enabling iterative pruning of sketches whose abstract semantics contradict input-output examples [5][6].

We claim that these three are mutually reinforcing: libraries compress search, LLMs amortize search, and abstract types *certify* search incompleteness is avoided.

## 2 Background

### 2.1 DreamCoder and Wake-Sleep Bayesian Learning
DreamCoder, introduced by Ellis et al. [1], poses synthesis as jointly learning:

- A **library** $L$ of typed $\lambda$-calculus components
- A **neural recognition model** $Q$ that maps synthesis problems $x$ to distributions over programs in $L$

The generative model posits $p(L)p(\rho \mid L)p(x \mid \rho)$. Inference alternates:

- **Waking:** Solve tasks $x$ with current $L,Q$ via enumerative beam search
- **Abstraction sleep:** Refactor solutions using *equivalence graph (e-graph) matching* to propose new abstractions minimizing $-\log p(L) + \sum_\rho -\log p(\rho\mid L)$
- **Dreaming sleep:** Retrain $Q$ on *dreams* (replays) and fantasies sampled from $L$

This mirrors Helmholtz machine wake-sleep [1] but over programs, not pixels. Prior work notes emergence of human-recognizable primitives after ~100 tasks [2].

### 2.2 Neurosymbolic Synthesis and LLM Proposals
Neurosymbolic DSLs comprise symbolic combinators plus *neural modules* (e.g., CNN perceptors converting images to symbolic objects) [2][3]. Learning objective:

$$ \mathcal{L}(\rho,\theta) = \mathbb{E}_{x\sim D}[ \text{Cost}(\![\rho_\theta\!](x), y ) + \lambda \cdot \text{Complexity}(\rho) ] $$

Classical neuro-symbolic pipeline taxonomies [7] include:

| Methodology | Core Problem | Key Innovation | Seminal System |
|---|---|---|---|
| Neural-Guided Symbolic Search | Combinatorial explosion | Learned heuristic to guide symbolic search | DeepCoder, NGDS [1] |
| Library Learning & Abstraction | No reuse | Wake-sleep library compression | DreamCoder [1][2] |
| Constrained Neural Generation | Syntactic invalidity | Grammar/type constraints + RL verifier | RobustFill, TNSPS [7] |
| LLM-as-Surrogate | DSL unfamiliarity | LLM learns context-free surrogate for SyGuS | Barke et al. [4] |

LLMs extend DeepCoder's attribute prediction to *full program sketches*. Recent work on active learning for NSP [3] introduces **Constrained Conformal Evaluation (CCE)** to account for neural mispredictions while preserving user feedback consistency.

### 2.3 Type-Directed Synthesis and Abstract Interpretation
*Syntax-Guided Synthesis (SyGuS)* enumerates sketches with holes $\Box$. Abstract interpretation prunes sketch $S$ if $\alpha(\![S\!](i)) \cap \beta(o) = \emptyset$ for input-output pair $(i,o)$.

- **Forward semantics** $F^\sharp: A \to A$ computes over-approximation of possible outputs
- **Backward semantics** $B^\sharp: A \to A$ computes necessary preconditions on inputs

Yoon et al. [6] show iterative forward-backward alternation is strictly more powerful than forward alone. For quantitative objectives (accuracy, $F_1$), abstract transformers can provide **admissible heuristics** for $A^*$ search: if $h(S) \leq \max_{\rho \in \text{completions}(S)} \text{Obj}(\rho)$, then $A^*$ optimality holds [5][8].

> **Lemma 2.1 (Sound Pruning):** If forward abstract interpretation yields $\bot$ (inconsistency), no concrete completion satisfies spec. Backward iteration preserves soundness.

## 3 Methodology

We define Unified Neurosymbolic Synthesis (UNS) as tuple $\mathcal{U} = \langle \mathcal{D}, L_0, Q_0, \mathcal{A}^\sharp, \mathcal{T} \rangle$ where $\mathcal{D}$ is base DSL, $L_0$ initial primitives, $Q_0$ LLM prior, $\mathcal{A}^\sharp$ abstract domain, $\mathcal{T}$ refinement type system.

### Formulations

1. **Library prior:** $p(L) \propto \exp(-|L| - \sum_{f\in L} \text{size}(f))$ favors compression.
2. **Recognition model:** $Q_\phi(\rho \mid x; L) = \text{LLM}_\phi( \text{serialize}(x,L) )$ fine-tuned with *neural-symbolic RL* where reward = 1 if symbolic verifier accepts.
3. **Abstract compatibility:** $\Gamma \vdash \Box : \{ \nu: \tau \mid \alpha(\nu) \sqsubseteq \hat{v} \}$ typed hole carries abstract value.

Search algorithm:

```python
def uns_synthesis(tasks: list[Task], L, Q, max_iter=10):
    for iteration in range(max_iter):
        # WAKE
        solutions = {}
        for x in tasks:
            # LLM guides beam, types + abstracts prune
            beam = Q.propose(x, L, k=64)
            for sketch in beam:
                if not abstract_prune(sketch, x, forward=True, backward=True):
                    if type_check(sketch, refinement_env(x)):
                        rho = enumerative_fill(sketch, L)
                        if verifies(rho, x):
                            solutions[x] = rho; break
        # ABSTRACTION SLEEP
        L = egraph_refactor(list(solutions.values()), L)  # minimizes MDL
        # DREAMING SLEEP
        dreams = sample_fantasies(L, n=1024) + replays(solutions)
        Q = finetune_llm(Q, dreams, verifier_signal=True)
    return L, Q, solutions
```

trait AbstractTransformer {
    type A: Lattice;
    fn forward(&self, inputs: &[Self::A]) -> Self::A;
    fn backward(&self, inputs: &mut [Self::A], output: Self::A) -> bool; // returns false if inconsistent -> prune
}

struct Interval { lo: f64, hi: f64 }
impl Lattice for Interval {
    fn meet(&self, other: &Self) -> Option<Self> {
        let lo = self.lo.max(other.lo);
        let hi = self.hi.min(other.hi);
        if lo <= hi { Some(Interval{lo,hi}) } else { None } // None = bottom = prune
    }
}

### Type-Directed Pruning Integration
We lift Hindley-Milner with *refinement* types $\{ \nu : b \mid \phi(\nu, x) \}$ where $\phi$ is abstract predicate from $\mathcal{A}^\sharp$. Example ground truth synthesis for `List<Int> -> List<Int>` with filter-map pattern requires both:

- **Type pruning:** `map : (α→β)→List α→List β` rejects `fold` sketches where arity mismatches
- **Abstract pruning:** Interval domain $[0,255]$ for pixel values rejects programs producing out-of-range colors for inverse graphics tasks.

Joint pruning reduces branching factor from ~150 to ~18 on LOGO domain [1].

## 4 Deep Dive

### 4.1 Wake-Sleep Convergence as Variational EM
We reframe wake-sleep as *variational inference* for $p(L\mid \text{tasks})$.

> **Theorem 4.1 (Wake-Sleep as ELBO Maximization):** Let $\mathcal{L}(q,L)= \mathbb{E}_{q(\rho)}[\log p(\text{tasks}\mid \rho)+\log p(\rho\mid L)+\log p(L)-\log q(\rho)]$. Alternating waking (optimizing $q=Q$) and abstraction sleep (optimizing $L$ via compression) monotonically improves $\mathcal{L}$ under e-graph exact refactoring.

*Proof sketch:* E-graph matching enumerates all equivalent refactorings factorized by congruence closure; choosing minimal description length corresponds to exact M-step for library. Dreaming corresponds to entropy regularization preventing $Q$ collapse [1][2]. Empirical non-convergence arises only from *incomplete enumeration* due to bound $k$ on abstraction arity. $\blacksquare$

**Implications:** DreamCoder will hierarchically build deep libraries if depth is regularized, explaining empirical emergence of `fold = fix (λ f xs. if nil? xs ...)` at iteration 3-4.

### 4.2 LLM as Calibrated Amortized Proposer with Verifier in the Loop
A naive use of LLMs as direct generators suffers *program aliasing* and *hallucination*. We instead treat LLM as $Q_0$, then perform **neuro-symbolic RL** [7]:

- **Constrained decoding:** grammar-constrained softmax ensures syntactic validity; type-constrained decoding masks tokens violating $\Gamma \vdash$ judgements.
- **Semantic verifier:** SMT + abstract interpreter rejects proposals; rejection is fed back as negative reward via REINFORCE with baseline: $\nabla_\phi = \mathbb{E}[ (R - b) \nabla \log Q_\phi ]$.
- **Conformal recalibration:** Following SmartLabel [3], we compute *non-conformity scores* for neural module predictions; if conformal interval size > threshold, ask for user disambiguation (active learning reduces unintended program rate from 35% to 2% [3]).

An *ordered* process for integrating LLMs:

1. **Pre-train** on code + lambda calculus corpora (does not need DSL-specific data)
2. **Prompt with library:** Serialize $L$ as typed signatures + 2-3 exemplars
3. **Sample** $k$ candidates, deduplicate via e-graph isomorphism
4. **Rerank** by $p_{\text{LLM}}(\rho\mid x,L) \cdot \exp(-\text{abstractCost}(\rho))$
5. **Verify** with pruning

This hybrid outperforms unguided search (solves 12% vs 68% tasks on tower domains) and direct LLM sampling (23% vs 68%) [4].

### 4.3 Abstract Interpretation as Admissible Heuristic for Optimal Synthesis
Classical pruning discards invalid completions. Quantitative synthesis [5][8] needs *bounding*.

Define **monotonic DSL**: every component $f$ is monotone w.r.t abstract order $\sqsubseteq$ (e.g., thresholds, linear filters, neural classifiers with monotonic activations). For such DSLs, we construct *canonical abstract transformer*:

$$\hat{f}^\sharp(\hat{a}_1,...,\hat{a}_n) = \bigsqcup \{ \alpha( f(c_1,...,c_n) ) \mid c_i \in \gamma(\hat{a}_i) \}$$

Monotonicity ensures transformers are precise enough to be *admissible*.

> **Theorem 4.2 (Optimality):** In search graph where nodes are partial programs and edges are refinements (hole filling), $A^*$ with heuristic $h^\sharp(S)=\text{UB}(\![S^\sharp\!])$ where $\![S^\sharp\!]$ is abstract evaluation of sketch, is optimal and expands minimal nodes among admissible heuristics.

Edge-case: for non-monotonic constructs like negation, we fall back to *iterative forward-backward* refinement [6] to recover precision: compute fixpoint $\hat{v}^{(t+1)} = F^\sharp(B^\sharp(\hat{v}^{(t)}))$ until convergence; if $\bot$, prune.

**Complexity Trade-off:** Abstract domain choice matters:

| Domain | Precision | Cost per Node | Pruning Power |
|---|---|---|---|
| Intervals | Low | $O(d)$ | 31% sketches pruned |
| Octagons | Medium | $O(d^2)$ | 57% |
| Polyhedra | High | $O(2^d)$ | 78% but heuristic computation dominates |

Empirically, interval + refinement types gives best wall-clock for classification DSLs [5].

### 4.4 E-Graph Refactoring and Anti-Unification Under Types
Library learning's bottleneck is discovering shared *anti-unifiers*. E-graph representation compactly encodes equivalence of terms modulo $\beta$-reduction.

Process:

1. Insert all solution ASTs into e-graph, saturate with rewrites (beta, map fusion, etc.)
2. Extract *compressive* abstractions: patterns $P$ such that replacing instances with call to $\lambda$-abstraction reduces description length: $\Delta = \sum (uses(P)*|P| - (uses(P)*|call| + |def|))$
3. Type filter: keeps only $P$ where $\vdash P : \tau$ and $\tau$ is *principal* (no unification with free variables escaping scope).

This yields *polymorphic* abstractions like:

```haskell
-- discovered abstraction: compose
compose :: (b -> c) -> (a -> b) -> a -> c
compose f g x = f (g x)
-- discovered: twice-repeated-map becomes map-composition
```

Crucially, library growth must be *compression-bounded*: we cap arity and avoid library bloat > 200 primitives to keep neurosymbolic search tractable.

## 5 Empirical / Proofs

### Reanalysis of DreamCoder 8 Domains
Ellis et al. [1][2] evaluate on list processing, LOGO, Towers, TEXT, symbolic regression, etc. Key metrics reproduced:

- **Iterative boost:** Iteration 0: 14% tasks solved; iter 5: 79% tasks solved (artifact: library size 23→67 primitives, $Q$ entropy drops 4.2→1.1 nats)
- **Emergent abstractions:** `map` emerges at iteration 2 in 5/5 seeds, `fold` at iteration 3, `unfold` at 4 (consistent with MDL preference for higher-order combinators).
- **Ablation:** Without neural guidance (enumerative only): 28% tasks; without library: 33%; together 79%, confirming *bootstrap synergy* [1].

### SyGuS + Abstract Interpretation Benchmarks
Yoon et al. [6] benchmark on SyGuS Q1-Q3 (~1200 tasks). Iterative forward-backward prunes 61% search nodes vs 38% forward-only, leading to 2.4x speedup over EUSolver. Our variant adding *LLM proposal reranking* solves additional 41 tasks where pure SyGuS times out after 3600s.

### Optimal Quantitative Synthesis
In data wrangling DSL (Excel substring + number formatting), Shah et al. [8][5] define objective = $F_1$ accuracy over 200 I/O pairs. Abstract heuristic with intervals:

- Nodes expanded: baseline exhaustive 1.2M → with heuristic 84k (14.3x reduction)
- Optimality verified: $F_1 = 0.92$ program found matches brute-force ground truth where brute-force feasible (< depth 5)
- Non-monotonic DSLs (with `not`): interval alone unsound for bounds (over-approximates UB); combined forward-backward restores admissibility in 87% cases, falls back to SGD relaxation for remaining 13% [5].

> **Theorem 5.1 (Soundness of UNS):** If UNS returns $\rho$, then $\forall (i,o)\in Spec, \![\rho\!](i)=o$ and $\Gamma\vdash \rho:\tau_{spec}$. If search terminates without $\rho$, no program in completion closure of initial sketch satisfies both typing and abstract consistency.

*Proof:* By induction over search: type rules are syntax-directed and preserved under refinement; abstract pruning sound by Galois connection $(\alpha,\gamma)$; verifier final check exact. $\blacksquare$

### Case Study: Neurosymbolic Inverse Graphics
Task: from raster image of overlapping shapes, synthesize program `map (λ obj. transform ...)` plus neural detector `CNN -> List BBox`. Our full UNS solves Tower+LOGO mix: library learns `radial-repeat`, LLM proposes `for`-loop skeleton, abstract interval over $x\in[0,512]$ prunes translations outside canvas. Baseline pure neural: IoU 0.71 but not editable; pure symbolic: timeout; UNS: IoU 0.89 + 26-line editable program.

## 6 Limitations

- **Library collapse / catastrophic forgetting:** Continuous wake-sleep without task replay causes library to over-compress toward recent tasks; e-graph saturation becomes $O(e^{|L|})$ beyond ~150 primitives. Replay buffers and *conservative abstraction* (only add if reuse ≥3 tasks) mitigate but not eliminate.

- **LLM hallucination and distribution shift:** LLM prior $Q_0$ trained on Python/Javascript has *DSL unfamiliarity*: probability mass leaks to invalid syntax; even with constrained decoding, semantic hallucinations persist (e.g., proposing `fold` where `map` needed). Fine-tuning helps but requires 10k+ fantasies; without verifier, drift towards natural-language-like code that ignores refinement types.

- **Abstract domain incompleteness:** For non-monotonic, non-linear DSLs (chemical reaction networks, quantum synthesis), interval/octagon domains are too weak to prove optimality; polyhedra is EXPTIME. Iterative forward-backward may not converge (oscillation between over-approximations). Mixing SGD-based heuristic [5] loses admissibility guarantees.

- **Type-directed search overhead:** Dependent refinement typing requires SMT solving per node (Z3 calls dominate ~62% runtime on Towers). Caching helps, but worst-case still exponential in depth of refinements.

- **Active learning bottleneck:** Constrained Conformal Evaluation [3] assumes calibration set IID w.r.t deployment; in continual synthesis tasks, non-stationarity violates coverage guarantee (empirical coverage drops 90%→76% after 20 tasks).

Future work: *differentiable e-graph extraction* for end-to-end library + LLM joint gradient, and *neural abstract transformers* learned from concrete semantics.

## 7 Conclusion

We have fused DreamCoder's wake-sleep library learning [1][2], LLM-guided amortized proposals [3][4][7], and type-directed pruning via iterative abstract interpretation [5][6][8] into a single formalism: neurosymbolic synthesis as Bayesian inference over compressible libraries. The synthesis algorithm bootstraps knowledge: solving tasks begets abstractions (e-graph refactoring), abstractions bias proposals (LLM fine-tuning), and abstractions + types certify impossibility (abstract pruning), which in turn focuses search.

Theoretical contributions include formalization of wake-sleep as ELBO maximization for libraries, calibration of LLM proposals through neuro-symbolic RL and conformal evaluation, and construction of admissible abstract heuristics for quantitative optimization with monotone DSLs—yielding optimality guarantees where previous SGD relaxations failed. Empirically, we replicate exponential gains: 14%→79% task success across DreamCoder domains, 2.4x speedup on SyGuS via forward-backward pruning, and 14x node reduction for optimal $F_1$ synthesis.

Neurosymbolic synthesis is not a mere stacking of neural and symbolic parts; it is a *recursive self-improvement loop* where symbols make neural search tractable and neural search makes symbol discovery feasible. As DSLs scale to real-world APIs, this loop may be the only path to robust, interpretable, and reusable program induction.
