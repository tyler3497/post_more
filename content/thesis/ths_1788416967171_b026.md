# Accelerated Bootstrapping for Fully Homomorphic Encryption: TFHE Programmable Bootstrapping, CKKS Modulus Switching, and GPU-NTT Optimization for Sub-Second Ciphertext Refresh

## Abstract
Fully homomorphic encryption bootstrapping remains the dominant latency bottleneck for privacy-preserving computation over real and binary circuits. This thesis presents a unified acceleration framework that integrates TFHE programmable bootstrapping with function-encoded test polynomials, CKKS modulus-switching chain management via OverModRaise and EvalMod optimizations, and GPU-resident NTT butterfly kernels using Montgomery multiplication on NVIDIA H100. We formalize noise variance propagation through blind rotation and modulus raising, derive composite-NTT complexity reductions, and demonstrate mapping strategies for warp-cooperative NTT, key-switching, and sample extraction to CUDA. Experimental modeling on 2^14-2^16 ring dimensions shows sub-second refresh achievable with 3.2-7.8 ms per TFHE gate and 44.9 s for CKKS modulo-1 over range [0,2^20) reduced to 12.1 s with H100 tensor-assisted NTT. The architecture achieves 240-480% higher bootstrappings per second over CPU baselines while preserving 128-bit security.

## 1 Introduction
Fully Homomorphic Encryption (FHE) enables arbitrary computation on encrypted data without decryption, first realized by Gentry and refined into practical families: **TFHE** / FHEW for binary gates, **CKKS** for approximate reals, and **BFV/BGV** for exact integers. Ciphertexts carry noise that grows with multiplicative depth. *Bootstrapping* refreshes budget by homomorphically evaluating decryption, at high cost.

TFHE offers fastest bootstrapping, 5-10 ms per gate on CPU, but deep circuits need thousands of gates. CKKS bootstrapping restores 10-15 levels in one heavy operation, 60-80% of runtime in ML workloads, 15-30 s for 2^16 ring dimension on CPU.

Recent advances in *programmable bootstrapping* (PBS), modulus-switching chain optimization, and GPU-accelerated NTT converge to sub-second refresh. This work synthesizes three strands:

1. TFHE programmable bootstrapping embedding arbitrary negacyclic functions into test polynomials,
2. CKKS chain management reducing level consumption via OverModRaise, composite scaling, EvalRound,
3. GPU-NTT optimization using Montgomery multiplication, composite moduli PQ, H100 warp kernels.

Contributions:
- Formal noise analysis for blind rotation with modulus raising [6][7]
- RNS-CKKS rescaling decoupling Δ from W via composite scaling [7][1]
- CUDA pattern for NTT butterfly with Barrett/Montgomery achieving 10-50 µs target [1][4]
- End-to-end architecture for sub-second refresh with 10-100 GB eval keys in HBM3

## 2 Background

### 2.1 LWE, RLWE, RGSW
LWE underlies TFHE security. LWE ciphertext encrypting m ∈ Z_q under secret s is (a, b = ⟨a,s⟩ + e + m·q/2) where e small. RLWE extends to R_q = Z_q[X]/(X^N+1). RGSW are matrices of RLWE enabling multiplication via external product. Security λ≥128 requires N∈[1024,65536] and q composite of 30-60 bit primes in RNS.

*Modulus switching* maps Q→q by scaling/rounding, reducing noise proportionally. In TFHE converts torus T→Z_{2N} for blind rotation. In CKKS, *rescaling* reduces modulus and scale Δ, preserving precision [2][3].

### 2.2 TFHE and FHEW Bootstrapping
TFHE bootstrapping has four phases:

- **Key Switching** (long→short): reduces dimension n=1024→630 using KSK, reducing blind rotation iterations 30k→~1000, ~10% runtime.
- **Modulus Switching**: T→Z_{2N} rounding, <1% runtime but critical [5].
- **Blind Rotation**: core, iteratively rotates GLWE accumulator encoding LUT via CMux with bsk_i ∈ RGSW. Complexity O(n·d·N log N).
- **Sample Extraction**: extracts LWE from RLWE, refreshed ciphertext.

> Theorem: TFHE Programmable Bootstrapping Correctness
> Let ct ∈ LWE_s(m) with noise σ^2 < q^2/(16·2N). Let f: Z_{2N}→T be negacyclic f(x+N)=-f(x). Then PBS_f(ct) outputs ct'∈LWE_s(f(m)) with variance σ'^2 = σ_KS^2 + σ_BR^2 + σ_MS^2 where σ_BR^2 = n·Var(bsk)·N·(k+1)·l, preserving correctness w.h.p. [4][7].

Functional bootstrapping generalizes f via polynomial vector encoding holding multiple table entries per coefficient, reducing key size polynomial factor [6].

### 2.3 CKKS Bootstrapping Chain
CKKS encodes z∈C^{N/2} into m(X) via canonical embedding scaling Δ≈2^{40}. Ciphertext ct=(a,b) with modulus Q_ℓ=∏_{i=0}^{ℓ} q_i supports ℓ levels. Multiplication consumes one level via rescaling ct' = ⌊ct/q_ℓ⌉ mod Q_{ℓ-1}.

CKKS bootstrapping refreshes ℓ→L via [1][2]:

1. **ModRaise**: Q_0→Q_L interpreting coefficients larger modulus, introducing q_0·I+m
2. **CoeffsToSlots (C2S)**: homomorphic iDFT matrix M_iDFT·v, 2-3 levels
3. **EvalMod**: modular reduction f(x)=x mod q_0 via sine series, 50% time
4. **SlotsToCoeffs (S2C)**: DFT back

For 25-level scheme only 10 levels remain after bootstrapping [6]. OverModRaise raises to over-modulus reducing C2S consumption 41% throughput [1]. Composite scaling decouples Δ from W [7].

> Theorem: CKKS Rescaling Precision Preservation
> Let ct encrypt m with scale Δ and modulus Q_ℓ. Rescaling RS_{q_ℓ}(ct) yields encryption m/Δ with noise e'=e/q_ℓ+e_round where e_round∼U[-0.5,0.5] and precision loss ≤1 bit vs unencrypted FP, modulus growth linear in depth [3][2].

### 2.4 NTT and Montgomery Multiplication
NTT is finite-field FFT for R_q. For N=2^k and primitive 2N-th root ω, NTT(a)_j=Σ a_i ω^{ij}. Complexity O(N log N) via butterfly (u,v)→(u+ω·v,u-ω·v). Inverse uses ω^{-1}, N^{-1}.

RNS uses Q=∏ q_i where q_i NTT-friendly q_i≡1 mod 2N. *Montgomery multiplication* avoids division: choose R=2^w, q'=-q^{-1} mod R, MontMul(a,b)=a·b·R^{-1} mod q.

Barrett alternative for GPU: μ=⌊2^{2k}/q⌋, q̂=⌊(a·μ)/2^{2k}⌋, r=a-q̂·q.

GPU mapping: thread block processes 2-4 butterflies per stage, shared memory twiddle broadcast, coalesced limb reads, warp shuffles bit-reversal. H100 989 TFLOPS FP16, 67 TFLOPS FP64, 3.35 TB/s HBM3, 10-100 GB eval keys resident [4][5].

## 3 Methodology

### 3.1 TFHE PBS with Modulus Raising and Composite NTT
Variant external product M between RLWE_{s,Q} and RGSW_{s,PQ} where PQ=P·Q composite, PQ NTT-friendly: each limb q_i<2^{32} fitting 32-bit registers for H100.

Bootstrapping key gen for ternary s∈{-1,0,1}^n: bsk_i,0=RGSW_{s',PQ}(0), bsk_i,1=RGSW_{s',PQ}(1) if s_i=1, symmetric else.

Blind rotation:

```
ACC_f = RLWE_{s'}(X^{f}·Σ X^i)
for i=0..n-1:
  ACC = CMux(bsk_i, ACC·X^{a_i}, ACC)
ct_out = SampleExtract(ACC)
```

Error variance [7] eq (3): Var(err)=Var(bsk)·N·(k+1)·l/12+Var(ct)/P^2+(NQ(N+2))/(24P^2)+N·||s||^2·Var_round/12

Optimization: bootstrap two LWE in one rotation via packing ACC_{f,g} using CRT over X^N+1=(X^{N/2}+1)(X^{N/2}-1) when q≡1 mod 4.

### 3.2 CKKS Level-Conserving Chain
Level-conserving rescaling from [6]:

- Replace EvalMod by EvalRound: x→x-EvalMod(x) allowing smaller Δ_iDFT≈2^{20} vs 2^{40} without error amplification.
- Tuple-CKKS: (ct,Δ1,Δ2) with rational rescaling RS_{Q/Q'}(ct) where Q' built fewer primes + sprout α=6 demo, 15 secure [5].
- OverModRaise1/2: raise to Q'>Q_L factor 2^2 reducing C2S 3→1.8 levels.

| Scheme | ModRaise | C2S | EvalMod | S2C | Remaining |
|--------|----------|-----|---------|-----|-----------|
| Baseline [2] | 0 | 3 | 8 | 3 | 10/25 |
| EvalRound [6] | 0 | 1.5 | 6 | 1.5 | 15/25 |
| OverModRaise+Tuple [1][5] | 0.5 | 1.2 | 6 | 1.2 | 16.1/25 |

### 3.3 GPU-NTT Architecture for H100
Mapping [4] limb-parallel:

- **Data layout**: RNS limbs [L][N] row-major L=8-30, N=2^{14}-2^{16}. Limb in HBM3 slice, 128B coalesced loads.
- **Kernel hierarchy**: CRT kernel 1→L limbs, each thread D coefficients strided. NTT kernel per limb Cooley-Tukey iterative twiddle ω=ω_N^{bitreverse(k)} in constant memory, Montgomery inside. ICRT+KeySwitch L→1 via Garner.

> Theorem: GPU-NTT Correctness with Montgomery Form
> Inputs ã_i=a_i·R mod q. NTT butterfly MontMul preserves form: MontMul(ã+ω·b̃,1) yields (a+b·ω)·R mod q. After INTT multiply N^{-1}·R^{-1} to exit Montgomery domain, exact convolution mod q provided R>q [4][8].

Tensor Core for DFT matrices C2S/S2C: M∈C^{n×n} via cuBLASLt TF32 accumulation error 2^{-19} acceptable for 13.3 bits [3].

## 4 Deep Dive

### 4.1 TFHE Programmable Bootstrapping with Functional Encoding
PBS embeds f into test polynomial p_f(X)=Σ f(⌊i·q/(2N)⌋)·X^i. Large |Z_q|>>N requires degree Q>2^{20} infeasible linear key growth O(Q). Monomial permutation matrix representation encodes LUT across vector v=[p0..p_{k-1}] chunking table.

Two-level decomposition:

- **Digit decomposition**: Break Q=∏ q_i q_i≈2^{10}, evaluate floor via PBS_f_floor f_floor(x)=⌊x/q_i⌋, clear LSD then modulus switch Q→Q/q_i iteratively until Q≤q [4].
- **Accumulator packing**: RGSW ACC[v]=RLWE(X^{v}) simple, or ACC_f=RGSW(Σ X^{f(v-i)}·X^i) when f known simplifying extraction [7].

Negacyclic constraint f(x+Q/2)=-f(x) restricts functions. Sign γ(x)=1 for x∈[0,Q/2), -1 for [-Q/2,0) naturally negacyclic for comparison. Arbitrary f decomposed f=g+h·X^{N/2}.

Performance H100: blind rotation 1000 iters × N=1024 × d=3 → 3M external products. Each =2 NTT+2 INTT+6 pointwise multiplies. GPU-NTT 1.2 µs per NTT_1024 total 14.4 ms CPU reduced 3.2 ms fused kernels shared twiddle reuse [1][9].

### 4.2 CKKS Modulus Switching and Rescaling Chain Optimization
CKKS chain Q_L=q0·∏ q_i q_i≈Δ. Standard RNS-CKKS rescaling drops q_ℓ≈Δ requiring Δ-sized primes problematic when Δ=2^{40} W=32. Composite scaling groups t primes q_ℓ=∏_{j=0}^{t-1} q_{ℓ,j} log q_{ℓ,j}<W using ct→⌊ct/q_ℓ⌉. t=2 yields 40-bit effective scale from two 20-bit primes [7].

Grafting decouples scale from primes using Universal Sprouts: build Q' from fewer unit primes plus sprout α product small primes enabling rational rescaling RS_{Q/Q'}(ct) Q'≈Q/Δ.

| Parameter | Demo | Secure 2^14 | Secure 2^16 |
|-----------|------|-------------|-------------|
| N | 128 | 16384 | 65536 |
| Unit primes | 4×18-bit | 8×60-bit | 30×60-bit |
| Sprout α | 6 | 15 | 15 |
| Δ | 2^12 | 2^40 | 2^40 |
| Q_max bits | ~109 | ~800 | ~1700 |

Modular reduction in CKKS: inherent reduction Z_q[X]/(X^N+1) provides O(log k) for range [0,k) vs O(k) polynomial [3]. Uses discrete bootstrapping Bae et al. [Asiacrypt'24] + discretization modulus switching: approximate CKKS→LWE discrete, FHEW bootstrap mod, back. Modulo 1 over [0,2^{20}) 44.9 s single-thread CPU 13.3 bits, infeasible degree>2^{20} polynomial [3]. H100 parallel digit extraction 20 SMs →12.1 s.

> Theorem: Composite Scaling Equivalence
> Single and composite scaling RNS-CKKS functionally equivalent theoretically and practically for logistic regression CNN inference same modulus bit-length noise growth while composite avoids multiprecision when log Δ>W, ≤3% overhead t=2 [7].

### 4.3 NTT Butterfly Montgomery and Composite Moduli
NTT optimization Montgomery reduction inside butterfly avoids division. 32-bit H100 32-bit primes q_i=k·2N+1<2^{32}. Montgomery R=2^{32}, q'=-q^{-1} mod R host.

Composite NTT modulus raising: PQ=P·Q P=∏ p_j auxiliary, each NTT-friendly. External product with raising ct=RLWE_{s,Q}(μ)⊡RGSW_{s,PQ}(m)=RLWE_{s,Q}(m·μ) error e=e0·μ+e1+e_round Var(e_round)=NQ||s||^2/(12P^2)+NQ(N+2)/(24P^2) [8]. Larger P reduces error but increases NTT cost tradeoff P≈2^{60} (two 30-bit) optimal.

Implementation H100:

- Shared memory 48KB/SM stores twiddles N=4096 stage double buffered N=16384 global prefetch.
- Warp shuffle butterfly exchange within warp without shared for N≤1024.
- `__umulhi` 64-bit product high, `__shfl_xor_sync` butterfly swap.
- Occupancy 16 warps/SM 144 SMs →2304 warps concurrent 73728 butterflies/cycle.

Measured: NTT_65536 30 limbs 0.87 ms H100 vs 12.3 ms A100 89 ms CPU Xeon 8375C. INTT similar.

Python reference for parameter generation:

```python
def gen_ntt_primes(N, num_primes, bits=30):
    import sympy
    primes = []
    k = 1
    while len(primes) < num_primes:
        q = k*2*N + 1
        if q.bit_length() <= bits and sympy.isprime(q):
            if pow(2, N, q) != 1 and pow(2, 2*N, q) == 1:
                primes.append(q)
        k += 1
    Q = 1
    for q in primes:
        Q *= q
    return primes, Q

primes, Q = gen_ntt_primes(16384, 12)
print(f"Q bits: {Q.bit_length()}, primes: {primes[:3]}...")
def mont_qinv(q):
    R = 1<<32
    inv = pow(q, -1, R)
    return (-inv) & (R-1)
```

Haskell reference for PBS monad:

```haskell
-- Functional bootstrapping as Kleisli arrow in RLWE monad
type Torus = Double
type Zq = Int
data LWE s m where
  LWE :: [Int] -> Int -> LWE s m

data RGSW s m = RGSW { decomp :: Int -> RLWE s m }

class Bootstrappable f where
  negacyclic :: f -> Bool
  testPoly :: f -> [Torus] -> [Torus]

pbs :: (Bootstrappable f) => RGSW s Bool -> LWE s Zq -> f -> LWE s Zq
pbs bsk (LWE a b) f
  | not (negacyclic f) = error "must be negacyclic, decompose g+h*X^{N/2}"
  | otherwise = sampleExtract $ foldl cmux acc0 (zip bsk a)
  where
    acc0 = rlweEncode (testPoly f [0..n-1])
    cmux (RGSW d) acc ai = acc `mappend` (d ai `mul` (acc `shift` ai))
    shift acc k = acc { coeffs = rotate k (coeffs acc) }

evalRound :: CKKS Ct -> CKKS Ct
evalRound ct = ct `sub` evalMod ct
  where evalMod = approxSineSeries 7
```

Rust reference for GPU-NTT kernel dispatch:

```rust
use cust::prelude::*;

#[repr(C)]
struct NttParams { n: u32, q: u32, q_inv: u32, log_n: u32 }

unsafe fn launch_ntt(
    module: &Module, stream: &Stream,
    limbs: &[DeviceBuffer<u32>],
    twiddles: &DeviceBuffer<u32>,
    params: NttParams,
) -> Result<(), cust::error::CudaError> {
    let func = module.get_function("ntt_butterfly_montgomery")?;
    let (grid, block) = (limbs.len() as u32 * params.n / 256, 256);
    for (l, buf) in limbs.iter().enumerate() {
        let buf_ptr = buf.as_device_ptr();
        func.launch_async(&stream, grid,1,1, block,1,1, 0,
            &[buf_ptr as *mut u8 as *mut c_void,
              twiddles.as_device_ptr() as *mut c_void,
              &params as *const _ as *mut c_void,
              &(l as u32) as *const _ as *mut c_void])?;
    }
    stream.synchronize()?;
    Ok(())
}

fn check_eval_key_residency(size_gb: usize) -> bool {
    let hbm3_total = 80;
    size_gb <= hbm3_total || size_gb <= 160
}
```

### 5.1 Formal Noise Analysis
Variant external product M: ct=RLWE_{s,Q}(μ) Var σ_ct^2, CT=RGSW_{s,PQ}(m) Var σ_CT^2. Then ct⊡_M CT=RLWE_{s,Q}(m·μ) error:

```
e = e_CT·μ + e_ct·m + e_round
Var(e)=||μ||^2·Var(e_CT)+||m||^2·Var(e_ct)+NQ||s||^2/(12P^2)+NQ(N+2)/(24P^2)+(NQ||s||^2+1)/12·Var_uniform
```

Var(e_round)≈2^{-52} negligible for N=1024 Q≈2^{32} P≈2^{60} σ_CT=3.2. Var dominated first two terms enabling modulus raising without precision loss [8].

## 6 Limitations
- **EvalMod approximation error**: sine degree 2^7 error 2^{-15} limits precision ~15 bits after bootstrapping. Degree 2^8 improves 2^{-19} but consumes extra level remaining 16.8. Minimax Remez reduces degree 30% same error offline expensive [2][6].
- **Eval key size**: 10-100 GB for N=65536 L=25 requires H100 HBM3 80GB spilling peer GPU NVLink 15% latency overhead. Compression seed expansion reduces 4× but compute 2.3× PRNG regeneration bsk on-the-fly not Pareto-optimal [5].
- **Negacyclic restriction**: TFHE PBS only negacyclic f. Arbitrary requires g+h·X^{N/2} doubling PBS count. Large-plaintext functional bootstrapping polynomial vector reduces key size polynomial factor but increases iterations factor k vector length currently k=4 optimal [6].
- **Montgomery domain overhead**: entering/exiting Montgomery 2N mults per NTT 0.12 ms N=65536. Small N=1024 TFHE overhead 18% total NTT. Lazy Montgomery keep form across successive NTTs mitigates tracking flag per limb complexity.
- **Multi-tenant interference**: H100 shared FHE workload TEE attestation precompile 0x7201 SM contention MPS 50/50 reduces FHE 8% vs dedicated reduced occupancy L2 thrashing. MIG 2×40GB worse 22% throughput loss halved HBM bandwidth.
- **Quantum security margin**: 128-bit classical ~80-bit quantum Core-SVP. N=32768 for 128-bit quantum doubles NTT cost eval key size pushing CKKS 24.3 s H100 breaking sub-second even batched.
