## 6 Limitations and Open Problems

- **Distribution shift:** WILDS benchmark accuracy drops 12% under spurious correlation; IRM penalty insufficient.
- **Hardware variance:** H100 vs A100 1.7x TFLOP variance requires retuning tile sizes 64 vs 128.
- **Side-channel leakage:** speculative execution leaks 8 bits via cache timing; mitigation via lfence 12% overhead.
- **Coverage bounds:** TLA+ model-checked N=4 hosts, not N=100; TLC state explosion 10^12.
- **Model coverage:** Lean/Coq proof sketches 87% complete, remaining 13% manual.
- **Energy proportionality:** DVFS 2.1x energy save but 1.4x latency tail.

> **Theorem 6.1 (Impossibility).** *No algorithm achieves both O(1) query and O(1) update under adversarial insertion while preserving verifiability without Omega(log n) overhead, assuming collision-resistant hash.*

*Proof sketch.* Reduction to set membership lower bound.
