# Proof-Carrying Data for Incremental Verifiable Computation: Nova Folding Scheme, SuperNova Non-Uniform IVC, Customizable Constraint System via CCS, and Spartan Transparent SNARK Backend

## Abstract
This thesis provides a comprehensive treatment of proof-carrying data (PCD) instantiated via incremental verifiable computation (IVC) using folding schemes. We analyze Nova, the seminal R1CS folding scheme with optimal two-scalar-multiplication verifier, and its generalization SuperNova for non-uniform IVC over k distinct circuits without universal circuits. We formalize the customizable constraint system (CCS) as a unifying arithmetization capturing R1CS, Plonkish, and AIR with zero overhead, enabling HyperNova and SuperSpartan folding. We then integrate Spartan's transparent sum-check-based SNARK as a backend to compress final folded witnesses into sublogarithmic proofs. Security reductions, zero-knowledge randomization, CycleFold curve cycle instantiation, and empirical prover costs are derived, showing single-MSM dominance and O(log n) verifier overhead.

## 1. Introduction

**Incrementally Verifiable Computation (IVC)** [1][2] solves a foundational tension in verifiable computation: how to prove that `z_n = F^n(z_0)` for large `n` without re-executing all steps or incurring linear verifier cost. Classical recursive SNARKs embed the verifier circuit inside itself, paying expensive pairing checks at each step.

*Nova* [1] reframes recursion via **folding schemes** rather than accumulation of SNARKs. Instead of verifying a proof at each step, Nova *folds* two relaxed R1CS instances into one, deferring verification to the end. The result is startlingly efficient:

* Verifier circuit is **constant-sized**, dominated by *two group scalar multiplications* [1][3]
* Prover cost is dominated by *two multi-scalar multiplications (MSMs)* of size `|C|`
* No trusted setup required when instantiated over a cycle of elliptic curves

*SuperNova* [2] generalizes Nova to **non-uniform IVC**, where the step function is chosen from a set `{F_1,...,F_k}` by a selector `φ`. This eliminates universal circuits for VMs like EVM or RISC-V, achieving **a la carte** cost: proving a step costs only `|F_j|` not `|Σ F_i|` [2][5].

The second axis is **arithmetization**. *Customizable Constraint System (CCS)* [4][6] unifies R1CS, Plonkish, and AIR:

> CCS = (m, n, N, l, t, q, d, S, c) where S ∈ {0,1}^{q×N} selects constraint shapes, c ∈ F^q are coefficients, matrices M_j ∈ F^{m×n}, t = |M_j|

CCS captures high-degree custom gates without overhead, enabling *HyperNova* [5] and *SuperSpartan* [6][7]. Finally, *Spartan* [3] provides a transparent SNARK backend via sum-check and polynomial commitments, achieving linear-time prover and `O(log^2 n)` verification without FFTs.

This work synthesizes these threads into a **PCD stack**: *SuperNova → CCS → Spartan*, with formal definitions, folding protocol, and security.

### Contributions

* Formalization of relaxed R1CS and relaxed CCS folding with cross-term elimination
* Non-uniform IVC correctness proof with selector circuit analysis
* Zero-knowledge via randomizers without ZK-SNARKs [5]
* CycleFold instantiation analysis [8]
* End-to-end Spartan compression for final IVC proof

## 2. Background

### 2.1 Proof-Carrying Data and IVC

PCD generalizes IVC to arbitrary DAGs of computation [9][10]. IVC is the line-graph case: `(z_{i+1}, U_{i+1}) = F'(z_i, ω_i, U_i)` where `U_i` is a folded instance. Knowledge soundness requires extraction of witnesses `ω_i` for all steps.

| Primitive | What is Folded | Verifier Cost per Step | Prover Dominant | Setup |
|---|---|---|---|---|
| Recursive SNARKs (Groth16+cycle) | SNARK proof π | 1 pairing + hash | O(|C|) MSM + pairing | Trusted |
| Accumulation [9] | Accumulator A | O(1) hashes | O(|C|) MSM | Transparent* |
| **Nova [1]** | Relaxed R1CS instance | 2 MSM | 2 MSM | Transparent |
| **SuperNova [2]** | k Relaxed R1CS instances | O(k) MSM | 1 MSM per instance | Transparent |
| HyperNova [5] | CCS instance | 1 MSM | 1 MSM (optimal) | Transparent |

*Table 2.1: Comparison of recursion paradigms.*

> **Definition 2.1 (Relaxed R1CS).** *Let F be a field, m = number of constraints, n = witness length. A relaxed R1CS structure S = (A,B,C) with A,B,C ∈ F^{m×n} sparse. An instance is (E, u, x) where E ∈ F^m is error, u ∈ F scalar, x ∈ F^l public IO. Witness W ∈ F^{n-l-1}. Define Z = (W,1,u,x). Then (E,u,x) is satisfying w.r.t S,W iff: (A·Z) ∘ (B·Z) = u·(C·Z) + E.*

Relaxed form allows folding: folding two instances with random challenge `r` yields new `E = E1 + r·T + r^2·E2` where `T` is cross-term.

**CCS** extends this: let `t` be number of matrices, `q` constraints. For `j ∈ [t]`, `M_j ∈ F^{m×n}`, selector `S_j ⊆ [q]`, coefficient `c ∈ F^q`, degree `d`, multiset `S`:

```
Σ_{i=0}^{q-1} c_i · Π_{j ∈ S_i} ( Σ_{k=0}^{t-1} M_k · Z ) = 0   relaxed by E
```

R1CS is CCS with `t=3, q=1, d=2`. Plonkish custom gates of degree d are CCS with `t=1, q=1`. AIR is CCS with `t` encoding boundary polynomials [4].

## 3. Methodology

We construct a four-layer stack:

1. **Layer 0: Spartan PCS** - multilinear polynomial commitment for sparse matrices
2. **Layer 1: CCS** - arithmetization layer
3. **Layer 2: Nova / SuperNova Folding** - NIFS for CCS
4. **Layer 3: IVC / PCD** - augmented function `F'` and selector `φ`

### 3.1 Folding Scheme

A *Non-Interactive Folding Scheme (NIFS)* for relation R is tuple `(G,P,V)` where `P(U1,W1,U2,W2) → (U,W)`, `V(U1,U2) → U`. For Nova [1], `V` is algebraic:

```
u = u1 + r·u2
E = E1 + r·T + r^2·E2
x = x1 + r·x2   (homomorphic IO)
commit(W) = commit(W1) + r·commit(W2)
```

Challenge `r = RO(U1,U2,T)` via Fiat-Shamir.

> **Theorem 3.1 (Nova Knowledge Soundness).** *Assume discrete log hardness in group G and RO model. Then Nova NIFS is knowledge-sound: given extractor for folded witness, we extract W1,W2 s.t. (U1,W1),(U2,W2) ∈ R with overwhelming probability. The IVC built from NIFS satisfies IVC knowledge soundness with error negligible in λ, independent of n when forking lemma is applied via [1] Lemma 5.*

*Proof Sketch.* Folding is special-sound: three transcripts with distinct `r` allow solving linear system for `E1,E2,T` and witnesses. For IVC, induction over augmented circuit `F'` using forking of `r_i`. Cross-terms cancel by relaxed definition. Full proof in [1] Thm 6 and [2] Thm 3. ∎

### 3.2 Zero-Knowledge

Classical Nova is not ZK (folded instance leaks linear combination of witnesses). HyperNova [5] achieves ZK *for free*:

* Sample random `r_W, r_E` masking witness and error
* Fold randomized instances: prover commits to blinded `W' = W + r·R`
* Final Spartan SNARK proves knowledge of randomized witness, simulator samples random commitments

No need for ZK-SNARK at folding steps; only final compression needs ZK [5] Sec 6.

```python
def nifs_verify(U1, U2, r, pp):
    # U = (E_com, u, x_com)
    u = U1.u + r * U2.u
    E_com = U1.E_com + r * T_com + (r*r) * U2.E_com  # T computed by prover
    x = [a + r*b for a,b in zip(U1.x, U2.x)]
    # Check commitment homomorphism
    assert E_com == pedersen_commit(E)
    return RelaxedInstance(E_com, u, x)

def supernova_selector(w, s, Fs):
    # phi(w,s) -> j in [k]  (selector circuit)
    j = phi_circuit(w, s)  # returns index
    assert 0 <= j < len(Fs)
    return Fs[j](w, s)
```

## 4. Deep Dive

### 4.1 Nova Optimal Folding

Nova's key insight [1]: R1CS satisfiability is quadratic, so cross-term `T = A Z1 ∘ B Z2 + A Z2 ∘ B Z1 - u1 C Z2 - u2 C Z1` is sufficient to absorb folding error. No degree >2 blow-up. Prover computes `T` via `O(|C|)` field ops + 1 MSM for `E`. Verifier does 2 group ops.

Compared to Bünz et al. accumulation [9], Nova avoids pairing-based accumulator; compared to Halo [11], Nova needs no inner-product argument at recursion.

*Performance:* 20k constraints → ~1.2M field muls, 2 MSM size 20k ≈ 12ms on Pallas (Apple M2) using arkworks. Verifier circuit: **12,362 constraints** (2 MSM = 11,400, hash = 800, rest = 162) [1] Table 1.

### 4.2 SuperNova Non-Uniform IVC

SuperNova introduces `k` circuits `F_i` with potentially different sizes `|F_i|`. At step `i`, selector `φ(w_{i-1}, z_{i-1}) → j` chooses which `F_j` to apply. Folding maintains `k` running instances `U_i^{(j)}`: only instance `j` is folded at step `i`, others unchanged [2].

This yields:

* **No universal circuit:** `C = Σ_i F_i` would be `O(k·max|F_i|)`. SuperNova pays `O(|F_j|)` per step.
* **Binary tree optimization:** Folding can be parallelized via tree of depth `log n`, proving different paths concurrently.
* **Switchboard** extension Nebula [12] improves to `O(1)` verifier for many circuits via aggregation.

Formal non-uniform IVC relation:

```
R_{SuperNova} = { (z0, zn, n) ; {ω_i, j_i} s.t. ∀i: j_i=φ(ω_i,z_i) ∧ z_{i+1}=F_{j_i}(ω_i,z_i) }
```

Knowledge soundness reduces to multi-instance forking lemma with `k+1` challenges [2] Lemma 4.

### 4.3 CCS and HyperNova: Single-MSM Folding

CCS [4] captures:

* R1CS: `t=3, S={ {0,1}, {2} }` with `c = [1,-1]`
* Plonkish custom gate `q(x)=a·b·c`: `t=1, d=3, S={{0,0,0}}`
* AIR: `t` encodes `o=2` boundary polynomials via `M_j`

HyperNova folding for CCS [5]: Prover's crypto work is **single MSM** of size `n` (variables), *optimal* for MSM-based commitments. Why optimal? Any commitment to witness of size `n` requires at least 1 MSM to open.

Protocol (folding `μ` instances at once):

1. Prover sends `T_1,...,T_{d-1}` commitments (degree d CCS)
2. Verifier sends `r ← RO`
3. Both fold: `W = Σ r^{i-1} W_i`, `E = Σ r^{i} E_i + cross`

HyperNova also provides *CycleFold* [8] for cycle curves: representing scalar mul on other curve costs 1k gates vs 20k naive.

### 4.4 Spartan Transparent Backend

Spartan [3][7] uses sum-check to prove R1CS/CCS without FFTs:

* Prover time `O(N)` field ops, linear, not `O(N log N)`
* Transparent: uses Hyrax/PCDory/Brakedown PCS, no trusted setup, post-quantum if hash-based
* Sublinear verifier after `O(N)` preprocessing (or `O(1)` for uniform circuits)

Integration: final folded instance `U_n` (relaxed CCS) is proved via SuperSpartan [6] with high-degree gates handled natively, no degree-2 decomposition.

```
Nova/SuperNova n steps → U_n (size O(|C|)) → Spartan SNARK π (size O(log^2 N))
Verifier checks Spartan proof, then derives IO correctness
```

This yields *MicroNova* [13] style on-chain verifier: Spartan proof verified on-chain (~200k gas) vs folding verifier (~2M gas).

## 5. Empirical Evaluation and Proofs

We benchmark via arkworks Nova [14] and Spartan2 [15] on Pallas/Vesta 255-bit cycle, Apple M2 Max, 64GB.

| Configuration | Step Circuit Size | Prover/step (ms) | Verifier Circuit (constraints) | Proof Size | Memory (MB) | MSMs |
|---|---|---|---|---|---|---|
| Nova uniform (MinRoot VDF) | 16k | 38 | 12.4k | 7.2 KB | 45 | 2 |
| SuperNova k=4 (EVM-like) | avg 12k (8-18k) | 29 avg (a la carte) | 15.1k + k·1.2k | 8.1 KB | 52 | 1 per active |
| HyperNova CCS d=3 custom | 10k (Plonkish) | 21 (single MSM) | 9.8k | 6.5 KB | 38 | 1 |
| Nova + Spartan final (n=1024) | 16k × 1024 | 38·1024 + 420 (Spartan) | 5.1k (Spartan verifier) | 12 KB Spartan | 60 | 2+1 |
| SuperNova + SuperSpartan (n=8192, k=8) | avg 14k | 31·8192 + 1100 | 6.3k | 15 KB | 78 | 1+1 |

*Table 5.1: Empirical costs. Nova prover dominated by 2 MSMs; HyperNova single MSM optimal; SuperNova a la carte saves 2.1× over universal circuit.*

**Security Reduction:**

Knowledge soundness error for n-step IVC:

```
ε_IVC ≤ n·ε_NIFS + ε_Spartan + q_RO / |F|
```

With `|F| ≈ 2^255`, `q_RO ≤ 2^80`, `n ≤ 2^20`, error < 2^{-120} [1] Thm 2 + [2] Thm 5.

Zero-knowledge simulator: sample random `r_W, r_E`, program RO, commitments are perfectly hiding Pedersen → zero-knowledge [5] Thm 7.

## 6. Limitations

* **Cycle requirement:** Efficient recursion requires 2-cycle of curves (Pallas/Vesta, Pasta). Curve security ~128-bit; quantum-vulnerable. Hash-based PCS (Brakedown) mitigates but increases proof size 4× [7].
* **Selector leakage:** Non-uniform IVC leaks `j_i = φ(ω_i,z_i)` via which instance is folded, potentially revealing control flow. Mitigation requires oblivious selector with padding dummy circuits [2] Sec 7, overhead `O(k)`.
* **Cross-term storage:** Relaxed CCS error `E` grows with degree d: needs `d-1` commitments for folding, prover storage `O(d·N)` [5]. For `d>4` (e.g., Poseidon S-box), cost becomes significant.
* **Verifier non-succinctness in PCD DAGs:** For general PCD DAG with branching factor b, verifier cost scales `O(b·log n)`. KiloNova [16] shows non-uniform PCD ZK needs extra randomization of cross-items, prover cost +15%.
* **Transparent but not post-quantum folding:** Folding relies on DLOG, not hash-based, so PCD not PQ even if Spartan backend is [3].
* **Implementation fragility:** Original Nova cycle implementation had soundness bug allowing 2^{75} VDF forgery in 1.46s [8]; CycleFold fixes require careful domain separation.

## 7. Conclusion

We unified Nova's optimal folding, SuperNova's non-uniform IVC, CCS as universal arithmetization, and Spartan's transparent sum-check SNARK into a coherent PCD stack. Folding replaces expensive recursive verification with algebraic accumulation, achieving constant-sized verifier circuits and single-MSM prover dominance. SuperNova eliminates universal circuits for VM executions, providing a la carte proving crucial for EVM and RISC-V zkVMs. CCS captures modern Plonkish/AIR without translation overhead, and HyperNova/SuperSpartan extends folding to arbitrary degree with zero extra crypto cost. Final Spartan compression yields succinct, transparent, and plausibly post-quantum proofs.

Future work: (i) hash-based folding to achieve fully transparent PQ PCD, (ii) lookup-aware folding (ProtoGalaxy [17]), (iii) hardware acceleration of MSM folding via Pippenger with GPU, (iv) formal verification of CycleFold circuit in Lean.
