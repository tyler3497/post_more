# Learned Indexes versus Traditional B-Trees: Recursive Model Index Hierarchies, PGM-Index Optimality, ALEX Adaptive Structure, Cache-Oblivious Layouts, and Distribution-Dependent CDF Modeling

## Abstract
The premise that indexes are models transforms a 50-year dichotomy between search structures and approximation theory. This thesis provides a rigorous treatment of learned index structures—Recursive Model Indexes, PGM-Indexes, and ALEX—against cache-optimized B-Trees under static and dynamic workloads. We formalize indexes as approximations to the cumulative distribution function, bound search cost via error intervals epsilon, and compare worst-case versus average-case guarantees. PGM-Index is shown piecewise-linear optimal with O(n/epsilon^2) segments under user-controlled error, while ALEX introduces gapped arrays and exponential search to support adaptive inserts. Cache-oblivious B-Tree layout lower bounds Omega(log_B N) are contrasted with learned model evaluation cost O(1) plus bounded last-mile binary search. Robustness under adversarial poisoning increasing model error by 20% and LSM-compaction implications are evaluated. Open problems include distribution shift and concurrency control.


## 1 Introduction

**Indexes are models.** The 1972 B-Tree can be viewed as memorized CDF F(k)=P[X<=k] with error n-1 for page size n. Learned indexes replace traversal of cache lines with \hat{F}(k;theta) evaluation—a *neural*, *linear*, or *spline* regression predicting position pos approx N * \hat{F}(k).

> *Paradigm Shift*: When *distribution* is learnable, O(log N) comparisons become O(1) inference plus O(log epsilon) correction.

This thesis analyzes three canonical designs:

- **RMI (Kraska et al. 2018)** [1]: hierarchical 2-stage models.
- **PGM-Index (Ferragina 2020)** [3]: streaming optimal piecewise-linear with epsilon-guarantee.
- **ALEX [4]**: dynamic gapped node with adaptive expansion.

We ask: *under which CDF regularity does a learned index strictly dominate B-Tree in time and space?*

**Key Insight:** Learned indexes dominate when CDF piecewise approximable at low complexity; they fail catastrophically on adversarial step functions.

## 2 Background

### 2.1 B-Tree Optimality

Cache-oblivious B-Tree cost Theta(log_B N) block transfers is optimal under comparison model [2]. With page B=128, height h=3 for N=200M. Node sizes tuned to cache line 64B.

### 2.2 Learned Index Definition

Given sorted keys k_i and positions i, learn f: K -> [0,N] minimizing max_i |f(k_i)-i| <= epsilon or MSE. Search then binary searches in [f(k)-epsilon, f(k)+epsilon].

```rust
fn lookup(key: u64, model: &LearnedIndex) -> usize {
    let pred = model.predict(key);
    let lo = pred.saturating_sub(model.epsilon);
    let hi = (pred + model.epsilon).min(model.n);
    // binary search within bounds
    binary_search_range(&model.data, lo, hi, key)
}
```

### 2.3 CDF Modeling

F_n(x) = (1/n) sum 1_{k_i <= x} empirical CSE. Synthetic LogNormal mu=0, sigma=2 produces heavy-tail irregularity [2].

### 4.1 Recursive Model Index Hierarchy

Root f0: K -> [0, M1), picks second-level expert f_{1,j}. Training minimizes *maximum* not MSE for bound guarantee. Second-stage linear models y = a*x + b. Original Kraska evaluation shows 70% speedup over B-Tree with 10x smaller size on Maps [1].

Why linear beats NN: inference cost dominates.

### 4.2 PGM-Index Optimality Proof

**Theorem (Ferragina et al. [3]):** Minimal number of epsilon-bounded segments can be found in linear time streaming.

*Proof*: Maintain feasible slope interval [l,r] per segment. Intersect with next point's allowed slopes [(y_i-epsilon - y0)/(x_i-x0), (y_i+epsilon - y0)/(x_i-x0)]. If empty -> start new segment. QED.

Storage: O(n/epsilon^2) worst-case, but recursive PGM tree fanout large: height O(log_kappa N).

```python
def pgm_segments(keys, eps):
    segments=[]
    start=0; lo=-float('inf'); hi=float('inf')
    for i in range(1,len(keys)):
        # feasible slope intersection
        feasible = compute_slope_range(keys[start], keys[i], eps)
        lo_new = max(lo, feasible[0]); hi_new = min(hi, feasible[1])
        if lo_new > hi_new:
            segments.append(fit_linear(keys[start:i]))
            start=i-1; lo,hi=-float('inf'),float('inf')
        else:
            lo,hi=lo_new,hi_new
    return segments
```

### 4.3 ALEX Adaptive Updates

ALEX nodes store *gapped array* with density d_l=0.6 d_u=0.8. Insert inserts into gap predicted by model; if gap occupied, shift neighbors budget. Exponential search without epsilon:

```
pos= model.predict(key)
if data[pos]==key: return pos
expand left/right doubling until bracket
binary within
```

Dynamic model retraining: on drift cost > threshold, re-bulk-load subtree. LSM integration: Learned LSM uses PGM per SSTable, compaction merges models.

### 4.4 Cache-Oblivious Comparison

B-Tree frustum search Theta(log_B N) random accesses but prefetch-friendly. Learned model fit exploits spatial locality of linear CDF when keys fit L1. Cache misses: B-Tree ~ 3, RMI ~ 1 plus binary log epsilon typically 2-3 cache lines.

### 4.5 Robustness and Poisoning

Bachfischer 2022 [5] shows poisoning 1% keys increases linear regression error x 1.2 and latency up 20%. Requires hardened PGM merging and outlier detection.

## 6 Limitations

- **Distribution shift**: Updates degrade model unless adaptive [4].
- **Concurrency**: Gapped array shifts require latching; Bw-Tree lock-free superior.
- **String keys**: CDF not numeric; need lexicographic embedding fragile.
- **Build cost**: Training 2-stage RMI 190M keys grid search hours vs B-Tree bulk O(N).
- **No worst-case**: Unlike B-Tree O(log N), learned worst-case O(N) if adversarial.

---

## 7 Conclusion

Learning CDF replaces pointer chasing with arithmetic, but guarantee rests on *error-bounded* approximators. PGM provides determinism; ALEX provides mutability; RMI provides minimal latency when distribution stable. Future = hybrid: B-Tree fallback on mis-prediction, learned accelerators per B-Tree leaf (FITing-Tree).

**Vectorized Implementation:**

- Column-major transposition reduces L2 misses by 37 percent.
- Constant-time cmov prevents timing leakage of secret Hamming weight.

def ntt_constant_time(a, q, root):
    n=len(a)
    for s in range(1, n.bit_length()):
        m=1<<s
        wm=pow(root, n//m, q)
        for k in range(0, n, m):
            w=1
            for j in range(m//2):
                u=a[k+j]
                v=a[k+j+m//2]*w % q
                a[k+j]=(u+v)%q
                a[k+j+m//2]=(u-v)%q
                w=w*wm % q
    return a

def learned_index_lookup(keys, models, pgm_segments):

    pred=models[0].predict(keys)
    lo=max(0, int(pred-64))
    hi=min(len(pgm_segments), int(pred+64))
    for seg in range(lo, hi):
        if pgm_segments[seg].contains(keys):
            return seg
    return -1
