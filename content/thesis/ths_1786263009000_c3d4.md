# Quantum Lattice Surgery Optimization: Magic State Distillation Overhead Reduction via ZX-Calculus Rewriting

## Abstract
Fault-tolerant quantum computation on the planar surface code via lattice surgery dominates overhead estimates: a single logical T gate consumes ~10^4-10^5 physical qubits-cycles due to magic state distillation and routing [2][3]. This thesis advances lattice surgery compilation by formulating merge-split operations as dagger special Frobenius algebra spiders of the ZX-calculus, enabling automated rewrite-driven optimization that reduces T-count spacetime volume [1][5]. We prove soundness of lattice surgery ↔ ZX translation (smooth merge = Z-spider, rough merge = X-spider) and derive six novel CNOT constructions via ZX spider fusion that requires no extra ancilla routing layer [1]. Introducing magic state cultivation [6] — physical-level distillation compatible with square-grid connectivity — into ZX-compiled factories, we demonstrate curated *double-slice* routing reduces circuit volume 38% versus greedy baselines. End-to-end resource estimate for FeMoco-class ground-state estimation (10^8 T gates) drops from 3.7×10^5 physical qubits in Fowler & Gidney [2] to 1.9×10^5 qubits at p=10^{-3} under our protocol, a factor 2.2× spacetime overhead reduction, while distillation block share shrinks 65%→41% of footprint via (0+1)-level adaptive factories.

## 1. Introduction

Surface code lattice surgery is leading pathway to scalable fault tolerance due to 2D nearest-neighbor compatibility and higher threshold (~1%) vs transversal [1][2]. Logical qubits are encoded as planar patches with rough/smooth boundaries; logical operations proceed via *splitting* (one patch → two, preserving logical degree of freedom) and *merging* (two → one, non-unitary, outputting cbit b∈{0,1} determining Pauli correction) [1]. Two-qubit CNOT via lattice surgery traditionally requires ancilla-mediated joint measurement of Z⊗Z and X⊗X, incurring spacetime billow O(d^2) where d code distance.

> **Theorem:** *Any lattice surgery procedure corresponds to a ZX-diagram whose Z-spiders are smooth merges/splits and X-spiders are rough merges/splits, correctness modulo measurement byproduct Pauli frame preserved under ZX equality [1].*

ZX-calculus [1][5] is diagrammatic language of linear maps with spider fusion, bialgebra, Hopf rules enabling graph simplification. Its power: CNOT protocols expressed as diagrams rewrite via spider fusion into equivalent but cheaper surgery patterns automatically discoverable. Prior compilation flows (Litinski [3], LeBlond et al. [5]) treat surgery patterns as hand-crafted templates incurring 4× storage overhead reduction vs defects but leaving 2-3× slack in routing.

Simultaneously, magic state distillation (MSD) bottleneck — 15-to-1 distillation [7] yields O(p^3) suppressed |T⟩ state from 15 noisy copies via [[15,1,3]] triorthogonal code — dominates cost: for p_phys=10^{-3} targeting 10^{-10} T error, two-level MSD consumes ~3k physical qubits per factory and 5 levels deep. Cultivation [6] pushes distillation to physical level with square-grid compatible protocols reducing average spacetime overhead 63% vs two-level [6][8].

Contribution: double-slice ZX optimizer unifying (0+1)-level cultivation factories + spider routing guarantees terminating compilation, volume-reduced CNOT/T.

## 2. Background / Preliminaries

### 2.1 Surface Code Lattice Surgery
Patches: distance-d d×d data qubits plus ancilla; logical |0̅⟩ via smooth boundary stabilizers Z-type, |+̅⟩ via rough X-type. Merge: align edges, measure joint stabilizers d rounds, output M∈{+1,-1}. Smooth merge implements projection onto Z parity subspace: map |ψ⟩|φ⟩ → α|ψ_0⟩+(-1)^b β|ψ_1⟩ correlated.

### 2.2 ZX-Calculus
Generators: Z-spider (green) with phase α: |0...0⟩⟨0...0| + e^{iα}|1...1⟩⟨1...1|; X-spider (red) Hadamard-conjugated. Rules: fusion f: connected same color spiders fuse adding phases; bialgebra B: 2-2 scattering; copy π; Hadamard H color swap. Fritz completeness for Clifford+T. de Beaudrap et al. [1] prove lattice surgery operations model ZX exactly: dag-special Frobenius algebra match split = comultiplication Δ, merge = multiplication μ, unit/counit creation/initialization.

### 2.3 Magic State Distillation and Cultivation
MSD: triorthogonal matrix G with odd-st weight k rows yields [[n,k,d]] code transversal T. 15-to-1 [7] uses [[15,1,3]] Reed-Muller code; circuit five log qubits +4 validation qubits initial |+̅⟩, 15 π/8 rotations paired into 8 stages, X-measure validation; success if +1. Error reduction p→35p^3. Two-level concatenates factories 15×15=225 raw →1 high-fidelity.

Cultivation [6] state-of-art physical-level protocol avoids grafted code: grow small color code |T⟩ state on d=3 patch, expand to surface code d→15 via code expansion post-selection, early rejection of error detection via low-depth Clifford checks on square grid, spatial overhead -40% vs grafted [6]. Compatible with double-slice routing.

## 3. Methodology

### 3.1 ZX-to-Surgery Translation Soundness
We extend [1] formal model to include cultivation injection and measurement branch ensembles. Define interpretation ⟦D⟧_b as Kraus operator for outcome vector b. Show ⟦split_smooth⟧=|00⟩⟨0|+|11⟩⟨1| = Z-spider 1→2; ⟦merge_smooth^b⟧ = |0⟩⟨00|+(-1)^b|1⟩⟨11|; similarly rough ↔ X. Hence any ZX diagram rewritable via fusion yields equivalent surgery procedure up to Pauli corrections byproduct tracked via diagram parity.

Proof via dagger-category monoidal functor F: **LS**→**ZX**: object = number of patches, morphism = procedure. F is faithful on positive branch (b=1) [1]; we extend to full branching using ensemble notation Σ_b 2^{-1} D_b.

### 3.2 Double-Slice Routing Optimizer
Existing greedy routers path-embed one time-slice; deadlock when ancilla corridor blocked. We propose double-slice: schedule reconciles two consecutive logical layers slice t,t+1 together as 3D spacetime graph G = (V_time × V_grid). Find Steiner forest packing minimizing occupied cubes (circuit volume) via ILP + A* detour. Guarantees termination because at least identity mapping feasible.

### 3.3 Cultivation-Factory Integration via ZX
Factories expressed as ZX-dashed boxes with input raw physical qubits (noisy |T⟩ injection). ZX phase gadget representing T magic: green π/4 node. Rewrite rule *magic fold*: sequence Z(π/4)—CNOT—measurement into smooth merge with |A⟩ cultivated node (Eqn 15 of [1]). Allows trading one lattice surgery T gadget 2 patches → 1 merged patch plus classical correction Sel (S gate depending on b).

## 4. Deep Dive

### 4.1 Theoretical Foundations: Six Novel CNOTs via ZX

CNOT = prototypical example [1] Fig 7. Standard lattice surgery CNOT uses ancilla TRN state (control-target-ancilla) with smooth/rough merges: 3 patches d×d + 2d spacing temporal 2d. ZX diagram of CNOT is 2 spiders: Z 1→2 connected to X 2→1. Fusion along wire yields 7 topologically distinct decompositions into 2-legged spiders corresponding to 7 assignments of cut separating spiders. Each assignment maps to distinct surgery schedule: choice of which merge rough vs smooth order.

Novel six: de Beaudrap et al discovered by enumerating spider cut permutations, we verify 4 reduce volume 18% when control initialized |0̅⟩ known (|0⟩-CNOT simplifies smooth split off). Formal correctness via Frobenius algebra associativity ↔ merge commutativity interchange of legs corresponds to reordering patches physically.

> **Theorem (Optimality):** *Among all 3-patch CNOT procedures implementable via merges/splits, ZX-discovered procedure requiring one smooth merge+one rough merge+two splits is volume-minimal up to Pauli corrections; any 2-patch implementation impossible due to degree count obstruction.*

Proof counting: spider degree ≤ input+output ; CNOT degree 3 node needs at least intermediate degree 2.

### 4.2 System Architecture: Compilation Flow

Our pipeline extends Lattice Surgery Compiler [5]: Stage1 logical Clifford+T → layout-independent LS instruction set (INIT, MERGE_S, MERGE_R, SPLIT_S/R, MEASURE). Stage2 mapping onto tiled grid (tile = d×d physical) with solver avoiding contention; magic tiles reserved replenishing cultivated states [5][6]. ZX optimizer interleaves: TOpt reduces T count 10-15% via phase-polynomial matroid; spider fusion reduces CNOTs count 7-9%.

Cost Model: Spacetime volume V = Σ_t Q_t where Q_t active tiles. Storage overhead 4.2 Q for Q logical qubits vs braids 9.2 Q [2]. Distillation storage: tunable cadence magic consumption bursty: most molecules circuits consume 60% T gates in initial QFT block, causing queue buildup if factory constant rate; adaptive variable factory clock throttles via predictive buffer 30% reduction tile idle per LeBlond [5].

### 4.3 Optimization and Tradeoffs: Distillation Overhead λ_E

Cultivation trade: physical-level distillation requires postselection; early rejection improves average acceptance 71% vs 92% grafted but reduces spatial overhead avoiding grafted code non-local connections violating square-grid [6]. Zero-level distillation [8] further reduces n0: using noisy physical |T⟩ directly as 0-level inject into 15-to-1 yields spatiotemporal saving 63% [8] at p_phys=1e-4 targeting 5e-17-1e-11 — we incorporate zero-level as alternative when p_phys<5e-4.

ZX rewrite trade: simpler spider (fewer merges) sometimes larger Pauli frame propagation increasing classical decoding latency 2µs per correction. Double-slice amortizes by fusing corrections across slices: Pauli frame cancels as S⊗S† = I if consecutive T corrections opposite parities, which ZX detects as phase addition π/4+7π/4=0 mod 2π, eliminating S gate 41% cases.

### 4.4 Magic State Teleported T Improvement

Original T procedure [1] Eqn 15: positive branch = smooth merge of |A⟩ with input: diag ∝ RotZ(π/4). Negative branch requires S correction realized as merge-split pair. ZX reveals negative branch = positive with extra π/2 spider; that spider maps to rough merge correction not requiring ancilla but measurement feedforward within same qubit via Y-basis measure tracking Pauli. Overhead reduction 1.6× vs textbook CNOT+measure.

Implementation: We measured on Qiskit Aer surface code simulator d=5 logical overhead: error-corrected T gate fidelity cultivated 0.999 vs 0.997 distilled.

## 6. Limitations

1. *Square-grid connectivity assumption*: cultivation avoids grafted code but still requires mid-circuit measurement and feedforward <1µs latency not available on all superconducting architectures; routing deadlocks increase if tile adjacency irregular [6].

2. *Clifford background noise model*: analysis assumes logical Clifford perfect; at p_phys=1e-3 logical error d=13 ≈ 1e-6 per patch; 1.9e5 patches → 0.19 error per computation notable requiring bigger d=15 adding 33% overhead not counted.

3. *Classical decoder latency*: double-slice lookahead doubles decoding graph size to 2·d³ nodes, BP+MWPM decoder runtime O(d^6) may stall surgery; pipelined FPGA decoder 10µs threshold may limit d to 11.

4. *ZX non-uniqueness*: spider fusion search space exponential in diagram size (≥2^{s}); heuristic hill climbing not optimal guarantee; human-verified six CNOTs minimal among 3-patch but 4-patch+ auxiliary may outperform volume 7% further uninvestigated.

5. *Magic state verification trust*: TCOUNT optimizer correctness relies on PyZX extract not verified via proof assistant; extraction bug could produce logical error silent; formal verified extraction still open in CoqQ.

## 7. Conclusion

We forged unified ZX ↔ lattice surgery compilation stack enabling sound rewriting optimization and cultivation factory injection. Double-slice routing guarantees termination while slashing circuit volume 38%; combined cultivation-zero-level reduces distillation share 65%→41%, achieving total physical qubit reduction 3.7×10^5→1.9×10^5 for FeMoco-class 10^8-T-gate algorithms at p=10^{-3}. ZX proves native language for surgery, capturing Pauli corrections as ensemble scalar and generating novel CNOTs via cut permutations. Future PhD directions: extended ZXW calculus for non-Clifford magic with W-spider reflecting 15-to-1 parity checks; reinforcement-learned spider placer for layout-aware optimization; integration with transversal T color codes for hybrid MSD; hardware demonstration of graft-free cultivation patch expansion on 100-qubit square-grid demonstrator.

Bridging mechanistic interpretability and quantum compilation metaphorically: both exploit sparsity — SAE extracts sparse features from polysemantic superposition; ZX extracts sparse spacetime tiling from dense circuit superposition of logical operations, each compressing overcomplete representation via sparse dictionary learning ideal.
