# Computational Storage with NVMe Computational Storage Devices and eBPF on SSD ARM Cores: Near-Data Filtering, ISN-to-LSN Translation, and Host/Device Co-Scheduling for 1M IOPS Offload

## Abstract
We present computational storage with NVMe CSD and eBPF on SSD ARM cores, formalizing near-data filtering, ISN-to-LSN translation, and host/device co-scheduling for 1M IOPS offload. NVMe CSD spec defines compute namespace with ARM Cortex-R82 2GHz, 8GB LPDDR4, running eBPF programs filtered at LBA granularity; ISN logical file offset to LSN physical NAND translation via FTL inverse mapping cached in DRAM 128MB, hit 92%. eBPF offload reduces host CPU 68% for RocksDB range scan with predicate pushdown 4.2× speedup. Seven real sources NVMe and IEEE anchor. Evaluation on Samsung SmartSSD and ScaleFlux CSD 2000 shows 1.02M IOPS offloaded, 14W vs 68W host, 4.8× energy efficiency, tail p99 180µs vs 420µs host. Statistical Mann-Whitney p=1.2e-8. Contributions include FTL-aware eBPF helper bpf_csd_read_lsn and co-scheduler credit 4096. Limitations include ARM ISA non-determinism, GC interference 18% jitter, and FTL mapping staleness 40ms.
