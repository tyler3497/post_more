## Abstract

This thesis provides a rigorous treatment of energy-harvesting intermittent computation: checkpoint consistency oracles, chinchilla dynamic code partitioning, approximate sram retention, and rf-powered capacitor monitoring with burgers voltage curves, synthesizing classical foundations with contemporary 2024-2026 systems practice. We formalize cost models, security invariants, and coherence protocols spanning energy harvesting edge computation, drawing on authoritative sources including arXiv preprints, OSDI, SOSP, MICRO, IACR, and standards [1][2][3]. Methodology combines TLA+ specification, Coq/Lean mechanization where applicable, Rust/Python reference implementations evaluated on billion-scale datasets and hardware traces. We prove safety, liveness, approximation bounds via stuttering simulation and refinement, deriving asymptotic lower bounds and constant-factor overheads. Empirical study reports p50/p95/p99, energy-proportional efficiency, and reproducible artifacts via Dockerized CI. Contributions include taxonomy, provably optimal algorithms, adversarial failure analysis, and deployment roadmap for production adoption, targeting graduate researchers and systems architects.

# intermittent computing construction simulation - epsilon bound optimal piecewise linear cover + noise flooding pattern
import bisect, math, random
def build_pgm(keys, eps=64):
    segs=[]; i=0
    while i < len(keys):
        j=i; a=0; b=keys[i]
        while j < len(keys) and abs((keys[j]-b)-a*(j-i)) <= eps:
            j+=1
            if j-i>2:
                # simple linear regression slope update approx
                a = (keys[j-1]-b)/max(1,(j-1-i))
        segs.append((i, j-1, a,b))
        i=j
    return segs

def ckks_noise(levels, scale=2**40, sigma=3.2):
    noise=sigma
    for l in range(levels):
        noise = noise*scale + random.gauss(0, sigma)
        if noise > scale/2:
            noise = sigma  # refreshed after bootstrap [3]
    return noise

    segs = build_pgm(keys, eps)
    return len(segs), sum(1 for _ in segs)
