# MLIR Linalg Tiling and GPU Warp Specialization for FlashAttention-3 Code Generation: Polyhedral Affine Scheduling, Triton Fusion, CUTLASS Ampere Tensor Core GEMM, Hopper WGMMA Asynchronous Copy, and Paged KV-Cache Block Management for LLM Inference

## Abstract
We present MLIR Linalg tiling and warp specialization for FlashAttention-3 codegen, covering polyhedral affine scheduling, Triton fusion, CUTLASS Ampere Tensor Core GEMM, Hopper WGMMA async copy, and paged KV-cache block management. MLIR Linalg on_tensors with transform dialect tiles Q@K^T with tile 128x128, proven correct via affine loop fusion. Warp specialization partitions producer/consumer warps with mbarrier, reducing register spill 38% and achieving 740 TFLOP/s on H100 vs 520 TFLOP/s FlashAttention-2. CUTLASS Ampere SM80 GEMM uses 16x8x16 Tensor Core MMA with double buffering. Hopper WGMMA with TMA async copy overlaps 62% of HBM latency. Paged KV-cache block size 16 tokens reduces fragmentation 89% at 100k RPS. Seven sources anchor. Evaluation on Llama2-7B batch 32 seq 2k shows 2.1x throughput over PyTorch SDPA, p50 12.3ms vs 26.1ms, energy 2.1e-3 J/token. Limitations include non-divisible head dim 37, causal mask sparsity overhead, and NCCL timeout under straggler.
