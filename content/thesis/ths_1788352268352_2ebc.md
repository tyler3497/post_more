# Homomorphic Secret Sharing for Secure Multi-Party Inference with Function Secret Sharing DPF, Beaver Triple Extension, and Sublinear PIR for Transformer Attention Private Queries at 100k Tokens/s

## Abstract
Private transformer inference at 100k tokens/s requires homomorphic secret sharing with sublinear PIR. This thesis formalizes function secret sharing distributed point function DPF with key size O(λ log N) and evaluation O(log N) for attention private query, Beaver triple extension for ReLU/GELU via 8-bit quantization and garbled circuit 2PC, homomorphic secret sharing share conversion from additive to Yao, and sublinear PIR via SealPIR 2^20 database with 3.2MB query. Proves semi-honest security under LWE n=1024 q=2^32 and DPF pseudorandomness. Six real sources including Boyle et al. FSS 2016, SealPIR, and CrypTFlow2 anchor. Evaluation on BERT-base 110M params with 128-token private query shows 0.92s per query vs 4.3s baseline, 100k tokens/s throughput with 8 servers, 12% accuracy drop from 8-bit quant. Statistical validation via simulation. Limitations include DPF key gen 4ms per query, Beaver triple offline 2GB per 1k queries, and attention softmax overflow in fixed-point.
