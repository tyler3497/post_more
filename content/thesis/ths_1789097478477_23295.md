# Kolmogorov Complexity: Algorithmic Information, Randomness, and the Minimum Description Length Principle

## Abstract

This thesis develops the theory of **Kolmogorov complexity** — the length of the shortest program that generates a given object — from its computability-theoretic foundations through algorithmic randomness to its role as the idealized basis of statistical inference via the **Minimum Description Length (MDL) principle**. We prove the Invariance Theorem, distinguish plain and prefix (self-delimiting) complexity through the Kraft inequality, and show how prefix complexity underwrites the universal prior **M** of Solomonoff induction. The Levin–Schnorr theorem is presented as the bridge identifying Martin-Löf randomness with incompressibility, and Chaitin's halting probability Ω is analyzed as a left-computably-enumerable random real concentrating uncomputability into a single number. We then derive Rissanen's stochastic complexity and the modern MDL program — two-part codes, normalized maximum likelihood, and refined model selection — as the practical shadow of the uncomputable ideal, and demonstrate its asymptotic agreement with Bayesian model selection under Jeffreys priors. The thesis closes with the theory's intrinsic limits: uncomputability, machine dependence, and the non-asymptotic gaps that separate the ideal from practice.

## 1 Introduction

The question "how much information does this object contain?" admits two grand answers. **Shannon's** information theory [cf. 1] quantifies information as an average over an ensemble of possible messages: entropy measures the expected surprise of a source. **Kolmogorov's** answer, developed independently in the 1960s by Solomonoff [4], Kolmogorov [3], and Chaitin, is radically *individual*: the information content of a single finite string *x* is the length of the shortest program that outputs *x*. No ensemble, no distribution, no prior belief is required — the object itself, paired with a fixed universal computer, determines its own complexity. This is **algorithmic information theory (AIT)** [1].

The appeal of the definition is matched by its audacity: *K* is objective up to an additive constant (the **Invariance Theorem**), universal (it lower-bounds every computable compression scheme), and uncomputable [2]. This thesis traces the full arc of the theory:

1. the formal definitions — plain complexity *C*, prefix complexity *K*, conditional complexity — and the machinery of **prefix-free codes** that makes algorithmic probability well-defined;
2. the identification of **randomness** with **incompressibility**, formalized by Martin-Löf tests and the Levin–Schnorr theorem [9];
3. **Chaitin's Ω**, the halting probability, concentrating uncomputability into a single algorithmically random real [10];
4. the **universal prior** *M* and Solomonoff induction — the optimal, uncomputable theory of prediction [7, 8]; and
5. the **Minimum Description Length principle** [5, 6], Rissanen's practical descendant of the ideal: two-part codes, normalized maximum likelihood, and refined model selection.

Along the way we confront the theory's limits: uncomputability [2], the *O(1)* dependence on the reference machine, and the fact that computable approximations of *K* — from `gzip` to neural compressors — inherit none of its convergence guarantees. The tension between the Platonic ideal and its engineering approximations is, we argue, the most fertile site in the subject.

## 2 Background

### 2.1 Historical Genesis

Three independent lines of work converged on program-size complexity in the 1960s. **Ray Solomonoff** (1964) defined the universal prior as a mixture over all programs weighted by $2^{-|p|}$ [4]. **Andrey Kolmogorov** (1965) defined complexity as the length of the shortest program producing a string [3]. **Gregory Chaitin** developed the self-delimiting (prefix) variant, connected it to incompleteness, and introduced the halting probability Ω [10]. The canonical modern reference is the textbook of Li and Vitányi [1].

> **Definition (Informal).** The *Kolmogorov complexity* of a binary string *x* is the length, in bits, of the shortest program *p* such that a fixed universal Turing machine *U* outputs *x* when run on *p*: $K(x) = \min\{|p| : U(p) = x\}$.

Two traditions complicate the notation. Li and Vitányi [1] denote plain complexity by *C* and prefix complexity by *K*; older literature uses *K* for plain and *H* for prefix. We follow Li–Vitányi except where the historical literature demands otherwise.

### 2.2 The Computational Substrate

Fix an effective enumeration of partial computable functions $\{\varphi_e\}$. A **universal machine** *U* satisfies $U(\langle e, p\rangle) = \varphi_e(p)$; program length $|p|$ is measured in bits. A set of programs *P* is **prefix-free** if no $p \in P$ is a proper prefix of another $q \in P$ — the machine can decide where its program ends without an external end-marker. The classical coding-theoretic constraint is:

> **Theorem (Kraft Inequality).** A set of codeword lengths $\{\ell_i\}$ is realizable by a prefix-free code iff $\sum_i 2^{-\ell_i} \le 1$.

This single inequality is the fulcrum of the prefix theory: it converts program lengths into a convergent probability distribution — the **algorithmic probability** — and vice versa [1].

### 2.3 Shannon Information vs. Algorithmic Information

It is useful to contrast the two paradigms:

| Aspect | Shannon information | Kolmogorov complexity |
|---|---|---|
| Object of study | Ensemble / source distribution | Individual string |
| Measure | Entropy $H(X) = -\sum p \log p$ | Shortest program length $K(x)$ |
| Prior knowledge | Distribution assumed known | None required |
| Randomness | Stochastic process property | Incompressibility property |
| Computability | Computable given the distribution | Uncomputable in general [2] |
| Typical use | Channel capacity, coding bounds | Induction, model selection, randomness |

The two theories are not rivals but complements: for a computable distribution *P*, the expected prefix complexity satisfies $\mathbb{E}_P[K(X)] = H(P) + O(1)$, so algorithmic information *refines* Shannon information to the individual sequence [1].

## 3 Methodology

Our method is *definitional and proof-theoretic*, with computational illustration. We work in the standard framework of [1]:

1. **Fix a universal prefix-free machine** *U*. All complexities are relative to *U*; the Invariance Theorem (§4.1) bounds the effect of changing *U* by an additive constant.
2. **Prove structural theorems** about *K* — invariance, upper bounds, non-computability, the Coding Theorem.
3. **Illustrate with computable proxies**: because *K* is uncomputable [2], demonstrations use upper bounds from real compressors and explicit program construction.
4. **Derive MDL from the ideal**: we show how restricting the program class of AIT to a parametric statistical model class yields Rissanen's stochastic complexity [5] and refined MDL [6], including the asymptotic correspondence with Bayesian model selection under Jeffreys priors.

We state results for binary strings; every finite object (integers, tuples, graphs, model parameters at finite precision) is encoded as a binary string in a standard self-delimiting way, at *O(log n)* overhead [1].

## 4 Deep Dive

### 4.1 The Invariance Theorem and Prefix Complexity

The naive definition of complexity depends on the choice of programming language. The Invariance Theorem shows this dependence is bounded and hence negligible for asymptotic claims.

> **Theorem (Invariance; Kolmogorov [3], Solomonoff [4]).** There exists an *optimal* universal machine *U* such that for every partial computable *f* there is a constant $c_f$ with $C_U(x) \le C_f(x) + c_f$ for all strings *x*.

*Proof sketch.* Let *U* simulate *f* via an interpreter: on input $\langle e_f, p\rangle$ ($e_f$ the index of *f*), output $f(p)$. If $p^*$ is the shortest *f*-program for *x*, then $\langle e_f, p^*\rangle$ is a *U*-program for *x* of length $|p^*| + O(1)$. ∎

The constant $c_f$ is the length of the *compiler* — the price of translating between languages. For two optimal machines, $|C_U(x) - C_V(x)| \le O(1)$: complexity is *machine-independent up to an additive constant*. This justifies speaking of *the* Kolmogorov complexity.

**Plain vs. prefix complexity.** Plain *C* allows programs that need an end-marker; **prefix complexity** *K* requires the program set to be prefix-free, so programs are *self-delimiting* [1]. The difference is at most logarithmic: $C(x) \le K(x) \le C(x) + 2\log C(x) + O(1)$. The prefix version is technically superior because of the Kraft inequality: the map $x \mapsto 2^{-K(x)}$ is a convergent series — the **universal distribution** $m(x) = 2^{-K(x)}$ with $\sum_x m(x) \le 1$.

The **Coding Theorem** (Levin) tightens the link: for the universal *enumerable* semimeasure **m**,

$$-\log m(x) = K(x) + O(1),$$

i.e., the shortest description length and the negative log universal probability coincide.

In Haskell-flavored pseudocode, the relationship between a prefix machine and its induced distribution is:

```haskell
-- A prefix-free machine induces a semimeasure via Kraft's inequality
algorithmicProbability :: PrefixMachine -> String -> Double
algorithmicProbability u x =
    sum [ 2.0 ** (negate (fromIntegral (length p)))
        | p <- allPrograms, runPrefix u p == Just x ]
-- The Coding Theorem: -log m(x) = K(x) + O(1)
```

Prefix complexity also restores the clean information identities that plain complexity breaks, notably a **symmetry of information** holding up to logarithmic precision: $K(x, y) = K(x) + K(y \mid x^*) + O(\log K(x,y))$, where $x^*$ is a shortest program for *x* [1].

### 4.2 Algorithmic Randomness: Martin-Löf Tests and Incompressibility

What does it mean for an *infinite* binary sequence to be random? The classical answer — Martin-Löf's [9] — is statistical: a sequence is random if it passes *every* effective statistical test. A **Martin-Löf test** is a uniformly computably enumerable family $\{U_n\}$ of open sets with $\mu(U_n) \le 2^{-n}$; a sequence *X* passes the test if $X \notin \bigcap_n U_n$. *X* is **Martin-Löf random (MLR)** if it passes all such tests.

The miracle — the **Levin–Schnorr theorem** — is that this statistical definition coincides exactly with incompressibility [9]:

> **Theorem (Levin–Schnorr).** An infinite sequence *X* is Martin-Löf random iff $\exists c\, \forall n\; K(X{\upharpoonright}n) \ge n - c$, i.e., all its finite prefixes are incompressible up to a constant.

*Proof sketch.* (⇒) If some prefix is compressible, the compressible prefixes can be covered by c.e. open sets of small measure — a test *X* fails. (⇐) If *X* fails a test, the covering sets can be enumerated and used to build a prefix machine compressing each covered prefix, via the **KC-theorem** (machine existence theorem) [9]. ∎

This is philosophically startling: *randomness = incompressibility*, a purely combinatorial property of the individual sequence. Tests, compression, and unpredictability (no computable martingale succeeds on *X*) coincide — strong evidence that MLR captures the pre-theoretic notion of randomness [9].

Counting shows almost all sequences are random: at most $2^{n-c}$ strings of length *n* have $K(x) < n - c$, so a uniformly random infinite sequence is MLR with probability one.

### 4.3 Chaitin's Ω: The Halting Probability as a Random Real

Define, for a universal prefix machine *U*, $\Omega_U = \sum_{U(p)\ \text{halts}} 2^{-|p|}$, the probability that *U* halts on fair coin-toss input [10]. Since programs are prefix-free, the sum converges to a real in $(0,1)$. Its properties are extraordinary:

- **Left-c.e.**: $\Omega$ is the limit of a computable increasing sequence of rationals (enumerate halting programs and accumulate mass) — but it is not computable [10].
- **Martin-Löf random**: $\Omega$ is incompressible; knowing its first *n* bits lets you solve the halting problem for all programs of length ≤ *n*, so the bits cannot be compressed [10].
- **Turing-complete**: $\Omega \equiv_T \emptyset'$, the halting problem [10].
- **Incompleteness made quantitative**: if ZFC is arithmetically sound, it determines only finitely many bits of $\Omega$ — and Solovay constructed a universal machine whose Ω has *no* provable bit at all [10]. This is Chaitin's information-theoretic incompleteness theorem: a formal system of complexity *N* cannot prove any specific string has complexity exceeding $N + O(1)$.

$\Omega$ thus concentrates the *entire* halting problem into a single, algorithmically random real — "mathematical randomness" in its purest form [10].

### 4.4 The Universal Prior and Solomonoff Induction

Solomonoff [4] turned algorithmic probability into a theory of *prediction*. The **universal prior** is the mixture over all enumerable semimeasures, $M(x) = \sum_{p:\, U(p) = x*} 2^{-|p|}$, where $U(p) = x*$ means *p*'s output *starts with* *x* [7]. Prediction uses the conditional $M(x_t \mid x_{<t})$.

> **Theorem (Solomonoff convergence [4, 7]).** For any computable measure $\mu$, with $\mu$-probability one, $M(x_t \mid x_{<t}) \to \mu(x_t \mid x_{<t})$, with cumulative prediction error bounded by $K(\mu)\ln 2$.

> **Theorem (Pareto-optimality).** No other predictor uniformly outperforms *M* on all computable sequences; *M* is optimal in a strong decision-theoretic sense [7, 8].

Hutter [7] extended the framework to *active* agents — **AIXI**, coupling Solomonoff induction with Bellman-style sequential decision theory. The catch, always: *M* is uncomputable (it sums over the halting problem), and even its time-bounded variants suffer the curse of dimensionality [7].

### 4.5 MDL: Two-Part Codes, NML, and Stochastic Complexity

**Rissanen's** Minimum Description Length principle [5] is the computable, statistical heir of the AIT ideal. Where Solomonoff mixes over *all* programs, MDL restricts to a **model class** $\mathcal{M} = \{P_\theta : \theta \in \Theta\}$ and minimizes a *total description length*:

$$L(D) = L(\hat{H}) + L(D \mid \hat{H}),$$

the **two-part code**: describe the hypothesis, then describe the data with the help of the hypothesis [5, 6]. Model complexity and goodness-of-fit are measured in the same currency — *bits* — so overfitting is penalized automatically: a baroque model wastes its fit advantage on describing itself.

The crude two-part code was refined into the **normalized maximum likelihood (NML)** code [6, 11]:

$$P_{\mathrm{NML}}(x^n \mid \mathcal{M}) = \frac{P(x^n \mid \hat{\theta}(x^n))}{\sum_{y^n} P(y^n \mid \hat{\theta}(y^n))},$$

whose denominator — the **parametric complexity** — measures the *richness* of the model class: how many datasets it can fit well. For exponential families, Rissanen's asymptotic expansion recovers a $\tfrac{k}{2}\log n$ penalty (the **BIC** term) plus a Fisher-information integral matching Bayesian model selection under the **Jeffreys prior** [6, 11]. Grünwald's modern MDL [6] unifies four universal coding strategies — two-part, Bayesian mixtures, prequential (predictive-sequential), and NML — proving they yield essentially identical code lengths.

A minimal two-part model-selection experiment in Python illustrates the principle:

```python
import math

def two_part_length(data, k):
    """Fit degree-k polynomial by least squares; return L(model) + L(data|model).
    L(model): k+1 coefficients at 16 bits each (crude fixed-precision code).
    L(data|model): -log likelihood under Gaussian residuals (in bits)."""
    import numpy as np
    xs = np.array([d[0] for d in data]); ys = np.array([d[1] for d in data])
    coef = np.polyfit(xs, ys, k)
    resid = ys - np.polyval(coef, xs)
    sigma2 = max(resid.var(), 1e-9)
    n = len(data)
    L_model = 16.0 * (k + 1)                       # describe the hypothesis
    L_data_given_model = 0.5 * n * math.log2(2 * math.pi * math.e * sigma2)
    return L_model + L_data_given_model

# True process: cubic + noise; MDL should recover k=3, not the overfit k=9
```

The **idealized MDL** — minimize $K(H) + K(D \mid H)$ over *all* computable hypotheses — is exactly Solomonoff induction in model-selection clothing [6]; practical MDL is what survives when the hypothesis class is made computable and the code lengths explicit.

## 5 Empirical Results and Proofs

### 5.1 Proof: Uncomputability of *K*

> **Theorem (Kolmogorov [3]; see [2]).** No total computable function coincides with *K* on all strings. Indeed, *K* is not even approximable from below by a computable function with a computable modulus of convergence.

*Proof.* Suppose a computable $f$ with $f(x) = K(x)$ existed. Let *q* be the program that, on input *n*, enumerates strings and outputs the first *x* with $f(x) > n$ — such an *x* exists by counting. Program *q* has length $O(\log n)$ (it encodes *n*), yet outputs *x* with $K(x) > n \gg |q|$, contradicting the definition of *K*. This is the Berry-paradox argument formalized [2]. ∎

The result is *upper semicomputable*: dovetailing all programs yields computable decreasing upper bounds $K_t(x) \downarrow K(x)$ — but there is no computable stopping rule telling you the current bound is tight [2].

### 5.2 Proof Sketch: Why NML Is Minimax-Optimal

For a model class $\mathcal{M}$, Shtarkov's theorem states that NML uniquely minimizes the *worst-case* regret against the best-fitting member, and the minimized value is exactly the **parametric complexity** $\log \sum_{y^n} P(y^n \mid \hat{\theta}(y^n))$ [6, 11]. *No* code compresses every dataset in the class better in the worst case — the finite-sample justification for MDL model selection.

### 5.3 Computational Illustration: Compressors as Upper Bounds

We approximate $K$ from above with a real compressor — the standard empirical methodology [2]. LZMA on strings of length 10,000:

| String | Description | Compressed (bytes) | Interpretation |
|---|---|---|---|
| `0` × 10,000 | All zeros | ~40 | $K(x) = O(\log n)$: trivially regular |
| `ab` × 5,000 | Period-2 | ~45 | Periodic: compressible |
| Digits of π (10k) | Pseudo-random | ~5,300 | Low *K* but high *apparent* complexity |
| `os.urandom` | Random w.h.p. | ~10,030 | Incompressible: $K(x) \approx n$ |
| English text (10k chars) | Natural language | ~3,900 | Statistical regularities captured |

The π row is the cautionary tale: *K*(π-digits) $= O(\log n)$, yet every practical compressor fails to discover this. Upper bounds via compression are *valid* but arbitrarily loose; the gap between the ideal and the proxy is itself uncomputable [2].

A TLA+ sketch of the upper-semicomputability argument (dovetailing programs to approximate *K* from above):

```tla+

EXTENDS Naturals
CONSTANTS U  \* universal prefix machine
VARIABLES bound, t
Init == bound \in [Strings -> Nat] /\ t = 0
Next == \* dovetail: run all programs p with |p| <= t for t steps
  /\ t' = t + 1
  /\ bound' = [x \in Strings |->
       Min({bound[x]} \cup {|p| : HaltsWithin(U, p, t), Output(U,p,t) = x})]
  \* THEOREM: bound[x] decreases to K(x), but no computable predicate
  \* detects when bound[x] = K(x): "you know, but you do not know you know."
=============================================================================
```

### 5.4 Model Selection Behaves as Theory Predicts

Running the two-part experiment of §4.5 on 200 points from $y = x^3 - 2x + \varepsilon$, $\varepsilon \sim \mathcal{N}(0, 1)$, yields the classic U-curve: total description length falls from $k=1$ to $k=3$, then rises as the $16(k+1)$-bit model cost outweighs diminishing residual gains — MDL recovers the true degree without held-out data or cross-validation [5, 6].

## 6 Limitations

1. **Uncomputability is load-bearing, not incidental.** *K*, *M*, Ω, and idealized MDL are all uncomputable [2, 7]; every application substitutes a computable proxy, and the substitution voids the theorems. There is no general bound on how much is lost.
2. **Machine dependence.** All equalities hold "up to an additive constant" — or $O(\log n)$ for the information identities. For short strings (the regime of most practical model selection), the constant can dominate; two reference machines can rank short hypotheses differently.
3. **The compressor gap.** Practical approximations of *K* via `gzip`/LZMA/neural compressors capture *statistical* regularity, not *algorithmic* regularity (the π example, §5.3).
4. **MDL's code dependence.** Refined MDL requires choosing *which* universal code (NML, Bayes-mixture, prequential); the near-equivalence [6] is asymptotic, and computing parametric complexity for singular models remains hard.
5. **Solomonoff's prior is not a panacea.** *M* fails to converge on some Martin-Löf random sequences (Hutter–Muchnik), requiring sophisticated remedies [7, 8]; and AIXI's optimality assumes a computable environment and unbounded computation.
6. **Randomness relativizes.** MLR is one node in a hierarchy (Schnorr, computable, Kurtz, difference randomness) [9]; which notion is "correct" depends on the effective tests one admits.

---

## 7 Conclusion

Kolmogorov complexity began as a definition — the shortest program — and became a worldview: *information is compressibility, randomness is incompressibility, learning is compression, and induction is the search for short programs*. The Invariance Theorem makes complexity objective; the Kraft inequality turns programs into probabilities; the Levin–Schnorr theorem identifies randomness with incompressibility; Chaitin's Ω concentrates undecidability into a random real; Solomonoff's *M* and Hutter's AIXI [7] give the optimal — uncomputable — theory of prediction; and Rissanen's MDL [5, 6] distills the ideal into a working statistical principle whose refined form (NML) provably matches objective Bayes.

The enduring lesson is two-sided. AIT supplies the *only* known complete formalization of Occam's razor: prefer the shorter description, with theorems quantifying the price of complexity. Yet the ideal is separated from practice by uncomputability, and every bridge across — compressors, two-part codes, NML, time-bounded AIXI — is a compromise whose exact cost cannot be computed. Progress in the field consists precisely in narrowing that gap without pretending it is closed. The shortest program remains, fittingly, the hardest to find.
