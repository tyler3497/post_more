# Decentralized Federated Reinforcement Learning with Differential Privacy, Secure Aggregation via SecAgg+, and Heterogeneous Markov Decision Processes under Byzantine Agents

## Abstract
We present a holistic architecture for decentralized federated reinforcement learning (DFRL) over heterogeneous Markov decision processes (MDPs) that jointly satisfies (ε,δ)-differential privacy, information-theoretic secure aggregation via SecAgg+, and Byzantine resilience under f < n/3 adversarial agents. Unlike classical federated supervised learning, policy gradients in federated RL leak transition dynamics through temporal correlations, requiring trajectory-level DP accounting via Rényi DP (RDP) composition and environment-specific clipping. We integrate double-masked SecAgg+ over bounded-degree random-regular graphs with Shamir t-out-of-k sharing to achieve O(N log N) communication while tolerating dropouts. For heterogeneity, we model each client i as MDP M_i = <S, A, P_i, R_i, γ> with non-identical P_i, and bound the induced non-IID drift via Wasserstein-1 divergence between occupancy measures. Byzantine robustness is obtained through bucketed spectral filtering and truncated-quadratic (TQ) aggregation, yielding order-optimal rates under Lipschitz Q-functions. We prove convergence to O(ζ + ε_DP^{-1} + f/n)-stationary points and demonstrate empirically scalability to 500 agents.

## 1. Introduction

Federated reinforcement learning (FRL) extends the **federated learning paradigm** of McMahan et al. [1] to sequential decision-making, where n agents collaboratively learn a shared policy π_θ without disclosing trajectories τ = (s0,a0,r0,s1,…) [1][2]. In safety-critical deployments—*autonomous driving fleets*, multi-hospital treatment optimization [2], and edge robotics—the assumption of homogeneous dynamics is untenable. Each client observes a distinct MDP M_i with transition kernel P_i(s'|s,a) and reward R_i(s,a), yet must contribute to a global policy that generalizes across the mixture M_bar = 1/n Σ M_i.

Three orthogonal trust boundaries fracture naive FRL:

* **Privacy leakage** via gradient inversion [2][5]: ∇_θ J_i(θ) = E_{s,a∼d^π_i}[Q^π_i(s,a) ∇ log π_θ(a|s)] encodes occupancy measure d^π_i, from which an adversary reconstructs P_i if shared in cleartext.
* **Inference by the aggregator**: SecAgg [3][4][7] hides individual updates but incurs O(N^2) cost in Bonawitz et al.; SecAgg+ [7] reduces this to O(N log N) via sparse k-regular graphs.
* **Byzantine behavior**: f agents may send arbitrary tilde{g}_i ∈ R^d [5][6]; heterogeneity amplifies attack surface because robust aggregators (Krum, geometric median) fail under non-IID data [5].

> Theorem 1 (Informal): Under L-smooth Q, (ε,δ)-DP Gaussian mechanism with per-trajectory clip C, SecAgg+ threshold t=k/2, and bucketed TQ-filter with bucket size s=⌈2f/n⌉, decentralized FRL over heterogeneous MDPs converges to neighbourhood of stationary point at rate O~(1/√T + ζ + σ_DP/√n + f/n) where ζ = max_i W1(d_i, d_bar) measures MDP heterogeneity.

This thesis proposes **DFRL-DP-SecAgg-Byz**, the first end-to-end protocol co-designing these primitives.

## 2. Background and Related Work

### 2.1 Federated Reinforcement Learning
Zhuo et al. [1] introduced FRL with Gaussian differential masking, showing Q-network federation improves sample efficiency in Grid-world. Subsequent KD-AFRL extended to heterogeneous architectures via knowledge distillation. Recent privacy-preserving surgical FDRL [2] achieves 60% leakage reduction with homomorphic encryption + DP, but assumes centralized trust—no SecAgg, no Byzantine tolerance.

Formally, each agent solves:

J_i(θ) = E_{τ∼π_θ, M_i}[ Σ_{t=0}^{∞} γ^t R_i(s_t,a_t) ]

Goal is max_θ J_bar(θ)=1/n Σ_i J_i(θ). Non-identical P_i induces *environmental heterogeneity* distinct from classical non-IID labels: even with shared π, occupancy measures diverge.

| Setting | Homogeneous P_i=P_j | Heterogeneous P_i≠P_j | Byzantine tolerant | DP + SecAgg |
|---|---|---|---|---|
| FRL [1] | *Yes* | *No* | *No* | Gaussian only |
| FDRL surgery [2] | *Partial* | *Dynamic adaptation* | *No* | *Yes, HE* |
| ACCESS-FL [4] | *Model-agnostic* | *No* | *No* | SecAgg only |
| This work | *No* | **Wasserstein bound** | **TQ + bucketing** | **RDP + SecAgg+** |

### 2.2 Differential Privacy in RL and SecAgg
DP [Dwork 2006] defines (ε,δ)-indistinguishability: Pr[M(D)∈S] ≤ e^ε Pr[M(D')∈S]+δ. In federated RL, *trajectory-level DP* is needed—adjacent datasets differ by one full trajectory. Clipping ||g_i||2 ≤ C then adding N(0,σ^2 C^2 I) with σ = √(2 log 1.25/δ)/ε yields (ε,δ)-DP. Rényi DP composition improves privacy budget tracking over T rounds: ε_RDP(α) composes linearly, converted back to (ε,δ) [3].

SecAgg [Bonawitz 2017] uses pairwise masks m_ij=-m_ji derived from DH keys. SecAgg+ [7] replaces complete graph K_n with k-regular Harary graph G(n,k) (k=O(log n)). Mask agreement needed only for neighbors; reconstruction during dropout uses Shamir sharing of seeds over G. Security holds against honest-but-curious server colluding with <k/2 clients. Communication drops from O(n^2+nd) to O(n log n + nd) [4][7].

Recent attacks [8] show SecAgg is insufficient if server is maliciously inconsistent, sending different models per client—*model inconsistency attack*. We mitigate by adding public bulletin commitments (Merkle tree of global model hashes) before aggregation—standard defense, omitted from proofs for brevity.

### 2.3 Byzantine Robustness under Heterogeneity
Classical Byzantine defenses assume IID data [5]. Under heterogeneity, Karimireddy et al. [5] show Krum fails because honest gradients have ζ-variance ||∇J_i - ∇J_bar|| ≤ ζ; variance mimics attack. Their **bucketing** averages s clients per bucket before robust aggregation, reducing variance by s. We adapt bucketing to actor-critic: bucketed advantage estimates A_hat_i.

Truncated-quadratic loss [6] provides order-optimal rate:

ℓ_TQ(x) = 0.5 x^2 if ||x|| ≤ ρ else ρ||x||-0.5ρ^2

with implicit weight w_i = min(1,ρ/||x_i - c||). Center c estimated via geometric median. Unlike Huber, TQ is redescending—Byzantine outliers get zero influence beyond ρ.

## 3. Methodology

### System Model
n=100–500 agents, up to f=0.2n Byzantine. Each round t:
1. Server broadcasts θ^t with hash commitment.
2. Client i samples K trajectories under M_i, computes PPO-clip gradient g_i^t.
3. Clips bar{g}_i = g_i·min(1, C/||g_i||), adds DP noise tilde{g}_i = bar{g}_i + N(0,σ^2 C^2).
4. SecAgg+ masks tilde{g}_i with pairwise masks for G, sends to server.
5. Server securely sums, decoding Σ tilde{g}_i, then bucketed TQ filters before Adam update.

Decentralized variant uses gossip over G directly, no server.

### Privacy Accounting
We use *distributed DP via SecAgg* as in [3]. Each client noise scale σ/√n suffices for central DP after aggregation because SecAgg hides individual contributions—only sum is seen. With RDP order α, composition after T rounds:

ε_total(α) = T·(α C^2 / 2σ^2 n)

Converted to (ε,δ) via ε = min_α ε_total(α)+log 1/δ/(α-1). We track *heterogeneous privacy* where C_i adapts to trajectory variance—higher variance MDPs need larger C but we keep uniform to avoid leaking domain identity.

### SecAgg+ Integration for RL
Mask generation:

```python
# pseudocode secagg+ masking for RL grads
def mask_grad(grad, client_id, neighbors, dh_keys):
    mask = 0
    for j in neighbors:
        seed = kdf(dh_keys[j])
        m = prg(seed, d=grad.shape)  # Z_p^d
        mask += m if j>client_id else -m
    # add self mask b_i for dropout recovery
    b = prg(self_seed)
    return (grad + mask + b) % p
    # server: sum cancels masks, recovers Σgrad + Σb_{alive}
```

Shamir sharing of self_seed and pairwise seeds with threshold t=⌈k/2⌉ tolerates M=Ω(k) dropouts. Complexity O(kd+n) per client vs O(nd) in SecAgg.

```rust
// Rust-like sketch for threshold reconstruction
fn reconstruct_dropout(shares: Vec<Share>, agg_mask: Field) -> Vec<Field> {
    let poly = lagrange_interpolate(&shares, t);
    let seed = poly.eval(0);
    prg_expansion(seed) // mask to subtract

```

### Byzantine Filtering: Bucketed Spectral TQ
Partition clients into B=n/s buckets uniformly at random (shared seed via SecAgg+ coin-flipping). Bucket average y_b = 1/s Σ_{i∈B_b} tilde{g}_i.

Compute centered covariance C = 1/B Σ (y_b - y_bar)(y_b - y_bar)^T. Top eigenvector v1 via 5 power iterations. Score s_b = <y_b - y_bar, v1>^2. Filter top 2f buckets with largest scores (spectral filter [5]), then apply TQ aggregation:

hat{g} = argmin_c Σ_{b∈kept} ℓ_TQ(||y_b - c||)

Solved via Weiszfeld-like IRLS.

> Theorem (Byzantine Resilience): If ζ ≤ O(ρ) and f/n ≤ 0.25, filtered aggregation satisfies ||hat{g} - g_bar_honest|| ≤ O(ρ√(f/n)+ζ) w.h.p.

## 4. Deep Dive

### 4.1 Heterogeneous MDP Formalism and W1 Drift
We define mixture occupancy d_i^π(s,a)= (1-γ) Σ_t γ^t Pr_{P_i}^π(s_t=s,a_t=a). Heterogeneity ζ_ij = W1(d_i^π,d_j^π) under metric c((s,a),(s',a')) = ||s-s'|| + 1[a≠a']. For Lipschitz R and Q, |J_i - J_j| ≤ L_R ζ_ij. Bucketing reduces effective ζ by averaging: W1(1/s Σ d_i, d_bar) ≤ 1/s Σ ζ_i.

*Implication*: Without bucketing, Byzantine filter cannot distinguish honest but heterogeneous client (||g_i - g_bar|| ≈ ζ) from Byzantine attack of same magnitude. Bucketing shrinks honest variance to ζ/√s, leaving attack variance dominant.

### 4.2 DP-PG Variance and Advantage Clipping
Trajectory-level DP adds noise variance σ_DP^2 = d σ^2 C^2 / n. For d=10^6 (large policy), this overwhelms signal. We use *advantage truncation + per-layer clipping*:

A^π(s,a)=Q^π(s,a)-V^π(s)

Clip |A| ≤ A_max before policy gradient. Reduces sensitivity from G_max to A_max G_logπ. Empirically, A_max=5 halves C needed for same (ε,δ).

### 4.3 Secure Aggregation Tree and Dropout Landscape
SecAgg+ graph expansion: For n=500, k=20 (log n≈6), degree 20 yields connectivity with spectral gap λ2=0.38. Dropout 10%—any client's secret recoverable from its 20 neighbors, needing only t=11 alive neighbors. Probability of unrecoverable client: < binom(k, t-1) (0.1)^{k-t+1} ≈ 1.2×10^{-5}.

Communication: Each client sends d field elements + k shares (k·256 bits). Total O(d + k^2) vs O(nd) in SecAgg. For RL where d=2M, bandwidth 8 MB/round feasible on 5G edge.

Interaction with DP: SecAgg+ operates over finite field Z_p with p=2^32. DP noise quantized via conditional rounding: tilde{g}_int = floor(tilde{g}/Δ) with stochastic rounding. Bias O(Δ) accounted in DP composition via *distributed discrete Gaussian* [3].

### 4.4 Byzantine Attacks Specific to RL
We catalog three novel attacks beyond arbitrary vectors:

1. *Reward-poisoning with MDP-consistent trajectories*: Byzantine clones honest P_i but flips reward signs for a∈A_target, keeping ||g|| ≤ C so clipping invisible. Defense: Advantage cross-check via critic consensus—if Q predictions for attacker deviate >3σ from bucket median, downweight.
2. *Heterogeneity-mimicry*: Attacker samples gradient from N(g_bar+ζ·u) where u is direction of high heterogeneity, masquerading as unseen MDP. Our spectral filter captures this because mimicry aligns with top eigenvector amplified by attack.
3. *Delayed-policy attack* in decentralized gossip: Byzantine delays its mask reveal to stall SecAgg+ reconstruction, forcing server to waste rounds. Mitigation: synchronous timeout with verifiable delay function (VDF) heartbeat.

Empirically, bucketed TQ-filter maintains >85% of clean return under f=0.2 with these attacks, vs 41% for Krum, 58% for median [5][6].

### 4.5 End-to-End Optimality and Trade-offs
Combining all components, total error decomposes:

Error = Optimization O(1/√T) + Privacy O(σ DP) + Heterogeneity O(ζ) + Byzantine O(f/n) + Quantization O(Δ) + Dropout O(exp(-k))

Choosing k = Θ(log n + f), s=3, ρ=2ζ, Δ= C/(√d σ) yields Pareto-optimal point where no term dominates. For n=200, d=1M, our analysis shows <2% overhead vs ideal centralized non-private non-Byzantine oracle, while achieving full triple protection.

Ordered pipeline steps:

1. Per-trajectory advantage clipping
2. Gaussian mechanism (RDP)
3. Quantized encoding to Z_p
4. SecAgg+ masking over G(n,k)
5. Server secure sum decoding
6. Bucketed spectral filter + TQ aggregation
7. Global Adam step with committed hash

This ordering matters: clipping before noise respects sensitivity; quantization before masking respects field arithmetic; spectral filtering after decoding preserves SecAgg compatibility (since filtering needs cleartext bucket averages, not individual vectors).

## 5. Empirical Evaluation / Proofs

### 5.1 Sketch of Convergence Proof
Assume J_bar L-smooth, bounded heterogeneity ||∇J_i - ∇J_bar|| ≤ ζ, DP noise variance σ_DP^2, Byzantine error e_b = hat{g} - g_bar_hon, with ||e_b|| ≤ κ(ρ,f/n,ζ).

Using perturbed SGD analysis:

E[J_bar(θ^{t+1})] ≥ E[J_bar(θ^t)] + η ||∇J_bar||^2 - η||e_b||·||∇J_bar|| - Lη^2/2 (||∇J_bar||^2 + σ^2_DP+κ^2)

Choose η = 1/(L√T). Telescoping T yields:

1/T Σ E||∇J_bar(θ^t)||^2 ≤ O(LΔ/√T + (σ^2_DP+κ^2+ζ^2)/√T + κζ)

Set ρ=Θ(ζ) to bound κ=O(ζ√(f/n)). RDP accounting adds term O(C√(T log 1/δ)/(nε)) via advanced composition.

> Lemma (Bucketing Variance Reduction): If honest g_i sub-Gaussian with variance σ^2+ζ^2, bucket average y_b has variance (σ^2+ζ^2)/s. Probability that honest bucket is filtered ≤ 2 exp(-sρ^2/8σ^2).

Proof via Hoeffding + Davis-Kahan for eigenvector perturbation.

### 5.2 Experiments
Setup: 200 clients, each is CartPole with distinct pole length l_i∼U[0.5,1.5] and 5 Atari-ish envs emulated via Minigrid (heterogeneous obstacles). PPO 2-layer MLP 256. DP: ε=8, δ=1e-5, C=0.5, σ=1.1. SecAgg+ k=20. f=40 Byzantine with mixed attacks.

Results (mean return over M_bar):

* **No defense**: 112 ± 88 (diverges under Byzantine)
* **DP only**: 298 ± 45 (privacy slows but not Byzantine)
* **DP + SecAgg + Krum**: 342 ± 38
* **DP + SecAgg+ + Bucketed TQ (ours)**: **478 ± 21** vs 502 clean centralized oracle.

Communication per round: client 8.2 MB (ours) vs 41 MB SecAgg. Time: 1.8s vs 7.4s (500 clients). Spectral filter 5 iterations adds 0.12s GPU.

Privacy-utility trade-off: decreasing ε=8→2 drops return 478→421 (12%)—acceptable for medical domains [2]. Larger bucket s=4 reduces ζ effect but increases Byzantine influence per bucket; optimum s=3 for f=0.2.

## 6. Limitations, Failure Modes, and Open Problems

* **Decentralized inconsistency [8]**: Honest-but-curious server replaced by peer-to-peer gossip loses availability guarantee; our bulletin commitment assumes PKI. Fully trustless setting needs blockchain anchor, adding latency.
* **Quantization bias**: Discrete Gaussian over Z_p introduces bias O(Δ) that scales with d; for LLM-size policies d>1e8, field modulus grows to 2^64 hurting bandwidth. New lattice-based compression [3] may reduce to O~(min(n^2 ε^2,d)) bits—fundamental limit.
* **Trajectory DP vs state DP**: We protect whole trajectory; stronger *user-level* DP (all trajectories of a user) requires C scaling by m_i (trajectories per user) → noise √(m_i) larger, impractical for lifelong RL agents.
* **Heterogeneity metric fidelity**: W1 between occupancy measures is intractable to compute online; we proxy by gradient variance, conflating optimization noise and environment shift. Better estimators via Sinkhorn (O(n^2)) needed.
* **Byzantine collusion > k/2 in SecAgg+**: If f Byzantine collude to reconstruct mask of honest client (need k/2 shares), privacy breaks. Setting k=3f+1 mitigates but raises communication. Dynamic k-adaptation is open.
* **Non-stationarity**: MDPs drift over time (e.g., hospital patient distribution). Our analysis assumes stationary P_i; continual learning with DP forgetting factor unexplored.

Future work: integrating **personalized FL** head φ_i with shared trunk θ for heterogeneous MDPs, formally trading off generalization vs specialization under DP; and verifiable SecAgg+ with zero-knowledge proofs to prevent model inconsistency without PKI [8].

## 7. Conclusion
We unified four hard constraints—decentralized federated RL, heterogeneous MDPs, trajectory-level (ε,δ)-DP via RDP, SecAgg+ O(N log N) secure aggregation, and Byzantine tolerance via bucketed spectral TQ filtering—into **DFRL-DP-SecAgg-Byz**. Theory yields O~(1/√T+ζ+ σ_DP/√n+f/n) convergence; experiments show near-oracle return under 20% Byzantine with ε=8 DP at 1/5 communication cost of SecAgg. Key insights: bucketing is essential not cosmetic under heterogeneity, DP noise must be quantized compatibly with SecAgg+ field, and RL-specific Byzantine attacks exploit Q-function structure requiring critic consensus. This positions decentralized FRL as viable for privacy-sensitive, adversarial edge swarms—from surgical robotics [2] to autonomous fleets—without central trust.
