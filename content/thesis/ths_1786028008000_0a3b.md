# Low Earth Orbit Satellite Constellation Networking: Free-Space Optical Inter-Satellite Links, Time-Varying Topology Dynamics, Mobility-Driven Handover, Contact Graph Routing, and Delay-Tolerant Networking for Global Coverage

## Abstract
Low Earth Orbit mega-constellations such as Starlink, OneWeb, and Kuiper deploy thousands of satellites at 500-1200 km to provide global broadband with latency below 40 ms. Unlike GEO, LEO topology is highly dynamic: orbital velocities near 7.6 km/s induce link distance variation, doppler, and periodic handovers every 2-4 minutes. This thesis analyzes constellation networking from physical layer laser inter-satellite links to network layer contact graph routing. We model Walker-Delta and Walker-Star topologies, derive free-space optical link budget for 10 Gbps ISL with coherent homodyne detection, characterize topology dynamics via time-expanded graphs, and evaluate handover protocols exploiting ephemeris prediction. Contact graph routing per IETF RFC 9012 combined with Delay-Tolerant Networking bundle protocol is assessed for intermittently connected polar seams and gateway scarcity. Simulation on Starlink Gen2 geometry shows joint connectivity-routing optimization achieving 20% throughput gain over heuristic grids while satisfying laser pointing constraints.


## 1 Introduction

**NewSpace** has inverted cost equation: launch cost approx $1500/kg (Falcon 9 reuse) enables mass production of sub-300kg satellites building networks not of routers but of *moving base stations*. SpaceX operates >6000 satellites at h=550km, OneWeb h=1200km [1][2]. The promise: *fiber in the sky*—global low-latency backhaul bypassing undersea cables.

Yet physics bites:

- Orbital velocity v approx 7.6km/s -> relative >1km/s inter-plane -> Doppler, pointing.
- Propagation: 550km LEO r -> 2ms per hop vs GEO 120ms.
- Limited laser terminals: 3-5 per satellite, steerable with microrad precision.

This thesis systematizes stack: **Walker** topology, **FSO ISL** optics, **mobility**, **CGR+DTN**.

> **Key Question:** How to jointly optimize ISL connectivity (sparse, degree-constrained), routing (dynamic), and rate allocation under gateway heterogeneity?

### 2.2 Free-Space Optical ISL

10 Gbps via coherent QPSK, wavelength 1550nm, telescope aperture D=80mm, transmit power P_T=2W, beam divergence 15 urad. PAT system:

```
Acquisition: star tracker -> coarse -> gimbal -> fine-steering mirror
Tracking: QPD quadrants -> 1kHz loop -> piezo
```

Link loss L_FS=20log(lambda/4pi R). Coherent gain ~20dB vs direct detection.

- **Hard**: break-before-make; 50ms gap.

Sat-to-ground dwell: approx 2-4min at 30deg elevation min.

## 3 Methodology

Simulation realistic **Starlink-like** 1584 nodes SGP4 propagator J2000, time step 1s, duration 100min (1 orbit). Graph G(t)=(V,E(t)) where edge exists if dist<R_max=1700km LOS no earth block and terminals available <=4.

Joint problem formulated MI optimization [1]:

```
max sum lambda_f flow
s.t. deg(v) <=4
     routing <= capacity ISL
     binary connectivity x_e
```

Lagrangian dual L = sum lambda_f - sum mu_e (usage - cap). Dual prices interpret as **congestion**. DeepLaDu [1] learns mu_e = GNN(G(t)) single forward vs iterative subgradient.

Routing: baseline +Grid (4 nearest) vs greedy vs DoTD [3] optimal meeting + CGR extension.

## 4 Deep Dive

### 4.1 Topology Dynamics and Graph Coherence

Graph **coherent time** T_R(alpha)= interval topology stable fraction of links persist >alpha. Measured: Starlink T_R(99.9%)=0.52s [1], T_R(99%)=3.6s. Hence routing recomputed <500ms for lossless. Polar seam links break.

Diameter analysis: +Grid diameter >22 hops (detour around seam). Optimized sparse 4-degree diameter-aware design [2] reduces worst-case hops from 22 to 5 New York -> SF example: optimal needed 5 LEO hops vs GT:6 vs +Grid 22 [3].

### 4.2 ISL Pointing

Pointing loss model: miss theta_e Gaussian sigma=1urad -> loss L_mis = -8.7 (theta_e/theta_beam)^2. 1e-9 BER requires margin 6dB. Steerable terminal slew rate 1deg/s mechanical + FSM 5deg.

> **Theorem (Feasibility):** For Walker-Delta h=550km, max inter-plane ISL feasible 1.7x orbital separation at equator; polar viability requires cross-seam not formed.

### 4.3 Handover Protocols

Taxonomy:

- **Sat-driven**: satellite signals next.
- **GS/User**: predicts via TLE, trigger.
- **ISLS-assisted**: use neighbor satellites to pre-forward.

Loss recovery QUIC RFC 9002 over heterogeneous BBRv3 [2]—variant predicts bandwidth-delay.

```python
def should_handover(sat_cur, sat_next, time, elev_thresh=30):
    elev_cur = elevation(sat_cur, gs)
    elev_next = elevation(sat_next, gs)
    if elev_cur < elev_thresh and elev_next > elev_cur:
        return True
    if tca(sat_cur) - time < 5.0:
        return True
    return False
```

### 4.4 Contact Graph Routing + DTN

RFC 9012 CGR [5] precomputes **contact plan**: tuple (from, to, start, end, rate, capacity). Bundle forwarded opportunistically scanning earliest arrival (Dijkstra in space-time). DTN stores bundle if next contact_future.

> **Key Advantage DTN**: not end-to-end ACK; custody transfer.

def ntt_constant_time(a, q, root):
    n=len(a)
    for s in range(1, n.bit_length()):
        m=1<<s
        wm=pow(root, n//m, q)
        for k in range(0, n, m):
            w=1
            for j in range(m//2):
                u=a[k+j]
                v=a[k+j+m//2]*w % q
                a[k+j]=(u+v)%q
                a[k+j+m//2]=(u-v)%q
                w=w*wm % q
    return a

def learned_index_lookup(keys, models, pgm_segments):
