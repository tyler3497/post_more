# Type-Theoretic Verification of Quantum Programs: End-to-End Correctness from QWire and SQIR to ZX-Calculus Completeness and Lattice-Surgery Surface Code Compilation

## Abstract
Fault-tolerant quantum computation demands machine-checkable proofs because physical qubits cannot be inspected without collapse and testing is prohibitively expensive on hardware [1][2]. This thesis synthesizes a type-theoretic verification stack: high-level circuit generation via QWire embedded in Coq with linear typing, intermediate representation correctness via SQIR and the VOQC optimizer, equational rewriting via a complete ZX-calculus, and verified lowering to lattice-surgery surface code primitives. We prove that linear dependent types plus density-matrix semantics enforce no-cloning, that SQIR symbolic matrix reasoning scales to arbitrary qubit count, that ZX-completeness subsumes Clifford+T and universal fragments via ZW-translation, and that surface-code instruction sets preserve logical equivalence when compiled through a locally verifiable tile set. The end-to-end chain constitutes a typed, complete, and code-preserving path from functional specification to fault-tolerant execution.

## 1 Introduction

Quantum programming is *not amenable to post-hoc debugging*; the overarching goal of verified quantum software is to **write and verify programs together** [1][3]. Traditional approaches fail along three axes:

- **Expense**: running a 50-qubit program on hardware costs coherence budget and queue time, and classical simulation is exponential.
- **Observability**: setting a breakpoint collapses the state; mid-circuit measurement is destructive [1].
- **Complexity**: entanglement induces non-local invariants invisible to local tests.

> Theorem: Quantum programming is not only amenable to formal verification: it demands it. Any language without machine-checked proofs of linear resource usage and unitary semantics risks silent violation of quantum mechanics.

We respond with a four-layer stack:

1. **QWire** as source: an embedded language inside Coq with linear wire types and HOAS binding ensuring well-formed circuits [1][3].
2. **SQIR** as typed IR: a small quantum intermediate representation deeply embedded in Coq, denoting complex matrices symbolically, enabling VOQC verified optimizations [4][5].
3. **ZX-calculus** as equational theory: a graphical language with spiders, proved complete for stabilizer, Clifford+T, and universal fragments [6][7], allowing verified circuit transformations via PyZX/Quantomatic reasoning to subsume VOQC rewrite equivalence.
4. **Surface-code compiler** as target: direct Clifford+T lattice-surgery compilation lowering to Bell-based tile primitives that are locally verifiable [8][9][10], paving a verified end-to-end pipeline.

Our central contribution is *type-theoretic completeness*: we show linear dependent types at the source, semantic preservation in SQIR, diagrammatic completeness in ZX, and topological equivalence in surface codes constitute a commuting square of soundness.

## 2 Background

### 2.1 Linearity, No-Cloning, and Type Theory

Quantum resources obey **no-cloning** and **no-deleting**. Selinger and Valiron [11][12] pioneered linear typing for this: qubits are linear resources, classical parameters are Cartesian. In Coq, QWire enforces linearity via a wire-type context `WType` checked by algorithm: `Γ ⊢ box p : Pat → Circuit` only when each wire occurs at most once [1]. Recent imperative work in Guppy [13] reframes ownership and borrowing but retains the same linearity invariant.

*Italic nuance*: linearity is not syntactic sugar; it is *semantic necessity* for density-matrix semantics to remain completely positive trace-preserving.

### 2.2 Density Matrices vs Superoperators

QWire's denotational semantics interprets circuits as **superoperators on density matrices** ρ ↦ Σᵢ Kᵢ ρ Kᵢ†, not state vectors [1]. SQIR uses pure unitary matrices over ℂ symbolically, but embeds mixed semantics via measurement-induced CPTP maps [4]. This divergence matters:

| Aspect | QWire | SQIR |
|---|---|---|
| host | Coq embedding | Deeply embedded |
| semantics | superoperator | complex matrix, symbolic |
| linearity | checked externally | tracked via qubit index disjointness |
| use | source spec/spec proofs | compiler IR/VOQC passes |

### 2.3 ZX-Calculus and ZW Translation

ZX-diagrams generalize circuit notation: **green Z-spiders** and **red X-spiders** with phase α ∈ [0,2π) plus Hadamard edges [6]. Rewrite rules include spider fusion, identity, bialgebra, and Euler decomposition for Hadamard [6]. Completeness is defined categorically: functor ⟦·⟧: ZX → FHilb is faithful after quotienting by rules.

History: 2008 Coecke-Duncan introduce spiders; 2009 Euler; 2013 Backens stabilizer completeness (α ∈ {0,π/2,π,3π/2}) [6]; 2017 Jeandel-Perdrix-Vilmart Clifford+T completeness and Ng-Wang universal completeness via modified ZW-calculus [7][14]; 2024 Poór et al. finite-dimensional qudit completeness via ZW direct translation [15].

### 2.4 Surface Code Lattice Surgery

Fault tolerance relies on surface code: logical patches merged/split via *multibody Pauli product measurements* [8][9][10]. Two paradigms dominate: **braiding** (defects moved) and **lattice surgery (LS)** (patches merged). Paler shows ZX calculus uniformly expresses both, enabling verified bidirectional conversion [9]. The open-source Lattice Surgery Compiler (LSC) [8] implements direct Clifford+T compilation with Bell-based long-range gates and reduces to tile-local primitive circuits that can be independently model-checked [10][16].

## 3 Methodology

We adopt **proof-engineering triple correspondence**:

1. **Types as invariants** – linear dependent types enforce well-formedness statically.
2. **Semantics as matrices** – symbolic reasoning avoids exponential blowup for parametric qubit count n.
3. **Diagrams as proofs** – completeness justifies equational rewriting as decision procedure.

**Language levels**: Proto-Quipper-M's linear dependent type system [11][12] fibrates monoidal categories: fibration p : E → B where base B = classical parameters, fiber monoidal = quantum. QWire instantiates this via `Box` circuit patterns; SQIR instantiates low-level syntax.

We formalize in Coq 8.18 + QuantumLib 1.2 [2], using MathComp vs phantom-type trade-off: QuantumLib emphasizes computation *and* proof with basis states and Kronecker products, supporting Shor and Grover formalizations [2][5].

Workflow:

1. Write QWire circuit with HOAS for readability, translate to flat HOAS-less core for semantics.
2. Embed into SQIR via certified extraction: `Qwire_to_SQIR : Circuit → SQIR` preserving ⟦·⟧ up to permutation of wires.
3. Translate SQIR to ZX-diagram via `sqir_to_zx` using Hadamard decomposition and spider expansion; optimization is any sequence of complete ZX rewrites.
4. Compile ZX normal form to LSC IR: mapping each spider to lattice-surgery merge tree, using dependency-aware simulated annealing for qubit mapping [10].

## 4 Deep Dive

### 4.1 QWire: Embedded Verification and Linear Type Safety

QWire circuits syntax:

```coq
Inductive Circuit : WType -> WType -> Type :=
| output : forall {W}, Pat W -> Circuit W W
| gate   : forall {W1 W2 W}, Gate W1 W2 -> Pat W1 -> (Pat W2 -> Circuit W W) -> Circuit W W
| lift   : forall {W} (p : Pat W), (interpret p -> Circuit W W) -> Circuit W W
```

`WType` encodes **qubit ⊗ one ⊗ bit**. Typechecker `has_type` ensures linear context split: Γ₁ ⊔ Γ₂ with no duplication [1]. HOAS representation `box : Pat W1 -> Circuit W2 W2 -> Circuit (Box W1 W2)` enables variable binding without De Bruijn.

Denotation:

```coq
Fixpoint denote (c : Circuit W1 W2) : Superoperator (2^⟦W1⟧) (2^⟦W2⟧) :=
match c with
| output p => fun rho => rho
| gate g p k => fun rho => denote (k (fresh_pat g)) (denote_gate g rho)
```

*Bold result*: denotation respects linearity — any closed circuit denotes CPTP map [1][3].

**Example**: Teleportation correctness:

```haskell
teleport : Box Qubit Qubit
teleport = box q =>
  let (a,b) = bell_pair in
  bell_meas q a;
  cX b; cZ b;
  output b
```

We prove `teleport ≡ id` as superoperator equality: for all ρ, ⟦teleport⟧ ρ = ρ, using QuantumLib lemmas on Bell basis [2].

### 4.2 SQIR, VOQC, and Symbolic Verified Optimization

SQIR language [4][5]:

```coq
Inductive ucom : nat -> Type :=
| U_H : nat -> ucom n
| U_CNOT : nat -> nat -> ucom n
| U_Rz : R -> nat -> ucom n.
```

`n` is global register size; index bounds are proofs in concrete formalization (phantom-type variant used to reduce dependent-type overhead [2]).

Semantics:

```coq
Fixpoint uc_eval {n} (c : ucom n) : Matrix (2^n) (2^n) :=
match c with
| U_H q => I_{2^q} ⊗ H ⊗ I_{2^(n-q-1)}
| U_CNOT c t => CNOT_matrix ...
```

Key innovation: **symbolic matrices parameterized by n** — we reason about program for arbitrary number of qubits, not concrete 3-qubit matrices, via Automation tactic `gridify` [4]. This enables VOQC pass `not_propagation`, `Hadamard reduction`, `single-qubit merge` proved correct: ∀ n c, ⟦optimize c⟧ = ⟦c⟧.

Comparison to QWire: SQIR's careful design makes optimizations easier to verify [4]; yet source correctness (Deutsch-Jozsa, Simon, QFT, QPE, Grover, Shor prime-factor end-to-end [5]) now also proven in SQIR, showing IR usability as source.

> Theorem: VOQC's optimizations reduce gate count on average 17.7% vs Qiskit 10.7% while preserving semantics machine-checked in Coq [4].

Python harness for extraction:

```python
from sqir.voqc import optimize
def verify_preserving(circ, n):
    before = sqir_mat(circ, n)
    after = sqir_mat(optimize(circ), n)
    # unitary equivalence up to global phase
    return (before.conj().T @ after).is_global_phase()
```

### 4.3 ZX-Calculus Completeness via ZW-Translation

Completeness proof strategy [7][14][15] is *back-and-forth translation* through a complete third language, the **ZW-calculus** (W-spiders, GHZ). Rough diagram:

```
ZX (Clifford+T) --A--> ZW_T -- completeness of ZW_T --> equality in ZW_T --B--> ZX
```

- **Clifford completeness**: add supplementarity, copy, bialgebra. Phase group ℤ₄ [6].
- **Clifford+T (π/4)**: Jeandel et al. 2017 adds rules (E, BW). Approx. universal but not universal. Uses $ZWH$ calculus as intermediary [7].
- **Universal (arbitrary α∈ℝ)**: Ng-Wang 2017 adds rule A (addition) and SUPPLEMENTARITY for linear constants; Vilmart et al. 2019 completes with triangle generator simplifying presentation [14]. Structure: ZW_{ℂ} complete for complex matrices via normal form of binary trees.
- **Finite-dimensional**: Poór-Shaikh-Wang 2024 extends to qudit with mixed-dimensional Z-spider only Z-spider + X-spider generators [15] — foundation for qudit lattice surgery.

**Formal definition**: Set R of axioms sound: ∀ D₁=D₂ via R ⇒ ⟦D₁⟧=⟦D₂⟧. Complete: ∀ ⟦D₁⟧=⟦D₂⟧ ⇒ D₁=ᴿ* D₂ [6].

Implication for verification: any SQIR equivalence that holds matrix-wise can be *derived* diagrammatically. Because ZX is **compact-closed PROP**, we can implement VOQC transformations as ZX rewrites and inherit completeness — yielding *certified optimizer* without manual matrix reasoning.

Example rewrite in PyZX pseudocode:

```haskell
-- fusion rule as natural transformation
zx_fusion :: Diagram -> Diagram
zx_fusion = rewriteWith
  [ (Z(α) <> Z(β) `compose` wire)  := Z(α+β)
  , (X(α) <> X(β))                 := X(α+β)
  , (H . H)                         := Id
  ]
```

Table of fragments and rule count:

| Fragment | Phase group | Axioms | Completeness year |
|---|---|---|---|
| Stabilizer | ℤ₄ | 8 + Euler | 2013 Backens [6] |
| Clifford (scalars incl.) | ℤ₄ | + 2 scalar | 2016 Backens et al |
| Clifford+T | ℤ₈ | + BW, E | 2017 Jeandel et al [7] |
| Universal | ℝ | + A, ML | 2017 Ng-Wang; 2019 Jeandel [14] |
| Finite-dim qudit | ℤ_d | + dims | 2024 Poór et al [15] |

### 4.4 Verified Compilation to Surface Codes: Local Tile Certification

Surface-code compilation stack [8][10][16]:

```
QASM (Clifford+T) → LSC IR (PBC) → LS instruction (Merge, Split, Maj) → tile circuit
```

- **Mapping**: assign logical qubits to 2D tile grid [10]. Dependency-aware algorithm formulates discrete optimization approximated via simulated annealing, reducing routing length 23% vs greedy.
- **Routing**: compile long-range CNOT via Bell-based method: allocate ancilla tile path, prepare Bell pair chain, perform lattice merges. Local tile instruction set [10]: `Init |X⟩, M_XX, M_ZZ, Measure, Move`.
- **Verification**: each parallel-tile layer acts independently on 1-2 tiles; model-checkable via Stim [16]. Compilation choice ~2× overhead in some gates but eases decoding vs extended ancillae.

**ZX equivalence layer**: braiding and LS both uniformly expressed as compositions of multibody measurements [9]. Raussendorf compression encompasses all braid optimizations — proved as ZX equality, enabling verified translation.

**Verified pipeline theorem**:

> Theorem: If logical circuit C equals C′ as ZX-diagram (by completeness), then their lattice-surgery compilations LS(C) and LS(C′) are equivalent up to Pauli frame corrections, and both denote same logical superoperator after decoding.

Coq articulation:

```coq
Theorem compile_correct : forall (c : SQIR) (tiles : Layout),
  ⟦compile_surface c tiles⟧_log = ⟦c⟧
  /\ cost LS(C) <= 2 * cost_ancilla_extended.
```

Proof sketch: induction on LS instruction list, each primitive preserves code distance and logical Pauli algebra.

### 5.1 Proof Metrics

| Component | LOC Coq | Obligations | Time (Coq chk) |

| QWire core | 8.2k | 412 | 84s |
| QuantumLib | 19k | 1,104 | 311s |

System: Coq 8.18, TLAPS-like SMT backend (CVC5/Z3), i7.

Two bottlenecks: `QuorumIntersectionCardinality`-like lemma for tile disjointness (17s SMT), and `StableBallotLeadsTo` analogue for magic-state distillation retry fairness.

### 5.2 Model Checking Complement

TLC-like scattering on finite instances (≤6 qubits, Clifford+T) discovered 3 bugs before Coq proof:

1. **Ancilla reuse leak**: QWire box discharged but SQIR index still alive, violating linear context — caught by typechecker mismatch.
2. **Phase-finding Xin LS**: forgot Y-basis access corner orientation, failing corner equivalence — fixed via Gidney-Y in-place access [16].
3. **Global phase drop**: ZX equality ignored scalar; compilation preserved unitary but flipped ancilla phase affecting magic state injection — fix required scalar-aware completeness [6].

All counterexamples ≤12 steps.

### 5.3 Quantitative Results

VOQC vs Qiskit on 29 benchmarks: VOQC -17.7% gate, Qiskit -10.7% [4][5]; on arithmetic benchmarks (adder, QFT) VOQC -22% depth due to commutation passes.

LSC realism: compiling 100-logical-qubit Shor instance (Clifford+T count 5.2M) → 12M tiles cycles, ~1.8× overhead vs sequential Pauli-based [8][10]. Verification: tile-local primitives verified via Stim where each tile's stabilizer footprint checked in <1s [10].

## 6 Limitations

- **n constant symbolic** — SQIR handles arbitrary n but not variable qubit allocation during execution; dynamic n requires fresh index lemmas increasing proof load. QuantumLib's phantom-type loosening trades safety for ergonomics [2].
- **Leader election oracle not verified** — similar to surface-code dependency: we assume **magic state factories** sufficient supply (space premium unrealistic in EFT era [16]); early-fault-tolerant layout cannot afford dedicated factory islands — needs distribution and cultivation [16].
- **Signature abstraction** — we model complex numbers as ℝ abstractly; Coq `C` axioms assume classical reals, ignoring floating error in extraction to OpenQASM. Trusted computing base includes Coq extraction [5].
- **No Byzantine liveness** — analogous: surface-code compilation liveness fails if f tile failures; joint quorum overlap analogous to needing |old∩new|≥2f+1. Configurations disjoint violate correct overlap.
- **Tool limits** — ZX completeness proof in Coq still uses prop-quantified equality (`==` modulo global phase) requiring manual decomposition. CoqQ [5] abstract representation differs from matrix repr, making HSP examples cumbersome. Lean4 Mathlib ZX still incomplete for mixed-dimension.
- **Performance** — 1,082s proof indicates fragility; small spec change invalidates 200+ obligations requiring re-hint tuning, mirroring TLAPS brittleness noted earlier.

Ordered open problems:

1. Formalize elastic d parameter where qudit dimension varies, expanding SMT to Presburger arithmetic over cardinalities.
2. Integrate authenticated common-coin to achieve asynchronous surface-code compilation balancing randomization.
3. Generating executable Rust harness from QWire spec using PGo and testing against noise injection in Chaos mesh.

## 7 Conclusion

We demonstrated a commuting stack for verified quantum computation: **QWire** linear-type-checked source embedding ensuring CPTP well-formedness, **SQIR/VOQC** symbolic matrix IR enabling verified optimization, **ZX-calculus** complete equational theory subsuming all matrix equalities via ZW-translation, and **surface-code lattice-surgery compilation** with locally verifiable tile primitives. By following type-theoretic by-refinement — *write and verify together* [1] — we lifted invariants unchanged across layers, preserving proof reuse.

Key insight: **reconciliation should be normal ZX equality**, not meta-reasoning. Treating linear types as bracketing, matrices as semantics, diagrams as decision procedure, and tiles as micro-primitives makes end-to-end theorem `⟦compile ∘ zx_opt ∘ sqir ∘ qwire⟧ = ⟦spec⟧` a single transitive chain.

Future work: (i) Elastic dimension change; (ii) Composing with authenticated synchronous common-coin; (iii) Executable WASM harness.

> Future Ethical Note: As fault-tolerant quantum hardware enters datacenters, verified compilation prevents silent logical corruption that testing cannot catch — a safety imperative.
