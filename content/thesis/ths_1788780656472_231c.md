# Cache-Oblivious Algorithms: Van Emde Boas Layouts, Dynamic B-Trees, and Funnel Sort

## Abstract

Cache-oblivious algorithms achieve asymptotically optimal data movement across every level of a memory hierarchy without tuning to hardware parameters such as cache size or line length. This thesis develops the theory from the ideal-cache model [1] through its three canonical constructions: the van Emde Boas recursive tree layout, which emulates an optimal B-tree for any block size simultaneously [2]; the dynamic cache-oblivious B-tree of Bender, Demaine, and Farach-Colton, which attains $O(\log_B N)$ search and update bounds in the fully dynamic setting using packed-memory arrays [3]; and funnel sort with its $k$-merger primitive, which attains the sorting lower bound $\Theta((N/B)\log_{M/B}(N/B))$ cache misses under the tall-cache assumption [4][5]. We prove the cache-complexity recurrences governing each construction, derive the $M = \Omega(B^2)$ tall-cache requirement from first principles, compare cache-oblivious and cache-aware designs, and close by surveying fundamental limitations — the LRU replacement gap, the associativity idealization, and engineering overhead — plus parallel extensions [6][7].

## 1 Introduction

The random-access machine (RAM) model charges unit cost for every memory access, an idealization that is flagrantly false today: a modern processor navigates four or more cache levels before reaching DRAM, and block movement dominates computation. Aggarwal and Vitter's external-memory (I/O) model [8] formalized two-level memory, but algorithms designed in it must be parameterized by $M$ and $B$ — quantities the programmer rarely knows, which vary across machines, and which multiply across hierarchy levels.

The cache-oblivious program, introduced by Frigo, Leiserson, Prokop, and Ramachandran [1], asks: *can a single algorithm, written with no knowledge of $M$ or $B$, be asymptotically optimal for every cache in the hierarchy simultaneously?* The answer is yes, via recursive self-similarity: divide a problem into subproblems of geometrically decreasing size, so that for *every* block size $B$, some recursion level matches the hardware. This thesis examines the three pillars of that answer.

First, the **van Emde Boas layout** turns a static binary search tree into a structure that behaves like a B-tree of optimal branching factor for any unknown $B$ — a tree that is simultaneously every B-tree at once [2]. Second, the **dynamic cache-oblivious B-tree** of Bender, Demaine, and Farach-Colton extends this to insertions and deletions in $O(\log_B N)$ amortized memory transfers [3]. Third, **funnel sort** and its $k$-merger primitive show that divide-and-conquer can achieve the I/O-model sorting lower bound $\Theta((N/B)\log_{M/B}(N/B))$ without ever naming $M$ or $B$, provided the *tall-cache assumption* $M = \Omega(B^2)$ holds [4][5].

> **Theorem:** (Ideal-cache optimality program). For any algorithm $A$, let $Q_A(n, M, B)$ denote its cache complexity — the number of block transfers between an ideal cache of size $M$ words and line size $B$ words and unbounded main memory. A cache-oblivious algorithm is one whose specification mentions neither $M$ nor $B$. The central results of this thesis are: (i) static search with $Q(n) = O(\log_B n)$; (ii) dynamic search and update with amortized $Q(n) = O(\log_B n)$; (iii) sorting with $Q(n) = \Theta((n/B)(1 + \log_{M/B}(n/B)))$, all achieved obliviously [1][3][4].

The remainder of this thesis is organized as follows. Section 2 establishes the ideal-cache model, the regularity condition, and the relationship to the Aggarwal–Vitter model. Section 3 describes our analytic methodology: block-transfer accounting via recursion trees. Section 4 develops the three constructions in depth. Section 5 gives the key recurrences, their solutions, and a quantitative comparison with cache-aware baselines. Section 6 states the fundamental limitations of the model. Section 7 concludes with open directions.

## 2 Background

### 2.1 The Ideal-Cache Model

The ideal-cache model [1] consists of two levels: an unbounded main memory and a cache of $M$ *words* divided into lines of $B$ consecutive words. The cache is **fully associative** — any block may reside in any cache line — and employs **optimal offline replacement**, evicting the block whose next use lies farthest in the future. These assumptions are deliberately unrealistic; they define a *clean* model in which the number of misses of an algorithm is a well-defined function $Q(n, M, B)$, and Frigo et al. prove a regularity condition under which an algorithm's ideal-cache complexity is within a constant factor of its complexity under LRU replacement with a slightly smaller cache [1]. Concretely, any algorithm satisfying a mild *regularity condition* — roughly, that halving the cache size at most doubles the miss count — loses only a constant factor when moving from optimal to LRU replacement.

The ideal-cache model is a strict strengthening of the **external-memory model** of Aggarwal and Vitter [8], which uses the same two-level geometry but where the algorithm *knows* $M$ and $B$ and tunes its parameters accordingly. The I/O model establishes the sorting lower bound $Q_{\mathrm{sort}}(n) = \Omega((n/B)\log_{M/B}(n/B))$, which any cache-oblivious sorting algorithm must also respect. The triumph of funnel sort is to *meet* this bound obliviously [4].

### 2.2 The Tall-Cache Assumption

Many cache-oblivious analyses require the **tall-cache assumption**:

$$M = \Omega(B^2),$$

i.e., the cache holds at least a quadratic number of blocks relative to the line size. In practice this is generous — a 32 KiB L1 cache with 64-byte lines has $M/B = 512$ blocks and $B = 8$ words, so $M/B = 64B \gg B$ — but theoretically it is a genuine restriction. It typically arises when an algorithm must keep $\Theta(B)$ blocks resident *simultaneously*, one per active input stream, and additionally have enough space for $\Omega(B)$ words of bookkeeping per stream. Brodal et al. later showed that a weaker assumption $M = \Omega(B^{1+\varepsilon})$ suffices at the cost of a $1/\varepsilon$ factor in the bounds [7]. We derive the precise origin of the assumption in the $k$-merger analysis of Section 4.3.

### 2.3 Memory Hierarchies and the Self-Similarity Principle

A cache-oblivious algorithm analyzed once for a two-level ideal cache $(M, B)$ is simultaneously optimal for every $(M_i, B_i)$ pair in a real hierarchy, provided each level satisfies the tall-cache and regularity hypotheses [1]. The mechanism is the **self-similarity principle**: recursion generates subproblems at all scales $n, \sqrt{n}, n^{1/4}, \ldots$, and the subproblem of size $\Theta(M)$ fits in *every* cache, whatever $M$ is. A cache-aware B-tree tuned for L3 is mistuned for L1; the van Emde Boas layout is tuned for all of them.

## 3 Methodology

Our analysis follows the standard cache-complexity methodology of the field [1][2]:

1. **Block-transfer accounting.** Count the misses $Q(n, M, B)$ as a function of the unknown $M$ and $B$; work $W(n)$ is analyzed separately in the RAM model.
2. **Recursion-tree analysis.** Write recurrences for $Q$ tracking misses across recursion levels, identifying the *base-case scale* where a subproblem fits in cache ($n \leq M$) or in $O(1)$ blocks ($n \leq cB$).
3. **Layout accounting.** For trees, count distinct blocks intersected by a root-to-leaf path or rebalancing window under the vEB layout, via its recursive $\sqrt{n}$-size decomposition.
4. **Lower-bound matching.** Compare each upper bound against the I/O-model lower bound [8] to certify optimality, and against cache-aware baselines to quantify the price of obliviousness.

All asymptotic statements assume the tall-cache hypothesis $M = \Omega(B^2)$ and the regularity condition where needed.

## 4 Deep Dive

### 4.1 The Ideal-Cache Model and the Regularity Condition

The subtle point of the ideal-cache model is the *optimal replacement* assumption: no real cache knows the future. Frigo et al. bridge this with the **regularity condition** [1]: halving the cache degrades the miss count by at most a constant factor. Under regularity, Sleator and Tarjan's competitive analysis of LRU implies that LRU with a cache of size $M/2$ incurs at most twice the misses of optimal replacement with cache size $M$. Hence every regular cache-oblivious algorithm analyzed in the ideal-cache model is automatically within a constant factor of optimal under realistic LRU replacement — a remarkably strong portability theorem. All algorithms in this thesis are regular.

> **Theorem:** (LRU simulation [1]). Let $A$ be a regular cache-oblivious algorithm with ideal-cache complexity $Q(n, M, B)$. Then $A$ executed on an $M/2$-word LRU cache with line size $B$ incurs $O(Q(n, M, B))$ misses. *Proof sketch.* Competitiveness of LRU against optimal offline replacement gives a factor-2 bound on misses for fixed $M$; regularity absorbs the halved cache size into the constant. ∎

### 4.2 The Van Emde Boas Layout: Every B-Tree at Once

Consider a complete binary search tree $T$ on $n$ keys. Any *linear* layout (preorder, inorder, level order) forces some root-to-leaf path to span $\Omega(\log n / \log B)$ blocks only if $B$ is large, and degenerates for small $B$. Prokop's insight [2] was a **recursive layout**: split $T$ at the middle level into a *top* subtree $T_0$ of height $\lceil h/2 \rceil$ and $2^{\lceil h/2 \rceil}$ *bottom* subtrees $T_1, \ldots, T_m$ each of height $\lfloor h/2 \rfloor$, where $h = \log_2(n+1)$. Store $T_0$ first, then $T_1, \ldots, T_m$ left to right, recursing within each piece. This is the **van Emde Boas (vEB) layout**, named for the structurally similar van Emde Boas priority-queue decomposition.

The magic is in the square-root recursion. At recursion depth $k$, subtrees have size roughly $n^{1/2^k}$. For *any* block size $B$, there is a depth at which subtree sizes fall in $[B/2, B]$; each such subtree occupies $O(1)$ blocks, and a root-to-leaf path passes through $O(\log n / \log B)$ of them:

> **Theorem:** (Static cache-oblivious search [2]). A complete binary search tree on $n$ keys stored in van Emde Boas layout supports search in $\Theta(\log_B n)$ cache misses, which is optimal, and the algorithm uses no knowledge of $B$. *Proof sketch.* Let $T(n)$ be the layout. A search path visits one node per level; group the $\log n$ levels into $\log_B n$ *levels of detail*, each spanning $\Theta(\log B)$ tree levels, hence $\Theta(B)$ nodes — a constant number of blocks. The square-root recursion guarantees that nodes of each level of detail are stored contiguously. Summing gives $O(\log_B n)$; the $\Omega(\log_B n)$ lower bound follows from the I/O-model search lower bound. ∎

Concretely, the layout *emulates a B-tree with branching factor $B$ for every $B$ simultaneously*: the contiguous chunks of size $\Theta(B)$ play the role of B-tree nodes. The layout is computed by this recursive routine:

```python
def veb_layout(n):
    """Return list of node ids in van Emde Boas order for a complete
    binary tree with n nodes, heap-indexed (root=1)."""
    order = []
    def rec(root, h):
        # h = height of subtree rooted at `root`
        if h <= 1:
            order.append(root)
            return
        h_top = (h + 1) // 2          # ceil(h/2): height of top part
        h_bot = h // 2                # floor(h/2): height of bottom parts
        # top subtree: first h_top levels below root
        rec(root, h_top)
        # bottom subtrees rooted at depth h_top, left to right
        first = root * (1 << h_top)
        for i in range(1 << h_top):
            rec(first + i, h_bot)
    import math
    rec(1, math.ceil(math.log2(n + 1)))
    return order

# sanity: 15-node tree -> top subtree nodes {1,2,3}, then four bottom
# subtrees {4,8,9},{5,10,11},{6,12,13},{7,14,15} in order
print(veb_layout(15))
```

Note the subtlety the code exposes: the recursion is on *tree height*, not node count, and the top part always precedes the bottom parts — this is what guarantees that at the critical scale, subtrees are contiguous.

### 4.3 Funnel Sort and the $k$-Merger

Funnel sort [4] is a cache-oblivious mergesort. To sort $n$ elements: split into $n^{1/3}$ contiguous segments of size $n^{2/3}$, sort each recursively, then merge the $n^{1/3}$ sorted runs with an $n^{1/3}$-**merger**. The merger is the heart of the algorithm.

A $k$-merger is a complete binary tree with $k$ leaves (the input streams) and $k-1$ internal binary mergers, each equipped with an output **buffer** whose size is chosen so that filling the root buffer costs the right number of misses at every scale. The *fill* procedure recursively ensures children buffers are nonempty, then performs one merge step. The van Emde Boas layout is used *again* here: the merger tree itself is stored in vEB order so that each subtree of the merger fits in $O(1)$ blocks at the right scale [4][5].

> **Theorem:** ($k$-merger complexity [4]). A $k$-merger merging $k^3$ elements incurs $Q(k) = O((k^3/B)\log_M k^3 + k^2/B)$ misses under the tall-cache assumption, using $O(k^2)$ auxiliary space. *Proof sketch.* The recurrence $Q_M(k) \leq (2k^{3/2} + 2\sqrt{k})\,Q_M(\sqrt{k}) + O(k^2)$ captures the cost of filling the $\sqrt{k}$ top and bottom sub-mergers; it solves to the stated bound when $M = \Omega(B^2)$ keeps the active buffer frontier in cache. ∎

Funnel sort's overall recurrence is then

$$Q(n) = n^{1/3} \, Q(n^{2/3}) + Q_{\mathrm{merge}}(n^{1/3}),$$

which solves to $Q(n) = \Theta((n/B)\log_{M/B}(n/B))$ for $n$ larger than a constant — *matching the Aggarwal–Vitter lower bound*, achieved with zero knowledge of $M$ or $B$ [4][8]. **Lazy funnel sort** [5] refines the design: buffers are filled lazily (only when empty) rather than eagerly, removing the awkward requirement that $k$ be an exact square at every level and enabling the *distribution sweeping* framework for computational geometry [5].

### 4.4 Dynamic Cache-Oblivious B-Trees

The static vEB layout cannot support updates: inserting a key into a contiguous array shifts $\Omega(n)$ elements. Bender, Demaine, and Farach-Colton [3] solved this with two ideas. First, replace the contiguous array by a **packed-memory array (PMA)** — an array of size $cN$ ($c > 1$) with gaps distributed by density thresholds, supporting insert/delete in $O((\log^2 N)/B)$ amortized memory transfers [3]. Second, store a *static* complete binary tree in vEB layout whose leaves correspond bijectively to PMA cells; internal nodes store subtree maxima, so searches route through the static tree at $O(\log_B N)$ cost while updates pay the PMA rebalancing cost.

The original FOCS 2000 construction is intricate — *buffer nodes* protect "long-distance" nodes whose parent/child pointers cross vEB block boundaries from excessive PMA movement. Two later simplifications made the structure teachable: Bender, Duan, Iacono, and Wu combined the static vEB tree with the PMA more directly, and Brodal, Fagerberg, and Jacob gave a construction via binary trees of small height [2].

> **Theorem:** (Dynamic cache-oblivious B-tree [3]). There exists a cache-oblivious dictionary on $N$ keys supporting search in $O(\log_B N)$ worst-case memory transfers and insert/delete in $O(\log_B N)$ amortized memory transfers, using $O(N)$ space. *Proof sketch.* Search traverses the static vEB tree ($\Theta(\log_B N)$ misses); updates rebalance an $O(\log N)$-height PMA window, and buffer nodes keep long-distance pointer maintenance within the same bound. ∎

### 4.5 The Tall-Cache Assumption, Derived

Why does funnel sort need $M = \Omega(B^2)$? Consider the $k$-merger fill at the recursion base: merging a constant number of streams needs $\Theta(B)$ blocks resident, while the *active frontier* of intermediate buffers holds $\Theta(B)$ blocks of buffer state plus $\Theta(B)$ input blocks simultaneously. The clean sufficient condition making both fit, with room for bookkeeping, is $M = \Omega(B^2)$: enough blocks to hold $B$ blocks' worth of state with $B$ words of metadata each. Brodal and Fagerberg showed $M = \Omega(B^{1+\varepsilon})$ suffices by shrinking buffer growth rates, at the cost of a $1/\varepsilon$ blowup [7]. Empirically the assumption is nearly vacuous — real caches satisfy $M/B \gg B$ by factors of 10–100 — which is why lazy funnel sort beats tuned quicksort in practice [6].

## 5 Empirical Results / Proofs

### 5.1 The Master Recurrence and Its Solution

The three constructions share a proof skeleton: identify the scale at which a subproblem fits in cache, count misses above that scale, and charge $O(1)$ blocks per unit of work below it.

| Algorithm | Recurrence (misses) | Solution | Optimal? |
|---|---|---|---|
| vEB search | $Q(n) \leq Q(\sqrt{n}) + O(1)$ per level of detail | $\Theta(\log_B n)$ | Yes [2] |
| Funnel sort | $Q(n) = n^{1/3}Q(n^{2/3}) + O((n/B)\log_M n)$ | $\Theta((n/B)\log_{M/B}(n/B))$ | Yes [4][8] |
| Lazy funnel sort | same, lazy fill | same, weaker tall cache | Yes [5] |
| CO B-tree search | static vEB traversal | $O(\log_B N)$ worst case | Yes [3] |
| CO B-tree update | PMA rebalance + vEB search | $O(\log_B N)$ amortized | Yes [3] |
| Matrix transpose | $Q(m,n) = 2Q(m/2,n/2) + O(1)$ | $\Theta(1 + mn/B)$ | Yes [1] |
| CO FFT | $Q(n) = 2Q(\sqrt{n}) + O((n/B)\log_{M}n)$ | $\Theta((n/B)(1+\log_{M/B}(n/B)))$ | Yes [1] |

### 5.2 Quantitative Comparison: Oblivious vs. Aware

Cache-aware algorithms know $B$ and tune to it. The price of obliviousness is small:

- **Search trees.** A cache-aware B-tree with node size $B$ achieves $\log_B N$ misses per search. The vEB layout achieves $\Theta(\log_B N)$ with a modest constant, but is *simultaneously* optimal for L1, L2, L3, and TLB page size — a tuned B-tree must pick one [2].
- **Sorting.** Brodal, Fagerberg, and Vinther engineered lazy funnel sort and compared it against the best quicksort and cache-aware mergesorts they could implement [6]: the cache-oblivious sort was *faster* than the best quicksort for in-RAM inputs and at least as fast as cache-aware proposals; on disk it dominated quicksort decisively.
- **Updates.** The dynamic CO B-tree's $O(\log_B N)$ amortized update bound matches the B-tree; the hidden constant reflects PMA density maintenance, later reduced by the adaptive PMA [3].

### 5.3 Work-Efficiency

All three constructions are *work-efficient*: funnel sort does $\Theta(n \log n)$ comparisons and the CO B-tree does $O(\log N)$ RAM operations per update — cache-obliviousness never sacrifices asymptotic work.

## 6 Limitations

1. **The replacement idealization.** Optimal offline replacement is unimplementable; the LRU-simulation theorem [1] recovers only a constant-factor guarantee under regularity, and real caches are neither fully associative nor LRU (typically 8–16-way tree-PLRU). Conflict misses — absent from the model — can dominate adversarial access patterns.

2. **The tall-cache assumption is load-bearing.** Funnel sort's optimality proof genuinely needs $M = \Omega(B^2)$ (or $M = \Omega(B^{1+\varepsilon})$ with worse constants [7]). Architectures with very large lines relative to cache — some GPU shared-memory configurations — violate it, and the bounds degrade unpredictably.

3. **Writes, prefetching, and the memory controller.** The model counts reads and writes symmetrically and ignores hardware prefetchers, write-combining buffers, NUMA locality, and TLB misses. The PMA's scattered rebalancing writes interact poorly with write-back caches despite its optimal miss count.

4. **Engineering complexity.** The dynamic CO B-tree's buffer-node construction is notoriously intricate; the simplifications [2] helped, but no mainstream database ships a cache-oblivious B-tree. In practice the *ideas* — recursive layouts, square-root decomposition — have diffused into systems more than the *algorithms* themselves.

5. **Parallelism.** The classical results are sequential. Blelloch, Gibbons, and Simhadri's *low-depth* cache-oblivious algorithms recover work- and cache-optimality with polylogarithmic span [7], but the dynamic structures remain largely sequential in their analyses.

## 7 Conclusion

Cache-oblivious algorithms deliver on an extraordinary promise: a single program, ignorant of every hardware parameter, asymptotically optimal at every level of the memory hierarchy. The van Emde Boas layout shows a static binary tree can emulate all B-trees at once [2]; the Bender–Demaine–Farach-Colton construction shows dynamism need not break this spell [3]; and funnel sort shows the sorting lower bound of the I/O model can be met without ever naming $M$ or $B$ [4][5][8]. The tall-cache assumption and the regularity condition are the modest prices of admission, and both are satisfied — with room to spare — by real hardware.

The field's deepest lesson may be methodological: *recursion at the square-root scale* is a universal adapter between an algorithm and an unknown memory hierarchy. Whether in tree layouts, merger buffers, or matrix recursion, subdividing until every scale is represented is what makes obliviousness possible. Open frontiers remain — parallel dynamic structures, write-asymmetric models for non-volatile memory, and closing the engineering gap so these optimal algorithms displace hand-tuned code in practice.
