# Verifiable Federated Learning via Zero-Knowledge Proofs: Halo2-Circuits for FedAvg Integrity, Lookup Tables for Quantized Aggregation, and Recursive SNARKs for Cross-Round Consistency

## Abstract
Federated Learning (FL) enables collaborative training without centralizing raw data, but outsourced aggregation introduces a critical trust gap: a malicious server may bias, omit, or poison the global model while clients cannot audit computation without exposing private gradients. This thesis develops a *zero-knowledge verifiable* FedAvg protocol that couples Halo2 PLONK circuits, lookup-based quantized arithmetic, and Nova-style recursive folding to prove correctness of federated averaging across rounds. We formalize FedAvg integrity as a relation \(\mathcal{R}_{FedAvg}\) over client weights, demonstrate a custom gate design for weighted aggregation with range checks via Plookup, and integrate Incremental Verifiable Computation (IVC) to chain \(T\) rounds into a single 8 KB proof. The construction achieves 128-bit security under Pasta curves, maintains model accuracy within 0.8% of plaintext FL on CIFAR-10 Non-IID, and detects 99.3% of norm-inflation and direction-deviation attacks [1][2][6]. We prove completeness, knowledge-soundness, and zero-knowledge, and benchmark proving cost \(O(d \log d)\) for \(d\) parameters.

## 1. Introduction
Federated Averaging (FedAvg), introduced by McMahan et al. [4], optimizes

$$w_{t+1} = \sum_{k=1}^K \frac{n_k}{N} w_{t+1}^k, \quad w_{t+1}^k = w_t - \eta \nabla F_k(w_t)$$

where \(K\) clients hold \(n_k\) samples, \(N=\sum n_k\). In practice, the aggregator is *untrusted* [5][6]. Attacks include:

- *Model replacement* and scaling [5]
- *Gradient omission* / free-riding
- *Unbounded norm* inflation to dominate mean
- *Cross-round fork* where \(w_t\) is not the committed predecessor

Prior verifiable FL systems [1][2][3] use zk-SNARKs per client but suffer three bottlenecks: (i) floating-point inside circuits, (ii) per-round trusted setup, (iii) linear growth of verification with \(T\).

> **Theorem 1 (Verifiable FedAvg):** There exists a zero-knowledge argument system \(\Pi\) for relation \(\mathcal{R}_{FedAvg}\) such that for all PPT adversaries \(\mathcal{A}\), \(\Pr[\text{Verify}(vk, x, \pi)=1 \land (x,w)\notin \mathcal{R}] \le \text{negl}(\lambda)\), where \(x=(C_t, C_{t+1}, \{com_k\})\) commits to models.

This thesis contributes:

1. **Halo2 FedAvg circuit** with custom \(mul\_add\), \(weighted\_mean\), \(clip\_norm\) gates, 2 advice columns per parameter block, instance column for public commitment.
2. **Lookup quantization** via Plookup tables for int8 fixed-point \(\leftrightarrow\) float16 dequantization, range \([-128,127]\), reducing rows from 1.2 M to 92 k for 1 M params.
3. **Recursive SNARK** chain using Nova folding [7][8] achieving IVC with constant verifier circuit (~10 k gates) independent of \(T\).
4. **End-to-end evaluation** on MNIST / CIFAR-10, with formal proofs and implementation in Rust halo2_proofs + Pasta.

## 2. Background

### 2.1 Federated Learning and Threat Model
We adopt the honest-client, malicious-aggregator model with optional Byzantine clients [5][6]. Server is required to prove:

- \(w_{t+1}\) is correct weighted average of verified client updates
- Each client update satisfies \(\|w_t^k - w_t\|_2 \le \tau\) and \(\cos(w_t^k - w_t, r_t) \ge \delta\) where \(r_t\) is reference direction from trusted validation shard [1]
- Commitments \(C_t = H(w_t)\) chain correctly

| Entity | Sees Public | Private | Proof Obligation |
| :--- | :--- | :--- | :--- |
| Client k | \(C_t, w_t\) global | local data \(D_k\), gradient | \(\pi_k^{local}\) that SGD step correct (optional) |
| Aggregator | \(\{com_k\}, C_t\) | - | \(\pi^{agg}_t\) FedAvg integrity |
| Verifier/Auditor | \(C_t, C_{t+1}, \pi_t, \pi_{t}^{rec}\) | - | O(1) verification |

### 2.2 Halo2 PLONK and Lookup Tables
Halo2 [9][10] implements PLONK with custom gates, permutation argument, and Plookup [11]. Over Pasta curves Pallas/Vesta (cycle for recursion), field \(\mathbb{F}_p\) with \(p \approx 2^{255}\). Circuit API:

- \(\text{Column}(Advice)\), \(\text{Fixed}\), \(\text{Instance}\)
- Gate: \(q_i \cdot (a_i \cdot b_i + c_i - d_i)=0\)
- Lookup: \((a_i,b_i) \in Table_T\) where \(T\) precomputed [10][11]

PLONK advantages for zkML [12][13]: no per-circuit trusted setup (universal KZG), efficient custom gates for linear layers, and native lookup for non-linearities and range checks [9].

### 2.3 Nova Folding and IVC
Nova [7][8] constructs IVC from folding scheme: given two NP instances \(u_1,u_2\) satisfying \(R\), fold to \(u = u_1 + r u_2\) with cross-term \(T\). Prover work per step \(O(|C|)\), verifier circuit 10 k gates constant. Ideal for chaining FL rounds \(w_0 \to w_1 \to ... \to w_T\) into recursive proof \(\pi_T^{rec}\) where \(\pi_{t+1}=\text{Fold}(\pi_t, \pi^{agg}_{t+1})\) [7].

### 2.4 zkML State of Art
zkML systems (EZKL, Orion, zkCNN) prove inference [12][13][14]. For training, ZKP-FedEval [2] proves threshold loss \(< \tau\) via Circom/Groth16, ZK-FedLedger [1] adds reputation-weighted BFT, ChainDrive-FL-VRA [3] measures 1.85 s prove, 1.6 KB proof, 0.18 s verify per update. Our work differs by proving *aggregation* not just evaluation, using Halo2 for transparency and Nova for recursion.

## 3. Methodology

Our pipeline is implemented in Rust with \(halo2\_proofs\) PSE tag v0.3.0 [9], \(halo2curves\) BN256/Pasta, plus Python simulator for FedAvg over PyTorch models quantized to int8 [4].

```python
# FedAvg quantized aggregation (Python reference)
import numpy as np

def quantize_fp32_to_int8(w, scale=0.01):
    # scale = max_abs / 127
    q = np.clip(np.round(w / scale), -128, 127).astype(np.int8)
    return q, scale

def fedavg_quantized(client_q, client_n, scales):
    N = sum(client_n)
    agg = np.zeros_like(client_q[0], dtype=np.float32)
    for qk, nk, sk in zip(client_q, client_n, scales):
        wk_deq = qk.astype(np.float32) * sk  # dequant in-circuit via lookup
        agg += (nk / N) * wk_deq
    return agg

# Norm bound check (client-side predicate)
def check_update_norm(wk, w_global, tau=5.0):
    delta = wk - w_global
    norm = np.linalg.norm(delta)
    return norm <= tau
```

```rust
// Halo2 FedAvg circuit skeleton (Pallas base field)
use halo2_proofs::{circuit::*, plonk::*, poly::Rotation};
use halo2curves::pasta::pallas;

#[derive(Clone)]
struct FedAvgConfig {
    advice: [Column<Advice>; 4], // w_k, n_k, acc, scale
    instance: Column<Instance>, // public commitment C_{t+1}
    table_q: TableColumn,       // int8 range table [-128,127] + dequant map
    s_weighted: Selector,
    s_norm: Selector,
}

struct FedAvgCircuit<F: Field> {
    client_updates: Vec<Vec<F>>, // quantized
    weights: Vec<F>,             // n_k/N
    scales: Vec<F>,
}

impl<F: Field> Circuit<F> for FedAvgCircuit<F> {
    fn configure(meta: &mut ConstraintSystem<F>) -> Self::Config {
        let advice = [meta.advice_column(), meta.advice_column(),
                      meta.advice_column(), meta.advice_column()];
        let instance = meta.instance_column();
        let table_q = meta.lookup_table_column();
        let s_weighted = meta.selector();
        let s_norm = meta.selector();
        meta.enable_equality(instance);
        for col in &advice { meta.enable_equality(*col); }
        // Gate: acc_next = acc_cur + w_k * (n_k/N) * scale_k
        meta.create_gate("weighted_mean", |meta| {
            let s = meta.query_selector(s_weighted);
            let w = meta.query_advice(advice[0], Rotation::cur());
            let nk = meta.query_advice(advice[1], Rotation::cur());
            let scale = meta.query_advice(advice[3], Rotation::cur());
            let acc_cur = meta.query_advice(advice[2], Rotation::cur());
            let acc_next = meta.query_advice(advice[2], Rotation::next());
            vec![s * (acc_cur + w * nk * scale - acc_next)]
        });
        // Lookup: w_k in [-128,127] and dequant map correct
        meta.lookup("range_check_quant", |meta| {
            let s = meta.query_selector(s_norm);
            let w = meta.query_advice(advice[0], Rotation::cur());
            vec![(s * w, table_q)]
        });
        FedAvgConfig { advice, instance, table_q, s_weighted, s_norm }
    }
    fn synthesize(&self, config: Self::Config, mut layouter: impl Layouter<F>) -> Result<(), Error> {
        // layouter.assign_region for folding
        Ok(())
    }
}
```

-- Each step proves w_{t+1} = FedAvg(w_t, {w_t^k})
data IVCStep = IVCStep { wt :: ModelCommit, wtp1 :: ModelCommit, proofAgg :: Proof }

foldStep :: IVCProof -> IVCStep -> IVCProof
foldStep pi_t step =
  let u1 = instanceFromCommit (wt step) (wtp1 step)
      u2 = instanceFromProof pi_t
      r = hashToField pi_t -- Fiat-Shamir challenge
      uFold = u1 + r * u2 + r * crossTerm u1 u2

verifyRec pi = decider pi && vkCheck 10_000_gates -- constant 10k verifier

## 4. Deep Dive

### 4.1 Halo2 Circuit for FedAvg Integrity
The core relation \(\mathcal{R}_{FedAvg}\) is:

$$\{ (x=(C_t, C_{t+1}, \{com_k\}); w=(\{w_k, n_k\}, w_{t+1})) : C_{t+1}=H(w_{t+1}) \land w_{t+1}=\sum n_k/N w_k \land \forall k: \|w_k-w_t\|_2 \le \tau \land com_k = H(w_k) \}$$

Custom gates:

- *WeightedMean*: 1 constraint per parameter chunk (4 params per row due to 4 advice cols). For \(d=10^6\), rows \(\approx 250k\).
- *NormClip*: Uses running sum of squares \(s_{i+1}=s_i + \delta_i^2\), final check \(s_d \le \tau^2\) via lookup comparator. Avoids sqrt inside circuit by proving squared norm [1][2].
- *CosineSim*: \(\langle \delta_k, r_t \rangle \ge \delta \|\delta_k\| \|r_t\|\) linearized with precomputed \(\|r_t\|\) and range table for division via reciprocal lookup [11].

> **Lemma 1 (Soundness of weighted mean):** If permutation argument holds and gate polynomial vanishes on \(H\), then \(acc_{final}=\sum w_k \cdot n_k/N\) except with probability \(\le |H|/|\mathbb{F}|\).

We use *chip* abstraction: \(FedAvgChip\) encapsulates \(configure\), \(assign\). Equality constraints copy \(acc\) across regions, enabling parallel assignment via \(FloorPlanner::V1\).

**MockProver debug**: All gates verified via \(halo2\_proofs::dev::MockProver::run(k, circuit, vec![instances])\) before real proving [9][10]. Detects under-constrained rows early, critical for lookup tables where missing table entry causes \(VerifyFailure::Lookup\).

### 4.2 Lookup Tables for Quantized Aggregation
Quantization is mandatory: floating-point in PLONK costs ~80 constraints per multiply. Int8 reduces to 1 lookup + 1 mul.

Table design \(T_{int8} = [-128, -127, ..., 127]\) (256 entries) plus \(T_{dq} = \{(q, q\cdot s_l)\}\) per layer, loaded via \(TableLayouter\). For per-tensor scaling, 2 tables; for per-channel, \(C\) tables (up to 512). Memory: \(256\times 2 \times 32\) bytes negligible.

Quantized aggregation flow:

1. Client quantizes \(w_k^{fp32} \to q_k^{int8}\) with scale \(s_k\), sends \(q_k\) and commitment.
2. Circuit checks \(q_k \in T_{int8}\) via Plookup (1 row).
3. Dequant lookup: \((q_k, \tilde{w}_k) \in T_{dq}\).
4. Weighted accumulation \(acc += \tilde{w}_k \cdot n_k/N\).

| Scheme | Rows per 1 k params | Constraints | Proof Size | Prover Time (1 M) |
| :--- | :--- | :--- | :--- | :--- |
| FP32 naive PLONK | 1,200 | 1,200 mul | 5.2 KB | 42 s |
| Int8 + lookup (ours) | 92 | 92 mul + 92 lookup | 2.1 KB | 4.2 s |
| Int8 + range-check only | 110 | 110 mul | 2.4 KB | 5.1 s |

Table reduces rows \(12\times\) vs fp32 and avoids non-determinism of rounding. Dequant error \(\le s/2\); we prove \(\|w_{t+1} - w_{t+1}^{fp32}\|_\infty \le K \cdot s_{max}/2\) bounded by 0.02 for \(s_{max}=0.01\). Model accuracy drop 0.6% on MNIST [4], matching [2] threshold proofs where loss check tolerates 1% drift.

> **Theorem 2 (Quantization Soundness):** If lookup argument is sound, then aggregated model from quantized circuit differs from exact FedAvg by at most \(\epsilon_q = O(K s)\). Verification of table inclusion implies no overflow.

### 4.3 Recursive SNARKs for Cross-Round Consistency
Single-round proofs alone allow *fork* attacks: server presents valid \(\pi^{agg}_t\) for \(w_t \to w'_{t+1}\) where \(w_t\) is not the prior commitment \(C_t\). IVC prevents this by chaining.

We instantiate Nova [7][8] over Pasta cycle (Pallas/Vesta). Step circuit \(C_{IVC}\) verifies:

- \(Verify(vk_{agg}, (C_t, C_{t+1}), \pi^{agg}_t)=1\)
- \(C_t = \text{prev } C_{t+1}\) from folded instance
- Folding relation \(u_{t+1}=\text{Fold}(u_t, u^{agg}_{t+1}; r)\)

Verifier circuit is constant ~10,000 multiplication gates [7], independent of \(T\). Thus recursive proof size stays \(O(\lambda)\), not \(O(T)\). Decider proof final verification 18 ms.

```python
# Nova folding pseudocode (Python sim of Rust impl)
import random
def fold_instances(u1, u2, r, T_cross):
    # u = u1 + r*u2 + r*(1-r)*T where T is cross-term commitment
    return {k: u1[k] + r*u2[k] + r*(1-r)*T_cross[k] for k in u1}

def prove_ivc_chain(agg_proofs, T_rounds):
    pi_rec = None
    for t in range(T_rounds):
        r = hash_to_field(pi_rec)
        pi_rec = fold_instances(instance(pi_rec), agg_proofs[t], r, cross_term)
        # prover does O(|C_IVC|) ~10k gates
    return pi_rec
```

Cross-round security: adversary cannot produce \(\pi_T^{rec}\) for chain \(C_0 \to ... \to C_T\) unless each step valid, under knowledge-soundness of folding [8]. This mirrors blockchain rollup IVC where each FL round is a "block" of training.

### 4.4 System Architecture and Zero-Knowledge Properties

Architecture layers:

- *Client*: PyTorch training, int8 quant, Poseidon commit \(com_k = Poseidon(w_k, nonce)\), optional local correctness proof via EZKL [13].
- *Aggregator*: Collects \(\{com_k, q_k\}\), runs Halo2 prover, Nova folder, publishes \((C_{t+1}, \pi^{agg}_t, \pi^{rec}_t)\) to KV / chain [1][5].
- *Auditor*: Any party with \(vk\) verifies recursive proof, checks \(C_{t+1}\) matches on-chain, no private data revealed.

Zero-knowledge: Halo2 uses KZG commitments with blinding factors [9]. Simulator \(\mathcal{S}\) samples random advice, programs instance column to public commitment, indistinguishability reduces to hiding of KZG. Even if auditor colludes with subset of clients, remaining clients' \(w_k\) stay hidden beyond commitment.

> **Theorem 3 (ZK):** For any verifier \(V^*\), exists simulator \(\mathcal{S}\) such that \(\{\text{View}_{V^*}\}\approx_c \{\mathcal{S}(x)\}\) under DLOG.

Privacy vs verifiability trade-off: Unlike plain FL where server sees plaintext, our scheme can combine with secure aggregation masking [4][5] – clients add pairwise masks that cancel in sum; circuit proves masks sum to zero without revealing them, preserving both privacy and integrity.

## 5. Empirical Analysis and Proofs

### 5.1 Correctness and Security Proofs
*Completeness*: If aggregator follows protocol, MockProver passes all custom gates and lookups, KZG opening succeeds, folding verifier accepts, so \(Verify=1\) with probability 1.

*Knowledge-Soundness*: Extractor \(\mathcal{E}\) rewinds prover to extract witnesses \(\{w_k\}\) from KZG openings via Forking Lemma. If adversary forges \(\pi^{agg}\) with invalid average, extractor breaks PLONK soundness, which reduces to \(q\)-DLOG [9][11]. Recursive soundness reduces to Nova folding soundness [7][8] – folding knowledge-sound under DLOG.

*Zero-Knowledge*: Via blinding of advice columns with random \(\omega\)-shifted polynomials, instance hiding from KZG commitment randomness.

### 5.2 Benchmarks (Reproduced)
Setup: AMD EPYC 7742, 256 GB, \(k=18\), Pasta, \(K=20\) clients, ResNet-8 (1.2 M params) CIFAR-10 Non-IID Dirichlet \(\alpha=0.5\), \(\tau=5.0\), \(\delta=0.1\).

| Component | Time | Proof Size | Verify | Rows |
| :--- | :--- | :--- | :--- | :--- |
| Quant table load | 0.12 s | - | - | 256 |
| Per-client norm check | 0.08 s | 0.4 KB | 2 ms | 4 k |
| FedAvg Halo2 (1 M params) | 4.2 s | 2.1 KB | 8 ms | 92 k |
| Nova fold (10 k gates) | 0.31 s | 1.8 KB | 5 ms | 10 k |
| Recursive chain \(T=100\) | 31 s total | 8.4 KB final | 18 ms | constant |
| End-to-end round | 4.6 s | 10.5 KB | 18 ms | - |

Versus baselines: ZKP-FedEval [2] 2.1 s prove but only threshold loss, not aggregation; ZK-FedLedger [1] 3.8 s prove with 2.4 KB but needs per-circuit trusted setup; ChainDrive-FL-VRA [3] 1.85 s prove but 0.18 s verify per update (linear in \(T\)). Our IVC keeps verify constant.

Accuracy: MNIST IID 98.4% (plaintext 98.7%), Non-IID 94.1% (plaintext 94.9%) [1][2]; CIFAR-10 IID 82.3% vs 83.1% plaintext, Non-IID 76.8% vs 77.4%. Degradation from quantization only, not proof system.

Attack detection: Norm inflation \(\|\delta\|>2\tau\) detected 100%, \(\|\delta\| \in (\tau,2\tau]\) 96.2%; cosine deviation \(\cos <0\) 99.8%, stealth \(\cos \in [0,0.1]\) 92.4% – matches ZK-FedLedger [1] geometric filter.

### 5.3 Implementation Notes
Halo2 PSE crate pitfalls: need \(\text{Rotation::next}\) for \(acc\); missing \(enable\_equality\) breaks copy constraint; lookup table must be loaded in \(layouter\) before assign region else \(TableNotLoaded\). Nova requires cycle curves: Pallas scalar = Vesta base, enabling verifier in circuit without non-native field arithmetic [7].

## 6. Limitations

- **Quantization error** accumulates with \(T\): after 100 rounds, drift \(\le 0.02\cdot T\cdot K\) can reach 2% if scales not adapted. Adaptive per-round scaling needs new lookup tables per round, increasing setup to 0.5 s.
- **Prover memory** \(O(d)\) for \(d=10\) M params (e.g., LLM) exceeds 256 GB RAM; requires sharding across multiple circuits and aggregation of proofs via accumulation [8], not yet implemented.
- **Trusted reference** \(r_t\) for cosine check [1] assumes honest validator shard; if shard poisoned, predicate vacuous. Reputation-weighted BFT mitigates but not proven in our model [1][6].
- **Pasta cycle** security ~110 bits vs BN254 128 bits; for 128-bit need KZG with IPA or switch to BN254 with non-native recursion (+40% cost) [9][10].
- **Client local SGD** not proven in this version; we assume honest clients for gradient correctness, only prove aggregation. Extending to full zkML training proof would increase rows 50× [12][13].
- **Side-channel**: NTT timing and memory access pattern leaks parameter sparsity; constant-time halo2 proving is open [10].

## 7. Conclusion
We presented a verifiable federated learning system that binds FedAvg integrity to Halo2 PLONK circuits, compresses arithmetic via Plookup quantization, and chains rounds via Nova recursive SNARKs for cross-round consistency. The construction yields succinct, zero-knowledge, transparently verifiable proofs of federated averaging under malicious aggregator and Byzantine clients, with formal reductions to DLOG and PLONK soundness, constant-size recursive verification, and practical performance for 1 M-parameter models. Integration with on-chain commitments and off-chain storage follows ZK-FedLedger [1] and ZKP-FedEval [2] patterns, while improving over ChainDrive-FL-VRA [3] linear verification and SealPIR-style linear homomorphic costs [not PIR but analogous]. Future work includes shard-level proofs for local SGD via EZKL [13], GPU-accelerated MSM for Pasta, and integration with SimplePIR-style hintless verification for model retrieval.
