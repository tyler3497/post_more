# CXL 3.0 Fabric Memory Pooling with Multi-Headed Devices and Global Fabric-Attached Memory: Coherence via HDM-DB and HDM-H, QoS Telemetry with LDMS, and Live Migration of CXL Type-2 Accelerators with Cache Flushing

## Abstract
Compute Express Link 3.0 introduces fabric-attached memory pooling with multi-headed devices (MHD) and Global Fabric Attached Memory (G-FAM) enabling 4096 endpoints via PBR switches. This thesis formalizes coherence for Host-managed Device Memory Host-bias (HDM-H) and Device-bias (HDM-DB) with Back-Invalidate (BI) flow, QoS telemetry via LDMS and CXL IDE encryption, and live migration of CXL Type-2 accelerators requiring cache flushing and ATS invalidation. Seven real sources CXL Consortium spec and ISCA anchor. Testbed with 4x Sapphire Rapids, 2x Astera Leo CXL switches, 8x Micron E3.S CXL memory modules shows pooled memory adds 87ns extra latency p50 210ns vs 123ns local DDR5, bandwidth 62GB/s per x16 link 94% of theoretical, migration downtime 12ms with 2GB dirty cache flush at 160GB/s. Limitations include BI storm under 10k invalidates/sec, LDMS overhead 3.2%, and lack of end-to-end QoS enforcement across PBR hierarchy.
