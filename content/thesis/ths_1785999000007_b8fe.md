# Homomorphic Secret Sharing and Function Secret Sharing: Distributed Point Functions, Pseudorandom Correlation Generators, and Lightweight 3-Party Computation for Private Information Retrieval

## Abstract
We present a unified treatment of **Homomorphic Secret Sharing (HSS)** and **Function Secret Sharing (FSS)**, focusing on the central role of **Distributed Point Functions (DPFs)**, their multi-party extensions, and the duality that enables **Pseudorandom Correlation Generators (PCGs)** and **lightweight 3-party computation** for **Private Information Retrieval (PIR)**. We formalize syntax and security for 2-party and N-party FSS/HSS, survey optimal PRG-based DPF constructions with key size $n\lambda + O(\lambda)$ for domain $\{0,1\}^n$, and detail recent breakthroughs constructing N-party DPF/HSS/PCG from Learning Parity with Noise (LPN) and Multivariate Quadratic (MQ) assumptions without resorting to FHE or indistinguishability obfuscation. We then give a modular reduction from 2-server keyword-PIR and PIR-by-keywords to DPF evaluation linearity, and show how PCGs instantiate *silent preprocessing* for correlated randomness (OT, VOLE, Beaver triples) with sublinear communication. A 3-server balancing technique yields optimal download rate with client-to-server communication $O(N d^3 \lambda)$ for $ \lambda^d $-size databases, and enables lightweight 3PC with $O(s/\log^* s)$ per-party cost. Proofs, lower bounds, and open problems in full-threshold DPF are discussed.

## 1 Introduction
The tension between *compression* and *privacy* underlies modern secure computation. Additive secret sharing of a vector $s \in \mathbb{G}^N$ classically requires $N\log|\mathbb{G}|$ bits per share, optimal under perfect secrecy. Once computational secrecy is permitted, a **Pseudorandom Generator (PRG)** $G:\{0,1\}^\lambda \to \mathbb{G}^N$ allows halving share size but no better for arbitrary $s$ [1]. If $s$ is *sparse* — weight-1, i.e., point function $f_{\alpha,\beta}(x)=\beta$ if $x=\alpha$ else $0$ — exponential compression becomes possible. This insight births **Distributed Point Functions (DPFs)** [1][2].

Concurrently, **Homomorphic Secret Sharing** reverses roles: input $x$ shared, function $f$ public; parties evaluate $f$ locally on shares to obtain additive shares of $f(x)$ [3][5]. HSS can be viewed as distributed FHE where non-collusion replaces heavy lattice ops, enabling DDH, DCR, LPN, MQ assumptions not known to imply FHE [2][3][6].

> **Theorem 1.1 (Informal):** Under LPN with dimension $n$, $2n$ samples, noise rate $n^{\epsilon-1}$ and MQ with $n$ variables $n^{1+\delta}$ equations, there exist for any constant $N$: (i) $N$-party DPF with key size $\tilde O(\lambda n)$, (ii) $N$-party HSS for XOR-AND of constant-degree polynomials with negligible error, (iii) $N$-party PCG for degree-$d$ correlations, and (iv) $N$-server PIR for $\lambda^d$-size databases with client communication $O(N d^3 \lambda)$ and optimal download rate [2].

## 2 Background / Preliminaries

### 2.1 Secret Sharing Vocabulary
Let $\mathbb{G}$ finite Abelian group. **Additive $m$-sharing** of $s\in\mathbb{G}$ is $s_0...s_{m-1}$ random conditioned on $\sum s_i = s$. PRG $G: \{0,1\}^\lambda \to \{0,1\}^{2\lambda}$ doubling. By iteration stretch $\lambda \to poly(\lambda)$. LPN$_{n,\tau}$: distinguish $(A, A s + e)$ vs uniform, $e\leftarrow Ber(\tau)$. MQ$_{n,m}$: random quadratics $p_i$, distinguish $(p_i,p_i(s))$ from random [2].

### 2.2 Function Classes
- Point $P_{\alpha,\beta}: \{0,1\}^n \to \mathbb{G}$
- Interval $I_{[a,b]}$, $t$-point $M = \sum_{i=1}^t P_{\alpha_i,\beta_i}$
- Polynomials degree $d$, branching programs, NC1, RMS programs [3][6].

### 2.3 PIR Syntax
$M$-server IT-PIR: DB $D\in\{0,1\}^N$, client $\alpha$. Protocol $(Q,A,R)$: $Q$ generates $q_i$, $A(i,D,q_i)=a_i$, $R(a_1..a_M)=D_\alpha$. Security $t$-private: $\forall T,|T|\le t$, $(q_i)_{i\in T}$ indep of $\alpha$. PIR from DPF Lemma 2.1: Any 2-party DPF yields 2-server PIR with total comm $2\cdot(|k_{DPF}|+|a|)$ and server $N\cdot Eval$ [1].

## 3 Methodology / Formalism

### 3.1 DPF Syntax
- Gen$(1^\lambda,\alpha,\beta)\to (k_0,k_1)$. Size $|k_b| = n(\lambda+2)+ \lceil\log|\mathbb{G}|\rceil + O(\lambda)$ [1].
- Eval$(b,k_b,x)\to y_b$ s.t. $\forall x: y_0+y_1 = P_{\alpha,\beta}(x)$.
Security: simulator $Sim(1^\lambda,\mathcal{D},\mathbb{G})$ indistinguishable.

### 3.2 FSS Syntax
Gen$^F(1^\lambda,f)\to (k_1..k_m)$, Eval$^F(i,k_i,x)\to s_i$, $\sum s_i=f(x)$. DPF is FSS for point class. Interval FSS known PRG-only [1].

### 3.3 HSS Syntax
- Share$(1^\lambda,x)\to (x^{(1)}..x^{(N)})$
- Eval$(i,f,x^{(i)})\to y^{(i)})$, Rec$ = f(x)$ additive $\sum y^{(i)}$ [3]. Succinctness independent of $|f|$ else trivial via OT. PK-HSS vs MK-HSS [6] reusable encodings under CRS.

### 3.4 PCG Syntax
For $Y=C(X)$:
- Gen$\to(k_0,k_1)$
- Expand$(k_b)\to(r_b,o_b)$ where sum satisfies correlation, e.g., OT $c=a_{choice}$, VOLE $c=a\cdot b$ over field [4][5]. Security programmable.

## 4 Deep Dive

### 4.1 Distributed Point Functions - Tree-Based Construction and Full-Threshold Barriers
The PRG-based 2-party DPF [1] builds on GGM puncturable PRF tree. Seeds $s_0^{(0)}, s_1^{(0)}$ random. Expand $G(s)=(s^L\|t^L,s^R\|t^R)\in\{0,1\}^{2(\lambda+1)}$. If away from $\alpha$, $t$-bits force correction; on path to $\alpha$, remain independent. Correction word $CW^{(l)}=(s_0^L\oplus s_1^L, t_0^L\oplus t_1^L\oplus1\oplus\alpha_l,...)$ plus payload correction for $\beta$ [1].

Invariant: If $x\neq\alpha$ prefix divergence, $s_0^{(l)}=s_1^{(l)}$, $t_0=t_1$, cancellations; if $x=\alpha$ prefix, seeds look independent.

Key size $n(\lambda+2)+\log|\mathbb{G}|$ bits [1][2]. Beats $\Omega(\sqrt N)$ IT lower bound. Full-threshold $N$-party DPF far harder: PRG-only $O(\sqrt N)$ for $N=3$, open $poly(n)$ for $N\ge3$ [1]. Recent [2] sidesteps via LPN+MQ nesting: external 2-party DPF shares internal DPF Eval function $g_k^{(internal)}(y)$. Internal shares $P_{\alpha}$; external homomorphically evaluates Gen/Eval inside HSS class $F^*$ including PRG ops. Doubling party count but degree managed by MQ [2].

Python intuition:
```python
def dpf_eval_share(k_b, x, CWs):
    s, t = k_b.seed, k_b.tbit
    for l in range(n):
        s0L, t0L, s0R, t0R = G(s)
        if t:
            sL = xor(s0L, CWs[l].sL)
        s = sL if x[l]==0 else sR
        t = t0 ^ (t*CW[l].t)
    return ((-1)**b)*Convert(s) + t*CW_last
```
Aggr for keyword PIR: server $i$ computes $y_i = \sum_{j} Eval(k_i,w_j)\cdot D_j$; client $y_0+y_1$ picks $\beta$.

> **Lemma 4.1:** For all $\alpha,x$, Eval$(0,k_0,x)+Eval(1,k_1,x)=\beta\cdot[x=\alpha]$ over $\mathbb{G}$.

### 4.2 Homomorphic Secret Sharing - From RMS Programs to Constant-Degree Polynomials
HSS classes:
- **DDH 2-party** [BGI16] RMS / branching prog, distributed DLog small space, $1/poly$ correctness.
- **DCR/MK-HSS** [6]: Each $x$ enc as Paillier/Jurik under own key; server $x_0\cdot x_1$ via $N$ mod. Optimization $N^4\to N^2$, 45x speedup 5.0ms vs 224.6ms [6].
- **LPN+MQ MP-HSS** [2]: Eliminates share conversion stuck at 2-party (proven inherent [BDIR18]). [DIJL23] sparse LPN eliminates conversion but inverse-poly error. Nesting+MQ negl error.

Blueprint [2]: internal 2-HSS for deg-d polys Share internal, external HSS for $F^*\ni g^*: Share\mapsto Eval(f,Share)$ (degree relates to internal complexity), share each internal share again $x_{b0,b1}\leftarrow Share^*(x_{b0})$, $N\times M$ parties hold shares, Eval composes $Eval^*(Eval(f,.))$. Iterated nesting $N$-party $poly(\lambda)$ at log* overhead.

| Assumption | Parties | Class | Error | Ref |
|---|---|---|---|---|
| DDH | 2 | RMS / branching | $1/poly$ | [3] |
| DCR+SEI | N (MK) | RMS | negl | [6] |
| Sparse-LPN | N | deg $\log/\log\log$ | $1/poly$ | DIJL23 |
| LPN+MQ | any poly | XOR-AND $O(1)$ | negl | [2] |

> **Theorem 4.2 (HSS correctness):** For any $x$, $f$, $\Pr[Rec(Eval(i,f,Share_i(x)))=f(x)] \ge 1-negl(\lambda)$ [2][6].

### 4.3 Pseudorandom Correlation Generators - Silent OT and VOLE from LPN
Goal: $M=poly(\lambda)$ instances $(r_i,C(r_i))$ with comm $o(M)$. Template [4][5][6]: Sample sparse $e\in\mathbb{F}^n$ $t$-sparse noise (LPN secret), compute $b=A s+e$, seeds party0 $(s_0,e_0)$, party1 $(s_1=A s+e...)$ such that sum to correlation. For **OT**: $s_0\oplus s_1=r_{choice}$; **VOLE**: $c=a\cdot b+\Delta$.

Silent OT ext [4]: stretch via PRG to length N, Expander $u=E\cdot t_b$ replicate, prefix-accumulate $w_i=sum_{j<=i}u_j$, output VOLE/OT from $w$.

**Expand-Accumulate Codes** [5] cache-friendly parallel linear time quasi-linear $O(N\log N)$ vs polynomial interpolation.

**Ring-LPN** [6] ring $R_q=F_q[X]/(X^n-1)$ structured $A$, NTT $O(N\log N)$.

Programmable PCG via QA-SD [5] OLE over any $F_q$, $q>2$, bridging field size restriction.

> **Lemma 4.3:** Under LPN, Ring-LPN, exists PCG for $N$ OLE with seed $O(\lambda\log N)$, compute $O(\lambda N)$ [6][5].

Haskell sketch:
```haskell
type Domain = [Bool]
type Gro = Integer

dpfEval :: Key -> Domain -> Gro
dpfEval key x = go 0 (keySeed key) (keyCtrl key) CWs
  where go l s t [] = convert s + t* cwFinal
        go l s t (cw:rest) = let (sL,tL,sR,tR)=prg s in go (l+1) s' t' rest
```

MPC: GMW needs $O(|C|)$ OTs; PCG exchange $O(\lambda)$ seeds then silent local OTs reducing WAN 10-100x [4].

### 4.4 Lightweight 3-Party Computation and PIR
Two PIR deployments:
1. Replication 2-server IT-PIR via DPF $O(\lambda\log N)$ comms, server $\Theta(N)$ linear pass mandatory (lower bound) [7] subpoly $n^{O(\sqrt{\log\log n/\log n})}$ Matching Vector Codes but DPF-PIR practical.
2. Lightweight 3PC: client secret-shares query to 3 servers $S_0,S_1,S_2$ any 1 corrupt but 2 not colluding. Using HSS servers answer wo client interaction.

Protocol DPF-keyword PIR [1] ext to 3PC [2]: client $\alpha$, DB $D:W\to V$ held by servers, client $(k_0,k_1)\leftarrow DPF.Gen(\alpha,1)$, mask $r$, send $k_0$ to $S_0$, $k_1$ to $S_1$, $r$ to $S_2$. Multiplicative DPF degree $(m-1)/t$ eval [1 Sec III-B] allows product shares $t$-privacy $m$ servers.

Optimal rate 3-server PIR: [2] obtains $N$-server PIR for $N^d$ size DB client-to-server $O(N d^3\lambda)$ optimal rate 1-negl. Block size $\lambda$ code achieves capacity. $M=3$, $O(3 d^3\lambda)$ beats $O(\sqrt N)$.

Lightweight 3PC: MK-HSS [6] three parties $A,B,C$ inputs $x_A,x_B,x_C$ each enc under indep keys via CRS crs, exchange simultaneous $pk_i,Enc_{pk_i}(x_i)$, then locally compute $f(x_A,x_B,x_C)$ as subtractive shares $y_i$, reconstruct addition. No further rounds. Reusable encodings.

## 5 Empirical Evaluation / Proofs / Analysis

### 5.1 Key Size Analysis and Lower Bounds
Optimal 2-party DPF lower bound $\Omega(n\lambda)$ [1]: Any DPF compressing $N=2^n$ point funcs into $o(n)$ bits would imply PRG stretch $\lambda$ to $2^n$ with shorter key than $n\lambda$, contradiction. Construction matches additive $O(\lambda)$. Multi-party full-threshold IT DPF $\Omega(\sqrt N)$ share size [BGI16].

Performance single core i7-1185G7 [6]:

| Operation | Theoretical | Optimized | Speedup |
|---|---|---|---|
| Homomorphic Mul ($mod N^4$) | 224.6 ms | 5.0 ms ($mod N^2$) | 44.9x |
| Geolocation KE 2pc | 28.4 s | 0.92 s | 30.8x |
| Fuzzy PAKE 8-word | 18.1 s | 0.61 s | 29.7x |

PCG EA-code $2^{20}$ OTs seed 16KB exp 2.3sec 4 cores vs 12sec [BGI19] polynomial-interp, cache misses 4x [5].

### 5.2 Security Proofs (Sketch)
**2-party DPF security**: Sim samples uniform seeds random $CW$s, hybrid over levels replace $G(s^{(l)}_{\neg Keep})$ random via PRG security, randomize correction hide $\alpha$ bit. After $n$ hybrids distribution indep $\alpha$. Payload $\beta$ hidden final OTP group element.

**HSS security (simulation)** [2]: leakage $n$ only. Sim for subset $T$ random shares same length indistinguishability reduces to LPN distinguishing $(A,As+e)$ uniform and MQ $p_i(s)$ random. Error negl via noise flooding modulus $>B\cdot2^\lambda$.

**PCG security**: Programmable PCG reduction to LPN: Expand $w=As+e$ looks random given $s$ unknown $e$ sparse hides positions. Correlation robustness hash $H$ (CRH) OT conversion ensures $H(w)$ pseudorandom.

> **Theorem 5.1:** If LPN$_{n,cn}^{(regular)}$ and MQ$_{n,n^{1+\delta}}$ hold for consts $c,\epsilon,\delta>0$, constructions Sec 4 secure PPT [2].

> **Lemma 5.2:** PCG programmable security implies MPC silent preprocessing secure with $o(N)$ communication [4].

### 5.3 PIR Rate Optimality and Sublinear MPC
Download rate $=|D_\alpha|/\sum|a_i|$. Optimal 1-o(1) when $|a|>>\lambda$. [2] block $\lambda$ code: Encode $D$ into $\lambda$-bit blocks answers additive shares blocks client linear rec adding $M$ shares redundancy ECC vanishes block $>>\log N$.

Sublinear MPC: Using $N$-HSS circuit $C$ size $s$, $N$ parties per-party comm $O(s/\log^* s)$ [2], improving $O(s/\log s)$ [BGI16] and $O(s/\log\log s)$ [DIJL23]. Reason HSS const-deg polys evaluate layered Bool circuit fan-in 2 grouping RMS size $\log s$, repeated stacking iterated log factor.

## 6 Limitations & Future Work

* **Full-threshold 10+ parties barrier**: Nesting yields $N$-party HSS for constant $N$ but party count poly($\lambda$) with $\log^* s$ overhead; superpoly LPN needed $poly(\lambda)$ MPC [2]. Removing superpoly assumption achieving $N=\lambda$ poly LPN remains open.
* **Inverse-poly vs negl correctness**: Early DDH HSS $1-1/poly$, parallel repetition blows share size $O(\lambda/error)$. [2] negl correctness relies CRT modulus switching increasing compute 5-10x. Tighter noise analysis to reduce modulus $N^2$ to $N$ w/o SEI assumption [6].
* **PIR comp cost**: 2-server IT-PIR linear scan $\Theta(N)$ per query optimal. $N=2^{30}$ ~1B AES ops ~0.5sec but repeated amplify. Sublinear-time PIR preprocessing [eprint 2025/2008] online scan $N^{0.82}$ quasilinear storage $O(N^{1+0.5\sqrt{\log N}})$ but comm $0.31poly$ large.
* **Quantum resistance**: DDH,DCR classical; LPN,MQ post-quantum plausible but QA-SD attack [eprint 2025/892] broke some QA-SD PCG small fields; resilient larger fields $q>2^{10}$ or ring-LPN fallback [eprint 2025/169]. Need standardization LPN params PCG like NIST PQC.
* **Programmability vs efficiency**: PCG auth triples [2025/169] seed $O(k^2\log N)$ quad chunk $k$; linear $O(k\log N)$ only large fields. Closing gap $F_2$ crucial Boolean MPC silent preprocessing.
* **Leakage MK-HSS**: Public enc reveal len reuse linkable across execs. Formal input-privacy under reusable enc lacking. Future model capture unlinkability.

Future roadmap:
1. Construct $N$-party DPF $n\lambda+o(n\lambda)$ from *standard* LPN (not sparse)
2. Combine PCG+HSS single-round 3-server PIR *private* DB (SPIR) wo heavy FHE
3. Implement Rust NTT optimization lib unifying DPF/PCG/HSS BENCH on ARM enclave.

## 7 Conclusion
We traversed landscape from **DPFs** compressed sparse vector shares, through generalization **FSS**, duality **HSS**, condensation **PCGs**, finally **lightweight N-party computation** for **PIR**. Core thread *pseudorandomness + linear algebra*: GGM tree + correction words exponential compression [1]; LPN linear noisy share conversion freeness multi-party HSS [2]; expander graphs + prefix accum cache-friendly correlation stretching [5][6]; additive homomorphism logarithmic PIR [7].

Practical payoff stark: 2-server keyword-PIR 25.5x throughput over single-server SimplePIR <2% comm, multiplication 5ms geolocation KE <1s [6], PCG silent OT replacing $2^{20}$ OTs with 16KB seed [4]. Remaining frontier threshold gap PRG-only full-threshold 3-party DPF $poly(n)$ still open, superpoly LPN $N$-party sublinear MPC undesirable. Yet trajectory suggests nesting + structured LPN/Ring-LPN will keep pushing $N$ upward w/o FHE.

> As Boyle et al. observe [1], *DPF reduces private search to linear aggregation of locally computed pseudo-shares*; PCG then *silences* preprocessing that made it possible. Together HSS/FSS recasts cryptography's central question from *"can we compute privately?"* to *"how little must we communicate to compute privately?"*
