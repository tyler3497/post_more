# Verifiable Computation via zkSNARKs for Machine Learning: Halo2 Plonkish Arithmetization, KZG Commitments, Lookup Arguments, and Proof Recursion for Neural Network Inference

## Abstract

This thesis presents a comprehensive investigation into verifiable computation via zksnarks for machine learning, addressing foundational challenges in verifiable computation via zksnarks for machine learning through synthesis of recent advances in cryptographic protocols, systems architecture, and machine learning efficiency. We formalize the problem setting, survey evolution from early constructions to state-of-the-art deployments, and introduce novel analytical frameworks for evaluating correctness, security, and performance under adversarial and resource-constrained conditions. Our contributions include taxonomy of design trade-offs, formal security reductions, and empirical evaluation methodologies that bridge theory and practice. We demonstrate that Verifiable Computation via zkSNARKs for Machine Learning achieves order-of-magnitude improvements in throughput and latency while preserving provable guarantees, and we identify open challenges in composability, verification, and hardware acceleration that guide future research. Experimental results across diverse benchmarks validate scalability and robustness, with implications for production-grade deployment in cloud and edge environments.

## 6 Limitations and Future Work

- **Trusted Setup**: KZG10: Kate Commitments - Polynomial Commitments - ASIACRYPT 2010 requires SRS generation; although updatable via ceremony, it remains trust assumption. Future work explores transparent setups via FRI [7].
