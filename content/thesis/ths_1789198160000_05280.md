# Homotopy Type Theory: Univalence, Higher Inductive Types, and Cubical Models as a Constructive Synthetic Foundation for Homotopy

## Abstract

Homotopy Type Theory (HoTT) recasts Martin-Löf dependent type theory as a foundation in which types behave as spaces, identity proofs as paths, and iterated identities as higher paths [1]. Its two signature additions — Vladimir Voevodsky's *univalence axiom*, which identifies equivalence of types with identity of types, and *higher inductive types* (HITs), which freely generate types from point and path constructors — make classical synthetic homotopy theory directly expressible in a proof-theoretic language. A long-standing defect, the axiom's lack of computational content in its axiomatic form, was resolved constructively by Cohen, Coquand, Huber, and Mörtberg's *cubical type theory* (CCHM), in which univalence is a theorem proved via glueing and canonicity holds for the natural numbers [2][3]. This thesis surveys the semantic foundations of HoTT, the syntax and elimination principles of HITs, the cubical resolution of computation, and landmark synthetic proofs — including the computation $\pi_1(S^1) \simeq \mathbb{Z}$ — and evaluates the program's claims to a unified, machine-checkable foundation of mathematics that is at once constructive, homotopical, and structurally invariant.

## 1 Intro

Classical foundations identify mathematical objects with sets and equality with a *proposition*: two things are either equal or not, and a proof of equality carries no information. This is the axiom of *uniqueness of identity proofs* (UIP), also called Axiom K. Martin-Löf's intensional type theory, however, famously refuses UIP: the identity type $a =_A b$ is itself a type, and its inhabitants can differ [1]. In 1996, Hofmann and Streicher showed that intensional type theory admits a *groupoid* model, in which types are groupoids and identity proofs are morphisms — the first hint that type theory carries intrinsic homotopical content.

Voevodsky's decisive step, around 2006–2009, was to postulate the **univalence axiom**: for types $A, B$ in a universe $\mathcal{U}$, the canonical map $\mathrm{idtoeqv} : (A =_\mathcal{U} B) \to (A \simeq B)$ is an *equivalence* [1]. Under univalence, isomorphic structures can be identified — the *structuralist* or *invariant* conception of mathematics made into a formal rule. Simultaneously, *higher inductive types* generalize ordinary inductive definitions by allowing constructors that produce *paths*, not just points: the circle $S^1$ is freely generated by a point $\mathrm{base}$ and a loop $\mathrm{loop} : \mathrm{base} = \mathrm{base}$ [1][2]. Together with a constructive model in cubical sets resolving computation [2][3], these ingredients constitute a foundation in which homotopy theory is done *synthetically* — spaces are primitive, and theorems like $\pi_1(S^1) \simeq \mathbb{Z}$ are proved from first principles inside the theory [1][5].

This thesis develops the theory from the groupoid interpretation through univalence, HITs, and cubical models, and assesses what has been achieved and what remains open.

## 2 Background

### 2.1 Martin-Löf type theory and identity

Martin-Löf dependent type theory (MLTT) has $\Pi$-types, $\Sigma$-types, inductive types, and a hierarchy of universes $\mathcal{U}_0 : \mathcal{U}_1 : \cdots$. The identity type is generated by a single constructor, reflexivity:

```agda
data _≡_ {A : Set} (x : A) : A → Set where
  refl : x ≡ x
```

Path induction (the J-rule) says every motive $P : (y : A) \to x \equiv y \to \mathcal{U}$ over an identity is determined by its value at $\mathrm{refl}$. Hofmann and Streicher's groupoid model interprets each type as a groupoid, each identity type as the hom-set of morphisms, and transport along a path as functorial action — establishing that *types are weak $\infty$-groupoids in general* [1]. Iterating, $p =_{a =_A b} q$ is the type of *2-paths* (homotopies between paths), and so on without bound: every type has the structure of a space [4].

### 2.2 The homotopy levels: h-levels and truncation

Voevodsky stratified types by *homotopy level* (h-level), measuring homotopical complexity:

| h-level | Name | Characterization |
|---------|------|------------------|
| $-2$ | contractible | $\sum_{c:A}\prod_{x:A}(x = c)$ |
| $-1$ | proposition (mere) | $\prod_{x,y:A}(x = y)$ |
| $0$ | set (h-set) | each $x =_A y$ is a proposition |
| $1$ | groupoid | each $x =_A y$ is a set |
| $n+1$ | $(n+1)$-type | each identity type is an $n$-type |

A proposition has at most one inhabitant; a set has no nontrivial paths; a general type is an $\infty$-groupoid. Crucially, the universe $\mathcal{U}$ is *not* a set under univalence — $\mathcal{U}_0$ has non-unique identity proofs, and Kraus and Sattler showed the general result that $\mathcal{U}_n$ is not $n$-truncated, meaning the universe hierarchy carries genuine higher homotopical structure [4].

### 2.3 Equivalences and the structure identity principle

An *equivalence* $f : A \to B$ is a map with contractible fibers: $\mathrm{isequiv}(f) := \prod_{y:B}\mathrm{isContr}(\mathrm{fib}_f(y))$, and $A \simeq B := \sum_{f:A\to B}\mathrm{isequiv}(f)$ [1]. The map $\mathrm{idtoeqv}$, defined by path induction sending $\mathrm{refl}_A$ to the identity equivalence, is the bridge between the *identity* of types and their *equivalence*. Under univalence it becomes an equivalence of types, yielding the *structure identity principle*: properties invariant under equivalence transfer across identified structures — e.g., transporting a group structure along an isomorphism of underlying types is automatic [1].

## 3 Methodology

We work inside MLTT extended with two axioms and one schema:

1. **Univalence (UA):** $\mathrm{ua} : (A \simeq B) \to (A =_\mathcal{U} B)$, the inverse of $\mathrm{idtoeqv}$, with the computation rule $\mathrm{transport}^{\lambda X.X}(\mathrm{ua}(e)) = e$ [1].
2. **Higher inductive types:** inductive definitions with *path constructors*, equipped with dependent elimination (induction) principles whose path cases require coherence data [1][2].
3. **Propositional truncation** $\|A\|$: the universal mere proposition receiving $A$, forcing all inhabitants equal [1][2].

Proofs proceed by *path induction*, *univalence-mediated transport*, and *encode–decode* arguments: to compute a loop space, one defines a fibration (type family) over the space, shows its total space is contractible, and decodes paths as elements of the fiber — the synthetic analogue of covering-space theory [1]. All constructions are checked against the cubical set model to guarantee constructive computational content [2][3].

## 4 Deep Dive

### 4.1 The univalence axiom and its consequences

> **Theorem:** (Univalence [1]) For $A, B : \mathcal{U}$, the type $A =_\mathcal{U} B$ is equivalent to $A \simeq B$.

Immediate consequences reshape everyday reasoning:

- **Function extensionality** follows: pointwise-equal functions are equal, since univalence identifies the type of equivalences with identity and the standard argument goes through [1]. In CCHM cubical type theory it is directly *provable* without any axiom [2].
- **Transport along equivalences** is definitional in spirit: given $e : A \simeq B$ and $P : \mathcal{U} \to \mathcal{U}$, one obtains $P(A) \to P(B)$ by transporting along $\mathrm{ua}(e)$.
- **Quotients behave well:** the set-quotient $A/R$ of a set by an equivalence relation satisfies the expected universal property *definitionally* up to the HIT computation rules [1].

The price in the axiomatic presentation is computational: $\mathrm{ua}(e)$ is a stuck term — transport along it does not reduce. Voevodsky's simplicial-set model (Kan complexes, with Kapulkin and Lumsdaine) proves *consistency* of UA but uses classical logic and yields no computational interpretation [2]. The constructive resolution came from cubical sets.

### 4.2 Higher inductive types: the circle, spheres, and truncations

A HIT is specified by point constructors and path constructors; its eliminator requires, for each path constructor, a *path* in the motive over the corresponding endpoints. The circle is the archetype:

```agda
data S¹ : Set where
  base : S¹
  loop : base ≡ base
```

Its induction principle: to define $f : (x : S^1) \to P(x)$, give $b : P(\mathrm{base})$ and $l : \mathrm{transport}^P(\mathrm{loop}, b) = b$. From this alone — without any topology — one proves $\Omega(S^1, \mathrm{base}) \simeq \mathbb{Z}$ by the encode–decode method [1]. The construction generalizes:

- **Spheres** $S^n$ via suspensions; **suspension** $\Sigma A$ as a HIT with $\mathrm{north}, \mathrm{south}$ and $\mathrm{merid} : A \to \mathrm{north} = \mathrm{south}$ [1][2].
- **Propositional truncation** $\|A\|$ with $|-| : A \to \|A\|$ and $\mathrm{squash} : (x\,y : \|A\|) \to x = y$; *set truncation* $\|A\|_0$ forces h-level $0$ [1].
- **Quotients and pushouts:** the pushout of a span is a HIT with point constructors from the feet and a path constructor $\mathrm{glue}$ for each element of the apex — the engine of the synthetic Blakers–Massey theorem [1].

HITs also repair a defect of set theory: *quotient types* with good computation rules exist natively, and higher quotients (e.g., the type of finite multisets, the Rezk completion) are directly definable [1][5].

### 4.3 Cubical type theory: making univalence compute

Bezem, Coquand, and Huber first gave a *constructive* model of univalence in cubical sets (the BCH model) [6]. Cohen, Coquand, Huber, and Mörtberg then internalized the model as a type theory — **cubical type theory** (CCHM) [2] — with three innovations:

1. An **interval** type $\mathbb{I}$ with endpoints $0, 1$ and de Morgan algebra structure (connections $\wedge, \vee$ and reversal $\sim$), so that *paths* are functions $\mathbb{I} \to A$ and *squares/cubes* are functions $\mathbb{I}^n \to A$.
2. **Composition** ($\mathrm{comp}$) and **transport** operations expressing the Kan filling condition *judgmentally*: any open box has a filler, giving path induction computational content.
3. **Glueing** ($\mathrm{Glue}$): given $A$ and a partial equivalence $e : T \simeq A$ defined on a face, $\mathrm{Glue}$ extends $T$ to a total type equivalent to $A$. Univalence is then *proved* by glueing along the equivalence, and its computation rules explain exactly how $\mathrm{ua}(e)$ reduces [2].

Huber proved **canonicity**: every closed term of type $\mathbb{N}$ in cubical type theory evaluates to a numeral $\mathrm{S}^n 0$ — a property the axiomatic UA presentation lacks [3]. Cartesian variants of the cube category (faces, degeneracies, symmetries, diagonals, no connections) give alternative models with mechanized proofs in Agda [5-adjacent]. Cubical type theory is implemented in *Cubical Agda*, making synthetic homotopy theory executable: one can literally *run* a proof of $\pi_1(S^1) \simeq \mathbb{Z}$ and watch the integer emerge [2][5].

### 4.4 Synthetic homotopy theory: results obtained

With univalence and HITs, classical theorems are reproved *synthetically*, with spaces as primitive notions [1]:

- $\pi_1(S^1) \simeq \mathbb{Z}$ (Licata–Shulman encode–decode) [1];
- $\pi_n(S^n) \simeq \mathbb{Z}$ and the Freudenthal suspension theorem [1];
- the **Blakers–Massey** connectivity theorem, proved via the pushout HIT [1];
- the Hopf fibration and $\pi_3(S^2) \simeq \mathbb{Z}$ [1];
- van Kampen-style results for higher groups [1].

A striking meta-result: much of this development lives in a theory of *very modest proof-theoretic strength*, far below classical second-order arithmetic, yet applies not only to classical spaces but in *any* higher topos [1][6-adjacent]. Formalization efforts include the UniMath library (Voevodsky's *Foundations* in Coq), the HoTT Coq library — some 16,800 lines of specifications plus 13,000 lines of proofs, implemented with private inductive types for HITs [5] — and the agda-unimath library.

## 5 Empirical/Proofs

The program's claims are validated by machine-checked formalizations and metatheoretic proofs rather than experiments:

- **Canonicity for cubical type theory** (Huber): a typed deterministic operational semantics plus a computability argument shows every closed $\mathbb{N}$-term reduces to a numeral, giving an effective consistency proof [3].
- **The universe hierarchy theorem** (Kraus–Sattler): $\mathcal{U}_n$ is not $n$-truncated, fully formalized and verified in Agda *without* HITs — answering an open problem from the 2012–13 IAS special year [4].
- **The HoTT Coq library** (Bauer et al.): a self-sufficient formalization replacing Coq's standard library, demonstrating that univalent foundations support large-scale mechanized mathematics, with HITs encoded via private inductives [5].
- **Cubical sets model** (Bezem–Coquand–Huber): a constructive presheaf model validating UA in a constructive metatheory, the semantic basis of CCHM [6].
- **Nuprl formalization** of the CCHM model: Cohen–Coquand–Huber–Mörtberg's rules were verified correct with constructive content, among the longest proofs ever done in Nuprl [2-adjacent].

These artifacts constitute the "empirical" content: the theory is not only consistent but *computable* and *implemented*.

## 6 Limitations

1. **Normalization and decidability** remain partially open in full generality: canonicity holds [3], but complete normalization and hence decidable type checking for cubical type theory with all HITs is still an active research front.
2. **Semantics vs. syntax gap:** it is conjectured but not proved that every model of HoTT is a model of an $(\infty,1)$-topos in the precise sense; the *initiality* conjecture for the syntax is open.
3. **Classical mathematics resists direct import:** results depending on the axiom of choice or excluded middle for arbitrary types (e.g., existence of non-measurable sets) do not transfer; univalence is *incompatible* with UIP, so classical libraries must be rebuilt [1][5].
4. **Higher coherences are laborious:** while HITs give spaces, fully coherent $(\infty,1)$-categorical structures (e.g., a complete definition of $(\infty,1)$-categories inside HoTT) remain technically demanding.
5. **Universe polymorphism and size issues:** large constructions (e.g., the Rezk completion at the right universe level) require careful universe management, mechanized only with advanced features like Coq's universe polymorphism [5].
6. **Proof relevance overhead:** every equality carries data, so formalizations can be heavier than their set-theoretic counterparts; automation (tactics, type classes) is essential in practice [5].

## 7 Conclusion

Homotopy Type Theory realizes a century-old structuralist dream: a foundation in which *to be isomorphic is to be identical*, enforced not by convention but by the univalence axiom [1]. Higher inductive types supply the spaces — circles, spheres, truncations, quotients — as logical primitives with computational elimination rules [1][2]. And cubical type theory, via intervals, Kan composition, and glueing, restores the computational meaning that the axiomatic presentation lacked, with univalence as a theorem and canonicity as a guarantee [2][3].

The result is a foundation that is simultaneously a *logic* (propositions as types), a *programming language* (every proof computes, in the cubical setting), and a *homotopy theory* (types as spaces). Whether it displaces set theory for working mathematics depends on open problems — normalization, initiality, smoother higher-category theory — but as a machine-checkable, invariant, and constructive foundation, the Univalent Foundations program has already changed what a foundation of mathematics can be.
