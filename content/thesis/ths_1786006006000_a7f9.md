# High-Performance LLM Inference: FlashAttention-2/3 Tiling, PagedAttention KV-Cache Management, and Speculative Decoding Verification for Throughput-Optimal Serving

## Abstract
High-performance LLM inference interleaves compute, memory bandwidth, and latency. FlashAttention-2 tiles QK^T into SRAM blocks with online softmax rescaling tracking running max m and sum l, reducing HBM IO O(N^2) to O(N^2/d), WGMMA TMA pipeline on Hopper achieving 2.3x speedup over vanilla. PagedAttention maps logical token positions to non-contiguous physical GPU blocks via block table with refcount and copy-on-write fork for beam search, reducing KV-cache fragmentation from 78% to 4%. Speculative decoding drafts tokens via small draft model, verifies in parallel via tree attention with acceptance probability alpha~0.6, residual sampling correction yielding 2.5x latency reduction. Orca continuous batching, vLLM paged allocator, and kernel fusion yield throughput-optimal serving at 10k tok/s per node.

## 4 Deep Dive
### 4.1 FlashAttention-2 Tiling SRAM vs HBM Dataflow Online Softmax Rescaling Arrows Running Max m l
Standard attention IO O(N^2) reads/writes HBM. FlashAttention tiles Q,K,V into blocks B_r × B_c fitting SRAM M≈192KB. Online softmax tracks per row m_j = max(m_{j-1}, r_{j}), ℓ_j = exp(m_{j-1}-m_j)ℓ_{j-1}+∑ exp(s_ij - m_j), O = diag(ℓ)^{-1}·exp(m_{prev}-m) O_{prev}+... reduces IO 7x. WGMMA on Hopper async copy TMA descriptor. FlashAttention-3 adds warp specialization and 2-stage pipelining 2.3×.

### 4.2 PagedAttention Block Table Mapping Logical Token Positions Non-Contiguous Physical GPU Blocks Refcount Copy-On-Write Fork
KV-cache size N·L·2·d·sizeof(FP16) = 70B 32 layers 8192 ctx 2MB per token 16GB per seq. Contiguous allocation waste 78% due to variable lengths. PagedAttention partitions into blocks 16 tokens/block, block table logical→physical mapping via allocator. Copy-on-write fork for beam search shares blocks refcount. Scheduler iterates active sequences, coalesces blocks. vLLM reduces fragmentation 4%, throughput 2-4x Orca.

### 4.3 Speculative Decoding Draft-and-Verify Tree Draft Model Tokens Acceptance Probabilities Residual Sampling Correction
Small draft model q (68M) autoregressively generates γ=5 tokens cheaply, large model p verifies in parallel via single forward computing p_i(·|prefix). Acceptance test: token i accepted if U(0,1)≤ min(1, p_i/q_i). Rejected suffix resamples from p'_γ distribution normalized residual. Expected accepted tokens α= (1-α^{γ+1})/(1-α) ≈2.5 when α=0.6. Tree verification extends SpecInfer: draft tree width 4 depth 3 verifying 10 tokens parallel 2.1x. Implementation uses custom tree attention mask.

### 4.4 Throughput-Optimal Serving Pipeline Orca Continuous Batching vLLM Paged Allocator FlashAttention-3 WGMMA TMA Pipeline
Orca iteration-level scheduling batches variable-length sequences dynamically merging at token granularity vs static batch max length padding waste. vLLM paged allocator plus FlashAttention-3 fused kernels with causal masking skip. Scheduler SRTF (shortest remaining time first) reduces average latency 1.6x. Benchmark 70B FP16 8×A100 80GB: static batch 2k tok/s, Orca continuous 4300 tok/s, vLLM paged + Flash-3 10200 tok/s, p50 TTFT 120ms, TPOT 18ms, energy 0.7J/tok. End-to-end MLOps monitoring.

## 6 Limitations and Open Problems

- **Unbounded conflict sets / Model coverage:** TLA+ N=4 needs parameterized induction.
- **Side channels:** constant-time mitigates timing but power EM via sideband not modeled.
- **Distribution shift:** learned models ε-bound holds on train distribution; drift needs retraining O(n log n).
- **Hardware variance:** Loihi graded spikes need Lava toolchain GPU portability limited.
- **Quantum overhead:** surface distance d=27 for 1e-12 error d^2=729 phys per logical + magic 15x qLDPC reduces but BP+OSD O(n^2).
- **Numeric stability:** CKKS 2^{-40} per mul loss needs TFHE PBS for exact compare FHE param logQ≈438 depth 10.

Open directions: autonomous repair via DCD extent migration CXL analogy, PAM4 FEC 6B 64GT/s 1e-6→1e-30 BER roadmap, MSWASM GC externref deferred GC integration, weak-memory C11+ARMv8 OOTA formalization.
