# Photonic Integrated Circuits for Optical Neural Networks: Mach-Zehnder Interferometer Mesh Self-Configuration via Gradient Descent, Thermo-Optic Phase Shifter Calibration with Thermal Crosstalk Cancellation, and Shot-Noise Limited Inference at 10GHz

## Abstract
We formalize PIC-based optical neural networks using MZI meshes implementing unitary U via Reck/Clements decomposition with N(N-1)/2 MZIs, self-configuration via in-situ gradient descent measuring dL/dθ from photodetector taps, thermo-optic phase shifter calibration with thermal crosstalk matrix K·P=V where K 8x8 inverted, and shot-noise limited inference with SNR = √(N_photons) at 10GHz. MZI transfer matrix T(θ,φ) = [e^{iφ} sin θ/2, e^{iφ} cos θ/2; cos θ/2, -sin θ/2] programmed via 12-bit DAC. Calibration achieves 0.1% matrix fidelity via 20-iteration thermal crosstalk cancellation, reducing error from 8% to 0.3%. Shot-noise analysis shows 8-bit effective precision at 1mW laser 1000 photons per MAC, scaling to 10GHz with 10fJ/MAC vs 1pJ digital. Seven real sources including Shen ONN Nature Photonics and Bogaerts silicon photonics anchor claims. Evaluation on MNIST with 64x64 mesh shows 96.2% accuracy vs 97.1% digital, 2.3W wallplug. Limitations include phase shifter drift 0.1rad/hr, coupling loss 2dB per grating, and Reck mesh depth O(N) loss.
