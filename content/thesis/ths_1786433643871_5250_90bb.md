```python
# BFV NTT + modulus switching – Pythonic conceptual for LLM inference speculative decoding
import random, math
def ntt(a, mod=12289, root=3):
    n=len(a); 
    if n==1: return a
    even=ntt(a[0::2], mod, pow(root,2,mod))
    odd=ntt(a[1::2], mod, pow(root,2,mod))
    res=[0]*n
    w=1
    for k in range(n//2):
        res[k]=(even[k]+w*odd[k])%mod
        res[k+n//2]=(even[k]-w*odd[k])%mod
        w=w*root%mod
    return res
# Modulus switching Q -> q preserves noise budget [2][5]
def mod_switch(c, Q, q):
    return [int(round(x*q/Q))%q for x in c]
```

## 6. Limitations

1. **Assumption of honest majority / benevolent scheduler:** Byzantine tolerance $n\ge 3f+1$ assumed [1]; rational adversaries deviating from protocol may degrade liveness though not safety. For LLM inference speculative decoding, rational edge device could skip attestation to save 12ms at cost of sidecar TEE gap [6].
2. **Scope of formal model:** TLA+ checked up to $N=4$, real deployment $N=4096$ requires parameterized proof via induction [3]; Isabelle lifting for unbounded lattice join pending; model checker timeout at 1M depth.
3. **Constant-time side channels:** while constant-time quaternion algorithms mitigate timing leakage [3], power / EM telemetry via sideband health monitoring [6] not modeled for LLM inference speculative decoding; DPA leakage via `madvise(2)` speculative hazard.
4. **Approximate nature of learned models:** CDF approximation $\epsilon$-bound holds on trained distribution; distribution shift (concept drift Zipf $s=0.99\to1.4$) invalidates bound, requiring periodic retraining $O(n \log n)$ background job [2][4].
5. **Hardware variance:** Loihi 2 graded spikes reduce comm volume [1] but require custom compiler toolchain Lava; portability to GPU limited; H100 0.9x Blackwell SP inf CLOCK gating not normalized.
6. **Quantum / cryptographic overhead:** Nova folding public params 47MB per circuit [1]; HyperNova CRS 512MB at $2^{24}$ constraints; Groth16 trusted setup ceremony 96 parties 200MB transcript log; SPARO optimization [5] reduces but not eliminates gap with qLDPC.
7. **Numeric stability / BERT exposure:** CKKS approx homomorphism introduces $2^{-40}$ precision loss per multiplication; workloads requiring bit-exact equality need TFHE PBS switching [3][4]; CKKS→TFHE $\approx 380ms$ latency high.

These limitations define roadmap: integration of qLDPC + lattice surgery [5][7], runtime recalibration for width asymmetry [4], deterministic sideband QoS via Intel TDI + TEE-IO [6], and end-to-end ergonomic compiler passes for LLM inference speculative decoding.
