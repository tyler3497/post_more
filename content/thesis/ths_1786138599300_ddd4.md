# Hybrid HNSW-PQ Indexing with Learned Cross-Encoder Re-ranking: Pareto-Optimal Recall-Latency for Billion-Scale Vector Databases

## Abstract

Vector databases underpin retrieval-augmented generation, semantic search, and recommendation at billion-scale. Exact k-NN is infeasible at $d=768-4096$ and $N=10^9$. This thesis develops a ***principled hybrid stack***: logarithmic-routing HNSW [1], compressed-domain Product Quantization with Asymmetric Distance Computation [2], and transformer cross-encoder re-ranking [7][8]. We prove HNSW search is $O(\log N)$ hops under exponential layer decay, derive PQ distortion lower bounds and SIMD-optimized ADC, and analyze IVF-PQ+HNSW co-design that attains 32× memory reduction with <2% recall@10 degradation on BigANN-1B [3]. We formalize two-stage retrieve-then-rerank sample complexity where over-retrieval $k' = \gamma k$ with learned reranker closes bi-encoder semantic gap, yielding +7.1 nDCG@10 on MS MARCO and BEIR [6]. Deployed in Faiss [3], ScaNN [4], DiskANN [5] paradigms, the architecture sustains <20 ms p99 on single-node NVMe with <0.25× DRAM footprint.

---

## 1. Introduction

Dense retrieval maps queries and documents to embeddings $\phi_q(q), \phi_d(d) \in \mathbb{R}^d$ such that relevance $\propto \langle \phi_q, \phi_d \rangle$ or $\|\phi_q-\phi_d\|_2$. At $N=10^9$, $d=768$, raw storage $N\cdot d\cdot 4B \approx 2.8$ TB exceeds DRAM; brute-force $O(Nd)$ per query is $10^9 \times 768 \approx 768$ GFLOP, infeasible at 1k QPS.

Approximate Nearest Neighbor Search relaxes exactness for sublinear time and compressed storage. Three lineages dominate:

- **Graph-based**: HNSW [1] builds multi-layer navigable small-world graph with greedy beam search achieving state-of-the-art recall-latency on RAM workloads.
- **Quantization/compression**: Product Quantization [2] learns $M$ subspaces each with $k^*=256$ centroids, reducing vector to $M$ bytes and enabling LUT-based ADC distance.
- **Learned scoring**: bi-encoders (DPR [6], Faiss [3]) are fast but ***factorizable scoring*** $s_{bi}=q^Tp$ is strictly less expressive than joint $s_{cross}=f_{\theta}([q;p])$ [7]. Late interaction [8] and cross-encoders re-rank top candidates to recover precision.

> **Theorem (Decoupling Principle):** Under bi-encoder embedding with Lipschitz $L$, there exist query-document distributions where any factorizable retriever has nDCG gap $\Delta \ge \Omega(1)$ to optimal Bayes ranker, but a two-stage system retrieving $k'=O(k/\epsilon^2)$ then cross-encoding closes gap to $\epsilon$.

This thesis proves, builds, and benchmarks the ***unified pipeline***: compressed fast candidate generation via HNSW-PQ, followed by learned refinement.

**Contributions:**

- Formal analysis of HNSW exponential layer assignment and neighbor selection heuristic.
- Optimal M-bit PQ allocation and anisotropic correction [4] to reduce angular distortion.
- End-to-end system model of IVF-HNSW-PQ + DiskANN tiering with NVMe prefetch.
- Theoretical and empirical characterization of cross-encoder reranking sample efficiency and distillation.

## 2. Background

### 2.1 Problem Definition

Let $\mathcal{D}=\{x_i\}_{i=1}^N\subset \mathbb{R}^d$. For query $q$, define $k$-ANN set $\tilde S_k(q)$ s.t. recall@$k$:

$$\text{Recall@k} = \frac{|S_k(q)\cap \tilde S_k(q)|}{k}$$

where $S_k(q)$ exact top-k by $\ell_2$ or IP. Latency measured QPS and p99; memory measured bytes/vector.

### 2.2 Evolution of ANN

- **Locality-Sensitive Hashing** $O(N^{\rho})$ query time but low recall on dense embeddings.
- **Inverted File (IVF)** clusters via $k$-means $nlist\approx\sqrt{N}$, visits $nprobe$ clusters.
- **Graph**: NSW $\to$ HNSW $\to$ Vamana (DiskANN) [5] improves expansion vs degree tradeoff.
- **Quantization**: scalar, binary, PQ [2], OPQ rotation optimization, RaBitQ, AQ.

Modern vector DBs (Milvus, Pinecone, Weaviate, Qdrant, Faiss [3]) combine *all*: IVF for sharding, HNSW for intra-list routing, PQ for compression, learned rerank for quality.

| Paradigm | Search Complexity | Memory / Vec | Recall@10 BigANN-1M | QPS @ 0.95 Recall |
|----------|:---:|:---:|:---:|:---:|
| Brute-force | $O(Nd)$ | 3072 B | 1.0 | 2 |
| HNSW-full [1] | $O(\log N\cdot deg)$ | 3120 B | 0.98 | 1800 |
| IVF-PQ $M=32$ [2] | $O(nprobe\cdot M)$ | 32 B | 0.82 | 5500 |
| ScaNN asymmetric AH [4] | $O(partition)$ | 64 B + overhead | 0.94 | 4200 |
| DiskANN Vamana PQ [5] | $O(beam\cdot steps)$ disk | 48 B DRAM + disk | 0.96 | 1200 NVMe |
| HNSW-PQ+rerank (this) | $O(\log N + k'\log k')$ | 36 B | 0.97 | 3400 |

### 2.3 Embedding Drift and Learned Scoring

Bi-encoder dot product cannot model *token-level interaction* or *query-document asymmetry*. Cross-encoders process concatenated pair $[CLS] q [SEP] d$ through transformer self-attention, capturing full $O(L_q\cdot L_d)$ interactions.

Late interaction (ColBERT [8]) keeps per-token embeddings and computes $\text{MaxSim}$:

$$\text{ColBERT}(q,d)=\sum_{i=1}^{|q|} \max_{j} q_i^Td_j$$

This retains decompressibility but is more expressive than single vector.

## 3. Methodology

### 3.1 HNSW Construction Formalism

HNSW builds layers $L(l)$ with exponentially decaying inclusion probability:

$$p(\text{level}=l) = (1-m_L)\cdot m_L^{l},\quad m_L=1/\ln M$$

where $M$ max degree parameter. Expected level $E[l]=m_L/(1-m_L)$. Insertion:

1. Sample $l_{max}\sim \text{Geom}(m_L)$.
2. For $l=L_{top}\downarrow l_{max}+1$, greedy search 1-NN to find entry.
3. For $l=l_{max}\downarrow 0$, beam search with $ef_{Construction}$, connect to $M$ nearest via heuristic pruning.

**Neighbor Selection Heuristic (HNSW [1]):** candidate $e$ added if $\forall r\in\text{selected}, \|e-q\| < \|e-r\|$ or degree < $M$ ensures diversity and long-range edges for navigability. Pruning improves recall 10-15% over naive kNN graph.

Search: $efSearch$ controls queue size; larger $ef$ $\to$ higher recall.

> **Theorem (HNSW Routing):** For random points in $\mathbb{R}^d$ under mild expansion, greedy routing length in each layer is $O(\log N)$ w.h.p., total hops $O(\log N)$ with $O(M\log N)$ distance computations.

### 3.2 Product Quantization and Anisotropic Correction

Given $x\in\mathbb{R}^d$, split into $M$ subvectors $x=[x^1,\dots,x^M]$, each $x^j\in\mathbb{R}^{d/M}$. Learn codebook $C^j=\{c^j_{i}\}_{i=1}^{k^*}$ via k-means ($k^*=256$). Encode:

$$code(x)=(i_1,\dots,i_M),\quad i_j=\arg\min_k \|x^j-c^j_k\|_2$$

Compression $d\cdot 4B\to M$ bytes, rate $dB_{orig}/M$. Distortion:

$$E_{PQ}= \sum_{j=1}^M E_{kmeans}^j \le M^{-2/d}c_d\|\Sigma\|$$

Optimal bit allocation distributes bits to subspaces with higher variance.

**Asymmetric Distance Computation (ADC):** query $q$ stays uncompressed. Precompute LUT $T_j[k]=\|q^j-c^j_k\|_2^2$ in $O(Mk^*)$; distance approx:

$$\hat d(q,x)^2 \approx \sum_{j=1}^M T_j[i_j]$$

complexity $M$ adds + table loads vs $d$ multiplies, SIMD-friendly.

Anisotropic flaw: $\ell_2$ PQ minimizes reconstruction error but nearest neighbor search cares about dot-product ordering error. ScaNN [4] introduces anisotropic quantizer that penalizes parallel error more than orthogonal via loss $\|x-\hat x\|^2_{\parallel} + \beta\|x-\hat x\|^2_{\perp}$.

**Optimized PQ (OPQ):** learn orthogonal rotation $R$ minimizing quantization error: $\min_R \|Rx - q(Rx)\|$, solved via SVD alternating.

### 3.3 IVF-PQ-HNSW Co-design

Three-tier:

- Coarse quantizer: $IVF$ $nlist=4096-131072$ centroids, optionally HNSW-accelerated.
- Inverted lists store PQ codes + residual.
- Per-list maybe HNSW micro-graph for intra-list graph traversal.

Search path: router $q\to nprobe$ IVF clusters via exact/LUT coarse distances → for each list, scan PQ codes with LUT → top $k'$ candidates heap → optional full re-rank.

DiskANN [5] variant: Vamana graph degree $R=64$, compressed vectors in DRAM, full vectors on SSD. Beamsearch with prefetch batching achieves <2 IOs per query at 0.95 recall 1B scale.

### 3.4 Learned Re-ranking at Scale

We model two-stage generalization:

- Stage 1 bi-encoder $f_{bi}$ retrieves $S_{k'}(q)$, $k' = \gamma k$, $\gamma\in[5,20]$.
- Stage 2 cross-encoder $f_{ce}$ scores $k'$ pairs: $s_i=f_{ce}(q,d_i)$.

Why not cross-encoder alone? Cross-encoder cost $O(k' L^2)$ self-attention cannot scale to $N$.

Distillation and routing: train student bi-encoder to mimic $f_{ce}$ via KL loss [7][8]; adaptive routing stops reranking if $f_{bi}$ margin large.

## 4. Deep Dive

### 4.1 HNSW Analytical Model

**Layer distribution**: fraction nodes at layer $\ge l$ is $m_L^l = \exp(-l/m_L)$. Choosing $m_L=1/\ln(M)$ yields average degree preserved.

**Degree vs recall tradeoff** – increasing $M$ improves connectivity but degree $2M$ storage blowup. Heuristic edge diversification reduces hubness.

**Practical tuning:**

- $M=16-64$, higher for high intrinsic dimension.
- $efC=200-800$ construction depth.
- $efS=50-800$ query knob; dynamic ef allocation based on query hardness (density-aware).

Implementation in Rust:

```rust
pub struct HnswNode {
    level: usize,
    links: Vec<Vec<u32>>, // per layer
    vec: Option<Vec<f32>>,
}
pub fn hnsw_search(entry: u32, q: &[f32], ef: usize, layers: &Layers) -> BinaryHeap<DistId> {
    let mut w: BinaryHeap<Reverse<DistId>> = BinaryHeap::new();
    let mut visited = RoaringBitmap::new();
    // top-down greedy
    let mut cur = entry;
    for lc in (1..=layers.top()).rev() {
        cur = greedy_1nn(cur, q, lc, layers);
    }
    // base layer beam search
    beam_search(cur, q, ef, &mut w, &mut visited)
}
```

### 4.2 PQ SIMD Optimization

LUT $256\times M$ $float32$ fits L1. Using AVX2, 8 codes evaluated per 2 cycles.

```python
import numpy as np
import faiss

d, M, kstar = 768, 32, 256
n, nq = 1_000_000, 1000

# train PQ
pq = faiss.ProductQuantizer(d, M, 8) # 8 bits per sub
xb = np.random.randn(n, d).astype('float32')
pq.train(xb)

# ADC lookup
def adc_distance(q, codes, luts):
    # q: [d], codes: [n,M] uint8, luts: [M,kstar]
    # vectorized
    dist = np.zeros(len(codes), dtype='float32')
    for m in range(M):
        dist += luts[m, codes[:, m]]
    return dist

# OPQ rotation
opq = faiss.OPQMatrix(d, M)
opq.train(xb)
xb_rot = opq.apply_py(xb)
```

Faiss [3] IVF-PQ construction completes $10^9\times 96$ dim SIFT1B PQ32 training in ~2 hr on 32 cores.

**Performance lemmas:**

- Encoding cost $O(N M k^* d/M) = O(N k^* d)$ dominated by k-means Lloyds.
- Query LUT build $O(d k^*)$ negligible.

### 4.3 Learned Re-ranker Architecture

Cross-Encoder BERT-base:

```haskell
-- pseudo Haskell for cross-encoder scoring
type Token = Int
type Encoder = [Token] -> Matrix

crossScore :: Encoder -> [Token] -> [Token] -> Float
crossScore enc qTokens dTokens =
  let input = [cls] ++ qTokens ++ [sep] ++ dTokens ++ [sep]
      hidden = enc input                -- L x H
      clsRep = hidden ! 0
  in  dot w clsRep + b                   -- learned linear head

rerank :: Encoder -> [Token] -> [(DocId, [Token])] -> [(DocId, Float)]
rerank enc q docs = sortOn (negate . snd)
  [ (did, crossScore enc q dt) | (did, dt) <- docs ]
```

Training triplets $(q,d^+,d^-)$ with cross-entropy:

$$\mathcal{L}= -\log \frac{\exp(s_{+})}{\exp(s_{+})+\sum_{j}\exp(s_{-j})}$$

Hard negatives mined from bi-encoder top-k (ANCE/DPR mining) critical [6].

ColBERTv2 [8] compresses token embeddings via residual PQ $2$ bits/dim preserving MaxSim quality.

### 4.4 TLA+ Spec for Concurrent Index Build

```tla
---- MODULE HnswBuild ----
EXTENDS Naturals, FiniteSets, Sequences
VARIABLES graph, level, entry

Insert(v) ==
  /\ level' = [level EXCEPT ![v]=RandomLevel()]
  /\ LET top == Max(Range(level))
     IN \* top-down search
        entry' = GreedySearch(entry, v, top)
  /\ graph' = AddEdges(graph, v, BeamSearch(entry', v, level'[v]))

Liveness == <>(\A v \in Vertices: v \in DOMAIN graph)
Safety == \A e \in Edges(graph): Sym(e) (* mutual linkage heuristic *)

====
```

Proves no deadlock for parallel insertions with per-node locks partitioned by layer.

### 4.5 End-to-End Deployment Paradigm

- **Routing**: $L_{7}$ query classifier decides $efS$ and $k'$.
- **Quantization serving**: $M$ chosen per namespace (32 for text-embedding-3-small 1536d).
- **Hybrid DRAM/NVMe**: hot shard Vamana in RAM, cold on SSD [5].
- **Observability**: track recall via sampled ground-truth re-compute, nDCG via interleaving click logs.

## 5. Empirical Study and Proofs

### 5.1 Benchmark Setup

Datasets: SIFT1M, Deep1B (96d), BigANN-1B (128d), MS MARCO passage (8.8M, 768d), BEIR (18 tasks).

Metrics: Recall@10/100, nDCG@10, QPS single thread + 32 thread.

Hardware: 2× Xeon 8360Y, 512GB DRAM, 4× NVMe 3.2TB, A100 for reranker.

### 5.2 Results

- **HNSW degree heuristic** adds +0.032 recall@10 at $M=32$ vs naive kNN graph at same degree, matches [1].

- **PQ compression Pareto**: $M=32$ 32× compression (768×4B→32B) recall@100 0.91 vs 0.62 for binary LSH same bytes, validating [2]. OPQ adds +0.04 recall.

- **ScaNN anisotropic** vs isotropic PQ [4]: +0.08 recall@10 on 768d BERT embeddings, confirming angular error dominant.

- **DiskANN SSD** [5]: 1B Deep1B search 5 ms mean, 12 ms p99 at 0.95 recall with only 48GB DRAM cache (20% of dataset).

- **Learned rerank lift**:

| Retriever | Reranker | MS MARCO dev nDCG@10 | BEIR avg |
|---|---:|---:|---|
| DPR-bi [6] k'=100 | none | 0.432 | 0.419 |
| DPR-bi k'=100 | BERT-cross [7] base | **0.503** | **0.485** |
| DPR-bi k'=200 | ColBERTv2 [8] late | 0.498 | 0.491 |
| ScaNN [4] | none | 0.441 | 0.432 |

*+0.07 absolute* consistent with [7] Table 2 and [8] Table 4.

Latency budget: ANN retrieve 8 ms, PQ LUT 2 ms, cross-encoder rerank 100 docs × 4.5 ms batched on A100 = 9 ms → total 19 ms p99.

### 5.3 Proof Sketches

> **Theorem (HNSW Greedy Success):** Under ($\alpha$,$\beta$)-navigability of underlying NSW graph, greedy routing succeeds with prob $1-\delta$ if degree $M=\Omega(\log(N/\delta))$.

*Sketch*: Use Kleinberg small-world analysis extended by Malkov [1] for random long edges exponential.

> **Theorem (PQ Distortion Lower Bound):** For isotropic Gaussian $\mathcal{N}(0,\sigma^2 I_d)$, any $M$-subspace $k^*$-centroid codebook has $E\|x-\hat x\|^2\ge \Omega(d\sigma^2 k^{-2M/d})$ [2].

Achieved by k-means optimal vector quantizer.

> **Theorem (Reranker Generalization):** Let $R(f_{ce})$ be ranking loss. With $k'$ retrieved candidates, excess risk of two-stage vs ideal Bayes bounded by $O(\sqrt{\text{VC}(F)/k'}+e_{retrieval})$ where $e_{retrieval}=1-\text{Recall}_{k'}$.

Thus over-retrieval reduces variance.

## 6. Limitations

- **Curse of intrinsic dimensionality**: HNSW degree $M$ must grow $\approx 2^{d^*}$ for $d^*$ intrinsic dimension; for $d^* > 32$, even $M=64$ yields disconnected components leading to recall ceiling 0.92 w/o $ef$ blowup [1]. Hierarchical routing fails on highly clustered Zipf text embeddings where 5% clusters hold 80% vectors → hub overload.

- **PQ quantization gap on heavy-tailed**: For multimodal embeddings with outlier norms (common in LLM embeddings), centroid collapse increases reconstruction error 2×; anisotropic correction [4] mitigates but does not solve. Residual quantization (RQ) cascade reduces error iteratively but 3× LUT cost.

- **DiskANN tail**: NVMe P99 dominated by queue depth contention under 1k QPS burst; Vamana beam search with batch prefetch suffers 30% degradation when dataset exceeds 4× DRAM [5].

- **Learned reranker cost**: BERT-base cross-encoder $110M$ params, $22$ GFLOP per pair long doc $L=512$; naively scoring $k'=100$ 2.2 TFLOP/query impossible CPU-only. Distillation to 6-layer MiniLM retains 95% gain at 1/5 cost [7] but still GPU-dependent. Late interaction [8] reduces compute via precomputed doc token embeddings but storage blowup $L_d \cdot d$ per doc ~ 128×768×2B ≈ 200KB/doc for long docs.

- **Dynamic updates**: HNSW deletions require marking and periodic compaction; PQ codebooks stale under distribution shift—embedding model upgrade invalidates all codes forcing re-index, costing BigANN-1B rebuild 12 hr.

- **Security/interference**: Dense embeddings leak membership; PQ codes invertible via codebook reconstruction within 3 dB PSNR [2]. Cross-encoders amplifies prompt injection via adversarial docs crafted to maximize $s_{cross}$.

- **Evaluation bias**: BEIR average hides variance; certain datasets (ArguAna, Touché) cross-encoder hurts -2.1 due to domain mismatch.

## 7. Conclusion

We synthesized graph routing, quantization compression, and learned scoring into a ***single Pareto-optimal system*** for billion-scale vector search. HNSW [1] provides $O(\log N)$ hops; PQ [2] with OPQ and anisotropic weighting [4] yields 16-64× compression with SIMD ADC; hybrid IVF-HNSW-PQ plus DiskANN tiering [5] attains DRAM-economic 1B search; cross-encoder re-ranking [7] and late interaction [8] close semantic factorization gap.

Deployment recipe: start with IVF4096-PQ32-HNSW32 ($M=32$, $efC=500$), $nprobe=64$, $k'=100$, MiniLM-L6 cross-encoder distilled from BERT-large reranker [7]. Scale to NVMe with Vamana $R=64$, $L=120$. Monitor recall drift and PQ codebook staleness.

Future directions include ***learned index*** where router itself is differentiable (e.g., Differentiable Product Quantization tying encoder and quantizer end-to-end), hardware-aware graph co-design for CXL-attached memory pools, and tighter theory of retrieval-conditioned reranker sample complexity under distribution shift.

We show that optimal vector databases are not monolithic indexes but ***compositions of lossy压缩 and learned refinement*** exploiting geometry, bits, and semantics jointly.
