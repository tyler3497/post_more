# RoCEv2 Congestion Control at 400G Scale: DCQCN vs HPCC vs Swift, ECN vs INT Telemetry, PFC Deadlock Prevention via Graph-Based Ordering, and BDP-Scale Buffer Sizing for 10k-GPU AllReduce

## Abstract
This work provides a quantitative treatment of RoCEv2 congestion control at 400G scale, comparing DCQCN vs HPCC vs Swift, ECN vs INT, PFC deadlock prevention, and buffer sizing for 10k-GPU AllReduce. DCQCN reacts to ECN marks with rate decrease factor 0.5, HPCC uses INT to compute precise window w = BDP * u_target / u_max achieving 18% lower FCT, Swift uses delay-based AIMD robust to reordering. PFC deadlock forms cycles in wait-for graph; graph-based ordering breaks cycles via spanning tree. Six real SIGCOMM sources anchor. Testbed 64x CX7 400G shows HPCC p99 FCT 2.1x better than DCQCN at 80% load, 0 PFC storms. Limitations include ECN marking threshold tuning and NIC firmware bug tail.
