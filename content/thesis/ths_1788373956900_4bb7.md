# Secure Multi-Party Computation for Transformer Inference: Function Secret Sharing via Distributed Point Functions DPF for ReLU/GELU, Beaver Triple Preprocessing with Silent OT, Mixed Arithmetic-Binary Secret Sharing for Softmax, and GPU-Accelerated MPC with CrypTen and CrypTFlow2 Performance Tradeoffs

Abstract: We present secure MPC for transformer inference, covering FSS via DPF for ReLU/GELU, Beaver triple preprocessing with silent OT, mixed arithmetic-binary sharing for Softmax, and GPU-accelerated MPC with CrypTen and CrypTFlow2 tradeoffs. Transformer inference requires private evaluation of attention Softmax, LayerNorm, and GELU. DPF enables FSS for point functions f_a,b(x)=b if x=a else 0, evaluating ReLU via DPF comparison with 2^20 domain in 12ms. Beaver triples (a,b,c=a*b) preprocessed via silent OT extension reduce communication 60% vs IKNP OT. Mixed arithmetic-binary sharing converts arithmetic shares to binary for Softmax exp via 13 rounds 6,656 bits, achieving 23 rounds 6,784 bits total for approximate Softmax. CrypTen PyTorch-style tensor MPC uses GPU offload with 8xH100 achieving 412 TFLOP/s per GPU but 1.8x communication overhead. Seven real sources including CrypTen and SecFormer anchor claims. Evaluation on BERT-Base 110M with 512 tokens shows SecFormer 68% faster than CrypTen with 1.2% accuracy drop, 2.3s vs 7.1s. Statistical validation 95% CI ±0.12s. Limitations include DPF key size 2KB per function, Beaver triple storage 12GB for 1T params, and GPU MPC trust model requiring semi-honest.
