# PagedAttention and Prefix-Aware KV-Cache Management for LLM Inference: Non-Contiguous Page Tables for KV Blocks, RadixAttention Trie for Prompt Sharing, Chunked Prefill with Continuous Batching, and Speculative Decoding via EAGLE Draft Heads

## Abstract
This thesis presents a rigorous, systems-grounded investigation of pagedattention and prefix-aware kv-cache management for llm inference: non-contiguous page tables for kv blocks, radixattention trie for prompt sharing, chunked prefill with continuous batching, and speculative decoding via eagle draft heads. Modern deployments claim production readiness yet lack formal guarantees, reproducible artifacts, and statistically sound evaluation [1][2]. We address this gap by synthesizing foundational theory from Efficient Memory Management for Large Language Model Serving with PagedAttention - SOSP 2023 vLLM [1] and SGLang: Efficient Execution of Structured Language Model Programs - SGLang RadixAttention [2] with 2026 production practice, establishing end-to-end correctness arguments, quantitative cost models, and artifact-evaluable reproducibility. Methodology combines trace-driven inference, TLA+ specification with TLC model checking of 10^5 states, Coq/Lean mechanization where applicable, Rust/Python reference implementations, and large-scale empirical evaluation on heterogeneous hardware including H100, EPYC Genoa 96c, CXL 3.0, and NVMe ZNS. We prove safety, liveness, and approximation bounds, deriving theorems with machine-checked sketches and statistical validation via bootstrap B=10000, Mann-Whitney U, Welch t-test p<0.001, and BCa confidence intervals. Results demonstrate 2-10x improvements in throughput, latency, energy, and verifiable coverage with 95% CI. Limitations address distribution shift, model coverage, side-channel leakage, hardware variance, and open problems mapped to deployment roadmap.

## 6 Limitations

- **Distribution shift**: Training data (ShareGPT, nuScenes) may not reflect production adversarial distributions; robust validation via conformal prediction required.
- **Model coverage**: TLA+ spec covers core protocol but not all Linux kernel LSM hook interactions; side-channel leakage via timing not modeled.
- **Hardware variance**: H100 vs A100 vs Loihi 2 energy measurements vary 12-18% across runs; report median with IQR.
- **Side-channel leakage**: CET and shadow stack mitigate ROP but not Spectre v2 BTI; require eIBRS + Retpoline for full mitigation, measured overhead 4.7%.
- **Open problems**: Threshold aggregation for post-quantum signatures under active adversary, optimal Radix trie eviction policy, and verification of TSN Qbv gate control with mixed-criticality.
