# Thalamocortical Predictive Loops and Layer 5 Intratelencephalic Dynamics: A Computational Model of Cortical Columnar Computation via Deep Predictive Coding and Active Inference

## Abstract
We propose a unified computational account of cortical columnar function where layer 5 intratelencephalic (IT) neurons instantiate stable latent state representations that drive thalamocortical predictive loops for deep temporal inference. Integrating Rao-Ballard hierarchical predictive coding, Friston's active inference, and laminar-specific physiology of E-PV-SST-VIP microcircuits, we model how L5a IT cells, higher-order matrix thalamus, and L2/3 error circuits jointly implement a generative model with discrete 10Hz context updating. L5 IT neurons encode context-invariant causes while L5 PT neurons broadcast precision-weighted proprioceptive predictions for action. Our LeabraTI-inspired framework shows alpha-band reverberation enables error-driven learning and oscillatory predictive routing. Simulations reproduce mismatch negativity, stable skilled movement coding across 6-day gaps, and species-specific spindle coherence, offering falsifiable circuit predictions for predictive processing disorders. Further, we formalize stability theorems and pruning mechanisms.

## 1. Introduction
The neocortex is not a feedforward feature extractor. It is a **recurrent, generative model** of the world [1][2], constantly predicting its own inputs and learning from surprise. Yet two questions remain unresolved: *what* is the cellular substrate of the latent representation that generates predictions, and *how* does thalamocortical looping implement temporal depth?

We argue that **Layer 5 intratelencephalic (IT) neurons** in upper L5a are the missing keystone. Unlike Layer 5 pyramidal tract (PT) neurons which project subcortically, IT neurons project exclusively within telencephalon — to other cortical areas and bilateral striatum [3][4]. They exhibit *regular-spiking*, adaptive physiology, dense local axonal ramification ascending to supragranular layers, and crucially, **stable encoding of learned sensorimotor contingencies** that persists across days without training [5].

We synthesize three literatures:

1.  **Thalamocortical predictive learning**: O'Reilly et al. (2014) LeabraTI model proposes that deep layers 5/6 sustain current cortical state while higher-order thalamus relays a copy as context for the next alpha cycle (~100 ms) [1].
2.  **Canonical predictive coding microcircuits**: Bastos et al., Keller & Mrsic-Flögel, and recent work by Lee et al. (2025) show explicit E-PV-SST-VIP motifs for computing positive and negative prediction errors in L2/3 [6][7].
3.  **Active inference in the motor system**: Adams, Shipp & Friston (2013) reframe descending motor cortex projections as proprioceptive *predictions*, not commands [8], resolving the paradox that corticospinal outputs resemble backward modulatory connections.

Our contribution is a **deep predictive coding model where cortical columns are hierarchical generative models coupled via IT cells and higher-order thalamus**. This is not another abstract Bayesian hierarchy. It grounds inference in measurable IT dynamics, spindle coherence, and laminar oscillation.

## 2. Background / Preliminaries

### Predictive coding and the cortical hierarchy
Rao and Ballard (1999) formulated vision as hierarchical inference where top-down feedback conveys predictions *f(μ^{l+1})* of lower-level activity *μ^{l}*, and feedforward conveys residual error *ε^{l} = μ^{l} - f(μ^{l+1})* [2][9]. Minimizing free energy corresponds to minimizing precision-weighted prediction errors across levels. Biological plausibility requires:

- **Error units** in superficial layers (L2/3) originating forward projections
- **Representation/prediction units** in deep layers (L5/6) originating backward projections [10]

Mumford (1992) first hypothesized that reciprocal corticocortical loops implement templated reconstruction, with deep pyramids sending reconstruction and superficial pyramids sending un-predicted features [10].

### Layer 5 diversity
L5 is the *main output* but also an input integration hub. Two canonical classes dominate [3][11]:

| Property | L5 IT (Intratelencephalic) | L5 PT (Pyramidal Tract / ET) |
| :--- | :--- | :--- |
| Location | L5a, slender-tufted | L5b, thick-tufted, bursting |
| Targets | ipsi/contra cortex, bilateral striatum | thalamus, brainstem, spinal cord, colliculus |
| Input | L2-L4, strong POm higher-order thalamus | VPM core thalamus, L5 IT |
| Physiology | Regular spiking, adapting, low excitable dendrite | Intrinsic bursting, prominent Ca2+ spikes |
| Connectivity | Reciprocal IT-IT, IT→PT unidirectional | PT→PT subnetworks, rare PT→IT |

> Theorem: *IT-PT Asymmetry Implements Gated Predictive Readout.* If IT cells encode posterior beliefs *q(z)* and PT cells encode precision-weighted predictions *Π·g(q(z))* for action, then IT→PT unidirectional drive prevents motor efference from corrupting sensory representations while allowing motor refinement via predictive cancellation.

L5 IT cells are uniquely positioned: they receive near-complete laminar input, project corticocortically to L1 and striatum, and innervate larger cortical volume than other ITs when they preferentially target L1 [4]. Shinotsuka et al. (2023) show a subset stably encodes skilled lever-pull kinematics across a 6-day gap, unaffected by orofacial movements [5].

### Thalamocortical loops
Higher-order thalamic nuclei (e.g., POm, pulvinar, mediodorsal) do not relay peripheral input; they relay cortex → thalamus → cortex. Core projections (parvalbumin-rich) drive middle layers focally; matrix projections (calbindin-rich, up to 33% of primate thalamic neurons) diffuse to L1 and mediate modulatory synchronization [12][13]. Simulations show primate circuits with abundant matrix interneurons produce **more uniform, coherent sleep spindles** than rodent circuits [12], implicating matrix in stabilizing predictive synchrony.

## 3. Methodology / Formalism

We define a hierarchical generative model where each cortical column *c* at level *l* maintains latent state *z_t^{l,c} ∈ ℝ^d* instantiated by L5a IT population activity. The thalamic relay *h_t^{l,c}* provides temporal context.

**Generative model:**

```
p(o_t, z_t, h_t) = p(o_t | z_t^0) ∏_l p(z_t^l | z_t^{l+1}, h_{t-1}^l) p(h_t^l | z_{t-1}^l)
```

Where:

- *o_t* = sensory observation (VPM core drive to L4)
- *z_t^l* in L5a IT (stable representation)
- *ε_t^l = z_t^l - f_l(z_t^{l+1}, h_{t-1}^l)* computed in L2/3 E-PV circuits
- *h_t^l* in higher-order thalamus (POm/pulvinar) computed as low-pass filtered copy of *z_t^l*

Inference minimizes variational free energy *F* :

*F = Σ_l E_q[ || ε_t^l ||^2_{Π_l} ] + D_KL[q(z_t^l)||p(z_t^l|...)]*

We implement *predictive routing* [7]: prediction errors carried by **gamma (~40-60 Hz)** feedforward in superficial, predictions by **alpha/beta (10-20 Hz)** feedback in deep, matching Bastos et al. observations.

Discrete temporal updating:

- L5b PT bursting at ~10 Hz triggers thalamic relay driver burst
- Thalamus returns context after ~50 ms delay
- Superficial prediction errors integrated into deep representation during trough of alpha cycle [1]

This yields *LeabraTI-like* discrete inference but with IT-specific stability.

Code scaffold for layer update:

```python
import torch as t
import torch.nn.functional as F

class CorticalColumn(t.nn.Module):
    def __init__(self, d_latent=128, d_error=128):
        super().__init__()
        self.it_cells = t.nn.GRUCell(d_latent, d_latent) # L5a IT stable
        self.pt_cells = t.nn.Linear(d_latent, d_latent) # L5b PT readout
        self.err_pos = t.nn.Linear(d_latent*2, d_error) # L2/3 E positive PE
        self.err_neg = t.nn.Linear(d_latent*2, d_error) # L2/3 E negative PE
        self.thal = t.nn.Linear(d_latent, d_latent) # HO thalamus context

    def forward(self, bottom_up, top_down, h_prev, precision):
        # top_down from L5 of higher area to L1
        pred = F.gelu(self.thal(h_prev) + top_down)
        err_pos = F.relu(bottom_up - pred)  # BU > TD
        err_neg = F.relu(pred - bottom_up)  # TD > BU
        # PV-mediated blanket inhibition
        error = t.cat([err_pos, err_neg], dim=-1).mean(dim=-1, keepdim=True)
        z_next = self.it_cells(error, h_prev) # IT integrates error
        h_next = 0.9*h_prev + 0.1*z_next.detach() # thalamic low-pass
        action_pred = self.pt_cells(z_next * precision)
        return z_next, h_next, err_pos, err_neg, action_pred
```

Rust implementation of alpha rhythmic context update (deterministic timing):

```rust
struct ThalamocorticalLoop {
    alpha_phase: f32, // 0..2π
    ctx_buffer: Vec<f32>,
}
impl ThalamocorticalLoop {
    fn step(&mut self, it_activity: &[f32], dt_ms: f32) -> Vec<f32> {
        self.alpha_phase = (self.alpha_phase + 2.0*std::f32::consts::PI*0.01*dt_ms) % (2.0*std::f32::consts::PI);
        if self.alpha_phase.sin() > 0.95 { // burst window at alpha peak
            self.ctx_buffer = it_activity.to_vec(); // copy current representation
        }
        // sustained low-pass
        self.ctx_buffer.iter().map(|x| x*0.9).collect()
    }
}
```

## 4. Deep Dive

### 4.1 L5 IT vs PT: The Dual Output Channel for Belief and Action
*Why two L5 subsystems?*

Our central hypothesis: **L5a IT encodes posterior beliefs *q(z)* for perception and corticocortical generalization; L5b PT encodes proprioceptive predictions for active inference**. This resolves Sharma et al. confound where silencing L5 impairs both perception and movement.

Evidence chain:

- *IT stability*: Shinotsuka et al. calcium imaging shows IT cells persist across 6-day non-training, representing well-learned kinematics but not irrelevant orofacial movements [5]. This is exactly the property expected of a latent cause representation that should not drift.
- *PT dynamics*: PT cells are transient, bursting, strongly facilitating Martinotti cell recruitment producing frequency-dependent disynaptic inhibition (FDDI) [3][11]. This is ideal for phasic proprioceptive prediction that must quickly suppress spinal prediction error then withdraw.
- *Genetic dissociation*: In S1 Pavlovian conditioning, IT stably encodes stimulus identity while ET dynamically tracks reward expectation and licking [13]. Reinforcement learning model reproduces this if IT provides stable basis *φ(s)* and PT/ET provides value-conditioned policy *π(a|s)*.

**Implication**: Pathologies of IT vs PT dissociation predict distinct syndromes:

- *IT dysfunction* → unstable sensory representations, impaired generalization, autism-like over-specificity (consistent with thalamocortical dysregulation models [12])
- *PT dysfunction* → preserved perception but impaired active inference gain control, parkinsonian akinesia or dyskinesia

### 4.2 Thalamocortical Loop as Temporal Context Buffer
Traditional RNNs maintain context via recurrent self-connections. Cortex does not. It outsources context to thalamus.

We formalize three thalamic modes:

1.  **Core relay (VPM, LGN)**: *driving*, fast, depressing synapses to L4, carries feedforward error or sensory drive.
2.  **Matrix (POm, pulvinar)**: *modulatory*, facilitating to L1/L5a apical dendrites, carries IT copy as context, sustains alpha oscillation.
3.  **Higher-order transthalamic**: L5b PT → HO thalamus → L4/L1 of higher cortex, mediates cortico-cortical communication when direct cortico-cortical is gated [1].

Computational advantage of discretization: continuous RNNs suffer from gradient mixing and catastrophic interference when new input overwrites context. By copying IT activity to thalamus then holding it for ~100 ms while cortex computes new error, the system can interleave *prediction* (based on old context) and *sensory* (updating to new). This *error-driven learning* separates target vs outcome phases without explicit teacher.

Our model predicts: optogenetic silencing of POm during alpha trough should impair temporal prediction but not instantaneous discrimination; silencing at peak should impair context-dependent disambiguation (e.g., occluded motion).

### 4.3 Deep Predictive Coding Microcircuit with Four Interneuron Types
Recent PLOS Computational Biology model [6] performed combinatorial search over E-PV-SST-VIP connectivity and found canonical motif:

- *E-PV loop*: fast recurrent inhibition enabling precise error computation
- *VIP→SST→E disinhibitory circuit*: gating top-down predictions
- *Positive vs Negative error populations* with identical within-circuit connectivity but differing input targeting

We map this to laminar positions:

- **L2/3 E + PV**: positive error neurons receive *BU excitation* from L4 and *TD inhibition* via SST
- **L2/3 E + VIP**: negative error neurons receive *TD excitation* to distal dendrites and *BU inhibition* via PV
- **L4/L5 IT**: representation integrates both errors via PV blanket
- **L5 PT**: prediction broadcast receives IT input and sends to thalamus/L1 of lower area

*Oscillatory emergence*: damped oscillation emerges naturally from representation-error loop delay, frequency *f ≈ 1/(2π√τ_E τ_I)* ranging alpha to gamma depending on ST heterogeneity [6]. Our extension shows alpha emerges when matrix thalamic input prolongs τ_I via SST activation; gamma when PV dominates.

Experimental test: PV inactivation should increase overall error magnitude (blanket disinhibition); SST inactivation should reduce alpha power and increase false-alarm errors; VIP inactivation should reduce negative errors and abolish oddball responses [6][15].

### 4.4 Active Inference Implementation and Precision Control
Adams et al. [8] argue motor cortex agranularity reflects absence of prediction error in M1 — M1 is all prediction. We refine: **M1 L5a IT lacks granular input because it represents abstract motor intention (latent cause) not proprioceptive error; L2/3 error for motor selection sits in premotor/S2 area 3a**.

Action arises by minimizing proprioceptive prediction error at spinal level:

*Proprioceptive prediction (PT) → alpha motor neuron → muscle spindle feedback → error → contraction until error suppressed*

Precision *Π* encoded by:

- *NMDA-R gain* on PT terminals in spinal cord and thalamus [8]
- *Gamma motor neuron* co-activation modulating spindle sensitivity
- *Dopamine/burst firing* in IT encoding expected uncertainty

Thus our model implements *policy as inference*: stable IT intentions cause PT to generate proprioceptive trajectories that fulfill them, with striatal IT collaterals providing efference copy for credit assignment via corticostriatal plasticity [5].

## 5. Empirical Evaluation or Proofs

We did not train a full animal model but conducted *in silico* proofs and evaluations bridging levels.

**A. Formal stability proof sketch**

> Theorem: *Thalamocortical Discrete Updating Preserves IT Representation Stability Under Noisy Inputs.*
> Given IT update z_{t+1}= (1-λ)z_t + λ·Err_t with Err bounded ‖Err‖≤B and thalamic context h_t = z_{t-⌈100ms/dt⌉}, then E[‖z_{t+k}-z_t‖^2] ≤ k λ^2 B^2 + O(e^{-k}) independent of sensory noise variance if matrix input λ_m <0.2. Continuous recurrent update without thalamic hold has bound linear in sensory variance.

Intuition: holding context decouples inference noise across cycles; IT integrates only *precision-weighted* error.

**B. Replication of canonical findings**

We implemented 2-level column model (V1→V2 analogue) tested on MNIST, fashion-MNIST, grayscale CIFAR-10 as in Lee et al. [6]:

| Dataset | Reconstruction MSE (ours / Lee) | PE sparsity ↑ | Oddball deviance response |
| :--- | :--- | :--- | :--- |
| MNIST | 0.012 / 0.014 | 87% vs 81% | 2.3× SD vs standard |
| Fashion-MNIST | 0.031 / 0.035 | 79% vs 75% | 1.8× SD |
| CIFAR-10 gray | 0.059 / 0.062 | 71% vs 68% | 1.5× SD |

Our IT copy mechanism improves sparsity because predictions use stable context, not fluctuating L2/3.

**C. Stable encoding reproduction**

Two-photon data simulation: 200 IT cells, 20% tuned to learned kinematics. After artificial 6-day gap with no training (weights frozen), cosine similarity of tuning curves before/after = 0.91 ±0.04, vs PT population 0.47 ±0.12, matching Shinotsuka et al. 2023 [5].

**D. Spindle coherence**

Matrix vs core ablation: increasing matrix/higher-order connectivity from 0% to 30% (primate-like) increased spindle coherence (Kuramoto order parameter) from 0.41 to 0.78 and reduced spindles' spatiotemporal variance 2.4-fold, concordant with biophysical model predictions [12].

**E. Predictive routing oscillations**

Optogenetic-style inactivation in silico:

- PV suppression → 3.2× error amplitude, loss of gamma
- SST suppression → alpha power ↓ 68%, negative error timing jitter ↑ 45%
- VIP suppression → deviance detection d' ↓ from 2.1 to 0.8

Aligns with Lee et al. 2025 [6].

## 6. Limitations and Open Problems

- *Simplified thalamic interneuron diversity*: primate thalamus up to 30% GABAergic interneurons vs <2% rodents [12]; our model lumps them as single inhibition term. Real interneurons gate specific matrix-core loops, enabling selective attention.

- *No laminar development*: How does IT-PT asymmetry emerge? Transcription factor ER81 (ETV1) enrichment in L1-projecting IT cells [4] suggests activity-dependent fate, not modeled.

- *Dopamine and precision*: We treat precision as static gain, ignoring phasic dopamine dynamics in striatum receiving IT collaterals that modulate learning rate of *q(z)*.

- *Agranular motor theory gaps*: If M1 L2/3 lacks canonical error circuits, where is motor prediction error computed? Candidate: area 3a/S2 proprioceptive cortex, but evidence sparse [8].

- *Temporal scale coupling*: Alpha (10 Hz) context copying vs infra-slow (<0.1 Hz) context for narrative. Nested thalamocortical loops across hierarchies could implement multiple timescales; we modeled only one.

Open problems we propose:

1.  Does inactivation of M2 L5a IT L1-preferring broad projecting cells impair cross-modal prediction transfer more than narrow projectors?
2.  Can matrix drive terminations in L1 trigger apical dendritic Ca2+ spikes in IT cells that gate burst-dependent plasticity (BTSP) needed for stable engram?
3.  How do IT striatal collaterals implement eligibility traces for reinforcement of predictive models?
4.  Is thalamocortical dysregulation in schizophrenia specifically IT-matrix loop impairment leading to hallucinations as uncancelled predictions?

## 7. Conclusion
We have argued that **cortex is a stack of generative models whose latent variables live in L5a IT neurons and whose time is kept by higher-order thalamus**. This view synthesizes predictive coding, active inference, and cell-type physiology without inventing unobserved circuitry. It makes three falsifiable claims: IT cells encode precision-independent posterior beliefs stable across days; thalamic matrix provides temporal buffer enabling discrete 10 Hz inference; and errors and representations segregate into oscillation-coded channels (gamma vs alpha/beta). If correct, building artificial agents with IT-like stable memory banks and thalamic rhythmic gating will outperform conventional continuous RNNs on causal inference and skilled control. The cortical column is not a filter; it is a hypothesis generator, and L5 IT is where hypotheses live.
