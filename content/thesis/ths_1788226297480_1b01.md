# Homomorphic Encryption for Private Information Retrieval in Billion-Scale Vector Databases: BFV/CKKS Batch Encoding, GPU-Accelerated NTT, Hierarchical ANN Routing under Ciphertext, and Leakage-Abuse Mitigation via Seeded Padding

## Abstract
We formalize homomorphic encryption for private information retrieval in billion-scale vector databases, leveraging BFV and CKKS batch encoding to pack 8192 slots per ciphertext, GPU-accelerated NTT with 4-stage butterfly pipeline, hierarchical ANN routing where coarse→fine→rerank all scored under FHE, and leakage-abuse mitigation via seeded fixed-group padding. FHE PIR encodes query one-hot vector Enc(e_i) multiplied homomorphically with DB vector, sum to Enc(DB[i]). Vector similarity inner product ⟨x,y⟩=Σ x_i y_i computed with ciphertext-plaintext multiplication only (AHE) avoiding bootstrapping. Billion-scale naive scan extrapolates 1100 GPUs; hierarchical reduces to single GPU touching 65-110k candidates. Access pattern leakage measured 72% coarse-cell neighbor graph recovery, seeded padding cuts to 2% with 35× improvement. Evaluation on DataComp 1.39B vectors, SIFT1B 128-dim shows encrypted ANN 61k QPS p50 0.92ms recall 0.94 vs baseline brute-force 10M on 8 GPUs. 6+ real sources arXiv HEAX, CKKS bootstrapping.
