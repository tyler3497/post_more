# Private Set Intersection at Billion-Scale via Secure Multi-Party Computation: OPPRF, Cuckoo Hashing, Circuit-PSI, and Malicious Security with VOLE and Silent OT ## Abstract We present billion-scale private set intersection via MPC, unifying OPPRF (oblivious programmable PRF), cuckoo hashing with 3 hash functions and stash size 2, circuit-PSI via half-gates garbling, and malicious security via VOLE and silent OT extension.
